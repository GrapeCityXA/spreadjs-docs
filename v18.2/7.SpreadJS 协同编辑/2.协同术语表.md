# glossary

| **名词** | **描述** |
| --- | --- |
| apply | **应用** 指的是执行或实施更改或操作以更新共享数据的过程，确保修改在所有参与者之间都能得到反映。 |
| auto connection | **自动连接** 指客户端与服务器之间自动建立或重新建立连接的过程，以确保即使在中断后也能实现无缝的实时交互。 |
| bidirectional communication | **双向通信** 指信息交换过程中双方都能发送和接收数据，从而实现实时的双向交互。 |
| broadcasting | **广播** 是将用户的更改或操作实时发送给所有其他参与者的过程，以确保共享更新和一致性。 |
| connection | **连接** 指客户端与服务器之间的活跃链接，用于实现实时通信、数据同步和更新共享。 |
| crdt | **CRDT（无冲突复制数据类型）** 是一种数据结构，允许在多个设备上并发进行无冲突的分布式更新，确保最终一致性而不会产生冲突。 |
| data consistency | 在协同场景中，**数据一致性** 确保所有参与者都能看到相同、准确且最新的共享数据版本，尽管存在并发编辑或更改。 |
| doc | 在协同中，**doc（文档）** 表示共享数据模型或文档，用于在用户之间同步实时更改，确保所有参与者之间的一致性。 |
| heartbeat | **心跳** 是客户端与服务器之间定期发送的信号，用于指示连接活跃并监控系统的实时健康状态。 |
| hook | **钩子** 是一个可自定义的函数或回调，允许开发人员在协同过程中的关键事件期间执行特定操作或扩展功能。 |
| message | **消息** 指参与者之间交换的数据或信息，通常包含更新、操作或命令，用于实时同步和协调更改。 |
| middleware | **中间件** 是一层管理客户端与服务器之间数据处理、同步和通信的组件，确保流畅的实时交互。 |
| op | **Op（操作）** 描述对模型的原子操作，例如对共享数据执行的编辑或更新，这些操作需要在所有参与者之间进行同步。 |
| ot | **OT（操作转换）** 是一种用于解决冲突并同步多个用户并发更改的技术，确保在实时协同环境中的数据一致性。 |
| permission | **权限** 指访问控制设置，用于定义用户在共享文档或资源上被允许执行的操作或更改。 |
| postgre | **PostgreSQL** 是一种开源的对象关系型数据库管理系统，以其稳健性、可扩展性以及对高级 SQL 功能（如事务、并发和复杂查询）的支持而闻名。 |
| presence | 协同中的**在线状态** 指用户在共享环境中的实时在线状态、操作和编辑位置的可见性。它有助于识别谁处于活跃状态、他们在何处工作以及当前活动，从而增强透明度和协调性。 |
| room | 在协同中，**房间** 是一个虚拟空间，将用户分组在一起，以便在特定上下文或任务中实现实时数据共享、同步和交互。 |
| snapshot | **快照** 指共享数据在特定时间点的已保存状态，可用于恢复或比较协同过程中所做的更改。 |
| sqlite | **SQLite** 是一种轻量级、自包含、无服务器的数据库引擎，专为嵌入式系统设计，使用单个文件提供可靠的零配置存储。 |
| transform | **转换** 指修改或调整操作或更改的过程，以在多个用户并发编辑共享数据时保持一致性。 |
| transmission | **传输** 指在客户端和服务器之间发送数据、更新或消息的过程，以确保实时同步和通信。 |
