# server-connection-class

[Connection ](gcdocsite__documentlink?toc-item-id=464e75e4-bb2c-4163-8997-3a576676fe36)类代表服务器和客户端实例之间的双向通信通道，支持发送和接收消息、广播以及事件管理。当客户端连接时，服务器会创建一个 `Connection` 对象，用于管理与特定客户端的通信。服务器通过中间件和钩子访问此对象。

## 属性

**id**: 连接的唯一标识符（字符串）。

```typescript
console.log(connection.id); // "XBtqzsRMPh7MaVvaAAAB"
```

**roomId**: 连接所属房间的 ID（字符串）。**query**: 客户端连接时提供的查询参数（键值对对象）。**auth**: 客户端的认证数据（键值对对象）。**tags**: 用于存储自定义数据的 Map。

```typescript
connection.tags.set('role', 'admin');
```

## 方法

### send

使用 `send` 方法向服务器发送消息。

```typescript
send(data: MessageData, type?: MessageType): void;
```

**参数**

* `data`: 要发送的数据。
* `type`（可选）: 消息类型，用于标识消息的用途或类别。

### broadcast

使用 `broadcast()` 方法向同房间的客户端广播消息。

```typescript
broadcast(data: MessageData, type?: MessageType, includeSelf?: boolean): void;
```

**参数**

* `data`: 要发送的消息内容。
* `type`: 消息类型，默认为空字符串。
* `includeSelf`（可选）: 若设为 `true`，房间内所有客户端（包括当前连接）都会收到消息。

**示例**

* 向同房间所有客户端广播消息（不包括发送者）：

```typescript
connection.broadcast('hello, client!');
```

* 向同房间所有客户端广播消息（包括发送者）：

```typescript
connection.broadcast('hello, client!', '', true);
```

### close

使用 `close` 方法关闭与客户端的连接。

```typescript
connection.close();
```

此方法会终止当前与客户端的连接并清理相关资源。
