# authentication

本教程将指导开发者修改服务端和客户端代码，以实现认证和权限管理功能。您将学习：

* 使用用户名和密码登录获取令牌
* 使用令牌加入聊天室
* 基于角色权限（管理员、成员、访客）发送消息

## 第一步：修改服务端以支持认证

我们将在服务端添加登录路由和认证中间件，确保只有经过认证的用户才能加入聊天室，并基于角色权限控制消息发送。
**更新** `server.js`，将 `server.js` 原始内容替换为以下代码：

```javascript
import express from "express";
import { createServer } from "http";
import { Server } from "@grapecity-software/js-collaboration";
import jwt from "jsonwebtoken";

const app = express();
const httpServer = createServer(app);
const server = new Server({ httpServer });

app.use(express.static("public"));
app.use(express.json());

// JWT 密钥
const JWT_SECRET = "your-secret-key-here";

// 模拟用户数据库
const users = new Map([
  ["admin1", { username: "admin1", password: "admin123", role: "admin" }],
  ["member1", { username: "member1", password: "member123", role: "member" }],
  ["guest1", { username: "guest1", password: "guest123", role: "guest" }],
]);

// 登录路由
app.post("/login", (req, res) => {
  const { username, password } = req.body;
  const user = users.get(username);
  if (!user || user.password !== password) {
    return res.status(401).json({ success: false, message: "用户名或密码无效" });
  }
  const token = jwt.sign({ username: user.username, role: user.role }, JWT_SECRET);
  res.json({ success: true, token, user: { username: user.username, role: user.role } });
});

// 认证中间件
server.use("connect", async (context, next) => {
  const token = context.connection.auth?.token;
  if (!token) return await next("未提供令牌");
  try {
    const decoded = jwt.verify(token, JWT_SECRET);
    context.connection.tags.set("user", { username: decoded.username, role: decoded.role });
    await next();
  } catch {
    await next("令牌无效");
  }
});

// 消息权限验证中间件
server.use("message", async ({ connection }, next) => {
  const user = connection.tags.get("user");
  if (user.role === "admin" || user.role === "member") await next();
  else await next("无发送消息权限");
});

// 事件处理器
server.on("connect", ({ connection }) => {
  const user = connection.tags.get("user");
  console.log(`${user.username} 加入房间`);
  connection.broadcast(`${user.username} 加入了聊天室`, "", true);
});

server.on("message", ({ connection, data }) => {
  const user = connection.tags.get("user");
  console.log(`收到来自 ${user.username} 的消息: ${data}`);
  connection.broadcast(`${user.username}: ${data}`, "", true);
});

server.on("disconnect", ({ connection }) => {
  const user = connection.tags.get("user");
  console.log(`${user.username} 离开房间`);
  connection.broadcast(`${user.username} 离开了聊天室`, "", true);
});

httpServer.listen(8080, () => {
  console.log("服务器运行在 http://localhost:8080");
});
```

**代码说明**

* **角色定义**：
    * admin：最高权限，可发送消息并管理聊天室
    * member：普通用户，可收发消息
    * guest：仅能接收消息
* **认证机制**：通过 `/login` 路由获取令牌，`connect` 中间件验证令牌并存储用户信息
* **权限控制**：`message` 中间件限制 guest 用户发送消息

2. 更新 `public/client.js`替换为以下代码以添加登录和认证逻辑：

```javascript
import { Client } from "@grapecity-software/js-collaboration-client";

let connection = null;

window.login = async function () {
  const username = document.getElementById("username").value;
  const password = document.getElementById("password").value;
  try {
    const response = await fetch("http://localhost:8080/login", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ username, password }),
    });
    const result = await response.json();
    if (result.success) {
      connectToChat(result.token);
      document.getElementById("login").style.display = "none";
      document.getElementById("chat").style.display = "block";
      document.querySelector(".input-area").style.display = "flex";
    } else {
      alert(result.message);
    }
  } catch (error) {
    alert("登录失败: " + error.message);
  }
};

function connectToChat(token) {
  const client = new Client();
  connection = client.connect("chatroom", { auth: { token } });

  connection.on("message", (data) => {
    const chatDiv = document.getElementById("chat");
    const message = document.createElement("p");
    message.textContent = data;
    chatDiv.appendChild(message);
    chatDiv.scrollTop = chatDiv.scrollHeight;
  });

  connection.on("error", (error) => {
    alert("错误: " + error.message);
  });
}

window.sendMessage = function () {
  const input = document.getElementById("message");
  const message = input.value.trim();
  if (message && connection) {
    connection.send(message);
    input.value = "";
  }
};
```

**代码说明**

1. 登录流程：通过 `/login` 接口获取令牌，登录成功后连接聊天室
2. 界面控制：登录成功后显示聊天区域并隐藏登录表单
3. 消息发送：仅 admin 和 member 用户的消息会被服务端广播
