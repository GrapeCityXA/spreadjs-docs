# user-authentication-and-permissions

本指南将指导您在 `js-collaboration` 中实现**用户认证**和**消息权限验证**。通过**中间件**验证用户身份，并在接收消息时检查权限以决定是否允许操作。

## **概述**

`js-collaboration` 通过令牌验证实现安全认证，并实施消息级别的权限控制，确保：

* 仅通过认证的客户端可建立服务器连接。
* 消息处理权限通过策略强制实施。

**关键点**：

* **认证**：通过令牌验证用户身份，确保客户端为合法用户。
* **权限验证**：通过存储和检索用户信息实现消息权限控制。

> 本示例中的令牌验证和权限验证仅用于演示。在实际应用中，应基于业务需求实现更安全、复杂的验证机制。

## **工作流程**

### **客户端**

1. 用户登录并获取**令牌**。
2. 客户端通过 [client.connect()](gcdocsite__documentlink?toc-item-id=402e864f-93d6-42e2-8aed-59863d91e723#connect) 将**令牌**作为 **auth** 参数传递给服务器。
3. 服务器接收并验证**令牌**：认证成功则建立连接，否则返回认证失败消息。

### **服务器**

1. 服务器通过 [server.use() ](gcdocsite__documentlink?toc-item-id=c94e9589-dfdf-4066-af97-776d49d2506e#use)中间件检索并验证客户端传递的**令牌**。
2. 若认证成功，服务器将用户信息存储在 [connection.tags](gcdocsite__documentlink?toc-item-id=464e75e4-bb2c-4163-8997-3a576676fe36#tags) 中，并允许客户端执行后续操作（如发送消息）。
3. 若认证失败，服务器返回错误消息，客户端可接收该消息。

## **客户端：发送认证信息**

前端需在建立连接时将令牌作为 `auth` 参数传递给服务器。以下是客户端发送认证信息的示例：

```typescript
import { Client } from '@grapecity-software/js-collaboration-client';

// 模拟登录
async function login(username, password) {
    const response = await fetch('http://localhost:8080/login', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json'
        },
        body: JSON.stringify({ username, password })
    });
    const result = await response.json();
    if (result.success) {
        return result.token;
    } else {
        throw new Error(result.message);
    }
}

// 获取令牌
const userToken = await login('reader1', 'read123');

// 创建客户端实例并连接房间
const client = new Client('ws://localhost:8080');
const connection = client.connect('room123', {
    auth: {
        token: userToken
    }
});
```

**代码说明**

* 客户端将 `userToken` 作为 `auth` 参数传递给服务器进行认证。
* 服务器通过中间件验证令牌，并根据验证结果允许或拒绝连接。

## **服务器：认证与消息权限**

服务器端使用中间件验证客户端传递的令牌，并基于验证的用户信息执行相关操作：

* 在 `connect` 中间件中检索并验证客户端传递的令牌，将用户信息存储到 `connection.tags`。
* 在 `message` 中间件中从 `connection.tags` 检索用户信息，执行权限检查。

```typescript
import express from 'express';
import { createServer } from 'http';
import { Server } from '@grapecity-software/js-collaboration';
import jwt from 'jsonwebtoken';

const app = express();
const httpServer = createServer(app);
const server = new Server({ httpServer });

app.use(express.json());

// JWT 密钥
const JWT_SECRET = 'your-secret-key-here';

// 模拟用户数据库
const users = new Map([
    ['admin1', { username: 'admin1', password: 'admin123', role: 'admin' }],
    ['reader1', { username: 'reader1', password: 'reader123', role: 'reader' }],
    ['editor1', { username: 'editor1', password: 'editor123', role: 'editor' }]
]);

// 登录路由
app.post('/login', (req, res) => {
    const { username, password } = req.body;

    const user = users.get(username);
    if (!user || user.password !== password) {
        return res.status(401).json({
            success: false,
            message: '用户名或密码无效'
        });
    }

    const token = jwt.sign(
        { username: user.username, role: user.role },
        JWT_SECRET
    );

    res.json({
        success: true,
        token,
        user: { username: user.username, role: user.role }
    });
});

server.use('connect', async (context, next) => {
    const token = context.connection.auth?.token;

    if (!token) {
        await next('未提供令牌');
        return;
    }

    try {
        const decoded = jwt.verify(token, JWT_SECRET);
        const user = {
            username: decoded.username,
            role: decoded.role
        };
        context.connection.tags.set('user', user);
        console.log(`用户认证成功: ${user.username} (${user.role})`);
        await next();
    } catch {
        await next('令牌无效');
    }
});

server.use('message', async ({ connection }, next) => {
    const user = connection.tags.get('user');
    if (user.role === 'admin' || user.role === 'editor') {
        await next();
    } else {
        await next('无编辑权限');
    }
});

// 启动服务器
httpServer.listen(8080);
```

**代码说明**

* **认证验证**：在 `connect` 中间件中，通过 `context.connection.auth?.token` 检索客户端传递的令牌并验证。验证通过后，检索用户信息并存储到 `connection.tags`。
* **权限验证**：在 `message` 中间件中，通过 `context.connection.tags.get('user')` 检索存储的用户信息，基于用户角色执行消息权限验证。
