# connection-class

`Connection` 是 [Client ](gcdocsite__documentlink?toc-item-id=402e864f-93d6-42e2-8aed-59863d91e723)类的 [connect ](gcdocsite__documentlink?toc-item-id=402e864f-93d6-42e2-8aed-59863d91e723#connect)方法返回的对象，表示与服务器的双向连接。本指南将教您：

* 发送和接收消息
* 监听事件
* 管理连接

## 属性

### id

每个新连接都会分配一个随机的20字符标识符。
该标识符与服务端的值同步。

> 每次重连时此ID会重新生成。

```typescript
// 客户端
connection.on("connect", () => {
    console.log(connection.id); // 示例输出: XBtqzsRMPh7MaVvaAAAB
});
connection.on("disconnect", () => {
    console.log(connection.id); // undefined
});
```

```typescript
// 服务端
server.on("connect", ({ connection }) => {
    console.log(connection.id); // 示例输出: XBtqzsRMPh7MaVvaAAAB
});
```

### roomId

连接所属房间的ID。

```typescript
console.log('connection.roomId'); // 示例输出: "room1"
```

### connected

指示连接当前是否与服务器连接。

```typescript
connection.on("connect", () => {
    console.log(connection.connected); // true
});
connection.on("disconnect", () => {
    console.log(connection.connected); // false
});
```

## 方法

### send

使用 `send` 方法向服务器发送消息。

```typescript
connection.send('Hello, server!');
connection.send('Hello, server!', 'document');
connection.send({ userId: 'user1', active: true });
connection.send({ userId: 'user1', active: true }, 'my-presence');
```

**参数**

* `data`：要发送的数据。
* `type`（可选）：消息类型，用于标识消息的用途或类别。

**示例**

```javascript
// 发送文档更新
connection.send({ content: 'New paragraph' }, 'my-document');
// 发送在线状态
connection.send({ userId: 'user1', active: true }, 'my-presence');
// 接收并区分消息
connection.on('message', (data, type) => {
    if (type === 'my-document') {
        console.log('Document update:', data);
    } else if (type === 'my-presence') {
        console.log('Status update:', data);
    }
});
```

### close

使用 `close` 方法关闭连接。

```javascript
connection.close();
```

### on

添加事件监听器。

```javascript
connection.on('connect', () => {
    console.log('Connected to the server');
});
connection.on('message', (data, type) => {
    console.log('Received message:', data, 'Type:', type);
});
```

### once

添加一次性监听器，触发后自动移除。

```javascript
connection.once('reconnect', (attempts) => {
    console.log(`Reconnection attempt #${attempts}`);
});
```

### off

移除事件监听器。

```javascript
const handler = () => console.log('Error occurred');
connection.on('error', handler);
connection.off('error', handler);
```

## 事件

#### 支持的事件

| 事件名称 | 描述 | 参数 |
| ---- | --- | --- |
| `connect` | 连接建立时触发 | 无 |
| `message` | 收到消息时触发 | `data`（消息内容）, `type`（消息类型） |
| `disconnect` | 连接断开时触发 | `reason`（断开原因将在下表详细说明） |
| `error` | 发生错误时触发 | `error`（错误对象） |
| `reconnectAttempts` | 重连尝试期间触发 | `attempts`（尝试次数） |
| `reconnect` | 重连成功时触发 | `attempts`（重试次数） |
| `reconnectFailed` | 重连失败时触发 | 无 |

#### 断开原因

下表列出了 `disconnect` 事件的断开原因。

| 值 | 描述 |
| --- | --- |
| `CLIENT_DISCONNECT` | 客户端主动断开 |
| `SERVER_DISCONNECT` | 服务器主动断开 |
| `PING_TIMEOUT` | 客户端未能及时响应ping |
| `TRANSPORT_CLOSE` | 传输层连接关闭 |
| `TRANSPORT_ERROR` | 传输层发生错误 |
