# presence-server

**服务器端的 Presence** 需要协调和广播所有客户端的 Presence 数据，确保协同房间内的用户状态信息实时同步。[presenceFeature ](gcdocsite__documentlink?toc-item-id=59f968ab-0464-4276-9c32-480234123766#presencefeature)方法提供以下主要功能：

* **状态广播**：接收客户端提交的状态，并通过服务器广播给其他客户端。
* **状态管理**：维护当前房间内所有用户的最新状态。

## API

### presenceFeature

在服务器端启用 Presence 功能。

```typescript
export declare function presenceFeature(): IFeature
```

**返回**`IFeature`：包含中间件（Middleware）和钩子（Hook）的功能对象。

## 使用方法

### 1\. 安装 NPM 包

```bash
npm install @grapecity-software/js-collaboration @grapecity-software/js-collaboration-presence
```

### 2\. 向服务器注册 Presence

```typescript
import { presenceFeature } from '@grapecity-software/js-collaboration-presence';

server.useFeature(presenceFeature());
```

### 完整示例

```typescript
import { createServer } from 'http';
import { Server } from 'js-collaboration';
import * as OT from 'js-collaboration-ot';
import { presenceFeature } from 'js-collaboration-presence';

OT.types.register(type);

const httpServer = createServer();
const server = new Server({ httpServer });

server.useFeature(OT.documentFeature());
server.useFeature(presenceFeature());

httpServer.listen(8080);
```
