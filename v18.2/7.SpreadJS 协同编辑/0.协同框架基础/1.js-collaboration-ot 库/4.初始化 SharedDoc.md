# initalizing-shareddoc

`js-collaboration-ot-client` 提供客户端 API，支持开发者连接服务器并创建共享文档（[SharedDoc](gcdocsite__documentlink?toc-item-id=9e659419-beff-4587-9334-629c91cea5e8)），实现实时协同编辑功能。本文将介绍客户端的初始化流程，包括：

* 安装依赖
* 配置连接
* 创建文档实例

## 安装

通过 npm 安装所需依赖包：

```bash
npm install @grapecity-software/js-collaboration-client @grapecity-software/js-collaboration-ot-client
```

* `js-collaboration-client`：提供 [Client ](gcdocsite__documentlink?toc-item-id=402e864f-93d6-42e2-8aed-59863d91e723)和 [Connection ](gcdocsite__documentlink?toc-item-id=01f01f56-2c37-4f99-b868-ac32e2c7e57b)类，用于建立与服务器的连接。
* `js-collaboration-ot-client`：提供 OT 功能及 [SharedDoc](gcdocsite__documentlink?toc-item-id=9e659419-beff-4587-9334-629c91cea5e8) 类。

## 初始化

### 1\. 注册 OT 类型

注册 [OT 类型](gcdocsite__documentlink?toc-item-id=89953b53-e259-4a92-a91d-aa7805748d7e) 以定义操作行为。以下是注册简单文本类型的示例：

```typescript
import { TypesManager } from '@grapecity-software/js-collaboration-ot';

const textType = {
    uri: 'http://example.com/types/text',
    create: (data) => data || '', // 初始化为空字符串
    transform: (op1, op2, side) => {
        if (op1.pos > op2.pos || (op1.pos === op2.pos && side === 'left')) {
            return { pos: op1.pos + op2.text.length, text: op1.text };
        }
        return op1;
    },
    apply: (snapshot, op) => {
        return snapshot.slice(0, op.pos) + op.text + snapshot.slice(op.pos);
    }
};

TypesManager.register(textType);
```

### 2\. 创建客户端实例

使用 [Client ](gcdocsite__documentlink?toc-item-id=402e864f-93d6-42e2-8aed-59863d91e723)类创建客户端实例，并指定服务器地址：

```typescript
import { Client } from '@grapecity-software/js-collaboration';
const client = new Client();
```

### 3\. 连接房间

通过 [connect ](gcdocsite__documentlink?toc-item-id=402e864f-93d6-42e2-8aed-59863d91e723#connect)方法连接到服务器的指定房间，返回 `Connection` 对象：

```typescript
const connection = client.connect('room1');
```

### 4\. 初始化 SharedDoc

使用 [SharedDoc](gcdocsite__documentlink?toc-item-id=9e659419-beff-4587-9334-629c91cea5e8) 类创建共享文档实例，并绑定到 `Connection`。`SharedDoc` 通过 `Connection` 收发消息，消息类型为 "ot-doc"：

```typescript
import { SharedDoc } from '@grapecity-software/js-collaboration-ot';
const doc = new SharedDoc(connection);
```

**参数**：`connection`：`client.connect` 返回的 `Connection` 对象。**作用**：创建共享文档实例，用于操作快照和提交操作。

## 完整示例

以下是 `SharedDoc` 初始化的完整示例：

```typescript
import { Client } from '@grapecity-software/js-collaboration';
import { SharedDoc, TypesManager } from '@grapecity-software/js-collaboration-ot';

// 定义 OT 类型
const textType = {
    uri: 'rich-text-ot-type',
    create: (data) => data || '', // 初始化为空字符串
    transform: (op1, op2, side) => {
        if (op1.pos > op2.pos || (op1.pos === op2.pos && side === 'left')) {
            return { pos: op1.pos + op2.text.length, text: op1.text };
        }
        return op1;
    },
    apply: (snapshot, op) => {
        return snapshot.slice(0, op.pos) + op.text + snapshot.slice(op.pos);
    }
};

// 注册 OT 类型
TypesManager.register(textType);

// 初始化客户端
const client = new Client();
const connection = client.connect('room1');
const doc = new SharedDoc(connection);
```
