# fragment

**片段机制**是一项高级服务器端功能，旨在优化大型文档的快照处理。通过将快照拆分为多个较小的片段（Fragments），服务器仅处理相关部分，避免频繁读写完整快照，从而提升性能。本文介绍片段的设计、实现和用法。

## 为何需要片段机制

对于大型文档（如工作簿或复杂数据结构），每次应用操作时读写完整快照会导致高I/O开销和性能瓶颈。不使用片段时，服务器端处理操作的流程如下：

1. 从数据库读取完整快照。
2. 应用操作修改数据。
3. 将完整快照写回数据库。

片段机制通过**分段存储和操作快照**显著降低资源消耗：

1. 将快照拆分为独立片段（如每个工作表一个片段）。
2. 操作时仅加载和更新相关片段。
3. 按需合并片段以返回完整快照。

## 设计

以工作簿为例，假设快照结构如下：

```typescript
interface IWorkbookSnapshot {
  activeSheetId: string;
  sheets: IWorksheetSnapshot[];
}
interface IWorksheetSnapshot {
  sheetId: string;
  dataTable: { [row: number]: { [col: number]: { value: string } } };
}
```

支持的操作类型：

* setCellValue：修改单元格值。
* addWorksheet：添加工作表。
* removeWorksheet：删除工作表。

### 片段化示例

一个工作簿快照：

```typescript
{
  activeSheetId: 'sheet1',
  sheets: [
    { sheetId: 'sheet1', dataTable: { 0: { 0: { value: 'Hello' } } } },
    { sheetId: 'sheet2', dataTable: { 0: { 0: { value: 'World' } } } }
  ]
}
```

可拆分为以下片段：

| **片段名称** | **片段数据** |
| ---- | ---- |
| workbook | { activeSheetId: 'sheet1' } |
| sheet\_sheet1 | { sheetId: 'sheet1', dataTable: { 0: { 0: { value: 'Hello' } } } } |
| sheet\_sheet2 | { sheetId: 'sheet2', dataTable: { 0: { 0: { value: 'World' } } } } |

## OT 类型支持

片段机制通过扩展服务器端 OT 类型（[OT_Type](gcdocsite__documentlink?toc-item-id=a3c4df01-9f5b-45c8-8cae-698c7f0debf0)）实现，添加以下方法：

| 方法 | 描述 |
| --- | --- |
| `createFragments(data: S): ISnapshotFragments;` | 从初始数据创建多个片段，返回`ISnapshotFragments`。 |
| `applyFragments(request: ISnapshotFragmentsRequest, op: T): Promise<void>;` | 对片段化快照应用操作，使用`ISnapshotFragmentsRequest`操作片段。 |
| `composeFragments(fragments: ISnapshotFragments): S;` | 将片段合并为完整快照。 |

> 使用片段时必须实现上述方法，可省略[create](gcdocsite__documentlink?toc-item-id=a3c4df01-9f5b-45c8-8cae-698c7f0debf0#create)和[apply](gcdocsite__documentlink?toc-item-id=a3c4df01-9f5b-45c8-8cae-698c7f0debf0#apply)方法。

## 工作流程

1. **创建文档**：调用[createFragments](gcdocsite__documentlink?toc-item-id=a3c4df01-9f5b-45c8-8cae-698c7f0debf0#createfragments)方法将快照拆分为片段并存储到数据库。
2. **应用操作**：
    * 接收操作（op），使用[applyFragments](gcdocsite__documentlink?toc-item-id=a3c4df01-9f5b-45c8-8cae-698c7f0debf0#applyfragments)和[ISnapshotFragmentsRequest](gcdocsite__documentlink?toc-item-id=724ffa60-979b-406c-a3c8-ea4400986a13)操作相关片段。
    * 仅更新受影响的片段（如修改单元格仅更新对应工作表）。
3. **客户端请求快照**：调用[composeFragments](gcdocsite__documentlink?toc-item-id=a3c4df01-9f5b-45c8-8cae-698c7f0debf0#composefragments)合并片段，向客户端返回完整快照。

> * **服务器特有**：片段仅在服务器端实现，客户端仍使用完整快照。
> * **OT 类型一致性**：客户端和服务器必须共享相同的 uri 和 transform。

## 有无片段的 OT 类型对比

以下基于工作簿示例，对比有无片段的 OT 类型实现：

### 无片段 OT 类型实现：

```typescript
const workbook_ot_type: OT_Type = {
    uri: 'workbook-ot-type',
    create: (data: IWorkbookSnapshot) => data,
    apply: (data: IWorkbookSnapshot, op: IOp) => {
        if (op.type === 'addWorksheet') {
            data.sheets.push(op.sheetSnapshot);
        } else if (op.type === 'removeWorksheet') {
            data.sheets = data.sheets.filter(sheet => sheet.sheetId !== op.sheetId);
        } else if (op.type === 'setCellValue') {
            const sheetSnapshot = data.sheets.find(sheet => sheet.sheetId === op.sheetId);
            sheetSnapshot.dataTable[op.row][op.col].value = op.value;
        }
        return data;
    },
    transform: (op1, op2, side) => {
        // 处理冲突
        return op1;
    }
}
```

### 有片段 OT 类型实现：

```typescript
const workbook_ot_type = {
    uri: 'workbook-ot-type',
    createFragments: (data: IWorkbookSnapshot) => {
        const fragments = {};

        // 为每个工作表创建片段
        for (const sheet of data.sheets) {
            const sheetFragmentName = 'sheet_' + sheet.sheetId;
            fragments[sheetFragmentName] = sheet.dataTable;
        }

        // 将工作簿其余部分创建为片段
        fragments['workbook'] = { ...data, sheets: undefined };
        return fragments;
    },
    applyFragments: async (request: ISnapshotFragmentsRequest, op) => {
        if (op.type === 'createSheet') {
            request.createFragment(op.sheetId, op.sheetSnapshot);
        } else if (op.type === 'deleteSheet') {
            request.deleteFragment(op.sheetId);
        } else if (op.type === 'setCellValue') {
            const sheetSnapshot = await request.getFragment(op.sheetId) as IWorksheetSnapshot;
            sheetSnapshot.dataTable[op.row][op.col].value = op.value;
            request.updateFragment(op.sheetId, sheetSnapshot);
        }
    },
    composeFragments: (fragments: ISnapshotFragments) => {
        const data = JSON.parse(JSON.stringify(fragments['workbook'])) as IWorkbookSnapshot;

        // 合并所有工作表片段
        for (const fragmentName in fragments) {
            if (fragmentName.startsWith('sheet_')) {
                data.sheets.push(fragments[fragmentName] as IWorksheetSnapshot);
            }
        }

        return data;
    },
    transform: (op1, op2, side) => {
        // 处理冲突
        return op1;
    }
};
```

| 特性 | 无片段 OT 类型 | 有片段 OT 类型 |
| --- | --------- | --------- |
| 工作流程 | 应用操作时需读写完整快照 | 应用操作时仅读写相关片段 |
| 性能 | 大型文档性能较低，I/O开销大 | 大型文档性能较高，仅处理小片段，降低I/O开销 |
| 复杂度 | 实现简单，仅需处理完整快照 | 实现复杂，需管理片段化和合并逻辑 |
| 适用场景 | 小型文档或低并发场景 | 大型文档或高并发场景 |

## API

```typescript
/**
 * 定义协同中自定义操作转换（OT）行为的接口。
 * @template S 快照数据的类型。
 * @template T 操作数据的类型。
 */
export interface OT_Type<S = unknown, T = unknown> {
    /**
     * 标识文档类型的URI。
     */
    uri: string;
    /**
     * 从提供的数据创建初始快照数据。
     * @param {S} data - 初始快照数据。
     * @returns {S} 创建的快照数据。
     */
    create?(data: S): S;
    /**
     * 从快照数据生成快照片段。
     * @param {S} data - 快照数据。
     * @returns {ISnapshotFragments} 生成的快照片段。
     */
    createFragments?(data: S): ISnapshotFragments;
    /**
     * 从快照片段组合快照数据。
     * @param {ISnapshotFragments} fragments - 快照片段。
     * @returns {S} 组合的快照数据。
     */
    composeFragments?(fragments: ISnapshotFragments): S;
    /**
     * 转换操作以解决与另一操作的冲突。
     * @param {T} op1 - 要转换的操作。
     * @param {T} op2 - 作为转换基础的操作。
     * @param {'left' | 'right'} side - 指示哪个操作后到达服务器。
     * @returns {T} 转换后的操作。
     */
    transform(op1: T, op2: T, side: 'left' | 'right'): T;
    /**
     * 对快照数据应用操作。
     * @param {S} snapshot - 当前快照数据。
     * @param {T} op - 要应用的操作。
     * @returns {S} 更新的快照数据。
     */
    apply?(snapshot: S, op: T): S;
    /**
     * 异步对快照片段应用操作。
     * @param {ISnapshotFragmentsRequest} request - 包含快照片段的请求。
     * @param {T} op - 要应用的操作。
     * @returns {Promise<void>} 操作应用完成时解析的Promise。
     */
    applyFragments?(request: ISnapshotFragmentsRequest, op: T): Promise<void>;
}

export type ISnapshotFragments<S = unknown> = { [key: string]: S };

export interface ISnapshotFragmentsRequest<S = unknown> {
    getFragment(id: string): Promise<S | undefined>;
    createFragment(id: string, data: S): void;
    updateFragment(id: string, data: S): void;
    deleteFragment(id: string): void;
}
```
