# tutorial-add-history-functionality

本教程将指导开发者通过服务端的 [getOps ](gcdocsite__documentlink?toc-item-id=e04a3031-c69b-4ba3-8926-c2813134ce43#getops)和 [fetchHistorySnapshot ](gcdocsite__documentlink?toc-item-id=e04a3031-c69b-4ba3-8926-c2813134ce43#fetchhistorysnapshot)API 实现历史记录管理。您将能够：

* 查看操作记录列表
* 预览特定版本内容

历史记录将显示在编辑器右侧的侧边栏中。预览时编辑器将禁用编辑功能，退出预览后恢复编辑能力。

## 前置条件

完成 [实时协同文本编辑器教程](gcdocsite__documentlink?toc-item-id=586c843b-82b8-4fd4-8bc5-276ac583ce1b)。

## 效果预览

在输入框中输入字符串 "Hello!" 并点击 **刷新** 按钮，右侧侧边栏将显示操作历史列表，记录所有操作记录。点击特定版本的 **预览** 按钮，可在输入框中查看对应版本的编辑器状态。
![text_editor_history](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1f04de1b-0add-4f88-889e-295f2a2e218b/text_editor_history.fc6b62.62d097.gif)

## 实现方案

### **服务端扩展**

* 添加 `/history/:roomId` 接口，使用 [getOps ](gcdocsite__documentlink?toc-item-id=e04a3031-c69b-4ba3-8926-c2813134ce43#getops)方法获取操作历史。
* 添加 `/snapshot/:roomId/:version` 接口，使用 [fetchHistorySnapshot ](gcdocsite__documentlink?toc-item-id=e04a3031-c69b-4ba3-8926-c2813134ce43#fetchhistorysnapshot)方法获取历史版本快照。

### **客户端增强**

* 在右侧添加侧边栏显示历史记录。
* 实现"预览"功能：加载快照并禁用编辑。
* 实现"退出预览"功能：恢复当前文档并启用编辑。

## 步骤 1：更新服务端

修改 `server.js` 以支持历史记录API。

```javascript
import express from 'express';
import { createServer } from 'http';
import { Server } from '@grapecity-software/js-collaboration';
import OT from '@grapecity-software/js-collaboration-ot';
import richText from 'rich-text';

const app = express();
const httpServer = createServer(app);
const server = new Server({ httpServer });

// 注册富文本类型
OT.TypesManager.register(richText.type);

// 初始化OT文档服务
const documentServices = new OT.DocumentServices();
server.useFeature(OT.documentFeature(documentServices));

// 提供静态文件服务
app.use(express.static('public'));

// 获取操作历史
app.get('/history/:roomId', async (req, res) => {
    const roomId = req.params.roomId;
    try {
        const ops = await documentServices.getOps(roomId, 0);
        res.json({ operations: ops });
    } catch (err) {
        res.status(500).json({ error: err.message });
    }
});

// 获取特定版本的快照
app.get('/snapshot/:roomId/:version', async (req, res) => {
    const roomId = req.params.roomId;
    const version = parseInt(req.params.version, 10);
    try {
        const snapshot = await documentServices.fetchHistorySnapshot(roomId, version);
        res.json(snapshot);
    } catch (err) {
        res.status(500).json({ error: err.message });
    }
});

// 启动服务器
httpServer.listen(8080, () => {
    console.log('服务器运行在 http://localhost:8080');
});
```

**代码说明**加粗部分为新增代码，引入两个REST接口：

* `/history/:roomId`：返回房间的完整操作历史记录。
* `/snapshot/:roomId/:version`：返回特定版本的文档状态。

### 2\. 更新 `public/client.js`

将基础教程中的代码替换为以下内容：

```javascript
import { Client } from "@grapecity-software/js-collaboration-client";
import * as OT from "@grapecity-software/js-collaboration-ot-client";
import richText from "rich-text";
import Quill from "quill";

// 注册富文本类型
OT.TypesManager.register(richText.type);

// 连接服务器并加入房间
const connection = new Client().connect("room-id");
const doc = new OT.SharedDoc(connection);
const quill = new Quill("#editor", { theme: "bubble" });
const previewQuill = new Quill("#preview-editor", { theme: "bubble", readOnly: true });

// 订阅文档
doc.subscribe().then(async () => {
    if (!doc.type) {
        try {
            await doc.create([{ insert: "Hi!" }], richText.type.uri, {});
        } catch (err) {
            if (err) console.error("错误: " + err); // 修正：传递单个错误对象
        }
    }
    quill.setContents(doc.data);
    quill.on("text-change", (delta, oldDelta, source) => {
        if (source !== "user") return;
        doc.submitOp(delta, { source: connection.id });
    });
    doc.on("op", (op, source) => {
        if (source === connection.id) return;
        quill.updateContents(op);
    });
    loadHistory(); // 启动时加载历史记录
})


// 错误处理（修正：合并并纠正）
connection.on("error", (err) => console.error("连接错误:", err.message));
doc.on("error", (err) => console.error("文档错误:", err.message));

// 加载历史记录
async function loadHistory() {
    const response = await fetch("/history/room-id");
    const data = await response.json();
    const historyList = document.getElementById("history-list");
    historyList.innerHTML = "";
    data.operations.forEach((op, index) => {
        const li = document.createElement("li");
        const infoDiv = document.createElement("div");
        infoDiv.classList.add("info");
        infoDiv.textContent = `版本 ${index}: ${JSON.stringify(op.create || op.op)}`;
        const previewBtn = document.createElement("button");
        previewBtn.textContent = "预览";
        previewBtn.addEventListener("click", () => previewVersion(index + 1));
        li.appendChild(infoDiv);
        li.appendChild(previewBtn);
        historyList.appendChild(li);
    });
}

// 预览特定版本
async function previewVersion(version) {
    const response = await fetch(`/snapshot/room-id/${version}`);
    const snapshot = await response.json();
    document.getElementById("editor").style.display = "none";
    document.getElementById("preview-editor").style.display = "block";
    previewQuill.setContents(snapshot.data);
    document.getElementById("exit-preview").style.display = "inline-block";
}

// 退出预览模式
function exitPreview() {
    document.getElementById("editor").style.display = "block";
    document.getElementById("preview-editor").style.display = "none";
    previewQuill.setContents([]);
    document.getElementById("exit-preview").style.display = "none";
}

// 全局函数
window.loadHistory = loadHistory;
window.exitPreview = exitPreview;
```
