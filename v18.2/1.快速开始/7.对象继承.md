# objectinh

对于SpreadJS控件的对象（例如表单，列和单元格），存在每个对象都从其“父级”继承的格式和其他属性。 单元格可以继承某些格式，例如，表单的背景色。 如果您为列中的所有单元格设置了文本对齐方式，则该单元格也会继承该对齐方式。 由于这种对象关系，许多属性和方法可以以不同的方式应用于控件的不同部分。
您可以覆盖单个单元格继承的格式，但是默认情况下，对象从其父级继承属性。 因此，在给定的上下文中，任何对象的设置都是应用于该对象的父对象设置的组合。 例如，您可以在单元格级别为单元格设置文本颜色，但是它可以继承行的垂直对齐方式，列的边框和表单的背景色。 由于可能在其中几个级别上设置背景色，因此必须应用某些优先级规则。
越接近单元格级别，优先级越高。 因此，如果您设置单元格的背景颜色，则从父级继承的设置将被覆盖。 请参阅列表以查看这些属性的优先顺序。 越靠近单元格（数字越小），优先级越高。

1. 单元格 / Cell
2. 行 / Row
3. 列 / Column
4. 表单 / Worksheet
