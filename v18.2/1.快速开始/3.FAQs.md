# techsupport

## SpreadJS 产品 FAQ

**Q：什么是 SpreadJS？**
A：SpreadJS 是一款基于 JavaScript 的电子表格控件，可嵌入网站、Web 应用或移动端应用中，为用户提供类 Excel 的在线表格编辑、数据处理和可视化功能，无需依赖本地 Excel 软件。
**Q：SpreadJS 支持哪些主流浏览器？**
A：兼容 Chrome、Firefox、Safari、Edge 等现代浏览器（完全支持 HTML5 标准），同时对 IE11 也有一定支持，能满足不同用户的浏览器使用习惯。
**Q：使用 SpreadJS 需要安装 Excel 吗？**
A：不需要。SpreadJS 是纯前端控件，通过 JavaScript 实现表格功能，完全独立于本地 Excel，用户无需安装 Excel 即可使用其核心功能。
**Q：SpreadJS 能否导入和导出 Excel 文件？**
A：可以。它支持导入.xlsx、.csv 等常见 Excel 格式文件，也能将编辑好的表格导出为 Excel 文件，且能较好地保留原文件的格式和数据。
**Q：SpreadJS 支持公式计算吗？**
A：支持。它内置了450+ Excel 兼容的[公式](https://demo.grapecity.com.cn/spreadjs/SpreadJSTutorial/features/calculation/basic-functions/purejs)，包括数学、逻辑、文本、日期等类型，可实现复杂的数据计算和分析。
**Q：能否自定义 SpreadJS 的界面样式？**
A：可以。用户可通过 CSS 样式或 API 接口自定义表格的外观，如单元格样式、工具栏、菜单等，使其与应用的整体风格保持一致。
**Q：SpreadJS 适合开发哪些类型的应用？**
A：适用于在线报表系统、数据录入平台、财务分析工具、项目管理软件等需要表格交互和数据处理的 Web 应用。
**Q：SpreadJS 能适配移动端吗？**
A：可以适配。它提供了移动端优化的交互模式，支持触摸操作，能在手机、平板等移动设备上良好运行。可参考在线示例：[移动端展示](https://demo.grapecity.com.cn/spreadjs/mobilesample/)
**Q：使用 SpreadJS 需要具备哪些技术基础？**
A：基本的 HTML、CSS 和 JavaScript 知识即可，若需进行深度定制开发，了解前端框架（如 Vue、React、Angular）会更有帮助。
**Q：SpreadJS 是否支持数据可视化功能？**
A：支持。它内置了多种[图表类型](https://demo.grapecity.com.cn/spreadjs/SpreadJSTutorial/features/charts/basic-chart/purejs)，如柱状图、折线图、饼图等，可将表格数据快速转换为直观的图表，方便数据展示和分析，同时也支持条件格式、形状、单元格样式及迷你图等数据可视化方法。
**Q：SpreadJS 的授权方式是怎样的？**
A：请参考[授权价格页面](https://www.grapecity.com.cn/developer/spreadjs/price)。
**Q：SpreadJS 的试用版本是否需要授权？是否有功能限制？**
A：试用版本不需要授权，即可在本地（localhost）开发应用。同时，试用版本没有功能限制。
**Q：能否与后端系统进行数据交互？**
A：可以。通过 AJAX、RESTful API 等方式，SpreadJS 可与后端服务器进行数据的读取和提交，实现前后端数据的实时同步。
**Q：SpreadJS 有提供开发文档和示例吗？**
A：有。官方提供了详细的[产品开发文档](gcdocsite__documentlink?toc-item-id=810f470f-6d3f-4dae-af04-f89de529860c)、[API 参考手册](https://demo.grapecity.com.cn/spreadjs/help/api/modules/GC)以及丰富的[示例代码](https://www.grapecity.com.cn/developer/spreadjs/demo)，帮助开发者快速上手和解决开发过程中的问题。
**Q：SpreadJS 支持多人实时协作编辑吗？**
A：支持。通过集成相关的协作插件或自行开发协作逻辑，可实现多人对同一表格进行实时编辑和查看，提高团队工作效率。
**Q：SpreadJS 的更新频率如何？**
A：官方会定期发布更新版本（hotfix），不断修复 bug、优化性能。并会每年发布年度版本，新增功能和特性，以满足用户不断变化的需求。
