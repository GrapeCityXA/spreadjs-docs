# system-requirements

## 浏览器要求

运行 SpreadJS 需要以下浏览器：

* Microsoft IE Edge
* Mozilla FireFox
* Safari
* Google Chrome

> type=warning
> 注意：浏览器必须完全支持 HTML5 标准！

## 操作系统

* Windows
* Linux
* macOS
* iOS
* iPadOS（仅支持 Chrome 和 Safari）

## JavaScript 框架

* Vue.js: V3
* Angular: V15 \~ V18
* React: V16 \~ V17
* Next.js: V13 \~ V14
* Knockout

注意：仅支持 CSR（客户端渲染）
