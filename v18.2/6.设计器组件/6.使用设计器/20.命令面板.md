# command-palette

SpreadJS 设计器的**命令面板**的核心优势在于它能够显著提高操作效率。用户无需在多层菜单中查找，只需使用快捷键（**Ctrl/Cmd+P**）调用该面板，输入一个关键词（例如“合并单元格”或“数据验证”），即可立即执行命令，减少了操作步骤并节省了时间。
对于公式编辑和批量样式设置等高频率、复杂的任务，此功能尤为重要。通过支持键盘驱动的导航和智能搜索，它最大程度地减少了因界面切换而带来的干扰，使用户能够专注于核心工作流程，加快电子表格设计和数据处理的速度。

## 配置

命令面板通过 `GC.Spread.Sheets.Designer.DefaultConfig` 集成到设计器的布局中。在配置中，它被注册为一个弹出式侧面板：

```javascript
GC.Spread.Sheets.Designer.DefaultConfig = {
  // ...
  sidePanels: [
    // ...
    {
      /*
       * 将面板显示为弹出式模态框。
       */
      position: 'popup',
      command: GC.Spread.Sheets.Designer.CommandNames.CommandPalettePanel,
      uiTemplate: GC.Spread.Sheets.Designer.TemplateNames.CommandPaletteTemplate,
    }
  ]
};
```

## **如何打开命令面板**

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1f04de1b-0add-4f88-889e-295f2a2e218b/image.3bfd74.png)

### **1\. 默认快捷键（`Ctrl/Cmd + P`）**

按下 **`Ctrl + P`**（Windows 系统）或 **`Cmd + P`**（Mac 系统）即可立即打开命令面板。

### **2\. 功能区按钮**

也可以从功能区的**“视图”选项卡**中访问命令面板。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1f04de1b-0add-4f88-889e-295f2a2e218b/image.f841e5.png)

## **用户界面与交互**

### **搜索与执行**

* **搜索字段**：输入关键词以筛选命令（搜索范围包括 `title`、`text`、`tip` 和 `name`）。
* **键盘导航**

| 快捷键 | 操作 |
| --- | --- |
| **向上/向下箭头** | 向上/向下移动选择项 |
| **Enter** | 执行所选命令 |
| **Esc** | <ol><li>当列表项处于选中状态时，按下 Esc 键会将焦点返回到搜索框。</li><li>当搜索框处于选中状态时，按下 Esc 键会关闭命令面板。</li><li>当焦点在子菜单下拉列表中时，按下 Esc 键：<ul><li>关闭当前子菜单</li><li>将焦点返回到搜索框</li></ul></li></ol> |
| **Backspace** | 删除搜索标签 |

### **支持的命令**

命令面板会搜索：

1. **所有功能区命令**
2. **隐藏命令**（例如，`GC.Spread.Sheets.Designer.CommandNames.Background`）
3. 在 `GC.Spread.Sheets.DefaultConfig.commandMap` 中定义的**自定义命令**
