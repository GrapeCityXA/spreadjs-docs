# edit-font-family

SpreadJS 允许用户在工作表、图表及其他视觉元素中选择并应用多种字体。值得注意的是，每当进行文本输入时，系统会自动应用[文档主题](gcdocsite__documentlink?toc-item-id=49874b66-77e9-46e7-8874-d825b5fe0bc6)的默认字体，在确保视觉一致性的同时，保留自定义的灵活性。
当然，在某些情况下，你可能需要偏离主题默认字体以满足特定设计需求。在 SpreadJS 设计器组件中，你可以轻松调整任意视觉元素的字体。
本文将重点介绍如何为工作表单元格内的文本配置字体，文末还将简要概述其他元素（图表、形状等）的字体配置方法。

## 单元格字体配置

你可以通过“开始”（HOME）功能区选项卡下“字体”（Fonts）组中的“字体”下拉框，修改电子表格中的字体。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.ce13b6.042a89.png)

### 方法一：通过下拉列表选择

1. **激活字体控制**
    * 将光标定位到目标单元格内。
    * 确保“字体”下拉框可见。
2. **选择偏好字体**
    * 点击下拉箭头，打开字体列表。
    * 滚动列表选择所需字体。
    * 点击字体名称完成设置。

![1.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/1.ca14b3.a212a4.gif)

### 方法二：直接文本输入

1. **激活字体控制**
    * 将光标定位到目标单元格内。
    * 确保“字体”下拉框可见。
2. **操作字体输入框**
    * 清除输入框中的默认字体名称。
    * 输入所需字体名称（不区分大小写，系统会自动去除空格字符）。
    * 按下**Enter 键**提交输入（下拉列表将自动关闭）。

![2.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/2.019543.9601f6.gif)

>type=note
> **注意：**
> 空输入不会被保存或应用。

SpreadJS 采用声明式字体机制，因此即使用户输入的字体未在字体列表中，该字体仍可生效。其生效规则遵循浏览器的字体渲染策略。
![3.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/3.d7eed7.73c448.gif)

#### 输入筛选目标字体

在下拉列表处于打开状态时，输入文本会触发列表自动选中第一个匹配的字体（匹配规则为“从字体名称开头匹配”）。
![4.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/4.058f29.7c7a43.gif)

>type=note
> **注意：**
> 输入后立即按下 Enter 键，若存在匹配字体，系统将自动选中第一个匹配项。

#### 开发者配置方式

开发者可通过公共 API 配置字体下拉列表，代码示例如下：

```javascript
export let FontFamily: IComboBoxCommand = {
  title: "${res.ribbon.home.fontFamily}",
  text: "Font Family",
  type: "comboBox",
  commandName: CommandNames.FontFamily,
  editable: true,    // 启用手动输入
  autoSelect: true   // 自动选中第一个匹配字体
  ...
}
```

>type=note
> **说明：**
>
> * 若 `editable` 设为 `false`，则手动输入功能被禁用。
> * 若 `autoSelect` 设为 `false`，则自动选中第一个匹配字体的功能被禁用。
