# spdesignhometab

**主页**选项卡允许你进行剪切、复制和粘贴操作，以及设置单元格格式和条件格式。你还可以添加和设置表格格式、进行排序、筛选和搜索。
![image.8f43f8](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1f04de1b-0add-4f88-889e-295f2a2e218b/image.8f43f8.fb95ca.png)
下表列出了 **主页** 选项卡的各个部分和选项：

| **部分** | **描述** |
| --- | --- |
| **撤销** | 提供重做和撤销选项。 |
| **剪贴板** | 提供剪切、复制和粘贴选项。 |
| **字体** | 提供单元格文本的相关选项，如颜色、字体类型和字号。 |
| **对齐方式** | 提供文本居中、自动换行以及创建合并单元格的选项。 |
| **数字** | 提供数字格式设置选项。 |
| **样式** | 提供使用规则和表格进行条件格式设置的选项，以及设置单元格样式的选项。 |
| **单元格** | 提供插入、删除和隐藏行与列的选项，以及设置行高、列宽和锁定单元格的选项。 |
| **编辑** | 提供自动填充、清除数据和格式、排序、筛选、搜索和替换的选项。 |

点击右下角的箭头图标，可查看 **设置单元格格式** 对话框。
![image.2c4054](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1f04de1b-0add-4f88-889e-295f2a2e218b/image.2c4054.c01cb3.png)

> **注意：** SpreadJS 允许你调整 **条件格式规则管理器** 对话框的大小。由于具备调整对话框大小的功能，对话框内的内容也支持自适应调整大小。
