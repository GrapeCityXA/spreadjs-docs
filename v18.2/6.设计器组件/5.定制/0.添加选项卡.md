# add_tab

按照以下步骤，通过添加名为“联系我们”的新选项卡来自定义功能区组件：

1. 访问默认配置。

    ```JavaScript
    // 配置工作簿和工作表
    var spread = new GC.Spread.Sheets.Workbook('ss');
    var activeSheet = spread.getActiveSheet();
    // 访问默认配置
    var config = GC.Spread.Sheets.Designer.DefaultConfig;
    
    ```
2. 为新选项卡创建布局结构，并将其添加到配置中。

    ```JavaScript
    // 新选项卡的布局结构
    var newTab = {
        id: 'contactUs',
        text: '联系我们',
        buttonGroups: [
            {
                commandGroup: {
                    children: [
                        {
                            type: 'textBlock',
                            text: '请致电 400-657-6008或发送邮件至info.xa@grapecity.com联系销售人员，以申请临时部署授权。',
                        },
                    ],
                },
            },
        ],
    };
    // 将新选项卡添加到配置的功能区中
    config.ribbon.push(newTab);
    
    ```
3. 通过传递用于可自定义配置的 `config` 参数来初始化设计器实例。

    ```JavaScript
    // 初始化设计器实例
    var designer = new GC.Spread.Sheets.Designer.Designer(document.getElementById("designerHost"), config, spread);
    ```

> **注意：** 如果你想从功能区组件中删除一个内置选项卡，请从默认配置中移除其内容，然后重复上述步骤2。
