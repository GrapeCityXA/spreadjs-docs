# dynamically_hide_scrollbar

### 问题：如何动态隐藏滚动条

#### 背景：

在一些场景中，需要根据内容的多上来觉得是否展示滚动条，按需展示。比如对于纵向滚动条来说，当sheet内容的高度小于可视区域的高度时，就自动隐藏滚动条。

#### 解决方案：

目前SpreadJS滚动条只支持显示和隐藏两种状态，没有根据行列所占的内容是否超出视图来动态隐藏的功能，但是可以通过下面的代码来帮助实现
首先需要监听相应的变化事件，例如浏览器大小变化，spread容器的大小改变以及在添加行，删除行这些事件。在其中判断viewport的宽高与所有行高，列宽的大小，对比来确定内容是否会超出viewport。来决定滚动条的显示和隐藏。
获取viewport宽度和高度可以通过getViewportHeight、getViewportWidth
总行高与总列宽需要通过循环遍历所有行/列，通过getRowHeight/getColumnWidth获取每一行的高度/每一列的宽度，进行累加来求得。
最后，在对比后，设置showVerticalScrollbar和showHorizontalScrollbar为true或者false即可

```javascript
    spread.options.showVerticalScrollbar = false;
    spread.options.showHorizontalScrollbar = false;
```
