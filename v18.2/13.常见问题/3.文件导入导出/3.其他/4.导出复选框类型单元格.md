# export-checkbox-cells

### 问题：在SpreadJS中设置了复选框，但是导出成Excel后这个复选框消失了，变为true?

#### 背景：

***

SpreadJS支持了很多Excel不支持的单元格类型，例如复选框单元格、单选列表、复选框列表等等，这为用户在展示数据时提供了直观易用的选择方式。
然而，当用户将包含此类型的的文件导出Excel时，就会发现出现了一定的问题。
以复选框为例，在SpreadJS中用户处于选中状态，而当导出到Excel中时，会发现复选框区域的数值变成True了。
这是因为，**复选框呈现出的小框属于SpreadJS特有的样式信息**，而当getValue()时，取到的其实仍旧是true/false/null。
而导出到Excel时，Excel并不支持这种样式信息，获取到的依旧是true/false/null。
在Excel中，复选框控件和单元格并没有联动，更像是一个浮在表单表面的一个形状控件，为了兼容Excel的这一特性，SpreadJS在v16版本中增加了形状控件，我们可以通过将特殊类型单元格转换成相对应的形状控件来实现该类型单元格的导出

#### 解决方案：

本文以复选框为例，实现一个将复选框导出到Excel，并使其维持正常样式的方案。本方法采用差异化导出中提到的方式，通过影子对象在导出时对文件进行个性化设置

#### Step1：导出前循环判断sheet中是否包含复选框单元格：

```js
sheet.getCellType(i,j) instanceof GC.Spread.Sheets.CellTypes.CheckBox
```

#### Step2：判断复选框时否为三态复选框，根据不同的状态取对应的值：

```js
let text = ''
let checkbox = sheet.getCellType(row, col)

// 如果是三选类型
if (sheet.getCellType(row, col).isThreeState()) {
    text = sheet.getValue(row, col) ? checkbox.textTrue() : (
        sheet.getValue(row, col) == null ? checkbox.textIndeterminate()
            :
            checkbox.textFalse()
    )
} else {
    var cellType = sheet.getCellType(row, col);
    text = cellType.caption();
}
```

#### **Step3：将复选框所在单元格类型置空：**

```js
sheet.setCellType(i,j,nulll)
```

#### Step4：通过单元格宽高的累加值判断复选框形状控件的起始位置

```js
var x = 0;
var y = 0;
// 影子对象，方便差异化导出
let spread_copy = new GC.Spread.Sheets.Workbook()
spread_copy.fromJSON(spread.toJSON())
let sheet = spread_copy.getActiveSheet()
let row = sheet.getRowCount()
let col = sheet.getColumnCount()

for (let i = 0; i < row; i++) {
    var hangArr = [];
    for (let j = 0; j < col; j++) {
        // 当前单元格信息
        var cellWidth = sheet.getCell(-1, j).width();
        var cellHeight = sheet.getCell(i, -1).height();

        if (sheet.getCellType(i, j) instanceof GC.Spread.Sheets.CellTypes.CheckBox) {
            cellTypeToShape(sheet, x, y, cellWidth, cellHeight, i, j);
        }

        x += cellWidth;
        if (j == col - 1) {
            x = 0;
            y += cellHeight;
        }
    }

}
return spread_copy.toJSON()
```

通过上述四步，就基本可以完成将复选框导出Excel的功能了，如果对于复选框单元格的样式还想要一比一还原，可以参考复选框[单元格API](https://demo.grapecity.com.cn/spreadjs/help/api/classes/GC.Spread.Sheets.CellTypes.CheckBox)和[复选框形状API](https://demo.grapecity.com.cn/spreadjs/help/docs/features/form-controls#site_main_content-doc-content_title)，通过对比两者之间对应关系也顺带着做个转换以此满足不同生产环境下的需求
