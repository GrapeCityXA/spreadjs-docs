# alt-enter-wrap

### 背景

***

用户在使用 SpreadJ S时，发现在使用 Alt+Enter 以后，单元格并没有按预期在单元格中设置自动换行的效果
实际上 SpreadJS 此时已经对这个字符串做了换行，但是如果此单元格这时的 `wordWrap` 允许换行是 false 的话，就没有换行效果了。

### 实现思路

解决办法也很简单，可以监听 `ValueChanged` 事件，当检测到变化后的值包含了"\\n"时，给单元格设置允许换行，并且设置该行自适应行高，即可实现和Excel一样的效果。

```javascript
sheet.bind(GC.Spread.Sheets.Events.ValueChanged, function (sender, args) {
    var str=args.newValue;
    if (str.indexOf("\n") >= 0) {
        sheet.getCell(args.row,args.col).wordWrap(true);
        sheet.autoFitRow(args.row);
    }
});
```
