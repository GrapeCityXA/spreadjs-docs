# calling-menu-functions-through-code

### 问题：如何通过代码调用菜单功能

***

#### 背景：

SpreadJS 的在线表格编辑器提供了很多和 Excel 基本一致的功能，我们不需要在调用 SpreadJS 的接口去实现这些功能，即可直接在浏览器中实现这些功能，免去了二次开发的工作。
但是有的客户出于界面定制的考虑，不希望使用 Designer 的 Ribbon 样式菜单，只想给用户展示SpreadJS 表格界面，同时又想要使用 Designer 编辑器中上方菜单提供的功能。

#### 解决思路：

对于这种需求一个可行的方案是，将在线表格编辑器中除 SpreadJS 表格外的部分全部隐藏，此时编辑器看起来就是一个单纯的 SpreadJS 表格，然后再通过命令的方式去调用即可，客户可以自己定义菜单，按钮或者通过在 SpreadJS 中定义右键菜单来调用这些命令。
一个典型的应用场景，通过一个按钮调用在线表格编辑器中本身提供的新建透视表的功能，这样自己不用再去额外开发这个新增透视表的弹窗，对于编辑器中提供的其他的一些复杂操作，同样如此。
1、隐藏workbook外的其他元素，并在 window 上挂载 designer 对象

```javascript
window.onload = function () {
    var designer = new GC.Spread.Sheets.Designer.Designer('ribbonHost');

    // 隐藏元素
    var config = GC.Spread.Sheets.Designer.DefaultConfig;
    config.ribbon = [];
    config.sidePanels = [];
    designer.setConfig(config);

    // 挂载 designer 对象，在点击事件中需要使用
    window.designer = designer;

    // 给 button 绑定点击事件的方法
    document.getElementById('insertBarcode').onclick = insertBarcode;
    document.getElementById('insertTable').onclick = insertTable;
    document.getElementById('insertPivot').onclick = insertPivot;
};
```

2、实现上面三个按钮调用在线编辑器功能，核心是获取到按钮后对应的命令，然后执行命令。

```javascript
insertBarcode = function () {
    var commandName = GC.Spread.Sheets.Designer.CommandNames.InsertBarCode;
    GC.Spread.Sheets.Designer.getCommand(commandName).execute(window.designer, null);
};
insertTable = function () {
    var commandName = GC.Spread.Sheets.Designer.CommandNames.InsertTable;
    GC.Spread.Sheets.Designer.getCommand(commandName).execute(window.designer, null);
};
insertPivot = function () {
    var commandName = GC.Spread.Sheets.Designer.CommandNames.InsertPivotTable;
    GC.Spread.Sheets.Designer.getCommand(commandName).execute(window.designer, null);
};
```
