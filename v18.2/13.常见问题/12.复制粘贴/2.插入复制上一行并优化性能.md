# InsertCopyOfPreviousRow

### 需求：想要通过addRow一次性复制上千行上一行的内容，如何实现且性能优异

***

#### 背景：

用户提出需求，希望在代码addRow的时候复制上一行的内容，并且一次添加上千行。
如果使用copyTo方法实现，需要一行一行来复制，性能很差，花费时间较长，复制3000行大约需要500秒。

#### 实现方式：

copyTo本身不适用于大批量数据的复制粘贴，建议使用clipboardPaste命令来完成， 其优点是不需要一行一行复制粘贴，在性能上表现较佳。
示例代码如下：

```javascript
spread.commandManager().execute({
  cmd: "clipboardPaste",
  sheetName: sheet.name,
  fromSheet: sheet,
  fromRanges: fromRange,
  pastedRanges: toRanges,
  isCutting: false,
  clipboardText: "",
  pasteOption: GC.Spread.Sheets.ClipboardPasteOptions.formulasAndFormatting,
}); // 先复制一大块区域
```

由于实例中存在大量的公式计算，用户希望保留样式和公式，不需要粘贴值。于是pasteOption可以设置如下：

```javascript
GC.Spread.Sheets.ClipboardPasteOptions.formulasAndFormatting。
```

如果有其他的需求，可以跟据[ClipboardPasteOptions](https://demo.grapecity.com.cn/spreadjs/help/api/enums/GC.Spread.Sheets.ClipboardPasteOptions#enumeration-clipboardpasteoptions)的选项按需选取。
另外，示例中还存在着大量的数字需要在添加行时动态序列填充，故使用fillAuto方法用来操作序列填充序号：

```javascript
sheet.fillAuto(
  new GC.Spread.Sheets.Range(addIndex - 1, -1, 1, -1),
  new GC.Spread.Sheets.Range(addIndex - 1, -1, addCount + 1, -1),
  {
    fillType: GC.Spread.Sheets.Fill.FillType.auto,
    series: GC.Spread.Sheets.Fill.FillSeries.column,
    direction: GC.Spread.Sheets.Fill.FillDirection.down,
  }
); // 将区域进行自动填充处理
```
