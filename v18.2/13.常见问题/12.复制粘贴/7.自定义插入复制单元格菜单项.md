# InsertPaste

### 需求：如何在SpreadJS自定义插入复制单元格菜单项

#### 背景：

在designer中右键菜单中有插入复制单元格菜单项，用户想在SpreadJS中自定义添加此菜单项效果。

#### 实现方式：

可以在右键的上下文菜单中增加要插入复制单元格的菜单项，然后重写粘贴逻辑。
自定义菜单项：

```javascript
var openDialog = {
    text: '插入粘贴',
    name: 'openDialog',
    command: insertPaste,
    workArea: 'viewport'// 生效区域
};
spread.contextMenu.menuData.push(openDialog);
```

新的插入粘贴的逻辑应该是在粘贴之前增加一个插入行的操作，如此一来就不会有覆盖的问题发生了。
插入粘贴逻辑：

```javascript
var selection = sheet.getSelections()[0];
var row = selection.row; // 粘贴的行索引
var col = selection.col; // 粘贴的列索引

var rowCount = copySelection.rowCount; // 复制的行数
var colCount = copySelection.colCount; // 复制的行数

sheet.addRows(row, rowCount - 1); // 增加rowCount-1行，因为你选中的位置也算一行
var fromRange = [
  new GC.Spread.Sheets.Range(
    copySelection.row,
    copySelection.col,
    rowCount,
    colCount
  ),
];
var toRange = [new GC.Spread.Sheets.Range(row, -1, rowCount, -1)];
spread.commandManager().execute({
  cmd: "clipboardPaste",
  sheetName: sheet.name(),
  fromSheet: sheet,
  fromRanges: fromRange,
  pastedRanges: toRange,
  isCutting: false,
  clipboardText: "",
  pasteOption: GC.Spread.Sheets.ClipboardPasteOptions.all,
});
```
