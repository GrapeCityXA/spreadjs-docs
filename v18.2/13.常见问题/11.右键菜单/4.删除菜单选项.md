### 问题：右键菜单删除菜单选项

***

#### 背景：

SpreadJS或在线表格编辑器的菜单选项中并不是所有的功能都会被实际应用场景使用到，需要在SpreadJS或在线表格编辑器中剔除用不到的菜单选项。

#### 解决方案：

SpreadJS和在线表格编辑器在删除右键菜单选项有些许不同，下面分别列举两种模式下删除右键菜单选项的方法

##### 1\. SpreadJS右键菜单选项删除

SpreadJS运行时的右键菜单配置项位spread实例的contextMenu下的menuData中，如下图所示：

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.58fa26.png)

截图可以看到第22项为目标删除项，此时执行数组的删除方法即可：
`spread.contextMenu.menuData.splice(22,1)`

##### 2\. 在线表格编辑器右键菜单选项删除

右键菜单的配置项位于设计器的config信息中，因此第一步我们需要拿到当前的配置信息：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.2fe9af.png)

上图中，config中的contextMenu就是右键菜单的配置项，英文单词也比较见名知意，插入行对应的为数组索引为24的数据项，对应的值为'gc.spread.contextMenu.insertRows'。
接下来，只要将该项从数组中删除即可，即执行：
`config.contextMenu.splice(24,1)`
最后，更新当前designer实例的配置信息，执行：
`designer.setConfig(config)`
完整的测试代码如下：

```js
// 获取默认配置
let config = GC.Spread.Sheets.Designer.DefaultConfig
//删除目标移除项，splice()方法第一参数根据自己的需求调整
config.contextMenu.splice(24,1)
//更新设计器配置
designer.setConfig(config)
```

### 问题：在线表格编辑器删除右键菜单”取消表单保护“项

***

#### 背景：
在对模板下发填报时，对于已被保护的表单不希望填报者”取消保护“。
所以可以考虑将”取消表单保护“项删除。

#### 解决方案：
1、修改command ”unprotectSheet“的visibleContext值为true，并进行注册

```
GC.Spread.Sheets.Designer.getCommand("unprotectSheet").visibleContext = true;
var newFun = GC.Spread.Sheets.Designer.getCommand("unprotectSheet");

config.commandMap = {
    "unprotectSheet": newFun
};
```

2、引入修改后的config，初始化designer

```
var designer = new GC.Spread.Sheets.Designer.Designer(document.getElementById("gc-designer-container"), config);
```
