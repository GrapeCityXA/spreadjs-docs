# ishidden

### 问题：控制右键菜单粘贴选项是否隐藏

***

#### 背景：

需要限制用户进行右键菜单中的粘贴操作功能，根据不同的条件判断是否给用户开放粘贴功能。

#### 解决方案：

在某些情况下，我们需要限制用户进行右键菜单中的操作行为，通过 visibleContext 属性进行控制。
visibleContext 用于控制对应的功能是否隐藏，用在右键菜单选项中就可以控制该菜单选项是否隐藏。
另外可以将 visibleContext 的结果设置为一个动态变量，用于动态的控制是否隐藏。
例如下面的示例，通过设置 visibleContext 来动态的隐藏或显示右键菜单中粘贴选项功能。

1. 是否隐藏是有 visibleContext 属性进行控制，所以我们需要修改对应菜单选项的 visibleContext。
2. 可以给 visibleContext 设置一个属性（showPasteItem），该属性名称由用户自定义，可以理解为声明了一个showPasteItem名称的变量。
3. 该属性可以通过 setData 方法来传递属性的值，可以通过 setData 实时更改属性的结果，用作动态控制。

示例中通过两个按钮来实现是否显示右键中的粘贴选项。
完整代码如下：

```javascript
window.onload = function () {
    let designerConfig = JSON.parse(
        JSON.stringify(GC.Spread.Sheets.Designer.DefaultConfig)
    );
    designerConfig.commandMap = {};
    const commandNames = [
    "designerPasteAll",
    "pasteFormula",
    "designerPasteValues",
    "designerPasteFormatting",
    "pasteValuesFormatting",
    "pasteFormulaFormatting",
    "contextMenuPaste",
  ];
    commandNames.forEach((commandName) => {
        const command = GC.Spread.Sheets.Designer.getCommand(commandName);
        command.visibleContext = "showPasteItem";
        designerConfig.commandMap[commandName] = command;
    });
    let designer = new GC.Spread.Sheets.Designer.Designer(
        "gc-designer-container",
        designerConfig
    );
    let spread = designer.getWorkbook();
    let sheet = spread.getActiveSheet();
    designer.setData("showPasteItem", true);
    document.querySelector("#button1").addEventListener("click", function () {
        designer.setData("showPasteItem", true);
    });
    document.querySelector("#button2").addEventListener("click", function () {
        designer.setData("showPasteItem", false);
    });
};
```
