# get-process-different-type-argument

### 问题：自定义函数不同参数如何获取和处理？

***

#### 背景：

熟悉SpreadJS功能的小伙伴可能有了解或使用过自定义函数，相关知识点在学习指南也有相关介绍：
[https://demo.grapecity.com.cn/spreadjs/SpreadJSTutorial/features/calculation/custom-functions/purejs](https://demo.grapecity.com.cn/spreadjs/SpreadJSTutorial/features/calculation/custom-functions/purejs)
本篇教程就来讲解下在定义自定义函数时，不同类型的参数是如何获取以及处理的。

#### 解析思路：

1、参数为单元格区域
在evaluate方法内，可以通过arguments获取传参数组，如下图：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.b25f4f.png)
使用argument.getSource().getSheet() 获取sheet，进而获取sheetName。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.f759e9.png)
使用getRow等方法获取参数区域的行列信息，最后使用rangeToFormula方法将区域信息转换为区域字符串。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.bc1dee.png)
最后可以拼接输出。
2、参数为字符串 或 数值
可以直接从argument获取参数值。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.4156ed.png)
具体代码如下：

```javascript
FactorialFunction.prototype.evaluate = function (arg) {
  var length = arguments.length;
  for (var i = 1; i < length; i++) {
    var argument = arguments[i];
    if (typeof argument == "string" || typeof argument == "number") {
      console.log("参数" + i + "为" + argument);
    } else {
      var sheet = argument.getSource().getSheet();
      var sheetName = sheet.name();
      console.log("参数" + i + "sheetName为：" + sheet.name());
      var r = argument.getRow();
      var c = argument.getColumn();
      var rc = argument.getRowCount();
      var cc = argument.getColumnCount();
      var range = new GC.Spread.Sheets.Range(r, c, rc, cc);
      var string = GC.Spread.Sheets.CalcEngine.rangeToFormula(
        range,
        0,
        0,
        GC.Spread.Sheets.CalcEngine.RangeReferenceRelative.allRelative
      );
      var setFormulaString = "" + sheetName + "!" + string;
      console.log("参数" + i + "为" + setFormulaString);
    }
  }
  return "anything";
};
```
