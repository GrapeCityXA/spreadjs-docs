# undoStack

### 问题：怎么实现多步操作一键撤销?

***

#### 背景：

在一些使用场景下，用户希望在表单中做了的操作一键还原，而不是单步多次还原。

#### 解决方案：

思路：根据spread.undoManager().getUndoStack()获取撤消栈，对栈中的每一个操作根据spread.undoManager().undo() 进行撤消操作。

以下面的一个代码片段为例，代码来自于文章最后的dmeo。这个demo是基于学习指南中[行为指南](https://demo.grapecity.com.cn/spreadjs/SpreadJSTutorial/features/worksheet/actions/undo-manager/purejs)改的。
首先模拟多步操作，在初始化的的时候通过execute执行了5个命令，使其进入了undo栈里面。

```javascript

function executeCommand(spread) {
  var commandManager = spread.commandManager();
  let sheet = spread.getActiveSheet();
  let sheetName = sheet.name();
  spread.suspendPaint();
  commandManager.execute({
    cmd: "resizeColumn",
    sheetName: sheetName,
    size: 70,
    rowHeader: false,
    columns: [
      {
        firstCol: 0,
        lastCol: 5,
      },
    ],
  });
  commandManager.execute({
    cmd: "editCell",
    sheetName: sheetName,
    row: 0,
    col: 0,
    newValue: "Edit Cell",
    autoFormat: true,
  });
  commandManager.execute({
    cmd: "resizeRow",
    sheetName: sheetName,
    rows: [
      {
        firstRow: 0,
        lastRow: 5,
      },
    ],
    size: 30,
    columnHeader: false,
  });

  commandManager.execute({
    cmd: "clearValues",
    sheetName: "Sheet1",
    ranges: [new GC.Spread.Sheets.Range(3, 2, 2, 2)],
  });

  commandManager.execute({
    cmd: "renameSheet",
    sheetName: "Sheet1",
    name: "新名称",
  });

  spread.resumePaint();
}
```

**一键撤回**

“一键回退”只需要利用undo栈的长度，做了个循环，循环操作指定次数的undo接口，关键代码如下

```js
let undoManager = spread.undoManager();
var arr = undoManager.getUndoStack();
    for (var i = 0; i < arr.length; i++) {
      undoManager.undo();
      updateInfo(spread);
    }
```

**按步长回退**
同理，按步长回退，即按照指定的步长undo到某一步。只需要循环执行指定次数的undo方法。和上述代码类似
关键代码如下

```js
    let value = Number(maxSizeDom.value);
    if (!isNaN(value)) {
      for (var i = 0; i < value; i++) {
        spread.undoManager().undo();
        updateInfo(spread);
      }
    }
```

扩展：
想要一键重做：也可以根据spread.undoManager().getRedoStack()获取重做栈，然后循环spread.undoManager().redo() 进行一键重做操作。

具体代码可以参考[这篇文章](https://gcdn.grapecity.com.cn/showtopic-93229-1-1.html)。
