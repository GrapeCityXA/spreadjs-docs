# clear

### 问题：如何清除表单或工作簿的内容？

***

#### 背景：

在实际项目中，用户会有需要清除表单或者整个工作簿内容的需求，本文介绍清除表单或工作簿内容的方法及注意事项。

#### 表单清除

清除表单数据的API为：`sheet.clear(row,column,rowCount,columnCount,area,storageType)`
该API中各参数的含义为：

* row: 起始行索引
* column: 起始列索引
* rowCount: 待清除行数
* columnCount: 待清除列数
* area: 待清除区域
* storageTpye: 待清除数据类型

用户在清除当前表单中的内容时，一般调用的方法为：

```javascript
sheet.clear(0, 0, sheet.getRowCount(), sheet.getColumnCount(), GC.Spread.Sheets.SheetArea.viewport, GC.Spread.Sheets.StorageType.data);
```

当表单内容为纯数据时，可以顺利将表单中的所有内容删除。
但是当表单中包含单选框、复选框这些单元格时，发现无法一次清除所有内容，此时需要用到了[storageType](https://demo.grapecity.com.cn/spreadjs/help/api/enums/GC.Spread.Sheets.StorageType)这个参数。
[clear](https://demo.grapecity.com.cn/spreadjs/help/api/classes/GC.Spread.Sheets.Worksheet#clear)()方法的第六个参数[storageType](https://demo.grapecity.com.cn/spreadjs/help/api/enums/GC.Spread.Sheets.StorageType)，代表的是需要清除内容的类型，查阅API可知，该参数的可选值如下：

* altText :存储数据类型为替代文本。
* bindingPath :存储数据类型为数据绑定路径
* comment :存储数据类型为注释
* data :存储数据类型为纯值
* hyperlink :存储数据类型为超链接
* sparkline :存储数据类型为迷你图
* style :存储数据类型为样式
* tag :存储数据类型为标签

由此可知，一个表单中待清除的数据类型可能不止有数据，还有很多样式、注释、标签等信息，这些内容如果不清除的话都会影响后续的使用。
而storageType参数是支持用或关系组合传递的，举例要清除表单中的数据及样式时，可以使用如下方法：

```javascript
sheet.clear(0, 0, sheet.getRowCount(), sheet.getColumnCount(), GC.Spread.Sheets.SheetArea.viewport, GC.Spread.Sheets.StorageType.date || GC.Spread.Sheets.StorageType.style);
```

当然，也可以将所有类型进行组合传递。

#### 工作簿清除

清除工作簿内容时可以采用遍历工作簿中的表单，然后调用上文提到的clear方法清除表单数据。
除此之外，也可以使用如下方法：

```javascript
spread.clearSheets()
```

但是调用上述API之后发现工作簿中没有一张工作表了，这个时候可以调用：

```javascript
spread.addSheet(0,new GC.Spread.Sheets.Worksheet('custom'))
```

执行完成后，工作簿中就已经有工作表，可以进行正常的后续操作了。
