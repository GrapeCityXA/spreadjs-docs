# excelcolrowimp

此表总结了 SpreadJS 从 Excel 文件导入数据时如何处理行和列的设置。除非另有说明，这些属性均为 GC.Spread.Sheets.Worksheet 类的成员。

| **Excel 设置** | **SpreadJS 设置** | **备注** |
| -------- | ----------- | --- |
| 隐藏的列或行 | Sheet.[setRowVisible ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#setrowvisible)或 Sheet.[setColumnVisible](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#setcolumnvisible) | SpreadJS 从 Excel 导入此设置。 |
| 行高 | Sheet.[setRowHeight](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#setrowheight) | SpreadJS 从 Excel 导入此设置。 |
| 列宽 | Sheet.[setColumnWidth](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#setcolumnwidth) | SpreadJS 从 Excel 导入此设置。 |
| 行数或列数 | Sheet.[setRowCount ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#setrowcount)或 Sheet.[setColumnCount](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#setcolumncount) | 导入时，`rowCount` 和 `columnCount` 是最后一个非空的行和列。如果工作表中没有数据，行和列则为 `activeCell.row` 和列。 |
| 起始列和行 |  | 目前不支持。 |
