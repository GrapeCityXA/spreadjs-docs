# clipboardobjects

你可以从 Excel 中复制 Excel 样式和浮动对象，并将它们粘贴到 SpreadJS 的工作表中。这使得你无需导入整个电子表格，就能轻松复制 Excel 样式和浮动对象。你可以通过将 `allowCopyPasteExcelStyle` 属性设置为 `true` 来启用样式和对象的复制与粘贴功能。
## Excel 样式
将 **`allowCopyPasteExcelStyle`** 属性设置为 `true` 以允许复制和粘贴样式。

```JavaScript
spread.options.allowCopyPasteExcelStyle = true;
```

## 浮动对象
通过将 **`allowCopyPasteExcelStyle`** 属性设置为 `true`，还可以从 Excel 中复制图像、图表和形状等浮动对象，并将它们粘贴到 SpreadJS 工作表中。请注意，你可以将 Excel 中的图表和形状复制并作为图像粘贴到 SpreadJS 中。此功能在 SpreadJS 中默认已启用，但是，它不支持将图像从 SpreadJS 复制并粘贴到 Excel 中。
在将图像粘贴到 SpreadJS 工作表时，你可以在 Windows 和 Mac 系统上分别使用 Ctrl + V 和 Command + V 组合键，如下图所示。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/copy_image_spreadjs.f2abd6.gif)
你可以看到，在将原始图像粘贴到 SpreadJS 中时，其大小和内容没有受到影响。不过，你可以使用调整大小的控制点来调整粘贴后图像的大小。图像在工作表中的位置由 SpreadJS 的活动单元格决定。你可以在 SpreadJS 工作表中逐个复制粘贴图像，也可以从 Excel 中复制所有图像，并将它们作为一个大图像粘贴到工作表中。
