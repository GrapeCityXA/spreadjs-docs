# excelcellex

下表总结了SpreadJS导出到Excel格式的文件时如何处理单元格设置。 除非另有说明，否则这些函数在GC.Spread.Sheets.CellRange类中。

|  **单元格设置**  |  **Excel设置和备注**  |
|--- |--- |
|  **value** 或 **text**  | Excel使用此设置。 |
|  **bindingPath**  | Excel会忽略此设置。 这是SpreadJS特定。 |
|  **cellType**  | Excel会忽略此设置。 这是SpreadJS特定。 |
|  **backgroundImage**  | Excel会忽略此设置。 这是SpreadJS特定。 |
|  **backgroundImageLayout**  | Excel会忽略此设置。 这是SpreadJS特定。 |
|  **backColor**  | Excel使用此设置。 |
|  **borderLeft** , **borderTop** , **borderRight** , or **borderBottom**  | Excel使用此设置。 |
|  **foreColor**  | Excel使用此设置。 |
|  **hAlign** (文字水平对齐) | Excel使用此设置。 |
|  **vAlign** (文字垂直对齐) | Excel使用此设置。 |
|  **font**  | Excel使用此设置。 |
|  **formatter**  | Excel使用此设置。 |
|  **formula**  | Excel使用此设置。 |
|  **locked**  | Excel使用此设置。 |
|  **shrinkToFit**  | Excel使用此设置。 |
|  **tabStop**  | Excel会忽略此设置。 这是SpreadJS特定。 |
|  **textIndent**  | Excel使用此设置。 |
|  **themeFont**  | Excel使用此设置。 |
|  **validator**  | Excel使用此设置。 |
|  **wordWrap**  | Excel使用此设置。 |
