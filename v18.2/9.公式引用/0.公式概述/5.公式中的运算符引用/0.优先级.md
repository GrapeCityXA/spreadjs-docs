# orderofprecedence

当公式中存在多个运算符时，该公式会按照特定顺序执行运算。公式会根据公式中每个运算符或函数的特定顺序从左到右进行解析。你可以在公式中使用括号来确定运算的优先级。
如果在单个公式中组合使用多个运算符，运算将按照下表所示的顺序进行。一元运算优先于二元运算。如果一个公式包含优先级相同的运算符，则从左到右对这些运算符进行求值。若要更改求值顺序，请将需要先计算的公式部分用括号括起来；括号的优先级最高。当两个运算符的优先级相同时，公式从左到右进行求值。

| @cols=2:从高到低的运算优先级顺序 |
| ------------ | ------------ |
| 运算符 | 描述 |
| 从左到右 | 方向 |
| ( ) | 括号（用于分组） |
| – | 取反 |
| + | 正号 |
| % | 百分比 |
| ^ | 指数运算 |
| \* 和 / | 乘法和除法 |
| + 和 - | 加法和减法 |
| & | 连接 |
| =、<、>、<=、>=、<> | 比较 |
