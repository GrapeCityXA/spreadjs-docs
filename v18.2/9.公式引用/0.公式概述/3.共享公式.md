# shared-formula

SpreadJS 支持共享公式，因此用户可以使用 formula 方法将共享公式应用于一系列单元格。 
这避免了为范围内的每个单元格重复相同的公式，并确保在从 JSON 文件导入或导出以及输入公式时获得更好的性能。 它还有助于减少导出文件的大小并降低内存成本。
例如这样一种情况，您的工作表中填充了以下表格格式的数据：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/e89163df-9462-4186-9f56-3bcf7b915acb/image.a1d3a5.png)
比方说，您想在“总计”列中添加一个函数来计算每件商品的总价。
总价的计算公式为 数量\*价格，即E3单元格为“=C3\*D3”。
有两种方法可以做到这一点：

* **将公式应用于单个单元格**
    在此方法中，必须更新每一行的单元格引用，以便 Spread 单元格可以单独解析每个公式。 但对于数据量大、公式复杂的工作表，这可能会消耗大量时间。 您可能还需要添加额外的代码行并使用循环。
* **应用共享公式**
    第二种方法使用共享公式。 这将自动更新每行中的单元格引用并计算总数。
    我们没有为总计列中的每个单元格添加公式，而是使用共享公式“=C3\*D3”。 共享公式方法使用 Formula (value?: string, autoAdjustReference?: boolean) 函数，它提供 autoAdjustReference 参数。 可以将此参数设置为 true 以调整每个单元格的相对引用。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/e89163df-9462-4186-9f56-3bcf7b915acb/image.f35bb4.png)
    要使用共享公式，请指定要应用公式的范围。 本例中范围为[E3:E6]，可以使用getRange方法获取单元格的具体范围。 您还可以在公式方法中设置第一个单元格的值，即E3，函数将自动计算“总计”列中其余单元格的值。

以下代码片段描述了使用 formula 方法在工作表中实现共享公式：

```javascript
// Use the Shared formula by setting autoAdjustReference to true
sheet.getRange(2, 4, 4, 1).formula("=C3*D3", true);
```

让我们将 autoAdjustReference 参数设置为 false 并查看差异。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/e89163df-9462-4186-9f56-3bcf7b915acb/image.2659e6.png)
正如所观察到的，当参数为 false 时，只有 C3 和 D3 中的单元格值在单元格范围 E3 到 E6 中被获取和更新。
