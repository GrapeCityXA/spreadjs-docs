# resulterror

由于输入无效或公式无效而可能在单元格中显示的值如下：

| 值 | 说明 |
| ---- | ---- |
| #DIV/0! | 当公式中包含除以零的运算，或者公式在除数中使用了对空白单元格或包含零的单元格的单元格引用时，会显示此值。 |
| #N/A | 当某个值对于函数或公式不可用时，会显示此值。 |
| #NAME? | 当公式中的文本未被识别、函数名称拼写错误，或者在包含文本时未使用双引号时，会显示此值。当你在单元格区域引用中省略冒号（:）时，也可能会出现这种情况。 |
| #NULL! | 当你指定了两个不相交的区域的交集时，会显示此值。可能的原因包括引用运算符输入错误或单元格引用输入错误。 |
| #NUM! | 当公式或函数中的数字无法计算时（例如公式产生的数字太大或太小而无法表示，或者在需要数字的函数中使用了不可接受的参数），会显示此值。如果你正在使用迭代函数（如 IRR 或 RATE）且该函数无法找到结果，也会显示此值。 |
| #REF! | 当单元格引用无效，或者你删除了公式所引用的单元格时，会显示此值。 |
| #VALUE! | 当使用了错误类型的参数或操作数时，会显示此值，例如当公式需要数字或逻辑值时却使用了文本，或者使用了区域而不是单个值。 |
