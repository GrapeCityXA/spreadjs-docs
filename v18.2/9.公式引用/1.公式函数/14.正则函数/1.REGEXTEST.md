# match

## 总结
REGEXTEST 函数可让你检查所提供文本的任何部分是否与正则表达式（“regex”）匹配。如果匹配，它将返回 TRUE；如果不匹配，则返回 FALSE。

## 语法
```javascript
=REGEXTEST(text, pattern, [case_sensitivity])
```

## 参数
| 参数 | 说明 |
| ---- | ---- |
| **text**<br>（必填） | 要进行匹配的文本，或者是包含该文本的单元格引用。 |
| **pattern**<br>（必填） | 描述你想要匹配的文本模式的正则表达式（“regex”）。 |
| **case\_sensitivity** | 确定匹配是否区分大小写。<br>**0**：（默认值）区分大小写<br>**1**：不区分大小写 |

## 备注
返回值：`TRUE` 或 `FALSE`。即正则表达式的测试结果。

## 示例
```cpp
=REGEXTEST("abc","a") // 结果为 TRUE
=REGEXTEST("abc","[A-Z]") // 结果为 FALSE
=REGEXTEST("abc","[A-Z]", 1) // 结果为 TRUE
=REGEXTEST("abc","[0-9]") // 结果为 FALSE
```

> REGEXTEST 函数与 Excel 的 REGEXTEST 函数兼容。同时，之前版本的 SJS.REGEXMATCH 函数已被弃用，但仍保持向后兼容性。这两个函数的区别如下：

| <br> | **REGEXTEST 函数** | **SJS.REGEXMATCH 函数** |
| --- | ------------------ | ----------------------- |
| 参数类型 | 仅支持用 0 或 1 来指定匹配是否区分大小写。<br>`=REGEXTEST("abc","[A-Z]", 1)` | 使用字符串修饰符。<br>`=SJS.REGEXMATCH("abc","[A-Z]", "i")` |
| 多行匹配 | 仅可使用正则表达式匹配<br>`=REGEXTEST("abc`<br>`ABC","\n[A-Z]")` | 可与修饰符“m”配合使用<br>`=SJS.REGEXMATCH("abc`<br>`ABC","^[A-Z]","m")` |
| 处理非字符串参数 | 接受所有类型。<br>`=REGEXTEST(2024,24)` | 对于非字符串输入返回 #VALUE! 。 |
