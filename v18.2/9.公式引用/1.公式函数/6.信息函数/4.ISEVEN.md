# ISEVEN

如果参数 value 为偶数，返回 TRUE，否则返回 FALSE。



#### 语法

ISEVEN( *cellreference* )

ISEVEN( *value* )

ISEVEN( *expression* )



#### 参数

参数可以是单元格引用，数字或文本值或表达式。



#### 注释

如果参数 value 为偶数，返回 TRUE，否则返回 FALSE。如果 value 为非数值型，则 ISEVEN 返回 #VALUE！ 。

使用此功能可以测试单元格、数字、文本值、函数或表达式的内容。



#### 数据类型

接受数值数据。返回布尔（TRUE或FALSE）数据。



#### 示例

ISEVEN(B3)

ISEVEN(R1C2)

ISEVEN(574) 得出结果 TRUE

ISEVEN(9) 得出结果 FALSE

ISEVEN(2.4) 得出结果 TRUE

ISEVEN(3.6) 得出结果 FALSE

ISEVEN(ROUND(3.6)) 得出结果 TRUE
