# SCATTERSPARKLINE

此函数返回用于表示散点迷你图的数据集。



#### 语法

SCATTERSPARKLINE( *points1, [points2, minX, maxX, minY, maxY, hLine, vLine, xMinZone, xMaxZone, yMinZone, yMaxZone, tags, drawSymbol, drawLines, color1, color2, dash]* )



#### 参数

| 参数 | 描述 |
|--- |--- |
|  *Points1*  | 第一个 xy 数据系列。<br /><br />如果行数大于或等于列数，则使用前两列的数据。第一列包含 x 值，第二列包含 y 值。<br /><br />如果行数小于列数，则使用前两行的数据。第一行包含 x 值，第二行包含 y 值。<br /><br /> |
|  *Points2*  | (可选) 第二个 XY 数据系列。<br /><br />如果行数大于或等于列数，则使用前两列的数据。第一列包含 x 值，第二列包含 y 值。<br /><br />如果行数小于列数，则使用前两行的数据。第一行包含 x 值，第二行包含 y 值。<br /><br /> |
|  *MinX*  | (可选) 两个系列的 x 最小值限制，如果省略，每个系列都有自己的值。 |
|  *MaxX*  | (可选) 两个系列的 x 最大值限制，如果省略，每个系列都有自己的值。 |
|  *MinY*  | (可选)  两个系列的 y 最小值限制，如果省略，每个系列都有自己的值。 |
|  *MaxY*  | (可选) 两个系列的 y 最大值限制，如果省略，每个系列都有自己的值。 |
|  *HLine*  | (可选) 横轴位置，省略则无直线。 |
|  *VLine*  | (可选) 纵轴位置，省略则无直线。 |
|  *XMinZone*  | (可选) 灰色区域的x最小值，如果省略这四个参数中的任何一个，则没有灰色区域。 |
|  *XMaxZone*  | (可选)  灰色区域的x-最大值，如果省略这四个参数中的任何一个，则没有灰色区域。 |
|  *YMinZone*  | (可选)灰色区域的y最小值，如果省略这四个参数中的任何一个，则没有灰色区域。 |
|  *YMaxZone*  | (可选) 灰色区域的y最大值，如果省略这四个参数中的任何一个，则没有灰色区域。 |
|  *Tags*  | (可选) 如果此选项为true，则将第一个系列的 y 值最大值的点标记为“#0000FF”，并将第一个系列的 y 值最小值的点标记为“#CB0000”。默认值为false。 |
|  *DrawSymbol*  | (可选)如果此选项为true，则将每个点绘制为符号。默认值是true。<br /><br />第一个系列的符号是圆形，第二个系列的符号是一个正方形。<br /><br /> |
|  *DrawLines*  | (可选)如果此选项为true，则将每个系列中的每个点按顺序连接起来。默认值为false. |
|  *Color1*  | (可选) 第一个点系列的颜色字符串。默认值为“#969696”。 |
|  *Color2*  | (可选)  第二个点系列的颜色字符串。默认值为“#CB0000”。 |
|  *Dash*  | (可选) 如果此选项为true，则线为虚线；否则，该行是整行。默认值为false. |



#### 数据类型

返回sparkline.



#### 例子

activeSheet.setFormula(2, 2, '=SCATTERSPARKLINE(A3:B11,,0,8,0,150,0,0,0,8,100,150,TRUE,TRUE,FALSE,"FD8E2C")');
