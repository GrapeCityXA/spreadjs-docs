# compatibility-functions

Spread 提供以下兼容性函数，按字母顺序列出。

| 函数 | 描述 |
|--- |--- |
| [BETADIST](gcdocsite__documentlink?toc-item-id=adf548ea-8ab6-4ef4-a79c-f2c875597ace) | 此函数计算累积 Beta 分布函数。 |
| [BETAINV](gcdocsite__documentlink?toc-item-id=e9ffbd0b-ad23-493b-8d95-37b88e2a45c0) | 此函数计算累积 beta 分布函数的倒数。 |
| [BINOMDIST](gcdocsite__documentlink?toc-item-id=aa07887a-f54b-48cb-826c-b912191bad4b) | 此函数计算单项二项式分布概率。 |
| [CHIDIST](gcdocsite__documentlink?toc-item-id=842b5ce9-f973-4961-be95-59021629df72) | 此函数计算卡方分布的单尾概率。 |
| [CHIINV](gcdocsite__documentlink?toc-item-id=1689b7fc-b0b6-4bd6-a337-0b5e9a929884) | 此函数计算卡方分布的单尾概率的倒数。 |
| [CHITEST](gcdocsite__documentlink?toc-item-id=1aad46b5-bdf2-42b8-bbc8-0f219c545c5b) | 此函数计算卡方分布的独立性检验。 |
| [CONFIDENCE](gcdocsite__documentlink?toc-item-id=dddea777-c186-4cca-957c-d55fd6c4ee3c) | 此函数返回总体均值的置信区间。 |
| [COVAR](gcdocsite__documentlink?toc-item-id=45da4f1a-04af-44ed-9b2d-43cf3922e33c) | 此函数返回协方差，即两组数字中每个数据点对的偏差乘积的平均值。 |
| [CRITBINOM](gcdocsite__documentlink?toc-item-id=76136f70-8673-4c71-bd00-66db92c86c9d) | 此函数返回标准二项式，即累积二项式分布大于或等于标准值的最小值。 |
| [EXPONDIST](gcdocsite__documentlink?toc-item-id=3e05dc59-db7f-4fc8-ad31-76387934eff5) | 此函数返回指数分布或概率密度。 |
| [FDIST](gcdocsite__documentlink?toc-item-id=ba98a6de-1a40-417a-8411-a632e2bd2607) | 此函数计算 F 概率分布，以查看两组数据之间的多样性程度。 |
| [FLOOR](gcdocsite__documentlink?toc-item-id=36b7a956-d6b0-47a8-9269-0343b8596c48) | 此函数将数字向下舍入到指定值的最接近倍数。 |
| [FTEST](gcdocsite__documentlink?toc-item-id=726d0429-27e3-4d58-a90f-bf0fc1f1cc85) | 此函数返回 F 检验的结果，该结果返回两个数组中的方差没有显着差异的单尾概率。 |
| [GAMMADIST](gcdocsite__documentlink?toc-item-id=6ea12c74-77c2-4c4a-b235-a164917ad0f7) | 此函数返回伽马分布。 |
| [GAMMAINV](gcdocsite__documentlink?toc-item-id=c5f364eb-cc89-4bd8-b3a6-b8b72a5b462b) | 此函数返回伽马累积分布的倒数。 |
| [HYPGEOMDIST](gcdocsite__documentlink?toc-item-id=ae366265-9273-4c60-a9cd-f84a80a204e5) | 此函数返回超几何分布。 |
| [LOGINV](gcdocsite__documentlink?toc-item-id=04932fc7-8d88-45d6-ba82-5a47a06c2bfa) | 此函数返回 x 的对数正态累积分布函数的倒数，其中 LN(x) 服从指定均值和标准差的正态分布。 |
| [LOGNORMDIST](gcdocsite__documentlink?toc-item-id=674158aa-a12a-476b-ad02-e49ccb744d2f) | 此函数返回 x 的累积自然对数正态分布，其中 LN(x) 是具有指定均值和标准差的正态分布。分析使用此函数进行对数变换的数据。 |
| [MODE](gcdocsite__documentlink?toc-item-id=b26d1adb-1e9d-4b19-a0ee-62e95069c06c) | 此函数返回一组数据中出现频率最高的值。 |
| [NEGBINOMDIST](gcdocsite__documentlink?toc-item-id=ee6b213a-f0fb-4f1c-bb5f-1be92aa655fb) | 此函数返回负二项式分布。 |
| [NORM.INV](gcdocsite__documentlink?toc-item-id=29f571a5-4f81-4e58-9c16-dccd71d52f70) | 此函数返回给定均值和标准差的正态累积分布的倒数。 |
| [NORMDIST](gcdocsite__documentlink?toc-item-id=16d98fe4-0a17-4ad5-9283-20e3bce7d16b) | 此函数返回指定均值和标准差的正态累积分布。 |
| [NORMSDIST](gcdocsite__documentlink?toc-item-id=9156b9ad-0535-4c6d-a1ad-665634a4867c) | 此函数返回标准正态累积分布函数。 |
| [NORMSINV](gcdocsite__documentlink?toc-item-id=32557bf3-2e1d-4cd5-892c-2fd6296998bf) | 此函数返回标准正态累积分布的倒数。该分布的均值为 0，标准差为 1。 |
| [PERCENTILE](gcdocsite__documentlink?toc-item-id=dd1060d2-ea41-42e3-b878-ea837945d78b) | 此函数返回范围内值的第 n 个百分位数。 |
| [PERCENTRANK](gcdocsite__documentlink?toc-item-id=33749d94-0683-4d8a-a982-9877dd2416b7) | 此函数返回数据集中某个值的排名，作为数据集的百分比。 |
| [POISSON](gcdocsite__documentlink?toc-item-id=e59e6031-6a1f-444b-9b8b-d3da9d18e873) | 此函数返回泊松分布。 |
| [QUARTILE](gcdocsite__documentlink?toc-item-id=677bf5b6-f6da-42f6-81c8-3d78fbe7747a) | 此函数返回值是数据集的哪个四分位数（哪个四分之一或 25%）。 |
| [RANK](gcdocsite__documentlink?toc-item-id=a3075fde-cca0-488e-a584-66153eecd857) | 此函数返回一个数字在一组数字中的排名。如果要对集合进行排序，则数字的排名将是它在列表中的位置。 |
| [STDEV](gcdocsite__documentlink?toc-item-id=b23020ff-6824-4e7d-9f7f-0c7592d41b7d) | 此函数返回一组数字的标准偏差。 |
| [STDEVP](gcdocsite__documentlink?toc-item-id=6a38093b-c7fd-44be-a752-ab5e86076878) | 此函数返回整个指定总体（数值）的标准偏差。 |
| [TDIST](gcdocsite__documentlink?toc-item-id=fb86c028-b0d1-46d6-b8f2-2a4bab0758b2) | 此函数返回 t 分布的概率。 |
| [TINV](gcdocsite__documentlink?toc-item-id=fb372308-06de-4053-bcb6-84d084a97f05) | 此函数返回作为概率和自由度函数的学生 t 分布的 t 值。 |
| [TTEST](gcdocsite__documentlink?toc-item-id=00d4c6c3-178f-42e4-8c33-439244aafa00) | 此函数返回与 t 检验相关的概率。 |
| [VAR](gcdocsite__documentlink?toc-item-id=9fe7fd4b-7d51-4d56-a5e7-8910cfccd2ce) | 此函数返回基于总体样本的方差，该样本仅使用数值。 |
| [VARP](gcdocsite__documentlink?toc-item-id=fbdccad0-8deb-415f-a3c4-9105bebcb7c8) | 此函数返回基于整个总体的方差，该总体仅使用数值。 |
| [WEIBULL](gcdocsite__documentlink?toc-item-id=dfd04094-1f22-461b-b54b-b76dd3dbf5c5) | 此函数返回二参数威布尔分布，常用于可靠性分析。 |
| [ZTEST](gcdocsite__documentlink?toc-item-id=a7b36e2f-94dd-481f-a710-cfe523779cbe) | 此函数返回 z 检验的显着性值。z 检验针对数据集生成 x 的标准分数，并返回正态分布的双尾概率。 |
