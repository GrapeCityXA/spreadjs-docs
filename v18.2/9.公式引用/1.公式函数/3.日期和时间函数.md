# date-time-functions

Spread 提供以下日期和时间函数，按字母顺序列出。

| 函数 | 描述 |
|--- |--- |
| [DATE](gcdocsite__documentlink?toc-item-id=d0daa1c5-20d8-4977-b09e-feeb7606cbdb) | 此函数返回特定日期的 DateTime 对象，由年、月和日指定。/td> |
| [DATEDIF](gcdocsite__documentlink?toc-item-id=3b21fb34-b91a-42be-bd2c-edff8db6f478) | 此函数返回两个日期之间的天数、月数或年数。 |
| [DATEVALUE](gcdocsite__documentlink?toc-item-id=7824fe2e-539b-4075-9b18-3e0490e601a6) | 此函数返回指定日期的 DateTime 对象。 |
| [DAY](gcdocsite__documentlink?toc-item-id=8fe11c96-36e7-4799-bef0-87247e47d0c2) | 此函数返回与指定日期对应的月份的天数（整数 1 到 31）。 |
| [DAYS](gcdocsite__documentlink?toc-item-id=9308750a-792e-4d5e-9f8b-9bfece08aaf3) | 此函数返回两个日期之间的天数。 |
| [DAYS360](gcdocsite__documentlink?toc-item-id=3dc1688a-d868-4eee-9a9d-fa40e02b5bec) | 此函数返回基于 360 天一年的两个日期之间的天数。 |
| [EDATE](gcdocsite__documentlink?toc-item-id=cc3148c9-daee-4971-b7a2-c400ddabf54b) | 此函数计算指定日期之前或之后指定月数的日期。 |
| [EOMONTH](gcdocsite__documentlink?toc-item-id=67403473-e861-438b-b2b1-69e96454f25e) | 此函数计算该月的最后一天（月末）的日期，即开始日期之前或之后指定的月数。 |
| [HOUR](gcdocsite__documentlink?toc-item-id=7333f0df-2c97-4bed-a578-455922885c15) | 此函数返回对应于指定时间的小时。 |
| [ISOWEEKNUM](gcdocsite__documentlink?toc-item-id=d6cd1fd5-974f-43b5-bddb-e55e6bc34f9e) | 此函数返回给定日期一年中 ISO 周数的编号。 |
| [MINUTE](gcdocsite__documentlink?toc-item-id=eed9dfb5-50e1-4295-975e-f18b95c702f5) | 此函数返回指定时间对应的分钟。 |
| [MONTH](gcdocsite__documentlink?toc-item-id=e8216948-2ea8-4830-b7ad-bc824ce2b236) | 此函数返回与指定日期值对应的月份。 |
| [NETWORKDAYS](gcdocsite__documentlink?toc-item-id=c2463bd5-8861-44e6-ad4f-9fe6f34bf054) | 此函数返回开始日期和结束日期之间的完整工作日总数。 |
| [NETWORKDAYS.INTL](gcdocsite__documentlink?toc-item-id=e5bf5fdc-a2d1-42f2-8321-61403f7942ec) | 此函数使用参数返回两个日期之间的工作日数以指示假期和周末天数。 |
| [NOW](gcdocsite__documentlink?toc-item-id=f33df289-9f83-4c48-b80a-593c6062d6ca) | 此函数返回当前日期和时间。 |
| [SECOND](gcdocsite__documentlink?toc-item-id=fea294f8-c124-42ee-ad2e-88f582c7b845) | 此函数返回指定时间的秒数（0 到 59）值。 |
| [TIME](gcdocsite__documentlink?toc-item-id=99b77f8a-eafd-40a8-9e8c-1225ec44232d) | 此函数返回指定时间的 TimeSpan 对象. |
| [TIMEVALUE](gcdocsite__documentlink?toc-item-id=7d7b7349-fb16-41ee-9a19-9b45e3b7a732) | 此函数返回由文本字符串表示的时间的 TimeSpan 对象。 |
| [TODAY](gcdocsite__documentlink?toc-item-id=ee6ac51e-9d39-4d90-82b3-a07d6e1c6ff2) | 此函数返回当前日期的日期和时间。 |
| [WEEKDAY](gcdocsite__documentlink?toc-item-id=6d58b42a-2aa7-4ed8-9989-c0e4fd239600) | 此函数返回与指定日期的星期几对应的数字。 |
| [WEEKNUM](gcdocsite__documentlink?toc-item-id=09016dab-62fd-42d1-9e40-f2e5bb971cf7) | 此函数返回一个数字，以数字方式指示一年中的第几周。 |
| [WORKDAY](gcdocsite__documentlink?toc-item-id=6a85628c-c3cc-4319-b208-e03885a406ff) | 此函数返回开始日期之前或之后的工作日数。 |
| [WORKDAY.INTL](gcdocsite__documentlink?toc-item-id=51cc2605-bcf7-45fa-a944-7df18dedcdef) | 此函数使用自定义周末参数返回多个工作日之前或之后的日期序列号。这些参数表示周末和节假日。 |
| [YEAR](gcdocsite__documentlink?toc-item-id=ddcbf02f-4d80-4135-9e4e-9386f54dd469) | 此函数以整数形式返回指定日期的年份。 |
| [YEARFRAC](gcdocsite__documentlink?toc-item-id=7ab9b7dd-ef7b-4791-a4ec-f1f2c707894e) | 此函数返回由开始日期和结束日期之间的整天数表示的年份的分数。 |
