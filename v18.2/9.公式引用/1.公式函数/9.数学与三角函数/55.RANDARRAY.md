# randarray

此函数返回一组随机数字。



#### 语法

RANDARRAY([rows],[columns],[min],[max],[integer])



#### 参数

RANDARRAY function has the following arguments:

| 参数 | 描述 |
|--- |--- |
| rows | 要返回的行数（如果未指定，则使用默认值1）。 |
| columns | 要返回的列数（如果未指定，则使用默认值1）。 |
| min | 指定要生成的最小值（如果未指定，则使用默认值0）。 |
| max | 指定要生成的最大值（如果未指定任何内容，则使用默认值1）。 |
| integer | 返回整数或十进制值 |



#### 数据类型

接受行数和列数。返回随机数数组。

RANDARRAY是易变函数。这意味着每次表单计算时，RANDARRAY函数都会重新计算新值。
> **注:** RANDARRAY是易变函数。这意味着每次表单计算时，RANDARRAY函数都会重新计算新值。 


#### 注释

默认情况下，如果用户未指定行或列参数，则RANDARRAY函数将返回0到1之间的单个值。此外，如果未指定最小和最大参数，则RANDARRAY函数将返回一个介于0和1的随机值。最小数参数必须小于最大数，否则 RANDARRAY 将返回 #VALUE! 错误。



#### 示例

例如，下图中的单元格A8包含公式“ = RANDARRAY（5,3）”，并返回介于0和1之间的一组随机值。

RANDARRAY(5,3,1,100) 返回1到100之间的一系列随机十进制值。

RANDARRAY(5,3,1,100,TRUE) 返回1到100之间的一系列随机整数。



#### 可用版本

该函数在SpreadJS 13或更高版本中可用。
