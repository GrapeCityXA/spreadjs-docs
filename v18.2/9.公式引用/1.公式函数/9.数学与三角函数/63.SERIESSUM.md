# SERIESSUM

此函数返回幂级数的和



#### 语法

SERIESSUM( *x* , *n* , *m* , *coeff* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *x*  | 幂级数的输入值。 |
|  *n*  | x 的首项乘幂。 |
|  *m*  | 级数中每一项的乘幂 n 的步长增加值。 |
|  *coeff*  | 与 x 的每个连续乘幂相乘的一组系数。 |
