# TRUNC

此函数将数字的小数部分截去，返回整数。



#### 语法

TRUNC( *value* , *precision* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *value*  | 需要截尾取整的数字。 |
|  *precision*  | 用于指定取整精度的数字。 precision 的默认值为 0（零）。 |



#### 注释

RUNC 和[INT](gcdocsite__documentlink?toc-item-id=1906dcdb-ded5-431c-bf2b-c51f7ff45350)的相似之处在于两者都返回整数。 TRUNC 删除数字的小数部分。 INT 根据数字小数部分的值将该数字向下舍入为最接近的整数。

INT 和 TRUNC 仅当作用于负数时才有所不同：TRUNC(-4.3) 返回 -4，而 INT(-4.3) 返回 -5，因为 -5 是更小的数字。



#### 数据类型

接受两个参数的数值数据。返回数值数据。



#### 示例

TRUNC(B16)

TRUNC(R16C2)

TRUNC(5.745) 得出结果 5

TRUNC(-5.745) 得出结果 -5

TRUNC(5.745,2) 得出结果 5.74

TRUNC(PI()) 得出结果 3
