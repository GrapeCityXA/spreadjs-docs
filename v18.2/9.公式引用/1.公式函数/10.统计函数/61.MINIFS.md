# MINIFS

此函数返回一组给定条件或标准指定的单元格之间的最小值。



#### 语法

MINIFS( *max_range, range1, critera1, [range2,criteria2],..* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *min_range*  | 确定最小值的实际单元格区域。 |
|  *range1*  | 是一组用于条件计算的单元格。 |
|  *criteria1*  | 用于确定哪些单元格是最小值的条件，格式为数字、表达式或文本。 |
|  *range2, criteria2...*  | [可选] 附加区域及其关联条件。 |



#### 注释

min_range 和 rangeN 参数的大小和形状必须相同，否则这些函数会返回 #VALUE! 错误。

如果单元格不符合指定的条件，则此函数将返回0。



#### 数据类型

接受所有参数的数值数据，表达式或文本。返回数值数据。



#### 示例

MINIFS(A3:A7,B3:B7,23) 得出结果 0.

MINIFS(A3:A7,B3:B7,325) 得出结果 325.
