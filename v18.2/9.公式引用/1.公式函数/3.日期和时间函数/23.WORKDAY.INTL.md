# WORKDAY.INTL

此函数返回指定的若干个工作日之前或之后的日期的序列号（使用自定义周末参数）。



#### 语法

WORKDAY.INTL( *startdate* , *numdays* , *weekend,holidays* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *startdate*  | 开始日期（将被截尾取整）。 |
|  *numdays*  | Startdate 之前或之后的工作日的天数。如果不是整数则截尾取整。 |
|  *weekend*  | [可选]指示一周中属于周末的日子和不作为工作日的日子。 |
|  *holidays*  | [可选] 一组可选的日期，表示要从工作日日历中排除的一个或多个日期。 |

weekend 数值表示以下周末日:

| 数字 | 日期 |
|--- |--- |
| 1 或 省略 | 星期六、星期日 |
| 2 | 星期日、星期一 |
| 3 | 星期一、星期二 |
| 4 | 星期二、星期三 |
| 5 | 星期三、星期四 |
| 6 | 星期四、星期五 |
| 7 | 星期五、星期六 |
| 11 | 仅星期日 |
| 12 | 仅星期一 |
| 13 | 仅星期二 |
| 14 | 仅星期三 |
| 15 | 仅星期四 |
| 16 | 仅星期五 |
| 17 | 仅星期六 |



#### 注释

Weekend字符串值的长度为七个字符，并且字符串中的每个字符表示一周中的一天（从星期一开始）。 1 表示非工作日，0 表示工作日。 在字符串中仅允许使用字符 1 和 0。 1111111 是无效字符串。

周末和节假日不被认为是工作日。



#### 数据类型

接受数值、字符串或DateTime对象数据。返回数值数据。



#### 示例

WORKDAY.INTL(A2,A4)

WORKDAY.INTL(R2C1,R5C5)

WORKDAY.INTL(A1,A2,A5:A7)
