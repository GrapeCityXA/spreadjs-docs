# DURATION

此函数返回 $100 的假定值的 macauley 修正期限持续时间。.



#### 语法

DURATION( *settlement* , *maturity* , *coupon* , *yield* , *frequency* , *basis* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *settlement*  | 有价证券的结算日。 |
|  *maturity*  | 有价证券的到期日。 |
|  *coupon*  | 有价证券的年息票利率。 |
|  *yield*  | 有价证券的年收益率。 |
|  *frequency*  | 年付息次数。 如果按年支付，frequency = 1；按半年期支付，frequency = 2；按季支付，frequency = 4。 |
|  *basis*  | [可选] 要使用的日计数基准类型。参考[Day Count Basis](gcdocsite__documentlink?toc-item-id=23b72e94-94be-44ed-9302-d582747f59dd)。 |



#### 注释

如果结算或到期日期不是有效日期，则 DURATION 返回 #VALUE！ 。

如果 frequency 是除1、2或4以外的任何数字，则 DURATION 返回 #NUM！ 。

Settlement、maturity、frequency 和 basis 将被截尾取整。

如果coupon < 0 或 yield < 0，则 DURATION 返回 #NUM！ 。

如果settlement≥maturity，则 DURATION 将返回 #NUM！ 。



#### 数据类型

接受数值和DateTime对象数据。返回数值数据。



#### 示例

DURATION(C1,C2,C3,C4,C5,C6)

DURATION(R5C2,R2C4,R3C1,R4C1,R5C1)
