# PRICE

返回定期付息的面值 ￥100 的有价证券的价格。



#### 语法

PRICE( *settlement,maturity,rate,yield,redeem,frequency,basis* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *settle*  | 有价证券的结算日。 |
|  *maturity*  | 有价证券的到期日。 |
| rate | 有价证券的年息票利率。 |
| yield | 有价证券的年收益率。 |
| redeem | 面值 ￥100 的有价证券的清偿价值。 |
| frequency | 年付息次数。如果按年支付，frequency = 1；按半年期支付，frequency = 2；按季支付，frequency = 4。 |
|  *basis*  | [可选] 要使用的日计数基准类型。请参考[Day Count Basis](gcdocsite__documentlink?toc-item-id=23b72e94-94be-44ed-9302-d582747f59dd)。 |



#### 注释

如果结算或到期日期不是有效的日期，返回 #VALUE！ 。

如果 frequency 是除1、2或4以外的任何数字，返回 #NUM！ 。

settle、maturity、last 和 basis 将被截尾取整。

如果settle≥maturity，返回 #NUM！ 。

如果 rate < 0 或 yield < 0，则返回错误值 #NUM!。

如果 basis < 0 或 basis > 4，则返回错误值 #NUM!。



#### 数据类型

接受数值数据和日期。返回数值数据。



#### 示例

PRICE(A3,A4,A5,A6,A7,A8,A9)
