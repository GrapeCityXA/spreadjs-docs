# ODDFPRICE

此函数返回首期付息日不固定（长期或短期）的面值 ￥100 的有价证券价格。



#### 语法

ODDFPRICE( *settle,maturity,issue,first,rate,yield,redeem,freq,basis* )



#### 参数

该函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *settle*  | 有价证券的结算日。 |
|  *maturity*  | 有价证券的到期日。 |
| issue | 有价证券的发行日。 |
| first | 有价证券的首期付息日。 |
| rate | 有价证券的利率。 |
| yield | 有价证券的年收益率。 |
| redeem | 面值 ￥100 的有价证券的清偿价值。 |
| freq | 年付息次数。 |
|  *basis*  | [可选] 要使用的日计数基准类型。 请参考[Day Count Basis](gcdocsite__documentlink?toc-item-id=23b72e94-94be-44ed-9302-d582747f59dd)。 |



#### 注释

如果 settle、maturity、issue 或 first 不是有效日期，则 ODDFPRICE 返回 错误值 #VALUE!。



#### 数据类型

接受数值数据或日期。返回数值数据。



#### 示例

ODDFPRICE(A1,A2,A3,A4,A5,A6,A7,A8,A9)
