# trimrange

此函数会从某个区域或数组的外边缘排除所有空行和/或空列。

## 语法

```javascript
=TRIMRANGE(range,[trim_rows],[trim_cols])   
```

## 参数

TRIMRANGE 函数会从某个区域或数组的边缘开始扫描，直到找到一个非空单元格（或值），然后排除那些空行或空列。

| 参数 | 说明 |
| --- | --- |
| **range**<br>必填 | 要修剪的区域（或数组） |
| **trim\_rows**<br>[可选] | 确定应修剪哪些行<br>0 - 不修剪<br>1 - 修剪开头的空行<br>2 - 修剪末尾的空行<br>3 - 修剪开头和末尾的空行（默认值） |
| **trim\_columns**<br>[可选] | 确定应修剪哪些列<br>0 - 不修剪<br>1 - 修剪开头的空列<br>2 - 修剪末尾的空列<br>3 - 修剪开头和末尾的空列（默认值） |

## 备注

返回值：RangeReference（区域引用）。一个已修剪的区域。
TRIMRANGE 函数不适用于像 **=Sheet1:Sheet3!A:A** 这样的三维引用。SpreadJS 会自动将公式 `=SUM(Sheet1:Sheet3!A.:.A)` 更正为 `=SUM(Sheet1:Sheet3!A:A)`
TRIMRANGE 不能直接用于创建动态数据透视表。
`.:.` `:.` `.:` 不是运算符，所以 `=A1.:.INDIRECT("A10")` 将是一个无效公式。而可以使用 `=TRIMRANGE(A1:INDIRECT("A10"))`。

> **重大变更**
> 在 V18.1.0 版本之前，A1. 是一个有效的自定义名称，因此公式 =A1.:A10 表示自定义名称 A1. 和 A10 之间的区域。
> 在 V18.1.0 及更高版本中，公式 =A1.:A10 的计算方式已更改为修剪 A1 到 A10 的区域。
> =A1.:AAA 在之前的版本中是一个有效公式，但在 v18.1.0 及更高版本中会出现解析错误。

## 修剪引用

修剪引用（也称为 Trim Refs）是一组速记表示法，可让你从某个区域中修剪空行和空列，而无需显式使用 TRIMRANGE 函数。
修剪引用通过添加点号（`.`）来修改传统的冒号（`:`）区域运算符，以指定你想要如何修剪该区域。修剪引用有三种类型：

| **修剪引用类型** | **语法** | **等效的 TRIMRANGE** | **说明** |
| ------ | --- | ------------- | --- |
| 全部修剪 | `A1.:.E10` | `=TRIMRANGE(A1:E10, 3, 3)` | 从该区域中修剪开头和末尾的空白部分。 |
| 修剪末尾空白 | `A1:.E10` | `=TRIMRANGE(A1:E10, 2, 2)` | 仅从该区域中修剪末尾的空白部分。 |
| 修剪开头空白 | `A1.:E10` | `=TRIMRANGE(A1:E10, 1, 1)` | 仅从该区域中修剪开头的空白部分。 |
