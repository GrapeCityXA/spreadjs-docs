# HLOOKUP

此函数在表格的首行或数值数组中搜索值，然后返回表格或数组中指定行的所在列中的值。



#### 语法

HLOOKUP( *value* , *array* , *row* , *approx* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *value*  | 要在表格的第一行中查找的值。 |
|  *array*  | 在其中查找数据的信息表。 |
|  *row*  | array 中将返回匹配值的行号。 |
|  *approx*  | [可选] 一个逻辑值，指定希望 HLOOKUP 查找精确匹配值还是近似匹配值。 |



#### 注释

如果为approx为False，则 HLOOKUP 将查找精确匹配值。 如果找不到精确匹配值，则返回错误值 #N/A。

如果approx为TRUE 或省略，则返回小于 value 的最大值。

此功能类似于[ VLOOKUP ](gcdocsite__documentlink?toc-item-id=9d503391-0bfa-4f93-8b24-3ec827da89c1)，不同之处在于它按行而不是按列搜索。



#### 数据类型

接受数值或字符串数​​据。返回数值数据。



#### 示例

HLOOKUP("Test",A1:D5,3,TRUE)
