# logical-functions

Spread 提供以下逻辑函数，按字母顺序列出。

| 函数 | 描述 |
|--- |--- |
| [AND](gcdocsite__documentlink?toc-item-id=adb289bc-abff-4490-b2f4-ff34e2357c86) | 检查所有参数是否为 True，如果所有参数都为 True，则返回 True。 |
| [FALSE](gcdocsite__documentlink?toc-item-id=5ffe023a-e921-4e8a-9492-a50a60ba3470) | 此函数返回逻辑 FALSE 的值。 |
| [IF](gcdocsite__documentlink?toc-item-id=c1abfa04-0b35-44fc-9fd3-17099d1c9201) | 此函数执行比较并根据该比较返回提供的两个值之一。 |
| [IFERROR](gcdocsite__documentlink?toc-item-id=c1ab1215-44e8-49fc-a3e9-213713c4a90f) | 如果出现错误或公式结果，此函数会计算公式并返回您提供的值。 |
| [IFNA](gcdocsite__documentlink?toc-item-id=7e487b9e-42a2-4262-a0d6-7620bfbceed8) | 如果公式返回 #N/A 错误值，此函数将返回您指定的值，否则返回公式的结果。 |
| [IFS](gcdocsite__documentlink?toc-item-id=e32cd709-3771-4b8f-a25f-b50ff6dd659a) | 此函数检查是否满足一个或多个条件并返回与第一个 TRUE 条件对应的值。 |
| [NOT](gcdocsite__documentlink?toc-item-id=6b972a21-b243-4873-8a98-9bdd6f817586) | 此函数反转其参数的逻辑值。 |
| [OR](gcdocsite__documentlink?toc-item-id=703571b0-cf9e-4667-b867-206ae530f78b) | 此函数计算逻辑或。如果任何参数为真，则返回 TRUE；否则，如果所有参数都为假，则返回 FALSE。 |
| [SWITCH](gcdocsite__documentlink?toc-item-id=3acbc317-4f13-428f-8178-06982d6125ac) | 此函数根据值列表计算一个值（称为表达式），并返回与第一个匹配值对应的结果。如果没有匹配项，则可能会返回一个可选的默认值。 |
| [TRUE](gcdocsite__documentlink?toc-item-id=ba9353a2-e62d-4ca8-bc0d-d1055c25c48e) | 此函数返回逻辑 TRUE 的值。 |
| [XOR](gcdocsite__documentlink?toc-item-id=7b2929c7-f6e2-47d8-b131-6428fc9867f3) | 此函数返回所有参数的逻辑异或。 |
