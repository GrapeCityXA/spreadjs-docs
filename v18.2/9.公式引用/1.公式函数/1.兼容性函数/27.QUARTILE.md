# QUARTILE

此函数返回一组数据的四分位点。



#### 语法

QUARTILE( *array* , *quart* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *array*  | 要求得四分位数值的数组或数字型单元格区域。 |
|  *quart*  | 指定返回哪一个值。 |



#### 注释

四分之一是25％。因此，四分位数是0（数据集中的最小值）和4（数据集中的最大值）之间的整数，如下表所示。

| 如果number为... | 函数 QUARTILE 返回... |
|--- |--- |
| 0 | 最小值 |
| 1 | 第一个四分位数（第 25 个百分点值） |
| 2 | 中分位数（第 50 个百分点值） |
| 3 | 第三个四分位数（第 75 个百分点值） |
| 4 | 最大值 |



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

QUARTILE(A1:A17,2)

QUARTILE(R1C1:R17C1,3)

QUARTILE({11,21,42,27,18,29,32,52},1) 得出结果 20.25
