# LOGINV

此函数返回 x 的对数累积分布函数的反函数值。



#### 语法

LOGINV( *prob* , *mean* , *stdev* )



#### 参数

该函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *prob*  | 与对数分布相关的概率。 |
|  *mean*  | ln(x) 的平均值。 |
|  *stdev*  | ln(x) 的平均值。 |



#### 注释

如果 p = LOGNORMDIST(x,...)，则 LOGINV(p,...) = x。



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

LOGINV(0.92,B8,G22)

LOGINV(0.88,2,1.2) 得出结果 30.26479297
