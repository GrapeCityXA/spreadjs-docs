# BETADIST

此函数返回累积 beta 概率密度函数。



#### 语法

BETADIST( *x* , *alpha* , *beta* , *lower* , *upper* )



#### 参数

此函数有以下参数:

| 语法 | 描述 |
|--- |--- |
|  *x*  | 用来计算其函数的值，介于值 lower 和 upper 之间。 |
|  *alpha*  | 分布参数。 |
|  *beta*  | 分布参数。 |
|  *lower*  | [可选]  x 所属区间的下界。 |
|  *upper*  | [可选]  x 所属区间的上界。 |



#### 注释

如果省略 lower 或 upper 值，则 BETADIST 使用标准的累积 beta 分布，即 lower = 0，upper = 1。



#### 数据类型

接受所有参数的数值数据。 返回数值数据。



#### 示例

BETADIST(3,B3,C3,2,4)

BETADIST(3,R3C2,R3C3,2,4)

BETADIST(3,6,9,2,4) 得出结果 0.7880249023
