# EURO

此函数根据ISO货币代码返回等价的1欧元。



#### 语法

EURO( *code* )



#### 参数

参数是某些国家/地区的ISO货币代码。 此功能不能转换所有货币； 仅此处列出的那些欧元成员国货币。

| 国家/地区 | ISO货币代码 |
|--- |--- |
| Belgium | BEF |
| Luxembourg | LUF |
| Germany | DEM |
| Spain | ESP |
| France | FRF |
| Ireland | IEP |
| Italy | ITL |
| Netherlands | NLG |
| Austria | ATS |
| Portugal | PTE |
| Finland | FIM |
| Euro member state | EUR |



#### 注释

ISO货币代码来自ISO 4217，该国际标准描述了三个字母的代码来定义货币名称。 ISO是国际标准化组织的昵称，代码的前两个字母是两个字母的国家代码（ISO 3166），第三个字母通常是货币本身的缩写。 所以BEF是比利时法郎。



#### 数据类型

接受代码的字符串数据。返回数值数据。



#### 示例

EURO(""BEF"")
