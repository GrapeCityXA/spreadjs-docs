# webpack

Webpack 是 JavaScript 的模块打包工器。它用于编译 JavaScript 模块。 SpreadJS 支持在 Webpack 开发环境中使用单独的模块和插件。

### 使用模块与插件

包含以下的步骤：

1. 打开命令提示符窗口并键入以下命令来配置 Webpack 开发环境。 创建目录，初始化npm，本地安装webpack，安装webpack-cli。

    ```shell
    mkdir webpack-demo 
    cd webpack-demo 
    npm init -y 
    npm install webpack webpack-cli --save-dev
    ```
2. 创建目录、文件及内容

    ```shell
    webpack-demo
    |- package.json
    |- webpack.config.js
    |- /dist
    |- index.html
    |- /src
    |- index.js
    ```
3. 添加以下代码到 package.json 中

    ```javascript
    {
      "name": "webpack-demo",
      "version": "1.0.0",
      "description": "",
      "private": true,
      "scripts": {
        "build": "webpack"
          },
          "keywords": [],
          "author": "",
          "license": "ISC",
          "devDependencies": {
                "webpack": "^5.88.1",
                "webpack-cli": "^5.1.4"
              }
    }
    ```
4. 添加以下代码到 webpack.config.js 中

    ```javascript
    const path = require('path');
    module.exports = {
        entry: './src/index.js',
        output: {
            filename: 'main.js',
            path: path.resolve(__dirname, 'dist'),
        },
        mode: 'none'
    };
    ```
5. 添加以下代码到 index.html 中

    ```html
    <!DOCTYPE html>
    <html>
      <head>
        <meta charset="utf-8" />
        <title>Getting Started</title>
      </head>
      <body>    
        <script src="./main.js"></script>
      </body>
    </html>
    ```
6. 运行命令

    ```shell
    npm run build
    ```
7. 在浏览器中打开 index.html。有关如何使用Webpack创建项目的更多信息，请参阅 [Webpack](https://webpack.js.org/guides/getting-started/)。
8. 通过 NPM 安装 SpreadJS 模块和插件，例如：

    ```shell
    npm install @grapecity-software/spread-common @grapecity-software/spread-calc-engine @grapecity-software/spread-sheets-core @grapecity-software/spread-sheets-calc-engine @grapecity-software/spread-sheets-print
    ```
9. 更新 index.js 文件内容：

    ```javascript
    import * as GC from "@grapecity-software/spread-common";
    import "@grapecity-software/spread-calc-engine";
    import "@grapecity-software/spread-sheets-core";
    import "@grapecity-software/spread-sheets-calc-engine";
    import "@grapecity-software/spread-sheets-print";
    let spread = new GC.Spread.Sheets.Workbook("ss");
    let sheet = spread.getActiveSheet();
    sheet.setValue(0, 0, "Hello SpreadJS");
    spread.print();
    ```
10. 更新 index.html 文件内容：

    ```html
    <!DOCTYPE html>
    <html>
    <head>
      <meta charset="utf-8" />
      <title>Getting Started</title>
      <link rel="stylesheet" type="text/css" href="../node_modules/@grapecity-software/spread-common/styles/gc.spread.sheets.excel2016colorful.css" />
    </head>
    <body>
      <div id="ss" style="width: 100%;height:300px;"></div>
      <script src="./main.js"></script>
    </body>
    </html>
    ```
11. 更新 webpack.config.js 文件内容：

    ```javascript
    const path = require('path');
    module.exports = {
      entry: './src/index.js',
      output: {
        filename: 'main.js',
        path: path.resolve(__dirname, 'dist'),
      },
      resolve: {
        alias: {
          "@grapecity-software/spread-sheets": require.resolve("@grapecity-software/spread-common")
        }
      }
    };
    ```
