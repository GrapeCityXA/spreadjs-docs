# UsingtheChartElement

在React中使用SpreadJS的图表功能，你可以为应用程序可视化数据，同时确保所有图表元素与原生数据绑定支持保持同步。

1. 创建React项目
    打开命令提示符窗口，输入以下命令：

    ```Shell
    npm install -g create-react-app
    create-react-app quick-start
    cd quick-start
    npm start
    ```

    完成后，React项目将在目录中的指定位置创建。有关如何创建 React 项目的更多信息，请参阅 https://reactjs.org/docs/create-a-new-react-app.html。
2. 在项目中安装SpreadJS React模块
    接下来，你需要使用以下命令在项目中安装`@grapecity-software/spread-sheets-react`：

    ```Shell
    npm install @grapecity-software/spread-sheets-react
    ```
3. 导入SpreadJS CSS
    接下来，你需要使用以下代码在`index.js`文件中导入SpreadJS CSS：

    ```javascript
    import '@grapecity-software/spread-sheets/styles/gc.spread.sheets.excel2013white.css';
    ```
4. 在项目中安装图表React模块
    接下来，你需要使用以下命令在项目中安装图表模块：

    ```bash
    npm install @grapecity-software/spread-sheets-charts
    ```
5. 在React应用中使用图表
    现在，你可以根据需求修改`App.js`文件。刷新浏览器窗口时，更改将立即显示。例如，你可以使用以下示例代码：
    此示例展示了如何在React应用中使用图表。

    ```javascript
    import React from "react";
    import "./App.css";
    import GC from "@grapecity-software/spread-sheets";
    import { SpreadSheets, Worksheet } from "@grapecity-software/spread-sheets-react";
    
    // 导入图表模块
    import "@grapecity-software/spread-sheets-charts";
    
    var SpreadJSKey = "xxx";
    GC.Spread.Sheets.LicenseKey = SpreadJSKey;
    
    class App extends React.Component {
        constructor(props) {
            super(props);
            this.hostStyle = {
                width: "1100px",
                height: "800px",
            };
        }
    
        // 处理工作簿初始化事件
        workbookInit = (spread) => {
            this.setState({
                spread: spread,
            });
            let chart_columnClustered, chart_columnStacked, chart_columnStacked100;
    
            // 获取工作表
            let sheetCharts = spread.getSheet(0);
    
            // 设置工作表名称
            sheetCharts.name("Charts");
            sheetCharts.suspendPaint();
    
            // 为图表准备数据
            sheetCharts.setValue(0, 1, "Q1");
            sheetCharts.setValue(0, 2, "Q2");
            sheetCharts.setValue(0, 3, "Q3");
            sheetCharts.setValue(1, 0, "移动电话");
            sheetCharts.setValue(2, 0, "笔记本电脑");
            sheetCharts.setValue(3, 0, "平板电脑");
            for (var r = 1; r <= 3; r++) {
                for (var c = 1; c <= 3; c++) {
                    sheetCharts.setValue(r, c, parseInt(Math.random() * 100));
                }
            }
    
            // 添加簇状柱形图
            chart_columnClustered = sheetCharts.charts.add(
                "chart_columnClustered",
                GC.Spread.Sheets.Charts.ChartType.columnClustered,
                5,
                150,
                300,
                300,
                "A1:D4"
            );
            chart_columnClustered.title({ text: "年度销售额" });
    
            // 添加堆积柱形图
            chart_columnStacked = sheetCharts.charts.add(
                "chart_columnStacked",
                GC.Spread.Sheets.Charts.ChartType.columnStacked,
                320,
                150,
                300,
                300,
                "A1:D4"
            );
            chart_columnStacked.title({ text: "年度销售额" });
    
            // 添加百分比堆积柱形图
            chart_columnStacked100 = sheetCharts.charts.add(
                "chart_columnStacked100",
                GC.Spread.Sheets.Charts.ChartType.columnStacked100,
                640,
                150,
                300,
                300,
                "A1:D4"
            );
            chart_columnStacked100.title({ text: "年度销售额" });
    
            sheetCharts.resumePaint();
        };
    
        render() {
            return (
                <div>
                    <SpreadSheets
                        backColor={this.spreadBackColor}
                        hostStyle={this.hostStyle}
                        workbookInitialized={this.workbookInit}
                    >
                        <Worksheet></Worksheet>
                    </SpreadSheets>
                </div>
            );
        }
    }
    
    export default App;
    ```
