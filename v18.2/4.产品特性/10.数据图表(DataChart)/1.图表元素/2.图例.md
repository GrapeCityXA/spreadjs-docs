# legend

数据图表中的图例是一种视觉辅助工具，通过将不同的线条、柱状图或其他数据与不同的颜色和大小相关联，帮助用户理解它们所代表的含义。
使用 `ILegendOptions` 接口来定义数据图表中图例的外观和行为。它包括可选属性，如标题、类型、位置、文本样式等等。此外，使用 `LegendType` 枚举来指定图例的类型，如颜色或大小，而 `LegendPosition` 枚举则定义了图例在数据图表中的位置。
图例中显示的符号类型取决于数据图表类型：

* **方形**：用于柱状图、面积图、旭日图、饼图、圆环图和范围图。
* **线条**：用于无符号的折线图。
* **圆形**：用于 XY 散点图、气泡图和带符号的面积图。
* **带圆形的线条**：用于带符号的折线图。

## 图例属性

以下列出了 `ILegendOptions` 接口的关键属性：

| 属性 | 描述 | 示例预览 |
| --- | --- | ---- |
| @rows=2:type | 通过不同颜色表示数据，适用于所有图表类型。如果在图表编码中将字段绑定到图例，颜色图例会自动出现。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.f29526.png) |
| 通过不同的符号大小表示数据，通常用于气泡图。大小图例默认不显示，需要显式配置。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.405562.png) |
| title | 为图例添加一个描述性标题，该标题描述了图例中所表示内容的含义或维度。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.340810.png) |
| position | 确定图例在图表中的位置。可用选项为无（默认）、顶部、底部、左侧和右侧。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.2c7cef.png) |
| textStyle | 定义图例区域中文本的外观。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.2124aa.png) |
| height & width | 将图例的尺寸设置为整个数据图表的百分比，范围从 0 到 1。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.d72709.png) |
| hAlign | 将图例的水平对齐方式（hAlign）设置为左、中（默认）或右。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.508d9e.png) |
| vAlign | 将图例的垂直对齐方式（vAlign）设置为上、中（默认）或下。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.93f85f.png) |
| padding | 调整图例内部的间距。默认内边距为：{top: 10, bottom: 10, left: 10, right: 10}。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.635614.png) |

以下代码示例说明了如何为数据图表配置图例。

// As long as the color legend related fields are bound in the “encodings”,
// the color legend will be shown in the DataChart by default.
dataChart.setChartConfig({
     tableName: 'Sales',
     plots: [
         {
             type: GC.Spread.Sheets.DataCharts.DataChartType.column,
             encodings: {
                 values: [{ field: 'Sales', aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum }],
                 category: { field: 'Salesman' },
                 color: { field: 'Salesman' },
