# header

标题是出现在数据图表顶部的文本区域。标题为图表提供总体信息或标识，帮助用户快速理解图表的主题和所呈现的数据。
你可以使用 `GC.Spread.Sheets.DataCharts` 命名空间中的 `IHeaderOption` 接口的属性（如标题、文本样式等）为数据图表添加和自定义标题。

## 标题属性

以下列出了`IHeaderOption`接口的关键属性：

| **属性** | **描述** | **示例预览** |
| --- | --- | ---- |
| title | 设置显示在数据图表表头区域的文本内容。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.702f50.png) |
| textStyle | 设置表头文本的样式，例如字体系列、字体大小、字体样式、字体粗细等。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.a140a8.png) |
| padding | 设置表头区域的内边距。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.0f41a1.png) |
| style | 设置表头区域的样式，如背景颜色、边框样式等。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.67238f.png) |

## 使用代码

以下代码示例展示了如何为数据图表配置自定义表头。
请注意，此代码示例使用了 [“创建数据图表” ](gcdocsite__documentlink?toc-item-id=83b6d588-0f69-4b37-9a6e-f9aa6a2b714e)页面中提到的 “salesTable” 数据。因此，请确保你已完成该页面概述的主要步骤来设置数据图表。完成后，你可以使用以下代码配置表头元素。此外，你可以根据具体需求灵活自定义数据源。

```javascript
// Chart header
const sheet = spread.getSheet(0);
sheet.name("Chart Header");
const dataChart = sheet.dataCharts.add('data-chart-1', 10, 10, 480, 300, GC.Spread.Sheets.DataCharts.DataChartType.column);

dataChart.setChartConfig({
    tableName: 'Sales',
    config: {
        // Configure the Header
        header: {             // interface GC.Spread.Sheets.DataCharts.IHeaderOption
            title: "My DataChart",      // string
            textStyle: {          // interface GC.Spread.Sheets.DataCharts.ITextStyleOption
                alignment: GC.Spread.Sheets.DataCharts.HAlign.center,
                color: "#9f3b47",
                fontFamily: "Century",
                fontSize: 18,
                fontStyle: GC.Spread.Sheets.DataCharts.FontStyle.italic,
                fontWeight: "Bold",
                writingMode: GC.Spread.Sheets.DataCharts.Orientation.horizontal,
                textDecoration: { underline: true },
            },
            padding: {       // GC.Spread.Sheets.DataCharts.IPaddingOption
                top: 10,
                bottom: 10
            },
            height: 30,      // number
            style: {         // GC.Spread.Sheets.DataCharts.IStyleOption
                fill: { type: "CssColor", color: "#dfeeea" },
                fillOpacity: 0.7,
                stroke: { type: "CssColor", color: "#aaaaaa" },
                strokeDasharray: "0.5,0.5",
                strokeOpacity: 0.7,
                strokeWidth: 1
            }
        }
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.column,
            encodings: {
                values: [{ field: 'Sales', aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum }],
                category: { field: 'Product' },
                color: { field: 'Product' },
            }
        }
    ]
});
```
