# treemap-charts

**树状图**是一种功能强大的数据可视化工具，可将层级结构数据以一组嵌套矩形的形式展示。每个矩形代表一个类别或子类别，其大小与特定数值成比例，便于比较层级结构中不同元素的相对大小。
SpreadJS 允许您通过修改各类属性来添加树状图并自定义其外观，这些属性包括调色板、图形不透明度、边框样式、图表背景、图表边框、绘图区内边距、提示框（tooltip）样式等。这些修改既可以通过代码实现，也可以在 SpreadJS 设计器（Designer）的“检查器”（Inspector）选项卡中操作。

>type=info
> **注意：**
> 不支持悬停动画（Hover animation）功能。

> **注意：**
> 本示例基于[“创建数据图表”](gcdocsite__documentlink?toc-item-id=83b6d588-0f69-4b37-9a6e-f9aa6a2b714e)页面中的“salesTable”数据。因此，请确保您已按照该页面所述的主要步骤完成了数据图表（Data Chart）的添加操作。您也可以根据自身具体需求自定义数据源。

```javascript
// 树状图（Treemap Chart）
const sheet = spread.getActiveSheet();
sheet.name("Treemap Chart"); // 工作表命名为“树状图”
const dataChart = sheet.dataCharts.add('data-chart', 10, 10, 600, 400); // 添加数据图表，设置位置与尺寸

dataChart.setChartConfig({
    tableName: 'Sales', // 关联数据表名称为“Sales”（销售数据）
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.treemap, // 图表类型为树状图
            encodings: {
                values: [{ field: 'Sales', aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum }], // 数值：基于“Sales”字段，计算方式为求和
                details: [{ field: 'Region' }, { field: 'Product' }], // 层级详情：依次为“Region”（地区）字段、“Product”（产品）字段
            },
            config: {
                text: [{ // 文本配置
                    template: '{detailFields.value}', // 文本模板：显示层级详情字段的值
                    textStyle: { // 文本样式
                        color: 'black', // 字体颜色：黑色
                        fontFamily: 'Calibri', // 字体：Calibri
                        fontSize: 16, // 字号：16
                        fontStyle: GC.Spread.Sheets.DataCharts.FontStyle.italic, // 字体样式：斜体
                        fontWeight: 'Bold', // 字体粗细：加粗
                    },
                }],
            }
        }
    ],
    config: {
        header: { // 图表标题栏配置
            title: "Treemap Chart", // 标题文本
            padding: { // 内边距
                left: 10,
                right: 10,
                top: 10,
                bottom: 10,
            },
            style: { // 标题栏样式
                fill: { type: 'CssColor', color: 'rgba(255,255,255,0.9)' }, // 填充色：白色（透明度90%）
                shadow: { blur: 4, color: 'rgba(0,0,0,0.05)' } // 阴影：模糊度4，颜色为黑色（透明度5%）
            },
            textStyle: { // 标题文本样式
                color: 'rgba(30,30,30,1)', // 字体颜色：深灰色
                fontSize: 18, // 字号：18
                fontFamily: 'Calibri', // 字体：Calibri
                fontStyle: GC.Spread.Sheets.DataCharts.FontStyle.italic, // 字体样式：斜体
                fontWeight: 'Bold', // 字体粗细：加粗
                alignment: GC.Spread.Sheets.DataCharts.HAlign.left, // 水平对齐方式：左对齐
            },
        },
    },
});
```
