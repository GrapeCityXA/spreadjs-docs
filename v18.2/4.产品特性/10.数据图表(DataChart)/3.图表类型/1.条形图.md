# bar-charts

**条形图**用于通过水平条形比较分类数据，其中每个条形的长度代表相应类别的值。在这些图表中，类别沿垂直轴排列，而数据值沿水平轴显示。当长类别标题难以适应x轴时，条形图是理想的选择。例如，不同产品类别的销售情况可以使用条形图来展示。
SpreadJS支持各种类型的条形图，可以通过修改图表属性进行自定义，例如设置颜色方案、图形透明度、边框样式、圆角半径等。这些修改可以通过代码进行，也可以在SpreadJS设计器中的[“属性设置”](gcdocsite__documentlink?toc-item-id=55f14079-f4d7-48fe-aebc-ed9390deeb94)选项卡中进行。

> 本主题中的所有示例都基于[创建数据图表](gcdocsite__documentlink?toc-item-id=83b6d588-0f69-4b37-9a6e-f9aa6a2b714e)页面中的“salesTable”数据。因此，请确保您已按照该页面上提到的主要步骤添加了数据图表。您也可以根据自己的特定需求自定义数据源。

## 条形图

条形图使用矩形条形来比较不同类别或说明类别与值之间的关系。每个条形的长度对应于它所代表的值，这使得比较不同类别的大小变得容易。
条形图常用于展示分类数据，例如比较不同产品的销售数字或显示不同年龄组的人口分布。它们在清晰、易于理解地呈现数据方面既灵活又有效。
以下是条形图的示例图像：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.a8a91c.png)
请参考以下示例代码来添加条形图。

```javascript
// Bar Chart
const sheet = spread.getActiveSheet();
sheet.name("Bar Chart");
const dataChart = sheet.dataCharts.add('data-chart', 10, 10, 500, 300);
dataChart.setChartConfig({
    tableName: 'Sales',
    config: {
        header: {
            title: "Bar Chart"
        }
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.bar,
            encodings: {
                values: [
                    {
                        field: "Sales",
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum
                    }
                ],
                category: {
                    field: "Product"
                },
                color: {
                    field: "Product"
                }
            },
        }
    ]
});
```

## 区间条形图

区间条形图可视化了不同类别中的数据范围。在这种类型的图表中，每个条形代表一个值范围，而不是单个值。这些条形有一个起点和一个终点，展示了该范围内的最小值和最大值。它适用于展示值的变化或分布范围较大的数据，特别是在分析或比较中，可视化上下限都至关重要的场景。
以下是区间条形图的示例图像：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.1fba9d.png)
请参考以下示例代码来添加区间条形图。

```javascript
// Range Bar Chart
const sheet = spread.getActiveSheet();
sheet.name("Range Bar Chart");
const dataChart2 = sheet.dataCharts.add('data-chart-2', 10, 10, 500, 300);
dataChart2.setChartConfig({
          tableName: 'Sales',
          config: {
                    header: {
                        // title settings
                        title: 'Range Bar Chart'
                    }
          },
          plots: [
                    {
                        type: GC.Spread.Sheets.DataCharts.DataChartType.rangeBar,
                        encodings: {
                            values: [
                                { field: 'Sales', aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum },
                                { field: 'Return', aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum },
                            ],
                            category: { field: 'Product' },
                            color: { field: 'Product' },
                        }
                    }
          ]
});
```

## 堆积条形图

堆积条形图在一个条形内将多个数据系列堆叠在一起。每个条形代表一个类别，条形的每个部分代表不同的子类别或数据系列。条形的总高度显示了该类别的总值，而各部分则展示了该总值是如何在子类别中分配的。
堆积条形图在比较不同类别的总大小的同时，还说明了每个类别作为整体的一部分的构成。这使得观众可以轻松地看到每个类别的总值以及该总值中子类别的相对比例。
以下是堆积条形图的示例图像：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.f9a4eb.png)
请参考以下示例代码来添加堆积条形图。

```javascript
// Stacked Bar Chart
const sheet = spread.getActiveSheet();
sheet.name("Stacked Bar Chart");
const dataChart3 = sheet.dataCharts.add('data-chart-3', 10, 10, 500, 300);
dataChart3.setChartConfig({
         tableName: 'Sales',
         config: {
                    header: {
                        // title settings
                        title: 'Stacked Bar Chart'
                    },
         },
         plots: [
                    {
                        type: GC.Spread.Sheets.DataCharts.DataChartType.stackedBar,
                        encodings: {
                            values: [{ field: 'Sales', aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum }],
                            category: { field: 'Region' },
                            color: { field: 'Product' },
                        }
                    }
         ]
});
```

## 百分比堆积条形图

百分比堆积条形图与堆积条形图类似，但增加了以百分比形式显示数据的功能。在这里，每个条形代表一个类别的总值，条形内的各个部分代表每个子类别占总值的百分比。
当您想比较不同类别的总大小，同时又想了解每个类别在百分比格式下的相对分布或构成时，这种类型的图表特别有用。百分比堆积条形图便于直观地比较不同类别中不同子类别的相对贡献，为每个类别内数据的百分比分解提供了清晰的视觉表示。
以下是百分比堆积条形图的示例图像：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.dcc7a7.png)
请参考以下示例代码来添加百分比堆积条形图。

```javascript
// Percent Stacked Bar Chart
const sheet = spread.getActiveSheet();
sheet.name("Percent Stacked Bar Chart");
const dataChart4 = sheet.dataCharts.add('data-chart-4', 10, 10, 500, 300);
dataChart4.setChartConfig({
    tableName: 'Sales',
    config: {
        header: {
            // title settings
            title: 'Percent Stacked Bar Chart'
        }
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.percentStackedBar,
            encodings: {
                values: [{ field: 'Sales', aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum }],
                category: { field: 'Region' },
                color: { field: 'Product' },
            }
        }
    ]
});
```
