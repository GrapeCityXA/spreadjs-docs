# datavalidate

SpreadJS 支持设置数据验证规则以确保数据完整性——既可以限制无效输入，又能通过清晰的选项为用户提供操作指引。对于基于列表的验证，你可以在单元格内直接显示预定义的有效值列表，用户无需手动输入；若输入无效内容，单元格会立即显示错误图标以提示错误。
当编辑带有列表数据验证的单元格时，下拉菜单会自动弹出，展示所有可用的有效选项。输入内容时，列表会实时筛选（按输入内容作为前缀匹配，不区分大小写）。
此外，你还可以通过方向键或鼠标操作列表：

* **上/下箭头键**：切换选中的选项
* **Enter 键**：确认选择当前选项
* **ESC 键**：关闭下拉菜单

>type=info
> **注意事项：**
>
> * 若选项列表包含空值，开始编辑时会默认选中该空值。
> * 通过将 `dataValidator.inCellDropdown()` 设置为 `false`，可禁用单元格内下拉菜单——编辑单元格时下拉菜单将不再显示。
> * 该功能仅兼容文本类型的单元格。

你可以通过以下方式验证工作表中输入的信息：

* 使用不同类型的数据验证
* 为数据验证使用不同的高亮样式

## 使用不同类型的数据验证

SpreadJS 支持以下多种类型的数据验证：

### 日期验证（Date Validation）

可通过 [createDateValidator](https://docs.grapecity.com.cn/spreadjs/help/api/v18.2/modules/GC.Spread.Sheets.DataValidation#createDateValidator) 方法验证单元格的特定日期条件。
日期验证能限制用户在电子表格中输入不符合单元格指定日期条件的无效日期信息。例如，若创建一个日期验证器，允许用户输入 2017 年 12 月 31 日至 2018 年 12 月 31 日之间的任意日期，则超出此范围的日期均会被判定为无效数据输入。
以下代码示例创建了一个日期验证器：

```javascript
// 启用无效数据高亮显示
spread.options.highlightInvalidData = true;
// 创建日期验证器：允许输入 2017年12月31日至2018年12月31日之间的日期
var dv = GC.Spread.Sheets.DataValidation.createDateValidator(
    GC.Spread.Sheets.ConditionalFormatting.ComparisonOperators.between, 
    new Date(2017, 12, 31), 
    new Date(2018, 12, 31)
);
// 启用输入提示
dv.showInputMessage(true);
// 设置输入提示内容
dv.inputMessage("请输入 2017年12月31日 至 2018年12月31日 之间的日期。");
// 设置输入提示标题
dv.inputTitle("提示");
// 在视图区域的（1,1）单元格（第2行第2列）应用日期验证器
activeSheet.setDataValidator(1, 1, 1, 1, dv, GC.Spread.Sheets.SheetArea.viewport);
```

### 公式验证（Formula Validation）

可通过 [createFormulaValidator](https://docs.grapecity.com.cn/spreadjs/help/api/v18.2/modules/GC.Spread.Sheets.DataValidation#createFormulaValidator) 方法验证单元格中输入的公式。
以下代码示例创建了一个公式验证器：

```javascript
// 启用无效数据高亮显示
spread.options.highlightInvalidData = true;
// 创建公式验证器：当公式条件（A1>0）返回true时，验证通过
var dv = GC.Spread.Sheets.DataValidation.createFormulaValidator("A1>0");
// 启用输入提示
dv.showInputMessage(true);
// 设置输入提示内容
dv.inputMessage("请在 A1 单元格中输入大于 0 的值。");
// 设置输入提示标题
dv.inputTitle("提示");
// 在视图区域的（0,0）单元格（第1行第1列）应用公式验证器
activeSheet.setDataValidator(0, 0, 1, 1, dv, GC.Spread.Sheets.SheetArea.viewport);
```

### 公式列表验证（Formula List Validation）

可通过 [createFormulaListValidator](https://docs.grapecity.com.cn/spreadjs/help/api/v18.2/modules/GC.Spread.Sheets.DataValidation#createFormulaListValidator) 方法验证电子表格中的公式列表。公式列表验证器会使用单元格区域创建有效值列表。
当公式条件返回 `true` 时，公式验证器判定为有效。当应用验证的单元格值无效时，会触发 [ValidationError](https://docs.grapecity.com.cn/spreadjs/help/api/v18.2/classes/GC.Spread.Sheets.Events#ValidationError_EV) 事件。
以下代码示例根据公式指定的单元格区域创建有效值列表：

```javascript
// 在C列设置示例值
activeSheet.setValue(0, 2, 5);  // C1单元格值为5
activeSheet.setValue(1, 2, 4);  // C2单元格值为4
activeSheet.setValue(2, 2, 5);  // C3单元格值为5

// 启用无效数据高亮显示
spread.options.highlightInvalidData = true;
// 创建公式列表验证器：有效值来自C1:C3单元格区域
var dv = GC.Spread.Sheets.DataValidation.createFormulaListValidator("$C$1:$C$3");
// 启用输入提示
dv.showInputMessage(true);
// 设置输入提示内容
dv.inputMessage("请从列表中选择一个值。");
// 设置输入提示标题
dv.inputTitle("提示");
// 在视图区域的（1,1）单元格（第2行第2列）应用公式列表验证器
activeSheet.setDataValidator(1, 1, 1, 1, dv, GC.Spread.Sheets.SheetArea.viewport);
// 获取（1,1）单元格的有效值列表
var validList = activeSheet.getDataValidator(1, 1).getValidList(sheet, 1, 1);
```

### 列表验证（List Validation）

可通过 [createListValidator](https://docs.grapecity.com.cn/spreadjs/help/api/v18.2/modules/GC.Spread.Sheets.DataValidation#createListValidator) 方法基于指定列表创建验证器。
以下代码示例创建有效值列表、显示输入提示，并在输入错误值时显示无效数据图标：

```javascript
// 启用无效数据高亮显示
spread.options.highlightInvalidData = true;
// 创建列表验证器：有效值为1、2、3
var dv = GC.Spread.Sheets.DataValidation.createListValidator("1,2,3");
// 启用输入提示
dv.showInputMessage(true);
// 设置输入提示内容
dv.inputMessage("值必须是 1、2 或 3");
// 设置输入提示标题
dv.inputTitle("提示");
// 在视图区域的（1,1）单元格（第2行第2列）应用列表验证器
activeSheet.setDataValidator(1,1,1,1,dv,GC.Spread.Sheets.SheetArea.viewport);
// 弹出（1,1）单元格的有效值列表
alert(activeSheet.getDataValidator(1,1).getValidList(activeSheet,1,1));
```

SpreadJS 还支持在列表中通过转义字符插入逗号（如下方图片所示）。其中 B2 单元格为数字列表，D2 单元格为运算符列表。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/data-valid-separator.6617ca.png)
以下代码示例展示了两种不同列表的验证：一种是数字列表，另一种是用逗号分隔的运算符列表。在不同单元格（B2 和 D2）中设置这两种列表验证规则，可限制用户在输入数据时只能从下拉列表中选择值：

```javascript
// 设置列宽（视图区域）
sheet.setColumnWidth(0, 200.0, GC.Spread.Sheets.SheetArea.viewport);
sheet.setColumnWidth(1, 120.0, GC.Spread.Sheets.SheetArea.viewport);
sheet.setColumnWidth(2, 200.0, GC.Spread.Sheets.SheetArea.viewport);
sheet.setColumnWidth(3, 120.0, GC.Spread.Sheets.SheetArea.viewport);

// 列表验证中使用逗号（通过转义字符）
// 数字列表验证器：有效值为123,456、234,567、789,564
var dv1 = new GC.Spread.Sheets.DataValidation.createListValidator("123\\,456,234\\,567,789\\,564");
// 在A2单元格设置提示文本
sheet.setText(1, 0, "从B2单元格选择一个数字");
// 设置输入提示标题
dv1.inputTitle("请选择一个数字：");
// 设置输入提示内容
dv1.inputMessage("金额数值");
// 在B2单元格应用数字列表验证器
sheet.setDataValidator(1, 1, dv1);

// 运算符列表验证器：有效值为逗号、>、<、*、/
var dv2 = new GC.Spread.Sheets.DataValidation.createListValidator("\\,,>,<,*,/");
// 在C2单元格设置提示文本
sheet.setText(1, 2, "从D2单元格选择一个运算符");
// 设置输入提示标题
dv2.inputTitle("请选择一个运算符：");
// 设置输入提示内容
dv2.inputMessage("计算器运算符");
// 在D2单元格应用运算符列表验证器
sheet.setDataValidator(1, 3, dv2);
```

## 数字验证（Number Validation）

可通过 [createNumberValidator ](https://docs.grapecity.com.cn/spreadjs/help/api/modules/GC.Spread.Sheets.DataValidation#createNumberValidator)方法验证单元格中输入的数字。
数字验证能限制用户输入不符合单元格验证条件的数值。
以下代码示例使用数字验证器、显示输入提示，并在输入错误值时显示无效数据图标：

```javascript
// 启用无效数据高亮显示
spread.options.highlightInvalidData = true;
// 创建数字验证器：允许输入5至20之间的数值（包含边界值）
var dv = GC.Spread.Sheets.DataValidation.createNumberValidator(
    GC.Spread.Sheets.ConditionalFormatting.ComparisonOperators.between, 
    "5", 
    "20", 
    true
);
// 启用输入提示
dv.showInputMessage(true);
// 设置输入提示内容
dv.inputMessage("值必须在 5 至 20 之间。");
// 设置输入提示标题
dv.inputTitle("提示");
// 在视图区域的（1,1）单元格（第2行第2列）应用数字验证器
activeSheet.setDataValidator(1, 1, 1, 1, dv, GC.Spread.Sheets.SheetArea.viewport);
```

## 文本长度验证（Text Length Validation）

可通过 [createTextLengthValidator](https://docs.grapecity.com.cn/spreadjs/help/api/v18.2/modules/GC.Spread.Sheets.DataValidation#createTextLengthValidator) 方法验证单元格中输入文本的长度。
通过文本长度验证，可限制单元格中输入的字符数量。
以下代码示例使用文本长度验证器、显示输入提示，并在输入错误值时显示无效数据图标：

```javascript
// 启用无效数据高亮显示
spread.options.highlightInvalidData = true;
// 创建文本长度验证器：允许输入字符长度大于4的文本
var dv = GC.Spread.Sheets.DataValidation.createTextLengthValidator(
    GC.Spread.Sheets.ConditionalFormatting.ComparisonOperators.greaterThan, 
    "4", 
    "20"
);
// 启用输入提示
dv.showInputMessage(true);
// 设置输入提示内容
dv.inputMessage("字符数量必须大于 4。");
// 设置输入提示标题
dv.inputTitle("提示");
// 在视图区域的（1,1）单元格（第2行第2列）应用文本长度验证器
activeSheet.setDataValidator(1, 1, 1, 1, dv, GC.Spread.Sheets.SheetArea.viewport);
```

## 为数据验证使用不同的高亮样式

你可以通过多种高亮样式（包括高亮类型、位置、颜色和图标）标记单元格中的无效信息。SpreadJS 支持三种高亮类型（圆形、折角、图标）和六种高亮位置（`topLeft` 左上角、`topRight` 右上角、`bottomRight` 右下角、`bottomLeft` 左下角、`outsideLeft` 外部左侧、`outsideRight` 外部右侧），方便用户在电子表格中标记无效数据。
默认情况下，高亮类型为“圆形”，高亮位置为 `topRight`（右上角），高亮颜色为“红色”。对于“图标”类型的高亮样式，你可以指定图片 URL 或图片 base64 数据作为图标。
除了不同的高亮样式，你还可以为用户显示输入提示，并展示包含有效值列表的下拉按钮，如下方图片所示：
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/invalidtip.8b4255.png)
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/invaliddrop.08b59f.png)

需将 `highlightInvalidData` 属性设置为 `true`，才能启用无效信息高亮功能。通过 **highlightStyle** 方法可控制高亮错误的样式，不同高亮类型对应不同的样式属性。
下方图片中，B2 单元格的高亮类型为“圆形”，D2 单元格为“折角”，F2 单元格为“图标”；其中 D2 单元格的高亮位置设为 `topLeft`（左上角），F2 单元格设为 `outsideLeft`（外部左侧）：
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/data-valid.65b076.png)

以下代码示例展示了三种不同的高亮样式（圆形、折角、图标），用于电子表格中的数据验证：
