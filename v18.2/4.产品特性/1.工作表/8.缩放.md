# zoom

SpreadJS 允许你执行缩放操作，对工作表的视口进行放大或缩小。你还可以设置特定的缩放限制。
![czoom](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/czoom.460afe.png)

> **注意**：
>
> * 单元格大小及其内容会随着视口一同放大或缩小。
> * 边框、网格线、冻结线、拆分条和选中指示符在缩放时不受影响。

## 执行缩放操作

要执行放大或缩小操作，你可以使用以下任何一种方法：

* Ctrl + 鼠标滚轮
* 状态栏的缩放指示器
* 双指缩放操作（仅适用于触摸设备）
* API 成员 `sheet.zoom` (`zoomFactor`)

通过使用 `sheet.zoom` (`zoomFactor`)，你可以将缩放因子设置为 0.1 到 4 之间的任意值。缩放操作默认启用。不过，你可以通过将 **options.allowUserZoom** 属性设置为 `false` 来选择禁用它。

### **代码示例**

此示例设置了 **options.allowUserZoom** 属性。

```javascript
activeSheet.zoom(3);
```

## 设置缩放限制

当执行缩放操作时，会触发 **ViewZooming** 和 **ViewZoomed** 事件。这些事件可用于干预缩放过程并执行任何操作，例如设置视口的最小或最大缩放限制。

### **代码示例**

此示例通过使用 **newZoomFactor** 参数设置电子表格视口的最小和最大缩放限制。

```javascript
// 通过 newZoomFactor 参数限制缩放操作
// 将 allowUserZoom 设置为 true
spread.options.allowUserZoom = true;
activeSheet.bind(GC.Spread.Sheets.Events.ViewZooming, function (e, info) {
    if (info.newZoomFactor >= 2) {
        info.newZoomFactor = 2; // 最大缩放因子为 2
    }
    if (info.newZoomFactor < 1) {
        info.newZoomFactor = 0.5; // 最小缩放因子为 0.5
    }
});
```

此示例通过使用 **cancel** 参数设置电子表格视口的最大缩放限制。

```javascript
// 通过 cancel 参数限制缩放操作
// 将 allowUserZoom 设置为 true
spread.options.allowUserZoom = true;

activeSheet.bind(GC.Spread.Sheets.Events.ViewZooming, function (e, info) {
    if (info.newZoomFactor >= 2) {
       info.cancel = true; // 取消此缩放操作
    }
});
```

## 使用设计器

你也可以使用 SpreadJS 设计器执行缩放操作。
要快速放大或缩小工作表的视口，可使用状态栏上的 **缩放** 滑块来调整放大级别。你可以点击并将缩放滑块向右或向左拖动以放大或缩小。你还可以使用 “–” 或 “+” 符号逐步放大或缩小。
![zoom slider.b7b97e](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/zoom%20slider.b7b97e.6b91c4.png)

在 SpreadJS 设计器中进行放大的另一种方法是使用 **视图** 选项卡上 **缩放** 组中的缩放选项。
![zoom group.8dc675](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/zoom%20group.8dc675.017757.png)

该组包含以下选项：

* **缩放**：从列表中选择你要使用的放大级别。
    ![zoom button.6fb3ab](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/zoom%20button.6fb3ab.836cbc.png)
<br>
* **100%**：选择以原始大小的 100% 缩放查看工作表的视口。
* **缩放到选定区域**：选择仅最大化显示所选单元格的视图。
