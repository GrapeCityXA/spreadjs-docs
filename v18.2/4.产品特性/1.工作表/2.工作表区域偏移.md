# SettingSheetAreaOffset

SpreadJS 允许用户确保整个工作表完全呈现。当隐藏行标题或列标题时，你可以配置工作表区域偏移量，以确保第一列/行的左/上边框、网格线、双线和选中边框完全呈现。你可以根据需求通过设置距宿主左侧或顶部点的偏移量来移动工作表区域。默认情况下，为保持向下兼容性，该值为{left:0, top:0} 。 
下图说明了在工作表中设置工作表区域偏移的重要性。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/sheetareaoffset.png)
以下共享的表描述了不同的情况以及在工作表中使用工作表区域偏移时可能需要参考的描述：

| **场景** | **描述** |
| --- | --- |
| 当行头可见时 | 第一列是指行头的第一可见列。选择边框将完全呈现。 |
| 当行头隐藏时 | 第一列是指视图的左列。所选内容的左边框不会被裁剪，可以完全呈现。左侧的双线将被部分渲染。 |
| 当列头可见时 | 第一行是列头的第一可见行。选择边框将完全呈现。 |
| 隐藏列头时 | 第一行是指视图的第一行。选择顶部边框不会被裁剪，可以完全呈现。顶部的双线将被部分渲染。 |
| 当选择从第一行/列开始时 | 左/上选择框将丢失。 |
| 当工作表具有行分组或列分组时 | 双线未完全呈现。选择边框将完全覆盖轮廓区域。 |
| 在打印工作表时 | 如果将打印选项：showBorder设置为false，并且工作表选项：sheetAreaOffset包含默认值，则它将偏移设置为2像素，以便在左/上边框中呈现双线。<br>如果将打印选项：showBorder设置为true，则行为将与以前相同。 |
| 在支持触控的设备中滚动工作表时 | 左侧或顶部的双线将始终在工作表之外呈现。左边框或上边框可以完全呈现。 |

## 示例代码

本示例说明如何在工作表中设置工作表区域的偏移量。

```JavaScript
sheet.options.sheetAreaOffset= {left : 2, top : 2};
```
