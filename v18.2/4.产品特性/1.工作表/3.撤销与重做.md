# undo

在 SpreadJS 中，你可以使用 Ctrl + Z 撤销操作，然后使用 Ctrl + Y 重做已撤销的操作。
你可以撤销以下类型的操作：

* 文本编辑
* 双击时的自动调整大小
* 标题大小调整
* 用鼠标拖动列或行
* 使用分组按钮展开或折叠组
* 双击选项卡栏编辑工作表选项卡名称
* 使用 Ctrl + V 粘贴
* 使用 [Commands ](gcdocsite__documentlink?toc-item-id=1295c3af-01b2-4a5e-a1a6-87be9b75a7da)类执行操作
* 在视口区域执行的上下文菜单操作

以下操作不响应 Ctrl + Z：

* 使用下拉按钮进行排序或筛选
* 选择区域
* 导航到特定单元格
* 滚动
* 调整选项卡栏大小调整框的大小
* 点击选项卡栏上的新建选项卡选项
* 在工作表选项卡区域执行的上下文菜单操作
* 在 [CommandManager ](gcdocsite__documentlink?toc-item-id=471e9c45-6625-4afa-86f9-8d4ce6b69103)类的 [execute ](gcdocsite__documentlink?toc-item-id=471e9c45-6625-4afa-86f9-8d4ce6b69103#execute)方法中调用 Workbook 的 [fromJSON ](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0#fromjson)方法或 Worksheet 的 [fromJSON ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#fromjson)方法
* 在 [CommandManager ](gcdocsite__documentlink?toc-item-id=471e9c45-6625-4afa-86f9-8d4ce6b69103)类的 [execute ](gcdocsite__documentlink?toc-item-id=471e9c45-6625-4afa-86f9-8d4ce6b69103#execute)方法中调用 [UndoManager](gcdocsite__documentlink?toc-item-id=7e93ff63-61ba-43eb-a07e-254d22cf3c76) 的 [Undo ](gcdocsite__documentlink?toc-item-id=7e93ff63-61ba-43eb-a07e-254d22cf3c76#undo)和 [Redo ](gcdocsite__documentlink?toc-item-id=7e93ff63-61ba-43eb-a07e-254d22cf3c76#redo)方法

你可以通过 **options.allowUndo** 属性在代码中阻止或允许撤销操作。
将 allowUndo 属性设置为 true 后，你可以使用 [startTransaction ](gcdocsite__documentlink?toc-item-id=cd9808fa-4d64-48a9-bd00-a337430ce860#starttransaction)方法、[undoTransaction ](gcdocsite__documentlink?toc-item-id=cd9808fa-4d64-48a9-bd00-a337430ce860#undotransaction)和 [endTransaction ](gcdocsite__documentlink?toc-item-id=cd9808fa-4d64-48a9-bd00-a337430ce860#endtransaction)方法来撤销或重做操作。

## 使用代码

本示例设置**options.allowUndo**属性并指定一个操作。

```javascript
spread.options.allowUndo = true;
spread.commandManager().execute({cmd: "outlineRow", sheetName: activeSheet.name(), index: 3, count: 5});
```

本示例使用 [startTransaction ](gcdocsite__documentlink?toc-item-id=cd9808fa-4d64-48a9-bd00-a337430ce860#starttransaction)方法、[undoTransaction ](gcdocsite__documentlink?toc-item-id=cd9808fa-4d64-48a9-bd00-a337430ce860#undotransaction)和 [endTransaction ](gcdocsite__documentlink?toc-item-id=cd9808fa-4d64-48a9-bd00-a337430ce860#endtransaction)方法更改单元格的背景颜色。

```javascript
var command = { canUndo: true, execute: function (context, options, isUndo)
  {
    var Commands = GC.Spread.Sheets.Commands;
    if (isUndo)
    {
       Commands.undoTransaction(context, options);
       return true;
    }
    else
    {
      Commands.startTransaction(context, options);
      var sheet = context.getSheetFromName(options.sheetName);
      var cell = sheet.getCell(options.row, options.col);
      cell.backColor(options.backColor);
      Commands.endTransaction(context, options);
      return true;
    }
  }
};
var spread = GC.Spread.Sheets.findControl(document.getElementById("sampleDiv"));
var commandManager = spread.commandManager();
commandManager.register("changeBackColor", command);
commandManager.execute({ cmd: "changeBackColor", sheetName: spread.getSheet(0).name(), row: 1, col: 2, backColor: "red" });
```

## 限制撤销和重做操作的次数

你可以通过控制撤销和重做堆栈的大小来限制撤销和重做操作的次数。可以使用 undoManager 类中的 **maxSize** 方法来实现此目的。这有助于通过减少内存消耗来提高应用程序性能。

> **注意**：如果向maxSize方法传递无效值，将返回undoManager。

```javascript
var spread = GC.Spread.Sheets.findControl(document.getElementById('ss'));
let undoManager = spread.undoManager();
undoManager.maxSize(20);        // 设置最大大小。
let maxSize = undoManager.maxSize();    // 获取最大大小。
```

## 获取撤销和重做堆栈

你可以使用 **getUndoStack** 和 **getRedoStack** 函数来检索撤销和重做堆栈。这些函数以对象形式返回堆栈，其中包括工作表名称和命令的字符串值。

```javascript
function getUndoStackFunction() {
    console.log(spread.undoManager().getUndoStack());
}

function getRedoStackFunction() {
    console.log(spread.undoManager().getRedoStack());
}
```

你还可以使用这些函数创建自定义菜单，并在电子表格中显示撤销和重做操作的列表。

```html
<body>
   <input type="button" value="获取撤销堆栈" onclick="getUndoStackFunction()">
   <input type="button" value="获取重做堆栈" onclick="getRedoStackFunction()">
</body>
```

SpreadJS Designer 会将撤销和重做堆栈显示为下拉列表中的操作列表。你可以选择任何操作，将电子表格导航到该特定时间点。
