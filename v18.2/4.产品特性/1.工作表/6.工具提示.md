# tooltips

SpreadJS 提供了在控件中进行大小调整、滚动，或在数据拖移、移动时显示工具提示的选项。

### 拖放操作的工具提示

通过设置 [Workbook ](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0)类的 [showDragDropTip ](gcdocsite__documentlink?toc-item-id=bd583123-fad0-4361-a362-c84ab97d0515#showdragdroptip)属性，您可以选择在执行拖放操作时是否显示工具提示。该属性接受布尔值，默认值为 `true`。在拖放操作期间，工具提示会根据 [Workbook ](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0)类中 [referenceStyle ](gcdocsite__documentlink?toc-item-id=bd583123-fad0-4361-a362-c84ab97d0515#referencestyle)属性的设置，以 A1 或 R1C1 样式显示单元格值。
以下图片展示了拖放提示的 A1 引用样式。
![tooltip-dragdrop](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/tooltip-dragdrop.8b426a.gif)

```javascript
spread.options.showDragDropTip = true; // 设置为 false 则隐藏。
```

### 拖动填充操作的工具提示

通过设置 [Workbook ](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0)类的 [showDragFillTip ](gcdocsite__documentlink?toc-item-id=bd583123-fad0-4361-a362-c84ab97d0515#showdragfilltip)属性，您可以选择在按顺序或等间距自动填充单元格区域时，是否显示拖动填充操作的工具提示。该属性接受布尔值，默认值为 `true`。
以下图片展示了一个拖动填充提示。
![tooltip-dragfill](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/tooltip-dragfill.1944dd.gif)

```javascript
spread.options.showDragFillTip = true; // 设置为 false 则隐藏。
```

### 滚动条操作的工具提示

通过设置 [Workbook ](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0)类的 [showScrollTip ](gcdocsite__documentlink?toc-item-id=bd583123-fad0-4361-a362-c84ab97d0515#showscrolltip)属性，您可以选择在滚动水平或垂直滚动条以显示行名或列名时，是否显示工具提示。
该属性接受 [ShowScrollTip ](gcdocsite__documentlink?toc-item-id=201e5ea1-6a70-41fb-a6ca-0e8e654c87e1)枚举值，包括 `none`（默认值）、`horizontal`、`vertical` 或 `both`。
以下图片展示了水平滚动条上的滚动提示。
![tooltip-scroll](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/tooltip-scroll.0aa1b0.gif)

```javascript
spread.options.showScrollTip = GC.Spread.Sheets.ShowScrollTip.Both;
// 或者
// spread.options.showScrollTip = 3;
```

### 大小调整操作的工具提示

通过设置 [Workbook ](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0)类的 [showResizeTip ](gcdocsite__documentlink?toc-item-id=bd583123-fad0-4361-a362-c84ab97d0515#showresizetip)属性，您可以选择在调整行高或列宽以显示像素大小时，是否显示工具提示。
该属性接受 [ShowResizeTip ](gcdocsite__documentlink?toc-item-id=82ab5fd0-aa38-4b10-af93-142896b1d4c2)枚举值，包括 `none`（默认值）、`column`、`row` 或 `both`。
以下图片展示了一个大小调整提示。
![tooltip-resize](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/tooltip-resize.75a566.gif)

```javascript
spread.options.showResizeTip = GC.Spread.Sheets.ShowResizeTip.Both;
// 或者
// spread.options.showResizeTip = 3;
```
