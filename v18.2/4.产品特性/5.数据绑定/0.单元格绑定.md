# bindcells

您可以在SpreadJS中使用单元级绑定。
单元级绑定将对象的属性绑定到表单单元。 将数据对象包装到GC.Spread.Sheets.Bindings.[CellBindingSource ](gcdocsite__documentlink?toc-item-id=7adee0d0-cfd4-4c0b-98d2-9af1578f50ca)在单元格绑定前。 然后将包装的源绑定到表单(sheet.[setDataSource ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#setdatasource))。
本示例绑定表单中的单元格。

```JavaScript
var person = {name: "Wang feng", age: 25, address: {postcode: "710075"}};
var source = new GC.Spread.Sheets.Bindings.CellBindingSource(person);
activeSheet.setBindingPath(0, 0, "name");
activeSheet.setBindingPath(1, 1, "age");
activeSheet.setBindingPath(3, 3, "address.postcode");
activeSheet.setDataSource(source);
```
