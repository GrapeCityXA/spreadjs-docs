# pivot-table-settings

你可以修改数据透视表的设置，使其更易于理解。

## 自动调整列宽

可以使用 **autoFitColumn** 方法根据数据自动调整数据透视表的列宽。下面的动图展示了数据透视表中自动调整列宽的效果。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pt-autoFitColumn-method.ba004f.gif)
以下代码示例展示了如何在数据透视表中自动调整列宽。

```JavaScript
// 自动调整列宽
myPivotTable.autoFitColumn();
```

## 计算字段

你可以向数据透视表的值字段区域添加自定义字段，这些字段使用公式来计算值。在公式中，你可以使用常量或引用数据透视表的其他字段。
可以使用 **addCalcField** 方法添加计算字段。此外，还可以分别使用 **getCalcFields** 和 **removeCalcField** 方法获取和删除计算字段信息。
在下面的图片中，向数据透视表添加了一个计算字段“Tax”。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pt-calculatedfields.f8b30c.png)
以下代码示例展示了如何在数据透视表中添加、获取和删除计算字段。

```javascript
// 添加计算字段“Tax”，其值等于“UnitPrice”字段的 0.08%
// “UnitPrice”是数据透视表的度量字段之一
myPivotTable.addCalcField('Tax', '=UnitPrice*0.08');
myPivotTable.add('Tax', 'Tax Calculated is 0.08 percent of Unit Price', GC.Spread.Pivot.PivotTableFieldType.valueField, GC.Pivot.SubtotalType.sum);

// 获取计算字段
calcFieldsInfo = myPivotTable.getCalcFields();
// 在新工作表中添加计算字段的名称
for (var i = 0; i < calcFieldsInfo.length; i++) {
    calcFieldSheet.setValue(i + 1, 0, calcFieldsInfo[i].fieldName);
    calcField = calcFieldsInfo[i].fieldName;
    calcFieldSheet.setValue(i + 1, 1, calcFieldsInfo[i].formula);
}

// 删除计算字段
myPivotTable.removeCalcField(calcField);
```

## 计算项

你可以向行或列字段区域添加一个计算项，它使用指定的公式来计算数据透视表中的特定项。在公式中，你可以使用常量或引用数据透视表的其他字段。
可以使用 **addCalcItem** 方法添加计算项。此外，还可以分别使用 **getCalcItems**、**updateCalcItem** 和 **removeCalcItem** 方法获取、更新和删除计算项。

## 计算项的特性

* 计算项不能在数据透视表报表区域的多个字段上使用。
* 计算项的公式只能引用数据透视表中的数据，而不能引用工作表中的数据。
* SpreadJS 可以向正在分组的字段添加计算项，并将基础信息添加到分组字段中。
* 如果有数字分组字段或日期分组字段，只有选择分组才能添加计算项。
* 对数据透视表的所有引用都必须遵循“SourceFieldName[itemName]”的格式。
* 数据透视报表中所有值字段的“计算类型”只能是以下之一：求和类型、计数、最大值、最小值、乘积、数值计数。
* 计算项中的字段不能存在于数据透视报表的筛选区域中。
* SpreadJS 允许我们设置计算项的值是否应聚合到小计中。

在下面的图片中，向数据透视表添加了一个计算项 **“Category[Bakery+Beverages]”**。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/calculateditem.451872.png)
以下代码示例展示了如何在数据透视表中添加、更新和删除计算项。

```javascript
// 添加计算项“Category[Bakery+Beverages]”，其值等于“Category[Bakery] + Category[Beverages]”
function addCalcItem(myPivotTable) {
    myPivotTable.addCalcItem('Category', 'Category[Bakery + Beverages]', '=Category[Bakery] + Category[Beverages]');
    myPivotTable.autoFitColumn();
    return myPivotTable;
}

// 更新计算项
function updateCalcItem(myPivotTable) {
    myPivotTable.updateCalcItem('Category', 'Category[Bakery + Beverages]', '=Category[Bakery] - Category[Beverages]', 1);
    myPivotTable.options.calcItemAggregation = GC.Spread.Pivot.CalcItemAggregation.include;
    myPivotTable.autoFitColumn();
    return myPivotTable;
}

// 删除计算项
function deleteCalcItem(myPivotTable) {
    myPivotTable.removeCalcItem('Category', 'Category[Bakery + Beverages]');
    myPivotTable.autoFitColumn();
    return myPivotTable;
}
```

## 条件规则

你可以使用 **addConditionalRule** 方法在数据透视区域应用条件规则。此外，还可以分别使用 **getConditionalRules** 和 **removeConditionalRule** 方法获取或删除任何现有的条件规则。无论数据透视表布局如何变化，条件规则都能按预期工作。
以下图片展示了值单元格中的颜色格式条件规则。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pivot-addConditionalRule.becd83.gif)
以下代码示例展示了如何在数据透视表中应用条件规则。

```javascript
// 添加条件规则
myPivotTable.addConditionalRule([{ dataOnly: true, references: [{ fieldName: 'City', items: ['Seattle'] }] }], new GC.Spread.Sheets.ConditionalFormatting.ScaleRule(GC.Spread.Sheets.ConditionalFormatting.RuleType.threeScaleRule, 1 /* 最低值 */, 0, 'lightblue', 0 /* 数字 */, 500, 'yellow', 2 /* 最高值 */, 2000, 'green'));
```

### 合并带有标签的单元格并使其居中

你可以使用 `mergeItem` 选项来合并带有标签的单元格并使其居中对齐。此选项接受布尔值，并根据数据透视表的定义布局按如下方式工作：

| **选项** | **压缩形式** | **大纲形式** | **表格形式** |
| --- | ---- | ---- | ---- |
| 合并 | 仅列标题 | 仅列标题 | 列标题和行标题 |
| 居中 | 仅列标题 | 列标题和行标题 | 列标题和行标题 |

在下面的动图中，使用 **mergeItem** 选项合并了带有标签的单元格并使其居中。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pivot-mergeItems.4a1d9a.gif)
以下代码示例展示了如何在数据透视表中合并带有标签的单元格并使其居中对齐。

```javascript
// 合并并居中带有标签的单元格
myPivotTable.options.mergeItem = true;
```

## 数据透视表工具提示

你可以在数据透视表中启用工具提示，以了解数据的更多含义。当鼠标悬停在数据透视数据上时，工具提示数据就会显示出来。但是，如果值字段中没有明确的信息，则不会显示工具提示。你可以使用 `showToolTip` 选项在行/列标题区域、数据区域以及小计/总计区域显示工具提示。
下面的图片展示了鼠标悬停在数据透视数据上时显示的工具提示。

以下代码示例展示了如何在数据透视表中启用工具提示。

## 数据透视表序列化与反序列化

你可以使用 **serialize** 方法对数据透视表数据进行序列化并保存，并使用 **deserialize** 方法将序列化后的数据透视表数据恢复到现有的数据透视表中。序列化支持以下数据透视表数据：字段、选项、筛选、排序、布局、数据透视表位置和主题。
以下代码示例对数据透视表数据进行序列化并保存，打印序列化信息，然后将数据恢复到现有的数据透视表中。

```javascript
// 使用 serialize 方法保存数据透视表数据
serialization = myPivotTable.serialize();
// 打印序列化信息
info = JSON.stringify(serialization, null, 2);
console.log(info);

// 使用 deserialize 方法恢复数据
myPivotTable.deserialize(serialization);
```

## 空值显示为

如果数据透视表数据源中存在空值，SpreadJS 提供以下选项来选择是否显示自定义值：

* `showMissing` 表示当实际值为空时是否应显示任何值。它接受布尔值，默认值为 true。
* `missingCaption` 表示当实际值为空时应显示什么值。它接受字符串和数字值，默认值为空。

下面的图片展示了数据透视表中空值显示为“无销售”的情况。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pivot-emptyValue.e112ba.png)
以下代码示例展示了如何用字符串值替换空值。

```javascript
// 在空单元格中显示自定义值
myPivotTable.options.showMissing = true;
myPivotTable.options.missingCaption = "No Sales";
```

## 显示无数据的项目

你可以使用 **showNoData** 方法在数据透视表中显示无数据的项目，并选择是否在字段中显示空白单元格。此方法接受字段名称和一个布尔值（表示是否应显示项目）作为参数。
此设置通过管理数据透视表中项目的可见性，帮助用户比较数据源中的项目。数据的可见性不取决于它是否包含任何值。
以下图片显示了每个商店的数据，包括没有销售的时间段。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pt-showitem-nodata.65c725.png)
以下代码示例展示了如何显示无数据的项目。

```javascript
function initPivotTable(sheet) {
    myPivotTable = sheet.pivotTables.add('myPivotTable', 'tableSales', 1, 1, GC.Spread.Pivot.PivotTableLayoutType.outline, GC.Spread.Pivot.PivotTableThemes.dark3);
    myPivotTable.suspendLayout();
    myPivotTable.add('City', 'City', GC.Spread.Pivot.PivotTableFieldType.rowField);
    myPivotTable.add('OrderDate', 'OrderDate', GC.Spread.Pivot.PivotTableFieldType.rowField);
    myPivotTable.add('Product', 'Product', GC.Spread.Pivot.PivotTableFieldType.rowField);
    let groupInfo = { originFieldName: 'OrderDate', dateGroups: [{ by: GC.Pivot.DateGroupType.months }] };
    myPivotTable.group(groupInfo);
    myPivotTable.add('Quantity', 'Quantity', GC.Spread.Pivot.PivotTableFieldType.valueField, GC.Pivot.SubtotalType.sum);

    // 将 showNoData 设置为 true 以显示没有数量的产品
    myPivotTable.showNoData('Product', true);
    myPivotTable.resumeLayout();
    myPivotTable.autoFitColumn();
    return myPivotTable;
}
```

## 数据透视表数据显示方式

你可以使用 **showDataAs** 方法将数据透视表数据显示为不同类型的计算值。此方法接受字段名称和 IPivotShowDataAsInfo 对象属性。可以使用 **PivotShowDataAs** 枚举将值字段设置为不同的计算方式。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pivot-showDataAs.6fba67.gif)

## 无样式的 JSON 输入输出

在将电子表格导入或导出为 JSON 格式时，你可以选择保留或丢弃数据透视表的样式。当 **toJSON** 和 **fromJSON** 方法的 `ignorestyle` 参数设置为 true 时，会丢弃数据透视缓存和数据透视表样式，同时保留数据透视表的值。
下面的图片展示了从 JSON 文件导入时没有样式的数据透视表。
![Pivot_table_without_style.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/Pivot_table_without_style.dec9a2.555cfc.png)
以下代码示例展示了如何导入或导出无样式的 JSON 文件。

```javascript
function bindExcelIOEvent(spread) {
    // 当 IgnoreStyle 参数设置为 true 时导入 ssjson 文件
    var openButton = document.getElementById('openButton');
    openButton.addEventListener('click', function () {
        var file = document.getElementById('importFileName').files[0];
        var fileName = file.name;
        var suffix = fileName.substr(fileName.lastIndexOf('.'));

        if (suffix === '.ssjson' || suffix === 'json') {
            var reader = new FileReader();
            reader.onload = function () {
                var spreadJson = JSON.parse(this.result);
                spread.fromJSON(spreadJson, { ignoreStyle: true });
            };
            reader.readAsText(file);
        }
    });
    // 当 IgnoreStyle 选项设置为 true 时导出 ssjson 文件
    var saveSSJSONButton = document.getElementById('saveSSJSONButton');
    saveSSJSONButton.addEventListener('click', function () {
        var fileName = 'ExportedFile';
        var index = fileName.lastIndexOf('.');
        if (index >= 0) {
            fileName = fileName.substr(0, index) + '.ssjson';
        } else {
            fileName += '.ssjson';
        }
        var json = spread.toJSON({ includeBindingSource: true, ignoreStyle: true }),
            text = JSON.stringify(json);
        saveAs(new Blob([text], { type: 'text/plain;charset=utf-8' }), fileName);
    });
}
```

## 数据透视表引用

在引用数据透视表单元格时，SpreadJS 默认使用 GETPIVOTDATA 函数创建单元格引用。例如，**"=GETPIVOTDATA("price",$A$1,"salesperson","Alan","car","Mercedes","quantity",3)"**。但是，你可以通过将 `pivotAreaReference` 选项设置为 `cellReference` 来更改此行为。在这种情况下，SpreadJS 会为数据透视表单元格生成普通的单元格引用。例如，**“=F6”**。无论哪种情况，使用单元格引用的公式结果都是相同的。
此功能使你能够在不更改公式的情况下保留特定单元格的引用，即使数据透视表发生了变化。当用户想要将公式引用拖动填充到多个单元格时，普通单元格引用也很有用。例如，垂直拖动填充上述公式会得到 **"=F7"**、**"=F8"** 等等。而 GETPIVOTDATA 函数则无法实现这种行为。

下表展示了在使用 GETPIVOTDATA 函数和普通单元格引用时，单元格引用的不同情况：

| GETPIVOTDATA 函数 | 普通单元格引用 |
| --------------- | ------- |
| ![image-20230301-065943](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image-20230301-065943.f9d905.1bfc8e.png) | ![image-20230301-065903](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image-20230301-065903.dd1bb0.f0d49d.png) |

```javascript
// 对数据透视表单元格使用普通单元格引用
workbook.options.pivotAreaReference= GC.Spread.Pivot.PivotAreaReference.cellReference;
```

> JSON 导入和导出支持普通的数据透视表引用。然而，此功能在 Excel 中不起作用，因为 Excel 不存储该选项。
