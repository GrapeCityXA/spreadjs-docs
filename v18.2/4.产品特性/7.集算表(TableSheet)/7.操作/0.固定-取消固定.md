# tablesheet-pin-unpin

你可以在集算表中固定行和列，以便在滚动时将它们显示在当前视图的顶部或左侧。
此操作可以通过右键单击特定的行标题或列标题，然后选择“固定/取消固定”选项来执行。如下面的图片所示，在固定的行和列之后会显示一条分隔线。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ts-pinned.03ea21.png)

同样地，你可以通过选择“固定/取消固定”选项来取消固定某一行或某一列。在集算表视图中，最多只能固定 10 行或 10 列。

> **注意：** 筛选和排序功能不会影响已固定的行和列。
> 不支持撤销和重做操作。

你可以使用 [TableSheet.togglePinnedRows](https://docs.grapecity.com.cn/spreadjs/help/api//classes/GC.Spread.Sheets.TableSheet.TableSheet#togglepinnedrows) 或 [TableSheet.togglePinnedColumns](https://docs.grapecity.com.cn/spreadjs/help/api//classes/GC.Spread.Sheets.TableSheet.TableSheet#togglepinnedcolumns) 方法来切换行或列的固定状态，如下代码示例所示。

```javascript
// 将视图绑定到集算表
myView.fetch().then(function () {
    sheet.setDataView(myView);
    sheet.togglePinnedRows([4,5]);  // 固定行
    sheet.togglePinnedColumns([1,3]); // 固定列
});
```
