# sorting-in-group

在SpreadJS中，集算表（TableSheet）提供了强大的数据操作功能，例如排序和筛选。
集算表支持分组排序，这种排序在分组列和基础列之间起作用。默认情况下，自动排序功能是启用的。要禁用分组列的排序功能，可在分组列配置中将`allowSort`属性设置为`false`。
以下图片显示了排序结果是基于分组结果的，其中“销售包装”分组列按升序排列，而“年份季度”分组列和“库存商品键”基础列按降序排列。
![ts-grouping-sort](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ts-grouping-sort.fb7670.png)
在集算表分组中使用排序功能时，会观察到以下行为：

* 分组列的源列和其自身之间共享排序状态。
    ![ts-grouping-sortsame](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ts-grouping-sortsame.fbfd4e.png)
* 在分组级别上，一次只能对一列进行排序。
    ![ts-grouping-sortsingle](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ts-grouping-sortsingle.f91156.gif)
* 应用`groupBy`方法之前和应用`removeGroupBy`方法之后的最后排序状态会被保留。
    ![ts-grouping-sortstatus](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ts-grouping-sortstatus.44bb21.gif)

另一方面，筛选功能允许用户根据选定的条件仅显示相关数据。默认情况下，分组中的自动筛选功能是启用的。
![Filter_TSGrouping.b2fd90](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/Filter_TSGrouping.b2fd90.eb14d4.png)
要禁用分组列中的筛选功能，可将`allowFilterByValue`和`allowFilterByList`属性设置为`false`。
以下示例代码在分组上下文中禁用了排序和筛选功能。这是通过将`allowSort`、`allowFilterByValue`和`allowFilterByList`属性设置为`false`来实现的。通过这些设置，用户将被限制访问“排序/筛选”对话框，从而防止对分组数据进行任何排序或筛选操作。

```javascript
var spread, sheet;
$(document).ready(function () {
    // 初始化Spread。
    spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 0 });
    spread.options.autoFitType = GC.Spread.Sheets.AutoFitType.cellWithHeader;

    // 初始化数据管理器。
    var dataManager = spread.dataManager();
    var myTable = dataManager.addTable("myTable", {
        remote: {
            read: {
                url: 'https://demodata.grapecity.com/wwi/api/v1/stockItems'
            }
        },
        schema: {
            columns: {
                validFrom: { dataType: "date" }
            }
        }
    });

    // 初始化集算表。
    sheet = spread.addSheetTab(0, "TableSheet1", GC.Spread.Sheets.SheetType.tableSheet);

    // 将视图绑定到集算表。
    myTable.fetch().then(function () {
        var view = myTable.addView("myView", [
            { value: "stockItemKey", width: 150, caption: "库存商品键" },
            { value: "stockItem", width: 120, caption: "库存商品" },
            { value: "buyingPackage", width: 120, caption: "采购包装" },
            { value: "sellingPackage", width: 120, caption: "销售包装" },
            { value: "unitPrice", width: 150, caption: "单价" },
            { value: "taxRate", width: 120, caption: "税率" },
            { value: "validFrom", width: 200, caption: "生效日期" }
        ]);
        sheet.setDataView(view);

    });
});

function grouping() {
    // 通过单个字段（销售包装）创建分组，包含汇总字段和切片字段。
    sheet.groupBy([
        {
            caption: "销售包装", field: "sellingPackage", width: 150, style: { backColor: "#F9CA9A" },
            allowSort: false,
            allowFilterByValue: false,
            allowFilterByList: false,
            summaryFields: [
                {
                    caption: "SUM(单价)",
                    formula: "=SUM([unitPrice])",
                    slice: { field: "=YEAR([@validFrom])", width: 120, style: { backColor: "#FCE3CA", formatter: "#,##0.00" } },
                    width: 150,
                    style: { backColor: "#FAD7B2", formatter: "#,##0.00" }
                }
            ]
        }
    ]);
}

function removeGroup() {
    // 移除分组。
    sheet.removeGroupBy();
}
```
