# show-row-number

TableSheet 在一个独立的行标题中显示行号，类似于 Worksheet 中显示的行号。默认情况下，行号标题是隐藏的。
要显示行号标题，请将 ITableSheetOptions 接口的 showRowNumber 属性设置为 True。

```javascript
// 启用行号标题。
tableSheet.options.showRowNumber = true;

// 禁用行号标题。
tableSheet.options.showRowNumber = false;
```

## 功能和行为

行号标题与以下 TableSheet 操作配合使用：

### 固定行

行号标题与固定行及自定义行操作的附件无缝集成。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.a3e0ae.png)

### 分组行

使用分组功能时，行号标题的行为如下：
**展开的组**：在展开的组内，所有行的行号正常显示。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.2e4f05.png)
**折叠的组**：在折叠的组内，行号隐藏。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.8e4fe9.png)

### 过滤行

当行被过滤掉时，行号标题保持连续编号。
下图展示了在过滤掉2019年行后显示行号标题的示例。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.ce2945.png)

### 排序行

与过滤类似，当行被排序时，行号标题将显示与新行顺序对应的连续编号。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.b8da2b.png)

### 层次结构行

对于层次结构数据，行号标题的行为如下：
**展开的层级**：所有可见行的行号均显示。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.93803d.png)
**折叠的层级**：在折叠的层级内，行号隐藏。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.f743b8.png)

## 使用 Designer

TableSheet 还允许您在 SpreadJS Designer 中切换行号标题的可见性。要启用/禁用 TableSheet 的 showRowNumber 属性，您需要在 TABLE SHEET DESIGN 选项卡中勾选/取消勾选“显示行号”选项。
