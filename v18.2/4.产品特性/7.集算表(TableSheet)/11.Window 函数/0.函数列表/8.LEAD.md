# lead

该函数提供对跟随当前行的给定物理偏移量之后的行的值进行访问的功能。如果没有这样的行，将返回默认值。它不接受窗口帧定义，如FRAMEROWS和FRAMERANGE。

## 语法

`LEAD(value_function, [offset_value], [default_value])`

## 参数

该函数提供以下参数。

| **参数** | **描述** |
| -------- | ----------- |
| *value\_function* | [必选] 字段名或公式。 |
| *[offset\_value]* | [可选] 当前行之后的行偏移量，offset = 1。<br>偏移量应为非负整数。如果为0，则对当前行评估*value\_function*。 |
| *[default\_value]* | [可选] 默认值，默认为null |

## 示例

```
// WINDOW(LEAD([@city]), ORDERBY([sold]))

城市      |    销售额    |    lead
----------------------------------------------
Paris         100           Berlin
Berlin        150           Rome      
Rome          200           Moscow
Moscow        200           London
London        300           null

// WINDOW(LEAD([@city], 2), ORDERBY([sold]))

城市      |    销售额   |    lead
----------------------------------------------
Paris         100           Rome      
Berlin        150           Moscow
Rome          200           London
Moscow        200           null
London        300           null
```
