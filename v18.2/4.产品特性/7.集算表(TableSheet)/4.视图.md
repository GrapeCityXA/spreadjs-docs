# tablesheet-views

表格视图是集算表的核心组成部分，由获取的数据源字段构成。它用于丰富数据列，并赋予数据列更多功能。
![ts-views-flowchart.cb2296](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ts-views-flowchart.cb2296.c360f4.png)
如上述流程图所示，表格视图可以通过以下方式呈现：

* **表格列**：直接由字段生成的默认列，这意味着它们仅具有字段名称属性，用于显示默认视图。
* **视图列**：可以使用样式、格式和更多属性进行自定义的丰富列。通过使用许多有用的属性（如标题、样式、宽度和表头样式），它们被渲染到集算表视图中。

你可以通过设置各种 **IColumn** 属性（如表头样式、表头自适应、条件格式、数据验证）以及列样式（如单元格类型和下拉列表）来自定义表格视图。

## 列显示值

你可以使用列的样式变量中的公式格式化器，在集算表的列中显示自定义值，以替代现有的列数据。该公式可以使用括号中的“@”运算符显示整行的属性，该运算符显示整行数据。
在集算表的列中显示自定义值有两种方法：

* 格式化器中的公式
    =[@contactTitle] & ":" & [@employee.FirstName] & " " & [@employee.LastName]
* 格式化器中的模板公式
    {{[@contactTitle]}} : {{=[@employee.FirstName] & " " & [@employee.LastName]}}

![column-display-value.63ee46](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/column-display-value.63ee46.bb4949.png)
以下代码示例展示了使用格式化器中的公式来显示自定义列值：

```JavaScript
// 在销售表和客户表之间添加关系
dataManager.addRelationship(salesTable, "customerKey", "myCustomer", customerTable, "customerKey", "mySales");

// 添加自定义视图
customerTable.fetch().then(function () {

var myView = salesTable.addView("myView", [
       { value: "saleKey", width: 100, caption: "销售键" },
       { value: "salesPerson", width: 150, caption: "销售人员" },
       { value: "myCustomer", width: 350, caption: "客户信息", style: { formatter: '=[@myCustomer.primaryContact] & " " & [@myCustomer.postalCode]' } },
       { value: "address", width: 350, caption: "地址" },
       { value: "stockItem", width: 350, caption: "库存商品" },
       { value: "quantity", width: 100, caption: "数量" }
          ]);
```

## 列标题样式

你可以通过在视图的 `headerStyle` 属性中定义 **HeaderStyleOptions** 来自定义列标题的样式。**HeaderStyleOptions** 包含背景颜色、主题字体、自动换行等选项。
![ts-columnheaderstyle](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ts-columnheaderstyle.5c7411.png)
以下代码示例展示了如何在集算表视图中设置列标题样式。

```javascript
// 定义列标题的样式，并在使用 addView() 方法添加视图时分配该样式
var headerStyle = {
    font: "italic bold 13pt Calibri",
    borderTop: {
        color: "red",
        style: "thick"
    },
    borderLeft: {
        color: "red",
        style: "thin"
    },
    borderRight: {
        color: "red",
        style: "thin"
    },
    borderBottom: {
        color: "red",
        style: "thin"
    }
};


// 将视图绑定到集算表
customerTable.fetch().then(function () {
    var view = customerTable.addView("myView", [
        { value: "customerKey", width: 130, headerStyle: headerStyle, caption: "客户键" },// 使用 headerStyle 属性设置列标题的样式
        { value: "customer", width: 200, headerStyle: headerStyle, caption: "客户" }, 
        { value: "billToCustomer", width: 200, headerStyle: headerStyle, caption: "账单收件客户" },
        { value: "category", width: 120, headerStyle: headerStyle, caption: "类别" },
        { value: "buyingGroup", width: 180, headerStyle: headerStyle, caption: "采购组" },
        { value: "primaryContact", width: 170, headerStyle: headerStyle, caption: "主要联系人" },
        { value: "postalCode", width: 120, headerStyle: headerStyle, caption: "邮政编码" },
        { value: "validFrom", width: 150, headerStyle: headerStyle, caption: "有效期从" },
        { value: "validTo", width: 180, headerStyle: headerStyle, caption: "有效期至" }

    // 该视图包含表格的所有默认列
    sheet.setDataView(view);
});
```

## 列标题自适应模式

你可以在集算表视图中为指定列设置列标题自适应模式，以更改标题布局，从而适当地显示标题和视口数据。
当列数据的内容长度较短但列标题的长度过长时，或者当某些列存在关系时，此功能非常有用。
视图选项属性 **headerFit** 可用于设置以下三种类型的标题自适应模式。

* 正常：列标题文本方向为水平，从左到右。这是默认的标题自适应模式。
    ![ts-columnheaderfit-normal](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ts-columnheaderfit-normal.6347ee.png)
* 垂直：列标题文本方向为垂直，从上到下。
    ![ts-columnheaderfit-vertical](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ts-columnheaderfit-vertical.db49ba.png)
* 堆叠：当列的宽度不足以容纳列标题文本时，列标题会相互堆叠。
    ![ts-columnheaderfit-stack](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ts-columnheaderfit-stack.1ad2d4.png)
    当列彼此相邻时，堆叠标题自适应模式会与垂直模式以交叉自适应的方式一起显示。
    ![ts-columnheaderfit-mixed](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ts-columnheaderfit-mixed.9010dd.png)

你还可以使用 **defaultStackRowHeight** 选项在集算表视图中设置堆叠行高。当该值为 null（默认值）时，它会默认计算平均行高。如果给定一个有效的数字作为值，它将计算从上到下的高度。
以下代码示例展示了如何在集算表视图中设置所需的列标题自适应模式并调整行高。

```javascript
// 将视图绑定到集算表
myTable.fetch().then(function () {
    var view = myTable.addView("myView", [
        { value: "saleKey", caption: "销售键", headerFit: "stack", headerStyle: headerStyle },// 将 headerFit 设置为 stack
        { value: "cityKey", caption: "城市键", headerFit: "stack", headerStyle: headerStyle },
        { value: "stockItemKey", width: 50, caption: "库存商品键", headerFit: "stack", headerStyle: headerStyle },
        { value: "invoiceDateKey", width: 120, caption: "发票日期键", headerFit: "vertical", headerStyle: headerStyle },
        { value: "deliveryDateKey", width: 120, caption: "交货日期键", headerFit: "vertical", headerStyle: headerStyle },
        { value: "salesPerson", width: 150, caption: "销售人员", headerFit: "vertical", headerStyle: headerStyle },
        { value: "address", caption: "地址", width: 300, headerFit: "normal", headerStyle: headerStyle }

    ]);
    sheet.setDataView(view);
    sheet.options.defaultStackRowHeight = 30;
    sheet.setDefaultRowHeight(220, 1);
});
```

> **注意**：如果行高无法显示整个标题，特定列的行堆叠将被截断。可以使用 **setDefaultRowHeight** 方法来调整此情况。

## 单元格类型和下拉列表

你可以在集算表视图中设置不同的单元格类型和下拉列表，以显示信息的呈现方式，并帮助轻松快速地选择数据。
![ts-celltype-dropdown.c03983](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ts-celltype-dropdown.c03983.19349d.gif)
集算表支持以下单元格类型和下拉列表：

* 单元格类型 - 复选框、组合框、超链接、单选按钮列表、复选框列表、范围模板
* 下拉列表 - 颜色选择器、日期选择器、时间选择器、月份选择器、列表、滑块、计算器、工作流列表、多列

以下代码示例展示了如何在集算表视图中添加单元格类型和下拉列表。

```javascript
// 单选按钮列表的代码
var radioButtonListStyle = new GC.Spread.Sheets.Style();
var cellTypeRadioButtonList = new GC.Spread.Sheets.CellTypes.RadioButtonList();
cellTypeRadioButtonList.items([
    { text: "Tailspin Toys (Head Office)", value: "Tailspin Toys (Head Office)" },
    { text: "Wingtip Toys (Head Office)", value: "Wingtip Toys (Head Office)" },
]);
radioButtonListStyle.cellType = cellTypeRadioButtonList;

// 按钮列表的代码
var buttonListStyle = new GC.Spread.Sheets.Style();
var buttonListCellType = new GC.Spread.Sheets.CellTypes.ButtonList();
buttonListCellType.items([
    { text: "Tailspin Toys", value: "Tailspin Toys" },
    { text: "Wingtip Toys", value: "Wingtip Toys" },
]);
buttonListStyle.cellType = buttonListCellType;

// 日期下拉列表的代码
var dateStyle = {};
dateStyle.cellButtons = [
    {
        imageType: "dropdown",
        command: "openDateTimePicker",
        useButtonStyle: true,
    }
];
dateStyle.dropDowns = [
    {
        type: "dateTimePicker",
        option: {
            showTime: true
        }
    }
];

// 将视图绑定到集算表
customerTable.fetch().then(function () {
    var view = customerTable.addView("myView", [
        { value: "customerKey", width: 120, caption: "客户键" },
        { value: "billToCustomer", width: 400, caption: "账单收件客户", style: radioButtonListStyle },
        { value: "buyingGroup", width: 250, caption: "采购组", style: buttonListStyle },
        { value: "primaryContact", width: 170, caption: "主要联系人" },
        { value: "validFrom", width: 190, caption: "有效期从", style: dateStyle }
    ]);
    // 该视图包含表格的所有默认列
    sheet.setDataView(view);
});
```

## 列标题多级表头

你可以在集算表视图中设置列标题，其中多个列可以归在一个公共标题下。通过将列分组到一个公共类别中，它可以帮助你以有组织的方式呈现可用信息。
**addView** 方法中 *columnInfos* 参数的 “caption” 属性接受一个字符串数组，用于在集算表中设置列标题的多行。标题中具有相同值的列会在行方向和列方向上自动合并。
在以下示例中，客户键、客户名称、账单收件客户和主要联系人等客户信息显示在公共标题 “客户信息” 下，同时保留每个列的现有标题。类似地，产品有效期日期可以显示在一个列标题下。
![ts-columnheader-multiplecol](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ts-columnheader-multiplecol.4cb2aa.png)
以下代码示例展示了如何在集算表视图中为多个列设置相同的标题。

```javascript
// 将视图绑定到集算表
myTable.fetch().then(function () {
   var view = myTable.addView("myView", [
       { value: "customerKey", width: 130, caption: ["客户信息", "客户键"] }, // 为 caption 设置字符串数组
       { value: "customer", width: 200, caption: ["客户信息", "客户"] },
       { value: "billToCustomer", width: 200, caption: ["客户信息", "账单收件客户"] },
       { value: "primaryContact", width: 170, caption: ["客户信息", "主要联系人"] },
       { value: "validFrom", width: 150, caption: ["有效期", "有效期从"], style: { formatter: "MM/dd/yyyy"} },
       { value: "validTo", width: 180, caption: ["有效期", "有效期至"], style: { formatter: "MM/dd/yyyy"} }
   ]);
   sheet.setDataView(view);
});
```

要了解如何使用 SpreadJS 设计器应用多级表头列标题，请参阅 [集算表设计模式](gcdocsite__documentlink?toc-item-id=ac09b6e6-9be4-4f73-83be-b945f3bb26d8)。

## 自由表头区域

你可以在集算表视图中添加一个表头区域，在该区域中你可以描述集算表，并使用公式和迷你图呈现汇总数据。自由表头区域位于主集算表视图的上方，可以由一行或多行组成，如下图所示。
![ts-freeheader](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ts-freeheader.e051b8.png)
[applyFreeHeaderArea ](gcdocsite__documentlink?toc-item-id=8dc0b7a4-ace7-4c61-b4a7-00790d5584fe#applyFreeHeaderArea)方法用于配置列标题的自由布局区域。此方法接受一个工作表 JSON，可以使用 **toJSON** 方法创建该 JSON。在生成工作表 JSON 之前，如果你希望保留包含工作表名称的公式，请将 **keepUnknownFormulas** 选项设置为 true。
以下代码示例展示了如何创建一个模板，并在集算表视图中应用自由表头区域。

```javascript
// 将视图绑定到集算表
myTable.fetch().then(function () {
   var view = myTable.addView("myView", [

       { value: "stockItem", width: 300, caption: "库存商品", headerStyle: headerStyle },
       { value: "unitPrice", width: 120, caption: "单价", headerStyle: headerStyle },
       { value: "taxRate", width: 120, caption: "税率", headerStyle: headerStyle },
       { value: "recommendedRetailPrice", width: 190, caption: "建议零售价", style: currencyFormatter, headerStyle: headerStyle, conditionalFormats: [dataBarRule1] },
       { value: "=([@unitPrice] * [@taxRate])/100 + [@unitPrice]", caption: "实际零售价", style: currencyFormatter, width: 190, headerStyle: headerStyle, conditionalFormats: [dataBarRule2] }, // 计算列

   ]);

   // 为自由表头区域 json 创建模板
   var templateSheet = new GC.Spread.Sheets.Worksheet();
   templateSheet.options.keepUnknownFormulas = true;
   var currencyFormatterStyle = new GC.Spread.Sheets.Style();
   currencyFormatterStyle.formatter = formatter;
   currencyFormatterStyle.hAlign = GC.Spread.Sheets.HorizontalAlign.left;
   templateSheet.setRowCount(6);
   var freeHeaderAreaStyle = new GC.Spread.Sheets.Style();
   freeHeaderAreaStyle.backColor = Colors.white;

   templateSheet.setValue(0, 0, "零售价分析");
   templateSheet.getCell(0, 0).hAlign(GC.Spread.Sheets.HorizontalAlign
   .left).font("bold 30px \"Calibri\"");
   templateSheet.addSpan(0, 0, 1, 5);
   var titleStyle = new GC.Spread.Sheets.Style();
   titleStyle.backColor = Colors.lightGreen;
   titleStyle.foreColor = Colors.black;
   templateSheet.setStyle(0, -1, titleStyle);
   templateSheet.setRowHeight(0, 80);

   templateSheet.getCell(1, 0)
       .value("Whether a Stock Item's Actual Retail Price is either under or over Recommended Retail Price is automatically calculated.")
       .font("italic 12px \"Calibri\"")
       .foreColor("rgb(120,120,120)")
       .textIndent(2);
   templateSheet.setStyle(1, -1, titleStyle);
   templateSheet.addSpan(1, 0, 1, 5);

   var headerDescriptionStyle = new GC.Spread.Sheets.Style();
   headerDescriptionStyle.backColor = Colors.lightGreen;
   headerDescriptionStyle.borderBottom = new GC.Spread.Sheets.LineBorder(Colors.middleGreen, GC.Spread.Sheets.LineStyle.thick);
   templateSheet.setStyle(2, -1, headerDescriptionStyle);
   templateSheet.addSpan(2, 0, 1, 5);
   templateSheet.setRowHeight(2, 16);

   templateSheet.setValue(3, 0, "Total Recommended Retail Price");
   templateSheet.getCell(3, 0).hAlign(GC.Spread.Sheets.HorizontalAlign.left).font("bold 14px \"Calibri\"").foreColor(Colors.darkGreen);
   templateSheet.addSpan(3, 0, 1, 2);
   templateSheet.setFormula(3, 2, '=SUM(TableSheet1[Recommended Retail Price])');
   templateSheet.getCell(3, 2).hAlign(GC.Spread.Sheets.HorizontalAlign.left).font("bold 14px \"Calibri\"").foreColor(Colors.darkGreen).formatter(formatter);
   templateSheet.setFormula(3, 3, '=HBARSPARKLINE(ROUND(C4/MAX(C4,C5),2),"' + Colors.darkGreen + '",false)');
   templateSheet.addSpan(3, 3, 1, 2);
   templateSheet.setStyle(3, -1, freeHeaderAreaStyle);

   templateSheet.setValue(4, 0, "Total Actual Retail Price");
   templateSheet.getCell(4, 0).hAlign(GC.Spread.Sheets.HorizontalAlign.left).font("bold 14px \"Calibri\"").foreColor(Colors.brown);
   templateSheet.addSpan(4, 0, 1, 2);
   templateSheet.setFormula(4, 2, '=SUM(TableSheet1[Actual Retail Price])');
   templateSheet.getCell(4, 2).hAlign(GC.Spread.Sheets.HorizontalAlign.left).font("bold 14px \"Calibri\"").foreColor(Colors.brown).formatter(formatter);
   var contentBorderStyle = new GC.Spread.Sheets.Style();
   contentBorderStyle.backColor = Colors.white;
   contentBorderStyle.borderBottom = new GC.Spread.Sheets.LineBorder(Colors.brown, GC.Spread.Sheets.LineStyle.thick);
   templateSheet.setStyle(4, -1, contentBorderStyle);
   templateSheet.setFormula(4, 3, '=HBARSPARKLINE(ROUND(C5/MAX(C4,C5),2),"' + Colors.brown + '",false)');
   templateSheet.addSpan(4, 3, 1, 2);

   templateSheet.setFormula(5, 0, '=IF(C4>C5,"Budget is under Total Recommended Retail Price by","Budget is over Total Recommended Retail Price")');
   templateSheet.getCell(5, 0).hAlign(GC.Spread.Sheets.HorizontalAlign.left).font("bold 14px \"Calibri\"").foreColor(Colors.black);
   templateSheet.addSpan(5, 0, 1, 2);
   templateSheet.setFormula(5, 2, '=C4-C5');
   templateSheet.getCell(5, 2).hAlign(GC.Spread.Sheets.HorizontalAlign.left).font("bold 14px \"Calibri\"").formatter(formatter).foreColor(Colors.black);
   templateSheet.setStyle(5, -1, freeHeaderAreaStyle);
   templateSheet.addSpan(5, 2, 1, 3);

   let template = templateSheet.toJSON();
   sheet.applyFreeHeaderArea(template);
   sheet.setDataView(view);
});
```

## 触发公式

你可以在列中存储独立的数据，但仍然可以使用集算表中的 **触发公式** 来使用公式计算列数据。根据选定的条件重新计算数据、在输入新值时清理数据或为列设置适当的默认值时，这非常有用。
SpreadJS 提供了一个新的接口 `GC.Data.ITriggerFormulaOptions`，其中包括 `when`、`formula` 和 `fields` 等属性来配置触发器。

| 名称 | 描述 | 用法 |
| --- | --- | --- |
| when<br>(必填) | 指示何时触发。 | <ul><li>**onNew**：将公式应用于创建的数据。</li><li>**onNewAndUpdate**：将公式应用于创建或更新的数据。</li></ul> |
| formula<br>(必填) | 指示应用的公式。 | 公式的计算结果将设置在行数据中。 |
| fields<br>(必填) | 指示哪些字段可能会影响公式的触发。 | “Any Field” 表示所有字段；“field1, field2, field3” 表示相关字段，用逗号分隔。<br>如果 **when** 为 **onNew**，则无需指定字段，否则是必需的。 |

以下代码示例实现了触发公式。

```javascript
schema: {
        type: "csv",
        columns: {
            SKU: {
                dataType: "string",
                trigger: {
                    when: "onNewAndUpdate",
                    formula: "=UPPER(TRIM([@SKU]))", // 格式化输入的 SKU 文本
                    fields: "SKU" // 如果输入了 SKU 字段，则触发公式来格式化输入文本
                }
            },
            OrderDate: {
                dataType: "date",
                trigger: {
                    when: "onNew", // 当添加订单时，记录订单创建日期
                    formula: "=TODAY()"
               }
            },
            lastUpdatedTime: {
                dataType: "date",
                trigger: {
                    when: "onNewAndUpdate",
                    formula: "=NOW()",
                    fields: "*" // 当任何字段更新或添加订单时，记录订单更新时间
                }
            },
            lastUpdateUser: {
                dataType: "string",
                trigger: {
                    when: "onNewAndUpdate",
                    formula: "=ACTIVEUSER()", // 用户可以自行决定如何获取当前更新用户
                    fields: "*" // 当任何字段更新或添加订单时，记录更新用户
                }
            },
            OrderPhone: {
                dataType: "string",
                trigger: {
                    when: "onNewAndUpdate",
                    formula: "=IF(ISBLANK([@OrderPhone]),[@customer.Phone],[@OrderPhone])",
                    fields: "CustomerId,OrderPhone"// 当订单电话为空时，提供客户电话
                }
            },
            Amount: {
                dataType: "number",
                trigger: {
                    when: "onNewAndUpdate",
                    formula: "=LET(amount, [@UnitPrice] * [@Quantity], IF([@Quantity] > 30, amount * 0.8, amount))",
                    fields: "UnitPrice,Quantity"  // 当 UnitPrice 或 Quantity 字段更新或添加订单时，Amount 字段将自动获得计算结果
                }
            },
            CustomerId: {
                lookup: {
                    name: 'customer', columns: [
                        { value: "Id", width: 60 },
                        { value: "CompanyName", width: 200 },
                        { value: "ContactName", width: 140 },
                        { value: "ContactTitle", width: 140 }
                    ]
                }
            },
            Quantity: { dataType: "number" },
            UnitPrice: { dataType: "number" },
        }
    }
});
```

触发公式有一定的规则，例如：

* 当添加新的行数据时，**onNew** 和 **onNewAndUpdating** 触发器会进行计算，类似于更新操作。
* 当一行数据中的多个字段被更新时，公式将被触发以更改被监视字段的值。否则，它不会被触发。
* 如果字段的触发器监视该字段本身，则触发公式将使用新值进行计算，并且结果将被视为该字段的更新值。
* 触发公式的计算值将被视为该字段的更新值，并且更新值将应用于直接引用该字段的触发公式的计算中。
* 如果同时为列应用了默认值和触发公式，则默认值具有更高的优先级。
