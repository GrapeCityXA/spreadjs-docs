# lookup-column

查找列是一种你可以在数据源模式中标记为“查找”的列，并且在 TableSheet 中可以将其呈现为组合框单元格类型或多列下拉列表。借助查找列，对于 TableSheet 视图而言，你能够以高效的方式从固定的查找列或一组相关行中选择列值。查找列的概念由 [TableSheet 跨列](gcdocsite__documentlink?toc-item-id=82fd1dec-c526-4aba-b29d-389ad61e198d) 引入。
TableSheet 允许你通过以下方式在数据模式中将列标记为“查找”：

1. **作为数组**
    当数据源模式中某列的查找值是一个数组时，组合框单元格类型将自动应用于该列，并且查找数组中的所有项都会显示在组合框中。
    ![array-lookup.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/array-lookup.121670.25277c.png)
    以下代码展示了如何在 TableSheet 中设置查找数组。例如，你可以将列的“类型”标记为查找，并为其设置数组值。

    ```JavaScript
    var workItemTable = dataManager.addTable('WorkItems', {
        data: [
            {
                ID: 1,
                Date: '9/12/2020',
                Description: '了解你的数据',
                TotalPoints: 10,
                Type: '家庭作业',
            },
            //...
        ],
        schema: {
            columns: {
                Date: { dataType: 'date' },
                // 将查找列设置为数组
                Type: { lookup: ['家庭作业', '小测验', '考试'] },
            },
        },
    });
    
    ```
2. **作为关系名称**
    在创建两个表之间的关系时，你可以在数据源模式中将列的查找值标记为关系名称。在这种情况下，单元格按钮和多列下拉列表将自动应用于该列，并且下拉列表将显示来自相关表的默认列数据。
    ![relationship-students.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/relationship-students.6815ab.b2d8d7.png)
    在下面的示例中，你可以创建“学生（Students）”和“成绩（Grades）”这两个表之间的关系，然后在“成绩（Grades）”表中将“学生 ID（Student ID）”列标记为查找，关系名称为“student”，这样相关表“学生（Students）”就会以默认列显示在下拉列表中。

    ```JavaScript
    var studentTable = dataManager.addTable('Students', {
        data: [
            {
                ID: 1,
                Name: '艾伦·罗宾逊',
            },
            //...
        ],
    });
    var gradeTable = dataManager.addTable('Grades', {
        data: [
            {
                StudentID: 1,
                WorkItemID: 1,
                Grade: 4,
            },
            //...
        ],
        schema: {
            columns: {
                StudentID: {
                    lookup: 'student',
                },
            },
        },
    });
    dataManager.addRelationship(gradeTable, 'StudentID', 'student', studentTable, 'ID', 'grades');
    
    ```
3. **作为选项**
    你可以在数据源模式中将列的查找值标记为一个选项，该选项包含一个关系名称和一些列选项。在这种情况下，单元格按钮和多列下拉列表将自动应用于该列。当列的查找值是一个选项时，选项列定义仅接受四个选项，即值、宽度、可见性和标题。因此，下拉列表将显示带有指定列的相关表，其中每列可以指定字段名称、标题、宽度和可见性属性。
    ![lookup-option-relationname.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/lookup-option-relationname.9ce76c.f23ff1.png)
    在下面的示例中，你可以创建“工作项（WorkItems）”和“成绩（Grades）”这两个表之间的关系，并在“成绩（Grades）”表中将“工作项 ID（WorkItem ID）”列标记为查找选项，关系名称为“workItem”，这样相关表“工作项（WorkItems）”就会以指定列显示在下拉列表中。

    ```JavaScript
    var workItemTable = dataManager.addTable('WorkItems', {
        data: [
            {
                ID: 1,
                Date: '9/12/2020',
                Description: '了解你的数据',
                TotalPoints: 10,
                Type: '家庭作业',
            },
            //...
        ],
    });
    var gradeTable = dataManager.addTable('Grades', {
        data: [
            {
                StudentID: 1,
                WorkItemID: 1,
                Grade: 4,
            },
            //...
        ],
        schema: {
            columns: {
                WorkItemID: {
                    // lookup: { name: 'workItem', columns: ["ID", "Description", "TotalPoints", "Type"]}
                    lookup: {
                        name: 'workItem',
                        columns: [{ value: 'ID' }, { value: 'Description', width: 150 }, { value: 'TotalPoints', width: 100 }, { value: 'Type', width: 150, caption: '工作项类型' }],
                    },
                },
            },
        },
    });
    dataManager.addRelationship(gradeTable, 'WorkItemID', 'workItem', workItemTable, 'ID', 'grades');
    
    ```

### 使用 SpreadJS 设计器

你可以使用 SpreadJS 设计器的“数据源”选项卡，在 TableSheet 中设置查找列。“数据源”选项卡会在表条目的“列”选项卡的“模式”部分提供“查找”选项。
![lookup-location-schema.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/lookup-location-schema.9a3225.c3cbc6.png)
默认情况下，你可以通过以下两种方式之一，在 TableSheet 的模式中设置“静态数组”作为查找值：

1. 直接在“查找”编辑器中输入数组字符串，例如“123, 628, 325”。
2. 从“查找”下拉列表中选择数组字符串。
    ![schema-dropdown-lookuparray.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/schema-dropdown-lookuparray.a19d97.f6383b.png)
    设置数组查找值后，你可以在 TableSheet 列的组合框下拉列表中查看数组项。例如，在这里，你可以在 TableSheet 的“发货方式（shipVia）”列中显示数组字符串作为查找值。
    ![lookup-array-sjsdesigner.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/lookup-array-sjsdesigner.9b7bf9.5be4ed.png)
    当你处理表之间相互关联的 TableSheet 时，你可以通过以下两种方式之一，在模式中设置“关系名称”作为查找值：
3. 直接在“查找”编辑器中输入关系名称，例如“Orders\_customId”。
4. 从“查找”下拉列表中选择“关系名称”项。
    ![lookup-relationshipname.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/lookup-relationshipname.fff333.109938.png)
5. 通常，当你将关系名称设置为查找值时，相关列也会显示在模式中“查找”的“列”选项下。你可以勾选任何你希望在 TableSheet 的多列下拉列表中显示的列。
    ![Lookup-dropdwon-columns.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/Lookup-dropdwon-columns.c63ac9.47b843.png)
6. 例如，在这里，你可以在 TableSheet 的“地址（address）”列中添加关系名称“Customer\_phone”作为查找值。“地址”列显示按钮单元格，点击这些单元格会显示列下拉列表，其中包含你从“查找”的“列”选项中选择的列。
    ![multicolumn-lookup.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/multicolumn-lookup.5d7b83.9688d5.png)
