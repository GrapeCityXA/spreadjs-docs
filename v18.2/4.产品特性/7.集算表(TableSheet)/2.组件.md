# tablesheet-components

TableSheet由各种组件组成，每个组件都有自己独特的功能和定制。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-component.png)

## TableSheet面板

TableSheet面板由视图名称和字段名称组成。 字段名称还可以包含计算出的字段和相关字段。
您可以选择在TableSheet视图中显示或隐藏哪些列以及拖动字段以调整其在字段集合中的顺序。 默认情况下，面板仅显示列标题。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-panel-showhide.gif)
如果缺少标题，则显示字段名称。 你也可以设置 **showSource** 选项为 "all" 在标题旁边显示字段名称。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-panel-colvalue.png)
以下代码示例显示了如何创建TableSheet面板

```JavaScript
//初始化一个tablesheet面板
var host = document.getElementById("panel");
panel = new GC.Spread.Sheets.TableSheet.TableSheetPanel("myPanel", sheet, host);
```

[TableSheetPanel](gcdocsite__documentlink?toc-item-id=795291ad-85b3-47b4-90a1-df4bfb933cc1)类提供诸如[attach](gcdocsite__documentlink?toc-item-id=795291ad-85b3-47b4-90a1-df4bfb933cc1#attach),[detach](gcdocsite__documentlink?toc-item-id=795291ad-85b3-47b4-90a1-df4bfb933cc1#detach), 和[destroy](gcdocsite__documentlink?toc-item-id=795291ad-85b3-47b4-90a1-df4bfb933cc1#destroy), 来在运行时与TableSheet Panel进行交互。
以下代码示例显示如何使用不同的TableSheetPanel类方法。

```示例标题
// 初始化一个tablesheet面板
var host = document.getElementById("panel");
panel = new GC.Spread.Sheets.TableSheet.TableSheetPanel("myPanel", sheet, host);

// 将一个TableSheet附加到当前的TableSheet面板
panel.attach(tableSheet);
// 从当前TableSheet面板卸载TableSheet
panel.detach();
// 销毁当前TableSheet面板。
panel.destroy();
```

## 分组面板

包括一个分组区域的一个面板。此区域提供添加分组字段，摘要字段和切片字段的选项。
您可以通过将列字段从字段区域拖动到组区域来分组字段。 双击以修改分组字段的标题。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-panel-addgroup.gif)

您可以通过将其从分组区域拖动到任何其他区域，或单击分组字段中的删除按钮来删除分组字段。

### 添加摘要和切片字段

您可以通过单击“添加摘要字段”按钮来创建摘要字段，并输入自定义公式。 摘要字段提供通过输入切片字段来添加切片项的选项。 您可以通过清除切片项公式来删除切片。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-panel-addsummaryslice.gif)

## 筛选对话框

TableSheet支持类似excel的筛选对话框，包括文本，编号和日期条件。 它还包括排序选项，例如升序和降序。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-filterdialog.png)
如果不需要清单或筛选对话框某些部分，可以控制TableSheet筛选对话框中每个部分的可见性。 要了解更多关于排序和筛选，请参阅[Sort and Filter](gcdocsite__documentlink?toc-item-id=2276aff6-b5d6-47ec-81f1-6cafe2386676)主题。

## 状态栏

TableSheet支持在状态栏中添加数据和自定义项。选择不同单元格范围可以在状态栏中显示相关信息。
例如，下图显示的状态栏，它在显示tablesheet中所选列的数量。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-statusbar.png)
要了解如何在状态栏中添加自定义项，请参阅[状态栏](gcdocsite__documentlink?toc-item-id=7cd86322-52e7-4b93-a1e2-86fb35306f6f).

## 上下文菜单

TableSheet支持在不同区域中显示上下文菜单，比如在视窗或角落、行标题、列标题等位置。
每个区域提供不同的菜单项，例如锚定/取消锚定，显示/隐藏 和 复制/剪切/粘贴 等选项。
