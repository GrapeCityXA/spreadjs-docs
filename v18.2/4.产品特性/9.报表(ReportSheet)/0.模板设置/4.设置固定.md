# pin

固定选项用于清除模板中溢出单元格的偏移量。
单元格溢出后，报表的布局可能会发生变化。在这种情况下，你可以在模板中固定单元格，以清除溢出单元格的偏移量。要配置固定选项，请使用 [Spread.Report.TemplateSheet](gcdocsite__documentlink?toc-item-id=a1bb51b8-9953-434b-947c-b37b83735c7a) 类的 `setTemplateCell` 方法中的 `pin` 属性。
`pin` 属性可用的选项有“无（None）”、“行（Row）”、“列（Column）”和“两者（Both）”。默认的固定值为“无（None）”。

>type=info
> **注意事项**：
>
> * 固定选项仅适用于没有父级的静态单元格，并且静态单元格不能与溢出单元格树的范围相交。
> * 固定列要求整行中不存在溢出单元格。
> * 固定行要求整列中不存在溢出单元格。

下面我们通过一些示例来讨论固定选项是如何清除溢出单元格的偏移量的。
在这些示例中，我们使用 *Orders* 数据表作为数据源。通过使用 *shipCountry* 字段，在模板单元格和数据源之间建立了数据绑定。
**示例 1：清除列偏移量**

1. 在报表中加载以下模板。

    ```javascript
    templateSheet.setTemplateCell(1, 0, {
        type: 'Group',
        binding: 'Orders[shipCountry]',
        spillDirection: 'Horizontal',
    });
    templateSheet.setValue(0, 1, 2023);
    ```

    上述代码的输出结果如下所示。
    ![Clear Column Offset.2a499f](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/Clear%20Column%20Offset.2a499f.b02881.jpg)
2. 为了将单元格 B1（值为 2023）保持在其原始位置，固定 A1 单元格。

    ```javascript
    templateSheet.setTemplateCell(0, 0, {
        pin: 'Column',
    });
    ```

    模板将如下所示。
    ![Clear Column Offset 1.d5acc8](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/Clear%20Column%20Offset%201.d5acc8.18847e.png)
3. 有了固定的单元格后，生成的报表将如下所示。
    ![Clear Column Offset Report](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/Clear%20Column%20Offset%20Report.a71090.jpg)

**示例 2：清除行偏移量**

1. 在报表中加载以下模板。

    ```javascript
    templateSheet.setTemplateCell(0, 1, {
        type: 'Group',
        binding: 'Orders[shipCountry]',
    });
    templateSheet.setValue(1, 0, 2023);
    ```

    上述代码的输出结果如下所示。
    ![Clear row offset.c3bc47](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/Clear%20row%20offset.c3bc47.2d8fda.jpg?width=150)
2. 为了将单元格 A2（值为 2023）保持在其原始位置，固定 A1 单元格。

    ```javascript
    templateSheet.setTemplateCell(0, 0, {
        pin: 'Row',
    });
    ```

    模板将如下所示。
    ![Clear Row Offset 1.baf420](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/Clear%20Row%20Offset%201.baf420.69aa2d.png)
3. 有了固定的单元格后，生成的报表将如下所示。
