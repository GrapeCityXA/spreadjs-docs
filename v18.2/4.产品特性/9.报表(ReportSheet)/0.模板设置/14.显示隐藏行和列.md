# show-hidden-row-and-col

通常情况下，设置为隐藏的行和列在电子表格界面中不可见。但在设计复杂报表模板时，若隐藏的行或列完全不可见，编辑其中的内容会十分困难。
ReportSheet 中的“**显示隐藏行和列**”功能，可让你在 ReportSheet 模板的**设计视图**内，切换标记为隐藏的行和列的可见性。无论这些行和列在最终状态下是否隐藏，该功能都能让你轻松访问模板的所有部分，从而简化模板的创建与修改流程。
![temp.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/temp.36c3df.gif)

## 功能核心特性

* **设计时可见性**：启用后，此前设置为隐藏的行和列将在设计视图中显示。
* **预览行为**：该功能不影响最终报表的预览或输出结果。在预览和报表生成时，隐藏的行和列始终会保持真正的隐藏状态。
* **视觉标识**：显示的隐藏行和列会以独特样式渲染，与常规可见单元格区分开。
* **可编辑性**：这些行和列在显示状态下，其内容和属性可像其他可见单元格一样进行编辑。
* **样式可自定义**：应用于显示状态下隐藏行和列的独特样式（如背景色、边框、字体效果等）可完全自定义。

## 通过代码实现

你可以通过 `reportSheet` 对象的 [options](https://docs.grapecity.com.cn/spreadjs/help/api/interfaces/GC.Spread.Report.IReportOptions) 属性，控制并自定义 ReportSheet 设计模板中隐藏行和列的显示效果。

### 启用与禁用功能

请参考以下示例代码，配置报表模板以隐藏特定行/列：

```javascript
const reportSheet = spread.getActiveSheetTab();
const template = reportSheet.getTemplate();

// 为模板设置值
template.setTemplateCell(2, 0, { 
    binding: "Orders[orderId]",
    type: "Group",
    filter: {
        condition: {
            and: [
                {
                    "parameter": "startDate",
                    "column": "orderDate",
                    "operator": "GreaterThan" // 大于
                },
                {
                    "parameter": "endDate",                
                    "column": "orderDate",
                    "operator": "LessThan" // 小于
                },
                {
                    "parameter": "customerId",             
                    "column": "customerId",
                    "operator": "Equal" // 等于
                }
            ]
        }
    }

});

// 为模板设置绑定关系
const columns = ['customerId', 'orderDate', 'freight', 'shipName', 'shipCity', 'shipCountry'];
columns.forEach((item, index) => {
    template.setTemplateCell(2, index + 1, {
        type: "Group",
        binding: `Orders[${item}]`
    })
});

// 设置报表参数
reportSheet.parameter({
    startDate: new Date("1997-01-01"),
    endDate: new Date("1998-01-01"),
    customerId: "VINET"
});

// 隐藏第4行和第4列（注：行/列索引从0开始）
template.setRowVisible(4, false);
template.setColumnVisible(4, false);
```

![隐藏行和列后的效果](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/showHidden5.990438.af4f39.png)
默认情况下，[showHiddenRowCol](https://docs.grapecity.com.cn/spreadjs/help/api/interfaces/GC.Spread.Report.IReportOptions#showhiddenrowcol) 参数值为 `false`，即明确设置为隐藏的行或列不会在当前视图中显示。
若需查看这些已隐藏的元素，可将该参数切换为 `true`：

```javascript
reportSheet.options.showHiddenRowCol = true;
reportSheet.refresh(); // 刷新工作表
```

> **注意**：
> 设置 `showHiddenRowCol` 属性后，ReportSheet 会自动刷新显示效果。

![启用显示隐藏行和列后的效果](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/showHidden6.2d3cdc.c221fb.png)
此操作会暂时显示隐藏的行和列，方便你按需检查或操作，同时其底层配置中的“隐藏”状态仍会保持不变。
例如，在上述示例中，通过 API 获取第5行（索引为4）的隐藏状态，代码如下：

```javascript
template.getRowVisible(4);
// 返回结果：true（表示该行在底层配置中仍为隐藏状态）
```

### 自定义显示的隐藏元素外观

在标题单元格中，ReportSheet 会使用默认的 [hiddenRowColStyle](https://docs.grapecity.com.cn/spreadjs/help/api/interfaces/GC.Spread.Report.IReportOptions#hiddenrowcolstyle) 进行渲染，你也可以设置自定义样式。

```javascript
// hiddenRowColStyle 的默认值
hiddenRowColStyle = {
  backColor: {
    type: GC.Spread.Sheets.PatternType.lightDown // 浅色下斜纹图案
  }
}
```

以下为调整样式的示例代码：

```javascript
// 创建新样式
var style = new GC.Spread.Sheets.Style();
style.backColor = "#B5B5B5"; // 背景色：灰色
style.foreColor = "#FFFFFF"; // 前景色（文字颜色）：白色
style.fontSize = "24px"; // 字体大小：24像素
// 应用样式
reportSheet.options.hiddenRowColStyle = style;
// 刷新工作表
reportSheet.refresh();
```

## 通过设计器实现

### 启用与禁用功能

在设计模式下，可通过勾选“报表设计”功能区中的“显示隐藏行/列”复选框，显示隐藏的行或列。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.09e400.png)
该功能不影响最终报表的预览或输出结果。在预览/分页预览和报表生成时，隐藏的行和列始终会保持真正的隐藏状态。
![temp.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/temp.361f7b.gif)

### 自定义显示的隐藏元素外观

可通过勾选“报表设计”功能区中的“隐藏行/列样式”复选框，调整隐藏行和列的显示样式。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.967226.png)
点击后，可在弹出的对话框中直接自定义样式设置。
