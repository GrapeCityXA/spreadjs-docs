# collapse-button

在报告表中的显示/折叠按钮允许您展开或折叠特定单元格。请注意，报告表仅允许在预览渲染模式下进行单元格显示/折叠操作。
通过将`IReportTemplateCell`接口的`showCollapseButton`属性设置为true，您可以在报表模板中添加显示/折叠按钮。
这个`showCollapseButton`属性控制是否显示可以折叠报告中单元格子项的按钮。

```javascript
// Configure the Show/Collapse button in the TemplateSheet.
const columns = ['shipCountry', 'shipCity'];
templateSheet.setTemplateCell(0, 0, {
    type: 'Group',
    binding: 'Orders[shipCountry]',
    showCollapseButton: true,
});
templateSheet.setTemplateCell(0, 1, {
    type: 'List',
    binding: 'Orders[shipCity]',
});
reportSheet.refresh();
```

>type=info
> 注意：此外，SpreadJS 在 `ReportSheet` 类中还有另外两个方法，`getCollapseState` 和 `toggleCollapseState`，用来确定单元格当前是折叠还是展开的，以及切换指定单元格的折叠状态。

## 展开和折叠单元格

SpreadJS 提供了动态管理模板中每个分组单元格可见性的能力。利用 `IReportTemplateCell` 接口的 **initialExpansionState** 属性，用户可以灵活地定义在加载报表时分组单元格应显示为展开还是折叠状态。
此功能对于设计结构良好且具有交互性的报表（如树形分组报表、交叉报表或包含层次结构数据的标准报表）特别有用，因为它允许用户定制数据的初始视图。默认情况下，`initialExpansionState` 属性设置为 **Expanded**，这意味着除非另有指定，否则分组单元格在加载时将是可见的。
以下示例代码展示了如何为与指定单元格相关联的分组单元格配置初始展开状态。

```javascript
// 将 initialExpansionState 设置为 Expanded。

templateSheet.setTemplateCell(r + 2, 0, {
    type: 'Group',
    binding: `Sales[${x}]`,
    spillDirection: 'Vertical',
    context: {
        vertical: r > 0 ? `A${r + 2}` : 'Default',
    },
    showCollapseButton: r !== 3,
    initialExpansionState: 'Expanded',
});
```
