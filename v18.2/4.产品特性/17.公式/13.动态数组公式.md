# dynamic-array-formulas

SpreadJS 为在电子表格中使用动态数组公式提供了广泛的支持。

## 使用场景

动态数组公式通过自动溢出并扩展到单元格区域，以多个结果作为输出返回。这使得在电子表格中使用数组公式变得更加轻松快捷。
动态数组公式非常实用，尤其是在以下情况：

* 用户希望在其电子表格中有效地利用数据缓存。
* 用户希望构建对缓存友好的数据结构，以实现低内存占用（紧凑性）的随机访问。一般来说，这是可行的，因为动态数组在存储有关大小和容量的信息时仅会产生少量固定的额外开销。

## UNIQUE 函数

UNIQUE 函数返回单元格区域中所有唯一值的列表。
例如，单元格 C4 包含公式 “=UNIQUE(A4:A15)”，它仅从单元格区域 A4 到 A15 的值中返回唯一的客户名称。根据唯一值的数量，动态数组公式会自动溢出到单元格区域 C5 到 C8，如下所示：
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/dynamic-1-uniq.01635e.png)

## FILTER 函数

FILTER 函数允许用户根据定义的条件对单元格区域进行筛选。筛选操作可以基于单个条件或多个条件来执行。为了组合两个或更多筛选条件，用户可以使用 “\*” 运算符。
例如，单元格 F5 包含公式 “=FILTER(A5:D17, C5:C17=F1)”。此公式根据一个筛选条件（当单元格区域 C5 到 C17 与单元格 F1 中的产品值即 “苹果” 匹配时）对单元格区域 A5 到 D17 进行筛选。结果，单元格区域 A5 到 D17 中包含产品 “苹果” 的所有值都将显示出来。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/dynamic2.9ec92c.png)
在上图中，单元格 F14 包含公式 “=FILTER(A5:D17, (C5:C17=F1)*(A5:A17=F2))”。此公式根据由乘法 (*) 运算符指定的两个筛选条件对单元格区域 A5 到 D17 进行筛选。第一个条件是单元格区域 C5 到 C17 应与单元格 F1 中的产品值即 “苹果” 匹配，第二个条件是单元格区域 A5 到 A17 应与 “东部” 区域匹配。结果，单元格区域 A5 到 D17 中产品为 “苹果” 且区域为 “东部” 的所有值都将显示出来。

## RANDARRAY 函数

RANDARRAY 函数返回一个随机数值数组。用户可以指定行数和列数、最小值和最大值，并指明返回整数还是小数。
例如，下图中的单元格 A8 包含公式 “=RANDARRAY(5,3)”，它返回一组介于 0 和 1 之间的随机值。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/dynamic5.ac7f11.png)

## SORT 函数

SORT 函数对单元格区域或数组中的数据进行排序。此函数的结果会溢出到结果区域，其动态数组中的值按升序（从小到大）或降序（从大到小）排列。如果未指定排序顺序，则默认情况下，值按字母顺序升序排序。
例如，单元格 D4 包含公式 “=SORT(A4:A15)”，它返回按升序排序的客户名称。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/dynamic-1-sort.843e13.png)
如果您想对区域 A4 到 A15 中的所有唯一值进行排序，您可以对 C4 列中显示的唯一值列表应用排序函数，或者也可以将 SORT 和 UNIQUE 这两个函数合并为一个公式。
例如，单元格 E4 包含公式 “=SORT(C4#)”，其中 # 表示一个列表。此公式将对 C 列中的值列表进行排序（单元格 C4 中已包含 UNIQUE 公式 “=UNIQUE(A4:A15)”），并在 E 列中显示结果。
或者，您也可以合并 SORT 和 UNIQUE 这两个函数。例如，下图中的单元格 F4 包含公式 “=SORT(UNIQUE(A4:A15))”，它返回区域 A4:A15 中按字母顺序排序的所有唯一值。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/dynamic-sortunique.d05b1d.png)

## SORT BY 函数

SORTBY 函数根据相应区域或数组中存在的值，对单元格区域或数组的内容进行排序。
例如，单元格 G4 包含公式 “=SORTBY(A4:B15,B4:B15)”。此函数根据另一个单元格区域 B4 到 B15 对单元格区域 A4 到 B15 进行排序，并返回按升序排列的客户名称及其年龄。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/dynamic-1-sortby.781e72.png)

## SEQUENCE 函数

SEQUENCE 函数以升序返回数组中的一系列连续数字。
例如，单元格 A2 包含公式 “=SEQUENCE(4,5)”，它返回一个数组，其值溢出到一个包含四行五列的单元格区域，显示的数字序列为 1、2、3、4 直至 20。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/dynamic4.ccee26.png)

## SINGLE 函数

SINGLE 函数使用隐式交集逻辑返回单个值、单个单元格区域或一个错误。
例如，单元格 A15 包含公式 “=SINGLE(A15:E15)”，它通过计算单元格区域 A15 到 E15 中行和列的交集，在单元格 C16 中返回结果 “C”。

## 溢出数组公式

在电子表格中使用常规公式是一项繁琐的任务，因为用户需要手动将公式复制到每个想要计算结果的单元格中。当一个单元格包含动态数组公式时，数组的元素会溢出到相邻的空白单元格中，并返回多个值。与常规数组不同，当从源区域插入或删除数据时，动态数组会自动调整大小。
**溢出**：当所有公式返回多个值（在一个数组中）时，相邻的单元格将填充结果（计算出的数据）。这种行为称为溢出。任何有可能返回多个结果的公式都可以称为动态数组公式。
**溢出数组公式**：在电子表格的单元格区域中返回多个结果，并且成功实现溢出的公式，称为溢出数组公式。
**溢出区域运算符**：溢出区域运算符（#）可用于引用整个溢出区域。当一个公式返回多个结果时，会返回溢出错误。

## 启用动态数组函数

为了在电子表格中使用动态数组函数，用户首先需要通过以下代码片段启用动态数组。

```javascript
// 启用动态数组
spread.options.allowDynamicArray = true;
```
