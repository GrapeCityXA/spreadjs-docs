# show_cell_formulas

用户可以查看电子表格中单元格里的所有公式，并且能轻松地在单元格之间复制和粘贴这些公式。SpreadJS 提供了 `showFormulas` 属性，这使用户能够看到单元格中的公式。一旦公式可见，就可以将其复制并粘贴到任何应用程序中。
以下代码示例设置了 `options.showFormulas` 属性。

```javascript
// 将 showFormulas 设置为 true，以便用户将公式复制到其他应用程序中
activeSheet.options.showFormulas = true;
```

**局限性**

* 当选中包含公式的单元格时，该公式所引用的单元格不会被高亮显示。
* 由于输入数组公式需要按 Ctrl+Shift+Enter 组合键，因此数组公式无法正确地复制到 Excel 或 SpreadJS 中。
