# chart-data-points

数据点是图表中的一个数据项，它显示了链接数据范围中某一单元格内容的值。你可以为一些具有特殊意义的数据点设置特殊样式，以使数据呈现更加突出，让图表更加直观高效。

## 自定义数据点样式

SpreadJS 提供了根据不同图表类型自定义图表系列数据点样式的选项。你可以使用 [GC.Spread.Sheets.Charts.IDataPoint](https://demo.grapecity.com.cn/spreadjs/help/api//interfaces/GC.Spread.Sheets.Charts.IDataPoint) 接口来定义所有属性。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/chart-datapoint-custom.0f967a.png)
不同系列中数据点的索引从 0 开始计数，并且按从上到下、从左到右的顺序排列。
不同类型图表可用的属性如下表所示：

| 图表类型 | 属性 |
| ---- | --- |
| 柱状图<br>饼图 / 圆环图<br>条形图<br>树状图<br>旭日图<br>漏斗图<br>组合图 | `backColor`（背景颜色）<br>`backColorTransparency`（背景颜色透明度）<br>`border.color`（边框颜色）<br>`border.transparency`（边框透明度）<br>`border.width`（边框宽度）<br>`border.lineType`（边框线条类型） |

> **注意**：面积图和填充雷达图不支持数据点，因此数据点 API 对它们不起作用。
> 旭日图和树状图的 backColor 和 backColorTransparency 属性也可以在旧的数据点样式结构中设置。

以下代码示例展示了如何为饼图中的每个数据点应用不同的背景颜色。

```javascript
// 配置工作簿和工作表
var spread = new GC.Spread.Sheets.Workbook("ss",{ sheetCount: 4 });
var activeSheet = spread.getActiveSheet();

// 设置图表数据
var pieData = [
    ["", 'Chrome', 'Firefox', 'IE', 'Safari', 'Edge', 'Opera', 'Other'],
    ["2017", 0.6360, 0.1304, 0.0834, 0.0589, 0.0443, 0.0223, 0.0246]
];
spread.sheets[1].setArray(0, 0, pieData);
var dataRange = new GC.Spread.Sheets.Range(0, 0, 2, 8);
            
// 创建饼图
var pieChart = spread.sheets[1].charts.add('Pie Chart', GC.Spread.Sheets.Charts.ChartType.pie, 2, 50, 600, 350, "A1:H2");
pieChart.title({
    text: "浏览器市场份额"
});
var pieStyle = pieChart.series().get(0);
            
// 自定义数据点样式
pieStyle.dataPoints = {
    0: {
        backColor: {
            type: GC.Spread.Sheets.Charts.PatternType.wideUpwardDiagonal,
            foregroundColor: "white",
            backgroundColor: "LightBlue",
        },
        backColorTransparency: 0.1,
    },
    1: {
        backColor: "Yellow",
    },
    2: {
        backColor: {
            type: GC.Spread.Sheets.Charts.PatternType.trellis,
            foregroundColor: "white",
            backgroundColor: "Green",
        }
    },
    3: {
        backColor: "Orange",
    },
    4: {
        backColor: "Red",
        backColorTransparency: 0.5,
    },
    5: {
        backColor: {
            type: GC.Spread.Sheets.Charts.PatternType.narrowVertical,
            foregroundColor: "white",
            backgroundColor: "Purple",
        }
    },
};

pieChart.series().set(0, pieStyle);
```

当你在图表系列中选择一个数据点时，整个系列会被选中。再次选择该数据点，即可专门自定义该图表系列中的那个数据点。
在同一图表的另一个系列中选择一个数据点会重新选择整个系列。
