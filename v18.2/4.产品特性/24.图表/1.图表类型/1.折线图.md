# CreatingLineChart

折线图被广泛用于在均匀刻度的轴上可视化随时间变化的连续数据。这些图表非常适合分析在相等时间间隔（如月份、季度或财政年度）内的数据趋势。
工作表中按列或行排列的数据可以绘制在折线图中。在折线图中，类别数据沿水平轴均匀分布，所有数值数据沿垂直轴分布。
SpreadJS 支持以下类型的折线图，其中展示了不同类别小工具（手机、笔记本电脑和平板电脑）在第一季度、第二季度和第三季度的年度销售记录趋势，分别使用了不同类型的折线图。

## 带数据标记的 100% 堆积折线图

此图表显示带有数据标记的各个数据值，通常展示每个值随时间或等距类别变化的贡献百分比趋势。当存在许多类别或数值为近似值时，使用此图表非常合适。
带数据标记的 100% 堆积折线图的图像如下所示：
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/100_Stacked_Line_with_Markers.b24f9d.png)
以下代码示例展示了如何向电子表格中添加不同类型的折线图。

```javascript
var chart_line, chart_lineStacked, chart_lineStacked100, sheet;
window.onload = function () {
    var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
    sheet = spread.getActiveSheet();
    sheet.suspendPaint();
    // 为图表准备数据
    sheet.setValue(0, 1, "Q1");
    sheet.setValue(0, 2, "Q2");
    sheet.setValue(0, 3, "Q3");
    sheet.setValue(1, 0, "手机");
    sheet.setValue(2, 0, "笔记本电脑");
    sheet.setValue(3, 0, "平板电脑");
    for (var r = 1; r <= 3; r++) {
        for (var c = 1; c <= 3; c++) {
            sheet.setValue(r, c, parseInt(Math.random() * 100));
        }
    }
    // 添加折线图
    chart_line = sheet.charts.add('chart_line', GC.Spread.Sheets.Charts.ChartType.line, 250, 20, 600, 400, "A1:D4");
    // 添加堆积折线图
    chart_lineStacked = sheet.charts.add('chart_lineStacked', GC.Spread.Sheets.Charts.ChartType.lineStacked, 250, 480, 600, 400, "A1:D4");
    // 添加 100% 堆积折线图
    chart_lineStacked100 = sheet.charts.add('chart_lineStacked100', GC.Spread.Sheets.Charts.ChartType.lineStacked100, 250, 900, 600, 400, "A1:D4");
    sheet.resumePaint();
};
```

## 平滑折线图

你还可以突出显示曲线趋势，并使用 `smooth` 属性使图表中的线条更平滑且在视觉上更具吸引力，而无需将连续数据拟合到特定角度。不过，`smooth` 属性仅支持以下折线图类型：

* 堆积折线图
* 100% 堆积折线图
* 带数据标记的折线图
* 带数据标记的堆积折线图
* 带数据标记的 100% 堆积折线图
    请参考以下图像，该图像设置了 `smooth` 属性以曲线形式描绘产品的季度销售情况。
    ![smoothlinechart](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/smoothlinechart.2b8aed.4f7fc0.png)
    以下代码示例实现了 `smooth` 属性。

```javascript
// 平滑系列
var series0 = chart_line.series().get(0);
series0.smooth = true;
chart_line.series().set(0, series0);
```
