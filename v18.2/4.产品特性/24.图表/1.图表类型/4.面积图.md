# CreatingAreaChart

面积图被广泛用于展示随着时间推移，每个数据值对总和的贡献情况。通常，当你需要展示随时间变化的绘图情况，并通过显示绘图值的总和来描绘某个趋势的总值时，这种图表是非常理想的选择。
工作表中按列或行排列的数据可以绘制在面积图中。
SpreadJS 支持以下类型的面积图。在下面展示的示例中，不同类别小工具（手机、笔记本电脑和平板电脑）在第一季度、第二季度和第三季度的年度销售记录，通过不同类型的面积图呈现出来。

## 面积图

簇状面积图将数据系列描绘为带有颜色的区域，这有助于比较同一数据点的多个系列的值。此图表展示了随时间变化的趋势。

## 堆积面积图

堆积面积图将数据系列描绘为颜色各异的堆积区域，这有助于对同一数据点的多个系列进行比较。此图表展示了每个值随时间或其他分类数据变化的贡献趋势。
下面是一张堆积面积图的图片：
![Stacked_Area](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/Stacked_Area.abb33e.png)

## 100% 堆积面积图

100% 堆积面积图描绘了随时间显示的带有正值和负值的数据点系列，以展示同一数据点的多个系列的值。此图表展示了每个值随时间或其他分类数据的贡献百分比。
下面是一张 100% 堆积面积图的图片：
![Stacked_Area](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/Stacked_Area.dd54a3.png)
以下代码示例展示了如何向电子表格中添加不同类型的面积图。

```javascript
var chart_area, chart_areaStacked, chart_areaStacked100, sheet;
window.onload = function () {
    var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'));
    sheet = spread.getActiveSheet();
    sheet.suspendPaint();
    // 为图表准备数据
    sheet.setValue(0, 1, '第一季度');
    sheet.setValue(0, 2, '第二季度');
    sheet.setValue(0, 3, '第三季度');
    sheet.setValue(1, 0, '手机');
    sheet.setValue(2, 0, '笔记本电脑');
    sheet.setValue(3, 0, '平板电脑');
    for (var r = 1; r <= 3; r++) {
        for (var c = 1; c <= 3; c++) {
            sheet.setValue(r, c, parseInt(Math.random() * 100));
        }
    }
    // 添加面积图
    chart_area = sheet.charts.add('chart_areaClustered', GC.Spread.Sheets.Charts.ChartType.area, 250, 20, 600, 400, 'A1:D4');
    // 添加堆积面积图
    chart_areaStacked = sheet.charts.add('chart_areaStacked', GC.Spread.Sheets.Charts.ChartType.areaStacked, 250, 480, 600, 400, 'A1:D4');
    // 添加 100% 堆积面积图
    chart_areaStacked100 = sheet.charts.add('chart_areaStacked100', GC.Spread.Sheets.Charts.ChartType.areaStacked100, 250, 900, 600, 400, 'A1:D4');
    sheet.resumePaint();
};
```
