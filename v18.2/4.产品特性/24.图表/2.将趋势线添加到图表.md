# add-trendlines-to-charts

SpreadJS允许用户在可视化表单中的数据的同时向图表添加趋势线。

## 什么是趋势线？

趋势线，也称为最佳拟合线，是图表中的另一条线，它指示特定数据系列中的斜率（趋势），以帮助用户快速分析整体趋势（即使当您的价格波动时 数据点）。

## 使用场景

向图表添加趋势线可以证明是对您的组织非常有用的分析工具，您可以使用它来显示一段时间内的数据移动或简单地描述两个变量之间的相关性。
趋势线在以下情况下非常有用：

* 得出趋势并预测未来价值。
* 分析库存，交易，财务和销售数据。
* 协助趋势分析以创建数据分析策略。

**示例** : 以下截图通过使用图表中的不同趋势线，描绘了三种不同产品（手机，笔记本电脑和平板电脑）的年度销售记录。

## 趋势线的类型

下表描述了在SpreadJS中使用图表时支持的各种趋势线。

| **趋势线类型** | **描述** | **示例** |
| ----- | --- | --- |
| 线性趋势线 | 线性趋势线是一条最佳拟合直线，它展示数据系列中的值如何以稳定的速率增加或减少，并为图表中的数据提供未来的近似值。<br>如果数据模式类似一条直线，那么该数据就是线性的。<br> **公式** -：y = mx + b<br> 其中 m 是斜率，b 是截距。 | ![linear-trendline](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/linear-trendline.59476e.png) |
| 指数趋势线 | 指数趋势线是一条最佳拟合曲线，当数据值以越来越高的速率上升（增加）或下降（减少），然后趋于平稳时，它最为有用。<br> **公式** -：y = ce<sup style="margin: 0px; padding: 0px; -webkit-font-smoothing: antialiased; box-sizing: border-box; position: relative; font-size: 0.75em; line-height: 0; vertical-align: baseline; top: -0.5em;">bx</sup><br> 其中 c 和 b 是常数，e 是自然对数的底数。 | ![exponential-trendline](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/exponential-trendline.721c06.png) |
| 对数趋势线 | 对数趋势线是一条最佳拟合曲线，它说明数据值如何快速增加或减少，然后趋于平稳。这种类型的趋势线可用于正值和负值数据。<br> **公式** -：y = c ln x + b<br> 其中 c 和 b 是常数，ln 是自然对数函数。<br> **注意**：此趋势线只能用于正数。如果数据包含零值或负值，用户无法创建指数趋势线。 | ![logairthmic-scale](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/logairthmic-scale.f531fb.png) |
| 多项式趋势线 | 多项式趋势线是一条曲线，用于说明数据值的波动情况。<br>这种类型的趋势线基于阶数属性，有助于用户分析大型数据集（例如股票、交易和金融应用）中的收益或损失。<br> **公式** -：y = b + c<sub style="margin: 0px; padding: 0px; -webkit-font-smoothing: antialiased; box-sizing: border-box; position: relative; font-size: 0.75em; line-height: 0; vertical-align: baseline; bottom: -0.25em;">1</sub>x + c2x + c3x + ...<br> 其中 c1、c2、c3 是常数。对于此趋势线，默认值为 2。<br> 阶数应为 2 到 6 范围内的正整数。如果阶数的值超出该范围，则结果如下所述：<br> 1.）小于 2：将按 2 处理。<br> 2.）大于 6：将按 6 处理。<br> 3.）小数：用户需要使用 `Math.floor` 将小数值转换为整数。<br> 4.）其他类型的值：趋势线将不会显示。 | ![polynomial-trendline](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/polynomial-trendline.c9b647.png) |
| 幂趋势线 | 幂趋势线是一条曲线，可用于比较以特定速率增加的度量值。<br> 注意 - 此趋势线只能用于正数。如果数据包含零值或负值，用户无法创建幂趋势线。<br> **公式** -：y = cx<sup style="margin: 0px; padding: 0px; -webkit-font-smoothing: antialiased; box-sizing: border-box; position: relative; font-size: 0.75em; line-height: 0; vertical-align: baseline; top: -0.5em;">b</sup><br> 其中 c 和 b 是常数。 | ![power-trendline](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/power-trendline.8a76e9.png) |
| 移动平均趋势线 | 移动平均趋势线是一种趋势线，它减少趋势线中的波动，以显示更平滑的模式。<br>这种类型的趋势线基于周期属性，通常通过考虑指定周期数的平均值来显示趋势。<br> 公式 -：P<sub style="margin: 0px; padding: 0px; -webkit-font-smoothing: antialiased; box-sizing: border-box; position: relative; font-size: 0.75em; line-height: 0; vertical-align: baseline; bottom: -0.25em;">m</sub> = P<sub style="margin: 0px; padding: 0px; -webkit-font-smoothing: antialiased; box-sizing: border-box; position: relative; font-size: 0.75em; line-height: 0; vertical-align: baseline; bottom: -0.25em;">m-1</sub> + (y<sub style="margin: 0px; padding: 0px; -webkit-font-smoothing: antialiased; box-sizing: border-box; position: relative; font-size: 0.75em; line-height: 0; vertical-align: baseline; bottom: -0.25em;">m</sub> \- y<sub style="margin: 0px; padding: 0px; -webkit-font-smoothing: antialiased; box-sizing: border-box; position: relative; font-size: 0.75em; line-height: 0; vertical-align: baseline; bottom: -0.25em;">m</sub> \- n\) / n<br> 此趋势线的默认值为 2。趋势线中第二个点使用第二个和第三个数据点的平均值，依此类推。最大周期是数据集的长度。<br> 例如 - 如果绘图中有 10 个数据集，那么最大周期是 9，所以如果数据集的长度小于 3，移动平均系列的趋势线将不会显示。<br> 周期应为 2 到最大周期范围内的正整数。如果不是，则结果如下所述：<br> 1.）小于 2：将按 2 处理。<br> 2.）大于最大周期：将按最大周期处理。<br> 3.）小数：用户需要使用 `Math.floor` 将小数值转换为整数。<br> 4.）其他类型的值：趋势线将不会显示。 | ![moving-average-trendline](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/moving-average-trendline.783ef6.png) |

除了以上六种趋势线类型外，SpreadJS还支持趋势线的自定义名称。 如果用户未设置趋势线名称，则会提供内置名称。 模板应该是这样的：

* 对于移动平均趋势线: '{period number}period MovingAverage({series name})'. 示例: '3period MovingAverage(Bears)'.
* 对于其他类型的趋势线: '{trendline type}({series name})'. 示例: 'Logarithmic(Bears)'.

## 支持的图表类型

在图表中添加趋势线时，支持以下图表类型：:

* 柱形图
* 条形图
* 折线图
* 散点图
* 面积图

> **注意:** 向图表添加趋势线时，必须牢记以下限制：
>
> * 无法向堆积图表类型（如堆积柱形图）添加趋势线。如果用户尝试向不支持趋势线的图表类型添加趋势线，或者将现有图表类型更改为不支持趋势线的图表类型，那么趋势线将不会显示。

下面的示例代码使用图表中的不同趋势线描绘了年度销售记录。

```JavaScript
var activeSheet = spread.getActiveSheet();
activeSheet.suspendPaint();
// Prepare data for chart
activeSheet.setValue(0, 1, 'Y-2016');
activeSheet.setValue(0, 2, 'Y-2017');
activeSheet.setValue(0, 3, 'Y-2018');
activeSheet.setValue(1, 0, 'Mobile Phones');
activeSheet.setValue(2, 0, 'Laptops');
activeSheet.setValue(3, 0, 'Tablets');
for (var r = 1; r <= 3; r++) {
    for (var c = 1; c <= 3; c++) {
        activeSheet.setValue(r, c, parseInt(Math.random() * 5000));
    }
}
// Add columnClustered chart
chart_columnClustered = activeSheet.charts.add('chart_columnClustered', GC.Spread.Sheets.Charts.ChartType.columnClustered, 50, 100, 600, 400, 'A1:D4');

// Adding TrendLines on series[0] i.e. Mobile Phones
var series1 = chart_columnClustered.series().get(0);
series1.trendlines = [
    {
        type: 2,
        forward: 2,
        name: 'MovingAverage',
        style: { color: 'blue' },
        period: 3, // only used for Moving Average Trendline
    },
];
// Adding TrendLines on series[1] i.e. Laptops
var series2 = chart_columnClustered.series().get(1);
series2.trendlines = [
    {
        type: 2,
        forward: 2,
        name: 'MovingAverage',
        style: {
            color: 'red',
        },
        period: 3,
    },
];
// Adding TrendLines on series[2] i.e. Tablets
var series3 = chart_columnClustered.series().get(2);
series3.trendlines = [
    {
        type: 2,
        forward: 2,
        name: 'MovingAverage',
        style: { color: 'green' },
        period: 3,
    },
];
chart_columnClustered.series().set(0, series1);
chart_columnClustered.series().set(1, series2);
chart_columnClustered.series().set(2, series3);
// Configure Chart Title
var title = chart_columnClustered.title();
title.text = 'Annual Sales Record';
title.fontFamily = 'Cambria';
title.fontSize = 28;
title.color = 'Red';
chart_columnClustered.title(title);
activeSheet.resumePaint();
```
