# scroll-by-pixel

SpreadJS 为类 Excel 的精确滚动提供了广泛支持，以确保你在对工作表进行额外控制的同时，能够享受到流畅且完美的滚动体验。
用户可以手动或自动按像素滚动电子表格。在手动滚动中，可以设置像素，并且可以使用滚动条末端的箭头按指定的像素在水平或垂直方向上滚动电子表格。而在自动滚动中，可以设置垂直和水平像素，从而使电子表格自动滚动到指定像素位置。

### 按像素滚动的优点

按像素滚动功能通过允许用户在工作表的单元格间平稳移动，提供了增强的用户体验。
让我们来看一些按像素滚动很有用的场景：

* 当电子表格中的单元格非常高（包含多行文本）或非常宽（列宽增加）时。
* 当用户想要通过拖动行或列的边缘来调整它们的大小时。
* 当用户试图在单元格内定位形状或图片时。
* 当用户需要在单个单元格中填入大量数据时。例如电子表格中的输入表单、调查问卷、记录等。
* 当用户在小屏幕（如平板电脑或手机）上滚动工作表时。
* 当用户想要移动到电子表格中特定的视口或包含所需数据的单元格时。

### 支持的用户交互操作

用户可以在两个方向上按像素滚动——水平方向（按像素滚动列）或垂直方向（按像素滚动行）。
SpreadJS 在工作表中使用按像素滚动功能时，为以下鼠标滚轮和键盘操作提供支持：

* 在视口区域（行视口索引为 1 或列视口索引为 1）使用鼠标滚轮或触控板。
* 使用鼠标滚轮或触控板点击滚动条的左/右/上/下按钮。
* 使用滚动条上的滚动箭头按钮、鼠标滚轮或触控板。
* 在视口区域进行触摸滚动。
* 触摸或点击滚动条的左/右/上/下按钮或追踪按钮。

### 启用按像素滚动（手动）

默认情况下，Excel 和 SpreadJS 都仅按行或列滚动。你可以通过将 **scrollByPixel** 属性设置为 "true" 来在工作表中启用按像素滚动，如下所示的代码片段。一旦设置，就可以使用滚动条末端的箭头手动按指定像素滚动电子表格。

### 使用场景

假设你正在处理一个电子表格，该表格展示了不同国家以及某个国家内各州的产品分析。在滚动行和列时，你可能想要查看某个国家的最后一项（州）或最后一列（产品详情）。在这种情况下，使用默认滚动无济于事，因为它会一次性完全跳过一整行或一列，而在尝试拖动边缘时，整个过程最终会变得繁琐。
以下图片展示了工作表中的按像素滚动：
![pixelaccurate-scrolling](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pixelaccurate-scrolling.062bc4.gif)

```javascript
// 启用按像素的精确滚动
spread.options.scrollByPixel = true;
spread.options.scrollPixel = 5;
```

> type=warning
> **注意**： 在电子表格中使用按像素滚动功能时，必须牢记以下限制：
>
> * 在基于触摸的设备上按像素滚动时，触摸手势将不支持边界反馈效果和滚动整行或整列。
> * 在将电子表格导出为 PDF 文件或打印时，用户将无法使用按像素滚动功能。然而，按像素滚动与其他所有功能配合使用时不会有任何问题。

### 启用按像素滚动（自动）

你可以通过使用 [scroll ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#scroll)方法在工作表中启用按像素的自动滚动，该方法允许你设置垂直（vpixels）和水平（hpixels）像素，以在相应方向上滚动。这样做时，工作表将自动滚动到指定的像素位置。

* 如果像素值为正，工作表将向下滚动 vpixels 并向右滚动 hpixels。
* 如果像素值为负，工作表将向上滚动 vpixels 并向左滚动 hpixels。
* 如果像素值为 0，工作表将不会向任何方向滚动。

除了 **scroll** 方法外，你还可以使用 **scrollByPixel** 属性，它以下列方式影响滚动行为：

* 当 **scrollByPixel** 为 true 时，工作表将滚动到新的顶行或左列索引以及新的顶行或左列偏移量（由 scroll 方法定义）。
* 当 **scrollByPixel** 为 false 时，工作表将滚动到新的顶行或左列索引（由 scroll 方法定义），但新的顶行或左列偏移量将始终为 0。

### 使用场景

假设你正在处理一个电子表格，该表格展示了不同国家以及某个国家内各州的产品分析。在滚动行和列时，你可能想要查看工作表的一个特定视口，该视口显示与一个国家相关的所有数据。在这种情况下，你可以使用自动滚动来查看所需数据。

### 使用代码

以下示例代码允许用户为水平和垂直方向设置自定义像素大小，并滚动到工作表中的指定位置。

```javascript
// 获取活动工作表
var activeSheet = spread.getActiveSheet();
spread.options.scrollByPixel = true;
// 此示例将工作表向下滚动 30 像素
// 并将工作表向右滚动 15 像素。
activeSheet.scroll(30, 15);
```
