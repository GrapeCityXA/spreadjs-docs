# scrollbars

你可以分别使用 **showVerticalScrollbar** 或 **showHorizontalScrollbar** 属性来隐藏或显示垂直或水平滚动条。
你可以使用 **options.scrollbarMaxAlign** 属性来指定是否将滚动条与活动工作表的最后一行和列对齐。你可以使用 **options.scrollbarShowMax** 属性来指定显示的滚动条是否基于工作表中的总列数和行数。
你可以使用 **options.scrollIgnoreHidden** 属性来指定是否忽略隐藏的行或列。这适用于宽度或高度为零的列或行、使用 **visible** 方法隐藏的列或行、折叠和分组的列或行，或者被筛选掉的行。


## 使用代码

以下示例隐藏了垂直和水平滚动条。

```js
spread.options.showHorizontalScrollbar = false;
spread.options.showVerticalScrollbar = false;
```
