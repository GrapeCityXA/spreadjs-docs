# tabstrip

# SpreadJS 标签栏（Tab Strip）功能配置指南

SpreadJS 提供了丰富的选项来控制标签栏及其元素的行为。通过 `Workbook.options` 字段的属性，你可以执行多种操作，例如修改工作表名称、设置工作表颜色、调整工作表顺序、配置标签栏的位置和宽度等。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/tabstriplabel.6919ee.png)

## 一、修改工作表名称（Change Sheet Name）

双击工作表标签即可进入编辑状态修改名称，点击标签外区域、按 **Esc 键**或 **Enter 键**可确认修改。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/edit-sheet-names.1c8389.gif)
通过 `options.tabEditable` 属性可启用或禁用工作表名称编辑功能，该属性默认值为 `true`（启用）。

```javascript
spread.options.tabEditable = false; // false：禁用编辑，true：启用编辑
```

## 二、调整工作表标签顺序（Arrange Sheet Tabs）

选中工作表标签并拖动至任意两个工作表之间，即可调整其顺序。拖动时会显示一个指示符（如下方图片所示），松开鼠标即可完成工作表移动。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/tab-reorder.849bed.png)
将 `options.allowSheetReorder` 属性设为 `true`，可启用工作表标签重排序功能。

```javascript
spread.options.allowSheetReorder = true; // true：启用重排序，false：禁用重排序
```

* [SheetMoving](https://docs.grapecity.com.cn/spreadjs/help/api/classes/GC.Spread.Sheets.Events#SheetMoving_EV) 事件：在工作表拖动移动前触发。
* [SheetMoved](https://docs.grapecity.com.cn/spreadjs/help/api/classes/GC.Spread.Sheets.Events#SheetMoved_EV) 事件：在工作表拖动移动后触发。

若需取消工作表移动，可将 [SheetMoving](https://docs.grapecity.com.cn/spreadjs/help/api/classes/GC.Spread.Sheets.Events#SheetMoving_EV) 类的 `cancel` 参数设为 `true`。

## 三、设置工作表标签样式（Set Sheet Tab Style）

可根据工作表标签的不同状态，设置其样式（如文本样式、背景色、图标等）。通过 `Workbook` 类的 `sheetTabStyles` 或 `defaultSheetTabStyles` 属性即可配置标签样式：

* `sheetTabStyles`：为单个工作表标签设置特定状态的样式；
* `defaultSheetTabStyles`：为所有工作表标签设置默认状态的样式。

下方图片展示了为工作表标签不同状态设置背景色、前景色和图标的效果：
![sheet-tabstyle](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/sheet-tabstyle.0976cc.44eb7e.png)
以下代码示例实现了工作表标签不同状态的样式配置：

```javascript
// 为“Sheet1”的“正常（normal）”状态设置新样式
spread.sheetTabStyles.add(
    GC.Spread.Sheets.SheetTabState.normal, 
    {
        icons: [{ src: '../images/img.png', width: 20, height: 20 }], // 图标（路径、宽高）
        foreColor: 'red', // 前景色（文本颜色）
        font: 'bolder', // 字体样式（加粗）
        backColor: 'green' // 背景色
    }, 
    ['Sheet1'] // 应用样式的工作表名称
);

// 为所有工作表标签的“受保护（protected）”状态设置默认样式
spread.options.defaultSheetTabStyles = {
    [GC.Spread.Sheets.SheetTabState.protected]: {
        icons: [{ src: '../images/lock.jpg', width: 20, height: 20 }], // 锁形图标
        foreColor: 'blue', // 文本颜色为蓝色
        backColor: 'orange' // 背景色为橙色
    }
};
```

### 通过 SpreadJS 设计器配置标签样式

SpreadJS 设计器也支持通过 **SETTINGS（设置）** 选项卡自定义工作表标签样式：

#### 1\. 管理单个工作表标签样式

1. 在 **Sheet Settings（工作表设置）** 组中，点击 **General（常规）** 按钮；
2. 选择 **SheetTab（工作表标签）** 选项卡，为特定标签状态定义颜色和样式；
    ![Manage Tab State styles](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/Manage20Tab20State20styles.c7fbf1.5016ff.png)
3. 点击 **Manage Style（管理样式）** 按钮，配置标签状态样式；
4. 在 **Tab State Style List（标签状态样式列表）** 中选择需修改的状态，点击该状态的 **Edit（编辑）** 图标；
    ![Tab state style setting](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/Tab20state20style20setting.bac95e.e15fa9.png)
5. 在 **Tab Style Setting（标签样式设置）** 对话框中，为选中状态应用所需的字体样式、背景色和图标；
    ![Tab style setting](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/Tab20style20setting.000d92.23e7e8.png)
6. 点击 **OK（确定）**，修改将应用到该工作表标签。

#### 2\. 管理默认工作表标签样式

1. 在 **Spread Settings（Spread 设置）** 组中，点击 **TabStrip（标签栏）** 按钮，打开 **Spread Settings（Spread 设置）** 对话框；
    ![Default Tab State styles](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/Default20Tab20State20styles.1eac45.0ecd39.png)
2. 选择 **Manage Style（管理样式）** 选项，设置工作表标签状态样式；
3. 在 **Tab State Style List（标签状态样式列表）** 中选择状态，点击 **Edit（编辑）** 图标进行修改；
4. 点击 **OK（确定）**，修改将应用到所有工作表标签。

## 四、支持工作表标签圆角样式（Support Border Radius for Sheet Tabs）

通过内置支持的 CSS 类的 `border-radius` 样式，可自定义工作表标签（**SheetTab**）的边框外观：

* 不同的 [工作表标签位置](https://docs.grapecity.com.cn/spreadjs/help/api/enums/GC.Spread.Sheets.TabStripPosition) 对应描述其外观的专属 CSS 类。

```css
/* 标签栏在底部时的标签圆角 */
.sjs-tab-strip-bottom-tab{
  border-radius: value;
}

/* 标签栏在左侧时的标签圆角 */
.sjs-tab-strip-left-tab{
  border-radius: value;
}

/* 标签栏在右侧时的标签圆角 */
.sjs-tab-strip-right-tab{
  border-radius: value;
}

/* 标签栏在顶部时的标签圆角 */
.sjs-tab-strip-top-tab{
  border-radius: value;
}
```

### 圆角样式规则

1. `sjs-tab-strip-[position]-tab` 类下的 `border-radius` 属性仅支持像素（px）单位，值需大于或等于 0；若所有圆角值设为 0，将禁用工作表标签的圆角样式。
2. 支持为每个角单独定义圆角样式：左上角、右上角、左下角、右下角。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.43a2a6.bcdada.png)

### 圆角值配置示例

1. **1 个值**：所有角使用同一圆角值。

```css
.sjs-tab-strip-bottom-tab{
  border-radius: 4px;
}
```

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.85c0d6.cf611b.png)
2. **2 个值**：第 1 个值对应左上角和右下角，第 2 个值对应右上角和左下角。

```css
.sjs-tab-strip-bottom-tab{
  border-radius: 0px 5px;
}
```

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.aff543.49e93a.png)
3. **3 个值**：第 1 个值对应左上角，第 2 个值对应右上角和左下角，第 3 个值对应右下角。

```css
.sjs-tab-strip-bottom-tab{
  border-radius: 0px 0px 4px;
}
```

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.c47451.60ea3a.png)
4. **4 个值**：依次对应左上角、右上角、右下角、左下角。

```css
.sjs-tab-strip-bottom-tab {
    border-radius: 4px 4px 0px 0px;
}
```

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.5322a1.6406b0.png)

> **注意：**
>
> 1. 工作表标签圆角样式不支持 Excel 2007 主题。
> 2. 需注意标签宽高限制，避免将圆角值设置过大。

## 五、显示“新建标签”按钮（Display New Tab Button）

通过 `options.newTabVisible` 属性可选择显示或隐藏“新建标签”按钮，该按钮默认可见。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/newtabvisible.a79901.png)

```javascript
spread.options.newTabVisible = true; // false：隐藏按钮，true：显示按钮
```

## 六、显示导航按钮（Display Navigation Buttons）

通过 `options.tabNavigationVisible` 属性可指定是否在工作簿中显示导航按钮。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/tabnavigation.f7a3e1.png)

```javascript
spread.options.tabNavigationVisible = false; // false：隐藏按钮，true：显示按钮
```

## 七、显示标签栏（Display Tab Strip）

通过 `options.tabStripVisible` 属性可隐藏整个标签栏。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/tabstripvisible.8239bc.png)

```javascript
spread.options.tabStripVisible = true; // true：显示标签栏，false：隐藏标签栏
spread.options.tabStripRatio = 0.5;  // 指定标签栏占用的水平空间比例（百分比值）
```

## 八、设置标签栏位置和宽度（Set Position and Width）

通过工作簿的 `tabstripPosition` 选项，可设置标签栏相对于工作簿的位置。该位置在触摸设备和所有 SpreadJS 主题中均适用；若位置设为“左（left）”“右（right）”或“上（top）”，标签栏将与滚动条分离。

| ------------ | ----------- |
| 底部（Bottom，默认） | ![tabBottom.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/tabBottom.ba0830.bfb396.png) |
| 左侧（Left） | ![tabLeft.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/tabLeft.5b3641.f8ec9d.png) |
| 右侧（Right） | ![tabRight.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/tabRight.c61b99.d75e1b.png) |
| 顶部（Top） | ![tabTop.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/tabTop.bf524c.30e5fb.png) |

> **说明：**
>
> * 仅当标签栏位置设为“底部（bottom）”时，水平调整条按钮才可见。
> * 若标签栏位置设为“上（top）”“左（left）”或“右（right）”，`tabStripRatio` 属性将被忽略。

若标签栏位置设为“左（left）”或“右（right）”，且工作表名称过长无法完整显示时，名称会被截断并以省略号（…）标识。此时可通过 `options.tabStripWidth` 属性修改标签栏宽度，以完整显示工作表名称。该属性默认值和最小值均为 80px。

> **说明：**
> 仅当标签栏位置设为工作簿的“左（left）”或“右（right）”时，`options.tabStripWidth` 属性才生效；若为其他位置，该属性将被忽略。
> ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/tabstripWidth.e4af9a.png)
> 以下代码示例设置了标签栏的位置和宽度：

```javascript
// 1. 创建工作簿时设置标签栏位置
var spread = new GC.Spread.Sheets.Workbook(
    document.getElementById("ss"), 
    {tabStripPosition: GC.Spread.Sheets.TabStripPosition.top} // 位置设为“顶部”
);
// 或通过工作簿选项修改标签栏位置
spread.options.tabStripPosition = GC.Spread.Sheets.TabStripPosition.top;
       
// 2. 创建工作簿时设置标签栏宽度
var spread = new GC.Spread.Sheets.Workbook(
    document.getElementById("ss"), 
    {tabStripWidth: 200} // 宽度设为200px
);
// 或通过工作簿选项修改标签栏宽度
spread.options.tabStripWidth = 200;        
```

## 九、“所有工作表”按钮（The “All Sheets” button）

SpreadJS 在标签栏中提供了“所有工作表”汉堡按钮，可帮助快速导航到工作簿中的特定工作表。点击该按钮会打开一个下拉列表，显示所有可用工作表。

当所有工作表无法在标签栏中完整显示时，“所有工作表”按钮会自动出现；也可通过调整标签栏宽度隐藏部分工作表，使其显示。

![gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/gif.a38e5d.25794d.gif)

通过 [AllSheetsListVisibility](https://docs.grapecity.com.cn/spreadjs/help/api/enums/GC.Spread.Sheets.AllSheetsListVisibility) 枚举值（`hide` 隐藏、`show` 显示、`auto` 自动，默认）设置 `allSheetsListVisible` 选项，可选择是否显示该汉堡按钮。

```javascript
// 1. 自动显示/隐藏“所有工作表”按钮（默认）
function AutoButton(spread) {
    spread.options.allSheetsListVisible = GC.Spread.Sheets.AllSheetsListVisibility.auto;
}

// 2. 始终显示“所有工作表”按钮
function ShowButton(spread) {
    spread.options.allSheetsListVisible = GC.Spread.Sheets.AllSheetsListVisibility.show;
}

// 3. 隐藏“所有工作表”按钮
function HideButton(spread) {
    spread.options.allSheetsListVisible = GC.Spread.Sheets.AllSheetsListVisibility.hide;
}
```

> **说明：**
> 无论 `allSheetsListVisible` 选项设置为何值，“所有工作表”汉堡按钮的位置始终保持不变。
