# manage-doc-properties

文档属性包含有关工作簿的信息，如标题、作者、主题等。SpreadJS 允许您在工作簿中管理这些属性。
要管理文档属性，SpreadJS 提供了类型为 `IDocProps` 接口的 `docProps` 属性。它允许自定义文档属性，例如 `coreDocProps`、`appDocProps` 和 `customDocProps`。

* **核心文档属性** \- 这些是基本属性，如标题、创建者和关键字，提供关于文档的重要信息
* **应用文档属性** \- 这些属性专用于管理文档，如经理、公司详情等
* **自定义文档属性** \- 这些是用户定义的属性，可以以各种数据类型保存

### 代码示例

以下代码示例描述了如何设置文档属性。

```javascript
// Set core document properties.
spread.docProps.coreDocProps = {
    title: 'Sample Document',
    creator: 'Admin',
    keywords: 'sample, document',
    subject: 'Sample Subject',
    description: 'This is a sample document',
    category: 'Sample Category',
    contentStatus: 'Draft',
    created: '11/01/24',
    lastPrinted: '20/01/24',
    modified: '21/01/24',
    lastModifiedBy: 'John'
};

// Set app document properties.
spread.docProps.appDocProps = {
    manager: 'John',
    company: 'XYZCompany',
    hyperlinkBase: 'https://example.com/documents/'
};

// Set custom document properties.
spread.docProps.customDocPropsManager.all([
    { name: 'Kim', value: '1' },
    { name: 'Smith', value: '2' }
]);

// Get document properties.
console.log(spread.docProps.coreDocProps);
console.log(spread.docProps.appDocProps);
console.log(spread.docProps.customDocPropsManager.all());
```

您还可以使用 `IDocProps` 接口的 `customDocPropsManager` 属性更改文档的自定义属性。以下代码示例演示如何使用自定义属性管理器添加、删除、获取、列出所有以及清除与文档关联的自定义属性。

```javascript
 const customPropsManager = spread.docProps.customDocPropsManager;
 customPropsManager.all([
     { name: 'name1', value: 'value1' },
     { name: 'name2', value: 'value2' },
 ]);

 // Set new custom document properties.
 customPropsManager.add('name3', 'value3');
 customPropsManager.add('name1', 'value1_modified');

 // Remove the custom document property 'name2'.
 customPropsManager.remove('name2');

 // Get the value of the custom document property 'name3'.
 customPropsManager.get('name3'); // Output: 'value3'

 // Get all remaining custom document properties.
 customPropsManager.all(); // Output: [ { name: 'name1', value: 'value1_modified' }, { name: 'name3', value: 'value3' } ]

 // Clear all custom document properties.
 customPropsManager.clear();
```

### 使用表格编辑器

**要管理工作簿中的文档属性，请按照以下步骤操作。**

1. 查看或修改标准属性 点击文件选项卡并选择信息。
2. 信息选项卡的右侧显示工作簿的属性。
3. 添加或修改必要的信息。
4. 点击文本字段外部以保存更改。

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.6dc970.png)
**编辑高级属性**

1. 点击文件选项卡并选择信息
2. 点击属性下拉菜单并选择高级属性
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.db96c6.png)
3. 在“属性”对话框中，有不同的选项卡，例如“摘要”、“统计信息”、“内容”和“自定义”
    每个选项卡有助于配置与文档相关的不同类型的信息。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.6c044e.png)
    默认情况下，选择摘要选项卡。您可以根据需要添加/更改文档摘要信息。您还可以在统计和内容选项卡中查看有关文档的一般信息。
4. 点击自定义选项卡以定义额外的自定义属性。
    1. 在名称字段中，为自定义属性输入名称或从列表中选择。
    2. 在类型下拉列表中，选择数据类型。
        可用的数据类型如下：
        1. 文本
        2. 日期
        3. 数字
        4. 是或否
    3. 在值字段中，输入与所选数据类型匹配的值。
        您提供的值必须与类型列表中的选择匹配。例如，如果您在类型列表中选择“数字”，则必须在值框中输入一个数字。请注意，与属性类型不匹配的值将保存为文本。
    4. 点击添加
        添加自定义属性后，它会显示在属性列表中。
        ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.8e5617.png)
        此外，SpreadJS 提供了“链接到内容”设置，将文档内容链接到属性值，以便每当内容值更改时，文档属性会自动更新以反映新值。以下是一个说明该设置如何工作的示例。
        示例：假设您有一个包含多个表格和图表的销售数据工作簿。
        1. 创建一个名为“Total Sales”的文档属性，该属性会在 Sheet1 中的单元格 B10 的总销售值发生变化时自动更新
        2. 在此示例中，首先为单元格创建一个自定义名称，如 Sheet1!$B$10
            自定义名称也会在内容选项卡和命名范围部分中显示
        3. 现在，导航到“自定义”选项卡，在名称字段中输入“Total Sales”，然后选中“链接到内容”复选框
            值字段显示您创建的自定义名称
        4. 单击“添加”，该属性将出现在属性列表中，并带有链接图标，其值与单元格 Sheet1!$B$10 的值相同
            每当单元格 B10 中的值更改时，“Total Sales”文档属性将自动更新以反映新值
<br>
            但是，如果自定义内容链接属性无效，则在属性名称前会显示一个未链接的图标，并且只能删除该属性
            单击“确定”将属性保存到工作簿中
5. 单击“确定”将属性保存到工作簿

> type=warning
> 注意：
>
> * 在使用 SpreadJS 导入/导出 Excel 文件时，应始终维护 `docProps` 属性
> * 如果导入的文档有创建时间，则将使用文档的现有创建时间。否则，没有创建时间
> * 在打开新的 Designer 时，创建时间默认设置为当前时间。单击添加新工作簿后，将更新为最新时间
> * 在导入时，SpreadJS 使用文档的修改时间，而导出的文档修改时间更新为导出时间
> * 当用户单击打印选项时，最后打印时间将更改为当前时间
