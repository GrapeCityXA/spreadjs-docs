# DisplayPreviewLineforPrint

通常，在打印任何报表数据之前，用户往往会预览文档在执行打印任务后的样子。这是通过使用“打印预览”对话框来完成的，该对话框有助于识别、查看和修复任何潜在的页面布局问题。但遗憾的是，“打印预览”对话框只能生成整个工作表的预览，不允许用户预览和打印特定的数据。
SpreadJS 允许用户显示用于打印的预览线，以便根据他们的自定义要求仅打印所需的数据。当你处理大型工作表，但又只想在不同页面上打印特定的数据块（或单元格区域）时，此功能尤其有用。
用户可以使用 [Worksheet ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1)类的 [isPrintLineVisible ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#isPrintLineVisible)方法来获取或设置是否在工作表中显示预览线。

## 示例

例如，假设你正在处理一个营销应用程序，其中包含来自不同地区的产品销售信息和其他统计数据。现在，你想在不同页面上打印不同地区的销售数据。在这种情况下，检查并预览所选的打印数据是否会打印在正确的页面上就变得很重要。通过显示用于打印的预览线，用户可以在特定页面上正确打印所需的数据。
下面展示了一个显示用于打印的预览线的示例图片。当用户将起始行设置为 2，起始列设置为 1，结束行设置为 6，结束列设置为 4 时；将会显示预览线以指示打印区域为 B3:E7。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/display-print-line-2.jpg)
请参考以下代码以显示预览行以进行打印。

```javascript
$(document).ready(function () {
    // Initialize spread
    var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });
    spread.suspendPaint();

    // Fetch the ActiveSheet
    var sheet = spread.getActiveSheet();
    sheet.setRowCount(600);
    sheet.setColumnCount(80);

    // Set value
    for (var r = 0, rc = sheet.getRowCount() + 150; r < rc; r++) {
        for (var c = 0, cc = sheet.getColumnCount() + 20; c < cc; c++) {
            sheet.setValue(r, c, r + c);
        }
    }

    // Set print info
    var printInfo = sheet.printInfo();
    spread.resumePaint();
    $('#print').click(function () {
        spread.print();
    });
    $('#printLine').click(function () {
        var activeSheet = spread.getActiveSheet();
        var isDisplayPrintLine = activeSheet.isPrintLineVisible();
        activeSheet.isPrintLineVisible(!isDisplayPrintLine);
    });
    $('#updatePrintInfo').click(function () {
        var activeSheet = spread.getActiveSheet();
        var printInfo = activeSheet.printInfo();
        var startRow = parseInt(document.getElementById('startRow').value);
        var endRow = parseInt(document.getElementById('endRow').value);
        var startColumn = parseInt(document.getElementById('startColumn').value);
        var endColumn = parseInt(document.getElementById('endColumn').value);
        printInfo.rowStart(startRow);
        printInfo.rowEnd(endRow);
        printInfo.columnStart(startColumn);
        printInfo.columnEnd(endColumn);
    });
});
```
