# NumberandDateFormat

用户可以在工作表中选择设置数字和日期格式。SpreadJS 提供了两种模式，即**掩码模式**（Mask）和**溢出模式**（Overflow），以帮助用户选择偏好的显示方式。
默认情况下，用户可以根据列宽对单元格中的数据进行掩码处理。这就是所谓的掩码模式。用户还可以取消对单元格数据的掩码，并使用溢出模式让数据溢出到相邻单元格中。
以下详细介绍每种模式。

### 掩码模式

当用户需要处理包含数百或数千列且列宽不同的电子表格时，掩码模式功能尤为有用。数据会根据列中可用空间动态显示。
例如-如果用户在单元格中输入“123456.654321”，根据列宽不同，该单元格中的数据显示会有所不同，如下图所示：123456.654321 -> 123456.65432 -> 123456.6543 -> 123456.654 -> 123456.65 -> 123456.7 -> 123457 -> 1E + 05 -> ####
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/number-display.png)
**数字显示时应用的规则**

* 当列宽不足以显示整数部分时，将使用科学计数法。[例如-参考下图中的单元格 B1]。
* 当列宽能够容纳整数部分但无法容纳小数部分时，小数将进行四舍五入。[例如-参考下图中的单元格 C1]。
* 当最短的科学计数法也不够用时 [例如-参考下图中的单元格 A1]，数字将显示为“####”，其中“#”的数量取决于列宽。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/number-display2.png)
**日期显示时应用的规则**

* 当日期的文本长度大于列宽时，单元格将显示为“######”，其中“#”的数量取决于列宽。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/date-display1.png)![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/date-display2.png)
以下代码示例展示了如何根据列宽显示日期和数字。

```JavaScript
// 显示数字
var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
var sheet = spread.getActiveSheet();
sheet.suspendPaint();
var width = [35, 45, 54, 66, 71, 80, 88, 95, 114];
for (var c = 0; c < 9; c++)
{
sheet.setValue(0, c, 123456.654321);
sheet.setColumnWidth(c, width[c]);
}
sheet.resumePaint();
// 显示数据
var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
var sheet = spread.getActiveSheet();
sheet.suspendPaint();
var date = new Date(2018, 9, 7);
sheet.setValue(0, 0, date);
sheet.setFormatter(0, 0, 'yyyy-mm-dd');
sheet.setColumnWidth(0, 80);
sheet.resumePaint();
```

> **注意**：在 SpreadJS 中设置日期和数字格式时，应牢记以下限制：
>
> * 设置 **TextIndent** 属性会影响单元格中的数字和日期格式。例如-当列宽为 60 像素且文本缩进设置为 40 像素时，那么只剩下 20 像素（60 像素-40 像素）来显示数字或数据。但对于显示“#”，我们将以“60 像素”的列宽来设置“####”。
> * 当 **shrinkToFit** 属性设置为布尔值 true 时，数字和日期格式将不受影响。
> * 当单元格格式和单元格值为数字时，如果文本长度大于列宽，SpreadJS 不会更改值，只会显示“###”。

### 溢出模式

当列宽不足以显示整个数字时，SpreadJS 会自动显示“####”、科学计数法和四舍五入后的整数值。但是，您可以更改 SpreadJS 的这种默认行为，通过使用 **NumbersFitMode** 工作簿选项并将其值设置为 1，来防止单元格内容被掩码。
此 **NumbersFitMode** 选项可帮助您在数字或日期长度大于列宽时，通过允许单元格内容溢出到相邻单元格来显示整个数字或日期。此选项也适用于日期。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/numberfitmode.png)
参考以下示例，当单元格中的日期和数字长度超过列宽时，允许其溢出。

```JavaScript
//将numbersFitMode选项设置为1
spread.options.numbersFitMode = 1;

//设置日期
var d = new Date();
activeSheet.setValue(1, 3, new Date(2011, 10, 11));

//设置数字
activeSheet.getCell(1, 1, GC.Spread.Sheets.SheetArea.viewport).text("12345678901239");
```
