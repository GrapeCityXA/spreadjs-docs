# BasicFormat

你可以使用标准数字、日期时间、自定义格式以及各种其他格式选项来设置单元格值的格式。
使用 [setFormatter ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#setFormatter)方法为单元格设置格式字符串，使用 [getFormatter ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#getFormatter)方法获取单元格的格式设置。
你还可以使用 [FormatterBase ](gcdocsite__documentlink?toc-item-id=bbd524b9-ba5b-4dc4-be4f-f02a92a34bad)类创建自定义格式设置，该类支持组合、条件和前景色格式设置。不支持 “(”、“)” 和 “\*” 表达式。

## 标准值格式设置

你可以使用 [formatter ](gcdocsite__documentlink?toc-item-id=64f05fd4-fafa-47dc-9856-b74263f357ec#formatter)方法获取单元格、列或行，并为单元格设置和获取格式设置。
以下代码示例展示了如何使用不同的格式样式设置单元格值的格式。

```javascript
var dvalue = 12345.6789;
activeSheet.setValue(0, 0, dvalue);
activeSheet.getCell(0, 1).formatter("M");
activeSheet.setValue(0, 1, new Date(2011, 2, 9));
activeSheet.getCell(0, 2).formatter("m");
activeSheet.setValue(0, 2, new Date(2012, 10, 15));
activeSheet.getCell(0, 3).formatter("General");
activeSheet.setValue(0, 3, new Date(2012, 10, 15));
activeSheet.getCell(0, 4).formatter("#.#%");
activeSheet.setValue(0, 4, 1);
activeSheet.getCell(1, 0).formatter('[<0](0.0);[>0]0.0;"zero";@');
activeSheet.setValue(1, 0, 3);
```

## 分数格式设置

SpreadJS 支持常见的分数格式，例如 “# ?/?”、“# ??/??”、“# ?/4” 和 “#,## ?/?”。你可以将负值转换为分数。
以下代码示例将单元格值设置为分数格式。

```javascript
var dvalue = 123.89;
activeSheet.setValue(0, 0, dvalue);
activeSheet.getCell(0, 0).formatter("# ??/??");
```

## 中文大写数字格式设置

SpreadJS 还支持本地标识符 “$-411” 和中文大写数字格式。
以下代码示例使用本地标识符 “$-411” 设置单元格值的格式。

```javascript
var dvalue = 123.89;
activeSheet.setValue(0, 0, dvalue);
activeSheet.getCell(0, 0).formatter("[$-411]dddd");
```

以下代码示例使用中文大写数字格式设置单元格值的格式。

```javascript
var dvalue = 123.89;
activeSheet.setValue(0, 0, dvalue);
activeSheet.getCell(0, 0).formatter("[DBNum2][$-411]General");
```

## 区域设置格式设置

你还可以将区域设置为 “ja-jp” 或 “en-us”。可以为整个控件或单个单元格指定区域设置。
以下代码示例为控件设置区域设置。

```javascript
// 控件设置
GC.Spread.Common.CultureManager.culture("ja-jp");
```

数字会根据当前区域设置进行格式化。默认区域设置为英语。单元格的区域设置不会改变控件的区域设置。
以下代码示例为单元格设置区域设置。

```javascript
// 单元格设置
// 在单元格 [0,0] 和 [0,1] 中输入日期字符串 "2014/01/07"
activeSheet.getCell(0, 0).formatter(new GC.Spread.Formatter.GeneralFormatter("yyyy/MM/dd dddd", "ja-jp"));
activeSheet.getCell(0, 1).formatter(new GC.Spread.Formatter.GeneralFormatter("yyyy/MM/dd dddd", "en-us"));
```

## 颜色格式设置

颜色格式会影响前景色，并且支持颜色字符串名称以及颜色索引，颜色索引范围从 1 到 56。
![format-colorindex](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/format-colorindex.755d73.png)
以下代码示例展示了如何通过索引设置颜色格式，根据值的范围来更改单元格的颜色。

```javascript
activeSheet.getRange(2, 2, 1, 6).formatter("[color44][<300]0.0;[color3][>400]0.0;[color45]0.0")
activeSheet.getCell(2, 2).value(100);
activeSheet.getCell(2, 3).value(200);
activeSheet.getCell(2, 4).value(300);
activeSheet.getCell(2, 5).value(400);
activeSheet.getCell(2, 6).value(500);
activeSheet.getCell(2, 7).value(600);
```

> **注意：** 在公式中使用颜色索引在导出为 Excel 时不会产生任何颜色效果。
