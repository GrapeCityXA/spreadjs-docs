# cellalign

您可以对齐或缩进单元格中的文本。 您还可以添加文字装饰。您可以使用 **`hAlign`** 和 **`vAlign`** 方法。 您可以使用 **`textIndent`** 方法指定缩进。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/cellalign.png)
**`vAlign`** 方法也 支持单元格编辑模式下的文本垂直对齐，如下图所示。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/edit_mode_cell.png)
下面分享的表格描述了在超链接单元格中，水平对齐方式和文本缩进是如何协同起作用的：

| 水平对齐方式 | 文本缩进 |
| ------ | ---- |
| 左对齐 | 在 **“文本缩进”** 中增加缩进值会使超链接文本向右移动一个制表符的宽度。 |
| 居中对齐 | 超链接文本将居中对齐。 |
| 右对齐 | 在 **“文本缩进”** 中增加缩进值会使超链接文本向左移动一个制表符的宽度。 |

> **注意:**
> 在单元格编辑模式下，仅“可编辑div”支持文本的垂直对齐方式，“ textarea” 元素不支持文本的垂直对齐方式。
> 在具有文本单元格类型的单元格的桌面设备上工作时，您需要用可编辑的 div 替换 textarea 元素，以便在单元格编辑模式下实现文本的垂直对齐。
> 此外， IME-Mode 在两种浏览器中均无法使用：Google Chrome 和 Mozilla Firefox。

本示例为单元格B2设置垂直和水平对齐方式，并为单元格B3指定文本缩进。

```JavaScript
window.onload = function()
                    {
                       var spread =
                       new GC.Spread.Sheets.Workbook(document.getElementById("ss"),{sheetCount:3});
                       var activeSheet = spread.getActiveSheet();
                      
                       // 将字符串的水平和垂直对齐方式设置为居中
                       var cell = activeSheet.getCell(1, 1, GC.Spread.Sheets.SheetArea.viewport);
                       cell.hAlign(GC.Spread.Sheets.HorizontalAlign.center);
                       cell.vAlign(GC.Spread.Sheets.VerticalAlign.center);
                       cell.value("Alignment");
                       // 设置字符串的缩进。
                       cell = activeSheet.getCell(2, 1, GC.Spread.Sheets.SheetArea.viewport);
                       cell.textIndent(2);
                       cell.value("Indent");
                       activeSheet.getRange(1, -1,  2, -1, GC.Spread.Sheets.SheetArea.viewport).height(40);
                       activeSheet.getRange(-1, 1, -1, 1, GC.Spread.Sheets.SheetArea.viewport).width(120);
                    }
```

### 跨所选区域居中对齐

SpreadJS 提供了“跨列居中”水平对齐，这有助于将选定单元格的内容跨列居中，而无需合并单元格。 可以使用 **HorizontalAlign.centerContinuous** 枚举选项设置这种类型的水平对齐方式。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/centerAcrossSelection.gif)
下表显示了使用“跨列居中”水平对齐时观察到的不同特性：

| 特性 | 示例 |
| --- | --- |
| 当范围设置为对齐时，每个单元格将不断向右寻找连续的空值单元格，最后将其内容放在所有单元格的中心 | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/center-selection-1.gif) |
| 如果稍后将值输入到所选范围内，则选择和居中将更新以排除该单元格。 | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/center-selection-2.gif) |
| 选择总是从格式化的单元格开始。  因此，如果选择从单元格的左侧延伸，则不包括这些单元格。 | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/center-selection-3.gif) |
| 调整列的大小时会调整居中。 | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/center-selection-4.gif) |

下面的代码示例在工作表中实现“跨列居中”水平对齐。

```JavaScript
activeSheet.getCell(1,1).value("跨列居中");
activeSheet.getRange(1, 1, 1, 5, GC.Spread.Sheets.SheetArea.viewport).hAlign(GC.Spread.Sheets.HorizontalAlign.centerContinuous);
```

“跨列居中”水平对齐通过以下方式与 SpreadJS 的其他功能交互：

* **溢出** \- 如果“跨列居中”对齐方式中的内容超出所选范围的宽度，则会触发向两边溢出
* **自动换行** \- 行高属性将强制单元格将文本换行在“跨列居中”区域的边界内
* **缩小字体填充** \- 如果选择该选项，则 width 属性将用于计算实际字体大小并适合所选范围内的内容
* **会计数字格式** \- “跨列居中”不直接将文本居中，而是将符号和值拉伸到两侧
* **文本缩进** \- “跨列居中”会将缩进锁定为 0
* **方向** \- “跨列居中”会将方向锁定为 0
* **合并单元格** \- 合并的单元格不能在选择样式中使用中心。如果单元格被合并，“跨列居中”将被替换为“Center”

### 分布式水平对齐

在 SpreadJS 中，分布式水平对齐将文本均匀分布在单元格的宽度上。分布式选项是居中对齐和文字换行的组合。
使用分布式水平对齐时，文本的每一行中的每个单词都会沿单元格的宽度均匀对齐，并且当应用缩进值时，单元格的左右两侧都会填充。
因此，当您同时应用分布式选项和缩进值时，两边的边距会与每行的两个边缘对齐。这种类型的水平对齐可以使用 HorizontalAlign.distributed 枚举选项来设置。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca82939a-5d1a-4838-9f3f-69a0f7ebeeb5/image.404378.png)
以下代码示例在工作表中实现了“分布式”水平对齐。

```javascript
style.hAlign = GC.Spread.Sheets.HorizontalAlign.distributed;
activeSheet.setStyle(1, 1, style, GC.Spread.Sheets.SheetArea.viewport);
activeSheet.getCell(1, 1).value("This is Distributed Alignment");
```

“分布式”水平对齐与 SpreadJS 的其他特性以以下方式交互：

* 文字换行 - 使用“分布式”对齐内容时，文字换行功能会自动实现，因此单独设置其值没有差异
* 缩小以适应 - 分布式对齐禁用此选项
* 文本缩进 - 在“分布式”对齐内容中，单元格的左右两侧都会缩进
* 对齐最后一行 - 分布式对齐禁用此选项
* 显示省略号 - 分布式对齐禁用此选项

### 使用 SpreadJS 设计器

您可以通过访问“设置单元格格式”窗口中的“对齐”选项卡来使用对齐和缩进功能。 单击“主页”选项卡> “对齐”组 > 右下箭头按钮打开“格式化单元格”窗口。
