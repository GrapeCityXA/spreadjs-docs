# check-box-list-cell

SpreadJS允许用户在电子表格的单元格内创建复选框列表。
这指的是一种带有多项选择字段值的交互式清单或待办事项列表。它通过嵌入在单个单元格内的多个复选框（小方形选择框）来显示一组项目。用户可以点击复选框来选择或取消选择特定选项。

## 使用场景

当用户在使用工作表时需要在一个单元格中选择多个字段值时，复选框列表单元格类型将很有帮助。借助复选框列表，用户可以快速高效地创建客户反馈调查、输入表单、交互式清单和动态报告。

**示例**\- 假设您想以一种简单有效的方式来分析公司产品的最终用户响应。在这种情况下，在工作表中创建一个用户友好的复选框列表是记录客户响应的好主意，如以下截图所示：

## 自定义复选框列表单元格

在SpreadJS中使用复选框列表单元格类型时，用户可以执行以下任务，以便根据其特定首选项对其进行自定义：

* 用户可以使用 [textAlign](gcdocsite__documentlink?toc-item-id=9c6c313f-1184-4a74-87b1-b51775c97386#textalign) 方法配置文本对齐方式。[TextAlign ](gcdocsite__documentlink?toc-item-id=3a6486ad-94da-4370-8627-044dc2d84913)枚举中的可用选项为左对齐和右对齐。
* 用户可以通过 [isFlowLayout ](gcdocsite__documentlink?toc-item-id=cd117110-3bba-477c-8fea-52d4a828c048#isflowlayout)方法来确定复选框列表的布局是否为自动适应。默认情况下，此方法的参数值设置为“true”。
* 用户可以使用 [Direction ](gcdocsite__documentlink?toc-item-id=c6a0f210-0329-4eb0-b1d7-f8277109ac4e)枚举，将复选框列表单元格类型的方向设置为水平或垂直。
* 用户可以分别使用 [maxRowCount ](gcdocsite__documentlink?toc-item-id=cd117110-3bba-477c-8fea-52d4a828c048#maxrowcount)方法和 [maxColumnCount ](gcdocsite__documentlink?toc-item-id=cd117110-3bba-477c-8fea-52d4a828c048#maxcolumncount)方法，获取或设置复选框列表的行数和列数的项目。只有当 [isFlowLayout ](gcdocsite__documentlink?toc-item-id=cd117110-3bba-477c-8fea-52d4a828c048#isflowlayout)方法的参数值设置为true且方向为水平时，才能进行此操作。
* 用户可以使用 [itemSpacing ](gcdocsite__documentlink?toc-item-id=cd117110-3bba-477c-8fea-52d4a828c048#itemspacing)方法，配置两个列表项之间的间距，以避免单元格内列表项之间出现拥挤和杂乱的情况。
* 用户可以使用 **boxSize** 方法更改复选框的大小，该方法的值可以设置为任意数字或“auto”。如果该方法设置为任何非法值，复选框大小将不会改变。复选框列表单元格类型中复选框的标准大小为12×12。不过，此方法仅在Chrome、Edge、Firefox、Internet Explorer、Opera、Safari、安卓WebView、安卓版Chrome、安卓版Firefox、安卓版Opera、iOS版Safari和三星浏览器上有效。
* 用户可通过 [CheckBoxList.mode('toggle')](https://docs.grapecity.com.cn/spreadjs/help/api/classes/GC.Spread.Sheets.CellTypes.CheckBoxList#mode) 方法，将标准复选框转换为交互式切换开关。
    * 该模式支持通过 `autoSize` 实现文本动态缩放，通过 `width`/`height` 设置固定尺寸，还可通过 `sliderColorOn`（激活态滑块颜色）、`trackColorOff`（未激活态轨道颜色）以及调整圆角半径，对激活/未激活状态进行视觉自定义。
    * 文本对齐选项包含 `CheckBoxTextAlign.inside`（文本嵌入开关内部），适用于紧凑布局场景。

>type=info
> **说明：**
>
> * 当 `autoSize`（自动适配）禁用时，`autoFitWidth`/`autoFitHeight`（自动适配宽/高）功能会忽略文本溢出。
> * 切换模式下，`boxSize`（复选框尺寸）配置不可用。
> * 状态切换需点击切换按钮（而非单元格任意区域）才能触发。

## 代码实现（Using Code）

以下示例代码展示了如何在电子表格的单元格中创建基础复选框列表：

```javascript
window.onload = function(){
    // 初始化 Spread 工作簿
    var spread = new GC.Spread.Sheets.Workbook('ss', { sheetCount: 1 });

    // 获取当前活动工作表
    var activeSheet = spread.getSheet(0);

    // 本示例创建复选框列表单元格类型
    var checkBoxListCellType = new GC.Spread.Sheets.CellTypes.CheckBoxList();
    // 设置（0,1）单元格字体样式：斜体、16像素、Calibri字体
    activeSheet.getCell(0, 1).font("italic 16px Calibri");
    // 设置（0,1）单元格字体颜色为红色
    activeSheet.getCell(0, 1).foreColor("Red");
    // 设置（0,1）单元格（视图区域）的值并启用文本换行
    activeSheet.getCell(0, 1, GC.Spread.Sheets.SheetArea.viewport).value("购买软件产品时，哪些因素对您很重要？ ").wordWrap(true);
    // 为复选框列表设置选项：文本（text）与对应值（value）
    checkBoxListCellType.items([{ text: "价格", value: 1 }, { text: "易用性", value: 2 }, { text: "功能", value: 3 }, { text: "支持服务", value: 4 }, { text: "其他", value: 5 }]);

    // 配置复选框列表中两个选项的间距
    checkBoxListCellType.itemSpacing({
        horizontal: 20, // 水平间距：20像素
        vertical: 10    // 垂直间距：10像素
    });

    // 配置复选框列表方向为垂直
    checkBoxListCellType.direction(GC.Spread.Sheets.CellTypes.Direction.vertical);

    // 配置复选框列表中文本的位置（仅支持左对齐和右对齐）
    checkBoxListCellType.textAlign(GC.Spread.Sheets.CellTypes.CheckBoxTextAlign.right);

    // 配置复选框列表中复选框的大小（仅支持数字和"auto"）
    checkBoxListCellType.boxSize(20);
    // 将复选框列表单元格类型应用到（1,1）单元格
    activeSheet.getCell(1, 1).cellType(checkBoxListCellType);

    // 配置行高（视图区域）
    activeSheet.setRowHeight(0, 70.0, GC.Spread.Sheets.SheetArea.viewport);
    activeSheet.setRowHeight(1, 160.0, GC.Spread.Sheets.SheetArea.viewport);

    // 配置列宽（视图区域）
    activeSheet.setColumnWidth(1, 200.0, GC.Spread.Sheets.SheetArea.viewport);
}
```

以下示例在复选框列表中实现切换模式：

```javascript
window.onload = function () {
    // 初始化 Spread 工作簿
    var spread = new GC.Spread.Sheets.Workbook('ss', { sheetCount: 1 });
    // 获取当前活动工作表
    var activeSheet = spread.getSheet(0);
    // 本示例创建复选框列表单元格类型
    var checkBoxListCellType = new GC.Spread.Sheets.CellTypes.CheckBoxList();
    // 为复选框列表设置选项
    checkBoxListCellType.items([
        { text: "价格", value: 1 },
        { text: "易用性", value: 2 },
        { text: "功能", value: 3 },
        { text: "支持服务", value: 4 },
        { text: "其他", value: 5 }]);
    // 配置复选框列表中两个选项的间距
    checkBoxListCellType.itemSpacing({
        horizontal: 20, // 水平间距：20像素
        vertical: 10    // 垂直间距：10像素
    });
    // 启用切换模式
    checkBoxListCellType.mode('toggle');
    // 配置切换开关属性
    checkBoxListCellType.toggleOptions({
        autoSize: true, // 启用自动适配
        sliderMargin: 2, // 滑块与轨道的间距：2像素
        trackColorOn: '#8cbae8', // 激活态轨道颜色
        trackColorOff: '#9e9e9e', // 未激活态轨道颜色
        sliderColorOn: '#1565c0', // 激活态滑块颜色
        sliderColorOff: '#ffffff', // 未激活态滑块颜色
    });
    // 配置复选框列表方向为垂直
    checkBoxListCellType.direction(GC.Spread.Sheets.CellTypes.Direction.vertical);
    // 配置复选框列表中文本的位置（仅支持左对齐和右对齐）
    checkBoxListCellType.textAlign(GC.Spread.Sheets.CellTypes.CheckBoxTextAlign.inside);
    // 配置复选框列表中复选框的大小（仅支持数字和"auto"）
    activeSheet.getCell(1, 1).cellType(checkBoxListCellType);
    // 配置行高（视图区域）
    activeSheet.setRowHeight(1, 180.0, GC.Spread.Sheets.SheetArea.viewport);
    // 配置列宽（视图区域）
    activeSheet.setColumnWidth(1, 150.0, GC.Spread.Sheets.SheetArea.viewport);
}
```
