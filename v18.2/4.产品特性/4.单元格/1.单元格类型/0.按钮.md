# cellbutton

您可以使用按钮单元格在单元格中显示按钮。 您还可以设置外观属性，例如颜色和文本。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/cellbutton.png)

## 添加按钮

本示例创建一个按钮单元并设置单元的背景色。

```JavaScript
var cellType = new GC.Spread.Sheets.CellTypes.Button();
cellType.buttonBackColor("#FFFF00");
cellType.text("this is a button");
activeSheet.getCell(0, 2).cellType(cellType);
```
