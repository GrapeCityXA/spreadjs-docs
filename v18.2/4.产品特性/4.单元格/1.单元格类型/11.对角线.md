# diagonal-cell

SpreadJS 中的 “对角线单元格” 类型代表一种对角线单元格，它能让你在单元格内插入对角线。这种单元格类型在设计表格标题或分隔报表中的数据区域时很有用。
对角线单元格可以在不同区域显示由对角线分隔的多个文本项。单元格的值决定了这些项的显示方式。要为特定单元格设置对角线单元格类型，可使用 `GC.Spread.Sheets.CellTypes.Diagonal()` 方法。导出到 Excel 时，对角线单元格会转换为图像。

## 对角线单元格的格式设置

下面我们来讨论一下设置对角线单元格所需的各种设置。

### 对角方向

对角方向决定了对角线的起止方向。无论对角方向如何，各项总是从顶部到底部按顺时针方向排列。要定义单元格中对角线的可能方向，可使用 `DivergeDirection` 枚举的属性。

### 单元格值类型

不同的 `divergeDirection` 设置会产生不同的对角线方向。对角线的值取决于工作表中单元格的值。你可以使用 `setValue` 方法来设置单元格的值。

| **值类型** | **描述** |
| --- | --- |
| 字符串 | 如果单元格的值是字符串，使用逗号（,）分隔各项。不过，在这种情况下，结果项中不包含任何逗号。<br>例如：<br>单元格值：“年份，产品，地区”<br>结果项：["年份", "产品", "地区"]<br>![DiagonalCellType_string.8ba3df](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/DiagonalCellType_string.8ba3df.ac0816.png)<br>逗号前后的空字符串也被视为有效项。<br>例如：<br>单元格值：“年份，产品，地区，”<br>结果项：["年份", "产品", "地区", " "]<br>![DiagonalCellType_stringwithcomma.8ad061](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/DiagonalCellType_stringwithcomma.8ad061.4ab886.png) |
| 数组 | 如果你想在输入项中包含逗号，可将字符串数组设置为单元格的值。如果数组中的某项不是字符串，该项的值将自动转换为字符串。<br>例如：<br>单元格值：sheet.setValue (0, 0, ["年份，月份", "产品", "地区，城市"])<br>结果项：["年份，月份", "产品", "地区，城市"]<br>![DiagonalCellType_array.49d85c](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/DiagonalCellType_array.49d85c.38c311.png) |
| CalcArray | 如果单元格的值是 CalcArray，CalcArray 会被展平为单个数组，并像数组一样处理。 |
| 其他 | 任何其他值类型都会被转换为字符串进行处理。 |

> **注意**：当单元格值为字符串时，用户可以通过双击对角线单元格或通过 API 进入编辑模式来编辑该单元格。在编辑模式下，输入字段和公式文本框将显示单元格的文本值。用户可以输入逗号分隔的字符串来修改值。但是，如果单元格的值是数组，则无法在单元格中直接编辑。

### 显示规则

| **数量** | **显示规则** |
| --- | ---- |
| 项数 <= 1 | 表现得像普通文本单元格。 |
| 项数 = 2 | 将单元格对角划分。 |
| 项数 = 3 | 将对角线端点固定在单元格长度或高度的三分之一处。 |
| 项数 > 3 | 根据项数将单元格等分为若干部分。 |
| 项数 >= 10 | 仅显示到项索引 10。多余的项将被忽略。 |

### 对角线样式

对角线单元格类型使用默认的 `GC.Spread.Sheets.LineBorder('black',GC.Spread.Sheets.LineStyle.thin)` 来绘制对角线。你可以使用 `lineBorder` 方法设置其他线条样式来改变对角线的外观。对角线样式的效果与单元格边框相同。
可应用于对角线单元格类型的样式包括：

* 背景颜色
* 前景颜色
* 字体
* 字体样式
* 字体大小
* 字体粗细

### 文本方向

项文本的绘制位置和方向会根据项的数量而有所不同。当项数为 2 或 3 时，第一个和最后一个项是水平的，而中间项沿对角线倾斜。但是，如果项数超过 3，则所有项都沿对角线倾斜。

### 文本换行与裁剪

对角线单元格支持宽度和高度的自动调整。自动调整宽度可在对角线单元格的不同区域水平显示所有文本，而自动调整高度则在文本无法单行显示时，在三角形区域内换行。
对于水平项，如果文本超出边界，它会先换行，然后裁剪多余的文本。
![Wrap_horizontalItem.ca7cde](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/Wrap_horizontalItem.ca7cde.684eab.gif)
对于倾斜项，如果文本超出边界，它会直接裁剪溢出的文本。
![Wrap_tiltedItem.813811](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/Wrap_tiltedItem.813811.d29e63.gif)

> **注意**：对角线单元格不支持硬换行（例如 \\n 或 \\r\\n）。

请参考以下代码示例来设置对角线单元格类型。

```javascript
sheet.setRowHeight(1, 150);
sheet.setRowHeight(2, 120);
sheet.setColumnWidth(1, 140);

var diagonalCellType = new GC.Spread.Sheets.CellTypes.Diagonal();
diagonalCellType.divergeDirection(GC.Spread.Sheets.CellTypes.DivergeDirection.topLeftToButtomRight);
var style = new GC.Spread.Sheets.Style();
style.cellType = diagonalCellType;
style.foreColor = "green";
style.backColor = "#ddebf7";
style.font = "italic normal 15px Mangal";
sheet.setStyle(1, 1, style);
sheet.setValue(1, 1, ["Year", "Month", "Product", "Region, City"]);

var dialognalCellType2 = new GC.Spread.Sheets.CellTypes.Diagonal();
dialognalCellType2.divergeDirection(GC.Spread.Sheets.CellTypes.DivergeDirection.bottomLeftToTopRight)
var lineStyle = new GC.Spread.Sheets.LineBorder('red', GC.Spread.Sheets.LineStyle.thick);
dialognalCellType2.lineBorder(lineStyle);
var style1 = new GC.Spread.Sheets.Style();
style1.cellType = dialognalCellType2;
sheet.setStyle(2, 1, style1);
sheet.setValue(2, 1, "Bottom Left,To,Top Right");
```

## 使用 SpreadJS 设计器

你也可以使用 SpreadJS 设计器来设置对角线单元格类型，方法是在 **“主页”** 选项卡下的 **“样式”** 组中选择 **“单元格编辑器”** \> **“单元格类型”** \> **“对角”** 选项。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.2243d3.png)
使用 **“对角线单元格类型”** 对话框的 **“值”** 选项卡来设置单元格值类型、显示项文本和对角方向。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.8c6a83.png)
此外，**“对角线单元格类型”** 对话框的 **“对角样式”** 选项卡允许你根据需要更改对角线的样式。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.ca4022.png)
