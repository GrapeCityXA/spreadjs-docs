# AllowMergingCellsviaMouseDrag

SpreadJS通过允许用户选择单元格并拖动选择以合并单元格来支持拖动和合并操作。
当您要使用工作表中的其他单元格创建新的更大的单元格时，或者仅当您需要创建跨几列或多行的标签时，拖放操作提供了一种绝佳的方式。
工作表的allowUserDragMerge选项可用于控制是否允许用户通过鼠标拖动来合并单元格。
默认情况下，allowUserDragMerge选项设置为boolean false，并且单元在正常模式下运行。 但是，当此选项设置为true时，选择边框中的指示符将出现，如下图所示。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/drag_merge_indicator.png)
本示例说明如何允许用户执行拖动合并操作。 **options.allowUserDragMerge** 属性用于指定是否允许工作表中的拖动合并操作。

```JavaScript
// 允许用户通过鼠标拖动来合并单元格
spread.options.allowUserDragMerge = true;
```

更多信息,请参考 [Cell Span](gcdocsite__documentlink?toc-item-id=be6ed9c1-1963-434c-adb4-df64fb2b8399).

> **注意:** 拖动合并操作具有以下限制：>
>
> * 拖动不能跨越已合并区域。
> * 拖动合并仅适用于向右或向下的方向。
> * 指示器颜色与选区边框颜色相同。
> * 如果用户所选区域包含部分合并的单元格区域，则无法执行拖动合并操作。
