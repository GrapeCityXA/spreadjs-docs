# hyperlink_cells

SpreadJS允许用户在单元格中添加超链接，以链接到网页上任何相关信息，工作簿中的任何范围或发送电子邮件。 **setHyperlink** 方法可用于在单元格中设置以下类型的超链接：

* 网页的网址-例如[https://www.grapecity.com/](https://www.grapecity.com/)
* 电子邮件地址-例如[spread.sales@grapecity.com](mailto:spread.sales@grapecity.com)
* 当前工作簿中的任何引用-例如 sjs://Sheet2!A1:B2

用户还可以通过输入诸如字符串值之类的链接并将 **allowAutoCreateHyperlink** 属性设置为true来自动生成超链接。

* 如果类似值的链接以www开头，则超链接会将其视为url
* 如果像value这样的链接与电子邮件链接匹配，但它不是以mailto：开头，则超链接会将其视为url
* 如果像value这样的链接与以“ sjs：//”开头的工作簿位置类型匹配，则超链接会将值设置为url

### 特性

* 具有超链接的Excel文件可以导入SpreadJS，反之亦然。
* 通过使用 **HyperlinkTargetType** 枚举，可以在新窗口或新标签页，同一框架，父框架或整个窗口中打开超链接。
* 可以使用各种属性来定义工具提示，链接颜色，访问的链接颜色和超链接的下划线。
* 可以为超链接定义自定义命令，例如缩放表单或打开日期选择器。
* 超链接支持公式以及诸如copy, paste, dragMove, dragFill, headers 以及 overflow。

### 特殊用例

* 如果需要将另一个超链接设置为已包含超链接的单元格，则新的超链接将替换旧的超链接而不是合并它。
* 如果需要修改单元格的超链接，可以先使用 **getHyperlink** 获取超链接对象，然后才能变更超链接数据的值。 最后，变更的超链接数据由 **setHyperlink** 设置。
* 如果需要从单元格中删除超链接，则可以使用 **setHyperlink** 方法将其设置为null。

### 超链接样式的优先顺序

* 如果单元格的 **linkColor** 或 **visitedLinkColor** 在超链接和foreColor样式中，超链接颜色将具有更高的优先级。
* 超链接的 **drawUnderline** 属性的优先级高于样式。
* 如果 **linkColor** 或 **visitedLinkColor** 未定义，或者 **drawUnderline** 为false，则超链接单元格将使用相应的样式作为单元格样式。
* 当单元格同时具有超链接和单元格类型（例如buttonList）时，单元格类型将具有更高的优先级。

### 限制

* 如果将函数传递给超链接数据中的 **command** 属性，则在使用fromJSON或toJSON时该函数会丢失。因此，建议使用命令代替函数。
* 导出PDF时，将显示超链接，但无法单击。

### 代码

此示例代码将不同的超链接添加到表单的单元格。

```JavaScript
// 获取表单
var activeSheet = spread.getSheet(0);

// 使用工具提示超链接到URL，并且不带下划线的链接
activeSheet.setValue(0, 0, 'GrapeCity');
activeSheet.setHyperlink(0, 0, {
url: 'https://www.grapecity.com/spreadjs',
tooltip: "GrapeCity Website",
linkColor: '#0066cc',
visitedLinkColor: '#3399ff',
drawUnderline: false
});

// 超链接到表单位置
activeSheet.setValue(1, 0, 'Sheet2!A1:B2');
activeSheet.setHyperlink(1, 0, { url: 'sjs://Sheet2!A1:B2', tooltip: "Link to Sheet2!A1:B2" }, GC.Spread.Sheets.SheetArea.viewport);

//  超链接到邮箱位置
activeSheet.setValue(2, 0, 'Send email');
activeSheet.setHyperlink(2, 0, { url: 'spread.sales@grapecity.com', tooltip: "Send email to spread.sales@grapecity.com" });

// 超链接到邮箱 & 主题
activeSheet.setValue(3, 0, 'Send Email With Subject');
activeSheet.setHyperlink(3, 0, {
url: 'spread.sales@grapecity.com?subject=Purchase Of License',
tooltip: "Send email to spread.sales@grapecity.com with Subject"
});

// 超链接到自定义命令-缩放表
activeSheet.setValue(4, 0, 'Zoom Sheet');
activeSheet.setHyperlink(4, 0, {
command: function (activeSheet) {
    if (activeSheet.zoom() === 1) {
        activeSheet.zoom(1.3);
    } else {
        activeSheet.zoom(1);
    }
}
});
// 设置日期超链接
activeSheet.setValue(5, 0, 'Set Date');
activeSheet.setHyperlink(5, 0, { command: 'openMonthPicker' });

// 超链接公式
activeSheet.setValue(6, 1, "www.google.com")
activeSheet.setValue(6, 2, "Google")
activeSheet.setFormula(6, 0, "=HYPERLINK(B7, C7");
```
