# gridline

网格线是指那些垂直和水平的线条，它们能让你的甘特图更易于阅读。这些线条有助于将甘特图中的任务栏与项目表格中的相应任务对应起来。你可以更改网格线的外观和间隔样式，以便更好地反映项目的范围。

## 网格线格式样式

网格线格式有两种样式：

* **常规样式**：这种样式有两个格式属性：[GC.Spreadsheet.GanttSheet.GanttGridline](gcdocsite__documentlink?toc-item-id=f3d567b2-6885-4950-a156-71d03a3e5d89#ganttgridline) 接口的 `lineType`（线条类型）和 `lineColor`（线条颜色）。
* **间隔样式**：这种样式同时定义了常规样式和交替样式，它继承了 **常规样式** 中的 `lineType` 和 `lineColor` 属性。它还包含 [GC.Spread.Sheet.GanttSheet.GanttGridlineInterval](gcdocsite__documentlink?toc-item-id=f3d567b2-6885-4950-a156-71d03a3e5d89#ganttgridlineinterval) 接口的 `interval`（间隔）、`intervalLineType`（间隔线条类型）和 `intervalLineColor`（间隔线条颜色）属性，以应用于间隔网格线。

## 可配置的网格线类型

甘特图中使用了不同类别的网格线。你可以使用 [GC.Spread.Sheets.GanttSheet.GanttGridlines](gcdocsite__documentlink?toc-item-id=cb27e072-62a3-447f-9d46-ce5c25dd0d8e) 类的可用属性来配置网格线，具体内容将在以下部分讨论。

### 时间刻度扩展网格线

这种 **常规样式** 的网格线用于分隔时间刻度列。要更改时间刻度层级列的网格线类型和颜色，可以为 `topTierColumn`（顶层列）、`middleTierColumn`（中间层列）和 `bottomTierColumn`（底层列）设置 `lineType` 和 `lineColor` 属性。

> **注意**：在甘特图区域中，
>
> * 底层列（bottomTierColumn）的网格线分别被中间层列（middleTierColumn）和顶层列（topTierColumn）的网格线覆盖。
> * 中间层列（middleTierColumn）的网格线被顶层列（topTierColumn）的网格线覆盖。

以下代码示例展示了如何更改底层和中间层列的网格线。

```javascript
// 将底层列的网格线更改为虚线类型且颜色为黄色。
ganttSheet.gridlines.bottomTierColumn = {
    lineType: GC.Spread.Sheets.GanttSheet.GanttGridlineType.dashed,
    lineColor: "yellow"
}
// 将中间层列的网格线更改为点划线类型且颜色为红色。
ganttSheet.gridlines.middleTierColumn = {
    lineType: GC.Spread.Sheets.GanttSheet.GanttGridlineType.dashDot,
    lineColor: "red"
}
```

### 项目辅助网格线

这种 **常规样式** 的网格线会突出显示当前日期或项目的开始和结束日期，以便清晰呈现项目的范围。要更改项目进度日期的网格线类型和颜色，可以为 `projectStart`（项目开始）、`projectFinish`（项目结束）和 `currentDate`（当前日期）设置 `lineType` 和 `lineColor` 属性。

> 注意：在甘特图区域中，
>
> * 项目开始（projectStart）的网格线分别被项目结束（projectFinish）和当前日期（currentDate）的网格线覆盖。
> * 项目结束（projectFinish）的网格线被当前日期（currentDate）的网格线覆盖。
> * 底层列（bottomTierColumn）、中间层列（middleTierColumn）和顶层列（topTierColumn）的网格线被项目开始（projectStart）、项目结束（projectFinish）和当前日期（currentDate）的网格线覆盖。

以下代码示例展示了如何更改项目开始和结束的网格线。

```javascript
// 将项目开始的网格线更改为细线条类型且颜色为红色。
 ganttSheet.gridlines.projectStart = { 
    lineType: GC.Spread.Sheets.GanttSheet.GanttGridlineType.thin, 
    lineColor: "red"
};
// 将项目结束的网格线更改为虚线类型且颜色为水绿色。
ganttSheet.gridlines.projectFinish = { 
    lineType: GC.Spread.Sheets.GanttSheet.GanttGridlineType.dashed, 
    lineColor: "aqua"
};
```

### 任务栏分隔网格线

这种 **间隔样式** 的网格线用于分隔任务行。你可以在行之间添加间隔网格线，以便对齐任务行，并通过使用 `interval`（间隔）、`intervalLineType`（间隔线条类型）和 `intervalLineColor`（间隔线条颜色）属性来更改其类型和颜色。
以下代码示例展示了如何更改甘特图任务行的间隔网格线。

```javascript
// 将甘特图任务行的间隔网格线更改为虚线类型且颜色为红色。
ganttSheet.gridlines.ganttRows = {
    lineType: GC.Spread.Sheets.GanttSheet.GanttGridlineType.thin,
    lineColor: "blue",
    interval: 2,
    intervalLineType: GC.Spread.Sheets.GanttSheet.GanttGridlineType.dashed,
    intervalLineColor: "red"
}
```
