# gantt-datamanger

数据管理器是一个强大的本地数据引擎，它会向服务器端发送请求，待数据准备好后将其绑定到甘特图工作表。甘特图工作表使用数据管理器视图作为数据源。
![甘特图工作表流程图](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/GS-flowchart.3b4a69.d4b527.png)

## 数据源架构

数据源架构指的是特定数据源内的数据结构。

### 数据和字段

甘特图工作表需要数据源提供以下字段作为[任务字段](gcdocsite__documentlink?toc-item-id=91e8db8d-279c-49d2-bf5b-9925c46b8a61#%E4%BB%BB%E5%8A%A1%E5%AD%97%E6%AE%B5)。

| **任务字段** | **数据类型** | **描述** |
| ---- | ---- | --- |
| @cols=3:**必填字段** |
| taskNumber | 数字 | 任务编号。<br>它代表每个任务的唯一编号。<br>注意：如果该字段不存在，甘特图工作表中将仅显示根任务。 |
| name | 字符串 | 任务名称。 |
| duration | 字符串/数字/对象 | 任务持续时间。<br>它包含值、单位或时间。 |
| predecessors | 字符串 | 任务依赖关系字符串。 |
| mode | 字符串 | 调度模式。<br>支持两种模式：‘自动’和‘手动’。<br>默认类型为‘自动’。 |
| @cols=3:**其他字段** |
| start | 日期 | 任务开始日期。<br>如果任务调度模式为‘自动’，该字段为计算字段。 |
| finish | 日期 | 任务结束日期。<br>如果任务调度模式为‘自动’，该字段为计算字段。 |
| complete | 数字 | 任务完成百分比。<br>百分比计算范围为 0 到 1。 |
| isMilestone | 布尔值 | 指示任务是否为里程碑。<br>默认值为‘False’。 |

以下是一个数据源示例。

```json
[
  {
    "id": 1,
    "taskNumber": 1,
    "parentId": null,
    "name": "Plan for Project Server 2013 deployment",
    "duration": "1 day", 
    "start": "21/12/23 8:00",
    "finish": "21/12/23 17:00",
    "predecessors": ""  
  },
  {
    "id": 2,
    "taskNumber": 2,
    "parentId": null,
    "name": "Prepare for deployment",
    "duration": "4 days",
    "start": "21/12/24 8:00",
    "finish": "21/12/29 17:00",
    "predecessors": "1"
  }
]
```

### 构建类型

甘特图工作表使用三种层次结构类型（如父级、级别和子级）构建任务树。不过，如有需要，你也可以手动更改所使用的构建类型。
要了解更多不同层次结构类型的信息，请参阅 [添加层次结构类型](gcdocsite__documentlink?toc-item-id=f1efa1af-0073-46e2-ba31-0148dfe63ca5)。

### 持续时间单位

甘特图工作表中的持续时间单位是一种日历设置，用于定义计算持续时间的特定参数。
当持续时间以字符串形式从数据源提供时，甘特图工作表会自动解析并规范化该持续时间。例如，将 6 天解析为实际的持续时间类型 { value: 1, unit: "Day", time: 86400000 }。
甘特图工作表支持以下持续时间单位：

* 分钟
* 小时
* 天
* 月
* 周

但是，如果源持续时间数据是一个数字或 { value: 6 }，甘特图工作表会使用 [project.calendarSettings.defaultDurationUnit](gcdocsite__documentlink?toc-item-id=77c5d783-deeb-4bf8-a9d3-3c7c4472767c#defaultdurationunit) 作为解析或编辑持续时间的默认单位。
要了解更多关于日历设置的信息，请参阅 [日历设置](gcdocsite__documentlink?toc-item-id=29a29170-1356-4f01-aa7d-78768532bed9)。

### 任务完成情况

甘特图工作表在“完成”字段中以百分比形式显示任务进度。为此，源数据中必须包含“complete”字段。
如果你在甘特图视图的列设置中定义了“complete”，可以通过拖动任务栏内的进度条来修改完成值。

> **注意**：目前，即使子任务的完成百分比发生变化，汇总任务的状态也不会改变。

以下代码示例为甘特图视图定义了“complete”列。

```csharp
var view = myTable.addView("ganttView", [
    ...
    { value: "complete", caption: "Complete" },
    ...
]);
```

要了解更多关于任务状态的信息，请参阅 [任务操作](gcdocsite__documentlink?toc-item-id=254f4e99-02ad-4fbb-a31e-600532517943)。

## 列架构

甘特图工作表需要有效的数据来安排任务。因此，甘特图视图为其列提供了多种单元格类型，以改善任务数据的编辑体验。

### 列单元格类型

甘特图工作表中的每个单元格类型都对应于表格配置列架构中定义的数据类型。这些单元格类型使你能够高效地管理和编辑与任务相关的数据。

| **单元格类型** | **描述** | **示例** |
| ----- | --- | --- |
| TaskSchedulingMode | TaskSchedulingMode 单元格类型是一个列表选择器，支持两种模式：‘自动’和‘手动’。<br>注意，不同的模式值会改变任务调度的结果。 | ![GS-TaskSchedulingMode.29973e](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/GS-TaskSchedulingMode.29973e.dabc64.png) |
| TaskDuration | TaskDuration 单元格类型是一个数字选择器。<br>你可以使用持续时间单位增加或减少持续时间值。 | ![GS-TaskDuration.5d2e99](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/GS-TaskDuration.5d2e99.0a1a98.png) |
| TaskDate | TaskDate 单元格类型是一个日期时间选择器。<br>通常，它应用于“start”和“finish”字段列。 | ![GS-TaskDate.5e1b74](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/GS-TaskDate.5e1b74.9c34f5.png) |
| TaskPrecessor | TaskPredecessor 单元格类型是一个树视图列表选择器，列出带有任务名称的任务。<br>通常，它应用于“predecessors”和“successors”字段列。 | ![GS-TaskPrecessor.d2d246](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/GS-TaskPrecessor.d2d246.a4abc5.png) |
| TaskSubject | TaskSubject 单元格类型是一个带有大纲显示的文本单元格。 | ![GS-TaskSubject.7aa285](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/GS-TaskSubject.7aa285.d66336.png) |

以下是一个列架构示例。

```css
schema: {
    columns: {
        ...
        mode: { dataType: "TaskSchedulingMode" },
        name: { dataType: "TaskSubject" },
        duration: { dataType: "TaskDuration" },
        start: { dataType: "TaskStartDate" },
        finish: { dataType: "TaskFinishDate" },
        predecessors: { dataType: "TaskPredecessor" }
        ...
    }
}
```

> **注意**：如果源数据中的字段名称与甘特图工作表中预定义的任务字段名称匹配，相关的数据类型将自动对齐。
