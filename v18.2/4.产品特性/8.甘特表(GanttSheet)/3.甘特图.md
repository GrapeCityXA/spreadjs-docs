# ganttchart

甘特图是 GanttSheet 中的一个特殊表列，用于说明项目进度表。它显示每个任务的开始和完成日期，并且通常添加每个任务的完成状态和任务之间的依赖关系等信息。
甘特图有两个基本组件：**时间尺度**和**图表区域**。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.2838c1.png?width=800)

## **时间尺度**

时间尺度表示甘特图的列标题。它显示更小或更大的时间单位，例如年、季度、月、周、日等。甘特图中的最大时间尺度为年，最小时间尺度为 15 分钟。
时间尺度由三个不同的层和一个刻度分隔符组成。

### 时间刻度层

甘特图具有三层模式，“middle”、“middleBottom”和“topMiddleBottom”来显示时间尺度。您可以使用“TimescaleTierMode”枚举来设置时间刻度的层模式。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.40b326.png?width=1000)
以下代码示例演示如何在甘特图中显示时间刻度的层模式。

```javascript
// Set the tier mode for the timescale.
   var timescale = ganttSheet.project.timescale; 
   timescale.tierMode = GC.Spread.Sheets.GanttSheet.TimescaleTierMode.middle;
```

时间刻度层具有以下可配置属性。

| **特性** | **类型** | **描述** |
| --- | --- | --- |
| unit | GC.Spread.Sheets.GanttSheet.TimescaleUnit | 层的单位。 |
| count | number | 代表刻度单位的数字。默认值为 1。 |
| labelAlign | Left/center/right | 刻度标签的对齐方式。默认值为“左”。 |
| showTickLines | boolean | 刻度线的状态。默认值是true'。 |
| formatter | string | 格式化层的刻度标签。<br>格式化程序可以是日期值的扩展数字格式字符串，例如“yyyy-mm-dd”，并支持甘特表特殊关键字，也可以是将在格式化中执行的回调函数。 |

以下示例代码展示了如何配置中间层属性。

```javascript
// Set the tier configuration.
var timescale = ganttSheet.project.timescale;
var targetTier = "middleTier";
timescale[targetTier].unit = GC.Spread.Sheets.GanttSheet.TimescaleUnit.days;
timescale[targetTier].count = 2;
timescale[targetTier].labelAlign = "Center";
timescale[targetTier].formatter = "dddd";
timescale[targetTier].showTickLines = false;
```

### 时间刻度分隔符

您还可以设置“showScaleSeparator”选项以显示 topMiddleButtom 和中间层之间的单独比例线。默认情况下，此选项值为 True。要隐藏，您需要将“showScaleSeparator”选项的值更改为 false。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.5cf46b.png?width=800)
以下代码示例演示如何隐藏刻度分隔线。

```javascript
// Hide scale separator.
ganttSheet.project.timescale.showScaleSeparator = false;
```

## 图表区域

图表区域是指甘特图的主体部分。它使您能够显示工作和非工作时间，配置图表布局，更改任务栏样式，添加任务摘要，显示网格线，链接/取消链接任务等。您还可以更改布局样式，放大/缩小甘特图，并水平或垂直滚动时间刻度以获得合适的视图。
要配置图表区域及其各种功能，请参阅以下主题：

| **话题** | **描述** |
| --- | --- |
| [Non-Working Time](gcdocsite__documentlink?toc-item-id=e491a9f6-8583-4bb5-acf1-a2d9d69f5204) | 更改甘特图中的非工作时间样式。 |
| [Gridlines](gcdocsite__documentlink?toc-item-id=c259f514-0e22-4b1d-977f-61f2ab9db914) | 更改甘特图中的网格线样式。 |
| [Taskbar Styles](gcdocsite__documentlink?toc-item-id=b44a50aa-6d5e-42f6-a4de-cac536b6d859) | 使用指定的样式规则更改指定任务栏的样式。 |
| [Task Layout](gcdocsite__documentlink?toc-item-id=d4755528-62da-442a-b63d-51c65a8b3e1c) | 配置甘特图布局，包括链接线模式、任务栏高度、日期文本格式以及是否将任务栏舍入为整日。 |
