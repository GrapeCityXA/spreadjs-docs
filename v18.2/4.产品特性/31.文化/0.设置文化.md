# cultureoption

你可以将区域设置设置为“zh-cn”（中文 - 中国）、“ja-jp”（日语 - 日本）或“en-us”（英语 - 美国）。默认的区域设置是英语。
你可以使用区域设置的 HTML `<meta>` 标签 `<meta name="spreadjs culture" content="culture-string"/>` 或者使用全球化变量 `GC.Spread.Common.CultureManager.culture("culture-string")` 来指定区域设置。
全球化的 [CultureManager](gcdocsite__documentlink?toc-item-id=1d75c6d6-9498-4322-bb74-dde3cc8b8ce4#culture) 变量的优先级高于 HTML 标签中的 `culture` 属性。如果设置了多个标签且未设置 `culture` 属性，那么最后一个标签会生效。
日语区域设置选项还要求你在页面中添加 `gc.spread.sheets.resources.ja.x.xx.xxxxx.x.min.js` 资源。韩语区域设置要求你在页面中添加 `gc.spread.sheets.resources.ko.xxx.min.js`。
中文区域标识是“$-804”。你可以设置区域标识来更改区域设置。格式化器支持中文大写数字（DBNum）。中文大写数字包含三种形式，“[DBNum1]”、“[DBNum2]” 和 “DBNum3”。大写数字必须与区域标识一起设置。例如，`[DBNum1][$-804]` 和一个格式字符串。区域标识的优先级高于区域设置名称。
韩语区域标识是 0x0412。你可以使用该标识来更改区域设置（例如：`\[$\-412\]dddd`）。格式化器支持 DBNum1、DBNum2 和 DBNum3（例如：`[DBNum1][$-412]General`）。
区域设置可能会影响单元格的格式化以及用户界面元素，例如筛选器、填充对话框和调整大小的工具提示。包含消息的异常信息和事件也可能会受到区域设置的影响。

以下代码示例使用全球化变量来更改区域设置。

```JavaScript
GC.Spread.Common.CultureManager.culture("ja-jp");
```

以下代码示例使用 HTML `<meta>` 标签中的 `culture` 属性来更改区域设置。

```HTML
<title>SpreadJS 区域设置示例</title>
<meta name="spreadjs culture" content="ja-jp"/>
```

以下代码示例使用 HTML `<meta>` 标签中的 `culture` 属性来更改区域设置并创建一个行筛选器。

```HTML
<!DOCTYPE html>
<html>
<head>
    <title>SpreadJS 区域设置示例</title>
    <!--更改区域设置-->
    <meta name="spreadjs culture" content="ja-jp" />
    <link type="text/css" href="./css/gc.spread.sheets.x.x.x.css" rel="stylesheet" />
    <script type="text/javascript" src="./scripts/gc.spread.sheets.all.x.x.x.min.js"></script>
    <script type="text/javascript" src="./scripts/resources/ja/gc.spread.sheets.resources.ja.x.x.x.min.js"></script> 
    <script type="text/javascript">
        window.onload = function () {     
            //初始化 Spread
            var spread = new GC.Spread.Sheets.Workbook(document.getElementById("sampleDiv"));
            var activeSheet = spread.getActiveSheet();
            var cellrange =new GC.Spread.Sheets.Range(0, 2, 5, 1);
            var hideRowFilter =new GC.Spread.Sheets.Filter.HideRowFilter(cellrange);
            activeSheet.rowFilter(hideRowFilter);
        }
    </script>
</head>
<body>
<div id="sampleDiv" style="width: 600px; height: 400px; border: 1px solid gray">
 </div>
</body>
</html>
```

以下代码示例使用全球化变量来更改单元格 `(0,0)` 的区域设置，并使用区域标识来更改单元格 `(0,1)` 和单元格 `(0,2)` 的格式。

```JavaScript
GC.Spread.Common.CultureManager.culture("zh-cn");
activeSheet.setValue(0,0, new Date("2012/5/8"));
activeSheet.getCell(0,0).formatter("dddd");
activeSheet.setValue(0,1, new Date("2012/5/8"));
activeSheet.getCell(0,1).formatter("[$-804]dddd");
activeSheet.getCell(0,1).formatter(new GC.Spread.Formatter.GeneralFormatter("dddd", "zh-cn"));
activeSheet.setValue(0, 2, 123456789123456000);
activeSheet.getCell(0,2).formatter("[DBNum1][$-804]General");
```
