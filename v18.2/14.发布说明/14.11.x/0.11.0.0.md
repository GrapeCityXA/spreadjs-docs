# rnotesv11




此版本的产品添加了以下特性

- Widget 特性- 添加了使用列缩进的简单轮廓特性.
- 超链接单元格现在支持回调操作
- 超链接单元格现在支持自动换行
- spread添加了hitTest方法.
- 添加了SheetMoved和SheetMoving事件
- 编辑单元格时，现在支持垂直对齐
- 超链接单元格现在可以缩进文本
- 添加了suspendDirty、resumeDirty和isDirtySuspended方法
- 增加了许多新的公式函数
- allowUserDragMerge选项已经添加.
- 添加了dragmerge和dragmerge事件
- 支持了会计格式
- 支持OutlineColumn
- 支持导出PDF
- 支持UMD模式
- 添加了由28个图表类型组成的8个图表类型组还提供了对组合图功能的支持，可以将多个图表类型组合在一起
- 工作簿添加了上下文菜单





# 与前一个版本的变更

此版本的产品有以下变更

- 内置的公式编辑器显示其他颜色
- 现在支持使用引号作为存储字符串的前缀
- NameInfo构造函数有一个附加参数
- addCustomName方法有一个附加参数
- spread模式已经更新
- 工作簿toJSON和fromJSON方法有附加的参数选项
