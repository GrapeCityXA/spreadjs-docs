# 1225

## 重要通知：

自 **19 版本**起，所有 SpreadJS 库将统一发布在新的 [@grapecity-software](https://www.npmjs.com/package/@grapecity-software/spread-sheets) NPM 命名空间下。原有的 [@grapecity](https://www.npmjs.com/package/@grapecity/spread-sheets) 命名空间将不再更新和维护。

>type=info
> **注意：** 所有 @grapecity 包仍会保留在 NPM 上，供旧项目使用，但在 18.2.5 版本后将不再更新或提供技术支持。

**请务必迁移**：如需获得最新功能、修复和技术支持，请将项目依赖从 `@grapecity` 迁移到 `@grapecity-software`，具体步骤请参考：[SpreadJS NPM 包迁移指南](gcdocsite__documentlink?toc-item-id=b37b6fc0-f5cc-4850-87bc-ba22876fd346)。
