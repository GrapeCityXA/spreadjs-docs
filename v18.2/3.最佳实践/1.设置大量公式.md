# SettingLargeAmountsofFormulas

每次用户调用API更改公式时，SpreadJS会自动进行计算，以响应这些修改。如果用户希望一次性整合大量公式更改，但又不想看到中间计算结果，建议使用 [suspendCalcService ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#suspendcalcservice)方法和 [resumeCalcService](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#resumecalcservice) 方法。
suspendCalcService方法将停止计算过程，直到公式设置完成。之后，可以调用resumeCalcService方法恢复计算系统。这两种方法在很大程度上提升了性能，尤其是当用户有大量包含众多公式的工作表时。
参考以下代码示例，使用 **suspendCalcService** 方法和 **resumeCalcService** 方法在工作表中设置大量公式。

```javascript
var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), {
    sheetCount: 1
});
var sheet = spread.getSheet(0);
spread.suspendPaint();
sheet.suspendCalcService(true);
sheet.setRowCount(10000);
sheet.setColumnCount(100);
for (var i = 0; i < 10000; i++) {
    for (var j = 0; j < 100; j++) {
        sheet.setFormula(i, j, "DATE(2019,3,11)", GC.Spread.Sheets.SheetArea.viewport);
        sheet.getCell(i, j).formatter("yyyy/mm/dd");
        sheet.setColumnWidth(j, 80.0, GC.Spread.Sheets.SheetArea.viewport);
    }
}
sheet.resumeCalcService(false);
spread.resumePaint();
```
