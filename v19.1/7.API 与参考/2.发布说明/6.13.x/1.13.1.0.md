# releasenotesv131




此版本的产品添加了以下功能。

- [图表系列线型](https://www.grapecity.com/spreadjs/docs/v13/online/ConfiguringSeries)现已支持，允许用户自定义图表中数据系列的线型。
- 在迷你图上提供了各种详细的渲染选项。[子弹图](https://www.grapecity.com/spreadjs/docs/v13/online/sparkbullet),[横向条状迷你图](https://www.grapecity.com/spreadjs/docs/v13/online/sparkhbar),[竖向条状迷你图](https://www.grapecity.com/spreadjs/docs/v13/online/sparkvbar)以及[阶梯瀑布迷你图](https://www.grapecity.com/spreadjs/docs/v13/online/sparkpareto)可以使用这些附加选项进行自定义。
- 可以使用[选择多个工作表](https://www.grapecity.com/spreadjs/docs/v13/online/select_multiple_worksheets)并应用隐藏或删除操作。
- [超链接](https://www.grapecity.com/spreadjs/docs/v13/online/hyperlink_cells)可以链接网页上的任何相关信息、工作簿中的任何区域，甚至发送电子邮件。
- [选择多个列表项](https://www.grapecity.com/spreadjs/docs/v13/online/cell-dropdowns)已支持，允许用户从下拉列表中选择多个选项。
- [单元格百分比格式](https://www.grapecity.com/spreadjs/docs/v13/online/percentage-format-in-cells)支持自动添加百分比格式的%登录单元格，就像Excel那样。
- PDF文件现在可以从中的表单导出[黑白样式](https://www.grapecity.com/spreadjs/docs/v13/online/CustomPDFExport)。
- [自定义排序](https://www.grapecity.com/spreadjs/docs/v13/online/custom-sorting)允许用户根据自己的定制需求对数据进行排序，例如根据软件版本或服装尺寸等进行排序。
- 现在可以使用[ShowFormulas属性](https://www.grapecity.com/spreadjs/docs/v13/online/show_cell_formulas)查看单元格中的公式。使用该属性，用户可以从SpreadJS查看公式，也可以将公式复制到剪贴板。
- [AutoSum 函数](https://www.grapecity.com/spreadjs/docs/v13/online/autosum_functions)在设计器现在支持自动计算要应用它的单元格范围，就像Excel那样。
- [RangeChanged 事件](gcdocsite__documentlink?toc-item-id=8579217b-549b-41f7-aa4f-f0e21c37872e#RangeChanged_EV)在SpreadJSAPI中提供，当在表上执行删除、拖放或粘贴操作时，将触发该API。
- [表格的自动扩展](https://www.grapecity.com/spreadjs/docs/v13/online/auto_expand_tables)支持允许用户启用或禁用表扩展。
- 操作[插入剪切或复制的单元格](https://www.grapecity.com/spreadjs/docs/v13/online/insert-cut-or-copied-cells)已支持，允许用户使用上下文菜单插入剪切/复制的单元格。
- [脏数据状态](https://www.grapecity.com/spreadjs/docs/v13/online/cell-states)支持在单元格值更改时将其状态更改为“脏”的。使用脏单元格状态，用户可以在单元格的状态变为脏时设置单元格上的任何样式，这有助于保持对更改的简单跟踪。
- [格式字符串](https://www.grapecity.com/spreadjs/docs/v13/online/format_string)已支持，允许用户同时设置单元格中的值和公式。使用此功能，用户可以将数字值显示为文字、设置长显示字符串的格式等等。
- [像素滚动](https://www.grapecity.com/spreadjs/docs/v13/online/scroll-by-pixel)现在支持使用，用户可以遍历到包含大量数据的表单中包含所需数据的特定视图或单元格。
- [图表隐藏行和列设置](https://www.grapecity.com/spreadjs/docs/v13/online/hidden_rows_columns_chart)允许用户选择是否在图表中显示隐藏行或隐藏列的数据。
- [单元格溢出的省略号或提示](https://www.grapecity.com/spreadjs/docs/v13/online/ellipsis_tips_cell_overflow)支持在单元格内容大于列宽时显示省略号。另外，当带省略号的单元格悬停在上面时，将显示提示，以显示单元格的完整内容。
- [日期轴](https://www.grapecity.com/spreadjs/docs/v13/online/ConfiguringAxes)在图表中受支持，该图表允许用户通过将其配置为日期（时间刻度）轴来配置类别轴上的日期。
- [具有属性公式的数据驱动形状](https://www.grapecity.com/spreadjs/docs/v13/online/AddingShapeswithFormulas)已支持，允许用户创建动态形状，其属性通过工作表、其他形状或数据源中定义的表达式进行计算。
- SpreadJS 支持 [$-ja-JP-x-gannen] 格式显示[Japanese era "元"](https://www.grapecity.com/spreadjs/docs/v13/online/eraformat).
- [图表显示 #N/A 单元格作为空单元格](https://www.grapecity.com/spreadjs/docs/v13/online/display_na_cells_chart)已支持。
- [TableRowsChanged](gcdocsite__documentlink?toc-item-id=8579217b-549b-41f7-aa4f-f0e21c37872e#TableRowsChanged_EV)与[TableColumnsChanged](gcdocsite__documentlink?toc-item-id=8579217b-549b-41f7-aa4f-f0e21c37872e#TableColumnsChanged_EV)事件在SpreadJS api中提供处理表行或列的添加或删除操作，并增加了对撤消操作的支持。
- 在通过SpreadJS导入或导出时，文件的文档属性现在被保留。
- 在SpreadJS中添加了兼容标志，使计算结果与Excel相匹配。
- 韩国文化支持DBNum4格式化模式，它会自动将数字更改为韩文数字。
- SpreadJS Designer现在支持筛选对话框中的“将当前选择添加到筛选”。
- 按需计算选项现在在SpreadJS Designer中可用，以增强计算过程。
- SpreadJS 设计器支持macOS Catalina。
- Vue示例已更新到最新的CLI 3。
- 支持最新版本的React。
