# 191

## 相较于上个版本的功能增强
### 设计器功能优化
* **[模板配置与默认模板](gcdocsite__documentlink?toc-item-id=2534a045-5a71-4537-b893-1546dd4cf3af)**：设计器现已支持在初始化或重置时加载默认模板，便于团队依托预设的样式、配置与表格结构新建工作簿，无需重复配置相同参数。
* **[函数插入对话框新增检索功能](gcdocsite__documentlink?toc-item-id=6d1b20e2-2d9b-46e0-94f0-58e18a6a3313)**：用户可在插入函数弹窗中通过关键词检索函数，在海量函数库中选用公式、或帮助零基础制表人员快速匹配所需函数。
* **[VS Code插件版SpreadJS XLSX编辑器](gcdocsite__documentlink?toc-item-id=47333dfc-1f31-4d07-99ca-d160fa0bea7a)**：SpreadJS设计器现已推出VS Code编辑器插件，开发者可在常规开发流程中直接打开、编辑`.sjs`、`.ssjson`、`.xlsx`、`.xlsm`、`.xltm`、`.xltx`以及`.csv`格式文件。
* **[设计器支持DataObject单元格类型配置](gcdocsite__documentlink?toc-item-id=4aed90c5-3d22-4758-bebf-1d88f8b77a69)**：用户可在设计器可视化界面配置DataObject单元格类型，搭建基于对象或JSON数据的单元格展示方案时，不必切换至代码编辑环境。
* **[桌面端设计器适配苹果芯片](gcdocsite__documentlink?toc-item-id=b7ea1685-97d3-4713-86d4-5e9d4acc1621)**：macOS桌面版设计器现已全面兼容苹果M系列处理器设备，优化运行性能，规避在新款Mac设备上运行老旧英特尔架构安装包带来的卡顿问题。

### 公式模块
* **[计算工作线程支持自定义函数](gcdocsite__documentlink?toc-item-id=5b81b0d2-14ee-45d6-adca-603ae36d82e4)**：自定义函数可在计算工作线程中运行，依托自定义业务逻辑的重度计算类应用能够将大量运算移出UI主线程，保障流畅的编辑体验。
* **数值与数组转文本函数**：新增[VALUETOTEXT](gcdocsite__documentlink?toc-item-id=14847f1a-4d9f-4322-8e3c-caaf2dfa1d3a)和[ARRAYTOTEXT](gcdocsite__documentlink?toc-item-id=17d5f4fb-72e2-414a-a92a-fa0f53a0c19f)函数，轻松将单个数值、数组数据转为文本格式，提升与新版Excel工作簿逻辑的兼容性。

### 条件格式
* **[前N%/后N%规则](gcdocsite__documentlink?toc-item-id=bb44c6c4-9a11-4a69-86b4-1bb15fe25fe4)**：基于百分比的靠前/靠后排名条件格式规则的运行逻辑对齐Excel，导入或重构已有工作簿时，可完整保留数据排名高亮规则。
* **[条件格式支持迷你图规则](gcdocsite__documentlink?toc-item-id=b03e5a40-1a0e-4acd-ae0f-67f29ec320c7)**：可通过条件格式直接生成迷你图样式可视化效果，无需额外编写公式，快速制作棒棒糖图、仪表盘、子弹图、差异对比图等精简关键指标看板。

### 单元格格式设置
* **[会计专用单下划线与双下划线](gcdocsite__documentlink?toc-item-id=53ffb2db-0f5e-4461-a469-06f928dd035f)**：新增Excel同款会计下划线样式，在财务报表中设置合计项、报表版式时，可贴合通用表格规范。
* **[单元格内嵌图片](gcdocsite__documentlink?toc-item-id=e7bef472-15f7-4893-8c72-e117b397216a)**：图片可作为单元格存储值，不再是悬浮浮动对象，便于对图片类数据执行排序、筛选、检索、引用，适配Excel兼容的业务流程。
* **[命名单元格模板](gcdocsite__documentlink?toc-item-id=29be3304-20c0-4f6c-bf5e-fae2b10a924e)**：新增命名单元格模板功能，用户可将单元格样式、数据校验、条件格式、单元格状态打包为可复用的工作簿级模板，批量套用至多个单元格区域。

### 模拟分析
* **[支持模拟分析数据表](gcdocsite__documentlink?toc-item-id=67b67fb5-16fb-4c52-915c-3eab304be07a)**：产品现已兼容Excel风格的模拟分析数据表，用户可直接在工作表内开展单变量、双变量情景测算，不用手动搭建模拟测算表格。
* **[支持模拟分析单变量求解](gcdocsite__documentlink?toc-item-id=3fb551c9-5e6c-4a66-8972-3f31fa7f0395)**：优化单变量求解功能，新增迭代次数管控、运算进度相关配置，更适用于预算编制、数据预测、目标值核算等业务场景。

### 导入导出
* **[支持XLTX文件格式](gcdocsite__documentlink?toc-item-id=9232fe6c-84ce-4d92-bff1-7921a5365506)**：支持`.xltx`模板文件的导入与导出，团队可在浏览器端与设计器流程中复用Excel模板文件。
* **[导出Excel时将扩展迷你图转为图片](gcdocsite__documentlink?toc-item-id=df415171-6213-4973-a307-ed986b8b0ad2)**：条形码、各类扩展迷你图可在导出Excel时保存为图片，即便Excel原生不支持对应公式类型，表格可视化内容也能完整留存。

### 数据管理器
* **[请求头可视化配置界面](gcdocsite__documentlink?toc-item-id=58637f3c-e668-4a9b-a307-91f2411fbeef#request-headers)**：设计器提供可视化面板配置接口请求头，方便对接需要身份鉴权、自定义请求头的安全接口，快速搭建绑定数据源的表格方案。
* **[数据源面板优化](gcdocsite__documentlink?toc-item-id=5e456b1f-99ba-42bb-ae5d-95a6506d68d3)**：重构数据管理器的可视化配置界面，数据源配置与预览流程更清晰，降低用户绑定、校验数据源的操作门槛。
* **[SJS文件内嵌JSON数据源配置](gcdocsite__documentlink?toc-item-id=58637f3c-e668-4a9b-a307-91f2411fbeef)**：数据管理器的JSON配置可更整洁地封装在`.sjs`文件内部，提升文件便携性，为后续嵌入更多资源文件拓展能力。

### 表格视图
* **[支持多列排序](gcdocsite__documentlink?toc-item-id=2276aff6-b5d6-47ec-81f1-6cafe2386676)**：表格视图现已支持多字段组合排序，配套清晰的控件与排序标识，新增排序条件时不会覆盖已设置的排序层级。
* **[多列批量套用列样式](gcdocsite__documentlink?toc-item-id=f0b2bf14-d1f4-4595-b26f-48b63d62eb78)**：批量选中多列表格列后，可一次性统一修改样式，大幅提升超大宽幅数据表的批量排版效率。
* **[表格视图空值自定义展示](gcdocsite__documentlink?toc-item-id=f7fbe7c6-c46b-4801-bc2c-9e23cb481283)**：自定义格式化器可智能处理空值与空白字符串，开发者无需新增自定义单元格类型，即可配置N/A、--、空白等占位展示内容。

### 数据透视表
* **[自动生成Excel式日期分组](gcdocsite__documentlink?toc-item-id=2243a886-847b-4ada-ae70-eac8cfd46d3d)**：透视表可自动对日期字段分组，用户无需手动设置，即可将原始交易日期按年、季度、月份汇总分析。
* **[透视面板新增字段检索框](gcdocsite__documentlink?toc-item-id=8708bbd5-c07d-408c-8ea6-f856b355b826)**：透视字段面板搭载Excel同款搜索框，处理海量源数据时能够快速定位所需字段。
* **[透视表兼容单元格内嵌图片数据源](gcdocsite__documentlink?toc-item-id=e7bef472-15f7-4893-8c72-e117b397216a#type-participation)**：透视表支持引用单元格图片作为源数据，便于制作产品目录、SKU数据看板、可视化汇总报表。

### 协同服务端
* **[适配表格视图与数据管理器协同编辑](gcdocsite__documentlink?toc-item-id=1d277aa3-6942-4b04-962e-d288cd982a16)**：协同服务支持表格视图、数据管理器配置项多人协同编辑，多名用户可共同编辑复杂数据视图并同步表格结构与参数。
* **[数据管理器支持本地数据源协同](gcdocsite__documentlink?toc-item-id=0123e95e-783d-475c-9caa-f8ae72cc8459)**：协同编辑拓展支持数据管理器本地数据源，团队可共同编辑海量本地数据集与层级视图，不再局限于远程数据源。

### 数据图表
* **[图表支持层级分类轴](gcdocsite__documentlink?toc-item-id=33cc65bd-869c-430b-9223-e86966d31a68#%E7%AC%AC%E5%85%AD%E6%AD%A5-%E5%B1%82%E7%BA%A7%E5%88%86%E7%B1%BB%E7%BB%91%E5%AE%9A)**：直角坐标系图表支持多级分类维度，轻松实现年份→季度→月份、大区→国家→城市这类层级数据可视化。
* **[树形图标题配置项](gcdocsite__documentlink?toc-item-id=2eb22520-9e87-402c-97e6-eba69bf447ef)**：树形图开放标题显示精细化配置，按需调整标签显隐程度，优化层级数据展示效果。
* **[折线、面积、雷达图扩充线条样式配置项](gcdocsite__documentlink?toc-item-id=d8e4eaf5-fcad-4dcb-810f-851c1d647863#%E7%BA%BF%E6%9D%A1%E6%A0%B7%E5%BC%8F%E7%B1%BB%E5%9E%8B)**：新增更多`LineAspect`线条样式参数，绘图人员可精细化控制各类图表的折线形态与趋势展示效果。
* **[多字段数值映射](gcdocsite__documentlink?toc-item-id=33cc65bd-869c-430b-9223-e86966d31a68#%E5%A4%9A%E5%AD%97%E6%AE%B5%E6%95%B0%E5%80%BC%E7%BC%96%E7%A0%81)**：图表可引用多个字段作为数值数据源，适用于财务统计、区间分析、多指标对比等绘图场景。

### 甘特视图
* **[甘特视图可视化搭建体验优化](gcdocsite__documentlink?toc-item-id=b5c1d40e-794c-4643-8268-b995675ae71e)**：精简甘特视图配置流程，用户可在统一界面完成字段映射、层级配置、时间轴规则设置，操作逻辑更直观。
* **[甘特视图适配表格主题](gcdocsite__documentlink?toc-item-id=44b9bbc6-62a3-4592-bf71-0202426b23e9)**：表格、时间刻度、图表区域统一沿用表格主题样式，保障甘特视图和整本工作簿视觉风格统一。
* **[表格与图表区域分割拖拽条](gcdocsite__documentlink?toc-item-id=f8f9f4b8-0a56-4d85-b9c4-e9ee687565c5)**：新增分隔拖拽控件，自由缩放甘特图表格区与图表区尺寸，解决任务详情和时间轴版面挤占问题。
* **[仅展示项目周期时间轴](gcdocsite__documentlink?toc-item-id=810f357e-acd5-4bda-8b5d-dde4aa6458a9)**：甘特图时间轴可自适应项目起止日期，剔除多余空白时段，方便浏览超长项目排期。

### 界面与交互优化
* **[滚动条自动显隐](gcdocsite__documentlink?toc-item-id=865a86b1-a47e-4a17-9197-5846fff5d1b4)**：内容完整适配可视区域时滚动条自动隐藏，内容溢出时自动显示，嵌入式表格、数据看板界面更整洁，同时保留滚动交互能力。
* **[Excel风格复选框](gcdocsite__documentlink?toc-item-id=9e090ad4-9713-474d-84e1-a93e33599491)**：搭载新版Excel同款复选框组件，导入外部表格时完整保留原生布尔交互控件样式。
* **[批注禁用@提及功能](gcdocsite__documentlink?toc-item-id=0b56f33f-0ad4-488f-833f-7edb23b81832)**：串行批注可关闭@人员提醒功能，适用于无统一协作人员目录、无需@提醒的部署环境，避免界面冗余。
* **[手绘插入形状](gcdocsite__documentlink?toc-item-id=1771b950-7f0e-4ea5-ae7b-deb34f39ed8c)**：开启绘图模式后可直接在表格手绘生成形状，精准插入图形，操作体验贴近Excel。
* **[弧形连接线形状](gcdocsite__documentlink?toc-item-id=f2edc0db-80e8-45dc-bf0f-4917974638bd)**：新增弧形连接线，制作流程图时可选用更顺滑的连线样式。
* **[连接点交互优化](gcdocsite__documentlink?toc-item-id=f2edc0db-80e8-45dc-bf0f-4917974638bd#connector-interaction-and-snapping-behavior)**：绘制流程图、关联图形时，吸附点位提示、连线状态标识、连线路径预览效果优化，图形连线操作更便捷。

* 修复部分图表渲染效果和Excel展示不一致的问题。
* 解决特定场景下趋势线超出图表边界的异常。

* 修复对象、数组类型列无法正常解析JSON字符串数据的问题。
* 优化重复项剔除功能，同一选区重复执行去重时空白单元格处理异常。
* 解决表格视图选用「向后新增行」、层级重算后新增行排版错位故障。
* 修复删除表格最后一列后，表格设计标签页残留显示、切换焦点才消失的问题。
* 统一表格视图行操作图标尺寸配置与接口规范。

### 界面交互
* 修复拆分列操作不会标记工作簿已修改的问题。
* 优化部分缩放比例下`scrollbarShowMax`、`scrollbarMaxAlign`配置不生效故障。
* 修复启用状态规则+表头拖拽时，双击表头行列高亮错误问题。
