## 修复问题

* 修复无法正常导入特定 xlsx（含 WPS 生成的异常结构导致控制台报错/导入失败）的问题
* 修复导出“带图片的透视表”到 Excel 后打开报错的问题
* 修复透视表移动后表现异常的问题（对齐 Excel 行为）
* 修复在英文语言环境（Culture）下导入/打开文件报错的问题
* 修复 ReportSheet 中 `HYPERLINK()` 拼接单元格引用后跳转丢失参数的问题
* 修复 Designer 页眉设置 11 号字号会被重置/无效的问题
* 修复包含 ReportSheet 的多选 Tab 场景下右键导致选中状态异常的问题
* 修复 `preserveUnsupportedChart` 保留箱线图后导出到 Excel 前后显示存在差异的问题
* 修复了包含 ChartEx（现代图表类型）的 Excel 文件经 SpreadJS 导入再导出后，在 GcExcel 或 Microsoft Excel 中打开时出现无效公式错误的问题。
* 修复了当 ChartEx 引用版本化定义名称（`_xlchart.v1.N`）时，瀑布图在 SpreadJS 中渲染不正确的问题。
* 修复了应用"跨列居中"对齐后，会计下划线仅显示在第一个单元格下方的问题。
* 修复了通过名称框（Name Box）导航到命名区域时，`SelectionChanged` 事件未被触发的问题。
* 修复了工作表保护同时阻止了代码级排序操作的问题。
* 修正了"Export SparklineEx To Image"示例中使用 `save` 方法导出 Excel 文件的错误，应使用 `export` 方法。
