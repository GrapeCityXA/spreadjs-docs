# 1913

## 修复问题

- 修复了禁用 `includeStyles` 导出 XLSX 时生成文件损坏、Excel 无法打开的问题。
- 修复了 TableSheet 或 GanttSheet 工作表名称以数字开头时导出 Excel 失败的问题。
- 修复了使用结构化表引用作为数据验证来源时，导出 Excel 后验证规则被移除的问题。
- 修复了导入包含散点图的 Excel 文件后，图表图例位置和布局发生变化的问题。
- 修复了部分 Excel 文件导入后图表无法正常渲染的问题。
- 修复了导入特定 Excel 文件后饼图图例不显示的问题。
- 修复了富文本对话框未正确使用工作簿主题正文字体的问题。
- 修复了 `DATEVALUE` / `TIMEVALUE` 对部分日期字符串解析结果与 Excel 不一致的问题。
- 改善了较大文件中批量删除多个工作表时的性能表现，降低浏览器超时风险。
- 更新了 SpreadJS 协同的相关依赖，修复 `npm audit` 报告的高危安全漏洞。
- 修复了 Designer 中剪切列后重新插入，导致 Table 绑定的 `dataField` 信息丢失的问题。
- 修复了 Designer 名称管理器中排序功能无效的问题，现在支持正确的升序和降序排序。
- 修复了 `SUM` 公式计算结果与 Excel 不一致的问题。
- 修复了 ReportSheet 打印预览或打印时 Checkbox 位置错位的问题。
- 修复了复制包含透视表的 Sheet 页后页面空白或无法操作的问题。
- 修复了导入 Excel 后形状内文字丢失以及照相机内容丢失的问题。
- 修复了导入部分有效 `.xlsx` 文件时误报“文件格式错误”的问题。
