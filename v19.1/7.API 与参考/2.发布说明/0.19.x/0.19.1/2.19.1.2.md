# 1912

## 修复问题
* 修复了瀑布图引用版本化定义名称（如 _xlchart.v1.N）时渲染错误的问题，使行为更贴近 Excel 的规范化处理，确保合计/小计正确渲染。
* 通过名称框选择命名区域时，现在能正确触发 SelectionChanged 事件，提升了依赖选区事件的集成功能的可靠性。
* 保护设置现在仅限制 UI 操作，同时允许代码级操作（如 VBA 驱动的排序），与 Excel 行为保持一致。
* 解决了 SpreadJS 往返处理 XLSX 文件后，Excel/DsExcel 报告"无效公式/导入错误"的问题。
* 会计下划线现在能跨越整个居中选区范围（而非仅第一个单元格），与 Excel 渲染效果一致。
* 修复了从 Designer Runtime 导出 Schema 时产生 undefined 且 Schema 加载失败的问题
* 修复了通过选中单元格输入的公式，无法全选删除的问题。
* 修复了开启 calcOnDemand 后滚动页面出现渲染错误的问题。
* 修复了开启 ExcelCompatibleCalcMode 后公式计算结果反而与 Excel 不一致的问题。
* 修复了状态栏合计值精度不符合预期的问题。
* 修复了公式/数组元数据损坏（arrayInfo colCount 变为 0）导致下游 JSON 解析（如 GcExcel fromJSON）失败的问题。
* 修复了使用 IMAGE 函数后导出文件图片渲染丢失的问题。
* 修复了页面布局设置标题行导出 SJS 文件再导入后标题行为空的问题。
* 修复了引入 calcWorker 资源后打开文件报错的问题（包括涉及 suspendCalcService() 的场景）。
* 修复了第二次添加数据绑定组合框时无法跳转到其他 Sheet 的问题。
* 修复了分页预览线位置与 Excel、WPS 不一致的问题，使预览线与实际打印输出对齐。
* 修复了自定义页面纸张尺寸后打印预览无内容的问题。
