# 1914

## 修复问题

* 修复了大数据量表格中执行数据筛选后，单元格编辑、导航等操作出现严重卡顿的性能问题。
* 修复了数据透视表排序变更导致 Excel 文件导出时报错的问题；同时修复了撤销编辑后公式未重新计算的异常。
* 修复了协同模块 ESM 环境下 OpType、OpModule、SelectionMode 等枚举无法命名导入的问题。
* 修复了协作只读模式下，Designer 后台 "返回" 按钮无响应、无法退回表格视图的问题。
* 修正了筛选对话框示例代码中条件格式日期参数的写法，确保导出 Excel 后规则正常生效。
* 修复了 API 文档中 ValidationError 事件格式错误及 UserMentioning 事件示例代码有误的问题。

## 新增功能

* 新增 commitInput 内置命令，按下绑定快捷键后仅提交当前单元格编辑内容并退出编辑模式，不自动跳转至下一单元格。
* 新增 API 支持自定义触摸设备上单元格选择指示器的尺寸，提升平板等触屏设备的操作精准度。
* ReportSheet 新增 ReportStart / ReportEnd 事件，支持在报表生成过程中展示加载提示或占位内容。
* 补充了 Designer 类型定义文件中缺失的 IProtectionOptions 及相关保护选项类型。
* SpreadJS 运行时及 Designer 组件现已支持 Angular 22。

## 文档与示例

* 新增 Designer Ribbon 在 Next.js 和 Nuxt.js 框架中的集成使用说明文档。
* 移除了 Angular 在线示例项目中不必要的 core-js 依赖。
