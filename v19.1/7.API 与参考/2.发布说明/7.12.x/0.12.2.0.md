# rnotesv122




此版本产品包含以下特性和改进

- [显示打印预览线](https://help.grapecity.com/spread/SpreadSheets12/webframe#DisplayPreviewLineforPrint.html)- 现在，用户可以像在Excel中一样在视窗区域中显示打印行指示器使用它，用户可以快速获得所需的表单数据是否将打印在正确的页面上的信息
- [获取页面信息](https://help.grapecity.com/spread/SpreadSheets12/webframe#GetPageInformation.html)- 用户可以在打印表单数据的同时获取页面的行数、列数、行号、列号等信息
- [打印背景图像作为水印](https://help.grapecity.com/spread/SpreadSheets12/webframe#PrintBackgroundImageAsWatermark.html)- 用户可以打印任何他们选择的背景图像作为水印
- [使用CalcEngine语言包](https://help.grapecity.com/spread/SpreadSheets12/webframe#AvailableCalcEngineLanguagePackagesForSpreadJS.html)- SpreadJS现在支持18种语言本地化函数名，表函数名，CalcError名，特殊函数逻辑和布尔值资源这允许用户使用他们的区域语言语法输入公式
- [使用自定义语言包](https://help.grapecity.com/spread/SpreadSheets12/webframe#CreatingandUsingaCustomLanguagePackage.html)- SpreadJS现在支持全球化和自定义本地化用户现在可以创建他们自己的自定义语言包，以他们喜欢的语言显示文本
- [单元格文本自带换行](https://help.grapecity.com/spread/SpreadSheets12/webframe#WrapTextInCell.html)- 用户可以通过在单元格中文本换行(包含空格或连字符)来在单个单元格中显示较多的内容
- [配置数据标记](https://help.grapecity.com/spread/SpreadSheets12/webframe#ConfiguringDataMarkers.html)- 在使用折线图和雷达图时，用户可以使用本版本中引入的新图表符号来变更默认数据标记该特性帮助用户更有效地区分信息和可视化数据
- [拖拽填充增强](https://help.grapecity.com/spread/SpreadSheets12/webframe#AutoFillData.html)- 拖动填充行为已经增强，支持高级的自动填充操作，如拖动和填充第一天，最后一天或同一天的一个月;在开始或结束处包含数字的填充字符串，以及用出现在自定义列表中的数据填充单元格
- JavaScript框架增强 - 对于Angular框架中的表单元素，React框架中的表格元素，以及Vue框架中的gc-spread-sheets元素;还支持其他一些选项



# 解决的问题

自上次发布以来，以下问题已得到解决

- 用户导入Excel文件后，形状的位置保持不变[269623].
- 在调用suspendCalcService()方法后导入Excel文件和删除表单时不会抛出错误 [273226]
- 在导入Excel文件的过程中，使用SpreadJS处理Angular框架不会抛出异常 [273487]
- 在使用数据验证时，Spread JS V10和V11之间没有兼容性问题 [272750]
- ROUND函数特定值的舍入计算正确 [273684]
- 修复了在控制台切换页面抛出的问题[273273]
- 在Excel中导入附件时不会抛出错误 [273544]
- 在IE11中将数据从Excel复制粘贴到SpreadJS时，单元格中不会出现空格[SJS-728]
- 在使用迁移文件时，如果highlightInvalidData选项被设置为true，则不会引发异常[SJS-668]
