# rnotesv141




此版本的产品包含以下功能和增强功能。

- 用户可以在图表中设置[轴数据标签的位置](ConfiguringAxes#i-heading-set-axis-label-position)。
- [使用对齐、分布和捕捉选项排列形状](gcdocsite__documentlink?toc-item-id=7d73cf88-bfa3-468d-84c4-adb1df1e01d8)- 用户可以对齐多个形状，分布它们，并将它们捕捉到其他形状或网格。
- [TrailingRow数据行后没有空格](gcdocsite__documentlink?toc-item-id=490a20b9-e42f-4084-96b5-c7019b9a80c8)- 用户可以指定是否在工作表中冻结尾随行或列，或同时冻结两者。
- [设置撤消和重做操作的数量限制](gcdocsite__documentlink?toc-item-id=aae5f324-a1b4-489e-ba55-5ed236a416b4)- 用户可以获得undo和redo堆栈，还可以设置undo和redo操作的数量限制。
- [更改标签带的位置和宽度](gcdocsite__documentlink?toc-item-id=ca743d24-50e8-45b7-b06a-dd5d0500d8b1)-用户可以设置标签带相对于工作簿的位置并更改标签带的宽度。
- [粘贴或跳过不可见范围内的数据](gcdocsite__documentlink?toc-item-id=d1e70e97-78b0-49c3-8fdd-bde194c4b3db)-用户现在可以控制是否将数据粘贴到不可见范围内。
- [支持以可自定义的日期格式导入Excel文件](gcdocsite__documentlink?toc-item-id=720d26df-a16e-4c2d-b38f-78357eff8120)-用户现在可以在导入Excel文件时根据系统区域设置自定义日期格式。
- SpreadJS supports[WEBSERVICE](gcdocsite__documentlink?toc-item-id=582e76fb-72a1-4065-8356-4d6378161a95)可以从Internet或Intranet上的web服务获取数据。
- SpreadJS supports[FILTERJSON](gcdocsite__documentlink?toc-item-id=46bba4aa-2cd0-40bc-b77e-fec703170f7b)函数，解析JSON字符串中的数据。
- [图片迷你图](gcdocsite__documentlink?toc-item-id=79e151b4-ec7a-4c67-9025-7262383368d8)- 用户现在可以使用图像迷你图功能将图像放置在单元格中。
- SpreadJS现在支持增强[复选框列表](gcdocsite__documentlink?toc-item-id=e81f7812-0377-4f86-938f-cb5e68e7a516),[单选按钮列表](gcdocsite__documentlink?toc-item-id=76239ed6-71ae-4ae1-a29a-c286e05c0a5a), 以及[复选框](gcdocsite__documentlink?toc-item-id=9e090ad4-9713-474d-84e1-a93e33599491)的尺寸。
- 用户可以[设置图表轴的方向](ConfiguringAxes#i-heading-set-axis-orientation)。
- 用户可以[更改单元格按钮的悬停背景色](gcdocsite__documentlink?toc-item-id=808e0528-47b0-4847-814b-932d1b98f6bd)当它可见或启用时。
- 用户可以创建[直方图迷你图](gcdocsite__documentlink?toc-item-id=c3602a0a-a1ce-4273-97b8-ab2567e07ce7)表示数据集的频率分布。
- 用户可以创建[仪表KPI迷你图](gcdocsite__documentlink?toc-item-id=5d167224-3073-4af5-90db-ed6c0c5e8b27)可视化有关KPI值的指标性能。
- 用户现在可以添加[数据透视表](gcdocsite__documentlink?toc-item-id=e92957b1-ad81-459d-89c1-7c638af239aa)并在SpreadJS中执行各种与pivot相关的操作。
- 用户可以使用[填充效果](gcdocsite__documentlink?toc-item-id=4a27b5aa-402a-41db-88a2-f665d43de126)例如形状中的实体填充、渐变填充、图片填充和纹理填充。
- [形状超链接](gcdocsite__documentlink?toc-item-id=54a77bba-e42a-470d-8493-c9f4dd49f5a2)- 用户可以在形状、连接器形状或组形状上添加超链接。
- [相机形状](gcdocsite__documentlink?toc-item-id=e53e0d49-f0cf-4742-bf34-aa8eab529b58)- 用户可以在表单中添加被引用区域的动态图像。
- 用户可以添加和[编辑形状中的文本](gcdocsite__documentlink?toc-item-id=43b79fd0-a4c3-4c5d-b5bf-5a6624b690a4)。
- 用户现在可以添加[不同类型的复合线](gcdocsite__documentlink?toc-item-id=e3b02cea-ae0f-401f-8803-49264c88a7ae)以定制其外观。

# 重大变更

在产品的最后一次发布之前，已经引入了以下重大的更改。

- [LET函数](“LET”)的name参数不应包含"."。所有使用LET function且变量名中包含“.”的先前存在的Excel和ssjson文件都将自动升级为有效的变量名。SpreadJS将"."转换为"\u"，再转换为；匹配更新的Excel行为。
