# 1718

### 发布说明 - Spread JS - v17.1.8

#### Bug 修复

* **SJS-24718** 在 V17 中，`Image` 公式被重复渲染。
* **SJS-26089** 图表的横轴日期显示不正确。
* **SJS-26190** `AVERAGEIFS` 计算结果为 `#DIV/0`。
* **SJS-26415** 通过命令设置单元格类型的问题。
* **SJS-26472** `TreeMap` 无法从其他工作表中选择数据源。
* **SJS-26486** 日期加操作产生错误。
* **SJS-26624** 在分组列单元格中，文本自动换行不起作用。
* **SJS-26639** SpreadJS 和 Excel 中 `GETPIVOTDATA` 函数结果不一致。
* **SJS-26641** 导入 Excel 文件后更改区域设置导致浏览器卡死。
* **SJS-26674** 隐藏的工作表在超链接对话框中显示问题。
* **SJS-26676** 在工作簿未聚焦时点击表格调整句柄会抛出错误。
* **SJS-26678** 导出到 Excel 后，取消隐藏的分组形状显示不正确。
* **SJS-26680** 使用自定义单元格后删除列时出现错误。
* **SJS-26682** 当复选框的文本和值均为 "-" 时，选中后会出现错误。
* **SJS-26715** 表格重新绑定后，引用的公式未自动计算。
* **SJS-26724** 当工作簿在隐藏的 `iframe` 中时，导出 PDF 会抛出异常。
* **SJS-26733** 包含报表的工作簿在复制和导出时出错。
* **SJS-26741** `Camera` 形状无法正确复制格式设置中的字体颜色。
* **SJS-26742** 当 `Promise.reject` 返回给 `TableSheet` 时，控制台窗口显示错误。
* **SJS-26743** `GanttSheet` 在错误的行标题中显示错误标记 "!"。
* **SJS-26744** 数组公式不计算。
* **SJS-26867** 文件导入后，`ReportSheet` 切换到分页模式时出现错误。
* **SJS-26873** 二维码生成无效。
* **SJS-26874** 导出到 Excel 后筛选器消失。
* **SJS-26921** 导入 JSON 后数据验证丢失。
* **SJS-26931** `ReportSheet` 中的隐藏列可见。
