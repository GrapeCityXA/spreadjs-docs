# rnotesv10




此版本的产品添加了以下特性

- Widget 特性- 添加了客户端Excel导入和导出
- 为水印添加了单元格填充
- 公式文本框控件现在支持选择多个范围
- 复制和粘贴得到了改进
- 增加Month迷你图
- 增加Year迷你图
- 已经为remove方法添加了TableRemoveOptions枚举
- allowCopyPasteExcelStyle和allowExtendPasteRange属性已添加到工作簿选项中
- copyPasteHeaderOptions属性已添加到工作簿选项中
- 附加参数已添加到ClipboardChanging、ClipboardChanged、ClipboardPasting和clipboardpaste事件中
- 已经添加了AsyncFunctionEvaluateMode类
- 添加了REFRESH公式功能
- 为向后兼容性添加了一个迁移文件





# 与前一个版本的变更

此版本的产品有以下变更

- 更新命名空间
- 剪贴板粘贴命令中的fromRange选项已变更为fromRanges
