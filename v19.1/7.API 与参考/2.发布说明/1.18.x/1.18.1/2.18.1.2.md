## 已解决的问题

* SJS-16309: 修复了 setDataSource 方法耗时过长的问题。
* SJS-18396: 修复了调用 setDataSource 方法后，SpreadJS 自定义异步函数触发执行两次的问题。
* SJS-24041: 修复了第一个工作表中的公式计算影响第二个工作表表格绑定速度的问题。
* SJS-26681: 修复了行筛选器中树节点结构不正确的问题。
* SJS-27569: 修复了 COUNTIF 和 SUMIF 函数在比较「ー」和「―」时结果与 Excel 不一致的问题。
* SJS-27862: 修复了导出为 Excel 后，公式中的弧线 @符号导致计算错误的问题。
* SJS-28887: 明确了 Data Provider 中 onClear 钩子的行为逻辑。
* SJS-29060: 修复了导出 ssjson 后再导入 SpreadJS 时，公式自动添加「@」符号的问题。
* SJS-29580: 完成了 demoStory 功能的增强优化。
* SJS-29696: 修复了 Data Manager 未默认设置模式列类型的问题。
* SJS-29709: 优化了 autoFitRows 和 autoFitColumns 方法，使其仅计算使用范围。
* SJS-29724: 修复了应用格式后，以意大利语区域粘贴的日期被错误解析为英语格式的问题。
* SJS-29729: 修改了「Office」主题的默认日语字体。
* SJS-29736: 修复了公式未按预期计算的问题。
* SJS-29754: 修复了保存或导出大数据集时出现未定义长度错误的问题。
* SJS-29811: 修复了 [报表] 在 RenderMode () 后调用 Refresh () 返回错误的问题。
* SJS-29816: 修复了 spreads getPrecedents 方法不支持跨工作簿公式的问题。
* SJS-29826: 修复了 SpreadJS「disabled」类的 CSS 样式泄漏影响全局输入样式的问题。
* SJS-29840: 修复了点运算符结果为 null 或 undefined 时，计算结果错误显示为 CalcError 的问题。
* SJS-29843: 修复了 XLSX 文件在 SpreadJS 中加载时，公式结果出现 #Value! 错误的问题。
