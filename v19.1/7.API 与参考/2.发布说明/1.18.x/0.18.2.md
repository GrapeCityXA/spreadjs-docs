## 与上一版本相比的增强功能

本产品版本已整合以下功能与增强特性：

### 设计器增强（Designer Enhancements）​

* **[主题支持与自定义](gcdocsite__documentlink?toc-item-id=82f86eb6-0564-49ac-8c9a-d5fa1275ac0b)**：SpreadJS 设计器现支持两种内置主题，并提供主题自定义功能，可适配更多现代风格主题。
* **[转换命令](gcdocsite__documentlink?toc-item-id=b644ac0a-4dcc-4687-b854-fc41a55caf1c)**：新增转换命令，可对选中内容应用 LAMBDA 公式，以替换选中的内容。
* **[名称管理器增强](gcdocsite__documentlink?toc-item-id=3405eaa9-d0d2-4dd3-aaee-d84a310e9bad)**：在名称管理器界面中新增排序与筛选功能。
* **[字体选择器编辑](gcdocsite__documentlink?toc-item-id=5b473bb6-a280-4a58-b427-fe0cc21709d0)**：支持在设计器的字体选择器组件内直接进行编辑。
* **[表格增强](gcdocsite__documentlink?toc-item-id=2c3bb383-cba6-4c87-9fa4-4f34bb96cee9)**：支持通过设计器命令，将表格与绑定的数据表（DataTable）进行双向转换。

### 用户界面与样式（UI & Styling）​

* **[复选框与复选框列表单元格类型](gcdocsite__documentlink?toc-item-id=9e090ad4-9713-474d-84e1-a93e33599491)**：为复选框（Checkbox）/复选框列表（CheckboxList）单元格类型新增切换模式支持，实现单元格内类似开关的交互效果。
* **[形状文本方向](gcdocsite__documentlink?toc-item-id=43b79fd0-a4c3-4c5d-b5bf-5a6624b690a4)**：支持为形状中的文本设置方向。
* **[带 LAMBDA 公式的选择性粘贴](gcdocsite__documentlink?toc-item-id=81f37fe5-bae5-48dd-9e0a-600c225196ac)**：支持在粘贴前通过 LAMBDA 公式对剪贴板数据进行转换。
* **[数据验证搜索](gcdocsite__documentlink?toc-item-id=1342cf86-5473-4687-b68e-359a0f5d5e19)**：增强数据验证功能，新增搜索能力。
* **[批注填充颜色](gcdocsite__documentlink?toc-item-id=2a02a36d-7080-4135-b02e-55c2e60126be)**：批注填充颜色功能现与 Excel 2019+ 功能保持一致。
* **[工作表列表搜索](gcdocsite__documentlink?toc-item-id=ca743d24-50e8-45b7-b06a-dd5d0500d8b1)**：在工作表列表中新增搜索功能，便于快速定位工作表。

### 公式与计算（Formula & Calculation）

* **[异步函数计算](gcdocsite__documentlink?toc-item-id=0f2da260-277b-4e6f-b839-4a3c8934f9bf)**：支持在工作表外部对异步函数进行计算。

### 数据透视表改进（PivotTable Improvements）

* **[数据透视表数据源](gcdocsite__documentlink?toc-item-id=c759c4d3-8abd-41b9-9b38-7c65e0d6ea2a)**：允许选择整列（例如 `Sheet1!C:D`）作为数据透视表的数据源，解决动态数据更新问题。

### 协作服务器改进 - 预览版（Collaboration Server Improvements - PREVIEW）

* **[实时协作状态](gcdocsite__documentlink?toc-item-id=568d0215-7f9a-4ba8-ac7c-686a4ccd5054)**：新增视觉指示器，用于显示协作过程中的文档编辑状态。
* **[批处理操作处理](gcdocsite__documentlink?toc-item-id=24d984bd-7688-4282-b8d3-e752a3aa5b58)**：引入批处理操作 API，用于提交多个变更。

### 文件格式兼容性（File Format Compatibility​）

* **[XLSM 与 XLTM 文件格式支持（无损）](gcdocsite__documentlink?toc-item-id=9232fe6c-84ce-4d92-bff1-7921a5365506)**：全面支持导入/导出启用宏的 Excel 文件，并保持格式无损。
* **[XML 源编辑](gcdocsite__documentlink?toc-item-id=9232fe6c-84ce-4d92-bff1-7921a5365506)**：新增 XML 源（工作簿 XML 映射）的无损编辑功能。

### 图表与可视化（Charts & Visualization​）

* **新增数据图表类型**​
    * **[树状图（Treemap Chart）](gcdocsite__documentlink?toc-item-id=2eb22520-9e87-402c-97e6-eba69bf447ef)**：通过嵌套矩形可视化层级数据。
    * **[漏斗图（Funnel Chart）](gcdocsite__documentlink?toc-item-id=be14b506-dd91-47cd-910c-52f198d5005c)**：以逐渐收窄的比例展示流程阶段。

### 报表（ReportSheet​）

* **[隐藏行/列可见性](gcdocsite__documentlink?toc-item-id=0c044024-49d3-45c5-ad4b-85697270f86b)**：在报表（Report Sheet）模板的设计阶段，支持显示隐藏的行和列。

### 框架支持（Framework Support​）​

* **[React 19](gcdocsite__documentlink?toc-item-id=0ecee964-956f-4c77-8e03-12e8b2197470)**：新增对 React 19 的全面兼容性支持。
* **[Next.js 15](gcdocsite__documentlink?toc-item-id=dc5a0a80-63ae-4c95-b4bc-f8c06da8bf26)**：新增对 Next.js 15 的全面兼容性支持。

### 改进的许可证错误提示（Improved License Error Messages​）

* [增强许可证错误提示，帮助用户排查问题](gcdocsite__documentlink?toc-item-id=f9e48ba0-5b2d-425a-aeec-127a486ab4fe)，包括：
    * 密钥无效/缺失
    * 版本不匹配
    * 域名不匹配
    * 密钥过期

## 已修复的问题（Resolved Issues）

自上一版本起，已修复以下问题：

### 数据验证与单元格操作（Data Validation & Cell Operations）

* 单元格移动后，验证规则不再失效，可保留原始验证设置。
* 剪切/粘贴操作后新建的单元格，现在能正确保留绝对引用。

### 计算引擎改进（Calculation Engine Improvements）

* 修复了当 `calcOnDemand=true` 时，与 Excel 计算结果不一致的问题（尤其针对 SUMIFS 函数）。
* 修复了 LET 公式的计算问题，通过正确处理 CalcArray 中的运算符，确保返回正确值。
* 修复了 BYROW 公式的引用问题，通过正确引用 LAMBDA 函数，确保返回正确结果。
* 修复了公式计算结果异常导致无法导出 Excel 的问题（尤其针对 URL 参数中包含 "&" 的图像函数）。

### 数据透视表与数据刷新（Pivot Table & Data Refresh）

* 当数据源字段与当前配置匹配时，刷新后的数据透视表字段仍保持勾选状态。
* 修复了数据透视表刷新过程中计算字段重命名错误的问题。
* 修复了含数据透视表的 Excel 文件导入问题，确保所有数据透视表在导入后可正常使用或添加。
* 修复了数据透视表刷新后，字段的降序排列恢复为升序排列的问题。

### 图表渲染与性能（Chart Rendering & Performance）

* 新增二维码生成的二进制（Binary）模式支持。
* 通过优化模型更新触发逻辑，显著提升了大型数据集下树状图（Treemap）的渲染性能。
* 加快了图表引用数据的切换速度。
* 从 Excel 导入的图表和数据透视表元素，现在能保留其原始状态。
* 当行高变化时，浮动对象（如图表）可正确更新位置。

### 用户界面与显示修复（UI & Display Fixes）

* 在增量加载场景下，ExcelIO 与 IO 加载的第一个工作表显示时间保持一致。
* 修复了甘特图（Gantt Chart）切换视图时表头尺寸无法正确恢复的问题。
* 修复了表格表（TableSheet）自定义分组在滚动时无法正确显示所有数据的问题。
* 修复了滚动条布局异常的问题。
* 修复了 MacOS 和 iOS 设备上 TabStrip 字体显示异常的问题。

### 报表（ReportSheet）

* 修复了 ReportSheet 中的下拉框（Combox）未显示正确数据的问题。

### 协同服务器（Collaboration Server）

* 修复了里程碑快照（Milestone snapshot）未保存的问题。

### 数据绑定与表格操作（Data Binding & Table Operations）

* 在数据绑定表格中插入列时，现在能正确移动页脚值和工作表模型数据。
* 修复了含合并单元格的表格表（TableSheet）行标题导出问题。
* 修复了移动设备上多列列表（MultiColumn list）单元格类型下拉项无法点击的问题。
* 修复了表格绑定在插入行时的内容移动问题，确保标签（tags）等内容也能正确迁移。

### 导入/导出与文件处理（Import/Export & File Handling）

* 修复了 Excel 文件导出时日期字符串的格式转换问题（即使使用中文资源也可正常转换）。
* 修复了 SpreadJS 对特定类型 Excel 文件（如含 purl.oclc.org 链接的文件）的处理问题。
* 修复了报表（ReportSheet）的 SUMIF 函数问题，确保能正确从报表数据模型中获取数据。
* 修复了从报表导出 CSV 时工作表索引被错误设为 -1 的问题。

### 公式与计算修复（Formula & Calculation Fixes）

* 修复了多种场景下公式结果与 Excel 计算不一致的问题。
* 修复了分组列展开/折叠行为不一致的问题。
* 修复了 `calcOnDemand` 模式下动态数组公式无法正确获取当前值的问题。
* 修复了加载 JSON 时因条件格式引用解析错误导致的公式无效问题。
* 修复了插入列导致公式错误更改的问题
* 修复了 SUMIFS 公式在导出的 xlsx 文件中无法计算的问题。

### 设计器与配置（Designer & Configuration）

* 设计器中所有数据源更新操作现在均封装为命令（commands）。
* 修复了主题字体（ThemeFont）无法正确应用于单元格样式（Cell Style）中标题（Title）和标题栏（Heading）的问题。
* 表格表（TableSheet）现在支持对面板输入和列标题中含区域性特定格式的公式进行转换。
* 修复了表格表（TableSheet）对 `arrayGroupSeparator` 设为分号（;）时的处理问题。
* 修复了表格配置变更在清除范围（ranges）前触发，导致 `getColumnFormula` 返回 null 的问题。
* 修复了 `moveTo` 操作过程中条件格式计数异常增加的问题。
* 修复了表格表（TableSheet）切换视图时表头尺寸无法保持的问题。

### 性能优化（Performance Optimizations）

* 显著提升了启用自动合并（auto-merge）和固定行（fixed rows）时的滚动性能。
* 通过优化状态栏计算逻辑，提升了 Shift+PgDown 快捷键的响应性能。
* 修复了列拆分（Column Splitting）功能的性能问题。

### 本地化与国际化（Localization & Internationalization）

* 修复了阿拉伯语货币环境下筛选菜单选项显示不全及右对齐问题。
* 修复了中文区域下日期字符串的处理问题。

### 错误处理与边界场景（Error Handling & Edge Cases）

* 修复了调用 `calculate()` 函数时，因引用无效工作表名称导致的报错问题。
* 修复了文件导入时因下拉属性错位和内置样式名称错误导致的单元格样式设置无效问题。

* 修复了格式变更后修改单元格值时出现错误提示的问题（涉及 `showZero` 值的处理）。
