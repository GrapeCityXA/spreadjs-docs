## 上一版本以来的增强功能

* SJS-27357: SpreadJS 设计器组件及 SpreadJS 桌面设计器支持 Windows Server 2025。

## 已解决的问题

* SJS-28719: 设置公式并执行撤销操作后未恢复到之前状态。
* SJS-28711: 报表（ReportSheet）中的上下文菜单错误地包含了删除超链接的选项。
* SJS-28706: 筛选对话框（FilterDialog）问题。
* SJS-28692: 分页线（paginationLine）与报表（ReportSheet）的分页结果不匹配。
* SJS-28678: 从 17.0.2 版本开始，插入一行后执行撤销操作，单元格类型和背景颜色会被清除。
* SJS-28658: 报表（reportsheet）中隐藏列的问题。
* SJS-28564: 设置“columnHeadersAsFrozenRows”后，“includeBindingSource”不起作用。
* SJS-28554: 数据图表（DataChart）的图例标题无法更改。
* SJS-28553: API 参考文档中“StringOperator”的枚举成员不正确。
* SJS-28519: 可以向受保护的工作表中插入数据透视表。
* SJS-28514: 公式结果与 Excel 不一致。
* SJS-28292: 列宽可自动调整的条件存在问题。
* SJS-28225: SLN 公式问题。
* SJS-28220: WORKDAY 函数的计算结果与 Microsoft Excel 不一致。
* SJS-28203: 计算进度（calculationProgress）事件中“totalCellCount”的意外行为。
* SJS-28128: 为单元格设置自定义样式后，无法在公式编辑器中编辑该单元格。
* SJS-27994: 设计器用户界面（designerUI）上的页边距数据错误。
* SJS-10757: 从 Excel 导入时，已删除的图例仍显示在电子表格（Spread sheet）上。
