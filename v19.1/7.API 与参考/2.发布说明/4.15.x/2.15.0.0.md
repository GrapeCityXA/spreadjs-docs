# rnotesv15

此版本的产品中包含以下功能和增强功能。

* SpreadJS引入了[集算表](gcdocsite__documentlink?toc-item-id=78a1fc3a-e9fa-42ca-9a9a-1a907ddaa35b)，是一个具有网格状行为和电子表格用户界面的快速数据绑定表的视图。
* SpreadJS在单元格格式中添加了对[颜色索引](gcdocsite__documentlink?toc-item-id=03d7e06d-8cfc-4599-928e-2e60bfcf0542#%E9%A2%9C%E8%89%B2%E6%A0%BC%E5%BC%8F%E8%AE%BE%E7%BD%AE)的支持。
* 用户可以使用"[跨列居中](gcdocsite__documentlink?toc-item-id=6ec6893b-05b8-4ead-9ff8-708e58688961#%E8%B7%A8%E6%89%80%E9%80%89%E5%8C%BA%E5%9F%9F%E5%B1%85%E4%B8%AD%E5%AF%B9%E9%BD%90)"选项水平对齐内容。
* SpreadJS已更新图表以支持[数据点定制](gcdocsite__documentlink?toc-item-id=002a4c9f-2fee-44d1-ab53-0a206ad712cb)。
* 用户可以像在MS Excel中一样[使用+号开始公式输入](gcdocsite__documentlink?toc-item-id=7c52b1f4-e691-47f9-8d5c-5331ae559a8d)。
* SpreadJS可在修改重复工作表名称时给出明确提示。
* InvalidOperation事件已更新为包含[dragFill invalid type](gcdocsite__documentlink?toc-item-id=d9b7fe64-81d9-458a-a9bf-8bd38115cd12#%E5%A4%84%E7%90%86%E6%97%A0%E6%95%88%E5%A1%AB%E5%85%85)。
* SpreadJS日期类型结构已在[筛选对话框](gcdocsite__documentlink?toc-item-id=eabc402b-ad59-47e8-86d4-314710342964#%E7%AD%9B%E9%80%89%E5%AF%B9%E8%AF%9D%E6%A1%86%E5%88%97%E8%A1%A8%E6%A1%86)中更新。
* SpreadJS包含了新的[ClipboardPasted和ClipboardPasting事件](gcdocsite__documentlink?toc-item-id=5f7dd968-51d2-44cd-9521-df24229fd1bc)参数，fromRanges、fromSheet、isCuttng。
* 数据透视表支持在行和列中添加[计算项](gcdocsite__documentlink?toc-item-id=3ab9997a-3a24-474a-8b97-d1ef90ae5e81#%E8%AE%A1%E7%AE%97%E9%A1%B9)。
* 数据透视表中增加了[筛选对话框](gcdocsite__documentlink?toc-item-id=d5504936-b5f0-46bc-86be-e146c9096e13)，以改进排序和筛选选项。
* 数据透视表中支持[切片器](gcdocsite__documentlink?toc-item-id=702939e9-2938-428b-b418-ae8c378ac831)，以启用数据的手动筛选。
* [GETPIVOTDATA](gcdocsite__documentlink?toc-item-id=5208d136-df5b-4687-bd44-9ed37dde89ec)公式函数支持溢出。
* SpreadJS打印设置支持[对首页、奇偶页进行不同的页眉页脚设置](gcdocsite__documentlink?toc-item-id=b4a1010c-bca4-4360-9676-e0612839d981)
* SpreadJS支持[LAMBDA](gcdocsite__documentlink?toc-item-id=82c104dd-75d7-4a7e-a060-48f697149e63)函数，该函数有助于创建和命名自定义的可重用函数，这些函数可以像任何其他函数一样被调用。
* SpreadJS支持七个新的[LAMBDA辅助函数](gcdocsite__documentlink?toc-item-id=82c104dd-75d7-4a7e-a060-48f697149e63#lambda%E8%BE%85%E5%8A%A9%E5%87%BD%E6%95%B0)，它们通过将LAMBDA函数作为参数来帮助创建可重用的LAMBDA函数。
* 如果上下文菜单不能完全展示在窗口中，用户可以[滚动上下文菜单](gcdocsite__documentlink?toc-item-id=2864507a-1f41-4b88-9e7a-a4e4d153d2a6)进行查看。
* 支持[ASC](gcdocsite__documentlink?toc-item-id=753b162f-3410-4380-939f-1601fccf14f6)公式函数。
* 支持[DBCS](gcdocsite__documentlink?toc-item-id=c2030737-5952-478e-9d21-14e0982a86d7)公式函数。
* 支持[JIS](gcdocsite__documentlink?toc-item-id=85c25650-75fb-4c77-9265-231dba314573)公式函数。
* SpreadJS表格编辑器在字体列表中显示带有操作系统文化的字体名称。
* SpreadJS表格编辑器提供了一个打印菜单，可让用户预览和打印工作表或工作簿的全部或部分内容。
* 在SpreadJS表格编辑器中使用Ctrl+F 快捷键，可以打开[查找和替换](gcdocsite__documentlink?toc-item-id=8e08067a-68d9-43a2-bf13-4c4bc52345cd)对话框。
* SpreadJS表格编辑器中添加了[删除重复项](gcdocsite__documentlink?toc-item-id=0855d551-c911-4f3d-beba-d82c9defb6a2)功能，使用户能够提高工作效率并删除冗余数据。
* SpreadJS表格编辑器中添加了[文字转列](gcdocsite__documentlink?toc-item-id=d58e3ef3-7472-42bd-bc89-229a15f64c83)功能，用于将简单的文本或具有多个单词的句子转换为单独的列。
* SpreadJS数据透视表支持将电子表格导入或导出为[没有样式的JSON](gcdocsite__documentlink?toc-item-id=3ab9997a-3a24-474a-8b97-d1ef90ae5e81#%E6%97%A0%E6%A0%B7%E5%BC%8F%E7%9A%84-json-%E8%BE%93%E5%85%A5%E8%BE%93%E5%87%BA)。
* 用户可以在数据透视表中[显示或隐藏标题](gcdocsite__documentlink?toc-item-id=3ab9997a-3a24-474a-8b97-d1ef90ae5e81#%E6%98%BE%E7%A4%BA%E6%88%96%E9%9A%90%E8%97%8F%E6%A0%87%E9%A2%98)。
* 数据透视表支持[行和列字段的数字格式](gcdocsite__documentlink?toc-item-id=b71c9fb7-156a-4fa3-8dc0-8285f94e1a61)。
* 日期解析增强了从JSON或CSV加载数据的性能。
* 用户可以在数据透视表中使用日期类型筛选，该筛选可用于筛选指定日期类型项的条件。
* SpreadJS支持[在命名样式中设置应用标志](gcdocsite__documentlink?toc-item-id=b83f13ab-8ddd-49c0-bcec-7c5a886922e1#%E8%AE%BE%E7%BD%AE%E5%91%BD%E5%90%8D%E6%A0%B7%E5%BC%8F)。
* 增加了对Windows 11和Windows Server 2022的支持。
* 升级了PDFkit以修复安全问题。
* 使用UglifyJS升级了filesaver.js以处理异常情况。
* SpreadJS允许用户根据[行和列的状态](gcdocsite__documentlink?toc-item-id=79bcbe70-f8ab-47a4-b056-d082eec3d316)设置样式。
* 用户可以通过SpreadJS表格编辑器中的工作表上下文菜单[更改标签条位置](gcdocsite__documentlink?toc-item-id=c7272fb8-18b0-4217-a7ce-48cd076592c3)。
* SpreadJS支持Angular 13以及Angular 11和12。
* SpreadJS表格编辑器中的功能区的用户体验已更新。
* SpreadJS表格编辑器中的[名称管理器对话框](gcdocsite__documentlink?toc-item-id=3405eaa9-d0d2-4dd3-aaee-d84a310e9bad#%E4%BD%BF%E7%94%A8%E5%90%8D%E7%A7%B0%E7%AE%A1%E7%90%86%E5%99%A8%E5%AF%B9%E8%AF%9D%E6%A1%86)添加了新的筛选选项。
* SpreadJS表格编辑器在[文件导出菜单](gcdocsite__documentlink?toc-item-id=7b2665d3-90dd-4b83-bb24-95bc9641cb37#%E4%BF%9D%E5%AD%98%E5%92%8C%E5%AF%BC%E5%87%BA%E6%96%87%E4%BB%B6)中添加了序列化选项。
* 表格下拉框中的工作流列表的用户体验已得到增强。
