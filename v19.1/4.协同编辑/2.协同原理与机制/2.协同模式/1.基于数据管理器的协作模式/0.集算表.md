# tablesheet

集算表（TableSheet）是依托数据管理器架构搭建的工作表类组件。
它可绑定数据管理器表格视图，支持交互式编辑、排序、筛选、分组以及层级化操作。
开启协作功能后，集算表遵循基于数据管理器的协作模式。
协作相关的运行逻辑由底层表格的数据源配置决定。

## 依数据源而定的运行特性

集算表本身不定义数据存储规则。
协作能力由该表格绑定的数据管理器表格决定。

### 1\. 本地数据（JSON格式数据配置项）

通过以下代码创建表格时：

```typescript
dataSourceOption: {    
data: [...]
}
```

以下用户操作可实现多人协作同步：

* 编辑单元格数值
* 新增或删除数据记录
* 修改列字段定义
* 更新数据表结构配置
* 执行层级操作（移动、升级层级、降级层级）
* 锁定与解除行锁定
* 排序、筛选、分组操作以及视图更新
    表格配置变更与数据集数据变更均会完成同步。

### 2\. 远程数据（基于网址传输模式）

通过以下代码创建表格时：

```typescript
dataSourceOption: {    
remote: { ... },    
autoSync: true
}
```

运行规则：

* 支持集算表在线编辑操作。
* 数据变动信息会发送至已配置的远程服务端。
* 数据集的数据变更不会通过协作系统完成同步。
* 可序列化的配置修改内容依旧支持同步。
    数据一致性由后端系统维护，而非协作功能层。

### 3\. 远程数据（函数处理器模式）

采用函数处理器实现远程数据传输时：

* 该表格不参与多人协作流程。
* 数据集数据与表格配置均不会进行同步。

### 4\. CSV/XML 格式数据

当数据集来源为CSV或XML格式文件时：

* 表格配置修改支持同步。
* 数据集的数据变更无法同步。

## 功能限制

* 暂不支持在线成员状态感知功能。
* 仅基于JSON的本地数据可实现数据集同步。
* 远程数据的数据一致性交由外部服务负责维护。
