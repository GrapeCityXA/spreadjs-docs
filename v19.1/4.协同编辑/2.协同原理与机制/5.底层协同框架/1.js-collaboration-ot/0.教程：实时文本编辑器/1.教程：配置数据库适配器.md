# tutorial-configure-database-adapter

本教程将指导您如何配置数据库适配器以实现数据持久化。我们将以SQLite3适配器为例，展示具体的配置步骤。

## 前置条件

* 完成 [实时协同文本编辑器教程](gcdocsite__documentlink?toc-item-id=586c843b-82b8-4fd4-8bc5-276ac583ce1b)
* 具备 [数据库适配器](gcdocsite__documentlink?toc-item-id=460f30b1-fd3f-4fc1-accf-9255b20329ce) 的基础知识

## 步骤1：安装依赖

```bash
npm install sqlite3 @grapecity-software/js-collaboration-ot-sqlite
```

## 步骤2：修改server.js

将基础教程中的代码替换为以下内容：

```javascript
import express from "express";
import { createServer } from "http";
import { Server } from "@grapecity-software/js-collaboration";
import OT from "@grapecity-software/js-collaboration-ot";
import richText from "rich-text";
import sqlite3 from "sqlite3";
import { SqliteDb } from "@grapecity-software/js-collaboration-ot-sqlite";

// 注册富文本类型
OT.TypesManager.register(richText.type);

const port = 8080;
const app = express();
const httpServer = createServer(app);
const server = new Server({ httpServer });

// 初始化SQLite数据库和数据库适配器
const db = new sqlite3.Database("./data.db");
const sqliteDbAdapter = new SqliteDb(db);

// 初始化OT文档服务
const documentServices = new OT.DocumentServices({ db: sqliteDbAdapter });
server.useFeature(OT.documentFeature(documentServices));

// 提供静态文件服务
app.use(express.static('public'));

// 启动服务器
httpServer.listen(port, () => {
    console.log(`服务器在端口 ${port} 监听`);
    console.log(`http://127.0.0.1:8080/index.html`);
});
```

## 步骤3：初始化数据库

在根目录创建`init-database.js`文件：

```javascript
import sqlite3 from "sqlite3";
const db = new sqlite3.Database("./data.db");

async function initSqliteDataTables(db) {
    const run = (sql) => {
        return new Promise((resolve, reject) => {
            db.run(sql, (e) => (e ? reject(e) : resolve()));
        });
    };

    await run(
        `CREATE TABLE IF NOT EXISTS documents (
            id TEXT PRIMARY KEY,
            type TEXT NOT NULL,
            version INTEGER NOT NULL,
            snapshot_version INTEGER NOT NULL
        )`
    );

    await run(
        `CREATE TABLE IF NOT EXISTS operations (
            doc_id TEXT NOT NULL,
            version INTEGER NOT NULL,
            operation TEXT NOT NULL,
            PRIMARY KEY (doc_id, version),
            FOREIGN KEY (doc_id) REFERENCES documents (id) ON DELETE CASCADE
        )`
    );

    await run(
        `CREATE TABLE IF NOT EXISTS snapshot_fragments (
            doc_id TEXT NOT NULL,
            fragment_id TEXT NOT NULL,
            data TEXT NOT NULL,
            PRIMARY KEY (doc_id, fragment_id),
            FOREIGN KEY (doc_id) REFERENCES documents (id) ON DELETE CASCADE
        )`
    );
}

// 调用初始化函数
initSqliteDataTables(db);
```

执行该文件以初始化数据库表：

```bash
node init-database.js
```

## 步骤4：构建与运行

1. 构建客户端代码

```bash
npm run build
```

2. 启动服务器

```bash
npm run start
```

3. 测试功能
    1. 打开 http://127.0.0.1:8080/index.html。
    2. 在输入框中输入"123"。
    3. 重启服务器，输入框中会显示相同的字符串。
