# ottypes

`js-collaboration-ot` 通过操作转换（OT）技术支持多用户协同编辑。`OT 类型`定义了操作（Ops）的转换和应用逻辑，需在客户端和服务端同时注册。`OT 类型`负责处理操作冲突和应用，确保多用户操作能正确同步。本文介绍`OT 类型`的定义和用法。

>type=note
> OT 类型必须在服务端和客户端同时注册。

## 前置条件

在阅读后续内容前，建议先阅读以下文章了解冲突与转换：[冲突与转换](gcdocsite__documentlink?toc-item-id=efb3b075-eaa9-4c17-ad09-6964c1a972b9)。

## 定义

通用`OT 类型`接口包含以下方法，需在客户端和服务端同时注册：

```typescript
/**
 * OT 类型接口，用户可自定义协同编辑的 OT 行为。
 * @template S 快照类型。
 * @template T 操作类型。
 */
export interface OT_Type<S = unknown, T = unknown> {
    /**
     * 文档的类型标识符。
     */
    uri: string;
    /**
     * 从初始化数据创建快照。
     * @param data - 快照数据
     * @returns 快照
     */
    create?(data: any): S;
    /**
     * 转换 op1 以处理冲突。
     * @param op1 待转换的操作。
     * @param op2 转换操作的基准（op1 基于 op2 转换）。
     * @param side 指示哪个参数对应的操作后到达服务器。
     * @returns 转换后的 op1。
     */
    transform(op1: T, op2: T, side: 'left' | 'right'): T;
    /**
     * 将操作应用到快照。
     * @param snapshot - 快照
     * @param op - 操作
     * @returns 新快照
     */
    apply(snapshot: S, op: T): S;
}
```

>type=note
> 本文仅描述 OT 类型的基本能力，更多扩展能力请参考：[片段机制](gcdocsite__documentlink?toc-item-id=f77f5781-0bee-4524-b771-c133764d53fa)。

### 示例：简单文本 OT 类型

以下是简化的文本 OT 类型示例，仅支持文本插入操作，不包含删除等操作。

>type=note
> 以下示例中的操作（Ops）已简化以便演示。在实际场景中，Op 的结构和内容可能因文档类型、操作复杂度和实现方式而有所不同。

```typescript
type ISnapshot = string;
interface IOp {
    pos: number;
    text: string;
};

const textType: OT_Type<ISnapshot, IOp> = {
    uri: 'rich-text-ot-type',
    create: (data) => data || '', // 初始化为空字符串
    transform: (op1, op2, side) => {
        if (op1.pos > op2.pos || (op1.pos === op2.pos && side === 'left')) {
            return { pos: op1.pos + op2.text.length, text: op1.text };
        }
        return op1;
    },
    apply: (snapshot, op) => {
        return snapshot.slice(0, op.pos) + op.text + snapshot.slice(op.pos);
    }
};
```

## 注册

### 客户端注册

```typescript
import { TypesManager } from '@grapecity-software/js-collaboration-ot';

// 注册 OT 类型
TypesManager.register(textType);
```

### 服务端注册

```typescript
import { documentFeature, TypesManager } from '@grapecity-software/js-collaboration-ot';

// 注册 OT 类型
TypesManager.register(textType);
```
