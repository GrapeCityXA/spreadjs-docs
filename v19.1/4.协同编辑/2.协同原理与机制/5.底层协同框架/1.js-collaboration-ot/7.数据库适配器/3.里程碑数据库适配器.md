# file-database-adapter

### 里程碑数据库适配器

**里程碑数据库适配器**（Milestone Database Adapter）通过定期保存文档快照来提升频繁查询历史快照的性能。与主数据库适配器（[IDatabaseAdapter](gcdocsite__documentlink?toc-item-id=2512e56f-4385-4fa4-a86e-ae14867d8d70)）仅保留最新快照不同，里程碑适配器（[IMilestoneDatabaseAdapter](gcdocsite__documentlink?toc-item-id=e1ba91f6-7359-40ea-907b-8d4135364c33)）会存储多个版本的快照，从而优化[fetchHistorySnapshot](gcdocsite__documentlink?toc-item-id=e04a3031-c69b-4ba3-8926-c2813134ce43#fetchhistorysnapshot)方法的性能。
**适用场景**：需要快速访问文档历史的应用场景**默认实现**：内置基于内存的适配器

## 接口：IMilestoneDatabaseAdapter

开发者需要实现以下方法以支持自定义存储：

```typescript
/**
 * 定义里程碑数据库适配器的接口。
 */
export interface IMilestoneDatabaseAdapter<S> {
    /**
     * 保存里程碑快照的时间间隔，-1表示禁用里程碑快照保存功能。
     */
    interval: number;

    /**
     * 保存里程碑快照。
     */
    saveMilestoneSnapshot(snapshot: ISnapshot<S>): Promise<boolean>;

    /**
     * 根据文档ID和版本号获取里程碑快照。
     */
    getMilestoneSnapshot(id: string, version: number): Promise<ISnapshot<S> | null>;
}
```

### `interval` 说明

该参数控制里程碑快照的保存频率。例如，若`interval`设置为`1000`，则每1000次操作（op）会保存一次快照。

* 较小的间隔会增加存储开销，但能提升历史查询性能。
* 较大的间隔会减少存储需求，但可能增加重建历史的时间。

## 默认实现

`js-collaboration-ot`库提供了内置的内存里程碑适配器：

* **说明**：数据存储在RAM中，重启后丢失。
* **用途**：开发和测试。
* **配置**：默认`interval`为`1000`。

> 内置适配器仅适用于开发和测试环境，生产环境请实现自定义适配器。

## 实现自定义适配器

可通过实现[IMilestoneDatabaseAdapter](gcdocsite__documentlink?toc-item-id=e1ba91f6-7359-40ea-907b-8d4135364c33)接口创建自定义适配器。以下是一个简单的内存里程碑适配器示例：

```typescript
import { IMilestoneDatabaseAdapter } from '@grapecity-software/js-collaboration-ot';

// 自定义里程碑适配器
class CustomMilestoneDb implements IMilestoneDatabaseAdapter {
  constructor() {
    this.interval = 1000; // 默认间隔
    this.map = new Map(); // 存储快照列表
  }

  async saveMilestoneSnapshot(snapshot) {
    let list = this.map.get(snapshot.id) || [];
    list.push(snapshot);
    list.sort((a, b) => a.v - b.v); // 按版本排序
    this.map.set(snapshot.id, list);
    return true;
  }

  async getMilestoneSnapshot(id, version) {
    const list = this.map.get(id) || [];
    let result;
    for (const snapshot of list) {
      if (snapshot.v <= version) {
        result = snapshot;
      } else {
        break;
      }
    }
    return JSON.parse(JSON.stringify(result)) ?? null;
  }
}

const docService = new DocumentServices({
  db: new MemoryDb(),
  milestoneDb: new CustomMilestoneDb()
});
```

## 总结

里程碑数据库适配器通过定期保存快照优化历史访问性能。内置的内存实现适用于测试，而自定义适配器可满足生产需求。将适配器集成到`DocumentServices`后，可显著提升`fetchHistorySnapshot`的效率，非常适合频繁查询历史数据的应用场景。
