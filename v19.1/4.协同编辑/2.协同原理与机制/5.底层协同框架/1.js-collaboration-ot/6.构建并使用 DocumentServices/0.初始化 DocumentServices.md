# initalizing-documentservices

本文介绍如何在服务端初始化 [DocumentServices](gcdocsite__documentlink?toc-item-id=e04a3031-c69b-4ba3-8926-c2813134ce43)，内容包括：

* 安装依赖
* 创建服务器实例
* 配置 OT 功能

## 安装

通过 npm 安装所需的依赖包：

```bash
npm install @grapecity-software/js-collaboration @grapecity-software/js-collaboration-ot
```

* `js-collaboration`：提供基础的服务器功能和 [Server ](gcdocsite__documentlink?toc-item-id=c94e9589-dfdf-4066-af97-776d49d2506e)类。
* `js-collaboration-ot`：提供 OT 功能，包括 [documentFeature ](gcdocsite__documentlink?toc-item-id=ccdcfeef-021d-4f3c-994b-206a0b8f86bd#documentfeature)和 OT 类型管理。

## 初始化服务器

### 1\. 注册 OT 类型

在启动服务器前，需要注册 [OT 类型](gcdocsite__documentlink?toc-item-id=89953b53-e259-4a92-a91d-aa7805748d7e) 以定义操作行为。以下是注册简单文本类型的示例：

```typescript
import { TypesManager } from '@grapecity-software/js-collaboration-ot';

const textType = {
    uri: 'rich-text-ot-type',
    create: (data) => data || '',
    transform: (op1, op2, side) => {
        if (op1.pos < op2.pos) return op1;
        return { pos: op1.pos + op2.text.length, text: op1.text };
    },
    apply: (snapshot, op) => {
        return snapshot.slice(0, op.pos) + op.text + snapshot.slice(op.pos);
    }
};

TypesManager.register(textType);
```

### 2\. 创建服务器实例

使用 `js-collaboration` 中的 [Server ](gcdocsite__documentlink?toc-item-id=c94e9589-dfdf-4066-af97-776d49d2506e)类创建服务器实例：

```typescript
import { Server } from '@grapecity-software/js-collaboration';

const server = new Server({ port: 8080 });
```

**作用**：初始化服务器并监听 WebSocket 连接。

### 3\. 集成 OT 功能

使用 `js-collaboration-ot` 中的 [documentFeature ](gcdocsite__documentlink?toc-item-id=ccdcfeef-021d-4f3c-994b-206a0b8f86bd#documentfeature)为服务器添加 OT 功能：

```typescript
import { documentFeature } from '@grapecity-software/js-collaboration-ot';

// 集成 OT 功能
server.useFeature(documentFeature());
```

**参数**`service`（可选）：`DocumentServices` 实例，用于自定义数据库和配置（见高级配置）。**作用**：启用 OT 文档功能，使服务器能够处理操作和快照。

## 完整示例

以下是服务器初始化的完整示例：

```typescript
import { Server } from '@grapecity-software/js-collaboration';
import { documentFeature, TypesManager } from '@grapecity-software/js-collaboration-ot';

// 定义 OT 类型
const textType = {
    uri: 'text',
    create: (data) => data || '',
    transform: (op1, op2, side) => {
        if (op1.pos < op2.pos) return op1;
        return { pos: op1.pos + op2.text.length, text: op1.text };
    },
    apply: (snapshot, op) => {
        return snapshot.slice(0, op.pos) + op.text + snapshot.slice(op.pos);
    }
};
// 注册 OT 类型
TypesManager.register(textType);

// 创建服务器
const server = new Server({ port: 8080 });

// 集成 OT 功能
server.useFeature(documentFeature());

// 可选：监听连接事件
server.on('connect', ({ connection }) => {
    console.log(`客户端 ${connection.id} 已连接`);
});
```

## 高级配置

如需自定义 OT 行为或数据存储，可配置 `DocumentServices` 并将其传递给 `documentFeature`：

```typescript
import { documentFeature, DocumentServices, MemoryDb } from '@grapecity-software/js-collaboration-ot';

// 配置 DocumentServices
const docService = new DocumentServices({
    db: new MemoryDb(), // 使用内存数据库
    submitSnapshotBatchSize: 50 // 快照提交批处理大小
});

// 集成 OT 功能
server.useFeature(documentFeature(docService));
```

**参数**（`IDocConfig`）：

* `db`：数据库适配器（默认使用 `MemoryDb`）。
* `maxSubmitRetries`：操作提交的最大重试次数（默认无限制）。
* `submitSnapshotBatchSize`：快照提交批处理大小（默认值为 100）。
