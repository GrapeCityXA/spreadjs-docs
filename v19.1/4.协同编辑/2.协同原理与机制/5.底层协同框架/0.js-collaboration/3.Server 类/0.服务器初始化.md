# initalizing-server

本文档介绍如何在 `js-collaboration` 中使用 [Server ](gcdocsite__documentlink?toc-item-id=c94e9589-dfdf-4066-af97-776d49d2506e)类初始化协同服务器，以实现与客户端的双向通信。

## 安装

通过 npm 安装所需依赖包：

```bash
npm install @grapecity-software/js-collaboration
```

## 创建服务器

### 独立使用

```typescript
import { Server } from '@grapecity-software/js-collaboration';
const server = new Server({ port: 8080 });
server.on('connect', (context) => {
    // ...
});
```

### 使用 HTTP 服务器

```typescript
import { createServer } from 'http';
import { Server } from '@grapecity-software/js-collaboration';
const httpServer = createServer();
const server = new Server({ httpServer });
server.on('connect', (context) => {
    // ...
});
httpServer.listen(8080);
```

### 使用 Express

```typescript
import express from "express";
import { createServer } from "http";
import { Server } from "@grapecity-software/js-collaboration";
const app = express();
const httpServer = createServer(app);
const server = new Server({ httpServer });
// 注册 Express 中间件
app.use(express.static('public'));
// 注册 Express 端点或路由，例如：
app.get('/recent-files', (req, res) => {
    res.send(['file1', 'file2']);
});
// 注册协同钩子，例如：
server.on('connect', (context) => {
    // ...
});
httpServer.listen(8080);
```

## 接口：IServerConfig

### path

参数 [path ](gcdocsite__documentlink?toc-item-id=4b095649-28db-491d-b970-1e8ad0b50f25)是服务器的请求路径，默认值为 `"/collaboration/"`。

> 服务器和客户端的值必须匹配。

```typescript
import { Server } from '@grapecity-software/js-collaboration';
const server = new Server({
    path: "/my-custom-path/"
});
```

```typescript
import { Client } from "@grapecity-software/js-collaboration-client";
const client = new Client("ws://server-domain.com:8000", {
    path: "/my-custom-path/"
});
```

### socketIoAdapter

适用于多节点或分布式部署的自定义[适配器 | Socket.IO](https://socket.io/docs/v4/adapter/)
支持与各类消息代理（Redis、MongoDB、PostgreSQL等）集成，实现多服务器实例间的消息广播。

**示例**

```auto
import { Server } from '@grapecity-software/js-collaboration';
import { createClient } from 'redis';
import { createAdapter } from '@socket.io/redis-adapter';
// 1. 初始化发布/订阅客户端
const pubClient = createClient({ url: 'redis://localhost:6379' });
const subClient = pubClient.duplicate();
await Promise.all([pubClient.connect(), subClient.connect()]);
// 2. 注入适配器
const server = new Server({    
port: 8080,    
socketIoAdapter: createAdapter(pubClient, subClient)
});
```
