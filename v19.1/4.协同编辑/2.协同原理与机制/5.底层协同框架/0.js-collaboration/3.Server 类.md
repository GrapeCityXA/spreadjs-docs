# server-class

[Server ](gcdocsite__documentlink?toc-item-id=c94e9589-dfdf-4066-af97-776d49d2506e)类是 `js-collaboration` 的核心组件，用于管理客户端连接和消息工作流。本文档将介绍其功能和用法。

## 概述

`Server` 类本身不包含任何业务逻辑，仅负责接收客户端的连接、消息和断开事件，并通过 **钩子（Hooks）** 和 **中间件（Middleware）** 机制将这些事件委托给开发者处理。

* **中间件**：用于拦截和处理连接或消息工作流，例如身份验证或权限验证。
* **钩子**：用于监听事件（如连接建立或消息接收）并执行自定义逻辑，且不影响工作流。

开发者通过注册中间件和钩子实现业务逻辑，而服务器仅作为事件调度器。

## 方法

### 注册钩子（`on`）

监听服务器生命周期事件（如连接、消息或断开）。
**批量注册**：

```typescript
server.on({
    connect: ({ connection }) => {
        console.log(`${connection.id} 已连接`);
    },
    message: ({ data, type }) => {
        console.log(`收到消息: ${data} (类型: ${type})`);
    },
    disconnect: ({ connection }) => {
        console.log(`${connection.id} 已断开`);
    }
});
```

**单独注册**：

```typescript
server.on('connect', ({ connection }) => {
    console.log(`${connection.id} 已连接`);
});
server.on('message', ({ data, type }) => {
    console.log(`收到消息: ${data} (类型: ${type})`);
});
server.on('disconnect', ({ connection }) => {
    console.log(`${connection.id} 已断开`);
});
```

> 钩子不拦截工作流，仅用于附加逻辑。

### 注册中间件（`use`）

在事件处理前执行拦截逻辑（如身份验证或日志记录）。

```typescript
server.use({
    connect: async (context, next) => {
        if (context.connection.auth.token === 'valid-token') {
            await next();
        } else {
            await next('身份验证失败');
        }
    },
    message: async ({ data }, next) => {
        console.log('消息:', data);
    }
});
```

更多中间件细节，参见：[服务器中间件](gcdocsite__documentlink?toc-item-id=e6de7cb2-7eb8-46f6-8f5c-1cdbee161334)。

### 注册功能（`useFeature`）

`useFeature` 方法支持同时注册中间件和钩子。部分扩展功能（如 OT 操作转换和 Presence 用户在线状态）以功能模块形式提供。

```typescript
import { documentFeature } from '@grapecity-software/js-collaboration-ot';

server.useFeature(documentFeature());
```

#### 接口定义

```typescript
export interface IFeature {
    middlewares?: IMiddlewares;
    hooks?: IHooks;
}
```

## 基础用例

1. **使用中间件进行身份验证和权限验证**参见：[用户认证与权限](gcdocsite__documentlink?toc-item-id=d7a401c5-ab47-4dd9-9937-37bbc0a548ac)。
2. **使用钩子处理事件**

```typescript
server.on({
    enterRoom: ({ connection, roomId }) => {
        console.log(`${connection.id} 加入房间 ${roomId}`);
    },
    message: ({ connection, roomId, data }) => {
        console.log(`收到来自 ${connection.id} 的消息: ${data}`);
        console.log(`向房间 ${roomId} 广播消息: ${data}`);
        connection.broadcast(data);
    },
    leaveRoom: ({ connection, roomId }) => {
        console.log(`${connection.id} 离开房间 ${roomId}`);
    }
});
```
