# ISLOGICAL

此函数测试引用单元格的值，表达式或内容是否为逻辑（布尔）值。



#### 语法

ISLOGICAL( *cellreference* )

ISLOGICAL( *value* )

ISLOGICAL( *expression* )



#### 参数

参数可以是单元格引用，数字或文本值或表达式。



#### 注释

如果引用一个空单元格或没有数据，则此函数返回FALSE。

使用此功能可以测试单元格、数字、文本值、函数或表达式的内容。



#### 数据类型

接受参数的任何数据类型。返回布尔（TRUE或FALSE）数据。



#### 示例

ISLOGICAL(B7)

ISLOGICAL(R4C8)

ISLOGICAL(true) 得出结果 TRUE

ISLOGICAL(OR(B7,B8)) 得出结果 TRUE
