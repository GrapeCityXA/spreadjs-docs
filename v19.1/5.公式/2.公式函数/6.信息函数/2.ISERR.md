# ISERR

此函数检验引用单元格的值，表达式或内容是否为为任意错误值（除去 #N/A）。



#### 语法

ISERR( *cellreference* )

ISERR( *value* )

ISERR( *expression* )



#### 参数

参数可以是单元格引用，数字或文本值或表达式。



#### 注释

使用此功能可以测试单元格、数字、文本值、函数或表达式的内容。

This function returns TRUE if the value refers to an empty cell or to no data.



#### 数据类型

接受参数的任何数据类型。返回布尔（TRUE或FALSE）数据。



#### 示例

ISERR(B12)

ISERR(R12C2)

ISERR(#N/A) 得出结果 FALSE

ISERR(#REF!) 得出结果 TRUE

ISERR(C14) 得出结果 TRUE if C14 contains a #NUM! error.
