# MATCH

使用 MATCH 函数在 范围 单元格中搜索特定的项，然后返回该项在此区域中的相对位置。



#### 语法

MATCH( *value1* , *array* ,type)



#### 参数

| 参数 | 描述 |
|--- |--- |
|  *value*  | 要在 array 中匹配的值。 |
| array | 要搜索的单元格区域。 |
| type | [可选]公式返回错误时要返回的值 |



#### 注释

参数value可以为值（数字、文本或逻辑值）或对数字、文本或逻辑值的单元格引用。

type为 0 (MATCH 查找完全等于 value 的第一个值)；

type为1 (MATCH 查找小于或等于 value 的最大值)；

type为 -1 (MATCH 查找大于或等于 value 的最小值)



#### 数据类型

参数value可以为值（数字、文本或逻辑值）或对数字、文本或逻辑值的单元格引用。返回数值数据。



#### 示例

MATCH(25,A1:E5)
