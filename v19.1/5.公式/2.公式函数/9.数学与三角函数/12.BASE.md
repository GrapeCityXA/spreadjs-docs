# BASE

此函数将数字转换为具备给定基数的文本表示。



#### 语法

BASE( *value,base,min_len* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *value*  | 要转换的数字。 必须是大于或等于0且小于 2 ^ 53 的整数。 |
|  *base*  | 要将数字转换为的基础基数。 必须是大于或等于2且小于或等于36的整数。 |
|  *min_len*  | [可选] 返回的字符串的最小长度。 必须是大于或等于0的整数。 |



#### 注释

如果上述参数超出最小值或最大值的限制范围，则 BASE 返回错误值 #NUM! 。



#### 数据类型

接受所有参数的数值数据。 返回数值数据。



#### 示例

BASE(9,3) 得出结果 100.

BASE(8,2,1) 得出结果 1000.

BASE(6,3,2) 得出结果 20.
