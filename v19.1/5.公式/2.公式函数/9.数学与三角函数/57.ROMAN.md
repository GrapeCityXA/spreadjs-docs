# ROMAN

此函数将阿拉伯数字转换为文字形式的罗马数字



#### 语法

ROMAN( *number* , *style* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *number*  | 需要转换的阿拉伯数字。 |
|  *style*  | 指定所需的罗马数字类型。 |



#### 注释

罗马数字的样式是由样式参数的数值设置的:

| 样式值 | 罗马数字样式 |
|--- |--- |
|  *0 or omitted*  | 古典 |
|  *1*  | 更简洁 |
|  *2*  | 更简洁 |
|  *3*  | 更简洁 |
| 4 | 简化 |
| TRUE | 古典 |
| FALSE | 简化 |

number为负值时返回错误值。



#### 数据类型

接受数值数据。返回字符串数据。



#### 示例

ROMAN(100,3)
