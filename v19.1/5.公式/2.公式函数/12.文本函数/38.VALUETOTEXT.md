# valuetotext

此函数可将数值转换为文本格式。
## 语法
```auto
VALUETOTEXT(数值, [格式])
```
## 参数
| 参数 | 说明 |
| -------- | ----------- |
| 数值 | 待转换的数据 |
| 格式 | 可选参数，用于指定输出格式<br>`0` — 简洁格式（默认格式）<br>`1` — 严格格式 |
## 返回值
返回指定数值对应的文本形式。
## 备注
* 若省略格式参数，默认取值为`0`。
* 输出结果统一采用常规格式，不受单元格数字格式影响。
* 空值会返回空白文本。
* 严格格式下规则：
* 文本内容会被双引号包裹。
* 文本内部的双引号会转义为`""`。
* 布尔值与数字值不添加引号。
* 绝大多数错误值无引号，`#溢出!`、`#计算!`这类动态数组错误会被双引号包裹。
* 日期和时间数据会转为对应的基础序列号。
* 函数、匿名函数、富文本数据及自定义对象，返回其页面展示样式。
* 文本语言样式跟随系统区域语言设置变化。
## 示例
| 公式 | 结果 |
| ------- | ------ |
| `=VALUETOTEXT(1234)` | 1234 |
| `=VALUETOTEXT("Hello",1)` | "Hello" |
| `=VALUETOTEXT(A1)`（A1单元格数值为2025/1/1） | 45658 |
| `=VALUETOTEXT(#溢出!,1)` | "#溢出!" |
