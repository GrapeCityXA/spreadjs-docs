# arraytotext

该函数可将数组转换为文本字符串。
## 语法
```auto
ARRAYTOTEXT(数组, [格式])
```
## 参数
| 参数 | 说明 |
| -------- | ----------- |
| 数组 | 待转换的数组或单元格区域。 |
| 格式 | 可选参数，用于指定输出格式。<ul><li>`0` — 简洁格式（默认）。</li><li>`1` — 严格格式。</li></ul> |
## 返回值
返回指定数组对应的文本形式内容。
## 备注
* 若省略格式参数，默认取值为`0`。
* 数组内每个元素的转换规则与VALUETOTEXT函数一致。
* 输出内容统一采用常规格式，不受单元格原有格式影响。
* 简洁模式（参数为`0`）：
* 数值以逗号分隔的列表形式呈现。
* 分组分隔符遵循当前系统区域语言设置。
* 严格模式（参数为`1`）：
* 整体结果被大括号`{}`包裹。
* 列数据以逗号分隔。
* 行数据以分号分隔。
* 文本类型数值会添加引号并做转义处理。
* 本地化文本显示效果由当前区域语言设置决定。
## 示例
以单元格区域A1:B3的数据为例：
| 真 | #值错误! |
| ---- | ------- |
| 1234.01234 | 西雅图 |
| 你好 | 1123.00美元 |
### 简洁模式
```auto
=ARRAYTOTEXT(A1:B3,0)
```
运算结果：
```auto
TRUE, #VALUE!, 1234.01234, Seattle, Hello, 1123
```
### 严格模式
```auto
=ARRAYTOTEXT(A1:B3,1)
```
运算结果：
```auto
'{TRUE,#VALUE!;1234.01234,"Seattle";"Hello",1123}'
```
