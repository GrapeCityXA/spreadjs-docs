# text-functions

Spread 提供以下文本函数，按字母顺序列出。

| 函数 | 描述 |
| --- | --- |
| [ARRAYTOTEXT](gcdocsite__documentlink?toc-item-id=17d5f4fb-72e2-414a-a92a-fa0f53a0c19f) | 该函数可将数组转换为文本字符串。 |
| [BAHTTEXT](gcdocsite__documentlink?toc-item-id=2a50de16-db99-472a-9068-c982eeab57b5) | 此函数将数字转换为泰文并添加“Baht”后缀 |
| [CHAR](gcdocsite__documentlink?toc-item-id=543b41a5-b0b8-455b-a65e-ffee24b364fe) | 此函数返回由数字指定的字符。 |
| [CLEAN](gcdocsite__documentlink?toc-item-id=54b70475-1220-4010-b1d9-809e41990211) | 此函数从文本中删除所有不可打印的字符。 |
| [CODE](gcdocsite__documentlink?toc-item-id=2a5ae87c-41d0-4672-9a75-395d5fb91ebf) | 此函数返回一个数字代码来表示文本字符串中的第一个字符。返回的代码对应于 Windows 字符集 (ANSI)。 |
| [CONCAT](gcdocsite__documentlink?toc-item-id=9aba03b5-7bb0-4228-8c74-cf37aa383e78) | 此函数将多个文本字符串或数字合并为一个文本字符串，该函数将保持可用以与“CONCATENATE”函数兼容。 |
| [CONCATENATE](gcdocsite__documentlink?toc-item-id=c3aa6dc9-abaf-4106-9921-f198ca918371) | 此功能将多个文本字符串或数字组合成一个文本字符串。 |
| [DOLLAR](gcdocsite__documentlink?toc-item-id=20493625-5d16-4d07-afb4-2c4e938f22fd) | 此函数使用货币格式将数字转换为文本，并将小数点四舍五入到指定的位置。 |
| [FIND](gcdocsite__documentlink?toc-item-id=3017900a-7d40-49ab-8701-866185282bde) | 此函数在另一个文本值中查找一个文本值，并返回该文本值在您搜索的文本中的位置。 |
| [FINDB](gcdocsite__documentlink?toc-item-id=40e9a389-0e1e-41f6-87bf-ed857263807f) | 此函数在另一个文本值中查找一个文本值并返回该文本值在您搜索的文本中的位置，并在将 DBCS 设置为默认语言时将每个双字节字符计为 2。 |
| [FIXED](gcdocsite__documentlink?toc-item-id=1b24741f-969d-4771-bc9a-50f65494d375) | 此函数将数字四舍五入到指定的小数位数，使用句点和逗号（如果指定）将数字格式化为十进制格式，并将结果作为文本返回。 |
| [LEFT](gcdocsite__documentlink?toc-item-id=9bac1bad-1f64-47f6-bd37-2767cb6580ab) | 此函数根据您指定的字符数从文本值返回指定的最左边的字符。 |
| [LEFTB](gcdocsite__documentlink?toc-item-id=aaa5a2ed-82f0-456a-9273-3f78cf0620a3) | 此函数根据您指定的字节数从文本值返回指定的最左边的字符。 |
| [LEN](gcdocsite__documentlink?toc-item-id=1dc56b1e-fb42-4256-bcbd-49c3b71ea8a5) | 此函数返回文本字符串中字符数的长度。 |
| [LENB](gcdocsite__documentlink?toc-item-id=d862756c-791e-4766-a758-cd2a045c0659) | 此函数返回文本字符串中字节数的长度。 |
| [LOWER](gcdocsite__documentlink?toc-item-id=9e1dec3c-29c0-481a-9bc0-16d94df06e55) | 此函数将文本转换为小写字母。 |
| [MID](gcdocsite__documentlink?toc-item-id=c7d57dce-6edc-437f-974c-71aff44510f7) | 此函数从您指定的位置开始并基于您指定的字符数从文本字符串返回请求的字符数。 |
| [MIDB](gcdocsite__documentlink?toc-item-id=adc8a6a6-80aa-4138-bd2d-83f6a580351f) | 此函数从您指定的位置开始并基于您指定的字节数从文本字符串返回请求的字符数。 |
| [PROPER](gcdocsite__documentlink?toc-item-id=f408c4b2-c751-4e04-abe3-e9ad4c1ad6e8) | 此函数将文本字符串的每个单词中的第一个字母大写。 |
| [REPLACE](gcdocsite__documentlink?toc-item-id=a9c420ba-68f4-4c0b-948f-32f7cb615ee7) | 此函数根据您指定的字符数用不同的文本字符串替换部分文本字符串。 |
| [REPLACEB](gcdocsite__documentlink?toc-item-id=3c321eae-1e28-41fb-8a81-c3ec8a2d31c0) | 此函数根据您指定的字节数用不同的文本字符串替换部分文本字符串。 |
| [REPT](gcdocsite__documentlink?toc-item-id=1b4d5983-c32a-4dd3-9ea2-975b95f4cca2) | 此函数将文本重复指定的次数。 |
| [RIGHT](gcdocsite__documentlink?toc-item-id=77b05452-05ed-4b10-831b-a84019a5bcb1) | 此函数根据您指定的字符数从文本值中返回指定的最右边的字符。 |
| [RIGHTB](gcdocsite__documentlink?toc-item-id=d8d0a246-d60e-4b3d-a6e3-311556c3bbff) | 此函数根据您指定的字节数从文本值返回指定的最右边的字符。 |
| [SEARCH](gcdocsite__documentlink?toc-item-id=86c48290-c5bd-4bd0-81c7-f343c76b90a4) | 此函数在另一个文本字符串中查找一个文本字符串，并返回找到的文本的起始位置的索引。 |
| [SEARCHB](gcdocsite__documentlink?toc-item-id=49942aee-fc37-405c-8564-2d69bab9f957) | 该函数在另一个文本字符串中查找一个文本字符串，并返回找到文本的起始位置的索引，并在将 DBCS 设置为默认语言时将每个双字节字符计为 2。 |
| [SUBSTITUTE](gcdocsite__documentlink?toc-item-id=a7f1f1ac-1eb3-48ef-95fe-7c7a413fd9af) | 此函数用新字符串替换现有字符串中的指定字符。 |
| [T](gcdocsite__documentlink?toc-item-id=4cac3a7e-a818-449d-8b74-dd508a15ba32) | 此函数返回指定单元格中的文本。 |
| [TEXT](gcdocsite__documentlink?toc-item-id=043e3d3f-953b-4a86-9523-e6c66d5cfe26) | 此函数格式化数字并将其转换为文本。 |
| [TEXTJOIN](gcdocsite__documentlink?toc-item-id=f47a0154-5e42-4e0d-986b-8549815d2599) | 此函数将多个范围和/或字符串合并为一个文本，该文本包含您在每个文本值之间指定的分隔符。 |
| [TRIM](gcdocsite__documentlink?toc-item-id=e43bb3ae-adbe-4399-8a40-c89aa39316a4) | 此函数从字符串中删除多余的空格并在单词之间留下单个空格。 |
| [UNICHAR](gcdocsite__documentlink?toc-item-id=8b95c3ed-627b-4ada-a947-edd1e8dcbaa2) | 此函数返回给定数字引用的 Unicode 字符。 |
| [UNICODE](gcdocsite__documentlink?toc-item-id=354a8b66-a0b6-4abb-83c0-8b3f7b85e9e4) | 此函数返回与文本的第一个字符对应的数字。 |
| [UPPER](gcdocsite__documentlink?toc-item-id=0291317f-2bd3-41b7-8e1c-c7d8b4959bcf) | 此函数将文本转换为大写字母。 |
| [VALUE](gcdocsite__documentlink?toc-item-id=71199e27-88d0-4e5e-bf66-574e9e9391cc) | 此函数将数字文本字符串转换为数值。 |
| [VALUETOTEXT](gcdocsite__documentlink?toc-item-id=14847f1a-4d9f-4322-8e3c-caaf2dfa1d3a) | 此函数可将数值转换为文本。 |
