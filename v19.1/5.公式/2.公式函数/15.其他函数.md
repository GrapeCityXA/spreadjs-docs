# other-functions

Spread 提供以下其他函数，按字母顺序列出。

| 函数 | 描述 |
|--- |--- |
| [EURO](gcdocsite__documentlink?toc-item-id=5b2742ca-419d-438d-9efc-4d2b434ce14d) | 此函数根据 ISO 货币代码返回相当于一欧元的值。 |
| [EUROCONVERT](gcdocsite__documentlink?toc-item-id=591516a9-89a6-4587-a250-934b7471c6e9) | 此函数将货币从欧元成员货币（包括欧元）转换为另一种欧元成员货币（包括欧元）。 |
| [OBJECT](gcdocsite__documentlink?toc-item-id=9ea36f28-42ac-4974-acc7-e7be2e547a5e) | 此函数将属性/表达式序列转换为对象。 |
| [PROPERTY](gcdocsite__documentlink?toc-item-id=e1c9ff0a-e7c0-4864-97db-bd857e1e81e6) | 此函数返回对象中属性路径的值。 |
| [REFRESH](gcdocsite__documentlink?toc-item-id=ea7fd7a9-b6c8-452e-81e0-385b840bb6d9) | 该函数决定如何重新计算公式。可以使用evaluateMode 参数来指定公式对更改的参考值进行重新计算、评估一次、重新计算或间隔。 |
