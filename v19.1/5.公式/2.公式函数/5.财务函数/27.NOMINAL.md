# NOMINAL

此函数基于给定的实际利率和年复利期数，返回名义年利率。



#### 语法

NOMINAL( *effrate* , *comper* )



#### 参数

该函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *effrate*  | 实际利率。 |
|  *comper*  | 每年的复利期数。如果不是整数，则截尾取整。 |



#### 注释

如果任一参数是非数值，则 NOMINAL 返回错误值 #VALUE! 。

如果 effrate ≤ 0 或 comper < 1，则 NOMINAL 返回错误值 #NUM! 。



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

NOMINAL(A4,A5)

NOMINAL(R4C1,3)

NOMINAL(6.2336%,2) 得出结果 0.061393703

NOMINAL(6.2336%,6) 得出结果 0.060776004
