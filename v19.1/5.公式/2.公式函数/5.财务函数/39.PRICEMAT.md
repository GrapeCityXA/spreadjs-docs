# PRICEMAT

此函数返回到期付息的面值 ￥100 的有价证券的价格。



#### 语法

PRICEMAT( *settle* , *mature* , *issue* , *rate* , *yield* , *basis* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *settle*  | 有价证券的结算日。 |
|  *mature*  | 有价证券的到期日。 |
|  *issue*  | 有价证券的发行日。 |
|  *rate*  | 有价证券在发行日的利率。 |
|  *yield*  | 有价证券的年收益率。 |
|  *basis*  | [可选] 要使用的日计数基准类型。请参考[Day Count Basis](gcdocsite__documentlink?toc-item-id=23b72e94-94be-44ed-9302-d582747f59dd)。 |



#### 注释

如果settle或mature或issue日期不是有效的日期，返回 #VALUE！ 。

settle、maturity、issue 和 basis 将被截尾取整。

如果settle≥maturity，返回 #NUM！ 。

如果 rate < 0 或 yield < 0，则返回错误值 #NUM!。

如果 basis < 0 或 basis > 4，则返回错误值 #NUM!。



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

PRICEMAT(A1,A2,A5,A7,A7,1)

PRICEMAT(R1C1,R2C1,R5C5,R5C7,R5C9,2)

PRICEMAT("5/15/2004","9/1/2004","5/15/2003",0.06,0.07,3) 得出结果 99.5842915904314
