# ACCRINTM

该函数用于计算在到期日支付利息的有价证券的应计利息。



#### 语法

ACCRINTM( *issue* , *maturity* , *rate* , *par* , *basis* )



#### 参数

函数语法具有下列参数：

| 参数 | 描述 |
|--- |--- |
|  *issue*  | 有价证券的发行日。 |
|  *maturity*  | 有价证券的到期日。 |
|  *rate*  | 有价证券的年息票利率。 |
|  *par*  | [可选] 证券的票面值。 如果省略此参数，则 ACCRINTM 使用 ￥10,000。 |
|  *basis*  | [可选]  要使用的日计数基准类型。 count (参考[Day Count Basis](gcdocsite__documentlink?toc-item-id=23b72e94-94be-44ed-9302-d582747f59dd).) |



#### 备注

如果 issue 不是有效日期，则 ACCRINTM 将返回 #VALUE! 错误值。 如果 rate ≤ 0 或 par ≤ 0，则 ACCRINTM 将返回 #NUM! 错误值。如果 basis < 0 或 basis > 4，则 ACCRINTM 将返回 #NUM! 错误值。 如果 issue ≥ settlement，则 ACCRINTM 将返回 #NUM! 错误值。



#### 数据类型

接受数字和DateTime对象数据。 返回数值数据。



#### 示例

ACCRINTM(A2,A3,B4,D9,3)

ACCRINTM(R1C1,R2C3,R4C2,R9C4,3)
