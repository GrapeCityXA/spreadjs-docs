# AMORLINC

This function calculates the depreciation for an accounting period, taking into account prorated depreciation.



#### 语法

AMORLINC( *cost* , *datepurchased* , *firstperiod* , *salvage,period,drate* , *basis* )



#### 参数

该函数有3个参数:

| 参数 | 描述 |
|--- |--- |
|  *cost*  | 资产原值 |
|  *datepurchased*  | 购入资产的日期 |
|  *firstperiod*  | 第一个期间结束时的日期 |
|  *salvage*  | 资产在使用寿命结束时的残值 |
|  *period*  | 期间 |
|  *rate*  | 折旧率 |
|  *basis*  | [可选] 要使用的年基准 (参考[Day Count Basis](gcdocsite__documentlink?toc-item-id=23b72e94-94be-44ed-9302-d582747f59dd)) |



#### 注释

此函数不同于[AMORDEGRC](gcdocsite__documentlink?toc-item-id=0a62d678-6d36-4f27-8cc4-5450c84e227a), 不同之处在于前者用于计算的折旧系数取决于资产的寿命。



#### 数据类型

接受数值和DateTime对象数据。返回数值数据。



#### Examples

AMORLINC(B1,B2,B3,B4,B5,B6,B7)
