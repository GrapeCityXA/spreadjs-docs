# DATE

此函数返回特定日期的DateTime对象，该日期由年，月和日指定。



#### 语法

DATE( *year* , *month* , *day* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *year*  | 代表年份的数字。 |
|  *month*  | 代表月份的数字。 |
|  *day*  | 代表天数的数字。 |



如果month大于12，依据需要年份会增加。例如，DATE（2003,16,2）返回代表（2004，4，2）的DateTime对象。

如果day大于指定月份中的天数，则day从下个月的第一天开始增加该天数。例如，DATE（2004,1,35）返回代表（2004，2，4）的DateTime对象。

如果参数的值不是整数，则截尾取整。月份的负值取自年份至前几年。天数的负值取自一个月到前几个月。



#### 数据类型

接受数值数据。返回一个DateTime对象。



#### 示例

DATE(A1,B1,C1)

DATE(R1C1,R1C2,R1C3)

DATE(2003,1,1) 得出结果 January 1, 2003

DATE(2004,2,10) 得出结果 February 10, 2004
