# TIME

此函数返回指定时间内的TimeSpan对象。



#### 语法

TIME( *hour* , *minutes* , *seconds* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *hour*  | hour是从0到23的数字 |
|  *minutes*  | Minutes 是从0到59的数字 |
|  *seconds*  | Seconds是从0到59的数字 |



#### 数据类型

接受所有参数的数值数据。返回TimeSpan对象。



#### 示例

TIME(A1,B1,C1)

TIME(R1C1,R1C2,R1C3)

TIME(12,0,0) 得出结果 12:00:00

TIME(16,48,10) 得出结果 16:48:10
