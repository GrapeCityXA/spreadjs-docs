# BC_CODE128

此函数返回一个表示 CODE128 的数据集。

## 语法

`BC_CODE128(value, color, backgroudColor, showLabel, labelPosition, codeSet, fontFamily, fontStyle, fontWeight, fontTextDecoration, fontTextAlign, fontSize, quietZoneLeft, quietZoneRight, quietZoneTop, quietZoneBottom)`

## 参数

| 参数 | 说明 |
| ---- | ---- |
| *value* | 一个字符串，表示在二维码符号上进行编码的内容。 |
| *color* | 表示条形码颜色的一种颜色。默认值为 'rgb(0,0,0)'。 |
| *backgroundColor* | 表示条形码背景颜色的一种颜色。默认值为 'rgb(255, 255, 255)'。 |
| *showLabel* | 指定当条形码带有标签时是否显示标签文本。 |
| *labelPosition* | 一个值，表示显示标签时标签的位置。 |
| *codeSet* | 一个值，表示设置用于二维码的是哪种编码。其取值有 'auto' 。 |
| *fontFamily* | 一个字符串，表示标签文本的字体系列。默认值为 'sans-serif'（无衬线字体）。 |
| *fontStyle* | 一个字符串，表示标签文本的字体样式。默认值为 'normal'（常规）。 |
| *fontWeight* | 一个字符串，表示标签文本的字体粗细。默认值为 'normal'（常规）。 |
| *fontTextDecoration* | 一个字符串，表示标签文本的文本装饰样式。默认值为 'none'（无装饰）。 |
| *fontTextAlign* | 一个字符串，表示标签文本的文本对齐方式。默认值为 'center'（居中）。 |
| *fontSize* | 一个字符串，表示标签文本的字体大小。默认值为 '12px'。 |
| *quietZoneLeft* | 一个值，表示左侧空白区的大小。 |
| *quietZoneRight* | 一个值，表示右侧空白区的大小。 |
| *quietZoneTop* | 一个值，表示顶部空白区的大小。 |
| *quietZoneBottom* | 一个值，表示底部空白区的大小。 |

## 数据类型

接受数字字符以及所有 ASCII 字符。返回条形码迷你图。

## 示例

`sheet.setFormula(3, 3, '=BC_CODE128(C4)');`
