# OCT2BIN

此函数将八进制数转换为二进制数。



#### 语法

OCT2BIN( *number* , *places* )



#### 参数

该函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *number*  | 要转换的八进制数。number 不能包含超过10个字符。如果 number 为负数，不能小于 7777777000；如果 Number 为正数，不能大于 777。 |
|  *places*  | [可选] 要返回的字符数； 如果不是整数，则截尾取整。 |



#### 注释

如果number无效、places为非数值或负值，OCT2BIN 返回 错误值。如果省略 places，则 OCT2BIN 使用必要的最小字符数。Places 可用于在返回的值前置 0（零）。



#### 数据类型

接受数值数据。返回数值数据。



#### 示例

OCT2BIN(77770000)
