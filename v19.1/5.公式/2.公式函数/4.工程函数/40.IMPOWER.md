# IMPOWER

此函数返回复数的 n 次幂。



#### 语法

IMPOWER( *complexnum* , *powernum* )



#### 参数

该函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *complexnum*  | 需要计算其幂值的复数。 |
|  *powernum*  | 需要对复数应用的幂次。 |

powernum 可以为整数、分数或负数。



#### 注释

如果complexnum的文本格式不是 x+yi 或 x+yj或者powernum为非数值型，则返回错误。更多信息，请参考[复数](gcdocsite__documentlink?toc-item-id=c8b1d52a-7442-4f53-85f4-3ef343e42d65)。



#### 数据类型

接受数值和字符串数据。返回字符串数据。



#### 示例

IMPOWER("2+5j",4)
