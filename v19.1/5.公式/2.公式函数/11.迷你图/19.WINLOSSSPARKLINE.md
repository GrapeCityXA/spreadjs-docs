# WINLOSSSPARKLINE

此函数返回用于表示win/loss迷你图的数据集。



#### 语法

WINLOSSSPARKLINE( *data, dataOrientation, [dateAxisData, dateAxisOrientation, setting]* )



#### 参数

| 参数 | 描述 |
|--- |--- |
|  *Data*  | 表示迷你图数据的区域引用。例如：A1:C3。 |
|  *DataOrientation*  | 代表迷你图数据方向的数字，0 为垂直，1 为水平。 |
|  *DateAxisData*  | (可选) 表示迷你图日期轴数据的区域参考。例如：D1:F3。 |
|  *DateAxisOrientation*  | (可选) 代表迷你图日期轴方向的数字，0 为垂直，1 为水平。 |
|  *Setting*  | (Optional)JSON 格式的字符串。<br /><br />例如: "{axisColor:rgb(255,255,0),firstMarkerColor:brown,highMarkerColor:red,lastMarkerColor:blue,lowMarkerColor:green,markersColor:purple,negativeColor:yellowgreen,seriesColor:pink,displayXAxis:true,showFirst:true,showHigh:true,showLast:true,showLow:true,showNegative:true,showMarkers:true,lineWeight:3,displayHidden:false,displayEmptyCellsAs:1,rightToLeft:false,minAxisType:1,maxAxisType:1,manualMax:5,manualMin:-3}".<br /><br /> |



#### 数据类型

返回sparkline.



#### 例子

activeSheet.setFormula(2, 4, '=WINLOSSSPARKLINE(B3:B14,0,A3:A14,0)');
