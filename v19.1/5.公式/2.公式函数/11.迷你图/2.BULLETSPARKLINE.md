# BULLETSPARKLINE

此函数返回用于表示子弹迷你图的数据集。



#### 语法

BULLETSPARKLINE ( *measure, target, maxi, [good, bad, forecast, tickUnit, colorScheme, vertical, measureColor, targetColor, maxiColor, goodColor, badColor, forecastColor, allowMeasureOverMaxi, barSize]* )



#### 参数

| 参数 | 描述 |
|--- |--- |
|  *measure*  | 表示度量栏长度的数字或参考，例如5 或“A1”。 |
|  *target *  | 表示目标行位置的数字或参考，例如 7 或“A2”。 |
|  *maxi*  | 代表迷你图最大值的数字或参考，例如 10 或“A3”。 |
|  *good *  | (可选) 表示good bar的长度的数字或参考，例如 3 或“A4”。默认值为 0。 |
|  *bad *  | (可选)表示bad bar长度的数字或参考，例如 1 或“A5”。默认值为 0。 |
|  *forecast *  | (可选)表示预测线长度的数字或参考，例如 8 或“A6”。默认值为0。 |
|  *tickunit *  | (可选) 表示刻度单位的数字或引用，例如 1 或“A7”。默认值为 0。 |
|  *colorScheme*  | (可选)表示用于显示迷你图的颜色方案的字符串。默认值为“#A0A0A0”。 |
|  *vertical*  | (可选) 一个布尔值，表示是否垂直显示迷你图。默认值为false。 |
|  *measureColor*  | (可选) 表示度量栏颜色的颜色字符串。 |
|  *targetColor*  | (可选) 表示目标线颜色的颜色字符串。 |
|  *maxiColor*  | (可选)表示最大区域颜色的颜色字符串。 |
|  *goodColor *  | (可选) 表示good区域颜色的颜色字符串。 |
|  *badColor *  | (可选) 表示bad区域颜色的颜色字符串。 |
|  *forecastColor *  | (可选)表示预测线颜色的颜色字符串。 |
|  *allowMeasureOverMaxi *  | (可选) 一个布尔值，表示度量是否可以超过最大面积。此参数的默认值为 false。 |
|  *barSize  *  | (可选) 一个大于 0 且等于或小于 1 的数值，表示条形宽度或高度与单元格宽度或高度的百分比。 |



#### 数据类型

返回sparkline.



#### 例子

activeSheet.setFormula(index, 3, '=BULLETSPARKLINE($C' + (index + 1) + ',$B$10,$B$11,$B$12,$B$13,$B' + (index + 1) + ',1,$B$14,false,$B$15,$B$16,$B$17,$B$18,$B$19,$B$20,$B$21,$B$22)');
