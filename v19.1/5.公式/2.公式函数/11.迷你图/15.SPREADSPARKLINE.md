# SPREADSPARKLINE

此函数返回用于表示spread迷你图的数据集。



#### 语法

SPREADSPARKLINE( *points, [showAverage, scaleStart, scaleEnd, style, colorScheme, vertical]* )



#### 参数

| 参数 | 描述 |
|--- |--- |
|  *points*  | 表示包含值的单元格区域的引用，例如“A1:A10”。 |
|  *showAverage*  | (可选)一个布尔值，表示是否显示平均值。默认值为false. |
|  *scaleStart*  | (可选) 表示迷你图最小边界的数字。默认值是所有值中的最小值。 |
|  *scaleEnd*  | (可选) 表示迷你图最大边界的数字。默认值是所有值中的最大值。 |
|  *style*  | (可选) 引用展开迷你图样式的数字。默认值为 4 (poles). |
|  *colorScheme*  | (可选)表示迷你图颜色的字符串。默认值为“#646464”。 |
|  *vertical*  | (可选) 一个布尔值，表示是否垂直显示迷你图。默认值为false. |



#### 数据类型

返回sparkline.



#### 例子

activeSheet.setFormula(2, 2, '=SPREADSPARKLINE(B3:B20,TRUE,,,4,"green")');
