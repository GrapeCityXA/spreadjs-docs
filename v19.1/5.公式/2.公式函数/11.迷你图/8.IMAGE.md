# IMAGE

# 简体中文翻译
该函数通过输入 URL 或 Base64 字符串，在单元格中显示图片。

## 语法
`=IMAGE(source, [alt_text], [sizing], [height], [width], [clipX], [clipY], [clipHeight], [clipWidth], [vAlign], [hAlign])`

## 参数
| 参数 | 说明 |
| ---- | ---- |
| *source* | （必选）图片文件的 URL 路径，需使用 HTTPS 协议。 |
| *alt_text* | （可选）用于辅助阅读功能的图片替代文本。 |
| *sizing* | （可选）指定图片尺寸。<br>可选值如下：<br>0 - 使图片适配单元格并保持宽高比。<br>1 - 填充整个单元格，不保持宽高比。<br>2 - 保持图片原始尺寸，可能超出单元格边界。<br>3 - 通过 height 和 width 参数自定义图片尺寸。<br><br>默认值为 0。 |
| *height* | （可选）图片高度，单位为像素。 |
| *width* | （可选）图片宽度，单位为像素。 |
| *clipX* | （可选）待绘制的源图片子区域左上角的 X 轴坐标。<br>默认值为 0。 |
| *clipY* | （可选）待绘制的源图片子区域左上角的 Y 轴坐标。<br>默认值为 0。 |
| *clipHeight* | （可选）待绘制的源图片子区域高度。<br>默认值为图片自身高度。 |
| *clipWidth* | （可选）待绘制的源图片子区域宽度。<br>默认值为图片自身宽度。 |
| *vAlign* | （可选）图片垂直对齐方式。<br>0 - 顶部对齐<br>1 - 居中对齐<br>2 - 底部对齐<br>默认值为 2（底部对齐）。 |
| *hAlign* | （可选）图片水平对齐方式。<br>0 - 左对齐<br>1 - 居中对齐<br>2 - 右对齐<br>默认值为 0（左对齐）。 |

> **注意**：当数据源为 Base64 格式时，SJS 不支持导入与导出操作。

### 限制说明
跨域 URL 会导致 SpreadJS 无法获取图片信息，且导出为 Excel 文件时图片无法显示。用户可通过编辑单元格重新请求图片信息。

## 数据类型
返回迷你图（sparkline）。

## 示例
```JavaScript
sheet1.setFormula(2, 0, '=IMAGE("https://upload.wikimedia.org/wikipedia/commons/thumb/f/fa/Flag_of_the_People%27s_Republic_of_China.svg/23px-Flag_of_the_People%27s_Republic_of_China.svg.png")');
sheet1.setFormula(3, 0, '= IMAGE("https://upload.wikimedia.org/wikipedia/en/4/41/Flag_of_India.svg")');
```
