# BETA.DIST

此函数返回 Beta 分布。



#### 语法

BETA.DIST( *x* , *alpha* , *beta* , *cumulative* , *lower* , *upper* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *x*  | 用来计算其函数的值，介于值 lower 和 upper 之间。 |
|  *alpha*  | 分布参数。 |
|  *beta*  | 分布参数。 |
|  *cumulative*  | 决定函数形式的逻辑值。如果此参数为true，则该函数返回累积分布函数。如果参数为false，则返回概率密度函数 |
|  *lower*  | [可选]  x 所属区间的下界。 |
|  *upper*  | [可选] x 所属区间的上界。 |



#### 注释

如果省略 lower 或 upper 值，则 BETADIST 使用标准的累积 beta 分布，即 lower = 0，upper = 1。



#### 数据类型

接受除cumulative以外的所有参数的数值数据。接受的cumulative的TRUE或FALSE。返回数值数据。



#### 示例

BETA.DIST(A1,A3,B4,TRUE,1,3)

BETA.DIST(2,8,10,TRUE,1,3) 得出结果 0.6854705810546875
