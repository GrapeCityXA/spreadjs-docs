# pivotby

此函数是一个功能强大的工具，可让您使用公式创建数据汇总。它支持沿两个轴进行分组，并聚合相关联的值。此函数类似于 GROUPBY 函数，但增加了按行和列对数据进行分组的功能。

## 语法

`PIVOTBY(row_fields, col_fields, values, function, [field_headers], [row_total_depth], [row_sort_order], [col_total_depth], [col_sort_order], [filter_array], [relative_to])`

## 参数

该函数具有以下参数：

| **参数** | **说明** |
| --- | --- |
| *行字段（必需）* | 一个列方向的数组或区域，包含用于对行进行分组并生成行标题的值。 |
| *列字段（必需）* | 一个列方向的数组或区域，包含用于对列进行分组并生成列标题的值。 |
| *值（必需）* | 一个列方向的数组或区域，包含要聚合的数据。 |
| *函数（必需）* | 一个 lambda 函数或 eta 简约 lambda（例如 SUM、AVERAGE、COUNT），用于定义如何聚合值。 |
| *字段标题* | 指定行字段、列字段和值是否有标题，以及结果中是否应返回字段标题。 |
| *行总计深度* | 确定行标题是否应包含总计。 |
| *行排序顺序* | 指示行应如何排序。 |
| *列总计深度* | 确定列标题是否应包含总计。 |
| *列排序顺序* | 指示列应如何排序。 |
| *筛选数组* | 一个列方向的一维布尔数组，指示是否应考虑相应的数据行。 |
| *相对于* | 控制向聚合函数的第二个参数提供哪些值，通常与 PERCENTOF 函数一起使用。 |

## 备注

* PIVOTBY 函数支持 Excel 导入和导出。
* PIVOTBY 是一个动态数组函数，会自动将结果填充到所需数量的单元格中。
