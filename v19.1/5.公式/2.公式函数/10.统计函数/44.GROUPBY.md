# groupby

GROUPBY 函数允许您使用公式创建数据汇总。它支持按行字段进行分组并聚合相关值。此外，它还可以对分组数据进行排序和筛选。

## 语法

`GROUPBY(row_fields, values, function, [field_headers], [total_depth], [sort_order], [filter_array], [field_relationship])`

## 参数

该函数有以下参数：

| **参数** | **描述** | **示例** |
| --- | --- | --- |
| row\_fields | 一个面向列的数组或区域，包含用于对行进行分组并生成行标题的值。 | <ul><li>基于一列对行进行分组：`=GROUPBY(A1:A62, E1:E62, SUM)`</li><li>基于多列对行进行分组：`=GROUPBY(A1:B62, E1:E62, SUM)`</li><li>基于不相邻列对行进行分组：`=GROUPBY(CHOOSECOLS(A1:D62, 1, 4), E1:E62, SUM)`</li></ul> |
| values | 要聚合的数据的面向列的数组或区域。 | <ul><li>聚合一列：`=GROUPBY(A1:A62, E1:E62, SUM)`</li><li>聚合多列：`=GROUPBY(B1:B62, E1:G62, MAX)`</li><li>聚合不相邻列：`=GROUPBY(B1:B62, CHOOSECOLS(E1:G62, 1, 3), MEDIAN)`</li></ul> |
| function | 用于汇总分组数据的函数。 | <ul><li>使用一个函数引用：`=GROUPBY(A1:A62, E1:E62, SUM)`</li><li>使用一个 LAMBDA 函数：`=GROUPBY(B1:B62, E1:E62, LAMBDA(a, IF(COUNT(a) > 2, "↑", "↓")))`</li><li>使用 HSTACK 进行多次聚合：`=GROUPBY(B1:B62, E1:E62, HSTACK(COUNT, LAMBDA(a, IF(COUNT(a) > 2, "↑", "↓")), PERCENTOF))`</li><li>使用 VSTACK 进行多次聚合：`=GROUPBY(B1:B62, E1:E62, VSTACK(COUNT, LAMBDA(a, IF(COUNT(a) > 2, "↑", "↓")), PERCENTOF))`</li><li>使用 HSTACK 并重命名聚合的多次聚合：`=GROUPBY(A1:B62, E1:E62, VSTACK(HSTACK(COUNT, LAMBDA(a, IF(COUNT(a) > 2, "↑", "↓"))), {"c", "good"}))`</li><li>使用 VSTACK 并重命名聚合的多次聚合：`=GROUPBY(A1:B62, E1:E62, HSTACK(VSTACK(COUNT, LAMBDA(a, IF(COUNT(a) > 2, "↑", "↓"))), {"c"; "good"}))`</li><li>对多个值列进行多次聚合：列数和聚合数应相同。</li><li>使用临时 LAMBDA 函数进行多次聚合：`=GROUPBY(A1:A13, C1:C13, VSTACK(MAP({1, 2, 3, 4}, LAMBDA(_m, LAMBDA(_x, @INDEX(_x, _m) / SUM(_x)))), "2024 Q" & {1, 2, 3, 4}), 1, 0)`</li></ul> |
| field\_headers [可选] | 一个数字，指定 row\_fields 和 values 是否有标题，以及结果中是否应返回字段标题。<br>选项：<ul><li>缺失（默认） - 根据 values 参数假设数据包含标题</li><li>0 - 否</li><li>1 - 是且不显示</li><li>2 - 否但生成</li><li>3 - 是且显示</li></ul> |  |
| total\_depth [可选] | 确定行标题是否应包含总计。<br>选项：<ul><li>缺失（默认） - 总计以及可能的小计</li><li>0：无总计</li><li>1：总计</li><li>2：总计和小计</li></ul> |  |
| sort\_order | 一个数字，指示应如何对行进行排序。数字对应于 row\_fields 中的列，然后是 values 中的列。如果数字为负，则按降序 / 逆序对行进行排序。<ul><li>缺失（默认）：基于 row\_fields 值按 A 到 Z 的升序排序。</li><li>按多列排序：提供一个一维数字数组，对应于 row\_fields 中的列，然后是 values 中的列。</li></ul> |  |
| filter\_array | 一个面向列的一维布尔数组，指示是否应考虑相应的数据行。 | `=GROUPBY(B:B, E:E, COUNT,, G:G > 200)` |
| field\_relationship | 当为 row\_fields 提供多列时，指定关系字段。<br>选项：<ul><li>0：层次结构（默认） - 后一列字段的排序考虑前一列的层次结构。</li><li>1：表 - 每个字段列的排序是独立进行的。不支持小计，因为它们依赖于具有层次结构的数据。</li></ul> |  |

## 备注

GROUPBY 函数支持 Excel 导入和导出。
