# TREND

此函数返回沿线性趋势的值。



#### 语法

TREND( *y* , *x* , *newx* , *constant* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *y*  | 关系 y = mx + b 中已知道的 y 值集 |
| x | (可选) 在关系 y = mx + b 中可能已经知道的一组可选 x 值 |
|  *newx*  | 要返回其趋势的新 x 值返回对应的 y 值 |
|  *constant*  | 个逻辑值，指定是否强制常量 b 等于0 |



#### 注释

如果 constant 为 TRUE 或省略，b 将按正常计算。如果 constant 为 FALSE，b 将被设为 0（零），m 将被调整以使 y = mx。

如果省略 x，则假设该数组为 {1,2,3,...}，其大小与 y 相同。

如果省略 newx，将假设它和 x 一样。

使用[INDEX](gcdocsite__documentlink?toc-item-id=61ae5b9c-8a40-4dfe-a7ad-ee6c4c7d9cd1)函数从返回的区域中获取单个元素。



#### 数据类型

接受区域。返回区域。



#### 示例

TREND(A2:A7,C2:C7,A9:A10)
