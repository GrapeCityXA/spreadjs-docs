# GROWTH

此函数使用现有数据计算预测的指数等比。 GROWTH 通过使用现有的 x 值和 y 值，返回指定的一系列的新 x 值的 y 值。



#### 语法

GROWTH( *y,x,newx,constant* )



#### 注释

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *y*  | 关系表达式 y = b*m^x 中已知的 y 值集合。 |
| x | (可选)) 关系表达式 y=b*m^x 中已知的 x 值集合。 |
|  *newx*  | GROWTH 返回对应 y 值的新 x 值。 |
|  *constant*  | 一个逻辑值，用于指定是否将常量 b 强制设为 1。 |



如果 const 为 TRUE 或省略，b 将按正常计算。如果 const 为 FALSE，b 将设为 1，m 值将被调整以满足 y = m^x。

如果省略 x，则假设该数组为 {1,2,3,...}，其大小与 y 相同。

如果省略 newx，则假设它和 x 相同。



#### 注释

使用[ INDEX ](gcdocsite__documentlink?toc-item-id=61ae5b9c-8a40-4dfe-a7ad-ee6c4c7d9cd1)函数从返回的数组中获取单个元素。



#### 数据类型

接受区域。返回一个数组。



#### 示例

GROWTH(A2:A7,C2:C7,A9:A10)
