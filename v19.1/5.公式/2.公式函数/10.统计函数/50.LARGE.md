# LARGE

此函数返回数据集中第 n 个最大值。



#### 语法

LARGE( *array* , *n* )



#### 参数

该函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *array*  | 需要确定第 n 个最大值的数组或数据区域。 |
|  *n*  | 返回值在数组或数据单元格区域中的位置（从大到小排）。 |



#### 注释

您可以使用此功能根据其相对位置选择一个值。 例如，您可以使用 LARGE 返回最高、第二或第三的分数。



#### 数据类型

接受所有参数的区域和数值数据。返回数值数据。



#### 示例

LARGE(F1:F8,2)

LARGE(R1C6:R8C6,5)

LARGE({35,31,47,51,37,31,58,39},3) 得出结果 47.0000000000
