# lookup-reference-functions

Spread 提供以下查找和引用函数，按字母顺序列出。

| 函数 | 描述 |
| --- | --- |
| [ADDRESS](gcdocsite__documentlink?toc-item-id=02917ca7-3f46-455d-b78f-9e82f5c78512) | 此函数使用行号和列号在文本中创建单元格地址。 |
| [AREAS](gcdocsite__documentlink?toc-item-id=4a49a10a-3970-43c7-af4a-9819eb2b6ba5) | 此函数返回引用中的区域数。 |
| [CHOOSE](gcdocsite__documentlink?toc-item-id=9df3cfe2-b931-4240-b772-3033fe92041c) | 此函数从值列表中返回一个值。 |
| [COLUMN](gcdocsite__documentlink?toc-item-id=d9b392a5-f08c-4965-a79e-585b162533b6) | 此函数返回引用的列号。 |
| [COLUMNS](gcdocsite__documentlink?toc-item-id=417e53ec-91e5-495c-bcd9-9949817638d1) | 此函数返回数组中的列数。 |
| [FILTER](gcdocsite__documentlink?toc-item-id=52b06b67-ab23-4f26-9984-9637c25d3617) | 此函数筛选区域或数组。 |
| [FORMULATEXT](gcdocsite__documentlink?toc-item-id=d4fb175c-2570-44fa-a188-a3adf2a7ba9b) | 此函数以字符串形式返回公式。 |
| [GETPIVOTDATA](gcdocsite__documentlink?toc-item-id=5208d136-df5b-4687-bd44-9ed37dde89ec) | 此函数提取存储在数据透视表中的数据。 |
| [HLOOKUP](gcdocsite__documentlink?toc-item-id=643bf7c3-c84a-4938-9c6e-11944bf2265b) | 此函数搜索顶行中的值，然后从指定行返回同一列中的值。 |
| [HYPERLINK](gcdocsite__documentlink?toc-item-id=32bd05fa-b70e-4ace-a9cf-39bd6bb9dfca) | 此功能创建一个快捷方式或跳转，以打开存储在网络服务器、内部网或 Internet 上的文档。 |
| [INDEX](gcdocsite__documentlink?toc-item-id=61ae5b9c-8a40-4dfe-a7ad-ee6c4c7d9cd1) | 此函数返回数组或区域内的值或对值的引用。 |
| [INDIRECT](gcdocsite__documentlink?toc-item-id=1d3173c6-a2ac-43f8-819b-ac601e5af35c) | 此函数返回由文本字符串指定的引用。立即评估引用以显示其内容。 |
| [LOOKUP](gcdocsite__documentlink?toc-item-id=2158763e-40ad-4a9e-b063-bd95ea3d2c66) | 此函数从第二个区域中的相同位置搜索一个值并返回一个值。 |
| [MATCH](gcdocsite__documentlink?toc-item-id=fb4b9979-56eb-4ec2-b717-62b5553549e5) | 此函数返回指定项目在区域内的相对位置。 |
| [OFFSET](gcdocsite__documentlink?toc-item-id=597105a1-a478-47a4-8803-09e95b749648) | 此函数返回对区域的引用。区域是一个单元格或单元格区域中指定数量的行和列。该函数返回单个单元格或一系列单元格。 |
| [ROW](gcdocsite__documentlink?toc-item-id=250f1f5e-7053-4089-b223-ef3112f2ce71) | 此函数返回引用中的行数。 |
| [ROWS](gcdocsite__documentlink?toc-item-id=b7cba992-2a18-44ae-b4b1-6b78d542ce29) | 此函数返回数组中的行数。 |
| [SINGLE](gcdocsite__documentlink?toc-item-id=9a9665ff-ba18-4c14-b72a-2f9c031aa8b5) | 当给定值、区域或数组时，此函数返回单个值。 |
| [SORT](gcdocsite__documentlink?toc-item-id=18d8efc2-1921-41e5-a2bf-bbd7e27786b3) | 此函数对区域或数组进行排序。 |
| [SORTBY](gcdocsite__documentlink?toc-item-id=39a428d6-3143-40d0-890c-b79a2e792724) | 此函数根据相应区域或数组中的值对区域或数组进行排序。 |
| [TRANSPOSE](gcdocsite__documentlink?toc-item-id=048e9678-b1d9-4126-8ab3-7e2e40811df0) | 此函数返回单元格的垂直区域作为水平区域或单元格的水平区域作为垂直区域。 |
| [UNIQUE](gcdocsite__documentlink?toc-item-id=9ca457b7-af28-4c27-bf5e-01238afc65f4) | 此函数返回区域或数组中的唯一值。 |
| [VLOOKUP](gcdocsite__documentlink?toc-item-id=9d503391-0bfa-4f93-8b24-3ec827da89c1) | 此函数在最左边的列中搜索值，并从您指定的列中返回同一行中的值。 |
| [XLOOKUP](gcdocsite__documentlink?toc-item-id=1e271c44-04de-44cd-be0f-66063ebc7499) | 此函数在区域或数组中搜索匹配项，并从第二个区域或数组中返回相应的项。默认情况下，使用完全匹配。 |
| [XMATCH](gcdocsite__documentlink?toc-item-id=8eac99a5-8687-4c2a-bde6-af807a2c2b19) | 此函数返回数组中项目的相对位置。默认情况下，需要完全匹配。 |
| [TRIMRANGE](gcdocsite__documentlink?toc-item-id=ab09f8ab-a180-47ed-87a8-99b3a41aaa29) | 此函数会从某个区域或数组的外边缘排除所有空行和/或空列。 |
