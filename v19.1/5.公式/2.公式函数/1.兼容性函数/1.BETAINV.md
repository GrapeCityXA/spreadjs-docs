# BETAINV

本函数返回指定 beta 分布的累积 beta 概率密度函数的反函数。



#### 语法

BETAINV( *prob* , *alpha* , *beta* , *lower* , *upper* )



#### 参数

本函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *prob*  | 与 beta 分布相关的概率。 |
|  *alpha*  | 分布参数。 |
|  *beta*  | 分布参数。 |
|  *lower*  | [可选]  x 所属区间的下界。 |
|  *upper*  | [可选] x 所属区间的上界。 |



#### 注释

如果省略 lower 或 upper 值，则 BETAINV 使用标准的累积 beta 分布，即 lower = 0，upper = 1。



#### 数据类型

接受所有参数的数值数据。 返回数值数据。



#### 示例

BETAINV(0.75,B3,C3,2,4)

BETAINV(0.75,R3C2,R3C3,2,4)

BETAINV(0.75,9,12,2,4) 得出结果 3.0011968805
