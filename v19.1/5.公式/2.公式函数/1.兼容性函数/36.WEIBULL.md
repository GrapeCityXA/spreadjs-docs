# WEIBULL

此函数返回 Weibull 分布。



#### 语法

WEIBULL( *x* , *alpha* , *beta* , *cumulative* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *x*  | 用来计算函数的值。 |
|  *alpha*  | 分布参数。 |
|  *beta*  | 分布参数。 |
|  *cumulative*  | 确定函数的形式。 |



#### 数据类型

除cumulative接受逻辑值(布尔)外，所有参数接受数值数据。返回数值数据。



#### 示例

WEIBULL(3,D4,D5,FALSE)

WEIBULL(50,10,20,TRUE)
