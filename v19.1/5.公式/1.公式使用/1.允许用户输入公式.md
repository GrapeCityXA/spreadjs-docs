# formulauser

用户可以在单元格中输入公式，输入时以等号（=）或加号（+）开头。先输入所需的符号，然后输入公式，例如 =sum(A1+B1) 或 +sum(A1+B1)。您可以使用 **options.allowUserEditFormula** 属性来允许或禁止用户输入公式。
加号（+）的功能与等号（=）相同，习惯使用加号的 Excel 用户在使用 SpreadJS 时无需改变他们的操作习惯。等号仍会自动添加在前面，以便公式按预期运行。例如，在编辑时输入 “+SUM(1,2)”，再次显示时它会变为 “=+SUM(1,2)”。
用户在使用加号（+）输入公式时应注意以下情况：

* 如果输入的值类似于 “+1”，那么这是一个数字而不是公式，会显示为 “1”。
* 如果输入的值是 “+”，那么这是一个字符串而不是公式。
* 如果输入的值类似于 “=++1+++1”，公式就是 “=++1+++1”。

> **注意**：减号（-）的行为与加号（+）相同。

以下代码示例允许用户输入公式。

```javascript
window.onload = function()
{
  var spread =
  new GC.Spread.Sheets.Workbook(document.getElementById("ss"),{sheetCount:3});
  var activeSheet = spread.getActiveSheet(); 

  // 允许用户输入数学公式。
  spread.options.allowUserEditFormula = true;
  activeSheet.setValue(0, 0, 1000);
  activeSheet.setValue(1, 0, 200);
}
```

SpreadJS 还为您提供了将引用单元格的预设格式应用到目标单元格的选项，以进一步加快格式化过程。不过，您可以通过将 **formulaFormatHint** 选项设置为 false 来避免使用预设格式，如下代码所示。

```javascript
spread.options.formulaFormatHint = false; 
```
