# allow-invalid-formula

**SpreadJS** 支持标记那些单元格值为无效公式字符串的单元格。“无效公式” 单元格状态可以为具有与无效公式匹配的字符串值的单元格应用一种样式。
![allow-invalid-formula-pic.fd076e](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/allow-invalid-formula-pic.fd076e.43110f.png)
[CellStatesType](gcdocsite__documentlink?toc-item-id=2af91a4b-28af-4ef5-8ae4-9e34f4e2b414)枚举提供了 [invalidFormula](gcdocsite__documentlink?toc-item-id=2af91a4b-28af-4ef5-8ae4-9e34f4e2b414#invalidformula)选项，用于指示单元格值是一个无效的公式字符串。你还可以查看工作表是否允许输入无效的公式字符串。为此，[GC.Spread.Sheets.IWorkbookOptions](gcdocsite__documentlink?toc-item-id=bd583123-fad0-4361-a362-c84ab97d0515) 接口提供了 [allowInvalidFormula](gcdocsite__documentlink?toc-item-id=bd583123-fad0-4361-a362-c84ab97d0515#allowinvalidformula)选项。通过这个选项，用户可以直接在编辑器中输入无效公式，并且工作表会将其作为字符串保留。该选项的默认值为 false。
下面的代码实现展示了为单元格值设置无效公式状态的过程：

```JavaScript
spread.options.allowInvalidFormula = true;
var style = new GC.Spread.Sheets.Style();
var wholeRange = new GC.Spread.Sheets.Range(0, 0, sheet.getRowCount(), sheet.getColumnCount());
var borderTop = new GC.Spread.Sheets.LineBorder('red', GC.Spread.Sheets.LineStyle.mediumDashed);
var borderBottom = new GC.Spread.Sheets.LineBorder('red', GC.Spread.Sheets.LineStyle.mediumDashed);
var borderLeft = new GC.Spread.Sheets.LineBorder('red', GC.Spread.Sheets.LineStyle.mediumDashed);
var borderRight = new GC.Spread.Sheets.LineBorder('red', GC.Spread.Sheets.LineStyle.mediumDashed);
style.borderTop = borderTop;
style.borderBottom = borderBottom;
style.borderLeft = borderLeft;
style.borderRight = borderRight;
sheet.cellStates.add(wholeRange, GC.Spread.Sheets.CellStatesType.invalidFormula, style, GC.Spread.Sheets.SheetArea.viewport);
```

如果两个或更多状态相交，最后设置的样式具有优先级，并且会与其他样式组合。单元格状态的优先级如下：
编辑 > 悬停 > 活动 > 选中 > 无效公式 > 脏数据 > 无效 > 只读
