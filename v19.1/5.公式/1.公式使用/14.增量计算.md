# incremental-calculations

SpreadJS 提供增量计算支持，通过将 `Workbook` 类的 `incrementalCalculation` 选项设置为 `true`，可在计算过程中将整体任务拆分为多个部分执行。这使得即使面对庞大的计算任务，也能及时响应用户操作。
你可以逐步计算单元格并响应 UI 事件，当工作簿包含大量公式时，该功能可避免 UI 冻结。在计算过程中更新单元格时，被更新的单元格及其依赖单元格会被添加到计算任务队列中。但需注意：若插入/删除行/列或工作表，未完成的计算将被丢弃，后续计算会基于调整后的公式重新执行。
当 `incrementalCalculation` 选项设置为 `true` 时，可通过 `CalculationProgress` 事件跟踪计算进度。以下代码示例展示了如何在该事件中监控进度：

```javascript
// 此示例使用 CalculationProgress 事件记录计算进度
spread.options.incrementalCalculation = true;
spread.bind(GC.Spread.Sheets.Events.CalculationProgress, function (e, info) { 
    let msg = "计算进度："; 
    if (info.pendingCells === 0) { 
        msg += "计算完成"; 
    } else if (info.iterate >= 0) { 
        msg += `迭代计算第 ${info.iterate} 轮，剩余 ${info.pendingCells} 个单元格`; 
    } else { 
        msg += `${info.totalCells - info.pendingCells}/${info.totalCells} 个单元格已计算`; 
    } 
    console.log(msg); 
}); 
```

## 添加状态栏进度显示

当 `incrementalCalculation` 选项启用时，状态栏会自动显示计算进度。以下代码示例展示了如何初始化状态栏并绑定到 Spread 实例：

```javascript
// 初始化状态栏并绑定到 spread，自动显示计算进度
var statusBar = new GC.Spread.Sheets.StatusBar.StatusBar(document.getElementById('statusBar'));
statusBar.bind(spread);
```

## 使用 Web Worker 运行增量计算

**calcWorker 插件** 可将电子表格计算任务卸载到 Web Worker 中执行，在密集型重新计算期间保持主线程响应。启用该插件可提升大型或公式密集型工作簿的性能，避免 UI 冻结。

>type=note
> 自 19 版本起可用。

### 启用方式

#### 方式 1 – 使用脚本文件

1. 在 HTML 文件中引入插件脚本；
2. 将 `incrementalCalculation` 选项设置为 `true`。

    ```html
    <script src="gc.spread.sheets.all.xx.x.x.min.js"></script>
    <script src="plugins/gc.spread.sheets.calcworker.xx.x.x.min.js"></script>
    <script>
    window.onload = function () {
        var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });
        spread.options.incrementalCalculation = true; // 启用增量计算
    };
    </script>
    ```

#### 方式 2 – 使用 NPM 包

1. 安装插件：

    ```bash
    npm install @grapecity-software/spread-sheets-calc-worker
    ```
2. 在代码中导入并启用：

    ```javascript
    import '@grapecity-software/spread-sheets-calc-worker'; // 导入插件
    spread.options.incrementalCalculation = true; // 启用增量计算
    ```

### 验证

启用成功后，计算任务将在浏览器后台线程异步执行。可通过浏览器开发者工具的线程面板查看 `calcWorker.js` 线程，确认插件是否生效。

### 核心功能

* 启用 `incrementalCalculation` 后，公式重新计算将在 Web Worker 中执行（而非主线程）：
    * 支持在计算过程中平滑处理单元格增量更新和用户交互；
    * 计算异步执行，结果完成后返回主线程。
* 禁用 `incrementalCalculation` 时，所有计算直接在主线程执行。

>type=note
> **注意**：
> 可使用 `waitForAllCalculations()` 方法等待所有未完成的计算任务结束。该 API 返回 Promise，同样适用于主线程的增量计算。

### 行为与限制

* **计算优先级**：`calcOnDemand`（按需计算）优先级低于增量计算。启用增量计算后，`calcOnDemand` 选项将自动禁用。
* **暂停计算**：使用 `spread.suspendCalcService()` 可临时暂停所有基于 Worker 的计算。
* **手动计算模式**：当计算模式设置为“手动（manual）”时，calcWorker 不会执行自动重新计算。
* **数据传输限制**：传递给 Worker 的值必须可序列化。不支持将函数或复杂对象（如闭包）作为单元格值。

    ```javascript
      sheet.setValue(1,1,{a:1,f:()=>{return 2;}}); // invalid in worker mode
    ```
* **依赖计算结果的 API**：执行依赖最新计算结果的操作（如排序、导出、汇总）前，需调用 `await waitForAllCalculations()` 确保所有 Worker 任务完成：

    ```javascript
    sheet.suspendPaint();
    for (let i = 0; i < 100; i++) {
     sheet.setFormula(i, 0, `=${100 - i}`);
    }
    sheet.resumePaint();
    await spread.waitForAllCalculations();
    sheet.sortRange(0, 0, 100, 1, true, [{ index: 0, ascending: true }]);
    ```
* **自定义函数**：自定义函数在主线程执行。当 Worker 中的公式遇到自定义函数时，会将计算委托给 UI 线程，结果返回后继续执行。
* **条件格式与视觉元素**：条件格式、形状和图表始终在主线程处理，使用来自 calcWorker 的最新计算结果进行刷新。
