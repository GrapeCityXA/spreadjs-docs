# operatorsinaformula

下表列出了可用的运算符。对于每个运算符，给出了使用字面值以及单元格引用的语法示例。针对每种类型的运算符，都给出了返回值的类型。

| 运算符类型 | 示例语法 | @cols=3:结果 |
| ----- | ---- | --- | --- | --- |
| 运算符 | 描述 | 字面值 & 字面值 | 单元格引用 & 字面值 | 返回类型 |
| @cols=5:二元运算符 |
| + | 加法 | 5 + 3 | A1 + 3 | 双精度浮点数 |
| – | 减法 | 5 – 3 | A1 – 3 | 双精度浮点数 |
| \* | 乘法 | 5 \* 3 | A1 \* 3 | 双精度浮点数 |
| / | 除法 | 5 / 3 | A1 / 3 | 双精度浮点数 |
| ^ | 指数运算 | 5 ^ 3 | A1 ^ 3 | 双精度浮点数 |
| & | 连接 | "F" & "p" | A1 & "p" | 字符串 |
| = | 等于 |  | A1 <> 3 | 布尔值 |
| < > | 不等于 |  | A1 = 3 | 布尔值 |
| < | 小于 |  | A1 <3 | 布尔值 |
| > | 大于 |  | A1 > 3 | 布尔值 |
| <= | 小于或等于 |  | A1 <= 3 | 布尔值 |
| \>= | 大于或等于 |  | A1 >= 3 | 布尔值 |
| @cols=5:一元运算符 |
| - | 取反 | -(5/3) | -(A1/3) | 双精度浮点数 |
| + | 正号 | +(5/3) | +(A1/3) | 双精度浮点数 |
| % | 百分比 | (5/3)% | (A1/3)% | 双精度浮点数 |

运算符指定了你想要对公式中的元素执行的计算类型。对于数学运算，大多数运算符返回双精度浮点数；对于比较运算符，则返回布尔（或逻辑）值。
在SpreadJS中，所有算术运算符（包括一元正号“+”）都会检查其参数，如果任何一个参数是无法转换为数字的字符串，就会返回 #VALUE 错误。这在数学上是正确的行为，无法覆盖。例如，+B5、0+B5 和 --B5 这三个公式应该都产生相同的结果，并且在SpreadJS中确实如此。
