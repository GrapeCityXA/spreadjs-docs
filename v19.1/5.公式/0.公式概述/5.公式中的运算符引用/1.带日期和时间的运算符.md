# opdatetime

你可以将以下几种运算符用于日期和时间的运算，总结如下：

| 运算符 | 运算类型 | 结果 |
| --- | ---- | --- |
| 正号 | + 时间间隔 | 时间间隔 |
| 取反 | \- 时间间隔 | 时间间隔 |
| 加法 | 日期时间 + 时间间隔 | 日期时间 |
| 加法 | 时间间隔 + 日期时间 | 日期时间 |
| 加法 | 时间间隔 + 时间间隔 | 时间间隔 |
| 减法 | 日期时间 - 日期时间 | 时间间隔 |
| 减法 | 日期时间 - 时间间隔 | 日期时间 |
| 减法 | 时间间隔 - 时间间隔 | 日期时间 |

同样适用之前在 [运算优先级](gcdocsite__documentlink?toc-item-id=605bbe82-a009-4cc1-8d46-4a919f9c1050) 中描述的运算优先级顺序，包括括号的使用规则。
如果在日期时间（DateTime）或时间间隔（TimeSpan）的计算中出现异常（例如，`OverflowException` 溢出异常），则该运算符将返回 #NUM! 错误。
