# cellreferences

公式可以引用常量值或单元格引用。如果任何被引用单元格中的值发生变化，公式的结果也会随之改变。如果在公式中使用常量值而不是单元格引用，那么只有在修改公式（或公式中的值）时，结果才会改变。
使用 SpreadJS，您可以使用 [formulaToRanges ](gcdocsite__documentlink?toc-item-id=3db14618-6aaf-4198-b174-826a09082d17#formulaToRanges)方法将特定的单元格区域转换为公式字符串。例如，从行号和列号中返回一个“A1”地址。
有关在公式中使用单元格引用的更多信息，请参阅 [使用单元格引用](gcdocsite__documentlink?toc-item-id=1b735077-3f3e-4722-81d2-642d54cfd3dc)。
如果在公式中的单元格区域之前或之后紧邻添加了新行，那么该区域将不包含新行。
以下主题介绍了不同的表示法样式和引用类型：

* A1 表示法
* R1C1 表示法
* 相对引用和绝对引用

## A1 表示法

每个单元格都可以通过其列字母（从 A 到 Z，然后是 AA 到 ZZ，AAA 到 ZZZ 等）和行号（1 及以上）的组合来引用，总共有 2,147,483,648 行和列。例如，D50 指的是 D 列和第 50 行交叉处的单元格。要引用一个单元格区域，输入该区域左上角单元格的引用、一个冒号（:），然后是该区域右下角单元格的引用。

## R1C1 表示法

每个单元格都可以通过其行号和列号来引用，在行号前加上字母“R”表示行，在列号前加上字母“C”表示列。例如，R1C3 是第一行第三列的单元格。

| A1 单元格引用 | R1C1 单元格引用 | 描述 |
| -------- | ---------- | --- |
| B12 | R12C2 | 第二列（B 列）和第十二行（第 12 行）的单元格 |
| D14:D48 | R14C4:R48C4 | 第四列（D 列）和第 14 行到第 48 行的单元格区域 |
| E16:H16 | R16C5:R16C8 | 第十六行（第 16 行）第五列到第八列（E 列到 H 列）的单元格区域 |
| A25:E70 | R25C1:R70C5 | 前五列（A 列到 E 列）和第 25 行到第 70 行的单元格区域 |

## 相对引用和绝对引用

相对单元格引用是相对于包含公式的单元格位置的单元格引用。绝对引用是一种单元格引用，它总是通过工作表中单元格的确切位置来引用该单元格，而与当前单元格无关。
复制相对引用时，它们会自动调整，但绝对引用不会。该控件可以使用绝对或相对单元格引用。您可以使用 [referenceStyle ](gcdocsite__documentlink?toc-item-id=cbd0a51d-62f0-48b0-8fb7-1855088c327f)属性为工作簿设置单元格引用样式。公式不支持同时包含绝对和相对行或列引用的区域引用。换句话说，区域引用中的起始行和结束行必须匹配（要么都是绝对引用，要么都是相对引用）。
以下表格包含了公式中有效相对单元格引用的示例。

| 函数 | 描述 |
| --- | --- |
| SUM(A1:A10) | 计算第一列中第 1 行到第 10 行的总和 |
| PI( )\*C6 | 将圆周率乘以 C6 单元格中的值 |
| (A1 + B1) \* C1 | 将前两个单元格中的值相加，并将结果乘以第三个单元格中的值 |
| IF(A1>5, A1*2, A1*3) | 检查 A1 单元格的内容是否大于 5，如果是，则将 A1 单元格的内容乘以 2，否则将 A1 单元格的内容乘以 3 |

对于 A1 表示法，在行或列（或两者）前面使用美元符号（$）表示绝对引用。例如：

| A1 单元格引用 | 描述 |
| -------- | --- |
| $A$1 | 绝对第一列，绝对第一行 |
| $A1 | 绝对第一列，相对行号加 1 |
| A$1 | 相对列号加 1，绝对第一行 |
| A1 | 相对列号加 1，相对行号加 1 |

对于 R1C1 表示法，在行号或列号（或两者）周围使用方括号 [ ] 表示相对引用。例如：

| R1C1 单元格引用 | 描述 |
| ---------- | --- |
| R1C1 | 绝对第一行，绝对第一列 |
| R1C[1] | 绝对第一行，相对列号加 1 |
| R[1]C1 | 相对行号加 1，绝对第一列 |
| R[1]C[1] | 相对行号加 1，相对列号加 1 |
| R[-1]C[-1] | 相对行号减 1，相对列号减 1 |

在这种表示法中，方括号内的数字是相对于当前单元格的偏移量。这个数字可以是负整数、正整数或零。完全省略偏移量是表示偏移量为零的一种简写方式。所以，
RC2 等同于 `R[0]C2`
`R[3]C` 等同于 `R[3]C[0]`

## 动态引用

SpreadJS 提供了 **dynamicReferences** 标志，以便在使用与计算相关的公式函数时支持最小化内存使用并提高性能。通过这个标志，跨工作表使用公式函数进行计算的过程变得更快。
**dynamicReferences** 标志接受布尔值，用于启用或禁用 CalcEngine 的动态引用模式。它有助于提高诸如 IF、CHOOSE、SUMIF、SUMIFS、AVERAGEIF、AVERAGEIFS、MAXIFS、MINIFS、COUNTIFS、VLOOKUP 和 HLOOKUP 等公式函数的性能。
默认情况下，**dynamicReferences** 标志的值为 true。为了提高计算性能，应将该标志设置为 false。

> **注意**：应在设置公式或 fromJSON 之前设置 **dynamicReferences** 标志。
> 以下代码片段展示了当 dynamicReferences 选项设置为 false 或 true 时，循环引用会受到怎样的影响。

```JavaScript
spread.options.dynamicReferences = false;
spread.options.iterativeCalculation = false;
sheet.setFormula(0, 1, '=SUMIF(A:A,"a*",B:B)');
sheet.setValue(1, 0, "aaa");
sheet.setValue(1, 1, 123); // 在这里，公式 B1 的结果不会改变。因为 B1 监听 A:A 和 B:B，这是循环引用，并且 iterativeCalculation 为 false。
spread.options.dynamicReferences = true;
spread.options.iterativeCalculation = false;
sheet.setFormula(0, 1, '=SUMIF(A:A,"a*",B:B)');
sheet.setValue(1, 0, "aaa");
sheet.setValue(1, 1, 123); // 在这里，公式 B1 的结果将会改变。因为 B1 监听 A:A 和 B2，而不是 B:B，这不是循环引用，当 iterativeCalculation 为 false 时可以进行计算。
```
