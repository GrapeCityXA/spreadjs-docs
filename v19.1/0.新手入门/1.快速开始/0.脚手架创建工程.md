# quick-start

本页介绍如何使用 `spreadjs-cli` 创建一个 SpreadJS 示例工程。该方式是快速开始的可选路径，适合希望通过模板快速生成 Demo 的开发人员。

如果您希望了解最小代码结构，建议先阅读 [快速开始](gcdocsite__documentlink?toc-item-id=2096e9f0-9e9d-42b7-bcee-2040ebd7cf49)。

## 前提条件

运行脚手架前，请先安装 Node.js 和 npm。

## 创建工程

全局安装 `spreadjs-cli`：

```bash
npm install -g spreadjs-cli
```

创建示例工程：

```bash
spreadjs-cli create my-first-demo
```

根据命令行提示选择框架，目前近支持Vue3、React、Javascript三种框架。
然后根据命令行选择模板，首次体验建议选择基础模板，即`基本电子表格（无表格编辑器）`。

## 运行工程

进入工程目录并安装依赖：

```bash
cd my-first-demo
npm install
```

启动项目：

```auto
npm run start
```

启动成功后，按照终端提示在浏览器中打开本地地址，即可查看生成的 SpreadJS 示例：

## 说明

脚手架会根据所选模板生成工程结构、依赖和示例代码。不同模板的目录结构和启动命令可能略有差异，请以生成项目中的 `package.json` 为准。

如果需要在已有 Vue、React、Angular、NextJS 或 NuxtJS 项目中集成 SpreadJS，请阅读 [框架集成](gcdocsite__documentlink?toc-item-id=94da5d60-da19-4b25-b2a0-5451a909910b)。
