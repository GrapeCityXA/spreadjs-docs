# overview

SpreadJS 是一款运行在浏览器端的类 Excel 电子表格控件。开发人员可以将其嵌入 Web 应用中，为用户提供表格编辑、数据录入、公式计算、样式设置、导入导出和数据可视化等能力。

SpreadJS 的核心对象模型为：

```text
Workbook -> Worksheet -> Range / Cell
```

通常，一个页面中会创建一个 `Workbook` 实例；工作簿中包含多个 `Worksheet`；大多数数据、公式和样式操作都发生在单元格或区域上。

## 适用场景

SpreadJS 适合以下类型的 Web 应用：

* 在线表格编辑和数据填报系统。
* 财务、预算、报表、台账等类 Excel 业务界面。
* 需要公式计算、条件格式、筛选、排序、图表等电子表格能力的业务系统。
* 需要在浏览器端导入、编辑或导出 Excel 文件的应用。

## 产品边界

SpreadJS 是前端表格控件，不是服务端 Excel 文件处理引擎，也不是完整的 BI 平台。

如果您的需求是浏览器端交互式表格编辑、类 Excel 数据录入或前端表格可视化，SpreadJS 可以作为核心控件集成到应用中。

如果您的需求主要是在服务器端批量生成、转换或处理 Excel 文件，应结合服务端文档处理方案评估。

## 常用能力

| 能力 | 说明 |
| --- | --- |
| 工作簿与工作表 | 创建、切换和管理多个工作表。 |
| 单元格与区域 | 设置值、公式、样式、格式、合并单元格等。 |
| 数据处理 | 支持筛选、排序、数据绑定、表格等常见数据操作以及数据透视表、报表、甘特表、集算表等高级数据处理插件。 |
| 公式计算 | 支持大量 Excel 兼容函数和公式计算场景。 |
| 文件能力 | 可按需引入导入导出， `.sjs`、`.xlsx` 、`.ssjson`、`.csv`等文件格式。 |
| 可视化能力 | 可按需引入图表、迷你图、条件格式等能力。 |
