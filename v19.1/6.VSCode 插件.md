# spreadjs-designer-vscode-plugin

SpreadJS设计器VSCode插件将功能完备的SpreadJS设计器集成到Visual Studio Code中，支持用户直接在VSCode工作区内预览并编辑表格文件。
该插件以自定义编辑器形式运行，可适配VSCode的文件系统规则、主题体系以及各类安全限制。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260526.480c25.png?width=800)

## 支持的文件格式

该插件可编辑以下格式文件：

* `.sjs`
* `.ssjson`
* `.xlsx`
* `.xltx`
* `.xlsm`
* `.xltm`
* `.csv`

插件会为上述格式注册自定义编辑器，还可将其设置为VSCode默认打开方式。

## 安装教程

### 环境要求

* 桌面版Visual Studio Code 1.107.0及以上版本
    查看VSCode版本路径：

```auto
帮助 → 关于
```

### 从VSCode应用商店安装

1. 打开Visual Studio Code软件
2. 进入扩展面板（快捷键`Ctrl+Shift+X`）
3. 搜索以下名称：
    1. **Excel SpreadJS Editor**
    2. **GrapeCity**
4. 选择由葡萄城发布的对应插件
5. 点击**安装**按钮
    也可直接前往应用商店网页端完成安装。

### 安装后设置

* 安装完成无需重启软件
* 插件不会自动设为对应文件格式的默认编辑器

设置为默认编辑器步骤：

1. 打开任意一款受支持的文件（例如.xlsx文件）
2. 右键点击文件标签页
3. 选择**使用SpreadJS打开**
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260420.628a17-20260525.276d44.png?width=230)

## VSCode融合适配功能

### 自定义文件菜单栏

由于VSCode依靠本地文件系统管理文件，网页版设计器里的部分操作功能无法在插件中使用。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260312.d9d650-20260525.40b573.png?width=800)

已移除的菜单选项：

* 新建
* 打开
* 导入
* 保存
* 打印

暂不支持打印功能，原因是VSCode插件无法调用`window.print`网页打印接口。

#### 导出功能

导出功能等同于**另存为**
如需保存为SpreadJS专属格式，可通过以下路径操作：
导出 > SpreadJS格式文件
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260312.1755df-20260525.67d155.png?width=800)

### 功能区样式

插件支持两种功能区显示样式：

* `classic`经典样式
* `toolbar`工具栏样式

用户可在设计器界面内自由切换，也能在`settings.json`配置文件中设定默认样式。

```json
{  
"spreadjs": {    
"ribbonMode": "classic"  
}
}
```

![ribbon](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/ribbon-20260526.9cedea.gif?width=800)

### 主题适配

设计器界面可自动跟随VSCode当前启用的主题切换样式：

* 浅色主题 → 界面同步变为浅色
* 深色主题 → 界面同步变为深色
    无需额外手动配置
    ![theme](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/theme-20260526.d7c70b.gif?width=800)

### 语言与区域设置

插件默认沿用VSCode的系统显示语言
用户可手动自定义设置，配置代码如下：

```json
{  
"spreadjs": {    
"language": "zh",    
"culture": "zh-cn"  
}
}
```

### 文件专属图标

插件为以下格式文件配备了专属图标![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260312.1ddd34-20260525.a8a714.png?width=15)：

## 自定义配置

所有相关配置参数均统一写在`settings.json`文件内。

### 工作簿基础配置

该配置仅在新建空白工作簿时生效：

```json
{  
"spreadjs": {    
"workbookOptions": {      
"allowDynamicArray": true,      
"allowInvalidFormula": true    
}  
}
}
```

更多可配置属性可查阅API文档：[GC.Spread.Sheets.IWorkbookOptions](gcdocsite__documentlink?toc-item-id=bd583123-fad0-4361-a362-c84ab97d0515)

### 文件打开与导入配置

该配置在加载各类表格文件时生效：

```json
{  
"spreadjs": {    
"openOptions": {},    
"importOptions": {},    
"importCsvOptions": {}  
}
}
```

参考配置文档：

* [`GC.Spread.Sheets.OpenOptions`](gcdocsite__documentlink?toc-item-id=93a45be2-e7f2-4fef-aa55-44b2d32eaf16#openoptions)
* [`GC.Spread.Sheets.ImportOptions`](gcdocsite__documentlink?toc-item-id=93a45be2-e7f2-4fef-aa55-44b2d32eaf16#importoptions)
* [`GC.Spread.Sheets.ImportCsvOptions`](gcdocsite__documentlink?toc-item-id=93a45be2-e7f2-4fef-aa55-44b2d32eaf16#importcsvoptions)

## 兼容性说明与使用限制

### 版本兼容规则

插件始终搭载最新版SpreadJS运行环境
若文件由其他主次版本的SpreadJS创建，会出现版本兼容限制。

打开这类版本不匹配的文件时：

* 软件弹出版本提示通知
* 禁止直接保存文件，避免用新版本覆盖原有旧版本文件
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260526.cd195e.png)

用户可使用另存为（导出）功能，将内容保存为全新文件。

>type=info
> 文件依旧可以正常编辑，只是无法直接回存为原始版本格式
> ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260526.8161bf.png)

>type=note
> **禁止直接保存的原因**
> 直接保存会将文件强制升级至当前运行环境版本，永久修改文件版本信息。
> 为防止用户无意之间升级文件版本，插件在版本不一致时关闭直接保存功能。

### 快捷键冲突问题

设计器内部的命令面板快捷键和VSCode的转到文件快捷键（Ctrl+P）冲突
现已重新设定快捷键为：

```auto
Ctrl + Alt + P
```
