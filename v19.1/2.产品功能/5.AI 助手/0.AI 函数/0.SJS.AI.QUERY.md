# sjsaiquery

## 总结

**SJS.AI.QUERY** 是 SpreadJS 中的一个动态数组函数，它允许用户向人工智能模型提交查询，以进行智能数据处理和分析。对于需要基于现有数据进行人工智能增强的转换或获取洞察的场景，这个函数特别有用。

## 语法

```javascript
=SJS.AI.QUERY(prompt, array)
```

## **参数**

| 参数 | 描述 |
| ---- | ---- |
| **prompt**<br>必需 | 你希望人工智能模型执行的操作的文本描述 |
| **array**<br>必需 | 输入文本或包含要由该操作处理的文本的单元格引用。 |

**备注**：

* SJS.AI.QUERY 是一个异步公式，在分析过程中会返回 #BUSY!。
* SJS.AI.QUERY 是一个动态数组公式，你需要在工作簿中启用动态数组功能。

## 示例

此公式从范围 **A2:A11** 中读取国家名称，并返回它们相应的首都城市。

```bash
=SJS.AI.QUERY("获取这些国家的首都", A2:A11) 
```
