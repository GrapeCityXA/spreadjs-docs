# data-parsing

数据解析定义在 `fetch()` 过程中，原始数据如何被解释并转换为表记录。
创建表时，`data` 选项可以包含不同的数据格式，例如：

* JSON 数组
* CSV 字符串
* XML 字符串
* 面向列的 JSON 数据

`schema` 配置控制这些原始数据如何转换为 DataManager 可以操作的记录集合。
数据解析由两部分组成：

* [Schema 类型](gcdocsite__documentlink?toc-item-id=2f879ffd-4c70-479d-9fd0-b43d39b6d5cc) - 指定原始数据的解析方式。
* [DataPath](gcdocsite__documentlink?toc-item-id=3ee38c2b-e118-4bf7-80d6-dde2b40d2a6d) - 从解析结果中选择记录集合。

解析过程按以下顺序执行：

1. 根据 `schema.type` 解析原始 `data`。
2. 使用 `dataPath` 解析已解析结果（如果指定）。
3. 最终解析得到的值必须是记录数组。

只有完成这些步骤后，列建模和其他 schema 功能才会生效。
数据解析不定义：

* 列行为
* 数据验证
* 公式
* 层次结构

这些能力需要在 `schema` 中单独配置。
