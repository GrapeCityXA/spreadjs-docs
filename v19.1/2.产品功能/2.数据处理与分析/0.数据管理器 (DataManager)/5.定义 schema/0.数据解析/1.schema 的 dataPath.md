# datapath-of-schema

`dataPath` 属性用于指定记录集合在已解析数据中的位置。
它通常与以下内容一起使用：

* `schema.type = "xml"`
* 嵌套 JSON 结构

在 `fetch()` 期间，数据源会先根据 `schema.type` 解析。
然后使用 `dataPath` 定位用于填充表的记录数组。

## 何时需要 dataPath

当解析后的根值**不是数组**时，必须定义 `dataPath`。
在 `fetch()` 期间，DataManager 期望解析得到的记录集合是数组。如果根解析结果是对象，必须使用 `dataPath` 选择包含记录数组的属性。
如果未指定 `dataPath`：

* 根解析结果会被视为记录集合。
* 如果根值不是数组，`fetch()` 期间会发生错误。

## XML 示例

以下面的 XML 数据为例：

```xml
<root>
    <data>
        <items>
            <row>
                <id>1</id>
                <name>Alice</name>
            </row>
            <row>
                <id>2</id>
                <name>Bob</name>
            </row>
        </items>
    </data>
</root>
```

实际记录位于：

```auto
root.data.items.row
```

配置如下：

```javascript
const table = dataManager.addTable("employees", {
    data: `
<root>
    <data>
        <items>
            <row>
                <id>1</id>
                <name>Alice</name>
            </row>
            <row>
                <id>2</id>
                <name>Bob</name>
            </row>
        </items>
    </data>
</root>
`,
    schema: {
        type: "xml",
        dataPath: "root.data.items.row"
    }
});
```

`fetch()` 之后，表中会包含两条记录。

## 嵌套 JSON 示例

`dataPath` 也可用于嵌套 JSON 数据。
示例：

```javascript
const table = dataManager.addTable("employees", {
    data: {
        meta: { version: 1 },
        payload: {
            items: [
                { id: 1, name: "Alice" },
                { id: 2, name: "Bob" }
            ]
        }
    },
    schema: {
        dataPath: "payload.items"
    }
});
```

表记录会从 `payload.items` 中提取。

## 路径格式

* `dataPath` 使用点表示法。
* 每个片段表示一个嵌套属性。
* 最终解析得到的值必须是记录数组。

如果解析路径不存在，或未引用有效集合，则会在 `fetch()` 期间发生错误。

## 总结

`dataPath`:

* 从已解析数据中选择记录集合
* 常用于 XML
* 可用于嵌套 JSON
* 必须解析为数组

它不定义列或数据行为。
列结构需要使用 `schema.columns` 单独配置。
