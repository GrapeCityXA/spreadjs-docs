# schema-type

`ISchemaOption` 的 `type` 属性定义数据源的解析方式。
它决定 `fetch()` 期间如何解释 `IDataSourceOption` 中提供的 `data` 值。
如果未指定 `type`，默认值为 `"json"`。

```javascript
const table = dataManager.addTable("products", {
    data: [
        { id: 1, name: "Laptop", price: 1200 }
    ],
    schema: {
        type: "json"
    }
});
```

## 支持的类型

支持以下值：

| 类型 | 说明 |
| ---- | ----------- |
| `"json"` | 将数据解析为 JSON 数组（默认）。 |
| `"csv"` | 将数据解析为 CSV 字符串。 |
| `"xml"` | 将数据解析为 XML 字符串。 |
| `"columnJson"` | 解析面向列的 JSON 数据。 |

## JSON（默认）

当 `type` 为 `"json"`（或未指定）时：

* `data` 应为对象数组。
* 如果未定义 `schema.columns`，列会自动从对象键推断。

示例：

```javascript
const table = dataManager.addTable("employees", {
    data: [
        { id: 1, name: "Alice" },
        { id: 2, name: "Bob" }
    ]
});
```

不需要额外配置。

## CSV

使用 `"csv"` 时：

* `data` 必须是 CSV 字符串。
* 该字符串会在 `fetch()` 期间解析。

示例：

```javascript
const table = dataManager.addTable("orders", {
    data: `id,name,amount
1,Alice,100
2,Bob,200`,
    schema: {
        type: "csv"
    }
});
```

如果未将 `type` 设置为 `"csv"`，该字符串不会作为 CSV 解析。

## XML

使用 `"xml"` 时：

* `data` 必须是 XML 字符串。
* 解析会在 `fetch()` 期间执行。
* 在大多数情况下，必须指定 `dataPath` 来定位记录集合。

示例：

```javascript
const table = dataManager.addTable("orders", {
    data: `
<root>
    <row><id>1</id><name>Alice</name></row>
    <row><id>2</id><name>Bob</name></row>
</root>
`,
    schema: {
        type: "xml",
        dataPath: "root.row"
    }
});
```

有关如何从已解析的 XML 数据中选择记录集合，请参阅 **Schema 的 DataPath**。

## ColumnJson

使用 `"columnJson"` 时：

* `data` 应为一个对象，其属性表示列。
* 每个属性都包含一个值数组。
* 行会通过按索引对齐各列值来构建。

示例：

```javascript
const table = dataManager.addTable("employees", {
    data: {
        id: [1, 2, 3],
        name: ["Alice", "Bob", "Cindy"],
        age: [24, 26, 25]
    },
    schema: {
        type: "columnJson"
    }
});
```

在 `fetch()` 期间，面向列的结构会转换为基于行的记录。

## 何时必须指定 schema 类型

在以下情况下，必须显式指定 `schema.type`：

* `data` 值是 CSV 字符串。
* `data` 值是 XML 字符串。
* `data` 值是面向列的 JSON。

对于标准 JSON 数组，可以不显式指定 `"json"`。

<br>
此属性只影响数据的解析方式。
列定义、数据行为和层次结构需要在 `schema` 中单独配置。
