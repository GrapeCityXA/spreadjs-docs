# data-behavior-settings

数据行为设置控制列值在解析后如何验证、转换、建立索引和存储。
核心结构设置定义标识和类型，而行为设置定义列如何参与数据操作。
这些设置会影响：

* 数据完整性
* 值规范化
* 记录结构转换
* 查询性能

它们作用于 DataManager 层，并独立于任何具体视图。

## required

将列标记为插入新记录时必填。

```javascript
columns: {
    name: {
        dataType: "string",
        required: true
    }
}
```

如果创建新行时未为必填列提供值，该记录会被视为无效。
该约束应用于数据层，不限于 UI 验证。

## readonly

防止列值在设置后被修改。

```javascript
columns: {
    id: {
        dataType: "number",
        readonly: true
    }
}
```

只读列：

* 不能通过数据更新操作更改
* 仍然可以参与公式和关系

只读不会阻止列在创建记录期间初始化。

## defaultValue

定义插入新行时使用的默认值。

```javascript
columns: {
    status: {
        dataType: "string",
        defaultValue: "New"
    }
}
```

默认值可以是：

* 常量值
* 公式表达式

只有在插入时未显式提供该字段时，才会应用默认值。

## dataPattern

定义字符串值如何解析为带类型的值。

```javascript
columns: {
    birthday: {
        dataType: "date",
        dataPattern: "dd/MM/yyyy"
    }
}
```

支持的解析场景示例：

* 日期格式字符串
* 自定义小数分隔符
* 布尔真值/假值映射（例如 `"Yes|No"`）

`dataPattern` 只影响解析行为。
它不会改变转换后值在内部的存储方式。

## dataMap

将已存储的值映射为更适合显示的值。

```javascript
columns: {
    product: {
        dataMap: {
            1: "Product-A",
            2: "Product-B"
        }
    }
}
```

注意：

* 底层存储值保持不变。
* 该映射只影响视图级数据展示。

`dataMap` 不会修改表数据，也不会改变原始记录值。

## showNullAs and showEmptyAs

`showNullAs` 和 `showEmptyAs` 定义特殊值的显示方式。

```javascript
columns: {
    Name: {
        showNullAs: "[NULL]",
        showEmptyAs: "[EMPTY]"
    }
}
```

* `showNullAs` 指定 `null` 或 `undefined` 值的显示文本。
* `showEmptyAs` 指定空字符串（`""`）值的显示文本。

这些设置：

* 只影响值的显示方式
* 不修改底层存储数据
* 不改变实际行值

例如，如果记录包含：

```javascript
{ Name: null }
```

存储值仍为 `null`，但显示值会变为 `[NULL]`。

### 视图级覆盖

这些属性也可以在视图列级别定义。

```javascript
columns: {
    Name: {
        showNullAs: "[NULL]",
        showEmptyAs: "[EMPTY]"
    }
}
```

当 schema 级和视图级设置同时存在时：

* 视图级配置会覆盖 schema 级配置。
* schema 级配置会作为所有视图的默认行为。

## spread

如果列包含对象值，`spread` 会在 fetch 期间将其属性展开为单独的列。

```javascript
columns: {
    address: {
        spread: true
    }
}
```

给定数据：

```javascript
{
    id: 1,
    address: {
        city: "Berlin",
        zip: "10000"
    }
}
```

fetch 之后，表结构会展开并包含：

* `address.city`
* `address.zip`

此转换发生在表级别。
与 `dataMap` 不同，`spread` 会在解析后修改表中的记录结构。

## indexed

在表 fetch 完成后为列创建索引。

```javascript
columns: {
    customerId: {
        indexed: true
    }
}
```

启用索引时：

* 内部会创建值到行的映射结构
* 针对此列的筛选和查找操作会更高效

索引会提升查询性能，但也会增加内存使用量。
索引会在 `fetch()` 完成后构建。

## 行为职责

数据行为设置定义：

* 验证约束
* 可变性规则
* 默认值
* 解析行为
* 记录结构展开
* 性能优化

它们不定义：

* 视觉格式
* UI 组件
* 列布局
* 跨表展示

这些能力由高级建模和视图配置单独处理。
