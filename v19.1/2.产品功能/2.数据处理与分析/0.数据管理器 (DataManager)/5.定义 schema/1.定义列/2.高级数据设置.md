# advanced-data-settings

高级数据设置在基础结构和验证之外扩展列能力。
这些设置可以启用：

* 计算列
* 响应式重新计算
* 值域定义
* 感知关系的行为

它们会在 DataManager 级别引入动态行为和关系行为。

## 公式列

当满足以下条件时，列会成为公式列：

* `dataType` 设置为 `"formula"`
* `value` 包含公式表达式

```javascript
columns: {
    TotalUnits: {
        dataType: "formula",
        value: "=[@UnitsInStock] + [@UnitsOnOrder]"
    }
}
```

公式列：

* 不直接映射到原始数据字段
* 按记录逐条计算
* 可以使用结构化引用（`[@FieldName]`）引用其他字段

计算完成后，计算结果的行为类似普通列值。
当依赖字段发生变化时，公式列会重新计算。

## 触发器公式

触发器公式允许列存储值，同时在特定事件期间使用公式对该值进行计算或规范化。

```javascript
columns: {
    Amount: {
        dataType: "number",
        trigger: {
            when: "onNewAndUpdate",
            formula: "=[@UnitPrice] * [@Quantity]",
            fields: "UnitPrice,Quantity"
        }
    }
}
```

触发器定义包括：

* `when` - 公式何时执行
    * `"onNew"`
    * `"onNewAndUpdate"`
* `formula` - 要计算的公式表达式
* `fields` - 触发公式执行的字段（`"onNewAndUpdate"` 必需）

### 触发器行为模型

插入行时：

* 带有 `onNew` 和 `onNewAndUpdate` 的触发器会被计算。

更新行时：

* 只有被监听字段之一发生变化时，触发器才会执行。
* 计算结果会成为该列的存储值。

>type=note
> **重要：**
>
> * 计算出的值会替换先前的值。
> * 触发器公式不应引入循环依赖。
> * 如果触发器监听自身字段，新值会参与计算。

触发器公式与公式列不同：

| 公式列 | 触发器公式 |
| -------------- | --------------- |
| 值始终通过计算得出 | 值会被存储 |
| 动态重新计算 | 仅在指定事件时执行 |
| 不存在持久化覆盖 | 执行后的结果会保留 |

## lookup

`lookup` 属性定义列的值域。
它限制或描述列允许使用的值集合。
支持三种形式：

### 1\. 静态列表

```javascript
columns: {
    Type: {
        lookup: ["Homework", "Quiz", "Exam"]
    }
}
```

列值会被限制在提供的列表中。

### 2\. 关系名称

```javascript
columns: {
    WorkItemID: {
        lookup: "workItem"
    }
}
```

在这种形式中：

* 该列引用关联表
* 必须单独定义关系
* 查找值来自关联表

### 3\. 查找选项

```javascript
columns: {
    WorkItemID: {
        lookup: {
            name: "workItem",
            columns: ["ID", "Description"]
        }
    }
}
```

这种形式指定：

* 关联表
* 哪些字段参与 lookup 配置

### lookup 职责

`lookup` 定义列的值来源。
它：

* 描述允许的值域
* 启用感知关系的行为
* 作为跨表视图的前提条件

lookup 列的实际 UI 展示由视图层处理。

## cross（schema 能力）

定义了 `lookup` 的列可以参与 cross 视图。
虽然 cross 配置通常定义在视图级别，但列必须：

* 具有有效的 lookup 定义
* 参与已定义的关系
* 在表上定义主键

cross 展示逻辑属于视图配置。
在 schema 级别，列只声明其关系能力。

## 高级职责

高级数据设置会引入：

* 计算逻辑
* 事件驱动的重新计算
* 受控值域
* 感知关系的建模

它们扩展列行为，同时独立于展示细节。
视觉渲染和布局行为需要在视图级设置中配置。
