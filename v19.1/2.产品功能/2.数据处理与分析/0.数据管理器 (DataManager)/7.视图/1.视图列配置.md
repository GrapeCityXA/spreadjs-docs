# view-column-configuration

视图由其列定义。
每个列决定：

* 显示哪些数据
* 如何标记
* 如何设置尺寸
* 如何格式化
* 在工作表中如何表现

可以在创建视图时定义列，也可以稍后添加列。

## 列定义模型

列可以定义为：

* 字符串（字段名），或
* 配置对象

### 使用字段名

```javascript
var view = table.addView("myView", [
    "Id",
    "Name",
    "Score"
]);
```

这会使用默认设置包含指定字段。

### 使用列配置对象

```javascript
var view = table.addView("myView", [
    { value: "Id", caption: "ID", width: 60 },
    { value: "Name", caption: "Full Name", width: 150 },
    { value: "Score", width: 80 }
]);
```

配置对象允许完整控制展示和行为。

## 选择和计算列值

`value` 属性定义列显示的内容。
它可以是：

* 宿主表中的字段
* 关联表中的字段
* 公式
* 行级表达式

### 使用关联表字段

```javascript
{ value: "customer.companyName", width: 200 }
```

关联字段需要先定义关系。

### 使用公式

```javascript
{ value: "=[@Score] * 2", caption: "Double Score" }
```

公式可以使用 `@` 引用当前行中的字段。

### 行模板列

```javascript
{ value: "=[@]", caption: "Summary" }
```

这允许通过样式格式化器对整行进行格式化。

## 控制 null 和空值的显示

可以自定义 null 和空值的显示方式。

### 在表 schema 级别

```javascript
var myTable = dataManager.addTable("myTable", {
    data: sampleData,
    schema: {
        columns: {
            Name: { showNullAs: "[NULL]", showEmptyAs: "[EMPTY]" }
        }
    }
});
```

### 在视图列级别

```javascript
{ 
    value: "Phone",
    showNullAs: "[NO PHONE]",
    showEmptyAs: "[BLANK]"
}
```

这些设置只影响值的显示方式，不影响底层数据。

## 列宽和布局

`width` 属性控制列尺寸。
它支持：

* 像素值
* 星号尺寸

### 固定宽度

```javascript
{ value: "Name", width: 150 }
```

### 星号宽度

```javascript
{ value: "Email", width: "2*" }
{ value: "Phone", width: "*" }
```

星号尺寸会按比例分配剩余水平空间。

## 表头配置

可以自定义表头外观和布局。

### 表头样式

```javascript
var headerStyle = {
    font: "italic bold 14pt Calibri"
};

{ value: "Id", headerStyle: headerStyle }
```

### 表头适配模式（TableSheet）

支持的模式：

* `"normal"`（默认）
* `"vertical"`
* `"stack"`

```javascript
{ value: "orderDate", headerFit: "vertical" }
```

表头配置只应用于展示。

## 单元格样式和格式化器

`style` 属性控制列级单元格外观。
示例：

```javascript
{
    value: "Score",
    style: {
        hAlign: "right"
    }
}
```

可以在 style 中定义格式化器：

```javascript
var employeeStyle = {
    formatter: '{{=[@employee.FirstName] & " " & [@employee.LastName]}}'
};

{
    value: "employee",
    caption: "Employee",
    style: employeeStyle
}
```

格式化器可以：

* 使用公式
* 使用模板语法
* 通过 `@` 访问整行数据

这可以在不修改原始数据的情况下实现计算式展示。

## 验证和数据行为

列定义可以包含：

* `readonly`
* `required`
* `defaultValue`
* `validator`
* `isPrimaryKey`

示例：

```javascript
{
    value: "Score",
    required: true,
    validator: {
        type: "number",
        min: 0,
        max: 100
    }
}
```

这些设置会影响在 UI 中编辑数据时的数据行为。

## ViewOptions

除了逐列配置外，还可以定义视图级选项：

```javascript
var view = table.addView("myView", columnInfos, true, {
    defaultColumnWidth: 120,
    showCrossValueHeader: true,
    cross: { /* cross column configuration */ }
});
```

ViewOptions 控制：

* 默认列宽
* 初始样式规则
* cross 列行为

有关详细定义，请参阅 API 参考。
