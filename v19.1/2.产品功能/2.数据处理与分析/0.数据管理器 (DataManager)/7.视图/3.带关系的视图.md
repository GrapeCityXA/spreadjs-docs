# view-with-relationships

视图可以包含关联表中的字段。
这样无需手动合并表，就可以展示连接后的数据。
跨表访问需要先定义关系。

## 前提：定义关系

在视图中使用关联字段前，请先定义表之间的关系。
示例：

```javascript
dataManager.addRelationship(
    orderTable,          // 源表
    "CustomerId",        // 源键
    "customer",          // 导航属性名
    customerTable,       // 目标表
    "Id",                // 目标键
    "orders"             // 反向导航名
);
```

定义关系后：

* `orderTable` 可以访问 `customer`
* `customerTable` 可以访问 `orders`

## 在视图中使用关联字段

关系存在后，可以使用点表示法引用关联字段。
示例：

```javascript
var orderView = orderTable.addView("orderView", [
    { value: "orderId", width: 100 },
    { value: "orderDate", width: 150 },
    { value: "customer.companyName", caption: "Company", width: 200 },
    { value: "customer.contactName", caption: "Contact", width: 150 }
]);
```

此时视图会显示来自以下位置的字段：

* 宿主表（`orderId`、`orderDate`）
* 关联表（`customer.companyName`、`customer.contactName`）

不会发生数据重复。
视图会动态解析关联值。

## 在格式化器中使用关联数据

关联字段也可以用于模板或公式。
示例：

```javascript
var addressStyle = {
    formatter: 'The detailed ship address: {{=CONCAT(@.shipAddress, ", ", @.shipCity)}}'
};

var orderView = orderTable.addView("orderView", [
    { value: "orderId", width: 100 },
    { value: "=[@]", caption: "Address", style: addressStyle, width: "3*" }
]);
```

格式化器可以引用：

* 宿主表字段
* 关联表字段
* 通过 `@` 引用整行上下文

## 关联字段的布局

星号尺寸同样适用于关联字段：

```javascript
var orderView = orderTable.addView("orderView", [
    { value: "customer.companyName", width: "2*" },
    { value: "customer.contactName", width: "*" }
]);
```

列布局行为与数据来自宿主表还是关联表无关。

## 绑定连接视图

定义视图后：

```javascript
orderView.fetch().then(function () {
    tableSheet.setDataView(orderView);
});
```

工作表会按照视图定义渲染连接后的结构。

## 关键特性

* 视图始终属于一个宿主表。
* 关联字段通过已定义的关系访问。
* 使用点表示法引用关联字段。
* 不需要手动编写连接逻辑。
* 数据在表级别保持规范化。
