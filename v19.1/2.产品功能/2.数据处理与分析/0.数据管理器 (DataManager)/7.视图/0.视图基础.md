# view-basics

## 创建视图

在表上使用 [`addView`](gcdocsite__documentlink?toc-item-id=f2382678-7491-4d87-8523-09bfc84e5b68#addview)：

```javascript
var view = table.addView(
    name,
    columnInfos?,
    includeDefaultColumns?,
    options?
);
```

### 参数

* **name** - 视图在表中的唯一名称。
* **columnInfos** - 字段名或列配置对象数组。
* **includeDefaultColumns** - 省略列信息时，是否包含默认表列。
* **options** - 其他视图级配置。

### 示例

假设表包含：

```javascript
var sampleData = [
    { Id: 1, Name: "John Doe", Score: 85 },
    { Id: 2, Name: "Jane Smith", Score: 92 }
];
```

创建表：

```javascript
var myTable = dataManager.addTable("myTable", {
    data: sampleData
});
```

创建视图：

```javascript
var myView = myTable.addView("myView", [
    { value: "Id", caption: "ID", width: 60 },
    { value: "Name", width: 150 },
    { value: "Score", width: 80 }
]);
```

此视图：

* 只包含选定字段
* 将 `Id` 重命名为 `ID`
* 控制列布局

如果未指定列，视图会包含宿主表的所有默认列。

## 初始化视图

创建视图后，应调用：

```javascript
view.fetch();
```

此步骤会初始化视图数据，并使其可用于后续操作。
该方法返回 Promise：

```javascript
view.fetch().then(function () {
    tableSheet.setDataView(view);
});
```

如果需要刷新底层数据源，请使用：

```javascript
view.fetch(true);
```

调用 [`fetch()`](gcdocsite__documentlink?toc-item-id=617d3d21-219e-45fe-b93f-6545f4f53257#fetch) 可确保视图在绑定或访问数据前反映宿主表的最新状态。

## 将视图绑定到工作表

视图会作为 UI 组件的结构化数据源。

### 绑定到 TableSheet

```javascript
view.fetch().then(function () {
    tableSheet.setDataView(view);
});
```

### 绑定到 GanttSheet

```javascript
view.fetch().then(function () {
    ganttSheet.bindGanttView(view);
});
```

工作表会根据视图定义的结构渲染数据。

## 管理视图

每个表都会维护一个视图集合。
可以创建多个视图，以表示同一份表数据的不同布局。

### 添加视图

```javascript
table.addView("summaryView");
```

### 移除视图

```javascript
table.removeView("summaryView");
```

移除视图不会影响底层表数据。

## 管理视图中的列

创建视图后，可以调整列。

### 添加列

```javascript
view.addColumn("Email");
```

### 添加带配置的列

```javascript
view.addColumn({
    value: "Email",
    caption: "Email Address",
    width: 200
});
```

### 移除列

```javascript
view.removeColumn("Email");
```

### 获取列

```javascript
view.getColumn();     // all columns
view.getColumn(1);    // specific column
```

这些操作只会修改视图结构，不会修改底层表 schema。
