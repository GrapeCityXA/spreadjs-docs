# view-styling-and-rules

除了定义结构之外，视图还可以控制数据如何以视觉方式解释并动态计算。
这包括：

* 条件格式
* 迷你图规则
* 视图级样式规则
* 自动重新应用筛选和排序
* 数据长度检查

## 条件格式（列级）

可以使用 `conditionalFormats` 属性直接在列配置中定义条件格式。
这些规则会按单元格计算。

### 基于公式的规则

```javascript
var formulaRule = {
    ruleType: "formulaRule",
    formula: "@ > 50",
    style: {
        backColor: "pink"
    }
};

var myView = productTable.addView("myView", [
    { value: "productId", caption: "ID" },
    { value: "unitPrice", caption: "Unit Price", conditionalFormats: [formulaRule] }
]);
```

* `@` 表示当前单元格值。
* 当公式计算结果为 true 时，会应用该样式。

### 迷你图条件规则

迷你图规则允许直接在单元格中可视化数据。
它们同样通过 `conditionalFormats` 定义。
**子弹图迷你图示例**

```javascript
var bulletRule = {
    ruleType: "sparklineRule",
    sparklineType: "BULLETSPARKLINE",
    sparklineOptions: {
        measure: '@',
        target: 500,
        maxi: 1000,
        good: 700,
        bad: 250
    },
    showSparklineOnly: true
};

var myView = salesTable.addView("salesView", [
    { value: "region", caption: "Region", width: 130 },
    { value: "target", caption: "Target ($K)", width: 100 },
    { value: "actual", caption: "Actual ($K)", width: 100 },
    { value: "actual1", caption: "Performance", width: 220, conditionalFormats: [bulletRule] }
]);
```

**棒棒糖差异图示例**

```javascript
var lollipopRule = {
    ruleType: "sparklineRule",
    sparklineType: "LOLLIPOPVARISPARKLINE",
    sparklineOptions: {
        plannedValue: '[target]',
        actualValue: '$CF_RANGE$',
        index: '@',
        reference: 0,
        mini: -0.3,
        maxi: 0.3
    },
    showSparklineOnly: true
};

var myView = salesTable.addView("salesView", [
    { value: "region", caption: "Region", width: 130 },
    { value: "target", caption: "Target ($K)", width: 100 },
    { value: "actual", caption: "Actual ($K)", width: 100 },
    { value: "actual2", caption: "Variance", width: 220, conditionalFormats: [lollipopRule] }
]);
```

迷你图规则可以在不修改底层数据的情况下进行内联数据可视化。

## 视图级样式规则

除了列级条件格式，还可以在视图级别定义样式规则。
这些规则可以是：

* 基于公式
* 基于状态

### 添加视图级规则

```javascript
view.addStyleRule(
    "dirtyRowStyle",
    { backColor: "yellow" },
    {
        direction: GC.Data.StateRuleDirection.row,
        state: GC.Data.RowColumnStates.dirty
    }
);
```

### 管理视图级规则

```javascript
view.getStyleRule();               // get all rules
view.getStyleRule("ruleName");     // get specific rule
view.removeStyleRule("ruleName");  // remove rule
view.clearStyleRules();            // remove all rules
```

视图级规则会应用于整个视图，而不是单个列。

## 自动重新应用筛选和排序

视图公开两个属性：

```javascript
view.autoFilte
rview.autoSort
```

这些属性控制底层数据变化时，是否自动重新应用现有筛选或排序定义。

* 为 `true`（默认）时，数据更新后会重新计算筛选和排序。
* 为 `false` 时，现有状态会保持不变，直到手动触发。

这些属性只影响运行时行为。

## 数据长度方法

视图提供两个用于检查数据大小的方法：

```javascript
view.length();
view.visibleLength();
```

* `length()` 返回宿主表的总数据长度。
* `visibleLength()` 返回视图中当前可见的数据长度。

根据筛选条件或视图状态，可见长度可能不同于总长度。
