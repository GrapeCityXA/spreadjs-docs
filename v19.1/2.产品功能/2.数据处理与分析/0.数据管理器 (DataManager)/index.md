# data-manager

SpreadJS内置一款名为**数据管理器**的结构化运行时数据建模引擎。
数据管理器是SpreadJS的基础数据层。
集算表、甘特工作表、报表以及数据图表等新版SpreadJS组件，均依托该引擎定义的结构化数据模型运行。
数据管理器规定数据的以下处理形式：

* 数据组织方式
* 数据结构形态
* 数据关联关系
* 数据校验规则
* 数据计算逻辑
* 数据展示预处理

每一个工作簿实例仅对应唯一一个数据管理器实例。
可通过以下代码调取该实例：

```javascript
var dataManager = spread.dataManager();
```

>type=info
> 虽然可以单独实例化GC.Data.DataManager，但手动创建的实例无法与工作簿建立关联。SpreadJS组件仅能调用隶属于工作簿的数据管理器。

## 数据管理器在SpreadJS中的作用

数据管理器负责以下工作：

* 管理结构化数据表
* 定义数据架构与列属性规则
* 搭建数据表之间的关联关系
* 支持层级数据与计算数据的自定义设置
* 生成用于页面展示和组件绑定的数据视图

它在原始数据源与界面组件之间搭建起数据建模中间层。
对象结构逻辑示意如下：

```auto
工作簿  
└─ 数据管理器（单个工作簿对应一个）        
├─ 数据表（可创建多个）        
│     ├─ 数据架构（单个数据表对应一套架构）        
│     │     └─ 数据列（可包含多列）        
│     └─ 数据视图（可创建多个）        
└─ 关联关系（可设置多项）
```

该架构是SpreadJS中所有结构化数据驱动类组件的运行基础。

## 运行环境与设计器

SpreadJS提供两种模式，可完成结构化数据的定义与使用操作：

### 运行环境

开发者借助数据管理器应用程序接口，通过代码编写的方式定义数据表与数据模型。
在运行环境中可执行这些操作：

* 获取工作簿的数据管理器
* 新建数据表
* 设定数据架构
* 构建数据表关联关系
* 创建数据视图

### 设计器

设计器配备可视化配置界面，可实现同等数据模型的定义操作。
在设计器的**数据源面板**中，能够完成下述操作：

* 搭建结构化数据表
* 配置数据架构与列属性
* 建立表间关联
* 开启层级数据功能
* 启用数据校验与格式规范
* 预览配置完成的数据

设计器内的所有配置内容，都会同步映射至运行环境的数据管理器中。
设计器并未增设独立数据体系，只是以可视化编辑形式，操作代码层面可调用的数据表、数据架构与关联关系。
如需了解设计器内的数据模型配置方法，可查阅设计器相关文档。

## 数据管理器的应用价值

集算表、甘特工作表这类结构化组件，无法仅依靠简单平面数组数据运行，还需要依托以下内容：

* 明确的数据表定义
* 列元数据信息
* 数据类型与校验规范
* 数据表间关联关系
* 用于展示的数据视图规则

借助数据管理器，能够实现多项功能：

* 数据绑定组件前，完成结构化数据预处理
* 针对多表业务场景构建关系型数据模型
* 配置层级结构与计算字段
* 单张数据表可复用至多个组件
* 拆分数据建模与界面展示两项工作

数据表一经数据管理器定义，便可实现多种用途：

* 绑定至集算表、甘特工作表
* 作为报表的数据源
* 为数据图表提供可视化数据支撑
* 在同一个工作簿内跨组件重复调用

## 数据建模流程

使用数据管理器建模遵循固定步骤：

1. 获取工作簿的数据管理器
2. 创建一张或多张数据表
3. 设定数据架构与列相关规则
4. 涉及多张数据表时，搭建相互关联关系
5. 制作若干用于展示的数据视图
6. 将视图绑定至结构化组件

本文档依照该建模流程编排内容，同时保证各项核心对象可单独查阅学习。
