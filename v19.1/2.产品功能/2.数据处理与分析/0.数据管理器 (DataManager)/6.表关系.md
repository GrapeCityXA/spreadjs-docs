# tables-relationships

DataManager 支持定义表与表之间的关系。
关系会将一个表中的字段连接到另一个表中的字段。
创建关系后，可以通过关系名称访问关联表中的字段。
关系在 `DataManager` 级别定义。

## 创建关系

使用 [`addRelationship`](gcdocsite__documentlink?toc-item-id=d168d582-7001-4e98-a184-2aafa89215e1#addrelationship) 定义两个表之间的关系。

```javascript
dataManager.addRelationship(
  sourceTable,
  sourceFieldName,
  sourceRelationshipName,
  targetTable,
  targetFieldName,
  targetRelationshipName
);
```

### 参数

* **sourceTable** - 定义关系的源表。
* **sourceFieldName** - 源表中用于匹配的字段。
* **sourceRelationshipName** - 从源表访问关联表时使用的名称。
* **targetTable** - 关联表。
* **targetFieldName** - 目标表中用于匹配的字段。
* **targetRelationshipName** - 从目标表访问源表时使用的名称。

该方法会返回一个描述此关系的 `IRelationship` 对象。

## 示例

```javascript
const dataManager = spread.dataManager();

const orders = dataManager.addTable("orders", {
  data: [
    { orderId: 1, orderDate: "2024-01-01", employeeId: 100 },
    { orderId: 2, orderDate: "2024-01-02", employeeId: 101 }
  ]
});

const employees = dataManager.addTable("employees", {
  data: [
    { employeeId: 100, firstName: "Nancy", title: "Manager", address: "Seattle" },
    { employeeId: 101, firstName: "Andrew", title: "Sales", address: "Tacoma" }
  ]
});

// 创建关系
const relationship = dataManager.addRelationship(
  orders,
  "employeeId",
  "employee",
  employees,
  "employeeId",
  "orders"
);

// 在视图中访问关联字段
const myView = orders.addView("myView", [
  { value: "orderId" },
  { value: "orderDate" },
  { value: "employee.firstName" },
  { value: "employee.title" },
  { value: "employee.address" }
]);
```

在此示例中：

* `"employee"` 是在 `orders` 表上定义的关系名称。
* 可以使用点表示法访问关联表字段：

```javascript
relationshipName.fieldName
```

## 访问关联数据

创建关系后，可以在视图中使用以下方式引用关联字段：

```javascript
relationshipName.fieldName
```

示例：

```javascript
{ value: "employee.firstName" }
```

关系名称相当于指向关联表的导航路径。

## 关系存储

关系存储在 `DataManager` 中。
每次调用 `addRelationship` 都会创建一个新的关系条目。
同一个 `DataManager` 中可以同时存在多个关系。
关系名称由开发者定义。API 不会强制要求关系名称唯一。

## 移除关系

使用 `removeRelationship` 按名称移除关系：

```javascript
dataManager.removeRelationship("employee");
```

移除后，将无法再通过该关系名称访问关联字段。
