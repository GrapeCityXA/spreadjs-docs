# indexes-of-table

## 目的

表索引是一种基于字段的结构，用于提升记录查找操作的速度。
如果没有索引，表在执行搜索时必须扫描所有记录。对于大型数据集，这可能会影响性能。通过在特定字段上创建索引，表可以更高效地定位匹配记录。
索引尤其适用于：

* 某个字段经常被搜索。
* 表包含大量记录。
* TableSheet 等交互式组件需要快速查找。

索引可以提升读取性能，但也会引入额外维护成本。插入、更新和删除操作可能产生少量开销，因为索引字段必须相应更新。
请有选择地为经常查询的字段使用索引。

## 单列索引

DataManager 支持<span class="font-semibold" data-streamdown="strong" style="margin: 0px; padding: 0px; -webkit-font-smoothing: antialiased; box-sizing: inherit; border: 0px solid; --tw-font-weight: 600; font-weight: 600; font-family: ui-sans-serif, -apple-system, system-ui, 'Segoe UI', Helvetica, 'Apple Color Emoji', Arial, sans-serif, 'Segoe UI Emoji', 'Segoe UI Symbol'; line-height: 1.7; color: rgb(248, 250, 252);">单列索引</span>。
调用以下代码时：

```javascript
table.createIndexes(["CompanyName", "City"]);
```

表会为以下字段创建**独立索引**：

* `CompanyName`
* `City`

每个字段都会单独建立索引。

## 创建索引

索引需要显式创建。

```javascript
table.createIndexes(["CompanyName", "City"]);
```

索引不会自动创建。
如果字段上没有索引，搜索操作会回退为线性扫描。

## 索引持久性

索引在以下情况下仍然有效：

* `fetch()` 之后
* 重新加载表数据之后

只有在以下情况下才会移除索引：

```javascript
table.dropIndexes(["City"]);
```

或

```javascript
table.clearIndexes();
```

这使你可以只定义一次索引，并在多次数据重新加载中复用。

## 管理索引

### 删除指定索引

```javascript
table.dropIndexes(["City"]);
```

移除指定字段的索引。

### 清除所有索引

```javascript
table.clearIndexes();
```

移除所有已建立索引的字段。

### 查看已建立索引的字段

```javascript
table.getIndexes();
```

返回当前已建立索引的字段名数组。
如果不存在索引：

```javascript
[]
```
