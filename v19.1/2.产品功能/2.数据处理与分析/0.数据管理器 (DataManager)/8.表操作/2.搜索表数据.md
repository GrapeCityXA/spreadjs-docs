# search-table-data

`search` 方法会检索在给定字段中与指定值完全匹配的记录。
搜索特性：

* 区分大小写。
* 仅完全匹配。
* 返回所有匹配记录。
* 如果没有匹配项，返回空数组。
* 如果字段不存在，返回空数组。
* 如果索引可用，则使用索引。
* 如果没有索引，则回退为线性扫描。

## 使用 search()

```javascript
table.search(value, field);
```

### 参数

* `value` - 要搜索的值。非字符串值会在内部转换为字符串。
* `field` - 目标字段名。

## 返回值

返回匹配记录对象数组。
示例结果：

```javascript
[
  { Month: "Jan", Sales: 120 }
]
```

如果没有匹配记录：

```javascript
[]
```

## 带索引的示例

```javascript
var dataManager = spread.dataManager();

var supplierTable = dataManager.addTable("Supplier", {
  remote: {
    read: { url: apiUrl }
  }
});

supplierTable.fetch().then(function () {
  supplierTable.createIndexes(["CompanyName", "City"]);

  var result =
    supplierTable.search("New Carlisle", "City");

  console.log(result);
});
```

### 假设数据

假设表包含以下记录：

```javascript
[
  { SupplierID: 1, CompanyName: "Tokyo Traders", City: "Tokyo" },
  { SupplierID: 2, CompanyName: "Grand Foods", City: "New Carlisle" },
  { SupplierID: 3, CompanyName: "Sunrise Market", City: "New Carlisle" }
]
```

### 搜索结果

```javascript
[
  { SupplierID: 2, CompanyName: "Grand Foods", City: "New Carlisle" },
  { SupplierID: 3, CompanyName: "Sunrise Market", City: "New Carlisle" }
]
```

如果 `"City"` 已建立索引，查找会使用该索引。
如果 `"City"` 未建立索引，表会执行线性扫描并返回相同结果，但在大型数据集上的性能较低。
