# getting-the-datamanager

每个 Workbook 实例都只包含一个 DataManager。
该实例会在 Workbook 初始化时由内部创建。
可以通过以下方式访问它：

```javascript
var dataManager = spread.dataManager();
```

返回的对象是以下操作的核心入口：

* 创建表
* 管理关系
* 定义结构化数据模型
* 为组件绑定准备数据

Workbook 中的所有结构化数据操作都必须通过此 DataManager 实例完成。

## Workbook 拥有的 DataManager

通过 `spread.dataManager()` 获取的 DataManager 归 Workbook 所有。
以下 SpreadJS 组件：

* TableSheet
* GanttSheet
* ReportSheet
* Data Chart

只会使用 Workbook 内部的 DataManager。
因此：

* 不能替换 Workbook 的 DataManager。
* 不能向 Workbook 注入外部 DataManager。

这样可以确保同一个 Workbook 中的所有结构化组件共享一致的数据模型。

>type=note
> 其他 SpreadJS 功能（例如普通工作表表格、数据透视表、公式和图表）可以直接基于工作表区域运行，不需要 DataManager。
