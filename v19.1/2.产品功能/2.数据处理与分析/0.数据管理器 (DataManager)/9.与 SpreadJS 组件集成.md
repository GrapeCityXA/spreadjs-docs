# integration-with-spreadjs-components

DataManager 为高级 SpreadJS 组件提供结构化数据模型。
它不负责渲染 UI，也不处理交互。
组件会绑定到 Workbook 的 DataManager 中定义的结构化表或视图。

## 集成模式

集成遵循一致的模型：

1. 访问 Workbook 的 DataManager
2. 定义表
3. 按需配置 schema 和关系
4. 创建视图（如有需要）
5. 将视图或表绑定到组件

不同组件会以不同方式使用该模型，但它们都依赖同一个 DataManager 实例。

## TableSheet

TableSheet 会绑定到**视图**。

```javascript
const dataManager = spread.dataManager();

// 定义表
const table = dataManager.addTable("Employees", {
    data: [
        { id: 1, name: "John" },
        { id: 2, name: "Jane" }
    ]
});

// 创建视图
const view = table.addView("employeeView", [
    { value: "id", caption: "ID" },
    { value: "name", caption: "Name" }
]);

await view.fetch();

// 绑定到 TableSheet
const tableSheet = spread.addSheetTab(
    0,
    "Employees",
    GC.Spread.Sheets.SheetType.tableSheet
);

tableSheet.setDataView(view);
```

TableSheet 使用表的视图投影。
所有结构逻辑都保留在 DataManager 中。
有关组件配置详情，请参阅 [TableSheet](gcdocsite__documentlink?toc-item-id=78a1fc3a-e9fa-42ca-9a9a-1a907ddaa35b) 文档。

## GanttSheet

GanttSheet 会绑定到**层次结构视图**。

```javascript
const dataManager = spread.dataManager();

const taskTable = dataManager.addTable("Tasks", {
    data: [
        { id: 1, name: "Planning", parentId: null },
        { id: 2, name: "Execution", parentId: 1 }
    ],
    schema: {
        hierarchy: {
            type: "Parent",
            column: "parentId"
        },
        columns: {
            id: { isPrimaryKey: true }
        }
    }
});

const view = taskTable.addView("taskView", [
    { value: "name", caption: "Task Name" }
]);

await view.fetch();

const ganttSheet = spread.addSheetTab(
    0,
    "Gantt",
    GC.Spread.Sheets.SheetType.ganttSheet
);

ganttSheet.bindGanttView(view);
```

层次结构配置定义在 schema 中。
GanttSheet 会渲染层次结构。
有关组件配置详情，请参阅 [GanttSheet](gcdocsite__documentlink?toc-item-id=1ced61ab-d7e7-47d9-86ba-c30ea995df44) 文档。

## ReportSheet

ReportSheet 使用数据绑定直接绑定到**表**。

```javascript
const dataManager = spread.dataManager();

const orders = dataManager.addTable("Orders", {
    data: [
        { orderId: 1001, customer: "A" },
        { orderId: 1002, customer: "B" }
    ]
});

await orders.fetch();

const reportSheet = spread.addSheetTab(
    0,
    "Report",
    GC.Spread.Sheets.SheetType.reportSheet
);

const template = reportSheet.getTemplate();

template.setTemplateCell(1, 0, {
    type: "List",
    binding: "Orders[orderId]"
});

reportSheet.refresh();
```

ReportSheet 通过绑定表达式使用结构化表数据。
有关组件配置详情，请参阅 [ReportSheet](gcdocsite__documentlink?toc-item-id=cea037a9-3660-4d7a-98e4-57363fb4ea43) 文档。

## Data Chart

Data Chart 使用表数据进行可视化。

```javascript
const dataManager = spread.dataManager();

const price = dataManager.addTable("Price", {
    data: [
        { product: "ItemA", price: 100 },
        { product: "ItemB", price: 120 }
    ]
});

await price.fetch();

const sheet = spread.getActiveSheet();

const chart = sheet.dataCharts.add("chart", 10, 10, 400, 300);

chart.setChartConfig({
    tableName: "Price",
    plots: [{
        type: GC.Spread.Sheets.DataCharts.DataChartType.column,
        encodings: {
            values: [{ field: "price" }],
            category: { field: "product" }
        }
    }]
});
```

图表会按名称引用表。
DataManager 仍然是结构化数据源。
有关组件配置详情，请参阅 [Data Charts](gcdocsite__documentlink?toc-item-id=8a01b66f-3b2c-4ef1-997a-0fcce372b466) 文档。

## 共享数据模型

由于 DataManager 属于 Workbook：

* 多个组件共享同一组表
* 单个表可以支持多个视图
* 更新会传播到已绑定组件

这可以确保整个应用中的数据行为保持一致。

## 职责边界

DataManager 负责：

* 表结构
* Schema 规则
* 关系
* 层次结构配置
* 计算和同步

组件负责：

* 渲染
* 布局
* 交互
* 组件特定命令

每个组件都提供各自的 UI 配置和高级功能文档。

## 将工作表表格转换为数据表

除了通过 DataManager API 直接定义表之外，SpreadJS 还允许将现有工作表表格转换为 DataManager 表。
这使传统工作表表格能够参与结构化数据建模系统，包括：

* Schema 配置
* 视图创建
* 组件绑定
* 数据关系

转换过程会：

* 创建新的 DataManager 表
* 将原始工作表表格绑定到该表
* 将数据管理职责移交给 DataManager

转换后，工作表表格会作为底层 DataManager 表的视图。
可以通过专用 API 以编程方式执行转换，Designer 也提供可视化转换工作流。
有关详细转换规则、约束和示例，请参阅 [Convert from/to Data Table](gcdocsite__documentlink?toc-item-id=2c3bb383-cba6-4c87-9fa4-4f34bb96cee9)。
