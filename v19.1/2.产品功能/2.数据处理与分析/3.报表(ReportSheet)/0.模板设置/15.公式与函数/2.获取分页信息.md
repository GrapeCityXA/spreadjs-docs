# get-pagination-info

报表中的分页详情可通过 `R.CURRENTPAGE` 和 `R.PAGECOUNT` 函数获取，这两个函数支持**报表级**和**分组级**分页场景。

>type=note
> **注意事项**：
> 分组级分页功能从 **v19 版本**开始支持，且仅适用于主从报表（Master-Detail）的行分页场景。

## 分页函数说明

| 函数语法 | 描述 | 参数 |
| ---- | --- | --- |
| `R.CURRENTPAGE(use_grouped_context)` | 返回当前页码 | `use_grouped_context`（可选，布尔类型，默认值 `false`）<br>\- 若为 `true`：返回当前主从分组内的当前页码<br>\- 若为 `false`：返回整个报表的当前页码 |
| `R.PAGECOUNT(use_grouped_context)` | 返回总页数 | `use_grouped_context`（可选，布尔类型，默认值 `false`）<br>\- 若为 `true`：返回当前主从分组内的总页数<br>\- 若为 `false`：返回整个报表的总页数 |

## 示例演示

### 获取全局分页信息

以下示例展示如何显示整个报表的当前页码和总页数。

```auto
// E6 单元格公式
=CONCAT("第 ",R.CURRENTPAGE()," 页，共 ",R.PAGECOUNT()," 页")
```

### 获取分组级分页信息（仅主从报表适用）

以下示例展示如何同时显示**整个报表的分页信息**和**各分组内的分页信息**。

```auto
// E5 单元格公式（全局分页）
=CONCAT("报表总页数：第 ",R.CURRENTPAGE()," 页 / 共 ",R.PAGECOUNT()," 页")
// E6 单元格公式（分组内分页）
=CONCAT("分组内页数：第 ",R.CURRENTPAGE(TRUE)," 页 / 共 ",R.PAGECOUNT(TRUE)," 页")
```
