# preserve-formula-in-export

**导出时保留公式（Preserve Formula in Export）** 功能允许用户将数据导出到 Excel 时，保留原始表格中的公式。

## 适用场景

导出报表时，开发人员常面临一个问题：计算字段或公式会被转换为静态值。这会导致导出的 Excel 文件失去动态计算能力，用户需手动重新输入或重建公式。
通过「导出时保留公式」功能，可避免此类问题：

* **保留计算逻辑**：数据集、模板或计算字段中定义的公式在导出后保持完整，确保 Excel 用户能继续使用动态计算功能，而非仅依赖固定数值。
* **Excel 可编辑性**：导出的工作簿支持终端用户调整单元格值或数据范围，关联公式会自动更新，与原始环境中的表现一致。

## 相关 API

该功能通过 [GC.Spread.Report.TemplateSheet.setTemplateCell](gcdocsite__documentlink?toc-item-id=a1bb51b8-9953-434b-947c-b37b83735c7a#settemplatecell) 方法配置。
在 **静态单元格（StaticCell）** 上应用设置时，需使用 `preserveFormulaInExport`（导出时保留公式）属性。

```typescript
export type StaticCell = {
    type: 'Static',
    preserveFormulaInExport?: boolean; // 导出时保留公式（可选）
    // 其他属性请参考 API 文档
};
```

>type=note
> **注意事项**：
>
> * 公式保留功能仅在 **预览模式（preview mode）** 下可用。
> * 需先正确配置相关 [选项](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0#options)，该功能才能生效。

## 使用示例

```javascript
const templateSheet = reportSheet.getTemplate();
templateSheet.setFormula(3, 3, '=SUM(D2)'); // 为单元格设置公式

// 启用“导出时保留公式”功能
templateSheet.setTemplateCell(3, 3, {
  type: 'Static',
  preserveFormulaInExport: true, // 设置为 true 表示保留公式
});
```
