# cell-states

单元格状态表示单元格将如何响应用户的不同操作。在报表中，随着报表的生成，单元格状态的范围将发生变化。
您可以在报表模板中设置不同的单元格状态，但它仅在预览渲染模式下更有效。

> 注意事项：
>
> * 如果‘`cellStates`’所在的单元格在报表模板上不是扩展单元格，则报告表范围内当前‘`cellStates`’的大小不会改变，但可能会有一些偏移（用于扩展的左上角存在单元格）。
> * 如果‘`cellStates`’放置在报表模板上的单元格是扩展单元格，那么报告表范围内当前‘`cellStates`’的大小将会变化，并且范围将以与模板单元格相同的方式扩展。也可能会有一些偏移（用于扩展的左上角单元格）。

以下代码示例展示了如何在用户悬停或选择报告表中的单元格时应用不同的样式。
这里，报表模板中的单元格状态将随当前单元格的扩展而扩展。因此，样式应用于单行和两列，但单元格状态将扩展到所有行。

```javascript
// 添加单元格状态。
const cfs = templateSheet.conditionalFormats;

// 悬停单元格时显示背景颜色“浅蓝色”。
cfs.addRowStateRule(GC.Spread.Sheets.RowColumnStates.hover, new GC.Spread.Sheets.Style('lightblue'), [new GC.Spread.Sheets.Range(3, 0, 1, 3)]);

// 选中的单元格将具有背景颜色“浅灰色”。
cfs.addRowStateRule(GC.Spread.Sheets.RowColumnStates.selected, new GC.Spread.Sheets.Style('lightgrey'), [new GC.Spread.Sheets.Range(3, 0, 1, 3)]);
```
