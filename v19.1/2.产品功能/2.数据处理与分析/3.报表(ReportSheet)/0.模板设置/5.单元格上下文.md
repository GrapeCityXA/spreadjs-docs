# cell-context

上下文（Context）是报表（ReportSheet）中一个非常重要的概念。它会影响报表的布局，因为默认情况下，它会在所有上下文中过滤子单元格中的数据，并且所有子单元格都会随着上下文重复显示。要在模板单元格中设置上下文，请使用 [Spread.Report.TemplateSheet](gcdocsite__documentlink?toc-item-id=a1bb51b8-9953-434b-947c-b37b83735c7a) 类的 `setTemplateCell` 方法的 `context` 属性。
单个单元格可以有两种上下文：

* **垂直上下文**：在此情况下，单元格将左侧具有垂直溢出方向的单元格用作垂直上下文。
* **水平上下文**：在此情况下，单元格将上方具有水平溢出方向的单元格用作水平上下文。

>type=info
> **注意**：如果一个单元格同时具有垂直上下文和水平上下文，那么它将是一个交叉单元格，用于生成交叉报表。

模板单元格的表现可能会因上下文值的不同而有所不同。

| **上下文** | **值** | **结果** |
| --- | --- | --- |
| @rows=3:Horizontal | 无 | 表示模板单元格没有水平上下文。 |
| 单元格名称 | 将该单元格用作水平上下文。 |
| 默认/未定义 | 将上方的水平溢出单元格用作其水平上下文。 |
| @rows=3:Vertical | 无 | 表示模板单元格没有垂直上下文。 |
| 单元格名称 | 将该单元格用作垂直上下文。 |
| 默认/未定义 | 将左侧的垂直溢出单元格用作其垂直上下文。 |

>type=info
> **注意**：如果一个单元格的水平和垂直上下文值都设置为默认或未定义，并且无法找到左侧的垂直上下文单元格和上方的水平上下文单元格，那么该单元格将使用层次结构的根节点作为其垂直或水平上下文。

**在模板中设置上下文的步骤**：

1. 在数据管理器中定义表数据源。
2. 配置模板单元格中的类型和绑定选项。
3. 在模板单元格中设置 `context` 属性值。

你可以使用以下代码示例为单元格设置垂直和水平上下文。

```javascript
// 将垂直上下文设置为一个单元格。
templateSheet.setTemplateCell(1, 1, {
    type: 'Group',
    binding: `Orders[customerId]`,
    context: {
        vertical: 'A1',
    },
});
// 将垂直上下文设置为无。
templateSheet.setTemplateCell(1, 1, {
    type: 'Group',
    binding: `Orders[customerId]`,
    context: {
        vertical: 'None',
    },
});

// 将水平上下文设置为一个单元格。
templateSheet.setTemplateCell(1, 1, {
    type: 'Group',
    binding: `Orders[customerId]`,
    spillDirection: 'Horizontal',
    context: {
        horizontal: 'A1',
    },
});
// 将水平上下文设置为无。
templateSheet.setTemplateCell(1, 1, {
    type: 'Group',
    binding: `Orders[customerId]`,
    spillDirection: 'Horizontal',
    context: {
        horizontal: 'None',
    },
});

// 为一个单元格同时设置垂直和水平上下文。
templateSheet.setTemplateCell(1, 1, {
    type: 'Summary',
    aggregate: 'Sum',
    binding: `Sales[Sales]`,
    context: {
        vertical: 'A2',
        horizontal: 'B1',
    },
});
```

让我们通过一些具体示例来看看如何设置单元格上下文。
**示例 1：将垂直上下文设置为无**
在下面的示例中，两个单元格 A2 和 B2 被配置为组单元格。单元格 A2 绑定到 *Orders* 数据表中的 *CustomerId* 字段。另一方面，B2 是另一个组单元格，它绑定到 *EmployeeId* 字段。此外，B2 单元格的垂直上下文设置为无。因此，A2 和 B2 单元格不会相互影响，并且会垂直溢出它们的数据。

```javascript
templateSheet.setTemplateCell(1, 0, {  // 单元格 A2
     type: 'Group',
     binding: 'Orders[CustomerId]'
});
templateSheet.setTemplateCell(1, 1, {  // 单元格 B2
     type: 'Group',
     binding: 'Orders[EmployeeId]',
     context: {
         vertical: 'None'
     }
})
reportSheet.refresh();
```

**示例 2：将垂直上下文设置为默认**
在下面的示例中，两个单元格 A2 和 C2 被配置为组单元格。单元格 A2 绑定到 *Orders* 数据表中的 *CustomerId* 字段。然而，C2 绑定到 *EmployeeId* 字段。在这种情况下，模板单元格的垂直上下文未设置（未定义），所以它将左侧的垂直溢出单元格用作其垂直上下文。这里，该单元格是 A2。

```javascript
templateSheet.setTemplateCell(1, 0, {  // 单元格 A2
     type: 'Group',
     binding: 'Orders[CustomerId]'
});
templateSheet.setTemplateCell(1, 2, {  // 单元格 C2
     type: 'Group',
     binding: 'Orders[EmployeeId]'
})
reportSheet.refresh();
```

上述代码的输出结果如下所示。

**示例 3：将垂直上下文设置为单元格名称**
在下面的示例中，两个单元格 A2 和 B3 被配置为组单元格。单元格 A2 绑定到 *Orders* 数据表中的 *CustomerId* 字段。另一方面，单元格 B3 绑定到 *EmployeeId* 字段，并且该单元格的垂直上下文设置为 A2（单元格名称）。当模板单元格的垂直上下文是一个单元格名称时，它将把指定的单元格作为其垂直上下文。因此，在这里，B3 单元格将把 A2 单元格作为其垂直上下文。

```javascript
templateSheet.setTemplateCell(1, 0, {  // A2
          type: 'Group',
          binding: 'Orders[CustomerId]'
});
templateSheet.setTemplateCell(2, 1, {  // B3
          type: 'Group',
          binding: 'Orders[employeeId]',
          context: {
              vertical: 'A2',
          }
})
reportSheet.refresh();
```
