# fill-blank-data

**空白数据填充（Fill Blank Data）** 功能可确保 **列表（list）** 或 **组（group）** 类型 **单元格（cells）** 内的数据集，在需要时自动填充 **空白行（blank rows）** 或 **空白列（blank columns）**，直至满足指定的 **倍数（specified multiple）** 要求。

## 适用场景

生成报表时，开发人员常面临布局错位问题：例如分页报表的最后一页行数可能少于预期，或分组区域中各数据块长度不一致，导致 Excel/PDF 导出结果排版不均。
通过「固定填充数量」功能，这些问题可自动解决：

* **分页与分组一致性**：每页或每个数据块（如组、列表）均填充至指定的行/列倍数，确保报表整体结构统一。
* **非侵入式空白填充**：自动插入空白行/列，不影响筛选、排序功能及数据集本身。
* **输出更整洁**：导出或打印的报表在所有数据块中均保持整洁、专业的布局。

## 相关 API

该功能通过 [GC.Spread.Report.TemplateSheet.setTemplateCell](gcdocsite__documentlink?toc-item-id=a1bb51b8-9953-434b-947c-b37b83735c7a#settemplatecell) 方法配置。
在 **列表单元格（ListCell）** 或 **组单元格（GroupCell）** 上应用设置时，需使用 `fixedFillCount`（固定填充数量）属性。

>type=note
> **注意事项**：
>
> * 取值必须为 **正整数**。
> * 默认值为 **1**，表示不额外填充空白。

```typescript
export type ListCell = DataCellBase & {
    type: 'List';
    fixedFillCount?: number; // 固定填充数量（可选）
    // 其他属性请参考 API 文档
};

export type GroupCell = DataCellBase & {
    type: 'Group';
    fixedFillCount?: number; // 固定填充数量（可选）
    // 其他属性请参考 API 文档
};
```

## 使用示例

### 步骤 1：创建报表

```javascript
let spread = new GC.Spread.Sheets.Workbook("spreadjs-host");

// 创建数据源
var sheet = spread.getActiveSheet();
sheet.tables.add('table1', 0, 0, 8, 5, GC.Spread.Sheets.Tables.TableThemes.light1);
sheet.setArray(0, 0, [
    ['orderId', 'name', 'employeeId', 'unitPrice', 'quantity'],
    ['A001', '铅笔', '1', 1.5, 2],
    ['A002', '笔记本', '1', 5, 1],
    ['A003', '橡皮', '2', 1, 2],
    ['A004', '橡皮', '1', 1, 1],
    ['A005', '铅笔', '2', 1.5, 1],
    ['A006', '铅笔', '2', 1.5, 2],
    ['A007', '笔记本', '2', 5, 1]
]);
// 将 table1 转换为数据管理器表格
sheet.tables.convertToDataTable('table1');

// 创建模板工作表
const reportSheet = spread.addSheetTab(1, '报表', GC.Spread.Sheets.SheetType.reportSheet);
reportSheet.renderMode('Design'); // 设计模式
const templateSheet = reportSheet.getTemplate();

// 为模板设置值和绑定关系
const columns = ['name','employeeId', 'orderId', 'unitPrice', 'quantity'];
columns.forEach((columnName, i) => {
    // 设置表头（首字母大写）
    templateSheet.setValue(0, i, `${columnName[0].toUpperCase()}${columnName.substring(1)}`);
    // 设置模板单元格绑定
    templateSheet.setTemplateCell(1, i, {
      type: 'List',
      binding: `table1[${columnName}]`,
    });
});

// 设置表格底部信息
templateSheet.setValue(2,0,'当前页码：');
templateSheet.setFormula(2,1,'=R.CURRENTPAGE()'); // 当前页码公式
templateSheet.setValue(2,2,'总页数：');
templateSheet.setFormula(2,3,'=R.PAGESCOUNT()'); // 总页数公式

// 设置模板边框样式
const style = new GC.Spread.Sheets.Style();
style.borderTop = new GC.Spread.Sheets.LineBorder("black", GC.Spread.Sheets.LineStyle.thin);
style.borderBottom = new GC.Spread.Sheets.LineBorder("black", GC.Spread.Sheets.LineStyle.thin);
templateSheet.getRange('A:E').setStyle(style);

// 设置分页配置
templateSheet.setPaginationSetting({    
   rowPagination: {       
        paginationDataCell: 'C2', // 分页数据单元格
        rowCountPerPage: 4, // 每页行数
   },    
   titleRow: { // 标题行范围
        start: 0,
        end: 0,
   },
   endRow: { // 底部信息行范围
        start: 2,
        end: 2,
   },
});

// 刷新报表并切换至预览模式
reportSheet.refresh();
reportSheet.renderMode('Preview');
```

### 步骤 2：设置固定填充数量

>type=note
> **注意事项**：
>
> * 支持 **垂直（行）** 和 **水平（列）** 两种扩展方向的填充。
> * 填充逻辑始终 **相对于父节点** 计算。

#### 场景 1：为列表列应用 fixedFillCount

* **配置**：为「名称（Name）」列设置 `fixedFillCount = 2`（填充至 2 的倍数）。
* **效果**：
    * 「名称」列从 7 个列表项扩展为 8 个列表项（7 不足 2 的 4 倍，填充 1 个空白项）。
    * 表格从 7 行扩展为 8 行。

```javascript
reportSheet.renderMode('Design'); // 切换至设计模式

templateSheet.setTemplateCell(1, 0, {
    type: 'List',
    binding: 'table1[name]',
    fixedFillCount: 2 // 设置固定填充数量为 2
});

reportSheet.refresh();
reportSheet.renderMode('Preview'); // 预览模式
```

#### 场景 2：为组列应用 fixedFillCount

* **配置**：将「名称（Name）」列设为分组列，设置 `fixedFillCount = 2`。
* **效果**：
    * 「名称」列从 3 个分组扩展为 4 个分组（3 不足 2 的 2 倍，填充 1 个空白分组）。
    * 表格从 7 行扩展为 8 行。

```javascript
reportSheet.renderMode('Design'); // 切换至设计模式

templateSheet.setTemplateCell(1, 0, {
    type: 'Group',
    binding: 'table1[name]',
    fixedFillCount: 2 // 设置固定填充数量为 2
});

reportSheet.refresh();
reportSheet.renderMode('Preview'); // 预览模式
```
