# pagination

报表表格支持分页功能。该功能允许在报表模板中自定义分页设置，以满足多样化的报表布局需求。要启用分页，请使用`TemplateSheet`类的`setPaginationSetting`方法配置分页设置。
为了对报表进行分页，报表表格将`TemplateSheet`和`TemplateCell`的分页设置以及打印信息中的纸张大小合并成最终的分页设置。

>type=info
> 注意：
>
> * 分页设置仅在分页预览渲染模式下生效。
> * 从版本 19 开始，报表表支持主从报表中的行分页。

报表表格中的分页功能提供了可自定义的报表布局。您可以按行或按纸张大小进行分页。

## 行分页

您可以使用`IPaginationSetting`接口的`RowPagination`成员启用基于行的分页。当每页显示固定数量的行时，这种模式非常有用。
您可以使用以下代码示例设置基于行的分页设置：

```javascript
// Set row pagination.
templateSheet.setPaginationSetting({    
   rowPagination: {       
        paginationDataCell: 'A2',        
        rowCountPerPage: 20,
   },    
   titleRow: {
        start: 0,
        end: 0,
   },
});
```

## 纸张大小分页

您可以使用`IPaginationSetting`接口的`PaperSizePagination`成员启用基于纸张大小的分页。这种模式非常适合打印报表，允许根据纸张大小进行自定义。
您可以使用以下代码示例设置基于纸张大小的分页设置：

```javascript
// Set paper size pagination.
templateSheet.setPaginationSetting({ 
        paperSizePagination: true,
        titleRow: {
                 start: 0,
                 end: 0,
       },
       titleCol: {
                 start: 0,
                 end: 0,
       },
       paginationOrder: 'OverThenDown',   // 'DownThenOver' | 'OverThenDown'
});
```

## 单元格分页设置

报表表格支持各种单元格分页设置，以控制报表中的分页行为。您需要在`setTemplateCell`方法中的特定行/列分页设置中将所需分页属性的值设置为true。

* paginateBeforeRow
* paginateAfterRow
* paginateBeforeColumn
* paginateAfterColumn
* canBreakWhenPaging
* repeatContentWhenPaging

以下代码示例展示了使用`paginateAfterRow`属性设计报表的方法，其中每个订单都显示在单独的页面上。

```javascript
templateSheet.setTemplateCell(3, 0, {
       type: 'Static',
       context: {
            vertical: "A3"
       },
       paginateAfterRow: true, 
});

// Switch to the PaginatedPreview to view the report.
reportSheet.renderMode('PaginatedPreview');
reportSheet.refresh();
```

这里是另一个代码示例，其中`canBreakWhenPaging`和`repeatContentWhenPaging`属性被设置为`true`。
在这种情况下，当单元格扩展到当前页面的最后一行时，可能会因为分页而中断。该行不会在第一页完全显示，并会在下一页重复显示。

```javascript
templateSheet.setTemplateCell(3, 0, {
      type: 'Static',
      context: {
            vertical: "A3"
      },
      canBreakWhenPaging: true, 
      repeatContentWhenPaging: true 
});

// Switch to the PaginatedPreview to view the report.
reportSheet.renderMode('PaginatedPreview');
reportSheet.refresh();
```

## 使用设计器

按照以下步骤为报表表格设置分页设置：

1. 转到 报表设计 选项卡并选择 Pagination Setting（分页设置）。
    将出现 Pagination Setting（分页设置）对话框。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca82939a-5d1a-4838-9f3f-69a0f7ebeeb5/image.46efad.png)
2. 在 Type（类型）下拉列表中选择 Pagination Type（分页类型）。
    可用选项包括 PaperSize Pagination（页面大小分页）和 Row Pagination（数据行分页）。
3. 为标题/行/列的开始和结束设置 Titles And Ends。
4. 在 Page Order（页面顺序）部分，选择 Down, then over（向下，然后向右）或 Over, then down（向右，然后向下）。
    每个选项的方向将在预览框中显示。

此外，您可以在每个报告中重复标题/行/列的结束。要重复标题或结束列，请在 contextMenu（上下文菜单）中选择 Set Repeat Title Columns（设置重复标题列）或 Set Repeat End Columns（设置重复结束列）。
