# template-sheet-setting

TemplateSheet 指的是报表的模板。它包括许多与报告相关的参数以及解释许多与报告相关的概念。
由于TemplateSheet是工作表的扩展，您也可以将其视为工作表。
您可以使用`TemplateSheet`类的各种方法和属性来配置报告模板的设置。
