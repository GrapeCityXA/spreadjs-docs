# outlinecolumn

在 SpreadJS 中，分级显示列是指对列中的文本进行缩进，以便在电子表格中创建一种树状结构，从而更好地组织数据。
当你想要在电子表格的行之间添加层级关系，并使用内置的展开和折叠用户界面时，这一功能尤为有用。此外，当你在处理电子表格中的大量数据，需要创建项目计划任务和项目计划子任务层级结构、财务报表以及物料清单文档时，分级显示列也能提供很大的帮助。
用户可以在工作表中对列进行分级显示，同时还能添加复选框、图片以及折叠和展开图标。
以下图片展示了一个带有折叠和展开图标、复选框、图片以及行分级显示的分级显示列。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/indentcolumn.png)
你可以使用 [showRowOutline ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#showrowoutline)方法在工作表中实现折叠和展开图标。树状结构中的层级对应缩进的次数。
你还可以按层级自定义图片、显示自定义指示符、显示复选框，并使用 `outlineColumn.options` 设置最大层级。

以下代码示例展示了在区域分组中添加和删除分级显示的操作。

```JavaScript
$('#button1').click(function () {
    var activeSheet = spread.getActiveSheet();
    activeSheet.suspendPaint();

    // 分级显示列
    activeSheet.rowOutlines.group(0, 4);
    activeSheet.rowOutlines.group(0, 1);
    activeSheet.rowOutlines.group(2, 1);

    // 设置分级显示列
    activeSheet.columnOutlines.group(0, 4);
    activeSheet.columnOutlines.group(0, 1);
    activeSheet.columnOutlines.group(2, 1);
    activeSheet.resumePaint();
});

$('#button2').click(function () {
    var activeSheet = spread.getActiveSheet();
    activeSheet.suspendPaint();

    // 移除分组
    activeSheet.rowOutlines.ungroupRange(0, 4);
    activeSheet.rowOutlines.ungroupRange(0, 1);
    activeSheet.rowOutlines.ungroupRange(2, 1);

    // 移除分组
    activeSheet.columnOutlines.ungroupRange(0, 4);
    activeSheet.columnOutlines.ungroupRange(0, 1);
    activeSheet.columnOutlines.ungroupRange(2, 1);
    activeSheet.resumePaint();
});
```

以下代码示例实现了展开和折叠组分级显示。

```JavaScript
window.onload = function() {
    var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"), { sheetCount: 3 });
    var activeSheet = spread.getActiveSheet();
    activeSheet.suspendPaint();

    // 设置行的分级显示
    activeSheet.rowOutlines.group(0, 4);
    activeSheet.rowOutlines.group(0, 1);
    activeSheet.rowOutlines.group(2, 1);

    // 设置列的分级显示
    activeSheet.columnOutlines.group(0, 4);
    activeSheet.columnOutlines.group(0, 1);
    activeSheet.columnOutlines.group(2, 1);
    activeSheet.resumePaint();

    $("#button1").click(function() {
        // 获取行分级显示的最大层级
        var rgl = activeSheet.rowOutlines.getMaxLevel();
        for (var index = 0; index <= rgl; index++) {
            // 展开行的分级显示
            activeSheet.rowOutlines.expand(index, true);
        }
        // 获取列分级显示的最大层级
        var cgl = activeSheet.columnOutlines.getMaxLevel();
        var gi = [];
        var colCount = activeSheet.getColumnCount();
        for (var index = 0, i = 0; index <= cgl; index++) {
            for (var col = 0; col < colCount; col++) {
                // 获取指定列和层级的分组信息
                var groupInfo = activeSheet.columnOutlines.find(col, index);
                if (groupInfo) {
                    gi[i] = groupInfo;
                    i++;
                    col = groupInfo.end;
                }
            }
        }

        for (var i = 0; i < gi.length; i++) {
            // 展开列的分组
            activeSheet.columnOutlines.expandGroup(gi[i], true);
        }
        activeSheet.invalidateLayout();
        activeSheet.repaint();
    });

    $("#button2").click(function() {
        // 获取行分级显示的最大层级
        var rgl = activeSheet.rowOutlines.getMaxLevel();
        for (var index = 0; index <= rgl; index++) {
            // 折叠行的分级显示
            activeSheet.rowOutlines.expand(index, false);
        }

        // 获取列分级显示的最大层级
        var cgl = activeSheet.columnOutlines.getMaxLevel();
        var gi = [];
        var colCount = activeSheet.getColumnCount();
        for (var index = 0, i = 0; index <= cgl; index++) {
            for (var col = 0; col < colCount; col++) {
                // 获取指定列和层级的分组信息
                var groupInfo = activeSheet.columnOutlines.find(col, index);
                if (groupInfo) {
                    gi[i] = groupInfo;
                    i++;
                    col = groupInfo.end;
                }
            }
        }

        for (var i = 0; i < gi.length; i++) {
            // 折叠列的分组
            activeSheet.columnOutlines.expandGroup(gi[i], false);
        }
        activeSheet.invalidateLayout();
        activeSheet.repaint();
    });
}
```

> **注意**：此功能存在以下限制：
>
> * 当你插入行时，新行的级别与所选行的上一行级别相同。
> * `sortRange` 方法会重新计算缩进文本并刷新缩进列。
> * 拖动填充和拖动移动操作仅会更改单元格内容。
> * 复制和粘贴操作仅会更改单元格内容。
