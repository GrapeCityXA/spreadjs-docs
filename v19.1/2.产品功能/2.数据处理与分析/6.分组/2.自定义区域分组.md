# CustomizingtheRangeGroups

SpreadJS 支持对区域组进行自定义设置，这样既能提升工作表的外观效果，又能使用户方便、高效地组织和处理数据。
你可以设置自定义背景颜色、边框颜色（轮廓区域）、图标背景颜色、数字和“+/-”的字体颜色、数字和“+/-”的背景图片、按钮边框颜色、线条颜色、线条宽度以及点的颜色，如下图所示：
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/custom-range-group.337954.png)
下面分享一张表格，列出了可自定义的区域组属性，以及对应的 CSS 类和 CSS 属性：

| **区域组属性** | **CSS 类名** | **CSS 属性** | **附加说明** |
| ----- | ------ | ------ | ---- |
| 轮廓区域背景颜色 | @rows=2:`gc-group` | `background-color` |  |
| 轮廓区域边框颜色 | `color` |  |
| 图标背景颜色 | @rows=3:`gc-group-box` | `background-color` |  |
| 数字和“+/-”的字体颜色 | `color` |  |
| 按钮边框颜色 | `border-color` | 此属性将使用 CSS 中的 `border-top-color`，并将忽略任何其他边框颜色。 |
| 数字“+”的背景图片 | `gc-group-box-expand` | `background-image` | 用户设置 `background-image` 时，默认边框颜色和背景颜色为透明。<br>如果未设置背景图片，默认将使用 `gc-group-box` 中定义的样式。<br>如果定义的 CSS 中包含多个背景图片，只有第一个背景图片会生效。 |
| 数字“-”的背景图片 | `gc-group-box-collapsed` | `background-image` | 用户设置 `background-image` 时，默认边框颜色和背景颜色为透明。<br>如果未设置背景图片，默认将使用 `gc-group-box` 中定义的样式。<br>如果定义的 CSS 中包含多个背景图片，只有第一个背景图片会生效。 |
| 线条颜色 | @rows=2:`gc-group-line` | `border-color` | 此属性将使用 CSS 中的 `border-top-color`，并将忽略任何其他边框颜色。 |
| 线条宽度 | `border-width` | 此属性将使用 CSS 中的 `border-top-width`，并将忽略任何其他边框颜色。 |
| 点的颜色 | `gc-group-dot` | `color` |  |

以下代码示例展示了在处理电子表格时如何自定义区域组的属性：

```css
    .gc-group {
        background-color: rgb(180, 211, 230);
        color: #999999;
        border-width: 0px;
        border-style:solid;
    }
    .gc-group-box {
        background-color: #fff;
        color: rgb(8, 154, 245);
        border-color:rgb(32, 158, 241);
    }
    .gc-group-line{
        border-width:2px;
        border-style:solid;
        border-color:rgb(137, 199, 243);
    }
    .gc-group-dot{
        color:blue;
    }
```

> **注意**：在同一页面上，无法为不同的电子表格元素自定义多个不同的 CSS 样式。
