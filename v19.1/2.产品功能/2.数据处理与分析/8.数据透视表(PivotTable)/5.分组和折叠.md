# group-and-collapse

SpreadJS 支持在数据透视表中执行分组和折叠操作，帮助您更便捷地查看和展示所需数据。
当数据透视表包含大量可进一步汇总的数据时，该功能尤为实用。您可以按日期、文本和数字三种类型对数据进行分组，具体操作如下：

## 分组日期

SpreadJS 允许对数据透视表中的日期时间类型字段进行分组和取消分组。您可以根据不同的时间间隔（如秒、分钟、小时、天、月、季度或年）分组数据，还可自定义起始和结束时间，通过 `dateGroups` 属性实现该功能。
下图展示了 2020 年数据按季度分组的效果：
![按季度分组日期]((/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.46b6a3.png?width=600))

```javascript
// 按日期分组
let groupInfo = {
    originFieldName: 'date', // 原始字段名
    dateGroups: [
        { by: GC.Pivot.DateGroupType.quarters }, // 按季度分组
        { by: GC.Pivot.DateGroupType.years },    // 按年份分组
        { by: GC.Pivot.DateGroupType.months }    // 按月份分组
    ],
};
pivotTable.group(groupInfo); // 执行分组
// 添加分组字段到列区域
pivotTable.add('Years (date)', 'Years (date)', GC.Spread.Pivot.PivotTableFieldType.columnField);
pivotTable.add('Quarters (date)', 'Quarters (date)', GC.Spread.Pivot.PivotTableFieldType.columnField);
pivotTable.add('Months (date)', 'Months (date)', GC.Spread.Pivot.PivotTableFieldType.columnField);
```

### 自动日期分组

借助透视表面板向透视表中添加日期类型字段时，SpreadJS 支持自动日期分组功能。
开启该功能后，日期字段会自动按照年份、季度、月份等时间维度形成日期层级结构，无需手动进行分组操作。

>type=info
> 为保持向下兼容性，该功能默认处于关闭状态。
> ![自动分组动图](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/autoGroup-20260310.efe66c-20260525.130c00.gif?width=800)

#### 开启自动日期分组

你可在程序运行阶段或设计器中开启自动日期分组功能。

1. 通过`透视表变更`事件开启

    ```javascript
    sheet.bind(GC.Spread.Sheets.Events.PivotTableChanging, function (sender, args) {    
    args.autoGroupDateField = true;
    });
    ```

    将`args.autoGroupDateField`设置为`true`，即可为新增的日期字段开启自动分组功能。
2. 通过设计器配置开启

    ```javascript
    designer.setData("autoGroupPivotDateField", true);
    ```

    该配置效果与在`透视表变更`事件中将`args.autoGroupDateField`设为`true`完全一致。

#### 分组规则

分组层级由字段内的日期范围决定。
SpreadJS 会读取字段内的日期最大值与最小值，依据二者之间的时间跨度判定分组层级。
系统将按照**年份→月份→日期→小时→分钟→秒**的层级顺序依次判定时间范围。
程序根据日期数据中差异最大和差异最小的时间分量，选定对应的分组层级，具体规则如下：

| 最高差异维度 | 最低差异维度 | 分组依据 |
| ------ | ------ | ---- |
| 年份 | 任意 | 年份、季度、月份 |
| 月份 | 任意 | 月份、日期 |
| @rows=4:日期 | 日期 | 无分组 |
| 小时 | 日期、小时 |
| 分钟 | 日期、小时、分钟 |
| 秒 | 日期、小时、分钟、秒 |
| @rows=3:小时 | 小时 | 小时 |
| 分钟 | 小时、分钟 |
| 秒 | 小时、分钟、秒 |
| 分钟 | 任意 | 小时、分钟 |
| 秒 | 任意 | 小时、分钟、秒 |

>type=info
> **注意事项：**
>
> * 若字段内最大日期与最小日期完全一致，则不会执行任何分组操作。
> * 若测算出的时间跨度无需拓展层级，系统会精简分组维度甚至直接跳过分组。
> * 当数据源发生变动或透视表完成刷新后，起止日期会同步更新为最新的日期极值。
> * 若日期字段中存在空值或空白数据，自动分组功能将不会生效。

## 分组文本

您可以使用 `textGroup` 方法对数据透视表的行标签或列标签项进行分组，通过 `add` 方法将新组添加到数据透视表中，添加文本组时会自动创建对应新字段。
下图展示了按行标签项创建的文本分组效果：
![文本分组效果](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.31512e.png?width=600)

```javascript
// 按文本项分组
myPivotTable.views.apply("empty_pt"); // 应用空白视图模板
// 添加原始字段到行区域
myPivotTable.add("Region", "Region", GC.Spread.Pivot.PivotTableFieldType.rowField);
// 添加数值字段到值区域（求和计算）
myPivotTable.add("Quantity", "Sum of quantity", GC.Spread.Pivot.PivotTableFieldType.valueField, GC.Pivot.SubtotalType.sum);
let groupInfo = {
    originFieldName: "Product", // 原始文本字段名
    textGroup: {
        fieldName: "NewProduct", // 新分组字段名
        groupItems: { // 分组规则：键为组名称，值为对应原始项数组
            Drinks: ['Coffee', 'Juice'], // 饮品组：包含咖啡、果汁
            Chocolate: ['Dark', 'White', 'Milk'], // 巧克力组：包含黑巧克力、白巧克力、牛奶巧克力
            Others: ['Breads', 'Cheese puffs', 'Cookie'] // 其他组：包含面包、奶酪泡芙、饼干
        }
    }
};
myPivotTable.group(groupInfo); // 执行分组
// 将新分组字段添加到列区域
myPivotTable.add("NewProduct", "TestProduct", GC.Spread.Pivot.PivotTableFieldType.columnField);
```

## 分组数字

创建频率分布表时，可对数值字段进行分组（而非单独显示每个数值），通过将数值归入不同范围便于分析。
您可以使用 `numberGroup` 方法实现数值分组，下图展示了数量字段的频率分布效果：
![数字分组频率分布](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.608097.png)

```javascript
// 按数字分组
myPivotTable.views.apply('empty_pt'); // 应用空白视图模板
// 添加数值字段到行区域
myPivotTable.add('Quantity', 'Quantity', GC.Spread.Pivot.PivotTableFieldType.rowField);
// 添加区域字段到列区域
myPivotTable.add('Region', 'Region', GC.Spread.Pivot.PivotTableFieldType.colField);
// 添加产品字段到值区域（计数计算）
myPivotTable.add('Product', 'Count of quantity', GC.Spread.Pivot.PivotTableFieldType.valueField, GC.Pivot.SubtotalType.count);
let groupInfo = { 
    originFieldName: 'Quantity', // 原始数值字段名
    numberGroup: { by: 30 } // 分组规则：按30为间隔分组（如0-30、31-60等）
};
myPivotTable.group(groupInfo); // 执行分组
```

## 折叠组

通过 `collapse` 方法可展开或折叠数据透视表中的特定组或整个透视字段，参数说明：

* 第一个参数：透视字段名
* 第二个参数：组名称（可选，不指定则操作整个字段）
* 第三个参数：`true` 表示折叠，`false` 表示展开

下图展示了“东部地区”“面包类”“巧克力类”字段被折叠的效果：
![折叠组效果](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.26bf57.png)

```javascript
// 折叠某些组
myPivotTable.collapse('Region', 'East', true); // 折叠“Region”字段下的“East”组
myPivotTable.collapse('Category', 'Bakery', true); // 折叠“Category”字段下的“Bakery”组
myPivotTable.collapse('Category', 'Chocolates', true); // 折叠“Category”字段下的“Chocolates”组
// 展开区域组
myPivotTable.collapse('Region', 'East', false); // 展开“Region”字段下的“East”组
```

## 隐藏折叠按钮

通过 `showDrill` 选项可控制数据透视表中展开/折叠按钮（透视项目标题左侧的“+”或“-”按钮）的显示状态。
![折叠按钮显示/隐藏效果](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.f012b7.png)

```javascript
// 隐藏展开和折叠按钮
myPivotTable.options.showDrill = false; // true 显示（默认），false 隐藏
```
