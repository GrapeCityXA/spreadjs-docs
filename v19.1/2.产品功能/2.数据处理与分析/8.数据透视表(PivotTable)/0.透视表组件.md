## 透视面板

透视面板是一个任务窗格，可用于轻松添加、删除、拖动和移动透视表中的字段。数据透视表面板由数据透视表字段、数据透视表区域和数据透视表管理器部分组成，如下图所示：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260519.01ab49.png)
您还可以使用panelLayout选项自定义透视面板的布局。上图显示了默认面板布局（堆栈），而下图显示了“流式”透视面板。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260519.7c8b61.png)
以下示例代码将透视面板布局设置为流动：

```Javascript
var layoutType = panel.panelLayout();
panel.panelLayout(GC.Spread.Pivot.PivotPanelLayoutType.flow);
```
默认情况下，透视面板尺寸固定。不过你可以将鼠标悬停在面板左侧边缘，待光标变为双向箭头后，按住鼠标左键拖动，即可调整透视面板大小，方便查看较长的字段名称（如有）。
![调整面板尺寸.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/resizePanel-20260303.d66fbf-20260525.050c57.gif?width=800)
若要将透视面板设置为可调整尺寸状态，需在`Designer`命名空间的[默认配置](gcdocsite__documentlink?toc-item-id=7e131f20-7eab-40bd-9f75-5ed6b663680e#defaultconfig)变量中修改SpreadJS设计器的默认配置项。
以下代码示例可在默认配置中开启透视面板尺寸可调功能：

```javascript
let designer = new GC.Spread.Sheets.Designer.Designer("designer-container");
var config = GC.Spread.Sheets.Designer.DefaultConfig;
let pivotPanelIndex = config.sidePanels.findIndex((item) => item.uiTemplate === "pivotTablePanelTemplate");
config.sidePanels[pivotPanelIndex].allowResize = true;
config.sidePanels[pivotPanelIndex].showResizeLine = true
config.sidePanels[pivotPanelIndex].minWidth = "200px";
config.sidePanels[pivotPanelIndex].maxWidth = "800px";
designer.setConfig(config);
```

### 数据透视表字段

数据透视表字段部分显示数据源中的字段，这些字段可以添加到数据透视表中。您可以选择或取消选择这些字段以获得所需的数据透视表视图。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260519.9fa301.png)
以下示例代码显示了如何从数据透视面板隐藏数据透视表字段部分。

```Javascript
// 隐藏“数据透视表字段”部分
var panel = new GC.Spread.Pivot.PivotPanel("myPivotPanel", myPivotTable, document.getElementById("panel"));
panel.sectionVisibility(GC.Spread.Pivot.PivotPanelSection.area | GC.Spread.Pivot.PivotPanelSection.viewList);
```

### 数据透视表区域

数据透视表区域是数据透视面板的一部分，它显示数据透视表的行、列、值和筛选字段。您只需在这些区域中拖放数据透视表字段即可在不同的数据透视表视图之间切换。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260519.cbf89b.png)
下表描述了上述区域：

| 区域 | 描述 |
| --- | --- |
| Rows | 在数据透视表中显示为行，其中行标签作为选定字段的值。 |
| Columns | 在数据透视表中显示为列，列标签作为选定字段的值。 |
| Filters | 用于数据透视表中的筛选操作。 |
| Values | 显示所选字段的统计数据。 |

以下示例代码显示了如何从数据透视面板隐藏数据透视表区域部分。

```Javascript
//  隐藏“数据透视表区域”部分
var panel = new GC.Spread.Pivot.PivotPanel("myPivotPanel", myPivotTable, document.getElementById("panel"));
panel.sectionVisibility(GC.Spread.Pivot.PivotPanelSection.fields | GC.Spread.Pivot.PivotPanelSection.viewList);
```

### 透视图管理器

Pivot 视图管理器可用于管理数据透视表的视图。它可以快速恢复某个时刻保存的数据透视表的状态。下图显示了视图管理器中数据透视表的不同保存视图。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/viewmanager.png)
以下示例代码显示了如何从透视面板中隐藏透视视图管理器部分。

```Javascript
//隐藏“Pivot View Manager”部分
var panel = new GC.Spread.Pivot.PivotPanel("myPivotPanel", myPivotTable, document.getElementById("panel"));
panel.sectionVisibility(GC.Spread.Pivot.PivotPanelSection.fields | GC.Spread.Pivot.PivotPanelSection.area);
```

有关更多详细信息，请参阅 [Pivot View Manager](gcdocsite__documentlink?toc-item-id=2536307f-0162-4b60-aeec-48d7aaba4344) 主题。
