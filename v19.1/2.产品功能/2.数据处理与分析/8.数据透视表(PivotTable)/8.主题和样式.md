# themes-and-style

SpreadJS 允许您在数据透视表上应用主题和样式以更改其外观。

## 主题

SpreadJS 提供了 29 个浅色、28 个中色和 28 个深色预定义主题，可以应用于数据透视表。下图显示了 light10 主题：
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/pt-theme.png)
您可以通过以下方式之一更改数据透视表的主题：

* 在向电子表格添加数据透视表时设置主题。请参阅以下示例代码。

    ```Javascript
    var myPivotTable = sheet.pivotTables.add("myPivotTable", "tableSales", 1, 1, GC.Spread.Pivot.PivotTableLayoutType.outline, GC.Spread.Pivot.PivotTableThemes.light10);
    ```
* 使用主题选项设置主题，如下所示。

    ```Javascript
    myPivotTable.theme(GC.Spread.Pivot.PivotTableThemes.light10);
    ```

## 样式

您可以应用数据透视表样式来突出显示任何特定数据。style方法可用于样式应用到行和列字段。下图显示了数据透视表的列字段的样式。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/style1.png)
以下示例代码显示了如何为列字段应用样式。

```JavaScript
function setMarkSubtotalPivotTableStyle(pivotTable) {
    // 创建样式以特定颜色标记 Qtr Total's
    let style = new GC.Spread.Sheets.Style();
    style.backColor = '#03A685';
    let subtotalLabelPivotArea = {
        labelOnly: true,
        references: [
            {
                fieldName: 'Qt',
                subtotal: true,
                items: ['Qtr1', 'Qtr2', 'Qtr3', 'Qtr4'],
            },
        ],
    };
    // 设置样式以特定颜色标记 Qtr Total's
    pivotTable.setStyle(subtotalLabelPivotArea, style);
    let subtotalDataPivotArea = {
        dataOnly: true,
        references: [
            {
                fieldName: 'Qtr',
                subtotal: true,
                items: ['Qtr1', 'Qtr2', 'Qtr3', 'Qtr4'],
            },
        ],
    };
    pivotTable.setStyle(subtotalDataPivotArea, style);
}
```

下图显示了数据透视表的行字段的样式。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/style2.png)
以下示例代码显示了如何为行字段应用样式。

```JavaScript
function setMarkSeattlePivotTableStyle(pivotTable) {
    // 创建并设置样式以标记带有“Seattle”的行
    let seattlePivotArea = {
        references: [
            {
                fieldName: 'City',
                items: ['Seattle'],
                applyLabel: true,
                applyData: true,
                applyGrandTotal: true,
                applySubtotal: true,
            },
        ],
    };
    let style = new GC.Spread.Sheets.Style();
    style.backColor = 'yellow';
    pivotTable.setStyle(seattlePivotArea, style);
}
```

## 设置数据透视表区域偏移量

SpreadJS 提供了一个 `offset` 属性，用于对特定的数据透视表区域设置样式，其中默认偏移量是指以数据透视表区域的左上角单元格 (0,0) 作为基准单元格来定义范围。
你可以实现 `IPivotAreaOffset` 接口，该接口包含 **row**（行）、**col**（列）、**rowCount**（行数）和 **colCount**（列数）来设置 `offset` 属性，其中：

* **row** 和 **col** 表示基准单元格的行偏移量和列偏移量。
* **rowCount** 和 **colCount** 表示要设置样式的行数和列数。

然而，偏移量只能影响特定的区域，如 **角落区域**、**右上角区域**、**总计区域** 和 **行标题** 区域。
设置 row、col、rowCount 和 colCount 的规则如下：

* 如果 **rowCount** 和 **colCount** 不是数字或者小于 2，则将其视为 1。
* 如果 **row** 和 **col** 为无穷大，则表示数据透视表区域的最后一行。
* 如果 **rowCount** 和 **colCount** 为无穷大，则表示直到此数据透视表的最后一行或最后一列的数量。

**示例**
下图展示了两种不同的情况。在第一种情况中，使用标签引用设置了偏移属性。在第二种情况中，使用 `PivotAreaType` 枚举将特定的数据透视表区域定义为角落区域，并设置 **offset** 属性来指定数据透视表的区域。
![pivotarea-offset](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pivotarea-offset.dcdc60.5f9819.png)
以下代码示例展示了如何为特定的数据透视表区域设置 **offset** 属性。

```javascript
let style = new GC.Spread.Sheets.Style();
style.backColor = 'rgb(247, 167, 17)';
let labelPivotAreaWithOffset = {
    labelOnly: true,
    references: [
        {
            fieldName: 'Region',
            items: ['East'],
        },
    ],
    offset: {
        row: 0,
        col: 0,
        rowCount: 2,
        colCount: 1,
    },
};
pivotTable.setStyle(labelPivotAreaWithOffset, style);
let cornerPivotAreaWithOffset = {
    type: GC.Spread.Pivot.PivotAreaType.corner,
    offset: {
        row: 0,
        col: 1,
        rowCount: 1,
        colCount: 1,
    },
};
pivotTable.setStyle(labelPivotAreaWithOffset, style);
let cornerPivotAreaWithOffset = {
    type: GC.Spread.Pivot.PivotAreaType.corner,
    offset: {
        row: 0,
        col: 1,
        rowCount: 1,
        colCount: 1,
    },
};
pivotTable.setStyle(cornerPivotAreaWithOffset, style);
```
