# sjs-table-function

`SJS.TABLE`函数可通过将结果单元格或单元格区域与一组或多组输入值进行比对运算，实现假设分析功能。
该函数会以动态数组形式返回计算结果。
单个公式内即可支持单变量与多变量模拟运算。

## 语法

```auto
=SJS.TABLE(结果引用单元格, 输入值1, 输入单元格1, …)
```

## 参数说明

| 参数 | 说明 |
| --- | --- |
| `结果引用单元格` | 每次模拟运算中需要进行求值计算的单元格或单元格区域。 |
| `输入值` | 用于替换输入单元格的数值，可为单元格引用、单元格区域、内联数组或单个数值。 |
| `输入单元格` | 运算过程中用来依次填入各项输入值的单个目标单元格。 |

可额外添加多组**输入值/输入单元格**配对参数实现多变量分析，首组之外的配对参数均为可选参数。

## 运行机制

`SJS.TABLE`函数对指定结果引用内容进行运算，并将汇总后的结果以溢出动态数组形式输出。

* 结果区域会依据输入数据结构自动扩展排布。
* 被引用输入单元格内的原始数值不会被永久修改。
* 该公式的使用规则与常规动态数组公式完全一致。
* 单值输入内容会应用到每一轮模拟运算中。

## 输出结果

`SJS.TABLE`函数输出动态数组，数组尺寸由结果引用单元格结构与传入的输入数据共同决定。

* 若结果引用为单个单元格，会依照输入数据维度生成对应规格的结果矩阵。
* 若结果引用为单元格区域，每一次模拟运算都会保留该区域原有行列结构。

当传入多组输入区域时，系统会依照输入与结果匹配规则中的维度规则和映射规则完成输入值运算匹配。

>type=info
> 如需详细了解输出尺寸判定规则以及输入值与模拟场景的匹配规则，请查阅[输入与结果匹配规则](gcdocsite__documentlink?toc-item-id=7016ce8a-58cf-48b5-912f-52a445bd89dc)。

## 常用使用方式

以下为`SJS.TABLE`函数的主流应用场景。

### 单变量——纵向输入

输入值纵向排列，运算结果向下溢出排布时使用该写法。

```auto
=SJS.TABLE(B2, A3:A10, A2)
```

公式会依次将A3至A10单元格中的数值填入A2单元格，逐行计算并返回对应的B2单元格运算结果。

### 单变量——横向输入

输入值横向排列，运算结果向右侧列方向溢出排布时使用该写法。

```auto
=SJS.TABLE(B2, B3:H3, A2)
```

每一列都会输出对应输入数值所算出的运算结果。

### 双变量运算

运算结果由两个独立输入变量共同决定时适用该用法。

```auto
=SJS.TABLE(A2, B2:H2, B1, A3:A5, A1)
```

最终输出的二维数组，涵盖所有横向输入值与纵向输入值的组合运算结果。

### 多变量运算（超过两个变量）

`SJS.TABLE`支持在同一个公式内设置两组以上变量配对参数。

```auto
A1: =B1 * C1 * D1
=SJS.TABLE(A1, {1,2,3}, B1, {1,2,3}, C1, {1;-1}, D1)
```

运算结果会包含所有输入数值两两组合后的全部计算结果。

### 内嵌数组与动态数组调用

输入数据不必局限于工作表单元格区域，同时支持内嵌数组以及各类动态数组函数作为入参。

```auto
=SJS.TABLE(B1, {1,2,3}, A1)
=SJS.TABLE(B1, 序列(2,2), A1)
```

最终输出结果的结构与传入的输入数组结构保持一致。

### 嵌套嵌入其他函数

由于`SJS.TABLE`属于标准表格公式，可直接嵌套在其他函数内部使用。

```auto
=求和(SJS.TABLE(A1, B2:B10, A2))
```

## 完整实例——双变量数据表

下述案例为完整的双变量假设分析数据表应用场景。
本案例设定：

* 价格、折扣率为两大输入变量
* 净收入依托预估销量进行计算
* 借助`SJS.TABLE`函数测算不同价格与折扣组合下对应的净收入数值

```javascript
var spread = new GC.Spread.Sheets.Workbook('ss');
spread.options.allowDynamicArray = true;
spread.suspendPaint();
var sheet = spread.getActiveSheet();
// 定义数据表需要重新运算的基础参数与计算公式
sheet.setArray(0, 0, [    
['价格', 300],    
['折扣', 0],    
['销量'],    
['净收入']
]);
sheet.setFormula(2, 1, '=四舍五入(P3+O3*B1+B2*N3,0)');
sheet.setFormula(3, 1, '=B3*(B1*(1-B2)-130)');
// 利用历史价格与折扣数据，通过线性回归函数预估后续销量数据
sheet.getRange('N2').value('依据历史数据进行线性回归测算');
sheet.getRange('N3').formula('=线性回归(P8:.P17,N8:.O17)');
sheet.setArray(5, 13, [    
['历史数据', 无, 无, '依托线性回归结果预估销量'],    
['价格', '折扣', '销量'],    
[300, 0, 38],    
[250, 0.1, 62],    
[300, 0.2, 60],    
[320, 0.25, 60],    
[200, 0.1, 70]
]);
// 展示每条历史数据对应的拟合销量数值
sheet.getRange('Q8:Q13').formula('=四舍五入(N$3*O8+O$3*N8+P$3,0)', true);
// 搭建假设分析数据表：顶部排布折扣档位，左侧排布价格档位
sheet.setArray(5, 0, [    
['预测数据表', 无, '折扣'],    
[无, 无, 0, 0.05, 0.1, 0.15, 0.2, 0.25, 0.3, 0.35]
]);
// 数据表左上角单元格填写需要重复运算的核心结果公式
sheet.setFormula(6, 1, '=B4');
sheet.setValue(7, 0, '价格');
for (let i = 0; i < 34; i++) {    
sheet.setValue(7 + i, 1, 150 + i * 10);
}
// 生成双变量运算数据表
sheet.setFormula(7, 2, '=SJS.TABLE(B7,C7:J7,B2,B8:B41,B1)');
spread.resumePaint();
```

### 结果排布规则

在C8单元格录入的公式，会自动溢出生成34行8列的动态数组结果。
该数组尺寸判定依据：

* `C7:J7` 区域：包含8组折扣数值，布局为1行8列
* `B8:B41` 区域：包含34组价格数值，布局为34行1列
* `B7` 单元格：为单单元格结果引用

因结果引用仅为单个单元格，最终输出表格会自动适配所有输入数据里最大的行列维度。
生成的数据表格规则：

* 每一行对应一组价格数值
* 每一列对应一组折扣数值
* 表格内每个单元格数值，均为该组价格与折扣组合重新计算得出的净收入

## 与传统Excel数据表的区别

相较于Excel传统旧式数据表，`SJS.TABLE`函数具备以下优势：

* 属于通用表格公式，支持直接编辑修改、复制粘贴使用
* 可在结果数据区域内自由插入、删除行列
* 支持两个以上变量同时参与运算分析
* 可直接调用数组数值、自定义名称区域以及跨工作表单元格引用
* 能够嵌套嵌入其他各类函数中使用

## 注意事项

* `SJS.TABLE`函数无法搭配异步函数使用，若与依赖默认值、异步结果回调的异步函数联用，运算结果易出现异常偏差。
* 执行`SJS.TABLE`函数运算期间，单元格内部数据更新不会触发协作同步机制，全部运算流程结束后会自动恢复协作同步功能。
* 可调用`waitForAllCalculations()`方法，等待所有`SJS.TABLE`模拟运算全部执行完毕。
