# input-and-result-rules

本主题对**[SJS.TABLE](gcdocsite__documentlink?toc-item-id=e07b0db6-00e9-4484-aaa0-11be694597a9)**函数进行补充说明，讲解输出数组维度的判定方式，以及输入值如何对应映射到各个模拟运算位置。

本文重点讲解以下内容：
* 溢出结果的尺寸计算方式
* 模拟运算的执行次数
* 每次模拟运算所选取的输入值
* 输入维度不匹配时的处理规则

以上规则适用于非标准结果引用区域形态，或是组合使用多个不同尺寸输入数据的场景。

## 维度总览
下表汇总了`result_reference`（结果引用区域）的形态对结果尺寸与模拟运算规则产生的影响。

| 结果引用区域形态 | 输出尺寸 | 模拟运算次数 | 输入值使用规则 |
| ---- | ---- | ---- | ---- |
| 多单元格区域 | 与结果引用区域尺寸一致 | 1次 | 仅取用首个数值 |
| 单列区域 | 保留原有行数，列数取所有输入数据的最大列数 | 按列执行 | 取用各组输入数据的首行数值 |
| 单行区域 | 保留原有列数，行数取所有输入数据的最大行数 | 按行执行 | 取用各组输入数据的首列数值 |
| 单个单元格 | 取所有输入数据中最大行数×最大列数 | 按每个输出单元格执行 | 完整位置对应映射 |

## 按区域形态划分示例
### 基础模型（源自[完整示例](gcdocsite__documentlink?toc-item-id=e07b0db6-00e9-4484-aaa0-11be694597a9#%E5%AE%8C%E6%95%B4%E5%AE%9E%E4%BE%8B%E2%80%94%E2%80%94%E5%8F%8C%E5%8F%98%E9%87%8F%E6%95%B0%E6%8D%AE%E8%A1%A8)）
预测表格使用公式：
```auto
=SJS.TABLE(B7, C7:J7, B2, B8:B41, B1)
```
参数释义：
* `B7`→净利润（单个单元格形式的结果引用区域）
* `C7:J7`→折现率数值（1行8列）
* `B8:B41`→价格数值（34行1列）

该模型用于讲解下文各项维度规则。
所有示例均共用基础计算公式：
```auto
结果公式：=B1*10 + C1
```

### 1. 单个单元格场景（完整示例场景）
运算公式：
```auto
=SJS.TABLE(B7, C7:J7, B2, B8:B41, B1)
```
区域形态：
* `B7`→1行1列
* `C7:J7`→1行8列
* `B8:B41`→34行1列

输出结果尺寸：
```auto
34行×8列
```
数值映射规则：
* 每一行对应一个价格数值
* 每一列对应一个折现率数值
* 每个单元格均按照以下数值重新计算净利润：
* 价格=当前行对应数值
* 折现率=当前列对应数值

该场景实现了完整的位置维度拓展。

### 2. 单列结果引用区域（基础模型变体）
若将净利润引用为纵向单元格区域：
```auto
=SJS.TABLE(B8:B41, C7:J7, B2)
```
运行规则：
* 保留原有34行行数不变
* 列数自动拓展至匹配8个折现率数值
* 每一个折现率数值对应执行一次模拟运算
每一列代表对应折现率下重新计算得出的结果。
![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260416.fdf9bd-20260525.b3964a.png?width=600)

### 3. 单行结果引用区域（变体场景）
以横向汇总行为引用区域时：
```auto
=SJS.TABLE(C7:J7, B8:B41, B1)
```
运行规则：
* 保留原有8列列数不变
* 行数自动拓展至匹配34个价格数值
* 每一个价格数值对应执行一次模拟运算
每一行代表对应价格下重新计算得出的结果。
![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260416.b2be6c-20260525.89c89e.png?width=600)

### 4. 多单元格结果引用区域
使用2行2列的结果数据块作为引用区域时：
```auto
=SJS.TABLE(B7:C8, C7:J7, B2)
```
运行规则：
* 输出结果固定为2行2列，尺寸不发生变化
* 仅取用第一个折现率数值参与运算
* 其余多余输入数值全部忽略不计
* 全程仅执行一次模拟运算

此场景不会产生任何维度拓展效果。

## 数值匹配规则
* 单值输入数据会统一应用到所有模拟运算中
* 单行输入数据随列变化切换取值
* 单列输入数据随行变化切换取值
* 多行多列输入数据同时随行、列位置变化切换取值
* 超出有效范围的位置统一视为空值，超出所需维度的多余输入数值直接舍弃。
