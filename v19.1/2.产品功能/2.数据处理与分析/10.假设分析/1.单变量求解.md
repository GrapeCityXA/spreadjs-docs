# goal-seek

单变量求解是假设分析中的一种单变量逆向分析工具。
它能够算出依赖公式单元格得出指定数值结果时，所需对应的一个输入单元格数值。它不像常规运算那样改变输入值查看结果变化，而是从目标结果出发，迭代推算出能够达成该结果的输入数值。
当已知预期结果，但不清楚所需输入数值时，使用单变量求解十分实用。

## 概念模型

单变量求解的运行依托三大要素：

* 可变单元格——需要进行调整的输入数值所在单元格
* 公式单元格——内置公式且计算结果依赖可变单元格的单元格
* 目标结果——公式单元格最终需要算出的指定数值

找到可行解后，系统会用计算得出的数值更新可变单元格内容。
若未能找到有效解，则会恢复可变单元格原本的数值。
**单变量求解仅支持求解单个变量**。

## 基础程序调用方式

可通过 [`GC.Spread.Sheets.CalcEngine.goalSeek`](gcdocsite__documentlink?toc-item-id=3db14618-6aaf-4198-b174-826a09082d17#goalseek) 方法以代码形式调用单变量求解功能。

```javascript
// 贷款金额：10000
// 贷款期限：18个月
sheet.setValue(0, 1, 10000);
sheet.setValue(1, 1, 18);
sheet.setFormatter(2, 1, '0%');
sheet.setFormula(3, 1, '-PMT(B3/12, B2, B1)');
// 求解B3单元格数值，使B4单元格结果等于600
GC.Spread.Sheets.CalcEngine.goalSeek(
    sheet,
    2,
    1, // 可变单元格（B3）
    sheet,
    3,
    1, // 公式单元格（B4）
    600 // 目标结果
);
```

默认配置参数：

* 最大迭代次数：200次
* 精度容差：0.001

该方法找到有效解则返回`true`，未找到则返回`false`（异步场景可参考下文执行机制）。

## 高级迭代控制

单变量求解支持通过可选的`options`配置参数实现精细化迭代管控，可精准调控收敛规则、计算精度以及运行过程监测。

### 收敛规则调控

可通过以下参数调整数值运算逻辑：

* `maximumIterations`——限定最大迭代运算次数
* `tolerance`——设定公式计算结果与目标结果之间允许的误差范围

示例代码：

```javascript
GC.Spread.Sheets.CalcEngine.goalSeek(sheet, 2, 1, sheet, 3, 1, 600, {
    maximumIterations: 500,
    tolerance: 1e-8,
});
```

金融运算、工程测算等对数值精度要求高的场景，建议设置更小的误差容差值。

### 迭代过程监听

借助`callback`回调函数，可实时监听每一次内部迭代运算状态。
回调函数可获取的迭代信息包含：

* 当前迭代次数
* 可变单元格实时数值
* 公式实时运算结果
* 当前是否已求出有效解

示例代码：

```javascript
GC.Spread.Sheets.CalcEngine.goalSeek(sheet, 2, 1, sheet, 3, 1, 600, {
    callback: (info) => {
        console.log(`迭代次数=${info.currentIteration}, ` + `变量值=${info.currentValue}, ` + `运算结果=${info.currentFormulaResult}, ` + `是否求解成功=${info.succeeded}`);
    },
});
```

该功能可用于：

* 运行日志记录与故障排查
* 教学演示场景
* 收敛过程实时可视化展示

### 提前终止与异步管控

若回调函数返回`true`，单变量求解会立刻停止运算，并保留当前计算数值。
同时回调函数支持异步写法，当回调返回异步Promise对象时，工具会等待Promise执行完成后，再开启下一轮迭代运算。
示例代码：

```javascript
GC.Spread.Sheets.CalcEngine.goalSeek(sheet, 2, 1, sheet, 3, 1, 600, {
    callback: async (info) => {
        await new Promise((r) => setTimeout(r, 100));
        if (Math.abs(info.currentFormulaResult / 600 - 1) < 1e-10) {
            return true; // 提前终止求解
        }
    },
});
```

依托该能力可实现：

* 收敛过程动画演示
* 自定义交互式终止逻辑
* 动态调整运算精度规则

## 执行机制

### 返回值规则

* 同步执行模式：返回布尔类型值
* 满足以下条件则返回Promise异步对象：
    * 开启增量计算功能
    * 传入异步回调函数

异步Promise执行成功解析后，求出有效解返回`true`，未求出则返回`false`。

### 页面重绘规则

* 同步执行时，SpreadJS会自动通过`暂停重绘`/`恢复重绘`机制优化运行性能
* 基于Promise的异步执行模式，不会自动暂停页面重绘，有需求可手动调用暂停重绘接口

### 计算模式适配

若工作簿未开启自动计算模式，执行单变量求解时会临时切换为自动计算模式，运算结束后自动恢复原本的计算模式。

## 功能使用限制

* 设定的目标结果必须为有限数值
* 参与单变量求解运算的公式必须支持同步计算
* 暂不支持异步公式参与求解运算
* 支持动态数组中的溢出单元格参与运算
* 异步Promise调用场景下，兼容`SJS.TABLE`表格组件
* 代码接口执行的单变量求解操作不支持撤销操作，设计器可视化界面内的该操作可正常撤销
* 多人协同编辑场景规则：
    * 代码运行接口会在迭代过程中实时推送试算数据
    * 设计器仅在确认求解完成后，推送最终运算结果

未求解出有效结果时，系统会自动还原可变单元格的原始数值。

## 算法说明

SpreadJS自研专属数值求解算法，运算逻辑如下：

1. 优先使用割线法进行求解运算
2. 割线法求解失败时，自动切换为二分法继续运算

因算法实现逻辑存在差异，该工具运算结果可能和微软Excel存在出入。
部分场景下Excel受搜索逻辑限制无法求出答案时，SpreadJS依旧能够顺利完成数值收敛求解。
