# what-if-analysis

假设分析是一种建模技术，用于评估一个或多个输入值发生变动时，会对公式计算结果产生怎样的影响。
无需手动修改单元格并反复重新计算，借助假设分析，你可以系统化推演各类不同场景，查看计算结果随预设条件变化产生的变动情况。
SpreadJS 提供两种相辅相成的方式来实现假设分析：

* **数据表分析**：使用`SJS.TABLE`工作表函数
* **单变量求解分析**：调用`GC.Spread.Sheets.CalcEngine.goalSeek`方法

这两项功能均支持基于场景的数值推演，但二者适用场景不同，运行逻辑也存在差异。

## 数据表分析（SJS.TABLE函数）

`SJS.TABLE`函数可依据多组不同的输入组合，对单个结果单元格或单元格区域进行运算，并将汇总得出的结果以动态数组形式返回。
该函数属于标准工作表公式，具备以下特性：

* 可参与工作表常规的重新计算流程
* 支持编辑、复制操作，也可嵌套在其他函数内部使用
* 能自动将计算结果填充至相邻单元格

除此之外，`SJS.TABLE`还拥有以下能力：

* 支持动态数组与内联数组
* 单个公式内可设置多个输入变量
* 支持跨工作表引用以及命名区域引用

数据表分析最适用于对比多组预设输入数值对应的各类输出结果。

## 单变量求解分析

`goalSeek`是指令式计算方法，能够自动调整指定单元格的数值，直至对应公式算出目标预期结果。
与`SJS.TABLE`函数相比，单变量求解具备这些特点：

* 可直接改动可变单元格内的数据
* 依托内置数值求解算法运行
* 返回布尔值或布尔类型异步承诺对象
* 通过计算引擎应用程序接口实现功能，而非依靠工作表公式

单变量求解多用于求解逆向运算问题，例如测算达成特定还款金额所需的利率数值。

## 功能对比

| 功能项 | 数据表（SJS.TABLE） | 单变量求解（goalSeek） |
| --- | -------------- | --------------- |
| 实现形式 | 工作表公式 | 计算引擎接口方法 |
| 执行模式 | 声明式 | 指令式 |
| 核心用途 | 测算多组输入组合对应的结果 | 反向推算得出目标结果所需的输入值 |
| 返回数据 | 动态数组 | 布尔值 或 布尔类型异步承诺对象 |
| 是否修改工作表单元格 | 否 | 是 |
