# slicercustom

你可以使用 [GeneralSlicerData ](gcdocsite__documentlink?toc-item-id=e2843bf4-9766-45f5-b0b2-bf639aff4f2c)类创建一个常规切片器。常规切片器用于处理二维数组的数据，并提供了一些属性和方法，可用于筛选数据并获取筛选结果。你可以将多个切片器附加到一个常规切片器上，每个切片器可以筛选一列数据。筛选完成后，[GeneralSlicerData ](gcdocsite__documentlink?toc-item-id=e2843bf4-9766-45f5-b0b2-bf639aff4f2c)类会通知其他切片器，然后这些切片器可以从 **GeneralSlicerData** 中获取筛选结果并更新其用户界面。

>type=info
> **注意：** 要在 SpreadJS 工作表中使用常规切片器，你需要引用 `gc.spread.sheets.all.js` 插件。

切片器基于以下步骤与 [GeneralSlicerData ](gcdocsite__documentlink?toc-item-id=e2843bf4-9766-45f5-b0b2-bf639aff4f2c)类协同工作：

1. 使用你的数据创建一个新的 **GeneralSlicerData**。
2. 创建一个新的自定义切片器，并将其附加到 **GeneralSlicerData** 上。
3. 从 **GeneralSlicerData** 中获取列数据并构建切片器的用户界面。
4. 响应界面事件并调用 GeneralSlicerData 的 [doFilter ](gcdocsite__documentlink?toc-item-id=e2843bf4-9766-45f5-b0b2-bf639aff4f2c#dofilter)方法。
5. 从 **GeneralSlicerData** 中获取筛选结果并更新切片器的用户界面。

GeneralSlicerData 类提供了以下方法来帮助控制常规切片器：

* 使用 [getData](gcdocsite__documentlink?toc-item-id=e2843bf4-9766-45f5-b0b2-bf639aff4f2c#getData) 方法获取特定列的所有数据。
* 使用 [getExclusiveData](gcdocsite__documentlink?toc-item-id=e2843bf4-9766-45f5-b0b2-bf639aff4f2c#getExclusiveData) 方法获取唯一（非重复）数据。
* 使用 [doFilter](gcdocsite__documentlink?toc-item-id=e2843bf4-9766-45f5-b0b2-bf639aff4f2c#doFilter) 方法筛选一列数据。
* 使用 [doUnfilter](gcdocsite__documentlink?toc-item-id=e2843bf4-9766-45f5-b0b2-bf639aff4f2c#doUnfilter) 方法清除筛选信息。

有关方法的完整列表，请参阅 [GeneralSlicerData](gcdocsite__documentlink?toc-item-id=e2843bf4-9766-45f5-b0b2-bf639aff4f2c) 类。
你可以使用 [attachListener](gcdocsite__documentlink?toc-item-id=e2843bf4-9766-45f5-b0b2-bf639aff4f2c#attachListener) 函数为 **GeneralSlicerData** 附加一个监听器，并使用 [detachListener](gcdocsite__documentlink?toc-item-id=e2843bf4-9766-45f5-b0b2-bf639aff4f2c#detachListener) 函数将其移除。

以下代码示例创建了一个常规切片器。

```html
<!DOCTYPE html>
<html>

<head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <script src="https://code.jquery.com/jquery-2.1.1.min.js" type="text/javascript"></script>
    <!--CSS 文件-->
    <link href="scripts/gc.spread.sheets.excel2013white.x.x.x.css" rel="stylesheet" />
    <!--脚本文件-->
    <script type="text/javascript" src="scripts/gc.spread.sheets.all.x.x.x.min.js"></script>
    <script type="text/javascript">
        // 定义数据源。
        columnNames = ["姓名", "城市", "生日"];
        data = [
            ["鲍勃", "纽约", "1968/6/8"],
            ["贝蒂", "华盛顿", "1972/7/3"],
            ["爱丽丝", "纽约", "1964/3/2"]
        ];
        // 定义自定义切片器。
        function MySlicer(container) {
            this.container = container;
            this.slicerData = null;
            this.columnName = null;
        }
        MySlicer.prototype.setData = function (slicerData, columnName) {
            this.slicerData = slicerData;
            this.columnName = columnName;
            this.slicerData.attachListener(this);
            this.onDataLoaded();
        }
        MySlicer.prototype.onDataLoaded = function () {
            // 创建切片器的 DOM 树。
            var columnName = this.columnName,
                exclusiveData = this.slicerData.getExclusiveData(columnName);
            $(this.container).append($('<span>' + this.columnName + ':</span>' + '<br />'));
            var domString = "";
            for (var i = 0; i < exclusiveData.length; i++) {
                domString += '<input type="checkbox" name="' + columnName + '" value="' + exclusiveData[i] + '">';
                domString += '<span>' + exclusiveData[i] + '</span>';
                domString += '<br />';
            }
            $(this.container).append($(domString));
            // 为 DOM 元素附加事件。
            var self = this;
            $("[name='" + self.columnName + "']").change(function () {
                var slicer = self,
                    exclusiveData = slicer.slicerData.getExclusiveData(slicer.columnName),
                    parent = $(this).parent(),
                    items = parent.children(),
                    indexes = [];
                for (var i = 0, length = items.length; i < length; i++) {
                    if (items[i].checked) {
                        var value = items[i].value;
                        if (!isNaN(parseInt(value))) {
                            value = parseInt(value);
                        }
                        indexes.push(exclusiveData.indexOf(value));
                    }
                }
                if (indexes.length === 0) {
                    slicer.slicerData.doUnfilter(slicer.columnName);
                } else {
                    slicer.slicerData.doFilter(slicer.columnName, { exclusiveRowIndexes: indexes });
                }
            });
        };
        MySlicer.prototype.onFiltered = function () {
            // 以下是显示筛选结果的示例。
            var slicerdata = this.slicerData;
            var filteredRowIndexs = slicerdata.getFilteredRowIndexes();
            var trs = $listTable.find("tr");
            for (var i = 0; i < slicerdata.data.length; i++) {
                if (filteredRowIndexs.indexOf(i) !== -1) {
                    $(trs[i + 1]).show();
                } else {
                    $(trs[i + 1]).hide();
                }
            }
        }
        // 定义显示筛选结果的方法。
        function initFilteredResultList() {
            var tableStr = "<table border='1' cellpadding='0' cellspacing='0'><tr>";
            for (var i = 0; i < columnNames.length; i++) {
                tableStr += "<th>" + columnNames[i] + "</th>";
            }
            tableStr += "</tr>";
            for (var i = 0; i < data.length; i++) {
                tableStr += "<tr>";
                for (var j = 0; j < data[i].length; j++) {
                    tableStr += "<td>" + data[i][j] + "</td>";
                }
                tableStr += "</tr>";
            }
            tableStr += "</table>";
            $listTable = $(tableStr);
            $("#list").append($listTable);
        }
        $(document).ready(function () {
            // 初始化筛选结果列表。
            initFilteredResultList();
            // 创建一个自定义切片器并将其添加到 "slicerContainer"  div 中。
            var slicer = new MySlicer($("#slicerContainer")[0]);
            var slicerData = new GC.Spread.Slicers.GeneralSlicerData(data, columnNames);
            slicer.setData(slicerData, "姓名");
        });
    </script>
</head>

<body>
    <div id="slicerContainer" style="border:1px solid gray;width:190px"></div>
    <hr />
    <div id="list" style="width:300px;float:left"></div>
</body>

</html>
```

> **注意：** 要升级到新的切片器，请参阅 [重大变更](gcdocsite__documentlink?toc-item-id=859de51d-bc4d-425f-b589-499bad917b71)。
