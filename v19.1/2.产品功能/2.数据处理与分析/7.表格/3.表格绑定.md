# tablebind

SpreadJS允许用户使用单元格级绑定将表格绑定到数据源。
表格绑定有两种方式。在处理电子表格时，用户可以使用 [bindColumns ](gcdocsite__documentlink?toc-item-id=a4dd1734-9813-4400-b8e4-f4e7b7b40536#bindcolumns)方法或 [bind ](gcdocsite__documentlink?toc-item-id=a4dd1734-9813-4400-b8e4-f4e7b7b40536#bind)方法将表格绑定到数据源。
在工作表中进行表格绑定操作时，必须牢记以下规则：

* 设置值会更改数据源。
* 添加或删除行将更改数据源。
* 添加或删除列不会更改数据源。
* 删除、清除、移动或调整表格大小不会更改数据源。
* 绑定会自动调整表格行数（但列数保持不变）。
* 公式不会保存到数据源中。

## 绑定表格列

要绑定工作表中的所有表格列，只需将工作表绑定到数据源，然后在 [Table ](gcdocsite__documentlink?toc-item-id=a4dd1734-9813-4400-b8e4-f4e7b7b40536)类中设置 [bindColumns ](gcdocsite__documentlink?toc-item-id=a4dd1734-9813-4400-b8e4-f4e7b7b40536#bindcolumns)和 [bindingPath](gcdocsite__documentlink?toc-item-id=a4dd1734-9813-4400-b8e4-f4e7b7b40536#bindingpath) 方法。用户还可以使用 [TableColumn](gcdocsite__documentlink?toc-item-id=2713a3ea-173f-4bd9-8684-ec4b47513699) 类中的 [dataField](gcdocsite__documentlink?toc-item-id=2713a3ea-173f-4bd9-8684-ec4b47513699#datafield) 和 [name ](gcdocsite__documentlink?toc-item-id=2713a3ea-173f-4bd9-8684-ec4b47513699#name)方法指定表格列的信息。

## 将格式化程序和单元格类型绑定到表格列

借助SpreadJS提供的高级列绑定功能，用户不仅可以将数据字段和名称与表格列绑定，还可以将格式化程序和各种单元格类型与表格列进行绑定。此外，用户还可以转换表格列中的公式函数。
[bind ](gcdocsite__documentlink?toc-item-id=a4dd1734-9813-4400-b8e4-f4e7b7b40536#bind)方法可用于将表格绑定到包含多个记录的字段，并将表格列绑定到其相应记录的数据字段。当用户设置不同的数据源来填充表格数据时，表格将自动绑定到其相应的记录。
以下代码展示了如何使用 [bind ](gcdocsite__documentlink?toc-item-id=a4dd1734-9813-4400-b8e4-f4e7b7b40536#bind)方法在表格列中绑定数据。

```javascript
// Initializing Spread
var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });
       
// Get the activesheet
var activeSheet = spread.getActiveSheet();
       
// Data
var data = {
    name: 'Jones', region: 'East',
    sales: [
        { orderDate: '1/6/2013', item: 'Pencil', units: 95, cost: 1.99, isMakeMoney: true },
        { orderDate: '4/1/2013', item: 'Binder', units: 60, cost: 4.99, isMakeMoney: false },
        { orderDate: '6/8/2013', item: 'Pen Set', units: 16, cost: 15.99, isMakeMoney: false }
    ]
};

var convert = function (item) {
    return item['cost'] + '$';
}
       
// Add table
var table = activeSheet.tables.add('tableSales', 0, 0, 5, 5);
var tableColumn1 = new GC.Spread.Sheets.Tables.TableColumn(1, "orderDate", "Order Date", "d/M/yy");
var tableColumn2 = new GC.Spread.Sheets.Tables.TableColumn(2, "item", "Item");
var tableColumn3 = new GC.Spread.Sheets.Tables.TableColumn(3, "units", "Units");
var tableColumn4 = new GC.Spread.Sheets.Tables.TableColumn(4, "cost", "Cost", null, null, convert);
var tableColumn5 = new GC.Spread.Sheets.Tables.TableColumn(5, "isMakeMoney", "IsMakeMoney", null, new GC.Spread.Sheets.CellTypes.CheckBox());
  
table.autoGenerateColumns(false);
        
// Bind table using the bind() method
table.bind([tableColumn1, tableColumn2, tableColumn3, tableColumn4, tableColumn5], 'sales', data);
for (var i = 0; i < 5; i++)
    activeSheet.setColumnWidth(i, 110.0, GC.Spread.Sheets.SheetArea.viewport);
```

## 绑定到数据管理器表格

SpreadJS 允许你将新的或现有的工作表表格绑定到数据管理器表格作为数据源，这会产生动态数据交互，并在表格中显示更新后的信息。要将工作表表格绑定到数据管理器表格，需在添加表格后使用 `table.bind` 方法。
绑定表格后，如果数据管理器表格的行数和列数超过工作表的行数和列数，用户应使用 `setRowCount/setColumnCount` 方法扩展工作表的范围。
在 `table.bind` 方法中，不一定要指定绑定列和绑定路径，但至少应传入一个空数组。但是，如果你在 `table.bind` 方法中指定了绑定列，那么你需要指定 `TableColumn` 的数据字段，使其与数据管理器表格中的字段相匹配。公式不能用作绑定字段。
根据 `autoGenerateColumns` 属性的布尔值不同，绑定列会显示不同的结果。
将表格绑定到数据管理器表格时，有以下几个要点：

* 你不能使用调整大小手柄来调整工作表表格的大小以适配数据管理器表格。
* 你只能通过绑定信息修改列的显示方式，但不能在数据管理器表格中添加、删除或更新实际的列。
* 不在数据管理器表格中的列可以有公式，而在数据管理器表格中的列不能有公式。
* 如果列标题是否包含数据，并且你编辑列标题：
    * 通过输入公式，如果列标题中已有数据，该列将转换为公式列。否则，它将创建一个新列来显示计算后的数据。但是，你不能手动编辑该列中单个单元格的公式。
    * 通过输入数据字段名称，表格将尝试查找该字段：
        * 如果该字段存在于表格中，它将显示相应的值。
        * 如果该字段不存在于表格中，该列将显示为空，并且你无法在其中设置值。
* 绑定到数据管理器表格可让你在表格结构的限制内对数据进行排序和筛选，重点关注表格中可用的数据列。
* 当绑定复杂的数据管理器表格（尤其是具有层级关系的表格）时，目前暂不支持完整功能。这可能导致绑定后某些表格操作无法按预期运行。
* 当多个表格绑定到同一个数据源时，可能会产生相互依赖关系。例如，一个表格中的结构变化（如扩展行，由`expandBoundRows`控制），可能会触发其他绑定表格中对应的行同步扩展。

以下代码通过传入空数组将工作表表格绑定到数据管理器表格。

```csharp
 let sheet5 = spread.getSheet(4);
 sheet5.name("Update Binding");
 ordersTable.fetch().then(() => {
     sheet5.suspendPaint();
     var ordersSheetTable = sheet5.tables.add('tableSales4', 0, 0, 1, 3);

     let bindingColumns = [tableColumn1, tableColumn2, tableColumn3];
     // bind the columns
     ordersSheetTable.autoGenerateColumns(false)
     ordersSheetTable.bind(bindingColumns, null, 'orders');
     sheet5.resumePaint();
     // update the data field or other properties of the column at other times
     sheet5.suspendPaint();
     bindingColumns[1].dataField(null); // << --- unbind the field
     bindingColumns[1].name('Total Cost'); // << --- specify the column name
     // re-bind the columns
     ordersSheetTable.bindColumns(bindingColumns);
     bindingColumns[0].dataField('cost'); // << --- update the data field
     bindingColumns[0].name('Cost'); // << --- update the table name
     bindingColumns[0].formatter('$#,##0');  // << --- update the column value formatter
     // re-bind the columns
     ordersSheetTable.bindColumns(bindingColumns);
     ordersSheetTable.setColumnDataFormula(1, '=[@Units]*[@Cost]'); // << --- set Total Cost with data formula
     sheet5.resumePaint();
 });
```

### 保存对数据管理器表格的更改

SpreadJS 允许你在工作表表格绑定到数据管理器表格时，保存对工作表表格所做的任何更改。当数据管理器表格处于批处理模式时，使用 `GC.Spread.Sheets.Commands` 命名空间中的 `tableSubmitChanges` 命令将更改保存到绑定的表格。它支持撤销/重做操作，并且可以使用诸如工作表名称和表格名称等特定选项来执行。

### 导入/导出绑定的工作表表格

将绑定的工作表导出为 SJS 或 SSJSON 文件格式时，更改会自动保存。但是，当你将其保存为 Xlsx 格式时，需要将 `ExportXlsxOptions` 中的 `includeBindingSource` 选项设置为 `true`。
导入 Excel 文件时，你可以将 `ImportXlsxOptions` 中的 `convertSheetTableToDataTable` 选项指定为 `true`，以将所有工作表表格转换为数据管理器表格。导入期间基于单元格的公式将被删除。但是，基于列的公式在导入和导出期间会被转换。

### 绑定工作表表格的导入/导出

将绑定的工作表导出为 SJS 或 SSJSON 文件格式时，更改会自动保存。但如果要将其保存为 Xlsx 格式，则需在 `ExportXlsxOptions`（Xlsx 导出选项）中，将 `includeBindingSource`（包含绑定源）选项设置为 `true`。

导入 Excel 文件时，可在 `ImportXlsxOptions`（Xlsx 导入选项）中，将 `convertSheetTableToDataTable`（将工作表表格转换为数据管理器表格）选项指定为 `true`，以将所有工作表表格转换为数据管理器表格。导入过程中，基于单元格的公式会被移除；但基于列的公式会在导入和导出过程中保留转换。

## 扩展绑定表格的行

SpreadJS 支持扩展绑定表格中的行。要实现此功能，你可以直接扩展工作表，或使用 **Table**（表格）类型的 [expandBoundRows](gcdocsite__documentlink?toc-item-id=a4dd1734-9813-4400-b8e4-f4e7b7b40536#expandboundrows) 方法，在绑定表格中插入/删除行。
![expand_rows](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/expand_rows.53b077.png)
以下代码展示了如何使用 **expandBoundRows** 方法扩展绑定表格中的行：

```javascript
// 初始化 Spread
var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 3 });
// 获取活动工作表
var sheet = spread.getSheet(0);
// 创建数据
var data = {
    name: '琼斯', region: '东部',
    sales: [
        { orderDate: '2013年1月6日', item: '铅笔', units: 95, cost: 1.99 },
        { orderDate: '2013年4月1日', item: '活页夹', units: 60, cost: 4.99 },
        { orderDate: '2013年6月8日', item: '钢笔套装', units: 16, cost: 15.99 },
        { orderDate: '2013年8月1日', item: '铅笔', units: 20, cost: 24.99 },
        { orderDate: '2013年10月8日', item: '活页夹', units: 31, cost: 16.99 }
    ]
};
// 添加名为“table1”的表格
var table1 = sheet.tables.add('tableRecords', 0, 0, 4, 4);
table1.autoGenerateColumns(true); // 自动生成列
// 添加另一个名为“table2”的表格
var table2 = sheet.tables.add('tableBelow', 4, 0, 4, 7);
// 绑定 table1
table1.expandBoundRows(true); // 启用扩展绑定行
table1.bindingPath('sales'); // 设置绑定路径为“sales”
// 设置数据源
var dataSource = new GC.Spread.Sheets.Bindings.CellBindingSource(data);
sheet.setDataSource(dataSource);
```

## 获取绑定源（Get Binding Source）

通过显示表格的绑定源，可判断该表格是否已绑定到数据管理器表格。

### 使用 API（应用程序编程接口）

`GC.Spread.Sheets.Tables.Table`（表格对象）的 `getBindingSource` 方法，可用于获取表格所绑定的底层数据源。

>type=info
> **注意：**
> 若表格未绑定任何数据源，`getBindingSource` 会返回 `null`。

* **示例 1：绑定到对象数组**
    当表格创建或绑定时，若使用 JavaScript 数组作为数据源，`getBindingSource` 会返回该数组。

    ```javascript
    var source = [
      { LastName: "弗里哈费尔", FirstName: "南希", Title: "销售代表", Phone: "(123)555-0100"},
      { LastName: "森西尼", FirstName: "安德鲁", Title: "销售副总裁", Phone: "(123)555-0101"},
      { LastName: "科塔斯", FirstName: "简", Title: "销售代表", Phone: "(123)555-0102"},
      { LastName: "谢尔盖延科", FirstName: "玛丽亚", Title: "销售代表", Phone: "(123)555-0103"},
    ];
    // 假设“activeSheet”为当前工作表
    const table = activeSheet.tables.addFromDataSource("Table1", 5, 2, source, GC.Spread.Sheets.Tables.TableThemes.dark1);
    
    // 获取绑定源——结果会是“source”数组
    const bindingSource = table.getBindingSource();
    console.log(bindingSource === source); // 应输出 true
    ```
* **示例 2：绑定到数据管理器表格**
    当表格创建或绑定时，若使用数据管理器表格的名称作为数据源，`getBindingSource` 会从数据管理器中返回对应的 `GC.Data.Table` 对象。

    ```javascript
    // 假设“spread”为 SpreadJS 实例
    const productsTable = spread.dataManager().addTable("products", {
      remote: { // 远程数据源配置
        read: { // 读取数据的配置
          url: 'https://northwind.vercel.app/api/products' // 数据接口地址
        }
      }
    });
    
    productsTable.fetch().then(()=>{ // 拉取数据
      // 方法 1：通过 addFromDataSource 添加表格并绑定到数据管理器表格
      const table1 = spread.getActiveSheet().tables.addFromDataSource("Table1", 0, 0, "products", GC.Spread.Sheets.Tables.TableThemes.medium7);
    
      // 获取绑定源——结果会是“productsTable”数据管理器表格
      let bindingTable1 = table1.getBindingSource();
      console.log(bindingTable1 === productsTable); // 应输出 true
    
      // 方法 2：先添加表格，再通过 bind 方法绑定到数据管理器表格
      const table2 = spread.getActiveSheet().tables.add('Table2', 0, 0, 5, 5);
      table2.bind(
        [], // 可选：指定绑定列，若无需指定可传空数组
        undefined, // 可选：绑定路径，若无需指定可传 undefined
        "products" // 指定数据管理器表格名称
      );
    
      // 获取绑定源——结果同样是“productsTable”数据管理器表格
      let bindingTable2 = table2.getBindingSource();
      console.log(bindingTable2 === productsTable); // 应输出 true
    });
    ```
