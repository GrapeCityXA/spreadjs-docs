# table-slicer

表格切片器可让您快速筛选数据。它无需使用下拉列表即可提供筛选详细信息，并直观地指示当前的筛选状态。
表格切片器派生自 ShapeBase，支持以下功能：

* 渐变填充：将鼠标悬停在切片器中的项目上时，会显示渐变效果。
* 多选模式：您可以通过选择切片器右上角的“多选”按钮一次选择多个筛选项目。您可以取消选择“多选”按钮，以便一次仅选择一个筛选项目。
* 性能提升：作为 ShapeForm 控件，表格切片器可用于筛选工作表中的大量数据。
* 优化的样式渲染：有关表格切片器样式设置的更多信息，请参阅“表格切片器样式”。

> **注意**：要在 SpreadJS 工作表中使用表格切片器，您需要引用以下插件：
> `gc.spread.sheets.all.js`
> `gc.spread.sheets.shapes.js`
> `gc.spread.sheets.slicers.js`
> 切片器插件依赖于形状插件，因此必须先导入形状插件。
> 表格切片器组件由切片器标题和切片器主体组成。切片器标题由切片器标题、“多选”按钮和“清除筛选”按钮组成。切片器标题用于显示标题，“清除筛选”按钮用于取消对切片器的筛选，默认情况下该按钮处于非活动状态。只有在筛选了切片器项目时，该按钮才会变为活动状态。
> ![table-slicer-elements.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/table-slicer-elements.e6d127.a355ad.png)
> 表格切片器依赖于表格，因此要创建切片器，您必须首先添加一个表格。您可以使用 **add** 方法添加切片器。您可以使用 **Slicers** 类为切片器设置选项。
> ![table-slicer-data.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/table-slicer-data.330814.231aa6.png)
> 以下代码示例可帮助您创建一个表格和一个切片器：

```JavaScript
//创建一个表格
datas = [
    ['1', '纽约', '1968/6/8', '80', '180'],
    ['4', '纽约', '1972/7/3', '72', '168'],
    ['4', '纽约', '1964/3/2', '71', '179'],
    ['5', '华盛顿', '1972/8/8', '80', '171'],
    ['6', '华盛顿', '1986/2/2', '89', '161'],
    ['7', '华盛顿', '2012/2/15', '71', '240'],
];
var table = activeSheet.tables.addFromDataSource('table1', 2, 2, datas);
dataColumns = ['姓名', '城市', '生日', '体重', '身高'];
table.setColumnName(0, dataColumns[0]);
table.setColumnName(1, dataColumns[1]);
table.setColumnName(2, dataColumns[2]);
table.setColumnName(3, dataColumns[3]);
table.setColumnName(4, dataColumns[4]);
//向工作表添加一个切片器并返回切片器实例。
var slicer = activeSheet.slicers.add('slicer1', table.name(), '姓名');
//更改切片器属性。
slicer.width(200);
slicer.height(200);
slicer.position(new GC.Spread.Sheets.Point(100, 200));
slicer.style(GC.Spread.Sheets.Slicers.SlicerStyles.dark4());
```

您可以移动、调整大小、删除、剪切、复制、粘贴、撤销或重做切片器操作。
被另一个切片器筛选掉的项目称为“有数据项目”和“无数据项目”。被该切片器筛选的项目称为“已选项目”和“未选项目”。

| **项目类型** | **说明** |
| ---- | --- |
| 无数据项目 | 已被另一个切片器筛选掉的项目 |
| 有数据项目 | 未被另一个切片器筛选掉的项目 |
| 已选项目 | 被该切片器筛选掉的项目 |
| 未选项目 | 未被该切片器筛选掉的项目 |

切片器与表格筛选器同步。以下表格更改会导致切片器发生变化：

| **表格更改** | **切片器更改** |
| ---- | ----- |
| 修改数据 | 切片器项目发生变化 |
| 修改列名称 | 切片器标题发生变化 |
| 添加行 | 切片器项目发生变化 |
| 添加列 | 无变化 |
| 删除行 | 切片器项目发生变化 |
| 删除列 | 连接到该列的切片器被移除 |
| 移除表格 | 连接到该表格的所有切片器被移除 |

您可以使用 [Slicers ](gcdocsite__documentlink?toc-item-id=cb0433ab-f73b-4a2e-9d36-4c760c490225)类为切片器设置选项。您可以分别使用 [isVisible ](gcdocsite__documentlink?toc-item-id=cb0433ab-f73b-4a2e-9d36-4c760c490225#isvisible)或 [isLocked ](gcdocsite__documentlink?toc-item-id=cb0433ab-f73b-4a2e-9d36-4c760c490225#islocked)方法指定切片器是否可见或已锁定。只有在工作表受保护的情况下，**isLocked** 方法才会生效。您可以使用 slicers.[add ](gcdocsite__documentlink?toc-item-id=f870acc3-ca09-41c8-b3af-b02f2899a2a2#add)方法添加切片器，并使用 slicers.[remove ](gcdocsite__documentlink?toc-item-id=f870acc3-ca09-41c8-b3af-b02f2899a2a2#remove)方法移除切片器。
调整行或列的大小或移动行或列可能会导致切片器的位置和大小根据 [dynamicMove ](gcdocsite__documentlink?toc-item-id=cb0433ab-f73b-4a2e-9d36-4c760c490225#dynamicmove)和 [dynamicSize ](gcdocsite__documentlink?toc-item-id=cb0433ab-f73b-4a2e-9d36-4c760c490225#dynamicsize)方法的设置而发生变化。下表显示了 dynamicMove 和 dynamicSize 设置的结果：

| **DynamicMove** | **DynamicSize** | **结果** |
| ----------- | ----------- | --- |
| true | true | 切片器被移动并调整大小 |
| true | false | 切片器被移动，但大小不变 |
| false | true 或 false | 切片器既不移动也不调整大小 |

## 使用表格切片器数据

[TableSlicerData ](gcdocsite__documentlink?toc-item-id=3afe4913-3c93-4353-8d26-e6432d44ed0d)类为切片器提供表格数据和筛选信息。用于 TableSlicerData 的数据源是 SpreadJS SheetTable。您必须将一个 SheetTable 设置到 TableSlicerData 的构造函数中才能使用表格切片器数据。
以下代码示例创建一个表格，并使用 TableSlicerData 类添加一个切片器：

```JavaScript
//创建表格
var dataSource = [
    { 姓名: '鲍勃', 城市: '纽约', 生日: '1968/6/8' },
    { 姓名: '贝蒂', 城市: '纽约', 生日: '1972/7/3' },
    { 姓名: '爱丽丝', 城市: '华盛顿', 生日: '2012/2/15' },
];
var table = activeSheet.tables.addFromDataSource('table1', 1, 1, dataSource);
var slicerData = table.getSlicerData();
//创建一个项目切片器
var slicer = new GC.Spread.Sheets.Slicers.ItemSlicer('slicer', slicerData, '姓名');
//将项目切片器添加到 dom 树中。
//“slicerHost” 是您要将切片器的 dom 添加到的 div。
$('#slicerHost').append(slicer.getDOMElement());
.....
<div id="slicerHost" style="height: 300px; width: 50%"></div>       
```

> **注意**：要升级到新的切片器，请参阅 [重大变更](gcdocsite__documentlink?toc-item-id=859de51d-bc4d-425f-b589-499bad917b71)。

## 表格切片器样式

您可以使用内置样式，也可以为特定区域（如标题）设置样式。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/sliderclear.ce4876.png)
有关内置样式的列表，请参阅 [SlicerStyles ](gcdocsite__documentlink?toc-item-id=d865580f-59b0-44dc-ac72-ee97ff756e91)类。有关特定区域的列表，请参阅 [SlicerStyle ](gcdocsite__documentlink?toc-item-id=f35611b2-797c-4879-9308-8ab9c704324d)类；有关可更改的样式，请参阅 [SlicerStyleInfo ](gcdocsite__documentlink?toc-item-id=744e0d26-fd4c-4c3b-a191-9c894d25c1b8)类。使用 [SlicerBorder ](gcdocsite__documentlink?toc-item-id=df2625bf-029f-43a6-8d61-035bbaec3eb8)类为样式创建边框。
以下代码示例创建一个表格，并添加一个具有标题样式的切片器：

```javascript
//创建一个表格
datas = [
    ['1', '纽约', '1968/6/8', '80', '180'],
    ['4', '纽约', '1972/7/3', '72', '168'],
    ['4', '纽约', '1964/3/2', '71', '179'],
    ['5', '华盛顿', '1972/8/8', '80', '171'],
    ['6', '华盛顿', '1986/2/2', '89', '161'],
    ['7', '华盛顿', '2012/2/15', '71', '240'],
];
var table = activeSheet.tables.addFromDataSource('table1', 2, 2, datas);
dataColumns = ['姓名', '城市', '生日', '体重', '身高'];
table.setColumnName(0, dataColumns[0]);
table.setColumnName(1, dataColumns[1]);
table.setColumnName(2, dataColumns[2]);
table.setColumnName(3, dataColumns[3]);
table.setColumnName(4, dataColumns[4]);
var hstyle = new GC.Spread.Sheets.Slicers.SlicerStyleInfo();
hstyle.backColor('red');
var style1 = new GC.Spread.Sheets.Slicers.SlicerStyle();
style1.headerStyle(hstyle);
//向工作表添加一个切片器并返回切片器实例。
var slicer = activeSheet.slicers.add('slicer1', table.name(), '姓名');
//更改切片器属性。
slicer.width(200);
slicer.height(200);
slicer.position(new GC.Spread.Sheets.Point(100, 200));
slicer.style(style1);
```
