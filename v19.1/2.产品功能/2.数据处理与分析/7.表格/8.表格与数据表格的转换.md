# convert-fromto-data-table

SpreadJS 支持用户在普通表格（Regular Tables）和数据表（Data Tables）之间无缝转换，可满足动态数据集成或静态数据管理等场景需求。该功能对两类应用至关重要：一类是需要结构化数据绑定的应用（如实时分析、报表生成），另一类是需要保留数据快照的应用（如数据审计、模板复用）。转换过程支持两种实现方式：

1. **API 驱动方式**：通过 `convertToDataTable`（转换为数据表）和 `convertFromDataTable`（从数据表转换为普通表格）等专用方法实现程序化控制。
2. **设计器 UI 操作**：通过 SpreadJS 设计器的可视化界面完成转换。

本指南将详细介绍两种方式的分步操作流程，同时强调实际应用场景与技术细节。

## 普通表格转换为数据表（Convert Table to Data Table）

通过此功能，可轻松将现有表格数据集成到数据管理器（Data Manager）生态系统中。这意味着你既能利用数据管理器提供的高级功能（如控件直接数据绑定、复杂筛选、排序、分组及数据源操作），又能继续使用工作表上的表格可视化展示形式。

### 重要注意事项与规则

将普通表格转换为数据表时，需遵守以下规则：

* **未绑定要求**：仅支持未绑定任何数据源的普通工作表表格进行转换。
* **数据与公式清空**：转换后，原始普通表格数据范围内的所有数据和公式将从工作表单元格中清空，数据及列定义将由数据管理器表格统一管理。
* **数据管理器表格创建**：系统会在 `spread.dataManager().tables` 集合中创建一个新的表格。
* **绑定关系**：原始工作表表格会重新绑定到这个新创建的数据管理器表格，此时工作表表格仅作为数据管理器所管理数据的“视图”。
* **命名规则**：新数据管理器表格会优先使用原始普通表格的名称。若该名称已存在于数据管理器表格中，系统会自动在名称后追加数字（从“1”开始，且数字为相同前缀名称中现有最大数字加1），以确保名称唯一。

### 使用 API 实现转换

参考以下代码，调用 `convertToDataTable` 方法将普通表格转换为数据表：

```javascript
// 向工作表添加普通表格
var sheet = spread.getActiveSheet();
sheet.tables.add('table1', 0, 0, 4, 4, GC.Spread.Sheets.Tables.TableThemes.light1);
// 为表格设置数据
sheet.setArray(0, 0, [
      ['编号（Id）', '姓名（Name）', '年龄（Age）', '成绩（Grade）'],
      [1000, '汤姆（Tom）', 23, 98],
      [1001, '鲍勃（Bob）', 22, 80],
      [1002, '托尼（Tony）', 23, 99]
]);

let dmTable = spread.dataManager().tables['table1']; // 此时 dmTable 为 undefined（未创建）
// 将普通表格转换为数据表，过程中会创建并绑定数据管理器表格
let table = sheet.tables.convertToDataTable('table1');
// 从 table1 转换后，数据管理器中会新增一个表格
let bindingTable = table.getBindingSource(); // 普通表格已成功转换为数据表
dmTable = spread.dataManager().tables['table1']; // 此时 dmTable 已创建
// bindingTable === dmTable // 返回 true，表格的绑定源即数据管理器中的表格
```

1. **选中表格**：点击待转换的普通表格内任意位置，功能区会激活 **“表格设计”（Table Design）** 选项卡。此时，“表格设计”选项卡下“表格绑定”（Tables Binding）面板的“绑定源”（Binding Source）为空。

    * 方式一：在功能区的 **“表格设计”** 选项卡中，找到“表格绑定”区域，点击 **“转换为数据表”（Convert to Data Table）** 按钮。

## 数据表转换为普通表格（Convert Data Table to Table）

SpreadJS 提供了断开工作表表格与底层数据管理器（DataManager）源连接的方法。将数据绑定表格转换为普通表格时，会发生以下变化：

* 表格当前显示的数据及所有列公式，会被直接复制并设置到表格所在的工作表单元格区域中。
* 工作表中的表格实例将变为普通表格，不再与数据管理器绑定。
* 数据管理器中原始的数据表不会被删除或影响，仍保留在数据管理器中，可用于其他场景。

当你需要捕获数据源的“数据快照”，并在工作表中以静态方式使用（无需表格从数据源自动更新，或无需该表格实例与数据管理器保持连接）时，此功能非常实用。

### 使用 API 实现转换

参考以下代码，调用 `convertFromDataTable` 方法将数据绑定表格转换回普通表格：

```javascript
var sheet = spread.getActiveSheet();

// 添加数据源
const productsTable = spread.dataManager().addTable("products", {
  remote: { // 远程数据源配置
         read: { // 读取数据配置
         url: 'https://northwind.vercel.app/api/products' // 数据接口地址
        }
  }
});

productsTable.fetch().then(()=>{ // 拉取数据源数据
// 通过 addFromDataSource 方法添加普通表格，并绑定数据管理器表格
sheet.tables.addFromDataSource("Table1", 0, 0, "products", GC.Spread.Sheets.Tables.TableThemes.medium7);

// 将绑定数据管理器表格的表格转换为普通表格
let table = sheet.tables.convertFromDataTable('Table1');
let bindingTable = table.getBindingSource(); // 数据表已转换为普通表格，故 bindingTable 为 null
});
```
