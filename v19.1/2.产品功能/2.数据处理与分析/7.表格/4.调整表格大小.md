# resize-tables

SpreadJS支持表大小调整功能，就像在Excel中一样。

 **Table Resizing Indicator** - 如果将showResizeHandle（）方法的值设置为true，则调整大小指示符将显示在表的右下角。

 **Table Resizing Handler** - 当用户将鼠标悬停在表大小调整指示器上时，将显示表大小调整处理程序。

在表单中处理表格时，用户可以使用 **showResizeHandle()** 方法获取或设置一个值的，该值指示是否显示表的大小调整。

当 **showResizeHandle（）** 方法的值设置为true时，该表将在表的右下角显示一个小的调整大小指示符。 之后，用户可以使用表调整大小处理程序简单地拖动表，以将表调整为所需的大小，如下图所示。

### 将表格调整到一个区域

用户可以根据自己的特定要求将表的大小调整为较大和较小的区域。

-  **Larger Range** - 通过将表大小调整处理程序移向正确的方向或底部方向来调整表的大小时； 扩展区域中的单元格将复制相同的样式，并且将分别使用新名称添加新的列或行。
-  **Smaller Range** - 通过向左方向或顶部方向移动表格大小调整处理程序来调整表格大小时； 表的数据值将保持不变，但样式将分别从其他列或行中删除。



### 使用标题行和总行调整表的大小

用户还可以调整包含标题行和总计行的表的大小。

当通过向右移动表大小调整处理程序来调整包含标题行和总行的表的大小时，扩展区域中的单元格将复制相同的样式，并且新列将添加新名称。

对于底部方向，调整大小范围的行计数包含标题行和总计行。 对于左方向，表中的数据值将保留，但样式将从其他列中删除。 对于顶部方向，行数也将被调整大小（调整区域的行数+ 1）。



### 调整包含公式的表的大小

调整表格大小后，所选范围将保持不变。 调整包含样式和数据的表的大小后，公式也将保持不变，并且也会自动应用于新范围。 调整表大小后，将更新表范围的公式。

在SpreadJS中调整表大小时，必须牢记以下几点：

- 用户只能同时在列方向或行方向上调整大小。
- 表格的最小大小是包含一个表格行和一个表格列的单元格范围，但标题行和总计行除外。
- 表的最大大小是包含表行数，表列数，表单行数和表单列数的单元格范围。
- 如果扩展区域中有值，那么这些值将自动填充到表格中。
- 在Excel中，如果用户调整包含总行的表的大小； 那么现有表格范围以下的所有值都将填充到展开范围。 但是，在SpreadJS中，总行将与低于现有表范围的最后一行重叠。
- 当表单中的单元格包含迷你图时，还支持表格大小调整功能。

### 代码

以下示例代码显示了在使用表单时如何启用表大小调整处理程序来调整表大小。


```JavaScript
// 初始化 Spread
var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });

// 获取表单
var activeSheet = spread.getActiveSheet();
// 添加表格
var table = activeSheet.tables.add("table1", 1, 1, 4, 4, GC.Spread.Sheets.Tables.TableThemes.light1);
// 通过将表的showResizeHandle方法设置为true来启用表调整大小处理程序
table.showResizeHandle(true);
activeSheet.getCell(1, 1).text("First Name");
activeSheet.getCell(1, 2).text("Last Name");
activeSheet.getCell(1, 3).text("Score");
activeSheet.getCell(1, 4).text("Position");
activeSheet.getCell(2, 1).text("Alexa");
activeSheet.getCell(2, 2).text("Wilder");
activeSheet.getCell(2, 3).text("90");
activeSheet.getCell(2, 4).text("Web Developer");
activeSheet.getCell(3, 1).text("Victor");
activeSheet.getCell(3, 2).text("Wooten");
activeSheet.getCell(3, 3).text("70");
activeSheet.getCell(3, 4).text(".NET Developer");
activeSheet.getCell(4, 1).text("Ifeoma");
activeSheet.getCell(4, 2).text("Mays");
activeSheet.getCell(4, 3).text("85");
activeSheet.getCell(4, 4).text("Sales Manager");
for (var i = 0; i < 3; i++)
activeSheet.setColumnWidth(i, 90.0, GC.Spread.Sheets.SheetArea.viewport);
activeSheet.setColumnWidth(4, 120);
```
