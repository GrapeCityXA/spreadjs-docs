# sorting

您可以对电子表格中的数据进行排序，并指定要排序的列或行索引以及排序条件。您还可以指定多个排序键（首先按指定的列或行排序，然后按另一列或行排序，依此类推）。

## 按升序或降序对范围进行排序

使用 **`sortRange`** 方法对数据进行排序。 在 **`sortRange`** 方法中使用 **`sortInfo`** 对象来指定排序键和升序或降序。
![codesort](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/codesort.f4f45e.gif)
选择一个按钮以对第一列进行排序。

```JavaScript
var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"),{sheetCount:3});
var activeSheet = spread.getActiveSheet();
activeSheet.setValue(0, 0, 10);
activeSheet.setValue(1, 0, 100);
activeSheet.setValue(2, 0, 50);
activeSheet.setValue(3, 0, 40);
activeSheet.setValue(4, 0, 80);
activeSheet.setValue(5, 0, 1);
activeSheet.setValue(6, 0, 65);
activeSheet.setValue(7, 0, 20);
activeSheet.setValue(8, 0, 30);
activeSheet.setValue(9, 0, 35);

$("#button1").click(function(){
     //每次单击按钮时，按升序对Column1进行排序。
    activeSheet.sortRange(-1, 0, -1, 1, true, [{index:0, ascending:true}]);
   });
 $("#button2").click(function(){
    //每次单击按钮时降序对Column1进行排序。
     activeSheet.sortRange(-1, 0, -1, 1, true, [
       {index:0, ascending:false}
     ]);
 });
//向页面添加按钮控件
<input type="button" id="button1" value="button1"/>
<input type="button" id="button2" value="button2"/>
```

## 对多个范围进行排序

您可以通过在 `sortInfo` 对象中指定多个排序键来对多个范围进行排序。
![sort-multiple-keys](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/sort-multiple-keys.c65e5e.gif)
本示例使用多个排序键对行进行排序。

```JavaScript
$(document).ready(function ()
{
    var spread =
    new GC.Spread.Sheets.Workbook(document.getElementById("ss"),
    {sheetCount:3});
    var activeSheet = spread.getActiveSheet();
    activeSheet.setRowCount(6);
    activeSheet.setValue(0, 0, 10);
    activeSheet.setValue(1, 0, 100);
    activeSheet.setValue(2, 0, 100);
    activeSheet.setValue(3, 0, 10);
    activeSheet.setValue(4, 0, 5);
    activeSheet.setValue(5, 0, 10);
    activeSheet.setValue(0, 1, 10);
    activeSheet.setValue(1, 1, 40);
    activeSheet.setValue(2, 1, 10);
    activeSheet.setValue(3, 1, 20);
    activeSheet.setValue(4, 1, 10);
    activeSheet.setValue(5, 1, 40);
    $("#button1").click(function()
   {
  
      // 创建一个SortInfo对象，其中1st Key：Column1 / 2nd Key：Column2。
      var sortInfo =
       [
            {index:0, ascending:true},
            {index:1, ascending:true}
       ];
       
      // 执行基于排序条件针对所有行的排序。
      spread.getActiveSheet().sortRange(0, 0, 6, 2, true, sortInfo);
   });
});
```

## 保留上次排序状态

可以在对数据进行排序之前保留数据的默认状态或上次应用的状态，
无论何时应用不同的排序顺序，该状态都不会更改。
可以在需要时使用`getSortState`方法获取当前工作表的最后排序状态，并且可以使用`sortRange`方法对数据范围重新排序。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.029abc.png)
以下代码示例实现工作表的`ValueChanged`事件，该事件调用`getSortRange`方法来恢复排序状态，然后在排序区域中检测到任何更改时使用`sortRange`方法。

```javascript
// To call automatic sorting every time any value is changed.
sheet.bind(GC.Spread.Sheets.Events.ValueChanged, function (e, info) {
     let sortState = sheet.getSortState();
     if (inSortStateRange(sortState, info.row, info.col)) {
         sheet.sortRange();
     }
});
```

>type=info
> 注意：
>
> * 此功能支持 SSJSON、SJS 和 XLSX 的导出/导入。
> * 使用`worksheet.getsortState()`进行过滤不会返回排序状态

## 排序时忽略隐藏数据

您还可以通过使用API中的 **ignoreHidden** 选项在排序时跳过隐藏数据。 在以下情况下，单元格或范围被认为是隐藏的：

* 行的高度或列的宽度为0
* 行或列被隐藏
* 行或列被筛选掉
* 某些行或列被分组且未展开

以下示例包含隐藏的行（单元格A5：A6），并显示如何使用不同的 **ignoreHidden** 值对数据进行排序：

## 排序时排除数据标题行

在工作表中排序数据时，用户通常需要固定标题行，避免列标题与数据一起被排序。
**SpreadJS 会自动检测所选范围中的标题行**，并可在排序时将其排除。

### 功能可用性

* 可通过 SpreadJS 设计器中的 **自定义排序对话框** 访问。
* 支持表格、**普通范围** 和筛选后的数据（含条件筛选）。
* 标题行检测仅适用于 **从上到下** 的排序方向。

### 核心优势

#### 1\. 自动标题行检测

SpreadJS 会自动检测并区分数据范围中的标题行与数据行：

* 主要评估所选范围的首行，必要时还会评估其正上方的行。
* 基于前两行的单元格类型、内容或样式差异进行判断（允许部分空白单元格）。
* 若无法识别明确的标题行，默认将当前所选范围的首行视为标题行。

#### 2\. 简化操作流程

用户可直接对整个数据集进行排序，标题行会自动保留在顶部，减少列标题排序错误的风险。

#### 3\. 准确的排序标签显示

* 检测到标题行时，排序对话框中的“排序依据”列表会显示标题单元格中的文本。
* 若取消勾选“我的数据包含标题行”选项，排序对话框将显示列字母（例如“列 A”“列 B”）而非标题文本。

### 操作步骤

步骤 1：在工作表中选择需要排序的数据范围。

步骤 2：通过以下任一方式打开“自定义排序”对话框：

* 方式 1：在 **数据** 选项卡的 **排序和筛选** 组中，点击 **排序**。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image.63837f-20251226.cfec58.png)
* 方式 2：右键单击所选范围，指向 **排序**，然后从上下文菜单中选择 **自定义排序**。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image.31c383-20251226.23ff9b.png)

>type=note
> **注意事项**：
>
> * **自定义排序记忆功能**：自定义排序对话框会自动保存每个所选范围的上次排序配置。后续可重新打开对话框，查看或调整已有的排序层级和顺序。
> * **一键排序行为**：使用一键式“升序排序（A→Z）”或“降序排序（Z→A）”命令时：
>     * 若文件打开后未执行过自定义排序，SpreadJS 会自动检测当前所选范围的首行是否为标题行，并将其排除在排序之外。
>     * 执行过自定义排序后，“我的数据包含标题行”选项的上次状态会被保留，并应用于同一会话中后续所有的一键排序操作。
