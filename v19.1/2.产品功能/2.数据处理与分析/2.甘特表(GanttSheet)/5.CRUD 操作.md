# crud-operations

甘特表允许用户通过行操作与数据进行交互，包括创建、读取、更新和删除（CRUD）操作。这些操作可方便地将已编辑的行数据与你的数据库同步。
以下是[甘特表](gcdocsite__documentlink?toc-item-id=ffc63013-9853-40f9-99bb-f94f4f1f0b74)类中可用作行操作的方法：

| **方法** | **描述** |
| --- | --- |
| addRow | 向表格添加新行。 |
| removeRow | 从表格中移除指定行。 |
| saveRow | 将表格中指定行的更改保存到数据管理器，包括更新和插入的行。 |
| resetRow | 重置表格中指定行的更改。 |

## 甘特表方法

让我们通过示例代码来理解甘特表中的 CRUD 操作。

### 创建（插入任务）

向甘特表添加新任务，包括层次关系（例如，父子关联）。任务以批处理模式排队。

```javascript
if (item.type == "insert") {
    item.dataItem.id = (item.sourceIndex + 1).toString();
    if (item.sourceParentIndex) {
        item.dataItem.parentId = item.sourceParentIndex + 1;
    }
    const params = { method: "POST", body: JSON.stringify(item.dataItem) };
    params.headers = { 'Content-Type': 'application/json; charset=utf-8' };
    results.push(fetch(url, params).then(resp => {
        console.log(resp)
        if (resp.ok) {
            return { succeed: true, data: resp.json() };
        } else {
            return { succeed: false, reason: resp.statusText };
        }
    }));
}
```

### 读取（获取任务）

从服务器检索数据以填充甘特表。

```javascript
remote: {
    read: {
        url: apiUrl,
    },
}
```

### 更新（修改任务）

修改任务属性，如持续时间、成本或依赖关系。更新操作将排队进行批处理。

```javascript
if (item.type == "update") {
    const params = { method: "PUT", body: JSON.stringify(item.dataItem) };
    params.headers = { 'Content-Type': 'application/json; charset=utf-8' };
    results.push(fetch(url + item.dataItem.id, params).then(resp => {
        if (resp.ok) {
            return { succeed: true, data: resp.json() };
        } else {
            return { succeed: false, reason: resp.statusText };
        }
    }));
}
```

### 删除（移除任务）

从甘特表中移除指定任务。删除操作将排队并以批处理模式进行处理。

```javascript
if (item.type == "delete") {
    const params = { method: "DELETE" };
    params.headers = { 'Content-Type': 'application/json; charset=utf-8' };
    results.push(fetch(url + item.dataItem.id, params).then(resp => {
        if (resp.ok) {
            return { succeed: true, data: resp.json() };
        } else {
            return { succeed: false, reason: resp.statusText };
        }
    }));
}
```

## 批处理模式同步

甘特表仅支持这些操作的批处理模式。
要使用甘特表，用户必须拥有一个支持批处理模式的服务器，或者实现服务器端逻辑来处理批量更新。如果没有服务器端支持，则应在客户端实现伪批处理模式。

```javascript
// Submitting changes
ganttSheet.submitChanges();
```

## 模式配置

该模式定义了甘特表中任务的结构，包括层次结构和列属性。

```javascript
var myTable1 = dataManager.addTable("myTable1", {
    batch: true,
    remote: {
        read: {
            url: apiUrl,
        },
        batch: function (changes) {
            return sendRequest(apiUrl, { body: changes });
        }
    },
    schema: {
        hierarchy: {
            type: "Parent",
            column: "parentId",
        },
        columns: {
            id: { isPrimaryKey: true },
            taskNumber: { dataType: "rowOrder" },
        }
    }
});
```

## 将甘特表绑定到视图

将任务视图绑定到甘特表以便进行可视化和交互。

```javascript
var ganttSheet = spread.addSheetTab(0, "GanttSheet1", GC.Spread.Sheets.SheetType.ganttSheet);

    ganttSheet.bindGanttView(view);
});
```

## 自定义请求

sendRequest 函数处理批处理操作的服务器请求。当服务器端不支持批处理时，这对于在客户端实现伪批处理模式至关重要。

```javascript
function sendRequest(url, options) {
    const results = [];
    for (const item of options.body) {
        // Insert, update, or delete logic
    }
    return Promise.all(results);
}
```

## 示例

为了清晰理解 CRUD 操作的工作原理，以下是一个完整示例，它将各个代码片段组合成一个有序的实现。

```javascript
 <script>
     function getBaseApiUrl() {
         return 'https://demo.grapecity.com.cn/spreadjs/demos/features/ganttsheet/overview/purejs'.match(/http.+spreadjs\/demos\//)[0] + 'server/api';
     }

     let spread = new GC.Spread.Sheets.Workbook("spreadjs-host");
     spread.options.tabStripRatio = 0.8;
     spread.setSheetCount(0);

     function sendRequest(url, options) {
         const results = [];

         for (const item of options.body) {
             if (item.type == "insert") {
                 item.dataItem.id = (item.sourceIndex + 1).toString();
                 if (item.sourceParentIndex) {
                     item.dataItem.parentId = item.sourceParentIndex + 1;
                 }
                 const params = { method: "POST", body: JSON.stringify(item.dataItem) };
                 params.headers = { 'Content-Type': 'application/json; charset=utf-8' };
                 results.push(fetch(url, params).then(resp => {
                     console.log(resp)
                     if (resp.ok) {
                         return { succeed: true, data: resp.json() };
                     } else {
                         return { succeed: false, reason: resp.statusText };
                     }
                 }));
             }
             else if (item.type == "update") {
                 const params = { method: "PUT", body: JSON.stringify(item.dataItem) };
                 params.headers = { 'Content-Type': 'application/json; charset=utf-8' };

                 results.push(fetch(url + item.dataItem.id, params).then(resp => {
                     if (resp.ok) {
                         return { succeed: true, data: resp.json() };
                     } else {
                         return { succeed: false, reason: resp.statusText };
                     }
                 }));
             }
             else if (item.type == "delete") {
                 const params = { method: "DELETE" };
                 params.headers = { 'Content-Type': 'application/json; charset=utf-8' };

                 results.push(fetch(url + item.dataItem.id, params).then(resp => {
                     if (resp.ok) {
                         return { succeed: true, data: resp.json() };
                     } else {
                         return { succeed: false, reason: resp.statusText };
                     }
                 }));
             }
         }
         return Promise.all(results);
     }

     var tableName = "Gantt_Id";
     var baseApiUrl = getBaseApiUrl();
     var apiUrl = baseApiUrl + "/" + tableName;
     var dataManager = spread.dataManager();

     var myTable1 = dataManager.addTable("myTable1", {
         batch: true,
         remote: {
             read: {
                 url: apiUrl,
             },

             batch: function (changes) {
                 return sendRequest(apiUrl, { body: changes });
             }
         },
         schema: {
             hierarchy: {
                 type: "Parent",
                 column: "parentId"
             },
             columns: {
                 id: { isPrimaryKey: true },
                 taskNumber: { dataType: "rowOrder" }
             }
         }
     });

     var ganttSheet = spread.addSheetTab(0, "GanttSheet1", GC.Spread.Sheets.SheetType.ganttSheet);
     var view = myTable1.addView("myView1", [
         { value: "taskNumber", caption: "NO", width: 60 },
         { value: '=CONCAT("(L",LEVEL(),"-",LEVELROWNUMBER(),")")', caption: "L" },
         { value: "name", caption: "Task Name", width: 200 },
         { value: "duration", caption: "Duration", width: 90 },
         { value: "predecessors", caption: "Predecessors", width: 60 },
         { value: "cost", caption: "Cost", style: { formatter: "$0" } }
     ]);
     view.fetch().then(function () {
         ganttSheet.bindGanttView(view);
     });

     document.getElementById("btn").onclick = () => {
         ganttSheet.submitChanges();
     }
 </script>
```
