# calendar-setting

甘特图工作表使用不同的日历来确定工作时间和非工作时间，以便进行精确的调度和资源分配。每个日历都包含可自定义的工作周、工作日和工作时间。
当你创建一个项目时，它会使用默认的基准日历来安排任务。如果你的项目的工作日和工作时间超出了默认范围，你可以切换到不同的基准日历，或者调整项目日历的工作时间以满足你的需求。

## 应用内置日历

SpreadJS 为甘特图工作表提供了以下内置日历：

* **标准**（周一至周五，上午 8:00 至下午 5:00）
* **夜班**（周一至周五，晚上 11:00 至凌晨 4:00；周六，晚上 11:00 至上午 8:00）
* **24 小时**（一周七天，每天 24 小时）

以下代码示例展示了如何将 `hours24` 日历分配给一个项目，该日历表示全天 24 小时连续工作。

```javascript
var calendar = GC.Spread.Sheets.GanttSheet.Calendar.hours24;
ganttSheet.project.calendar = calendar;
```

## 创建默认日历

SpreadJS 允许你定义和自定义项目日历、工作周和工作时间。使用 `GC.Spread.Sheets.GanttSheet.Calendar` API 来创建一个默认的项目日历。为此，你需要像以下代码示例那样给出一个日历名称。

```javascript
GC.Spread.Sheets.GanttSheet.Calendar("defaultCalendar") 
```

一旦创建完成，你可以使用 `GC.Spread.Sheets.GanttSheet.WorkWeek` API 来定义日历中的常规工作周。工作周是一个工作日的列表，你可以在其中指定每天的工作时间。另一方面，工作日是一个数组，用于设置每个工作时段的开始和结束时间。使用 `GC.Spread.Sheets.GanttSheet.WorkTime` 和 `GC.Spread.Sheets.GanttSheet.Time` API，你可以在工作周所定义的日期内设置工作时间。
此外，SpreadJS 提供了 `GC.Spread.Sheets.GanttSheet.CustomWorkWeek` API 来创建自定义工作周，它是常规工作周的扩展。它允许你通过设置特定日期和调整这些时段的工作时间来标记特殊时间，如假期或请假时间。

## 自定义日历设置

日历设置主要为计算工期定义了一些属性。你可以配置日历的以下设置。

| **设置** | **描述** | **默认值** | **示例代码** |
| --- | --- | --- | ---- |
| 周起始日 | 一周的第一天 | 星期日 | ganttSheet.project.calendarSettings.weekStartOn = GC.Spread.Sheets.GanttSheet.DayOfWeek.Sunday; |
| 默认开始 / 结束时间 | 每日工作的开始 / 结束时间 | 开始时间：上午 8:00<br>结束时间：下午 5:00 | ganttSheet.project.calendarSettings.defaultStartTime = { hour: 8, minute: 0 };<br>ganttSheet.project.calendarSettings.defaultFinishTime = { hour: 17, minute: 0 }; |
| 每日工时 | 一个工作日的时长 | 8 小时 | ganttSheet.project.calendarSettings.hoursPerDay = 8; |
| 每周工时 | 工作周的时长 | 40 小时 | ganttSheet.project.calendarSettings.hoursPerWeek = 40; |
| 每月天数 | 工作月的时长 | 20 天 | ganttSheet.project.calendarSettings.daysPerMonth = 20; |
| 工期单位<br>注意，工期单位仅可对汇总任务进行更改。在甘特图视图中，普通任务始终使用 “天” 作为工期单位 | 工作时间的度量单位 | 天 | ganttSheet.project.calendarSettings.defaultDurationUnit = "Day"; |
| 默认工期小数位数 | 计算时保留的时间精度 | 3 | ganttSheet.project.calendarSettings.defaultDurationDecimalDigits = 3; |

## 更改工作时间

如果一个项目的常规工作安排与任何可用的基准日历都不匹配，你也可以更改项目的工作时间，以便正确安排任务。
要更改工作时间，首先你需要从项目的当前日历或内置命名空间中获取默认工作周。之后，你可以对日历进行更改，然后将编辑后的日历应用到项目中。以下代码示例展示了如何更改日历上的工作时间：

```javascript
// Get the default workweek from project current calendar.
var calendar = ganttSheet.project.calendar;
console.log(calendar.defaultWorkWeek);

// or

// Get the default workweek from built-in namespace.
console.log(GC.Spread.Sheets.GanttSheet.Calendar.standard);
console.log(GC.Spread.Sheets.GanttSheet.Calendar.hours24);
console.log(GC.Spread.Sheets.GanttSheet.Calendar.nightShift);

// Change the working time.
var calendar = GC.Spread.Sheets.GanttSheet.Calendar.standard;
var defaultWorkWeek = calendar.defaultWorkWeek;
var workday = defaultWorkWeek.getWorkDay(GC.Spread.Sheets.GanttSheet.DayOfWeek.Monday);

// The Working Day is formed with time range:
    /*
    [
        { start: { hour: 8, minute: 0 }, end: { hour: 12, minute: 0 } },
        { start: { hour: 13, minute: 0 }, end: { hour: 17, minute: 0 } }
    ]
        // 8:00~12:00 13:00~17:00
    */
workday[1].end.hour = 13;

// Apply the edited calendar
ganttSheet.project.calendar = GC.Spread.Sheets.GanttSheet.Calendar.standard;
}
```

你可以在 SpreadJS 设计器中更改工作时间并设置所选的日历信息。为此，在添加甘特图工作表后，你可以使用 “项目” 选项卡，并在 “属性” 组中选择 “更改工作时间” 按钮。在 “更改工作时间” 对话框中，你需要从 “对于日历” 下拉菜单中选择要修改的日历信息，并通过选择不同日期来查看当天的具体工作时间。
然后，点击 “工作周” 选项卡选择一个时间段，再点击 “详细信息” 来更改默认工作时间。如果你选择 “将（某些）天设置为这些特定工作时间”，使用 “开始” 和 “结束” 列来设置所选日期的工作时间。
![change working time.7dd26f](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/change%20working%20time.7dd26f.6fded6.png)

> **注意**：
>
> * 只有选择 “将（某些）天设置为这些特定工作时间” 时才能更改工作时间。
> * 更改的日期将被标记为 “非默认工作周”。

此外，你还可以通过在 “更改工作时间” 对话框的右上角选择 “创建新日历...” 来创建自己的基准日历。
