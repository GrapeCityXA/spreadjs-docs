# table-themes

甘特表格支持应用[GC.Spread.Sheets.Tables.TableTheme](gcdocsite__documentlink?toc-item-id=f44373d6-7a91-4c68-9ab5-ad56d0f36768)来控制工作表的基础外观样式。
通过`applyTableTheme`方法应用主题后，甘特表格会读取主题样式，并将其样式分配至不同的界面区域。

>type=info
> 主题样式仅作为基础样式使用，所有明确设置的甘特表格配置（例如任务条样式规则、非工作时间设置等）都会覆盖已应用的主题样式。
> ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260525.ba14b6.png?width=800)

## 主题应用范围

甘特表格包含三大视觉区域：

* 表格区域（任务列表）
* 时间刻度区（时间轴表头）
* 甘特图区域（时间轴主体与任务条）
    不同区域仅会调用`TableTheme`中的对应子集样式。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260525.a7e18e.png?width=800)
    下文将分别说明各个区域的主题应用规则。

## 表格区域

表格区域会完整调用**全部**表格主题样式。
可生效的样式包含：

* 整体表格样式
* 表头行样式
* 奇偶行第一种交替样式
* 奇偶行第二种交替样式
* 边框样式
* 字体与文字颜色
* 行交替配色样式
    甘特表格支持主题内定义的行交替配色样式。

### 任务层级显示规则

主题中的字体配置会结合内置层级规则，直观区分不同任务类型。

| 任务类型 | 字体粗细 | 字体大小 |
| ---- | ---- | ---- |
| 项目摘要任务 | 粗体 | 12磅 |
| 摘要任务 | 粗体 | 11磅 |
| 普通任务 | 常规字体 | 11磅 |

主题可提供以下基础配置：

* 字体类型
* 基础文字颜色
    甘特表格会通过预设的字号与字重调整方式突出任务层级，以此实现以下效果：
* 项目摘要任务视觉效果最醒目
* 摘要任务可与其他任务清晰区分
* 普通任务保持常规视觉效果

## 时间刻度区

时间刻度区为时间轴的表头区域，其视觉样式与表格区域的列表表头保持一致。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260525.7ea28f.png?width=800)
时间刻度区仅调用主题内和表头相关的样式：

* 背景颜色
* 表头文字字体
* 表头文字颜色
* 水平网格线颜色
* 垂直网格线颜色
    网格线仅会读取主题内的边框颜色进行绘制。

>type=info
> **注意：**
> 网格线是否绘制由甘特表格自身的网格线配置决定。
> 若未定义网格线样式，即便应用了主题，也不会渲染出网格线。

## 甘特图区域

甘特图区域包含以下组成部分：

* 时间轴背景
* 网格线
* 任务条
* 任务关联连接线
* 非工作时间背景
    只有在`TableTheme`中有对应样式定义的元素，才能够读取并应用主题样式。

### 可通过表格主题设置样式的元素

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260525.0eccf3.png?width=800)
支持调用主题样式的元素如下：

* 背景颜色
* 水平网格线颜色
* 垂直网格线颜色
* 任务条内文字字体
* 任务条内文字颜色

任务条文字样式会和任务样式规则组合生效，若二者同时设置了文字样式，以任务样式规则为准。
网格线绘制遵循以下规则：

* 若网格线单独指定了颜色，优先使用该颜色
* 若仅定义了网格线线型、未指定颜色，则沿用主题对应的边框颜色
* 未设置任何线型的网格线，不会进行渲染绘制

### 不受表格主题控制的元素

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260525.6d8fd8.png?width=800)
以下元素的样式不会被`TableTheme`影响：

* 任务条主体填充色与边框样式
* 任务之间的关联连接线
* 非工作时间背景
* 最后一列专属特殊样式
    如需自定义以上元素样式，可使用甘特表格对应的应用程序编程接口实现。

## 样式优先级

当同时使用多种样式设置方式时，实际生效优先级顺序如下：

```自动排版
任务条样式规则 / 组件级配置    
> 甘特表格专属接口方法        
> 表格主题
```

已应用的`TableTheme`仅作为全局基础样式层存在。

## 代码示例

### 应用主题

```javascript
ganttSheet.applyTableTheme(    
GC.Spread.Sheets.Tables.TableThemes.medium2
);
```

应用表格主题后，会同步更新以下位置的基础外观：

* 表格区域
* 时间刻度区
* 甘特图背景与网格线
* 任务条内文字样式

### 应用主题并开启网格线

网格线的颜色可直接取自已应用的主题样式。

```javascript
// 应用主题
ganttSheet.applyTableTheme(    
GC.Spread.Sheets.Tables.TableThemes.medium3
);
// 开启水平与垂直网格线
ganttSheet.options.gridline = {    
horizontal: { lineStyle: 1 },    
vertical: { lineStyle: 1 }
};
```

若仅设置了网格线线型、未手动指定颜色，网格线会自动沿用当前已应用表格主题中的对应颜色。

### 获取当前生效主题

```javascript
var theme = ganttSheet.getTableTheme();
```

可通过该方法获取当前甘特表格正在使用的表格主题实例对象。

### 覆盖主题默认样式

主题仅作为底层基础样式，组件级别的自定义配置可以直接覆盖主题样式。

```javascript
// 应用内置浅色表格主题
ganttSheet.applyTableTheme(    
GC.Spread.Sheets.Tables.TableThemes.light2
);
// 自定义任务条外观（优先级高于表格主题）
var rule = ganttSheet.project.taskStyleRules.getRule('task');
rule.style.taskbarStyle.middleColor = '强调色1';
rule.style.taskbarStyle.topText = '名称';
var index = ganttSheet.project.taskStyleRules.getIndexByItem(rule);
ganttSheet.project.taskStyleRules.setItemAt(index, rule);
```

任务样式规则的优先级高于表格主题样式。
