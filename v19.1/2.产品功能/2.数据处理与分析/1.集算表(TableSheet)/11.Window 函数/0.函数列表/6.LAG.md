# lag

该函数提供对给定偏移量之前的当前行的值进行访问的功能。如果没有这样的行，将返回默认值。它不接受窗口帧定义，比如FRAMEROWS和FRAMERANGE。

## 语法

`LAG(value_function, [offset_value], [default_value])`

## 参数

该函数提供以下参数。

| **参数** | **描述** |
| -------- | ----------- |
| *value\_function* | [必选] 字段名或公式。 |
| *[offset\_value]* | [可选] 当前行之前的行偏移量，offset = 1。 |
| *[default\_value]* | [可选] 默认值，默认为null |

## 示例

```
// WINDOW(LAG([@city]), ORDERBY([sold]))

城市       |   销售额  |   lag
----------------------------------------------
Paris         100           null
Berlin        150           Paris
Rome          200           Berlin
Moscow        200           Rome      
London        300           Moscow

// WINDOW(LAG([@city], 2), ORDERBY([sold]))

城市      |    销售额  |   lag
----------------------------------------------
Paris        100           null
Berlin       150           null
Rome         200           Paris
Moscow       200           Berlin
London       300           Rome
```
