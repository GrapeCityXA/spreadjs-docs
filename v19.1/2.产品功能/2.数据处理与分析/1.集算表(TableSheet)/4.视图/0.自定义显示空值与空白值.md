# customize-display-null-and-empty-values

默认情况下，当数据值为`null`、`undefined`或是空字符串（`""`）时，集算表中的单元格会显示为空白。这就导致很难区分以下几种数据状态：

* `null`空值
* 空字符串
* 缺失值

为了让数据展示更清晰，你可以在列级别为这类数值指定自定义展示文本。
![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260319.75a713-20260525.7d5f43.png?width=600)

## 列属性

```typescript
interface GC.Data.IColumn {  
showNullAs?: string;   // 用于展示null或undefined值的文本
showEmptyAs?: string;  // 用于展示空字符串（""）的文本
}
```

* `showNullAs`适用于数值为`null`或`undefined`的场景。
* `showEmptyAs`适用于数值为空字符串（`""`）的场景。

同一个列中可同时使用这两个属性。

## 代码配置

本示例演示以下内容：

* 默认空白显示效果
* 表格架构层级配置
* 视图层级补充配置

**步骤一：准备示例数据**

```javascript
var sampleData = [  
{ Id: 1, Name: "约翰·多伊", Email: "john@example.com", Phone: "123-456-7890", Score: 85, Notes: "普通用户" },  
{ Id: 2, Name: null, Email: "", Phone: "234-567-8901", Score: null, Notes: null },  
{ Id: 3, Name: "简·史密斯", Email: null, Phone: "", Score: 92, Notes: "" },  
{ Id: 4, Name: "", Email: "jane@example.com", Phone: null, Score: 78, Notes: "贵宾用户" },  
{ Id: 5, Name: "鲍勃·威尔逊", Email: "", Phone: null, Score: null, Notes: "" }
];
```

未进行任何配置时，`null`值与空字符串都会在单元格内显示为空白。
![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260319.236d0d-20260525.5fa70f.png?width=600)

**步骤二：在表格架构层级配置**

```typescript
var myTable = dataManager.addTable("myTable", {    
data: sampleData,    
schema: {        
columns: {            
Id: { dataType: "number" },            
Name: { showNullAs: "[空值]", showEmptyAs: "[空字符]" },            
Email: { showNullAs: "[空值]", showEmptyAs: "[空字符]" },            
Score: { showNullAs: "[无数据]", dataType: "number" }        
}    
}
});
```

本步骤配置说明：

* 姓名列和邮箱列针对`null`值与空字符串均设置了自定义展示文本。
* 分数列在数值为`null`时展示`[无数据]`。
    ![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260319.7bedee-20260525.4ff70b.png?width=600)

**步骤三：在视图层级配置**

```typescript
var myView = myTable.addView("myView", [    
{ value: "Id", caption: "编号", width: 60 },    
{ value: "Name", caption: "姓名", width: 150 },    
{ value: "Email", caption: "邮箱", width: 200 },    
// 手机号和备注栏进行视图层级配置
{ value: "Phone", caption: "手机号", width: 130, showNullAs: "[无号码]", showEmptyAs: "[空白内容]" },    
{ value: "Score", caption: "分数", width: 80},    
{ value: "Notes", caption: "备注", width: 150, showNullAs: "[空值]", showEmptyAs: "[无备注]" }
]);
```

本步骤配置说明：

* 手机号列与备注列完成视图层级的参数设置。
* 视图层级的配置仅对当前指定视图生效。

>type=info
> 若某一列未在视图中配置参数，则会沿用已定义的表格架构层级配置。

**步骤四：渲染视图**

```javascript
myView.fetch().then(function() {    
tableSheet.setDataView(myView);
});
```

在集算表中完成渲染后，`null`值和空字符串就会展示预先设置好的自定义文本内容。
![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260319.fc1607-20260525.c7a221.png?width=600)

## 文本对齐相关说明

如果未在列样式中明确设置水平对齐方式，文本对齐效果会依据**基础数据类型**遵循默认规则。

使用自定义展示文本时遵循以下规则：

* 常规数据值按照自身数据类型执行对齐规则。
* 自定义展示文本统一按照文本格式进行对齐。

**示例**
假设邮箱列设置为数值类型列：

```typescript
showNullAs: "0"
```

此时效果为：

* 普通数字数值靠右对齐。
* 代表`null`值展示出的`"0"`会靠左对齐。
    ![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260319.34236c-20260525.f0ce94.png?width=600)

## 设计器内配置方法

### 视图层面配置

1. 选中集算表视图。
2. 打开菜单栏中的**列设置**选项卡。
3. 在**空白内容展示**区域，分别设置空值、空内容对应的展示文字。
    ![视图动图](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/view-20260319.82c7c5-20260525.93e4b3.gif?width=800)

### 表格架构层面配置

1. 打开数据源面板。
2. 选中目标数据表。
3. 进入**列设置**界面。
4. 为对应列配置空白内容展示相关选项。
    ![表格架构动图](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/tableSchema-20260319.b9551b-20260525.d349f2.gif?width=800)

## 数据导出规则

导出为Excel文件时，是否导出自定义展示文本，由导出配置项[`saveAsView`](gcdocsite__documentlink?toc-item-id=eb1d4099-e070-4860-a56a-4b7f2986223a#saveasview)决定，该配置隶属于[`ExportOptions`](gcdocsite__documentlink?toc-item-id=93a45be2-e7f2-4fef-aa55-44b2d32eaf16#exportoptions)导出选项。

* `saveAsView = true`：导出的Excel文件中，单元格内容为通过`showNullAs`和`showEmptyAs`定义的展示文本。
* `saveAsView = false`（默认值）：导出文件保留原始底层数据，为空值或空字符串的单元格在Excel中依旧显示为空白。

### saveAsView配置使用示例

```javascript
spread.export(function (blob) {    
saveAs(blob, "导出表格.xlsx");
}, function (e) {    
console.log(e);
}, {    
fileType: GC.Spread.Sheets.FileType.excel,    
saveAsView: true
});
```

在可视化设计器中，可通过对应的导出复选框来开启或关闭该功能，实现相同配置效果。
