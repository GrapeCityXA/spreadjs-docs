# data-operations

TableSheet提供了行操作的形式与数据交互的能力，如创建、读取、更新和删除行操作。通过这些操作，您可以方便地将编辑的行数据与数据库同步。
以下类方法可用作TableSheet行操作：

| 方法 | 描述 |
| --- | --- |
| [addRow](gcdocsite__documentlink?toc-item-id=8dc0b7a4-ace7-4c61-b4a7-00790d5584fe#addRow) | TableSheet新增行 |
| [removeRow](gcdocsite__documentlink?toc-item-id=8dc0b7a4-ace7-4c61-b4a7-00790d5584fe#removeRow) | TableSheet删除特定行 |
| [saveRow](gcdocsite__documentlink?toc-item-id=8dc0b7a4-ace7-4c61-b4a7-00790d5584fe#saveRow) | 将TableSheet中指定行的更改保存到数据管理器，包括更新的行或插入的行 |
| [resetRow](gcdocsite__documentlink?toc-item-id=8dc0b7a4-ace7-4c61-b4a7-00790d5584fe#resetRow) | 重置表TableSheet中指定行的更改。 |

## 数据同步

TableSheet与数据管理器交互以更改表数据。如果要将更改的数据与远程数据库同步，还应启用自动更新或批量更新。
同步数据的相关配置请参考：[同步数据变更](gcdocsite__documentlink?toc-item-id=c929c2e0-554d-403b-b8c3-3bb0ecdf7d3d)

## 错误处理

当服务器返回连接错误（例如HTTP 404、HTTP 500）和服务器数据库错误（例如duplicated primary key, update failed）时，TableSheet允许用户通过回调来处理或显示错误。
行标题会显示一个红色报警图标，当用户将鼠标悬停在该图标上时，会显示错误提示。

## 获取数据变更

TableSheet 支持在将变更保存到服务器之前，从其当前数据视图中获取变更。你可以使用 TableSheet 类的 [getChanges ](gcdocsite__documentlink?toc-item-id=8dc0b7a4-ace7-4c61-b4a7-00790d5584fe#getchanges)方法，该方法会针对每种同步模式返回包含以下对象的数组。

* 数据项：当前行数据。
* 旧数据项：原始行数据（此为可选项）。
* 索引：TableSheet 视图索引。
* 变更类型：根据同步模式的不同，分为“更新”“插入”和“删除”。

在自动同步模式下，**getChanges** 方法会返回“更新行”或“插入行”的信息。然而，在批处理模式下，**getChanges** 方法会返回“更新行”“插入行”以及“删除行”的信息。

```JavaScript
tablesheet.getChanges();
```
