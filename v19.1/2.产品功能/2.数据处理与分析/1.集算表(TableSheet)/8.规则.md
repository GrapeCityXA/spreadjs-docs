# tablesheet-rules

集算表（TableSheet）支持不同的数据规则，以帮助突出显示数据中的差异并使其可视化，同时还能控制在集算表中输入的数据类型。

## 条件格式和数据验证

集算表在集算表视图中支持数据绑定的条件格式和数据验证。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ts-rules-condformat-dataval.fc276e.gif)
在定义视图列信息时，你可以指定 `conditionalFormat` 和 `validator` 属性。这些属性接受不同类型的规则选项数组，如下表所示。
集算表支持以下条件格式和数据验证类型。

| **属性** | **类型** |
| --- | --- |
| 条件格式 | ``` AverageRule``CellValueRule``DataBarRule``DateOccuringRule``DuplicateRule``FormulaRule``IconSetRule``SpecificTextRule``ThreeScaleRule``Top10Rule``TwoScaleRule``UniqueRule ``` |
| 数据验证器 | ``` DateValidator``FormulaListValidator``FormulaValidator``ListValidator``NumberValidator``TextLengthValidator``TimeValidator ``` |

以下代码示例展示了如何在集算表中应用条件格式和数据验证。

```javascript
// 应用条件格式的公式
var formulaRule = {
    ruleType: 'formulaRule',
    formula: '@<10',
    style: {
        backColor: 'green',
        foreColor: 'lime',
    },
};
// 创建一个数据验证器
var positiveNumberValidator = {
    type: 'formula',
    formula: '@>0',
    inputTitle: '数据验证:',
    inputMessage: '单价不能小于0。',
    highlightStyle: {
        type: 'icon',
        color: 'red',
        position: 'outsideRight',
    },
};
// 将视图绑定到集算表
myTable.fetch().then(function () {
    var view = myTable.addView('myView', [
        { value: 'stockItem', width: 300, caption: '库存商品' },
        { value: 'unitPrice', width: 120, caption: '单价', conditionalFormats: [formulaRule], validator: positiveNumberValidator }, // 在此处应用条件格式和数据验证
        { value: 'taxRate', width: 120, caption: '税率' },
        { value: '=([@unitPrice] * [@taxRate])/100 + [@unitPrice]', caption: '总价', width: 150 },
    ]);
    sheet.setDataView(view);
});
```

## 样式规则

样式规则是在满足特定条件时应用的样式。你可以使用 `GC.Data.View` 类的 `addStyleRule` 方法添加状态规则和公式规则，或者在 `addView` 方法的 `viewOptions` 参数中进行定义，这也允许你使用 `GC.Data.RowColumnStates` 枚举向数据管理器表格添加视图。你还可以选择 `viewport` 或 `colHeader` 作为视图区域来实现样式规则。

* **状态规则**：当触发行或列的状态时应用样式。例如，如果你希望在鼠标悬停在某一行上时，将该行以灰色背景色突出显示，或者像下图所示那样突出显示选中的列：
    ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ts-rules-staterule.0dff1a.gif)
* **公式规则**：对满足特定条件的特定值应用样式。例如，如果你想突出显示产品的较低价格，可以设置如 "[@UnitPrice]<10" 这样的公式，并使用不同的前景色，如下图所示：
    ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ts-rules-formularule.9a7d82.png)
    以下代码示例展示了如何在集算表中同时应用状态规则和公式规则。

    ```javascript
    // 设置公式规则
    var formulaRule = {
        ruleType: 'formulaRule',
        formula: '@<=10',
        style: {
            borderLeft: { color: 'orange', style: 'medium' },
            borderRight: { color: 'orange', style: 'medium' },
            borderTop: { color: 'orange', style: 'medium' },
            borderBottom: { color: 'orange', style: 'medium' },
        },
    };
    // 将视图绑定到集算表
    var myView = productTable.addView('myView', [
        { value: 'Id', caption: 'ID' },
        { value: 'ProductName', caption: '名称', width: 400 },
        { value: 'ReorderLevel', caption: '再订购水平', width: 120 },
        { value: 'UnitPrice', caption: '单价', width: 100, readonly: true, conditionalFormats: [formulaRule] },
        { value: 'UnitsInStock', caption: '库存数量', width: 100 },
        { value: 'UnitsOnOrder', caption: '订购数量', width: 100 },
    ]);
    // 通过 addStyleRule 方法添加规则
    myView.addStyleRule(
        'lowPrice',
        { backColor: 'green', foreColor: 'white' },
        {
            formula: '[@UnitPrice] <= 10',
        }
    );
    myView.addStyleRule(
        'HoverStyle',
        { backColor: 'gray', foreColor: 'white' },
        {
            area: GC.Data.ViewArea.colHeader,
            direction: GC.Data.StateRuleDirection.row,
            state: GC.Data.RowColumnStates.hover,
        }
    );
    myView.addStyleRule(
        'SelectedStyle',
        { backColor: 'yellow', foreColor: 'red' },
        {
            area: GC.Data.ViewArea.colHeader,
            direction: GC.Data.StateRuleDirection.column,
            state: GC.Data.RowColumnStates.selected,
        }
    );
    myView.fetch().then(function () {
        sheet.setDataView(myView);
    });
    
    ```

**状态类型**
下表列出了 `GC.Data.RowColumnStates` 中所有可用的行和列状态枚举选项。

| **枚举值** | **描述** |
| --- | --- |
| active | 当行或列处于焦点时，其状态包含 “active” 状态。 |
| dirty | 当单元格值发生变化时，单元格所在的行和列状态包含 “dirty” 状态。 |
| hover | 当鼠标悬停在行和列上时，其状态包含 “hover” 状态。 |
| inserted | 当插入一行时，其状态包含 “inserted” 状态。此状态仅支持行。 |
| pin | 当固定一行/列时，其状态包含 “pin” 状态。 |
| primaryKey | 当列具有主键时，其状态包含 “primaryKey” 状态。此状态仅支持列。 |
| readonly | 当列被锁定时，其状态包含 “readonly” 状态。此状态仅支持列。 |
| required | 当列的值为必填时，其状态包含 “required” 状态。此状态仅支持列。 |
| selected | 当单元格处于选择范围内时，单元格所在的行和列状态包含 “selected” 状态。 |
| updated | 当更新一行时，其状态包含 “updated” 状态。此状态仅支持行。 |

使用 SpreadJS，你还可以更新或移除默认规则。
以下代码示例展示了如何 **更新** **readonly** 状态的图标。

```javascript
            // 更新 readonly 状态的图标
            view.addStyleRule("readonly", {
                decoration: {
                    icons: [
                        {
                            src: 'readonly.png'
                        }
                    ]
                }
            }, {
                area: GC.Data.ViewArea.colHeader,
                direction: GC.Data.StateRuleDirection.column,
                state: GC.Data.RowColumnStates.readonly
            });
```

以下代码示例展示了如何移除样式规则中的 **readonly** 图标。

```javascript
 // 移除 readonly 状态图标
 view.removeStyleRule("readonly"); 
```

### 使用设计器

你可以使用 SpreadJS 设计器的 **列设置** 选项卡，将预定义的规则分配给列标题。
![set-rule](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/set-rule.c9593c.ad9581.png)
以下图片展示了规则在集算表列标题上的显示效果。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.8051ec.png)
应用规则后，你可以使用 SpreadJS 设计器的 **集算表设计** 选项卡对集算表中的规则进行样式设置。
![style-rules](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/style-rules.393552.a53da2.png)
**对规则进行样式设置的步骤如下：**

1. 点击 “集算表设计” 选项卡中的 “状态规则” 选项，打开 “管理状态规则” 对话框。
    ![manage-state-rules](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/manage-state-rules.d24621.2922cc.png)
2. 选择一个合适的选项，以在列标题上应用规则。
3. 要对选中的列标题进行样式设置，你可以使用 “新建规则” 按钮创建一个新规则，或者编辑现有规则并将其分配给列标题。
4. 点击 “样式” 列中的图标，这将打开 “设置单元格格式” 对话框。
    ![rule-format](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/rule-format.ba4143.9083b6.png)
5. 要从选中的列标题中移除图标，请使用 “移除规则” 按钮。
    ![remove-state-rules](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/remove-state-rules.db1d30.d47e04.png)
