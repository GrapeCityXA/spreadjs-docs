# hierarchy-type

## 层级操作

TableSheet 支持以下层级操作：

* **提升指定行的层级数据级别**
<br>
    TableSheet 允许用户使用 **promoteHierarchyLevel(row: number)** 方法，通过指定索引来提升层级数据的级别。

    ```JavaScript
    tableSheet.promoteHierarchyLevel(8);
    ```
* **降低指定行的层级数据级别**
<br>
    TableSheet 允许用户使用 **demoteHierarchyLevel(row: number, withChildren?: boolean)** 方法，降低指定行的层级数据级别。

    ```JavaScript
    tableSheet.demoteHierarchyLevel(8);
    ```
* **将指定行的层级数据上移**
<br>
    TableSheet 允许用户使用 **moveUp(row: number)** 方法，通过指定索引将层级数据上移。

    ```JavaScript
    tableSheet.moveUp(8);
    ```
* **将指定行的层级数据下移**
<br>
    TableSheet 允许用户使用 **moveDown(row: number)** 方法，通过指定索引将层级数据下移。

    ```JavaScript
    tableSheet.moveDown(8);
    ```
* **在选定行之后添加一条记录**
<br>
    TableSheet 允许用户使用 **addHierarchyItemAfter(row: number, rowData: any)** 方法，在指定行之后添加一个新行。

    ```JavaScript
    tableSheet.addHierarchyItemAfter(8, {id: 8, name: "grapecity"});
    ```
* **在选定行上方添加一条记录**
<br>
    TableSheet 允许用户使用 **addHierarchyItemAbove(row: number, rowData: any)** 方法，在选定行上方添加一条记录。添加的记录将取代选定记录的位置，而选定记录将成为添加记录的子记录。

    ```JavaScript
    tableSheet.addHierarchyItemAbove(8, {id: 8, name: "grapecity"});
    ```
* **在选定行下方添加一条记录**
<br>
    TableSheet 允许用户使用 **addHierarchyItemBelow(row: number, rowData: any)** 方法，将新的行数据作为指定行的子记录添加。你可以在选定行下方添加一条记录，添加的记录将成为选定记录的最后一个子记录。

    ```JavaScript
    tableSheet.addHierarchyItemBelow(8, {id: 8, name: "grapecity"});
    ```
* **删除一条记录**
<br>
    TableSheet 允许用户删除记录及其子记录。
* **展开一条记录**
<br>
    点击列标题时会出现此菜单项。它使用 **expandAllHierarchyLevels()** 方法展开所有层级。

    ```JavaScript
    tableSheet.expandAllHierarchyLevels();
    ```
* **折叠一条记录**
<br>
    点击列标题时会出现此菜单项，它使用 **collapseAllHierarchyLevels()** 方法折叠所有层级。

    ```JavaScript
    tableSheet.collapseAllHierarchyLevels();
    ```

## 切换菜单项可见性

升级、降级、上移/下移、添加前/后/上/下、展开/折叠级别的菜单项可以在运行时显示或隐藏。
下图展示了单击行标题时显示以下菜单项。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/e89163df-9462-4186-9f56-3bcf7b915acb/image.a573ae.png)
下图展示了在右键单击列标题时显示以下菜单项。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/e89163df-9462-4186-9f56-3bcf7b915acb/image.06208a.png)
代码示例显示了如何切换菜单项可见性。

```javascript
// show the menu items for hierarchical records
sheet.options.menuItemVisibility = {
// the options below be on the row header
promoteMenuItemVisible: true,
demoteMenuItemVisible: true,
// the options below be on the column header
expandAllLevelMenuItemVisible: true,
collapseAllLevelMenuItemVisible: true,
expandToLevelMenuItemVisible: true,
// the options below be on the row header
// and the menu items be enable for the dataType of the column be rowOrder
moveUpMenuItemVisible: true,
moveDownMenuItemVisible: true,
addBeforeMenuItemVisible: true,
addAfterMenuItemVisible: true,
addAboveMenuItemVisible: true,
addBelowMenuItemVisible: true,
};
```

## 使用 SpreadJS 设计器

使用数据源和 TableSheet 功能区的列选项卡，在 SpreadJS Designer 中也支持层次结构数据。 您可以配置层次结构类型、汇总公式、大纲列图像等。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/e89163df-9462-4186-9f56-3bcf7b915acb/image.910477.png)
层次结构部分提供以下选项：

* 层次结构类型：类型可以是 Parent、ChildrenPath 或 Level。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/e89163df-9462-4186-9f56-3bcf7b915acb/image.bd61ad.png)
* 汇总公式：用户可以为表格的指定列输入层级汇总公式。 要了解有关汇总公式的更多信息，请参阅公式主题。
* 大纲栏：大纲栏可用于自定义大纲栏的显示。
