# tablesheet-sort-filter

TableSheet 可在视图层面实现基于列的排序与筛选功能。
这两项功能均由视图选项和列配置定义，通过列表头的筛选按钮执行。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260421.8654e5-20260525.8d1a05.png?width=400)

## 排序

### 排序模式

每一列存在三种排序状态：

* 升序
* 降序
* 无排序
    ![sort.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/sort-20260421.3a8e12-20260525.c4e46e.gif?width=800)
    默认情况下，TableSheet 支持多列排序。
    进行多列排序时，视图会保存排序规则的有序列表，并依照该顺序依次执行排序操作，后续排序仅在前一轮排序生成的结果数据集中进行。
    ![multiSort.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/multiSort-20260421.8a00e5-20260525.995805.gif?width=800)

>type=info
> 清除所有排序规则即可恢复数据原始排列顺序。

### 排序控制

**多列排序模式**
由`ITableSheetOptions.allowSorts`属性控制：

```typescript
interface GC.Spread.Sheets.TableSheet.ITableSheetOptions {  
allowSorts?: boolean; // 默认值：true
}
```

* `true` — 允许同时启用多个排序规则。
* `false` — 仅保留单个生效排序规则，存在多个排序时只保留首个排序规则。
    **自动重新排序**
    通过视图属性进行设置：

```javascript
view.autoSort = false;
```

* 默认值：`true`
* 开启后，在已排序列中编辑数据会自动触发重新排序。
* 关闭后，编辑数据不会重新执行排序操作。

### 排序使用规则

**执行排序操作**
通过列菜单栏操作：

* 基础排序操作 — 为当前列设置排序并清空其他列的排序规则。
* 添加/移除排序（仅多列排序模式可用）：
* `+` 将当前列加入生效排序列表。
* `–` 将当前列从排序列表中移除。
    列的添加顺序决定排序优先级。
    移除某一列排序后，剩余排序规则会自动重新排序，同时重新计算整理数据顺序。
    ![addAndRemove.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/addAndRemove-20260421.002d5f-20260525.393714.gif?width=800)

### 排序标识

已设置排序的列会展示以下标识：

* 排序方向（升序/降序）
* 排序序号（仅启用多列排序时显示）
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260319.39ad0e-20260525.abdc87.png?width=400)
    未设置任何排序时，排序标识自动隐藏。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260319.4f16b6-20260525.7316f6.png?width=400)

### 结构化数据排序

**层级数据**
排序操作仅作用于同级节点，不会破坏原有层级结构。
![hierarchy.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/hierarchy-20260421.c98500-20260525.417a52.gif?width=800)
**分组数据**

* 分组列与其源列共用同一套排序状态。
* 多列排序模式下，每个分组层级均可设置多项排序规则。
* 排序优先级从高到低：

1. 高层级分组
2. 低层级分组
3. 普通数据列

* 若分组结构发生变动，关联分组列的排序规则可能会被重置。
    ![group.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/group-20260421.c8aabf-20260525.d40a09.gif?width=800)
    **交叉列**
    支持对交叉列执行排序操作，但若数据源发生变更或视图列重新构建，已设置的排序规则可能失效。
    ![cross..gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/cross.-20260421.edb40a-20260525.c95610.gif?width=800)

## 筛选

### 筛选模式

筛选功能以列为单位，支持同时启用多项筛选条件。

### 筛选控制

**筛选类型**

* 按值筛选 — 依据条件筛选文本、数字、日期类数据。
* 按列表筛选 — 从列内所有不重复数据项中勾选筛选内容。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260319.d5f02f-20260525.a70a57.png?width=400)
    可通过以下属性控制单列筛选功能的显示状态：
* `allowFilterByValue`
* `allowFilterByList`
    **自动重新筛选**
    配置方式如下：

```javascript
view.autoFilter = true;
```

* 默认值：`false`
* 开启后，新增或修改的数据若符合当前筛选的排除条件，会被自动隐藏。
* 关闭状态下，新增数据会默认保持显示状态。

## 单列自定义配置

开发者可单独为每一列配置排序与筛选的界面交互权限：

* `allowSort` 开启/关闭列排序
* `allowFilterByValue` 开启/关闭按值筛选
* `allowFilterByList` 开启/关闭按列表筛选

```javascript

var view = customerTable.addView('myView', [     { value: 'customerKey', allowSort: false, allowFilterByValue: false, allowFilterByList: false },     { value: 'customer', allowSort: false },     { value: 'billToCustomer', allowFilterByValue: false },     { value: 'category', allowFilterByList: false }, ]); sheet.setDataView(view); 

```
