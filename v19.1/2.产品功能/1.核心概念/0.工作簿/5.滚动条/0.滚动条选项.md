# scrollbars

你可以控制工作簿滚动条的显示状态与滚动行为。
## 显示或隐藏滚动条
使用`showHorizontalScrollbar`和`showVerticalScrollbar`控制滚动条是否显示。
这些属性支持三种取值：
* `true` — 始终显示滚动条
* `false` — 始终隐藏滚动条
* `"auto"` — 仅在工作表存在可滚动内容时显示滚动条
设置为`"auto"`模式后，若内容可完全适配可视区域，滚动条会自动隐藏。
```javascript
spread.options.showHorizontalScrollbar = "auto";
spread.options.showVerticalScrollbar = "auto";
```
![autoShow.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/autoShow-20260305.dd0b0f-20260525.413c68.gif?width=600)
在`"auto"`模式下，满足以下条件时滚动条同样会隐藏：
* 所有行和列均可完整显示在可视区域内
* 冻结行或列占据全部可滚动区域
>type=note
> **注意：** 导出为Excel文件时，`"auto"`会被视作`true`，因为Excel不支持滚动条自动显隐功能。
## 控制可滚动范围
你可以调整滚动条判定可滚动范围的规则。
* `scrollbarMaxAlign`：让滚动条对齐活动工作表的最后一行与最后一列。
* `scrollbarShowMax`：依据表格总行数与总列数计算滚动条的滚动范围。
```javascript
spread.options.scrollbarMaxAlign = true;
```

```javascript
spread.options.scrollbarShowMax = true;
```

## 忽略隐藏行与列
通过`scrollIgnoreHidden`属性，可在计算滚动范围时排除隐藏的行和列。
隐藏行和列包含以下类型：
* 高度或宽度设为零的行列
* 借助`visible`方法隐藏的行列
* 折叠后的分组行列
* 筛选后被隐藏的数据行
```javascript
spread.options.scrollIgnoreHidden = true;
```
