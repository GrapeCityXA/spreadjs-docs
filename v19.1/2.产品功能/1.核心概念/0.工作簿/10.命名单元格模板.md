# named-cell-templates

命名单元格模板支持自定义可复用的单元格配置，能够应用于工作簿内任意兼容区域。

命名样式仅封装外观样式属性，与之不同，命名单元格模板可在单个复用配置中纳入多项单元格相关设置：
* 样式
* 条件格式规则
* 数据验证规则
* 单元格状态

将各类配置整合为模板，能够保障多张工作表及其他兼容表格类型的格式统一，减少重复设置操作。

## 核心概念
### 模板定义
命名单元格模板具备以下特性：
* 拥有唯一标识名称
* 作用范围为整个工作簿
* 名称区分大小写不敏感

若使用已存在的名称新增模板，原有模板定义会被直接替换。
模板通过`workbook.namedCellTemplates`进行管理。

### 仅应用模式
命名单元格模板遵循仅应用使用模式：
* 模板仅在执行应用操作时生效
* 模板与目标单元格区域不会建立绑定关联
* 更新模板内容，不会改动已经应用该模板的单元格区域

若要在已格式化区域同步模板修改内容，需要重新套用模板。

### 不可变读取机制
调用模板管理器的`get(name)`方法，会返回存储模板的深层副本。
修改返回的副本对象，不会影响系统内已注册的模板。
如需更新现有模板，使用同名参数再次调用`add()`方法即可覆盖原有定义。

## 应用生效规则
将命名单元格模板应用至目标区域时，各项配置遵循下述执行规则：

| 设置项 | 生效规则 |
| ------- | -------- |
| 样式 | 覆盖原有单元格样式 |
| 数据验证 | 覆盖原有验证规则 |
| 条件格式 | 追加新增规则 |
| 单元格状态 | 追加新增状态 |

补充规则：
* 不会对规则进行合并与去重处理
* 保留原有的条件格式和单元格状态规则
* 新增规则的插入优先级遵循SpreadJS标准排序逻辑

由于模板采用仅应用模式，后续对模板的修改，不会同步到此前套用格式的单元格区域。

## 模板管理
可通过工作簿对外开放的`INamedCellTemplatesManager`接口管理模板，支持以下操作：
* 新增模板
* 基于现有单元格创建模板
* 查询获取模板
* 删除模板
* 遍历查看全部模板
* 清空所有模板
* 借助JSON格式实现模板序列化与反序列化

模板统一存储在工作簿层级，会随同工作簿一同完成序列化保存。
可查阅应用程序接口参考文档，查看完整的方法签名与配置参数。
涉及接口：
* `INamedCellTemplatesManager`
* `INamedCellTemplate`

### 模板创建示例
```javascript
spread.namedCellTemplates.add("Financial Amount", {    
style: {        
formatter: "#,##0.00",        
hAlign: GC.Spread.Sheets.HorizontalAlign.right    
},    
conditionalFormats: [{        
ruleType: GC.Spread.Sheets.ConditionalFormatting.RuleType.cellValueRule,        
operator: GC.Spread.Sheets.ConditionalFormatting.ComparisonOperators.lessThan,        
value1: 0,        
style: { foreColor: "Accent 2" }    
}]
});
```

## 适配表格类型
命名单元格模板可应用于多种表格类型，不同表格的实际生效效果略有差异。

### 普通工作表
可在工作表或单元格区域中调用`applyNamedCellTemplate`方法套用模板。
```javascript
sheet.applyNamedCellTemplate("Financial Amount", "A1:A10");
// 也可使用以下写法
sheet.getRange("B1:B10")     
.applyNamedCellTemplate("Financial Amount");
```

**支持的地址格式**
* A1样式单元格区域（如`"A1:C3"`）
* 整行、整列范围（如`"A:A"`、`"1:3"`）
* 表格结构化引用（如`"Table1"`、`"Table1[[#Data]]"`、`"Table1[[#Headers]]"`）

可参考接口文档查阅对应方法说明：
* `Worksheet.applyNamedCellTemplate`
* `CellRange.applyNamedCellTemplate`

### 报表表格
报表表格未直接提供模板套用方法。
需在其布局格式模板表格中执行模板应用操作：
```javascript
const report = spread.addSheetTab(0, "Report", GC.Spread.Sheets.SheetType.reportSheet);
const templateSheet = report.getTemplate();
templateSheet.applyNamedCellTemplate("Financial Amount", "A1:A5");
```

### 数据表
在数据表中，通过指定数据源字段名称来套用模板。
```javascript
tableSheet.applyNamedCellTemplate("Financial Amount", ["price", "quantity"]);
```

**生效说明**
* 表格必须绑定数据源，无数据源时无法应用模板
* 按照指定字段逐列套用模板配置
* 忽略数据源中不存在的字段名称
* 模板内的单元格状态配置不生效，会直接跳过
* 常规条件格式规则按列执行
* 状态类规则在表格整体层级生效

参考接口：
* `TableSheet.applyNamedCellTemplate`

### 甘特图表格
甘特图表格套用命名单元格模板的方式与数据表一致。

**额外生效规则**
* 自动跳过甘特图专属图表列
* 系统内置功能列保留原有交互式编辑功能

## 命名单元格模板适用场景
满足以下场景时，可使用命名单元格模板：
* 复用配置包含样式之外的多项设置
* 需要统一规范条件格式与数据验证规则
* 要求单元格交互状态保持标准化

若仅需复用外观格式样式，可选择使用命名样式功能。

## 与SpreadJS设计器联动
命名单元格模板全面适配SpreadJS运行时接口。
设计器提供可视化操作界面，支持创建、编辑、套用模板，同时预置多款便捷模板可供直接使用。
