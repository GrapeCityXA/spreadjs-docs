# frozen

## 冻结首行首列

您可以指定是否要冻结表单中的行或列，或同时冻结两者。 冻结的列和行不会滚动。 您还可以指定是冻结行尾还是列尾。
在冻结行下方（或冻结尾随行上方）和冻结列右侧（或冻结尾随列左侧）显示一条线。 您可以使用 **options.frozenlineColor** 属性指定线条的颜色。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/cfrozen.png)
冻结的行保留在表单的顶部，冻结的列保留在表单的左侧。 冻结的尾随行保留在表单的底部，冻结的尾随列保留在表单的右侧。

### 示例代码

本示例创建一个冻结行和一个冻结列。

```JavaScript
activeSheet.frozenRowCount(1);
activeSheet.frozenColumnCount(1);
//activeSheet.options.frozenlineColor = "red";
```

## 冻结尾行尾列

您可以使用 **frozenTrailingRowCount** 和 **frozenTrailingColumnCount** 函数指定是否在工作表中冻结尾行或列或两者。 冻结尾行或列 滚动工作表时保持可见。
一条线显示在冻结的尾行上方和冻结的尾随列的左侧。您可以使用 **options.frozenlineColor** 属性设置线条的颜色。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/trailingrowandcolumn.png)
默认情况下，当数据行和冻结行的高度等于或大于视口区域时，冻结尾行显示在视口区域的最底部。对于显示在 视口区域最右侧的冻结尾列也是如此。
但是，当数据行和冻结尾行的高度小于视口区域的高度时，您可以选择是否在数据行和冻结尾行之间显示空白。 **frozenTrailingRowCount** 和 **frozenTrailingColumnCount** 函数的 **stickToEdge** 参数可用于控制此行为，如下图所示：

| When **stickToEdge =** True (defaut value) | When **stickToEdge =** False |
| -------------------------------------- | ------------------------ |
| ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/sticktoegdeparamtrue.png) | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/sticktoegdeparamfalse.png) |

同样，您也可以通过 **stickToEdge** 参数选择是否在数据列和冻结尾随列之间显示空白。

### 使用代码

本示例将 **stickToEdge** 参数设置为 冻结的尾随行和冻结的尾随 列。

```JavaScript
activeSheet.frozenTrailingRowCount(1, false);
activeSheet.frozenTrailingColumnCount(1, false);
//activeSheet.options.frozenlineColor = "red";
```
