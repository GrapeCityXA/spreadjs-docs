# decoration

SpreadJS支持多种可应用于单元格文本的文本装饰样式，包含普通下划线与会计下划线类型。
可通过单元格或`Style`对象上的[textDecoration](gcdocsite__documentlink?toc-item-id=021795e2-2829-4d94-bcc5-f9222f2e188b)属性来配置文本装饰效果。

## 支持的样式类型

文本装饰样式由枚举值`TextDecorationType`定义。
`TextDecorationType`属于位运算标识枚举。

| 名称 | 数值 | 说明 |
| --- | --- | --- |
| none | 0 | 无装饰效果 |
| underline | 1 | 单下划线 |
| lineThrough | 2 | 删除线 |
| overline | 4 | 上划线 |
| doubleUnderline | 8 | 双下划线 |
| accountingUnderline | 16 | 会计单下划线 |
| doubleAccountingUnderline | 32 | 会计双下划线 |

![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260317.3e8ebd-20260526.0d95fb.png?width=400)

> **备注：**
> 该枚举在适用场景下支持位运算组合（例如`underline | lineThrough`）。

## 文本装饰的使用方式

### 借助`getCell`方法

```javascript
activeSheet.getCell(0, 0).textDecoration(    
GC.Spread.Sheets.TextDecorationType.underline
);
activeSheet.getCell(1, 0).textDecoration(    
GC.Spread.Sheets.TextDecorationType.doubleAccountingUnderline
);
```

### 借助样式对象

```javascript
var style = new GC.Spread.Sheets.Style();
style.textDecoration =    
GC.Spread.Sheets.TextDecorationType.accountingUnderline;
activeSheet.setStyle(2, 1, style);
```

## 普通下划线与会计下划线的区别

SpreadJS既支持常规下划线样式，也支持兼容Excel格式的会计下划线样式。

| 对比项 | 普通下划线 | 会计下划线 |
| --- | ----- | ----- |
| 支持类型 | <ul><li>单下划线</li><li>双下划线</li></ul> | <ul><li>会计单下划线</li><li>会计双下划线</li></ul> |
| 绘制位置 | 紧贴文字字形下方绘制 | 绘制在文字基线更靠下的位置 |
| 间距特点 | 视觉间距固定 | 间距会随字体大小按比例缩放 |
| 下划线宽度 | 与文字宽度保持一致 | 数字和旋转文本匹配文字宽度，普通文本可铺满整列宽度 |
| 旋转适配 | 跟随文字旋转（不支持竖排文字） | 跟随文字旋转（不支持竖排文字） |
| 适用场景 | 日常文本内容强调 | 财务报表制作、适配Excel的会计格式排版 |

### 会计下划线使用注意事项

* 会计下划线作用于整个单元格，无法单独为富文本中的某段文字单独设置。
* 数字与日期格式内容的下划线宽度和文字宽度一致。
* 普通文本对应的下划线可延伸至整列宽度。
* 合并单元格内，下划线会铺满整个合并单元格的宽度。
* 竖排文字不会显示会计下划线，该规则与Excel保持一致。
* 应用会计下划线时，SpreadJS不会自动增高行高。
    若行高不足，会出现下划线显示异常的情况。
    （Excel在此场景下会自动调整行高）

## 在SpreadJS设计器中设置文本装饰

除调用接口外，还可在SpreadJS设计器内可视化配置文本装饰。

1. 选中一个或多个目标单元格。
2. 切换至开始选项卡。
3. 在字体功能组中，点击对话框启动器（小箭头图标）。
    ![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260317.37e6ec-20260526.08b99c.png?width=600)
4. 在设置单元格格式弹窗中，打开字体选项卡。
    ![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260317.2bbc66-20260526.dac6fe.png?width=400)
5. 点开下划线下拉列表，可选择以下样式：

* 单下划线
* 双下划线
* 会计单下划线
* 会计双下划线
    ![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260317.9ad08f-20260526.a87204.png?width=400)

6. 点击确定即可生效。
    删除线同样可在该弹窗的效果栏目中开启设置。
    ![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260317.160990-20260526.bea473.png?width=400)

>type=info
> 会计下划线样式不可与其他类型下划线混用。
> 所选下划线样式会应用至整个单元格，且与开发接口内的`TextDecorationType`枚举一一对应。
