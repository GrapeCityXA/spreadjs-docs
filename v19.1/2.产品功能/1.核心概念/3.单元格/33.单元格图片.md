# image-rich-data

单元格图片是一种单元格值类型，用于将图像作为结构化数据进行存储。
与图片形状或背景图片不同，单元格图片会直接存储为单元格的值。由于它被视为数据而不是可视对象，因此可以参与排序、筛选、公式、搜索和数据透视表等工作表操作。
单元格图片适用于图像属于数据集的一部分，并且必须像其他单元格值一样保持一致行为的场景。

## 数据结构

单元格图片是 `IRichData` 接口的一个具体实现。若要在单元格中存储图像，该值必须包含一个类型标识符和一个值载荷。
结构如下：

```typescript
{
    richDataType: "Image",
    value: {
        src: string,
        imageBase64Data?: string,
        altText?: string,
        drawType?: number,
        width?: number,
        height?: number,
        clipX?: number,
        clipY?: number,
        clipWidth?: number,
        clipHeight?: number,
        vAlign?: number,
        hAlign?: number
    }
}
```

* `richDataType` 必须设置为 `"Image"`。
* `value` 包含图像源，以及可选的布局或裁剪设置。

在排序、筛选、搜索和逻辑比较操作中，`altText` 属性会作为主要比较键使用。

### 示例

可以使用 `sheet.setValue` 赋值一个符合 `IImageRichData` 结构的对象，以创建单元格图片。

```javascript
var sheet = spread.getActiveSheet();
sheet.setValue(0, 0, {
    richDataType: "Image",   // 将该值标识为单元格图片
    value: {
        src: "https://example.com/product.png",  // 图像 URL
        altText: "Laptop Pro",                   // 用于排序、筛选、搜索和逻辑比较操作
        drawType: 0,                             // 保持宽高比并适配到单元格内
        vAlign: 1,                               // 垂直居中图像
        hAlign: 1                                // 水平居中图像
    }
});
```

## 行为语义

### 类型参与

单元格图片：

* 会被视为一等单元格值类型
* 可以存储在区域和表中
* 可以在公式中被引用
* 可以出现在数据透视表数据源中

它不会被视为 Shape 对象。

### 排序语义

排序行为遵循以下规则：

1. 当单元格图片与基础数据类型（数字、字符串、布尔、错误、空）进行比较时，其排序方式与 Excel 保持一致。
2. 当比较两个单元格图片值时，排序主要由 `altText` 属性决定。

![sort.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/sort-20260403.e10666-20260525.1d15e0.gif?width=600)

>type=note
> **注意：**
>
> * 如果两个值具有相同的 `altText`，排序行为可能与 Microsoft Excel 不同。
> * 由于 Excel 没有公开记录单元格图像的比较规则，因此无法保证行为完全等同。

### 筛选语义

筛选操作会使用 `altText` 属性来评估单元格图片。

### 搜索语义

搜索操作会使用 `altText` 属性来评估单元格图片。
![search.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/search-20260403.3fc627-20260525.3b07ad.gif?width=600)

### 公式语义

单元格图片可用于：

* [查找和引用函数](gcdocsite__documentlink?toc-item-id=235d8144-bf20-48d8-9f41-09e3260319d9)（例如 `VLOOKUP`、`XLOOKUP`、`INDEX`、`MATCH`）
* [动态数组函数](gcdocsite__documentlink?toc-item-id=e827bf8c-bf14-497c-96df-cb721d10ecd4)（例如 `SORT`、`UNIQUE`、`FILTER`）
* 逻辑比较运算符（`=`、`<>`）
* 计数函数，例如 `COUNT` 和 `COUNTA`
* `SUMIF` 和 `SUMIFS` 等函数中的条件参数

大多数数学和统计函数不支持单元格图片。
不受支持的操作可能会返回 `#VALUE!`，或产生与 Excel 不同的结果。

## 示例场景

**示例 1：在数据透视表中使用单元格图片**
如果某一列包含具有不同 `altText` 值的单元格图片值，则该列可用作数据透视表字段。
从此区域创建数据透视表时：

* 图像会显示为字段项。
* 分组和筛选基于 `altText`。
* 排序遵循“排序”部分中描述的相同语义。

无需额外配置。
![pt.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/pt-20260407.fdf3cf-20260525.3ad51f.gif?width=800)

**示例 2：在条件格式中使用单元格图片**
单元格图片可用于依赖逻辑比较的条件格式规则。
例如：

```auto
=B7="Laptop Pro"
```

如果单元格 `B7` 包含 `altText` 为 `"Laptop Pro"` 的单元格图片，则该条件的计算结果为 `TRUE`。
条件格式规则会使用 `altText` 属性来评估单元格图片。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260407.897ba2-20260525.05dd07.png?width=600)

**示例 3：使用单元格图片进行查找**
单元格图片可以参与查找操作。

```auto
=XLOOKUP("Laptop Pro", A:A, B:B)
```

如果 A 列包含具有匹配 `altText` 的单元格图片，则会返回 B 列中的对应值。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260407.d2cf50-20260525.0309dc.png?width=600)

## 导入和导出行为

### Excel 导入（.xlsx）

* Excel 单元格图像会作为单元格图片导入。
* 它们不再映射到 `SparklineEx`。

`.sjs` 和 `.ssjson` 格式中 `SparklineEx` 的导入/导出行为保持不变。

### Excel 导出

* SVG 图像在导出到 Excel 时可能导致错误。
* API 层不会执行自动验证或格式转换。
* 在设计器中，使用 *Place in Cell* 插入的 SVG 图像会在存储前转换为 PNG。

## 剪贴板限制

从 Excel 桌面版复制的包含图像的单元格无法粘贴到 SpreadJS 中。
Excel 会将 HTML 剪贴板数据与指向本地文件的 `<img src="file:///...">` 引用一起放入剪贴板。
浏览器无法访问本地文件路径，因此 SpreadJS 无法获取图像数据。
此行为与 Excel 网页版一致。

## 平台限制

以下平台不支持单元格图片：

* Data Manager
* TableSheet
* GanttSheet

如果使用 [转换为数据表](gcdocsite__documentlink?toc-item-id=2c3bb383-cba6-4c87-9fa4-4f34bb96cee9#convert-table-to-data-table) 转换包含单元格图片的表，则图像值会被丢弃。

## 相关功能

单元格图片不同于：

* [IMAGE() 函数](gcdocsite__documentlink?toc-item-id=7ca8106f-146b-49fc-8ab0-8041719d52c8)（公式生成的图像值）
* [单元格背景图片](gcdocsite__documentlink?toc-item-id=87a8a7f4-da8c-4f56-ac4c-5421fd73d241)（仅用于视觉显示）
* [图片形状](gcdocsite__documentlink?toc-item-id=a49f70a5-e28b-4de0-843a-1bdbdf0fb639)（浮于单元格上方）

> 图片形状和单元格图片可以在设计器中相互转换。
> 有关详细信息，请参阅 [在设计器中插入图片](gcdocsite__documentlink?toc-item-id=e328c9bd-2875-4bd9-91fb-14e943a66a89#convert-between-placement-modes)。

## 替代文本行为

单元格图片包含自己的 `altText` 属性，用于描述图像内容。

* 此替代文本与 Excel 行为一致。
* 它可以显示在公式栏中。
* 它可以在“替代文本”面板中编辑。

此属性独立于使用 `CellRange.altText()` 设置的单元格替代文本。

* 单元格图片中的 `altText` 描述图像值本身。
* SpreadJS 中单元格级别的替代文本是单独的属性，不会影响图像值。
