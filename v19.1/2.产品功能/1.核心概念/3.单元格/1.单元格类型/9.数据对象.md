# dataobject-cell

数据对象单元格类型可让单元格展示结构化对象数据，并能直接将对象属性提取至相邻单元格中。
当单元格数值为对象，且单元格类型设置为[`GC.Spread.Sheets.CellTypes.DataObject`](gcdocsite__documentlink?toc-item-id=075af6fd-87ac-47f4-8a1d-852b3c2e5923)时，单元格内会出现内置按钮![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260330.bbbbec-20260525.e538fc.png?width=20)。
点击该按钮会弹出对象属性下拉列表，选中某项属性后，对应数值会填入右侧相邻空白单元格，该操作支持撤销功能。
![dataObject.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/dataObject-20260330.9cd8e6-20260525.2dfedd.gif?width=600)
>type=note
>备注：若相邻单元格为合并单元格或是表格组成部分，属性提取操作将会失败，同时触发无效操作事件，提示信息为：`"无法插入数据"`。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260330.b52d4a-20260525.a1e359.png?width=600)

数据对象单元格类型支持格式字符串，用以控制单元格内对象的展示样式，格式可使用`PROPERTY`函数或是`@.`点运算符。
**示例：**
```javascript
// 获取对象数据
sheet.setFormula(1, 1,  
'=FILTERJSON(WEBSERVICE("https://demodata.grapecity.com/northwind/api/v1/Products/1"))'
);
// 设置数据对象单元格类型并配置展示格式
var cellType = new GC.Spread.Sheets.CellTypes.DataObject(  
'=@.productName & " " & @.unitPrice'
);
sheet.setCellType(1, 1, cellType);
```

也可在SpreadJS设计器中配置数据对象单元格类型：
*开始选项卡→样式组→单元格编辑器→单元格类型→数据对象*
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260421.d155ce-20260525.15d49c.png?width=800)

在格式输入框中填写合规的格式字符串，即可自定义对象属性的展示形式。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260330.f48f6b-20260525.44d6e8.png?width=400)
>type=note
>格式表达式必须合法，否则设置无法生效。
