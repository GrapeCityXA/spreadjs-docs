# cellcheckbox

SpreadJS复选框单元格类型是一种可交互的嵌入式单元格控件，支持用户在工作表内切换二值状态或三值状态。
该控件兼容Excel新式样式，同时保留传统复选框样式以实现向下兼容。
* `checkbox`——经典方形复选框（默认样式）
* `modern`——适配Excel的圆角样式
* `toggle`——开关式切换按钮

同时还支持以下功能：
* 可自定义交互行为
* 文本自动换行与对齐方式管控
* 兼容Excel文件的导入与导出

## 显示模式
`mode`属性用于定义复选框的视觉渲染样式与展示行为。
```javascript
cellType.mode(value);
```

### 模式对比
|  | 经典复选框模式 | 新式模式 | 开关切换模式 |
| --- | --------------------- | ----------- | ----------- |
| `mode`取值 | `"checkbox"` | `"modern"` | `"toggle"` |
| 边框样式 | 1像素黑色直角边框 | 2像素边框，跟随单元格字体颜色 | 开关式轨道边框 |
| 边角样式 | 直角 | 圆角 | 圆角轨道 |
| 颜色规则 | 固定黑色 | 跟随单元格字体颜色 | 可通过`toggleOptions`自定义配置 |
| 默认自适应尺寸 | 8像素（原生尺寸） | 15像素（随字体大小缩放） | 由`toggleOptions`参数控制 |
| 背景样式 | 白色 | 透明（沿用单元格背景色） | 轨道专属背景色 |
| 不确定状态样式 | 绿色实心方块 | 跟随字体颜色（默认黑色） | 不支持 |
| 三态功能`isThreeState` | 支持 | 支持 | 不支持 |
| 不确定状态文本`textIndeterminate` | 支持 | 支持 | 不支持 |
| 复选框尺寸`boxSize` | 支持 | 支持 | 不支持 |
| 悬浮鼠标样式 | 默认样式 | 手型指针 | 按钮交互样式 |
| 双击编辑功能 | 支持 | 支持 | 不支持 |
| 状态触发区域 | 由`hitTestMode`控制 | 由`hitTestMode`控制 | 仅开关按钮区域生效 |

### 开关模式配置
开关切换模式可通过`toggleOptions`实现更多外观自定义配置：
* 宽度/高度
* 自动尺寸适配
* 开启滑块颜色、关闭滑块颜色
* 开启轨道颜色、关闭轨道颜色
* 动画过渡时长
* 滑块边距
* 轨道圆角半径

当`autoSize`设为关闭且文本对齐方式为内置对齐时，自动适配宽高属性会忽略文本溢出情况，仅依据开关按钮尺寸进行计算。

### 使用示例
**经典复选框模式（默认）**
```javascript
var cellType = new GC.Spread.Sheets.CellTypes.CheckBox();
cellType.caption("标题文字");
cellType.textTrue("选中");
cellType.textFalse("未选中");
cellType.textIndeterminate("不确定");
cellType.textAlign(GC.Spread.Sheets.CellTypes.CheckBoxTextAlign.bottom);
cellType.isThreeState(true);
cellType.boxSize(20);
activeSheet.getCell(1, 1).cellType(cellType);
```

**新式样式模式**
```javascript
var cellType = new GC.Spread.Sheets.CellTypes.CheckBox();
cellType.caption("新式复选框");
cellType.mode("modern");
activeSheet.getCell(2, 1).cellType(cellType);
```

**开关切换模式**
```javascript
const spread = new GC.Spread.Sheets.Workbook();
const sheet = spread.getActiveSheet();
const cellType = new GC.Spread.Sheets.CellTypes.CheckBox();
cellType.textTrue('开启');
cellType.textFalse('关闭');
cellType.mode('toggle');
cellType.textAlign(GC.Spread.Sheets.CellTypes.CheckBoxTextAlign.inside);
cellType.toggleOptions({  
width: 65,  
height: 30,  
sliderMargin: 2,  
trackColorOn: '#8cbae8',  
trackColorOff: '#9e9e9e',  
sliderColorOn: '#1565c0',  
sliderColorOff: '#ffffff',
});
sheet.setCellType(0, 0, cellType);
```

## 交互逻辑
### 点击判定区域（hitTestMode）
用于设定单元格内响应鼠标点击的区域，仅适用于经典复选框与新式样式模式。
* `"cell"`（默认）——点击整个单元格均可触发状态切换
* `"checkbox"`——仅点击复选框图标才可触发（适配Excel原生交互逻辑）

>备注
>为保证向下兼容性，经典模式与新式模式默认均采用整单元格点击触发逻辑；若需和微软Excel交互逻辑保持一致，可设置为仅图标点击触发。

```javascript
var cellType = new GC.Spread.Sheets.CellTypes.CheckBox();
cellType.textTrue("是");
cellType.textFalse("否");
cellType.hitTestMode("checkbox");
activeSheet.getCell(1, 1).cellType(cellType);
```

### 文本编辑权限（textEditable）
控制复选框是否支持进入文本编辑状态（双击单元格或按下F2键），仅适用于经典复选框与新式样式模式。
* `true`（默认）——允许编辑文本内容
* `false`——禁止文本编辑

设置为禁用后，复选框无法进入编辑状态。
```javascript
var cellType = new GC.Spread.Sheets.CellTypes.CheckBox();
cellType.textTrue("是");
cellType.textFalse("否");
cellType.textEditable(false);
activeSheet.getCell(1, 1).cellType(cellType);
```

>备注
>1. 经典复选框编辑状态会调用浏览器原生复选框渲染样式
>2. 新式样式复选框在编辑过程中依旧保留新式视觉外观

## 状态规则
### 三态使用规则
复选框可实现三种状态：选中、未选中、不确定状态。
启用不确定状态需配置以下代码：
```javascript
cellType.isThreeState(true);
```
三态效果仅支持经典复选框模式与新式模式，开关切换模式暂不支持。

### 数值对应关系
单元格数值决定复选框展示状态，对应关系如下：
| 单元格数值 | 对应状态 |
| ---------- | ----- |
| `null` | 不确定状态 |
| `0` | 未选中状态 |
| `1` | 选中状态 |

可借助value方法通过代码程序控制复选框状态。

## 布局与文本换行
### 自动换行
当复选框标题文本长度超出单元格显示范围时，可开启单元格文本自动换行功能，该功能默认处于关闭状态。
```javascript
cellType.caption("这是一段长度很长很长的演示文本");
activeSheet.getCell(1, 1).cellType(cellType);
activeSheet.setRowHeight(1, 120);
activeSheet.setColumnWidth(1, 110);
// 开启自动换行
activeSheet.getCell(1, 1).wordWrap(true);
```

开启自动换行后：
1. 优先按照单词边界进行文本分行
2. 空间不足时，拆分单词完成自适应换行

## Excel文件导入导出
复选框单元格类型全面支持Excel格式文件的导入与导出操作。

### 导入适配规则
从Excel导入文件时遵循以下规则：
1. 单元格数据不为空值、未定义值、布尔真、布尔假时，不会自动生成复选框控件
2. 单元格数据为空值或未定义值时，自动启用复选框三态模式
3. 导入生成的复选框默认使用自适应尺寸
4. 水平对齐方式非左对齐、居中对齐、右对齐时，统一重置为居中对齐
5. 垂直对齐方式非顶部对齐、居中对齐、底部对齐时，统一重置为底部对齐
6. 导入后复选框样式自动设为新式模式
7. 表格列样式中自带的复选框，导入后同样自动转为新式模式

### 导出适配规则
导出为Excel文件时遵循以下规则：
1. 所有复选框均可正常导出
2. 处于不确定状态的复选框，导出后统一识别为未选中状态
3. 标题文字等附加内容不会被导出，仅保留复选框选中状态信息
4. 受单元格原生数据影响，导出后的Excel文件可能不会直观显示复选框样式，但单元格属性依旧为复选框类型
5. 水平对齐方式超出指定类型范围时，导出后统一改为左对齐
6. 垂直对齐方式超出指定类型范围时，导出后统一改为顶部对齐

## 设计器内使用复选框控件
在设计器中可通过两种方式插入复选框控件：
1. 直接将单元格类型设置为复选框
2. 调用功能区菜单栏的复选框插入命令

两种方式均可为选中单元格绑定复选框单元格类型，但初始化默认配置存在差异。

### 两种插入方式
1. 设置单元格类型为复选框
开始菜单栏→样式→单元格编辑器→单元格类型→复选框
该方式直接将选中单元格定义为复选框类型。
![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260317.af7dac-20260525.33175f.png?width=800)

2. 功能区命令插入
插入菜单栏→控件→复选框
该命令可直接在选中单元格内嵌入复选框控件。
![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260421.6c1379-20260525.8cba13.png?width=800)

### 默认配置差异
两种插入方式生成的复选框默认参数区别如下：
|  | 手动设置单元格类型 | 菜单栏插入命令 |
| --- | ------------- | -------------- |
| 显示模式 | `"checkbox"`经典模式 | `"modern"`新式模式 |
| 排版位置 | 垂直顶部对齐、水平左对齐 | 垂直顶部对齐、水平居中对齐 |
| 控件尺寸 | 12像素×12像素 | 自适应尺寸 |
| 点击触发区域 | 整单元格均可点击 | 仅复选框图标可点击 |
| 文本编辑权限 | 支持进入编辑状态 | 禁止进入编辑状态 |

>备注
>1. 两种方式创建的均为标准复选框单元格类型
>2. 差异仅体现在初始化的显示模式与交互配置上
