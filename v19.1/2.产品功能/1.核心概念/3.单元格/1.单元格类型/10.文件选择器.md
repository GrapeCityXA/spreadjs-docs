# cellfileupload

SpreadJS 提供文件选择器单元格类型，允许上传任何文件或图片。对于图片上传，它接受 .jpg, .jpeg, .png, .gif, .bmp, .svg, .ico, .webp 格式。SpreadJS 将这些上传的文件存储为对象。
默认情况下，文件选择器单元格类型会显示默认的上传按钮。然而，在上传图片后，它会显示图片的缩略图；在上传其他文件时，它会显示与文件扩展名相关的文件图标及文件名。
一旦在文件选择器单元格类型中上传了文件或图片，当鼠标悬停在单元格上时，会出现一个蒙层，提示必须先删除现有文件才能上传新文件。
以下图片展示了第一列作为文件选择器单元格类型，并上传了一名学生的照片。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.5e0e21.png)
参考以下代码示例来设置文件选择器单元格类型

```javascript
// 设置 FileUpload 单元格类型
const fileUpload = new GC.Spread.Sheets.CellTypes.FileUpload();
for (var i = 1; i < 7; i++)
    activeSheet.getCell(i, 0).cellType(fileUpload);
```

可以通过使用 FileUpload 类的 `maxSize` 和 `accept` 方法来指定最大文件大小和类型（格式）限制。如果上传的文件超过最大文件大小，会触发 `invalidOperation` 事件。
参考以下代码示例来设置文件的最大大小和文件类型。

```javascript
// 设置文件的最大大小和文件类型限制
fileUpload.maxSize(3072);
fileUpload.accept('image/png, image/jpeg');

// 使用 invalidOperation 事件，如果上传的文件超过最大文件大小
spread.bind(GC.Spread.Sheets.Events.InvalidOperation, (e, args) => {
    if (args.invalidType === GC.Spread.Sheets.InvalidOperationType.sizeLimitExceeded) {
        alert(args.message);
    }
});
```

## 自定义文件上传操作

你可以在文件选择器单元格类型中对上传的图片进行预览、下载和清除操作，对上传的文件进行下载和清除操作。然而，SpreadJS 允许你使用 `isPreviewEnabled` 和 `isDownloadEnabled` 方法隐藏特定的按钮列表。
以下图片展示了包含预览和清除操作的蒙层。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.35c05e.png)
参考以下代码示例来禁用下载按钮。

```javascript
// 设置自定义操作
buttonfileUpload.isDownloadEnabled(false); 
```

## 修改内置文件图标

SpreadJS 提供默认内置文件图标，最大大小为 20px。然而，它允许你使用 `builtInFileIcons` spread 选项为非图片文件修改内置文件图标。设置自定义内置文件图标时，键是文件扩展名，值是文件的 base64 编码字符串。
以下图片展示了自定义的文本文件图标。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.affbee.png)
