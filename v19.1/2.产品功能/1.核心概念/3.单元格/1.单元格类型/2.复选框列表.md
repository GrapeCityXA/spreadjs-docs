# check-box-list-cell

复选框列表单元格类型可在单个单元格内呈现一组可选择项。
每个选项都会显示为独立复选框，支持多选操作。
与单一复选框单元格类型不同，复选框列表代表一组数值，而非单个布尔状态。
该组件支持三种显示模式：

* `checkbox`（复选框）
* `modern`（简约新式）
* `toggle`（开关切换）
    ![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260317.e110cf-20260525.76b932.png?width=600)

## 显示模式

`mode` 属性用于控制每个选项的展示样式。

```javascript
cellType.mode(value);
```

可用取值：

```typescript
'checkbox' | 'modern' | 'toggle'
```

### 模式功能对照表

| 功能特性 | 复选框模式 | 简约新式模式 | 开关切换模式 |
| ---- | ----- | ------ | ------ |
| 多选功能 | 支持 | 支持 | 支持 |
| 三态选择 | 不支持 | 不支持 | 不支持 |
| 复选框尺寸设置 | 支持 | 支持 | 不支持 |
| 开关配置项 | 不支持 | 不支持 | 支持 |
| 内部文本对齐 | 不支持 | 不支持 | 支持 |

>type=info
> 复选框列表不具备三态选择功能。

## 选择规则

复选框列表单元格类型支持在单个单元格内实现多选。
单元格的值为数组格式，数组内存储所有选中项对应的`value`字段值。
示例代码：

```javascript
checkBoxListCellType.items([  
{ text: "价格", value: "1749" },  
{ text: "易用性", value: "5495496" }
]);
```

若同时选中两个选项：

```javascript
sheet.getCell(1, 3).value();
// ["1749", "5495496"]
```

未选中任何选项时，单元格值为空数组。
数组内每个元素的数据类型与选项定义的`value`取值类型保持一致。

## 选项配置

可通过`items()`方法定义列表内的各项内容：

```javascript
cellType.items([  
{ text: "价格", value: 1 },  
{ text: "易用性", value: 2 }
]);
```

单个选项包含两个配置字段：

* `text` — 页面展示的文字标签
* `value` — 后台存储的实际数据值

## 布局规则

单元格内选项的排列布局由以下属性控制：

* `direction`（横向排列/纵向排列）
* `isFlowLayout`（流式布局）
* `maxRowCount`（最大行数）
* `maxColumnCount`（最大列数）
* `itemSpacing`（选项间距）
    开启流式布局后，选项会根据单元格可用空间以及排列方向自动换行排布。

## 文本对齐方式

通过`textAlign`属性设置选项文字的对齐样式，支持取值如下：

* `left`（左对齐）
* `right`（右对齐）
* `inside`（内部对齐，仅开关切换模式可用）

## 复选框尺寸

可借助`boxSize`属性自定义复选框大小：

* 可填写数字数值或填写`"auto"`自适应尺寸
* 默认尺寸为12×12像素
* 开关切换模式下该配置无效

## 开关切换模式配置

切换模式会将每一个选项渲染为开关样式控件。

```javascript
cellType.mode('toggle');
```

可通过`toggleOptions`自定义开关的外观样式：

```javascript
cellType.toggleOptions({  
width: 60,  
height: 30,  
trackColorOn: '#4CAF50',  
trackColorOff: '#767577',  
sliderColorOn: '#ffffff',  
sliderColorOff: '#ffffff',  
sliderMargin: 2,  
animationDuration: 100,  
trackRadius: 8,  
sliderRadius: 4
});
```

无参数调用`toggleOptions()`方法，可获取当前已设置的配置参数。
在开关切换模式下：

* 无法使用复选框尺寸配置
* 需点击开关控件才可切换选中状态

## 在设计器中使用复选框列表

在设计器中可通过设置单元格类型来启用该功能：
开始→样式→单元格编辑器→单元格类型→复选框列表

右键点击目标单元格，选择**编辑单元格类型…**
