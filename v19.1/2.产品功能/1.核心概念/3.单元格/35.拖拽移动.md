# dragmove

SpreadJS 支持使用鼠标拖动并移动单元格、单元格区域以及表格中的单元格。你可以将鼠标指针移至选定单元格、列、行或单元格区域的边缘，然后点击并将选定区域拖动到新位置。
下表描述了 Spread 工作表中可用的操作和事件：

| 操作 | 单元格 | 表格 |
| --- | --- | --- |
| 拖动 | 剪切粘贴 | 剪切并向下移动单元格 |
| 拖动 + Ctrl | 复制粘贴 | 复制并向下移动单元格 |
| @rows=2:拖动 + Shift | 剪切并向下移动单元格 | @rows=2:剪切粘贴 |
| 剪切并向右移动单元格 |
| @rows=2:拖动 + Ctrl + Shift | 复制并向下移动单元格 | @rows=2:复制粘贴 |
| 复制并向右移动单元格 |

你可以使用 Spread 选项 **allowUserDragDrop** 来允许或禁止拖放操作。该选项接受一个布尔值，默认值为 ‘true’，允许在活动工作表或表格中拖放选定的单元格或单元格区域。
以下代码示例展示了如何禁用工作表中单元格的拖放操作。

```javascript
var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"),{sheetCount:3});
var sheet = spread.getActiveSheet();

// 禁用单元格的拖放操作
spread.options.allowUserDragDrop = false;
```

在使用拖放操作时，无法执行以下操作：

* 将单元格拖入数据透视表区域。
* 拖动多个区域。
* 移动影响表格或数据透视表的单元格。
* 在表格中移动单元格区域，且该单元格区域与表格区域大小不同。
