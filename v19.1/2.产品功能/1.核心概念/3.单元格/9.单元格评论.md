# cell-threaded-comments

评论允许用户为特定单元格添加情境化讨论，并在评论中回复。每个评论作为包含多条回复的对话容器，帮助团队高效地讨论、审阅和解决问题。
以下示例展示了团队成员如何使用评论审阅季度预算：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image-20260127.f2b3a6.png)

## 核心优势

* 支持协作与情境化反馈
* 回复中可包含用户提及（@用户）和超链接
* 提供基于事件的集成能力及撤销/重做支持
* 兼容 SpreadJS API 和 Excel 导出功能

## 依赖项

可通过引用全量包或单独加载所需子模块启用评论功能：

### 方式 1 – 使用全量包

若引用完整的库文件（如以下示例），评论功能会自动包含：

```html
<script src="gc.spread.sheets.all.<version>.min.js"></script>
```

### 方式 2 – 使用模块化包

若选择按需加载模块，需确保加载以下包以启用评论：

```html
<script src="gc.spread.sheets.comments.<version>.min.js"></script>
<script src="gc.spread.sheets.components.<version>.min.js"></script>
<script src="gc.spread.sheets.threadedcomments.<version>.min.js"></script>
```

>type=note
> **注意**：
> 该功能自 SpreadJS v19.0 及以上版本开始提供。

评论依赖 `GC.Spread.Common.UserManager` 组件识别创建或回复评论的当前用户。若未明确配置用户，系统会自动生成默认的“访客（Guest）”用户。有关全局用户配置和管理的详细信息，请参阅用户管理功能文档。

## 用户界面操作

以下操作可通过 UI 执行，也可通过相关 API 调用实现：

| **操作** | **描述** |
| --- | --- |
| 添加评论 | 在选中单元格创建新的评论，包含作者信息和时间戳。 |
| 回复（Reply） | 在现有评论中添加回复，回复按时间顺序追加。 |
| 编辑/更新（Edit/Update） | 修改已有的评论或回复，编辑后的消息保留原始时间戳。 |
| 删除（Delete） | 移除评论或回复，授权用户可在允许时删除他人的内容。 |
| 标记已解决/重新打开（Resolve/Reopen） | 将评论标记为已解决（禁止新回复）或重新打开（允许继续讨论）。 |
| 复制/剪切/粘贴（Copy/Cut/Paste） | 复制、剪切或粘贴单元格时，保留评论。 |
| 撤销/重做（Undo/Redo） | 撤销或重做上一次添加、编辑或删除操作。 |

## 详细功能说明

### 事件（Events）

| **事件** | **触发时机** |
| --- | ---- |
| `ThreadedCommentChanging` | 评论或回复更新前触发。 |
| `ThreadedCommentChanged` | 评论或回复更新后触发。 |
| `UserMentioning` | 即将触发提及行为时触发，支持取消操作。<br>自版本19.1.0起可用。 |
| `UserMentioned` | 回复中提及用户时触发。 |

### 协作模式（Collaboration Model）

* **编辑者（Editors）**：可添加、编辑、删除和解决评论。
* **查看者（Viewers）**：仅拥有只读权限（无操作按钮或回复编辑器）。

### 用户提及（@）

**启用要求**
提及功能需要配置`GC.Spread.Common.UserManager`。

* 若未配置`UserManager`，提及功能将被禁用。
* 输入`@`符号时仅作为普通文本录入，不会唤起提及用户列表弹窗，不会生成提及区块，也不会触发各类提及相关事件。
* 完成`UserManager`配置后，即可在层级评论编辑器中正常使用提及功能。

**交互流程**
用户可在层级评论编辑器中输入`@`，在回复内容里提及协作人员。
输入`@`后：

* 系统会在提及用户列表弹窗弹出前，同步触发`UserMentioning`事件。
* 开发人员可设置`args.cancel = true`关闭弹窗，将`@`视为普通文本字符。
* 若取消提及操作，不会生成提及区块，同时也不会触发`UserMentioned`事件。

提交包含单个或多个提及对象的回复时：

* 将会触发`UserMentioned`事件。

提及列表最多展示20位用户，若存在更多匹配用户，界面会给出提示以展示更多匹配结果。

### 解决状态（Resolved State）

评论包含“已解决”标记：

* **紫色标记**：未解决
* **灰色标记**：已解决

## 行为与限制

### 编辑规则

* 可同时编辑多条评论。
* 隐藏评论时，未保存的编辑会被丢弃。
* 不维护显式的编辑状态标记。

### 提及与链接

* 点击提及内容（**@用户**）不会打开用户信息卡片。
* 超链接编辑行为因浏览器而异：
    * **Safari**：发布后自动将粘贴或输入的 URL 转换为超链接。
    * **其他浏览器**：按下 **空格** 或 **回车** 时将文本转换为超链接。

### 导出与兼容性限制

* 导出到 Excel 时，用户 ID 必须符合 **UUID** 格式：
    `{XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX}`
* 若用户 ID 不符合该格式，SpreadJS 会调整其以适配 Excel 规范。
    这可能导致重新导入后编辑权限丢失（因用户 ID 发生变化）。

### 结构限制

评论目前 **不支持嵌套结构**，所有回复均为扁平层级。

### 实时状态限制

评论不支持实时在线状态或实时编辑指示器。

## 键盘快捷键

操作评论时支持以下键盘快捷键：

| **快捷键** | **功能** |
| --- | --- |
| Ctrl + Alt + M | 在选中单元格插入新的评论。 |
| Ctrl + Enter | 提交正在编辑的回复。 |
| Enter | 展开或折叠选中的评论。 |
| Esc | 取消回复编辑，不保存更改。 |

>type=note
> **注意**：macOS 系统中，使用 **Command（⌘）** 替代 **Ctrl**。

## 底层 API

评论依赖 SpreadJS 中的多个核心类和事件：

### 核心对象（Core Objects）

| **类** | **用途** |
| --- | --- |
| `GC.Spread.Sheets.ThreadedComments` | 管理与工作表单元格关联的所有评论。 |
| `GC.Spread.Sheets.ThreadedComments.ThreadedComment` | 表示单条评论或回复，支持编辑内容和标记已解决。 |
| `GC.Spread.Sheets.Events` | 评论相关事件，如 `ThreadedCommentChanging`、`ThreadedCommentChanged` 、`UserMentioning` 和 `UserMentioned`。 |
| `GC.Spread.Common.UserManager` | 配置和跟踪评论作者的当前用户。 |

### 附加支持

`GC.Spread.Sheets.Search` 和 `GC.Spread.Sheets` 类扩展了常见操作（搜索、复制、剪切、清除和使用范围），以包含评论数据。

## 代码示例

本节展示使用 SpreadJS API 执行评论的基本操作：

### 基础示例 — 添加评论

在单元格 E3 中创建一条由当前用户发布的评论，单元格会自动显示评论指示器：

```javascript
// 初始化工作簿
const spread = new GC.Spread.Sheets.Workbook("ss");
const sheet = spread.getActiveSheet();

// 定义用户信息
var users = [
        { id: "user1", name: "爱丽丝·约翰逊", email: "alice.johnson@company.com" },
        { id: "user2", name: "鲍勃·史密斯", email: "bob.smith@company.com" }
    ];

// 配置用户管理器
GC.Spread.Common.UserManager.configure({
    get: async (userId) => {
        if (userId === undefined) {
            return;
        }
        return new Promise((resolve) => {
            const user = users.find(u => u.id === userId);
            resolve(user);
        });
    },
    search: async (query) => {
        return new Promise((resolve) => {
            resolve(users.filter(u => 
                        u.name.toLowerCase().includes(query.toLowerCase()) || 
                        u.email.toLowerCase().includes(query.toLowerCase())
                    ));
        });
    }
});

// 设置当前用户
GC.Spread.Common.UserManager.current("user1");

// 创建评论内容（包含文本、用户提及和链接）
const comment_1 = {
    message: [
       { type: GC.Spread.Sheets.ThreadedComments.ContentType.text, value: "嗨 " },
       { type: GC.Spread.Sheets.ThreadedComments.ContentType.mention, userId: "user2" },
       { type: GC.Spread.Sheets.ThreadedComments.ContentType.text, value: "，请审阅研发部门的预算差异：" },
       { type: GC.Spread.Sheets.ThreadedComments.ContentType.link, href: "https://example.com/budget-policy", text: "预算政策文档" }
    ],
    authorId: "user1",
    createdAt: new Date("2025-12-10T15:44:00")
};

// 向单元格 B4（行索引 2，列索引 4）添加评论
const threadedCommentManager = sheet.threadedComments;
const threadedComment = threadedCommentManager.add(2, 4);
threadedComment.add(comment_1);
```

### 示例 — 更新、回复、更改状态或删除评论

基于上述示例扩展，展示评论的高级操作：

```javascript
// 获取指定评论（单元格 B4）
const thread = threadedCommentManager.get(2, 4);  
console.log(thread.row()); // 输出：2（行索引）

// 创建回复内容
const reply_1 = {
    message: [
    { type: GC.Spread.Sheets.ThreadedComments.ContentType.text, value: "已确认。" }
    ],
    authorId: "user2", 
    createdAt: new Date("2025-12-12T11:47:00")
};

// 添加回复
thread.add(reply_1);

// 编辑现有回复（修改索引为 0 的评论）
thread.set(0, { 
    message: [{ type: GC.Spread.Sheets.ThreadedComments.ContentType.text, value: '请核实该数值。' }] 
});

// 删除回复（删除索引为 1 的回复）
thread.remove(1);

// 标记评论为已解决/重新打开
thread.resolved(true); // true = 已解决，false = 重新打开
```

### 示例 — 处理评论事件

订阅事件以触发自定义逻辑：

```javascript
// 监听评论更新前事件
sheet.bind(GC.Spread.Sheets.Events.ThreadedCommentChanging, function (e, info) {
    // 处理评论属性或回复变更的自定义逻辑
});

// 用户输入@符号时触发用户提及事件，触发时机在弹出弹窗之前
// 将args.cancel设为true可屏蔽弹窗，把@符号视作普通文本
工作表绑定(GC.Spread.Sheets.Events.UserMentioning, function (e, args) {    
args.cancel = true; // 隐藏用户提及列表弹窗
});

// 监听用户被提及事件
sheet.bind(GC.Spread.Sheets.Events.UserMentioned, function (e, info) {
    console.log(info); // 输出提及相关信息（如提及者、被提及者、评论等）
});
```
