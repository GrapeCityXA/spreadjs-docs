# form-controls

SpreadJS 允许你向工作表添加表单控件，或者打开一个带有表单控件的现有 Excel 文件。
表单控件使用户能够轻松地与工作表中的单元格数据进行交互。例如，表单控件可用于从对话框工作表的列表中选择项目。如下截图所示：
![overview-formcontrols.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/overview-formcontrols.107f53.bd4df6.png)
SpreadJS 支持以下类型的表单控件：

* 按钮
* 数值调节钮
* 列表框
* 组合框
* 复选框
* 选项按钮
* 分组框
* 标签
* 滚动条
    SpreadJS 提供了 **[GC.Spread.Sheets.Shapes](gcdocsite__documentlink?toc-item-id=3619e0b0-f2ae-4633-80e5-45ca5e417b27)** 命名空间，通过 **addFormControl** 函数向形状集合中添加新的表单控件形状。该命名空间还提供了 **[FormControlType](gcdocsite__documentlink?toc-item-id=898bd4ce-66a1-4054-b1e7-3f59f465e35a)**[ ](gcdocsite__documentlink?toc-item-id=898bd4ce-66a1-4054-b1e7-3f59f465e35a)枚举，用于定义所有类型的内置表单控件。
    要实现表单控件，**[IFormControlOptions](gcdocsite__documentlink?toc-item-id=3619e0b0-f2ae-4633-80e5-45ca5e417b27#iformcontrolshapeoptions)**[ ](gcdocsite__documentlink?toc-item-id=3619e0b0-f2ae-4633-80e5-45ca5e417b27#iformcontrolshapeoptions)接口提供了诸如 **IOptionButtonFormControlOptions**、**ICheckBoxFormControlOptions**、**ISpinButtonFormControlOptions**、**IScrollBarFormControlOptions**、**IListBoxFormControlOptions**、**IComboBoxFormControlOptions** 和 **IGroupBoxFormControlOptions** 等选项。
    此外，表单控件具有 **cellLink** 属性，可用于将表单控件与单元格链接起来。因此，当表单控件的值发生变化时，单元格的值也会随之改变。而且，每当表单控件的值在用户界面操作、API 调用或更改关联单元格的值时发生变化，都会触发一个名为 **FormControlValueChanged** 的事件。表单控件还具有一个 **enabled** 属性，用于控制表单控件的交互。一旦将 **enabled** 属性设置为 false，表单控件的交互就会被禁用。默认情况下，该属性设置为 true。

> **enabled** 属性支持 Excel 的导入和导出操作，并且其行为与 Excel 一致。

## 样式设置

下表展示了表单控件及其支持的样式设置：

| 控件 | 文本样式 | 文本对齐方式 | 填充 | 线条 | Excel 支持情况 |
| --- | ---- | ------ | --- | --- | ---------- |
| 按钮 | 支持 | 支持 | 不支持 | 不支持 | 支持 |
| 选项按钮 | 支持 | 支持 | 支持 | 支持 | 仅支持少数渐变和图片填充属性 |
| 复选框 | 支持 | 支持 | 支持 | 支持 | 仅支持少数渐变和图片填充属性 |
| 标签 | 支持 | 支持 | 支持 | 支持 | 支持纯色填充和无填充。不支持线条样式 |
| 分组框 | 支持 | 不支持 | 不支持 | 不支持 | 支持 |
| 组合框 | 支持 | 不支持 | 不支持 | 不支持 | 不支持 |
| 列表框 | 支持（字体）不支持（颜色） | 不支持 | 不支持 | 不支持 | 不支持 |
| 数值调节钮 | 不支持 | 不支持 | 不支持 | 不支持 | 支持 |
| 滚动条 | 不支持 | 不支持 | 不支持 | 不支持 | 支持 |

尽管样式 API 与形状 API 一致，但并非所有样式设置都能在所有表单控件中实现。

> **注意**：SpreadJS 在执行 JSON 输入/输出操作时支持带有表单控件的 Excel 文件。

## 添加表单控件

让我们看看如何向工作表中添加每种表单控件。

### 按钮

你可以向工作表添加一个按钮表单控件。这可以通过将 **FormControlType** 枚举的 **button** 选项作为参数传递给 **addFormControl** 方法来实现。你可以使用 **text** 和 **style** 属性设置按钮控件的文本和样式。你还可以调用 **bind** 事件来提醒用户按钮已被点击。
![button-gif.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/button-gif.ef536a.49bc18.gif)
以下代码实现展示了如何添加一个按钮表单控件：

```JavaScript
var button = sheet.shapes.addFormControl("button", GC.Spread.Sheets.Shapes.FormControlType.button, 50, 50, 160, 100);
button.text("Click me");
var style = button.style();
style.textEffect.color = "rgb(0, 0, 0)";
style.textEffect.font = "bold 21px Calibri";
style.textFrame.vAlign = GC.Spread.Sheets.VerticalAlign.center;
style.textFrame.hAlign = GC.Spread.Sheets.HorizontalAlign.center;
button.style(style);
sheet.bind(GC.Spread.Sheets.Events.FormControlButtonClicked, function (s, args) {
    alert("button clicked...");
});  
```

### 数值调节钮

你可以向工作表添加一个数值调节钮表单控件。这可以通过将 **FormControlType** 枚举的 **spinButton** 选项作为参数传递给 **addFormControl** 方法来实现。你还可以使用 **options** 方法设置数值调节钮的选项并分配一个数值调节钮的 **value**。此外，你可以调用 **bind** 事件将一条消息写入控制台或记录下来，表明数值调节钮的值已发生变化。
![spin-button-gif.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/spin-button-gif.fa74f0.b7a6bc.gif)
以下代码实现展示了如何添加一个数值调节钮表单控件：

```JavaScript
var spinButton = sheet.shapes.addFormControl("spin button", GC.Spread.Sheets.Shapes.FormControlType.spinButton, 50, 50, 160, 100);
var options = spinButton.options();
options.minValue = 0;
options.maxValue = 50;
options.step = 1;
options.cellLink = "A1";
spinButton.options(options);
spinButton.value(25);
sheet.bind(GC.Spread.Sheets.Events.FormControlValueChanged, function (s, args) {
    console.log("value changed...", args.newValue);
});
```

### 列表框

你可以向工作表添加一个列表框表单控件。这可以通过将 **FormControlType** 枚举的 **listBox** 选项作为参数传递给 **addFormControl** 方法来实现。你还可以使用 **options** 方法设置列表框的选项、分配输入范围、设置选择类型并链接一个单元格。这样，当用户在列表框控件中更改值时，单元格中的值也会随之改变。此外，你可以调用 **bind** 事件将一条消息写入控制台或记录下来，表明控件的值已发生变化。
![listbox-formcontrol.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/listbox-formcontrol.a7c73d.b435a8.png)
以下代码实现展示了如何添加一个列表框表单控件：

```JavaScript
for (var i = 0; i < 14; i++) {
    sheet.setValue(i, 0, "A" + (i + 1));
}
var listBox = sheet.shapes.addFormControl("list box", GC.Spread.Sheets.Shapes.FormControlType.listBox, 100, 50, 200, 150);
var options = listBox.options();
options.inputRange = "A1:A14";
options.cellLink = "C1";
options.selectionType = GC.Spread.Sheets.Shapes.ListBoxSelectionType.single;
listBox.options(options);
listBox.value(2);
sheet.bind(GC.Spread.Sheets.Events.FormControlValueChanged, function (s, args) {
    console.log("value changed...", args.newValue);
});
```

### 组合框

你可以向工作表添加一个组合框表单控件。这可以通过将 **FormControlType** 枚举的 **comboBox** 选项作为参数传递给 **addFormControl** 方法来实现。你还可以使用 **options** 方法设置组合框的选项、分配输入范围、设置下拉列表长度并链接一个单元格。这样，当用户在组合框控件中更改值时，单元格中的值也会随之改变。此外，你可以调用 **bind** 事件将一条消息写入控制台或记录下来，表明控件的值已发生变化。
![combobox-formcontrol.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/combobox-formcontrol.561916.59cb24.png)
以下代码实现展示了如何添加一个组合框表单控件：

```JavaScript
for (let i = 0; i < 14; i++) {
    sheet.setValue(i, 0, "A" + (i + 1));
}
var comboBox = sheet.shapes.addFormControl("comboBox", GC.Spread.Sheets.Shapes.FormControlType.comboBox, 100, 50, 200, 30);
var options = comboBox.options();

options.cellLink = "C1";
options.dropDownLines = 6;
comboBox.options(options);
comboBox.value(1);

    console.log("value changed...", args.newValue);

```

### 分组框

你可以向工作表添加一个分组框表单控件。这可以通过将 **FormControlType** 枚举的 **groupBox** 选项作为参数传递给 **addFormControl** 方法来实现。你还可以使用 **options** 方法设置不同的分组框选项、链接一个单元格并添加文本。此外，你可以调用 **bind** 事件将一条消息写入控制台或记录下来，表明控件的值已发生变化。
![group-box.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/group-box.6ec197.2001e7.png)
以下代码实现展示了如何添加一个分组框表单控件：

```JavaScript
var contactMethod = sheet.shapes.addFormControl("email", GC.Spread.Sheets.Shapes.FormControlType.groupBox, 40, 130, 240, 80);
contactMethod.text("contact method");
var email = sheet.shapes.addFormControl("email", GC.Spread.Sheets.Shapes.FormControlType.optionButton, 50, 160, 100, 30);
email.text("email");
var phone = sheet.shapes.addFormControl("phone", GC.Spread.Sheets.Shapes.FormControlType.optionButton, 160, 160, 100, 30);
phone.text("phone");
options = phone.options();
options.cellLink = "C6";
phone.options(options);
phone.value(true);
sheet.bind(GC.Spread.Sheets.Events.FormControlValueChanged, function (s, args) {
    console.log("value changed...", args.newValue);
});
```

使用分组框表单控件对选项按钮进行分组的规则如下：

* 同一分组框中的选项按钮属于同一组。选项按钮的边框必须完全在分组框内部，仅分组框内的文本无效。
* 分组框外部的所有选项按钮属于同一组。
* 当你将一个选项按钮与一个单元格链接时，同一组的选项按钮都将与该单元格链接。

### 标签

![label.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/label.ffd0dc.4a3684.png)

```JavaScript
var label = sheet.shapes.addFormControl("label", GC.Spread.Sheets.Shapes.FormControlType.label, 50, 50, 160, 30);
label.text("I am a label");
```

### 滚动条

你可以向工作表添加一个滚动条表单控件。为此，将 **FormControlType** 枚举的 **scrollBar** 选项作为参数传递给 **addFormControl** 方法。你还可以使用 **options** 方法设置滚动条的选项、链接一个单元格并设置值。此外，你可以调用 **bind** 事件将一条消息写入控制台或记录下来，表明控件的值已发生变化。
![scroll-bar.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/scroll-bar.50a6ed.1d5945.png)

```JavaScript
var scrollBar = sheet.shapes.addFormControl("scrollBar", GC.Spread.Sheets.Shapes.FormControlType.scrollBar, 125, 21, 30, 118);
var options = scrollBar.options();

```

## 使用设计器

要在设计器中使用表单控件，请按照以下步骤操作：

1. 在设计器功能区中，单击“插入”选项卡，然后从“控件”库中选择表单控件。
    ![ribbon-for-form-controls.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ribbon-for-form-controls.9a3304.b0b0d9.png)
    一个表单控件将被添加到工作表中。
    ![control-added-sheet.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/control-added-sheet.239290.e87816.png)
2. 选择表单控件，然后使用命令快捷键“Ctrl + 鼠标左键单击”或“鼠标右键单击”来移动或调整控件的大小。
    ![combobox-designer-gif.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/combobox-designer-gif.8f91eb.f20dfc.gif)
3. 如上述 GIF 所示，从上下文菜单中选择“设置形状格式”选项。根据所使用的表单控件类型自定义形状、文本和控件选项。
    通常，当表单控件未被选中时，可以直接使用鼠标左键执行交互操作。当选中一个表单控件时，你可以移动或调整它的大小，但不能旋转它。

## 限制

表单控件不支持 VBA 代码和宏。
