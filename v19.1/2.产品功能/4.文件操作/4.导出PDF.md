# ExportingToPDF

SpreadJS 支持将工作簿导出为 PDF 文件，即使用 [Workbook](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0) 类的 [savePDF ](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0#savepdf)方法将工作簿导出为 PDF 格式（扩展名为.pdf 的文件）。
下表列出了 [savePDF ](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0#savepdf)方法的参数：

| 参数 | 描述 |
| --- | --- |
| successCallback | 在成功将文件导出为 PDF 后调用此函数。 |
| errorCallback | 当发生错误时调用此函数。 |
| options | 在导出为 PDF 文件时，你可以从以下选项中进行选择：<ul><li>`options.creator` \- 你可以指定创建原始文档（即转换源文档）的应用程序名称（例如 Adobe Framemaker）。</li><li>`options.title` \- 你可以指定文档的标题。</li><li>`options.author` \- 你可以指定创建该文档的人员姓名。</li><li>`options.keywords` \- 你可以指定与该文档相关的关键字。</li><li>`options.subject` \- 你可以指定文档的主题。</li></ul> |
| sheetIndex | 你可以通过指定要导出的工作表的索引，将工作簿中的特定工作表导出为 PDF。如果未提供此参数，默认情况下将导出所有可见工作表。 |

导出为 PDF 的操作使用 `printInfo` 对象进行页面设置，并支持 SpreadJS 中所有可用的打印功能。有关自定义导出 PDF 文件的更多信息，请参阅 [自定义 PDF 导出](gcdocsite__documentlink?toc-item-id=7d998b72-70cd-4d34-bd46-e81db1a2e0c2)。
在导出为 PDF 文件时，你可以指定要嵌入到 PDF 文档中的字体。用户在导出为 PDF 时，既可以嵌入标准字体（如下所列），也可以通过注册新字体来嵌入自定义字体。有关在执行导出为 PDF 操作时如何嵌入自定义字体的更多信息，请参阅 [在 PDF 导出中使用自定义字体](gcdocsite__documentlink?toc-item-id=823a69dc-54d0-488f-900d-fb7a4a9c31c0)。
下表列出了 PDF 文档中支持的 14 种标准字体：

| 字体 |  |
| --- | --- |
| Courier | Courier<br>Courier-Bold<br>Courier-Oblique<br>Courier-BoldOblique |
| Times | Times-Roman<br>Times-Bold<br>Times-Italic<br>Times-BoldItalic |
| Helvetica | Helvetica<br>Helvetica-Bold<br>Helvetica-Oblique<br>Helvetica-BoldOblique |
| Symbol | Symbol |
| ZapfDingbats | ZapfDingbats |

## 代码示例

此示例展示了如何使用 [savePDF ](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0#savepdf)方法将 Excel 文件导出为 PDF 文件。导出的文件将以.pdf 为扩展名进行保存。
代码示例的第一部分列出了执行导出为 PDF 操作所需的依赖项。

```HTML
<script src='.../spreadjs/gc.spread.sheets.all.x.x.x.min.js' type='text/javascript'></script>
<script src='.../spreadjs/plugins/gc.spread.sheets.print.x.x.x.min.js' type='text/javascript'></script>
<script src='.../spreadjs/plugins/gc.spread.sheets.pdf.x.x.x.min.js' type='text/javascript'></script>
```

代码示例的第二部分展示了如何使用 savePDF 方法将文件导出为 PDF 格式。

```JavaScript
spread.savePDF(
    function (blob) {
        var fileName = $('#fileName').val() || 'download';
        saveAs(blob, fileName + '.pdf');
    },
    function (error) {
        console.log(error);
    },
    {
        title: '测试标题',
        author: '测试作者',
        subject: '测试主题',
        keywords: '测试关键字',
        creator: '测试创建者',
    }
);
```

> **注意：** 在导出为 PDF 时，你需要牢记以下几点：
>
> * 要导出为 PDF 格式，你需要引用以下两个模块：
>     * gc.spread.sheets.print.x.x.x.min.js
>     * gc.spread.sheets.pdf.x.x.x.min.js
>
> 请注意，必须先加载打印插件。
>
> * 来源为 URL 或指定路径的图片不会自动编码为 base64 格式。因此，如果你使用文件协议方案，图片可能无法导出。
