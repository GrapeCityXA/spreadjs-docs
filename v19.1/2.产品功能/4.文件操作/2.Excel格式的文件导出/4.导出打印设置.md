# excelprintexp

下表总结了如何使用 **PrintInfo** 设置SpreadJS将数据导出到Excel格式的文件。

|  **SpreadJS 设置**  |  **Excel 设置**  |  **备注**  |
|--- |--- |--- |
|  **blackAndWhite**  | BlackAndWhite | Excel使用该设置。 |
|  **centering**  | CenterHorizontally or CenterVertically | Excel使用该设置。 |
|  **columnEnd**  | PrintArea | Excel使用该设置。 |
|  **columnStart**  | PrintArea | Excel使用该设置。 |
|  **firstPageNumber**  | FirstPageNumber | Excel使用该设置。 |
|  **fitPagesTall**  | FitToPagesTall | Excel使用该设置。 |
|  **fitPagesWide**  | FitToPagesWide | Excel使用该设置。 |
|  **footerCenter**  | CenterFooter | Excel使用该设置。 |
|  **footerCenterImage**  | CenterFooterPicture | SpreadJS仅在OpenXml Excel中支持此功能。 |
|  **footerLeft**  | LeftFooter | Excel使用该设置。 |
|  **footerLeftImage**  | LeftFooterPicture | SpreadJS仅在OpenXml Excel中支持此功能。 |
|  **footerRight**  | RightFooter | Excel使用该设置。 |
|  **footerRightImage**  | RightFooterPicture | SpreadJS仅在OpenXml Excel中支持此功能。 |
|  **headerCenter**  | CenterHeader | Excel使用该设置。 |
|  **headerCenterImage**  | CenterHeaderPicture | SpreadJS仅在OpenXml Excel中支持此功能。 |
|  **headerLeft**  | LeftHeader | Excel使用该设置。 |
|  **headerLeftImage**  | LeftHeaderPicture | SpreadJS仅在OpenXml Excel中支持此功能。 |
|  **headerRight**  | RightHeader | Excel使用该设置。 |
|  **headerRightImage**  | RightHeaderPicture | SpreadJS仅在OpenXml Excel中支持此功能。 |
|  **margin**  | LeftMargin 或 RightMargin 或 TopMargin 或 BottomMargin 或 FooterMargin 或 HeaderMargin | Excel使用该设置。 |
|  **orientation**  | Orientation | Excel使用该设置。 |
|  **pageOrder**  | Order | Excel使用该设置。 |
|  **paperSize**  | PaperSize | Excel使用该设置。 |
|  **repeatColumnEnd**  | PrintTitleColumns | Excel使用该设置。 |
|  **repeatColumnStart**  | PrintTitleColumns | Excel使用该设置。 |
|  **repeatRowEnd**  | PrintTitleRows | Excel使用该设置。 |
|  **repeatRowStart**  | PrintTitleRows | Excel使用该设置。 |
|  **rowEnd**  | PrintArea | Excel使用该设置。 |
|  **rowStart**  | PrintArea | Excel使用该设置。 |
|  **showColumnHeader**  | PrintHeadings | Excel使用该设置。 |
|  **showGridLine**  | PrintGridlines | Excel使用该设置。 |
|  **showRowHeader**  | PrintHeadings | Excel使用该设置。 |
|  **zoomFactor**  | Zoom | Excel使用该设置。 |
