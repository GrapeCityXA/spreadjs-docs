# excelcellimp

下表总结了SpreadJS从Excel文件导入数据时如何处理单元格设置。 这些属性是GC.Spread.Sheets.CellRange类的成员，除非另有特别说明。

| **Excel 设置** | **SpreadJS 设置** | **备注** |
| -------- | ----------- | --- |
| 单元格颜色或图案 | Cell.backColor or Cell.foreColor | SpreadJS从Excel读取颜色设置，并根据每个单元格的单独设置的设置分配颜色。 支持填充模式。 |
| 单元格边框 | Cell.borderLeft , borderTop , borderRight , borderBottom | SpreadJS导入边框。 SpreadJS将颜色设置为Excel中使用的颜色。 |
| 单元格值 | Cell.value or Cell.text | 单元格内容会以对应单元格数值的形式导入SpreadJS中，部分特殊内容类型可映射至专属数值模型。 |
| 单元格主题字体，字体，字体类型 | Cell.font | SpreadJS从Excel加载单元格字体。 |
| 单元格水平和垂直文本对齐 | Cell.hAlign or Cell.vAlign | SpreadJS从Excel加载单元格字体 |
| 单元锁定 | Cell.locked | SpreadJS导入Excel设置。 请注意，Excel中所有单元格的Lock属性的默认值为True。 |
| 单元格自动收缩 | Cell.shrinkToFit | SpreadJS从Excel加载单元格字体 |
| 单元格换行 | Cell.wordWrap | SpreadJS从Excel加载单元格字体 |
| 单元格缩进 | Cell.textIndent | SpreadJS从Excel加载单元格字体 |
| 单元格格式 | Cell.formatter | SpreadJS将所有Excel单元格格式导入常规单元格类型，并通过设置NumberFormat，DateTimeFormat和FormatString属性来尽可能紧密地分配格式。 |
| 单元格验证器 | Cell.validator | SpreadJS将Excel单元格验证器导入到DefaultDataValidator，并通过设置不同类型的Validator属性来分配验证器。 |
| 公式单元格隐藏 | Style.hidden<br>CellRange.hidden | SpreadJS 导入带有隐藏公式单元格的 Excel 文件 |
