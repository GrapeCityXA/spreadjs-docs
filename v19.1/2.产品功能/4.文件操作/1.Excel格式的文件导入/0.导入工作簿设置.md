# excelwbimp

此表总结了 SpreadJS 从 Excel 格式文件导入数据时如何处理工作簿设置。

| **Excel 设置** | **SpreadJS 设置** | **备注** |
| -------- | ----------- | --- |
| 受密码保护的文件 | SpreadJS 的输入输出选项 | SpreadJS 可以打开受密码保护的文件（在 SpreadJS 的输入输出导入 API 服务中指定密码设置）。 |
| 命名样式 | [Spread.addNamedStyle](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0#addnamedstyle) | Excel 文件中的命名样式会被导入到 SpreadJS 中。<br>Excel 文件中应用于命名样式的标志会被导入到 SpreadJS 中。 |
| 活动工作表索引 | [Spread.setActiveSheetIndex](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0#setactivesheetindex) | SpreadJS 从 Excel 导入此设置。 |
| 引用样式 | Spread.**referenceStyle** | SpreadJS 从 Excel 选项中导入此设置。 |
| 起始工作表索引 | [Spread.startSheetIndex](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0#startsheetindex) | SpreadJS 从 Excel 导入此设置。 |
| 工作表数量 | SpreadJS.length | SpreadJS 从 Excel 导入此设置。 |
| 滚动条 | Spread.**showHorizontalScrollbar** 或 Spread.**showVerticalScrollbar** | SpreadJS 从 Excel 选项中导入此设置。 |
| 显示工作表选项卡 | Spread.**tabStripVisible** | SpreadJS 从 Excel 选项中导入此设置。 |
