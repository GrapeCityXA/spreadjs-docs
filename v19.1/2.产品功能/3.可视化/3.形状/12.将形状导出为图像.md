# export-shapes-as-image

SpreadJS 支持将各种形状（如基本形状、连接符形状、自定义形状、照相机形状、迷你图形状和文本框形状）导出为图像源。SpreadJS 还允许您将表单控件形状导出为图像。不过，对于列表框控件，仅会导出当前滚动到的区域；而对于组合框控件，其下拉部分的区域则无法导出。 
插入形状或形状基对象后，可以使用 `shape.toImageSrc()` API 获取图像源。

## 使用代码

以下代码示例展示了如何将电子表格上的形状对象保存为图像源。

```javascript
// 添加一个形状
var donutShape = sheet.shapes.add('autoShape', GC.Spread.Sheets.Shapes.AutoShapeType.donut, 100, 50, 150, 150);

// 获取形状的图像源
let shapeImageSrc = sheet.shapes.all()[0].toImageSrc();
```

对于某些形状，不同的设置会导致导出的形状图像大小不同。例如，对于连接器形状，如果线宽不同，则导出的图像大小可能会因线宽而异。

## 使用设计器

Spread Designer 还提供了 **“保存为图片”** 选项，当您选择一个形状时，可以将选定的形状保存为图像。
以下是将形状保存为图像的步骤：

1. 打开一个工作表
2. 根据需要插入形状
3. 右键单击形状，然后单击 **“保存为图片”**
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.9de130.png)
4. 选择您要保存图像的位置。
5. 命名文件并单击 **“保存”**。

> type=warning
> 注意事项：
>
> * 目前，导出的文件格式为 PNG，文件名为默认对象名称。例如，**chord 1**
> * 如果选择了多个形状对象，它们将一起导出，默认情况下导出文件名为 **SpreadShapes**
