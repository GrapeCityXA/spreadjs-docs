# sparkline-shape

迷你图通常被用作小巧、简洁且数据丰富的图形，以一种具有视觉吸引力的方式传达信息。然而，SpreadJS 允许你以创造性的方式将迷你图呈现为形状或图像，以增强视觉设计，或者在各种可以移动、缩放或旋转的场景中传达含义。
作为形状和图片的迷你图可用于演示文稿中，以简洁易懂的方式传达信息，或者用于用户界面中，以显示任务的进度。
![sparkline-shapepic](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/sparkline-shapepic.fcdc3c.1dcaa8.gif)
你可以通过将图片填充的 **src** 或 **style.fill.src** 属性绑定到迷你图公式，将迷你图呈现为图像。同样地，迷你图公式可以绑定到自选图形的 **style.fill.src** 属性上。此外，SpreadJS 允许你在将迷你图绑定到 **src** 属性时，为迷你图添加渐变、纯色和其他填充效果。
以下示例代码展示了如何添加一个矩形作为形状，并将其绑定到一个柱形迷你图。

```javascript
// 添加自选图形
var rect = sheet.shapes.add("rect", GC.Spread.Sheets.Shapes.AutoShapeType.rectangle, 0, 300, 142, 162); 

// 设置图片填充
var style = rect.style(); 
style.fill = { src: '' }; 
rect.style(style); 
sheet.setValue(11,0,"销售额: "); 
sheet.setValue(11,3,"备注: "); 

// 将迷你图公式绑定到图片填充的 src 属性
rect.setFormula('style.fill.src', '=COLUMNSPARKLINE(Sheet1!B3:B9,0)'); 
```

以下示例代码展示了如何将一个图片形状与饼图迷你图绑定，并设置纯色背景填充。

```javascript
 // 添加图片形状
var pic = sheet.shapes.addPictureShape("pic", '', 400, 300, 142, 162); 

// 将迷你图公式绑定到图片的 src 属性
pic.setFormula('src', '=PIESPARKLINE(Sheet1!B3:B8,"#919F81","#D7913E","CEA722","#B58091","#8974A9","#728BAD")'); 

// 设置纯色背景
var style = pic.style(); 
style.fill = { color: '#4F80BC' }; 
pic.style(style); 
```
