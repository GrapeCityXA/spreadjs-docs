# AddingCustomShapes

SpreadJS支持根据特定要求在表单中添加自定义形状。 您可以自定义形状模型以绘制您选择的形状，就像将图形绘制到画布上一样。
下面共享的截图描述了添加到表单中的自定义形状。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/custom_shapes.png)
本示例说明如何在表单中添加自定义形状。

```JavaScript
// Adding a custom shape to the worksheet
window.onload = function ()
{
var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
var sheet = spread.getActiveSheet();
// Define a model to create custom shape
   var model =
{
   left: 50,
   top: 50,
   width: 300,
   height: 300,
   options:
   {
        fill:
          {
            type: 1,
            color: "green",
            transparency: 0.5,
           },                    
         stroke:
           {
             type: 1, // solid fill (now only support solid fill)
                 color: "blue",
             width: 3                   
            }                    
      },
            path: [
             [
                    ["M", 4, 1], // M: move to (x, y)
                        ["L", 104, 1], // L: line to (x, y)
                        ["L", 4, 94],
                    ["L", 104, 94],
                    ["L", 4, 1],
                    ["M", 4, 47],
                    ["L", 104, 47],
                    ["Z"]
              ]
            ]
        };
//Add defined custom shape to sheet
    sheet.shapes.add('name', model);          
}
```

> **注意：** 在集成自定义形状时，SpreadJS 不支持以下情况：
>
> * 目前不支持将自定义形状导入或导出到 Excel 文件中。
> * 形状文本仅支持水平方向、水平和垂直文本对齐方式、纯色填充、字体（名称和字号）以及边距等。
> * 目前不完全支持翻转形状（水平翻转、垂直翻转或两者皆有的翻转）。
> * 标注形状类型中超出形状边界部分的命中测试（HitTest）功能并非完全支持。因此，用户无法通过点击超出形状边界的部分来选择形状。
