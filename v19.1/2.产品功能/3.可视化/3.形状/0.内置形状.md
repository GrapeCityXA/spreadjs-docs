# AddingBuiltInShapes

SpreadJS支持两百余种内置形状，可插入工作表中，涵盖直线、矩形、块状箭头、公式形状、流程图图形、星形、旗帜、标注、连接线等各类样式。

插入后的形状可进行移动、调整大小、旋转、设置样式以及删除操作。

你既可以通过SpreadJS设计器插入形状，也能编写代码实现该操作。

## 通过设计器插入形状
在设计器中打开**插入**选项卡，从形状图库内选择所需形状。

选中形状后，工作表会进入绘图模式，带来与Excel相仿的交互式绘制体验。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260421.bb56fc-20260525.f68eb3.png?width=800)

### 绘图模式
选定形状类型后：
* 鼠标光标进入工作表区域时会变为精准十字光标 ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260318.38421b-20260525.22eccc.png?width=25)。
* 按住鼠标拖动即可划定形状的尺寸范围。
* 拖动过程中会实时显示半透明形状预览效果。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260318.f12c0c-20260525.4e6770.png?width=200)
<br>
* 预览轮廓与所选实际形状样式完全一致，并非通用矩形样式。
![draw.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/draw-20260421.a08581-20260525.a69cca.gif?width=800)

#### 绘制完成操作
* 拖动后松开鼠标：按照划定的范围插入对应形状。
![Drag.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/Drag-20260421.562a74-20260525.e87b2f.gif?width=800)
<br>
* 仅点击不拖动：在点击位置以默认尺寸插入形状。
![Click.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/Click-20260421.c62d3a-20260525.7fc094.gif?width=800)
<br>
* 按下**ESC键**：取消绘制操作并退出绘图模式。
![esc.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/esc-20260421.0a5ade-20260525.152ece.gif?width=800)
<br>
所有形状插入操作均可存入撤销/重做操作栈，支持撤回与恢复。
默认状态下，完成单个形状插入后会自动退出绘图模式。

### 锁定绘图模式
若需要连续多次插入同一种形状，可开启锁定绘图状态。

在设计器中操作步骤：
1. 在**插入**选项卡选中目标形状。
2. 右键点击选中的形状图标。
3. 在弹出的右键菜单中点击**锁定绘图模式**。

开启该功能后，每插入一个形状仍会保持绘图模式不变。
按下**ESC键**即可退出锁定模式，恢复普通鼠标指针状态。
![lock.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/lock-20260421.bb16d0-20260525.4fcd2e.gif?width=800)

>type=note
> **注意事项：**
>
> * 实时预览功能适用于全部两百余种内置形状，包含自选图形与连接线。
> * 直线型、折线型、曲线型连接线在绘制时可完整适配连接点，支持实时线路调整。
> * 形状预览与放置过程中，支持吸附网格、吸附其他形状对齐功能。
> * 各类特定形状的详细使用规则与相关应用程序接口，可查阅对应专属文档。
> * 多人协同编辑场景相关说明：
>     * 绘制过程中的临时预览状态不会同步展示给其他协同编辑人员。
>     * 仅最终确定完成的形状插入操作会进行数据同步。
> * 平板触控设备（如iPad）上的形状插入操作逻辑，与电脑桌面端保持一致。

## 代码方式插入形状
你也可以通过编写程序代码添加内置形状。
```javascript
// 假设工作簿已完成初始化
var sheet = spread.getActiveSheet();
spread.suspendPaint();
try {    
var donutShape = sheet.shapes.add(        
"donutShape",        
GC.Spread.Sheets.Shapes.AutoShapeType.donut,        
100,        
50,        
150,        
150    
);
    donutShape.text("环形形状");
    var style = donutShape.style();    
style.fill.color = "#FFF4D6";    
style.line.color = "#F59E0B";    
style.line.width = 2;    
style.textEffect.color = "#C2410C";    
style.textEffect.font = "16px Arial";    
style.textFrame.hAlign = GC.Spread.Sheets.HorizontalAlign.center;    
style.textFrame.vAlign = GC.Spread.Sheets.VerticalAlign.center;
    donutShape.style(style);
} finally {    
spread.resumePaint();
}
```

## 使用限制
* 形状内文字仅支持横向排版。
* 标注类形状暂未完全支持形状主体边界外的点击判定，用户点击形状主体范围外区域可能无法选中该形状。
