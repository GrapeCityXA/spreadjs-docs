# resize-shape

SpreadJS 支持在工作表中调整形状的大小。为此，**[ShapeBase](https://demo.grapecity.com.cn/spreadjs/help/api//classes/GC.Spread.Sheets.Shapes.ShapeBase#class-shapebase)**[ ](https://demo.grapecity.com.cn/spreadjs/help/api//classes/GC.Spread.Sheets.Shapes.ShapeBase#class-shapebase)类提供了 **allowResize** 属性。该属性可以有不同的调整大小模式和布尔值。
![resizing-allshapes.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/resizing-allshapes.88ae90.b08012.gif)
**[ResizeMode](https://demo.grapecity.com.cn/spreadjs/help/api//enums/GC.Spread.Sheets.Shapes.ResizeMode#enumeration-resizemode)**[ ](https://demo.grapecity.com.cn/spreadjs/help/api//enums/GC.Spread.Sheets.Shapes.ResizeMode#enumeration-resizemode)枚举提供了以下几种调整大小模式：

* **按比例（Aspect）**：按比例调整大小模式会显示所有的调整大小控点，即上、下、左、右、左上、右上、左下和右下控点，这样你就可以在各个方向上调整形状的大小。这有助于保持形状的宽高比。
    ![aspect-resizemode.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/aspect-resizemode.30cad2.e33dfe.png)
* **水平（Horizontal）**：水平调整大小模式仅显示左和右的调整大小控点，以便可以水平调整形状的大小。
    ![resize-horizontal.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/resize-horizontal.0bd72e.fd88fd.png)
* **垂直（Vertical）**：垂直调整大小模式仅显示上和下的调整大小控点，以便可以垂直调整形状的大小。
    ![resize-vertical.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/resize-vertical.fb179e.52ba16.png)

请参考以下示例代码，使用 **allowResize** 方法来调整形状的大小。

```JavaScript
// 按比例调整形状大小
shape2.allowResize(GC.Spread.Sheets.Shapes.ResizeMode.aspect);
// 水平调整形状大小
shape3.allowResize(GC.Spread.Sheets.Shapes.ResizeMode.horizontal);
// 垂直调整形状大小
shape4.allowResize(GC.Spread.Sheets.Shapes.ResizeMode.vertical);
```

你还可以通过在 **allowResize** 方法的参数中传入 `false` 值来禁用形状上的所有调整大小控点，并阻止用户调整形状的大小。同样地，要启用形状上的所有调整大小控点，你可以在 **allowResize** 方法的参数中传入 `true` 值。
![resizemode-false.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/resizemode-false.6345d5.79f8f6.png)

```JavaScript
// 禁用形状调整大小
shape1.allowResize(false);
```

## 支持的形状类型和默认值

下表列出了不同的形状类型和默认的调整大小模式值：

| 形状类型 | 默认值 |
| ---- | --- |
| 形状 | true |
| 组合形状 | true |
| 连接符 | true |
| 表单控件 | true |
| 图片形状 | 按比例（aspect） |
| 摄像头形状 | 按比例（aspect） |

> **注意**：**allowResize** 属性仅影响用户界面行为。形状的宽度和高度属性不受影响。

**SpreadJS** 支持像在 Excel 中一样的 “Shift + 鼠标” 调整大小行为。因此，如果你在调整形状大小时按下 Shift 键，形状将保持宽高比。此行为仅在 **allowResize** 属性设置为 `true` 时才生效。

### 调整连接符形状的大小

当你调整连接符形状的大小时，将鼠标悬停在另一个形状附近，比如下面 GIF 中所示的内置形状，该形状的连接点就会显示出来。然后，连接符形状会直接连接到另一个形状最近的一个连接点上。

## 使用设计器

要使用设计器调整形状的大小，请按照以下步骤操作：

1. 选择形状。
2. 右键单击，从上下文菜单中选择 **设置形状格式** 选项。这会在右侧调出 **设置形状格式** 面板。
3. 使用面板中的 **调整大小** 模式选项选择不同的调整大小模式。
    ![designer-resize-shapes.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/designer-resize-shapes.69c11c.65b0cd.gif)
