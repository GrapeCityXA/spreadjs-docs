# add-charts-with-multi-selections

SpreadJS 支持添加具有多项选择功能的图表，这使您能够根据选定的条件动态更改可视化效果。无论您是在比较多种情况、跟踪特定类别的表现，还是分析各种因素的影响，以交互方式选择数据点的功能都能增强分析的深度和精度。
在图表中，数据源的多项选择功能的工作方式如下：

* 第一个选定的范围将作为 **基准数据源**。
* 如果用户未指定合适的 **数据方向**，它会通过考虑数据源来推断出最佳方向。
* **名称区域**、**类别区域** 和 **数据区域** 会根据各自的数据类型进行区分。

**示例**：以下屏幕截图显示了熊、鲸鱼和海豚的年度记录数据。此外，它还包含一个图表，该图表使用多项选择选项描绘了熊和海豚选定数据范围的柱状图。
![chartwithmultiselection.38bb58](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/chartwithmultiselection.38bb58.15266a.png)
以下代码示例展示了使用多项选择选项选定的熊和海豚的数据范围。

```javascript
// 添加图表。
sheet.charts.add("chart1", GC.Spread.Sheets.Charts.ChartType.columnClustered, 0, 100, 400, 300, "Sheet1!$A$1:$C$2,Sheet1!$A$3:$C$5");
```

此外，如果某个数据源与图表的结构不匹配，则相应的数据源将被丢弃。不过，如果第一个数据源不包含数字，它将被视为名称区域。
**示例**：以下屏幕截图显示第一个数据源为字符串。因此，图表将第一个数据源用作名称区域，将选定的数据源用作类别区域和数据区域。
![chart-firststring.8c399d](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/chart-firststring.8c399d.97d5e4.png)

#### 使用设计器

您也可以通过 SpreadJS 设计器按照以下步骤启用此功能：

1. 从数据表中选择第一个数据区域，然后按住 **Ctrl** 键选择其他所需的数据源。
2. 在 **插入** \> **图表** 选项卡组中，为可用数据选择图表类型。
