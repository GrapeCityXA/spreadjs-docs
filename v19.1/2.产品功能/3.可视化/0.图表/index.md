# Charts

在数据分析场景中，图表以图形化格式展示数据，是理解电子表格内大量信息的重要工具。用户借助图表，能将复杂数据转化为直观可视形式，快速把握数据蕴含的意义。
SpreadJS 如同 Excel，为用户提供完整且易于使用的图表支持功能。运用 SpreadJS 时，用户可在电子表格中便捷插入多种二维图表，包括柱状图、折线图、饼图、散点图等，操作简便。同时，SpreadJS 支持用户对图表元素进行深度自定义，从图表标题、坐标轴标签，到数据系列的颜色、样式等，均可按需灵活调整，从而以高效方式实现数据可视化，快速汇总关键信息，为高级信息分析提供支撑。
需注意，SpreadJS 的图表功能以插件形式存在。这一设计简化了图表创建流程，新手用户也能快速上手。并且，插件特性使用户在图表定制方面拥有极大的灵活性。
凭借对十一个图表组、三十三种图表类型以及组合图表功能的广泛支持，用户通过简单点击操作，即可在电子表格中插入所需二维图表，设置自定义图表布局，按个人偏好定制图表元素，甚至组合多种图表类型。在实际应用中，这些操作可满足不同场景需求，如在财务分析中评估财务信息、进行股票分析，以及在销售场景中查看销售收入情况等 。
