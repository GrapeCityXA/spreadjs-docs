# sparkmain

迷你图是一种小型图表，可用于快速将数据可视化，并在一个单元格中以紧凑的形式呈现数据。它使用一系列单元格中的数据，帮助您轻松地在单元格层面分析数据。
您可以使用 [setSparkline ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#setSparkline)方法将迷你图类型设置为柱形、折线或盈亏类型，也可以使用特定类型的公式来创建 SpreadJS 中可用的不同迷你图。
您还可以实现自己的逻辑，利用提供的数据集和设置来定义自定义迷你图公式；并使用 [addSparklineEx ](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0#addSparklineEx)方法添加该自定义迷你图。

>type=info
> **注意**：使用公式创建的迷你图无法导出到 Excel 文件中。

## 迷你图分组

您可以使用 [groupSparkline ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#groupSparkline)和 [ungroupSparkline ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#ungroupSparkline)方法对迷你图进行分组和取消分组操作。
分组功能使您能够一次性对多个迷你图应用更改，从而节省操作时间。分组还可以通过在一个组中使用相同类型的迷你图和坐标轴，更方便地比较迷你图。

```javascript
var spread = GC.Spread.Sheets.findControl(document.getElementById('ss'));
var sheet = spread.getActiveSheet();
var s1 = sheet.setSparkline(13, 0, data, GC.Spread.Sheets.Sparklines.DataOrientation.vertical, GC.Spread.Sheets.Sparklines.SparklineType.line, setting);
var s2 = sheet.setSparkline(13, 3, data, GC.Spread.Sheets.Sparklines.DataOrientation.vertical, GC.Spread.Sheets.Sparklines.SparklineType.column, setting);
var s3 = sheet.setSparkline(13, 6, data, GC.Spread.Sheets.Sparklines.DataOrientation.vertical, GC.Spread.Sheets.Sparklines.SparklineType.winloss, setting);
// 对迷你图进行分组
var group = sheet.groupSparkline([s1, s2, s3]);
group.sparklineType = GC.Spread.Sheets.Sparklines.SparklineType.column;
// 取消迷你图的分组
sheet.ungroupSparkline(group);
```

## 将迷你图导出为图片

微软Excel本身并不支持SpreadJS迷你图公式。默认情况下，导出的Excel文件会保留相关公式，但无法直观显示出迷你图效果。
若要在Excel中正常展示迷你图，导出时需将[saveAsView](gcdocsite__documentlink?toc-item-id=93a45be2-e7f2-4fef-aa55-44b2d32eaf16#saveoptions)参数设置为`true`，代码示例如下：

```javascript
saveOptions.saveAsView = true;
```

开启该设置后：

* 迷你图会以静态图片形式呈现在导出文件中
* 原始公式会完整保留
* 在Excel中修改数据后，对应的静态图片不会同步更新

![saveAsView.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/saveAsView-20260304.a83135-20260525.579ecb.gif?width=800)

如有需求，还可通过`includeFormulas`参数屏蔽公式导出。

**性能说明**：开启此功能会延长导出耗时、增大文件体积，存在大量迷你图时该现象尤为明显。

**适用场景**：工作表、表格表单、甘特图表单以及报表表单。
