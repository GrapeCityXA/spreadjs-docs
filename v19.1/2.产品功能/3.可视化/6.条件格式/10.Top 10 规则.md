# top10rule

前十项规则可高亮指定区域内数量或占比排名最高、最低的数值。可借助`Top10ConditionType`枚举值，设定从区域顶部数值还是底部数值进行匹配。
默认情况下，`rank`参数用于指定需要高亮的单元格确切数量。将`isPercent`设置为`true`，即可把该排名数值当作百分比来判定。

## 百分比模式

当`isPercent`设为`true`时，匹配数量会依据区域内非空数值单元格数量计算，而非单元格总数量。

* 若区域内不存在任何非空数值单元格，则不会高亮任何单元格。
* 只要区域内存在至少一个非空数值单元格，就必定会高亮至少一个单元格。

## 示例

### 基础配置

```auto
// 填充数据
for (var row = 0; row < 10; row++) {    
var randomValue = Math.floor(Math.random() * 20) + 1;     
sheet.setValue(row, 0, randomValue);
}
var ranges = [new GC.Spread.Sheets.Range(0, 0, 10, 1)];
// 设置样式
var style = new GC.Spread.Sheets.Style();
style.backColor = "red";
```

### 基于数量的规则

以下代码示例可高亮指定区域内数值排名前2的数据：

```javascript
activeSheet.conditionalFormats.addTop10Rule(GC.Spread.Sheets.ConditionalFormatting.Top10ConditionType.top, 2, style, ranges);
```

### 基于百分比的规则

SpreadJS 提供三种等效方式来创建基于百分比的顶部/底部数值判定规则。
**使用`NormalConditionRule`构造函数：**

```javascript
var topRule = new GC.Spread.Sheets.ConditionalFormatting.NormalConditionRule(    
GC.Spread.Sheets.ConditionalFormatting.RuleType.top10Rule,    
ranges,style, undefined, undefined, undefined, undefined, undefined,    
GC.Spread.Sheets.ConditionalFormatting.Top10ConditionType.top, 20, true /* 开启百分比模式 */
);
activeSheet.conditionalFormats.addRule(topRule);
```

**使用`NormalConditionRule`属性设置方法：**

```javascript
var topRule = new GC.Spread.Sheets.ConditionalFormatting.NormalConditionRule();
topRule.ruleType(GC.Spread.Sheets.ConditionalFormatting.RuleType.top10Rule);
topRule.type(GC.Spread.Sheets.ConditionalFormatting.Top10ConditionType.top);
topRule.rank(20);
topRule.isPercent(true);
topRule.style(style);
topRule.ranges(ranges);
topRule.stopIfTrue(true);
activeSheet.conditionalFormats.addRule(topRule);
```

**调用`addTop10Rule`方法：**

```javascript
activeSheet.conditionalFormats.addTop10Rule(GC.Spread.Sheets.ConditionalFormatting.Top10ConditionType.top, 2, style, ranges, true /* 开启百分比模式 */);
```
