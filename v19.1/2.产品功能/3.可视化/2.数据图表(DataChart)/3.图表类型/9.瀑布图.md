# waterfall-charts

瀑布图能够展示依次增减的数值如何累加得出总计数值，常被用于分析利润变动、预算偏差、销售业绩以及其他数值增减变化情况。
每一个柱体代表单独一项数值变动，末尾柱体可按需展示合计总数。
![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image.afbb70-20260525.525f1b.png?width=600)

## 分类项配置

瀑布图仅支持绑定单个分类字段。
若绑定多级分类层级，系统只会读取第一级分类，嵌套的分类层级会被忽略且不会展示。
为保证标签显示效果稳定，配置瀑布图时建议使用单层分类字段。

## 基础瀑布图

以下示例为最简瀑布图配置代码。

```javascript
const sheet = spread.getActiveSheet();
sheet.name('Waterfall Chart');
const dataChart = sheet.dataCharts.add('waterfall-chart', 10, 10, 600, 400, GC.Spread.Sheets.DataCharts.DataChartType.waterfall);
dataChart.setChartConfig({
    tableName: 'Profits',
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.waterfall,
            encodings: {
                values: [
                    {
                        field: 'Value',
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum,
                    },
                ],
                category: {
                    field: 'Category',
                },
            },
        },
    ],
});
```

## 瀑布图专属配置

瀑布图可在`config.waterfall`配置项中设置专属参数。

| **属性** | **说明** | **效果预览** |
| --- | --- | ---- |
| `showTotal` | 控制图表是否展示总计柱体。<br>设为`true`显示末尾合计柱体，设为`false`则隐藏。 | ![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image.64068d-20260525.dcdd96.png?width=500) |
| `totalLabel` | 自定义总计柱体的文字名称，默认值为`"Total"`。 | ![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image.905643-20260525.e3e221.png?width=500) |
| `orientation` | 设置图表排列方向，默认竖向`"vertical"`，也可选择横向`"horizontal"`。 | ![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image.b33be6-20260525.0465a5.png?width=500) |
| `connectingLineStyle` | 定义柱体之间连接线样式，可自定义以下参数<ul><li>`stroke`线条颜色</li><li>`strokeWidth`线条粗细</li><li>`strokeDasharray`实线或虚线样式</li></ul> | ![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image.2eefcb-20260525.6b4984.png?width=500) |

配置示例：

```javascript
config: {  
    waterfall: {    
        showTotal: true,    
        totalLabel: "净利润",    
        orientation: "vertical",    
        connectingLineStyle: {      
            stroke: { type: 'CssColor', color: 'red' },      
            strokeWidth: 2,      
            strokeDasharray: "5,5"    
        }  
    }
}
```

## 高级应用示例

下方代码可制作同比净利润分析瀑布图，包含自定义图表样式、文字格式、悬浮提示框与动画效果。

```javascript
// 基础初始化
const sheet = spread.getActiveSheet();
sheet.name('Waterfall Data Chart');
const dataManager = spread.dataManager();
function createProfitsTable(dataManager) {
    const records = [
        ['上年净利润', 846.5],
        ['产品销售额增长', 235.8],
        ['售价与品类优化收益', 87.3],
        ['原材料成本上涨', -162.7],
        ['运营费用增加', -95.4],
        ['税收优惠', 38.6],
    ];
    const columns = ['Category', 'Value'];
    return dataManager.addTable('Profits', {
        data: records.map((record) => {
            const item = {};
            columns.forEach((column, index) => (item[column] = record[index]));
            return item;
        }),
    });
}
const ProfitsTable = createProfitsTable(dataManager);
await ProfitsTable.fetch();
// 创建瀑布数据图表
const dataChart = sheet.dataCharts.add('WaterfallChart6', 10, 10, 600, 400);
dataChart.setChartConfig({
    tableName: 'Profits',
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.waterfall,
            encodings: {
                values: [{ field: 'Value', aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum }],
                category: { field: 'Category' },
            },
            config: {
                waterfall: {
                    totalLabel: '本年净利润',
                    connectingLineStyle: {
                        stroke: { type: 'CssColor', color: 'red' },
                        strokeWidth: 2,
                    },
                },
                text: [
                    {
                        template: '{valueField.value}',
                        format: { value: '0.00' },
                        overlappingLabels: 'Hide',
                        position: GC.Spread.Sheets.DataCharts.TextPosition.center,
                        textStyle: {
                            fontFamily: 'Calibri',
                            fontSize: 10,
                            fontWeight: 'Lighter',
                            fontStyle: GC.Spread.Sheets.DataCharts.FontStyle.italic,
                            color: '#333333',
                        },
                    },
                ],
                tooltip: [
                    {
                        style: {
                            fill: { type: 'CssColor', color: '#ffffff' },
                            stroke: { type: 'CssColor', color: '#e0e0e0' },
                            strokeWidth: 1,
                        },
                        textStyle: {
                            fontFamily: 'Calibri',
                            fontSize: 12,
                            fontWeight: 'Lighter',
                            fontStyle: GC.Spread.Sheets.DataCharts.FontStyle.italic,
                            color: '#333333',
                        },
                    },
                ],
                hoverAnimation: {
                    duration: 400,
                    easing: GC.Spread.Sheets.DataCharts.AnimationEasing.linear,
                    scale: 1.5,
                },
                updateAnimation: {
                    startDelay: 200,
                    duration: 1000,
                    easing: GC.Spread.Sheets.DataCharts.AnimationEasing.linear,
                },
            },
        },
    ],
    config: {
        header: {
            title: '利润变化桥图：年度净利润同比分析',
            padding: {
                left: 10,
                right: 10,
                top: 10,
                bottom: 20,
            },
            style: {
                fill: { type: 'CssColor', color: '#f2f2f2' },
            },
            textStyle: {
                color: 'black',
                fontSize: 18,
                fontStyle: GC.Spread.Sheets.DataCharts.FontStyle.italic,
                fontWeight: 'Bold',
                alignment: GC.Spread.Sheets.DataCharts.HAlign.left,
            },
        },
    },
});
```
