# area-charts

**面积图**用于展示单个或多个数据量随时间产生的变化。它与折线图原理相近，先绘制数据点并用线段相连，同时将线条与横轴之间的区域填充上色。填充区域能够直观体现不同时间节点的数据数值大小。
SpreadJS支持多种类型的面积图，可通过修改图表属性完成自定义设置，例如调配配色方案、调整图形透明度、更改边框样式、设置分类轴与数值轴样式等。相关设置既可以编写代码实现，也能借助SpreadJS设计器中的检查面板完成操作。

>type=info
> **备注：**
>
> * 本文档所有示例均采用《创建数据图表》章节中介绍的销售数据表。添加图表前，请确保已完成数据源配置。
> * 分类与数值映射的相关详情，可参考《绑定数据源》文档。

## 面积图

面积图可以呈现连续区间或时间段内的量化数据。这类图表会将横轴与数据折线之间的区域填充色彩，便于直观查看数值大小，以及数值随时间、不同分类产生的变动情况。面积图适用于展示数据时间趋势、统计各类别数据总和，还可对比不同组成部分在整体中的占比贡献。
面积图效果如下所示：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260525.26bc30.png?width=800)
可参考下方示例代码添加面积图。

```javascript
// 面积图
const sheet = spread.getActiveSheet();
sheet.name('面积图');
const dataChart = sheet.dataCharts.add('data-chart', 10, 10, 600, 400);
dataChart.setChartConfig({
    tableName: 'Sales',
    config: {
        header: {
            title: '面积图',
        },
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.area,
            encodings: {
                category: {
                    field: 'Salesman',
                },
                values: [
                    {
                        field: 'Sales',
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum,
                    },
                ],
                color: {
                    field: 'Product',
                },
                filter: {
                    operate: GC.Spread.Sheets.DataCharts.LogicalOperation.and,
                    conditions: [
                        {
                            field: 'Region',
                            excludeMatched: false,
                            operate: GC.Spread.Sheets.DataCharts.ComparisonOperator.in,
                            value: ['East'],
                        },
                    ],
                },
            },
            config: {
                axisMode: GC.Spread.Sheets.DataCharts.AxisMode.cartesian,
            },
        },
    ],
});
```

## 区间面积图

区间面积图能够展示不同分类下数值上下限之间的差值范围。该图表不再绘制单条数据序列，而是填充两条边界线之间的区域，以此凸显数据波动幅度。
从SpreadJS 19.1版本开始，区间面积图可将数值下限字段与上限字段绑定为一个逻辑区间数值。
区间面积图效果如下所示：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260525.39cb5d.png)
参考下方示例代码添加区间面积图。

```javascript
// 区间面积图
const sheet = spread.getActiveSheet();
sheet.name('区间面积图');
const dataChart2 = sheet.dataCharts.add('data-chart-2', 10, 10, 600, 400);
dataChart2.setChartConfig({
    tableName: 'Sales',
    config: {
        header: {
            title: '区间面积图',
        },
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.rangeArea,
            encodings: {
                category: {
                    field: 'Salesman',
                },
                details: [
                    {
                        field: 'Product',
                    },
                ],
                values: [
                    {
                        field: 'Sales',
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum,
                    },
                    {
                        field: 'Return',
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum,
                    },
                ],
                filter: {
                    operate: GC.Spread.Sheets.DataCharts.LogicalOperation.and,
                    conditions: [
                        {
                            field: 'Region',
                            excludeMatched: false,
                            operate: GC.Spread.Sheets.DataCharts.ComparisonOperator.in,
                            value: ['East'],
                        },
                    ],
                },
            },
            config: {
                axisMode: GC.Spread.Sheets.DataCharts.AxisMode.cartesian,
            },
        },
    ],
});
```

## 堆叠面积图

堆叠面积图将多组数据序列逐层叠加呈现，每组序列以不同颜色的区域区分。各区域数值累加，既能展示数据总量，也便于对比不同时间段、不同分类下的整体数值规模，以及各组数据在整体中的占比贡献。
在该图表中，任意节点的纵向高度代表所有叠加数据的总和，每一段色块分别对应一组独立数据序列。借助这种展示形式，用户可以清晰查看整体数据的组成结构。
堆叠面积图效果如下所示：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260525.78740e.png)
参考下方示例代码添加堆叠面积图。

```javascript
// 堆叠面积图
const sheet = spread.getActiveSheet();
sheet.name('堆叠面积图');
const dataChart3 = sheet.dataCharts.add('data-chart-3', 10, 10, 600, 400);
dataChart3.setChartConfig({
    tableName: 'Sales',
    config: {
        header: {
            title: '堆叠面积图',
        },
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.stackedArea,
            encodings: {
                category: {
                    field: 'Salesman',
                },
                color: {
                    field: 'Product',
                },
                values: [
                    {
                        field: 'Sales',
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum,
                    },
                ],
                filter: {
                    operate: GC.Spread.Sheets.DataCharts.LogicalOperation.and,
                    conditions: [
                        {
                            field: 'Region',
                            excludeMatched: false,
                            operate: GC.Spread.Sheets.DataCharts.ComparisonOperator.in,
                            value: ['North'],
                        },
                    ],
                },
            },
            config: {
                axisMode: GC.Spread.Sheets.DataCharts.AxisMode.cartesian,
            },
        },
    ],
});
```

## 百分比堆叠面积图

百分比堆叠面积图融合了堆叠面积图的特性，同时以百分比形式展示数据。图表中整块区域代表单个分类或时段的总数值，区域内各个分段则展示各子类别数值占整体的百分比比例。
该图表常用于对比不同分类、不同时段的数据总体规模，也可直观分析各类别数据的占比构成。以百分比形式呈现数据，能够便捷地横向对比各子项在不同维度中的相对贡献大小。
百分比堆叠面积图效果如下所示：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260525.727aa3.png)
参考下方示例代码添加百分比堆叠面积图。

```javascript
// 百分比堆叠面积图
const sheet = spread.getActiveSheet();
sheet.name('百分比堆叠面积图');
const dataChart4 = sheet.dataCharts.add('data-chart-4', 10, 10, 600, 400);
dataChart4.setChartConfig({
    tableName: 'Sales',
    config: {
        header: {
            title: '百分比堆叠面积图',
        },
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.percentStackedArea,
            encodings: {
                category: {
                    field: 'Salesman',
                },
                color: {
                    field: 'Product',
                },
                values: [
                    {
                        field: 'Sales',
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum,
                    },
                ],
                filter: {
                    operate: GC.Spread.Sheets.DataCharts.LogicalOperation.and,
                    conditions: [
                        {
                            field: 'Region',
                            excludeMatched: false,
                            operate: GC.Spread.Sheets.DataCharts.ComparisonOperator.in,
                            value: ['North'],
                        },
                    ],
                },
            },
            config: {
                axisMode: GC.Spread.Sheets.DataCharts.AxisMode.cartesian,
            },
        },
    ],
});
```

### 代码示例

```javascript
dataChart.setChartConfig({
    tableName: 'Sales',
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.area,
            config: {
                lineAspect: GC.Spread.Sheets.DataCharts.LineAspect.Spline,
            },
        },
    ],
});
```

若未指定`lineAspect`属性，或将其赋值为空值、未定义状态，图表将默认采用基础线条样式。
堆叠面积图与百分比堆叠面积图的线条渲染规则，和普通面积图保持一致。
