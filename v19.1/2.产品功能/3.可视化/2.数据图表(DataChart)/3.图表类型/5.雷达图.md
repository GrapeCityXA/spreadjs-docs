# radar-charts

**雷达图**是一种径向图表，用于在不同特征或特性上比较两组或多组数值。这些图表在彼此等距围绕中心排列的单独轴上表示每个变量。这些轴都具有相同的刻度标记和刻度。每个观测值的数据沿这些轴绘制，然后组合形成一个多边形。这种类型的图表通常用于分析绩效或比较诸如收入和支出等数值。
SpreadJS 支持各种类型的雷达图，可通过修改图表属性进行自定义，例如设置调色板、图形不透明度、点符号、类别轴和数值轴样式等。这些修改可以通过代码或使用 SpreadJS 设计器中的 [“检查器”](gcdocsite__documentlink?toc-item-id=55f14079-f4d7-48fe-aebc-ed9390deeb94) 选项卡来完成。

> 本主题中的所有示例均基于 [“创建数据图表”](gcdocsite__documentlink?toc-item-id=83b6d588-0f69-4b37-9a6e-f9aa6a2b714e) 页面中的 “salesTable” 数据。因此，请确保已遵循该页面上提到的添加数据图表的主要步骤。您也可以自定义数据源以满足特定需求。

## 雷达图

雷达图是一种以二维格式显示多元数据的图形方法，其中三个或更多定量变量在从同一点开始的轴上表示。此图表之所以被称为雷达图，是因为连接数据点的线条类似于车轮的辐条或飞机的雷达屏幕。
以下是雷达图的示例图像：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.b57aa6.png)
请参考以下示例代码添加雷达图：

```javascript
// Radar Chart
const sheet = spread.getActiveSheet();
sheet.name("Radar Chart");
const dataChart = sheet.dataCharts.add('data-chart', 10, 10, 600, 400);
dataChart.setChartConfig({
    tableName: 'Sales',
    config: {
        header: {
            title: "Radar Chart"
        }
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.radar,
            encodings: {
                values: [
                    {
                        field: "Sales",
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum
                    }
                ],
                category: {
                    field: "Salesman"
                },
                color: {
                    field: "Product"
                },
                filter: {
                    operate: GC.Spread.Sheets.DataCharts.LogicalOperation.and,
                    conditions: [
                        {
                            field: "Region",
                            excludeMatched: false,
                            operate: GC.Spread.Sheets.DataCharts.ComparisonOperator.in,
                            value: ["East"]
                        }
                    ]
                }
            }
        }
    ]
});
```

## 填充雷达图

填充雷达图是传统雷达图的一种变体，其中数据点所围成的区域被填充以创建一个实心形状。在这种类型的图表中，数据点和中心点之间的空间被着色或阴影处理，以突出显示数据系列所覆盖的区域。
以下是填充雷达图的示例图像：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.5d8c71.png)
请参考以下示例代码添加填充雷达图：

```javascript
// Filled Radar Chart
const sheet = spread.getActiveSheet();
sheet.name("Filled Radar Chart");
const dataChart2 = sheet.dataCharts.add('data-chart-2', 10, 10, 600, 400);
dataChart2.setChartConfig({
     tableName: 'Sales',
     config: {
         header: {
             title: "Filled Radar Chart"
         },
     },
     plots: [
         {
             type: GC.Spread.Sheets.DataCharts.DataChartType.filledRadar,
             encodings: {
                 values: [
                     {
                         field: "Sales",
                         aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum
                     }
                 ],
                 category: {
                     field: "Salesman"
                 },
                 color: {
                     field: "Product"
                 },
                 filter: {
                     operate: GC.Spread.Sheets.DataCharts.LogicalOperation.and,
                     conditions: [
                         {
                             field: "Region",
                             excludeMatched: false,
                             operate: GC.Spread.Sheets.DataCharts.ComparisonOperator.in,
                             value: ["East"]
                         }
                     ]
                 }
             },
         }
     ]
});
```

## 线条样式
雷达图与填充雷达图支持`lineAspect`属性，可控制数据点沿径向轴的连接形式。

|数据类型|默认样式|平滑曲线样式|
| ---- | ---- | ---- |
|雷达图|![雷达图](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/Radar20chart.87092e-20260526.d52a14.png?width=300)<br>|![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260420.025cf7-20260526.b3c1b0.png?width=300)<br>|
|填充雷达图|![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260402.626ec7-20260526.f7d5ae.png?width=300)<br>|![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260420.cb8bb7-20260526.b8ffff.png?width=300)<br>|

若`lineAspect`设置为`null`或`undefined`，图表将按照默认样式进行渲染。

**示例**
```javascript
config: {  
    lineAspect: GC.Spread.Sheets.DataCharts.LineAspect.Spline
}
```
