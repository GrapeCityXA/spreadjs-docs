# funnel-charts

**漏斗图（Funnel Chart）** 是一种可视化工具，用于展示流程的各个阶段，并量化每个阶段中流转的用户或项目数量。它通常呈现出从初始阶段到最终阶段数据量逐渐减少的趋势，形状类似漏斗——顶部宽、底部窄。
借助漏斗图功能，你可以在应用中直观追踪销售漏斗、网站访客转化或招聘流程等数据流，轻松识别各阶段的数据规律或流失节点。
在 SpreadJS 中，你可以通过修改多种属性来添加和自定义漏斗图，包括漏斗类型、调色板、图形透明度、边框样式、画布内边距、顶部宽度、底部宽度、颈部高度、方向、是否反转等。这些调整既可以通过代码编程实现，也可以在 SpreadJS 设计器的“检查器（Inspector）”选项卡中可视化操作，为开发人员和设计人员提供了灵活的配置方式。

## 示例基础代码（Example Foundation）

本文中的所有示例代码均基于下方提供的基础代码构建，其中包含核心变量、数据源等核心配置。你可根据具体业务需求自定义这些配置。

```javascript
// 获取当前活动工作表
const sheet = spread.getActiveSheet();
// 设置工作表名称为“Funnel Chart”（漏斗图）
sheet.name("Funnel Chart");
// 获取数据管理器实例
const dataManager = spread.dataManager();

/**
 * 创建转化数据表
 * @param {object} dataManager - 数据管理器实例
 * @returns {object} 转化数据表
 */
function createConversionTable (dataManager) {
    // 转化流程数据（阶段名称、数量）
    const records = [
        ['访问（Visit）', 5350],
        ['浏览（View）', 3503],
        ['加入购物车（Cart）', 1651],
        ['结账（Checkout）', 916],
        ['支付（Pay）', 587],
    ];
    // 数据表列名
    const columns = ['Stage（阶段）', 'Count（数量）'];

    // 向数据管理器添加“转化（Conversion）”表
    return dataManager.addTable('Conversion', {
        data: records.map(record => {
            const item = {};
            // 映射记录与列名，构建数据表结构
            columns.forEach((column, index) => {
                item[column] = record[index];
            });
            return item;
        })
    });
}

// 创建转化数据表
const ConversionTable = createConversionTable(dataManager);
// 拉取数据表数据（异步操作）
await ConversionTable.fetch();

// 在工作表中添加数据图表：位置（10,10），尺寸（600x400）
const dataChart = sheet.dataCharts.add('data-chart', 10, 10, 600, 400);
```

## 两种数据绑定模式（Two Data Binding Modes）

根据数据绑定配置的不同，漏斗图可分为以下两种类型：

### 类别-值绑定（Category-Value Binding）

这种模式将分类数据（如流程阶段）映射到漏斗的分段，数值数据映射到分段大小。分段通过**顶部宽度**来表示数据，因此漏斗侧边会呈现非平滑效果。
![2.2](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/2.2.9dcc5c.655b4b.png?width=500)
以下示例代码展示如何通过类别-值绑定添加漏斗图：

```javascript
// 类别-值绑定模式的漏斗图
dataChart.setChartConfig({
    tableName: 'Conversion', // 绑定的数据表名称
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.funnel, // 图表类型：漏斗图
            encodings: {
                // 数值绑定：统计“Count”字段的总和
                values: [{ field: 'Count', aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum }],
                // 类别绑定：使用“Stage”字段作为分类
                category: { field: 'Stage' },
            },
        }
    ],
    config: {
        // 图表标题配置
        header: {
            title: "Funnel Chart Using Category-Value Binding（类别-值绑定模式漏斗图）",
            // 标题内边距
            padding: { left: 10, right: 10, top: 10, bottom: 10 },
            // 标题样式
            style: {
                fill: { type: 'CssColor', color: 'rgba(255,255,255,0.9)' }, // 背景色（白色，90%透明度）
                shadow: { blur: 4, color: 'rgba(0,0,0,0.05)' } // 阴影（模糊度4，黑色5%透明度）
            },
            // 标题文本样式
            textStyle: {
                color: 'rgba(30,30,30,1)', // 文本颜色（深灰色）
                fontSize: 24, // 字体大小
                fontFamily: 'Calibri', // 字体
                fontStyle: GC.Spread.Sheets.DataCharts.FontStyle.italic, // 字体样式：斜体
                fontWeight: 'Bold', // 字体粗细：加粗
                alignment: GC.Spread.Sheets.DataCharts.HAlign.left, // 水平对齐：左对齐
            },
        },
        // 绘图区域配置
        plotAreas: [{
            // 图例配置
            legends: [{
                type: GC.Spread.Sheets.DataCharts.LegendType.color, // 图例类型：颜色图例
                // 图例文本样式
                textStyle: {
                    fontFamily: 'Calibri',
                    fontSize: 18,
                    fontStyle: GC.Spread.Sheets.DataCharts.FontStyle.italic,
                    fontWeight: 'Bold',
                },
            }],
        }],
    },
});
```

### 详情-值绑定（Detail-Value Binding）

这种模式将详细数据字段（如子阶段指标）绑定到分段属性，同时保留数值数据用于表示分段大小。分段通过**高度**来表示数据，整体形状由特定的宽度和高度选项决定，因此漏斗侧边会呈现平滑效果。
![2.3](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/2.3.918710.54868a.png?width=500)
以下示例代码展示如何通过详情-值绑定添加漏斗图：

```javascript
// 详情-值绑定模式的漏斗图
dataChart.setChartConfig({
    tableName: 'Conversion', // 绑定的数据表名称
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.funnel, // 图表类型：漏斗图
            encodings: {
                // 数值绑定：统计“Count”字段的总和
                values: [{ field: 'Count', aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum }],
                // 详情绑定：使用“Stage”字段作为详情
                details: [{ field: 'Stage' }],
            },
        }
    ],
    config: {
        // 图表标题配置（与类别-值绑定模式一致）
        header: {
            title: "Funnel Chart Using Detail-Value Binding（详情-值绑定模式漏斗图）",
            padding: { left: 10, right: 10, top: 10, bottom: 10 },
            style: {
                fill: { type: 'CssColor', color: 'rgba(255,255,255,0.9)' },
                shadow: { blur: 4, color: 'rgba(0,0,0,0.05)' }
            },
            textStyle: {
                color: 'rgba(30,30,30,1)',
                fontSize: 24,
                fontFamily: 'Calibri',
                fontStyle: GC.Spread.Sheets.DataCharts.FontStyle.italic,
                fontWeight: 'Bold',
                alignment: GC.Spread.Sheets.DataCharts.HAlign.left,
            },
        },
        // 绘图区域配置（与类别-值绑定模式一致）
        plotAreas: [{
            legends: [{
                type: GC.Spread.Sheets.DataCharts.LegendType.color,
                textStyle: {
                    fontFamily: 'Calibri',
                    fontSize: 18,
                    fontStyle: GC.Spread.Sheets.DataCharts.FontStyle.italic,
                    fontWeight: 'Bold',
                },
            }],
        }],
    },
});
```

>type=info
> **说明：**
> 若用户同时配置了“类别（category）”“详情（detail）”和“值（value）”三种数据绑定，仅“类别-值”绑定会生效。

## 专属配置项（Unique Settings）

漏斗图通过 [plots.config.funnel](gcdocsite__documentlink?toc-item-id=af7d5d1a-e235-45a4-96a2-bc73b710e3ff) 下的专属配置参数，自定义其视觉结构和分析重点。

* `topWidth`（顶部宽度）、`bottomWidth`（底部宽度）、`neckHeight`（颈部高度）等属性定义了漏斗分段的几何比例，可精确控制图表形状，以突出转化趋势或资源分布规律；
* 方向配置（`vertical` 垂直/`horizontal` 水平）和方向调整（`reversed` 反转）可进一步适配不同的数据展示场景；
* `funnelType`（漏斗类型）的不同变体（如梯形、矩形、三角形）扩展了漏斗图的适用范围，可用于销售漏斗、用户流失分析等多种场景。

### 代码实现（Using Code）

以下代码片段将上述属性集成到两个漏斗图配置中，在之前的“类别-值绑定”和“详情-值绑定”基础上，添加了自定义形状和方向设置：

```javascript
// 在工作表中添加两个数据图表（用于对比不同配置）
const dataChart1 = sheet.dataCharts.add('data-chart1', 10, 10, 600, 400);
const dataChart2 = sheet.dataCharts.add('data-chart2', 10, 10, 600, 400);

// 1. 类别-值绑定：水平方向、金字塔类型的漏斗图
dataChart1.setChartConfig({
    tableName: 'Conversion',
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.funnel,
            encodings: {
                values: [{ field: 'Count', aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum }],
                category: { field: 'Stage' },
            },
            config: {
                // 漏斗专属配置
                funnel: {
                    funnelType: GC.Spread.Sheets.DataCharts.FunnelType.pyramid, // 类型：金字塔
                    orientation: GC.Spread.Sheets.DataCharts.Orientation.horizontal, // 方向：水平
                },
                palette: ['#2A5CAA', '#4ECDC4', '#FFD700', '#E63946', '#22B573'], // 调色板
                // 漏斗分段样式
                style: {
                    stroke: { type: 'CssColor', color: '#96CEB4' }, // 边框颜色（淡绿色）
                    strokeWidth: 1, // 边框宽度
                    strokeOpacity: 0.5, // 边框透明度
                },
                // 分段文本配置
                text: [{
                    template: '{valueField.value}', // 文本模板：显示数值
                    position: GC.Spread.Sheets.DataCharts.TextPosition.center, // 文本位置：居中
                    textStyle: {
                        fontFamily: 'Calibri',
                        fontSize: 20,
                        fontWeight: 'Bold',
                        fontStyle: GC.Spread.Sheets.DataCharts.FontStyle.italic,
                        color: 'rgba(51,51,51,1)', // 文本颜色（中灰色）
                    },
                }],
            }
        }
    ],
    config: {
        header: {
            title: "Category-Value Binding: Horizontal Funnel Chart Using Pyramid Type（类别-值绑定：水平金字塔型漏斗图）",
            padding: { left: 10, right: 10, top: 10, bottom: 10 },
            textStyle: {
                color: 'rgba(255,255,255,0.9)', // 文本颜色（白色，90%透明度）
                fontSize: 24,
                fontFamily: 'Calibri',
                fontStyle: GC.Spread.Sheets.DataCharts.FontStyle.italic,
                fontWeight: 'Bold',
                alignment: GC.Spread.Sheets.DataCharts.HAlign.left,
            },
        },
        plotAreas: [{
            padding: { left: 40, right: 40, top: 40, bottom: 40 }, // 绘图区域内边距
            legends: [{
                type: GC.Spread.Sheets.DataCharts.LegendType.color,
                position: GC.Spread.Sheets.DataCharts.LegendPosition.bottom, // 图例位置：底部
                hAlign: GC.Spread.Sheets.DataCharts.HAlign.center, // 图例水平对齐：居中
                textStyle: {
                    fontFamily: 'Calibri',
                    fontSize: 18,
                    fontStyle: GC.Spread.Sheets.DataCharts.FontStyle.italic,
                    fontWeight: 'Bold',
                    color: 'rgba(255,255,255,1)' // 图例文本颜色（白色）
                },
            }],
        }],
        // 数据视图样式
        dvStyle: {
            fill: { type: 'CssColor', color: 'black' }, // 背景色：黑色
            stroke: { type: 'CssColor', color: 'grey' }, // 边框色：灰色
            strokeWidth: 2, // 边框宽度：2px
        },
    },
});

// 2. 详情-值绑定：反转、自定义尺寸的漏斗图
dataChart2.setChartConfig({
    tableName: 'Conversion',
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.funnel,
            encodings: {
                values: [{ field: 'Count', aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum }],
                details: [{ field: 'Stage' }],
            },
            config: {
                // 漏斗专属配置（自定义尺寸+反转）
                funnel: {
                    bottomWidth: 0.4, // 底部宽度：40%
                    neckHeight: 0.4, // 颈部高度：40%
                    topWidth: 0.8, // 顶部宽度：80%
                    reversed: true, // 启用反转
                },
                palette: ['#2A5CAA', '#4ECDC4', '#FFD700', '#E63946', '#22B573'], // 与上方一致的调色板
                // 漏斗分段样式（与上方一致）
                style: {
                    stroke: { type: 'CssColor', color: '#96CEB4' },
                    strokeWidth: 1,
                    strokeOpacity: 0.5,
                },
                // 分段文本配置（与上方一致）
                text: [{
                    template: '{valueField.value}',
                    position: GC.Spread.Sheets.DataCharts.TextPosition.center,
                    textStyle: {
                        fontFamily: 'Calibri',
                        fontSize: 20,
                        fontWeight: 'Bold',
                        fontStyle: GC.Spread.Sheets.DataCharts.FontStyle.italic,
                        color: 'rgba(51,51,51,1)',
                    },
                }],
            }
        }
    ],
    config: {
        header: {
            title: "Detail-Value Binding: Reversed Funnel Chart with Custom Size（详情-值绑定：反转+自定义尺寸漏斗图）",
            padding: { left: 10, right: 10, top: 10, bottom: 10 },
            textStyle: {
                color: 'rgba(255,255,255,0.9)',
                fontSize: 24,
                fontFamily: 'Calibri',
                fontStyle: GC.Spread.Sheets.DataCharts.FontStyle.italic,
                fontWeight: 'Bold',
                alignment: GC.Spread.Sheets.DataCharts.HAlign.left,
            },
        },
        plotAreas: [{
            padding: { left: 40, right: 40, top: 40, bottom: 40 },
            legends: [{
                type: GC.Spread.Sheets.DataCharts.LegendType.color,
                textStyle: {
                    fontFamily: 'Calibri',
                    fontSize: 18,
                    fontStyle: GC.Spread.Sheets.DataCharts.FontStyle.italic,
                    fontWeight: 'Bold',
                    color: 'rgba(255,255,255,1)'
                },
            }],
        }],
        // 数据视图样式（简化版）
        dvStyle: {
            fill: { type: 'CssColor', color: 'black' },
        },
    },
});
```
