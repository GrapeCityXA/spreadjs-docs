# column-charts

**柱形图**是一种通过垂直条形比较分类数据的有用方式。在这些图表中，类别在x轴上绘制，数据值在垂直轴上显示。当值的数量过多，不适合在x轴上使用时，柱形图特别有帮助。例如，全球不同国家的人口占比可以用柱形图来表示。
SpreadJS支持各种类型的柱形图，你可以通过修改图表属性进行自定义，如设置颜色方案、图形透明度、边框样式、圆角半径等，既可以通过代码进行，也可以使用SpreadJS设计器中的[检查器选项](gcdocsite__documentlink?toc-item-id=55f14079-f4d7-48fe-aebc-ed9390deeb94)卡进行。

>type=info
> **备注：**
>
> * 本章节所有示例均使用[创建数据图表](gcdocsite__documentlink?toc-item-id=83b6d588-0f69-4b37-9a6e-f9aa6a2b714e)章节中介绍的`Sales`数据表。添加图表前请确保已完成数据源配置。
> * 类目与数值映射的相关详情，可参考[绑定数据源](gcdocsite__documentlink?toc-item-id=33cc65bd-869c-430b-9223-e86966d31a68)章节。

## 柱形图

柱形图是一种常见的数据可视化工具，用于比较不同类别或显示随时间变化的趋势。它由垂直条形组成，每个条形的高度代表相应类别的值，这使得数据点之间的比较变得直接。
以下是柱形图的示例图像：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.25ebcd.png)
请参考以下示例代码来添加柱形图。

```javascript
// Column Chart
const sheet = spread.getActiveSheet();
sheet.name("Column Chart");
const dataChart = sheet.dataCharts.add('data-chart', 10, 10, 600, 400, GC.Spread.Sheets.DataCharts.DataChartType.column);
dataChart.setChartConfig({
    tableName: 'Sales',
    config: {
        header: {
            title: "Column Chart"
        }
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.column,
            encodings: {
                values: [
                    {
                        field: "Sales",
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum
                    }
                ],
                category: {
                    field: "Product"
                },
                color: {
                    field: "Product"
                }
            }
        }
    ]
});
```

### 分层类别柱状图

柱状图支持分层类别结构。
可在类别编码中设置多个分组层级。
下方示例展示按年份→季度→月份分组的柱状图。
![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260420.ea11f8-20260525.60faaf.png?width=550)

```javascript
// 分层类别柱状图
const sheet = spread.getActiveSheet();
sheet.name('分层柱状图');
const dataChart = sheet.dataCharts.add('分层数据图表', 10, 10, 600, 400, GC.Spread.Sheets.DataCharts.DataChartType.column);
dataChart.setChartConfig({
    tableName: '分层销售数据',
    config: {
        header: {
            title: '分层类别柱状图',
        },
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.column,
            encodings: {
                values: [
                    {
                        field: '销售额',
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum,
                    },
                ],
                category: {
                    field: '年份',
                    child: {
                        field: '季度',
                        child: {
                            field: '月份',
                        },
                    },
                },
            },
        },
    ],
});
```

## 区间柱形图

区间柱形图显示数据范围而不是单个数据点。在这种图表中，每根柱子代表一个值范围，显示为一个带有起点和终点的垂直条形，表示该范围内的最小值和最大值。
这种类型的图表适用于可视化范围内确切值重要的数据。它们在比较类别或时间段的范围时非常有效，并且通常用于金融、统计和项目管理中，以显示如最高和最低值、目标范围或置信区间等数据。
以下是区间柱形图的示例图像：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.ad76f1.png)
请参考以下示例代码来添加区间柱形图。

```javascript
// Range Column Chart
const sheet = spread.getActiveSheet();
sheet.name("Range Column Chart");
const dataChart2 = sheet.dataCharts.add('data-chart-2', 10, 10, 600, 400, GC.Spread.Sheets.DataCharts.DataChartType.column);
dataChart2.setChartConfig({
    tableName: 'Sales',
    config: {
        header: {
            title: "Range Column Chart"
        }
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.rangeColumn,
            encodings: {
                values: [
                    {
                        field: "Sales",
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum
                    },
                    {
                        field: "Return",
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum
                    }
                ],
                category: {
                    field: "Product"
                },
                color: {
                    field: "Product"
                }
            }

        }
    ]
});
```

## 堆积柱形图

堆积柱形图显示并比较不同类别的总大小，同时也显示每个类别作为整体一部分的构成。在这种图表中，每根柱子代表一个类别，不同的数据系列堆叠在一起。每根柱子的高度显示该类别的总值，而各部分显示每个子类别对该总值的贡献。堆积柱形图适用于显示单项与总项之间的关系，同时也便于比较每个总值的大小以及每个总值中子类别的相对比例。
以下是堆积柱形图的示例图像：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.e54454.png)
请参考以下示例代码来添加堆积柱形图。

```javascript
// Stacked Column Chart
const sheet = spread.getActiveSheet();
sheet.name("Stacked Column Chart");
const dataChart3 = sheet.dataCharts.add('data-chart-3', 10, 10, 600, 400, GC.Spread.Sheets.DataCharts.DataChartType.column);
dataChart3.setChartConfig({
    tableName: 'Sales',
    config: {
        header: {
            title: 'Stacked Column Chart'
        }
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.stackedColumn,
            encodings: {
                values: [{ field: 'Sales', aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum }],
                category: { field: 'Region' },
                color: { field: 'Product' },
            }
        }
    ]
});
```

## 百分比堆积柱形图

百分比堆积柱形图与普通堆叠柱形图类似，但以百分比形式显示数据。在这种图表中，每根柱子的高度代表该类别的总值，而柱子内的各个部分显示每个子类别占总值的百分比。
百分比堆积柱形图有助于比较不同类别的总大小，同时也了解每个类别在百分比方面的相对分布或构成。这种类型的图表通过允许轻松比较不同类别中不同子类别的相对贡献，提供了数据整体分布的更清晰画面。
以下是百分比堆积柱形图的示例图像：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.5b1409.png)
请参考以下示例代码来添加百分比堆积柱形图。

```javascript
// Percent Stacked Column Chart
const sheet = spread.getActiveSheet();
sheet.name("Percent Stacked Column Chart");
const dataChart4 = sheet.dataCharts.add('data-chart-3', 10, 10, 600, 400, GC.Spread.Sheets.DataCharts.DataChartType.column);
dataChart4.setChartConfig({
    tableName: 'Sales',
    config: {
        header: {
            title: 'Percent Stacked Column Chart'
        }
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.percentStackedColumn,

            encodings: {
                values: [{ field: 'Sales', aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum }],
                category: { field: 'Region' },
                color: { field: 'Product' },
            }
        }
    ]
});
```
