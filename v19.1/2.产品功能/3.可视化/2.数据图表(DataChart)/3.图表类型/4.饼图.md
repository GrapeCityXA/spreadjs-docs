# pie-charts

**饼图**是一种圆形图表，通过扇形或切片来展示每个类别的比例贡献。这些图表用于绘制具有非零正值的单个数据系列。
SpreadJS 支持不同类型的饼图变体，您可以通过修改图表属性（如调色板、图形不透明度、起始角度、半径、扇形角度等）进行自定义。这种自定义可以通过代码或使用 SpreadJS 设计器中的[ “检查器” ](gcdocsite__documentlink?toc-item-id=55f14079-f4d7-48fe-aebc-ed9390deeb94)选项卡来完成。

> 本主题中的所有示例均基于 [“创建数据图表”](gcdocsite__documentlink?toc-item-id=83b6d588-0f69-4b37-9a6e-f9aa6a2b714e) 页面中的 “salesTable” 数据。因此，请确保您已按照该页面上提到的主要步骤添加数据图表。您也可以自定义数据源以满足特定需求。

## 饼图

饼图是一种圆形统计图形，被分割成多个扇形以说明数值比例。每个扇形代表整体的一部分，其大小与所代表的数量成比例。
如下所示为饼图示例：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.3ec635.png)
以下是添加饼图的示例代码：

```javascript
// Pie Chart
const sheet = spread.getActiveSheet();
sheet.name("Pie Chart");
const dataChart = sheet.dataCharts.add('data-chart', 10, 10, 600, 400);
dataChart.setChartConfig({
    tableName: 'Sales',
    config: {
        header: {
            title: "Pie Chart"
        }
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.pie,
            encodings: {
                values: [
                    {
                        field: "Sales",
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum
                    }
                ],
                color: {
                    field: "Product"
                },
            },
            config: {
                axisMode: GC.Spread.Sheets.DataCharts.AxisMode.radial,
                innerRadius: 0
            }
        }
    ]
});
```

## 圆环图

圆环图是饼图的一种变体，其图表中心被移除，在中间形成一个 “洞”，类似圆环。这种类型的图表以环形显示数据，每个环代表一个数据系列。与饼图一样，每个环的大小与其所代表的数据成比例。
如下所示为圆环图示例：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.2b2832.png)
以下是添加圆环图的示例代码：

```javascript
// Donut Chart
const sheet = spread.getActiveSheet();
sheet.name("Donut Chart");
const dataChart2 = sheet.dataCharts.add('data-chart-2', 10, 10, 600, 400);
dataChart2.setChartConfig({
    tableName: 'Sales',
    config: {
        header: {
            title: "Donut Chart"
        }
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.donut,
            encodings: {
                values: [
                    {
                        field: "Sales",
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum
                    }
                ],
                color: {
                    field: "Product"
                },
            },
            config: {
                axisMode: GC.Spread.Sheets.DataCharts.AxisMode.radial,
                innerRadius: 0.6
            }
        }
    ]
});
```

## 玫瑰图

玫瑰图是一种以圆形格式显示数据的数据可视化技术。它类似于饼图，但每个扇形从中心开始以圆形方式向外延伸，而不是围绕一个公共点居中。在玫瑰图中，每个 “花瓣” 或线段的长度代表特定类别或数据点的变量值。每个线段围绕图表中心的角度通常用于表示不同的类别或组，便于识别相似数据之间的差异。
如下所示为玫瑰图示例：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.4e9415.png)
以下是添加玫瑰图的示例代码：

```javascript
// Rose Chart
const sheet = spread.getActiveSheet();
sheet.name("Rose Chart");
const dataChart3 = sheet.dataCharts.add('data-chart-3', 10, 10, 600, 400);
dataChart3.setChartConfig({
    tableName: 'Sales',
    config: {
        header: {
            title: "Rose Chart"
        }
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.rose,
            encodings: {
                category: {
                    field: "Salesman"
                },
                values: [
                    {
                        field: "Sales",
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum
                    }
                ],
                filter: {
                    operate: GC.Spread.Sheets.DataCharts.LogicalOperation.and,
                    conditions: [
                        {
                            field: "Region",
                            excludeMatched: false,
                            operate: GC.Spread.Sheets.DataCharts.ComparisonOperator.in,
                            value: ["East"]
                        }
                    ]
                }
            },
            config: {
                axisMode: GC.Spread.Sheets.DataCharts.AxisMode.radial,
                innerRadius: 0.25
            }
        }
    ]
});
```

## 极坐标放射堆积柱状图

极坐标放射堆积柱状图结合了堆积柱状图和饼图的元素。在这种图表类型中，数据以类似于饼图的圆形格式表示，但各部分是沿径向堆积而不是并排显示。
如下所示为极坐标放射堆积柱状图示例：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.a30317.png)
以下是添加极坐标放射堆积柱状图的示例代码：

```javascript
// Radial Stacked Bar Chart
const sheet = spread.getActiveSheet();

const dataChart = sheet.dataCharts.add('data-chart', 10, 10, 600, 400);
dataChart.setChartConfig({
    tableName: 'Sales',
    config: {
        header: {
            title: "Radial Stacked Bar Chart"
        }
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.radialStackedBar,
            encodings: {
                category: {
                    field: "Salesman"
                },
                details: [{
                    field: "Product"
                }],
                values: [
                    {
                        field: "Sales",
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum
                    }
                ],
                filter: {
                    operate: GC.Spread.Sheets.DataCharts.LogicalOperation.and,
                    conditions: [
                        {
                            field: "Region",
                            excludeMatched: false,
                            operate: GC.Spread.Sheets.DataCharts.ComparisonOperator.in,
                            value: ["East"]
                        }
                    ]
                }
            },
            config: {
                axisMode: GC.Spread.Sheets.DataCharts.AxisMode.radial
            }
        }
    ]
});
```

## 旭日图

旭日图以圆形形式表示层次结构数据。它类似于多级饼图，但层次结构由同心圆表示。每个环对应于层次结构中的不同级别。最内层的圆代表层次结构的顶级，后续的环显示子类别或子级别。
如下所示为旭日图示例：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.3ca877.png)
以下是添加旭日图的示例代码：

```javascript
// Sunburst Chart
const sheet = spread.getActiveSheet();
sheet.name("Sunburst Chart");
const dataChart2 = sheet.dataCharts.add('data-chart-2', 10, 10, 600, 400);
dataChart2.setChartConfig({
    tableName: 'Sales',
    config: {
        header: {
            title: "Sunburst Chart"
        }
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.sunburst,
            encodings: {
                details: [
                    {
                        field: "Region"
                    },
                    {
                        field: "Salesman"
                    }
                ],
                values: [
                    {
                        field: "Return",
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum
                    }
                ]
            },
            config: {
                axisMode: GC.Spread.Sheets.DataCharts.AxisMode.radial
            }
        }
    ]
});
```

## 极坐标柱状图

极坐标柱状图使用从中心点向外辐射的柱形来表示数据。与使用直角坐标的传统柱状图不同（在直角坐标中，柱形沿水平或垂直轴对齐），极坐标柱状图将柱形围绕中心点放置在不同角度。
如下所示为极坐标柱状图示例：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.f23661.png)

dataChart.setChartConfig({

    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.polarCoordinatesBar,

                category: {

                    field: "Product"
