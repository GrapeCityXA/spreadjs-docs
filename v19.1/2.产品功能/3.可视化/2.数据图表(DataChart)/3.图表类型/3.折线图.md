# line-charts

**折线图**通过线条连接数据点，展示数值随类别或时间产生的变化。这类图表常用来呈现业务、财务及运营数据中的趋势、波动与数值走向。
开发者可借助代码，或是在SpreadJS设计器的检查面板中修改配色方案、线条粗细、标记样式、提示框外观、坐标轴样式等参数，自定义折线图样式。

>type=info
> **注释**：本文示例均采用绑定数据源章节中介绍的销售数据表。添加图表前，请先完成数据源配置。

## 折线图

基础折线图可展示各类别下的汇总数值，将各个数据点相连，直观呈现整体变化趋势。
![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260420.80667b-20260525.46d1b3.png?width=550)

```javascript
// 折线图
const sheet = spread.getActiveSheet();
sheet.name('折线图');
const dataChart = sheet.dataCharts.add('数据图表', 10, 10, 600, 400);
dataChart.setChartConfig({
    tableName: '销售表',
    config: {
        header: {
            title: '折线图',
        },
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.line,
            encodings: {
                category: { field: '产品' },
                color: { field: '区域' },
                values: [
                    {
                        field: '销售额',
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum,
                    },
                ],
            },
            config: {
                axisMode: GC.Spread.Sheets.DataCharts.AxisMode.cartesian,
            },
        },
    ],
});
```

### 层级类别折线图

折线图支持层级化的类别分组展示。

```javascript
category: {
  field: "ProductCategory",
  child: {
    field: "Product"
  }
}
```

嵌套层级决定数据分组的层级结构。

}

## 标记与线条样式

可自定义折线粗细以及数据标记的外观样式。

```javascript
config: {
  style: {
    strokeWidth: 2,
    symbolShape: GC.Spread.Sheets.DataCharts.SymbolShape.dot,
    symbolSize: 10
  },
  symbols: true
}
```

* `strokeWidth`：设置线条粗细
* `symbolShape`：设定数据标记形状
* `symbolSize`：调整数据标记尺寸
* `symbols`：开启或关闭标记显示

## 配色方案

`palette`属性用于设定多组数据系列依次使用的颜色序列。

```javascript
config: {
    palette: ['#88bde6', '#fbb258', '#90cd97', '#f6aac9', '#bfa554', '#bc99c7'];
}
```

配色会按照列表顺序依次应用到各个数据系列中。
