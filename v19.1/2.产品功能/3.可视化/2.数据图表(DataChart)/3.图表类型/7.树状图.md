# treemap-charts

树形图通过嵌套矩形展示层级数据。

* 每个矩形代表层级中的一个节点。
* 矩形尺寸由数值大小决定。
* 层级结构由明细编码中的多个字段定义。

树形图能够以紧凑的布局，对比不同层级分类间的占比关系。

## 数据结构要求

创建树形图需满足以下条件：

* 数值字段存放于数值项中，用于判定矩形大小。
* 一个或多个分类字段存放于明细项中，用以划分层级。

当明细项配置多个字段时，将按照字段顺序构建层级关系：

```javascript
details: [{ field: 'Category' }, { field: 'Subcategory' }, { field: 'Product' }];
```

* 分类 → 顶层分组
* 子分类 → 隶属于对应顶层分类
* 产品 → 末端子节点

默认状态下，仅末端节点会渲染为可见矩形。

## 示例数据

```javascript
const dataManager = spread.dataManager();
function createTreemapTable(dataManager) {
    const records = [
        ['饮品', '果汁', '苹果汁', 420],
        ['饮品', '果汁', '橙汁', 680],
        ['饮品', '乳制品', '牛奶', 950],
        ['零食', '巧克力', '黑巧克力', 530],
        ['零食', '巧克力', '牛奶巧克力', 610],
        ['零食', '肉制品', '牛肉干', 720],
        ['零食', '薯片', '土豆片', 480],
        ['零食', '薯片', '玉米片', 390],
    ];
    const columns = ['Category', 'Subcategory', 'Product', 'Sales'];
    return dataManager.addTable('TreemapData', {
        data: records.map((x) => {
            const record = {};
            columns.forEach((c, i) => (record[c] = x[i]));
            return record;
        }),
    });
}
const TreemapData = createTreemapTable(dataManager);
await TreemapData.fetch();
```

## 绘制树形图

```javascript
const sheet = spread.getActiveSheet();
sheet.name('树形图');
const dataChart = sheet.dataCharts.add('data-chart', 10, 10, 600, 400);
dataChart.setChartConfig({
    tableName: 'TreemapData',
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.treemap,
            encodings: {
                values: [
                    {
                        field: 'Sales',
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum,
                    },
                ],
                details: [{ field: 'Category' }, { field: 'Subcategory' }, { field: 'Product' }],
            },
        },
    ],
    config: {
        header: {
            title: '树形图',
            textStyle: {
                fontSize: 18,
                fontWeight: 'Bold',
            },
        },
    },
});
```

## 自定义末端节点标签

可借助绘图配置里的文本设置，在末端节点内部展示文字内容。

```javascript
config: {
    text: [
        {
            template: '{detailFields.value}',
        },
    ];
}
```

**完整示例代码**

```javascript
dataChart.setChartConfig({
    tableName: 'TreemapData',
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.treemap,
            encodings: {
                values: [
                    {
                        field: 'Sales',
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum,
                    },
                ],
                details: [{ field: 'Category' }, { field: 'Subcategory' }, { field: 'Product' }],
            },
            config: {
                text: [
                    {
                        template: '{detailFields.value}',
                    },
                ],
            },
        },
    ],
    config: {
        header: {
            title: '树形图',
            textStyle: {
                fontSize: 18,
                fontWeight: 'Bold',
            },
        },
    },
});
```

该配置仅对末端节点生效。

## 显示非末端节点标题

若明细项中定义了多层级结构，可开启树形图标题功能展示非末端节点。
文本配置仅作用于末端节点，而树形图标题专门用于渲染非末端节点。

### 开启树形图标题

在绘图配置的树形图参数中设置标题选项：

```javascript
config: {
  treemap: {
    header: {
      template: '{detailFields.value}',
    textStyle: {
      fontSize: 14,
      fontWeight: 'Bold'
    }
    }
  }
}
```

**完整示例代码**

```auto
dataChart.setChartConfig({
    tableName: 'TreemapData',
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.treemap,
            encodings: {
                values: [
                    {
                        field: 'Sales',
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum,
                    },
                ],
                details: [{ field: 'Category' }, { field: 'Subcategory' }, { field: 'Product' }],
            },
            config: {
                text: [
                    {
                        template: '{detailFields.value}',
                    },
                ],
                treemap: {
                    header: {
                        template: '{detailFields.value}',
                        textStyle: {
                            fontSize: 14,
                            fontWeight: 'Bold',
                        },
                    },
                },
            },
        },
    ],
    config: {
        header: {
            title: '树形图',
            textStyle: {
                fontSize: 18,
                fontWeight: 'Bold',
            },
        },
    },
});
```

未设置模板或模板内容为空时，不会展示节点标题。

### 标题展示规则

* 标题会占用节点内部空间。
* 子层级内容在剩余区域排布。
* 标题尺寸会自适应文字内容。
* 标题尺寸超出所属矩形范围时，标题不予显示。

## 使用限制

* 不支持悬浮动画效果。
* 树形图标题无法应用文字样式中的对齐与溢出属性。
* 标题文本内不允许使用换行符。
