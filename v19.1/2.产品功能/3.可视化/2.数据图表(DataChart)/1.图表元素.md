# data-chart-elements

数据图表是展示数据的强大工具。每个图表都由多个元素组成，这些元素可以单独设置格式，以创建具有自定义布局的图表。在数据图表中配置这些元素不仅能以有意义的方式呈现信息，还能清晰地展示对比和趋势，实现高级数据可视化和分析。
下面的图片展示了一个包含主要数据图表元素的基本图表。
![DataChart Components.81b85a](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/DataChart%20Components.81b85a.fde841.png)
以下各部分将解释数据图表的各种元素及其格式设置选项：

| 元素 | 描述 |
| --- | --- |
| [标题](gcdocsite__documentlink?toc-item-id=fb3e2729-5431-4ff7-8cde-f01efdb1b785)（Header） | 代表图表的标题。 |
| [坐标轴](gcdocsite__documentlink?toc-item-id=a21e02eb-47c0-4e04-bcdb-b839c3de43f1)（Axes） | 代表用于绘制图表趋势的标尺。在某些类型的数据图表中，坐标轴分为数值轴（Y 轴）和类别轴（X 轴）。然而，有些数据图表可能根本不包含坐标轴，例如饼图和圆环图。 |
| [图例](gcdocsite__documentlink?toc-item-id=ea50d6ec-e3d5-4c7b-9576-76b6d66c139a)（Legend） | 代表数据每个系列的标识符。 |
| [数据标签](gcdocsite__documentlink?toc-item-id=3aaf976b-8ad6-491e-90af-485b9a523fb6)（Data Label） | 代表图表上的相关信息，它直接在数据点上显示特定的值或信息，使用户无需查看坐标轴或提示信息就能快速识别和理解关键信息。 |
| [提示信息](gcdocsite__documentlink?toc-item-id=bcaa9cbb-3f24-43b5-bc92-8e6061d682bb)（Tooltip） | 代表当用户将鼠标悬停在特定数据点上或与之交互时显示的额外信息。它提供精确的值、标签或其他上下文信息，有助于用户更好地理解数据，同时又不会使图表布局杂乱。 |
| [动画效果](gcdocsite__documentlink?toc-item-id=c9499d8b-b31a-43f3-b03a-c9d21e59a5fc)（Animation） | 代表用于增强用户交互体验和提升图表视觉吸引力的样式。 |
