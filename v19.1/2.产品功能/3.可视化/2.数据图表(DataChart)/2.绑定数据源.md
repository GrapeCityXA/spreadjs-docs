# bind-data-source

数据图表必须先连接数据源，才能展示数据。在SpreadJS中，数据通常通过数据管理器统一管理，数据表的创建与维护都在此模块中完成。
若要在数据图表中展示数据，需执行以下两步操作：

1. 将图表与数据表绑定
2. 把数据表字段映射至图表编码

本文档讲解数据绑定的配置方法，以及编码规则如何管控数据可视化效果。

## 将图表绑定数据表

在图表配置中设置`tableName`属性，即可完成单个数据图表与数据表的绑定。

```javascript
dataChart.setChartConfig({  
tableName: 'Sales',  
plots: [...]
});
```

绑定的数据表必须已存在于数据管理器内。
数据图表也可关联多张存在关联关系的数据表，多表绑定需满足以下条件：

* 数据表间的关联关系需在数据管理器中预先定义
* 可通过`数据表名.字段名`的格式引用关联表中的字段

## 编码

编码用于设定数据字段与图表可视化元素的映射规则。
单个绘图区域的编码配置均位于如下路径中：

```javascript
plots[n].encodings
```

编码可管控以下内容：

* 数据聚合计算方式
* 数据分组形式
* 颜色、提示框、筛选条件的应用规则

编码分为三类：

* 数值编码
* 分类编码
* 其他编码

### 数值编码

数值编码指定哪些数值字段将作为指标数据展示，这类数据一般对应图表纵轴。

#### 单字段数值编码

最常用场景为单个数值项绑定一个数据表字段：

```javascript
encodings: {  
values: [    
{      
field: "Sales",      
aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum    
}  
]
}
```

![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260420.52eaa2-20260525.ba5654.png?width=400)

配置多个数值字段时遵循以下规则：

* 每个字段单独作为一组数据系列
* 图例依据数值字段自动生成

饼图、环形图等部分图表仅支持绑定单个数值字段。

#### 多字段数值编码

**支持的图表类型**

* 区间数值图表：
    * 区间柱形图
    * 区间条形图
    * 区间面积图
* 股票数值图表：
    * K线图
    * 开盘最高最低收盘图

部分图表需要多个字段组合，才能表达一项完整业务数值。
举例说明：

* 区间图表需要最小值、最大值两个字段
* K线图与开盘最高最低收盘图需要开盘价、最高价、最低价、收盘价四个字段

此类图表可借助向量结构，将多个字段归集至同一个数值项中。
**区间图示例**

```javascript
encodings: {  
values: [{    
vectors: {      
lower: { field: "Return" },      
upper: { field: "Sales" }    
},    
aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum  
}],  
category: { field: "Product" }
}
```

**股票图示例**

```javascript
encodings: {
```

向量结构使用规范：

* 每个命名向量对应绑定一个数据表字段
* 需按照图表类型补齐全部必填向量字段

沿用旧版独立数值项的配置仍可正常运行，为保证代码清晰统一，推荐使用向量结构编写配置。

>type=info
> **注释：**
> 采用向量结构的图表，必须填写所有必填字段。缺失任一必填向量字段，图表都无法正常渲染。

### 分类编码

分类编码定义数据的维度分组规则，分组维度一般对应图表横轴。

#### 平铺分类

平铺分类仅绑定单个数据表字段：

```javascript
encodings: {  
category: {    
field: "timePeriod"  
}
}
```

![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260417.27b715-20260525.d56de6.png?width=400)

#### 层级分类

层级分类可在单个绘图区域内设置多级分组，适配层级嵌套类数据，常见场景如下：

* 年份→季度→月份
* 地区→国家→城市

通过嵌套子级对象即可定义多层级分组结构。
**示例代码**

```javascript
encodings: {  
values: [{    
field: "Sales",    
aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum  
}],  
category: {    
field: "Year",    
child: {      
field: "Quarter",      
child: {        
field: "Month"      
}    
}  
}
}
```

![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260417.f76f78-20260525.d1caf0.png?width=400)
层级分类核心特性：

* 嵌套层级顺序决定数据分组顺序
* 下级分组基于上级分组进一步细分
* 所有层级统一套用相同的数据聚合规则
* 未设置子级结构时，分类形式等同于平铺分类

| 支持的图表类型 | 不支持的图表类型 |
| ------- | -------- |
| <ul><li>柱形图</li><li>区间柱形图</li><li>堆积柱形图</li><li>百分比堆积柱形图</li><li>条形图</li><li>区间条形图</li><li>堆积条形图</li><li>百分比堆积条形图</li><li>面积图</li><li>区间面积图</li><li>堆积面积图</li><li>百分比堆积面积图</li><li>折线图</li><li>K线图</li><li>开盘最高最低收盘图</li></ul> | <ul><li>饼图</li><li>环形图</li><li>雷达图</li><li>极坐标图</li><li>树形图</li><li>漏斗图</li><li>散点图</li><li>气泡图</li></ul> |

>type=info
> **注释：**
> 所有层级分组会同步展示，层级分类不支持展开、收起以及下钻查看操作。

### 其他编码

* **明细**：将单个分类下的数据再次细分分组，绝大多数图表仅允许设置一个明细字段
* **颜色**：指定字段，依据该字段数值为图形与图例分配对应色彩
* **尺寸**：启用连续尺寸缩放效果，仅气泡图支持该配置
* **提示框**：设定鼠标悬浮弹窗内展示的字段内容
* **筛选**：数据聚合前对原始数据筛选过滤，支持数值、文本筛选以及多层逻辑条件筛选

## 代码使用方式

数据图表依托SpreadJS数据管理器中维护的数据表完成绑定。
配置图表前，需依次完成三项准备操作：

1. 初始化数据管理器
2. 注册数据表
3. 可选操作：定义数据表之间的关联关系

### 第一步 初始化数据管理器

```javascript
const dataManager = spread.dataManager();
```

### 第二步 注册数据表

创建图表前，提前注册所有需要使用的数据表。

```javascript
// 销售数据表
const salesTable = createSalesTable(dataManager);
await salesTable.fetch();
// 订单数据表
const ordersTable = createOrders(dataManager);
await ordersTable.fetch();
// 订单明细数据表
const orderDetailsTable = createOrderDetails(dataManager);
await orderDetailsTable.fetch();
// 层级销售数据表（用于层级分类示例）
const hierarchySalesTable = createHierarchySalesTable(dataManager);
await hierarchySalesTable.fetch();
```

### 第三步 定义数据表关联关系（可选）

多表绑定场景下，必须预先建立数据表间的关联关系。

```javascript
dataManager.addRelationship(    
ordersTable, "orderId",    
"orderDetailsTable",    
orderDetailsTable, "OrderId",    
"ordersTable"
);
```

### 第四步 基础数据绑定示例

下述示例将柱形图绑定至销售数据表。

```javascript
const sheet = spread.getSheet(0);
sheet.name('绑定数据');
const dataChart = sheet.dataCharts.add('data-chart', 10, 10, 600, 400);
dataChart.setChartConfig({
    tableName: 'Sales',
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.column,
            encodings: {
                values: [
                    {
                        field: 'Sales',
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum,
                    },
                ],
                category: {
                    field: 'Product',
                },
            },
        },
    ],
    config: {
        header: {
            title: '各产品销售额',
        },
    },
});
```

### 第五步 多数据表绑定

数据表建立关联后，可通过路径表达式调用关联表内的字段。
该示例以订单数据表为主体，调取关联订单明细表的数据完成聚合统计。

```javascript
let sheet2 = spread.getSheet(1);
sheet2.name('多表绑定');
const dataChart2 = sheet2.dataCharts.add('data-chart-2', 10, 10, 600, 400);
dataChart2.setChartConfig({
    tableName: 'Orders',
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.column,
            encodings: {
                values: [
                    {
                        field: 'orderDetailsTable.Sales',
                    },
                ],
                category: {
                    field: 'shipCountry',
                },
            },
        },
    ],
    config: {
        header: {
            title: '各国销售额（多数据表）',
        },
    },
});
```

### 第六步 层级分类绑定

在分类编码中嵌套子级字段，即可实现图表多级分组展示。
以下示例制作年份、季度、月份三级分组的柱形图。

```javascript
let sheet3 = spread.getSheet(2);
sheet3.name('层级分类绑定');
const dataChart3 = sheet3.dataCharts.add('data-chart-3', 10, 10, 600, 400);
dataChart3.setChartConfig({
    tableName: 'HierarchySales',
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.column,
            encodings: {
                values: [
                    {
                        field: 'sales',
                    },
                ],
                category: {
                    field: 'year',
                    child: {
                        field: 'quarter',
                        child: {
                            field: 'month',
                        },
                    },
                },
            },
        },
    ],
    config: {
        header: {
            title: '层级柱形图',
        },
    },
});
```
