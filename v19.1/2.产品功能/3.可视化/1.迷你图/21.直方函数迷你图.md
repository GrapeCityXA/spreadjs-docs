# histogram-sparkline

直方图用于表示数据集的频率分布。SpreadJS 允许您使用直方图迷你图函数来创建直方图迷你图。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/histogram-label.9f2033.png)
上图展示了一个直方图迷你图及其组成元素：

* **组距（Bin）**：包含指定数值范围内数据的数据容器。
* **条形（Bar）**：负责用户界面显示的绘制块。如果 `paintLabel` 选项为 `true`，则条形的高度由以下表达式确定：
    `(单元格行高 - 标签字体大小 - 6px)`
    否则，由以下表达式确定：
    `(单元格行高 - 6px)`
* **边缘（Edge）**：条形的边框。
    * 如果字体大小大于上述表达式计算的值，则取小于或等于该表达式的最大整数作为字体大小。
    * 如果单元格的高度小于单元格行高，则字体大小为 12px。
* **数据标签（Data Label）**：在迷你图中显示的数据范围。数据标签的字体大小由以下表达式确定：
    `Math.floor(单元格行高/3)`
    * 如果字体大小大于上述表达式计算的值，则取小于或等于该表达式的最大整数作为字体大小。
    * 如果单元格的高度小于单元格行高，则字体大小为 12px。

## 直方图迷你图的类型

直方图迷你图可以像下面这样以离散或连续的方式显示：

| ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/discrete-histogram.40e4ef.png) | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/continuous-histogram.3b49e8.png) |
| --- | --- |
|

**离散型直方图** 通过采用现有数值以离散的方式（没有连续的区间）表示数据。例如：20、34、38。这些数值按升序绘制。
**连续型直方图** 通过采用一系列连续的数值来表示数据。第一个组距的区间是左闭右闭的，而其余组距的区间是左开右闭的。

* 下限使用以下公式计算：
    `Math.floor(最小值/比例)*比例`
    而上限使用以下公式计算：
    `Math.ceil(最大值/比例)*比例`
* 组距的宽度默认值为 1
* 如果比例小于 0，则迷你图设置为 1

直方图的类型可以通过在 `HistogramSparkline` 公式中使用 `continuous` 选项来指定。直方图迷你图公式有以下选项，其中只有 `dataRange` 是必填参数：

| 选项 | 说明 |
| --- | --- |
| **dataRange** | 指定数据源的范围。它支持一个范围。<br>它支持计算数组和计算引用。 |
| **continuous** | 如果设置为 `true`，则迷你图是连续型直方图。<br>如果设置为 `false`，则迷你图是离散型直方图。<br>默认值为 `true`。 |
| **paintLabel** | 如果设置为 `true`，迷你图将绘制数据标签。<br>默认值为 `false`。 |
| **scale** | 指定组距宽度。当直方图类型为连续型时，此值很有用。<br>默认值为 `false`。 |
| **barWidth** | 指定条形宽度。默认值为 1。<br>条形宽度 = 自动计算的宽度 \* barWidth<br>取值范围是 0 < 值 ≤ 1。 |
| **barColor** | 指定条形的颜色。<br>默认值是 `5B9BD5`。<br>支持 CSS 颜色属性。 |
| **labelFontStyle** | 指定数据标签字体的字体样式。<br>默认值是 9pt 字号的 Calibri 字体。<br>支持 CSS 字体属性。它支持 `font-style`（字体风格）、`font-weight`（字体粗细）、`font-size`（字体大小）、`font-family`（字体系列）。 |
| **labelColor** | 指定数据标签字体的颜色。<br>默认值是黑色（#00000）。<br>支持 CSS 颜色字符串。 |
| **edgeColor** | 指定边缘的颜色。<br>默认值是银色（#C0C0C0）。<br>支持 CSS 颜色属性。 |

直方图迷你图公式具有以下语法：
`=HISTOGRAMSPARKLINE(dataRange,continuous?,paintLabel?,scale?,barWidth?,barColor?,labelFontStyle?,labelColor,edgeColor?)`
**注意事项**

* 迷你图的默认内边距是 3px。
* 当自定义字体大小大于单元格行高的三分之一时，`paintLabel` 选项不会绘制数据标签。
* 当任何一个数据标签的宽度大于条形的平均宽度时，数据标签将不会绘制。平均宽度由表达式（单元格宽度/条形数量）确定。
    例如，对于宽度为 100px 的单元格，迷你图中有 5 个条形。条形的平均宽度是 20px。在这个迷你图中，如果任何数据标签的宽度大于 20px，则该数据标签将不会绘制。
* 在数据范围中，任何非数字类型的值将被忽略。
