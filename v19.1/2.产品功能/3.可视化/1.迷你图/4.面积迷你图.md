# sparkarea

通过 **AreaSparkline** 函数可以创建面积函数迷你图。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/sparkarea.png)
AREASPARKLINE函数有以下这些参数：

| **选项** | **描述** |
| --- | --- |
| Points | 单元格区域。 无效的数字将被忽略。 |
| Min | 一个数字，表示迷你图的最小值。 此设置是可选的。 |
| Max | 一个数字，代表迷你图的最大值。 此设置是可选的。 |
| Line1 | 代表水平线垂直位置的数字。 此设置是可选的。 |
| Line2 | 代表第二条水平线的垂直位置的数字。 此设置是可选的。 |
| ColorPositive | 一个字符串，代表正值的区域颜色。 此设置是可选的。 |
| ColorNegative | 一个字符串，代表负值的区域颜色。 此设置是可选的。 |

你可以通过面积函数创建一个面积函数迷你图。比如：

```text
=AREASPARKLINE(points, min, max, line1, line2, colorPositive, colorNegative)
```

下面代码展示了如何创建面积函数迷你图

```JavaScript
activeSheet.addSpan(6, 0, 3, 4);
activeSheet.setValue(0, 0, 10);
activeSheet.setValue(1, 0, 5);
activeSheet.setValue(2, 0, 25);
activeSheet.setValue(3, 0, -5);
activeSheet.setValue(4, 0, 17);
activeSheet.setValue(5, 0, 1);
activeSheet.setFormula(6, 0, '=AREASPARKLINE(A1:A6,-15,15,5,-5,"red","green")');
activeSheet.setColumnWidth(0, 80);
activeSheet.setColumnWidth(1, 80);
activeSheet.setColumnWidth(2, 80);
activeSheet.setColumnWidth(3, 80);
```
