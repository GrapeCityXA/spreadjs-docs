# accessibility-support

SpreadJS 为依赖屏幕阅读器应用程序的用户提供可选的可访问性支持，例如 Windows 讲述人、NVDA（NonVisual Desktop Access）以及 macOS 的 VoiceOver。
具体行为可能因所使用的屏幕阅读器和浏览器组合而异。

## 启用或禁用可访问性

默认情况下，可访问性处于禁用状态。
如果未启用可访问性，屏幕阅读器将不会朗读 SpreadJS 内容。
若要启用可访问性支持，请设置：

```javascript
spread.options.enableAccessibility = true;
```

## 自定义可访问输出

SpreadJS 在不同级别提供替代文本支持。这些机制彼此独立。

### 单元格替代文本

单元格替代文本用于自定义屏幕阅读器朗读单元格的方式。
它不会影响排序、筛选、公式或搜索。
可以使用以下 API 设置或获取单元格替代文本：

* `CellRange.altText()`
* `Worksheet.setAltText()`
* `Worksheet.getAltText()`

示例：

```javascript
activeSheet.getCell(0, 0).altText("设置单元格的替代文本");
console.log(activeSheet.getCell(0, 0).altText());
```

SpreadJS 支持在 `.ssjson` 和 `.sjs` 格式中序列化和反序列化单元格替代文本。
使用 [`StorageType.altText`](gcdocsite__documentlink?toc-item-id=db7d19ea-a2d9-41cf-88d1-703e3f55b29a#alttext) 枚举，可以清除替代文本：

```javascript
activeSheet.clear(0, 0, 3, 3, 
    GC.Spread.Sheets.SheetArea.viewport, 
    GC.Spread.Sheets.StorageType.altText);
```

也可以使用 `CopyToOptions.altText` 复制替代文本。

>type=note
> **限制：** 行、列和工作表级别不支持替代文本。

### 图片、形状和图表的替代文本

对于图片、图表、形状和连接线等图形对象，可以使用 `alt()` 方法设置替代文本。
示例：

```javascript
picture.alt("这是一张芒果图片");
chart.alt("这是一个柱形图");
shape.alt("这是一个云形形状");
```

该替代文本用于可访问性支持。

## 兼容性和限制（参考）

| 屏幕阅读器 | 浏览器 | Tab 键 | 鼠标悬停 | 活动标签页 |
| ----- | --- | ----- | ---- | ----- |
| NVDA (Windows) | Chrome | 支持 | 支持 | 支持 |

| NVDA (Windows) | IE | 不支持 | 不支持 | 不支持 |
| Windows 讲述人 | Chrome | 支持 | 支持 | 不支持 |
| Windows 讲述人 | Firefox | 支持 | 支持 | 不支持 |

| VoiceOver (macOS) | Safari | 有限制地支持 | 有限制地支持 | 不支持 |

### VoiceOver 限制

* 当 `div` 元素包含内容时，VoiceOver 会忽略 `aria-label` 属性。
* VoiceOver 无法识别动态更新的 `aria-label` 属性。
* VoiceOver 无法识别工作表标签栏、滚动条，或图片、图表和形状等图形对象。

### 其他说明

* 行为可能因屏幕阅读器和浏览器而异。
* 基于鼠标或触摸的 UI 操作（例如拖拽填充和筛选）可能难以配合屏幕阅读器使用。
* 可访问性支持提供的是基础功能。
