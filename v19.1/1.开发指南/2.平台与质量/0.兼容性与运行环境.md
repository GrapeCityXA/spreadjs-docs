# system-requirements

本页说明运行和集成 SpreadJS 时需要关注的浏览器、操作系统、JavaScript 框架和渲染方式要求。

## 浏览器

SpreadJS 运行在支持 HTML5 标准的现代浏览器中，包括：

* Microsoft Edge
* Google Chrome
* Mozilla Firefox
* Safari

>type=warning
> 如果浏览器未完整支持 HTML5 标准，SpreadJS 可能无法正常渲染或交互。

## 操作系统

SpreadJS 是浏览器端控件，可在能够运行现代浏览器的操作系统中使用，包括：

* Windows
* macOS
* Linux
* iOS
* iPadOS

在移动端或触屏设备中使用 SpreadJS 时，请同时参考 [移动端与触控](gcdocsite__documentlink?toc-item-id=afe226de-8020-4364-9b0d-6ae503544223)。

## JavaScript 框架

SpreadJS 支持在原生 JavaScript 项目中使用，也提供 Vue、React、Angular 等框架封装组件，并支持 NextJS、NuxtJS 等上层框架集成。

不同框架的安装包、组件写法和初始化方式不同。开始框架集成前，请阅读 [框架集成](gcdocsite__documentlink?toc-item-id=94da5d60-da19-4b25-b2a0-5451a909910b)，并选择与项目技术栈对应的文档。

## 客户端渲染

SpreadJS 依赖浏览器端 API，需要在客户端环境中初始化。

在 NextJS、NuxtJS 等支持服务端渲染的框架中，请在客户端组件、客户端插件或禁用 SSR 的动态组件中创建 SpreadJS 实例，避免在服务端直接访问 `window`、`document` 或 DOM 容器。
