# nuxtjs

本教程将展示如何在 Nuxt 项目中集成 SpreadJS、配置客户端渲染，并可选启用设计器组件（Designer Component）以获得类 Excel 的编辑工具。

## 在 Nuxt 应用中集成 SpreadJS

### 步骤 1：搭建 Nuxt 项目

可使用现有 Nuxt 3 或 Nuxt 4 项目，若需从零开始搭建：

```bash
npm create nuxt@latest nuxt-with-spreadjs
cd nuxt-with-spreadjs
npm install
```

启动项目验证基础环境：

```bash
npm run dev
```

访问 `http://localhost:3000` 确认 Nuxt 基础应用正常运行后，即可开始集成 SpreadJS。

### 步骤 2：安装并配置 SpreadJS

1. **安装 SpreadJS 依赖包**若项目根目录无 `components` 文件夹，先创建该文件夹，再执行安装命令：

    ```bash
    npm install --save @grapecity-software/spread-sheets-vue
    ```
2. **创建 SpreadJS 组件**在 `components` 文件夹中新建 `Spreadsheet.vue` 文件，定义组件如下（可在初始化控件前输入 SpreadJS 许可证密钥）：

    ```html
    <template>
      <div>
        <gc-spread-sheets class="hostClass" @workbookInitialized="initSpread">
          <gc-worksheet> </gc-worksheet>
        </gc-spread-sheets>
      </div>
    </template>
    
    <script setup>
    // 导入 SpreadJS 样式表
    import "@grapecity-software/spread-sheets/styles/gc.spread.sheets.excel2016colorful.css";
    // 导入 SpreadJS Vue 组件
    import { GcSpreadSheets, GcWorksheet } from "@grapecity-software/spread-sheets-vue";
    // 导入 SpreadJS 核心模块
    import * as GC from "@grapecity-software/spread-sheets";
    
    // 示例数据
    var data = [
      {
        jobTitleName: "开发工程师",
        preferredFullName: "罗敏·伊拉尼",
        region: "加利福尼亚州",
        phoneNumber: "408-1234567",
      },
      {
        jobTitleName: "开发工程师",
        preferredFullName: "尼尔·伊拉尼",
        region: "加利福尼亚州",
        phoneNumber: "408-1111111",
      },
      {
        jobTitleName: "项目总监",
        preferredFullName: "汤姆·汉克斯",
        region: "加利福尼亚州",
        phoneNumber: "408-2222222",
      },
    ];
    
    // 工作簿初始化回调函数
    let initSpread = function (spread) {
      var sheet = spread.getSheet(0); // 获取第一个工作表
      sheet.setDataSource(data); // 绑定数据源
    };
    </script>
    
    <style scoped>
    .hostClass {
      width: 600px;
      height: 600px;
    }
    </style>
    ```
3. **在主应用中使用组件**将 `app.vue` 的默认内容替换为：

    ```html
    <template>
      <div>
          <h1>
              在 Jamstack 应用中集成电子表格
          </h1>
          <p>
              Nuxt.JS + SpreadJS 演示
          </p>
          <SpreadSheet /> <!-- 引入 SpreadJS 组件 -->
      </div>
    </template>
    ```
4. **更新 Nuxt 配置（可选）**

    ```javascript
    // https://nuxt.com/docs/api/configuration/nuxt-config
    export default defineNuxtConfig({
      //...
      ssr: false, // 禁用服务端渲染（SpreadJS 依赖客户端 API）
      components: true, // 启用组件自动导入
    })
    ```

> **注意**：
> SpreadJS 依赖浏览器 API，仅支持客户端运行。若 Nuxt 启用 SSR（服务端渲染）模式，需将 SpreadJS 组件包裹在 `<client-only>` 标签中，或注册为客户端专属插件（例如 `plugins/spreadjs.client.ts`）。

### 步骤 3：运行并验证集成效果

```bash
npm run dev
```

访问 `http://localhost:3000`，即可看到 Nuxt 应用中已成功渲染 SpreadJS 组件，展示绑定的数据表格：

### 步骤 4（可选）：添加 SpreadJS 设计器组件

可通过集成设计器组件增强用户界面，获得类 Excel 的格式设置和编辑命令。详细配置指南参考 [SpreadJS 设计器组件文档](gcdocsite__documentlink?toc-item-id=86f33927-2214-4999-aa50-9f52b5d8850a)。

1. **安装设计器相关依赖**

    ```bash
    npm i --save @grapecity-software/spread-sheets @grapecity-software/spread-sheets-barcode @grapecity-software/spread-sheets-charts @grapecity-software/spread-sheets-datacharts-addon @grapecity-software/spread-sheets-designer @grapecity-software/spread-sheets-designer-resources-en @grapecity-software/spread-sheets-designer-vue @grapecity-software/spread-sheets-formula-panel @grapecity-software/spread-sheets-ganttsheet @grapecity-software/spread-sheets-io @grapecity-software/spread-sheets-languagepackages @grapecity-software/spread-sheets-pdf @grapecity-software/spread-sheets-print @grapecity-software/spread-sheets-pivot-addon @grapecity-software/spread-sheets-reportsheet-addon @grapecity-software/spread-sheets-shapes @grapecity-software/spread-sheets-slicers @grapecity-software/spread-sheets-tablesheet
    ```
2. **更新 Spreadsheet.vue 组件**替换为设计器组件配置：

    ```html
    <template>
      <div id="gc-designer-container">
        <gc-spread-sheets-designer
          :styleInfo="styleInfo"
          :config="config"
          :spreadOptions="spreadOptions"
          @designerInitialized="initDesigner"
        />
      </div>
    </template>
    
    <script setup>
    // 导入 SpreadJS 基础样式
    import "@grapecity-software/spread-sheets/styles/gc.spread.sheets.excel2013white.css";
    // 导入设计器样式
    import "@grapecity-software/spread-sheets-designer/styles/gc.spread.sheets.designer.light.min.css";
    
    // 导入 SpreadJS 功能插件
    import "@grapecity-software/spread-sheets-print"; // 打印插件
    import "@grapecity-software/spread-sheets-shapes"; // 形状插件
    import "@grapecity-software/spread-sheets-datacharts-addon"; // 数据图表插件
    import "@grapecity-software/spread-sheets-slicers"; // 切片器插件
    import "@grapecity-software/spread-sheets-pivot-addon"; // 数据透视表插件
    import "@grapecity-software/spread-sheets-tablesheet"; // 集算表插件
    import "@grapecity-software/spread-sheets-ganttsheet"; // 甘特图工作表插件
    import "@grapecity-software/spread-sheets-reportsheet-addon"; // 报表插件
    import "@grapecity-software/spread-sheets-formula-panel"; // 公式面板插件
    import "@grapecity-software/spread-sheets-io"; // 导入导出插件
    import "@grapecity-software/spread-sheets-designer-resources-en"; // 设计器英文资源包
    
    // 导入设计器核心模块
    import * as GCDesigner from "@grapecity-software/spread-sheets-designer";
    import GcSpreadSheetsDesigner from "@grapecity-software/spread-sheets-designer-vue";
    
    // 设计器样式配置
    const styleInfo = { height: "85vh", width: "100%" };
    // 设计器默认配置
    const config = GCDesigner.Spread.Sheets.Designer.DefaultConfig;
    // SpreadJS 初始化选项（设置工作表数量为 2）
    const spreadOptions = { sheetCount: 2 };
    
    // 设计器实例
    let designer = null;
    
    // 设计器初始化回调函数
    function initDesigner(value) {
      designer = value;
      console.log("设计器初始化完成:", designer);
    
      // 获取设计器中的工作簿实例
      const spread = designer.getWorkbook();
      if (spread) {
        const sheet = spread.getSheet(0);
        sheet.setValue(0, 0, "欢迎使用 SpreadJS 设计器！"); // 在单元格(0,0)写入文本
      }
    }
    </script>
    
    <style scoped>
    #gc-designer-container {
      width: 100%;
      height: 100%;
    }
    </style>
    ```
3. **运行并验证设计器功能**

    ```bash
    npm run dev
    ```

访问 `http://localhost:3000`，即可看到集成后的 SpreadJS 设计器，包含完整的类 Excel 工具栏和编辑功能：
