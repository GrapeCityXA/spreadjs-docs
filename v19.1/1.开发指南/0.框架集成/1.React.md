# UsingSpread.SheetswithReact

SpreadJS支持React-一个JavaScript库，允许开发人员通过处理MVC框架的视图层为Web应用程序和移动应用程序构建用户界面。
使用React，您可以在创建可重用组件和大型应用程序时修改数据而无需重新加载页面。

>type=warning
> **注意**：SpreadJS 支持 React 16、17、18 以及 19.

## 使用Vite搭建项目

### 1\. 创建Vite React项目

*框架选择React，变体选择TypeScript*

```bash
npm create vite@latest spreadjs-vite-app
cd spreadjs-vite-app
npm install
```

### 2\. 安装SpreadJS React相关模块

```bash
npm install @grapecity-software/spread-sheets @grapecity-software/spread-sheets-react
```

## 基础配置

### 1\. 引入SpreadJS样式文件

在`src/App.tsx`文件中，通过以下代码引入SpreadJS样式文件。

```javascript
import { useState } from 'react';
import { SpreadSheets } from '@grapecity-software/spread-sheets-react';
import * as GC from '@grapecity-software/spread-sheets';
import './App.css';
import '@grapecity-software/spread-sheets/styles/gc.spread.sheets.excel2013white.css';
// 填入有效的授权密钥
// GC.Spread.Sheets.LicenseKey = '你的授权密钥';
function App() {
    let spread: GC.Spread.Sheets.Workbook;
    const [spreadBackColor, setSpreadBackColor] = useState('aliceblue');
    const [sheetName, setSheetName] = useState('我的工作表');
    const [hostStyle, setHostStyle] = useState({
        width: '800px',
        height: '600px',
    });
    const initSpread = function (spreadObj: GC.Spread.Sheets.Workbook) {
        spread = spreadObj;
        const sheet = spread.getActiveSheet();
        sheet.setValue(0, 0, '欢迎使用SpreadJS');
    };
    return (
        <>
            <div className="sample-spreadsheets">
                <SpreadSheets backColor={spreadBackColor} hostStyle={hostStyle} workbookInitialized={(spread) => initSpread(spread)}>
                </SpreadSheets>
            </div>
        </>
    );
}
export default App;
```

### 2\. 在React项目中使用SpreadJS并完成授权配置

根据自身需求修改`src/App.tsx`文件，刷新浏览器页面即可生效。可在组件初始化前填写有效的SpreadJS授权密钥，参考示例代码如下：

```bash
npm run dev
```
