# nextjs

SpreadJS 支持 NextJS（一款基于 React 的框架），借助该框架，你可开发适用于 Windows、Linux、Mac 等不同平台的 Web 应用程序。NextJS 提供了生产环境所需的全部功能，无论是 TypeScript 支持、混合静态与服务端渲染、路由预获取，还是智能打包，均能实现。
如需了解更多信息，请参阅 [https://nextjs.org/docs/getting-started](https://nextjs.org/docs/getting-started)。
本教程将构建一个使用 SpreadJS 的 Next.js 应用程序。

>type=info
> **注意**：SpreadJS 现已支持 NextJS 16 版本。若要创建 Next.js 应用程序，请确保已安装的 Node.js 版本为20.9及以上。

## 创建 Next.js 应用

在命令行界面（CLI）工具中，创建 Next.js 应用程序最简单的方式是使用 `create-next-app` 命令。

1. 在命令提示符或终端中运行以下命令，创建一个 Next.js TypeScript 项目：

    ```auto
    npx create-next-app@latest
    ```
2. 输入项目名称，例如 *nextjs-with-spreadjs*。
3. 当终端提示配置信息时，选择所需选项并按 Enter 键确认。等待终端完成项目的安装与创建（此过程需耗时片刻）。

    >type=info
> 

> Next.js 16 将 Turbopack 作为默认打包工具。你无需再手动开启，它会在开发环境与生产环境的构建流程中自动启用。

4. 依赖项安装完成后，在终端中输入以下命令以启动项目：

    ```auto
    cd nextjs-with-spreadjs
    npm run dev
    ```
5. 使用浏览器打开 http://localhost:3000，即可看到 NextJS 的欢迎页面。
6. 关闭当前终端，使用 Visual Studio Code 或其他集成开发环境（IDE）打开 *nextjs-with-spreadjs* 文件夹。

## 安装 SpreadJS

1. 安装 SpreadJS 包：

    ```auto
    npm install @grapecity-software/spread-sheets-react
    ```
2. 创建一个名为 *SpreadSheet.tsx* 的 JavaScript XML 文件，将其添加到 app 文件夹中，并在文件内添加以下代码。初始化组件前，你可输入有效的 SpreadJS 许可证密钥。

    ```javascript
    "use client";
    
    import React, { useState } from "react";
    import { SpreadSheets, Worksheet, Column } from "@grapecity-software/spread-sheets-react";
    import * as GC from "@grapecity-software/spread-sheets";
    
    // SpreadJS 授权
    var SpreadJSKey = "xxx";          // 输入有效的许可证密钥
    GC.Spread.Sheets.LicenseKey = SpreadJSKey;
    
    export default function SpreadSheet() {
    
        const [spreadBackColor, setSpreadBackColor] = useState('aliceblue');
        const [sheetName, setSheetName] = useState('Empolyees'); 
        const [hostStyle, setHostStyle] = useState({
            width: '100%',
            height: '700px'
        });
        const dataArr = [
            {
                "jobTitleName": "Developer", // 职位名称：开发工程师
                "preferredFullName": "Romin Irani", // 首选全名
                "region": "CA", // 地区（CA 通常指美国加利福尼亚州）
                "phoneNumber": "408-1234567" // 电话号码
            },
            {
                "jobTitleName": "Developer",
                "preferredFullName": "Neil Irani",
                "region": "CA",
                "phoneNumber": "408-1111111"
            },
            {
                "jobTitleName": "Program Director", // 职位名称：项目负责人
                "preferredFullName": "Tom Hanks",
                "region": "CA",
                "phoneNumber": "408-2222222"
            }
        ];
        const [data, setData] = useState(dataArr);
        const [columnWidth, setColumnWidth] = useState(200);
        return (
            <SpreadSheets backColor={spreadBackColor} hostStyle={hostStyle}>
                <Worksheet name={sheetName} dataSource={data}>
                    <Column dataField='preferredFullName' width={columnWidth}></Column>
                    <Column dataField='jobTitleName' width={columnWidth}></Column>
                    <Column dataField='phoneNumber' width={columnWidth}></Column>
                    <Column dataField='region' width={columnWidth}></Column>
                </Worksheet>
            </SpreadSheets>);
    }
    ```
3. 修改索引文件内容。将 *app/page.tsx* 文件的默认内容替换为以下代码：

    ```javascript
    'use client';
    
    import dynamic from "next/dynamic";
    
    const SpreadSheet = dynamic(
      () => {
        return import("../SpreadSheet");
      },
      { ssr: false } // ssr（Server-Side Rendering）：服务端渲染，此处设置为“false”表示禁用服务端渲染
    );
    
    export default function Home() {
      return (
        <div>
          <h1>
          Next.JS + Spreadsheets 演示
          </h1>
          <SpreadSheet />
        </div>
      )
    }
    ```

>type=info
> 必须使用配置`ssr: false`的`next/dynamic`，因为SpreadJS依赖仅浏览器端可用的应用程序接口（`window`、`document`、画布），电子表格组件必须禁用服务端渲染。务必在标注了`'use client'`的客户端组件中使用带`ssr: false`参数的`next/dynamic`。

## 在Next.js 16中引入SpreadJS

在搭配Turbopack使用Next.js 16时，建议采用默认导入语法引入SpreadJS核心依赖包：

```javascript
import GC from "@grapecity-software/spread-sheets";
```

请勿使用命名空间导入写法：

```javascript
import * as GC from "@grapecity-software/spread-sheets";
```

在部分Next.js 16运行环境中，命名空间导入方式会导致SpreadJS扩展插件包（例如数据透视表、报表相关插件）无法正常扩展`GC`对象。即便已经安装对应的扩展插件，也可能出现`GC.Pivot`、`GC.Report`等相关命名空间提示未定义的问题。
采用默认导入方式，能够保证各类扩展模块可正常将自身功能挂载至SpreadJS核心对象上。

## 导入样式

在 app 文件夹下的 *globals.css* 文件中添加以下代码行，将 SpreadJS 的 CSS 样式导入应用程序：

```auto
@import '@grapecity-software/spread-sheets/styles/gc.spread.sheets.excel2016colorful';
```

## 运行并测试应用

可使用 `npm run dev` 命令运行应用程序。默认情况下，项目将在 http://localhost:3000/ 地址运行。
