# add_new_dialog

你可以在设计器组件中添加一个新对话框，并映射用于打开和关闭该对话框的命令。

## 打开对话框

按照以下步骤操作，在上下文菜单组件中选择“插入签名”选项后，添加并打开一个“签名对话框”。

1. 访问默认配置。

    ```javascript
    // 配置工作簿和工作表
    var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
    var activeSheet = spread.getActiveSheet();
    // 访问默认配置
    var config = GC.Spread.Sheets.Designer.DefaultConfig;
    ```
2. 在 `contextMenu` 标签中添加“插入签名”选项，并在项目中把它设置到 `commandMap` 中。

    ```javascript
    // 在配置的上下文菜单中添加上下文菜单项
    if (config && config.contextMenu) {
        config.contextMenu.unshift('insertSignatureMenu');
    }
    // 为新的上下文菜单项创建命令
    config.commandMap = {
        insertSignatureMenu: {
            text: '插入签名',
            commandName: 'insertSignatureMenu',
            visibleContext: 'clickRowHeader',
            // 执行 InsertSignature，以下只是一个简单的代码片段示例
            execute: () => {
                // 在此处添加在步骤4中注册的对话框模板名称。
                GC.Spread.Sheets.Designer.showDialog('signature');
            },
        },
    };
    
    ```
3. 通过传递用于可自定义配置的 `config` 参数来初始化设计器实例。

    ```JavaScript
    // 初始化设计器实例
    var designer = new GC.Spread.Sheets.Designer.Designer(document.getElementById("designerHost"), config, spread);
    ```
4. 在项目中创建并注册 `insertSignature` 对话框模板。上下文菜单中的“插入签名”选项会打开“签名”对话框。

    ```JavaScript
    let insertSignature = {
        templateName: 'insertSignature',
        title: '签名对话框',
        content: [
            {
                type: 'FlexContainer',
                children: [
                    {
                        type: 'TextBlock',
                        margin: '5px -4px',
                        text: '插入范围',
                    },
                    {
                        type: 'RangeSelect',
                        title: '选择范围',
                        absoluteReference: true,
                        needSheetName: false,
                        margin: '5px -5px',
                    },
                ],
            },
        ],
    };
    // 使用 registerTemplate 注册对话框模板实例
    GC.Spread.Sheets.Designer.registerTemplate('signature', insertSignature);
    
    ```

## 以编程方式关闭对话框

你可以使用 `Designer.closeDialog` 方法以编程方式关闭对话框。该方法接受已注册的模板名称，以及在关闭对话框后是否提交对话框的值。
在完成上述步骤后，为了打开“签名对话框”，可以进行以下修改以自动关闭“签名对话框”。

* 修改步骤2中的代码，在现有的 `commandMap` 中添加 `closeDialog` 方法。

    ```JavaScript
    config.commandMap = {
        insertSignatureMenu: {
            text: '插入签名',
            commandName: 'insertSignatureMenu',
            visibleContext: 'ClickRowHeader',
            // 执行_InsertSignature，以下只是一个简单的代码片段示例
            execute: () => {
                // { 现有代码 }
                // 添加关闭对话框的执行代码
                var showTips = document.querySelector('.show-tips');
                var i = 4;
                var showTipsInterval = setInterval(() => {
                    showTips.innerText = '你必须在 ' + i + ' 秒内输入有效值！';
                    i--;
                    if (i === -1) {
                        clearInterval(showTipsInterval);
                        GC.Spread.Sheets.Designer.closeDialog('signature', false); // 如果时间到了，关闭对话框。
                    }
                }, 1000);
            },
        },
    };
    
    ```
* 修改步骤4中的代码，在对话框模板中添加一个新的文本块。

    ```JavaScript
    let insertSignature = {
        templateName: 'insertSignature',
        title: '签名对话框',
        content: [
            // { 现有代码 }
            // 在对话框模板中添加一个新的文本块
            {
                type: 'TextBlock',
                text: '你必须在 5 秒内输入有效值！',
                className: 'show-tips',
            },
        ],
    };
    
    ```

## 控制对话框位置

你可以通过在 `setData` 方法中把 `dialogOpeningPosition` 参数设置为 `screenCenter` 或 `designerCenter` 来调整对话框的打开区域位置。

* **designerCenter** 是默认选项，它会尽可能将设计器调整到可视区域的中心位置。不过，从第一个对话框中打开的第二个对话框会出现在第一个对话框的中心位置。
* **screenCenter** 选项会直接在当前可见区域内调整对话框位置，且不会滚动页面。这里浏览器窗口的大小必须大于当前打开的对话框的大小。

> **注意**：当设计器的大小不支持打开所有对话框时，对话框会调整其位置。但是，如果有足够的空间，对话框将在功能区下方打开，仅覆盖工作表部分。
> 使用 `setData` 方法的 `dialogOpeningPosition` 参数来设置设计器的对话框位置，如下所示。

```javascript
designer.setData("dialogOpeningPosition", "screenCenter");
```
