# customize-save-file-dialog

SpreadJS 允许用户在 Spread Designer 组件中导入和保存文件时，自定义“保存文件”对话框的行为。此功能通过使用户能够根据个人喜好选择文件格式并指定文件名，增强了灵活性和效率。

## 默认行为

默认情况下，当 Spread 文件中有内容时，导入本地文件会提示是否保存当前内容。如果选择保存，保存的文件格式将与导入文件的格式相匹配。

### 示例：

1. 导入一个带有内容的 Excel 文件
2. 然后从本地系统导入一个 CSV 文件
3. 出现提示信息，要求保存当前文件更改
4. 点击“是”
5. “保存文件”对话框显示 .xlsx 格式以保存当前文件

注意：如果之前没有导入任何文件，它会以 ssjson（默认）格式保存内容。

## 自定义文件保存格式

您可以使用 `setData` 方法中的 `saveFileType` 参数设置首选的文件保存格式。
目前，GC.Spread.Sheets.Designer.FileType 枚举中仅支持以下导出的文件类型：

| 格式 | 描述 |
| --- | --- |
| JSON | 指定文件保存格式为 json |
| Excel | 指定文件保存格式为 .xlsx |
| CSV | 指定文件保存格式为 .csv |
| SJS | 指定文件保存格式为 .sjs |

通过如下所示在 `setData` 方法中设置 `saveFileType` 参数来设置文件保存格式：

```javascript
designer.setData("saveFileType", GC.Spread.Sheets.Designer.FileType.Excel);
```

下面的输出将生成，仅允许以 .xlsx 格式保存导入的 .csv 文件。
![CustomizedSaveFiledialog.a018a8](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/CustomizedSaveFiledialog.a018a8.26775b.gif?width=600)
但是，要恢复默认的导入/导出保存规则，可以将 `saveFileType` 设置为 `undefined`，如下所示：

```javascript
designer.setData("saveFileType", undefined);
```

## 自定义文件名

默认情况下，导出文件时，“保存文件”对话框不显示任何文件名。您可以使用 `setData` 方法中的 `saveFileName` 参数设置自己的文件名。

```javascript
designer.setData("saveFileName", "New File");
```

将生成如下输出：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.bfa0e3.png)

> type=warning
> 注意：
> 文件名必须遵循系统规则，例如：
>
> * 文件名应始终为字符串
> * 对于 Windows，最大字符长度应为 255
> * 避免使用符号字符，如 "<>"
> * 避免使用系统保留名称
