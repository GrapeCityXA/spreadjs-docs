# print-settings-designer

SpreadJS 设计器组件提供了一个页面设置对话框，可帮助设置页面的布局和打印选项。点击 **页面布局** 选项卡，然后在 **页面设置** 组中，点击右下角的箭头按钮。
![print-settings](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/print-settings.d3457a.1919b0.png)
“页面设置” 对话框包含 4 个选项卡 —— 页面、页边距、页眉/页脚和工作表。每个选项卡都包含一组有助于工作表打印的选项，具体内容如下：
* **页面** —— 包含 “方向”、“缩放”、“纸张大小” 和 “打印质量” 等选项。
* **页边距** —— 带有各边（左、上、页脚等）测量输入字段和内容位置的页面预览。
* **页眉/页脚** —— 页码和标题等格式字符串。可选择创建自定义页眉/页脚。
* **工作表** —— 打印区域、打印标题等等。
## 页面
此选项卡提供 “方向”、“缩放”、“纸张大小” 和 “打印质量” 等选项。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/designer-print-page.4637a5.png)
| 功能 | 描述 |
| ---- | ----------- |
| 方向 | 设置工作表的打印方向。可从纵向和横向中选择。 |
| 缩放 | 设置打印区域的缩放比例。您可以将大小调整为与正常大小成比例，也可以相应地适配页面。 |
| 纸张大小 | 设置纸张大小。从下拉列表中选择所需的大小。 |
| 打印质量 | 使用 1 到 8 之间的正整数设置打印质量因子。质量因子越大，打印质量越好。当质量因子较大时，打印效率会受到影响。 |
| 首页页码 | 设置起始页码。该字段设置为 “自动” 时，将从 “1” 开始编号（如果这是打印的第一页）或从下一个连续的页码开始编号。 |
## 页边距
此选项卡提供了带有各边（左、上、页脚等）测量输入字段和内容位置的页面预览等选项。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/designer-print-margins.3a0979.png)
| 功能 | 描述 |
| ---- | ----------- |
| 页边距预览 | 设置页边距设置并在预览框中查看结果。您可以设置上、右、下、左、页眉和页脚的页边距。 |
| 居中方式 | 设置水平、垂直或两者，以使数据在页边距内居中显示在页面上。 |
## 页眉/页脚
此选项卡提供了字符串格式（页码、标题）和创建自定义页眉/页脚等选项。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/designer-print-headerfooter.d84966.png)
| 功能 | 描述 |
| ---- | ----------- |
| 页眉 | 从下拉列表中选择一个内置页眉来设置页眉格式。内置页眉会显示在下拉列表上方的预览框中。 |
| 自定义页眉 | 在新对话框中创建自定义页眉。提供了各种格式设置选项，如格式文本、工作表元素和图片，可在页眉的左、中、右部分进行设置。 |
| 页脚 | 从下拉列表中选择一个内置页脚来设置页脚格式。内置页脚会显示在下拉列表上方的预览框中。 |
| 自定义页脚 | 在新对话框中创建自定义页脚。提供了各种格式设置选项，如格式文本、工作表元素和图片，可在页脚的左、中、右部分进行设置。 |
| 奇偶页不同 | 分别设置奇数页和偶数页的页眉和页脚。启用此选项可分别访问自定义页眉/页脚窗口中的不同选项卡。如果为页眉/页脚选择了模板格式，那么默认情况下奇数页部分也会显示相同的内容。 |
| 首页不同 | 单独设置首页的页眉和页脚。启用此选项可分别访问自定义页眉/页脚窗口中的不同选项卡。 |
## 工作表
此选项卡提供了打印区域、打印标题或从工作表中打印任何特定元素等选项。
![showborder-print](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/showborder-print.f3d145.ab7378.png)
| 功能 | 描述 |
| ---- | ----------- |
| 打印区域 | 指定要打印的范围。设置多个范围时将使用第一个值。 |
| 打印标题 | 如果您希望将特定行作为每页的水平标题，请设置 “顶端标题行” 字段。如果您希望在每页上有垂直标题，请设置 “左侧标题列” 字段。 |
| 打印内容 | 指定从工作表中打印的内容。<ul><li>网格线 - 选中此项可在打印输出中包含工作表网格线。</li><li>显示边框 - 选中此项可在打印输出中包含边框。</li><li>黑白 - 当您使用彩色打印机，但希望在打印时仅使用黑白时，请选中此项。</li><li>行和列标题 - 选中此项可在打印输出中包含这些标题。</li></ul> |
| 页面顺序 | 指定数据在一页放不下时的编号和打印顺序。<ul><li>先列后行</li><li>先行后列</li></ul> |
