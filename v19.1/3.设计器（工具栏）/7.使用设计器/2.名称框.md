# SpreadJS 名称框与名称管理器使用说明

SpreadJS 中的**名称框**会显示工作表中活动单元格的地址，还可用于执行以下单元格区域操作：

* 选中单元格区域后，在名称框中输入名称，可为该区域创建**自定义名称**。
    ![创建自定义名称.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/1.f0d3eb.4cd606.gif)
* 从名称框的下拉列表中选择相应自定义名称，可快速访问已保存的单元格区域。
    ![访问自定义名称区域](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/2.8b308e.adb02d.gif)
* 在名称框中输入单元格引用（如 `A1:C5`），可自动选中对应的单元格区域。
    ![通过引用选择区域](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/3.bdbd17.6d1c99.gif)

## 名称框输入警告场景

当在名称框中输入文本时，若出现以下情况，SpreadJS 会弹出警告提示：

* 输入文本无法解析为有效单元格区域，或自定义名称不符合命名规则（如名称含空格、以数字开头等）。
    ![无效名称/引用警告](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/invalid-ref-name.gif)
* 输入文本虽能解析为单元格引用，但该引用在当前工作表中不存在。
    ![无效工作表引用警告](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/invalid-ref-sheet.gif)

### 批量删除自定义名称

以下表格总结了 Windows 和 macOS 系统中，通过鼠标或键盘选择多个自定义名称的操作方法。选中目标名称后，即可执行批量删除。

| Windows 系统操作 | macOS 系统操作 | 描述 |
| ------------ | ---------- | --- |
| 鼠标点击并拖动 | 鼠标点击并拖动 | 按住鼠标左键拖动，选中连续的多个名称行 |
| **Shift** + **↑** / **↓** | **Shift** + **↑** / **↓** | 向上或向下连续扩展选择范围 |
| **Ctrl** + **Shift** + **↑** / **↓** | **Command** + **Shift** + **↑** / **↓** | 从当前行选中至列表开头或结尾（包含首尾行） |
| **Ctrl** + 鼠标点击 | **Command** + 鼠标点击 | 单独添加或移除选中行（支持非连续选择） |
| **Ctrl** + 鼠标点击并拖动 | **Command** + 鼠标点击并拖动 | 在现有选择基础上，连续添加或移除多个名称行 |

>type=note
> **注意事项**：
> 选中多个名称行时，无法执行编辑操作。

以「鼠标点击并拖动」为例，以下动图演示了如何选择多个名称并批量删除：
![批量删除自定义名称](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/mult-del.d3d864-20251229.a77583.gif)

### 筛选自定义名称

1. 通过筛选下拉菜单筛选
    ![筛选下拉菜单](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/9.6a5d6a-20251229.7a9c88.gif)

>type=note
> 筛选下拉菜单分为三类选项组：工作簿/工作表、含错误/无错误、自定义名称/表格名称。每个选项组可选择一个筛选条件，支持多条件组合筛选。

2. 通过列列表筛选
    1. 勾选需显示的名称对应复选框
        ![勾选筛选](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/11.d63f6e-20251229.26b2b1.gif)
<br>
    2. 全选或取消全选
        ![全选/取消全选](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/13.c24ab3-20251229.ba25ce.gif)
<br>
    3. 在搜索框中输入筛选条件
        ![搜索筛选](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/12.a12204-20251229.2a2257.gif)
