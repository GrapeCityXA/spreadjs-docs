# insert-function-dialog

该对话框支持分类浏览、关键词搜索、键盘快捷操作，还能预览所选函数的功能说明。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260326.1b7c57-20260525.042940.png?width=800)
## 界面概览
此对话框由以下区域组成：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260326.0ef1f7-20260525.3a6955.png?width=400)
### 1. 顶部搜索框
位于对话框最上方。
* 标签文字：搜索函数
* 支持关键词检索
* 输入内容后会显示清除（X）按钮
* 最大输入字符数：500个
输入文字即可实时筛选匹配的函数。

### 2. 左侧函数分类列表
展示所有可用函数分类：
* 数据库函数
* 日期与时间函数
* 工程函数
* 财务函数
* 信息函数
* 逻辑函数
* 查找与引用函数
* 数学与三角函数
* 统计函数
* 文本函数
* 网页函数
选中对应分类，即可筛选出函数列表内对应的函数。

### 3. 右侧函数列表
展示所选分类下的全部函数。
* 列表支持滚动查看
* 单击选中目标函数
* 双击可直接插入选中函数

### 4. 底部函数说明区域
展示当前选中函数的简要功能介绍。

## 函数搜索功能
借助搜索框可快速查找所需函数。
### 搜索运行机制
输入搜索内容时：
* 分类列表顶部会自动弹出动态推荐分类
* 系统自动选中推荐分类
* 实时展示匹配到的相关函数
* 搜索结果按相关度排序

清空搜索内容时：
* 推荐分类自动消失
* 自动切换至全部函数分类
* 恢复展示完整函数列表

### 匹配规则
搜索功能不区分大小写，支持以下匹配方式：
* 局部匹配（例如输入`sum`，可匹配到`SUM`、`SUMIF`、`DSUM`等函数）
* 分词匹配
* 元数据匹配，匹配范围包含：
  * 函数名称
  * 函数功能说明
  * 所属分类名称
  * 参数名称

### 结果排序规则
推荐分类下的搜索结果按照相关度分值从高到低排列。
若多个函数相关度分值一致，则依据本地化语言规则按字母顺序排序。

## 键盘快捷操作
该对话框支持键盘快捷键操作：
| 按键 | 执行操作 |
| --- | ------ |
| 向下方向键 | 将焦点切换至函数列表 |
| 向上/向下方向键 | 上下切换选择函数 |
| 回车键 | 插入选中的函数 |
| ESC键 | 关闭当前对话框 |

## 函数插入方法
插入函数操作步骤：
1. 选择函数分类，或是在搜索框输入关键词查找。
2. 在函数列表中选中需要使用的函数。
3. 点击确定按钮、按下回车键，或是双击目标函数即可完成插入。

确认操作后，所选函数会自动填入工作表的公式编辑区域。
