# managing-columns

**列**选项卡用于定义数据管理器中的数据表架构。
你可在此执行以下操作：

* 新增数据列
* 配置列的数据定义与运行规则
* 设定数据表之间的关联关系
* 配置数据校验、样式以及层级相关参数

所有列配置均对应数据管理器运行时调用的数据表架构。
如需了解架构、关联关系与层级的相关概念说明，请查阅功能板块中的**数据管理器**章节。

## 列列表

列列表会展示该数据表内所有已定义的列。
点击任意列，即可打开对应的配置面板。
![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260409.af5c3c-20260525.ec794e.png?width=600)

### 列类型标识

列名称前方会显示图标，用以区分列的类型类别。
示例如下：

* **#** 代表数值类类型，例如数字、行序号。
* **ABC** 代表文本类类型，例如字符串、空类型。
* **B** 代表布尔类型。
* 矩形图标![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260410.8bed9c-20260525.849ea4.png?width=20)代表对象类型。
* **[]** 代表数组类型。
* 日历图标![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260410.1f194a-20260525.c4e8a4.png?width=20)代表日期类型。
* **fx** 代表用户自定义公式列。

仅通过添加列功能创建的列会显示fx图标。
图标会根据列的数据类型自动匹配，若要更改类型，可在下文介绍的架构板块中修改**类型**设置。

### 列状态与操作标识

列名称后方还会出现其他图标，用于标示列状态或可执行操作。

* 关联图标![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260409.8fb960-20260525.3ed18c.png?width=20)表示该列已配置数据表关联关系。
* 回收站删除图标![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260410.9e01af-20260525.3f8e26.png?width=20)仅出现在用户新增的公式列上，支持删除该列。

### 添加列

点击**添加列**即可新建公式列。
新增列具备以下特性：

* 默认以公式列形式创建
* 展示fx标识图标
* 排列在列列表末尾
    ![添加动图](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/add-20260410.3060ad-20260525.fb1dcd.gif?width=800)

### 删除列

仅用户手动添加的公式列支持删除操作。
数据表原生架构自带的列无法删除。若需隐藏列，可取消勾选属性中的**可见**选项。
![删除动图](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/delete-20260410.ad9a27-20260525.7128d5.gif?width=800)

### 重置扩展列

点击**重置扩展列**，可将数据管理器的列定义与表格控件当前的列绑定信息同步。
该操作会依据表格控件内现有字段定义、绑定关系以及嵌套数据路径，更新列结构。
当表格控件结构发生变动后，可使用此功能对齐数据管理器的列配置。
![扩展列动图](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/spread-20260410.4a7a97-20260525.55276c.gif?width=800)

## 列配置

选中列后，系统会弹出对应的配置面板。
配置项分为以下五大板块：

* 列基础属性
* 架构与触发器
* 样式与数据校验
* 关联关系
* 层级结构

### 列基础属性

选中列后，右侧面板会展示该列基础属性。
这些属性决定列在绑定组件中的展示样式与运行规则。
![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260409.a3bf52-20260525.a74e01.png?width=350)

各项设置作用如下：

| 属性 | 说明 |
| --- | --- |
| 值 | 列对应的字段名称，该属性为只读状态，无法修改 |
| 标题 | 列表头展示的文字，默认空白，未自定义时表头直接显示字段名 |
| 宽度 | 设定列的宽度，默认数值为120 |
| 设为主键 | 将该列标记为主键，开启后表头会显示主键标识 |
| 必填项 | 限定该列必须填写内容，开启后表头会显示必填标识 |
| 只读 | 禁止编辑该列数据，开启后表头会显示只读标识 |
| 可见 | 控制列是否在表格控件中显示，取消勾选后列仍保留架构，仅页面隐藏 |
| 默认值 | 新增数据行时，自动为该列填充的初始数值 |
| 表头适配 | 调整表头文字展示形式，可选常规、分行、竖向排列三种样式 |

### 架构与触发器

**架构**板块用于定义数据管理器对列数据的解析、格式化及处理规则。
![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260409.15b71e-20260525.895e61.png?width=350)

#### 核心设置

| 设置项 | 说明 |
| --- | --- |
| 类型 | 指定列的数据类型，包含数字、字符串、布尔、日期、对象、数组、行序号等类别，修改类型后前端标识图标同步更新 |
| 空值显示 | 自定义空数据的展示文字，仅改变页面呈现效果 |
| 空白值显示 | 自定义空白数据的展示文字，仅改变页面呈现效果 |
| 格式模板 | 配置数据格式化、解析规则，适配日期、数字等格式场景 |
| 映射名称 | 填写字段路径，用于绑定数据源，支持直接字段名与嵌套路径格式，例如customer.name |
| 建立索引 | 开启索引可提升数据筛选与查询的运行效率 |

#### 表格扩展与数据查找

| 设置项 | 说明 |
| --- | --- |
| 表格扩展 | 仅适用于对象类型列，开启后会将对象内部属性拆解为一级独立列，可通过重置扩展列恢复原有嵌套结构 |
| 数据查找 | 将列设为查找列，页面会以下拉选框、多列下拉列表形式展示，可使用数组格式录入固定可选值，例如1,2,3 |

#### 触发器设置

触发器公式可在数据新增、修改时，自动计算并更新列数值。

| 设置项 | 说明 |
| --- | --- |
| 触发时机 | 选择公式生效时机，新建行触发、新建及编辑行均触发 |
| 计算公式 | 编写数值运算表达式，计算结果会自动回写入当前列 |
| 关联字段 | 仅选择新建及编辑行触发时可用，指定哪些字段变动会触发重算，可选择任意字段或指定单个字段 |

![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260410.cd5d4c-20260525.e97a51.png?width=350)

### 样式与数据校验

**样式**板块可快速设置选中列的外观样式与数据校验规则。
点击对应选项会跳转至表格组件专属配置窗口，详细功能与高级用法可查阅单独文档。

![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260409.bc7e5b-20260525.5f7279.png?width=350)

| 设置项 | 说明 |
| --- | --- |
| 单元格模板 | 打开模板配置窗口，可套用预设模板，模板包含样式、条件格式、校验规则、单元格状态等配置 |
| 单元格样式 | 调出单元格格式窗口，设置数字格式、字体、对齐方式、边框、填充底色等外观参数 |
| 表头样式 | 单独打开表头格式配置窗口 |
| 条件格式 | 进入条件格式管理界面，创建和管理列的条件显示规则 |
| 数据校验 | 开启数据校验窗口，设定列的数据录入限制规则 |

以上设置仅改变数据展示效果与录入规范，不会改动底层数据架构。

### 关联关系

**关联关系**板块能够建立当前列与其他数据表列之间的关联绑定。
关联操作虽基于单列配置，最终会在数据管理器中搭建起两张数据表的连接关系。
![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260409.97d1ab-20260525.6158a2.png?width=350)

#### 关联参数设置

| 设置项 | 说明 |
| --- | --- |
| 目标数据表 | 选择需要建立关联的数据表，下拉列表展示数据管理器内所有可用数据表 |
| 目标数据列 | 选定目标数据表中用于关联的字段，可选列随所选数据表自动变化 |
| 源端名称 | 当前数据表侧的关联名称，选定目标表和列后自动生成，默认格式为源表名\_源列名，支持手动修改 |
| 目标端名称 | 目标数据表侧的关联名称，系统自动生成，默认格式为目标表名\_目标列名，支持自定义编辑 |

关联配置完成后，列列表内对应列名称旁会显示关联图标。
![关联动图](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/relationship-20260410.8a2096-20260525.fc6ba1.gif?width=800)

如需了解关联逻辑、数据跳转与数据引用的详细规则，可查看功能板块的数据管理器章节。

### 层级结构

**层级结构**板块可将层级类数据以树形结构展示。
层级配置的前提是数据源本身符合规范的层级架构。

>type=info
> **注意事项：**
>
> * 层级功能生效要求底层数据源已满足支持的层级结构规范
> * 只有开启展开收起标识，树形层级外观才会正常显示

![图片](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260409.987e2e-20260525.70df74.png?width=350)

#### 层级参数设置

| 设置项 | 说明 |
| --- | --- |
| 层级类型 | 选择层级模式，包含父级、子级路径、层级等级三类，选择无则关闭层级功能 |
| 汇总公式 | 编写公式计算父级行汇总数据，仅该行存在子级数据时公式生效 |
| 树形列 | 设定当前列作为树形展示列，单张数据表仅能设置一个树形列 |

#### 树形列可选配置

| 选项 | 说明 |
| --- | --- |
| 显示复选框 | 在层级每行前方展示勾选方框 |
| 自定义层级图标 | 为不同层级搭配专属图片标识 |
| 层级图片资源 | 录入各层级对应的图片地址，单行填写一个链接，支持网址与Base64编码格式，按层级深度依次匹配展示 |
| 展示展开收起标识 | 显示树形展开、折叠操控按钮，开启后方可实现层级交互操作 |
| 展开节点图标 | 设置节点展开状态的图标，仅支持单个有效网址或Base64编码 |
| 折叠节点图标 | 设置节点收拢状态的图标，仅支持单个有效网址或Base64编码 |

#### 层级开启后效果

* 数据行以树形层级样式排列展示
* 开启标识显示后，可点击按钮展开、收拢分支
* 配置汇总公式后，父级行可自动统计展示汇总数值
* 开启层级图标功能后，不同层级匹配对应图片标识
