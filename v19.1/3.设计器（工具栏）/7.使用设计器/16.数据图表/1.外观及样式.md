# appearance-and-style-settings

SpreadJS 允许你在数据图表上应用不同的样式，使其更易于理解且视觉效果更佳。应用样式还有助于用户突出重要细节，保持所有内容清晰一致。
通过“数据图表面板”中的“检查器”选项卡，你可以为数据图表设置各种外观和样式。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.0e125a.png)
数据图表样式有许多配置设置，以下列出了一些常见设置。

### 图表样式

此设置的属性可帮助你设置数据图表的整体外观和感觉。
![image.492b5a](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1f04de1b-0add-4f88-889e-295f2a2e218b/image.492b5a.f45787.png?width=400)
Available options vary depending on the selected chart type.

#### 整体外观

| **属性** | **说明** |
| --- | --- |
| 调色板 | 选择配色方案以区分不同图例，可选：主题配色、标准配色、自定义配色 |
| 图表不透明度 | 调整图表数据点的透明程度 |
| 画布边距 | 调整图表绘图区域的留白间距 |

#### 线条与标记样式设置

（仅折线类图表可用）

| **属性** | **说明** |
| --- | --- |
| 线条颜色 | 设定系列线条或数据点边框的颜色 |
| 线条类型 | 将线条样式设置为实线或虚线 |
| 线条粗细 | 设定系列线条或数据点边框的宽度 |
| 线条形态 | 定义系列线条的绘制样式，包含直线、样条线、阶梯线、曲线等类型，可选样式随图表类型变化 |
| 显示标记 | 在数据点位置展示标记图形 |
| 标记形状 | 设定数据点标记的外形 |
| 标记大小 | 设定数据点标记的尺寸 |

>type=info
> **备注**
>
> * 线条形态仅支持可绘制系列线条的图表类型
> * 不同图表支持的样式选项存在差异：
>     * 折线图、面积图、堆叠面积图、百分比堆叠面积图：`默认样式`、`样条线`、`左阶梯`、`右阶梯`、`居中阶梯`、`贝塞尔曲线`
>     * 区间面积图：`默认样式`、`样条线`、`贝塞尔曲线`
>     * 雷达图、填充雷达图：`默认样式`、`样条线`
> * 若切换至不兼容当前线条形态的图表类型，线条样式将自动恢复为该图表的默认样式

#### 饼图与环形图设置

（仅饼图类图表可用）

| 属性 | 说明 |
| --- | --- |
| 起始角度 | 设定图表的起始偏转角度 |
| 半径 | 设置内圈半径与外圈半径 |
| 扫掠角度 | 设定图表整体占据的角度范围 |
| 圆角半径 | 设置数据区块的圆角弧度 |

#### 树形图标题设置

（仅树形图可用）
**标题显示设置**

| 属性 | 说明 |
| --- | --- |
| 显示标题标签 | 开启树形图标题标签，开启后详情、数值、标签分隔符设置将作用于标题内容 |

**标题内容（开启显示标题标签后生效）**

| 属性 | 说明 |
| --- | --- |
| 详情信息 | 在各个树形图标题中展示详细内容 |
| 数值 | 在各个树形图标题中展示对应数值 |
| 标签分隔符 | 设定标题内各项标签内容之间的分隔符号 |

**标题文字样式**

| 属性 | 说明 |
| --- | --- |
| 字体颜色 | 设置标题文字颜色 |
| 字体类型 | 设置标题文字字体 |
| 字体大小 | 设置标题文字字号 |
| 字体样式 | 设置标题文字字形 |
| 字体粗细 | 设置标题文字字重 |

### 外观样式

此设置的属性有助于调整数据图表的视觉细节，如背景颜色、边框类型和颜色，以提高可读性。
![image.8d8676](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1f04de1b-0add-4f88-889e-295f2a2e218b/image.8d8676.70ef83.png?width=400)

| **属性** | **描述** |
| --- | --- |
| 背景颜色 | 设置数据图表的背景颜色。 |
| 边框类型 | 将数据图表的边框类型设置为实线或虚线。 |
| 边框颜色 | 设置数据图表的边框颜色。 |
| 边框宽度 | 设置数据图表的边框线宽度。 |

### 标题

此设置的属性可用于自定义图表标题的样式。标题是指数据图表上出现的文本字段，为图表数据提供描述性标题。
![image.98b8df](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1f04de1b-0add-4f88-889e-295f2a2e218b/image.98b8df.be8262.png?width=400)

| **属性** | **描述** |
| --- | --- |
| 显示标题 | 设置数据图表是否显示标题。 |
| 标题 | 输入数据图表标题的文本内容。 |
| 背景颜色 | 设置数据图表标题区域的背景颜色。 |
| 边框颜色 | 设置数据图表标题区域的边框颜色。 |
| 边框线型 | 将数据图表标题区域的边框线条形状设置为实线或虚线。 |
| 边框宽度 | 设置数据图表标题区域的边框线宽度。 |
| 对齐方式 | 设置数据图表标题文本内容的对齐方式。 |
| 字体名称 | 设置数据图表标题文本的字体。 |
| 字体大小 | 设置数据图表标题文本的字体大小。 |
| 字体粗细 | 设置数据图表标题文本的字体粗细。 |
| 字体样式 | 将数据图表标题文本的字体样式设置为正常或斜体。 |
| 字体颜色 | 设置数据图表标题文本的字体颜色。 |
| 内部边距 | 调整数据图表标题区域的边距。 |

### 数据标签

此设置的属性可让你配置数据标签，以便在图表上直接显示数值，使数据解读清晰易懂。
![image.c8cc34](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1f04de1b-0add-4f88-889e-295f2a2e218b/image.c8cc34.ab1af2.png?width=400)

| **设置** | **描述** |
| --- | --- |
| 显示数据标签 | 启用数据图表上数据标签的显示，这需要与“值”、“系列”和“类别”属性结合使用。 |
| 数值 | 设置是否在数据标签中显示“值”字段的值。 |
| 格式 | 设置数据标签中“值”字段值的格式。 |
| 系列名 | 设置是否在数据标签中显示“系列”的值。 |
| 类别名 | 设置是否在数据标签中显示“类别”的值。 |
| 标签分隔符 | 设置数据标签中“值”、“系列”和“类别”属性值之间的分隔符，如逗号、分号、句号等。 |
| 显示位置 | 将数据标签的位置设置为“环绕”或“在切片上”。 |
| 背景颜色 | 设置数据标签的背景颜色。 |
| 最大宽度 | 设置数据标签的最大宽度。 |
| 重叠时隐藏 | 启用此功能可在标签重叠时隐藏部分标签。 |
| 显示连接线 | 设置是否显示数据标签与数据点之间的连接线。 |
| 连接线颜色 | 设置连接数据标签与数据点的线条颜色。 |
| 连接线宽度 | 设置连接数据标签与数据点的线条宽度。 |
| 最大线长 | 设置数据标签与数据点之间线条的最大长度。在笛卡尔坐标系中，该线为直线，因此只能设置最大长度。 |
| 字体名称 | 设置数据标签文本的字体。 |
| 字体大小 | 设置数据标签的文本大小。 |
| 字体粗细 | 设置数据标签的文本粗细。 |
| 字体样式 | 将数据标签的文本样式设置为正常或斜体。 |
| 字体超长设置 | 当数据内容太长时，该如何显示。 |
| 字体颜色 | 设置数据标签的文本颜色。 |

### 提示标签

此设置的属性用于启用工具提示并设置其样式，以便在用户将鼠标悬停在特定图表区域时提供交互式数据详细信息。
![image.2ff834](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1f04de1b-0add-4f88-889e-295f2a2e218b/image.2ff834.a6c1a4.png?width=400)

| **设置** | **描述** |
| --- | --- |
| 显示提示标签 | 在数据绑定面板中显示/隐藏提示内容。默认情况下，数据图表将显示值作为工具提示。 |
| 样式设置 | 自定义以下工具提示样式：<ul><li>背景颜色</li><li>边框颜色</li><li>边框宽度</li><li>字体颜色</li><li>字体名称</li><li>字体大小</li><li>字体粗细</li><li>删除线</li><li>上划线</li><li>下划线</li></ul> |

### 分类轴

此设置的属性在自定义类别（X 轴）和值（Y 轴）时很有用，可用于定义与数据集匹配的比例、间隔和格式。
![image.f7e6ca](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1f04de1b-0add-4f88-889e-295f2a2e218b/image.f7e6ca.6564f8.png?width=400)

| **设置** | **描述** |
| --- | --- |
| 显示轴 | 设置数据图表是否显示类别轴和值轴。 |
| 轴位置 | 设置数据图表分类轴的位置。 |
| 显示轴线 | 启用显示数据图表分类轴的轴线。 |
| 轴线宽度 | 设置数据图表分类轴的线宽。 |
| 轴线颜色 | 设置数据图表分类轴的线条颜色。 |
| 轴线类型 | 设置数据图表分类轴的轴线类型。 |
| 显示网格线 | 启用在数据图表分类轴方向上显示网格线。 |
| 网格线宽度 | 设置网格线的宽度。 |
| 网格线颜色 | 设置网格线的颜色。 |
| 网格线类型 | 设置网格线的线条类型。 |
| 显示刻度标记 | 启用显示分类轴的刻度标记。 |
| 显示刻度标签 | 启用显示分类轴刻度的标签。 |
| 标签方向 | 设置分类轴刻度标签的显示方向。 |
| 标签超长设置 | 将分类轴刻度标签溢出时的显示设置为裁剪、省略号或换行。 |
| 显示标题 | 启用显示分类轴的名称。 |
| 字体名称 | 设置分类轴中的文本字体。 |
| 字体大小 | 设置分类轴中的文本大小。 |
| 字体粗细 | 将分类轴中的文本粗细设置为更细、正常或加粗。 |
| 字体样式 | 将分类轴的文本样式设置为正常或斜体。 |
| 字体颜色 | 设置分类轴中的文本颜色。 |
| 最大值 | 设置值轴的最大刻度。 |
| 最小值 | 设置值轴的最小刻度。 |
| 间距 | 设置值轴的刻度步长。 |
| 反转 | 启用显示反转的值轴。 |
| 格式 | 设置值轴标签数据的格式。 |
| 显示单位 | 设置值轴上标签数据的数量级。 |
| @cols=2:**请注意，以下设置仅适用于“气泡图”和“散点图”类型的数据图表。** |
| 比例 | 设置分类轴的比例类型，例如，你可以将其设置为“日期”。 |
| 日期模式 | 设置日期的间隔单位，例如年、月、日等。 |
| 主要间隔 | 设置主要刻度的间隔，与“日期模式”一起使用。 |
| 次要间隔 | 设置次要刻度的间隔，与“日期模式”一起使用。 |

### 图例

使用此设置的属性，你可以管理图例样式，以有效地展示数据。
![image.4291b9](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1f04de1b-0add-4f88-889e-295f2a2e218b/image.4291b9.39108a.png?width=400)

| **设置** | **描述** |
| --- | --- |
| 显示图例 | 启用在数据图表上显示图例。 |
| 标题 | 启用显示数据图表图例的标题。 |
| 字体名称 | 设置图例的文本字体。 |
| 字体大小 | 设置图例的文本大小。 |
| 字体粗细 | 将图例的文本粗细设置为更细、正常或加粗。 |
| 字体样式 | 将图例的文本样式设置为正常或斜体。 |
| 字体颜色 | 设置图例的文本颜色。 |
| 位置 | 将图例的显示位置设置为顶部、底部、右侧或左侧。 |
| 自适应大小 | 启用自动调整图例区域。 |
| 水平对齐 | 设置数据图表中图例的水平对齐方式。 |
| 垂直对齐 | 设置数据图表中图例的垂直对齐方式。 |
| 自动折叠图例 | 启用在图例中有许多项目时自动折叠。 |

### 布局大小

此设置的属性对于组织图表布局以提高视觉清晰度是必要的。
![image.7c647b](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1f04de1b-0add-4f88-889e-295f2a2e218b/image.7c647b.b455f0.png?width=400)

| **设置** | **描述** |
| --- | --- |
| X 位置 | 设置有关数据图表当前 x 位置的信息。 |
| Y 位置 | 设置有关数据图表当前 y 位置的信息。 |
| 宽度 | 设置数据图表的宽度。 |
| 高度 | 设置数据图表的高度。 |

### 动画

此设置的属性可帮助你添加平滑效果，使数据表示具有动画效果，从而提高用户参与度。
![image.a39f40](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1f04de1b-0add-4f88-889e-295f2a2e218b/image.a39f40.4fe525.png?width=400)

| **设置** | **描述** |
| --- | --- |
| 显示悬停动画 | 启用鼠标悬停在数据点上时的动画效果。 |
| 显示更新动画 | 启用数据图表设置更改时的动画效果。 |
