# template-range

当你的报表需要重复区域、嵌套详情或能动态适配数据结构的分组汇总时，**模板区域（Template Range）** 正是你所需的工具。
它允许你直接在 SpreadJS 中设计结构化、数据驱动的报表布局——关联表格、构建层级结构，并自动渲染重复区域，无需关注字段上下文或布局逻辑。
只需将几个定义好的单元格块绑定到数据，模板区域就能将层级数据（如 客户 → 产品 → 订单详情）扩展为清晰、可重复的布局，并与数据更新保持同步。

## 支持的结构

根据数据的组织方式，模板区域支持两种结构模式：

* **嵌套层级（Nested Levels）** —— 适用于跨关联表格的层级数据（例如 客户 → 订单 → 商品）。
* **分组（Groups）** —— 适用于单个表格内的汇总或重复区域（例如 按类别分组的产品）。

## 核心功能

无论使用哪种结构模式，模板区域都具备以下核心能力：

* 可视化、基于单元格的报表设计流程
* 自动检测父子关系
* 与数据绑定和字段上下文逻辑无缝集成
* 完全支持导入/导出和撤销/重做功能

## 使用步骤

### 步骤 1：创建模板区域

1. 在报表（ReportSheet）上选择一个连续的单元格区域。
2. 在 **报表（ReportSheet）** 选项卡的 **模板区域（Template Range）** 组中，点击 **详情区（Detail）**。
3. 所选区域将成为新的 **详情区（Detail）** 区域，显示边框并标注区域名称。

![create-detail.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/create-detail-20260127.c00990.gif)

>type=note
> **注意**：
> 每个报表只能包含一个模板区域。

### 步骤 2：添加区域组件

所有区域组件的添加方式相同——选择目标单元格区域，然后在 **报表（ReportSheet）** 选项卡的 **模板区域（Template Range）** 组中选择组件类型。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image-20260127.c615ff.png)

添加后，所选区域会自动显示边框并标注组件类型。

#### 路径 A：嵌套层级结构

1. 在父级区域下方插入嵌套详情区（Nested Detail）。
    ![nested-detail.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/nested-detail-20260127.d6065c.gif)
2. 绑定数据表格
    1. 点击目标 **模板区域** 内部。
    2. 右侧将打开 **模板区域（Template Range）** 面板，显示当前的区域层级。
        ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image-20260127.ea1186.png)
    3. 在面板中选择 **详情区（Detail）** 或 **详情层级（Detail Level）** 项，点击 **绑定表格（Bind Table）**。
        ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image-20260127.9064c4.png)
    4. 从可用数据源中选择一个数据表格。
        ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image-20260127.b250f4.png)
    5. 所选表格名称将显示在区域项旁边，确认绑定成功。
        ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image-20260127.d83bfb.png)

>type=note
> **注意**：
> 详情层级（Detail Level）区域只能绑定与父表格已定义关系的子表格。

![nested-detail-binding-table.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/nested-detail-binding-table-20260127.08bb31.gif)

3. （可选）使用 **区域选择（Range Selection）** 调整区域坐标。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image-20260127.99daee.png)

#### 路径 B：分组结构

1. 在详情区周围插入分组页眉/分组页脚（Group Header/Footer）。
    ![group-header-footer](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/group-header-footer-20260127.53bfc8.gif)
2. 编辑分组和层级
    1. 在模板区域面板中点击 **分组页眉/分组页脚（Group Header/Footer）** 项。
        ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image-20260127.159b31.png)
    2. 使用 **分组字段（Group Field）** 按钮指定分组列。
        ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image-20260127.5c451c.png)
    3. 使用 **区域选择（Range Selection）** 调整分组区域边界。
        ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image-20260127.605d18.png)

### 步骤 3：设计报表布局

完成任一结构配置后，即可设计报表的外观和数据展示方式。
![design-layout.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/design-layout-20260127.4252bf.gif)

>type=note
> **注意事项**：
> 布局设计过程中，系统会自动管理上下文逻辑，确保数据绑定一致：
>
> * 字段上下文检测（Field Context Detection）—— 拖放表格字段时，系统会自动判断数据上下文和扩展方向。
> * 默认单元格类型（Default Cell Type）—— 插入的字段默认使用“列表（List）”单元格类型，采用垂直上下文。
> * 上下文初始化（Context Initialization）—— 第一个插入的字段将设置该详情区（Detail）或嵌套层级（Nested Level）的上下文。
> * 上下文复用（Context Reuse）—— 同一区域内后续插入的字段将继承已有的上下文设置。
> * 父子关系推断（Parent-Child Inference）—— 嵌套层级会自动继承父区域的上下文。
> * 编辑锁定（Edit Lock）—— 上下文设置由系统管理，无法通过 UI 编辑。
> * 字段限制（Field Restrictions）—— 未绑定的字段不能放置在任何模板区域内。

### 步骤 4：预览或重置

* 点击 **预览（Preview）** 渲染并验证报表输出效果。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image-20260127.262c54.png)
* 点击 **重置（Reset）** 清除当前模板区域。
    ![delete-range.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/delete-range-20260127.bdb5a2.gif)

>type=note
> **注意**：
> 当你删除父级 **详情区（Detail）** 或 **详情层级（Detail Level）** 时，其所有嵌套的子层级将被自动删除。

## 设计注意事项和限制

### 创建顺序

* 必须 **先创建详情区（Detail）区域**，再添加嵌套层级、分组页眉/页脚或其他模板区域组件。
* 只有存在详情区后，才能绑定数据表格。

### 区域限制

* 每个工作表 **仅支持一个模板区域**。
* 同一详情区（Detail）内不能同时存在 **嵌套层级（Nested Level）区域** 和 **分组（Group）区域**。
* 绑定到非关联表格的区域无法形成层级结构。

### 数据绑定和上下文规则

* 仅能使用该区域 **绑定表格** 中的字段。
* **第一个插入的字段** 定义数据上下文，默认使用 **列表（List）** 单元格类型和垂直扩展。
* 后续字段自动复用已有的上下文。
* 嵌套布局中，**子区域继承父详情区（Detail）的上下文和扩展方式**。
* 上下文由系统 **自动管理**，**无法通过 UI 编辑**。

### 页眉和页脚

* 这些区域会自动使用其父级详情区（Detail）绑定的表格。
* 无需直接绑定数据。

### 父子级删除规则

* 删除父级 **详情区（Detail）或详情层级（Detail Level）** 时，会自动移除所有嵌套层级。

### 区域调整和移动规则

* 当模板区域被移动或调整大小时，系统会重新评估上下文规则。
* 若任何单元格绑定了该区域表格外的字段，该绑定将被 **清除**。
* 子区域会随父级选择一起移动。
* 禁止在层级之间移动区域。
* 移动后，目标位置必须完全位于一个模板区域或工作表区域内。
* 所有模板单元格必须与目标模板区域使用相同的绑定表格。

### 模板单元格类型转换规则

| **位置** | **允许的转换** |
| --- | ----- |
| 通用/空单元格 | 空单元格 ↔ 图表 |
| 分组区域外 | 列表（List） ↔ 汇总（Summary） |
| 分组页眉/页脚内 | 分组（Group） ↔ 汇总（Summary） |

### 导入/导出和撤销/重做

* 模板区域支持以报表设计器（ReportSheet Designer）格式导入/导出。
* 所有操作均支持 **撤销/重做**。
