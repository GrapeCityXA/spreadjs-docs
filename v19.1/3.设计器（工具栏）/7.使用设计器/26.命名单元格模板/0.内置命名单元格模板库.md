# built-in-named-cell-template-gallery

SpreadJS设计器内置了多款常用命名单元格模板，可满足通用财务格式设置、状态追踪、数据可视化以及交互功能配置需求。
本页面汇总了各类模板应用后对应的配置内容。
所有模板共分为三大类别：
* 财务类
* 状态与评分类
* 数据与交互类

## 财务类模板
此类模板提供财务报表与数据分析场景中常用的标准化数字格式。
### 财务金额
适用于通用财务报表的数值格式设置。
**配置项**
* 数字格式：`#,##0.00`
* 对齐方式：右对齐
* 条件格式：负值以红色（强调色2）显示
* 数据验证：仅允许录入数值
**使用效果**
自动添加千位分隔符并保留两位小数，同时通过颜色直观区分正负金额。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260331.74a839-20260525.dd36c7.png?width=200)
### 增长率
对百分比类指标进行格式设置，用颜色区分正负数值。
**配置项**
* 数字格式：`0.00%`
* 对齐方式：右对齐
* 条件格式：
* 数值大于0 → 字体设为绿色（强调色6）
* 数值小于0 → 字体设为红色（强调色2）
**使用效果**
统一百分比展示样式，清晰凸显数据增减变化。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260331.d699d7-20260525.b12cd2.png?width=200)
### 预算差异
展示财务数据差异值，通过醒目视觉样式区分有利差异与不利差异。
**配置项**
* 数字格式：`+#,##0.00;-#,##0.00;0.00`
* 对齐方式：右对齐
* 条件格式：
* 正值 → 绿色底色搭配深绿色文字
* 负值 → 红色底色搭配深红色文字
**使用效果**
借助底色突出差异方向，便于快速对比分析。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260331.7e7567-20260525.fd45f9.png?width=200)
### 货币格式
应用美元货币专属格式样式。
**配置项**
* 数字格式：`$#,##0.00`
* 对齐方式：右对齐
**使用效果**
数值自动添加美元符号与千位分隔符。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260331.34ea6d-20260525.5ff169.png?width=200)
### 会计专用格式
适配正式财务报表的会计类数字排版格式。
**配置项**
* 货币符号对齐的会计专用数字格式
* 负值统一用括号标注
* 对齐方式：右对齐
**使用效果**
统一财务数据展示规范，标准化负值呈现形式。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260331.f7d6db-20260525.f15121.png?width=200)
## 状态与评分类模板
此类模板可实现规范化状态管理、评分体系搭建以及进度追踪功能。
### 流程状态
标准化流程状态选择器，搭配不同颜色区分各类状态。
**配置项**
* 对齐方式：居中对齐
* 数据验证：下拉选项（未开始/进行中/已完成/已停滞）
* 条件格式：
* 已完成 → 绿色底色
* 进行中 → 蓝色底色
* 未开始 → 灰色底色
* 已停滞 → 红色底色
**使用效果**
统一状态填写规范，直观区分各流程推进阶段。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260331.0c5037-20260525.ecee68.png?width=200)
### 进度条
以可视化数据条形式展示完成进度。
**配置项**
* 数字格式：百分比格式
* 对齐方式：居中对齐
* 条件格式：数据条（数值范围0-100%）
* 数据验证：仅可录入0至1之间的小数
**使用效果**
可视化展示完成占比，同时保留原始数值信息。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260331.5e60e6-20260525.8b7d78.png?width=200)
### 优先级等级
带颜色区分的优先级选择工具。
**配置项**
* 对齐方式：居中对齐
* 数据验证：下拉选项（高/中/低）
* 条件格式：
* 高优先级 → 红色底色
* 中优先级 → 黄色底色
* 低优先级 → 绿色底色
**使用效果**
统一优先级划分标准，直观标注事务紧急程度。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260331.40f5b1-20260525.77df1f.png?width=200)
### 截止日期
将单元格设置为日期格式，并高亮提醒临近及逾期事项。
**配置项**
* 日期格式：`yyyy-mm-dd`
* 对齐方式：居中对齐
* 数据验证：限定合法日期范围
* 条件格式：
* 已逾期 → 红色底色
* 今日到期 → 黄色底色
**使用效果**
醒目展示时效类事务，快速识别即将到期与已逾期任务。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/image-20260331.92f85b-20260525.48a91d.png?width=200)
### 等级评分

* 90-100分 → 深绿色
* 80-89分 → 浅绿色
* 70-79分 → 黄色
* 60-69分 → 浅红色
* 60分以下 → 深红色

## 数据与交互类模板
此类模板能够强化数据可视化效果，丰富表格交互使用体验。
### 热力图
依据单元格数值大小自动应用三色渐变配色。
**配置项**
* 对齐方式：居中对齐
* 条件格式：三色色阶
* 最小值 → 红色（强调色2）
* 中间值 → 黄色（强调色4）
* 最大值 → 绿色（强调色6）
**使用效果**
借助渐变色彩清晰展现区间内的数据分布情况。
![热力图.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/Heat20Map-20260331.f3bf6e-20260525.f8d0f0.gif?width=200)
### 可编辑输入框
打造表单式输入单元格，搭配动态交互视觉反馈。
**配置项**
* 基础样式：白色底色，底部设强调色5边框
* 单元格状态样式：
* 鼠标悬浮 → 浅蓝色底色
* 编辑状态 → 蓝色底色且显示完整边框
* 激活状态 → 强调色1边框
**使用效果**
让可编辑单元格具备表单式操作反馈效果。
![可编辑输入框.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/EditableField-20260331.b88762-20260525.c8ce98.gif?width=200)
### 极值标注
自动标注数据区间内数值排名前10%与后10%的数据。
**配置项**
* 对齐方式：右对齐
* 条件格式：
* 前10%数值 → 绿色底色
* 后10%数值 → 红色底色
**使用效果**
快速筛选出数据集中的极值数据。
![极值标注.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/TopBottom-20260331.6ec0e7-20260525.059127.gif?width=200)
### 重复值检测
自动高亮标注指定区域内的重复内容。
**配置项**
* 条件格式：重复值规则（黄色底色搭配深黄色文字）
**使用效果**
助力用户排查重复数据，完成数据校验与清理工作。
![重复值检测.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/DuplicateCheck-20260331.cf9e8b-20260525.17d3df.gif?width=200)
### 电子邮箱格式框
专为邮箱录入设计单元格格式，并校验录入内容格式。
**配置项**
* 对齐方式：左对齐
* 字体颜色：强调色1（蓝色）
* 数据验证：邮箱格式校验规则并附带录入提示
**使用效果**
引导用户规范填写邮箱地址，同时从视觉上区分邮箱录入单元格。
![电子邮箱格式框.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/0f73f140-2ccc-4566-a244-10944255eeb4/EmailAddress-20260331.4c173c-20260525.b3982f.gif?width=200)
### 选中行高亮
自动高亮选中单元格所在的整行内容。
**配置项**
* 条件格式：行状态选中规则
* 底色：半透明强调色1
**使用效果**
在海量数据表格中更方便定位查看整行信息。

鼠标移动至某一行时，自动高亮该行内容。
**配置项**
* 条件格式：行状态悬浮规则
* 底色：半透明强调色5
**使用效果**
提升批量浏览数据时的阅读舒适度。

### 十字光标定位
同时高亮选中单元格所在的整行与整列。
**配置项**
* 条件格式：
* 行选中状态规则
* 列选中状态规则
* 单元格状态调整：选中单元格设为透明底色，避免色彩重叠遮挡
**使用效果**
在矩阵式数据表格中精准定位数据位置。
