# nextjs

## 内容

SpreadJS Designer Component 支持 NextJS。NextJS 是一个基于 React 的框架，可用于开发适用于 Windows、Linux 和 Mac 等不同平台的 Web 应用程序。NextJS 提供了生产环境所需的全部功能，包括 TypeScript 支持、混合静态与服务器渲染、路由预取以及智能打包。
有关更多信息，请参阅 [https://nextjs.org/docs/getting-started](https://nextjs.org/docs/getting-started "https://nextjs.org/docs/getting-started")。
在本教程中，我们将构建一个使用 SpreadJS Designer Component 的 Next.js 应用程序。

>type=note
> **注意**：SpreadJS Designer Component 现已支持 NextJS version 16。要创建 Next.js 应用程序，请确保已安装的 Node.js 版本为 20.9 或更高版本。

## 创建 Next.js 应用

要创建 Next.js 应用程序，最简单的方式是在 CLI 工具中使用 `create-next-app` 命令。
创建项目之前，请确保已经安装 Node.js 和 npm。你可以使用以下命令检查已安装的版本。

```bash
node -v
npm -v
```

`npx create-next-app@latest` 命令会自动下载并运行 `create-next-app`，因此无需全局安装 `create-next-app`。你也可以使用 npm create 命令，即 `npm create next-app@latest`。

1. 从命令提示符或终端运行以下命令，创建一个 Next.js TypeScript 项目。

```bash
npx create-next-app@latest
```

2. 输入项目名称，例如 *nextjs-with-spreadjs-designer*。
3. 依赖安装完成后，在终端中输入以下命令启动项目。

```bash
cd nextjs-with-spreadjs-designer
npm run dev
```

4. 使用浏览器打开 [http://localhost:3000](http://localhost:3000/ "http://localhost:3000")。随后你会看到 NextJS 的欢迎页面。
5. 关闭当前终端，并使用 Visual Studio Code 或 IDE 打开 *nextjs-with-spreadjs-designer* 文件夹。

## 安装 SpreadJS Designer Component

1. 安装 SpreadJS Designer Component 包。

```bash
npm install @grapecity-software/spread-sheets @grapecity-software/spread-sheets-io @grapecity-software/spread-sheets-barcode @grapecity-software/spread-sheets-charts @grapecity-software/spread-sheets-languagepackages @grapecity-software/spread-sheets-pdf @grapecity-software/spread-sheets-print @grapecity-software/spread-sheets-shapes @grapecity-software/spread-sheets-tablesheet @grapecity-software/spread-sheets-pivot-addon @grapecity-software/spread-sheets-designer @grapecity-software/spread-sheets-designer-resources-en @grapecity-software/spread-sheets-designer-react
```

2. 创建一个名为 *designer.tsx* 的 TypeScript 文件，将其添加到 app 文件夹中，并写入以下代码。

```typescript
'use client';

import React, { useState } from "react";
import GC from "@grapecity-software/spread-sheets";
import "@grapecity-software/spread-sheets-io";
import "@grapecity-software/spread-sheets-barcode";
import "@grapecity-software/spread-sheets-charts";
import "@grapecity-software/spread-sheets-languagepackages";
import "@grapecity-software/spread-sheets-pdf";
import "@grapecity-software/spread-sheets-print";
import "@grapecity-software/spread-sheets-shapes";
import "@grapecity-software/spread-sheets-tablesheet";
import "@grapecity-software/spread-sheets-pivot-addon";

import "@grapecity-software/spread-sheets-designer-resources-en";
import GCD from "@grapecity-software/spread-sheets-designer";
import { Designer } from "@grapecity-software/spread-sheets-designer-react";

// Optional: Set your SpreadJS license key and Designer Component license key
// GC.Spread.Sheets.LicenseKey = "your-spreadjs-license-key";
// GCD.Spread.Sheets.Designer.LicenseKey = "your-designer-component-license-key";

export default function SpreadJSDesigner() {

    const [styleInfo, setStyleInfo] = useState({
        width: '100%',
        height: '90vh'
    });
    return (
        <Designer
            styleInfo={styleInfo}
            designerInitialized={(designer: GCD.Spread.Sheets.Designer.Designer) => {
                const workbook = designer.getWorkbook() as GC.Spread.Sheets.Workbook;
                const sheet = workbook.getActiveSheet();
                sheet.setValue(1, 1, 'Test');
            }}>
        </Designer>);
}
```

3. 修改 index 文件内容。将 *app/page.tsx* 文件的默认内容替换为以下代码。

```typescript
'use client';
import dynamic from "next/dynamic";

const SpreadJSDesigner = dynamic(
  () => {
    return import("./designer");
  },
  { ssr: false }
);

export default function Home() {
  return (
    <div>
      <h1>
        Next.JS 16 + SpreadJS Designer Component demo
      </h1>
      <SpreadJSDesigner />
    </div>
  )
}
```

>type=note
> 需要使用带有 `ssr: false` 的 `next/dynamic`，因为 SpreadJS Designer Component 依赖浏览器特定 API（`window`、`document`、Canvas）。必须为 SpreadJSDesigner 组件禁用 SSR。请确保在 Client Component（使用 `'use client'` 标记）中使用带有 `ssr: false` 的 `next/dynamic`。

## 在 Next.js 16 中导入 SpreadJS

使用带有 Turbopack 的 Next.js 16 时，我们建议使用默认导入语法导入 SpreadJS 核心包：

```auto
import GC from "@grapecity-software/spread-sheets";
import GCD from "@grapecity-software/spread-sheets-designer";
```

>type=warning
> 避免使用命名空间导入形式：

 ```typescript
import * as GC from "@grapecity-software/spread-sheets";
import * as GCD from "@grapecity-software/spread-sheets-designer";
 ```

在某些 Next.js 16 环境中，命名空间导入可能会阻止 SpreadJS 插件包（例如 Pivot 或 Report）正确扩展 `GC` 对象。因此，即使已安装相应插件包，某些命名空间（例如 `GC.Spread.Pivot` 或 `GC.Spread.Report`）也可能显示为 undefined。
使用默认导入可以确保插件模块能够将其功能正确附加到 SpreadJS 核心对象。

## 导入样式

通过在 *app* 文件夹中的 *globals.css* 文件里添加以下行，将 SpreadJS CSS 和 Designer Component CSS 导入应用程序。

```css
@import '@grapecity-software/spread-sheets/styles/gc.spread.sheets.excel2013white.css';
@import '@grapecity-software/spread-sheets-designer/styles/gc.spread.sheets.designer.light.min.css';
```
