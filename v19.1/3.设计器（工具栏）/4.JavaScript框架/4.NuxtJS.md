# nuxtjs

## 内容

SpreadJS Designer Component 可与 Nuxt 3 和 Nuxt 4 无缝配合使用。
本教程介绍如何在 Nuxt 项目中集成 SpreadJS Designer Component，将其配置为客户端渲染，并启用类似 Excel 的编辑工具。

## 在 Nuxt 应用中集成 SpreadJS Designer Component

### 第 1 步：设置 Nuxt 项目

你可以使用任何现有的 Nuxt 3 或 Nuxt 4 项目。
如果想从一个干净的环境开始，请运行：

```bash
npm create nuxt@latest nuxt-with-spreadjs-designer
```

当终端提示配置选项时，选择所需选项并按 Enter 键确认。在本教程中，你可以选择以下选项：

* Template: Minimal
* Package manager: npm
* Initialize git repository: Yes
* Would you like to browse and install modules?: No

等待一段时间，让终端安装依赖并创建项目。然后在终端中输入以下命令：

```bash
cd nuxt-with-spreadjs-designer
npm install
```

>type=note
> **注意：**
> 如果 `npm install` 失败，并提示 `Cannot find native binding` 或缺少 `@rolldown/binding-*` 包，请删除 `node_modules` 文件夹和 `package-lock.json` 文件，然后再次运行 `npm install`。

然后启动应用：

```bash
npm run dev
```

确认基础 Nuxt 应用可以运行后（*[http://localhost:3000](http://localhost:3000/ "http://localhost:3000")*），即可开始集成 SpreadJS Designer Component。

### 第 2 步：安装并配置 SpreadJS Designer Component

1. **安装 SpreadJS Designer Component 包**

```bash
npm i --save @grapecity-software/spread-sheets @grapecity-software/spread-sheets-barcode @grapecity-software/spread-sheets-charts @grapecity-software/spread-sheets-datacharts-addon @grapecity-software/spread-sheets-designer @grapecity-software/spread-sheets-designer-resources-en @grapecity-software/spread-sheets-designer-vue @grapecity-software/spread-sheets-formula-panel @grapecity-software/spread-sheets-ganttsheet @grapecity-software/spread-sheets-io @grapecity-software/spread-sheets-languagepackages @grapecity-software/spread-sheets-pdf @grapecity-software/spread-sheets-print @grapecity-software/spread-sheets-pivot-addon @grapecity-software/spread-sheets-reportsheet-addon @grapecity-software/spread-sheets-shapes @grapecity-software/spread-sheets-slicers @grapecity-software/spread-sheets-tablesheet
```

2. **添加 SpreadJS Designer Component**
    在 Nuxt 项目的根文件夹中创建一个名为 components 的文件夹。如果该文件夹不存在，请先创建它。在 `components` 文件夹中创建一个名为 `Spreadsheet.vue` 的文件。例如，在本教程中，该文件路径为 `nuxt-with-spreadjs-designer/components/Spreadsheet.vue`。按如下方式定义组件。

```auto
<template>
    <div id="gc-designer-container">
        <gc-spread-sheets-designer :styleInfo="styleInfo" :config="config" :spreadOptions="spreadOptions"
            @designerInitialized="initDesigner" />
    </div>
</template>

<script setup>
import "@grapecity-software/spread-sheets/styles/gc.spread.sheets.excel2013white.css";
import "@grapecity-software/spread-sheets-designer/styles/gc.spread.sheets.designer.light.min.css";

import "@grapecity-software/spread-sheets-print";
import "@grapecity-software/spread-sheets-shapes";
import "@grapecity-software/spread-sheets-datacharts-addon";
import "@grapecity-software/spread-sheets-slicers";
import "@grapecity-software/spread-sheets-pivot-addon";
import "@grapecity-software/spread-sheets-tablesheet";
import "@grapecity-software/spread-sheets-ganttsheet";
import "@grapecity-software/spread-sheets-reportsheet-addon";
import "@grapecity-software/spread-sheets-formula-panel";
import "@grapecity-software/spread-sheets-io";
import "@grapecity-software/spread-sheets-designer-resources-en";

import * as GC from "@grapecity-software/spread-sheets";
import * as GCD from "@grapecity-software/spread-sheets-designer";
import GcSpreadSheetsDesigner from "@grapecity-software/spread-sheets-designer-vue";

// Optional: Set your SpreadJS license key and Designer Component license key
// GC.Spread.Sheets.LicenseKey = "sjs-distribution-key";
// GCD.Spread.Sheets.Designer.LicenseKey = "designer-component-distribution-key";

const styleInfo = { height: "85vh", width: "100%" };
const config = GCD.Spread.Sheets.Designer.DefaultConfig;
const spreadOptions = { sheetCount: 2 };

let designer = null;

function initDesigner(value) {
    designer = value;
    console.log("Designer initialized:", designer);

    const spread = designer.getWorkbook();
    if (spread) {
        const sheet = spread.getSheet(0);
        sheet.setValue(0, 0, "Welcome to SpreadJS Designer!");
    }
}
</script>

<style scoped>
#gc-designer-container {
    width: 100%;
    height: 100%;
}
</style>
```

3. **在主应用中使用该组件**
    将 `app.vue` 的默认内容替换为：

```auto
<template>
  <div>
    <h1>
      Nuxt.JS + SpreadJS Designer Component Demo
    </h1>
    <SpreadSheet />
  </div>
</template>

<script setup>
import SpreadSheet from "../components/Spreadsheet.vue";
</script>
```

4. **更新 Nuxt 配置（可选）**

```auto
// https://nuxt.com/docs/api/configuration/nuxt-config
export default defineNuxtConfig({
  //...

  ssr: false,
  components: true,
})
```

>type=note
> **注意：**
> SpreadJS Designer Component 依赖浏览器 API，并且只能在客户端运行。在 SSR 模式下使用 Nuxt 时，请将 SpreadJS Designer Component 包裹在 \<client-only> 标签中，或将其注册为仅客户端插件（例如 plugins/spreadjs.client.ts）。

### 第 3 步：运行并验证集成

```bash
npm run dev
```

应用应可通过 *[http://localhost:3000](http://localhost:3000/ "http://localhost:3000")* 访问，并在 Nuxt 应用中渲染 SpreadJS Designer Component。
