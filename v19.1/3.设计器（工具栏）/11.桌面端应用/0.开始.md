# spdesigner-gettingstarted

## 系统要求

SpreadJS桌面设计器是一款基于Electron开发的应用程序，所需最低操作系统版本如下：

| 平台 | 最低版本 |
| --- | ---- |
| Windows | Windows 10 |
| macOS | macOS 12 Monterey |
| Linux | Ubuntu 20.04 LTS |

>type=info
> 重要提示：从19.1版本开始，SpreadJS桌面设计器将不再支持以下操作系统：
>
> * Windows 7, Windows 8 / 8.1
> * macOS 11 Big Sur and earlier
> * Ubuntu 18.04 LTS

### macOS架构适配说明（19.1版本重大变更）

自19.1版本起，适用于macOS系统的SpreadJS桌面设计器仅支持苹果自研芯片（Arm64架构）设备。
不再提供英特尔（x86\_64架构）版本安装包。
若你使用搭载英特尔处理器的苹果电脑设备，可选择以下替代使用方式：

* SpreadJS在线设计器
* SpreadJS代码编辑器扩展插件

## 安装流程

你可以通过以下方式安装 SpreadJS 设计器：将 SpreadJS ZIP 文件（SpreadJS.Release.xxxx.zip）下载到系统的临时目录中，然后在将文件解压到某个目录后，执行相应的安装文件。

>type=info
> **注意：** SpreadJS 设计器已包含在 SpreadJS 产品下载包中。

| **安装目录** | **文件** | **说明** |
| ---- | --- | --- |
| @rows=4:\\SpreadJS.Release.xxxx\\Designer\\Designer Runtime |  | 产品主目录 |
| SpreadJS-Designer.xxx.exe | Windows 系统的安装程序 |
| SpreadJS-Designer.xxx.dmg | MacOS 系统的安装程序 |
| SpreadJS-Designer.xxx.AppImage | Linux 系统的安装程序 |

## 许可证信息

桌面 SpreadJS 设计器有以下几种类型的许可证或状态：

### 无授权状态

未授权状态下，桌面 SpreadJS 设计器会提示您输入激活许可的 key，如下图所示：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.bd8811.png)
您可以通过申请，免费获取到评估许可，或者通过购买获取正式许可。

### 评估许可证

评估许可证允许您使用桌面 SpreadJS 设计器的所有功能。
但是，应用程序窗口的顶部栏显示以下消息：
*"试用授权剩余（xx天），可点击左侧“解锁按钮”输入正式授权。"*
右下角会显示水印。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.9c8d82.png)

### 正式授权

许可版本允许您使用桌面 SpreadJS 设计器的所有功能。

### 输入许可证

桌面 SpreadJS 设计器的许可证密钥应在“许可证信息”对话框中设置
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.72810b.png)
如果通过上述对话框应用了无效的许可证密钥，则会在顶部和电子表格区域中显示以下消息：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.3b493f.png)

## 数据透视表插件

在 14.1 或更高版本中，桌面 SpreadJS 设计器默认包含数据透视表插件，仅供开发人员使用。这未获得部署许可。
