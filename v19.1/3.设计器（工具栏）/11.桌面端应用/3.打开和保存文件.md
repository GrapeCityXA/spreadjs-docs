# spdesigneropen

# 文件操作指南

你可以打开和保存现有的 Excel 格式文件（.xlsx、.xlsm、.xltm）、逗号分隔值文件（.csv）以及 Spread 格式文件（.ssjson）。此外，若你需要为设计器导入这些文件内容时设置选项，也可选择导入操作。
在保存文件时，SpreadJS 会在每次保存工作簿时记录工作表视图的位置。与 Excel 类似，下次打开同一工作簿时，系统会自动滚动到你上次保存前离开的位置。该功能通过记录工作表的左上角单元格实现，确保用户保存工作簿时工作表视图位置保持不变。例如，若你上次保存工作簿时，工作表左上角单元格为 A10，那么当你再次打开该工作簿时，工作表会自动滚动，使 A10 单元格位于左上角位置。

## 打开和导入文件

**打开新文件**：点击“文件”，选择“新建”。在“新建”对话框中，点击“空白”即可打开新的电子表格。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.e123bb.png)
**打开现有文件**：点击工具栏中的“打开”。在“打开”对话框中，浏览并找到需打开的文件。你可从下拉列表中选择文件类型，以筛选浏览时显示的文件；但需注意，若点击“文件”后选择“打开”，则仅允许打开现有的 SpreadJS 格式文件。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.ed3b21.png)
**导入现有文件并选择导入设置**：点击“文件”，选择“导入”。在“导入”菜单页面，选择需导入的文件类型，然后指定导入文件的相关设置。此外，若需将工作表表格转换为数据表，必须启用“将工作表表格转换为数据表”选项。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.89fe75.png)
导入 Excel 文件时，需从格式选择下拉列表中选择所需的文件格式（.xlsx、.xlsm、.xltm）。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.16e8e4.png?width=800)

>type=info
> **说明：**
>
> * 在 SpreadJS 中无法查看、编辑或执行宏。所有修改仅适用于工作簿数据，不影响宏代码。
> * 在 SpreadJS 中修改工作表布局，可能会影响引用特定单元格地址的宏逻辑。

## 保存和导出文件

当你完成对已打开或新建电子表格的编辑后，可将其保存为 Spread 格式文件（.ssjson）、Excel 格式文件或逗号分隔值文件（.csv）。以这些格式保存的文件，可通过 SpreadJS 设计器重新打开，或加载到应用程序中的 SpreadJS 组件中。

>type=info
> **说明：**
> 若将文件保存/导出为 .xlsx 格式或 SpreadJS 内部格式（.sjs、.ssjson），宏将**不会被保留**。

**保存电子表格**：点击工具栏中的“保存”。在“保存”对话框中，浏览并确定文件的保存路径，指定文件名并设置文件类型。但需注意，若点击“文件”后选择“保存”，则仅允许将电子表格保存为 SpreadJS 格式文件。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.c03dad.png)
你可通过“保存”选项将文件保存为 JavaScript 格式（.js），该格式文件仅能通过 [fromJSON ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#fromjson)方法加载。
你还可将电子表格导出为 Spread 格式文件（.ssjson）、Excel 格式文件（.xlsx）、逗号分隔值文件（.csv）、可移植文档格式文件（.pdf）或 JavaScript 格式文件（.js）。选择导出操作时，可指定电子表格的导出相关选项。
**导出电子表格**：点击“文件”，选择“导出”。在“导出”菜单页面，选择需导出的文件类型，然后在“Excel 文件”部分指定导出文件的设置。若需导出数据表绑定，需启用“包含绑定源”选项。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.58cb23.png)
导出为 Excel 格式时，需从格式选择下拉列表中选择所需的文件格式（.xlsx、.xlsm、.xltm）。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.580722.png)

>type=info
> **警告：**
> 宏可能传播恶意软件，因此 Excel 会将来自互联网的启用宏文件标记为不可信。在 Excel 中打开从 SpreadJS 导出的宏工作簿时，**需先启用宏**，否则宏无法运行。详情请参阅：[默认阻止 Internet 宏 | Microsoft Learn](https://learn.microsoft.com/en-us/microsoft-365-apps/security/internet-macros-blocked "https://learn.microsoft.com/en-us/microsoft-365-apps/security/internet-macros-blocked")。
