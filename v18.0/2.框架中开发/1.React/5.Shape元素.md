# UsingtheShapeElement

在React中使用SpreadJS的形状（Shape）元素，你可以轻松地在工作表中快速嵌入并呈现各种形状，包括正方形、圆形、矩形、三角形、五边形、六边形、八边形等几何图形。

1. **创建React项目**
打开命令提示符窗口，输入以下命令：
    ```Shell
    npm install -g create-react-app
    create-react-app quick-start
    cd quick-start
    npm start
    ```
完成后，React项目将在目录中的指定位置创建。有关如何创建React项目的更多信息，请参阅[https://reactjs.org/docs/create-a-new-react-app.html](https://reactjs.org/docs/create-a-new-react-app.html)。

2. **在项目中安装SpreadJS React模块**
接下来，你需要使用以下命令在项目中安装@grapecity-software/spread-sheets-react：
`Shell npm install @grapecity-software/spread-sheets-react `

3. **导入SpreadJS CSS**
接下来，你需要使用以下代码在index.js文件中导入SpreadJS CSS：
    ```JavaScript
    import '@grapecity-software/spread-sheets/styles/gc.spread.sheets.excel2013white.css';
    ```
4. **在项目中安装形状React模块**
接下来，你需要使用以下命令在项目中安装形状模块：
    ```Shell
    npm install @grapecity-software/spread-sheets-shapes
    ```
5. **在React应用程序中使用形状**
现在，你可以根据需求修改App.js文件。浏览器窗口刷新时，更改将立即生效。例如，你可以使用以下示例代码：
此示例展示了如何在React应用程序中使用形状。
    ```JavaScript
    import React from "react";
    import "./App.css";
    import GC from "@grapecity-software/spread-sheets";
    import { SpreadSheets, Worksheet } from "@grapecity-software/spread-sheets-react";
    
    // 导入形状模块
    import "@grapecity-software/spread-sheets-shapes";
    
    var SpreadJSKey = "xxx";
    GC.Spread.Sheets.LicenseKey = SpreadJSKey;
    
    class App extends React.Component {
      constructor(props) {
        super(props);
        this.hostStyle = {
          width: "1100px",
          height: "800px",
        };
      }
    
      // 处理工作簿初始化事件
      workbookInit = (spread) => {
        this.setState({
          spread: spread,
        });
    
        // 获取工作表
        let sheetShape = spread.getSheet(0);
    
        // 设置工作表名称
        sheetShape.name("Shapes");
        sheetShape.suspendPaint();
    
        // 添加内置形状“甜甜圈”
        var donutShape = sheetShape.shapes.add(
          "autoShape",
          GC.Spread.Sheets.Shapes.AutoShapeType.donut,
          50,
          50,
          150,
          150
        );
    
        // 向内置形状“甜甜圈”添加文本
        donutShape.text("Donut Shape");
    
        // 向内置形状“甜甜圈”添加样式
        var shapeStyle = donutShape.style();
        shapeStyle.textEffect.color = "Red";
        shapeStyle.textEffect.font = "18px Arial";
        shapeStyle.textFrame.hAlign = GC.Spread.Sheets.HorizontalAlign.center;
        shapeStyle.textFrame.vAlign = GC.Spread.Sheets.VerticalAlign.center;
        donutShape.style(shapeStyle);
    
        sheetShape.resumePaint();
      };
      render() {
        return (
          <div>
            <SpreadSheets
              backColor={this.spreadBackColor}
              hostStyle={this.hostStyle}
              workbookInitialized={this.workbookInit}
            >
              <Worksheet></Worksheet>
            </SpreadSheets>
          </div>
        );
      }
    }
    
    export default App;    
    ```
