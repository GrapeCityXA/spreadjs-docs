# CreatingSunburstChart

旭日图以图形形式展示分层数据集，其中针对多个类别或层级的数据按行和列进行绘制。
SpreadJS 支持旭日图，使用户在工作表中处理表格和关系数据库时，能够分析同质和异质数据。此外，这种类型的图表有助于用户将数据分解为不同的实体，以便快速、高效地识别和可视化不同业务场景中的多级父子关系。

## 旭日图的工作原理

通常，旭日图是由多个层级或类别创建的。每个类别或层级由一个圆环或圆圈表示，最内层的圆圈描绘最高层级，从而展示外层圆环（子类别或子层级）与内层圆环（父类别或最高层级）之间的关系。
在 SpreadJS 中，[Points ](gcdocsite__documentlink?toc-item-id=64ea8d29-4e4c-4afb-8349-6d8087bfb364)类表示图表系列中的所有数据点。数据点可用于表示分层数据中的每个最高层级及其子数据点。
如果创建的旭日图只有一个类别或层级，它的外观类似于圆环图。当用户想要展示一个类别或层级（圆环）如何分解为其组成部分时，旭日图尤其有用。

最内层的圆圈展示了所有四个最高层级（亚洲、非洲、欧洲和其他地区），其中亚洲是世界上人口最多的地区，欧洲是世界上人口最少的地区。此外，根据上述图表，人口最多的国家是东亚次区域的中国。
以下代码示例展示了如何在电子表格中创建旭日图来分析世界人口。

```javascript
// 创建旭日图
window.onload = function () {
    var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'));
    var sheet = spread.getActiveSheet();
    sheet.setColumnWidth(2, 100);
    sheet.setColumnWidth(4, 100);
    var dataArray = [
        ['地区', '次区域', '国家', '人口'],
        ['亚洲', '南部', '印度', 954051854],
        [, , '巴基斯坦', 200813818],
        [, , '泰国', 466368149],
        [, , '其他', 170220300],
        [, '东部', '中国', 1215045928],
        [, , '日本', 527185332],
        [, , '其他', 191652273],
        [, '东南部', , 955036576],
        [, '西部', , 272298399],
        [, '中部', , 71860465],
        ['非洲', '东部', , 433043132],
        [, '西部', , 381980688],
        [, '北部', , 237784677],
        [, '其他', , 234512021],
        ['欧洲', , , 742648010],
        ['其他', , , 1057117703],
    ];

    sheet.setArray(1, 1, dataArray);
    var chart = sheet.charts.add('chart1', GC.Spread.Sheets.Charts.ChartType.sunburst, 450, 0, 500, 500, 'B2:E18');
    var title = chart.title();
    title.fontSize = '24.00';
    title.color = 'rgb(228,65,54)';
    title.text = '世界人口';
    chart.title(title);
    var dataPoints = chart.series().dataPoints();
    var fillColors = ['#4472c4', '#a5a5a5', '#ffc000', '#ed7d31'];
    fillColors.forEach(function (color, index) {
        var dataPoint = dataPoints.get(index);
        dataPoint.fillColor = color;
        dataPoint.transparency = 0; // 0~1
        dataPoints.set(index, dataPoint);
    });
};
```

> **注意**：旭日图仅支持一个系列。此外，旭日图中的数据标签可以配置为仅显示类别名称。
