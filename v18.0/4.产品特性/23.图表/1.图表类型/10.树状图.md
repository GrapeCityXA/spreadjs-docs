# CreatingTreemapChart

矩形树状图是一种二维线性图表，可用于在工作表中以树状结构排列的一组嵌套矩形的形式来显示分层数据。
SpreadJS 在电子表格中支持矩形树状图，以增强数据可视化效果并进行有效的信息分析。当用户面临空间限制，且需要在工作表的表格中绘制包含众多实体的数千个数据点时，这种类型的图表尤为有用。

## 矩形树状图的工作原理

在矩形树状图中，用户可以通过将数据可视化为彩色矩形（称为分支），来比较一个或多个类别内的定量值或聚合值。每个分支（或矩形）代表层次结构中的一个层级，其中包含其他矩形（称为叶子节点）。每个矩形的面积（内部空间）是根据所测量的定量值来分配的。这些矩形根据它们的数值维度（宽度和高度）从左上角（最大尺寸）到右下角（最小尺寸）进行排列。
在 SpreadJS 中，[Points ](gcdocsite__documentlink?toc-item-id=64ea8d29-4e4c-4afb-8349-6d8087bfb364)类表示图表系列中的所有数据点。数据点可用于表示分层数据中的每个最高层级及其子数据点。

上图中的彩色矩形描绘了四个不同的类别（亚洲、非洲、欧洲和其他地区），其中亚洲是世界上人口最多的地区（位于左上角的最大矩形），欧洲是世界上人口最少的地区（位于右下角的最小矩形）。此外，根据上述图表，人口最多的国家是东亚次区域的中国。
以下代码示例展示了如何在工作表中设置矩形树状图。

```javascript
// 创建矩形树状图
window.onload = function () {
    var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'));
    var sheet = spread.getActiveSheet();
    sheet.setColumnWidth(2, 100);
    sheet.setColumnWidth(4, 100);
    var dataArray = [
        ['地区', '次区域', '国家', '人口'],
        ['亚洲', '南部', '印度', 1354051854],
        [, , '巴基斯坦', 200813818],
        [, , '孟加拉国', 166368149],
        [, , '其他', 170220300],
        [, '东部', '中国', 1415045928],
        [, , '日本', 127185332],
        [, , '其他', 111652273],
        [, '东南部', , 655636576],
        [, '西部', , 272298399],
        [, '中部', , 71860465],
        ['非洲', '东部', , 433643132],
        [, '西部', , 381980688],
        [, '北部', , 237784677],
        [, '其他', , 234512021],
        ['欧洲', , , 742648010],
        ['其他', , , 1057117703],
    ];

    sheet.setArray(1, 1, dataArray);
    var chart = sheet.charts.add('chart1', GC.Spread.Sheets.Charts.ChartType.treemap, 450, 0, 500, 500, 'B2:E18');
    var title = chart.title();
    title.fontSize = '24.00';
    title.color = 'rgb(228,65,54)';
    title.text = '世界人口';
    chart.title(title);
    var dataPoints = chart.series().dataPoints();
    var fillColors = ['#4472c4', '#a5a5a5', '#ffc000', '#ed7d31'];
    fillColors.forEach(function (color, index) {
        var dataPoint = dataPoints.get(index);
        dataPoint.fillColor = color;
        dataPoint.transparency = 0; // 0~1
        dataPoints.set(index, dataPoint);
    });
};
```

> **注意**：矩形树状图仅支持一个系列。此外，矩形树状图中的数据标签可以配置为仅显示类别名称。
