# waterfall-chart

瀑布图是一种可视化工具，用于展示一系列正负值如何影响初始值。在瀑布图中，绘制的值像瀑布一样从左向右流动，并在不同的列或步骤中表示对结果有贡献的每个阶段或因素。
SpreadJS 支持瀑布图，它有助于理解按顺序引入的正值或负值的累积影响。瀑布图通常用于金融、项目管理和其他与业务相关的场景中，以展示起始值细分为各个组成部分的情况。
该图表通常从一个代表初始值的条形开始，随后添加其他条形来表示正负变化。正值通常表示为高于初始值的条形，而负值表示为低于初始值的条形。最后一个条形代表最终的总和或结果。
**示例**：让我们来看一个瀑布图的简单示例，展示一名员工的月工资情况。假设你从基本工资开始，然后加上或减去每个月的工资以显示最终收入。你可以使用系列中的 `subtotals` 属性来接受一个你想要设置为总计的点索引的组合数组。
你还可以设置 `showConnectorLines` 属性来显示连接线，这些线将每一列的末尾与下一列的开头连接起来，以展示图表中的数据流向。
![waterfall-classic.63f20e](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/waterfall-classic.63f20e.12b65f.png)
以下代码示例展示了如何在电子表格中创建一个瀑布图来分析月工资情况。

```javascript
var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });
var sheet = spread.getActiveSheet();
var dataArray = [
    ['起始', 800],
    ['一月', 1000],
    ['二月', 1200],
    ['三月', 500],
    ['四月', -800],
    ['五月', -400],
    ['六月', 300],
    ['七月', -700],
    ['八月', -1000],
    ['九月', 700],
    ['十月', 1200],
    ['十一月', 2000],
    ['十二月', 2400],
    ['结束', 7200]
];
sheet.setArray(0, 0, dataArray);

// 基本瀑布图
let chart = sheet.charts.add("baseWaterfallChart", GC.Spread.Sheets.Charts.ChartType.waterfall, 300, 0, 700, 450, "A1:B14");
let title = chart.title();
title.text = "月收入";
title.fontSize = 16;
chart.title(title);
let series = chart.series().get(0);
series.showConnectorLines = true;
series.subtotals = [13];  
chart.series().set(0, series);
```

然而，瀑布图存在一些限制，例如：

* 它们不能切换方向，并且只支持一个有效的系列。
* 它们不支持设置误差线和趋势线。
* 瀑布图的连接线样式与系列边框样式相同。
* 它们不能与其他图表类型组合使用。

## 自定义瀑布图

自定义瀑布图是指经过定制或修改的瀑布图，以满足超出标准表示形式的特定需求或要求。可以使用一些额外的功能来创建自定义瀑布图，例如通过将 `showValue` 属性设置为 `true` 来设置用户界面行为的格式，以便在点击数据列项目后显示相应的值。你还可以使用 `backColor` 或 `fontSize` 等属性来修改图表的外观。
参考以下图片，该图片显示了与数据列项目相关联的值，其中图例的背景颜色也已修改。
![waterfall-ui-behavior.32c371](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/waterfall-ui-behavior.32c371.4088bf.png)
以下示例代码实现了自定义瀑布图。

```javascript
let chart = sheet.charts.add("customWaterfallChart", GC.Spread.Sheets.Charts.ChartType.waterfall, 400, 0, 700, 450, "A1:B14");
let chartArea = chart.chartArea();
chartArea.fontSize = 14;
chart.chartArea(chartArea);
let dataLabels = chart.dataLabels();
dataLabels.showValue = true;
dataLabels.color = 'rgb(64,60,61)';
dataLabels.position = GC.Spread.Sheets.Charts.DataLabelPosition.center;
chart.dataLabels(dataLabels);
let legend = chart.legend();
legend.position = GC.Spread.Sheets.Charts.LegendPosition.bottom;
chart.legend(legend);
let title = chart.title();
title.text = "月收入";
title.fontSize = 16;
chart.title(title);
let series = chart.series().get(0);
series.showConnectorLines = true;
series.gapWidth = 0.2;
series.subtotals = [0, 13];
chart.series().set(0, series);
chart.formatOvers({
    0: {
        backColor: "rgb(61,198,147)",
    },
    1: {
        backColor: "rgb(225,128,99)",
    },
    2: {
        backColor: "rgb(91,188,214)",
    }
});
```
