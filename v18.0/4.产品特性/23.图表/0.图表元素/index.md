# ConfigureChartElements

在SpreadJS中，一个图表包含几个图表元素（图表区域，图表标题，绘图区域，系列，轴，数据标签，数据标记和图例），可以分别设置其格式以生成具有自定义布局的二维图表。

在表单中配置图表元素不仅使用户能够以有意义的方式表示信息，而且还可以帮助他们整理比较和趋势的更清晰视图，以增强数据的可视化和分析能力。

下面显示了具有自定义图表元素的基本图表，供您参考。
