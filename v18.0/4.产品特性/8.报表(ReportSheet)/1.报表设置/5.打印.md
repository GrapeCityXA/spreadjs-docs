# print

要打印报表工作表，您可以使用 SpreadJS 中的打印 API。

> type=warning
> **注意**：要使用打印功能，必须添加以下脚本文件：
> \<script src="scripts/gc.spread.sheets.print.x.x.x.min.js">\</script> 

通过更改报表模板中的分页属性，您可以以不同的效果打印报表。有关分页设置的更多信息，请参考设置分页。
报表插件支持报表的所有渲染模式下的打印。
然而，推荐使用分页预览渲染模式以获得更好的打印支持。
默认情况下，所有页面将以分页预览渲染模式被打印。该模式下的每个页面将打印在单独的纸张上，必要时进行缩放，且不会重新分页。
如果您只想打印当前页面，请在设置中将 `printAllPages` 选项设置为 `false`。

```javascript
// Print all pages.
reportSheet.options.printAllPages = true;
// Print the current page.
reportSheet.options.printAllPages = false; 
```
