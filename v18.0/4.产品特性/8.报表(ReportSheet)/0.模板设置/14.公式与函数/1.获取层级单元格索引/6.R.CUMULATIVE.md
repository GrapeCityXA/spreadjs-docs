# rcumulative

获取单元格累计值。

## 语法

`R.CUMULATIVE(ValueCell, [ContextCell1], [ContextCell2])`

## 参数

此函数具有以下参数：

| **参数** | **描述** |
| --- | --- |
| *cell* | [必需] 指定您想要获取累计值单元格。 |
| *ContextCell1* | [可选] 指定上下文单元格1。<br>例如：如果 A2 单元格绑定到年份列，B2 单元格绑定到月份列，C2 单元格绑定到销售额列，则：<br>R.CUMULATIVE(C2) 将返回多年销售额的累计值。<br>R.CUMULATIVE(C2, A2) 将返回当前年份销售额的累计值。 |
| *ContextCell2* | [可选] 指定上下文单元格2。<br>如果值单元格是交叉单元格，您需要指定上下文单元格2。 |
