# cell-alias

可以为模板单元格定义别名，然后在公式中使用这个别名。
要为模板单元格设置别名，可以使用以下代码示例：

```javascript
const templateCell = {
    type: 'List',
    binding: 'SalesTable[sales]',
    alias: 'sales',
};
templateSheet.setTemplateCell(0, 0, templateCell);
templateSheet.setFormula(1, 0, '=SUM(sales)'); // same as the templateSheet.setFormula(1, 0, '=SUM(A1)');
```

> 备注：
>
> * 模板表中的别名必须唯一
> * 别名不区分大小写，最多接受255个字符
> * 别名的第一个字符必须是字母、下划线(\_)或反斜杠()
> * 名称中的其余字符可以是字母、数字、点和下划线字符
> * 不允许使用选择列/行的Excel快捷方式（“C”、“c”、“R”或“r”）
> * 不允许使用单元格引用，如Z$100或R1C1。至少使用4个字母后跟一个数字被认为是有效的
> * 单元格别名只能在工作表中的公式中使用，但不能在其他函数中使用，如条件格式、数据验证等
