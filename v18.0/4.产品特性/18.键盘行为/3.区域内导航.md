# selection-navigation

SpreadJS 允许你使用常见的热键在选定区域内进行导航，例如使用 Tab/Shift + Tab 键实现左右聚焦，使用 Enter/Shift + Enter 键实现上下聚焦。
下表展示了使用键盘按键时，光标在选定区域内的移动情况：

| **按键** | **描述** | **场景** |
| --- | --- | --- |
| @rows=5:Tab | 焦点在当前选中区域内向右移动到下一个单元格。 | ![tab-normal.0319bf](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/tab-normal.0319bf.df68fa.gif) |
| 焦点从选中区域内最后一列移动到下一行的第一个单元格。 | ![tab-last.92cb61](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/tab-last.92cb61.07fff7.gif) |
| 焦点从当前选中区域的最后一个单元格移动到第一个单元格。 | ![tab-lastrow.14969a](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/tab-lastrow.14969a.a98bc7.gif) |
| 若存在合并单元格，且合并单元格与当前选中单元格在同一行且相邻，焦点将移动到合并单元格；<br>否则，焦点将移动到合并单元格之后的下一个单元格。 | ![tab-span.0e8151](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/tab-span.0e8151.3f2db0.gif) |
| 若存在多个选中区域，焦点将从第一个选中区域的最后一个单元格移动到下一个选中区域的第一个单元格。 | ![tab-multipleselection.e7d9aa](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/tab-multipleselection.e7d9aa.e972d3.gif) |
| @rows=5:Shift + Tab | 焦点在选中区域内向左移动到上一个单元格。 | ![tabshift-normal.c84a67](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/tabshift-normal.c84a67.b9db9b.gif) |
| 焦点从选中区域内第一列移动到上一行的最后一个单元格。 | ![tabshift-firstlast.5d5598](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/tabshift-firstlast.5d5598.a27d3d.gif) |
| 焦点从当前选中区域的第一个单元格移动到最后一个单元格。 | ![tabshift-firstcolfirstrow.e0f1cd](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/tabshift-firstcolfirstrow.e0f1cd.e56a5d.gif) |
| 若存在合并单元格，且合并单元格与当前选中单元格在同一行且在其之前，焦点将移动到合并单元格；<br>否则，焦点将移动到合并单元格之前的单元格。 | ![tabshift-span.4456d4](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/tabshift-span.4456d4.3639ee.gif) |
| 若存在多个选中区域，焦点将从第二个选中区域的第一个单元格移动到第一个选中区域的最后一个单元格。 | ![tabshift-multipleselection.7680bb](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/tabshift-multipleselection.7680bb.65f1f8.gif) |
| @rows=5:Enter | 焦点在选中区域内向下移动。 | ![enter-normal.9b34d9](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/enter-normal.9b34d9.5b0f77.gif) |
| 焦点从选中区域内上一列的最后一个单元格移动到下一列的第一个单元格。 | ![enter-lastfirst.ccc76b](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/enter-lastfirst.ccc76b.d27f4f.gif) |
| 焦点从当前选中区域的最后一个单元格移动到第一个单元格。 | ![enter-lastcollastrow.0b497e](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/enter-lastcollastrow.0b497e.073674.gif) |
| 若存在合并单元格，且合并单元格与当前选中单元格在同一列且相邻，焦点将移动到合并单元格；<br>否则，焦点将移动到合并单元格之后的下一个单元格。 | ![enter-span.2d29bf](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/enter-span.2d29bf.0d5fcf.gif) |
| 若存在多个选中区域，焦点将从第一个选中区域的最后一个单元格移动到下一个选中区域的第一个单元格。 | ![enter-multipleselection.7b068f](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/enter-multipleselection.7b068f.30e7ae.gif) |
| @rows=5:Shift + Enter | 焦点在选中区域内向上移动。 | ![shiftenter-normal.ca8687](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/shiftenter-normal.ca8687.d9bf43.gif) |
| 焦点从选中区域内某一列的第一个单元格移动到上一列的最后一个单元格。 | ![shiftenter-firstcolfirstrow.b98bf0](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/shiftenter-firstcolfirstrow.b98bf0.f61e9a.gif) |
| 焦点从当前选中区域的第一个单元格移动到最后一个单元格。 | ![shiftenter-lastrow.453a94](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/shiftenter-lastrow.453a94.192104.gif) |
| 若存在合并单元格，且合并单元格与当前选中单元格在同一列且在其之前，焦点将移动到合并单元格；<br>否则，焦点将移动到合并单元格之前的单元格。 | ![shiftenter-span.0829bb](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/shiftenter-span.0829bb.362c98.gif) |
| 若存在多个选中区域，焦点将从第二个选中区域的第一个单元格移动到第一个选中区域的最后一个单元格。 | ![shiftenter-multipleselection.00343f](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/shiftenter-multipleselection.00343f.4fc7fc.gif) |

> **注意**：使用 register 方法来更改导航键及其对应的操作。更多信息，请参阅 [输入映射](gcdocsite__documentlink?toc-item-id=cace035d-298f-4f0c-87ee-6d0b95d21d8f)。
