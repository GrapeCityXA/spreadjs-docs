# select

使用 SpreadJS，你可以在工作表中选择单元格、行、列或多个区域。通常，在选择大量单元格或多个单元格区域时，如果你不小心选中了一些不需要的单元格并想要取消选中它们，那么先取消整个选中区域，然后再重新选择的整个过程会变得过于繁琐，难以处理。
SpreadJS 不仅能让你节省大量时间，还能避免冗余操作，因为它允许用户从已选中的区域中取消选中特定单元格，并在处理电子表格时根据自己的需求自定义选择内容。
要在工作表中开始选择一个区域，只需按住鼠标左键点击并拖动，即可选择一个单元格块、列或行。你也可以使用鼠标点击并配合 Ctrl 键来选择多个单元格区域。

以下代码示例选择了一个单元格区域。

```javascript
activeSheet.addSelection(4, 0, 2, 2);
//activeSheet.clearSelection();
var sels = activeSheet.getSelections();
alert(sels.length);
```

你可以使用 [selectionUnit ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#selectionUnit)方法指定选择单元的类型（单元格、列或行）。你可以使用 [selectionPolicy ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#selectionPolicy)方法指定选择的范围（单个、区域或多个区域）。
以下代码示例允许选择单行或块行。

```javascript
activeSheet.selectionUnit(GC.Spread.Sheets.SelectionUnit.row);
activeSheet.selectionPolicy(GC.Spread.Sheets.SelectionPolicy.range);
```

你可以使用 `options.selectionBackColor` 和 `options.selectionBorderColor` 属性设置选择区域的颜色和边框。你可以使用标准颜色和主题颜色。
以下代码示例设置了选中区域和边框的颜色。

```javascript
activeSheet.options.selectionBackColor = "Accent 6";
activeSheet.options.selectionBorderColor = "Accent 1";
```

要取消选择，只需按下键盘上的 Ctrl 键或 Cmd 键，然后使用向左、向上、向右或向下箭头键来取消选择你想要取消的单元格。
为了在工作表中启用取消选择功能，必须将 `allowUserDeselect` 属性设置为布尔值 “true”。默认情况下，此选项设置为 true。但是，如果用户在使用 SpreadJS 时不希望有取消选择功能，他们可以将此选项设置为 “false”。
以下代码示例展示了如何在工作表中取消选择。

```javascript
var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
var sheet = spread.getActiveSheet();

// 对于“类似 Excel 的精确选择”功能，用户需要将 spread 的 allowUserDeselect 选项设置为 true。默认情况下，此选项为 true。如果您不想要“类似 Excel 的精确选择”功能，则需要将此选项设置为 false。
spread.options.allowUserDeselect = true;
```
