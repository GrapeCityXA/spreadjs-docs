# keyboard

你可以使用鼠标或键盘按键来更改活动单元格或选定的单元格。你还可以使用键盘按键来更改单元格数据。
最终用户可以使用以下默认的键盘按键：

| 按键 | 操作 |
| --- | --- |
| Ctrl+Z | `撤销` |
| Ctrl+Y | `重做` |
| Ctrl + 向下箭头 | `导航至底部` |
| 向下箭头 | `向下导航` |
| End | `导航至末尾` |
| Ctrl+向右箭头 | `导航至末尾` |
| Ctrl+Home | `跳转到工作表开头` |
| Home | `导航至开头` |
| Ctrl+向左箭头 | `导航至开头 2` |
| Ctrl+End | `跳转到工作表右下角` |
| 向左箭头 | `向左导航` |
| Tab | `移动到下一个单元格` |
| PageDown | `向下翻页导航` |
| PageUp | `向上翻页导航` |
| Ctrl+PageUp | `导航到上一个工作表` |
| Ctrl+PageDown | `导航到下一个工作表` |
| Shift+Tab | `移动到上一个单元格` |
| 向右箭头 | `向右导航` |
| Ctrl+向上箭头 | `导航至顶部` |
| 向上箭头 | `向上导航` |
| Delete | `清除` |
| Backspace（退格键） | `清除并进入编辑状态` |
| Enter | `提交输入并向下导航` |
| Shift+Enter | `提交输入并向上导航` |
| ESC | `取消输入` |
| Shift+向左箭头 | `向左选择` |
| Shift+向右箭头 | `向右选择` |
| Shift+向上箭头 | `向上选择` |
| Shift+向下箭头 | `向下选择` |
| Shift+Home | `选择到开头` |
| Ctrl+Shift+向左箭头 | `选择到开头` |
| Shift+End | `选择到末尾` |
| Ctrl+Shift+向右箭头 | `选择到末尾` |
| Shift+PageUp | `向上翻页选择` |
| Shift+PageDown | `向下翻页选择` |
| Ctrl+Shift+向上箭头 | `选择到顶部` |
| Ctrl+Shift+向下箭头 | `选择到底部` |
| Ctrl+Shift+Home | `选择到第一个` |
| Ctrl+Shift+End | `选择到最后一个` |
| Ctrl+C | `复制` |
| Ctrl+X | `剪切` |
| Ctrl+V | `粘贴` |
| Alt+Enter | `输入新行` |

> **注意**：Ctrl+PageUp 和 Ctrl+PageDown 键盘快捷键仅在与宿主环境无冲突时才起作用。
> 有关使用键盘快捷键进行复制和粘贴操作的更多信息：
>
> * SpreadJS 无法直接访问系统剪贴板。
> * 在 SpreadJS 中使用 Ctrl+C 进行复制时，它将同时执行外部复制和内部复制。
> * 在 SpreadJS 中使用 Ctrl+V 进行粘贴时，它将决定是执行外部粘贴还是内部粘贴。
> * 当使用上下文菜单或命令管理器时，SpreadJS 始终执行内部复制和内部粘贴，因为它无法访问系统剪贴板。

## 其他键盘快捷键

SpreadJS 支持一些其他的键盘快捷键命令。你可以通过下载并使用可从 [此处](https://github.com/GrapeCity/spreadjs-resources) 获取的 **键盘快捷键** 项目，将这些快捷键作为扩展包含在你的项目中。你也可以基于此项目添加自定义快捷键。

| 按键 | 操作 |
| --- | --- |
| Shift + Space | `选择整行` |
| Ctrl + Space | `选择整列` |
| Ctrl + "-" | `删除整行或整列` |
| Ctrl + 9 | `隐藏选定行` |
| Ctrl + [ | `跳转到引用单元格` |
| Ctrl + ] | `跳转到从属单元格` |
| Ctrl + ; | `设置日期` |
| Alt + = | `对选定范围自动求和` |
| Alt + Shift + 向右箭头 | `对选定范围分组` |
| Alt + Shift + 向左箭头 | `取消选定范围分组` |
| Alt + ; | `选择可见单元格` |
| Ctrl + D | `向下复制单元格` |
| Ctrl + R | `向右复制单元格` |
| Ctrl + Shift + "+" | `插入行或列` |
| Ctrl + A | `全选` |
| Ctrl + B | `设置单元格加粗` |
| Ctrl + I | `设置单元格倾斜` |
| Ctrl + U | `设置单元格下划线` |
| Ctrl + Shift + % | `将数字设置为百分比` |
| Ctrl + 箭头键 | `导航到下一个非空单元格` |
| Ctrl + Shift + 箭头键 | `选择非空范围` |
| Ctrl + Shift + + | `插入范围` |
| Ctrl + - | `删除范围` |

> **注意**：
>
> * 快捷键库已集成到设计器库中，并包含在设计器库的构建输出中，因此用户无需单独链接快捷键库文件。
> * Ctrl + 箭头键和 Ctrl + Shift + 箭头键不支持重做和撤销操作。
> * 这些快捷键不支持 MAC OS 系统。
> * 这些快捷键不支持表格工作表（TableSheet）和甘特图工作表（GanttSheet）。
