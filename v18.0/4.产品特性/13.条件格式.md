# condformat

SpreadJS支持单元格中的条件格式。你可以使用各种样式来设置格式化单元格的视觉外观。
条件格式可以通过条件格式规则应用于工作表。类如`ConditionalFormatting`和`ConditionalFormats`可以用来访问各种不同的方法和枚举选项。
有几种类型的条件规则。下表列出了这些规则及其描述：

| **规则** | **描述** |
| --- | --- |
| 平均值规则 | 平均值规则检查值是否高于或低于平均值。 |
| 单元格值规则 | 单元格值规则比较值。 |
| 数据条规则 | 数据条规则使用作为每个单元格背景显示的条。条的长度基于单元格值。 |
| 日期规则 | 日期规则比较日期。 |
| 重复值规则 | 重复值规则检查重复值。 |
| 公式规则 | 公式规则允许你在检查条件时使用公式。 |
| 图标集规则 | 图标集规则基于值显示图标。你可以指定图标的类型以及是否仅显示图标或同时显示图标和单元格中的数据。 |
| 颜色刻度规则 | 颜色刻度规则使用滑动颜色刻度。 |
| 特定文本规则 | 特定文本规则搜索文本字符串。 |
| 前10规则 | 前10规则检查值是否在范围的前10或后10之内。 |
| 唯一值规则 | 唯一值规则检查值是否在范围内是唯一的。 |

## 管理条件格式规则

你可以使用如“当前选择”或“此工作表”等条件格式选项，将条件格式应用于特定区域，以关注相关数据。这可以帮助你突出异常值，使你的工作表更具信息性和视觉吸引力。

## 条件格式的优先级

这些规则有一个优先顺序。列表中最后的规则具有最高优先级。列表中的第一个规则具有最低优先级。默认情况下，新的规则总是最后添加并具有最高优先级。当两条规则冲突时，优先级较高的规则被应用。如果两条规则不冲突（一条规则使用粗体字体而另一条规则使用单元格背景颜色），那么将同时应用这两条规则。
