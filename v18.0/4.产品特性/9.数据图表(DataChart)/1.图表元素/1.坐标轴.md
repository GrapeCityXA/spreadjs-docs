# chart-axis

坐标轴是图表上用于帮助理解所展示数据的尺度和维度的线条。水平（x 轴）和垂直（y 轴）坐标轴用于绘制时间、数量、百分比等数据。使用 `IAxisOption`接口来定义数据图表中坐标轴的外观和行为。

## 坐标轴属性

`IAxisOption` 接口中可用的坐标轴主要可配置属性如下：

| **属性** | **描述** | **示例预览** |
| --- | --- | ---- |
| type | 定义坐标轴类型为 “类别轴” 或 “数值轴”。行为可能因图表类型和坐标系（如笛卡尔坐标系或极坐标系）而异。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.871514.png) |
| labels | 控制坐标轴标签的可见性。默认行为可能因图表类型而异，需要显式设置来覆盖默认值。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.55d941.png) |
| axisLine | 确定是否显示坐标轴线条。数据图表为不同的图表类型提供不同的默认值，需要显式设置来覆盖默认值。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.e91323.png) |
| reversed | 反转坐标轴方向。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.bff387.png) |
| title | 指定坐标轴标题，包括单位或其他描述。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.3fd854.png) |
| max & min | 设置坐标轴范围的最大值和最小值。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.f6387c.png) |
| position | 确定坐标轴在数据图表上的位置。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.ccc138.png) |
| format | 设置坐标轴的格式信息，包括数据单位和格式字符串。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.6baee7.png) |
| majorUnit & minorUnit | 设置刻度标记之间的间隔。<ul><li>如果当前刻度是 “数字” 类型，则直接设置值。</li><li>如果当前刻度不是 “数字” 或 “日期” 类型，也直接设置值，计数规则是每个类别值之间的间距为 1。</li></ul> | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.d14b97.png) |
| labelAngle | 设置坐标轴标签的旋转角度（范围：-90 到 90 度）。注意，目前此属性仅对数组的第一个元素起作用。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.49b589.png) |
| labelStyle | 定义坐标轴标签的文本样式。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.d01638.png) |
| titleStyle | 指定坐标轴标题的样式。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.b52fe4.png) |
| lineStyle | 配置坐标轴线条的外观。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.84e492.png) |
| majorTickSize & minorTickSize | 设置当前坐标轴的主要和次要刻度线的长度。<br>主要和次要刻度线有助于在坐标轴上定位数据点。<ul><li>主要刻度用于标记关键数值，通常间隔较大，旨在突出关键数据点。</li><li>次要刻度表示主要刻度之间的较小间隔，间距更近且标记更精细，能够实现更精确的定位和比较。</li></ul>支持的值：无、内部、外部和交叉。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.159f90.png) |
| majorGrid & minorGrid | 设置以增强数据解读。它们通常描绘更精细的数字间隔，使用户能够更精确地查看数据。<br>默认值可能因图表类型而异；例如，饼图默认不显示网格线。<ul><li>主要网格线与主要刻度对齐，突出数据的主要结构。</li><li>次要网格线与次要刻度对齐，位于主要网格线之间。</li></ul>每个主要单位绘制主要网格线和刻度线。每个次要单位绘制次要网格线和刻度线。默认情况下，每个主要单位由一条次要网格线和一个刻度线分隔。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.b6ebb4.png) |
| majorGridStyle & minorGridStyle | 配置主要网格线和次要网格线的样式信息。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.93b240.png) |
| dateMode | 在散点图和气泡图等数据图表中设置坐标轴的时间跨度。 | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.d0a3e7.png) |

## 使用代码

请参考以下示例代码在数据图表上配置和自定义坐标轴。
请注意，此示例使用了 [“创建数据图表” ](gcdocsite__documentlink?toc-item-id=83b6d588-0f69-4b37-9a6e-f9aa6a2b714e)页面中提到的 “salesTable” 数据。因此，请确保你已完成该页面概述的主要步骤来设置数据图表。完成后，你可以使用以下代码配置坐标轴。此外，你还可以根据具体需求灵活自定义数据源。
