# line-charts

**折线图**是通过直线或曲线连接数据点创建的基本图表。它们通常用于显示数据随时间或其他连续变量的趋势、波动和变化。使用这种类型的图表，你可以可视化数据趋势，从而帮助你做出更好的决策和分析。
SpreadJS允许你通过修改各种属性来添加和自定义折线图的外观，包括颜色方案、图形透明度、边框样式、线条粗细、点符号、提示框样式等。这些修改可以通过代码进行，也可以在SpreadJS设计器中的[“检查器”](gcdocsite__documentlink?toc-item-id=55f14079-f4d7-48fe-aebc-ed9390deeb94)选项卡中进行。

请参考以下示例代码来添加折线图。
请注意，此示例基于[创建数据图表](gcdocsite__documentlink?toc-item-id=83b6d588-0f69-4b37-9a6e-f9aa6a2b714e)页面中的“salesTable”数据。因此，请确保你已经按照该页面上提到的主要步骤添加了数据图表。你也可以根据自己的特定需求自定义数据源。

```javascript
// Line Chart
const sheet = spread.getActiveSheet();
sheet.name("Line Chart");
const dataChart = sheet.dataCharts.add('data-chart', 10, 10, 600, 400);
dataChart.setChartConfig({
    tableName: 'Sales',
    config: {                    
        header: {   
            title: "Line Chart With Symbol",                        
        },                    
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.line,
            encodings: {
                category: {
                    field: "Product"
                },
                color: {
                    field: "Region"
                },
                values: [
                    {
                        field: "Sales",
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum
                    }
                ]
            },
            config: {
                axisMode: GC.Spread.Sheets.DataCharts.AxisMode.cartesian,
                palette: [
                    "#88bde6",
                    "#fbb258",
                    "#90cd97",
                    "#f6aac9",
                    "#bfa554",
                    "#bc99c7"
                ],
                style: {
                    strokeWidth: 2,
                    symbolShape: GC.Spread.Sheets.DataCharts.SymbolShape.dot,
                    symbolSize: 10,
                },
                symbols: true,                            
            }
        }
    ]
});
```
