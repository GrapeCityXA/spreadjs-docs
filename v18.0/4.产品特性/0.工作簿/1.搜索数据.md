# searching

你可以在部件中搜索一个字符串，并指定各种搜索选项，例如大小写、精确匹配、通配符、单元格范围和搜索顺序。[search ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#search)方法和 [SearchCondition ](gcdocsite__documentlink?toc-item-id=648850c5-e4a6-4a2c-b129-772ebdc2cb3c)类允许你检查单元格文本、单元格标记、注释、值或公式。
此外，`SearchFoundFlags` 枚举确定搜索的目标，它指定应在何处进行搜索。它还包括几个标志选项，用于在单元格值、公式、标记或注释中进行搜索。

> **注意**：
>
> * 搜索条件时遵循 `SearchFlags` 和 `SearchOrder` 定义的规则。
> * 使用代码在注释中搜索时，注释中的文本是搜索的目标。
> * 在 SpreadJS 中，搜索时会同时考虑注释文本和用户名。

以下代码展示了如何在搜索目标为单元格注释的情况下搜索一个字符串。你可以根据搜索标准更改搜索目标的值。

```javascript
var sheet = spread.getSheet(0);
sheet.getCell(2,3).value("user");

// 添加一个注释
var comment = new GC.Spread.Sheets.Comments.Comment();
comment.text("user comment!");
sheet.getCell(3, 3).comment(comment);

// 搜索注释
var searchCondition = new GC.Spread.Sheets.Search.SearchCondition();
searchCondition.searchString = "user";
searchCondition.startSheetIndex = spread.getActiveSheetIndex();
searchCondition.endSheetIndex = spread.getActiveSheetIndex();
searchCondition.searchOrder = GC.Spread.Sheets.Search.SearchOrder.nOrder;

// 搜索目标是单元格注释
searchCondition.searchTarget = GC.Spread.Sheets.Search.SearchFoundFlags.cellComment;

// 搜索目标是单元格中的文本 
// searchCondition.searchTarget = GC.Spread.Sheets.Search.SearchFoundFlags.CellText; 

searchCondition.searchFlags = GC.Spread.Sheets.Search.SearchFlags.ignoreCase | GC.Spread.Sheets.Search.SearchFlags.useWildCards;
var searchresult = spread.search(searchCondition);
var str = "[searchFoundFlag:" + searchresult.searchFoundFlag + ",\r\n foundSheetIndex:" + searchresult.foundSheetIndex + ",foundRowIndex:" +
searchresult.foundRowIndex + ", foundColumnIndex:" + searchresult.foundColumnIndex + ", foundComment:" + searchresult.foundString + "]";
console.log(str);
```

## 使用设计器

Spread 设计器允许你使用以下步骤通过“查找和替换”对话框搜索包含值、单元格标记、公式和单元格注释的字符串：

1. 点击“开始”选项卡中的“查找”按钮。
    “查找和替换”对话框将会出现。
2. 点击对话框中的“选项<<”按钮。
3. 点击“查找范围”下拉菜单，并根据你的需求和搜索标准选择任何选项。
