# tabstrip

SpreadJS 提供了大量选项来控制标签条及其元素的行为。 您可以通过 **Workbook.options** 字段的属性来执行各种操作，例如更改工作表名称、设置工作表颜色、排列工作表、设置标签条的位置和宽度等。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/tabstriplabel.png)

### 更改工作表名称

您可以通过双击工作表进行编辑来更改工作表的名称。 单击选项卡外或使用 Esc 或 Enter 键确认更改。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/edit-sheet-names.gif)
您可以使用 **options.tabEditable** 属性启用或禁用编辑工作表名称的功能。 此属性的默认值为 true。

```JavaScript
spread.options.tabEditable = false; // false: 禁用, true: 启用
```

### 排列工作表标签

您可以通过选择工作表选项卡并在任意两个工作表之间拖动它来在选项卡条中排列工作表名称。 拖动工作表时会显示一个指示符，如下图所示。 释放鼠标以移动工作表。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/tab-reorder.png)
您可以通过将 **options.allowSheetReorder** 属性设置为 true 来启用重新排序工作表选项卡的功能。

```JavaScript
spread.options.tabStripVisible = true;
spread.options.tabEditable = true;
spread.options.newTabVisible = true;
spread.options.tabStripRatio = 1;
```

[SheetMoving](gcdocsite__documentlink?toc-item-id=8579217b-549b-41f7-aa4f-f0e21c37872e#SheetMoving_EV) 和[ SheetMoved](gcdocsite__documentlink?toc-item-id=8579217b-549b-41f7-aa4f-f0e21c37872e#SheetMoved_EV) 事件分别在工作表被拖动和移动之前和之后发生。 为了取消sheet的移动，可以将 [SheetMoving](gcdocsite__documentlink?toc-item-id=8579217b-549b-41f7-aa4f-f0e21c37872e#SheetMoving_EV) 类的 **`cancel`** 参数设置为 true。

### 设置工作表标签样式

您可以根据工作表标签的状态设置工作表标签样式，例如文字样式、背景颜色和图标。要为工作表标签设置样式，可以使用 `Workbook` 类的 `sheetTabStyles` 或 `defaultSheetTabStyles` 属性。
`sheetTabStyles` 属性为每个工作表标签应用特定状态样式，而 `defaultSheetTabStyles` 属性设置所有工作表标签的默认状态样式。
请参考以下图像，该图像为工作表标签的不同状态设置了背景颜色、前景色和图标。
![sheet-tabstyle.0976cc](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/sheet-tabstyle.0976cc.a39d00.png)
以下代码示例实现了不同状态下的工作表标签的样式。

```javascript
// Set a new style for the normal state of 'Sheet1'.
spread.sheetTabStyles.add(GC.Spread.Sheets.SheetTabState.normal, {
    icons: [{ src: '../images/img.png', width: 20, height: 20 }],
    foreColor: 'red',
    font: 'bolder',
    backColor: 'green',
}, ['Sheet1']);

// Set a default style for the protected state of all sheet tabs.
spread.options.defaultSheetTabStyles = {
    [GC.Spread.Sheets.SheetTabState.protected]: {
        icons: [{ src: '../images/lock.jpg', width: 20, height: 20 }],
        foreColor: 'blue',
        backColor: 'orange',
    }
};
```

### 显示新标签按钮

您可以使用 **options.newTabVisible** 属性选择显示或隐藏“新标签”按钮。 此按钮默认可见。
![newtabvisible](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/newtabvisible.cb2c8d.png)

```JavaScript
spread.options.newTabVisible = true; // false: 隐藏, true: 显示
```

### 显示导航按钮

您可以使用 **options.tabNavigationVisible** 属性指定是否在工作簿中显示导航按钮。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/tabnavigation.png)

```JavaScript
spread.options.tabNavigationVisible = false; // false: 隐藏, true: 隐藏
```

### 显示标签条

您可以使用 **options.tabStripVisible** 属性隐藏整个标签栏。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/tabstripvisible.png)

```JavaScript
spread.options.tabStripVisible = true; // true: 显示, false: 隐藏
spread.options.tabStripRatio = 0.5;  // 百分比值，指定分配给标签条的水平空间
```

### 设置位置和宽度

您可以使用 **tabstripPosition** 工作簿选项设置标签栏相对于工作簿的位置。 触摸设备以及所有 SpreadJS 主题都支持这些位置。 如果位置设置为左、右或上，则标签条与滚动条分离。

| Position | Image |
| -------- | ----- |
| Bottom (default) | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/tabBottom.png) |
| Left | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/tabLeft.png) |
| Right | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/tabRight.png) |
| Top | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/tabTop.png) |

调整横条大小按钮仅在标签条位置设置为底部时可见。属性在设置顶部、左侧或右侧位置时也会被忽略。

> **注意：** 调整横条大小按钮仅在标签条位置设置为底部时可见。 **tabStripRatio** 属性在设置顶部、左侧或右侧位置时也会被忽略。

如果工作表位置设置为左或右，并且工作表名称太长而无法显示，则会被剪裁并用省略号指示。 但是，您可以使用 **options.tabStripWidth** 属性更改标签条的宽度以显示完整的工作表名称。 该属性的默认最小值为 80。
如果标签条位置未设置在工作簿的左侧或右侧，则忽略属性。

> **注意：** 如果标签条位置未设置在工作簿的左侧或右侧，则忽略 **options.tabStripWidth** 属性。

![](https://docs.grapecity.com.cn/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/tabstripWidth.png)
以下示例代码设置标签条位置和宽度。

```JavaScript
// 创建工作簿时更改标签条位置
var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"), {tabStripPosition: GC.Spread.Sheets.TabStripPosition.top});
// 或通过工作簿选项更改标签条位置
spread.options.tabStripPosition = GC.Spread.Sheets.TabStripPosition.top;
        
// 创建工作簿时更改标签条宽度
var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"), {tabStripWidth: 200});
// 或通过工作簿选项更改标签条宽度
spread.options.tabStripWidth = 200;
```

### “所有工作表”按钮

SpreadJS 在选项卡条中提供了一个“所有工作表”按钮，有助于更快地导航到工作簿中的特定工作表。该按钮打开一个包含可用工作表的下拉列表。
当所有工作表无法在选项卡条中完全显示时，会自动出现“所有工作表”按钮。它也可以通过调整栏的大小以隐藏工作表来显示。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/tabstrip-allsheetsbutton.gif)
您可以通过使用[AllSheetsListVisibility](gcdocsite__documentlink?toc-item-id=e4a44742-f199-4cfb-88f5-b5883eb3bce5)枚举值（例如“hide”、“show”和“auto”（默认））设置allSheetsListVisible 选项来 选择是否显示所有工作表按钮。

```JavaScript
// 自动显示或隐藏“所有工作表”按钮 - 默认
function AutoButton(spread) {
    spread.options.allSheetsListVisible = GC.Spread.Sheets.AllSheetsListVisibility.auto;
}

// 始终显示“所有工作表”按钮
function ShowButton(spread) {
    spread.options.allSheetsListVisible = GC.Spread.Sheets.AllSheetsListVisibility.show;
}

// 隐藏“所有工作表”按钮
function HideButton(spread) {
    spread.options.allSheetsListVisible = GC.Spread.Sheets.AllSheetsListVisibility.hide;
}
```

> **注意:** 无论allSheetsListVisible选项中的设置值如何，都会保留所有工作表按钮的位置。
