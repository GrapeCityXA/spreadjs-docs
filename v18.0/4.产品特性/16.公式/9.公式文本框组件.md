# formulacontrol

你可以将公式文本框用作页面上的一个控件。
你可以在公式文本框控件中输入或查看公式，如下图所示。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/formulaboxcontrol.985889.png)
你还可以选择要添加到公式文本框控件中的单元格区域。选择文本框中的公式区域图标，然后通过按 Ctrl 键或在文本框中添加逗号 (,) 来选择多个区域。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/formulacrange.42572f.png)
以下代码示例将公式文本框控件添加到页面中。

```html
<script>
window.onload = function () {
    var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 3 });
    var activeSheet = spread.getActiveSheet();
    activeSheet.setArray(0, 0, [1, 2, 3, 4, 5]);
    var fbx = new GC.Spread.Sheets.FormulaTextBox.FormulaTextBox(document.getElementById('formulaTextBox'));
    fbx.workbook(spread);
};
</script>
...
<input type="text" id="formulaTextBox" />
```

以下代码示例允许你将所选区域添加到公式文本框中。

```javascript
<script type="text/javascript">
window.onload = function () {
    var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });
    rangeSelector = new GC.Spread.Sheets.FormulaTextBox.FormulaTextBox(document.getElementById('ftb'), { rangeSelectMode: true });
    rangeSelector.workbook(spread);
};
function buttonClick() {
    alert(rangeSelector.text());
}
</script>
...
<div id="ss" style="width:50%; height:400px; border:1px solid gray;"></div>
<div id="ftb" style="width:50%;height:20px;border:1px solid gray"></div>
<button onclick="buttonClick()">Get Range Text</button>
```

## 更改公式文本框布局

SpreadJS 还允许你自定义跨工作表的单元格内公式文本框及其弹出元素的布局。当单元格内公式文本框绑定到多个工作表的引用时，你可以隐藏或移动它。为此，需在 CSS 文件中编辑 `gc-across-sheet-ftb` 和 `gc-across-sheet-func-popup` 类的 CSS 属性。
以下示例 CSS 代码说明了如何自定义跨工作表的单元格内公式文本框的布局。

```javascript
// 隐藏跨工作表的单元格内公式文本框。   
<style>       
    .gc-across-sheet-ftb {            
        z-index: -1 !important;        
    }        
    .gc-across-sheet-func-popup {            
        z-index: -1 !important;        
    }   
</style>

//或者    

<style>      
    .gc-across-sheet-ftb {            
        width: 0px !important;            
        height: 0px !important;            
        border: none !important;        
    }      
    .gc-across-sheet-func-popup {            
        width: 0px !important;            
        height: 0px !important;            
        border: none !important;            
        overflow: hidden;        
    }   
</style> 

// 将跨工作表的单元格内公式文本框移动到工作簿宿主的上方
    <style>        
        .gc-across-sheet-ftb {            
            top: 10px !important;        
        }        
        .gc-across-sheet-func-popup {            
            max-height: 80px;            
            overflow-y: scroll;       
        }
    </style>
```

> **注意**：在 SpreadJS 设计器中，跨工作表的单元格内公式文本框和弹出元素是隐藏的。
