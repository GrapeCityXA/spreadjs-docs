# incremental-calculations

SpreadJS 提供了增量计算支持，通过将 Workbook 类的 incrementalCalculation 选项设置为 true，可以在执行期间将整个计算分成多个部分。这使得在计算任务非常庞大时，可以对用户操作作出响应。
你可以逐步计算单元格并响应 UI 事件。当工作簿包含许多公式时，这可以防止 UI 冻结。当在待计算单元格的过程中更新单元格时，更新的单元格及其依赖单元格会被添加到计算任务中。然而，如果插入或删除行/列或工作表，则挂起的计算将被丢弃，后续的计算将使用调整后的公式。
当 incrementalCalculation 选项设置为 true 时，可以使用 CalculationProgress 事件跟踪进度更新。
下面的代码示例显示了如何在 CalculationProgress 事件中跟踪进度。

```javascript
// 此示例使用 CalculationProgress 事件记录计算进度。
spread.options.incrementalCalculation = true;
spread.bind(GC.Spread.Sheets.Events.CalculationProgress, function (e, info) { 
    var msg = "Calculate "; 
    if (info.pendingCells === 0) { 
        msg += "finished"; 
    } else if (info.iterate >= 0) { 
        msg += info.pendingCells + " cells in iterative calculation round " + info.iterate; 
    } else { 
        msg += (info.totalCells - info.pendingCells) + "/" + info.totalCells + " cells"; 
    } 
    console.log(msg); 
}); 
```

## 添加状态栏项

当 incrementalCalculation 选项设置为 true 时，增量计算也会显示在状态栏中，以显示计算进度。
下面的代码示例显示了如何将 spread 绑定到状态栏，状态栏将自动显示计算进度。

```javascript
// 初始化状态栏并将其绑定到 spread。
var statusBar = new GC.Spread.Sheets.StatusBar.StatusBar(document.getElementById('statusBar'));
statusBar.bind(spread);
```
