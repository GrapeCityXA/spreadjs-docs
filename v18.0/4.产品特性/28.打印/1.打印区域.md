# PrintArea

SpreadJS 通过自定义名称“Print\_Area”在工作表中定义打印区域。“Print\_Area”自定义名称的好处是：

* 当用户插入或删除行或列时，打印区域会更新。
* 自定义名称可用于公式函数。
* 当用户将“Print\_Area”设置为公式时，打印区域会自动更新。

## 与名称管理器的交互

SpreadJS 名称管理器添加了一个与设置的打印区域具有相同引用的“Print\_Area”自定义名称。可以通过名称框下拉菜单在工作表中选择它。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/printarea.gif)
用户还可以通过名称管理器对话框手动创建或编辑“Print\_Area”自定义名称，就像任何其他自定义名称一样。自定义名称既不与文化相关也不区分大小写。

> **注意:** “Print\_Area”自定义名称在工作表区域或者被工作表引用时有效。如果无效，它仅用作自定义名称。
> 所以，用户可以在工作簿区域内添加自定义名称“Print\_Area”，但不会影响打印区域。

## 与打印信息的交互

T从“Print\_Area”自定义名称获取的打印区域设置以下[PrintInfo](gcdocsite__documentlink?toc-item-id=6f8e15e8-6dec-4e4f-a772-49bbdae4daa3)类方法的值: *rowStart* , *rowEnd* , *columnStart* , and *columnEnd* .
相反，类方法在 SpreadJS 工作表中设置“Print\_Area”自定义名称。建议通过自定义名称“Print\_Area”或通过 PrintInfo 方法设置打印区域，而不是同时设置。

## 例子

以下代码示例显示了“Print\_Area”自定义名称如何影响 PrintInfo 方法。

```JavaScript
//  配置工作簿和工作表
var spread = new GC.Spread.Sheets.Workbook("ss");
var sheet = spread.getActiveSheet();

var printInfo = sheet.printInfo();

//  Print_Area 影响 PrintInfo
sheet.addCustomName("Print_Area", "=A1:B5")
console.log(printInfo.rowStart())   // 输出: 0
console.log(printInfo.rowEnd())     // Output: 4

sheet.removeCustomName("Print_Area", "")
console.log(printInfo.rowStart())   // 输出: -1
console.log(printInfo.rowEnd())     // 输出: -1
```

以下代码示例显示了 PrintInfo 方法如何影响“Print\_Area”自定义名称。

```JavaScript
//PrintInfo 影响 Print_Area
printInfo.rowStart(1)
// 假设 sheet 的 rowCount 为 20
sheet.getCustomName("Print_Area")
// 返回一个 NameInfo 实例，公式为 "=2:20"
console.log(printInfo.rowStart())   // 输出: 1
console.log(printInfo.rowEnd())     // 输出: -1

printInfo.rowEnd(15)
sheet.getCustomName("Print_Area")
//  返回一个 NameInfo 实例，并且公式为 "=2:16"
console.log(printInfo.rowEnd())     // 输出: 15
```

以下代码示例显示了“Print\_Area”自定义名称和 PrintInfo 方法如何相互影响。

```JavaScript
//Print_Area 和 PrintInfo 相互影响
sheet.addCustomName("Print_Area", "=A1:B5")
console.log(printInfo.rowStart())   // 输出: 0
console.log(printInfo.rowEnd())     // 输出: 4

printInfo.rowStart(1);
sheet.getCustomName("Print_Area")
// 返回一个 NameInfo 实例，公式为 "=A2:B5"
```

## 与公式的交互

SpreadJS 提供了在公式中使用自定义名称“Print\_Area”的能力。可以应用在工作表中创建动态打印区域的条件语句。
例如，您可以输入公式“=IFERROR(ROWS(Print\_Area),"none")”来显示要打印的行数，如果不存在则显示“none”。
您还可以根据单元格中是否插入值自动更新打印区域，如下面的代码示例所示。

```JavaScript
// 配置工作簿和工作表
var spread = new GC.Spread.Sheets.Workbook("ss");
var sheet = spread.getActiveSheet();

var printInfo = sheet.printInfo();

// 带有条件语句的公式
sheet.addCustomName("Print_Area", "=IF(Sheet1!$A$1,Sheet1!$B$1:$C$5,Sheet1!$D$5:$F$8)")
// 假设 A1是一个真实值
console.log(printInfo.rowStart())
// 输出: 0
console.log(printInfo.rowEnd())
// 输出: 4

printInfo.rowStart(1);
sheet.getCustomName("Print_Area")
// 返回一个NameInfo实例，公式为“=B2:C5”
```
