# print-header-footer

SpreadJS 允许用户使用 printInfo方法自定义打印在工作簿或工作表顶部或底部的页眉和页脚。用户通过使用 **pageHeaderFooter** 方法可以获取或设置在页面上自定义打印的页眉和页脚的文本和格式。
**IPageCustomHeaderFooterOptions** 接口提供以下类型的页面格式来自定义页眉和页脚：

* Normal: 在所有页面上应用页眉或页脚。
* First: 仅在第一页上应用页眉或页脚。 使用 **differentFirstPage** 方法来启用此格式。
* Odd and even: 仅在奇数页或偶数页上应用页眉或页脚。 使用 **differentOddAndEvenPages** 方法来启用此格式。

页面格式优先级 "first page only" > "odd and even pages" > normal。

* 如果同时启用"first page only" and "odd and even pages"页面格式, 则首页页眉和页脚按照"first page only"格式，其他的按照 "odd and even pages"格式。
* 普通页面的页眉和页脚以及奇数页的和页脚共享相同的自定义格式。

以下代码示例在所有页面上应用自定义页眉和页脚。

```JavaScript
// 配置工作簿和工作表
var spread = new GC.Spread.Sheets.Workbook('ss');
var activeSheet = spread.getActiveSheet();

var printInfo = activeSheet.printInfo();

printInfo.pageHeaderFooter({
    normal: {
        header: {
            left: '&G',
            center: 'Custom Header',
            leftImage: 'sampleImage.jpg',
        },
        footer: {
            center: '&P/&N',
        },
    },
});
```
