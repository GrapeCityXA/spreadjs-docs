# hierarchy-type

您必须使用层次结构的数据来构建 GanttSheet 任务树。甘特表任务树中存在三种类型的层次结构：父级、级别和子级。
当向数据管理器添加表时，可以配置它们中的每一个。您还可以使用数据表选项的“schema.hierarchy.type”手动更改使用的构建类型。

## 父层次结构

在Parent层次结构中，使用层次结构类型“Parent”，并且主键用于指示层次结构id。
以下代码示例演示如何在甘特表中设置父层次结构。

```json
schema: {
    hierarchy: {
        type: "Parent",
        column: "parentId"
    },
    columns: {
        id: {
            isPrimaryKey: true
        }, // 构建层次结构树节点需要主键
        taskNumber: { 
            dataType: "rowOrder"
        } //Id-ParentId类型中需要行顺序，以确保您更新正确的数据
     }
}
```

## 级别层次结构

在级别层次结构中，使用层次结构类型“Level”。在这种情况下，主键不是必需的，但是最好指示主键。
以下代码示例演示如何在甘特表中设置父层次结构。

```javascript
schema: {
    hierarchy: {
        type: "Level",
        column: "level"
    } 
}
```

## 子层次结构

在子层次结构中，使用层次结构类型“Children”。在这种情况下，主键不是必需的，但是最好为子项指定主键。
以下代码示例演示如何在甘特表中设置父层次结构。

```javascript
schema: {
    hierarchy: {
        type: "ChildrenPath",
        column: "children"
    } 
}
```
