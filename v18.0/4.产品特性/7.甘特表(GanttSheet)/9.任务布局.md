# task-layout

在甘特图中，使用 `TaskbarLayout` 类，你可以通过链接线模式、任务条高度、日期文本格式进行任务布局配置，还能将任务条时长舍入为整天数。

## 链接线模式

项目会在甘特图视图中显示链接线，这些链接线会突出显示相关联任务之间的依赖关系。如有必要，你可以通过设置 `linkLineMode` 选项的值来自定义链接线的外观，或者将其隐藏。有三种链接线模式可供选择：`noLinks`、`toTop` 和 `toEnd`，默认模式为 `toTop`。

## 任务条高度

你可以使用 `barHeight` 选项来设置任务条的高度。`barHeight` 的默认值是 12 像素。以下代码示例将任务条的高度设置为 36 像素。

```javascript
var barHeight = 36;
ganttSheet.project.layout.barHeight = barHeight;
```

运行上述代码将生成以下输出效果。
![TaskBarHeight.9cfd4d](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/TaskBarHeight.9cfd4d.536f10.png)

## 任务条日期格式

当你将日期字段添加到甘特图任务条时，会显示日期文本。你可以使用 `barTextDateFormat` 选项自定义日期格式的显示方式。默认的日期格式是 "yyyy/mm/dd hh:mm"。
以下代码示例将日期格式设置为 "yyyy/mm/dd"。

```javascript
var barTextDateFormat = "yyyy/mm/dd";
ganttSheet.project.layout.barTextDateFormat = barTextDateFormat;
```

运行上述代码将生成以下输出效果。
![TaskbarDateformat.d74d9c](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/TaskbarDateformat.d74d9c.730b68.png)

## 舍入为整天数

实际的任务持续时间并不总是整天数。如果你想将持续时间值覆盖为舍入后的整天数值，可以将 `roundBarsToWholeDays` 选项的值设置为 `true`。这样会将任务条的时长舍入为整天数。

| **属性值** | **输出效果** |
| --- | ---- |
| ganttSheet.project.layout.roundBarsToWholeDays = true; | ![Roundtowholedays_True.689b16](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/Roundtowholedays_True.689b16.b5dfe5.png) |
| ganttSheet.project.layout.roundBarsToWholeDays = false; | ![Roundtowholedays_false.2a415f](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/Roundtowholedays_false.2a415f.552b81.png) |
