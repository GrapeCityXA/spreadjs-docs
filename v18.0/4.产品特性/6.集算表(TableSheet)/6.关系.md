# tablesheet-relationships

Tablesheet 提供了通过创建关系在同一视图中绑定多个数据表的能力。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-relationview-flowchart.png)
如上图所示，Tablesheet关系定义了相关表和相关字段，可广泛用于具有主键和外键关系的表结构中。关系中的两个数据表都在数据管理器中进行双向绑定，并且可以访问两个表中的所有属性。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-relationview.gif)
以下步骤显示如何在表“Customers”和“Sales”之间添加表格关系。

1. 使用[addTable](gcdocsite__documentlink?toc-item-id=d168d582-7001-4e98-a184-2aafa89215e1#addTable)方法将多个表添加到数据管理器。

    ```JavaScript
    //将客户表添加到DataManager
    var customerTable = dataManager.addTable("customerTable", {
        remote: {
            read: {
                url: 'https://demodata.grapecity.com/wwi/api/v1/customers'
    
            }
        }
    });
    
    // 将销售表添加到DataManager
    var salesTable = dataManager.addTable("salesTable", {
        remote: {
            read: {
                url: 'https://demodata.grapecity.com/wwi/api/v1/sales?PageNumber=10&PageSize=500'
            }
        }
    });
    ```
2. 使用 [addRelationship](gcdocsite__documentlink?toc-item-id=d168d582-7001-4e98-a184-2aafa89215e1#addRelationship) 方法在表之间添加关系。
    此方法接受的参数为： 源表、字段名称、关系名称 和 目标表、字段名称、关系名称
    在以下代码示例中，“SalesTable”是目标表，“customerKey”是绑定这两个表的外键。

    ```JavaScript
    //在销售表和客户表之间添加关系
    dataManager.addRelationship(customerTable, "customerKey", "mySales", salesTable, "customerKey", "myCustomer");
    ```

    ```JavaScript
    var selectView = customerTable.addView("customersView",
        [
            { value: 'customerKey' },
            { value: 'customer' },
            { value: 'category' }
        ]);
    
    var multiSelectStyle = {
        formatter: '{{=IFERROR(CONCAT(PROPERTY(@, "customer"), ", ", PROPERTY(@, "customerKey")), "")}}',
        cellButtons: [
            {
                imageType: "dropdown",
                command: "openMultiColumn",
                useButtonStyle: true,
            }
        ],
        dropDowns: [
            {
                type: "multiColumn",
                option: {
                    width: 400,
                    height: 300,
                    dataSource: selectView,
                    bindingInfos: [
                        { name: "customerKey", size: 100, caption: "Customer Key" },
                        { name: "customer", size: "*", caption: "Customer" },
                        { name: "category", size: 100, caption: "Category" }
                    ]
                }
            }
        ]
    };
    
    var myView = salesTable.addView("myView", [
        { value: "saleKey", width: 100, caption: "Sale Key" },
        { value: "salesPerson", width: 150, caption: "Sales Person" },
        { value: "myCustomer", width: 350, caption: "Customer Information", style: multiSelectStyle },
        { value: "address", width: 350, caption: "Address" },
        { value: "stockItem", width: 350, caption: "Stock Item" },
        { value: "quantity", width: 100, caption: "Quantity" }
    ]);
    ```
4. 将视图绑定到集算表。

    ```JavaScript
    await selectView.fetch();
    await myView.fetch();
    
    tableSheet.setDataView(myView);
    ```
