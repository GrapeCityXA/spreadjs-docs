# tablesheet-io

您可以和spreadsheet一样以各种不同格式导出纸张表，例如JSON，Excel，PDF，甚至打印。

## JSON 序列化

TableSheet JSON 序列化和反序列化是使用工作簿的 [toJSON](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0#toJSON) 和 [fromJSON](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0#fromJSON) 方法完成的。JSON 文件包括了选项和 actionColumn 等信息，但不包括 dataView 和 dataView 列。
建议在 fromJSON 之后使用 [setDataView](gcdocsite__documentlink?toc-item-id=8dc0b7a4-ace7-4c61-b4a7-00790d5584fe#setDataView) 方法。

```JavaScript
function saveJSON() {
    // 保存json
    var json = spread.toJSON({ includeBindingSource: true, saveAsView: true });
    saveAs(new Blob([JSON.stringify(json)], { type: "text/plain;charset=utf-8" }), 'exportedJSON.ssjson');
}

function openJSON() {
    // 加载json
    var file = document.getElementById("fileDemo").files[0];
    if (file) {
        var reader = new FileReader();
        reader.onload = function () {
            var json = JSON.parse(this.result);
            spread.fromJSON(json);
        };
        reader.readAsText(file);
    }

}
```

### 导出Excel文件

使用 gc.sproad.excel.io 的 [save](/spreadjs/api/GC.Spread.Excel.IO.html#save) 方法可以将TableSheet导出到Excel。 当 **saveAsView** 为 true 且不包括图标集、数据栏和数据验证时，TableSheet视为worksheet中的一个包括 alterRowStyles 和条件格式的table，
导出到 Excel 时，建议将 **includeBindingSource** 设置为 true。导出到 Excel 时，将 **saveAsView** 设置为 true 是可选的。

```JavaScript
function saveExcel() {
    // 保存Excel.
    var excelIo = new GC.Spread.Excel.IO();
    var json = spread.toJSON({ includeBindingSource: true, saveAsView: true });
    excelIo.save(json, function (blob) {
        saveAs(blob, "exportedExcel.xlsx");
    }, function (e) {
        console.log(e);
    });
}
```

## 导出PDF

使用工作簿的[savePDF](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0#savePDF)方法将TableSheet导出为PDF。 PDF 包括绑定结果，但不包括图标、选项和 actionColumn。
在打印或导出为PDF时，用户可以使用[printInfo](gcdocsite__documentlink?toc-item-id=6f8e15e8-6dec-4e4f-a772-49bbdae4daa3)方法自定义打印信息。

```JavaScript
function savePDF() {
    // 保存PDF.
    spread.savePDF(function (blob) {
        saveAs(blob, "exportedPDF.pdf");
    }, function (error) {
        console.log(error);
    }, null, spread.getSheetCount() + spread.getActiveSheetTabIndex());
}
```

## 打印 Tablesheet

使用工作簿的[print](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0#print)方法可以进行Tablesheet打印。 打印包括绑定结果，但不包括图标、选项和 actionColumn。

```JavaScript
function print() {
    // Print Spread
    spread.print();
}
```
