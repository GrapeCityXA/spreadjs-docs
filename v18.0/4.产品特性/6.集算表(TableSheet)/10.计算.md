# tablesheet-calculations

TableSheet使用增强的计算引擎来帮助用户在当前视图中像正常电子表格一样创建和分析数据。

## 计算列

您可以通过简单列引用或高级摘要和逻辑函数来添加计算的列。可以使用例如"=[@column1]"这种结构化的引用来创建这些计算的列 同时也支持Calcengine函数。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-calccols.png)

引用包括至少一个行或列引用。您可以在下表中找到所有可用的行和列引用。

| 引用 | 描述和示例 |
| --- | ----- |
| **Row References** |
| Current Row | 引用当前行。<br>[@column1] - 返回当前行中column1的值。 |
| Relative Row | 引用相对行。<br>[@+1column1] - 返回下一行中的column1的值。<br>[@-1column1] - 返回上一行中的column1的值。 |
| Absolute Row | 通过行号或 "last"/"odd"/"even" 引用绝对位置行。<br>[#1[column1]] - 返回第一行中的column1的值。[#last[column1]] - 返回最后一行中的column1的值。 |
| Absolute Row by ID | 按主键引用行。<br>[$1234[column1]] -返回主键为"1234"的column1的值 |
| Row Range | 引用一个包含开始和结束的行范围。<br>[@:#last[column1]] - 返回从当前行到最后一行的行column1的值 |
| Several Rows | 通过逗号引用若干行。<br>[#1,@-1:@+1,#last[column1]] - 返回第1行、上一行到下一行、最后一行中column1的值。 |
| **列引用** |
| Regular Field | 引用当前字段。<br>[@column1] - 当前字段column1中的数据。 |
| Attribute of object field | 引用当前字段的属性。<br>[@column1.abc] - 返回当前行中column1字段的的“abc”属性值。 |
| Item of array field | 引用当前字段的索引项。<br>[@column1.1] - 返回当前行中column1字段的一个值 |
| Special Field | 用空格引用当前字段的属性。<br>[@[column 1].[a aa]] - 使用方括号返回某些字段和属性。 |
| Whole Column | 引用整个字段。<br>[column1] - 返回column1中的所有数据。 |

以下代码示例显示如何创建计算列，其中 "Total Price" 列由公式 "=([@unitPrice] \* [@taxRate])/100 + [@unitPrice]"定义。

```JavaScript
//bind a view to the table sheet
myTable.fetch().then(function () {
    var view = myTable.addView("myView", [

        { value: "stockItem", width: 300, caption: "Stock Item" },
        { value: "unitPrice", width: 120, caption: "Unit Price" },
        { value: "taxRate", width: 120, caption: "Tax Rate" },
        { value: "=([@unitPrice] * [@taxRate])/100 + [@unitPrice]", caption: "Total Price", width: 150 } // calculated column
    ]);
    sheet.setDataView(view);
});
```

## 在视图中引用计算列

你可以使用 `formula`（公式）数据类型在数据管理器表格中添加虚拟列，这些虚拟列可以引用诸如数据列、表格列或其他公式列等列。这些公式列可以在表格工作表的 **视图** 中使用。
例如，以下图片展示了如何使用 `formula` 数据类型来创建虚拟列 “**累计求和（Running Sum）**” 和 “**库存价值比率（Stock Value Ratio）**”。
![ts-formulacalculatedcolumn.b60653](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ts-formulacalculatedcolumn.b60653.30f793.png)
以下代码示例展示了如何使用 `formula` 数据类型来创建虚拟列，然后使用这些虚拟列定义来创建表格工作表的视图。

```javascript
// 添加产品表格。
var productTable = dataManager.addTable("productTable", {
    remote: {
        read: {
            url: baseApiUrl + "/Product"
        }
    },
    schema: {
        columns: {
            TotalUnits: {
               dataType: "formula",
               value: "[@UnitsInStock] + [@UnitsOnOrder]"
            },
            StockValue: {
                dataType: "formula",
                value: "[@UnitPrice] * ([@TotalUnits])"
            }
        }
    }
});

// 将视图绑定到表格工作表
var myView = productTable.addView("myView", [
    { value: "Id", caption: "ID", width: 50 },
    { value: "ProductName", caption: "名称", width: 170 },
    { value: "UnitPrice", caption: "单价", style: { formatter: "$#,##0.00" }, width: 120 },
    { value: "UnitsInStock", caption: "库存数量", width: 120 },
    { value: "TotalUnits", caption: "总数量", width: 120 },
    { value: "StockValue", caption: "库存价值", style: { formatter: "$#,##0.00" }, width: 120 },
    { value: "=SUM([#1:@[UnitPrice]]*([#1:@[UnitsInStock]]+[#1:@[UnitsOnOrder]])", caption: "累计求和", style: { formatter: "$#,##0.00" }, width: 150 },
    { value: "=[@StockValue]/SUM([UnitPrice] * ([UnitsInStock] + [UnitsOnOrder]))", caption: "库存价值比率", style: { formatter: "0.00%" }, width: 160 }
]);
```

## 在工作表中的引用TableSheet

您可以使用结构化引用在工作表中像表格一个引入tablesheet，这有助于交叉引用和汇总表格中的数据以创建高级报告视图。
与表格引用一样，您可以在公式中设置表格名称和列标题。它还支持 A1/R1C1 参考风格，虽然它不那么容易阅读。
下面的GIF说明了 SUM、COUNT 和 UNIQUE 等函数的使用，其中tablesheet引用是SUM(Tablesheet1[Total Price])等
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-referencews.gif)
引用样式也可被用于单元格公式、图表和条件格式。
下面的代码示例演示如何在工作表中设置tablesheet引用。

```JavaScript
// 创建一个新工作表并将其添加为工作簿的第二个sheet。
var sheet1 = new GC.Spread.Sheets.Worksheet();
sheet1.name("TS Reference in Formula");
spread.addSheet(1, sheet1);
sheet1.setColumnWidth(0, 250);
sheet1.setColumnWidth(1, 150);

// 在工作表公式中设置tablesheet引用
sheet1.setValue(0, 0, "Stock Items Count")
sheet1.setFormula(0, 1, "=COUNTA(TableSheet1[Stock Item Key])");
sheet1.setValue(1, 0, 'Sum of Total Price')
sheet1.setFormula(1, 1, '=SUM(TableSheet1[Total Price])');
// 独特税率
sheet1.setValue(3, 0, 'Different Tax Rates are:-')
sheet1.setFormula(3, 1, '=UNIQUE(TableSheet1[Tax Rate])'); // it returns a dynamic array and we have already set allowDynamicArray to true initially
```

您可以使用 QUERY 函数从 Data Manager 表中获取数据。要了解更多信息，请参考公式中的[QUERY 函数](gcdocsite__documentlink?toc-item-id=58273c8f-3627-459e-86b9-b03467f14e33)
