# tablesheet-operations

TableSheet 提供了丰富的操作来与 TableSheet 视图进行交互和排列，以便轻松导航或分析当前数据。请参阅以下主题以了解更多信息：

| **功能** | **描述** |
| --- | --- |
| [固定/取消固定](gcdocsite__documentlink?toc-item-id=0b681e51-8c90-43c2-bb49-bc2e7d71b768) | 将行或列固定到当前表格工作表视图的顶部或左侧。 |
| [排序和筛选](gcdocsite__documentlink?toc-item-id=2276aff6-b5d6-47ec-81f1-6cafe2386676) | 通过代码或使用筛选对话框对列进行排序和筛选。<ul><li>[排序](gcdocsite__documentlink?toc-item-id=2276aff6-b5d6-47ec-81f1-6cafe2386676#%E6%8E%92%E5%BA%8F)</li><li>[筛选](gcdocsite__documentlink?toc-item-id=2276aff6-b5d6-47ec-81f1-6cafe2386676#%E7%AD%9B%E9%80%89)</li></ul> |
| [行操作](gcdocsite__documentlink?toc-item-id=e9df7972-64f6-4063-a91d-fbd41322f6ac) | 显示数据行状态或执行操作。<ul><li>[自定义操作](gcdocsite__documentlink?toc-item-id=e9df7972-64f6-4063-a91d-fbd41322f6ac#%E8%87%AA%E5%AE%9A%E4%B9%89%E6%93%8D%E4%BD%9C)</li></ul> |
| [行操作命令](gcdocsite__documentlink?toc-item-id=cc7167af-97b0-4989-b4d0-b0f97bf61420) | 使用命令属性在点击行标题时实现用户行操作命令。 |
| [分组](gcdocsite__documentlink?toc-item-id=91cdc22b-1a69-43e1-935b-b1ddee4cfe37) | 按指定字段对数据源进行分组。<ul><li>[多重分组](gcdocsite__documentlink?toc-item-id=299478ff-44eb-4ef2-9118-100cc904b26d)</li><li>[分组中排序/筛选](gcdocsite__documentlink?toc-item-id=2d7c0ce4-cf40-4796-a6f5-e011082e4933)</li><li>[在分组中使用单元格类型](gcdocsite__documentlink?toc-item-id=bc119e53-3395-4290-9c0a-0495c59c188a)</li></ul> |
| [重新排列](gcdocsite__documentlink?toc-item-id=bc044c9b-a409-49b5-a8c2-2e48fa9670a8) | 根据您的偏好一起重新排列工作表和表格工作表的位置。 |
| [撤销/重做](gcdocsite__documentlink?toc-item-id=e790855d-2e6f-44b6-ad03-0e4eb579f8d1) | 轻松撤销和恢复对表格工作表数据所做的更改。 |
