# lastvalue

该函数从窗口帧的最后一行返回参数的值。它不需要使用ORDERBY子句。

## 语法

`LASTVALUE(value_function)`

## 参数

该函数提供以下参数。

| **参数** | **描述** |
| -------- | ----------- |
| *value\_function* | [必选] 字段名或公式。 |

## 示例

```
// WINDOW(LASTVALUE([@sold]), PARTITIONBY([city]),ORDERBY([month]), FRAMERANGE(-1,-1))

城市     |   月份  | 销售额 | 最后值
----------------------------------------------
Paris      1      500       400
Paris      2      300       400
Paris      3      400       400
Rome       2      200       500
Rome       3      300       500
Rome       4      500       500
```
