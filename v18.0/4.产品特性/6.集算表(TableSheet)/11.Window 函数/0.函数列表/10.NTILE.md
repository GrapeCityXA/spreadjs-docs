# ntile

该函数将一个分区划分为N个桶，并为分区中的每一行分配其桶编号。它不接受窗口帧定义，如FRAMEROWS和FRAMERANGE。

## 语法

`NTILE(n)`

## 参数

该函数提供以下参数。

| **参数** | **描述** |
| -------- | ----------- |
| *n* | [必选] 桶的数量。 |

N应为正整数，桶编号从1开始。如果分区内的行数不能被N整除，则会出现两种大小的桶。较大的桶排在较小的桶之前。如果N大于或等于行数，则每一行都被视为一个桶。

## 示例

```
// WINDOW(NTILE(3), ORDERBY([sold]))

城市      |    销售额   |    ntile
----------------------------------------------
Paris         100           1
Berlin        150           1
Rome          200           2
Moscow        200           2
London        300           3
```
