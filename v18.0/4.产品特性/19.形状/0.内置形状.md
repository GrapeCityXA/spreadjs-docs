# AddingBuiltInShapes

SpreadJS 支持在工作表中添加 182 种类型的内置形状。用户还可以在工作表中移动、调整大小、旋转或删除已插入的形状。
你可以从各种各样的内置形状中进行选择，并通过使用 SpreadJS 设计器中的 “插入” 选项卡或通过代码，在工作表中嵌入任何类型的绘图对象（包括线条、矩形、带箭头的块状图形、公式形状、流程图、星形、横幅、标注等）。
在使用 SpreadJS 设计器插入形状时，你会看到如下方截图所示的 “形状菜单”。使用此菜单，你可以根据自己的需求插入任何类型的绘图对象。添加内置形状后，你还可以通过设置其文本格式、颜色和样式来自定义该形状。

下方分享的是一张截图，展示了添加到工作表中的一个内置形状 —— “圆环”。
![builtinshape](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/builtinshape.a5bdd8.png)
以下代码示例展示了如何通过代码向工作表中添加一个内置形状。

```javascript
// 在工作表中添加内置形状 “圆环”
window.onload = function ()
{
    var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
    var sheet = spread.getActiveSheet();
    // 添加内置形状 “圆环”
    var donutShape = sheet.shapes.add('autoShape',GC.Spread.Sheets.Shapes.AutoShapeType.donut,100,50,150,150);          
    // 向内嵌形状 “圆环” 添加文本
    donutShape.text("Donut Shape");
    // 向内嵌形状 “圆环” 添加样式
    var shapeStyle = donutShape.style();
    shapeStyle.textEffect.color = "Red";
    shapeStyle.textEffect.font = "18px Arial";
    shapeStyle.textFrame.hAlign = GC.Spread.Sheets.HorizontalAlign.center;
    shapeStyle.textFrame.vAlign = GC.Spread.Sheets.VerticalAlign.center;
    donutShape.style(shapeStyle);
};
```

> **注意：** 在集成内置形状时，SpreadJS 不支持以下情况：
>
> * 形状文本仅支持水平方向、水平和垂直文本对齐方式、纯色填充、字体（名称和大小）以及边距等。
> * 标注形状类型中超出形状边界部分的命中测试（HitTest）功能并非完全支持。因此，用户无法通过点击超出形状边界的部分来选择形状。
