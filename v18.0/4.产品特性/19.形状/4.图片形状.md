# picture-shape

SpreadJS 支持将图片作为形状添加并进行格式化。
图片对象使用 `ShapeBase` 类创建，并继承形状的属性。这有助于对图片进行格式化并与形状进行交互。
![image.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.9ce3e8.488154.png)
你可以使用 **addPictureShape** 方法添加图片形状。该方法接受诸如名称、源、位置（x 和 y 坐标）以及大小（宽度和高度）等参数。

```JavaScript
// 配置工作簿和工作表
var spread = new GC.Spread.Sheets.Workbook("ss");
var sheet = spread.getActiveSheet();
// 将图片作为形状添加
var originalPic = sheet.shapes.addPictureShape("Apple", '/apple.png', 20, 50, 200, 200);
```

[PictureShape ](gcdocsite__documentlink?toc-item-id=9c7d5080-c3a8-49cc-9c08-138fe8cd735f)类提供了各种方法来控制图片形状的外观。例如，下图展示了在椭圆形几何类型形状中添加的旋转图片。
![image.png](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.423ccb.4e8a9f.png)

```JavaScript
var pic = sheet.shapes.addPictureShape("Apple", '/apple.png', 280, 60, 200, 200);
// 设置样式
var style = pic.style();
style.fill.type = GC.Spread.Sheets.Shapes.ShapeFillType.solid;
style.fill.color = 'rgb(14, 242, 200)';
style.line.color = 'rgb(255, 204, 0)';
style.line.width = 3;
pic.style(style);
// 设置为不同的形状
pic.geometryType(GC.Spread.Sheets.Shapes.AutoShapeType.oval);
// 旋转图片
var n = pic.rotate();
pic.rotate(n + 30);
```

> **注意**：在工作表中复制和粘贴图像文件时，默认会创建图片形状。必须添加形状插件，否则将创建浮动对象图片而非图片形状。

## 图片格式

有许多调整选项可用于对图片形状进行格式化。你可以在 **pictureFormat** 方法中设置一个包含以下选项的格式化数组。

| 选项 | 描述 | 示例 |
| --- | --- | --- |
| blackAndWhite number | 指定双色效果。值的范围是 [0, 1]。<ul><li>如果亮度大于或等于阈值，则设置为白色。</li><li>如果亮度小于阈值，则设置为黑色。</li></ul> | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pic-format-black-white.29a80d.ac4a4e.gif) |
| brightness number | 调整图片亮度。值的范围是 [-1, 1]。它会将所有颜色线性地向白色或黑色偏移。 | @rows=2:![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pic-format-brightness-contrast.1037ac.d2ee3c.gif) |
| contrast number | 调整图片对比度。值的范围是 [-1, 1]。它会将所有颜色的差异进行缩放，使其更接近或更远离。 |
| cropIPictureCropInfo | 指定用于填充的图像部分。 | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pic-format-crop.fc0bf1.a0a8f1.gif) |
| duotone Object | 指定双色调效果。它通过线性插值将颜色 1 和颜色 2 组合起来，为每个像素确定新的颜色。 | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pic-format-duotone.ebea8d.5b874a.gif) |
| transparency number | 调整透明度级别。值的范围是 [0, 1]。 | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pic-format-transparency.df7920.b1fafe.gif) |
| grayscale boolean | 指定是否应用灰度效果。默认值为 False。它会将所有受影响的颜色值转换为与其亮度对应的灰色调。 | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pic-format-grayscale.9959dd.599483.gif) |

以下代码示例展示了如何对 SpreadJS 工作表中的图片形状应用每个格式化选项。

```JavaScript
   // 设置黑白效果
   pic.pictureFormat({ blackAndWhite: 0.5 });  
   // 设置亮度和对比度
   var format = pic.pictureFormat();
   // 设置亮度和对比度
   format.brightness = 0.4;
   format.contrast = 0.4;
   pic.pictureFormat(format);
   // 设置裁剪
   var format = pic.pictureFormat();
   // 裁剪图片
   format.crop = { left: -.015, right: -0.15, top: -0.15, bottom: -0.15 };
   pic.pictureFormat(format);
   // 设置双色调
   pic.pictureFormat({ duotone: { color1: "black", color2: "red" } });
   // 设置透明度
   var format = pic.pictureFormat();
   // 设置透明度
   format.transparency = 0.5;
   pic.pictureFormat(format);
   // 设置灰度效果
   pic.pictureFormat({ grayscale: true });
```
