# row-col-states

SpreadJS允许用户根据行和列的当前状态配置样式。用户可以通过使用 [GC.Spread.Sheets.RowColumnStates](gcdocsite__documentlink?toc-item-id=ba29c6aa-46ad-4c97-a29e-b0b16e5f4d02) 枚举来设置所有状态。
用户可以使用 [ConditionalFormatting.RuleType](gcdocsite__documentlink?toc-item-id=27b8d503-6632-4c6c-a7cf-b981d2443429) 枚举选项中的 **rowStateRule** 或 **columnStateRule** ，然后添加规则以指定状态。
行和列状态都基于条件格式，因此用户还可以使用 [ConditionalFormats](gcdocsite__documentlink?toc-item-id=bff875a5-6d6d-4777-a40a-cfe2d4c17ef1) 类中的方法 [addRowStateRule](gcdocsite__documentlink?toc-item-id=bff875a5-6d6d-4777-a40a-cfe2d4c17ef1#addRowStateRule) 和 [addColumnStateRule](gcdocsite__documentlink?toc-item-id=bff875a5-6d6d-4777-a40a-cfe2d4c17ef1#addColumnStateRule) 添加行和列状态。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/rowcolStates.gif)

> **提示：** 行和列状态不支持移动或复制条件格式区域。

### 状态类型

下表列出了[GC.Spread.Sheets.RowColumnStates](gcdocsite__documentlink?toc-item-id=ba29c6aa-46ad-4c97-a29e-b0b16e5f4d02) 中所有可用的行和列状态枚举选项。

| 枚举选项 | 描述 |
| ---- | --- |
| edit | 当任意单元格被编辑时，样式将在处于编辑状态下指定的行或列中被执行。 |
| hover | 当任意单元格被悬浮时，样式将在处于悬浮状态下指定的行或列中被执行。 |
| active | 当任意单元格处于焦点时，样式将在处于活动状态下指定的行或列中被执行。 |
| selected | 当任意单元格被选中时，样式将在处于选中状态下指定的行或列中被执行。 |
| updated | 当任意单元格更新时，会锁定受保护工作表中的相应行或列。 |
| inserted | 当插入任意单元格时，会锁定受保护工作表中的相应行。 |
| dirty | 当任意单元格状态设置为脏状态时，样式将在处于脏状态下指定的行或列中被执行。 这使得行或列可以轻松跟踪工作表中数据的任何更改。<br>\> 脏行状态包括插入行状态。但脏列状态不包括插入的列。 |
| invalid | 当任意单元格设置为无效时，样式将在处于无效状态的指定行或列中被执行。 |

### 状态优先级

当用户在同一方向和同一范围内设置多个状态时，如果相应的行或列需要同时满足不同的状态，则设置的状态样式将具有优先级。
状态样式优先级按照以下顺序：
Edit > Hover > Active > Selected > Updated > Inserted > Dirty > Invalid.

### 代码应用

以下代码示例展示如何同时使用[ConditionalFormats](gcdocsite__documentlink?toc-item-id=bff875a5-6d6d-4777-a40a-cfe2d4c17ef1)类方法和添加新状态规则来添加行和列状态。

```JavaScript
$(document).ready(function () {
    
    var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"), { sheetCount: 3 });
    var sheet = spread.getSheet(0);

    // 使用新的状态规则
    var cfs = sheet.conditionalFormats;            
    var ruleType = GC.Spread.Sheets.ConditionalFormatting.RuleType.rowStateRule;
    var hoverstate = GC.Spread.Sheets.RowColumnStates.hover;
    var style = new GC.Spread.Sheets.Style("yellow");
    var ranges = [new GC.Spread.Sheets.Range(-1, -1, -1, -1)];
    var rule = new GC.Spread.Sheets.ConditionalFormatting.StateRule(ruleType, hoverstate, style, ranges);
    cfs.addRule(rule);

    // 使用 ConditionalFormats 类方法
    var cfs1 = sheet.conditionalFormats;
    var style1 = new GC.Spread.Sheets.Style("lightblue");
    var columnRange = [new GC.Spread.Sheets.Range(-1, -1, -1, -1)];
    cfs1.addColumnStateRule(GC.Spread.Sheets.RowColumnStates.selected, style1, columnRange); // adding column state

    var cfs2 = sheet.conditionalFormats;
    var style2 = new GC.Spread.Sheets.Style("pink");
    var rowRange2 = [new GC.Spread.Sheets.Range(-1, -1, -1, -1)];
    cfs2.addRowStateRule(GC.Spread.Sheets.RowColumnStates.dirty, style2, rowRange2); // adding row state
});
```
