# dirty

当单元格发生变化时，SpreadJS 会将该单元格设置为“脏”状态，因此需要重新计算。如果一个单元格是脏的，那么当前行也会是脏的。你可以获取单元格和行的脏状态。
加载绑定数据时，单元格不是脏的。将单元格绑定到数据源后对其进行更改会设置脏状态。
如果在插入行时设置了值，该行将被视为插入行而非脏行。设置行或列的数量后，或者使用 `fromJSON` 和 `toJSON` 方法时，脏状态会被清除。
你可以使用 [clearPendingChanges ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#clearpendingchanges)方法清除脏状态。可以使用 [getDirtyRows ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#getdirtyrows)和 [getDirtyCells ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#getdirtycells)方法获取脏行和脏单元格。
以下代码示例展示了如何编辑单元格以设置脏状态，并使用按钮清除脏状态。

#### 示例代码

编辑单元格以设置脏状态。 选择按钮以清除脏状态。

```JavaScript
var customers = [
           { ID: 0, Name: 'A', Info1: 'Info0' },
           { ID: 1, Name: 'B', Info1: 'Info1' },
           { ID: 2, Name: 'C', Info1: 'Info2' },
        ];
        activeSheet.setDataSource(customers);
$("#button1").click(function () {
activeSheet.clearPendingChanges();
});
// 将按钮控件添加到页面
<input type="button" id="button1" value="button1"/>
```
