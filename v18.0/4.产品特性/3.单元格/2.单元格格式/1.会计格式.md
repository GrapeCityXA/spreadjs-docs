# AccountingFormat

SpreadJS支持单元格上的会计格式，以避免在读取货币值时出错。 与Excel中相同的方式支持此功能。
会计格式允许用户对齐列中数字的货币符号和小数点，从而提高了可读性。 负数显示在括号中，零显示为破折号。
下表列出了会计格式字符和为使用会计格式而提供的格式字符:

| **字符** | **描述** |
| --- | --- |
| \_ | 您可以使用下划线字符 “\_*” 创建一个空格，该空格是数字格式字符的宽度。 例如，*）使正数与括号中包含的负数对齐。 |
| \* | 在数字格式中使用星号 “\*” 重复下一个字符，以使其填满列宽。 例如，键入0 *-以在数字后包含足够的破折号以填充单元格。* <br>*在任何格式之前输入* 0以包含前导零。 |
| , | 逗号显示数字中的千位分隔符。 如果格式包含用数字符号 “＃” 或零括起来的逗号，则Spread用逗号分隔成千上万。 <br>占位符后的逗号会将数字按1,000缩放。 例如，如果格式为＃.0，并在单元格中键入12,200,000，则会显示数字$ 12200.0 |
| % | 在数字格式中使用百分号“％”将数字显示为100的百分比。例如，将.08显示为8％。 |
| ? | 数字占位符 ( '?' ): 在数字占位符中添加数字占位符，这个数字占位符?遵循与0相同的规则。<br>然而在小数点的两边增加了一个零的空间。 |

以下列表描述了使用会计格式时需要注意的一些事项：

* 如果允许自动换行并且单元格包含多行，则重复字符不生效。
* 如果单元格支持文本溢出，则忽略重复字符。
* 重复字符不能自动配合使用。
* 重复字符不会因收缩而变空白。
* 空白区域不显示文字装饰。
* 会计格式支持的单元格类型包括：文本单元格类型，按钮单元格类型，组合框单元格类型和标题单元格单元格类型。

本示例使用 **setValue** 方法设置单元格的记帐格式。

```JavaScript
var sheet = spread.getActiveSheet();
sheet.setValue(1, 0, 'Standard Accounting Format :  _($* #,##0.00_);_($* (#,##0.00);_($* "-"??_);_(@_)');
sheet.setValue(2, 0, 'Value');
sheet.setValue(3, 0, 12);
sheet.setValue(4, 0, -12);
sheet.setValue(5, 0, 0);
sheet.setValue(6, 0, 'Text');
sheet..setValue(2, 2, 'Formatted Result');
sheet.getRange(3, 2, 4, 1).formatter('_($* #,##0.00_);_($* (#,##0.00);_($* "-"??_);_(@_)');
sheet.setValue(3, 2, 12);
sheet.setValue(4, 2, -12);
sheet.setValue(5, 2, 0);
sheet.setValue(6, 2, 'Text');
```

此示例使用了 **setFormatter** 方法。

```JavaScript
var sheet = spread.getActiveSheet();
sheet.setValue(1, 2, 12.34);
sheet.setFormatter(1, 2, '$* #.##');
```
