# cellcheckbox

你可以使用复选框单元格在单元格中显示一个复选框。复选框单元格会显示一个小复选框，该复选框可以具有三种状态之一：已选中、未选中或不确定状态。你可以通过设置文本来定制复选框。
将 [isThreeState ](gcdocsite__documentlink?toc-item-id=9c6c313f-1184-4a74-87b1-b51775c97386#isthreestate)方法设置为 `true`，以显示三种状态（而不是两种：已选中或未选中）。你还可以使用 [textAlign](gcdocsite__documentlink?toc-item-id=9c6c313f-1184-4a74-87b1-b51775c97386#textalign) 方法指定复选框和文本的对齐方式。
![cellcheckbox](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/cellcheckbox.2f790a.png)
你可以使用 [value ](gcdocsite__documentlink?toc-item-id=64f05fd4-fafa-47dc-9856-b74263f357ec#value)方法在代码中设置复选框的状态，如下表所示：

| **值** | **状态** |
| --- | --- |
| `null` | 不确定 |
| `0` | 未选中 |
| `1` | 已选中 |

你可以使用 **boxSize()** 方法更改复选框的大小，该方法的值可以设置为任意数字或 "auto"。如果该方法被设置为任何无效值，复选框的大小不会改变。复选框单元格类型中复选框的标准大小是 12\*12。

### 使用代码

以下示例创建了一个具有三种状态的复选框单元格。

```javascript
// 获取活动工作表
var activeSheet = spread.getSheet(0);
var cellType = new GC.Spread.Sheets.CellTypes.CheckBox();
cellType.caption("caption");
cellType.textTrue("True");
cellType.textFalse("False");
cellType.textIndeterminate("Indeterminate");
cellType.textAlign(GC.Spread.Sheets.CellTypes.CheckBoxTextAlign.bottom);
cellType.isThreeState(true);
cellType.boxSize(20);
activeSheet.getCell(1, 1).cellType(cellType);
//activeSheet.getCell(1, 1).value(1);
```

## 复选框单元格中的文本换行

在复选框标题过长而无法完全显示在单元格中的情况下，若要对显示的文本进行换行，你需要将单元格样式的 **wordWrap** 属性设置为 `true`。**wordWrap** 属性默认设置为 `false`。

| **wordWrap 属性** | **输出** |
| ----------- | --- |
| **wordWrap** = false | ![wordWrap_false.a6ede2](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/wordWrap_false.a6ede2.6743bb.png) |
| **wordWrap** = true | ![wordWrap_true.1db0f2](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/wordWrap_true.1db0f2.91b4a2.png) |

复选框单元格遵循的换行规则是，它首先按单词进行内容的换行，如果需要，会进一步拆分内部单词以适应可用空间。
![wordWrap_innerWordBreak.d51d01](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/wordWrap_innerWordBreak.d51d01.2bc2ed.png)
如果复选框单元格启用了 **wordWrap** 且设置了单元格的垂直对齐方式，那么复选框将如下显示：

| **垂直对齐方式** | **输出** |
| ------ | --- |
| 如果单元格的 vAlign 为顶部，则复选框将与文本顶部对齐。 | ![wordWrap_true.08d8f5](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/wordWrap_true.08d8f5.ff0040.png) |
| 如果单元格的 vAlign 为中间，则复选框将与文本中间对齐。 | ![wordWrap_middleAlign.f596f7](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/wordWrap_middleAlign.f596f7.4bcacb.png) |
| 如果单元格的 vAlign 为底部，则复选框将与文本底部对齐。 | ![wordWrap_bottomAlign.f325dc](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/wordWrap_bottomAlign.f325dc.b34b2c.png) |

然而，你可以根据单元格的 hAlign 值更改换行文本的水平对齐方式。例如，如果单元格的 hAlign 设置为右侧，只有标题文本会与单元格右侧对齐。类似地，如果单元格的 hAlign 设置为左侧或居中，只有标题文本的对齐方式会更改为左侧或居中。

### 使用代码

以下示例在复选框单元格中实现了 **wordWrap**。

```javascript
// 设置长标题
cellType.caption("This is a very very long long text"); 
activeSheet.getCell(1, 1).cellType(cellType); 
activeSheet.setRowHeight(1, 120); 
activeSheet.setColumnWidth(1, 110); 
// 将 wordwrap 属性设置为 true
activeSheet.getCell(1, 1).wordWrap(true);
```
