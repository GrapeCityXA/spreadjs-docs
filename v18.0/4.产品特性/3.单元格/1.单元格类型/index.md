# celltypes

单元格类型定义了单元格中信息的类型，信息的显示方式以及用户如何与之交互。 SpreadJS支持组合框，可编辑组合框，复选框，复选框列表，按钮，单选按钮列表，文本，超链接和自定义单元格类型。
