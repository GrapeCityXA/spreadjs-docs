# cellcombo

SpreadJS 支持组合框单元格，该单元格会显示一个下拉列表。
![cellcombo](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/cellcombo.960e18.png)
如果选项宽度小于单元格宽度，则选项宽度将设置为单元格宽度；否则，选项宽度将等于最长选项的宽度。
以下示例创建了一个带有选项列表的组合框单元格。

```javascript
var cellType2 = new GC.Spread.Sheets.CellTypes.ComboBox();
cellType2.items(["a","b","c"]);
activeSheet.getCell(2, 2).cellType(cellType2);
```

组合框单元格是可编辑的，你可以在单元格的编辑部分输入内容，列表中匹配的选项会自动被选中。
![cellecombo](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/cellecombo.d4fc9a.png)
以下示例创建了一个可编辑的组合框单元格，并带有选项列表。

```javascript
var items2 = ["a", "ab", "abc", "apple", "boy", "cat", "dog"];
var eComboBoxCellType = new GC.Spread.Sheets.CellTypes.ComboBox().items(items2).editable(true);
activeSheet.getCell(1, 3).cellType(eComboBoxCellType);
activeSheet.setColumnWidth(3,120);
```

下拉列表中最多可显示20个可见选项。当下拉列表显示时，使用向上或向下箭头键选择选项。向左和向右箭头键可确认所选选项并移动到下一个或上一个单元格。回车键也可确认所选选项，而Esc键则取消所选选项。
在使用快速输入模式时，箭头键的行为可能会有所不同。如果单元格的编辑状态为 `EditorStatus.Enter`，按下向左或向右箭头键将结束编辑并导航到上一个或下一个单元格。如果编辑状态为 `EditorStatus.Edit`，按下向左或向右箭头键不会结束编辑。

### **绑定组合框单元格**

SpreadJS 允许用户通过将组合框绑定到数据源（如表名或公式计算结果），在电子表格单元格中创建动态下拉列表。用户可以使用公式对数据源进行过滤、获取唯一值或排序。要绑定组合框单元格类型，可使用 `ComboBoxCellType` 类的 `dataBinding` 方法，该方法接受 `dataSource`、`text` 和 `value` 属性。

* “text” 或 “value” 必须是表的列名或公式计算结果的列索引。
* 如果设置了 “text” 或 “value” 其中一个选项，另一个将采用相同的值。
* 如果既未设置 “text” 也未设置 “value”，则 “text” 和 “value” 都将绑定到数据源的第一列。

> 注意 -
>
> * 要在 `ComboBoxCellType` 中使用数据绑定，必须启用 `spread.options.allowDynamicArray` 选项。
> * `dataBinding` 方法不会影响 `ComboBoxCellType` 的 `editValueType`。
> * 如果 `dataSource` 是一个公式，该公式的结果必须是一个数组。
> * 复制/移动/重命名工作表时，公式引用的范围不会自动更改。
> * 公式中不支持 R1C1 引用。

以下代码用于将 **组合框** 单元格类型与表列绑定，分别使用表名作为数据源以及公式计算结果作为数据源。

```javascript
spread.options.allowDynamicArray = true;
const dataManager = spread.dataManager();
const productsTable = dataManager.addTable("Products", {
     remote: {
         read: {
             url: 'https://northwind.vercel.app/api/products'
         }
     }
 });
await productsTable.fetch(true);

// 绑定到表名
let sheet = spread.getSheet(0);
sheet.name("Binding To A Table Name");
sheet.setColumnWidth(2, 250);
let binding = { dataSource: "Products", text: "name", value: "id" };
let cellType = new GC.Spread.Sheets.CellTypes.ComboBox();
cellType.dataBinding(binding);
sheet.getCell(2, 2).cellType(cellType);

// 绑定到公式查询
let sheet1 = spread.getSheet(1);
sheet1.name("Binding To A Formula Query");
sheet1.setColumnWidth(2, 250);
let binding1 = { dataSource: '=SORT(UNIQUE(QUERY("Products", {"name","id"})))', text: 0, value: 1 };
let cellType1 = new GC.Spread.Sheets.CellTypes.ComboBox();
cellType1.dataBinding(binding1);
sheet1.getCell(2, 2).cellType(cellType1);
```

### **设置下拉框位置**

SpreadJS 组合框单元格类型提供了 **allowFloat** 属性，用于处理组合框下拉框的位置。当 SpreadJS 组件没有足够空间容纳下拉框或防止下拉框溢出时，该属性有助于管理下拉框的位置和大小。
当 **allowFloat** 属性设置为 `false` 且 SpreadJS 中没有足够空间容纳下拉框时，组合框单元格类型会调整下拉框的大小，以确保其不会溢出 SpreadJS 实例的区域。
然而，如果 **allowFloat** 属性设置为 `true`（默认值），那么打开下拉框时，它会浮动在 SpreadJS 区域上方以显示更多内容，并且当用户滚动 SpreadJS 时，不会影响下拉框的大小和位置。
