# dynamic-column-size

SpreadJS支持动态列大小调整（也称为星形大小调整和比例大小调整）。

### 什么是动态大小调整？

动态列大小调整用于配置列的宽度和行的高度，以使视口完全按照用户指定的加权比例（以\*符号表示）填充。
这种大小调整可以与数字结合使用以定义加权比例，其中：

* 加权因子使用\*（星号）或n \*字符（n可以是任何整数值（例如2 \*，3 \*等）或非整数值（例如0.5 \*或1.5 \*等）表示。 ）。
* 可用大小=视口大小-可见的固定大小。
* 可用大小根据用户定义的加权因子分配到可见行或列。
* 总列宽=视口宽度。

### 使用场景

动态大小调整非常有用，特别是当用户需要按比例扩大多列以便分析报告或处理大型表单。

### 支持的用户操作

动态大小调整（或比例大小调整）确保每当变更视口大小或用户添加，删除或调整任何行或列的大小时，表单中的列和行就完全填充视口。
用户可以使用 **setColumnWidth()** 与 **setRowHeight()** 方法在表单中配置动态列大小。 应用动态列大小后，当用户在worskheet上执行以下操作时，将自动调整列和行的大小（在其上应用星型调整大小）以填充视口：

* 用户变更视图的大小。
* 用户添加，删除或调整表单中的任何列或行的大小。
* 用户变更行数或列数。
* 用户隐藏或取消隐藏行或列。
* 用户对行和列进行分组或取消分组。
* 用户将筛选应用于行和列。
* 用户展开或折叠表单中的大纲列。

导入和导出JSON文件时也支持动态列大小调整。

### 动态大小调整规则

在表单中使用动态大小功能时，必须牢记以下规则：

* 在表单上，行和列都可以设置为星形。
* 当用户尝试调整星号大小的行或列的大小，或调用 **autoFitColumn()** / **autoFitRow()** 方法, 那么操作的行或列的大小将被覆盖为具有实际大小的固定数字。 如果您正在使用拆分调整大小模式（仅适用于nextTo模式），则它将会将操作的行或列以及下一个行或列的大小覆盖为固定数字。
* 如果最小的星形 <1 (小于 1) 或者可用大小 <1 (小于 1), 那么星号将保持旧尺寸，因为它将停止计算动态尺寸。
* 如果用户将星号大小的行或列设置为“隐藏”或“ 0 \*”，方法 **getColumnWidth()** 和 **getRowHeight()** 将返回0。
* 如果用户将星号大小的行或列设置为无效字符串（如“ abc”），它将被视为默认值。
* 用户缩放表单后，固定的行或列将缩放，并且星形调整将拉伸以填充视图。
* 当星形行或列变更时，表单中的任何绑定对象（如形状，图表，注释和浮动对象）也将跟随变更。

### 代码

请参考以下示例代码，以在表单中配置动态列的大小。

```JavaScript
<script>
$(document).ready(function ()
{
// 初始化 Spread
var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });

// 获取表单
var activeSheet = spread.getSheet(0);
activeSheet.suspendPaint();
var colHeader = GC.Spread.Sheets.SheetArea.colHeader;
activeSheet.setRowCount(12);
activeSheet.setColumnCount(5);

// 设置动态列大小
activeSheet.setColumnWidth(0, "1.5*");
activeSheet.setColumnWidth(1, "1.5*");
activeSheet.setColumnWidth(3, "*");
activeSheet.setColumnWidth(4, "*");
//设置行高
activeSheet.setRowHeight(0, 50, colHeader);
for (var row = 0; row < 12; row++)
{
activeSheet.setRowHeight(row, "*");
for (col = 0; col < 5; col++)
{
activeSheet.getCell(row, col)
.cellPadding('0 0 0 10')
.vAlign(GC.Spread.Sheets.VerticalAlign.center);
}
}
activeSheet.setValue(0, 0, 'Company Name', colHeader);
activeSheet.setValue(0, 1, 'City', colHeader);
activeSheet.setValue(0, 2, 'State', colHeader);
activeSheet.setValue(0, 3, 'Phone', colHeader);
```
