# pivot-table-timeline-slicer

时间线切片器是一种交互式筛选器，可让您按日期、月份、年份和季度快速筛选数据。它提供了一个带有控制器的可视化界面，帮助您放大或缩小任何时间段，以便查看和筛选数据透视表中的数据。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pt-timelineslicer-ui.a99416.png)
时间线切片器仅适用于使用标签条件筛选器的数据透视表中的日期字段。可以使用 [Slicers.add](gcdocsite__documentlink?toc-item-id=f870acc3-ca09-41c8-b3af-b02f2899a2a2#add) 类方法将其添加到数据透视表中。将 *PivotTimeline* 设置为切片器类型，并应用 [TimelineLevel ](gcdocsite__documentlink?toc-item-id=7f6b24ac-0b4e-4969-9209-e4e946d1b564)枚举选项，如年份、季度、月份和日期，以指定如何在切片器中筛选数据。
[PivotTableTimelineSlicer ](gcdocsite__documentlink?toc-item-id=6e6c90d3-8344-471b-b301-cd257e5767a9)类提供了各种方法来自定义切片器的用户界面。

## 用例场景

以一家销售食品和饮料产品的食品销售公司为例，该公司希望展示一年中各个季度的产品销售数据。
时间线切片器可以帮助根据时间段分析数据，如下图所示：
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pt-timelineslicer.49f916.gif)

```javascript
// 添加用于按年份、季度、月份筛选的时间线切片器
var timeline_year = sheet.slicers.add("timeline_year", pt.name(), "OrderDate", GC.Spread.Sheets.Slicers.TimelineStyles.dark6(), GC.Spread.Sheets.Slicers.SlicerType.pivotTimeline);
timeline_year.position(new GC.Spread.Sheets.Point(600, 10));
timeline_year.level(GC.Spread.Sheets.Slicers.TimelineLevel.years);
timeline_year.showSelectionLabel(false);
timeline_year.showTimeLevel(false);
timeline_year.showHorizontalScrollbar(false);
timeline_year.height(100);
timeline_year.captionName("年份");

var timeline_quarter = sheet.slicers.add("timeline_quarter", pt.name(), "OrderDate", GC.Spread.Sheets.Slicers.TimelineStyles.dark1(), GC.Spread.Sheets.Slicers.SlicerType.pivotTimeline);
timeline_quarter.position(new GC.Spread.Sheets.Point(600, 130));
timeline_quarter.level(GC.Spread.Sheets.Slicers.TimelineLevel.quarters);
timeline_quarter.captionName("季度");
timeline_quarter.showSelectionLabel(false);

var timeline_month = sheet.slicers.add("timeline_month", pt.name(), "OrderDate", GC.Spread.Sheets.Slicers.TimelineStyles.light4(), GC.Spread.Sheets.Slicers.SlicerType.pivotTimeline);
timeline_month.position(new GC.Spread.Sheets.Point(600, 290));
timeline_month.captionName("月份");
timeline_month.showTimeLevel(false);
```

## 使用设计器选择切片器项目

在 SpreadJS 设计器中，可以执行以下操作来选择数据透视表切片器项目：

* 操作：单击/拖动
* 模式：单选/多选
* 附加按键：Ctrl/Shift/无

| 参数（操作 + 模式 + 按键） | 情况 |
| ---------------- | --- |
| 单击 + 单选 + 无 | 选择单击的项目。 |
| 单击 + 单选 + Ctrl<br>单击 + 多选 + 无<br>单击 + 多选 + Ctrl | 切换单击项目的选择状态。 |
| 单击 + 单选 + Shift | 设置从起始点到单击项目索引的选择范围。范围内的项目保持选中状态，其他项目保持未选中状态。 |
| 单击 + 多选 + Shift<br>拖动 + 多选 + Shift | 设置从起始点到单击项目索引的选择范围，并将选择状态设置为已选中。（不会设置为未选中） |
| 拖动 + 单选 + 无 | 将拖动的项目状态设置为已选中，其他项目设置为未选中。 |
| 拖动 + 单选 + Ctrl<br>拖动 + 多选 + 无<br>拖动 + 多选 + Ctrl | 切换拖动项目的选择状态。 |
| 拖动 + 单选 + Shift | 设置从起始点到拖动结束项目索引的选择范围。<br>范围内的项目将被选中。 |

## 设置自定义时间线切片器样式

SpreadJS 提供了 6 种浅色和 6 种深色的预定义主题，可应用于数据透视表时间线切片器。不过，您可以通过添加、删除和修改切片器样式来管理自定义数据透视表时间线切片器主题，然后将这些主题应用于您的数据透视表切片器。要使用这些样式，您只需为时间线切片器设置一个样式名称即可。要设置时间线切片器样式，请使用 GC.Spread.Sheets.WorkBook 类的 `customTimelineThemes` 属性。
`CustomTimelineThemesManager` 类提供了以下方法来管理自定义时间线切片器主题：

| 方法 | 描述 |
| --- | --- |
| all | 获取所有自定义时间线切片器主题。 |
| get | 按名称获取特定的自定义时间线切片器主题。 |
| add | 使用样式对象或名称添加新的自定义时间线切片器主题。 |
| remove | 按名称删除自定义时间线切片器主题。 |
| update | 按名称或样式对象更新现有的自定义时间线切片器主题。 |

此外，GC.Spread.Sheets.WorkBook 类的 `defaultTimelineTheme` 方法使您能够有效地管理默认时间线切片器样式，以确保所有时间线切片器的外观和感觉一致。

> 注意：
>
> * 时间线切片器主题名称必须唯一。
>     例如，如果您已经有一个名为“TEST”的自定义时间线切片器样式，则不能再创建另一个同名的时间线切片器样式。
> * 时间线切片器样式名称不区分大小写。
> * 当将样式名称添加到时间线切片器时，它会按名称查找样式。如果样式名称与内部样式匹配，将直接应用该样式。如果不匹配，它将在自定义样式集合中搜索相应的样式。如果找到，则应用该样式。否则，将使用默认样式。
> * `defaultTimelineTheme` 应该是一个表示时间线切片器样式名称的字符串。如果创建切片器时未显式指定样式，并且存在具有此默认名称的样式，则该样式将应用于该切片器。
> * 自定义时间线切片器主题不支持旧版本的 Excel IO。

以下代码示例演示了管理自定义时间线切片器主题所需的不同方法。

1. 添加新的自定义时间线切片器主题。

    ```javascript
    const spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
    
    // 添加一个名为“custom0”的新时间线切片器主题。
    const slicerTheme = spread.customTimelineThemes.add("custom0");
    const styleInfo = new GC.Spread.Sheets.Slicers.SlicerStyleInfo();
    styleInfo.backColor("orange");
    styleInfo.borderBottom(new GC.Spread.Sheets.Slicers.SlicerBorder(2,"solid","green"));
    slicerStyle.wholeSlicerStyle(styleInfo);
    ```
2. 获取自定义时间线切片器主题。

    ```javascript
    spread.customTimelineThemes.get("custom0");
    ```
3. 应用自定义时间线切片器主题。

    ```javascript
    timeline.style("custom0");
    ```
4. 修改自定义时间线切片器主题。
    当您对现有时间线切片器样式进行更改时，它将自动更新所有先前应用了该样式的切片器。

    ```javascript
    // 修改时间线切片器主题。
    const slicerStyle = spread.customTimelineThemes.get("custom0");
    slicerStyle.wholeSlicerStyle().backColor("red");
    
    // 更新时间线切片器主题。
    spread.customTimelineThemes.update("custom0", new GC.Spread.Sheets.Slicers.TimelineStyle());
    ```
5. 删除现有的自定义时间线切片器主题。
    当您删除自定义时间线切片器样式时，所有使用了已删除样式的切片器将切换为默认样式。

    ```javascript
    // 删除时间线切片器主题。
    spread.customTimelineThemes.remove("custom0");
    ```
6. 设置默认时间线切片器主题。

    ```javascript
    // 设置默认时间线切片器主题。
    spread.defaultTimelineTheme("custom0");
    ```

您还可以按照以下步骤使用 SpreadJS 设计器组件添加和设置时间线切片器样式的格式：

1. 单击添加的时间线切片器，打开 **时间线** 选项卡以配置时间线设置。
2. 单击 **时间线样式** 组中的 **样式** 按钮。
    ![Timeline Style.f56de9](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/Timeline%20Style.f56de9.f4ae61.png)
3. 选择 **新建切片器样式...** 选项，这将打开 **新建切片器样式** 对话框。
    ![New TimelineStyle.7fc217](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/New%20TimelineStyle.7fc217.601929.png)
4. 在 **名称** 文本字段中输入新的样式名称，从 **切片器元素** 部分中选择要应用样式的元素，然后单击 **设置格式** 为自定义时间线切片器主题配置所需的样式。
    ![New Timeline Style Dialog.154830](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/New%20Timeline%20Style%20Dialog.154830.4a2a25.png)
5. 所有用户创建的时间线切片器样式都显示在切片器样式集合列表的 **自定义** 部分下。
    ![customTimelineStyle](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/customTimelineStyle.e31f58.a1d291.png)
6. 右键单击自定义时间线切片器样式，然后根据您的需求执行诸如应用、修改、复制、删除和设置为默认等操作。
    ![customTimelineStyle_properties](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/customTimelineStyle_properties.c978df.193f22.png)

> **注意**：您不能修改或删除内置的数据透视表时间线切片器样式。
