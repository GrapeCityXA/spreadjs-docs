# pivot-table-item-slicer

SpreadJS 提供了**数据透视表项目切片器**，只需单击一下即可对数据透视表进行筛选。您可以通过使用切片器连接多个数据透视表来筛选聚合目标。它可以使用手动筛选器对数据透视表的数据进行筛选。它提供了一个用户友好的界面，使您能够高效地管理数据透视表中行字段和列字段的筛选状态。
[PivotTableItemSlicer](gcdocsite__documentlink?toc-item-id=83fd499b-7921-4813-abe3-b430a92691d9) 类提供了各种与切片器相关的方法，以便使用数据透视表切片器。
![slicer_filter_pivottable](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/slicer_filter_pivottable.c839b3.gif)
以下代码示例展示了如何使用 [SlicerCollection.add](gcdocsite__documentlink?toc-item-id=f870acc3-ca09-41c8-b3af-b02f2899a2a2#add) 方法添加数据透视表切片器。切片器类型（SlicerType）应设置为 `pivotTable`。

```javascript
$(document).ready(function () {
    // 初始化 Spread
    spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 2 });
    spread.options.allowDynamicArray = true;
    spread.suspendPaint();
    // 获取工作表
    pivotLayoutSheet = spread.getSheet(0);
    dataSourceSheet = spread.getSheet(1);

    // 隐藏网格线
    pivotLayoutSheet.options.gridline = { showVerticalGridline: false, showHorizontalGridline: false };

    // 设置工作表名称
    pivotLayoutSheet.name("PivotLayout");
    dataSourceSheet.name("DataSource");
    // 设置行数
    dataSourceSheet.setRowCount(245);
    // 设置数据源
    dataSourceSheet.setArray(0, 0, pivotDB_UseCase);
    // 向 dataSourceSheet 添加表格
    dataSourceSheet.tables.add('tableSales', 0, 0, 245, 8);

    // 初始化数据透视表
    var pt = initPivotTable(pivotLayoutSheet);
    pivotLayoutSheet.setColumnCount(200);
    initSlicer(pivotLayoutSheet, pt);

    // 自动调整两个工作表的列宽
    autoFit(pivotLayoutSheet);
    autoFit(dataSourceSheet);
    spread.resumePaint();
});

function initPivotTable(sheet) {
    myPivotTable = sheet.pivotTables.add("pivotTable", "tableSales", 1, 1, GC.Spread.Pivot.PivotTableLayoutType.outline, GC.Spread.Pivot.PivotTableThemes.dark3);
    myPivotTable.suspendLayout();
    myPivotTable.add("City", "City", GC.Spread.Pivot.PivotTableFieldType.rowField);
    myPivotTable.add("Category", "Category", GC.Spread.Pivot.PivotTableFieldType.rowField);

    myPivotTable.add("OrderDate", "OrderDate", GC.Spread.Pivot.PivotTableFieldType.columnField);
    let groupInfo = {
        originFieldName: "OrderDate",
        dateGroups: [
            {
                by: GC.Pivot.DateGroupType.quarters
            }
        ]
    };
    myPivotTable.group(groupInfo);
    myPivotTable.add("TotalPrice", "TotalPrice", GC.Spread.Pivot.PivotTableFieldType.valueField, GC.Pivot.SubtotalType.sum);
    formatValueField(myPivotTable);
    myPivotTable.resumeLayout();
    myPivotTable.autoFitColumn();
    return myPivotTable;
}

function initSlicer(sheet, pt) {
    slicer_City = sheet.slicers.add("slicer_City", pt.name(), "City", GC.Spread.Sheets.Slicers.SlicerStyles.light4(), GC.Spread.Sheets.Slicers.SlicerType.pivotTable);
    slicer_City.position(new GC.Spread.Sheets.Point(1020, 10));
    slicer_Category = sheet.slicers.add("slicer_Category", pt.name(), "Category", GC.Spread.Sheets.Slicers.SlicerStyles.light1(), GC.Spread.Sheets.Slicers.SlicerType.pivotTable)
    slicer_Category.position(new GC.Spread.Sheets.Point(1220, 10));
    slicer_Date = sheet.slicers.add("slicer_Date", pt.name(), "OrderDate", GC.Spread.Sheets.Slicers.SlicerStyles.other2(), GC.Spread.Sheets.Slicers.SlicerType.pivotTable);
    slicer_Date.position(new GC.Spread.Sheets.Point(1020, 280));
}
```

## 对切片器中的项目进行排序

您可以在筛选的同时对数据透视表切片器中的项目进行排序。切片器设置对话框中有以下选项：

1. **源名称**：指定切片器的名称。
2. **标题**：
    * 显示标题复选框：如果您希望在标题上显示切片器的名称，请勾选此复选框。
    * 标题：您希望在标题上显示的切片器名称。
3. **排序状态**：指升序/降序的选中状态。
4. **无数据项目显示**：指以下选项：
    * **隐藏无数据的项目**：如果为真，则在切片器中不显示无数据的项目。
    * **将无数据的项目显示在最后**：如果为真，则将无数据的项目显示在最后。如果为假，则根据排序状态对项目进行排序。
        例如，像 <1/1/2013 5:30:00 和 >12/30/2014 5:30:00 这样的订单日期会根据排序状态进行排序。
        ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/nodataitemsinlast.2efca6.png)
    * **直观显示无数据的项目**：如果为真，则将无数据的项目显示为灰色。如果为假，则无数据的项目将与有数据的项目以相同方式显示。
        例如：当像 <1/1/2013 5:30:00 和 >12/30/2014 5:30:00 这样的订单日期不包含任何数据时，它们仍会显示在列表中。
        ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/visuallynodataitems.75b790.png)

默认的排序值是“隐藏无数据的项目”和“将无数据的项目显示在最后”。切片器项目分为两部分，每部分都按升序或降序进行排序。
以下代码示例定义了不同的排序或筛选函数。

```javascript
function setMultiSelectFalseForSlicerCity() {
    // 将多选设置为真
    slicer_City.multiSelect(true);
}
function setSortStateForSlicerCity() {
    // 将排序状态设置为降序
    slicer_City.sortState(GC.Spread.Sheets.SortState.descending);
}

function showNoDataItem() {
    myPivotTable.updateSource();
    // 要检查此操作，请删除城市“泽西”（或数据源中的任何一个城市，然后单击此按钮 - 单击此按钮时，数据透视表将首先更新）
    slicer_City.showNoDataItems(false);
}

function visuallyNoDataItems() {
    myPivotTable.updateSource();
    slicer_Date.visuallyNoDataItems(false);
}
function showNoDataItemsInLast() {
    slicer_Date.showNoDataItemsInLast(false);
}
```

## 切片器与数据透视表的连接

您可以使用 [PivotTableItemSlicer.connectPivotTable](gcdocsite__documentlink?toc-item-id=83fd499b-7921-4813-abe3-b430a92691d9#connectPivotTable) 方法在切片器和数据透视表之间建立连接。连接由双方控制，因为切片器和数据透视表都可以相互连接或断开连接。如果切片器与数据透视表断开连接，其筛选操作将不会影响数据透视表，反之亦然。
以下代码示例展示了如何断开连接。

```javascript
function disconnectSlicerWithPivotTable() {
    // slicer_Date 与数据透视表断开连接。
    slicer_Date.disconnectPivotTable(myPivotTable.name());
    slicer_Date.captionName("已断开连接");
}
```

## 自定义项目切片器样式

SpreadJS 提供了 8 种浅色和 6 种深色的预定义主题，可应用于数据透视表切片器。不过，您可以通过添加、删除和修改切片器样式来管理自定义切片器主题，这些自定义样式也可以应用于您的数据透视表切片器。您只需为切片器设置一个样式名称即可使用这些自定义样式。要设置切片器样式，请使用 [GC.Spread.Sheets.WorkBook](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0) 类的 `customSlicerThemes` 属性。
`CustomSlicerThemesManager` 类提供了以下方法来管理自定义项目切片器主题。

| 方法 | 描述 |
| --- | --- |
| all | 获取所有自定义切片器主题。 |
| get | 按名称获取特定的自定义切片器主题。 |
| add | 使用样式对象或名称添加新的自定义切片器主题。 |
| remove | 按名称删除自定义切片器主题。 |
| update | 按名称或样式对象更新现有的自定义切片器主题。 |

此外，GC.Spread.Sheets.WorkBook 类的 `defaultSlicerTheme` 方法使您能够有效地管理默认切片器样式，以确保所有项目切片器的外观和感觉一致。

> 注意：
>
> * 切片器主题名称必须唯一。
>     例如，如果您已经有一个名为“TEST”的自定义项目切片器样式，则不能再创建另一个同名的项目切片器样式。
> * 切片器样式名称不区分大小写。
> * 当将样式名称添加到切片器时，它会按名称查找样式。如果样式名称与内部样式匹配，将直接应用该样式。如果不匹配，它将在自定义样式集合中搜索相应的样式。如果找到，则应用该样式。否则，将使用默认样式。
> * `defaultSlicerTheme` 应该是一个表示切片器样式名称的字符串。如果创建切片器时未显式指定样式，并且存在具有此默认名称的样式，则该样式将应用于该切片器。
> * 自定义切片器主题不支持旧版本的 Excel IO。

以下代码示例演示了管理自定义切片器主题所需的不同方法。

1. 添加新的自定义切片器主题。

    ```javascript
    const spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
    
    // 添加一个名为“custom0”的新切片器主题。
    const slicerStyle = spread.customSlicerThemes.add("custom0");
    const styleInfo = new GC.Spread.Sheets.Slicers.SlicerStyleInfo();
    styleInfo.backColor("orange");
    styleInfo.borderBottom(new GC.Spread.Sheets.Slicers.SlicerBorder(2,"solid","green"));
    slicerStyle.wholeSlicerStyle(styleInfo);
    ```
2. 获取自定义切片器主题。

    ```javascript
    const slicerTheme = spread.customSlicerThemes.get("custom0");
    ```
3. 应用自定义切片器主题。

    ```javascript
    slicer.style("custom0");
    ```
4. 修改自定义切片器主题。
    当您对现有切片器样式进行更改时，它将自动更新所有先前应用了该样式的切片器。

    ```javascript
    // 修改自定义切片器主题。
    const slicerStyle = spread.customSlicerThemes.get("custom0");
    slicerStyle.wholeSlicerStyle().backColor("red");
    
    // 更新自定义切片器主题。
    spread.customSlicerThemes.update("custom0", new GC.Spread.Sheets.Slicers.SlicerStyle());
    ```
5. 删除现有的自定义切片器主题。
    当您删除自定义切片器样式时，所有使用了已删除样式的切片器将切换为默认样式。

    ```javascript
    // 删除自定义切片器主题。
    spread.customSlicerThemes.remove("custom0");
    ```
