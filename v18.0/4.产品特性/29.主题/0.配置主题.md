# themes

你可以为单元格、列、行或该组件指定主题。
对于单元格、行或列，你可以使用 [themeFont ](gcdocsite__documentlink?toc-item-id=64f05fd4-fafa-47dc-9856-b74263f357ec#themeFont)方法。对于工作表，你可以使用 [currentTheme ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#currentTheme)方法。
以下主题名称可与 **currentTheme** 方法配合使用：

| @cols=3:**主题** |
| --- | --- | --- |
| Default | Office | Apex |
| Aspect | Concourse | Civic |
| Oriel | Origin | Paper |
| Solstice | Technic | Trek |
| Urban | Verve | Equity |
| Flow | Foundry | Median |
| Metro | Module | Opulent |

以下图片展示了你可以为主题颜色设置的强调色。

以下代码示例使用 **currentTheme** 方法设置主题。

```JavaScript
activeSheet.currentTheme("Metro");
```
