# sceventclipboard

你可以使用四种类型的剪贴板事件，例如 [ClipboardChanged](gcdocsite__documentlink?toc-item-id=8579217b-549b-41f7-aa4f-f0e21c37872e#ClipboardChanged)、[ClipboardChanging](gcdocsite__documentlink?toc-item-id=8579217b-549b-41f7-aa4f-f0e21c37872e#ClipboardChanging)、[ClipboardPasted ](gcdocsite__documentlink?toc-item-id=8579217b-549b-41f7-aa4f-f0e21c37872e#ClipboardPasted)和 [ClipboardPasting ](gcdocsite__documentlink?toc-item-id=8579217b-549b-41f7-aa4f-f0e21c37872e#ClipboardPasting)事件。`ClipboardChanged` 事件在剪贴板内容发生改变后触发，而 `ClipboardChanging` 事件在剪贴板内容正在改变时触发。同样，`ClipboardPasted` 事件在用户从剪贴板粘贴内容后触发，`ClipboardPasting` 事件在用户正在进行粘贴操作时触发。借助这些剪贴板事件，用户可以在 Excel 和 Spread 工作表之间、工作表内部以及工作表之间对文本、单元格数据、图片、图表、形状、切片器和自定义浮动对象执行复制粘贴操作。
在执行剪贴板复制粘贴操作时，你还可以获取源工作表和范围信息等值，以及是否正在执行剪切操作。
目前，不支持从 SpreadJS 向 Excel 执行剪切或复制操作。
以下代码示例展示了如何使用不同的剪贴板事件。

```JavaScript
$(document).ready(function () {
    // 初始化 Spread
    var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });
    // 获取活动工作表
    var activeSheet = spread.getActiveSheet();
    // 将 allowCopyPasteExcelStyle 设置为 true
    spread.options.allowCopyPasteExcelStyle = true;
    // 绑定剪贴板事件
    activeSheet.bind(GC.Spread.Sheets.Events.ClipboardChanged, function (sender, args) {
        console.log('剪贴板内容已改变。');
    });
    activeSheet.bind(GC.Spread.Sheets.Events.ClipboardChanging, function (sender, args) {
        console.log('剪贴板内容正在改变');
    });
    activeSheet.bind(GC.Spread.Sheets.Events.ClipboardPasted, function (sender, args) {
        console.log('已从剪贴板粘贴内容');
    });
    activeSheet.bind(GC.Spread.Sheets.Events.ClipboardPasting, function (sender, args) {
        console.log('正在从剪贴板粘贴内容');
    });
});
```

## 从 Excel 复制粘贴到 SpreadJS

假设你在 Excel 中有多个对象，如图像、图表和形状，并且你想将除图像之外的所有对象复制并粘贴到 SpreadJS 中。为此，需要将 `ClipboardPasting` 事件中的 `cancel` 参数设置为 `true`。
请注意，要将图像、图表和形状等对象从 Excel 复制粘贴到 Spread 工作表，你需要将 `allowCopyPasteExcelStyle` 属性设置为 `true`。要了解更多关于将 Excel 对象复制到 Spread 的信息，请参考此 [主题](gcdocsite__documentlink?toc-item-id=1737b42e-14a2-4daf-90e9-90a7278951e3)。
以下代码示例展示了如何防止将图像从 Excel 复制到 Spread。

```JavaScript
$(document).ready(function () {
    // 初始化 Spread
    var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });
    // 获取活动工作表
    var activeSheet = spread.getActiveSheet();
    // 将 allowCopyPasteExcelStyle 设置为 true
    spread.options.allowCopyPasteExcelStyle = true;
    // 添加图片
    activeSheet.pictures.add('f2', 'Capture.PNG', 100, 60, 200, 100);
    // 此代码防止将图像从 Excel 复制到 SpreadJS
    spread.bind(GC.Spread.Sheets.Events.ClipboardPasting, (e, args) => {
        if (args.pasteData && args.pasteData.image) {
            args.cancel = true;
        }
    });
});
```

## 在 SpreadJS 工作表内复制粘贴

假设你在 SpreadJS 中有多个对象，如图像、图表和形状，并且你想从 SpreadJS 中的特定工作表复制并粘贴除图像之外的所有浮动对象。剪贴板事件中的 `objects` 参数可用于复制粘贴文本、单元格数据、图片、自定义浮动对象、切片器、图表和形状。
以下代码示例展示了如何通过将 `cancel` 参数设置为 `true` 来防止从特定工作表复制图像（使用 `fromSheet` 参数），并警告用户防止意外的剪切操作（使用枚举 **GC.Spread.Sheet.ClipboardActionType**，它表示当前操作的类型）。

```JavaScript
// 配置工作簿和工作表
var spread = new GC.Spread.Sheets.Workbook('ss', { sheetCount: 2 });
var activeSheet = spread.getActiveSheet();
// 将 allowCopyPasteExcelStyle 设置为 true
spread.options.allowCopyPasteExcelStyle = true;
// 添加图片
// activeSheet.pictures.add("f2", "Capture.PNG", 100, 60, 200, 100);
ss.getSheet(0).pictures.add('f5', 'https://cdn.pixabay.com/photo/2015/10/01/17/17/car-967387__480.png', 2, 2, 200, 200);
spread.bind(GC.Spread.Sheets.Events.ClipboardPasting, (e, args) => {
    // 此代码防止内部浮动元素的复制粘贴
    if (args.objects && args.objects.length > 0 && args.fromSheet.name() == 'Sheet1') {
        args.cancel = true;
    }
    // 此代码防止意外的剪切操作
    else if (args.action == GC.Spread.Sheets.ClipboardActionType.cut) {
        if (confirm('你正在执行剪切操作。\n要继续吗？') == true) {
            text = '你点击了确定！';
        } else {
            text = '你取消了！';
            args.cancel = true;
        }
    }
});
```
