# ImplementCopyPasteUsingCode

### 需求：如何自定义实现复制粘贴按钮

#### 背景：

在designer中，用户选中区域，点击 toolbar 中的复制按钮，即可进行复制。用户想在SpreadJS中自定义类似的复制粘贴按钮。

#### 实现方式：

可以借助[commandManager](https://demo.grapecity.com.cn/spreadjs/help/api/classes/GC.Spread.Commands.CommandManager#class-commandmanager)方法来实现，主要代码如下：

```javascript
document.getElementById('copy').addEventListener('click', function () {
    var sheet = spread.getActiveSheet();
    spread.commandManager().execute({ cmd: "copy", sheetName: sheet.name() });
})
document.getElementById('paste').addEventListener('click', function () {
    var sheet = spread.getActiveSheet();
    spread.commandManager().execute({ cmd: "paste", sheetName: sheet.name() });
})
```
