### 问题：如何通过按钮快速切换表单？

***

#### 背景：

当用户的表单过多时，一个个按下表单名称切换会比较麻烦。这时候希望通过按钮实现返回首页，最后一页以及通过页索引和页名称进行切换。

#### 解决方案：

切换表单的相关API有：[setActiveSheetIndex](https://demo.grapecity.com.cn/spreadjs/help/api/classes/GC.Spread.Sheets.Workbook#setactivesheetindex)、[setActiveSheet](https://demo.grapecity.com.cn/spreadjs/help/api/classes/GC.Spread.Sheets.Workbook#setactivesheet)、[startSheetIndex](https://demo.grapecity.com.cn/spreadjs/help/api/classes/GC.Spread.Sheets.Search.SearchCondition#startsheetindex)。前两个用于切换活跃表单，后一个接口用于将某表单设为首张展示的表单。

#### 设置首页

```
spread.setActiveSheetIndex(0);
                spread.startSheetIndex(0)
```

#### 设置末页

```
var index = spread.getSheetCount();
                spread.setActiveSheetIndex(index-1);
                spread.startSheetIndex(index-1)
```

#### 根据表单索引切换表单

```
var index = _getElementById('activeSheetIndex').value;
                if (!isNaN(index)) {
                        index = parseInt(index);
                        if (0 <= index && index < spread.getSheetCount()) {
                                spread.setActiveSheetIndex(index);
                                spread.startSheetIndex(index);
                        }
                }
```

#### 根据表单名称切换表单

```
 var 　name = _getElementById('activeSheet').value;
                console.log(name)
                spread.setActiveSheet(name);
                var index1 = spread.getActiveSheetIndex();
                spread.startSheetIndex(index1);
```
