# quick-drag-column

### 问题：如何通过拖拽快速移动列的位置？

***

#### 背景

在SpreadJS中，可以通过shift+拖动整列的方式来快速移动列，这个方式和Excel是保持一致的。
但是按住shift的操作并不是所有用户都了解，所以本文介绍通过直接拖拽的方式来快速移动列 。

#### 解决方案

在SpreadJS中用户的UI行为都是响应浏览器事件后调用spreadjs内置的command。拖拽调用的是GC.Spread.Sheets.Commands.dragDrop命令。
所以直接修改dragDrop即可。

```
var oldDragDropExcecte = GC.Spread.Sheets.Commands.dragDrop.execute;
GC.Spread.Sheets.Commands.dragDrop.execute = function (context, option, isUndo) {
    if (option.fromRow === -1 || option.fromColumn === -1) {
        option.insert = true;
    }
    oldDragDropExcecte.call(this, context, option, isUndo);
}



var sheet = spread.getActiveSheet();

sheet.setValue(0, 0, 0);
sheet.setValue(0, 1, 1);
sheet.setValue(0, 2, 2);
sheet.setValue(0, 3, 3);
```

在上面代码中，首先判断fromRow或者fromColumn为-1，代表整列或者整行的操作。将insert直接设置为true，改变一切拖动覆盖的行为。
执行上面的代码后，可以直接移动列，而不是替换列，参考下面的动图。
