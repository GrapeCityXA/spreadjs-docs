# how-to-set-watermark-background-in-workbook

### 问题：怎么在SpreadJS中平铺显示水印

***

#### 背景

用户想在显示表格时添加水印效果，以达到版权保护等用途，

#### 解决方案

SpreadJS 中提供添加背景图的功能，但是暂时无法通过API设置背景图布局方式为平铺。

解决思路： 在表单初始化后，通过代码获取表单Canvas的Dom节点，用JavaScript 代码修改其CSS样式。

关键代码：

```js
var html = document.getElementById("ssvp_vp"); //通过ID获取对象
html.style.backgroundRepeat="repeat"
```
