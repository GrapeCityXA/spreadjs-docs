# only-select

### 背景：下拉框如何只能选择不能输入

***

对于下拉框列表，有时需要实现只能选择不能输入的需求，应该如何实现呢？

### 实现思路

可以使用 `EditStarting` 事件来实现，具体代码如下：

```javascript
sheet.bind(GC.Spread.Sheets.Events.EditStarting, function (sender, args) {
  var r = args.row;
  var c = args.col;
  //判断如果单元格内有cellButtons
  if (sheet.getCell(r, c).cellButtons()) {
    args.cancel = true;
  }
});
```

在事件中判断该单元格是否包含 cellButtons，如果包含的话就无法进入编辑状态。
