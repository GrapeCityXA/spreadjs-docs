# show-formula-cell-type

### 问题：如何在SpreadJS中实现指定单元格显示公式

***

#### 背景：

有些用户想要实现让一个设置了公式的单元格仅显示公式，而不用显示计算结果。熟悉产品的小伙伴很容易想到，可以使用"显示公式"功能。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.f0ae02.png)
但这个设置是对整个sheet中的公式生效的，如果想指定某个单元格显示公式，该如何实现呢？

#### 解决方案：

对于这样的需求，可以使用自定义单元格来实现，只需要重写paint方法即可，让单元格在绘制的时候绘制公式而不是绘制值。
核心代码为：

```javascript
ShowFormula.prototype.paint = function (
  ctx,
  value,
  x,
  y,
  w,
  h,
  style,
  context
) {
  let formular = sheet2.getFormula(context.row, context.col);
  console.log(context);
  if (value) {
    spreadNS.CellTypes.Base.prototype.paint.apply(this, [
      ctx,
      formular,
      x,
      y,
      w,
      h,
      style,
      context,
    ]);
  }
};
```
