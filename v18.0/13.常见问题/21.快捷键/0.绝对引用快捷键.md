# Absolute-Reference-Keyboard-Shortcuts

### 需求：设置F4快捷键将相对引用变为绝对引用

***

#### 背景：

SpreadJS 中默认的公式引用是相对引用，要将其变为绝对引用，手动添加$符号例如：$A$1 比较麻烦，可以设置快捷键来实现这个效果。

#### 思路：

SpreadJS　提供了一个内置命令：changeFormulaReference, 使用该命令可以快速实现该功能, SpreadJS中的命令管理器有绑定快捷键的方法:setShortcutKey
关键代码:

```javascript
spread
  .commandManager()
  .setShortcutKey("changeFormulaReference", 115, false, false, false, false);
```

#### 实现效果:

选择公式编辑器中引用的单元格,按下F4,可以将其变为绝对引用,再次按下切换不同的状态:
