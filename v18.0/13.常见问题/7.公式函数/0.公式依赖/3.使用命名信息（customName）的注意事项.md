# custom-name-caution

### 问题：使用命名信息（customName）的注意事项

***

背景：用户在添加custom name后，发现导出Excel，会提示错误。检查后往往是不符合Excel中的custom name的命名规范。那么本文将总结下使用custom name的一些规范。

1、在Excel中，一旦定义了自定义名称，在公式中需要加入相应的sheet名，否则就会抛出一个异常，在SpreadJS中没有这样的限制。
所以，在SpreadJS中，用户想导出Excel时需要检查公式。
原始:

```
sheet.addCustomName("customName1", "=$B$3", 0, 0, "this is a customName!");
```

修改后：

```
sheet.addCustomName("customName1", "=Sheet1!$B$3", 0, 0, "this is a customName!");
```

2、此外，在Excel中命名，需要注意以下几点：

1. 以字母或\_开头
2. 不能包括空格等特殊字符
3. 同一个workbook中不能有相同的名字
