# listen-formula-cell-change

### 问题：如何监听由公式引起的单元格变化？

***

背景：用户在工作簿中设置了大量的公式，希望当修改其中一个公式时，能够获取到引用该公式的单元格。比如 B1 的公式为 \`=A1\`，在修改 A1 时，如何才能够监听到 B1 的值变化？
对于这样的需求，在SpreadJS中可以用[公式追踪](https://demo.grapecity.com.cn/spreadjs/help/api/classes/GC.Spread.Sheets.Worksheet#getdependents)实现：
如下代码：

```
sheet.bind(GC.Spread.Sheets.Events.EditEnded, function (e, info) {
    const row = info.row, col = info.col;
    if (row == 0 && col == 0) {
        let dependents = sheet.getDependents(row, col);
        for (let i = 0; i < dependents.length; i++) {
            let {row: _row, col: _col} = dependents[i]
            let value = sheet.getValue(_row, _col)
            console.log(value)
        }
    }
});
```

在上面的代码中监听EditEnded事件，当判断到A1单元格发生变化时，获取A1单元格的从属单元格的位置。然后去遍历，获取到每一个从属单元格的位置后，通过sheet.getValue()获取值。
