# add-theme-template

### 需求：如何自定义主题并实现复用

***

#### 背景：

在在线表格编辑器中，我们可以在设计模块中通过选定现有的透视表主题样式，快速地应用透视表主题样式。那么如何否提前设计好对应的主题样式模板并且可以存起来然后应用到不同的透视表呢？
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.c6f13b.png)
实际上，我们只要借助透视表主题的序列化方法即可实现

#### 解决办法：

1\. 借助toJSON\(\)序列化自定义的主题样式

```js
var theme = pivot1.theme().toJSON()
```

查看序列化对象的内容：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.892065.png?width=1000)

上图中序列化的主题对象是通过编辑器的新建数据透视表样式来实现的。也就是说想要创建或者设计一个模板，我们可以基于一个透视表，去设计一个模板，然后再应用到透视表上，最后再通过toJSON进行序列化。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.ba0a29.png)

2\. 存储序列化后的主题样式，你可以将此序列化后的json存储到服务端

3\. 将存储的主题样式应用到新的透视表上
我们先创建一个透视表主题实例，然后根据主题对象的属性进行设置即可。
主题样式中一共有5个属性，分别是firstColumnStyle、headerRowStyle、subtotalColumn1Style、wholeTableStyle。除了name外，这里面传的就是PivotTableStyle样式实例。也即是把上面获取到的theme一个一个设置到t1这个透视表主题中。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.b45a66.png)

4\. 将新的主题应用到新的透视表中

```js
pivot.theme(t1)
```

最后实现的效果就是把右侧的透视表样式，应用到了左侧
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.695daa.png)
