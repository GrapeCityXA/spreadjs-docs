# select-image-and-insert

### 问题：如何在SpreadJS'中实现选择图片并插入功能

***

#### 背景：组件版设计器工具栏提供了插入图片功能，用户希望在SpreadJS中实现类似效果

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.d0dd79.png)

#### 实现方法：

代码方面也较为简单，核心代码如下。要想实现根据我们选择的单元格位置插入图片，需要获取当前活跃单元格的横纵坐标与行高列宽。读取文件后将其转为base64的形式。最后通过add方法将图片插入到指定的单元格。

```javascript
startRow = sheet.getActiveRowIndex();
startCol = sheet.getActiveColumnIndex();
rowHeight = sheet.getRowHeight();
colWidth = sheet.getColumnWidth();
file = document.getElementById("fileDemo").files[0];

reader = new FileReader();
reader.readAsDataURL(file); /*当读取操作成功完成时调用*/ //异步读取文件内容，结果用data:url的字符串形式表示

reader.onload = function (e) {
  timestamp = Date.parse(new Date());
  picture = sheet.pictures.add(
    timestamp.toString(),
    this.result,
    startCol * colWidth,
    startRow * rowHeight
  );
};
```
