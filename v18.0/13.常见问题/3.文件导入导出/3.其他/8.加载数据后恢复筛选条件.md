# restore-filter-conditions-after-loading-data

### 需求：希望Filter保存筛选状态，再次加载表单数据时恢复筛选条件

***

#### 背景：

在表格加载的数据中，用户做了一些筛选的操作，并希望再次加载时还能保留这些加载项。
而我们一般不会把用户的每次操作的完整文档都执行保存，那么能否仅保留筛选状态呢？

#### 解决方案：

我们可以通过以下代码来获取到当前sheet表单的filter：

```js
var filter = sheet.rowFilter()
```

然后我们可以发现，这个filter实际上是有一个toJSON方法的，如API所示：[https://demo.grapecity.com.cn/spreadjs/help/api/classes/GC.Spread.Sheets.Filter.RowFilterBase#tojson](https://demo.grapecity.com.cn/spreadjs/help/api/classes/GC.Spread.Sheets.Filter.RowFilterBase#tojson)
通过调用这个toJSON方法，可以序列化出来一个json对象，对象结构如下：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.a809ba.png)
可以看到，包括筛选区域、筛选按钮是否可见、筛选列标、被筛选掉的行等信息都有(途中我没有完全展开它），
实际上这个对象就包含了所有与筛选器相关的属性，而且与sheet无关联。
我们只要把它保存起来，当再次加载数据，需要再次把它投射到指定区域然后执行筛选时，只需要调用：

```js
sheet.rowFilter().fromJSON(json);
```

需要注意的是，fromJSON后filter只是拿到了筛选状态，
还没有执行出最终结果集，所以需要再调用一下filter的filter()方法，如下：

```js
sheet.rowFilter().filter();
```

之后刷新sheet，即可重新载入筛选设置。

```js
sheet.repaint()
```
