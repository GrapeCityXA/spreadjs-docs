# import-export-csv-files

### 问题:如何导入导出CSV文件

***

#### 解决方案：

我们对于CSV有两个接口提供，一个是getCsv，另一个是setCsv，下面是api，我们的导入导出就是围绕这两个api来实现。
[https://demo.grapecity.com.cn/spreadjs/help/api/classes/GC.Spread.Sheets.Worksheet#getcsv](https://demo.grapecity.com.cn/spreadjs/help/api/classes/GC.Spread.Sheets.Worksheet#getcsv)
[https://demo.grapecity.com.cn/spreadjs/help/api/classes/GC.Spread.Sheets.Worksheet#setcsv](https://demo.grapecity.com.cn/spreadjs/help/api/classes/GC.Spread.Sheets.Worksheet#setcsv)
导入CSV，我们就使用set方法，代码层面，主要思路就是读取文件操作，然后文件转成fileString，最后通过setCsv设置。CSV接口的传参可以到上面api中了解，传参也可以通过input获取。

```js
function csvChange() {
    var ssjsonFile = document.getElementById("fileDemoCsv").files[0];
    //获取到文件列表
    var files = $('#fileDemoCsv').prop('files');
    //新建一个FileReader
    var reader = new FileReader();
    //读取文件
    reader.readAsText(files[0], "UTF-8");
    //读取成功触发onload事件
    reader.onload = function (evt) {
        var fileString = evt.target.result;
        sheet.setCsv(0, 0, fileString, "\r\n", ",");
    };
    // 读取失败触发onerror
    reader.onerror = function (e) {
        console.log(e);
    };
}
```

导出CSV，我们只需使用getCsv获取到csv，在调用导出文件的方法即可。

```js
var testJson = spread.getSheet(0).getCsv(0, 0, spread.getSheet(0).getRowCount(), spread.getSheet(0).getColumnCount(), "\r\n", ",");
```
