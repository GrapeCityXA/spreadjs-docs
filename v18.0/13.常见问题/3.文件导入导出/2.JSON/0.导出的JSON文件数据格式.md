# ssjson-format

### 问题：我想知道SpreadJS导出的JSON数据格式是什么样

***

公开模式描述了SpreadJS JSON 数据格式，使 SpreadJS JSON 数据清晰易读，对人类和机器可读的文档有用，并提供完整的结构验证，这对于使用代码生成 SpreadJS JSON 数据非常有用， 自动测试和 JSON 数据验证。
参考以下 JSON Schema

* [v15](https://cdn.grapecity.com.cn/spreadjs/online/spreadjs-json-schema.json)
* [v16](https://cdn.grapecity.com.cn/spreadjs/online/spreadjs-json-schema-v16.json)
