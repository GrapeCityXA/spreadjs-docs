# CheckingCheckboxesBasedOnBoundData

### 问题：如何实现根据绑定的数据自动勾选 CheckBox

***

#### 背景

在表格中使用了 CheckBox，想通过数据绑定的结果给 CheckBox 设置选中状态，就可以用本文的方法。

#### 实现思路

通过表格绑定，你可以在表格的列中绑定名称，数据字段，格式，单元格类型和转换函数。本次，我们用的就是转换函数。
我们先看下 [TableColumn API](gcdocsite__documentlink?toc-item-id=2713a3ea-173f-4bd9-8684-ec4b47513699)，`value?` 参数就是列表值转换函数。要想让CheckBox勾选，单元格的值就为true。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.af18ee.png?width=800)
我们可以定义下面这样的转换函数，里面有个三目运算符，当值为1的时候传true，然后将返回值传到上述接口就能实现勾选。

```javascript
var convert1 = function (item) {
  return item["isMakeMoney"] === 1 ? true : false;
};
```
