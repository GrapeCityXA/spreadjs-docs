# typescript

你可以为SpreadJS添加TypeScript支持。TypeScript提供强类型访问，并能更好地呈现代码相关信息。
你可以从TypeScript官方网站[https://www.typescriptlang.org/](https://www.typescriptlang.org/)下载TypeScript并获取更多信息。
SpreadJS的TypeScript定义文件位于产品主文件夹下的“definition”文件夹中（`SpreadJS\definition\GC.Spread.Sheets.d.ts`）。
按照以下步骤为SpreadJS添加TypeScript支持：

1. 在你的TypeScript文件中添加对`GC.Spread.Sheets.d.ts`和`jquery.d.ts`的引用。

    ```ts
    /// <reference path="path/jquery.d.ts" />
    /// <reference path="path/GC.Spread.Sheets.d.ts" />
    ```
