### **以下功能和增强功能已被纳入本版本的产品**

* 添加支持创建报表（ReportSheet）插件，报表（ReportSheet）是一种简单灵活的方式，可以轻松创建复杂的报告，还支持数据输入、分页、数据过滤、排序、条件格式化等
* 用户现在可以将不同的任务分配给不同的资源，以有效地管理任务、日程和资源，使用 GanttSheet
* 添加支持在 GanttSheet 的完成字段中以百分比显示任务进度状态
* SpreadJS 现在支持基于形状的图表，使用 `zIndex` 方法设置定位元素的堆叠顺序，然后使用 `group` 方法将所有元素组合在一起
* 增强支持使用偏移量为特定数据透视区域设置样式，其中偏移量指的是以数据透视区域的左上角单元格 (0,0) 为基准单元格来定义范围
* 添加支持在滚动时顶行或左列更改时使用 `TopRowChanged` 和 `LeftColumnChanged` 事件
* 使用 `font` 属性为工作表设置字体样式，该属性包括字体样式、字体粗细、字体大小和字体族的值
* SpreadJS 现在支持添加具有多项选择的图表，以根据所选标准动态更改可视化效果
* SpreadJS 现在允许您使用 `LOLLIPOPVARISPARKLINE` 方法创建棒棒糖方差迷你图
* 现有的 `IMAGE` 函数已更新以匹配最新的 Excel 函数
* 添加对集算表中的触发器公式的支持，这些公式对于在列中存储独立数据很有用
* 它允许您根据选定的条件重新计算数据或在输入新值或为列设置适当的默认值时清除数据
* 添加支持在集算表中查看引用的计算列
* 用户现在可以使用 `getSortState()` 方法获取当前工作表的最后排序状态
* 添加了对分布式水平对齐的支持，其中每行文本中的每个单词在单元格的宽度上均匀对齐，并且当应用缩进值时，单元格的左右两侧都填充
* 增强支持通过在折线图和散点图中将平滑属性设置为 true 来显示累积增长的曲线
* 增强支持使用不同范围为指定的表区域设置布局样式，例如第二列的数据区域
* 用户现在可以在工作表标签中实现高级工作表标签样式，例如工作表标签的文本样式、背景颜色和图标
* 添加了瀑布图的支持，这对于理解连续引入的正值或负值的累积影响非常有用
* 粘贴到剪贴板现在支持更多选项，这些选项可以从 SpreadJS 设计器的上下文菜单或在运行时访问
* 为集算表中的数据分析添加了新的 WINDOW 函数，例如 `FrameGroups`、`ExcludeMode` 和 `WindowChaining`
