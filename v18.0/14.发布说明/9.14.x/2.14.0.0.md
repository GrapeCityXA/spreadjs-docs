# rnotesv14




以下的特性和改进已经包含在这个版本的产品中

- [Cascade Sparkline Total Column](gcdocsite__documentlink?toc-item-id=3b468f28-6e57-450f-b8ba-05ab8aa0b8e5)- 用户现在可以使用cascade sparkline中的total列指示器
- [Support for exporting to HTML](gcdocsite__documentlink?toc-item-id=fcfbecbf-1339-4443-9a44-b5b35e30f7b7)- 用户可以将区域或整个表单导出为html您可以以HTML格式导出任何特定区域的单元格
- [SpreadJS Accessibility Support](gcdocsite__documentlink?toc-item-id=7a01412b-1c48-4624-bc87-58892c2d240f)- 用户现在可以获得基本的可访问性支持，这样SpreadJS就可以兼容ADA和屏幕阅读器
- [Iterative calculation](gcdocsite__documentlink?toc-item-id=ba2e6b4f-05b4-4d6d-957e-64f26e496538)- 当单元格中的公式在表格中引用它自己的单元格来重新计算公式，直到找到一个确定的结果时，SpreadJS提供了对迭代计算的支持
- [Support changing color for comment icon](gcdocsite__documentlink?toc-item-id=2a02a36d-7080-4135-b02e-55c2e60126be)- 用户现在可以自定义单元格评论指示器的颜色和大小.
- [Horizontal axis cross value](gcdocsite__documentlink?toc-item-id=3f11f3a1-fe93-42d7-9c54-c823d253d5e7)- SpreadJS允许用户调整图表轴叉，这样用户可以将x轴或y轴移动到点轴值或轴的最小/最大值
- 当表单被保护时，用户现在可以根据不同的保护选项启用或禁用功能区菜单
- [Support Access range](gcdocsite__documentlink?toc-item-id=94104842-bda8-45f1-99f6-4f2cbc4045ba)- 用户可以根据自己的需要方便地选择在表格区域获取区域信息的方式，可以使用行和列信息，也可以使用区域/单元地址字符串
- [Support Header Formulas and Sparklines](gcdocsite__documentlink?toc-item-id=d1d9e12f-df7e-4fee-8299-88e9dd9f575d)- 用户可以向表格的行标题区域和列标题区域添加formula和SparklineEx
- [Intervals of Bars of Bar Chart](gcdocsite__documentlink?toc-item-id=2a771b82-92a5-4d53-99d2-323da31a7f69)- 用户可以通过调整系列间隙宽度和重叠来定制条形图和柱状图的外观
- [Support Excel Fill Effects and Pattern](gcdocsite__documentlink?toc-item-id=04268445-c3e6-47c2-99db-09a3eb603998)- 用户可以通过应用图案填充效果自定义图表元素
- SpreadJS Angular库现在支持AOT和Prod编译器
- [Support copy pasting floating images](gcdocsite__documentlink?toc-item-id=1737b42e-14a2-4daf-90e9-90a7278951e3)- 用户可以将Excel中的图像复制粘贴到SpreadJS表单中
- [Support customizing doughnut charts hole size](gcdocsite__documentlink?toc-item-id=8eba613c-66fb-4a0b-a496-a2afbcfc5725)- 用户可以定制甜甜圈图的甜甜圈孔大小
- SpreadJS 现在支持[XLOOKUP](gcdocsite__documentlink?toc-item-id=1e271c44-04de-44cd-be0f-66063ebc7499)和[XMATCH](gcdocsite__documentlink?toc-item-id=8eac99a5-8687-4c2a-bde6-af807a2c2b19)函数
- 用户现在可以使用[LET](gcdocsite__documentlink?toc-item-id=dfcae82f-d66b-40ab-90ea-a12295cd5fa6)函数在公式中存储和定义值
- [滚动条像素滚动](gcdocsite__documentlink?toc-item-id=611a1476-c432-483f-8c51-a9aa19238d8f)行为现在更加准确
- 支持[auto-merge](gcdocsite__documentlink?toc-item-id=4cee90a9-627c-4915-a918-5852d68e2311)的选择——客户可以使用addSpan的自动合并选择功能
- [Clipboard events for floating object](gcdocsite__documentlink?toc-item-id=5f7dd968-51d2-44cd-9521-df24229fd1bc)- 用户现在可以使用剪贴板事件对浮动对象(如图片、图表、形状、切片器和自定义浮动对象)进行复制粘贴操作
- [Multiple-Column Dropdown](gcdocsite__documentlink?toc-item-id=2a4ec0ae-7edf-470e-bf25-ea15f2fc6ad9)- 用户可以提供一个下拉列表以及使用多列下拉单元格的可编辑区域
- [Table binding support](gcdocsite__documentlink?toc-item-id=3a484162-caa2-4630-9959-6fd9482d824d)- 用户可以选择表绑定情况下如何展开行
- [Set a switch that does not display ###](gcdocsite__documentlink?toc-item-id=8e97f3f5-55c9-4ace-88e2-ecf5c5024a0a)- 当列宽度不够时，用户可以设置一个开关，使单元格不会被“####”、科学符号、整数小数等掩盖
- [Incremental Loading Support](gcdocsite__documentlink?toc-item-id=541d1f89-cdfd-4464-9cd6-4b865ffd6f2f)- SpreadJS现在支持增量加载，使表单中的高性能数据处理成为可能
- [Custom Array Formula](gcdocsite__documentlink?toc-item-id=05fcc1bd-c089-4b8c-bfef-950745763d5d)- 用户可以在自定义函数中返回数组
- SpreadJS支持[OBJECT](gcdocsite__documentlink?toc-item-id=9ea36f28-42ac-4974-acc7-e7be2e547a5e)和[RANGEBLOCK](gcdocsite__documentlink?toc-item-id=80ab7ba1-5a1d-4e2a-965d-8bad609d4718)函数 - 用户可以设置rangetemplate单元格类型并使用此函数绑定对象
- Designer 支持[RangeTemplate](gcdocsite__documentlink?toc-item-id=e62490e1-8b7e-474c-b9a5-daac00f2abd8)单元格类型 -用户可以通过设计器创建区域模板单元格类型
- [SpreadJS Support Funnel Chart](gcdocsite__documentlink?toc-item-id=ed95ddd5-5d86-4a30-b89e-3bbf37abe6d5)- 用户可以添加一个称为漏斗图的新图表类型
- SpreadJS 支持[PROPERTY](gcdocsite__documentlink?toc-item-id=e1c9ff0a-e7c0-4864-97db-bd857e1e81e6)函数, 这样用户就可以指定返回对象值的属性路径
