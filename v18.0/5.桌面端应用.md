# spdesigner

SpreadJS 设计器是一款独立的应用程序，它允许你设计电子表格并向其中添加数据，保存文件，然后将其加载到你的应用程序或其他资源中。例如，你可以设计一个包含单元格类型和格式的电子表格，添加数据，然后将其保存为 Spread 格式或 Excel 格式，以便加载到你的应用程序中的 SpreadJS 组件中。
下图展示了用户在工作表中设置单元格格式的情况。
![formatcells](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/formatcells.c13893.cd4d1c.png)
如插图所示，SpreadJS 设计器提供了一个所见即所得的设计环境，因此在你进行操作时，可以看到单元格类型及其格式，以及图像、颜色和其他设计元素。该设计器不仅是使用 SpreadJS 时的一个实用工具，也是一个用于尝试各种设计思路和处理数据的独立工具。
