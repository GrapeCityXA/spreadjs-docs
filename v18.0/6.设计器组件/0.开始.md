## 许可证信息

SpreadJS 设计器组件支持以下类型的许可证：

### 无许可证

无许可证版本允许你在本地计算机上使用 SpreadJS 设计器组件的所有功能。以下是一些示例 URL：

* http(s)://localhost
* http(s)://127.0.0.1
* file://xxxx
* http(s)://xxx.local
* http(s)://xxx
* http(s)://[::1]
* http(s)://[0:0:0:0:0:0:0:1]

然而，功能区中的 **“SpreadJS 设计器许可证”** 选项卡会显示以下消息：
![spreadjs-designer-component-license](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/spreadjs-designer-component-license.43ae1b.001877.png)
如果在 Web 服务器上执行，功能区组件将被销毁，并显示以下错误消息：
*“未找到部署许可证密钥。请发邮件至 info.xa@grapecity.com 以申请测试部署许可证。”*

### 评估许可证

评估许可证允许你在本地计算机和 Web 服务器上使用 SpreadJS 设计器组件的所有功能。
然而，功能区中的 **“SpreadJS 设计器许可证”** 选项卡会显示以下消息：
**本地计算机**
“*评估许可证。请联系 info.xa@grapecity.com 的销售人员以申请测试部署许可证。”*
**Web 服务器**
“*评估许可证。请联系 400-657-6008 的销售人员或发邮件至 info.xa@grapecity.com 以购买部署许可证。”*
如果你想部署一个网站，还需要一个有效的表格组件评估许可证，可以通过使用 `GC.Spread.Sheets.LicenseKey = "xxx"` 来设置。

### 已授权许可证

已授权版本允许你在本地计算机和 Web 服务器上使用 SpreadJS 设计器组件的所有功能。如果你想部署一个网站，也需要一个有效的表格组件许可证。

### 应用许可证

SpreadJS 和 SpreadJS 设计器组件的许可证密钥应分别通过使用 GC.Spread.Sheets.LicenseKey 和 GC.Spread.Sheets.Designer.LicenseKey 来设置，并且必须在创建设计器实例之前设置，如下所示：

```JavaScript
GC.Spread.Sheets.LicenseKey = "xxxx";
GC.Spread.Sheets.Designer.LicenseKey = "xxxx";
var designer = new GC.Spread.Sheets.Designer("designerHost");
```

## SpreadJS 设计器组件和数据透视表附加组件

如 [此处](gcdocsite__documentlink?toc-item-id=f9e48ba0-5b2d-425a-aeec-127a486ab4fe) 所述，在 14.1 版本或更高版本中，你可以选择购买带有数据透视表附加组件的 SpreadJS 许可证。下表描述了在使用 SpreadJS 设计器组件时数据透视表功能的可用性：

| 使用场景 | **许可证密钥（SpreadJS、设计器组件和数据透视表）** | **许可证密钥（SpreadJS 和设计器组件）** |
| ---- | --------------------------- | ---------------------- |
| 设计器组件：无许可证密钥<br>SpreadJS 运行时：无许可证密钥 | 所有数据透视表功能均可用，并且可以在本地计算机上运行。 | @rows=5:无数据透视表功能可用。 |
| 设计器组件：评估许可证密钥<br>SpreadJS 运行时：许可证 + 无附加组件 | 数据透视表功能不可用。 |
| 设计器组件：评估许可证密钥<br>SpreadJS 运行时：许可证 + 附加组件 | 在评估许可证密钥有效期内，所有数据透视表功能均可用。 |
| 设计器组件：生产许可证密钥<br>SpreadJS 运行时：许可证 + 无附加组件 | 数据透视表功能不可用。 |
| 设计器组件：生产许可证密钥<br>SpreadJS 运行时：许可证 + 附加组件 | 所有数据透视表功能均无任何限制地可用。 |
