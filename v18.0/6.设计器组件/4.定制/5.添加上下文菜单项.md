# add_context_menu_item

按照以下步骤在上下文菜单组件中添加“插入签名”选项。
1. 访问默认配置。
    ```JavaScript
    // 配置工作簿和工作表
    var spread = new GC.Spread.Sheets.Workbook("ss");
    var activeSheet = spread.getActiveSheet();
    // 访问默认配置
    var config = GC.Spread.Sheets.Designer.DefaultConfig;
    ```
2. 在 `contextMenu` 标签中添加“插入签名”选项，并在项目中把它设置到 `commandMap` 中。
    ```JavaScript
    // 在配置的上下文菜单中添加上下文菜单项
    if (config && config.contextMenu) {
        config.contextMenu.unshift("insertSignatureMenu");
    }
    // 为新的上下文菜单项创建命令
    config.commandMap = {
        "insertSignatureMenu": {
            文本: "插入签名",
            commandName: "insertSignatureMenu",
            visibleContext: "ClickRowHeader",
            // 执行 InsertSignature，以下只是一个简单的代码片段示例
            execute: () => {
                console.log("插入签名");
            }   
        }
    }
    ```
3. 通过传递用于可自定义配置的 `config` 参数来初始化设计器实例。
    ```JavaScript
    // 初始化设计器实例
    var designer = new GC.Spread.Sheets.Designer.Designer(document.getElementById("designerHost"), config, spread);
    ```
