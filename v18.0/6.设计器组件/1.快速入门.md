# quick-start-designer

以下快速入门部分将帮助你在项目中使用SpreadJS设计器组件来创建新的电子表格或处理现有电子表格。你可以[在此处](https://www.grapecity.com.cn/developer/spreadjs/download)下载设计器组件的最新脚本和CSS文件。有关添加引用的更多信息，请参阅[入门指南](gcdocsite__documentlink?toc-item-id=9ca012fb-c74a-4e76-ac74-61420067be72)主题。

> **注意**：设计器组件只能与工作表组件配合使用。若要了解如何使用工作表组件，请参阅[快速入门](gcdocsite__documentlink?toc-item-id=98e23ddf-b47b-4b4e-90d7-b279885af3e9)主题。

## 将设计器组件与新电子表格配合使用

### HTML页面

按照以下步骤创建一个HTML页面，该页面将显示SpreadJS设计器组件以及一个新的电子表格。

1. 打开 “记事本” 或你喜欢的代码编辑器。
2. 在文件中添加以下HTML语法代码。

    ```HTML
    <!DOCTYPE html>
    <html>
    <head>
        <meta charset="utf-8" />
        <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    
        <script type="text/javascript" src="https://code.jquery.com/jquery-2.1.1.min.js"></script>
    
        <script>
        </script>
    </head>
    <body>
    </body>
    </html>
    ```
3. 在HEAD元素标签内添加以下SpreadJS的CSS和JS文件。

    ```HTML
    <!--CSS文件--> 
    <link rel="styleSheet" href="css/gc.spread.sheets.x.x.x.css" />
    
    <!--脚本文件-->
    <script src="scripts/gc.spread.sheets.all.x.x.x.min.js" type="text/javascript"></script>
    <script src="scripts/gc.spread.sheets.shapes.x.x.x.min.js" type="text/javascript"></script>
    <script src="scripts/gc.spread.sheets.charts.x.x.x.min.js" type="text/javascript"></script>
    <script src="scripts/gc.spread.sheets.print.x.x.x.min.js" type="text/javascript"></script>
    <script src="scripts/gc.spread.sheets.pdf.x.x.x.min.js" type="text/javascript"></script>  
    ```

    根据你的需求，你可以在此处包含用于不同附加功能的JS文件，如条形码、数据透视表、表格工作表、甘特图工作表、导入/导出等等。
4. 在HEAD元素标签内添加以下设计器组件的CSS和JS文件。

    ```HTML
    <!--CSS文件--> 
    <link rel="styleSheet" href="css/gc.spread.sheets.designer.x.x.x.min.css" />
    
    <!--脚本文件-->
    <script src="scripts/gc.spread.sheets.designer.resource.en.x.x.x.min.js" type="text/javascript"></script>
    <script src="scripts/gc.spread.sheets.designer.all.x.x.x.min.js" type="text/javascript"></script>
    ```

    > **注意**：电子表格引用应添加在设计器组件引用之上。此外，设计器组件资源文件（在此例中为*gc.spread.sheets.designer.resource.en.x.x.x.min.js*）必须始终在*gc.spread.sheets.designer.all.x.x.x.min.js*之前引用。
5. 在BODY元素中包含一个DOM元素作为容器。

    ```HTML
    <body>
        <div id="designerHost" style="width:100%; height:1000px; border: 1px solid gray;"></div>
    </body>
    ```
6. 在HEAD部分的脚本元素标签内初始化设计器组件。并且，在初始化之前设置设计器组件和SpreadJS的许可证密钥。

    ```JavaScript
    <script>
        //设置许可证密钥
        //GC.Spread.Sheets.Designer.LicenseKey = "XXX";
        //GC.Spread.Sheets.LicenseKey = "XXXX";
    
        var designer = new GC.Spread.Sheets.Designer.Designer(document.getElementById("designerHost"));
    </script>
    ```

    HTML文件中的完整代码将如下所示：

    ```HTML
    <!DOCTYPE html>
    <html>
    <head>
        <meta charset="utf-8" />
        <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    
        <script src="https://code.jquery.com/jquery-2.1.1.min.js" type="text/javascript"></script>
    
        <!--CSS文件--> 
        <!--电子表格CSS文件--> 
        <link rel="styleSheet" href="css/gc.spread.sheets.x.x.x.css" />
        <!--设计器组件CSS文件--> 
        <link rel="styleSheet" href="css/gc.spread.sheets.designer.x.x.x.min.css" />
    
        <!--脚本文件-->
        <!--电子表格JS文件--> 
        <script src="scripts/gc.spread.sheets.all.x.x.x.min.js" type="text/javascript"></script>
        <script src="scripts/gc.spread.sheets.shapes.x.x.x.min.js" type="text/javascript"></script>
        <script src="scripts/gc.spread.sheets.charts.x.x.x.min.js" type="text/javascript"></script>
        <script src="scripts/gc.spread.sheets.print.x.x.x.min.js" type="text/javascript"></script>
        <script src="scripts/gc.spread.sheets.pdf.x.x.x.min.js" type="text/javascript"></script>
    
        <!--设计器组件JS文件--> 
        <script src="scripts/gc.spread.sheets.designer.resource.en.x.x.x.min.js" type="text/javascript"></script>
        <script src="scripts/gc.spread.sheets.designer.all.x.x.x.min.js" type="text/javascript"></script>
    
        <script>
            window.onload = function () {
    
                //设置许可证密钥
                //GC.Spread.Sheets.Designer.LicenseKey = "XXX";
                //GC.Spread.Sheets.LicenseKey = "XXXX";
    
                var designer = new GC.Spread.Sheets.Designer.Designer(document.getElementById("designerHost"));
            }
        </script>
    </head>
    <body>
        <!--DOM元素-->
        <div id="designerHost" style="width:100%; height:1000px;border: 1px solid gray;"></div>
    </body>
    </html>
    ```
7. 将其另存为HTML文件。例如，“index.html”。
8. 在保存HTML文件的同一位置创建一个新文件夹。将步骤3和4中提到的脚本和CSS文件添加到该文件夹中。
9. 在浏览器中查看HTML文件，以查看带有新电子表格的设计器组件。

## 将设计器组件与现有电子表格配合使用

你还可以将设计器组件与任何现有电子表格配合使用。例如，下图显示了一个带有树形图及其数据的电子表格。
![spreadjs-designer-existing-worksheet-without](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/spreadjs-designer-existing-worksheet-without.bad066.png)
要将设计器组件与上述电子表格配合使用，请在现有HTML文件中执行以下步骤：

1. 包含设计器组件的脚本和CSS文件引用。

    ```HTML
    <!--设计器组件CSS文件--> 
    <link rel="styleSheet" href="css/gc.spread.sheets.designer.x.x.x.min.css" />
    
    <!--设计器组件脚本文件-->
    <script src="scripts/gc.spread.sheets.designer.resource.en.x.x.x.min.js" type="text/javascript"></script>
    <script src="scripts/gc.spread.sheets.designer.all.x.x.x.min.js" type="text/javascript"></script>
    ```

    > **注意**：如上述步骤所述，电子表格引用应添加在设计器组件引用之上。
2. 在初始化设计器组件时，将电子表格的变量作为参数传递。

    ```JavaScript
    var designer = new GC.Spread.Sheets.Designer.Designer(document.getElementById("designerHost"), '', spread);
    ```
3. 包含设计器组件的DOM元素以及工作表的DOM元素。

    ```HTML
    <div id="designerHost" style="width:100%; height:1000px; border: 1px solid gray;"></div>
    ```

HTML文件中的完整代码将如下所示，其中现有电子表格添加数据并创建树形图。此电子表格进一步与设计器组件配合使用以执行任何UI操作。

```HTML
<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />

    <script src="https://code.jquery.com/jquery-2.1.1.min.js" type="text/javascript"></script>
    
    <!--CSS文件--> 
    <link rel="styleSheet" href="css/gc.spread.sheets.x.x.x.css" />
    <!--设计器组件CSS文件--> 
    <link rel="styleSheet" href="css/gc.spread.sheets.designer.x.x.x.min.css" />

    <!--脚本文件-->
    <script src="scripts/gc.spread.sheets.all.x.x.x.min.js" type="text/javascript"></script>  
    <script src="scripts/gc.spread.sheets.shapes.x.x.x.min.js" type="text/javascript"></script>  
    <script src="scripts/gc.spread.sheets.charts.x.x.x.min.js" type="text/javascript"></script>  
    <script src="scripts/gc.spread.sheets.print.x.x.x.min.js" type="text/javascript"></script>  
    <script src="scripts/gc.spread.sheets.barcode.x.x.x.min.js" type="text/javascript"></script>
    <script src="scripts/gc.spread.sheets.pdf.x.x.x.min.js" type="text/javascript"></script>
    <script src="scripts/gc.spread.sheets.tablesheet.x.x.x.min.js" type="text/javascript"></script>
    
    <!--设计器组件JS文件--> 
    <script src="scripts/gc.spread.sheets.designer.resource.en.x.x.x.min.js" type="text/javascript"></script>
    <script src="scripts/gc.spread.sheets.designer.all.x.x.x.min.js" type="text/javascript"></script>

    <script>
        $(document).ready(function () {
            // 初始化Spread
            var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
            // 获取活动工作表
            var sheet = spread.getSheet(0);
            // 设置列宽
            sheet.setColumnWidth(2, 100);
            sheet.setColumnWidth(4, 100);
            // 创建数据数组
            var dataArray =
                [
                    ['地区', '子地区', '国家', '人口'],
                    ['亚洲', '南部', '印度', 1354051854],
                    [,, '巴基斯坦', 200813818],
                    [,, '孟加拉国', 166368149],
                    [,, '其他', 170220300],
                    [, '东部', '中国', 1415045928],
                    [,, '日本', 127185332],
                    [,, '其他', 111652273],
                    [, '东南部',, 655636576],
                    [, '西部',, 272298399],
                    [, '中部',, 71860465],
                    ['非洲', '东部',, 433643132],
                    [, '西部',, 381980688],
                    [, '北部',, 237784677],
                    [, '其他',, 234512021],
                    ['欧洲',,, 742648010],
                    ['其他',,, 1057117703]
                ];
            // 设置数组
            sheet.setArray(1, 1, dataArray);
            var treemapChart = sheet.charts.add('chart1',
            GC.Spread.Sheets.Charts.ChartType.treemap, 450, 0, 500, 500, "B2:E18");
            
            // 初始化设计器组件并使用上述创建的spread组件
            var designer = new GC.Spread.Sheets.Designer.Designer(document.getElementById("designerHost"), '', spread);

        });
    </script>
</head>
<body>
    <div id="ss"></div>
    <!--设计器组件的DOM元素-->
    <div id="designerHost" style="width:100%; height:1000px; border: 1px solid gray;"></div>
</body>
</html>
```
