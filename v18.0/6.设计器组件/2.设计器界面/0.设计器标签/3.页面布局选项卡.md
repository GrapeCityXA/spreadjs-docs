# page-layout-tab

**页面布局**选项卡使你能够控制和自定义工作簿或工作表内容在打印页面上的显示方式。
![PageLayoutTab](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/PageLayoutTab.4b35fa.6ce3df.png)
下表列出了“页面布局”选项卡的各个部分和选项：

| 部分 | 描述 |
| --- | --- |
| 主题 | 提供工作表的主题、颜色和字体相关选项。 |
| 页面设置 | 提供页边距、纸张方向、页面大小、打印区域、分页符、背景和页面标题等选项。 |
| 调整为合适大小 | 提供页面宽度、高度和缩放比例的选项。 |
| 工作表选项 | 提供活动工作表的网格线和标题显示视图以及打印相关的选项。 |
