# designerinterface

这一简要概述指出了界面的一些主要部分，并展示了 SpreadJS 设计器组件的基本布局。
SpreadJS 设计器组件提供了以下界面来设计你的组件。
![designerspreadjs](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/designerspreadjs.d00ea4.79cefa.png)
当设计器组件的宽度足够小，以至于功能区按钮和导航选项卡被隐藏时，SpreadJS 还支持功能区滚动。
![designer-scrollable](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/designer-scrollable.590f5a.f0c36a.png)
