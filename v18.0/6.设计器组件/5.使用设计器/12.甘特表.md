# ganttsheet-designer

SpreadJS 设计器组件提供了在工作簿中插入 [甘特表](gcdocsite__documentlink?toc-item-id=1ced61ab-d7e7-47d9-86ba-c30ea995df44) 的选项。
**甘特图工作表** 按钮位于 **插入** \> **工作表** 选项卡组中。点击 **甘特图工作表** 按钮会在工作簿的工作表集合中添加一个名为 **甘特图工作表1** 的工作表，并打开 **甘特图格式** 选项卡。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.daceed.png)
默认情况下，**甘特图格式** 选项卡左侧显示一个空白区域，右侧显示一个甘特图工作表面板。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.719954.png)
要添加数据源，可以从 **甘特图工作表面板** 中 **绑定表** 下拉菜单中选择 **(新建表)** 选项，或者点击 **数据** \> **数据绑定** 选项卡组中的 **数据源** 功能区按钮。
在 **数据源** 中，你可以添加表格并为 CRUD 操作提供外部 URL。你还可以使用 **列** 选项卡获取表格数据。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.2c347a.png)

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.8948d6.png)

你可以点击列项目来查看或编辑其属性、模式类型并添加关系。也可以通过点击列表底部的 **添加计算列** 来添加计算列。
使用 Designer 获取数据源后，现在你可以通过甘特图工作表面板将表格数据源绑定到甘特图工作表中。
**绑定表** 下拉菜单允许你选择现有数据源或创建新数据源。甘特图现在将显示在空白的甘特图工作表视图区域中。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.e8796c.png)

SpreadJS 使你能够在设计器和运行时甘特图工作表面板的数据源 **列** 列表中显示列的关系。会显示一个链接图标来指示相关列。要查看关系的详细信息，可以点击箭头按钮。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.b28610.png)

SpreadJS 还会在甘特图工作表面板上显示关系。**字段** 部分会显示连接列的名称以及一个展开箭头按钮。如果需要，你可以展开关系列节点并查看子节点。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.35451e.png)
甘特图工作表面板以树状结构显示，以便更好地描绘父子节点之间的关系。
请注意，还有勾选/取消勾选按钮，用于在甘特图工作表中勾选或取消勾选列。当你选择主要关系列时，甘特图工作表中会出现一个包含对象的列。但是，如果选择了子关系列，则会插入匹配的列，并且子列名称将包含使用 “.” 符号表示的层次关系，例如 *Gantt\_Mode\_id*。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.7dfd4a.png)

SpreadJS 设计器组件还允许你修改列设置。要修改默认设置，在甘特图工作表中选择一列。这将打开 **列设置** 选项卡，你可以根据需要在此调整各种参数，如标题、值、列名、数据类型、样式等。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.86c1cd.png)

此外，甘特图工作表允许你执行不同的任务相关操作、查看数据信息、更改图表格式等。要了解更多信息，请参考以下主题。

| 主题 | 描述 |
| --- | --- |
| [任务选项卡](gcdocsite__documentlink?toc-item-id=dca395ab-fef5-4595-a855-277b93b1ea5b) | 提供执行各种任务操作的选项。 |
| [项目选项卡](gcdocsite__documentlink?toc-item-id=342d36f0-9a03-4979-bb5c-27875faff390) | 提供管理项目信息的选项。 |
| [视图选项卡](gcdocsite__documentlink?toc-item-id=1dc429e7-8f91-4543-864d-e5ce579630cb) | 提供对特定时间尺度进行排序和缩放的选项。 |
| [甘特表格式选项卡](gcdocsite__documentlink?toc-item-id=999313eb-47cd-46d8-9539-e4ea8530d676) | 提供自定义任务栏外观的选项。 |
