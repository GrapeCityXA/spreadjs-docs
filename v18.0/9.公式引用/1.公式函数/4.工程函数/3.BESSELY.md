# BESSELY

此函数返回 Bessel 函数值。



#### 语法

BESSELY( *value* , *order* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *value*  | 用来计算函数的值。 |
|  *order*  | 函数的阶数。 如果 n 不是整数，将被截尾取整。 |



#### 注释

如果 value 或 order 是非数值型，则 BESSELI 返回 #VALUE! 错误值。如果 order < 0，则 BESSELY 返回 #NUM! 错误值。



#### 数据类型

接受两个参数的数值数据。 返回数值数据。



#### 示例

BESSELY(A4,D5)

BESSELY(R4C1,R5C4)

BESSELY(2.85,1) 得出结果 0.2801918953
