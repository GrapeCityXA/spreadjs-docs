# replace

此功能有助于使用正则表达式将部分文本字符串替换为不同的文本字符串。

## 句法

`GC.REGEXREPLACE(text, regular_expression, replacement, [modifiers])`

## 参数

此函数具有以下参数：

| **参数** | **描述** |
| --- | --- |
| `text` | 指的是您要替换的文本。该函数可以输入字符串、单元格引用或单元格范围引用。 |
| `regular_expression` | 替换文本的所有匹配实例的正则表达式。 |
| `replacement` | 指根据regular\_expression可以插入的代替原文的文字。 |
| `modifiers` | [可选] 输入以定义模式。 <ul><li>g (global)：保留最后一个匹配的索引，并允许后续搜索从上一个匹配的末尾开始。 </li><li>i （忽略大小写）：使整个表达式不区分大小写。 </li><li>m（多行）：启用时，开始和结束锚点与一行的开始和结束匹配，而不是整个字符串的开始和结束。 </li><li>u ( unicode )：启用后，您可以在表单中使用扩展的 unicode 转义符。 </li><li>s ( dotall )：点匹配任何字符，包括换行符。 </li></ul> |

> type=warning
> 您可以使用此函数将文本（而非数字）作为输入并返回文本作为输出
> 如果你想要数字作为输出。将 VALUE 函数与此函数结合使用
> 如果要使用数字作为输入，请使用 TEXT 函数将它们转换为文本

## 例子

`GC.REGEXREPLACE("SpreadJS Worksheet", "s.\*t", "book")`给出结果 SpreadJS Worksheet
`GC.REGEXREPLACE("12/23/2022", "(\\d{2})/(\\d{2})/(\\d{4})", "$3-$1-$2")`给出结果 2022-12-23
`GC.REGEXREPLACE("John-Smith", "(\\w{4})-(\\w{5})", "$2 $1")`给出结果 Smith John
**错误**

* 返回#VALUE！如果 text 或regular\_expression的值类型不是文本，则会出错。
* 如果参数的长度 < 3，则返回 #N/A 错误。
* 如果任何参数无效，则返回 #NAME 错误。
