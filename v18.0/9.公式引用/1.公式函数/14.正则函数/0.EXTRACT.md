# extract

这个动态数组函数有助于根据正则表达式提取匹配的子字符串。动态数组是可调整大小的数组，可根据在单个单元格中输入的公式自动计算并将值返回到多个单元格。在使用该功能之前，您需要开启 allowDynamicArray 选项。

## 句法

`GC.REGEXEXTRACT(text, regular_expression, [modifiers])`

## 参数

此函数具有以下参数：

| **参数** | **描述** |
| --- | --- |
| `text` | 指您要搜索的文本。该函数可以输入字符串、单元格引用或单元格范围引用。 |
| `regular_expression` | 指与返回的正则表达式匹配的文本的第一部分。 |
| `modifiers` | [可选] 输入以定义模式。<ul><li>g (global)：保留最后一个匹配的索引，并允许后续搜索从上一个匹配的末尾开始。</li><li>i （忽略大小写）：使整个表达式不区分大小写。</li><li>m（多行）：启用时，开始和结束锚点与一行的开始和结束匹配，而不是整个字符串的开始和结束。</li><li>u ( unicode )：启用后，您可以在表单中使用扩展的unicode转义符。s ( dotall )：点匹配任何字符，包括换行符。</li></ul> |

> type=warning
> 您可以使用此函数将文本（而非数字）作为输入并返回文本作为输出
> 如果你想要一个数字作为输出。将 VALUE 函数与此函数结合使用
> 如果要使用数字作为输入，请使用 TEXT 函数将它们转换为文本

## 例子

* `spread.options.allowDynamicArray = true;`将所有示例的 allowDynamicArray 设置为 true
* `GC.REGEXEXTRACT("I think SpreadJS is Good", ".*(good).*", "i")` 输出 good
* `GC.REGEXEXTRACT("There are 195 countries in the world", "\d+") ` 输出 195
* `GC.REGEXEXTRACT("You can also extract multiple values from text.", "You can also (\w+) multiple (\w+) from text.")` 输出 ["extract", "values"]

**错误**

* 返回#VALUE！如果 text 或 regular\_expression 的值类型不是文本，则会出错。
* 如果参数的长度 < 2，则返回 #N/A 错误。
* 如果任何参数无效，则返回 #NAME 错误。
* 如果 regular\_expression 与文本不匹配，则返回 #N/A 错误。
* 如果数组结果未展开，则返回 #SPILL 错误。
