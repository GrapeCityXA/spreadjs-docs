# match

此函数有助于查找文本是否与正则表达式匹配。

## 句法

`GC.REGEXMATCH(text, regular_expression, [modifiers])`

## 参数

此函数具有以下参数：

| **参数** | **描述** |
| --- | --- |
| `text` | 指的是您要针对regular\_expression进行测试的文本。 |
| `regular_expression` | 指用于测试文本的正则表达式。 |
| `modifiers` | [可选] 输入以定义模式。<ul><li>g (global)：保留最后一个匹配的索引，并允许后续搜索从上一个匹配的末尾开始。</li><li>i（忽略大小写）：使整个表达式不区分大小写。</li><li>m（多行）：启用时，开始和结束锚点与一行的开始和结束匹配，而不是整个字符串的开始和结束。</li><li>u (unicode)：启用后，您可以在表单中使用扩展的unicode转义符。</li><li>s (dotall)：点匹配任何字符，包括换行符。</li></ul> |

> type=warning
> 您可以将此函数与文本（而非数字）一起用作输入并返回一个逻辑值，即 TRUE 或 FALSE 作为输出
> 如果要使用数字作为输入，请使用 TEXT 函数将它们转换为文本

## 例子

`GC.REGEXMATCH("SpreadJS Supports 400 functions.", "\d+")`结果 TRUE
`GC.REGEXMATCH("My Name is (John Smith)", "\(([\w]+)\)")`结果 TRUE
`GC.REGEXMATCH("Red", "[^red]", "i")`结果 FALSE

**错误**

* 返回#VALUE！如果text或regular\_expression的值类型不是文本，则会出错。
* 如果参数的长度 < 2，则返回 #N/A 错误。
* 如果任何参数无效，则返回 #NAME 错误。
