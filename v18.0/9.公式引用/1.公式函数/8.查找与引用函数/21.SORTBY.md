# sortby

此函数基于相应范围或数组中的值对范围或数组的内容进行排序。

与SORT函数不同，SORTBY函数不要求将排序键包含在指定的数组或排序范围内。但是，在使用此函数时，有必要为排序键分配适当的大小(相对于它们的正确长度)。



#### 语法

SORTBY( *array, by_array1, [order_array1], [by_array2, order_array2], …* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
| array | [必需] 指定要排序的范围或数组。 |
| by_array1 | [必需]要对其进行排序的数组或区域 |
| order_array1 | [可选] 要用于排序的顺序。 1表示升序，-1 表示降序。 默认值为 "升序"。 |
| by_array2 | [可选] 要对其进行排序的数组或区域。 |
| order_array2 | [可选] 要用于排序的顺序。 1表示升序，-1 表示降序。 默认值为 "升序"。 |

此函数接受成对参数。用户可以指定下一个排序键范围，并根据自定义需求进行排序。



#### 数据类型

接受单元格区域。返回排序后的数组。



#### 示例

#### Version Available

This function is available in SpreadJS 13 or later.
