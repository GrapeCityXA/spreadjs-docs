# INDIRECT

此函数返回由文本字符串指定的引用。



#### 语法

INDIRECT( *Reftext* , *A1* )



#### 参数

该函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *Reftext*  | 必需。 对包含 A1 样式的引用、R1C1 样式的引用、定义为引用的名称或对单元格的引用作为文本字符串的单元格的引用。 |
|  *A1*  | 可选。一个逻辑值，用于指定包含在单元格 Reftext 中的引用的类型。 |



#### 注释

如果需要变更公式中对单元格的引用，而不变更公式本身，请使用函数 INDIRECT。

如果 A1  为 TRUE 或省略，Reftext 被解释为 A1 样式的引用。

如果 A1 为 FALSE，则将 Reftext 解释为 R1C1 样式的引用。

如果 Reftext 不是有效的单元格引用, 则间接返回 #REF! 。



#### 数据类型

接受任何数据。返回任何数据类型。



#### 示例

INDIRECT("A1")

INDIRECT(A1)

INDIRECT("R[-"&B1&"]C[-"&B2&"]", false)



#### 使用代码

本示例将值添加到单元格并使用INDIRECT公式。


```JavaScript
activeSheet.setValue(0,0,"b1");
activeSheet.setValue(1,0,"A")
activeSheet.setValue(2,0,"B")
activeSheet.setValue(0,1,2);
activeSheet.setValue(1,1,3);
activeSheet.setValue(2,1,1);
//activeSheet.getCell(1,3).formula("=INDIRECT(A1)");
//activeSheet.getCell(1,3).formula('=INDIRECT("A1")');
activeSheet.getCell(1,3).formula("=INDIRECT(A3&B2)");
```
