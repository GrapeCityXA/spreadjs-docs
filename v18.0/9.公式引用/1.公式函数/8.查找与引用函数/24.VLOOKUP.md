# VLOOKUP

此函数在最左列中搜索值，并从指定的列返回同一行中的值。



#### 语法

VLOOKUP( *value* , *array* , *colindex* , *approx* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *value*  | 要查找的值。 |
|  *array*  | 包含要搜索数据的数组或单元格区域 |
|  *colindex*  | 包含返回值的列号 |
|  *approx*  | [可选] 逻辑值，该值指定希望 VLOOKUP 查找近似匹配还是精确匹配。 |



#### 注释

如果approx为false，VLOOKUP 查找精确匹配。如果找不到，返回#N/A错误值。

如果approx为true或省略，并且找不到value，则返回小于value的最大值。

此函数与[HLOOKUP](gcdocsite__documentlink?toc-item-id=643bf7c3-c84a-4938-9c6e-11944bf2265b)的区别在于前者是按列搜索，后者是按行搜索。



#### 数据类型

接受数值或字符串数据。返回数值数据。



#### 示例

VLOOKUP(2,A1:D10,3)
