# FLOOR

将参数 value 向下舍入（沿绝对值减小的方向）为最接近的 signif 的倍数。



#### 语法

FLOOR( *value* , *signif* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *value*  | 要舍入的数值。 |
|  *signif*  | 要舍入到的倍数。 |



如果 value 的符号为正，则数值向下舍入，并朝零调整。 如果 value 的符号为负，则数值沿绝对值减小的方向向下舍入。 如果 value 正好是 signif 的倍数，则不进行舍入。



#### 数据类型

接受两个参数的数值数据。返回数值数据。



#### 示例

FLOOR(C4,B2)

FLOOR(B3,0.05)

FLOOR(R1C2,1)

FLOOR(4.65,2) 得出结果 4

FLOOR(-2.78,-1) 得出结果 -2
