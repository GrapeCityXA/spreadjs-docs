# BOXPLOTSPARKLINE

此函数返回用于表示箱线图迷你图的数据集。



#### 语法

BOXPLOTSPARKLINE( *points, boxPlotClass, [showAverage, scaleStart, scaleEnd, acceptableStart, acceptableEnd, colorScheme, style, vertical]* )



#### 参数

| 参数 | 描述 |
|--- |--- |
|  *Points*  | 表示包含值的单元格区域的引用，例如"A1:A4". |
|  *boxPlotClass *  | Q1–>25% 百分位, Q3–>75% 百分位, IQR-->Q3-Q1. |
| 5ns: 须在最小值和最大值处结束，中间值，无异常值。 |
| 7ns: 须在 2% 和 98% 处结束，影线在 9% 和 91% 处结束，异常值在 2% 和 98% 处结束 |
| tukey: 须结束于一个值（Q1 和 Q1 之间的点的最小值 - 1.5*IQR，如果存在则使用该点或使用最小值）和一个值（Q3 和 Q3 之间的点的最大值 + 1.5 * IQR ，如果存在则使用该点或使用最大值），超出 Q1 - 1.5*IQR 和 Q3 + 1.5 * IQR 的异常值，以及超出 Q1 - 3 * IQR 和 Q3 + 3 * IQR 的极端异常值。 |
| bowley: 须在最小值和最大值处结束，孵化标记在 10% 和 90% 百分位，没有异常值。 |
| sigma3: 须以一个值（平均值 - 2 * StDev > scaleStart ? average - 2 * StDev : minimum）和一个值（平均值 + 2 * StDev < scaleEnd ? average = 2 * StDev : 最大值）结束，盒子平均 +/ - 标准偏差，超出平均值的异常值 - 2 * 标准偏差和平均值 + 2 * 标准偏差，以及超出平均值的极端异常值 - 3 * 标准偏差和平均值 + 3 * 标准偏差。 |
|  *showAverage *  | (可选) 一个布尔值，表示是否显示平均值。默认值为FALSE. |
|  *scaleStart *  | (可选) 代表迷你图最小边界的数字或参考，例如 1 或“A6”。默认值是所有值中的最小值。 |
|  *scaleEnd *  | (可选) 代表迷你图最大边界的数字或参考，例如 8 或“A7”。默认值是所有值中的最大值。 |
|  *acceptableStart *  | (可选) 表示可接受行开头的数字或参考，例如 3 或“A8”。默认值为None. |
|  *colorScheme *  | (可选) 表示迷你图框颜色的字符串。默认值为"#D2D2D2". |
|  *style *  | (可选) 代表迷你图样式的数字或参考。此设置是可选的。默认值为0 (Classical). 样式可以是 0 或 1。<br /><br /> |
|  *vertical *  | (可选) 一个布尔值，表示是否垂直显示迷你图。默认值为FALSE. |



#### 数据类型

返回sparkline.



#### 例子

activeSheet.setFormula(0,1,'=BOXPLOTSPARKLINE(C1:P1,"5ns",TRUE,0,100,-1,100,"red",0,FALSE)');
