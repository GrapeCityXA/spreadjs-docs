# VARISPARKLINE

此函数返回用于表示方差迷你图的数据集。



#### 语法

VARISPARKLINE( *variance, [reference, mini, maxi, mark, tickunit, legend, colorPositive, colorNegative, vertical]* )



#### 参数

| 参数 | 描述 |
|--- |--- |
|  *variance*  | 表示条形长度的数字或引用，例如 2 或“A1”。 |
|  *reference*  | (可选) 表示参考线位置的数字或引用，如0或“A2”。默认值为0。 |
|  *mini*  | (可选) 表示迷你图最小值的数字或引用，例如 -5 或“A3”。默认值为 -1。 |
|  *maxi*  | (可选) 表示迷你图最大值的数字或引用，例如 5 或“A4”。默认值为 1。 |
|  *mark*  | (可选) 表示标记线位置的数字或引用，例如 3 或“A5”。 |
|  *tickunit*  | (可选)  表示刻度单位的数字或引用，例如 1 或“A6”。默认值为 0。 |
|  *legend*  | (可选)一个布尔值，表示是否显示文本。默认值为false. |
|  *colorPositive*  | (可选) 一个字符串，表示方差的颜色方案并且大于参考。默认值为"green". |
|  *colorNegative*  | (可选)一个字符串，表示方差的配色方案并且小于参考。默认值为 "red". |
|  *vertical*  | (可选)一个布尔值，表示是否垂直显示迷你图。默认值为false. |



#### 数据类型

返回sparkline.



#### 例子

activeSheet.setFormula(0,1,'=VARISPARKLINE(3,0,-5,5,0.5,0.5,TRUE,"green","red",FALSE)');
