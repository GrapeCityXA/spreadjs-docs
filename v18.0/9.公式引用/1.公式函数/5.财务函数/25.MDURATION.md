# MDURATION

此函数返回假设面值 ￥100 的有价证券的 Macauley 修正期限。



#### 语法

MDURATION( *settlement* , *maturity* , *coupon* , *yield* , *frequency* , *basis* )



#### 参数

该函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *settlement*  | 有价证券的结算日。 |
|  *maturity*  | 有价证券的到期日。 |
|  *coupon*  | 有价证券的年息票利率。 |
|  *yield*  | 有价证券的年收益率。 |
|  *frequency*  | 年付息次数。 如果按年支付，frequency = 1；按半年期支付，frequency = 2；按季支付，frequency = 4。 |
|  *basis*  | [可选] 要使用的日计数基准类型。 请参考[Day Count Basis](gcdocsite__documentlink?toc-item-id=23b72e94-94be-44ed-9302-d582747f59dd)。 |



#### 注释

如果settlement或maturity不是有效日期，则 MDURATION 返回 #VALUE！ 。

如果 frequency 是除1、2或4以外的任何数字，MDURATION 返回 #NUM！ 。

如果 yield < 0 或 coupon < 0，MDURATION 返回 #NUM！ 。

如果settlement≥maturity，MDURATION 将返回 #NUM！ 。



#### 数据类型

接受数值和DateTime对象数据。返回数值数据。



#### 示例

MDURATION(A1,B2,C3,D4,E5,F6)
