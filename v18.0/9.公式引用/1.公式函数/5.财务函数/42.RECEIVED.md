# RECEIVED

此函数返回一次性付息的有价证券到期收回的金额。



#### 语法

RECEIVED( *settle* , *mature* , *invest* , *discount* , *basis* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *settle*  | 有价证券的结算日。 |
|  *mature*  | 有价证券的到期日。 |
|  *invest*  | 有价证券的投资额。 |
|  *discount*  | 有价证券的贴现率。 |
|  *basis*  | [可选] 要使用的日计数基准类型。请参考[Day Count Basis](gcdocsite__documentlink?toc-item-id=23b72e94-94be-44ed-9302-d582747f59dd)。 |



#### 注释

如果 settle、maturity不是有效日期，则返回 错误值 #VALUE!。

settle、maturity和 basis 将被截尾取整。

如果 invest <= 0 或 discount <= 0，则返回错误值 #NUM!。

如果 basis < 0 或 basis > 4，则返回错误值 #NUM!。

如果 settle ≥ maturity，则返回 错误值 #NUM!。



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

RECEIVED(A1,B2,C3,C4,1)

RECEIVED("3/01/2004","6/01/2004",600000,0.03,2) gives $604,635.50
