# EFFECT

此函数利用给定的名义年利率和每年的复利期数，计算有效的年利率。



#### 语法

EFFECT( *nomrate* , *comper* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *nomrate*  | 名义利率。 |
|  *comper*  | 每年的复利期数。 如果不是整数，则将截尾取整。 |



#### 注释

如果任一参数为非数值型，则 EFFECT 返回 #VALUE！ 。如果 nomrate ≤0或 comper < 1，则 EFFECT 返回 #NUM！ 。



#### 数据类型

接受两个参数的数值数据。返回数值数据。



#### 示例

EFFECT(J12,B3)

EFFECT(R12C10,R3C2)

EFFECT(6.5%,8) 得出结果 0.66878782
