# CUMIPMT

此函数返回一笔贷款在给定的 startperiod 到 endperiod 期间累计偿还的利息数额。



#### 语法

CUMIPMT( *rate* , *nper* , *pval* , *startperiod* , *endperiod* , *paytype* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *rate*  | 利率。 |
|  *nper*  | 总付款期数。 |
|  *pval*  | 现值。 |
|  *startperiod*  | 计算中的首期。 |
|  *endperiod*  | 计算中的末期。 |
|  *paytype*  | 付款时间类型： |
|  | 0 - 期末付款 |
|  | 1 - 期初付款 |



#### 注释

如果 rate ≤0、nper ≤0或 pval ≤0，CUMIPMT 将返回 #NUM！ 。

如果 startperiod < 1、endperiod < 1 或 startperiod > endperiod，则 CUMIPMT 返回 #NUM！ 。

如果 paytype 不是0或1以外的任何数字，CUMIPMT 将返回 #NUM！ 。



#### 数据类型

接受数值和DateTime对象数据。返回数值数据。



#### 示例

CUMIPMT(B2/12,B4*12,C4,14,20,0)

CUMIPMT(B2/12,B4*12,C4,14,20,0)
