# TBILLPRICE

此函数返回面值 ￥100 的国库券的价格。



#### 语法

TBILLPRICE( *settle* , *mature* , *discount* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *settle*  | 国库券的结算日。 |
|  *mature*  | 国库券的到期日。 |
|  *discount*  | 国库券的贴现率。 |



#### 注释

如果 settle、settle不是有效日期，则返回 错误值 #VALUE!。

settle、mature将被截尾取整。

如果 discount <= 0 ，则返回错误值 #NUM!。

如果settle > settle或结算后的到期日超过一年, 返回 #NUM! 错误值。



#### 数据类型

接受所有参数的数值和日期时间对象数据。返回数值数据。



#### 示例

TBILLPRICE(A1,B2,C3)

TBILLPRICE("3/31/2003","6/1/2003",0.065)得出结果 $98.88055556
