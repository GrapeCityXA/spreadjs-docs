# HYPGEOM.DIST

此函数返回超几何分布。



#### 语法

HYPGEOM.DIST( *x* , *n* , *M* , *N,cumulative* )



#### 参数

参数如下，如果不是整数则截尾取整：:

| 参数 | 描述 |
|--- |--- |
|  *x*  | 样本中成功的次数。 |
|  *n*  | 样本量。 |
|  *M*  | 总体中成功的次数。 |
|  *N*  | 总体大小。 |
|  *cumulative*  | 决定函数形式的逻辑值。 如果 cumulative 为 TRUE，则 HYPGEOM.DIST 返回累积分布函数；如果为 FALSE，则返回概率密度函数。 |



#### 注释

如果任一参数为非数值型，则 HYPGEOM.DIST 返回 错误值 #VALUE!。



#### 数据类型

除cumulative参数以外，接受其他参数的数值数据。返回数值数据。



#### 示例

HYPGEOM.DIST(A22,B23,62,1000,C10)

HYPGEOM.DIST(R22C11,R22C12,R34C14,R35C15,R10C5)

HYPGEOM.DIST(2,37,6,100,200) 得出结果 0.6079646750428083
