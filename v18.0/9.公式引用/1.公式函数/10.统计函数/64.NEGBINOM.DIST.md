# NEGBINOM.DIST

此函数返回负二项式分布。



#### 语法

NEGBINOM.DIST( *x* , *r* , *p,cumulative* )



#### 参数

该函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *x*  | 失败的次数。 |
|  *r*  | 成功次数的阈值。 |
|  *p*  | 成功的概率，值介于0至1。 |
|  *cumulative*  | 决定函数形式的逻辑值。 如果 cumulative 为 TRUE，则 LOGNORM.DIST 返回累积分布函数；如果为 FALSE，则返回概率密度函数。 |



#### 注释

如果 p < 0 或 p > 1，NEGBINOM.DIST返回 #NUM！ 。

如果 x < 0 或 r < 1，NEGBINOM.DIST 返回 #NUM！ 。



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

NEGBINOM.DIST(B1,C15,0.335,TRUE)

NEGBINOM.DIST(R1C2,R15C3,0.75,TRUE)

NEGBINOM.DIST(4,13,0.85,TRUE) 得出结果 0.9012900017858557
