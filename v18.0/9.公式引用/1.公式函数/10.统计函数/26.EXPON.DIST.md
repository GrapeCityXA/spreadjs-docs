# EXPON.DIST

此函数返回指数分布。



#### 语法

EXPON.DIST( *value* , *lambda* , *cumulative* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *value*  | 函数值，必须>=0。 |
|  *lambda*  | 参数值，必须>0。 |
|  *cumulative*  | 逻辑值，用于指定指数函数的形式。 如果 cumulative 为 TRUE，则 EXPON.DIST 返回累积分布函数；如果为 FALSE，则返回概率密度函数。 |



#### 注释

使用 EXPON.DIST 可以建立事件之间的时间间隔模型，如银行自动提款机支付一次现金所花费的时间。 例如，可通过 EXPON.DIST 来确定这一过程最长持续一分钟的发生概率。

#### 数据类型

第三个参数接受逻辑值，除此之外的其他参数接受数值数据。返回数值数据。



#### 示例

EXPON.DIST(C12,10,TRUE)

EXPON.DIST(R12C3,8,FALSE)

EXPON.DIST(0.2,10,TRUE) 得出结果 0.8646647167633873
