# T.DIST.RT

此函数返回t分布



#### 语法

T.DIST.RT( *x* , *deg* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *x*  | 需要计算分布的数值。 |
|  *deg*  | 一个表示自由度数的整数 |



#### 注释

如果任何参数为非数值型，则此函数返回 #VALUE！ 。



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

T.DIST.RT(A1,B45)

T.DIST.RT(0.245,2) 得出结果 0.41465072364379996
