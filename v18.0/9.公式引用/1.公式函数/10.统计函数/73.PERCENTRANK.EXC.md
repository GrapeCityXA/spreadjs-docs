# PERCENTRANK.EXC

此函数返回某个数值在一个数据集中的百分比（0 到 1，不包括 0 和 1）排位。



#### 语法

PERCENTRANK.EXC( *array* , *n* , *sigdig* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *array*  | 定义相对位置的数值数组或数值数据区域。 |
|  *n*  | 需要得到其排位的值。 |
|  *sigdig*  | [可选] 用于标识返回的百分比值的有效位数的值。 if omitted, the calculation used three significant digits |



#### 注释

如果 array 为空，则返回 #NUM！。

如果 sigdig < 1，返回 #NUM！。



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

PERCENTRANK.EXC(A1:A12,0.95)

PERCENTRANK.EXC(R1C1:R1C45,0.866)

PERCENTRANK.EXC(A1:A17,23,3)

PERCENTRANK.EXC(R1C1:R43:C1,255.4,2)

PERCENTRANK.EXC({10,12,13,14,14,14.5,16,17.5,17.75,20,22},18,1) 得出结果 0.8
