# PERCENTILE.EXC

此函数返回区域中数值的第 k 个百分点，其中 k 的范围为0到1，介于0和1之间。



#### 语法

PERCENTILE.EXC( *array* , *k* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *array*  | 定义相对位置的数组或数据区域。 |
|  *k*  | 0 到 1 之间的百分点值，包含 0 和 1。 |



#### 注释

如果 array 为空，返回 #NUM！ 错误值。

如果 k 为非数值型，则返回 #VALUE！ 。

如果 k≤0 或 k ≥1，返回 #NUM！ 。

如果 k 不是 1/（n + 1）的倍数，则该函数插以确定第 k 个百分点的值。

当指定的百分点值位于数组中的两个值之间时，PERCENTILE.EXC 将会插入。如果函数不能为指定的百分点值进行内插，则返回#NUM！。



#### 数据类型

接受两个参数的数值数据。返回数值数据。



#### 示例

PERCENTILE.EXC(A1:A12,0.95)

PERCENTILE.EXC(R1C1:R1C45,0.866)

PERCENTILE.EXC({5,15,25,50,65},0.45) 得出结果 22
