# Z.TEST

此函数返回 z 检验的单尾 P 值。



#### 语法

Z.TEST( *array* , *x* , *sigma* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *array*  | 用来检验 x 的数组或数据区域。 |
|  *x*  | 要测试的值。 |
|  *sigma*  | [可选]  总体（已知）标准偏差。 |



#### 注释

如果未指定标准差，则使用样本标准偏差。

计算公式如下，n为数据点个数。

#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

Z.TEST(A2:D12,40,0.877)

Z.TEST(R2C1:R12C4,2)

Z.TEST({5,10,15,12,11,8,16,7},10) 得出结果 0.355512703503418

Z.TEST({5,10,15,12,11,8,16,7},10,3) 得出结果 0.31867594409823696
