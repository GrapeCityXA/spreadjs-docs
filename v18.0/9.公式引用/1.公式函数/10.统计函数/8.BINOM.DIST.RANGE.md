# BINOM.DIST.RANGE

此函数使用二项式分布返回试验结果的概率。



#### 语法

BINOM.DIST.RANGE( *N,p,s,s2* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *N*  | 独立试验次数。 必须大于或等于 0。 |
|  *p*  | 每次试验成功的概率。 必须大于或等于 0 并小于或等于 1。 |
|  *s*  | 试验成功次数。 必须大于或等于 0 并小于或等于N。 |
|  *s2*  | [可选] 如提供，则返回试验成功次数将介于s 和 s2 之间的概率。 必须大于或等于 s 并小于或等于 N。 |



#### 注释

此函数中的所有数值参数都将截尾取整。

如果任何参数超出其限制范围，则 BINOM.DIST.RANGE 返回错误值 #NUM! 。



#### 数据类型

接受所有参数的数值数据。 返回数值数据。



#### 示例

BINOM.DIST.RANGE(50,0.35,28) 得出结果 0.00116

BINOM.DIST.RANGE(30,0.25,15,25) 得出结果 0.00274
