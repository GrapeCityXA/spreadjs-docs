# BC_QRCODE

此函数返回一个表示二维码（QRCode）的数据集。

## 语法

`BC_QRCODE(value, color, backgroundColor, errorCorrectionLevel, model, version, mask, connection, connectionNo, charCode, charset, quietZoneLeft, quietZoneRight, quietZoneTop, quietZoneBottom)`

## 参数

| 参数 | 说明 |
| ---- | ---- |
| *value* | 一个表示在二维码符号上进行编码内容的字符串。 |
| *color* | 表示条形码颜色的一种颜色。默认值为 'rgb(0,0,0)'。 |
| *backgroundColor* | 表示条形码背景颜色的一种颜色。默认值为 'rgb(255, 255, 255)'。 |
| *errorCorrectionLevel* | 一个表示二维码纠错级别的字符串。其值有 'L'。 |
| *model* | 一个表示二维码型号的值。有 1 和 2 两种型号。默认值为 2。 |
| *version* | 对于型号 1 和型号 2，版本范围是 1 到 14。其值有 'auto'（自动）。 |
| *mask* | 一个表示二维码掩码图案的值。有 'auto'（自动）和 0 到 7 这八种掩码图案。 |
| *connection* | 一个表示该符号是否为结构化追加消息一部分的值。默认值为 false（否）。 |
| *connectionNo* | 指定该符号在结构化追加消息中处于哪个块。其值范围是 '0 到 15'。默认值为 '0'。 |
| *charCode* | 一个表示二维码字符集合的值。 |
| *charset* | 一个表示使用哪种字符集的值。其值有 'UTF-8' 和 'Shift-JIS'。 |
| *quietZoneLeft* | 一个表示左侧空白区大小的值。 |
| *quietZoneRight* | 一个表示右侧空白区大小的值。 |
| *quietZoneTop* | 一个表示顶部空白区大小的值。 |
| *quietZoneBottom* | 一个表示底部空白区大小的值。 |

## 数据类型

接受数字字符和字母数字字符。返回条形码迷你图。

## 示例

`sheet.setFormula(3, 3, '=BC_QRCODE(C4)');`
