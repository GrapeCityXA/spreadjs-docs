# agrregate

AGGREGATE函数用于返回列表或数据库中的聚合值。用户可以对列表应用不同的聚合函数，如COUNT（计数）、AVERAGE（平均值）、SUM（求和）、MAX（最大值）、MIN（最小值）等，同时忽略电子表格中的“错误值”和“隐藏行”。
AGGREGATE函数特别适用于以下情况：
 - 用户想要对数据应用筛选器，并且在对所有值求和时需要忽略通过筛选器隐藏的单元格。
 - 用户想要阻止错误在整个工作表中传播。
 - 用户想要处理数据，例如在忽略诸如“返回无效数字”等错误或其他类型的错误时，求多个公式结果的平均值。

### 语法
在使用AGGREGATE函数时，用户可使用以下语法：
 - `AGGREGATE(function_num, options, ref1, [ref2], …)`
此语法仅适用于“function_num”参数值范围为1到13的情况。详情请参考下表。
 - `AGGREGATE(function_num, options, array, k)`
此语法仅适用于“function_num”参数值范围为14到19的情况。详情请参考下表。

### 参数
该函数具有以下参数：
|参数|说明|
| ---- | ---- |
|*Function_num*|[必需]，指（范围在1 - 19内）用于指定所使用函数的数字。|
|*Options*|[必需]，指用于指定函数中忽略值选项的特定数字。|
|Ref1|[必需]，指定对单元格区域的引用。|
|Ref2|[可选]，指定对单元格区域的引用。|
|array|[仅当上述“function_num”参数值范围为14到19时必需]，指定一个数组、数组公式或对单元格区域的引用。|
|k|[必需]，当“function_num”值范围为14 - 19时，此参数用于指定函数。|

在使用AGGREGATE函数时，必须牢记以下几点：
 - 如果未提供参数array、k或ref1，AGGREGATE函数将返回#VALUE!错误。
 - 如果参数k以数组形式提供，则使用第一个值。如果参数k以单列单元格引用形式提供，则使用最后一行的值。（例如：{1,2,3,4} => 1，A1:A23 => A23，A1:B23 => #VALUE!，A1:C1 => #VALUE!）
 - 引用不支持三维引用。如果使用三维引用，函数将返回#VALUE!（例如：“Sheet1:Sheet3!B3”将返回#VALUE错误）。
 - “忽略隐藏”不支持隐藏列。
 - 通过筛选/隐藏/分组操作隐藏的行将支持忽略功能。
 - 如果数组包含计算，AGGREGATE函数将不会忽略隐藏行。（例如：“=AGGREGATE(14,3,A1:A6*123,1)”）

### 数据类型
接受数值列表或数据库。返回诸如平均值、计数、最小值、最大值等聚合计算结果，同时忽略隐藏行和错误。
