# ISTEXT

此函数检验引用单元格的值，表达式或内容是否为文本。



#### 语法

ISTEXT( *cellreference* )

ISTEXT( *value* )

ISTEXT( *expression* )



#### 参数

参数可以是单元格引用，数字或文本值或表达式。



#### 注释

使用此功能可以测试单元格、数字、文本值、函数或表达式的内容。

如果参数的数据类型是文本，则此函数返回TRUE。如果参数的数据类型不是文本，则此函数返回FALSE。如果参数引用一个空单元格，则此函数返回FALSE。



#### 数据类型

接受参数的任何数据类型。返回布尔（TRUE或FALSE）数据。



#### 示例

ISTEXT(B3)

ISTEXT(R1C2)

ISTEXT("Total") 得出结果 TRUE

ISTEXT(12) 得出结果 FALSE
