# ERRORTYPE

返回对应的错误值之一的数字



#### 语法

ERROR.TYPE( *errorvalue* )



#### 参数

此处总结了可以在参数中使用的有效错误值及其相应的返回值：

| 如果 errorvalue | 函数 ERROR.TYPE 返回 |
|--- |--- |
| #NULL! | 1 |
| #DIV/0! | 2 |
| #VALUE! | 3 |
| #REF! | 4 |
| #NAME? | 5 |
| #NUM! | 6 |
| #N/A | 7 |



#### 注释

您可以使用 IF 函数中的 ERROR.TYPE 测试错误值并返回一个文本字符串（例如消息）而非错误值。



#### 数据类型

接受错误值作为数据。返回数值数据。



#### 示例

ERROR.TYPE(B13)

ERROR.TYPE(R13C2)

ERROR.TYPE(#REF!) 得出结果 4
