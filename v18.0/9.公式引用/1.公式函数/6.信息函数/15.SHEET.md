# SHEET

该函数返回引用sheet的sheet数字



#### 语法

SHEET( *value* )



#### 参数

| 参数 | 描述 |
|--- |--- |
|  *value*  | (可选) 要检查的值 |



#### Remarks

- SHEET函数包括编号序列中的隐藏工作表。
- SHEET 函数接受一个参数 value，它应该是一个引用、一个命名区域或一个 SpreadJS 表。
- 省略 value 时，SHEET 将返回当前工作表的数字索引



#### 数据类型

返回sheet的下标数字



#### 例子

=SHEET(Sheet1!A1) // 返回 1
