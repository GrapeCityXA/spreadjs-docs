# ISERROR

此函数检验引用单元格的值，表达式或内容是否为任意错误值。



#### 语法

ISERROR( *cellreference* )

ISERROR( *value* )

ISERROR( *expression* )



#### 参数

参数可以是单元格引用，数字或文本值或表达式。



#### 注释

使用此功能可以测试单元格、数字、文本值、函数或表达式的内容。

如果value引用的是空单元格或没有数据，则此函数返回TRUE。



#### 数据类型

接受参数的任何数据类型。返回布尔（TRUE或FALSE）数据。



#### 示例

ISERROR(B12)

ISERROR(R12C2)

ISERROR(#N/A) 得出结果 TRUE

ISERROR(#REF!) 得出结果 TRUE

ISERROR(C14) 得出结果 TRUE if C14 contains a #NUM! error.
