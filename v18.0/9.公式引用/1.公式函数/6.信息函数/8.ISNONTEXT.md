# ISNONTEXT

此函数检验引用单元格的值，表达式或内容是否不是文本的任意项。



#### 语法

ISNONTEXT( *cellreference* )

ISNONTEXT( *value* )

ISNONTEXT( *expression* )



#### 参数

参数可以是单元格引用，数字或文本值或表达式。



#### 注释

使用此功能可以测试单元格、数字、文本值、函数或表达式的内容。

如果值是或引用空白单元格，则此函数返回TRUE。



#### 数据类型

接受参数的任何数据类型。返回布尔（TRUE或FALSE）数据。



#### 示例

ISNONTEXT(A3)

ISNONTEXT(R3C1)

ISNONTEXT(12) 得出结果 TRUE

ISNONTEXT("Total") 得出结果 FALSE
