# EDATE

此函数返回表示某个日期的序列号，该日期与指定日期 (start_date) 相隔（之前或之后）指示的月份数。



#### 语法

EDATE( *startdate* , *months* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *startdate*  | 开始日期 |
|  *months*  | startdate 之前或之后的月份数。如果不是整数，则将截尾取整。 |



#### 注释

使用函数 EDATE 可以计算与发行日处于一月中同一天的到期日的日期。



#### 数据类型

startdate参数接受数值，字符串或DateTime对象数据，months参数接受数值数据。返回一个DateTime对象。



#### 示例

EDATE(A1,-6)

EDATE(R1C1,4)

EDATE("2004/01/09",2) 得出结果 3/9/2004 12:00:00 AM
