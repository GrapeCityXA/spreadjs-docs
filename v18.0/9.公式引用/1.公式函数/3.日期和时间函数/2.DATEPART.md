# datepart-function

此函数返回由年、月和日指定的特定日期的日期对象。



### 语法

DATEPART ( *date_value* , *format_string* , [ *week_num_type* ] )



### 参数

| 参数 | 描述 |
|--- |--- |
| date_value | (必须)日期值。 |
| format_string | (必须) 日期格式字符串 |
| [week_num_type] | (可选)与WEEKNUM函数的第二个参数相同。 |



### 注释

可以使用此功能对字段分组。

下表显示了可用于DATEPART公式的不同格式字符串：

| 格式 | 结果 | 描述 |
|--- |--- |--- |
| yyyQ | 20214 | 数值：最后一位表示季度名 |
| yyyQQ | 202104 | 数值： 季度用两位数字表示，补0扩展 |
| yyyyQQQ | 2021Q4 | 季度简写 |
| yyyy QQQQ | 2021 4th quarter | 季度详细描述 |
| YYYY w | 2021 8 | 数值：最后一位表示一年中的第几周<br /><br />当在带有年份的模式中使用时，年份用“Y”表示。<br /><br /> |
| YYYY ww | 2021 08 | 数值: 最后两位表示周，不足两位时补0 |
| MM-yyyy | 09-2021 | Provide partial date formatter in cell formatting. |



### 数据类型

接收字符串类型，返回日期类型。



### 示例

下面的示例代码显示了DATEPART函数的基本用法。


```JavaScript
sheet.groupBy([
    {
        caption: "Company Name", field: "Customers.CompanyName", width: 160,
    },
    {
        caption: "Year Quarter", field: `=DATEPART([@OrderDate],"yyyyQQQ")`, width: 160,
    }
]);
```
