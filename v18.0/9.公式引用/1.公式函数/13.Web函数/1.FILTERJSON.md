# filterjson

此函数从 JSON 字符串解析数据。



#### 语法

FILTERJSON( *json_string* )



#### 参数

此函数具有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *json_string*  | [必需] 有效格式的 JSON 字符串数据。 |



#### 备注：

如果 JSON 字符串的格式无效，则返回 #VALUE！错误。下面显示了一些具有预期结果的示例：

| JSON String | Formula | Result |
|--- |--- |--- |
| {"a": 123} | FILTERJSON("{""a"": 123}") | [object Object] |
| "123" | FILTERJSON("123") | 123 |
| [1,2, "string"] | FILTERJSON([1,2,"string"]) | #VALUE! |
| {a: 123} | FILTERJSON("{a: 123}") | #VALUE! |
| '[1, "string", {"a": 123}]' | FILTERJSON("[1, ""string"", {""a"": 123}]") | 1 | string | [object Object] |



#### 数据类型

接受字符串数据。返回标量值、对象或对象数组。



#### 示例

您可以从 JSON 字符串解析数据。


```JavaScript
var json_string = `{
    "store": {
        "book": [
            {
                "category": "reference",
                "author": "Nigel Rees",
                "title": "Sayings of the Century",
                "price": 8.95
            },
            {
                "category": "fiction",
                "author": "Evelyn Waugh",
                "title": "Sword of Honour",
                "price": 12.99
            },
            {
                "category": "fiction",
                "author": "Herman Melville",
                "title": "Moby Dick",
                "isbn": "0-553-21311-3",
                "price": 8.99
            },
            {
                "category": "fiction",
                "author": "J. R. R. Tolkien",
                "title": "The Lord of the Rings",
                "isbn": "0-395-19395-8",
                "price": 22.99
            }
        ],
        "bicycle": {
            "color": "red",
            "price": 19.95
        }
    },
    "expensive": 10
}`;
sheet.setValue(4,0,json_string);
sheet.setFormula(5,0,'=FILTERJSON(A5)');
sheet.setFormula(6,0,'=PROPERTY(A6,"store.book.0.title")'); // "Sayings of the Century"
```

您可以使用带有嵌套[WEBSERVICE](gcdocsite__documentlink?toc-item-id=582e76fb-72a1-4065-8356-4d6378161a95)函数的FILTERJSON函数来解析包含 JSON 数据的 URL。可以使用[PROPERTY](gcdocsite__documentlink?toc-item-id=e1c9ff0a-e7c0-4864-97db-bd857e1e81e6)函数显示解析后的数据 。


```JavaScript
sheet.setFormula(0,0,'=FILTERJSON(WEBSERVICE("https://cors-demo.glitch.me/allow-cors"))'); // WEBSERVICE 获取json数据。
sheet.setFormula(1,0,'=PROPERTY(A1,"message")'); // "You are handling CORS like a pro!"

spread.options.allowDynamicArray = true; // allow dynamicArray
sheet.setFormula(2,0,'=FILTERJSON(WEBSERVICE("https://restcountries.eu/rest/v2/name/Japan"))'); // WEBSERVICE 获取json数据。
sheet.setFormula(3,0,'=PROPERTY(A3,"name")'); // "Japan"
```
