# IFERROR

可以使用 IFERROR 函数捕获和处理公式中的错误。



#### 语法

IFERROR( *value* ,error)



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *value*  | 要比较的值或表达式 |
|  *error*  | 公式计算错误时返回的值。 |



#### 注释

计算以下错误类型： #N/A、#VALUE！、#REF！、#DIV/0！、#NUM！、#NAME？或 #NULL！。



#### 数据类型

接受该值的任何类型的公式。返回任何数据类型。



#### 示例

IFERROR(A3/A5,"dogs")
