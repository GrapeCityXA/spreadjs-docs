# AND

是一个逻辑函数，用于确定测试中的所有条件是否均为 TRUE。



#### 语法

AND( *bool1* , *bool2* ,...)

AND( *array* )

AND( *array1* , *array2* ,...)

AND( *expression* )

AND( *expression1* , *expression2* ,...)



#### 参数

对于此函数的参数，请最多指定255个参数，例如数字（0或1）或逻辑值（TRUE或FALSE）。您也可以指定一个数组，而不必单独列出值，也可以指定最多255个数组。您也可以将逻辑参数指定为表达式。



#### 注释

如果其所有参数都为true，则此函数返回TRUE；如果至少一个参数为false，则返回FALSE。



#### 数据类型

支持逻辑值(TRUE 或 FALSE) 或数字 (0 or 1)。返回逻辑值(TRUE 或 FALSE)。



#### 示例

AND(D12,E12)

AND(R12C42,R12C5,R12C1)

AND(D2:D12)

AND(R12C1:R12C9)

AND(true,true,true) 得出结果 TRUE

AND(TRUE(),FALSE()) 得出结果 FALSE

AND(5+3=8,5+1=6) gives the result TRUE
