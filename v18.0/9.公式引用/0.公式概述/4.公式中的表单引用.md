# SheetRefFormula

一个公式可以引用同一工作表中的单元格、其他工作表中的单元格，以及工作表中的单元格区域。
在下面展示的示例中，我们使用 A1（字母-数字）表示法来引用单元格，但对于 R1C1（数字-数字）表示法来说，同样的规则也适用。无论使用哪种表示法风格，只需如这里所述，在单元格引用前加上工作表名称即可。
## 跨工作表引用
当对单元格的引用包含对另一个工作表中单元格的引用时，这就称为跨工作表引用。
在一个使用加法运算符的公式中，跨工作表引用的一个示例如：
`(FirstRoundData!A2 + SecondRoundData!A2)`
其中一个工作表的名称是 “FirstRoundData”，另一个工作表的名称是 “SecondRoundData”。工作表名称在单元格引用之前，工作表名称后面跟着一个感叹号 (!)。
这个公式可以位于 Spread 中的任何工作表上，因为它明确指定了每个单元格所在的工作表作为操作数。这个示例将两个不同工作表中 A2 单元格的值相加。通过明确工作表名称，就不会对所指的是哪个 A2 单元格产生混淆。如果不包含工作表名称，则会使用当前工作表（即公式所在的工作表）。
如果上述示例中的公式位于 SecondRoundData 工作表上，那么该公式可以写成：
`(FirstRoundData!A2 + A2)`
如果把当前工作表上的单元格写在前面，可能会减少混淆，如下所示：
`(A2 + FirstRoundData!A2)`
只要工作表名称符合常规的变量名规则（首字符为字母或下划线，其余字符为字母、数字或下划线），那么公式就可以直接使用工作表名称加上感叹号。否则，工作表名称需要用单引号括起来。如果工作表名称本身包含一个单引号，那么在公式中就要使用两个单引号。
例如，如果工作表的名称包含一个单引号（或撇号），比如给定月份的销售工作表名称，那么在公式中对该工作表的引用会是这样的：
`('November''s Sales'!A2 + 'December''s Sales'!A2)`
在 “s” 前面有两个单引号（或撇号）。如果工作表名称中有空格，就在工作表名称周围使用单引号。在下面的示例中，工作表名称是 East Coast Sales。
`('East Coast Sales'!A2 + 'West Coast Sales'!A1)`
如果工作表名称中有引号，就需要添加该语言所需的分隔符。例如，在 C# 中，如果工作表名称是 “Zippy” Sales，其中引号是工作表名称的一部分，那么包含对该工作表引用的公式可能会是这样的：
`('/"Zippy/" Sales'!A2 + 'West Coast Sales'!A1)`
其中整个工作表名称用单引号括起来，反斜杠 (/) 分隔符在引号之前。
对于 Visual Basic，你需要使用两个双引号字符，如下所示：
`('""Zippy"" Sales'!A2 + 'West Coast Sales'!A1)`
要跨工作表引用另一页上的单元格区域，在该区域前加上工作表名称即可。例如：
`SUM(SecondRoundData!A2:A10)`
这会将名为 `SecondRoundData` 的工作表中 A2 到 A10 单元格的值相加。在区域引用的后半部分没有必要包含工作表名称，因为这些单元格都在同一张工作表上。你不能在一个区域中指定两个不同的工作表；单元格区域只存在于特定的一张工作表上，而不是跨工作表的。
