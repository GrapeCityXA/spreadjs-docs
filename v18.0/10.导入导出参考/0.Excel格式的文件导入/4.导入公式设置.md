# excelformimp

此表总结了 SpreadJS 从 Excel 文件导入数据时，与公式相关的单元格设置是如何处理的。

| **Excel 设置** | **SpreadJS 设置** | **备注** |
| -------- | ----------- | --- |
| 单元格引用样式 | [referenceStyle](gcdocsite__documentlink?toc-item-id=cbd0a51d-62f0-48b0-8fb7-1855088c327f) | 如果 Excel 的引用样式是 R1C1，当 Spread 导入电子表格时，`Sheet.setColumnHeaderAutoTest` 函数会被设置为 1（显示数字）。请参阅此表中的公式备注。 |
| 公式 | [CellRange.formula](gcdocsite__documentlink?toc-item-id=64f05fd4-fafa-47dc-9856-b74263f357ec#formula) | 公式从 Excel 导入到 SpreadJS 中。<br>Excel 设置中的 “单元格引用”、“运算符” 和 “函数” 也作为公式的一部分被导入。 |
| 隐藏公式 | [Style.hidden](gcdocsite__documentlink?toc-item-id=1a4e9265-6694-48bb-b0fc-15e5ab238a26#hidden)<br>[CellRange.hidden](gcdocsite__documentlink?toc-item-id=64f05fd4-fafa-47dc-9856-b74263f357ec#hidden) | 导入包含隐藏公式单元格的 Excel 文件。<br>请注意，隐藏属性不会影响通过 API 访问的公式。 |
