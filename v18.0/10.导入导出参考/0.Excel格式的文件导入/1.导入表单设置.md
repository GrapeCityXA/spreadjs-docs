# excelwhimp

此表总结了 SpreadJS 从 Excel 格式文件导入数据时如何处理工作表设置。除非另有说明，这些设置均为 GC.Spread.Sheets.Worksheet 类的成员。

| **Excel 设置** | **SpreadJS 设置** | **备注** |
| -------- | ----------- | --- |
| 工作表 工作表名称 | SpreadJS Spread.name | SpreadJS 从 Excel 导入此设置。 |
| 默认宽度 | Sheet.defaults.colWidth | SpreadJS 从 Excel 导入此设置。 |
| 冻结窗格 | Sheet.**frozenRowCount** 或 Sheet.**frozenColumnCount** | SpreadJS 从 Excel 导入此设置。 |
| 数据 |  | SpreadJS 从 Excel 加载数据。 |
| 迷你图 | Sheet.[setSparkline](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#setsparkline) | SpreadJS 从 Excel 导入此设置。 |
| 合并单元格 | Sheet.[addSpan](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#addspan) | SpreadJS 从 Excel 加载所有合并单元格信息。 |
| 活动单元格 | Sheet.[setActiveCell](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#setactivecell) | SpreadJS 从 Excel 导入数据时设置活动单元格。 |
| 选区 | Sheet.[setSelection](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#setselection) | SpreadJS 从 Excel 导入数据时设置选区。 |
| 网格线 | Sheet.**options.gridline** | SpreadJS 从 Excel 导入此设置。 |
| 缩放 | Sheet.[zoom](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#zoom) | SpreadJS 从 Excel 导入数据时保留缩放比例。 |
| 主题 | Sheet.[currentTheme](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#currenttheme) | SpreadJS 从 Excel 导入此设置。 |
| 条件格式 | Sheet.[ConditionalFormats](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#conditionalformats) | SpreadJS 从 Excel 导入数据时加载所有条件格式。 |
| 选项卡颜色 | Sheet.**options.sheetTabColor** | SpreadJS 从 Excel 导入此设置。 |
| 工作表已保护 | Sheet.**options.isProtected** | SpreadJS 从 Excel 导入此设置。 |
| 表格 | Sheet.tables.[add](gcdocsite__documentlink?toc-item-id=df2be8fa-7823-4002-b22a-18e2a1499d7a#add) | SpreadJS 从 Excel 导入数据时加载所有表格。 |
| 区域分组 | Sheet.rowOutlines 或 Sheet.columnOutlines | SpreadJS 从 Excel 导入数据时加载所有分组信息。 |
| 单元格溢出 | Sheet.**options.allowCellOverflow** | SpreadJS 将 allowCellOverflow 设置为 true（在 Excel 中单元格总是可以溢出）。 |
| 筛选 | Sheet.[rowFilter](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#rowfilter) | SpreadJS 从 Excel 导入数据时加载所有筛选信息。 |
| 工作表自定义名称 | Sheet.[addCustomName](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#addcustomname) | SpreadJS 从 Excel 导入数据时加载所有自定义名称。 |
| 工作表行标题或列标题 | Sheet.**options.rowHeaderVisible** 或 Sheet.**options.colHeaderVisible** | SpreadJS 从 Excel 导入此设置。 |
| 将零显示为空白 | Sheet.options.showZeros | SpreadJS 从 Excel 导入此设置。 |
