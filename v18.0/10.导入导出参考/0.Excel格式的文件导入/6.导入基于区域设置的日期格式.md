# LocalebasedDateFormatImported

SpreadJS 允许你在导入 Excel 文件时，根据系统的区域设置来自定义日期格式。
例如，当在英语（EN）区域设置下导入包含日期格式为“dd/mm/yyyy”的 Excel 文件时，在 SpreadJS 中日期格式将显示为“dd/mm/yyyy”。但是，当在法语区域设置下导入同一个 Excel 文件时，在 SpreadJS 中日期格式将显示为“yyyy-MM-dd”，因为这是法语区域的默认日期格式。法语区域的默认数字格式 ID 是 14。你可以将默认数字格式 ID 设置为其他任何数字格式，例如：{14: yyyy-M-d}，以显示自定义的日期格式。
在 SpreadJS 中导入 Excel 文件之前，可以使用 **LocalNumberFormat** 字段将自定义日期格式指定给默认数字格式 ID。
可以通过以下步骤设置自定义日期格式：

1. 获取 [Excel 内置数字格式](https://docs.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.numberingformat?view=openxml-2.8.1)。
2. 创建新的区域信息，并将 Excel 数字格式设置为自定义格式。
3. 将区域信息设置到区域管理器中。
4. 导入 Excel 文件。

下面的示例演示了如何将自定义日期格式设置为法语区域的默认数字格式 ID。

```javascript
// 初始化 Spread
var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });
// 获取工作表
var sheet = spread.sheets[0];
var excelIO = new GC.Spread.Excel.IO();
$('#button1').click(function () {
    spread.suspendPaint();
    // 创建新的区域信息
    var culture = new GC.Spread.Common.CultureInfo();
    culture.LocalNumberFormat = {
        14: 'yyyy/m/d',
    };
    // 将区域信息设置到区域管理器中
    GC.Spread.Common.CultureManager.addCultureInfo('fr', culture);
    GC.Spread.Common.CultureManager.culture('fr');
    // 导入 Excel 文件
    var excelFile = document.getElementById('fileDemo').files[0];
    excelIO.open(
        excelFile,
        function (json) {
            var workbookObj = json;
            spread.fromJSON(workbookObj);
        },
        function (e) {
            console.log(e);
        }
    );
    spread.resumePaint();
});
```
