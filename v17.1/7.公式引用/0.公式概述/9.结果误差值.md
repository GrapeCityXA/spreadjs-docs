# resulterror

由于输入无效或公式无效而可以在单元格中显示的值如下：

| 值 | 描述 |
|--- |--- |
| #DIV/0! | 当公式包括被零除的公式或公式在除数中使用对空白单元格或包含零的单元格的单元格引用时，将显示此信息。 |
| #N/A | 当值不可用于函数或公式时显示。 |
| #NAME? | 当无法识别公式中的文本或函数名称拼写错误时，或者在不使用双引号的情况下包含文本时，将显示此消息。 当您在单元格范围引用中省略冒号（:)时，也会发生这种情况。 |
| #NULL! | 当您指定两个不相交的区域相交时，将显示此信息。 可能的原因包括引用运算符类型错误或单元格引用类型错误。 |
| #NUM! | 当无法计算公式或函数中的数字，公式产生的数字太大或太小而无法表示或在需要数字的函数中使用不可接受的参数时，将显示此信息。 如果您使用的是迭代函数（例如IRR或RATE），但该函数找不到结果，则会显示此值。 |
| #REF! | 当单元格引用无效或删除公式引用的单元格时，将显示此信息。 |
| #VALUE! | 当使用错误类型的参数或操作数时显示，例如在公式需要数字或逻辑值时使用文本，或者使用范围而不是单个值。 |
