# whatisaformula

公式可以由值，运算符和函数组成。 数据可以来自其他单元格，也可以来自另一个单元格中的数据与硬编码数据（例如A1 + 2）的组合，也可以来自硬编码数据（例如SUM（4,5））。 公式可以对其他单元格中的值执行数学运算，例如加法和乘法，也可以比较其他单元格中的值。 公式可以通过其绝对单元格位置或相对于其中包含公式的单元格来引用同一表单中的单元格； 它们可以指单个单元格或一系列连续单元格。 如果引用的单元格中的值变更，则公式单元格的值也会变更。
公式可以由以下组成：

* 单元格引用和单元格范围（表示一个或多个单元格地址的符号）
* 运算符（作用于一个或两个值）
* 内置函数（预定义公式）
* 常数或常数数组（您输入的不变的值）

### 示例公式

在Worksheet类中使用setFormula方法指定公式。 返回公式属性的值将提供一个包含公式的书面表达式的字符串，例如`SUM（A1：B1）`。
在代码中，公式的设置在JavaScript中看起来像这样（仅用于说明目的）：
`sheet.getCell(2, 0).formula = "SUM(A1:A10)"`
并由最终用户添加到单元格中：
`=SUM(A1:A10)`
在本文档中，在显示示例的地方，公式显示为：
`SUM(A1:A10)`
或者
`SUM(3,4,5)` 
表示公式的结果将在单元格中显示值12。
