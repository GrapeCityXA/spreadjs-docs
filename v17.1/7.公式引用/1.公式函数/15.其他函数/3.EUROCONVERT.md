# EUROCONVERT

此函数将数字由欧元形式转换为欧盟成员国货币形式，或利用欧元作为中间货币将数字由某一欧盟成员国货币转化为另一欧盟成员国货币的形式（三角转换关系）。



#### 语法

EUROCONVERT( *currency* , *source* , *target* , *fullprecision* , *triangulation* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
| currency | 要转换的货币值 |
| source | 源货币的 ISO 代码。（见下表） |
|  *target*  | 要转换数值的货币的 ISO 代码。（见下表） |
|  *fullprecision*  | [可选] 一个逻辑值（TRUE 或 FALSE），或计算结果为 TRUE 或 FALSE 的表达式，它用于指定结果的显示方式。 |
|  *triangulation*  | [可选] 一个等于或大于 3 的整数，在两种欧盟成员国货币之间转换时用于指定中间欧元值要使用的有效位数。 |



如果忽略此参数，Excel 不对中间欧元值进行四舍五入。 在将欧元成员国货币转换为欧元时，如果包括此参数，Excel 先计算中间欧元值，然后将其转换为欧盟成员国货币。



#### 注释

此函数仅能转换表中所列货币。

| 国家/地区 | ISO 代码 |
|--- |--- |
| 比利时 | BEF |
| 卢森堡 | LUF |
| 德国 | DEM |
| 西班牙 | ESP |
| 法国 | FRF |
| 爱尔兰 | IEP |
| 意大利 | ITL |
| 荷兰 | NLG |
| 奥地利 | ATS |
| 葡萄牙 | PTE |
| 芬兰 | FIM |
| 欧盟成员国 | EUR |



ISO货币代码来自ISO 4217，该国际标准使用三个字母的代码来定义货币名称。 ISO是国际标准化组织的昵称，代码的前两个字母是两个字母的国家代码（ISO 3166），第三个字母通常是货币本身的缩写。所以BEF是比利时法郎。



#### 数据类型

接受大多参数的数值和字符串数据；参数fullprecision 的逻辑值。返回数值数据。



#### 示例

EUROCONVERT(B5,"DEM","EUR")

EUROCONVERT(R5C2,"DEM","EUR", TRUE, 3)
