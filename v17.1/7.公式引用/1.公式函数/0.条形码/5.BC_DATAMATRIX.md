# BC_DATAMATRIX

该函数返回一个代表 CODE93 的数据集。DATAMATRIX.



#### 语法

BC_DataMatrix( *value, color, backgroudColor, eccMode, ecc200SymbolSize, ecc200EndcodingMode, ecc00_140Symbole, structureAppend, structureNumber, fileIdentifier, quietZoneRight, quietZoneTop, quietZoneBottom* )



#### 参数

| 参数 | 描述 |
|--- |--- |
|  *value*  | 表示二维码符号上的编码的字符串。 |
|  *color*  | 表示条形码颜色的颜色。默认值为 'rgb(0,0,0)'。 |
|  *backgroundColor*  | 表示条形码背景颜色的颜色。默认值为 'rgb(255, 255, 255)' |
|  *eccMode*  | 一个值，表示要使用的 ECC 模式。它具有以下值：'ECC000, ECC050, ECC080, ECC100, ECC140, ECC200'. |
|  *ecc200SymbolSize*  | 一个值，用于指定符号使用的编码模式。默认值为'auto'. |
|  *ecc200EndcodingMode*  | 一个值，表示设置用于 QRCode 的代码。它具有'auto|A|B|C' 值。默认值为 'auto'. |
|  *ecc00_140Symbole*  | 仅指定 ECC000-140 符号大小的值。默认值为'auto'. |
|  *structureAppend*  | 指定符号是否仅是结构化附加消息 ECC200 的一部分。默认值为'false'. |
|  *structureNumber*  | 一个值，表示符号在结构化附加消息中的哪个块。它的值为'0-15'，仅适用于 ECC200。默认值为 '0'. |
|  *fileIdentifier*  | 指定文件标识的值。它的值为“1-254”，仅适用于 ECC200。默认值为'0'. |
|  *quietZoneRight*  | 表示右静区大小的值。 |
|  *quietZoneTop*  | 表示顶部静区大小的值。 |
|  *quietZoneBottom*  | 表示底部静区大小的值。 |



#### 数据类型

接受二维条码。返回条形码迷你图。



#### 例子

sheet.setFormula(3, 3, '=BC_DataMatrix(C4)');
