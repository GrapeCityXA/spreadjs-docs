# information-functions

Spread 提供以下信息函数，按字母顺序排列。

| 函数 | 描述 |
|--- |--- |
| [ERROR.TYPE](gcdocsite__documentlink?toc-item-id=5653e447-7627-45ea-8f68-890d2d95af48) | 此函数返回与错误值之一对应的数字。 |
| [ISBLANK](gcdocsite__documentlink?toc-item-id=29809361-9353-4e06-88f3-252850689060) | 此函数测试引用单元格的值、表达式或内容是否为空。 |
| [ISERR](gcdocsite__documentlink?toc-item-id=0bcab2bf-d07b-4ed6-ba8b-18f782228828) | 此函数是不可用以外的错误，测试引用单元格的值、表达式或内容是否存在不可用以外的错误 (#N/A)。 |
| [ISERROR](gcdocsite__documentlink?toc-item-id=a79f455f-9c29-483f-8d91-4ab9dbbc58ec) | 这个函数是任何类型的错误，测试被引用单元格的值、表达式或内容是否有任何类型的错误。 |
| [ISEVEN](gcdocsite__documentlink?toc-item-id=65151181-eea3-4421-9afa-cc2464c8020f) | 用于测试被引用单元格的值、表达式或内容是否为偶数。 |
| [ISFORMULA](gcdocsite__documentlink?toc-item-id=3de14050-268b-483e-b978-96aee6ea8755) | 此函数测试是否包含引用单元格的公式。 |
| [ISLOGICAL](gcdocsite__documentlink?toc-item-id=4b8131f5-de0b-4996-8377-bdbf2af96b80) | 此函数测试引用单元格的值、表达式或内容是否为逻辑（布尔）值。 |
| [ISNA](gcdocsite__documentlink?toc-item-id=c63caa6e-76cb-4c07-b72c-dc2169602277) | 此函数不可用，测试引用单元格的值、表达式或内容是否具有不可用 (#N/A) 错误值。 |
| [ISNONTEXT](gcdocsite__documentlink?toc-item-id=5534c138-be10-4fb3-9fe6-dad8271f80fc) | 此函数测试引用单元格的值、表达式或内容是否具有文本以外的任何数据类型。 |
| [ISNUMBER](gcdocsite__documentlink?toc-item-id=fee37a03-8ddb-47c4-ab8c-5eea549dd2cd) | 此函数测试引用单元格的值、表达式或内容是否具有数字数据。 |
| [ISODD](gcdocsite__documentlink?toc-item-id=a1b43e9b-6d98-4c29-9c0b-997cd1dc6d6f) | 此函数测试引用单元格的值、表达式或内容是否具有数字数据。 |
| [ISREF](gcdocsite__documentlink?toc-item-id=a521695c-204e-4cda-be87-796a41927f58) | 此函数测试被引用单元格的值、表达式或内容是否是对另一个单元格的引用。 |
| [ISTEXT](gcdocsite__documentlink?toc-item-id=056e0933-dce4-4967-8577-52903990d701) | 此函数测试引用单元格的值、表达式或内容是否具有文本数据。 |
| [N](gcdocsite__documentlink?toc-item-id=1f8f98e8-11d4-4b1e-95dd-945bb8f2cd22) | 此函数返回一个转换为数字的值。 |
| [NA](gcdocsite__documentlink?toc-item-id=25e5b4b3-1d72-4b2e-b6a9-aa056ee7935e) | 此函数返回错误值#N/A，表示不可用。 |
| [TYPE](gcdocsite__documentlink?toc-item-id=8611ee68-8a6a-422c-a466-91edea20eff6) | T此函数返回值的类型。 |
