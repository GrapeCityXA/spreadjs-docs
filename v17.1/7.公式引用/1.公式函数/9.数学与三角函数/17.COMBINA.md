# COMBINA

此函数返回给定数目的项的组合数（包含重复）。



#### 语法

COMBINA( *Value, Value_chosen* )



#### 参数

此函数有下列参数:

| 参数 | 描述 |
|--- |--- |
|  *<em>Value</em>*  | 必须大于或等于 0 并大于或等于 Value_chosen。 |
|  *<em>Value_chosen</em>*  | 必须大于或等于 0。 |



#### 注释

使用以下公式计算COMBINA函数:

(Value + Value_chosen -1) / (Value-1)



#### 数据类型

接受两个参数的数值数据。返回数值数据。



#### 示例

COMBINA(5,4) 得出结果 70.

COMBINA(6,5) 得出结果 252.

COMBINA(11,3) 得出结果 286.
