# GAUGEKPISPARKLINE

此函数返回用于表示仪表 KPI 迷你图的数据集。



#### 语法

GAUGEKPISPARKLINE ( *targetValue, currentValue, minValue, maxValue, [showLabel, targetValueLabel, currentValueLabel, minValueLabel, maxValueLabel, fontArray, minAngle, maxAngle, radiusRatio, gaugeType, colorRange]* )



#### 参数

| 参数 | 描述 |
|--- |--- |
|  *targetValue*  | 仪表 KPI 迷你图的目标值。目标值介于 minValue 和 maxValue 之间。 |
|  *currentValue*  | 仪表 KPI 迷你图的当前值。当前值介于 minValue 和 maxValue 之间。 |
|  *minValue*  | 仪表 KPI 迷你图的最小值。minValue 小于 maxValue。 |
|  *maxValue*  | 仪表 KPI 迷你图的最大值。maxValue 大于 minValue。 |
|  *showLabel*  | (可选) 指定是否显示迷你图中提供的所有值的标签。<br /><br />默认值为true.<br /><br /> |
|  *targetValueLabel*  | (可选)  要显示为目标值标签的字符串。默认值为 *targetValue* . |
|  *currentValueLabel*  | (可选) 要显示为当前值标签的字符串。默认值为 *currentValue* . |
|  *mintValueLabel*  | (可选) 要显示为最小值标签的字符串。默认值为 *minValue* . |
|  *maxValueLabel*  | (可选) 要显示为最大值标签的字符串。默认值为 *maxValue* . |
|  *fontArray*  | (可选) 数组包含字体格式作为四种标签类型的字符串项 -The *showLabel* 选项必须为true.<br /><br /> |
|  *minAngle*  | (可选) 圆形类型的最小角度值。minAngle应小于maxAngle。<br /><br />角度值对应于时钟中的时间。0 是 12 点，-90 是 9 点，90 是 3 点，-180/180 是 6 点。<br /><br />默认值为-90.<br /><br />gaugeType选项必须为 0(Circle类型).<br /><br /> |
|  *maxAngle*  | (可选) 圆形类型的最大角度值。maxAngle应该大于minAngle。<br /><br />角度值对应于时钟中的时间。0 是 12 点，-90 是 9 点，90 是 3 点，-180/180 是 6 点。<br /><br />默认值为 90。<br /><br />gaugeType选项必须为 0（Circle类型）。<br /><br /> |
|  *radiusRatio*  | (可选) 该值计算为内圆半径与外圆半径的比值。外圆半径值由像元大小决定。<br /><br />取值范围为 0 到 1。默认值为 0。<br /><br />gaugeType选项必须为 0（Circle类型）。<br /><br /> |
|  *gaugeType*  | KPI 迷你图类型。<br /><br />0 - Circle1 - Vertical Bar2 - Horizontal Bar<br /><br />默认类型是circle.<br /><br /> |
|  *colorRange*  | (可选)以下指定值之间的颜色范围 - *startValue, endValue, color_string.* <br /><br />其中startValue是一个范围内的起始值，endValue是一个范围内的结束值，color_string是两个指定值之间的范围的颜色。<br /><br />startValue必须小于endValue并且两个值都应该在minValue和maxValue之间。<br /><br />从minValue到maxValue的默认颜色范围用浅灰色填充。<br /><br /> |



#### 数据类型

返回sparkline.



#### 例子

sheet1.setFormula(1, 0, '=GAUGEKPISPARKLINE(Sheet2!B2,Sheet2!C2,Sheet2!D2,Sheet2!E2,TRUE,TEXT(Sheet2!B3/1000,"$0.0K"),Sheet2!A2,TEXT(Sheet2!D2/1000,"$0.0K"),TEXT(Sheet2!E2/1000,"$0.0K"),{"normal normal 11pt Calibri","normal bold 16pt Calibri","normal normal 9pt Calibri","normal normal 9pt Calibri"},-90,90,0.4,0,{0,1200,"#FFB2BD"},{1200,1500,"#FFDFB0"},{1500,2000,"#BCEAB4"})');
