# IMAGE

此函数输入 URL 或 base64 字符串以在单元格中显示图像。



#### 语法

IMAGE( *url, [mode, height, width, clipX, clipY, clipHeight, clipWidth, vAlign, hAlign]* )



#### 参数

| 参数 | 描述 |
|--- |--- |
|  *URL*  | 图片网址或base64字符串 |
|  *mode*  | (可选)指定如何调整图像大小。<br /><br />1 - 保持纵横比以适合单元格。2 -拉伸图像以覆盖整个单元格。3 - 即使裁剪也保持原始尺寸。4 - 自定制<br /><br />默认值为 1。<br /><br /> |
|  *height*  | (可选) 图像的高度。mode选项必须为 4 。 |
|  *width*  | (可选) 图像的宽度。 *mode* 选项必须为 4 。 |
|  *clipX*  | (可选) 要绘制到目标上下文中的源图像子矩形左上角的 x 轴坐标。默认值为 0。 |
|  *clipY*  | (可选) 要绘制到目标上下文中的源图像子矩形左上角的 y 轴坐标。默认值为 0。 |
|  *clipHeight*  | (可选) 要绘制到目标上下文中的源图像子矩形的高度。默认值为图像的高度。 |
|  *clipWidth*  | (可选) 要绘制到目标上下文中的源图像子矩形的宽度。默认值为图像的宽度。 |
|  *vAlign*  | (可选) 图像的垂直对齐。<br /><br />0 - Top1 - Center2 - Bottom<br /><br />默认值为 1 (center).<br /><br /> |
|  *hAlign*  | (可选) 图像的水平对齐。<br /><br />0 - Left1 - Center2 - Right<br /><br />默认值为1 (center).<br /><br /> |



#### 数据类型

返回sparkline.



#### 例子

sheet1.setFormula(2, 0, '=IMAGE("https://upload.wikimedia.org/wikipedia/commons/thumb/f/fa/Flag_of_the_People%27s_Republic_of_China.svg/23px-Flag_of_the_People%27s_Republic_of_China.svg.png")');sheet1.setFormula(3, 0, '= IMAGE("https://upload.wikimedia.org/wikipedia/en/4/41/Flag_of_India.svg")');
