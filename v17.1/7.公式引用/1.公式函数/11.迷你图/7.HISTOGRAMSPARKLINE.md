# HISTOGRAMSPARKLINE

此函数返回用于表示直方图迷你​​图的数据集。



#### 语法

HISTOGRAMSPARKLINE( *dataRange, [continuous, paintLabel, scale, barWidth, barColor, labelFontStyle, labelColor, edgeColor]* )



#### 参数

| 参数 | 描述 |
|--- |--- |
|  *dataRange*  | 表示数据源的区域。它支持一个区域。<br />它支持计算数组和计算引用。 |
|  *continuous*  | (可选) 表示直方图迷你​​图的类型。<br /><br />如果设置为 true，则迷你图是连续直方图。如果设置为 false，则迷你图是离散直方图。<br /><br />默认值是true。<br /><br /> |
|  *paintLabel*  | (可选) 表示是否绘制迷你图数据标签。默认值为false. |
|  *scale*  | (可选) 表示 bin 宽度。当直方图类型是连续的时，此值很有用。默认值为false. |
|  *barWidth*  | (可选) 表示条形宽度。默认值为 1。<br /><br />Bar width = auto calc width * barWidth<br /><br />取值区域为 ： 0 < 值 ≤ 1。<br /><br /> |
|  *barColor*  | (可选) 表示条形的颜色。默认值为“5B9BD5”。<br /><br />支持 CSS 颜色属性。<br /><br /> |
|  *labelFontStyle*  | (可选) 表示数据标签字体的字体样式。默认值为 9pt Calibri。<br /><br />支持 CSS 字体属性。它支持font-style, font-weight, font-size, font-family.<br /><br /> |
|  *labelColor *  | (可选)表示数据标签字体的字体颜色。默认值为black(#00000).<br /><br />支持 CSS 颜色字符串。<br /><br /> |
|  *edgeColor *  | (可选) 表示边缘的颜色。默认值为silver (#C0C0C0).<br /><br />支持 CSS 颜色属性。<br /><br /> |



#### 数据类型

返回sparkline.
