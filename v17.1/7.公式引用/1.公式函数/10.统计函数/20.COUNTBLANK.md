# COUNTBLANK

该函数计算单元格区域中的空单元格的数量。



#### 语法

COUNTBLANK( *cellrange* )



#### 参数

需要计算其中空白单元格个数的区域。



#### 注释

包含返回 ""（空文本）的公式的单元格也会计算在内。 包含零值的单元格不计算在内。

SpreadJS[0].Cells[0,0].Value = null; // empty

SpreadJS[0].Cells[1,0].Value = ""; // string

SpreadJS[0].Cells[2,0].Value = "abc"; // string

SpreadJS[0].Cells[3,0].Value = 123.0; // number

SpreadJS[0].Cells[4,0].Formula = "COUNTBLANK(A1:A4)";

单元格A5中的公式计算为1，因为单元格A1是A1：A4范围内唯一的空单元格。

 **注意: ** 函数实现通常遵循流行的表单应用程序中的行为。 但是，并非所有这些应用程序都同意是否将空字符串“”与空单元格一样对待。 在GC.Spread中，COUNTBLANK和[ ISBLANK ](gcdocsite__documentlink?toc-item-id=29809361-9353-4e06-88f3-252850689060)函数一致地将空字符串“”与空单元格区别对待。



#### 数据类型

接受单元格引用区域。返回数值数据。



#### 示例

COUNTBLANK(A1:G5)

COUNTBLANK(R6C3:R9C4)
