# LOGNORM.DIST

此函数返回 x 的对数分布函数，此处的 ln(x) 是含有 Mean 与 Standard_dev 参数的正态分布。



#### 语法

LOGNORM.DIST( *x* , *mean* , *stdev,cumulative* )



#### 参数

该函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *x*  | 用来计算函数的值。 |
|  *mean*  | ln(x) 的平均值。 |
|  *stdev*  | ln(x) 的标准偏差。 |
|  *cumulative*  | 决定函数形式的逻辑值。 如果 cumulative 为 TRUE，则 LOGNORM.DIST 返回累积分布函数；如果为 FALSE，则返回概率密度函数。 |



#### 注释

如果任何参数为非数值型，则此函数返回 #VALUE！ 。

对数累积分布函数的公式为：

LOGNORM.DIST( *x,µ,o* ) = NORM.S.DIST( *1n(x)-µ / o* ).



#### 数据类型

接受 `x` ，`mean` 和 `stdev` 参数的数值数据。接受 `cumulative` 的逻辑值。返回数值数据。
