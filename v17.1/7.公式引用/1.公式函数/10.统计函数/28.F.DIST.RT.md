# F.DIST.RT

此函数返回两个数据集的（右尾）F 概率分布（变化程度）。



#### 语法

F.DIST.RT( *value* , *degnum* , *degden* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *value*  | 用来计算函数的值。 |
|  *degnum*  | 分子自由度。如果不是整数，则将截尾取整。 |
|  *degden*  | 分母自由度。如果不是整数，则将截尾取整。 |



#### 注释

如果任何参数为非数值型，则返回 #VALUE！ 。



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

F.DIST.RT(A1,2,2)

F.DIST.RT(R1C1,2,1)

F.DIST.RT(16.83975,5,3) 得出结果 0.021000082461949843
