# DEC2OCT

此函数将十进制数转换为八进制数。



#### 语法

DEC2OCT( *number* , *places* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *number*  | 要转换的十进制整数，范围在 -536,870,912 至 536,870,911之间。 |
|  *places*  | [可选]  要使用的字符数。如果不是整数，则将截尾取整。 |

如果省略 places，则 DEC2OCT 使用必要的最小字符数。 Places 可用于在返回的值前置 0（零）。



#### 注释

如果 number、places为非数值型则 DEC2OCT  返回 #VALUE！ 。

如果 number <-536870912 或 number > 536870911，DEC2OCT 返回 #NUM！ 。



#### 数据类型

接受数值数据。返回数值数据。



#### 示例

DEC2OCT(-99)
