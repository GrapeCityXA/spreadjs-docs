# ISNA

此函数检验引用单元格的值，表达式或内容是否具有不可用（＃N / A）错误值。



#### 语法

ISNA( *cellreference* )

ISNA( *value* )

ISNA( *expression* )



#### 参数

参数可以是单元格引用，数字或文本值或表达式。



#### 注释

使用此功能可以测试单元格、数字、文本值、函数或表达式的内容。

如果该值是或引用了#N/A错误值，则此函数返回TRUE，如果值是或引用没有数据的单元格，则返回FALSE。



#### 数据类型

接受参数的任何数据类型。返回布尔（TRUE或FALSE）数据。



#### 示例

ISNA(B12)

ISNA(R12C2)

ISNA(#N/A) 得出结果 TRUE

ISNA(NA()) 得出结果 TRUE

ISNA(#REF) 得出结果 FALSE
