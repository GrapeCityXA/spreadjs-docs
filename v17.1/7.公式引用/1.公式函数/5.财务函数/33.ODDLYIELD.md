# ODDLYIELD

此函数返回末期付息日不固定的有价证券（长期或短期）的收益率。



#### 语法

ODDLYIELD( *settle,maturity,last,rate,price,redeem,freq,basis* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *settle*  | 有价证券的结算日。 |
|  *maturity*  | 有价证券的到期日。 |
| last | 有价证券的末期付息日。 |
| rate | 有价证券的利率。 |
| price | 有价证券的价格。 |
| redeem | 面值 ￥100 的有价证券的清偿价值。 |
| freq | 年付息次数。 |
|  *basis*  | [可选] 要使用的日计数基准类型。请参考[Day Count Basis](gcdocsite__documentlink?toc-item-id=23b72e94-94be-44ed-9302-d582747f59dd)。 |



#### 注释

如果 settle、maturity或 last 不是有效日期，则返回 错误值 #VALUE!。

settle、maturity、last 和 basis 将被截尾取整。

如果 rate < 0 或 price < 0，则返回错误值 #NUM!。

如果 basis < 0 或 basis > 4，则返回错误值 #NUM!。

必须满足下列日期条件，否则返回错误值 #NUM!：maturity > settle > last



#### 数据类型

接受数值数据和日期。返回数值数据。



#### 示例

ODDLYIELD(G1,G2,G3,G4,G5,G6,G7,G8)
