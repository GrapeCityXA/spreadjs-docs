# PV

PV 是一个财务函数，用于根据固定利率计算贷款或投资的现值。



#### 语法

PV( *rate* , *numper* , *paymt* , *fval* , *type* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *rate*  | 各期利率。 |
|  *numper*  | 年金的付款总期数。 |
|  *paymt*  | 每期的付款金额，在年金周期内不能变更。 |
|  *fval*  | [可选] 未来值。如果省略，以payments为基础计算。 |
|  *type*  | [可选] 指定到期付款时间。数字 0 或 1 指示支付时间。 |

在年金函数中，现金支出（如存款）用负数表示；现金收入（如股利支票）用正数表示。



#### 注释

请确保指定 rate 和 numper 所用的单位是一致的。 如果贷款为期四年（年利率 12%），每月还一次款，则 rate 应为 12%/12，nper 应为 4*12。 如果对相同贷款每年还一次款，则 rate 应为 12%，numper 应为 4。



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

PV(B1/12,N24,-75,0,1)

PV(R1C1/12,48,R1C2,0,0)

PV(0.005,60,-100,0,1) 得出结果 $5,198.42
