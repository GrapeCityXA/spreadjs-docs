# RATE

此函数返回每期年金的利率。



#### 语法

RATE( *nper* , *pmt* , *pval* , *fval* , *type,guess* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *nper*  | 年金的付款总期数。 |
|  *pmt*  | 年金的付款总期数。 |
|  *pval*  | 现值，即一系列未来付款当前值的总和。 |
|  *fval*  | 未来值，或在最后一次付款后希望得到的现金余额。 |
|  *type*  | [可选] 指定到期付款时间。数字 0 或 1 指示支付时间。 |
|  *guess*  | [可选]数字 0 或 1，用以指定各期的付款时间是在期初还是期末。 |



#### 注释

如果省略 guess，则假定其值为 10%。



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

RATE(A1,B2,C3,C4,1)

RATE(360, -600, 80000) 得出结果 0.686%
