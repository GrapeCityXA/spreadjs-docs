# COUPNUM

此函数返回在结算日和到期日之间的付息次数，向上舍入到最近的整数。



#### 语法

COUPNUM( *settlement* , *maturity* , *frequency* , *basis* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *settlement*  | 有价证券的结算日。 |
|  *maturity*  | 有价证券的到期日。 |
|  *frequency*  | 年付息次数。 如果按年支付，frequency = 1；按半年期支付，frequency = 2；按季支付，frequency = 4。 |
|  *basis*  | [可选] 要使用的日计数基准类型。请参考[Day Count Basis](gcdocsite__documentlink?toc-item-id=23b72e94-94be-44ed-9302-d582747f59dd) |



#### 注释

如果结算或到期日期不是有效日期，则 COUPNUM   返回 #VALUE！。

如果 basis < 0 或basis > 4，则 COUPNUM   返回 #NUM！ 。

如果 frequency 是除1、2或4以外的任何数字, COUPNUM   返回 #NUM! 错误值。

所有参数都将被截尾取整。

如果结算日≥到期日，COUPNUM 将返回 #NUM！



#### 数据类型

接受数值和DateTime对象数据。返回数值数据。



#### 示例

COUPNUM(A1,A2,A3,A4)

COUPNUM(R6C3:R9C4)
