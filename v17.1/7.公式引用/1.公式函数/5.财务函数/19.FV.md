# FV

此函数用于根据固定利率计算投资的未来值。



#### 语法

FV( *rate* , *numper* , *paymt* , *pval* , *type* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *rate*  | 各期利率。 |
|  *numper*  | 年金的付款总期数。 |
|  *paymt*  | 各期所应支付的金额。 |
|  *pval*  | [可选] 现值，或一系列未来付款的当前值的累积和。 如果省略，则假定其值为 0（零），并且必须包括 paymt 参数。 |
|  *type*  | [可选] 数字 0 或 1，用以指定各期的付款时间是在期初还是期末。 如果省略 type，则假定其值为 0。 |



#### 注释

请确保指定 rate 和 nper 所用的单位是一致的。 如果贷款为期四年（年利率 12%），每月还一次款，则 rate 应为 12%/12，nper 应为 4*12。

对于所有参数，支出的款项，如银行存款，以负数表示；收入的款项，如股息支票，以正数表示。

有关函数 FV 中各参数以及年金函数的详细信息，请参阅函数[PV](gcdocsite__documentlink?toc-item-id=f63c0327-0f4d-444f-a597-323a23beb28b)。



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

FV(A1/12,48,B1,1000,0)

FV(R1C1/12,48,R1C2,1000,0)

FV(0.005,60,-100,100,1) 得出结果 $6877.00
