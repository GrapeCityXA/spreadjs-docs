# PPMT

此函数返回根据定期固定付款和固定利率而定的投资在已知期间内的本金偿付额。



#### 语法

PPMT( *rate* , *per* , *nper* , *pval* , *fval* , *type* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *rate*  | 各期利率。 |
|  *per*  | 指定期数，该值必须在 1 到 nper 范围内。 |
|  *nper*  | 年金的付款总期数。 |
|  *pval*  | 现值，即一系列未来付款当前值的总和。 |
|  *fval*  | [可选] 未来值，或在最后一次付款后希望得到的现金余额。 如果省略 fv，则假定其值为 0（零） |
|  *type*  | [可选] 指定到期付款时间。数字 0 或 1 指示支付时间。 |



#### 注释

请务必按年表示利率。例如，如果利率是8％，则将8用作rate参数。

结果用负数表示，因为它是您支付的钱。

有关财务的公式，请参考[ PV ](gcdocsite__documentlink?toc-item-id=f63c0327-0f4d-444f-a597-323a23beb28b)函数。



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

PPMT(B1,C4,C5,C6,C7,1)

PPMT(R1C2,R4C3,R6C3,R7C3,0)

PPMT(0.45, 22, 30, 6000, 7000) 得出结果 -$206.47
