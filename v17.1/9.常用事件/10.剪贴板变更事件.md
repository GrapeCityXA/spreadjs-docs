# sceventclipboard

您可以使用四种类型的剪贴板事件，如 **ClipboardChanged** 、 **ClipboardChanging** 、 **ClipboardPasted** 和 **ClipboardPasting** 事件。

ClipboardChanged和ClipboardChanging事件分别在剪贴板发生变更和剪贴板正在变更时发生。类似地，clipboardpaste和ClipboardPasting事件分别发生在用户从剪贴板粘贴时和用户正在粘贴时。通过这些剪贴板事件，用户可以对Excel中的文本、单元格数据、图片、图表、形状、切片器和自定义浮动对象执行复制粘贴操作，也可以在表单内部和表单之间执行复制粘贴操作。

Currently, cut or copy operations from SpreadJS to Excel is not supported.



#### 使用代码

本示例使用了不同的剪贴板事件。


```Javascript
<script>
    $(document).ready(function () {
        //初始化spread
        var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });
        //获取活动表
        var activeSheet = spread.getActiveSheet();

        // 将allowCopyPasteExcelStyle设置为true
        spread.options.allowCopyPasteExcelStyle = true;

        // 剪贴板事件绑定
        activeSheet.bind(GC.Spread.Sheets.Events.ClipboardChanged, function (sender, args) {
            console.log("ClipboardChanged.");
        });

        activeSheet.bind(GC.Spread.Sheets.Events.ClipboardChanging, function (sender, args) {
            console.log("ClipboardChanging");
        });

        activeSheet.bind(GC.Spread.Sheets.Events.ClipboardPasted, function (sender, args) {
            console.log("ClipboardPasted");
        });

        activeSheet.bind(GC.Spread.Sheets.Events.ClipboardPasting, function (sender, args) {
            console.log("ClipboardPasting");
        });
    });
</script>
```



#### 用例

您可以在以下用例中使用剪贴板事件。

 **复制粘贴从Excel到SpreadJS** 

假设你有多个对象，如图像，图表和形状在Excel中，你想复制和粘贴所有对象，除了图像。为此，“cancel”参数在ClipboardPasting事件设置为真。

注意，为了将图像、图表和形状等对象从Excel复制粘贴到扩展表单中，需要将“allowCopyPasteExcelStyle”属性设置为true。要了解更多关于复制Excel对象的内容，请参考本[主题](gcdocsite__documentlink?toc-item-id=1737b42e-14a2-4daf-90e9-90a7278951e3)。

下面的代码片段描述了如何防止图像副本从Excel扩展。


```Javascript
<script>
    $(document).ready(function () {
        //初始化spread
        var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });
        //获取活动表
        var activeSheet = spread.getActiveSheet();

        // 将allowCopyPasteExcelStyle设置为true
        spread.options.allowCopyPasteExcelStyle = true;

        // 添加图片
        activeSheet.pictures.add("f2", "Capture.PNG", 100, 60, 200, 100);

        // 这段代码防止将图像从Excel复制到SpreadJS
        spread.bind(GC.Spread.Sheets.Events.ClipboardPasting, (e, args) => {
            if ((args.pasteData && args.pasteData.image)) {
                args.cancel = true;
            }
        });
    });
</script>
```

 **SpreadJS表单复制粘贴** 

假设您在SpreadJS中有多个对象，比如图像、图表和形状，并且您想要复制粘贴SpreadJS中除了图像以外的所有浮动对象。剪贴板事件中的“objects”参数可用于复制粘贴文本、单元格数据、图片、自定义浮动对象、切片器、图表和形状。下面的代码片段描述了如何通过将“cancel”参数设置为true来防止在扩展表单中复制图像。


```Javascript
<script>
    $(document).ready(function () {
        //初始化spread
        var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });
        //获取活动表
        var activeSheet = spread.getActiveSheet();

        // 将allowCopyPasteExcelStyle设置为true
        spread.options.allowCopyPasteExcelStyle = true;

        spread.bind(GC.Spread.Sheets.Events.ClipboardPasting, (e, args) => {
            // 这段代码防止内部浮动元素复制粘贴//这段代码防止外部图像粘贴
            if ((args.objects && args.objects.length > 0) || (args.pasteData && args.pasteData.image)) {
                //alert("test");
                args.cancel = true;
            }
        });
    });
</script>
```
