# CustomizingtheRangeGroups

SpreadJS支持自定义区域分组，以增强表单的外观，同时还使用户易于以有效的方式组织和操作数据。

您可以设置自定义背景颜色，边框颜色大纲区域，图标的背景颜色，数字和+/-的字体颜色，数字和+/-的背景图像，按钮的边框颜色，线条颜色，线条宽度和点颜色，如下图所示：

下面列出了可以自定义范围组的属性以及相应的CSS类和CSS属性：

|  **区域分组属性**  |  **CSS类名**  |  **CSS属性**  |  **附加注释**  |
|--- |--- |--- |--- |
| Backcolor of outline area | gc-group<br /><br /> | background-color |  |
| Border color of outline area<br /><br /> | color |  |
| Backcolor of icon | gc-group-box<br /><br /> | background-color |  |
| Font color of number and +/- | color |  |
| Border color of button | border-color | 此属性将使用CSS中的border-top-color，并将忽略任何其他边框颜色。 |
| BackgroundImage of number and + | gc-group-box-expand | background-image | 当用户设置背景图像时，默认的边框颜色和背景颜色是透明的。<br /><br />如果未设置背景图像，则默认情况下它将使用gc-group-box中定义的样式。<br /><br />如果定义的CSS包含多个背景图片，则只有第一个背景图片才会生效。<br /><br /> |
| BackgroundImage of number and - | gc-group-box-collapsed | background-image | 当用户设置背景图像时，默认的边框颜色和背景颜色是透明的。<br /><br />如果未设置背景图像，则默认情况下它将使用gc-group-box中定义的样式。<br /><br />如果定义的CSS包含多个背景图片，则只有第一个背景图片才会生效。<br /><br /> |
| Line color | gc-group-line<br /><br /> | border-color | 此属性将使用CSS中的border-top-color，并将忽略任何其他边框颜色。 |
| Line Width | border-width | 此属性将使用CSS中的border-top-width，并将忽略任何其他边框颜色。 |
| Dot Color | gc-group-dot | color |  |



#### 示例代码

请参考下面示例，以便在使用表单时自定义范围组的属性：


```JavaScript
<style>
.gc-group {
    background-color: rgb(180, 211, 230);
    color: #999999;
    border-width: 0px;
    border-style:solid;
}
.gc-group-box {
    background-color: #fff;
    color: rgb(8, 154, 245);
    border-color:rgb(32, 158, 241);
}
.gc-group-line{
    border-width:2px;
    border-style:solid;
    border-color:rgb(137, 199, 243);
}
.gc-group-dot{
    color:blue;
}
</style>
```

在同一页面中无法针对不同的Worksheet元素自定义多个CSS。
> **注意:** 在同一页面中无法针对不同的Worksheet元素自定义多个CSS。
