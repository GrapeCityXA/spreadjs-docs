# sort-pt

SpreadJS 允许您对数据透视表数据进行排序，以便您可以对其进行组织以便快速方便地进行分析。
处理大量数据时，排序特别有用。您可以使用`PivotTable.sort`接受对象`sortInfo`作为参数的函数对数据进行排序。
SpreadJS 允许用户以四种不同的方式对数据透视表数据进行排序和排序：

1. 按字段项名称排序
2. 按值排序
3. 按自定义字段项值排序
4. 按自定义回调排序

## 按字段项名称排序

要按字段对数据透视表数据进行排序，您可以指定字段名称并使用属性`sortType`并将`sortInfo`排序顺序设置为升序、降序或自定义。
下图演示了应用于“类别”字段的降序排序顺序。
![枢轴排序字段名称](https://documentsitestorage.blob.core.windows.net/document-site-files/images/df1fe1ee-eb3c-4da7-8c20-a0d8d2b7e734/pivot-sort-by-field-name.6635c7.png)
以下代码示例显示了如何按字段项名称对数据透视表数据进行排序：

```javascript
let pivotTable = spread.getActiveSheet().pivotTables.get("PivotTable");
 var sortInfo = {
  sortType: GC.Pivot.SortType.desc
 };
pivotTable.sort("Category", sortInfo);
```

### 使用设计器

您还可以通过单击字段的**筛选器下拉列表**中的**更多排序选项...，**通过设计器对数据进行排序。此选项会打开一个**排序字段**对话框，您可以在其中选择目标字段并将排序类型设置为升序或降序。
下图演示了如何使用设计器按字段项名称排序：
![枢轴排序字段名称](https://documentsitestorage.blob.core.windows.net/document-site-files/images/df1fe1ee-eb3c-4da7-8c20-a0d8d2b7e734/pivot-sort-by-field-name.6dac76.gif)

## 按值排序

要按字段值对数据透视表数据进行排序，您可以设置类的`sortType`和`sortValueFieldName`属性`sortInfo`。sortValueFieldName 属性允许您指定要作为数据排序依据的字段的名称。此功能允许您按“总计”列中的值对数据透视表数据进行排序。
下图演示了按“**数量**”值升序排序的**“类别”**字段。
![按值排序](https://documentsitestorage.blob.core.windows.net/document-site-files/images/df1fe1ee-eb3c-4da7-8c20-a0d8d2b7e734/pivot-sort-by-value.b7e3ef.png)
以下代码示例显示如何对数据透视表应用按值排序。

```javascript
let pivotTable = spread.getActiveSheet().pivotTables.get("PivotTable");
var sortInfo = {
    sortType: GC.Pivot.SortType.asc,
    sortValueFieldName: "Quantity"
 };
  pivotTable.sort("Category", sortInfo);
```

### 使用设计器

您还可以通过单击字段的**筛选器下拉列表**中的**更多排序选项...，**通过设计器对数据进行排序。此选项会打开一个**排序字段**对话框，您可以在其中选择目标字段并将排序类型设置为升序或降序。

## 按自定义字段项目值排序

要按自定义字段项值对数据透视表数据进行排序，您可以使用对象`sortByPivotReferences`的属性`sortInfo`。
下图演示了根据**OrderDate**字段的**Qtr1中的数据对Category**字段进行升序排序。
![按自定义值进行数据透视排序](https://documentsitestorage.blob.core.windows.net/document-site-files/images/df1fe1ee-eb3c-4da7-8c20-a0d8d2b7e734/pivot-sort-by-custom-value.58dbfa.png)
以下代码示例显示了如何设置按自定义字段项值排序：

```javascript
let pivotTable = spread.getActiveSheet().pivotTables.get("PivotTable");
 var sortInfo = {
  sortType: GC.Pivot.SortType.asc,
  sortValueFieldName: "Quantity",
  sortByPivotReferences: [
     {
        fieldName: "OrderDate",
        items: ["Qtr1"]
     }
    ]
}
pivotTable.sort("Category", sortInfo);
```

### 使用设计器

您还可以通过单击字段的**过滤器下拉列表中的更多排序选项...**，通过设计器对数据进行排序<span style="margin: 0px; padding: 0px; -webkit-font-smoothing: antialiased; color: rgb(24, 24, 24);">。</span>此选项将打开一个**排序字段**对话框，您可以在其中选择目标字段的排序顺序，然后单击**更多选项...**按钮以打开另一个**排序**对话框。在此对话框中，默认情况下，GrandTotal 处于选中状态，其结果与按值排序的结果相同。要按自定义字段项值排序，请使用**所选列中的值**的范围选择器选择一个范围，然后单击**确定。**

> 行或列区域字段的对话框选项被禁用。例如，在这种情况下，如果您单击类别字段的更多选项...按钮，它将被禁用，因此您必须选择数量字段，然后单击更多选项...**按钮**。

下图演示了如何使用设计器按自定义字段项值排序：
![按自定义字段值进行数据透视排序](https://documentsitestorage.blob.core.windows.net/document-site-files/images/df1fe1ee-eb3c-4da7-8c20-a0d8d2b7e734/pivot-sort-by-custom-field-value.47e35c.gif)

## 按自定义回调排序

要使用自定义逻辑对数据透视表数据进行排序，而不是按值的升序或降序排序，您可以使用自定义回调函数。
下图演示了使用自定义回调函数对**TotalSales列进行排序。**
![按自定义回调进行数据透视排序](https://documentsitestorage.blob.core.windows.net/document-site-files/images/df1fe1ee-eb3c-4da7-8c20-a0d8d2b7e734/pivot-sort-by-custom-callback.ac07df.png)
以下代码示例显示了使用自定义回调对 TotalSales 列进行排序：

```javascript
let pivotTable = spread.getActiveSheet().pivotTables.get("PivotTable");
 var sortInfo = {
       sortType: GC.Pivot.SortType.desc,
       customSortCallback: (fieldItemNameArray)=>{
       alert("sorting from custom callback")
       return fieldItemNameArray.sort((a,b)=>b-a);
    }
  };
pivotTable.sort("TotalSales", sortInfo);
```
