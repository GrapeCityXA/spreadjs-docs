# exceltheme

你可以在 Spread.Sheets 中使用 Excel 主题。这需要你在页面上引入一个 CSS 文件：


```text
<link rel="stylesheet" href="css/gc.spread.sheets.excel2013white.13.0.0.css" />
```



![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/exceltheme.png)

Excel 2013 主题也支持标签栏和滚动条。

你可以使用以下主题

|  **主题名称**  |  **对应的 CSS 文件**  |
|--- |--- |
| Excel 2007 | gc.spread.sheets.13.0.0.css |
| Excel 2013 White | gc.spread.sheets.excel2013white.13.0.0.css |
| Excel 2013 Light Gray | gc.spread.sheets.excel2013lightGray.13.0.0.css |
| Excel 2013 Dark Gray | gc.spread.sheets.excel2013darkGray.13.0.0.css |
| Excel 2016 Colorful | gc.spread.sheets.excel2016colorful.13.0.0.css |
| Excel 2016 Dark Gray | gc.spread.sheets.excel2016darkGray.13.0.0.css |
| Excel 2016 Black | gc.spread.sheets.excel2016black.13.0.0.css |

Excel 主题和其他主题（比如 bootstrap 主题）可以共存。


```text
<link rel="stylesheet" href="css/gc.spread.sheets.excel2013white.13.0.0.css" />
```




```text
<link rel="stylesheet" href="css/bootstrap/bootstrap.min.css" title="aa" />
<link rel="stylesheet" href="css/bootstrap/bootstrap-theme.min.css" title="aa" />
```



使用 **refresh** 方法来刷新 Spread.Sheet 的显示，并应用主题。
