# data-manager

数据管理器是一个强大的本地数据引擎，它向服务器端发送请求，然后在数据准备就绪时将数据绑定到表中。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-overview-flowchart.png)

数据管理器与数据库交互，使用[GC.Data.DataManager](gcdocsite__documentlink?toc-item-id=d168d582-7001-4e98-a184-2aafa89215e1)类来管理（排序、筛选、分组、聚合）并同步实时数据，
    返回数据库。使用[addTable](gcdocsite__documentlink?toc-item-id=d168d582-7001-4e98-a184-2aafa89215e1#addTable)和[addRelationship](gcdocsite__documentlink?toc-item-id=d168d582-7001-4e98-a184-2aafa89215e1#addRelationship)方法
    来创建表和表之间的关联关系。同样，也可以使用DataManager类来移除关系或关联关系。

数据管理器作为TableSheet的数据核心，允许它更多地关注业务逻辑和呈现。支持远程源，如REST API、OData、GraphQL，以及JSON对象数组、CSV字符串或XML等本地源来创建表。



### 数据源模式

添加数据源以定义数据表时，可以提供数据模式，它包含以下属性：

| 属性 | 描述 |
|--- |--- |
| type<br /><br /> *string* <br /><br /> | 使用的数据类型，支持JSON,CSV,XML,columnJson,默认类型为JSON。<br /><br /> |
| countPath<br /><br /> *string* <br /><br /> | 用于获取数据源集合长度。 |
| dataPath<br /><br /> *string* <br /><br /><br /><br /> | 用于在解析后获取数据源集合。 |
| columns<br /><br /> *GC.Data.IColumnCollection* <br /><br /><br /><br /> | 数据源表的列定义。它的键是列名，值是列信息，包含dataType、dataPattern、dataMap。<br /><br /> |

下面的代码示例演示如何为TableSheet设置数据架构。


```JavaScript
var dataManager = spread.dataManager();
var customerTable = dataManager.addTable("customerTable", {
    remote: {
        read: {
            url: apiUrl
        }
    },
    // 数据源模式 - 这里设置了dataType、 dataPattern、 dataMap等。
    schema: {
        columns: {
            validFrom: { dataType: "date" },
            billToCustomer: { dataMap: { "Tailspin Toys (Head Office)": "Tailspin Toys(HO)", "Wingtip Toys (Head Office)": "Wingtip Toys(HO)" } },
            buyingGroup: { dataMap: { "Tailspin Toys": "TT", "Wingtip Toys": "WT" } },
            postalCode: { dataType: "number" }
        }
    }
});
```
