# tablesheet-appearance

本主题介绍TableSheet样式，以及以不同的方式来增强TableSheet的样式，视觉效果。



### 交替行样式

TableSheet支持交替行样式，这样可以在有类似内容的行中使您直观地区分以识别同一行的内容。

您可以指定指定TableSheet[alternatingRowOptions](gcdocsite__documentlink?toc-item-id=8dc0b7a4-ace7-4c61-b4a7-00790d5584fe#options)，用一个步进数组指示填充行和空白行的数量，使用[GC.Spread.Sheets.Style](gcdocsite__documentlink?toc-item-id=1a4e9265-6694-48bb-b0fc-15e5ab238a26)类应用样式

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-alternaterow.png)

以下代码示例显示如何将十六进制颜色代码添加为纸张表中的备用行样式。


```JavaScript
// 创建一个交替行样式
sheet.options.alternatingRowOptions = { 
    step: [1, 2],
    style: new GC.Spread.Sheets.Style("#E6EF9D")
};
```

### 主题

TableSheet提供了许多内置主题，您可以使用[applyTableTheme](gcdocsite__documentlink?toc-item-id=8dc0b7a4-ace7-4c61-b4a7-00790d5584fe#applyTableTheme)方法应用主题。 该方法接受一个[GC.Spread.Sheets.Tables.TableTheme](gcdocsite__documentlink?toc-item-id=f44373d6-7a91-4c68-9ab5-ad56d0f36768)实例，可以包括许多属性，如FirstrovStripstyle，headErrowstyle等。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-theme.png)

以下代码示例显示如何在tablesheet中应用内置的“professional5”主题。


```JavaScript
// 将主题应用于TableSheet变量
sheet.applyTableTheme(GC.Spread.Sheets.Tables.TableThemes.professional5);
```
