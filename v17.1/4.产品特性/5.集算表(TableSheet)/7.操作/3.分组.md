# tablesheet-grouping

TableSheet 支持通过指定字段对数据源进行分组，即自动将相同的单元格内容合并到一个单元格中。分组列位于基础列的左侧，包含以下类型的列：

* 基础列：包含原始列值
* 汇总列：包含通过用户定义公式计算的汇总结果
* 切片列：包含汇总结果的切片

下图显示了 TableSheet 分组中不同类型的列。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.200cd4.png)
您可以使用 TableSheet 类方法 `groupBy` 和 `removeGroupBy` 分别添加和移除分组。以下代码示例展示了如何添加包含汇总列和切片列的分组。

```javascript
function grouping() {
    // 通过单字段（销售包）创建分组，包含汇总字段和切片字段
    sheet.groupBy([
        {
            caption: "Selling Package", field: "sellingPackage", width: 150, style: { backColor: "#F9CA9A" },
            summaryFields: [
                {
                    caption: "SUM(Unit Price)",
                    formula: "=SUM([unitPrice])",
                    slice: { field: "=YEAR([@validFrom])", width: 120, style: { backColor: "#FCE3CA", formatter: "#,##0.00" } },
                    width: 150,
                    style: { backColor: "#FAD7B2", formatter: "#,##0.00" }
                }
            ]
        }
    ]);
}
```

## 分组布局

TableSheet 提供了表格式、轮廓和压缩三种分组布局，可以切换模式以优化分组数据的展示。

### 表格式模式

在此模式下，会为分组字段、汇总和切片生成类别或计算列。下图展示了依据“Office”列分组的表格式布局。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.1b143b.png)

```javascript
sheet.options.groupLayout.mode = GC.Spread.Sheets.TableSheet.GroupingLayout.tabular;
```

### 轮廓模式

在此模式下，分组字段名称和值会添加到标题中，并显示在每组项目之前，提供层次结构。下图展示了轮廓模式。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.02970f.png)

```javascript
sheet.options.groupLayout.mode = GC.Spread.Sheets.TableSheet.GroupingLayout.outline;
```

### 压缩模式

此模式通过将所有标题信息和汇总合并到一行中来简化显示，使标题和页脚变得更薄。下图展示了压缩模式。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.3797cf.png)

```javascript
sheet.options.groupLayout.mode = GC.Spread.Sheets.TableSheet.GroupingLayout.condensed;
```

## 限制

* 轮廓和压缩分组布局不显示切片分组配置，而表格式布局不显示位置和 relateTo 设置。
* 如果页眉或页脚中出现多个汇总结果，压缩和轮廓布局模式只显示第一个汇总结果。
* 在轮廓和压缩布局模式中，`detailColumnsVisible` 方法不起作用。

> type=warning
> 注意：您可以使用 SpreadJS Designer 应用这些分组布局设置。更多信息，请参阅 TableSheet 设计模式。
