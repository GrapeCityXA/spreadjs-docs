# tablesheet-sort-filter

TableSheet 提供了按 TableSheet 视图中的列进行排序和筛选的能力。您可以使用列头上的过筛选按钮（向下箭头图标）来显示筛选框。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-filterdialog.png)

您可以使用 IColumn 选项（例如 allowSort、allowFilterByValue 和 allowFilterByList）来控制 TableSheet筛选对话框的每个部分的可见性。

以下代码示例显示了如何在每列中使用特定的筛选项设置筛选框。


```JavaScript
//绑定视图
customerTable.fetch().then(function () {
    var view = customerTable.addView("myView", [
        { value: "customerKey", width: 150, caption: "Customer Key", allowSort: false, allowFilterByValue: false, allowFilterByList: false }, // this will disable the filter button in column header
        { value: "customer", width: 200, caption: "Customer", allowSort: false }, // this will hide only sorting in filter dropdown
        { value: "billToCustomer", width: 200, caption: "Bill To Customer", allowFilterByValue: false}, // this will hide only allowFilterByValue
        { value: "category", width: 120, caption: "Category", allowFilterByList: false }, // this will hide only allowFilterByList
        { value: "buyingGroup", width: 180, caption: "Buying Group" },
        { value: "primaryContact", width: 170, caption: "Primary Contact" },
        { value: "postalCode", width: 120, caption: "Postal Code" },
        { value: "validFrom", width: 150, caption: "Valid From" },
        { value: "validTo", width: 180, caption: "Valid To" }

    ]);
    
    sheet.setDataView(view);
});
```



### 排序

你可以通过从筛选框中选择升序或降序选项对字段中的数据进行排序。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-sort.gif)

默认情况下，TableSheet 会在修改值时自动重新排序，但您可以通过在定义 TableSheet 视图时设置 autoSort属性来禁用该行为。


```JavaScript
//绑定视图
customerTable.fetch().then(function () {
    var view = customerTable.addView("myView", [
        { value: "customerKey", width: 120, caption: "Customer Key" },
        { value: "customer", width: 200, caption: "Customer" },
        { value: "billToCustomer", width: 200, caption: "Bill To Customer" },
        { value: "buyingGroup", width: 200, caption: "Buying Group" },
        { value: "primaryContact", width: 170, caption: "Primary Contact" },
        { value: "postalCode", width: 120, caption: "Postal Code" },
        { value: "validFrom", width: 190, caption: "Valid From" }

    ]);
    //  设置autoSort为false来禁止编辑单元格值后自动排序
    view.autoSort = false;
    
    sheet.setDataView(view);
});
```



### 筛选

您可以通过筛选仅显示感兴趣的数据。/p>

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-filter.gif)

您可以使用其中一种方法来筛选TableSheet中的数据。

-  **按value筛选:** 筛选数据类型，例如数字、文本、日期。
选择筛选项目（"contains", "ends with", "greater than", "between", "before"等）后，将打开筛选框。
-  **按list筛选** : 筛选list列中存在的单个值。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-filter-types.png)

默认情况下，TableSheet 不会在修改值时自动重新筛选，但您可以通过在定义 TableSheet 视图时设置 autoFilter属性来启用该行为。

如果新值与已筛选值相同，则该属性会筛选新值。否则，无论筛选条件如何，都不会筛选任何新值


```JavaScript
customerTable.fetch().then(function () {
    var view = customerTable.addView("myView", [
        { value: "customerKey", width: 120, caption: "Customer Key" },
        { value: "customer", width: 200, caption: "Customer" },
        { value: "billToCustomer", width: 200, caption: "Bill To Customer" },
        { value: "buyingGroup", width: 200, caption: "Buying Group" },
        { value: "primaryContact", width: 170, caption: "Primary Contact" },
        { value: "postalCode", width: 120, caption: "Postal Code" },
        { value: "validFrom", width: 190, caption: "Valid From" }

    ]);
    //  将 autoFilter 设置为 true 以筛选与筛选值相同的任何新值或更新值
    view.autoFilter = true;
    
    sheet.setDataView(view);
});
spread.resumePaint();
```
