# multiple-grouping

TableSheet 支持多重分组，其中可以在 groupBy 方法中定义多个字段以创建多层次分组。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.3234dc.png)
以下代码示例展示了如何在表格视图中设置多个分组。

```javascript
function grpByMultipleFields() {
    // 先按“sellingPackage”字段分组，然后使用 DATEPART 公式按年份的季度分组
    sheet.groupBy([
        { caption: "销售套餐", field: "sellingPackage", width: 150, style: { backColor: "#FAD7B2" } },
        { caption: "年份季度", field: `=DATEPART([@validFrom],"yyyyQQQ")`, width: 150, style: { backColor: "#FCE3CA" } }
    ]);
}
```

### 多重分组的行为

在表格中应用多重分组时，布局默认会占用更多空间。以下是多重分组的一些表现方式，可以帮助更好地显示分组结果。
当一个分组被折叠时，详细列的单元格将显示为空单元格。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.e997c6.png)
当父分组被折叠时，子分组的单元格也会显示为空单元格。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.3f1324.png)
你还可以使用 expandGroup 和 expandGroupItem 方法来设置多重分组的展开或折叠状态。

### 多重分组字段

SpreadJS 已经支持多重分组。下图中标示了与多重分组相关的各个字段：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.ae6507.png)

* Grouping Header: 你可以为不同层次的分组项设置标题名称
* Grouping Footer: 你可以在分组项底部设置不同的聚合，称为分组页脚
* Aggregations: 你可以同时为不同列的独立分组标题或页脚定义不同的聚合
* Aggregation Captions: 你还可以为每个聚合公式设置别名，在显示结果时一起展示
* Summary Style: 你可以为分组标题或页脚应用各种样式，如背景色、格式化、前景色或其他字体相关属性

上述所有分组字段都可以通过 groupBy 方法应用，如以下代码示例所示：

```javascript
sheet.groupBy([ 
    { 
        field: "Office", 
        style: { foreColor: '#000000', backColor: '#a1c0c5' }, 
        summaryFields: [ 
            { 
                caption: "SUM_AMOUNT", 
                formula: '=SUM([Amount])', 
                relateTo: "Amount", 
                style: { 
                    formatter: "$ #,##0.00", 
                    backColor: '#bce4df', 
                    foreColor: '#000000' 
                } 
            }, 
            { 
                caption: "Σ(Count)", 
                formula: "=SUM([Quantity])", 
                style: { 
                    foreColor: '#000000' 
                } 
            }, 
        ]
    } 
]);
```

**Spacing**: 你可以通过设置 spacing 属性的值，为 Outline 和 Condensed 分组模式分隔分组级别项。
以下示例代码展示了如何实现 spacing 属性。

```javascript
sheet.options.groupLayout = { 
    mode: GC.Spread.Sheets.TableSheet.GroupLayoutMode.outline, 
    spacing: { 
        row: 20 
    } 
}; 
```

**Position**: 你可以使用 position 属性将默认的汇总位置从标题更改为页脚。
以下示例代码展示了如何实现 position 属性。

```javascript
sheet.options.groupLayout.position = 'footer';
```
