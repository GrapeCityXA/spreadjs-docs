# spread-object-data

集算表创建一个具有默认列的视图，其中**字段**对象显示为一个对象列。SpreadJS 允许您构建一个视图，将字段对象显示为多列。从服务器获取 JSON 文件并通过指定要传播的对象列来更新数据源架构。
您可以通过使用表格代码的架构列定义中的**spread**属性将列展开为第一级属性来展平分层数据。这种将嵌套对象展开为普通对象的能力使用户阅读表格更加容易和方便。
下面的代码显示了定义的数据源。


以下代码示例显示如何在定义架构的列时将列字段的 spread 属性设置为 true。

```json
// data source schema
      schema: 
        { 
          dataPath: 'records', 
             columns: 
                {
                   fields: { spread: true }
                } 
        } 
```

### 使用点分隔符

在 SpreadJS 中，您还可以使用点分隔符作为 spread 属性的替代方法。将视图绑定到表格时可以使用点分隔符。
以下代码示例显示如何使用点分隔符将视图绑定到表格。

```javascript
//bind a view to the table sheet 
 customerTable.fetch().then(function (data) 
 { 
     var view = customerTable.addView("myView", 
       [ 
          "customerKey", 
          "customer", 
          "fields.billToCustomer", 
          "fields.category", 
          "fields.postalCode", 
          "fields.validTo" 
     ], 
     undefined, 
      { 
       defaultColumnWidth: "*" 
      }); 
//the View has all default columns of the Table 
sheet.setDataView(view); 
}); 
```
