# rotate-text-in-cells

SpreadJS允许用户旋转单元格中的文本。 此功能可帮助用户变更数据在单元格中的显示方式。

用户可以在使用表单时将字体角度从-90度旋转到+90度（包括45°，90°，-45°，-90°等），或根据自己的喜好变更数据对齐方式。 可以按向上，向下，顺时针或逆时针方向旋转文本，如以下共享的截图所示：

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/spreadjsv13images/rotate1.png)



### 使用场景

文本旋转很有用，尤其是在以下情况下：

- 用户正在使用具有数百列的大型表单进行工作，并且列标题中的文本比单元格中的文本长。 在这种情况下，最好旋转标题中的文本，以使列变窄，并且在分析数据时可以在视口中看到最大的列标题数。
- 用户希望在较小的区域中容纳更多的数据列，以轻松，快速地管理批量数据。



### 旋转单元格中的文本

当要旋转的文本是普通文本或文本为计费格式时，则填充的字符数将与单元格高度相关。 如果用户调整单元格高度，则文本将动态变更。

下图显示了表单中不同公司的年销售收入，其中文本旋转功能以及边框样式和自定义背景色应用于单元格。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/spreadjsv13images/rotate5.png)

旋转单元格中的文本时，以下表单功能将受到影响：

- 文本对齐 - 旋转角度将影响文本的顺序。 旋转角度为负数时，从右到左显示文本。 当旋转角度为正时，则从左到右显示文本。
- 自动换行 - 只有当前单元格的高度会影响自动换行功能。
- 单元格溢出 - 这与水平对齐有关。 当“ hAlign = left”时，文本将在右边；当“ hAlign = right”时，文本将在左边。
- 文本缩进 - 如果单元格中的文本缩进，则文本旋转功能将不起作用。
- 缩小以适应 - 对于会计格式的文本，将消除重复字符，因此，文本将缩小以适合单元格。
- 文本修饰-旋转文本时，占位符也将具有文本修饰，就像在Excel中一样。
- 隐藏文本和自动调整-旋转后的高度超过当前单元格的高度时，文本将隐藏视口上方的多余文本，并且rowHeightAutoFit将根据旋转后的垂直长度进行计算。 对于会计格式的文本，将消除重复字符，因此，文本将自动适合单元格。



### 旋转单元格边框与背景

当用户在表单的单元格（包含数据值）中应用文本旋转时，边框和背景色也将旋转到相应的角度。 旋转后，文本的位置将根据单元格的位置自动进行调整，如下面的截图所示：

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/spreadjsv13images/rotate-2.png)

当用户设置背景颜色时，只有当单元格包含一个值并具有任意边框时，背景颜色的旋转才会生效，以便背景可以填充旋转的边框区域。
> **注意:** 当用户设置背景颜色时，只有当单元格包含一个值并具有任意边框时，背景颜色的旋转才会生效，以便背景可以填充旋转的边框区域。 


### 代码

请参考以下示例代码，以在使用表单时旋转单元格中的文本。


```JavaScript
// 初始化 Spread
var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });

// 获取表单
var activeSheet = spread.getActiveSheet();
// 准备数据
activeSheet.setValue(1, 1, "Company Sales Data");
activeSheet.setValue(1, 3, "Year-2015");
activeSheet.setValue(1, 4, "Year-2016");
activeSheet.setValue(1, 5, "Year-2017");
activeSheet.setValue(1, 6, "Year-2018");
activeSheet.setValue(1, 7, "Year-2019");
activeSheet.setValue(2, 2, "Gradlco");
activeSheet.setValue(3, 2, "Saagiate");
activeSheet.setValue(4, 2, "Inferno");
activeSheet.setColumnWidth(1, 120);
for (var r = 2; r <= 4; r++) {
for (var c = 3; c < 8; c++) {
activeSheet.setValue(r, c, parseInt(Math.random() * 5000));
}
}
// 使用TextOrientation创建样式并将其应用于一系列单元格
var style = new GC.Spread.Sheets.Style();
style.textOrientation = 60;
style.backColor = "pink";
style.foreColor = "red";
for (var i = 3; i < 8; i++)
activeSheet.setStyle(1, i, style, GC.Spread.Sheets.SheetArea.viewport);
// 设置行高
activeSheet.setRowHeight(1, 60, GC.Spread.Sheets.SheetArea.viewport);
activeSheet.addSpan(1, 1, 4, 1, GC.Spread.Sheets.SheetArea.viewport);

// 为Cell（1,1）设置textOrientation，此单元格没有边框。
activeSheet.getCell(1, 1).textOrientation(60);
activeSheet.getCell(1, 1).hAlign(GC.Spread.Sheets.HorizontalAlign.center);
activeSheet.getCell(1, 1).hAlign(GC.Spread.Sheets.VerticalAlign.center);
activeSheet.getCell(1, 1).backColor("LightBlue");
// 设置单元格的边框
activeSheet.getRange(1, 3, 4, 5, GC.Spread.Sheets.SheetArea.viewport).setBorder(new GC.Spread.Sheets.LineBorder("Blue", GC.Spread.Sheets.LineStyle.medium), { all: true }, 3);

// 设置单元格的backColor
for (var i = 2; i < 5; i++)
activeSheet.getCell(i, 2).backColor("lightGray");
```
