# SetVerticalTextDirectioninaCell

SpreadJS允许用户根据自己的喜好设置单元格中的文本方向，就像在Excel中一样。这增强了电子表格中数据呈现的灵活性和可读性。

### 垂直文本方向

当您在单元格中输入文本时，字母默认是水平显示的。然而，如果您希望文本垂直显示，可以将文本样式设置为垂直，如下图所示。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.f9dd95.png)
要将单元格中的文本方向切换为垂直方向，您可以使用CellRange类的isVerticalText方法。该方法接受布尔参数——true或false。当在此方法中传递布尔值true时，表示文本将垂直显示；传递布尔值false时，表示文本将水平显示（与默认情况相同）。

SpreadJS中的垂直文本方向功能支持水平和垂直对齐。您可以通过自定义vAlign方法（用于垂直对齐）和hAlign方法（用于水平对齐）来指定对齐样式。如下图所示。

#### 使用vAlign和hAlign设置垂直文本方向

您还可以在设置单元格中的垂直文本方向时使用textIndent方法控制文本缩进。如下图所示。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.e78600.png)
当单词在垂直文本中看起来太长而无法适应单元格时，您可以使用wordWrap方法使其适应同一个单元格。如下图所示。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.2d8fff.png)
如果不希望在单元格中使用自动换行，可以使用shrinkToFit方法让Spread自动缩小垂直文本的字体大小。如下图所示。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.939137.png)
如果不想在单元格中同时使用自动换行和适应缩放功能，可以使用AutoFitType枚举让Spread自动调整单元格的宽度和高度以适应所有内容。如下图所示。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.b9ecbd.png)
以下代码示例通过在isVerticalText方法中传递布尔值“true”来设置D4单元格中的垂直文本方向。

```javascript
var sheet = spread.getActiveSheet();
sheet.setRowHeight(3, 150);
sheet.getCell(3, 3).value("SpreadJS").isVerticalText(true);
sheet.getCell(3, 4).value("SpreadJS").isVerticalText(false);
```

### 从右到左的文本方向

在SpreadJS中，您可以将单元格中的文本方向从左到右更改为从右到左，甚至标点符号也会显示在文本左侧。可以使用TextDirectionType枚举通过设置样式的textDirection属性为rightToLeft来实现。
这可以适应从右至左书写和阅读的语言和文字。

> type=warning
> 注意：目前，SpreadJS仅为阿拉伯语和希伯来语字母指定了从右到左的文本方向。

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.09e653.png)
以下代码示例使用TextDirectionType枚举来设置文本方向。

```javascript
// 此示例使用getCell方法和textDirection方法。
activeSheet.getCell(0, 0).textDirection(GC.Spread.Sheets.TextDirectionType.rightToLeft).value("هذه الفقرة باللغة العربية ، لذا يجب الانتقال من اليمين إلى اليسار。");

// 或
// 此示例使用getRange方法和textDirection方法。
activeSheet.getRange(1, -1, 1, -1).textDirection(GC.Spread.Sheets.TextDirectionType.rightToLeft);
activeSheet.setValue(1, 1, "هذه الفقرة باللغة العربية ، لذا يجب الانتقال من اليمين إلى اليسار。");
activeSheet.setValue(1, 3, "هذه الفقرة باللغة العربية ، لذا يجب الانتقال من اليمين إلى اليسار。");

// 或
// 此示例使用setStyle方法与textDirection属性。
var style = new GC.Spread.Sheets.Style();
style.textDirection = GC.Spread.Sheets.TextDirectionType.rightToLeft;
activeSheet.setStyle(2, 2, style, GC.Spread.Sheets.SheetArea.viewport);
activeSheet.setValue(2, 2, "هذه الفقرة باللغة العربية ، لذا يجب الانتقال من اليمين إلى اليسار。");
```

SpreadJS中的文本方向支持打印和导出为PDF文件。在导入/导出.sjs、.ssjson和.xlsx文件时也支持文本方向。

> type=warning
> 注意：从右到左的文本方向不支持图表、形状、注释和切片器。此外，SpreadJS Designer不允许在TableSheets、GanttSheets和ReportSheets中更改文本方向。

### 限制

* 从右到左的文本方向不适用于英文、中文、日文和韩文字符。
