# editmode

您可以将单元格设置为在用户单击时始终处于编辑模式。 通常，用户在单元格进入编辑模式之前输入或双击。

设置 **startEdit** 方法在 **EnterCell** 事件，一旦用户单击或使用选项卡或Enter进入单元格，单元格便进入编辑模式。

如果将 **startEdit** 方法中的 *selectAll* 参数设置为true，则当在编辑过程中变更文本时，它将选择所有文本。



#### 示例代码

本示例在用户单击单元格时将其置于编辑模式。


```JavaScript
window.onload = function()
{
   var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"),{sheetCount:3});
   var activeSheet = spread.getActiveSheet();
  // 设置为始终处于输入模式。
   spread.bind(GC.Spread.Sheets.Events.EnterCell, function (event, data)
  {
     var sheet = data.sheet;
     activeSheet.startEdit(false);
   });
 }
```

本示例在编辑开始时选择文本。
