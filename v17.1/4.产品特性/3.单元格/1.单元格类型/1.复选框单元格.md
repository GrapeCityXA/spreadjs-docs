# cellcheckbox

您可以使用复选框单元格在一个单元格中显示一个复选框。 复选框单元格显示一个小复选框，该复选框可以具有以下三种状态之一：选中，未选中或不确定。 您可以通过设置文本来自定义复选框。

设置 **isThreeState** 方法为 true 显示三个状态而不是两个（选中或未选中）. 您还可以使用 **textAlign** 方法指定复选框和文本的对齐方式。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/cellcheckbox.png)

您可以使用 **value** 方法在代码中设置复选框的状态，如下表所示：

|  **值**  |  **状态**  |
|--- |--- |
| null | 不定 |
| 0 | 未勾选 |
| 1 | 勾选 |



#### 示例代码

本示例创建一个具有三个状态的复选框单元格。


```JavaScript
// Get the activesheet
var activeSheet = spread.getSheet(0);
var cellType = new GC.Spread.Sheets.CellTypes.CheckBox();
cellType.caption("caption");
cellType.textTrue("True");
cellType.textFalse("False");
cellType.textIndeterminate("Indeterminate");
cellType.textAlign(GC.Spread.Sheets.CellTypes.CheckBoxTextAlign.bottom);
cellType.isThreeState(true);
cellType.boxSize(20);
activeSheet.getCell(1, 1).cellType(cellType);
// activeSheet.getCell(1, 1).value(1);
```
