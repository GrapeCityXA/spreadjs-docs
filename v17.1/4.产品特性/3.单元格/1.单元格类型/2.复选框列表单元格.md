# check-box-list-cell

SpreadJS允许用户在表单的单元格中创建复选框列表。



### 什么是复选框列表单元格？

复选框列表单元格是指交互式检查列表或具有多选字段值的待办事项列表。 它通过嵌入单个单元格中的多个复选框（小方形选择框）显示一组项目。 用户可以单击复选框以选择或取消选择特定选项。



### 使用场景

当用户在使用表单时需要在一个单元格中选择多个字段值时，复选框列表单元格类型将很有帮助。 借助复选框列表，用户可以快速高效地创建客户反馈调查，输入表单，交互式清单和动态报告。 **示例** - 假设您想以一种简单有效的方式来分析公司产品的最终用户响应。 在这种情况下，在表单中创建一个用户友好的复选框列表是记录客户响应的好主意，如以下截图所示：![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/spreadjsv13images/checkbox.png)



### 自定义复选框列表单元格

在SpreadJS中使用复选框列表单元格类型时，用户可以执行以下任务，以便根据其特定首选项对其进行自定义：

- 用户可以使用 **textAlign()** 方法设置文本对齐。 可用选项 **TextAlign** 枚举为左与右
- 用户可以使用 **isFlowLayout()** 方法来识别复选框列表的布局是否自动调整。 默认情况下，此方法的value参数设置为“ true”。
- 用户可以使用 **Direction** 枚举将复选框列表单元格类型的方向设置为水平或垂直
- 用户可以使用 **maxRowCount()** 方法和 **maxColumnCount()** 方法获取或设置复选框列表的行数和列数的项目。只有当的值参数 **isFlowLayout()** 方法设为true并且方向是水平的才可以实现。
- 用户可以在两个列表项之间配置间距，以避免单元格内列表项内的拥塞和混乱。 通过使用 **itemSpacing()** 方法可以实现。



### 代码

请参考以下示例代码，以在使用表单时在单元格中创建基本的复选框列表。


```JavaScript
<script>
$(document).ready(function ()
{
// 初始化 Spread
 var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });

// 获取表单
 var activeSheet = spread.getSheet(0);

// 本示例创建一个CheckBoxList单元格类型
var checkBoxListCellType = new GC.Spread.Sheets.CellTypes.CheckBoxList();
activeSheet.getCell(0, 1).font("italic 16px Calibri");
activeSheet.getCell(0, 1).foreColor("Red");
activeSheet.getCell(0, 1, GC.Spread.Sheets.SheetArea.viewport).value("What factors are important to you when buying software products? ").wordWrap(true);
checkBoxListCellType.items([{ text: "Price", value: 1 }, { text: "Usability", value: 2 }, { text: "Features", value: 3 }, { text: "Support", value: 4 }, { text: "Others", value: 5 }]);

// 在CheckBoxList中配置两个项目的间距
checkBoxListCellType.itemSpacing({
horizontal: 20, vertical: 10
});

// 将checkBoxListCellType配置为纵向
checkBoxListCellType.direction(GC.Spread.Sheets.CellTypes.Direction.vertical);

// 配置文本在CheckBoxList中的位置，仅支持向左和向右
checkBoxListCellType.textAlign(GC.Spread.Sheets.CellTypes.CheckBoxTextAlign.right);
  // 在复选框列表中配置复选框大小，仅支持数字和“自动”
  checkBoxListCellType.boxSize(20);
activeSheet.getCell(1, 1).cellType(checkBoxListCellType);

// 配置行高
activeSheet.setRowHeight(0, 70.0, GC.Spread.Sheets.SheetArea.viewport);
activeSheet.setRowHeight(1, 140.0, GC.Spread.Sheets.SheetArea.viewport);

// 配置列宽
activeSheet.setColumnWidth(1, 200.0, GC.Spread.Sheets.SheetArea.viewport);
});
</script>
```
