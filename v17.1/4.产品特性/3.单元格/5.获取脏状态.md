# dirty

您可以获取单元格和行的脏状态。

更换单元会导致设置为脏状态。 如果单元格脏了，则当前行也脏了。

加载绑定的数据时，单元格不是脏数据。将单元绑定到数据源后对其进行变更会设置脏状态。

如果在插入行时设置了值，则将行视为插入行，而不是脏行。 设置行数或列数后，或使用fromJSON和toJSON方法时，将清除脏状态。

你可以通过 **clearPendingChanges** 方法清除脏数据状态。 你可以获取脏行和单元格通过 **getDirtyRows** 与 **getDirtyCells** 方法。



#### 示例代码

编辑单元格以设置脏状态。 选择按钮以清除脏状态。


```JavaScript
var customers = [
           { ID: 0, Name: 'A', Info1: 'Info0' },
           { ID: 1, Name: 'B', Info1: 'Info1' },
           { ID: 2, Name: 'C', Info1: 'Info2' },
        ];
        activeSheet.setDataSource(customers);
$("#button1").click(function () {
activeSheet.clearPendingChanges();
});
// 将按钮控件添加到页面
<input type="button" id="button1" value="button1"/>
```
