# SettingCodabar

Codabar是使用字母数字字符的条形码，包括：A B C D +-：。 / $和所有数字。

下面共享了描绘Codabar迷你图的截图。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/codabar.png)



#### 公式定义

您可以使用以下公式在表单中设置codabar迷你图：

=BC_CODABAR(value, color, backgroudColor, showLabel, labelPosition, checkDigit, nwRatio, fontFamily, fontStyle, fontWeight, fontTextDecoration, fontTextAlign, fontSize, quietZoneLeft, quietZoneRight, quietZoneTop, quietZoneBottom)



#### 参数

| 名称 | 描述 |
|--- |--- |
| value | 表示条形码编码的数据 |
| color | 条形码的字体颜色(默认值是 'rgb(0,0,0)') |
| backgroundColor | 条形码的背景色(默认值是'rgb(255, 255, 255)') |
| showLabel | 是否显示条形码标注 |
| labelPosition | 表示标签位置的值显示标签时。 |
| checkDigit | 指定符号是否需要校验位。 默认值为“ false”。 |
| nwRatio | 代表宽窄条比率的值。 它的值为2 | 3。 默认值为“ 3”。 |
| fontFamily | 一个字符串，代表标签文本fontFamily。 默认值为“ sans-serif”。 |
| fontStyle | 一个字符串，表示标签文本fontStyle。 默认值为“正常”。 |
| fontWeight | 一个字符串，表示标签文本fontWeight。 默认值为“正常”。 |
| fontTextDecoration | 条形码标记的装饰线(默认值是 'none') |
| fontTextAlign | 一个字符串，表示标签文本fontTextAlign。 默认值为“中心”。 |
| fontSize | 一个字符串，代表标签文本fontSize。 默认值为“ 12px”。 |
| quietZoneLeft | 条形码左侧静默区的大小 |
| quietZoneRight | 代表右区域大小的值。 |
| quietZoneTop | 代表顶部区域大小的值。 |
| quietZoneBottom | 代表底部区域大小的值。 |



#### 示例代码

此示例代码在表单中设置Codabar迷你图。


```JavaScript
var sheet = spread.getActiveSheet();
// 设置Codabar条形码迷你图
sheet.setValue(3, 1, "Codabar", GC.Spread.Sheets.SheetArea.viewport);
sheet.setValue(3, 2, "9787560044231", GC.Spread.Sheets.SheetArea.viewport);
// 设置样式
sheet.setRowHeight(3, 100);
for (var col = 1; col < 4; col++)
{
sheet.setColumnWidth(col, 200);
}
sheet.getRange(3, 0, 1, 4).hAlign(GC.Spread.Sheets.HorizontalAlign.center);
sheet.getRange(3, 0, 1, 4).vAlign(GC.Spread.Sheets.VerticalAlign.center);
// 设置公式
sheet.setFormula(3, 3, '=BC_CODABAR(C4)');
```
