# SettingQRCode

QRCode是二维条形码，代表符号系统，可有效处理数字，字母数字和字节数据。 该条形码最多可编码7,366个字符。

下面共享了描绘QRCode条码迷你图的截图。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/qrcode.png)



#### 公式定义

您可以使用以下公式在表单中设置QRCode迷你图：

=BC_QRCODE(value, color, backgroundColor, errorCorrectionLevel, model, version, mask, connection, connectionNo, charCode, charset, quietZoneLeft, quietZoneRight, quietZoneTop, quietZoneBottom)



#### 参数

| 名称 | 描述 |
|--- |--- |
| value | 表示条形码编码的数据 |
| color | 条形码的字体颜色(默认值是 'rgb(0,0,0)') |
| backgroundColor | 条形码的背景色(默认值是'rgb(255, 255, 255)')。 |
| errorCorrectionLevel | 一个字符串，代表QRCode的纠错级别。 它具有'L | M | Q | H'四个错误校正级别。 默认值为“ L”。 |
| model | 代表QRCode模型的值。 它有1和2个模型。 预设值为2。 |
| version | 模型1和模型2的版本范围是1-14。它具有'auto | 1-14 | 1-40'值。 默认值为“auto”。 |
| mask | 代表QRCode的掩码图案的值。 它具有“auto和0-7”八个遮罩图案。 |
| connection | 一个值，该值表示符号是否是结构化附加消息的一部分。 默认值为false。 |
| connectionNo | 指定符号在结构化附加消息中位于哪个块。 它具有“ 0-15”值。 默认值为“ 0”。 |
| charCode | 一个表示QRCode字符集合的值。 |
| charset | 代表要使用的字符集的值。 它具有“ UTF-8和Shift-JIS”。 |
| quietZoneLeft | 条形码左侧静默区的大小 |
| quietZoneRight | 条形码右侧静默区的大小 |
| quietZoneTop | 条形码上侧静默区的大小 |
| quietZoneBottom | 条形码下侧静默区的大小 |



#### 示例代码

此示例代码在表单中设置QRCode迷你图。


```JavaScript
var sheet = spread.getActiveSheet();
// 设置QR Code条码迷你图
sheet.setValue(3, 1, "QR Code", GC.Spread.Sheets.SheetArea.viewport);
sheet.setValue(3, 2, "Police:911", GC.Spread.Sheets.SheetArea.viewport);
// 设置样式
sheet.setRowHeight(3, 100);
for (var col = 1; col < 4; col++)
{
sheet.setColumnWidth(col, 200);
}
sheet.getRange(3, 0, 1, 4).hAlign(GC.Spread.Sheets.HorizontalAlign.center);
sheet.getRange(3, 0, 1, 4).vAlign(GC.Spread.Sheets.VerticalAlign.center);
// 设置公式
sheet.setFormula(3, 3, '=BC_QRCODE(C4)');
```
