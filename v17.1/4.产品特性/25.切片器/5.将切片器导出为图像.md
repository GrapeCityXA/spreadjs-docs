# export-slicers-as-image

SpreadJS 支持将切片器导出为图像源。添加切片器后，可以使用 slicer.toImageSrc() API 获取图像源

> type=warning
> 注意：只有表格切片器和数据透视表切片器可以使用 toImageSrc() 方法导出为图像

### 代码示例

以下代码示例展示了如何将电子表格上的表格切片器保存为图像源。

```javascript
// 创建一个表格。
var datas = [
    ["1", "NewYork", "1968/6/8", "80", "180"],
    ["4", "NewYork", "1972/7/3", "72", "168"],
    ["4", "NewYork", "1964/3/2", "71", "179"],
    ["5", "Washington", "1972/8/8", "80", "171"],
    ["6", "Washington", "1986/2/2", "89", "161"],
    ["7", "Washington", "2012/2/15", "71", "240"]
];
var table = sheet.tables.addFromDataSource("table1", 2, 2, datas);
var dataColumns = ["Name", "City", "Birthday", "Weight", "Height"];
table.setColumnName(0, dataColumns[0]);
table.setColumnName(1, dataColumns[1]);
table.setColumnName(2, dataColumns[2]);
table.setColumnName(3, dataColumns[3]);
table.setColumnName(4, dataColumns[4]);

// 向工作表添加切片器并返回切片器实例。
var slicer = sheet.slicers.add("slicer1", table.name(), "Name");

// 更改切片器属性。
slicer.width(200);
slicer.height(200);
slicer.position(new GC.Spread.Sheets.Point(100, 200));
slicer.style(GC.Spread.Sheets.Slicers.SlicerStyles.dark4());

// 获取切片器的图像源。
let slicerImageSrc = sheet.slicers.all()[0].toImageSrc();
```

### 使用设计器

在 Spread Designer 中选择一个切片器后，也可以通过点击“另存为图片”选项将其保存为图像。
以下是将切片器保存为图像的步骤：

1. 打开工作表
2. 插入数据
3. 插入切片器
4. 右键点击切片器，然后点击“另存为图片”
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.fa450a.png)
5. 选择要保存图像的位置
6. 命名文件并点击“保存”

> type=warning
> 注意：
>
> * 在导出为图像过程中，切片器会保留当前选择和鼠标悬停状态
> * 目前，导出的文件格式为 PNG，文件名为切片器名称
> * 如果选择了多个切片器对象，它们将一起导出，默认文件名为 SpreadShapes
