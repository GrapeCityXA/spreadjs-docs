# scrollbars

您可以隐藏或显示垂直或水平滚动条。

使用拇指栏（拖动按钮）滚动控件的大区域。 使用带有箭头的按钮一次滚动行或列。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/scrollbar.png)

您可以使用 **options.scrollbarMaxAlign** 属性指定是否将滚动条与活动表单的最后一行和最后一列对齐。 您可以使用 **options.scrollbarShowMax** 属性来指定显示的滚动条是否基于表单中的列和行的总数。

您可以使用 **options.scrollIgnoreHidden** 属性指定是否忽略隐藏的行或列。 这适用于宽度或高度为零的列或行，使用 **visible** 方法隐藏的列或行，折叠或分组的列或行或筛选出的行。



#### 示例代码

下面的示例隐藏垂直和水平滚动条.


```JavaScript
spread.options.showHorizontalScrollbar = false;
spread.options.showVerticalScrollbar = false;
```
