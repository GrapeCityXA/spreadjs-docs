# select_multiple_worksheets

SpreadJS允许用户选择多个表单并对其执行删除或隐藏操作。 **isSelected** 属性可用于选择或取消选择多个表单。 选择多个表单时，可以使用上下文菜单选项对其进行隐藏或删除操作。

下图描绘了一个表单的多个选定的表单。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/Multi_select.PNG)



使用 **isSelected** 属性或 **SheetChanging** 事件，也可以变更活动表单的选定状态。 取消选择活动表单后，其视图将变为 **activeNotSelected。** 即使使用 **reset <!-- strong-->方法，表单的选定状态也会保留。**
