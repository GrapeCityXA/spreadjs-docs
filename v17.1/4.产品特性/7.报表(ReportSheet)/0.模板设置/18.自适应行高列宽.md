# auto-fit-template-cell

在 ReportSheet 中，自动调整功能会在生成报告时自动调整列宽和行高以适应内容。为此，您需要在 `setTemplateCell` 方法中配置 `autoFit` 属性。
在使用 ReportSheet 时，您可以为自动调整操作设置以下枚举值：

* None（无）
* Row（行）
* Column（列）

### 使用代码

以下代码示例显示了如何为模板单元格设置自动调整类型。

```javascript
// 将 autoFit 属性设置为 Row（行）。
templateSheet.setTemplateCell(1, 0, {
    type: 'List',
    binding: Orders[orderDate],
    autoFit: 'Row',
});

// 将 autoFit 属性设置为 Column（列）。
templateSheet.setTemplateCell(1, 2, {
    type: 'List',
    binding: Orders[shipName],
    autoFit: 'Column',
});

// 将 autoFit 属性设置为 None（无）。
templateSheet.setTemplateCell(1, 3, {
    type: 'List',
    binding: Orders[shipAddress],
    autoFit: 'None',
});
```

> type=warning
> 注意事项：
>
> * ReportSheet 支持在同一报告中组合行和列的自动调整。这意味着您可以对不同的模板单元格应用不同的自动调整类型。
> * 当 `autoFit` 属性值小于模板中设置的尺寸时，自动调整操作不会减少行高或列宽。
> * 在预览模式下，如果单元格的 `autoFit` 属性设置为 'Row' 且该单元格是行合并的一部分，它将扩展跨距的最后一行。同样，设置为 'Column' 的单元格将扩展跨距的最后一列
