# filter-condition

在某些条件下，用户只想看到经过一些条件筛选后的数据，或者他们想在一个报告中通过主外键合并多个数据表。
在这种情况下，SpreadJS 允许你在模板单元格中设置过滤条件来筛选数据。
要在报表模板中配置数据过滤条件，需要在 DataManager 中定义表格源，在模板单元格中配置`tableName`和`columnName`（位于`dataColumn`选项内），最后使用模板单元格中的`filter`属性添加所需的过滤条件。
可以使用以下任何方法在报表中过滤数据。

* 通过静态值过滤数据
* 通过公式过滤数据
* 通过连接表过滤数据

数据过滤的几个条件规则如下：

| 过滤条件规则 | 描述 |
| ------ | --- |
| **filterByCondition** |  |
| ConditionRuleValueType | 静态过滤条件，过滤值数据类型为字符串<br>根据`ConditionRuleOperator`和值来过滤记录 |
| ConditionRuleCellType | 单元格名称（如A1）<br>当单元格值为静态值时，过滤条件与ConditionRuleValueType相同<br>当单元格具有dataColumn数据绑定时，过滤条件与ConditionRuleDataColumnType相同 |
| ConditionRuleDataColumnType | 表连接条件，通过ConditionRuleOperator将当前表列与目标表列连接。 |
| ConditionRuleParameterType | 使用现有参数名称的静态过滤条件。 |
| ConditionRuleFormulaType | 静态过滤条件，用户可以在此处设置公式。 |
| **filterByFormula** |  |
| FilterConditionFormulaRule | 静态过滤条件，用于过滤与公式规则匹配的记录<br>此处，SpreadJS不支持公式中的单元格引用，例如“=YEAR([@orderDate])=A1” |
| ConditionRule | ConditionRule列是带有表字段的公式 |

以下代码示例展示了数据过滤的几种用法：

```auto
// ConditionRule value is static value. 
// Filter by CustomerId Equals to "VINET".
templateSheet.setTemplateCell(2, 0, {
       type: "Group",
       binding: `Orders[customerId]`,
       filter: {
            condition: {
                 column: "customerId",
                 operator: "Equal",
                 value: "VINET"
            }
       }
});
templateSheet.setTemplateCell(2, 1, {
      type: "Group",
      binding: `Orders[employeeId]`,
});

// ConditionRule Value is CellName, cell value is static value.
templateSheet.setValue(1, 0, 'VINET');
templateSheet.setTemplateCell(1, 1, {
        type: "Group",
        binding: `Orders[customerId]`,
        filter: {
           condition: {
                  column: "customerId",
                  operator: "Equal",
                  cell: "A2"
            }
       }
});
templateSheet.setTemplateCell(1, 2, {
        type: "Group",
        binding: `Orders[employeeId]`,
});

// Join Table Condition.
// Add table relationship.
spread.dataManager().addRelationship(customerTable, "Id", "orderTable", ordersTable, "customerId", "customerTable");
templateSheet.setTemplateCell(2, 1, { // B1
         type: "List",
         binding: "Customers[CompanyName]",
         filter: {
               "condition": {
                        "column": "id",
                        "operator": "Equal",
                        "dataColumn": {
                            "tableName": "Orders",
                            "columnName": "customerId"
                        }
               }
       }
});
```

### 使用设计器过滤数据

您也可以通过报告单元属性面板中可用的过滤选项，使用设计器来过滤数据。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca82939a-5d1a-4838-9f3f-69a0f7ebeeb5/image.16cb86.png?width=250)
您可以添加多个静态过滤条件、表连接条件或公式过滤条件，并且还可以在过滤对话框中更改规则顺序或删除规则。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca82939a-5d1a-4838-9f3f-69a0f7ebeeb5/image.089740.png)
以下表格展示了过滤对话框中存在的属性以及它们的描述：

| 属性 | 描述 |
| --- | --- |
| 关系 | 显示两个条件之间的关系。 |
| 列 | 展示当前节点表格列的列表。您也可以使用表格列输入公式，例如 =YEAR([@orderDate])。 |
| 操作符 | 展示所有过滤条件操作符列表。 |
| 值 | 用于切换到不同的数据类型并输入数据值。 |
| 括号 | 用于改变条件的优先级。左括号和右括号必须始终匹配。 |
| 规则类型 | 指定过滤规则的类型。如果类型是条件，您可以选择列、操作符或值。如果规则类型是公式，只能设置公式值。 |
