# condition-format

条件格式化是一项功能，允许您根据特定条件对单元格应用格式设置。您可以使用工作表在报表模板上设置条件格式。
当报表生成时，条件格式的范围可能会随着单元格的变化而变化。您可以使用`ConditionalFormats`类的`addCellValueRule`方法添加新的条件格式化规则。
注意：

* 条件格式化适用于报表模板，但当切换到预览模式时，其性能会得到提升
* 如果条件格式化应用于报表模板上的单元格不是扩展单元格，则报表单元格范围内存在的条件格式的大小不会改变，但可能会有一些偏移（用于扩展的左上角存在单元格）
* 如果条件格式化放置于报表模板上的单元格是扩展单元格，则报表单元格范围内当前条件格式的大小将会变化，并且范围会以与模板单元格相同的方式扩展。也可能会有一些偏移（用于扩展的左上角单元格）

以下代码示例设置了一个条件格式化规则，如果特定单元格的值小于或等于15，则应用红色。

```auto
const cfs = templateSheet.conditionalFormats;

// Create a new Style.
const style = new GC.Spread.Sheets.Style();
style.foreColor = 'red';

// Define the Ranges.
const ranges = [new GC.Spread.Sheets.Range(2, 2, 1, 1)];

// Display the ForeColor as "red" if the value is less than or equal to 15.
cfs.addCellValueRule(GC.Spread.Sheets.ConditionalFormatting.ComparisonOperators.lessThanOrEqualsTo, 15, 15, style, ranges);
```
