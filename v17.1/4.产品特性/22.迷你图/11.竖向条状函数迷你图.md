# sparkvbar

您可以使用 **VBARSPARKLINE** 公式和单元格值创建竖向条状函数迷你图。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/vbar-sparkline.png)

迷你图从正值的单元格底部开始，向负值的单元格顶部开始。 如果该值大于100％或小于-100％，则显示箭头。

竖向条状函数迷你图具有以下选项：

|  **选项**  |  **描述**  |
|--- |--- |
| value | 类型为数字或者引用，表示这个条的长度，比如 0.3 或者 "A1"。如果这个值大于100% 或者小于 -100%，将会出现一个箭头。 |
| colorScheme | （可选参数）类型为颜色字符串，表示条的填充色的字符串；默认值是 "gray"。 |
| axisVisible | (可选参数) 类型为布尔值，表示轴是否可见，默认值为true。 |
| barWidth | (可选参数) 类型为数值，表示相对于单元格宽度的百分比线条宽度，值需大于0且小于等于1. |

竖向条状函数迷你图公式具有以下格式：


```text
=VBARSPARKLINE(value, colorScheme, axisVisible, barWidth)
```





#### 代码

以下代码创建竖向条状函数迷你图。


```JavaScript
// 初始化 Spread
var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });
// 获取表单
var activeSheet = spread.getSheet(0);
activeSheet.setValue(0, 0, .4);
activeSheet.setValue(1, 0, -.4);
activeSheet.setValue(2, 0, 2);
activeSheet.setFormula(0, 1, '=VBARSPARKLINE(A1,"red", FALSE, 0.8)');
activeSheet.setFormula(1, 1, '=VBARSPARKLINE(A2,"blue")');
activeSheet.setFormula(2, 1, '=VBARSPARKLINE(A3,"green", TRUE, A3)');

for (var i = 0; i < 4; i++) {
activeSheet.setRowHeight(i, 50);
}
```
