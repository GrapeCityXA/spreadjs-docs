# formula-edit-panel

长而复杂的公式在狭窄的公式栏或单个单元格框中很难查看和编辑。因此，公式编辑器允许您以多行显示并缩进长而复杂的公式，以便于阅读和编辑。
SpreadJS提供了这个功能作为一个插件，它依赖于 `gc.spread.sheets.formulapanel.x.x.x.min.js` 脚本文件。
因此，您需要在应用程序中包含这个脚本文件来使用公式编辑器面板。为了使工作簿与公式编辑器面板同步工作，您需要使用 `attach()` 方法将它们绑定在一起。
以下代码示例将工作簿绑定到公式编辑器面板。

```javascript
let workbook = new GC.Spread.Sheets.Workbook("spread-host");
let formulaEditor = new GC.Spread.Sheets.FormulaPanel.FormulaEditor("formula-editor-host");
formulaEditor.options.formatWidthLimit = -1;
formulaEditor.options.tabSize = 4;
formulaEditor.attach(workbook);
......
<!--DOM element-->
<div id="spread-host" style="width:100%; height:250px;border: 1px solid gray;"></div>
<div id="formula-editor-host" style="width:100%; height:300px;border: 1px solid gray;"></div>
```

公式编辑器提供了\*\*`formatWidthLimit`\*\*选项，可以根据所选择的限制来更改公式文本的宽度。可用的值如下：

| **值** | **描述** |
| --- | --- |
| `Auto` | 根据 DOM 容器的宽度调整公式文本的宽度。如果文本长度超过 DOM 容器的宽度，则只有公式会被分成多行显示。 |
| `Number` | 当公式表达式（包括子表达式）的长度超过指定值时，调整公式文本的宽度。如果将值设置为-1，则公式表达式会格式化为多行显示。 |

此外，\*\*`tabSize`\*\*选项用于在按下Tab键时在公式表达式之前插入制表符空格。

## 主要特点

公式编辑器的主要特点如下：

* **格式化**：调整公式的缩进、间距、换行等，使公式更易读、易于维护。
    ![Formula adjustments.c2855a](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/Formula%20adjustments.c2855a.2ed9ce.png?width=800)
* **自动补全建议**：提供公式自动补全、函数参数提示等功能，提高编写公式的效率。在输入公式时，它会智能地提供可用的函数、自定义名称、枚举参数等建议。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.aa0fb0.png?width=800)
* **灵活的大纲视图**：允许在公式编辑器中折叠和展开公式视图。
    ![ExpandCollapsePanel.bfa73a](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/ExpandCollapsePanel.bfa73a.10bc2c.png?width=800)
* **语法高亮**：通过突出显示公式中的不同语法元素，提升可读性和可用性。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.c6d484.png?width=800)
* **Lint选项**：提供错误提示，如不正确的函数参数、括号不匹配等，以减少错误。
    ![ErrorMessage.0659ab](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/ErrorMessage.0659ab.7d2b0b.png)
* **工具提示信息**：当用户悬停或输入函数时，显示包含有关函数详细信息的工具提示。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.8f955d.png)
* **主题定制**：提供多个主题，并允许自定义现有主题以改变编辑器的外观。
    ![FormulaEditorTheme.40ff2c](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/FormulaEditorTheme.40ff2c.ec542c.png)

```css
// Define the color of the function token
.gc-formula-editor-token-function {
 color: blue;
}

// Define the color of the string token
.gc-formula-editor-token-const-string {
  color: red;
}

// Define the color, background-color, and font of the formula editor
.gc-formula-editor-content {
color: black;
background-color: white;
font: 16px, sans-serif;
}
```

## 使用设计器

要在Spread 设计器中开始使用公式编辑器，请选择包含要编辑的公式的单元格，然后单击 FORMULAS > Formulas Auditing 选项卡组中的**显示公式编辑器**按钮。公式编辑器允许您选择在面板上如何显示您的公式。您可以编辑公式视图和公式文本。使用**保存**按钮可以保存编辑后的公式。保存后，SpreadJS会自动将编辑器中的文本同步到单元格中。您还可以使用`editor.commandManager` API进行异步操作。此外，**格式化**按钮可用于获取应用公式的格式树视图，并更改公式宽度和制表符大小限制。

## 快捷键

在使用公式编辑器格式化公式时，您可以使用以下快捷键。

| **快捷键** | **操作** |
| --- | --- |
| Alt+Shift+F | FormatDocument（格式化文档） |
| F4 | ToggleAbsoluteRelativeReferences（切换绝对或相对引用） |
| Ctrl+S | CommitContentToActiveCell（将内容提交到活动单元格） |
| ESC | ExitEdit/ CloseHints（退出编辑/关闭提示） |
| Ctrl+Shift+Whitespace | ShowHints（显示提示） |
