# add-charts-using-table-structure-reference

SpreadJS支持表格中的结构化引用公式。如果在SpreadJS中，图表绑定到整个表格或使用表格结构引用的某些列，那么表格中的任何更新将在运行时自动更新图表的系列或数据值。
您可以使用三种不同的结构化表格引用策略来创建图表。接下来我们逐一讨论这些策略。

### 如果图表的数据源来自整个表格范围

当使用整个表格范围创建图表时，如果表格的范围被调整或添加、删除行和列，或自动扩展行为受影响，则图表的系列也会同时更新，如下图所示：
![entirerange-chart-table structure.6f98a2](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/entirerange-chart-table%20structure.6f98a2.5cdef2.gif)
以下代码示例展示了如何使用结构化引用设置整个表格作为图表的数据源。

```javascript
// Add chart with data range as whole table range.
var chart1 = sheet.charts.add('chart1', GC.Spread.Sheets.Charts.ChartType.columnClustered, 50, 150, 400, 200, "Table1[[#Headers],[#Data]]");
```

### 如果图表的数据源来自表格的特定列

当表格操作更改绑定到图表的特定列中的数据时，图表会根据新数据进行更新，但系列保持不变，如下图所示：
![specific column-chart-table structure.a0b564](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/specific%20column-chart-table%20structure.a0b564.13dc09.gif)
以下代码示例使用结构化引用来创建使用表格中特定列的图表。

```javascript
// Set the chart range to a certain column range of the table.
var chart2 = sheet.charts.add('chart2', GC.Spread.Sheets.Charts.ChartType.columnClustered, 500, 150, 400, 200, "Table1[[#Headers],[#Data],[Name]],Table1[[#Headers],[#Data],[Age]]");
```

### 如果图表的数据源是表格结构引用和常规范围的组合

当图表的数据源定义为表格结构引用和常规范围的组合时，图表会如图所示进行更新：
![combo-chart-tablestructure.34a88b](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/combo-chart-tablestructure.34a88b.652b20.gif)
以下代码示例展示了如何使用表格结构引用和常规范围的组合来设置图表的数据源。

```javascript
// Set the chart's range to a combination of table structure reference and regular range.
var chart3 = sheet.charts.add('chart3', GC.Spread.Sheets.Charts.ChartType.columnClustered, 50, 400, 400, 200, "Table1[[#Headers],[#Data],[Id]],Sheet1!D1:D4");
```
