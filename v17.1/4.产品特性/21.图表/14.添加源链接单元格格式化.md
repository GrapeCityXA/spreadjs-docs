# add-source-linked-cell-formatter

图表应用单元格数字格式设置，使用链接单元格动态更新数据标签、轴和工具提示等图表元素的格式。SpreadJS中的图表提供了`IDataLabels`接口和`IAxes`接口的`numberFormatLinked`属性来实现此功能。

#### 设置数据标签的源链接格式器

当`numberFormatLinked`属性设置为`true`时，数据标签的“值”字段将保留数据源单元格格式，而不论数据标签链接的格式代码如何；而如果`numberFormatLinked`属性设置为`false`，数据标签中的“值”字段将使用指定的格式器。
**示例：** 假设你想要创建一个浏览器的性能仪表盘，用来跟踪每月的销售数据。仪表盘包括一个簇状柱形图，显示每个浏览器的月平均销售数据，并且你希望确保图表的数据标签根据用户选择的平均销售数据动态更新其格式。下图显示了在`numberFormatLinked`属性设置为`true`时的销售数据。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.342ec8.png)
以下代码示例展示了如何使用链接单元格动态更新图表数据标签的单元格数字格式。

```javascript
// 获取系列并设置数据标签属性。
for (var i = 0; i < 3; i++) {
    var series = chart.series().get(i);
    series.dataLabels = {
        showValue: true,
        showCategoryName: false,
        showPercentage: false,
        separator: ",",
        position: GC.Spread.Sheets.Charts.DataLabelPosition.Center,
        format: "#,##0",    
        color: "white",
        backColor: "red",
        borderColor: "blue",
        borderWidth: 2
    };

    // 设置数据标签的源链接格式器。
    series.dataLabels.numberFormatLinked = true;
    chart.series().set(i, series);
}
```

> type=warning
> **注意：** 散点图是个例外，其中数据标签的“x值”、“y值”和“气泡大小”字段使用用户指定的格式器。

#### 设置轴的源链接格式器

当`numberFormatLinked`属性设置为`true`时，图表的轴将保留数据源单元格格式，而不论轴链接的格式代码如何。其中，

* 如果轴类型是文本轴，所有轴标签都将从系列点的格式器中格式化。
* 如果轴类型是日期轴或值轴，所有轴标签都将从系列第一个点的格式器中格式化。

当`numberFormatLinked`属性设置为`false`时，图表的轴将使用指定的数字格式器。然而，对于值轴，所有轴标签都将从系列第一个点的格式器中格式化。

**示例：** 假设你想要创建一个浏览器的性能仪表盘，用来跟踪每月的销售数据。你的仪表盘包括一个簇状柱形图，显示每个浏览器的月平均销售数据，并且你希望确保图表的x轴根据用户选择的日期格式动态更新其格式。下图显示了在`numberFormatLinked`属性设置为`true`且轴类型设置为“文本”时，图表x轴上的日期。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.61b831.png)
以下代码示例展示了如何使用链接单元格动态更新轴的单元格数字格式。

```javascript
// 设置轴的源链接格式器。
var chart = activeSheet.charts.all()[0];
var axes = chart.axes();
axes.primaryCategory.categoryType = GC.Spread.Sheets.Charts.CategoryType.CategoryScale;
axes.primaryCategory.numberFormatLinked = true;
chart.axes(axes);
var series = chart.series().get(0);
series.dataLabels.numberFormatLinked = true;
chart.series().set(0, series);
```

#### 限制

* 如果数据源格式器被更新，图表需要额外的支持来刷新数据。
