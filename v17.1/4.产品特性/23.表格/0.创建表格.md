# tables

您可以在控件的表中显示数据。 该表具有用于筛选或数据排序的选项。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/table.png)

默认表样式为medium2。

您可以通过设置以下选项来控制是否显示表格的页眉和页脚 **showHeader** 和 **showFooter** 方法。您可以通过设置设置突出显示第一列还是最后一列 **highlightFirstColumn** 或 **highlightLastColumn** 方法。 您可以通过设置 **bandRows** 或 **bandColumns** 方法控制是否显示带状的行和列。您可以使用 **TableStyle** 类, **headerRowStyle** 方法,以及 **footerRowStyle** 方法自定义表格样式。您可以设置页眉单元文本和页脚单元文本以及公式。

该表的行数包括页眉和页脚行。 表支持冻结的行和列，迷你图和单元格跨度。



#### 示例代码

下面的示例创建一个表并设置表样式。


```JavaScript
activeSheet.tables.add("Table1", 0, 0, 3, 3, GC.Spread.Sheets.Tables.TableThemes.dark1);
activeSheet.getCell(0,0).text("Name");
activeSheet.getCell(0,1).text("Value");
activeSheet.getCell(0,2).text("T/F");
activeSheet.getCell(1,0).text("AW");
activeSheet.getCell(1,1).text("5");
activeSheet.getCell(1,2).text("T");
```
