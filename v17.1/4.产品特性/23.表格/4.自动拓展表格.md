# auto_expand_tables

SpreadJS支持表的自动扩展。 如果在表的空白相邻行或列中输入或粘贴数据，则表将自动展开。

 **allowAutoExpand** 功能可用于启用或禁用表的自动扩展。 其默认值为true。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/TableExpand.gif)



#### 示例代码

下面的示例添加一个表并显示 **allowAutoExpand** 函数的值。


```JavaScript
// 添加表格
var table = activeSheet.tables.add("ExpandTable", 1, 1, 4, 3, GC.Spread.Sheets.Tables.TableThemes.dark1);
// 默认情况下，allowAutoExpand为true，但我们也可以将其设置为false，以禁用表的自动扩展
alert(table.allowAutoExpand());
```
