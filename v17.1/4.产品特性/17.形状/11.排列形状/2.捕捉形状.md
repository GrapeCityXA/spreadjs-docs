# snap-shapes

您可以使用snapMode方法在 SpreadJS 中捕捉形状，该方法根据网格线或工作表中的其他形状将形状对齐、拖动或调整到最近的边缘。

使用工作表中的水平或垂直对齐线将形状与网格或其他形状对齐。下图显示了垂直对齐线：

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/shape-snapLines.png)



### 对齐形状

您可以使用snapMode.shape选项将形状与工作表中其他形状的最近边缘对齐。当形状在水平或垂直方向移动时，它与捕捉线对齐。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/shape-snapShape.gif)


```JavaScript
var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
// 获取捕捉模式
var snap = spread.getActiveSheet().shapes.snapMode();
// 设置对齐形状
spread.getActiveSheet().shapes.snapMode(GC.Spread.Sheets.Shapes.SnapMode.shape);
```



### 对齐网格

您可以使用snapMode.grid选项将形状与工作表上最近的网格交点对齐（即使它不可见）。当形状在水平或垂直方向移动时，它与捕捉线对齐。

您还可以使用箭头键（向上、向左、向下和向右）移动形状，而不是使用鼠标拖动它。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/shape-snapGrid.gif)


```JavaScript
var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
// 获取捕捉模式
var snap = spread.getActiveSheet().shapes.snapMode();
// 设置对齐网格
spread.getActiveSheet().shapes.snapMode(GC.Spread.Sheets.Shapes.SnapMode.grid);
```

可以使用snapMode方法一次捕捉多个形状。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/shape-snapMultiple.gif)

该snapMode.shape和snapMode.grid选项可以一起使用，以对齐形状。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/shape-snapBoth.gif)


```JavaScript
var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
// 设置对齐形状和网格
spread.getActiveSheet().shapes.snapMode(GC.Spread.Sheets.Shapes.SnapMode.grid | GC.Spread.Sheets.Shapes.SnapMode.shape);
```
