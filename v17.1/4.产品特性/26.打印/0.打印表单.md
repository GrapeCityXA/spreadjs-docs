# printsheet

您可以在SpreadJS中打印一表单或所有表单。

在SpreadJS中打印时，将打印以下内容：

- 角，行标题，列标题或视图中可见的行或列
- 单元格文字
- 样式
- 跨度
- 溢出

不会打印以下信息：

- 隐藏的行或列
- 浮动对象
- 批注
- 标签条
- 滚动条
- 组
- 筛选按钮
- 验证按钮或高亮圆圈
- 积极作用
- 选择/li>
- 冻结线

使用 **print** 方法打印一表单或多张表单。使用索引指定一个特定的表单，或为所有可见表单指定一个索引。 您可以使用 **PrintInfo** 类指定许多打印选项，例如是否打印标题，边框，网格线等。

下表显示了在创建打印页眉或页脚时可以使用的选项：

|  **控制字符**  |  **描述**  |  **示例**  |  **结果**  |
|--- |--- |--- |--- |
| & | 转义符 |  |  |
| P | 当前页面 |  | 这是10页的第1页。 （如果有10页，这是第一页。） |
| N | 页数 |  | 这是10页的第1页。 （如果有10页，这是第一页。） |
| D | 当前日期 |  | 现在是2015/6/19. (如果今天是2015年6月19日。) |
| T | 当前时间 |  | 现在是16:30:36. (If 16:30:36 is如果现在是16:30:36。 now.) |
| G | 图片 |  | 显示图片。 |
| S | 删除线 |  |  |
| U | 下划线 |  |  |
| B | 加粗 |  |  **这是文本。**  |
| I | 斜体 |  |  *这是文本。*  |
|  | 字体大小 |  | 这是文本。 |
| " | 字体前缀 |  |  |
| K | 颜色前缀 |  |  |
| F | Spread 名称 |  | spread 名称: testSpread (打印的spread名称"testSpread".) |
| A | 表单名称 |  | 表单名称: Sheet1 (如果表单名称为"Sheet1".) |

 **orientation** 方法仅在导入或导出到Excel时支持。 **paperSize** 方法仅适用于分页结果，不适用于打印机。 不支持打印预览。 在浏览器之间打印结果可能会有所不同。


> **注意:** 打印要求您将打印模块添加到页面中 (gc.spread.sheets.print.*.*.*.min.js).<br /><br /> 


#### 示例代码

本示例打印表单。


```JavaScript
<script src="./scripts/pluggable/gc.spread.sheets.print.13.0.0.min.js" type="application/javascript"></script>
...

var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"),{sheetCount:3});
var activeSheet = spread.getActiveSheet();
activeSheet.suspendPaint();



// 设置值
for (var r = 0, rc = activeSheet.getRowCount() - 5; r < rc; r++) {
for (var c = 0, cc = activeSheet.getColumnCount() - 5; c < cc; c++) {
activeSheet.setValue(r, c, r + c);
}
}
activeSheet.resumePaint();
$("#button1").click(function () {
spread.print(0);
});
```
