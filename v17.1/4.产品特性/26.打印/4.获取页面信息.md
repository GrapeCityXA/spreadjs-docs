# GetPageInformation

SpreadJS允许用户在使用表单时获得基本页面信息，包括页面总数，每页的行数，列数，行索引和列索引。 当用户希望在打印表单数据之前了解有关页面的重要信息时，此功能特别有用。

例如，假设您正在使用Excel作为报告工具来处理Financial应用程序。 现在，您希望在表单执行打印作业之前获取页面信息，并且还希望创建一个“索引页面”。 使用此功能，用户可以确定1）准确的页数（在表单中可以打印多少页）和2）每个打印页的打印范围[即页面行和列信息]。 这将帮助用户以有效的方式打印所需的数据。



#### 示例代码

请参考以下示例代码，以在使用表单时获取页面信息。


```JavaScript
// 初始化 Spread
var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'),
{ sheetCount: 1 });
spread.suspendPaint();

// 获取表单
var sheet = spread.getActiveSheet();
for (var i = 0; i < 20; i++)
{
for (var j = 0; j < 18; j++)
{
sheet.setValue(i, j, "Row" + i + " Col" + j);
}
}
spread.resumePaint();
var pageInfos = spread.pageInfo(0);
console.log("Total no. of pages: " + pageInfos.pageCount);
for (var p = 0; p < pageInfos.pageCount; p++) {
console.log("ColCount of Page[" + p + "] is: " + pageInfos.pages[p].columnCount);
console.log("RowCount of Page[" + p + "] is: " + pageInfos.pages[p].rowCount);
}
```
