# resources-tasks

您可以通过使用GanttSheet资源功能高效地管理任务、日程和资源。利用GanttSheet资源，您可以指定哪些资源分配给哪些任务，并将不同的任务分配给不同的资源。
通过在GanttSheet中列出项目所需的所有资源并将它们与任务链接，可以更准确地估算和跟踪任务的发展。此外，通过优化资源的分配和利用，您可以提高项目的效率和效果，并适当管理成本。
让我们详细讨论GanttSheet资源功能。

### 加载资源

要使用资源功能，首先需要设置资源和分配的相应数据源，以创建必要的关系。
您可以使用任务、分配和资源表通过关系添加资源。此外，任务和分配表之间的关系必须有源名称和目标名称。资源列可以直接从配置的关系中检索资源名称。
以下示例代码添加了TaskResources的dataType，它在资源列中添加了一个下拉框。

```javascript
dataManager.addRelationship(assignmentTable, "taskId", "task", taskTable, "id", "taskId");
dataManager.addRelationship(assignmentTable, "resourceId", "resource", resourceTable, "id", "assignment");
ganttView = taskTable.addView("ganttView", [
    { value: "id", caption: "ID", width: 60 },
    { value: "parentId", caption: "PID", width: 60 },
    { value: "taskNumber", caption: "Task Number", width: 120 },
    { value: "mode", caption: "Mode", width: 65 },
    { value: "name", caption: "Task Name", width: 200 },
    { value: "duration", caption: "Duration", width: 90 },
    { value: "predecessors", caption: "Predecessors", width: 120 },
    { value: "taskId.resource.name", caption: "Resources Name", dataType: "TaskResources", width: 300 },
]);
ganttView.fetch().then(function() {
    ganttSheet.bindGanttView(ganttView);
});
```

上述代码的输出将在GanttSheet顶部显示相应的资源名称，如下图所示。

### 更改资源分配

GanttSheet允许您通过使用资源列来分配资源。
GanttSheet的资源列显示了所有资源的内容，如下图所示。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca82939a-5d1a-4838-9f3f-69a0f7ebeeb5/image.7ea713.png)
当您拥有资源名称列和资源表被绑定时，当前列的单元格类型将在下拉菜单中显示所有现有资源。您可以使用下拉菜单向活动任务添加和更新资源。所有对分配的更新将导致分配表中的更改。GanttSheet首先将当前操作分解为多个插入和删除操作，然后生成必要的更改，最后将它们存储在分配表上。
另外，您还可以从GanttSheet中删除任务和资源。请注意，删除一个任务或资源可能会同时移除多个相关的分配。

### 提交分配更改

一旦所有更改完成，您需要提交您所做的所有分配更改。如果没有资源，只会更改当前视图。但是当添加资源时，需要提交分配信息，然后将任务与分配信息一起提交。您必须同时提交任务的更改和分配表的更改到Ganttsheet.submitChanges中。

### 更新资源

资源表只能在TableSheet中更改。要更新在GanttSheet中使用的资源的内容，您必须将当前的修改提交到数据源以再次检索相关内容。
只有当资源表将最新的修改提交到数据库后，GanttSheet才必须再次检索资源数据，以准确更新资源列下的资源。

### 设置分配的工作时间

将资源分配给任务不会影响其持续时间，但会增加当前任务的工作时间。
任务的工作时间代表分配给当前任务的所有资源的工作时间，默认单位是小时。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca82939a-5d1a-4838-9f3f-69a0f7ebeeb5/image.4a1043.png)
要添加一个工作时间列，您需要在视图上方添加一个名为"workTime"的列。例如，如果一个任务当前的持续时间为1天，并且有2个资源同时在其上工作，则该任务的工作时间为2天。每天的工作时间是8小时，所以当前任务的总工作时间是16小时。

```javascript
var view = taskTable.addView("ganttView1", [
    ...
    { value: "workTime" },
    ...
]);
```

> type=info
> 注释：
>
> * 在一个普通任务中，当前工作时间是持续时间乘以资源数量。
> * 在一个汇总任务中，当前工作时间是持续时间乘以资源数量，然后加上所有子节点的工作时间。
> * 如果当前汇总任务没有资源，那么它的工作时间是所有子节点的工作时间之和。
