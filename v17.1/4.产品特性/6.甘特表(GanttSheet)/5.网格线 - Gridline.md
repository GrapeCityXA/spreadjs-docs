# gridline

网格线是使甘特图更具可读性的垂直线和水平线。它们有助于将甘特图任务栏与项目表中的相应任务进行匹配。
甘特图中使用了三种不同类别的网格线。对于所有网格线，可用的属性有“`GC.Spread.Sheets.GanttSheet.GanttGridlines`”类的“`lineType`”、“`lineColor`”、“`interval`”。
您可以更改网格线的外观和间隔样式，以更好地反映项目的范围。

## 时间刻度扩展网格线

该网格线分隔时间刻度列。
要更改时间刻度层列的网格线类型和颜色，请为“`topTierColumn`”、“`middleTierColumn`”和“`bottomTierColumn`”设置“`lineType`”和“`lineColor`”属性。
以下代码示例显示如何更改底部和中间层列的网格线。

```javascript
// 将底层列的网格线更改为虚线类型和黄色。
ganttSheet.gridlines.bottomTierColumn = {
    lineType: GC.Spread.Sheets.GanttSheet.GanttGridlineType.dashed,
    lineColor: "yellow"
}
// 将中间层列的网格线更改为点划线类型和红色。
ganttSheet.gridlines.middleTierColumn = {
    lineType: GC.Spread.Sheets.GanttSheet.GanttGridlineType.dashDot,
    lineColor: "red"
}
```

## 项目助手网格线

该网格线突出显示当前日期或开始和完成日期，以清晰地显示项目范围。
要更改项目计划日期的网格线类型和颜色，请设置“`projectStart`”、“`projectFinish`”和“`currentDate`”的“`lineType`”和“`lineColor`”属性。
以下代码示例展示了如何更改开始和结束项目的网格线。

```javascript
// 更改项目的网格线从细型和红色开始。
 ganttSheet.gridlines.projectStart = { 
    lineType: GC.Spread.Sheets.GanttSheet.GanttGridlineType.thin, 
    lineColor: "red"
};
// 使用虚线类型和水绿色更改项目完成的网格线。
ganttSheet.gridlines.projectFinish = { 
    lineType: GC.Spread.Sheets.GanttSheet.GanttGridlineType.dashed, 
    lineColor: "aqua"
};
```

## 任务栏分隔网格线

该网格线分隔任务行。
您可以在行之间添加间隔网格线以对齐任务行，并使用“`interval`”、“`intervalLineType`”和“`intervalLineColor`”属性更改其类型和颜色。
以下代码示例展示了如何更改甘特行的间隔网格线。

```javascript
// 将甘特行的间隔网格线更改为虚线类型和红色。
ganttSheet.gridlines.ganttRows = {
    lineType: GC.Spread.Sheets.GanttSheet.GanttGridlineType.thin,
    lineColor: "blue",
    interval: 2,
    intervalLineType: GC.Spread.Sheets.GanttSheet.GanttGridlineType.dashed,
    intervalLineColor: "red"
}
```
