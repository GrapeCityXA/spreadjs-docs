# gantt-datamanger

数据管理器（DataManager）是一个强大的本地数据引擎，它向服务器端发送请求，然后在数据准备就绪时将数据绑定到 GanttSheet 上。
GanttSheet 支持使用 DataManager 视图作为数据源。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.f0f206.png)

### 数据源架构

数据源架构指的是特定数据源中数据的结构。
GanttSheet 需要从数据源获取以下任务字段。

| **任务字段** | **数据类型** | **描述** |
| ---- | ---- | --- |
| @cols=3:**必要字段** |
| taskNumber | number | 任务编号。<br>它代表每个任务的唯一编号。<br>注意：如果不存在，则甘特表中将仅显示根任务。 |
| name | string | 任务名称。 |
| duration | String/number/object | 任务持续时间。<br>它包含值、单位或时间。 |
| predecessors | string | 任务依赖字符串。 |
| mode | string | 日程安排模式。<br>它支持两种类型的模式：“Auto”和“Manual”。<br>默认类型为“Auto”。 |
| @cols=3:**可选字段** |
| start | date | 任务开始的日期。<br>如果任务计划模式为“Auto”，则该字段为计算字段。 |
| finish | date | 任务结束的日期。<br>如果任务计划模式为“Auto”，则此字段为计算字段。 |
| complete | number | 任务完成百分比。<br>百分比的计算范围为 0 到 1。 |
