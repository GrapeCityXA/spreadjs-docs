# task-layout

在甘特图表中，通过使用 `TaskbarLayout` 类，您可以配置任务布局，包括链接线模式、任务条高度、日期文本格式以及将任务条舍入到整天。

### 链接线模式

项目在甘特图表视图上显示链接线，以突出显示链接任务的任务依赖关系。
如果需要，可以通过设置 `linkLineMode` 选项值来自定义链接线的外观或隐藏链接线。
有三种链接线模式可用，即 `noLinks`、`toTop` 和 `toEnd`。默认模式是 `toTop`。

| --- | --- |

| `ganttSheet.project.layout.linkLineMode = "toTop";` | ![ToTop_Linkmode](https://docapp-us.grapecitydev.com/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/df1fe1ee-eb3c-4da7-8c20-a0d8d2b7e734/ToTop_Linkmode.a2b735.png?width=600) |

### 任务条高度

您可以通过使用 `barHeight` 选项来设置任务条的高度。默认情况下，`barHeight` 的值为12像素。以下代码示例将任务条高度设置为36。

```javascript
var barHeight = 36;
ganttSheet.project.layout.barHeight = barHeight;
```

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.8634d2.png?width=600)

### 任务条日期格式

当您将日期字段添加到甘特图表的任务条时，日期文本将被显示。您可以使用 `barTextDateFormat` 选项自定义日期格式的显示。默认的日期格式为 "yyyy/mm/dd hh:mm"。
以下代码示例将日期格式设置为 "yyyy/mm/dd"。

```javascript
var barTextDateFormat = "yyyy/mm/dd";
ganttSheet.project.layout.barTextDateFormat = barTextDateFormat;
```

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.131421.png)

### 舍入到整天

实际任务持续时间并不总是整天。如果您想要用四舍五入后的值覆盖持续时间值，请将 `roundBarsToWholeDays` 选项值设置为 true。这将把任务条舍入到整天。

| **设置值** | **样式** |
| --- | --- |
| `ganttSheet.project.layout.roundBarsToWholeDays = true;` | ![Roundtowholedays_True](https://docapp-us.grapecitydev.com/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/df1fe1ee-eb3c-4da7-8c20-a0d8d2b7e734/Roundtowholedays_True.689b16.png?width=600) |
| `ganttSheet.project.layout.roundBarsToWholeDays = false;` | ![Roundtowholedays_false](https://docapp-us.grapecitydev.com/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/df1fe1ee-eb3c-4da7-8c20-a0d8d2b7e734/Roundtowholedays_false.2a415f.png?width=600) |
