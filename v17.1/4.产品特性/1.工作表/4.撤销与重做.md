# undo

您可以使用Ctrl + Z撤消控件中的操作。 然后，您可以使用Ctrl + Y重做您取消的操作。

您可以撤消以下类型的操作：

- 编辑文本
- 双击时自动适应
- 调整标题大小
- 用鼠标拖动列或行
- 使用组按钮扩展或折叠组
- 通过双击标签栏来编辑表单标签名称
- 使用Ctrl + V粘贴
- 使用 **Commands** 类 执行行为
- 在视图区域中执行的上下文菜单操作。

以下操作不响应Ctrl + Z：

- 使用下拉按钮进行排序或筛选
- 选择区域
- 导航到特定的单元格
- 滚动
- 调整标签条调整大小框的大小
- 单击选项卡条上的新选项卡选项
- 在表单标签区域中执行的上下文菜单操作。
- 调用 **fromJSON()** 工作簿方法或 **fromJSON()** 工作簿方法在 **execute()** 方法的 **CommandManager ** 类。
- 调用 **Undo** 方法以及 **Redo** 方法的 **UndoManager** 类在 **execute()** 方法 **CommandManager ** 类。

您可以使用 **options.allowUndo** 属性阻止或允许代码中的撤消操作。

将allowUndo属性设置为true后，您可以使用 **startTransaction()** 方法, **undoTransaction() <font color="black">方法</font>** 和 **endTransaction() <font color="black"></font>** 方法。



#### 示例代码

本示例设置 **options.allowUndo** 属性并指定一个操作。


```JavaScript
spread.options.allowUndo = true;
spread.commandManager().execute({cmd: "outlineRow", sheetName: activeSheet.name(), index: 3, count: 5});
```

本示例使用 **startTransaction()** 方法变更单元格的背景颜色, **undoTransaction() <font color="black"></font>** 方法 和 **endTransaction() <font color="black"></font>** 方法。


```JavaScript
var command = { canUndo: true, execute: function (context, options, isUndo)
            { var Commands = GC.Spread.Sheets.Commands;
              if (isUndo)
              {
                 Commands.undoTransaction(context, options);
                 return true;
              }
                else
              {
                Commands.startTransaction(context, options);
                var sheet = context.getSheetFromName(options.sheetName);
                var cell = sheet.getCell(options.row, options.col);
                cell.backColor(options.backColor);
                Commands.endTransaction(context, options);
                return true;
               } 
             }
            };
var spread = GC.Spread.Sheets.findControl(document.getElementById("sampleDiv"));
var commandManager = spread.commandManager();
commandManager.register("changeBackColor", command);
commandManager.execute({ cmd: "changeBackColor", sheetName: spread.getSheet(0).name(), row: 1, col: 2, backColor: "red" });
```



### 限制撤消和重做操作的次数

您可以通过控制撤消和重做堆栈大小来设置撤消和重做操作的数量限制。 undoManager 类中的 **maxSize** 方法可以用来做同样的事情。 这有助于通过减少内存消耗来提高应用程序的性能。

如果将无效值传递给 maxSize 方法，则返回 undoManager。
> **注意：** 如果将无效值传递给 maxSize 方法，则返回 undoManager。 

```JavaScript
var spread = GC.Spread.Sheets.findControl(document.getElementById('ss'));
let undoManager = spread.undoManager();
undoManager.maxSize(20);        // 设置最大尺寸.
let maxSize = undoManager.maxSize();    // 获取最大尺寸.
```



### 获取撤消和重做堆栈

您可以使用 **getUndoStack** 和 **getRedoStack** 函数来检索撤消和重做堆栈。 这些函数将堆栈作为对象返回，包括工作表名称和命令的字符串值。


```JavaScript
function getUndoStackFunction() {
    console.log(spread.undoManager().getUndoStack());
}

function getRedoStackFunction() {
    console.log(spread.undoManager().getRedoStack());
}
```

您还可以使用这些功能创建自定义菜单并在电子表格中显示撤消和重做操作的列表。


```JavaScript
<body>
    <input type="button" value="Get Undo Stack" onclick="getUndoStackFunction()">
    <input type="button" value="Get Redo Stack" onclick="getRedoStackFunction()">
</body>
```

SpreadJS 设计器将撤消和重做堆栈显示为下拉列表中的操作列表。 您可以选择任何操作在该特定点导航电子表格。![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/undoRedoStack.gif)
