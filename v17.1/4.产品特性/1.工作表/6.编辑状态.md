# editor-status

当表单处于编辑模式时，您可以使用箭头键进行导航。

如果编辑器处于编辑模式，则状态为Enter或edit。如果编辑器未处于编辑模式，则状态为Ready。

在进入状态时，Spread提交当前输入并导航或选择其他单元格(如果用户使用导航或选择操作)。在编辑状态下，如果用户使用导航或选择操作，Spread不会提交当前输入并导航或选择其他单元格。

键入并双击一个空单元格将导致该单元格进入Enter状态。双击非空单元格将使该单元格进入编辑状态。如果单元格处于输入状态，并且您使用鼠标左键单击编辑器，则状态变更为Edit。使用[startEdit](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#startEdit)方法类似于双击

您可以使用[editorStatus](gcdocsite__documentlink?toc-item-id=a5e8c3ef-95ec-4d6b-ac6e-e43cbea5b3b6)类型来检查编辑模式。



#### 使用代码

下面的示例显示编辑器状态。


```JavaScript
<script>
        $(document).ready(function () {
            var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
            var activeSheet = spread.getActiveSheet();
            spread.commandManager().register("startEditing", {
                canUndo: false,
                execute: function (context, options) {
                    var sheet = context.getSheetFromName(options.sheetName);
                    if (sheet && !sheet.isEditing()) {
                        sheet.startEdit();
                    }
                }
            }, 113, false, false, false, false);
            setstatus(activeSheet);
            activeSheet.bind(GC.Spread.Sheets.Events.EditorStatusChanged, function (e, args) {
                setstatus(activeSheet, args.status);
            });
        });
        function setstatus(activeSheet, status) {
            var statusnow = status || activeSheet.editorStatus();
            if (statusnow === GC.Spread.Sheets.EditorStatus.ready) {
                $("#status").text("Ready");
            } else if (statusnow === GC.Spread.Sheets.EditorStatus.enter) {
                $("#status").text("Enter");
            } else if (statusnow === GC.Spread.Sheets.EditorStatus.edit) {
                $("#status").text("Edit");
            }
        }
    </script>
</head>
<body>
    <div id="ss" style="height:700px;width:900px"></div>
    <label id="status" style="margin: 10px" />
</body>
```
