# split-resize-columns-and-rows

SpreadJS在处理表单时支持拆分调整大小功能。



### 拆分大小调整如何实现？

拆分调整大小功能使用户可以调整当前行或列以及下一个可见的列或行的大小，而不会影响表单中其余的行和列。 这样可以防止相邻的行和列移出表单中的可见区域或视口。

例如-如果您在拆分调整大小模式下工作，则调整列A的大小也将调整列B的大小，但所有其他列（如列C，D，E，F，G，H，I等）的大小仍保留 未经修改，因此您的视口区域将不会受到影响。

[正常调整大小模式与分割调整大小模式](gcdocsite__documentlink?toc-item-id=8294cbd6-4de9-4474-b4d1-fd1c926a1d42)在正常的调整大小模式下，调整行或列的大小会将所有相邻的行和列向右推，从而将其移出视口。 相反，拆分调整大小模式可确保在表单上执行调整大小操作时，其他行和列的位置不会受到影响。



### 使用场景

拆分大小调整很有用，尤其是当用户正在分析复杂的应用程序，例如金融，银行，股票和交易应用程序时。 此外，在拆分调整大小模式下工作是有益的，因为它在导出或打印表单时不会影响分页。 另一方面，正常的调整大小模式可以将行推到下一页，也可以修剪尾栏。

 **例如** - 假设您正在表单中进行股票应用分析，并且需要比较当前会计年度出售给客户的多只股票的股票投资表现。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/spreadjsv13images/resize-split.gif)

 **<u>Split Resize Mode</u>** - 在拆分调整大小模式下，即使在调整了上面表单中的第一列（股票投资名称）的大小之后，您仍然能够在同一视口中跟踪最后一列中的信息-损益百分比，而无需向左滚动和 一遍又一遍。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/spreadjsv13images/resize-normal.gif)

 **<u>Normal Mode</u>** - 如果您在正常模式下调整A列（股票投资名称）的大小，则最后一列可能会超出视口，并且您将失去对关键信息（即-损益百分比）的关注，如上图所示。



### 启用分割调整大小

在调整行和列的大小时，用户可以在两种不同的模式之间进行选择 - " **normal** " and " **split** ". 默认设置为正常。 但是，如果在调整行或列的大小时按下Ctrl键，则默认情况下它将始终使用“拆分调整大小”功能。

分割调整大小功能可以通过使用启用" **split** " 选项在 **ResizeMode** 枚举中。 当 **ResizeMode** 设置为 **split** ,然后:

- 用户只能选择单个行或列（包括整个行/列）。
- 如果用户选择多个行和列，则拆分大小调整功能将不起作用，并且仅在正常模式下会调整行和列的大小。
- 如果用户调整一个视口中最后一行或列的大小（包括视口除以冻结行或冻结列功能），则拆分大小调整功能也将不起作用，并且仅在正常模式下会调整行和列的大小。
- 如果行或列不可见（当列宽= 0或列被隐藏时），则将修改后的行或列以及下一个可见行或列的大小调整。

可以在分割调整大小模式下执行以下操作：

- 用户可以在表单中隐藏行和列。
- 用户可以将行和列的高度和宽度调整为零。
- 即使同时启用了缩放功能，用户也可以调整行和列的大小。



### 代码

此示例代码可用于在拆分调整大小模式下调整行和列的大小。


```JavaScript
<script>
$(document).ready(function ()
{
// 初始化 Spread
 var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });

// 获取表单
var activeSheet = spread.getSheet(0);
// 将columnResizeMode rowResizeMode设置为“ Split”
spread.options.columnResizeMode = GC.Spread.Sheets.ResizeMode.split;
spread.options.rowResizeMode = GC.Spread.Sheets.ResizeMode.split;
activeSheet.suspendPaint();
var colHeader = GC.Spread.Sheets.SheetArea.colHeader;
activeSheet.setRowCount(12);
activeSheet.setColumnCount(5);
for (var i = 0; i < activeSheet.getColumnCount(GC.Spread.Sheets.SheetArea.viewport); i++)
activeSheet.setColumnWidth(i, 120);
activeSheet.setValue(0, 0, 'Stock Investment Name', colHeader);
activeSheet.setValue(0, 1, 'Current Quote($)', colHeader);
activeSheet.setValue(0, 2, 'Market Value($)', colHeader);
activeSheet.setValue(0, 3, 'Total Cost($)', colHeader);
activeSheet.setValue(0, 4, 'Gain/Loss(%)', colHeader);
activeSheet.setArray(0, 0, [
["Citycon-Oyj Corporation", 232.460, 492.00, 500.00, '-1.6%'],
["M-Secure Corporation", 560.270, 312.00, 300.00, '4.0%'],
["Nortan Corporation", 433.220, 711.00, 688.50, '3.3%'],
["Teski Corporation", 232.310, 693.00, 465.90, '48.7%'],
]);
spread.resumePaint(); 
});
</script>
```
