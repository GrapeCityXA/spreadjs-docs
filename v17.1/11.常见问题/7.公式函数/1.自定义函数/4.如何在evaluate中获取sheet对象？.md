# get-current-location

### 问题：如何在evaluate中获取sheet对象？

***

在某些情况下，用户需要再evaluate方法中获取到spread或者sheet对象，从而去获取到某些单元格的值，应该如何实现这样的需求呢？

在evaluate方法中可以通过以下代码来获取sheet对象：

```js
let context = arguments[0];
let sheet = context.source.getSheet();
```

但是在此之前需要将自定义函数的isContextSensitive重写，并返回为true：

```js
XXXXEvaluate.prototype.isContextSensitive = function () {
    return true;
}
```

如此一来就可以在evaluate方法中获取sheet对象了，如果想再获取spread对象，只需要调用getParent接口即可。
