# hyperlink-remove-underline

### 背景：

可以设置不带下划线的超链接吗？
答案是可以的。

### 解决方案：

在使用 `setHyperlink` 设置超链接时，有个 `drawUnderline` 属性可以用来控制是否绘制超链接的下划线，默认为 true。
所以基于此需求，将 `drawUnderline` 设置为 false 即可。
下方为示例代码，供参考：

```javascript
sheet.setHyperlink(1, 1, {
    url: 'https://www.grapecity.com/spreadjs',
    tooltip: 'GrapeCity',
    target: GC.Spread.Sheets.Hyperlink.HyperLinkTargetType.top,
    drawUnderline: false,
    command: 'navigationLeft'
}, GC.Spread.Sheets.SheetArea.viewport);

sheet.setText(1, 1, 'GrapeCity');
```

更多超链接相关内容请参考[学习指南](https://demo.grapecity.com.cn/spreadjs/SpreadJSTutorial/features/cells/hyperlink/introduction/purejs)。
