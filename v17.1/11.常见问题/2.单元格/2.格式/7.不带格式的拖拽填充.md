# drag-fill-without-format

### 背景：

当选中某个单元格时，点击右下角的“+”图标向某个方向拖动会默认会复制单元格的值，样式等，在拖动的时候能否只复制单元格的值而不需要复制其他内容（如样式）呢？

### 解决方案：

可以通过修改 `defaultDragFillTyp`e 来实现这个需求，如：

```
spread.options.defaultDragFillType = GC.Spread.Sheets.Fill.AutoFillType.fillWithoutFormatting
```

这样默认就只复制单元格的值了。

另外，如果想要不显示填充的按钮，可以使用下面这一行代码来实现：

```
spread.options.showDragFillSmartTag = false
```
