# updateRowHeaderStyle

### 问题：如何修改行头列头样式？

***

#### 背景：

在实际开发中，需要对特殊行头或者列头添加样式，来区别于其他行或者列。

#### 解决方案：

可以通过 setStyle（row, col, value, sheetArea）中第四个参数sheetArea来实现。
其中 sheetArea 包括colHeader、corner、rowHeader、viewport 其分别表示列头，表角，行头，视图区域。

**自定义列头：**
当想要修改列头颜色黑色时，可以使用如下代码：

```
var sheet = spread.getActiveSheet();
var style = new GC.Spread.Sheets.Style();
style.backColor = "black";
sheet.setStyle(-1,5,style,GC.Spread.Sheets.SheetArea.colHeader);
```

**自定义行头：**
当想要修改行头颜色黑色时，可以使用如下代码：

```
var sheet = spread.getActiveSheet();
var style = new GC.Spread.Sheets.Style();
style.backColor = "black";
sheet.setStyle(5,-1,style,GC.Spread.Sheets.SheetArea.rowHeader);
```
