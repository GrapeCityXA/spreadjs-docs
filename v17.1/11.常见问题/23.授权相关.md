# 开发授权

## **<span style="color: rgb(153, 51, 102);">Q：什么是开发授权？</span>**

葡萄城提供的控件产品在经过再次开发、封装、包装后，成为服务于最终用户的软件、系统、平台一部分(或全部），开发授权（也称开发人员授权）是针对在这个过程中使用控件产品的人员，如开发、设计、测试等以合法合规的方式取得的使用资格。

## **<span style="color: rgb(153, 51, 102);">Q：为什么必须购买开发授权？</span>**

开发授权作为控件（或称组件、中间件）厂商在出售产品时的标准计价单位，也是业内的统一标准做法。
同时，获得开发授权也是您合法合规获得产品的使用、修改、封装、再分发权力的基础必要条件。

## **<span style="color: rgb(153, 51, 102);">Q：需要购买多少开发授权？</span>**

根据使用产品的人员数量决定
*举例：在一个总数为20人的项目组中，开发与 SpreadJS 相关模块的开发人员有3人，测试1人，设计1人，应购买5个开发授权。*

# 部署授权

## **<span style="color: rgb(153, 51, 102);">Q：什么是部署授权？</span>**

包括任何 SpreadJS 可再分发文件的终端用户应用。部署授权按照部署域名或者 IP 地址的数量计数。一个域名（例如：[www.grapecity.com.cn](http://www.grapecity.com.cn/)）或IP地址需要一个部署授权。
<em>例：包含 SpreadJS 代码的OA系统，用户通过域名 </em>[<em>http:///www.oa.com</em>](http://115.28.216.99/www.oa.com)<em> 访问使用</em>
*注：这里的域名也可以是IP地址（但不包括http://localhost以及端口号）*

## **<span style="color: rgb(153, 51, 102);">Q：为什么需要购买部署授权？</span>**

作为与后端无关的前端（JavaScript）组件，部署授权也是业内统一的标准做法。
有以下的原因：

1. 部署授权能够保证发布的终端用户应用取得合法授权，并得到厂商的技术支持
2. 部署授权同样保护客户的系统，防止因人员流失或者前端代码的可复制性，而被非法使用（域名绑定）

# 授权常见问题

## **<span style="color: rgb(153, 51, 102);">Q：提示：授权未找到（Licese not found）</span>**

出现此问题的原因是没有加入授权或者加入授权方式不正确。如已加入授权请检查：

1. 授权变量是否输入正确；GC.Spread.Sheets.LicenseKey 是否有拼写错误。
2. 授权设置代码是否在初始化 SpreadJS 控件之前，一般在引用完 SpreadJS 资源后直接加入授权代码。

若未加入授权，还在试用阶段，只能在本地开发部署，若访问的浏览器地址非 localhost 或 127.0.0.1 会出现 License not found 提示。
<strong><span style="color: rgb(153, 51, 102);">注：</span></strong>如果是一般的 这样的 web 应用开发，导入导出组件不需要授权。只需要对 SpreadJS 进行授权即可。
如果是 Typescript 开发常见于: Angular、React 、Vue 等框架使用，需要对导入导出组件（ExcelIO）进行单独授权，类似：

```javascript
import * as Excel from "@grapecity-software/spread-excelio"
GC.Spread.Sheets.LicenseKey = Excel['LicenseKey'] = "yourkey";
```

## **<span style="color: rgb(153, 51, 102);">Q：提示：无效许可证（Invalid license key）</span>**

出现此问题的原因是授权和当前网站地址不匹配或者和使用版本不匹配。
请检查以下几点：

1. 确定授权和 SpreadJS 使用版本是否一致。
2. 确定当前网站部署的域名或者 IP 是否与申请授权提供的一致，检查范围为“http(s)://”后到第一个“/”之前。
