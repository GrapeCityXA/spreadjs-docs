### 问题：在Vue3中spread实例挂载问题

***

#### 背景：

在Vue3中用户将spread实例挂载当前的this上，导致spread实例被自动代理，出现了一些异常，例如下面出错代码如下所示：

```javascript
<template>
   <gc-spread-sheets class="spreadHost" @workbookInitialized="initSpread">
    </gc-spread-sheets>
</template>
<script>
import ...

export default {
   name: "App",
   methods: {
      initSpread(v){
        this.spread = v;
      },
      addSheet(){ 
        this.spread.addSheet()
      }
   }
}
```

这样的操作最终可能导致以下功能或性能问题：

#### addSheet方法出现了白屏问题。

#### fromJSON导入后，单元格输入内容，需要双击后才会显示。

#### 鼠标在sheet页签点或者下拉滚动才会出现数据

#### 原因：

类似spread这种层级很深属性很多的大对象，不建议挂载在this上被框架自动代理。
vue3 会使用代理包装该对象，这将破坏 javascript 对象的生命周期，导致页面出现各种问题。

#### 解决方法：

挂载spread对象的原因是为了方便后续上下文中调取，为此不必将spread直接挂载到当前的this，可以将spread对象的host挂载到this。
使用时通过findControl获取host对应的spread对象并进行后续操作。
您可以参考以下代码解决：

```javascript
initSpread(spread) {        
    this.spreadHost = spread.getHost();
},     
getSpread() {
    var spread = GC.Spread.Sheets.findControl(this.spreadHost);
    // do something
}
```

如果是在线表格编辑器的designer，可以通过下面的操作解决：

```javascript
designerInitialized(designer) {
    this.designer = designer;
    
}
getSpread() {
    let spread = this.designer.getWorkbook();
    // do something
}
```

### 问题： 在Vue3+Vite中，项目部署后，Designer不显示

***

#### 原因：

出现此问题属于vite的bug

#### 解决方案：

建议做如下操作

1. 在package.json文件中升级vite版本
2. 删除 package-lock.json文件
3. 重新npm install
4. 再次启动项目，发现Designer组件显示
