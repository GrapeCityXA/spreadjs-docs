# DisplayingBoundFields

### 需求：如何通过代码显示绑定字段名

***

#### 背景:

表格编辑器有数据绑定功能，在点击工具栏“工作表绑定”后，会在右侧打开字段列表。
用户可以通过UI操作添加字段，并将其拖拽至左侧单元格，以实现字段绑定。
如下图：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.5d1d0e.png?width=1000)
客户希望可以通过外部按钮来控制字段的显示，接下来了解下如何实现。

#### 思路：

可以通过自定义单元格来绘制字段，并由按钮来控制自定义单元格的设置。

#### 步骤：

1、设置自定义单元格显示字段

```javascript
function BindingPathCellType() {
  spreadNS.CellTypes.Text.call(this);
}
BindingPathCellType.prototype = new spreadNS.CellTypes.Text();
BindingPathCellType.prototype.paint = function (
  ctx,
  value,
  x,
  y,
  w,
  h,
  style,
  context
) {
  if (value === null || value === undefined) {
    var sheet = context.sheet,
      row = context.row,
      col = context.col;
    if (sheet && (row === 0 || !!row) && (col === 0 || !!col)) {
      var bindingPath = sheet.getBindingPath(context.row, context.col);
      if (bindingPath) {
        value = "[" + bindingPath + "]";
      }
    }
  }
  spreadNS.CellTypes.Text.prototype.paint.apply(this, arguments);
};
var bindingPathCellType = new BindingPathCellType();
```

2、在单元格设置该自定义单元格类型

```javascript
sheet.getCell(1, 1).bindingPath("test1");
sheet.getCell(2, 1).bindingPath("test2");
sheet.getCell(3, 1).bindingPath("test3");
```

3、通过按钮控制自定义单元格类型的设置

```javascript
document.getElementById("showItem").addEventListener("click", function () {
  // 单元格绑定字段
  sheet
    .getCell(1, 1)
    .cellType(bindingPathCellType)
    .vAlign(spreadNS.VerticalAlign.bottom);
  sheet
    .getCell(2, 1)
    .cellType(bindingPathCellType)
    .vAlign(spreadNS.VerticalAlign.bottom);
  sheet
    .getCell(3, 1)
    .cellType(bindingPathCellType)
    .vAlign(spreadNS.VerticalAlign.bottom);
});

document.getElementById("hideItem").addEventListener("click", function () {
  // 单元格绑定字段
  sheet.getCell(1, 1).cellType(null);
  sheet.getCell(2, 1).cellType(null);
  sheet.getCell(3, 1).cellType(null);
});
```
