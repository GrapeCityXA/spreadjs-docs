# code-control-file-tab-switch

### 问题：如何使用代码控制文件选项卡开关

***

#### 背景：

部分用户需要通过代码来控制文件选项卡开关，从而实现快速打开关闭等自动操作。

#### 实现思路：

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.385a9b.png)
1、打开

```javascript
// 获取designer（具体以实际项目为例）
var designer = GC.Spread.Sheets.Designer.findControl(document.getElementById("gc-designer-container"))
// 开
var command = GC.Spread.Sheets.Designer.getCommand("fileMenuButton");
command.execute(designer);
```

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.a11d2b.png)
2、关闭

```javascript
// 获取designer（具体以实际项目为例）
var designer = GC.Spread.Sheets.Designer.findControl(document.getElementById("gc-designer-container"))
// 关
GC.Spread.Sheets.Designer.getCommand('fileMenuPanel').execute(designer,"activeCategory_hide",true)
```
