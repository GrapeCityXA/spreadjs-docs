# modify-the-default-open-tab-panel

### 问题：如何使用设计器修改默认打开的Tab面板

***

#### 需求：

在使用编辑器的时候，默认打开的就是”开始“面板，部分用户需要在进入设计器时默认打开其他的面板，如数据、视图等面板。

#### 实现步骤：

可以通过给指定ribbon设置visibleWhen属性来实现这个需求。例如，需要默认展示的Tab面板是”数据“。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.cd2eb5.png?width=900)

只需要用下面的代码即可实现默认打开”数据“面板：

```javascript
let designer = new GC.Spread.Sheets.Designer.Designer(
  document.getElementById("gc-designer-container")
);
let spread = designer.getWorkbook();
const FirstLoad = "firstLoad";
let config = GC.Spread.Sheets.Designer.DefaultConfig;
config.ribbon[3].visibleWhen = FirstLoad;
designer.setConfig(config);
designer.setData(FirstLoad, true);
designer.refresh();
```
