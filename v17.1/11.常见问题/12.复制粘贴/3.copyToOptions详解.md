# In-depthExplanationOfCopyToOption

### 问题：copyTo方法提供的复制选项CopyToOptions的参数都有什么作用

[copyTo](https://demo.grapecity.com.cn/spreadjs/help/api/classes/GC.Spread.Sheets.Worksheet#copyto)方法用于将数据从一个区域复制到另一个区域，并且提供了[CopyToOptions](https://demo.grapecity.com.cn/spreadjs/help/api/enums/GC.Spread.Sheets.CopyToOptions#enumeration-copytooptions) 复制选项用于进行差异化的内容复制。
如下面的代码设置：

```js
sheet.copyTo(0, 0, 1, 1, 2, 2, GC.Spread.Sheets.CopyToOptions.value);
```

CopyToOptions设置的内容是GC.Spread.Sheets.CopyToOptions.value，这代表这只会将区域内容的value复制另一个指定区域。
诸如此类的设置还有：

| 参数 | 类型 | 枚举值 | 解释 |
| --- | --- | --- | --- |
| value | number | 1 | 表示数据类型为纯数据 |
| formula | number | 2 | 表示数据类型为公式 |
| comment | number | 4 | 表示数据类型为批注 |
| outline | number | 8 | 表示复制区域分组 |
| sparkline | number | 16 | 表示数据类型为迷你图 |
| span | number | 32 | 表示复制单元格合并 |
| style | number | 64 | 表示数据类型为样式 |
| tag | number | 128 | 表示数据类型为标签 |
| bindingPath | number | 256 | 表示数据类型是绑定路径 |
| conditionalFormat | number | 512 | 表示数据类型为条件格式 |
| hyperlink | number | 1024 | 表示数据类型为超链接 |
| all | number | 2047 | 表示所有类型的数据 |

通过上面的设置可以有效的将数据内容按种类进行剥离复制粘贴。
如果想要同时复制其中的多项（并非全部），例如从一片区域的复杂数据中只复制值value，公式formula，样式style。
可以参考下面代码完成：

```javascript
sheet.copyTo(
  fromRow,
  fromColumn,
  toRow,
  toColumn,
  rowCount,
  columnCount,
  GC.Spread.Sheets.CopyToOptions.value |
    GC.Spread.Sheets.CopyToOptions.formula |
    GC.Spread.Sheets.CopyToOptions.style
);
```
