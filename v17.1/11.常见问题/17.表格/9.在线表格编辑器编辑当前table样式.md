# edit-current-table-style-in-online-editor

### 需求：如何实现在线表格编辑器对当前table样式的编辑

#### 背景：

在线表格编辑器中可以给表格新建样式，并在表格中使用。 也可以通过设计器提供的API，直接调用表格样式的Dialog来编辑当前表格。

#### 实现方式：

核心代码实现：

```javascript
let sheet = spread.getActiveSheet();
var rowIndex = sheet.getActiveRowIndex();
var colIndex = sheet.getActiveColumnIndex();
var table = sheet.tables.find(rowIndex, colIndex);
if (!table) return;
let args = {
  data: {
    currentTheme: sheet.currentTheme(),
    styleName: table.style().name(),
    customTableStyle: table.style(),
  },
};

GC.Spread.Sheets.Designer.showDialog(
  GC.Spread.Sheets.Designer.TemplateNames.TableStyleDialogTemplate,
  args,
  function (result) {
    table.style(result.data.customTableStyle);
  }
);
```
