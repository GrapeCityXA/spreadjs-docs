# dynamic-name-manager-splicing

### 问题：如何实现动态名称管理器拼接

***

#### 背景：

在用代码添加名称管理器时，一些场景中，客户会觉得自己来拼接编写名称管理器的引用区域略显复杂，希望可以根据区域来动态生成名称管理器的引用范围。

#### 解决方案：

可以先参考一下在SpreadJS在线表格编辑器中，对于一个单元格区域生成的名称管理器引用区域
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.57da35.png)

根据上图，当添加一个名称管理器时，引用区域为Sheet2!$C$5:$D$6，由工作表名称和区域引用组成。如果使用API去添加，容易出错，此时，我们可以借助其它API来拼接出引用字符串，详细代码如下：

```js
let rangeStr = GC.Spread.Sheets.CalcEngine.rangeToFormula(
  sheet.getRange(0, 0, 4, 4)
);
let cusref = `='${sheet.name()}'!${rangeStr}`;
sheet.addCustomName("test", cusref, 0, 0);
```

添加完上述代码之后，打开名称管理器，就可以看到添加的信息：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.a85eb3.png)
需要注意的时，这列拼接工作表名称时，工作表名称需要加单引号，防止当工作表名称出现一些运算符时，后续定位单元格有问题。

另外，作为补充，这里也附加介绍一下在**GCExcel**中为某个单元格区域生成名称管理器的引用范围

```Java
Workbookwb=newWorkbook();
IWorksheetws=wb.getActiveSheet();
ws.setName("CIT.WP01.3_预提费用-FS");
Referencerefer=newReference();
refer.setWorksheetName(ws.getName());
refer.setRow(0);
refer.setColumn(0);
refer.setIsColumnRelative(false);
refer.setIsRowRelative(false);
ws.getNames().add("test",refer.toString());
wb.save("test.xlsx");
```

添加完成后，导出Excel，名称管理器展示如下：
