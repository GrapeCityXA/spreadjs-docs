# set_scrollbarMaxAlign_to_avoid_scrollarea

### 问题：为什么sheet区域没有超出视图区域，滚动条也能滚动

#### 背景

在一些场景中，行列数并不多，从界面上来看，如下图，所有的行列甚至没有占满视图区域，但是为什么滚动条仍然可以滚动
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.5a0c48.png)

#### 解决方案

这个是spreadjs本身的设计，默认设置下，以纵向滚动条为例，会一直滚动到最后一行显示在顶部
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.51ac3b.png)

如果需要避免这种情况
你可以设置 **scrollbarMaxAlign** 和 **scrollbarShowMax** 选项来限制滚动的区域。
scrollbarMaxAlign: 滚动条是否对齐视图中表单的最后一行或一列。
scrollbarShowMax: 是否基于表单全部的行列总数显示滚动条。

```javascript
    spread.options.scrollbarMaxAlign = true;
    spread.options.scrollbarShowMax = true;
```

使用上述代码即可避免在滚动区域和表单区域不一致的问题
