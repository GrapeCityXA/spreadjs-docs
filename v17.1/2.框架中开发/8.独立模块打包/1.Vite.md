# vite

Vite 是一个用于多个框架（例如 React、Vue 等）的脚手架项目的构建工具。SpreadJS 支持在 Vite 开发环境中使用单个模块和插件。

### **使用模块与插件**

包含以下的步骤：

1. 打开命令提示符窗口，输入以下命令配置 Vite 开发环境。

    ```shell
    npm create vite@latest
    ```

    然后选择以下选项。

    ```shell
    √ Project name: ... vite-project
    √ Select a framework: » Vanilla
    √ Select a variant: » TypeScript
    ```

    并使用以下命令启动项目。

    ```shell
    cd vite-project
    npm install
    npm run dev
    ```

    更多如何使用Vite创建项目，请参考 [Vite](https://vitejs.dev/guide/)。
2. 在项目中安装SpreadJS模块和插件。
    使用以下命令安装 SpreadJS NPM 模块和插件:

    ```shell
    npm install @grapecity-software/spread-common @grapecity-software/spread-calc-engine @grapecity-software/spread-sheets-core @grapecity-software/spread-sheets-calc-engine @grapecity-software/spread-sheets-print
    ```
3. 使用以下代码更新 main.ts 文件：

    ```typescript
    import * as GC from "@grapecity-software/spread-common";
    import "@grapecity-software/spread-calc-engine";
    import "@grapecity-software/spread-sheets-core";
    import "@grapecity-software/spread-sheets-calc-engine";
    import "@grapecity-software/spread-sheets-print";
    let spread = new GC.Spread.Sheets.Workbook("ss");
    let sheet = spread.getActiveSheet();
    sheet.setValue(0, 0, "Hello SpreadJS");
    spread.print();
    ```
4. 使用以下代码更新index.html文件：

    ```html
    <!DOCTYPE html>
    <html lang="en">
      <head>
        <meta charset="UTF-8" />
        <link rel="icon" type="image/svg+xml" href="/vite.svg" />
        <meta name="viewport" content="width=device-width, initial-scale=1.0" />
        <title>Vite + TS</title>
        <link rel="stylesheet" type="text/css" href="../node_modules/@grapecity-software/spread-common/styles/gc.spread.sheets.excel2016colorful.css" />
      </head>
      <body>
        <div id="ss" style="width: 100%;height:300px;"></div>
        <script type="module" src="/src/main.ts"></script>
      </body>
    </html>
    ```
5. 在 vite-project 文件夹中添加 vite.config.js 文件，代码如下：

    ```javascript
    import { fileURLToPath, URL } from 'node:url'
    import { defineConfig } from 'vite'
    // https://vitejs.dev/config/
    export default defineConfig({  
    resolve: {   
    alias: {      
    '@grapecity-software/spread-sheets': fileURLToPath(new URL('./node_modules/@grapecity-software/spread-common', import.meta.url))    
    } 
    }
    })
    ```
