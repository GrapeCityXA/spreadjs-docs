# export-range-to-html

可以使用[CellRange](gcdocsite__documentlink?toc-item-id=64f05fd4-fafa-47dc-9856-b74263f357ec)类的[toHTML](gcdocsite__documentlink?toc-item-id=64f05fd4-fafa-47dc-9856-b74263f357ec#toHtml)方法将单元格区域或整个表单导出到HTML字符串。

 **toHTML** 方法提供了两个参数， **includeStyle** 和 **headerOptions** 。 **includeStyle** 参数指示是否包含style和span，其默认值为true。 **headerOptions** 参数指示当单元格区域是视图端口区域的整行或整列时，是否包含行标题或列标题。

[HeaderOptions](gcdocsite__documentlink?toc-item-id=92c0ae6b-7112-40f8-bdec-1573501e9f9b)枚举有4个选项，如下:

-  **noHeaders** : 这是默认值。当导出区域数据到HTML时，删除列和行标题。
-  **rowHeaders** : 在导出区域数据到HTML时包括指定的行标题。
-  **columnHeaders** : 在导出区域数据到HTML时包括指定的列标题。
-  **allHeaders** : 在将区域数据导出到HTML时，包括指定的行和列标题。

可以使用 **includeStyles** 参数来指定在将区域导出为HTML字符串时是否需要包含单元格样式。此参数的默认值为true。

以下是导出区域到HTML时所支持的特性。

- Cell text
- Cell span
- 单元格样式设置，如 backColor, foreColor, font, vAlign, hAlign, borderLeft, borderRight, borderTop, borderBottom, and textDecoration
- Gridlines
- Row height / Column width

以下是导出区域到HTML时所不支持的特性

- 单元格样式属性，如 textIndent, wordWrap, showEllipsis, shrinkToFit, backgroundImage, cellType, watermark, diagonalDown, diagonalUp, isVerticalText, cellButtons, dropDowns, textOrientation, etc.
- Zoom
- Scrollbar
- TabStrip
- AutoMerge
- Barcode
- Chart
- Comment
- Data bar and Icon set
- Filter
- Picture and custom floating object
- Formula TextBox
- Group
- Hyperlink
- OutlineColumn
- Pivot table
- Shape
- Slicer
- Sparkline
- Status bar
- Table
- Validation



### 导出区域到HTML

使用 **toHTML** 方法在运行时或通过代码将选择的区域导出到HTML字符串。

你可以使用the **toHTML** 方法在运行时将选择的视口区域区域导出为HTML字符串。下面的示例在运行时以html格式导出选定的单元格区域。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/export-range-to-html-runtime.png)

下面的代码在运行时将选择的视口区域区域导出为HTML字符串。


```JavaScript
//Gets the Html content from selected range of viewport area to an htmlContainer
var r, c, rc, cc;
// 获取选择区域
var selectedRanges = activeSheet.getSelections();
r = selectedRanges[0].row;
rc = selectedRanges[0].rowCount;
c = selectedRanges[0].col;
cc = selectedRanges[0].colCount;
var html = activeSheet.getRange(r, c, rc, cc).toHtml();
document.getElementById("htmlContainer").innerHTML = html;
```

您还可以在后台使用代码而不是在运行时将选择的视口区域区域导出为HTML字符串。

以下代码将表单中特定区域的单元格[A1:B8]导出为HTML字符串。


```Javascript
// Gets the Html content from range "A1:B8" of viewport area to an htmlContainer
var html = activeSheet.getRange("A1:B8").toHtml();
document.getElementById("htmlContainer").innerHTML = html;
```



### 导出整个表单到HTML

使用 **toHTML** 方法将整个表单导出为HTML字符串。下面的示例导出整个表单，其中包含关于产品在各国不同城市和州的销售情况的信息。

下面的代码将整个表单导出为HTML字符串。


```JavaScript
// 从具有数据的viewport区域获取Html内容到htmlContainer
var html = activeSheet.getRange(-1, -1, -1, -1).toHtml(GC.Spread.Sheets.HeaderOptions.allHeaders);
document.getElementById("htmlContainer").innerHTML = html;
```
