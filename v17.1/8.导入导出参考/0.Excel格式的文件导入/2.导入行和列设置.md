# excelcolrowimp

下表总结了SpreadJS从Excel文件导入数据时如何处理行和列设置。 除非另有说明，否则这些属性是GC.Spread.Sheets.Worksheet类的成员。

|  **Excel 设置**  |  **SpreadJS设置**  |  **备注**  |
|--- |--- |--- |
| 隐藏的列或行 | Sheet. **setRowVisible** or Sheet. **setColumnVisible**  | SpreadJS从Excel导入此设置。 |
| 行高 | Sheet. **setRowHeight**  | SpreadJS从Excel导入此设置。 |
| 列宽 | Sheet. **setColumnWidth**  | SpreadJS从Excel导入此设置。 |
| 行数或列数 | Sheet. **setRowCount** or Sheet. **setColumnCount**  | 导入时，rowCount和columnCount是最后一个非空的行和列。 如果表单中没有数据，则行和列为activeCell.row和column。 |
| 起始列和行 |  | 目前不支持。 |
