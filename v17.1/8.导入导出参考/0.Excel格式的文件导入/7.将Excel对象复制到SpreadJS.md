# clipboardobjects

你可以从Excel中复制Excel样式和浮动对象，然后粘贴到SpreadJS中的表单中。这使得您可以很容易地复制Excel样式和浮动对象，而无需导入整个表格。您可以通过设置 **allowCopyPasteExcelStyle** 属性为true来启用样式和对象的复制和粘贴。



### Excel的样式

将 **allowCopyPasteExcelStyle** 属性设置为true，允许复制和粘贴样式。


```JavaScript
spread.options.allowCopyPasteExcelStyle = true;
```

### 浮动对象

通过设置 **allowCopyPasteExcelStyle** 属性为true，也可以从Excel复制浮动对象并粘贴到SpreadJS表单中。请注意，您可以从Excel复制图表和形状，并将它们作为图像粘贴到SpreadJS中。默认情况下，这个特性已经在SpreadJS中启用了，但是它不支持从SpreadJS复制和粘贴图片到Excel。

你可以在Windows和Mac中使用Ctrl + V和Command + V键盘组合，同时将图片粘贴到SpreadJS表单中，如下图所示。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/copy_image_spreadjs.gif)

可以看到，在SpreadJS中粘贴原始图像时，它的大小和内容没有受到影响。但是，您可以使用调整大小处理程序来调整已粘贴图像的大小。图像在表单中的位置由SpreadJS的活动单元格决定。你可以在SpreadJS表单中一个一个的复制粘贴图像，或者从excelor复制所有的图像，并将它们作为一个大图像粘贴到表单中。
