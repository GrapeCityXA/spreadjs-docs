# excelwhimp

下表总结了SpreadJS从Excel格式的文件导入数据时如何处理表单设置。 除非另有说明，否则这些设置是GC.Spread.Sheets.Worksheet类的成员。

|  **Excel 设置**  |  **SpreadJS 设置**  |  **备注**  |
|--- |--- |--- |
| Worksheets Worksheet names | SpreadJS Spread.name | SpreadJS从Excel导入此设置。 |
| Default Width | Sheet.defaults.colWidth | SpreadJS从Excel导入此设置。 |
| Frozen panes | Sheet. **frozenRowCount** or Sheet. **frozenColumnCount**  | SpreadJS从Excel导入此设置。 |
| Data |  | SpreadJS从Excel加载数据。 |
| Sparkline | Sheet.setSparkline | SpreadJS从Excel导入此设置。 |
| Spans | Sheet.addSpan | SpreadJS从Excel加载所有跨度信息。 |
| ActiveCell | Sheet.setActiveCell | 从Excel导入时，SpreadJS设置活动单元格。 |
| Selections | Sheet.setSelection | 从Excel导入时，SpreadJS设置选择。 |
| GridLine | Sheet. **options.gridline**  | SpreadJS从Excel导入此设置。 |
| Zoom | Sheet.zoom | 从Excel导入时，SpreadJS保留缩放因素。 |
| Theme | Sheet.currentTheme | SpreadJS从Excel导入此设置。 |
| Conditional Formats | Sheet.ConditionalFormats | 从Excel导入时，SpreadJS加载所有条件格式。 |
| TabColor | Sheet. **options.sheetTabColor**  | SpreadJS从Excel导入此设置。 |
| Sheet Protected | Sheet. **options.isProtected**  | SpreadJS从Excel导入此设置。 |
| Tables | Sheet.tables.add | 从Excel导入时，SpreadJS加载所有表。 |
| Range Group | Sheet.rowOutlines or Sheet.columnOutlines | 从Excel导入时，SpreadJS加载所有组信息。 |
| Cell Overflow | Sheet. **options.allowCellOverflow**  | SpreadJS将allowCellOverflow设置为true（单元始终可以在Excel中溢出）。 |
| Filter | Sheet.rowFilter | 从Excel导入时，SpreadJS加载所有筛选信息。 |
| Sheet Custom Names | Sheet.addCustomName | 从Excel导入时，SpreadJS加载所有自定义名称。 |
| Sheet Row or Column Header | Sheet. **options.rowHeaderVisible** or Sheet. **options.colHeaderVisible**  | SpreadJS从Excel导入此设置。 |
