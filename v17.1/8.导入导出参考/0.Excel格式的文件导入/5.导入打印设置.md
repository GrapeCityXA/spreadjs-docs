# excelprinti

下表总结了如何使用 **PrintInfo** 设置SpreadJS从Excel格式的文件导入数据。

|  **Excel 设置**  |  **SpreadJS 设置**  |  **备注**  |
|--- |--- |--- |
| BlackAndWhite |  **blackAndWhite**  | SpreadJS从Excel导入设置。 |
| CenterHorizontally or CenterVertically |  **centering**  | SpreadJS从Excel导入设置。 |
| PrintArea |  **columnEnd**  | SpreadJS从Excel导入设置。 |
| PrintArea |  **columnStart**  | SpreadJS从Excel导入设置。 |
| FirstPageNumber |  **firstPageNumber**  | SpreadJS从Excel导入设置。 |
| FitToPagesTall |  **fitPagesTall**  | SpreadJS从Excel导入设置。 |
| FitToPagesWide |  **fitPagesWide**  | SpreadJS从Excel导入设置。 |
| CenterFooter |  **footerCenter**  | SpreadJS从Excel导入设置。 |
| CenterFooterPicture |  **footerCenterImage**  | SpreadJS仅在OpenXml Excel中支持此功能。 |
| LeftFooter |  **footerLeft**  | SpreadJS从Excel导入设置。 |
| LeftFooterPicture |  **footerLeftImage**  | SpreadJS仅在OpenXml Excel中支持此功能。 |
| RightFooter |  **footerRight**  | SpreadJS从Excel导入设置。 |
| RightFooterPicture |  **footerRightImage**  | SpreadJS仅在OpenXml Excel中支持此功能。 |
| CenterHeader |  **headerCenter**  | SpreadJS从Excel导入设置。 |
| CenterHeaderPicture |  **headerCenterImage**  | SpreadJS仅在OpenXml Excel中支持此功能。 |
| LeftHeader |  **headerLeft**  | SpreadJS从Excel导入设置。 |
| LeftHeaderPicture |  **headerLeftImage**  | SpreadJS仅在OpenXml Excel中支持此功能。 |
| RightHeader |  **headerRight**  | SpreadJS从Excel导入设置。 |
| RightHeaderPicture |  **headerRightImage**  | SpreadJS仅在OpenXml Excel中支持此功能。 |
| LeftMargin 或 RightMargin 或 TopMargin 或 BottomMargin 或 FooterMargin 或 HeaderMargin |  **margin**  | SpreadJS从Excel导入设置。 |
| Orientation |  **orientation**  | SpreadJS从Excel导入设置。 |
| Order |  **pageOrder**  | SpreadJS从Excel导入设置。 |
| PaperSize |  **paperSize**  | SpreadJS从Excel导入设置。 |
| PrintTitleColumns |  **repeatColumnEnd**  | SpreadJS从Excel导入设置。 |
| PrintTitleColumns |  **repeatColumnStart**  | SpreadJS从Excel导入设置。 |
| PrintTitleRows |  **repeatRowEnd**  | SpreadJS从Excel导入设置。 |
| PrintTitleRows |  **repeatRowStart**  | SpreadJS从Excel导入设置。 |
| PrintArea |  **rowEnd**  | SpreadJS从Excel导入设置。 |
| PrintArea |  **rowStart**  | SpreadJS从Excel导入设置。 |
| PrintHeadings |  **showColumnHeader**  | SpreadJS从Excel导入设置。 |
| PrintGridlines |  **showGridLine**  | SpreadJS从Excel导入设置。 |
| PrintHeadings |  **showRowHeader**  | SpreadJS从Excel导入设置。 |
| Zoom |  **zoomFactor**  | SpreadJS从Excel导入设置。 |
