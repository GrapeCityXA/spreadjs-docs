# ExportingToPDF

SpreadJS支持PDF文件导出，即通过 **savePDF** 方法的 **Workbook** 类将工作簿（扩展名为.xlsx的Excel文件）导出PDF格式（扩展名为.pdf的文件）。

下表列出了 **savePDF** 方法的参数:

| 参数 | 描述 |
|--- |--- |
| successCallback | 导出到pdf操作成功后调用此函数。 |
| errorCallback | 发生错误时调用此函数。 |
| options | 导出PDF文件时，可以从以下选项中进行选择：<br /><br /> |
| sheetIndex | 通过指定要导出的表单索引，可以将工作簿中的特定表单导出PDF。 如果未指定此参数，则默认情况下将导出所有可见的表单。 |

导出PDF操作使用 **printInfo** 对象进行页面设置，并支持SpreadJS中所有可用的打印功能。

有关自定义导出PDF文件的更多信息，请参见[Custom PDF Export](gcdocsite__documentlink?toc-item-id=7d998b72-70cd-4d34-bd46-e81db1a2e0c2).

导出PDF文件时，您可以指定要嵌入到PDF文档中的字体。 用户可以嵌入标准字体（下面列出）和自定义字体（通过注册新字体）以进行PDF导出。

有关如何在执行导出PDF操作时嵌入自定义字体的更多信息，请参见[Use Custom Font for PDF Export](gcdocsite__documentlink?toc-item-id=823a69dc-54d0-488f-900d-fb7a4a9c31c0).

#### 示例代码

本示例说明了如何使用 **savePDF** 方法将Excel文件导出PDF文件。 导出的文件以.pdf扩展名保存。

代码的第一部分列出了执行“导出到PDF”操作的依赖项。

代码的第二部分说明了 **savePDF** 方法可用于导出PDF格式。


```JavaScript
<script src='.../spreadjs/gc.spread.sheets.all.x.xx.xxxxx.x.min.js' type='text/javascript'></script>
<script src='.../spreadjs/plugins/gc.spread.sheets.print.x.xx.xxxxx.x.min.js' type='text/javascript'></script>
<script src='.../spreadjs/plugins/gc.spread.sheets.pdf.x.xx.xxxxx.x.min.js' type='text/javascript'></script>
```


```JavaScript
spread.savePDF(function (blob) {
var fileName = $('#fileName').val() || 'download';
saveAs(blob, fileName + '.pdf');
}, function (error) {
console.log(error);
}, {
title: 'Test Title',
author: 'Test Author',
subject: 'Test Subject',
keywords: 'Test Keywords',
creator: 'test Creator'
});
```


> **注意:** 导出PDF时应牢记以下几点：<br /><br />1) 为了导出到excel文件，用户需要参考文件: gc.spread.sheets.pdf.*.*.*.min.js<br /><br />2) 图像未经过base64编码。 因此，当用户使用文件协议方案时，它们可能不会导出。 用户在执行导出操作时必须使用http或https协议方案。<br /><br />
