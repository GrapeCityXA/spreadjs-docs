# UseCustomFontforPDFExport

SpreadJS中的“导出为PDF”功能允许用户嵌入标准字体和自定义字体。 如果用户在导出为PDF时不想使用标准字体，则可以使用自定义字体。

使用自定义字体时，PDF将作为字体的子集嵌入文件中。 但是用户在执行导出操作时必须嵌入字体文件。

为了注册用于导出PDF的自定义字体，您可以使用 **registerFont** 方法的 **PDFFontManager** 类。 您还可以使用 **fallbackFont** 方法的 **PDFFontManager** 类为特定字体字符串提供自定义字体文件。

SpreadJS不支持导出.ttc字体。 仅True Type字体（.ttf字体）和Open Type字体（.otf）可以成功导出。 如果用户要使用.ttc字体，则可以使用在线转换器将它们转换为.ttf，然后在导出为PDF时使用它们。
> **注意:** SpreadJS不支持导出.ttc字体。 仅True Type字体（.ttf字体）和Open Type字体（.otf）可以成功导出。 如果用户要使用.ttc字体，则可以使用在线转换器将它们转换为.ttf，然后在导出为PDF时使用它们。 


#### 示例代码

本示例演示如何使用 **registerFont** 方法注册自定义字体。


```JavaScript
var font = {
normal: fonts['SIMSUN.ttf']
};
GC.Spread.Sheets.PDF.PDFFontsManager.registerFont('SimSun', font);
```



#### 示例代码

本示例说明了如何使用 **fallbackFont** 方法为特定字体字符串提供自定义字体文件。


```JavaScript
GC.Spread.Sheets.Print.PDFFontsManager.fallbackFont = function (font) {
var fontInfoArray = font.split(' '), fontName = fontInfoArray[fontInfoArray.length - 1];
if (fontName === 'Calibri') {
    return Calibri.ttf(encode with base64);
}
return Arial.ttf(in ArrayBuffer)
}
```



在使用自定义字体进行PDF导出时，必须确保该字体包含您已使用的所有字符集。 不这样做可能会使您的PDF文件不可读。
> **注意:** 在使用自定义字体进行PDF导出时，必须确保该字体包含您已使用的所有字符集。 不这样做可能会使您的PDF文件不可读。
