# excelspreadex

下表总结了SpreadJS导出到Excel格式的文件时如何处理组件级项目。 除非另有说明，否则这些函数在GC.Spread.Sheets.Workbook类中。

|  **Spread 设置**  |  **Excel 设置与备注**  |
|--- |--- |
| name | Excel将忽略Spread设置。 这特定于SpreadJS。 |
|  **options.sheetCount**  | Excel使用此设置。 |
|  **activeSheetIndex**  | Excel使用此设置。 |
|  **options.tabStripRatio**  | Excel将忽略Spread设置。 这特定于SpreadJS。 |
|  **options.tabStripVisible**  | Not supported at this time. |
|  **options.tabEditable**  | Excel将忽略Spread设置。 这特定于SpreadJS。 |
|  **options.newTabVisible**  | Excel将忽略Spread设置。 这特定于SpreadJS。 |
|  **options.referenceStyle**  | Excel使用此设置。 |
|  **options.allowUserEditFormula**  | Excel将忽略Spread设置。 这特定于SpreadJS。 |
| startSheetIndex | Excel使用此设置。 |
|  **options.allowUndo**  | Excel将忽略Spread设置。 这特定于SpreadJS。 |
|  **options.allowUserZoom**  | Excel将忽略Spread设置。 这特定于SpreadJS。 |
|  **options.allowUserResize**  | Excel将忽略Spread设置。 这特定于SpreadJS。 |
|  **options.allowUserDragDrop**  | Excel将忽略Spread设置。 这特定于SpreadJS。 |
|  **options.allowUserDragFill**  | Excel将忽略Spread设置。 这特定于SpreadJS。 |
|  **options.highlightInvalidData**  | Excel将忽略Spread设置。 这特定于SpreadJS。 |
|  **options.autoFitType**  | Excel将忽略Spread设置。 这特定于SpreadJS。 |
|  **options.showScrollTip**  | Excel将忽略Spread设置。 这特定于SpreadJS。 |
|  **options.showResizeTip**  | Excel将忽略Spread设置。 这特定于SpreadJS。 |
|  **options.showDragDropTip**  | Excel将忽略Spread设置。 这特定于SpreadJS。 |
|  **options.showDragFillTip**  | Excel将忽略Spread设置。 这特定于SpreadJS。 |
|  **options.showHorizontalScrollbar**  | Excel使用此设置。 |
|  **options.showVerticalScrollbar**  | Excel使用此设置。 |
|  **options.backColor**  | Excel将忽略Spread设置。 这特定于SpreadJS。 |
|  **options.backgroundImage**  | Excel将忽略Spread设置。 这特定于SpreadJS。 |
|  **options.backgroundImageLayout**  | Excel将忽略Spread设置。 这特定于SpreadJS。 |
|  **options.grayAreaBackColor**  | Excel将忽略Spread设置。 这特定于SpreadJS。 |
| named styles | Excel使用此设置。 |
| names | Excel使用此设置。 |
