# spdesigner-gettingstarted




您可以通过将 SpreadJS ZIP 文件 (SpreadJS.Release.xxxx.zip) 下载到系统上的临时目录来安装 SpreadJS Designer，然后在将文件解压缩到目录后执行首选安装文件。

SpreadJS 设计器已包含在 SpreadJS 产品下载中。
> **注意:** SpreadJS 设计器已包含在 SpreadJS 产品下载中。 
|  **安装目录**  |  **文件**  |  **描述**  |
|--- |--- |--- |
| \SpreadJS.Release.xxxx\Designer\Designer Runtime |  | 产品主目录 |
| SpreadJS-Designer.xxx.exe | Windows |
| SpreadJS-Designer.xxx.dmg | MacOS |
| SpreadJS-Designer.xxx.AppImage | Linux |



## 许可证信息

SpreadJS Designer 支持以下类型的许可证：



### Unlicensed

未授权版本允许您使用 SpreadJS Designer 的所有功能 30 天。

应用程序窗口的顶部栏显示以下消息：

 *"Evaluation version (30 day(s) left). Select the LOCK button to activate the Designer before the trial ends."* 

右下角显示水印：

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/no-key-watermark.png)



30 天试用期到期后，所有导入/导出操作都将被禁用。打开 Designer 后，顶部会出现以下消息：

 *"License not found. Select the LOCK button to activate the Designer."* 

许可证对话框如下所示：

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/license-active-dialog.png)



### 评估许可证

评估许可证允许您使用 SpreadJS Designer 的所有功能。

但是，应用程序窗口的顶部栏显示以下消息：

 *"Evaluation version (30 day(s) left). Select the LOCK button to activate the Designer before the trial ends."* 

右下角会显示水印。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/evaluation-watermark.png)



### Licensed

许可版本允许您使用 SpreadJS Designer 的所有功能。



#### 申请许可证

SpreadJS Designer 的许可证密钥应在“License Information”对话框中设置

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/license-active-dialog.png)

如果通过上述对话框应用了无效的许可证密钥，则会在顶部和电子表格区域中显示以下消息：

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/invalid-license.png)



### 数据透视表插件

在 14.1 或更高版本中，SpreadJS Designer 应用程序默认包含数据透视表插件，仅供开发人员使用。这未获得部署许可。
