# page-layout-tab

 **页面布局** 选项卡允许用户控制和自定义工作簿或工作表内容在打印页面上的显示方式。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/designer-pagelayout-tab.png)

下表列出了“页面布局”选项卡的区域和选项：

| 区域 | 描述 |
|--- |--- |
| Page Setup | 提供边距、方向、页面大小、打印区域、分页符、背景和页面标题的选项。 |
| Scale to Fit | 提供页面宽度、高度和比例的选项。 |
| Sheet Options | 为活动工作表和打印提供网格线和标题显示视图选项。 |
