# print-settings-designer

SpreadJS表格编辑器提供了一个页面设置对话框，有助于设置页面的布局和打印选项。 单击页面布局选项卡，然后在页面设置组中，单击右下方箭头按钮。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/designer-printsetup-button.png)

“页面设置”对话框包含 4 个选项卡 - Page, Margin, Header/Footer, Sheet。每个选项卡都包含一组有助于打印工作表的选项，下方对每个选项卡的功能进行了描述。

-  **Page** - 包含的选项有 "Orientation", "Scaling", "Paper size", "Print quality".
-  **Margins** - 页面预览，包含所有边（左侧、顶部、页脚等）和内容位置的边距输入字段。
-  **Header/Footer** - 设置字符串格式，例如页码、标题。 创建自定义页眉/页脚的选项。
-  **Sheet** - 设置打印区域、打印标题等。



### Page

此选项卡包含"Orientation", "Scaling", "Paper size", "Print quality"等选项。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/designer-print-page.png)

| 功能 | 描述 |
|--- |--- |
| Orientation | 设置打印纸张的方向，包含纵向和横向选型。 |
| Scaling | 设置打印区域的缩放比例。<br /><br />用户可以将尺寸调整为与正常尺寸成比例，或正好适合页面大小。<br /><br /> |
| Paper size | 设置纸张尺寸，用户可以从下拉列表中选择推荐尺寸。 |
| Print quality | 设置打印质量因数，用户可以从正整数1-8中进行选择。<br /><br />品质因数越大，打印质量越好。 当品质因数较大时，会影响打印效率。<br /><br /> |
| First page number | 设置起始页。<br /><br />当该字段设置为“自动”时，则从“1”（如果它是打印的第一页）或下一个连续页开始编号。<br /><br /> |



### Margins

此选项卡提供例如页面预览等选项，其中包含所有边（左侧、顶部、页脚等）和内容位置的边距输入字段。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/designer-print-margins.png)

| 功能 | 描述 |
|--- |--- |
| Margin preview | 设置边距，并在预览框中查看结果。<br /><br />用户可以设置顶部、右侧、底部、左侧、页眉和页脚的边距。<br /><br /> |
| Center on page | 设置水平、垂直或水平垂直，用来使页面上的数据居中。 |



### Header/Footer

此选项卡提供字符串格式（页码、标题）和创建自定义页眉/页脚等选项。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/designer-print-headerfooter.png)

| 功能 | 描述 |
|--- |--- |
| Header | 通过从下拉列表中选择内置页眉来设置页眉格式。<br /><br />内置页眉显示在下拉列表上方的预览框中。<br /><br /> |
| Custom header | 在新对话框中创建自定义页眉。<br /><br />提供了各种格式选项，例如格式文本、表单元素、图片，可以被设置在页眉的左侧、中间和右侧部分。<br /><br /> |
| Footer | 通过从下拉列表中选择内置页脚来设置页脚格式。<br /><br />内置页脚显示在下拉列表上方的预览框中。<br /><br /> |
| Custom footer | 在新对话框中创建自定义页脚。<br /><br />提供了各种格式选项，例如格式文本、表单元素、图片，可以被设置在页尾的左侧、中间和右侧部分。<br /><br /> |
| Different odd and even pages | 以不同方式设置奇数页和偶数页的页眉和页脚。<br /><br />启用此选项可分别访问自定义页眉/页脚窗口中的不同选项卡。<br /><br />如果已为页眉/页脚选择了模板格式，则奇数页部分也默认显示相同的内容。<br /><br /> |
| Different first page | 以不同方式设置第一页的页眉和页脚。<br /><br />启用此选项可分别访问自定义页眉/页脚窗口中的不同选项卡。<br /><br /> |



### Sheet

此选项卡提供打印区域、打印标题或打印工作表中的任何特定元素等选项。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/designer-print-sheet.png)

| 功能 | 描述 |
|--- |--- |
| Print area | 指定要打印的范围。 设置多个范围时将使用第一个值。 |
| Print titles | 如果用户需要将特定行作为每页的水平标题，请设置"Rows to repeat at top" 字段。<br /><br />如果用户需要在每页上显示垂直标题，请设置"Columns to repeat at left"字段。<br /><br /> |
| Print | 指定从工作表打印的内容。<br /><br /> |
| Page order | 指定当数据超过一页时的编号和打印顺序。<br /><br /> |
