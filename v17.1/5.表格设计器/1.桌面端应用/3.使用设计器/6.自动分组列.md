# auto-outline

SpreadJS 提供了在包含公式的单元格区域中自动区域分组的选项。您可以在“DATA”>“GROUP”功能区按钮中访问“Auto Outline”选项。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/designer-autooutline-option.gif)

如果工作表中已存在分组，则会弹出一个确认对话框。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/autooutline-10.png)

如果选择“确定”，则删除所有现有分组并根据当前公式创建新分组。



### 自动区域分组的行为

您可以在应用自动区域分组时观察以下行为。

| 行为 | 例子 |
|--- |--- |
| 分组方向遵循公式单元格位置。 | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/autooutline-formula-pos.png) |
| 如果行或列区域的分组方向与另一个不同，则将遵循前者。 | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/autooutline-1.png) |
| 如果行或列区域相交，则仅对第一个区域进行分组。 | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/autooutline-2.png) |
| 如果公式单元格的区域也包含公式，则合并所有合法单元格。 | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/autooutline-3.png) |
| 如果多个单元格组合成一个合法的单元格区域，则会添加一个区域分组。 | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/autooutline-4.png) |

以下单元格区域不能添加分组。

| 单元格区域 | 例子 |
|--- |--- |
| 单个单元格 | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/autooutline-7.png) |
| 多行多列 | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/autooutline-6.png) |
| 错位的行或列 | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/autooutline-8.png) |
| 跨sheet区域 | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/autooutline-9.png) |
| 循环引用 | ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/autooutline-5.png) |



### 清除分组

您可以使用“DATA”>“Ungroup”功能区按钮中的“Clear Outline”按钮清除工作表中所有分组。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/designer-clearoutline-option.gif)

自动分组和清除分组不支持撤销操作。
> **注意:** 自动分组和清除分组不支持撤销操作。
