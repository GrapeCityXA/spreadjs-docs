# designer-customize-culture

你可以在单元格格式窗口自定义组件版设计器文化对话框。[Spread.Common.CultureInfo](gcdocsite__documentlink?toc-item-id=36975826-ad1b-46dc-905c-05542a548c85)类可以通过区域ID、显示名称和预定义格式（货币、会计、日期、时间、特殊）等属性定义新的文化项。

- 初始化设计器实例。
```JavaScript
// 初始化组件设计器
var designer = new GC.Spread.Sheets.Designer.Designer(document.getElementById("designerHost"));
```


- 使用[CultureInfo](gcdocsite__documentlink?toc-item-id=36975826-ad1b-46dc-905c-05542a548c85#_ctor)构造方法获取文化示例。它代表自定义文化类。
```JavaScript
// 获取文化示例信息
var cultureInfo = new GC.Spread.Common.CultureInfo()
```


- 设置要在格式窗口中指定的文化信息属性。 请参阅[Microsoft Locale ID definition](https://docs.microsoft.com/en-us/openspecs/windows_protocols/ms-lcid/63d3d639-7fd2-4afb-abbe-0d5b5551eef8)来了解所有可用的区域设置ID。
```JavaScript
// 为德语设置新的文化信息
cultureInfo.displayName = "German (Germany)"
cultureInfo.name = function () { return "de-DE" }
cultureInfo.id = 0x407;
cultureInfo.predefinedFormats.Accounting = '_-* #,##0. [$€-407]_-;-* #,##0. [$€-407]_-;_-* "-". [$€-407]_-;_-@_-';
cultureInfo.predefinedFormats.Currency = [
    "#,##0. [$€-407]",
    "#,##0. [$€-407];[Red]#,##0. [$€-407]",
    "#,##0. [$€-407];-#,##0. [$€-407]",
    "#,##0. [$€-407];[Red]-#,##0. [$€-407]"
];
cultureInfo.predefinedFormats.Date = [
    "yyyy-mm-dd;@",
    "d.m;@",
    "d.m.yy;@",
    "dd.mm.yy;@",
    "[$-407]d. mmm.;@",
    "[$-407]d. mmm. yy;@",
    "[$-407]d. mmm yy;@",
    "[$-407]mmm. yy;@",
    "[$-407]mmmm yy;@",
    "[$-407]d. mmm yy;@",
    "[$-409]d/m/yy h:mm AM/PM;@",
    "d.m.yy h:mm;@",
    "[$-407]mmmmm;@",
    "[$-407]mmmmm yy;@",
    "d.m.yyyy;@",
    "[$-407]d. mmm. yyyy;@"
]
cultureInfo.predefinedFormats.Time = [
    "h:mm;@",
    "[$-409]h:mm AM/PM;@",
    "h:mm:ss;@",
    "[$-409]h:mm:ss AM/PM;@",
    "mm:ss.0;@",
    "[h]:mm:ss;@",
    "[$-409]d/m/yy h:mm AM/PM;@",
    "d.m.yy h:mm;@"
]
cultureInfo.predefinedFormats.Special = {
    "Postleitzahl": "00000",
    "Postleitzahl (A)": "\A-00000",
    "Postleitzahl (CH)": "C\H-00000",
    "Postleitzahl (D)": "\D-00000",
    "Postleitzahl (L)": "L-00000",
    "Versicherungsnachweis-Nr. (D)": "\[@\]",
    "Sozialversicherungsnummer (A)": "0000-00 00 00",
    "Sozialversicherungsnummer (CH)": "000\.00\.000\.000",
    "ISBN-Format (ISBN x-xxx-xxxxx-x)": "I\S\B\N #-###-#####-#",
    "ISBN-Format (ISBN x-xxxx-xxxx-x)": "I\S\B\N #-####-####-#",
    "ISBN-Format (ISBN x-xxxxx-xxx-x)": "I\S\B\N #-#####-###-#"
}
```


- 使用[addCultureInfo](gcdocsite__documentlink?toc-item-id=1d75c6d6-9498-4322-bb74-dde3cc8b8ce4#addCultureInfo)方法 添加新的文化信息对象 。
```JavaScript
// 添加新的文化信息
GC.Spread.Common.CultureManager.addCultureInfo(cultureInfo.name(), cultureInfo);
```
