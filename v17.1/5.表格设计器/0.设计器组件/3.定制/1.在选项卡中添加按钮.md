# add_button_in_tab

按照以下步骤在ribbon组件的“Home”选项卡中添加“Save Data”按钮。

- 打开并编辑config.js文件，将“保存数据”按钮添加到“HOME”栏的“buttonGroups”字段中。
```JavaScript
var config = {
    "ribbon": [
        {
          "id": "home",
          "text": "HOME",
          "buttonGroups": [
              // 自定义"Save Data"按钮
              {
                "label": "Save Data",
                "thumbnailClass": "",
                "commandGroup": {
                    "children": [
                        {
                         "direction": "vertical",
                         "commands": [
                         "cmdSaveData"
                          ]
                        }
                      ]
                   }
              },
```


- 在您的项目中设置上面的命令为commandMap。
```JavaScript
config.commandMap = {
   cmdSaveData: {
      title: "Save data to server",
      text: "Save",
      iconClass: "cmdSaveData",
      bigButton: "true",
      commandName: "cmdSaveData",
      execute: async (context, propertyName, fontItalicChecked) => {
      // 自定义操作符
         alert('Save data successfully.');
     }
   }
}
```


- 为“cmdSaveData”按钮添加CSS样式设置
```JavaScript
.cmdSaveData {
    background-image: url('./saveData.png');
    background-size: 35px 35px;
}
```


- 通过传递以下参数初始化设计器实例可自定义配置的"config"参数。
```JavaScript
// 初始化设计器实例
var designer = new GC.Spread.Sheets.Designer.Designer(document.getElementById("designerHost"), config);
```
