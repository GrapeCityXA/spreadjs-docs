# custom-status-bar

您可以通过使用[StatusBar class](gcdocsite__documentlink?toc-item-id=13dbecf6-db64-40a6-b060-5cc99c393de0)方法添加自定义项来自定义设计器组件中的状态栏。

要了解有关自定义状态栏的更多信息，请参阅[Status Bar](gcdocsite__documentlink?toc-item-id=7cd86322-52e7-4b93-a1e2-86fb35306f6f)。

按照以下步骤在状态栏中添加公司联系人邮件（例如“us.sales@grapecity.com”）作为状态项。

- 初始化设计器实例。
```JavaScript
var designer = new GC.Spread.Sheets.Designer.Designer(document.getElementById("designerHost"), '', spread);
```


- 使用[StatusBar.findControl](gcdocsite__documentlink?toc-item-id=13dbecf6-db64-40a6-b060-5cc99c393de0#findControl)方法获取状态栏实例 。此方法接受宿主元素或宿主元素 id
```JavaScript
var statusBar = GC.Spread.Sheets.StatusBar.findControl(document.getElementsByClassName("gc-statusBar"));
```


- 使用[StatusBar.StatusItem](gcdocsite__documentlink?toc-item-id=13dbecf6-db64-40a6-b060-5cc99c393de0#StatusItem)方法添加状态项 。
```JavaScript
var spanItem = new GC.Spread.Sheets.StatusBar.StatusItem('spanItem', {menuContent: 'current span', value: 'Contact: us.sales@grapecity.com'});
statusBar.add(spanItem);
```
