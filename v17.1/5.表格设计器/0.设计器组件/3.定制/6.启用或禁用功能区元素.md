# enable_disable_ribbon_elements

按照以下步骤禁用“INSERT”选项卡中的“Table”字段按钮。

- 
打开 config.js 文件以识别与“Table”按钮关联的命令，在本例中为“insertTable”命令。
```config.js
var config = {
    "ribbon": [
    {
      "id": "insert",
      "text": "INSERT",
      "buttonGroups": [
        {
          "label": "Table",
          "thumbnailClass": "ribbon-thumbnail-table",
          "commandGroup": {
            "commands": [
              "insertTable"
            ]
          }
        }]
    }]
}
```


- 在上面的命令（insertTable）上应用[getCommand](SpreadJSDesigner~GC.Spread.Sheets.Designer~getCommand)方法来识别它的状态表达式。
```JavaScript
console.log(GC.Spread.Sheets.Designer.getCommand('insertTable'));
// commandName: "insertTable"// enableContext: "AllowInsertTable  && !IsProtected"
```


- 在您的项目中将上述命令设置为 commandMap，并通过设置 **enableContext** 选项禁用相应的状态表达式。
```JavaScript
config.commandMap = {
    insertTable: {
        commandName: "insertTable",
        // To disable the Table button
        enableContext: "!AllowInsertTable" 
    }
}
```


- 通过传递“config”参数来初始化设计器实例
```JavaScript
// 初始化设计器实例
var designer = new GC.Spread.Sheets.Designer.Designer(document.getElementById("designerHost"), config);
```
