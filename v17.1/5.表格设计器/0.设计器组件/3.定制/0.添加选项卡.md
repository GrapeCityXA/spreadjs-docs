# add_tab

按照下面的步骤，通过添加一个新的标签“Contact Us”来定制ribbon组件。

* 获取defaultConfig，通过添加一个新的ribbon选项卡来定制布局结构。

```JavaScript
var config = GC.Spread.Sheets.Designer.DefaultConfig;
                        config.ribbon.push({
                            "id" : "contactUs",
                            "text": "Contact Us",
                            "buttonGroups": [{
                                "label": "Contact sales at (+1) 412-681-4343 or us.sales@grapecity.com to request temporary deployment authorization.",
                                "commandGroup": {
                                    "children": []
                                }    
                            }]
                        })
```

* 通过传递以下参数初始化设计器实例可自定义配置的"config"参数。

```JavaScript
// 初始化设计器实例
let spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
let designer = new GC.Spread.Sheets.Designer.Designer(document.getElementById("designerHost"), config, spread);
```

类似地，如果你想从ribbon组件中删除一个内置的标签，从config.js中删除它的内容，然后重复上面的第2步。
