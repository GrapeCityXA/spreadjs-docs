您可以通过下载ZIP文件(SpreadJS. designer . release . xxxxx . ZIP)到系统上的一个临时目录，然后将文件解压缩到一个目录来安装SpreadJS 组件版设计器。

* http(s)://xxx

评估许可允许您在本地机器和 Web 服务器上使用 SpreadJS 设计器组件的所有特性。然而，“SpreadJS Designer License”选项卡在工具栏显示以下消息:

#### **本地开发环境或本机 Web Server**

### 设置授权

许可版本允许您在本地机器和web服务器上使用SpreadJS设计器组件的所有特性。
如果你想部署一个网站，一个有效的许可证表组件也是必需的，可以通过设置 `GC.Spread.Sheets.LicenseKey = "xxx"` 使用.
SpreadJS设计器组件的许可密钥应该设置为 `GC.Spread.Sheets.Designer.LicenseKey` 和必须在创建设计器实例之前设置，如下所示:

```javascript
GC.Spread.Sheets.Designer.LicenseKey = "xxxx";
var designer = new GC.Spread.Sheets.Designer.Designer("designerHost");
```
