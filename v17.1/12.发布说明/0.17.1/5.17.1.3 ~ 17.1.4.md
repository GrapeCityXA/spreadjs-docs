# 1714

以下是 SpreadJS v17.1.4（包含v17.1.3） 的发布说明：

### 错误修复

* **SJS-24352**：修复了当 `tabStripPosition` 设置为左侧时会出现空白区域的问题。
* **SJS-25188**：修复了在报告中有大量图片时，切换 `RenderMode` 界面会导致卡顿的问题。
* **SJS-25356**：修复了数据透视表中小计文本“Total”位置不正确的问题。
* **SJS-25370**：修复了在编辑设计器单元格时再次点击后插入功能被禁用的问题。
* **SJS-25433**：修复了在设计器中设置无效公式后出现空白消息框的问题。
* **SJS-25519**：修复了 SpreadJS 的跨工作簿公式计算结果与 Excel 不一致的问题。
* **SJS-25522**：修复了在 Forguncy 中拖动列标题后，条件格式会错误地应用于拖动的列的问题。
* **SJS-25533**：修复了由 SpreadJS 导出的 xlsx 文件在筛选时非常卡顿的问题。
* **SJS-25554**：增加了支持可调整大小的数据透视面板的功能。
* **SJS-25572**：修复了在查找时选择列的行为与 Excel 不一致的问题。
* **SJS-25574**：修复了在修改列宽后，使用 `fromJSON` 定位到列 A 的问题。
* **SJS-25575**：修复了行分组中的分组结果不正确的问题。
* **SJS-25577**：修复了在设计模式下执行表格表的撤销操作时，撤销列表显示不正确的问题。
* **SJS-25585**：修复了 SpreadJS 大数据渲染内存使用量持续上升的问题。
* **SJS-25602**：修复了在取消拖放操作后，`DragDropBlockCompleted` 事件会被触发的问题。
* **SJS-25647**：修复了在预览并转换为工作表后，`Image()` 和 `Sparkline()` 无法正常工作的问题。
* **SJS-25650**：修复了报告中格式菜单的工作表保护状态未正确更新的问题。
* **SJS-25682**：修复了导入 JSON 后导出的 PDF 显示乱码的问题。
* **SJS-25684**：修复了手动 `CalculationMode` 下增量计算无法正常工作的问题。
* **SJS-25685**：修复了删除工作表命令导致异常的问题。
* **SJS-25694**：修复了 `AVERAGEIF` 计算结果与 Excel 不一致的问题。
* **SJS-25697**：修复了当行数为 0 时，通过列标题拖动列后会错误地添加新列的问题。
* **SJS-25711**：修复了导出特定工作簿时发生文件损坏的问题（v17.0.10）。
* **SJS-25730**：修复了报告单元格设置为自适应后，图片未在预期位置显示的问题。
* **SJS-25731**：修复了在重复行中插入图片后，第二页未显示图片的问题。
* **SJS-25733**：修复了文档属性未使用资源处理自定义属性的问题。
* **SJS-25736**：修复了 SpreadJS 设计器（日本版）设置对话框中选项卡控件的高度不正确的问题。
* **SJS-25744**：修复了在 Node 环境中加载 Excel 文件时的问题（SpreadJS v17.1.1）。
* **SJS-25746**：修复了在报告表中输入无效公式时会弹出两个错误对话框的问题。
* **SJS-25750**：修复了升级到 v17.1 后重写右键菜单错误的问题。
* **SJS-25759**：修复了 SpreadJS 的 `goalSeek` 计算结果与 Excel 不一致的问题。
* **SJS-25762**：修复了 Forguncy 中报告表多表提交记录错误的问题。
* **SJS-25773**：修复了在修改数据透视表的计算字段并保存后页面会卡住的问题。
* **SJS-25786**：修复了重新读取 JSON 后使用 `getUsedRange` 结果不正确的问题。
* **SJS-25787**：修复了报告设置数据行分页、固定行标题设置和扩展字段显示异常的问题。
* **SJS-25790**：修复了设置 `frozenColumnCount` 后难以将列拖动到第一列的问题。
* **SJS-25792**：修复了导入 Excel 后使用对话框修改单元格格式无效的问题。
* **SJS-25814**：修复了当 `isPrintLineVisible` 为 false 时，预览和 PDF 导出为空白的问题。
