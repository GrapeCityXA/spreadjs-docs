# releasenotesv13




此版本的产品添加了以下特性。

- [复选框列表单元格类型](https://www.grapecity.com/spreadjs/docs/v13/online/check-box-list-cell)现在支持用户创建具有多个选择字段值的交互式检查列表和待办事项列表
- [单选按钮列表单元格类型](https://www.grapecity.com/spreadjs/docs/v13/online/radio-button-list-cell)现在支持为用户提供从表单中一个单元格中可用的多个选项列表中选择单个项的能力
- [按钮列表单元格类型](https://www.grapecity.com/spreadjs/docs/v13/online/button-list-cell)现在支持在单个单元格中嵌入一组项，其中可以选择一个或多个选项来记录用户响应
- [区域模板单元类型](https://www.grapecity.com/spreadjs/docs/v13/online/range-template-cell)现在支持将单元格范围模板定义为单个单元格类型，并将该模板应用于整个表单的一个或多个单元格
- [单元格状态](https://www.grapecity.com/spreadjs/docs/v13/online/cell-states)(如编辑，悬停，活动，选择等)
- [单元格按钮](https://www.grapecity.com/spreadjs/docs/v13/online/cell-buttons)现在提供了预定义的按钮，如下拉按钮、撤消/重做按钮、启用/禁用按钮、旋转按钮等，以允许用户在表单的单元格中配置其他功能
- [单元格下拉](https://www.grapecity.com/spreadjs/docs/v13/online/cell-dropdowns)插入带有特定属性的自定义下拉菜单以创建高级输入表单和交互式仪表板的特性
- [自动合并](https://www.grapecity.com/spreadjs/docs/v13/online/auto-merge-cells)该特性的引入是为了允许用户自动合并包含重复文本的相邻单元格
- [公式审核](https://www.grapecity.com/spreadjs/docs/v13/online/formula-auditing)已经提供，允许用户通过跟踪表单中的前例和依赖的单元格来显示公式和单元格之间的关系
- [动态数组公式](https://www.grapecity.com/spreadjs/docs/v13/online/dynamic-array-formulas)([UNIQUE](https://www.grapecity.com/spreadjs/docs/v13/online/unique)公式,[FILTER](https://www.grapecity.com/spreadjs/docs/v13/online/filter-dynamic-array)公式,[RANDARRAY](https://www.grapecity.com/spreadjs/docs/v13/online/randarray)公式,[SORT](https://www.grapecity.com/spreadjs/docs/v13/online/sort)公式,[SORTBY](https://www.grapecity.com/spreadjs/docs/v13/online/sortby)公式,[SEQUENCE](https://www.grapecity.com/spreadjs/docs/v13/online/sequence)公式,[SINGLE](https://www.grapecity.com/spreadjs/docs/v13/online/single)公式等.) 构建缓存友好的数据结构
- [分大小](https://www.grapecity.com/spreadjs/docs/v13/online/split-resize-columns-and-rows)特性允许用户调整当前行或列以及下一个可见列或行的大小，而不影响表单中的其余行和列
- [动态列大小](https://www.grapecity.com/spreadjs/docs/v13/online/dynamic-column-size)允许用户配置列的宽度和行高，以这样的方式，viewport是完全按照用户指定的权重比例(*符号)填充
- ;[像素滚动](https://www.grapecity.com/spreadjs/docs/v13/online/scroll-by-pixel)特性的引入是为了支持类似excel的精度滚动
- [在单元格中旋转文本](https://www.grapecity.com/spreadjs/docs/v13/online/rotate-text-in-cells)(从-90度到+ 90度)改变数据在单元格中的显示方式
- [自定义图例格式、定位和样式](https://www.grapecity.com/spreadjs/docs/v13/online/ConfiguringLegends)现在支持在图表中使用图例
- 用户在表格中处理图表时[在值轴上配置显示单元](https://www.grapecity.com/spreadjs/docs/v13/online/ConfiguringAxes)
- [在图表中添加趋势线](https://www.grapecity.com/spreadjs/docs/v13/online/add-trendlines-to-charts)现在支持，以便使用户能够快速分析总体趋势(数据点的涨落)，显示一段时间内的数据移动，或者简单地关联两个不同的变量
- [在图表中添加错误条](https://www.grapecity.com/spreadjs/docs/v13/online/add-error-bars-in-charts)现在支持允许用户识别误差范围、标准差和显示数据可变性以及测量精度等
- [添加悬停动画和样式](https://www.grapecity.com/spreadjs/docs/v13/online/add-hover-animation-and-style)允许用户与图表中的数据点交互
- 用户可以将[垂直轴变更为对数刻度](https://www.grapecity.com/spreadjs/docs/v13/online/change-vertical-axis-to-logarithmic-scale)，允许用户自定义垂直轴(也称为值轴)的最小和最大刻度值
- 用户可以在图表中[在图表中显示空单元格和空值](https://www.grapecity.com/spreadjs/docs/v13/online/display-empty-cells-in-chart)，就像在Excel中一样此功能有助于在图表中绘制丢失的数据，从而快速识别和纠正数据中的任何问题
- 现在支持[自定义图表区域边界](https://www.grapecity.com/spreadjs/docs/v13/online/chart-area)
- 现在，当工作簿被保存时，SpreadJS就会像在Excel中一样[记住表单视图的位置](https://www.grapecity.com/spreadjs/docs/v13/online/spdesigneropen)
- 现在支持[AGGREGATE](https://www.grapecity.com/spreadjs/docs/v13/online/agrregate)函数.
- 本版本引入了新的主题"[Excel 2016 Black](https://www.grapecity.com/spreadjs/docs/v13/online/exceltheme)"
- 表格UI增强——在使用表格中的表格时引入了以下UI增强功能:- 现在支持“自动扩展表区域”特性在使用SpreadJS Designer时，用户可以在表区域旁边的下一行或列中输入数据，表将自动展开当用户执行剪切、复制、粘贴操作、拖填操作(向右或向下)或拖放操作时，如果粘贴区域超过表格范围，也会自动扩展表格
- 现在，可以通过SpreadJS设计器中的内置上下文菜单插入和删除表列和行
- 现在，用户可以通过在表单的多个位置移动游标来选择表的列、行或整个表例如，用户可以通过将鼠标悬停在表列标题的上边缘来选择表列，直到光标变为向下箭头，然后单击标题来选择表列用户还可以选择表的行或左上角来选择表
- 用户可以使用“TAB键”或“Shift+TAB”键在表格中的单元格之间快速切换或扩展表格范围
- 有了新引入的“固定滚动表标头”特性，当用户滚动表数据并且表标头不在表单的可见区域时，可以在列标头中显示表标头


- 在使用表格时，用户可以像在Excel中一样添加“合计行”还支持total row公式，以允许用户快速[显示表格页脚下拉列表](https://www.grapecity.com/spreadjs/docs/v13/online/tablestyle)，并选择下拉列表来选择和插入所需的摘要函数
- 现在，用户可以使用表调整处理程序轻松地[调整表格](https://www.grapecity.com/spreadjs/docs/v13/online/resize-tables)的大小
- 支持高级列绑定特性，允许用户[将格式化程序和单元格类型绑定到表列](https://www.grapecity.com/spreadjs/docs/v13/online/tablebind)



# 解决问题

自上次发布以来，以下问题已得到解决

- 通过双击行执行自动行高操作的结果现在是准确的
- 导入excel文件时不会显示任何内容错误
- 当单元格包含多行文本并且在编辑模式下使用“Ctrl+Z”键盘快捷键时，现在不会抛出DOMException
- STDEVA公式计算准确.
- 在将SSJSON文件导出到Excel文件时样式不变
- 导入Excel文件后计算函数时不会抛出 #Value错误
- 当使用中文输入法使用SpreadJS时，符号“=”现在可以在单元格中输入而不进入编辑模式
- 现在，SpreadJS中的wordwrap功能与Excel中的工作方式相同
- 表单可以正常删除，没有任何问题
- 当导入Excel文件到SpreadJS时，原来的边框没有丢失
- 当导出到PDF文件，边框保持完整，不会变窄
- 当使用sheet.visible()方法再次显示隐藏的表单时，不会抛出错误
- 现在解决了浮点精度问题，在计算ROUND函数时没有抛出计算错误
- 现在，SpreadJS在所有操作系统上的表现都是一致的，包括MAC、Linux和Windows (Chrome 67)
- 即使表单的“缩放”发生变更，嵌入到表单中的形状的位置仍保持不变
- 在处理图表时，右侧的网格线和标签会显示出来，没有任何问题
- 用户可以在使用图表时设置x轴的缩放间隔
- 不同的图表类型现在可以显示在同一图例区域此外，用户还可以修改图表中图例的图表线条类型
- 当公式参数是一个特定的字符串时，现在参数不会自动改变，选择单元格的操作也不会导致任何错误
- 删除表单后不会抛出错误
- 在SpreadJS中执行公式的结果现在的工作方式与在Excel中相同
- 在SpreadJS中导入Excel文件时，图表标题的样式保持不变
- 禁用形状调整大小功能后，形状调整光标现在不显示
- 当使用回退字体时，现在对导出PDF操作的性能没有影响
- 现在一个表中绑定了数千行(50,000行)，滚动速度更快了
- 在已单击的图形下面的另一个图形现在不会被意外选中
- 在表格中使用二维码时不会抛出错误
- SJS设计器的图表菜单现在工作正常，没有任何问题
- 现在的导出操作比以前花的时间少了，速度也快了很多
- 自定义单元格样式现在可以正常工作
- 在打开导出的Excel文件，现在用户可以恢复警告消息
- 在导出Excel文件时，如果设置了二级轴，列栏不会重叠
- 当用户右键单击表格时，现在形状的上下文菜单按预期工作，如果形状是隐藏的，则不会显示
- 导入的Excel文件现在显示正确的格式
- 如果数据源通过逗号分隔，图表的数据源现在会正确突出显示
- 如果一个工作簿包含小计公式和工作簿被销毁作为路由到另一个页面或由于错误条件*ngIF，那么错误“TypeError: Cannot read property 'getRowCount' of null”现在不抛出错误
- 筛选后的行的拖拽填充操作现在就像在Excel中一样，没有任何问题
- 用户可以正确导入包含交叉工作簿公式引用的Excel文件
- 用户可以很容易地复制粘贴换行内容使用公式文本框
- 可以缩放形状
- 即使在一个循环中导出多个文件，也可以正确导出Excel文件
- SMALL公式可以正确计算
- 图表现在可以呈现特定的高度值
- 当用户设置了条件格式时，筛选对话框就会立即显示出来
