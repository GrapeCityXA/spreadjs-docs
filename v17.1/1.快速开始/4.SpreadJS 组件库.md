核心 JS 必须始终加载。 必须先加载 calcengine js 才能使用函数。 许多功能都使用 calcengine js，因此您可能希望先加载它。 如果使用尚未加载的js文件中的函数，则该函数不会生效。
JS 文件位于 SpreadJS 脚本文件夹下。

#### 示例代码

本示例使用基本的 SpreadJS 功能。

```JavaScript
<!DOCTYPE html>
<html>
<head>
<title>SpreadJS Pluggable Sample</title>
    <link type="text/css" href="./css/gc.spread.sheets.13.0.0.css" rel="stylesheet"/>
    <!--SpreadJS pluggable common function library-->
<script type="text/javascript" src="./scripts/pluggable/gc.spread.common.13.0.0.min.js"></script>
    <!--SpreadJS pluggable core function library-->
<script type="text/javascript" src="./scripts/pluggable/gc.spread.sheets.core.13.0.0.min.js"></script>
    <script>
    // The Spread definition and most UI behavior is in the SpreadJS core library.
        window.onload = function () {
        var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
        var sheet = spread.getActiveSheet();
        sheet.setValue(0, 0, 20);
    };
</script>
</head>
<body>
<div id="ss" style="width:800px; height:600px; border: 1px solid gray;"></div>
</body>
</html>
```
