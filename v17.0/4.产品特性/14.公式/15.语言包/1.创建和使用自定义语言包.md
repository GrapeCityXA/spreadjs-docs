# CustomLanguagePackage

除了超过 18 个可用的语言包外，SpreadJS 还支持自定义本地化。

您可以自定义语言包并修改现有的语言包。根据您的特定偏好显示单词或短语。



### 使用自定义语言包

创建和使用自定义语言包非常有用，尤其是当用户在不同语言环境中工作时需要使用区域日期和时间格式时。

您可以本地化函数名称、使用自定义函数、定义表函数、自定义表公式关键字、CalcError 短语、布尔值，并使用首选语言处理特殊函数逻辑。

您可以使用[culture()](gcdocsite__documentlink?toc-item-id=1d75c6d6-9498-4322-bb74-dde3cc8b8ce4#culture)方法，[addCultureInfo() ](gcdocsite__documentlink?toc-item-id=1d75c6d6-9498-4322-bb74-dde3cc8b8ce4#addCultureInfo)方法自定义语言包

### 修改现有语言包

您可以自定义现有的语言包并将它们翻译成特定的语言。 比如需要在spread中显示不同的文本。

您可以使用[CultureManager.getResources](gcdocsite__documentlink?toc-item-id=1d75c6d6-9498-4322-bb74-dde3cc8b8ce4#getResources)方法来获取当前或指定的文化资源。此方法返回当前工作语言或指定的语言包。

获得语言包后，您可以按照以下步骤将修改后的包应用到Spread：

- 修改返回的语言包。
- 使用 addCultureInfo 方法将语言添加到 SpreadJS 中。
- 使用 CultureManager.culture 方法更改 SpreadJS 语言。


> **注意:** 如果您通过 addCultureInfo 方法添加自定义语言，则无法立即获取此资源，直到使用 CultureManager.culture 方法将当前文化更改为自定义文化。<br /><br />或者，您可以直接使用 CultureManager.getLanguage 方法。<br /><br /> 
下面的 GIF 说明了使用特定的中文字符串（宽度滚动提示）与日语语言包。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/get-resource.gif)



以下示例代码显示了如何修改和使用现有语言包。


```JavaScript
// 配置工作簿和工作表
var spread = new GC.Spread.Sheets.Workbook("ss");
var sheet = spread.getActiveSheet();

// 显示行高和列宽的调整大小提示
spread.options.showResizeTip = GC.Spread.Sheets.ShowScrollTip.both;
// 获取指定语言
var originResources = GC.Spread.Common.CultureManager.getResources("ja-jp"); 
// 修改语言。
originResources.Sheets.Tip_Width = "宽度： {0} 像素"; 
GC.Spread.Common.CultureManager.addCultureInfo("custom", null, originResources);
GC.Spread.Common.CultureManager.culture("custom");
```
