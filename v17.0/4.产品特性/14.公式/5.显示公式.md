# show_cell_formulas

用户可以查看单元格中的所有公式，并轻松地在表单的单元格之间复制和粘贴这些公式。 SpreadJS提供了 **showFormulas** 属性，该属性使用户可以在单元格中查看公式。 公式可见后，可以将其复制并粘贴到任何应用程序中。



#### 示例代码

本示例设置 **options.showFormulas** 属性。


```JavaScript
// 将showFormulas设置为true以使用户可以将公式复制到其他应用程序中
activeSheet.options.showFormulas = true;
```

 **局限性** 

- 选择公式单元格时，公式的参考单元格未突出显示。
- 数组公式无法正确复制到Excel或SpreadJS，因为输入数组公式需要ctrl + shift + enter键组合。
