# formulauser

用户可以通过以等号（=）开头在单元格中输入公式。 键入等号，然后键入公式，例如= sum（A1 + B1）。 您可以允许或禁止用户使用 **options.allowUserEditFormula** 属性输入公式。



#### 示例代码

本示例允许用户输入公式。


```JavaScript
window.onload = function()
{
  var spread =
  new GC.Spread.Sheets.Workbook(document.getElementById("ss"),{sheetCount:3});
  var sheet = spread.getActiveSheet();

  // 允许用户输入数学公式。
  spread.options.allowUserEditFormula = true;
  activeSheet.setValue(0, 0, 1000);
  activeSheet.setValue(1, 0, 200);
}
```
