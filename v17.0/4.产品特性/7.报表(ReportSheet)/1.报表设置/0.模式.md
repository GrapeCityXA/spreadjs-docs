# render-mode

报表表格类提供了不同的渲染模式，以提供用户特定的视图。使用报表表格类中的`renderMode`属性，您可以设置和获取这些渲染模式。
报表表格支持三种不同类型的渲染模式：

* **Design（设计）**：显示模板。
* **Preview（预览）**：显示数据录入预览。报表表格中仅在此模式下支持数据录入。更多信息，请参考报表表格数据录入支持。
* **PaginatedPreview（分页预览）**：显示报表表格的分页预览。

它允许通过自定义分页设置在页面之间导航。更多信息，请参考设置分页。
以下代码示例演示了如何在报表表格类中使用`renderMode`属性在设计模式、预览模式和分页预览模式之间切换：

```javascript
// Switch to Design mode.
reportSheet.renderMode('Design');

// Switch to Preview mode.
reportSheet.renderMode('Preview');

// Switch to PaginatedPreview mode.
reportSheet.renderMode('PaginatedPreview');
```

这些代码片段展示了如何在不同的渲染模式之间切换，以适应不同的报表查看和编辑需求。
使用`Design`模式可以编辑和设计模板表，`Preview`模式用于查看数据录入效果，而`PaginatedPreview`模式则提供了一个分页的报表预览，便于查看最终的打印或展示效果。
