# spill-mode

SpreadJS 允许你报表单元格扩展时设置覆盖单元格而不是插入。
要在模板表中设置覆盖模式，请在`setTemplateCell`方法中配置`spillMode`属性。
有两种不同类型的覆盖模式可用。

* Insert：这是默认模式。在呈现报告时，此模式会插入行和列。
* Overwrite：在呈现报告时，此模式不会插入新行和列。它保持报告的布局和大小与模板相同。

> type=warning
> 注意：
>
> * 使用Overwrite覆盖模式时，模板单元格类型必须设置为列表单元格
> * Overwrite覆盖模式仅对未合并的单元格有效
> * 您可以使用以下代码示例来设置单元格的覆盖模式

您可以使用以下代码示例来设置单元格的覆盖模式：

```javascript
const columns = ['Id', 'Name'];
columns.forEach((columnName, i) => {
       templateSheet.setValue(4, 3 + i, columnName.toUpperCase());
       templateSheet.setTemplateCell(5, 3 + i, {
              type: 'List',
              binding: `Products[${columnName}]`,
              // Set the Spill Mode : "Overwrite" || "Insert"
              spillMode: 'Overwrite'
       });
});
```
