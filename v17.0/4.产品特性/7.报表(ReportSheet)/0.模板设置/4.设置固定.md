# pin

在 SpreadJS 中，当单元格溢出后，报表布局可能被更改。
例如，在默认的扩展模式下，生成报告时可以插入新的行或列。在这种场景下，您可以使用`pin`选项来清除报表模板中溢出单元格的偏移量。
要做到这一点，您需要在`setTemplateCell`方法中为`pin`属性设置值。
`pin`属性有几个可用选项，例如None（无）、Row（行）、Column（列）和Both（两者）。默认的pin值是None。

> 注意事项：
>
> * `pin`选项只能在没有父单元格的静态单元格上工作，且静态单元格不能与溢出单元格树范围相交。
> * `pin`列要求整行中不能有溢出单元格。
> * `pin`行不要求整列中不能有溢出单元格。

您可以使用以下代码示例来设置`pin`选项。

```auto
// Clear column offset. 
templateSheet.setTemplateCell(0, 1, {
    type: 'Group',
    binding: 'Orders[shipCountry]',
});
templateSheet.setValue(1, 0, 2023);
templateSheet.setTemplateCell(0, 0, {
    pin: 'Row',
});

// Clear row offset. 
templateSheet.setTemplateCell(0, 1, {
    type: 'Group',
    binding: 'Orders[shipCountry]',
});
templateSheet.setValue(1, 0, 2023);
templateSheet.setTemplateCell(0, 0, {
    pin: 'Column',
});
```
