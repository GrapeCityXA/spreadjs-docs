# cell-context

在报表模板中，上下文（Context）是一个非常重要的概念。它默认为所有子单元格筛选数据，并且还会影响报表布局，因为所有子单元格都会随着上下文单元格重复。要在模板单元格中设置上下文，可以在`setTemplateCell`方法中使用`contextproperty`。
单个单元格可以有两个上下文：垂直上下文和水平上下文。然而，如果一个单元格同时具有垂直上下文和水平上下文，它将成为一个交叉单元格，并用于生成交叉报表。
根据上下文值，模板单元格的行为可能会有所不同。

| 上下文选项 | 值 | 结果 |
| ----- | --- | --- |
| 水平 | None | 表示模板单元格没有水平上下文。 |
|  | 单元格名称 | 使用该单元格作为水平上下文。 |
| 垂直 | None | 表示模板单元格没有垂直上下文。 |
|  | 单元格名称 | 使用该单元格作为垂直上下文。 |
| undefined | - | 使用左侧的垂直扩展单元格作为其垂直上下文，使用顶部的水平扩展单元格作为其水平上下文。 |

> 注意：如果单元格的水平和垂直上下文值都设置为`Default`，并且找不到垂直上下文的左侧或水平上下文的上方，则单元格使用树范围根节点作为其垂直或水平上下文。

在报表模板中设置上下文的步骤：

1. 在 DataManager 中定义表格源。
2. 在模板单元格中配置类型和绑定选项。
3. 在模板单元格中设置`contextproperty`值。

你可以使用以下代码示例来为单元格设置垂直和水平上下文。

```auto
// Set vertical context as a custom cell.
templateSheet.setTemplateCell(1, 1, {
    type: 'Group',
    binding: `Orders[customerId]`,
    context: {
        vertical: 'A1',
    },
});
// Set vertical context as none.
templateSheet.setTemplateCell(1, 1, {
    type: 'Group',
    binding: `Orders[customerId]`,
    context: {
        vertical: 'None',
    },
});

// Set horizontal context as a custom cell.
templateSheet.setTemplateCell(1, 1, {
    type: 'Group',
    binding: `Orders[customerId]`,
    spillDirection: 'Horizontal',
    context: {
        horizontal: 'A1',
    },
});
// Set horizontal context as a none.
templateSheet.setTemplateCell(1, 1, {
    type: 'Group',
    binding: `Orders[customerId]`,
    spillDirection: 'Horizontal',
    context: {
        horizontal: 'None',
    },
});

// Set both vertical and horizontal context for a cell.
templateSheet.setTemplateCell(1, 1, {
    type: 'Summary',
    aggregate: 'Sum',
    binding: `Sales[Sales]`,
    context: {
        vertical: 'A2',
        horizontal: 'B1',
    },
});
```
