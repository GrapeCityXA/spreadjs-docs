# add-picture

为了使报表更加信息丰富，您可以将图片作为形状添加到报表中。
报表中图片的位置可能会根据扩展单元格的变化而变化。
请注意，在报表表格中，图片不支持分组，但遵循特定的定位策略。
图片的位置由其起始行和起始列决定，并受到模板单元格的`pin`属性值的影响，与“静态”单元格的缩放策略一致。其大小保持不变，与报表中的图像大小相同。
以下是一些图片定位的示例。
示例 1：如果图片的顶部或左边缘与扩展单元格在同一行或列上，则图片将根据当前扩展单元格首次扩展的单元格进行定位。

要添加图片形状，您需要使用`addPictureShape`方法并指定参数，如名称、源、位置（x和y）以及大小（宽度和高度）。
以下代码示例展示了如何向报表模板添加图片形状：

```javascript
// Add picture shape to the TemplateSheet.
let picture = templateSheet.shapes.addPictureShape("picture", '/imageSrc.png', 0, 0, 200, 200); 

// Adjust the picture shape.
picture.startRow(0);
picture.endRow(6)
picture.startColumn(6);
picture.endColumn(6);
picture.startColumnOffset(60);
```
