# refresh-data-source

如果数据透视表的数据源在任何时间点发生更改，则需要刷新数据透视表以反映最新信息。SpreadJS 允许您使用数据透视表的updateSource方法刷新数据源并在数据透视表中反映最新数据。

下面的 gif 显示了如何使用“刷新数据源”按钮使用数据源中的任何更改来刷新数据透视表。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/refresh-datasource.gif)

以下示例代码显示了如何使用数据源中的任何更改刷新数据透视表。


```Javascript
function refreshDataSource() {
    myPivotTable.updateSource();
}
```
