# pivot-table-layout

SpreadJS 允许您选择数据透视表布局并使用PivotTableLayoutType枚举应用它。

- 紧凑型
- 区域分组型
- 表格型



## 紧凑型

紧凑形式是数据透视表的默认报告布局，它在单独的行中显示每个行标签，但在同一列中。顾名思义，这种布局通过减少数据透视表的宽度以紧凑的形式呈现数据。下图描绘了数据透视表的紧凑形式布局。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/compact.png)

下表解释了使用紧凑型布局时行标签、行字段和Subtotals的行为和定位：

|  **行标签**  |  **行字段**  |  **Subtotals**  |
|--- |--- |--- |
| 行字段标签始终位于内部字段标签上方。 | 所有行字段都在一个列中。 | Subtotals可以显示在每组的顶部或底部。 |
| 为了便于理解这些字段，每个行标签都从上面的字段中略微缩进。 |  | W当您设置Subtotals时，行字段将按照以下说明进行更改：<br /><br /> |
| 行标签不能重复。 |  | 对于列字段，Subtotals始终显示在底部。 |
| 您只能更改此报告布局中字段的缩进。 |  | 即使Subtotals在底部，行标签仍位于顶部。 |

以下示例代码设置数据透视表的紧凑型布局。


```Javascript
myPivotTable.layoutType(GC.Spread.Pivot.PivotTableLayoutType.compact);
```

您可以在紧凑型布局中使用rowLabelIndent选项自定义行字段的缩进级别。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/custom_compact.png)

以下示例代码以数据透视表的紧凑型设置缩进。


```Javascript
myPivotTable.options.rowLabelIndent = 12;
```



## 区域分组型

区域分组型布局在单独的列中显示每个行字段。当您想要将所有字段名称显示为标题标签并且不关心数据透视表的宽度时，此布局很有用。下图描绘了数据透视表的区域分组型布局。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/outline.png)

下表解释了使用区域分组型布局时行标签、行字段和Subtotals的行为和定位：

|  **行标签**  |  **行字段**  |  **Subtotals**  |
|--- |--- |--- |
| 每个行标签在单独的行中定义。 | 所有行字段都在一个单独的列中。 | Subtotals可以显示在每组的顶部或底部。 |
| 行字段标签始终位于内部字段标签上方。 | 每个行字段在列标题中显示其名称。 | 当您设置Subtotals时，行字段将按照以下说明进行更改：<br /><br /> |
| 行标签可以重复。 |  | 对于列字段，Subtotals始终显示在底部。 |

以下示例代码设置数据透视表的区域分组型布局。


```Javascript
myPivotTable.layoutType(GC.Spread.Pivot.PivotTableLayoutType.outline);
```



## 表格型

除了外部字段的行标签与相关内部字段的第一个标签在同一行上之外，表格型布局与大纲表单布局类似。因此，它减少了数据透视表中的行数。下图描述了数据透视表的表格布局。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/tabular.png)



下表解释了使用表格布局时行标签、行字段和Subtotals的行为和定位：

|  **行标签**  |  **行字段**  |  **Subtotals**  |
|--- |--- |--- |
| 外部字段的行标签与相关内部字段的第一个标签位于同一行。 | 所有行字段都在一个单独的列中。 | Subtotals只能显示在每组的底部。 |
| 行标签可以重复。 | 每个行字段在列标题中显示其名称。 | 当您在底部设置Subtotals时，会在底部添加一个新行。<br /><br /> |
|  |  | 对于列字段，Subtotals始终显示在底部。 |

以下示例代码设置数据透视表的表格布局。


```Javascript
myPivotTable.layoutType(GC.Spread.Pivot.PivotTableLayoutType.tabular);
```



## 其他设置



### 设置Subtotals和GrandTotals

您可以分别使用subtotalsPosition和grandTotalPosition选项设置Subtotals和GrandTotals的位置。subtotalsPosition 可以设置为 none、top 或 bottom 值（适用于上述布局），而 grandTotalPosition 可以设置为所有布局的所有值（例如 none、both、col 或 row）。默认情况下，subtotalsPosition 选项设置为“bottom”，而grandTotalPosition 选项设置为“both”。

以下示例代码设置Subtotals和GrandTotals在数据透视表中的位置。


```Javascript
// 将 SubtotalsPosition 设置为 none
myPivotTable.options.subtotalsPosition = GC.Spread.Pivot.SubtotalsPosition.none;
        
// 将grandTotalPosition 设置为col
myPivotTable.options.grandTotalPosition = GC.Spread.Pivot.GrandTotalPosition.col;
```



### 设置重复标签项

对于区域分组型和表格型布局，您可以使用fillDownLabels选项在外行字段中启用重复项标签 。

以下示例代码将表格型布局中的重复标签项设置为 true。


```Javascript
//  设置重复标签项
myPivotTable.options.fillDownLabels = true;
```

此选项不能应用于 Compact 表单。
> **注意:** 此选项不能应用于 Compact 表单。 


### 设置空白行

您可以使用有助于轻松理解数据的insertBlankLineAfterEachItem选项在每个项目后添加一个空白行 。

以下示例代码在数据透视表中的每个项目之后设置空白行。


```Javascript
// 设置空行
myPivotTable.options.insertBlankLineAfterEachItem = true;
```
