# pivot-table-print

SpreadJS 允许您像打印电子表格一样打印数据透视表。当您需要自定义数据透视表的打印副本以保存记录时，这尤其有用。您可以设置不同的属性，例如printDrill、itemPrintTitles 和fieldPrintTitles 来打印具有不同效果的数据透视表。

该 printDrill选项可用于显示打印页面上展开或折叠按钮。下图描述了使用 printDrill 选项打印数据透视表的示例。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/printdrill.png)

请参考以下示例代码来设置 printDrill 选项。


```Javascript
//将 printDrill 选项设置为 True
myPivotTable.options.printDrill = true;
```

您可以使用 itemPrintTitles选项，以防数据透视表数据溢出下一页并且需要在下一页上重复行标签。下图描述了使用 itemPrintTitles 选项进行打印的示例。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/itemprinttitle.png)

请参考以下示例代码来设置 itemPrintTitles 选项。


```Javascript
//将 itemPrintTitles 选项设置为 True
myPivotTable.options.itemPrintTitles = true;
```


> **注意:** 此选项在以下情况下不起作用：<br /><br /> 
您可以使用 fieldPrintTitles选项来设置每页上的打印标题。当有大量行和列并且您想在每个页面上显示标题时，这很有用。下图描述了使用 fieldPrintTitles 选项进行打印的示例。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/fieldprinttitles.png)

请参考以下示例代码来设置 fieldPrintTitles 选项。


```Javascript
//将 fieldPrintTitles 选项设置为 True
myPivotTable.options.fieldPrintTitles = true;
```

当单个spreadsheet有多个数据透视表时，此选项不起作用。
> **注意:** 当单个spreadsheet有多个数据透视表时，此选项不起作用。
