# slicerdesign

您可以使用SpreadJS设计器为表创建切片器。

使用以下步骤添加切片器。

- 添加表格数据，并使用 **插入** 标签下的 **表格** 选项插入表格。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/designersliceraddtable.png)
- 选择 **工具** 部分下的 **插入切片器** 选项。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/designerslicertab.png)
- 显示 **插入切片器** 对话框。 选择一个或多个要为其创建切片器的列。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/designerslicerinsert.png)
- 使用 **选项** 标签设置标题，高度，宽度，列数和样式。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/designersliceroptions.png)
- 使用 **切片器** 部分中的 **切片器设置** 对话框为切片器设置其他选项，例如是否显示标题等。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/designerslicersettings.png)

您还可以通过右键单击切片器来显示切片器的上下文菜单。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/designerslicercontext.png)

菜单中的 **大小和属性** 选项显示以下 **格式切片器** 对话框。 该对话框包含 **位置和布局** ， **大小** 和 **属性** 标签。

 **格式切片器** 对话框允许您设置切片器的水平和垂直位置，列数，是否禁用调整大小和移动切片器，基于原始大小的缩放宽度和高度，是否 移动并调整其大小，依此类推。
