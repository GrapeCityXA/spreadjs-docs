# sparkboxplot

您可以使用 **BoxPlotSparkline** 公式和单元格值创建箱形图迷你图。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/sparkboxplot.png)

BoxPlotSparkline函数有以下参数:

|  **选项**  |  **描述**  |
|--- |--- |
| points | 表示所描述的数据区域。例如： "A1:A4"。 |
| boxPlotClass | Q1–>25% percentile, Q3–>75% percentile, IQR-->Q3-Q1. |
|  | 5ns: 晶须以最大值和最小值，中位数结尾，没有异常值。 |
|  | 7ns: 晶须的结束点为2％和98％，阴影标记为9％和91％，离群值超过2％和98％。 |
|  | tukey: 晶须以一个值（Q1和Q1之间的最小点-1.5 * IQR，如果存在或使用最小点）和一个值（Q3和Q3之间的最大点+ 1.5 * IQR，一个点）结束 点是否存在或使用最大值），则超出Q1-1.5 * IQR和Q3 + 1.5 * IQR的异常值，超出Q1-3-IQR和Q3 + 3 * IQR的极端值。 |
|  | bowley: 晶须在最小和最大处结束，阴影线在10％和90％百分数处，没有异常值。 |
|  | sigma3: 晶须在 (average - 2 * StDev > scaleStart ? average - 2 * StDev :  minimum) 以及 (average + 2 * StDev < scaleEnd ? average = 2 * StDev : maximum), 箱的平均值为+/- stdev，离群值超出平均值-2 * StDev和平均值+ 2 * StDev，而极端离群值超出平均值-3 * StDev和平均值+ 3 * StDev。 |
| showAverage | 代表是否显示平均值的布尔值。 此设置是可选的。 默认值为FALSE。 |
| scaleStart | 代表迷你图最小边界的数字或参考，例如1或“ A6”。 此设置是可选的。 默认值为所有值中的最小值。 |
| scaleEnd | 代表迷你图最大边界的数字或参考，例如8或“ A7”。 此设置是可选的。 默认值为所有值中的最大值。 |
| acceptableStart | 代表可接受行开头的数字或参考，例如3或“ A8”。 此设置是可选的。 默认值为“none”。 |
| acceptableEnd | 数字或参考代表可接受行的结尾，例如5或“ A9”。 此设置是可选的。 默认值为“none”。 |
| colorScheme | 一个字符串，代表迷你图框的颜色。 此设置是可选的。 默认值为“＃D2D2D2”。 |
| style | 代表迷你图样式的数字或参考。 此设置是可选的。 默认值为0（古典）。 样式可以为0或1。<br /><br />0: 晶须是一条线，离群值是一个圆。<br /><br />1: 晶须是一个矩形，离群值是一条线。<br /><br /> |
| vertical | 表示是否垂直显示迷你图的布尔值。 此设置是可选的。 默认值为FALSE。 |

下面这张图片展示了5ns类型的箱线函数迷你图

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/sparkbp.png)

你可以通过箱线函数创建一个箱线函数迷你图。例如：


```text
=BOXPLOTSPARKLINE(points, boxPlotClass, showAverage, scaleStart, scaleEnd, acceptableStart, acceptableEnd, colorScheme, style, vertical)
```





#### 示例代码

下面代码展示了如何创建箱线函数迷你图


```JavaScript
activeSheet.setValue(0, 2, 60);

activeSheet.setValue(0, 4, 54);
activeSheet.setValue(0, 5, 0);
activeSheet.setValue(0, 6, 99);
activeSheet.setValue(0, 7, 86);
activeSheet.setValue(0, 8, 98);
activeSheet.setValue(0, 9, 75);
activeSheet.setValue(0, 10, 76);
activeSheet.setValue(0, 11, 80);
activeSheet.setValue(0, 12, 85);
activeSheet.setValue(0, 13, 86);
activeSheet.setValue(0, 14, 65);
activeSheet.setValue(0, 15, 88);
activeSheet.getRange(0, -1, 1, -1, GC.Spread.Sheets.SheetArea.viewport).height(90);
activeSheet.setFormula(0,1,'=BOXPLOTSPARKLINE(C1:P1,"5ns",TRUE,0,100,-1,100,"red",0,FALSE)');
```
