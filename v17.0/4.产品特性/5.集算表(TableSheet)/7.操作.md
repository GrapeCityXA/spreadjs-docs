# tablesheet-operations

TableSheet 提供丰富的操作来交互和排列 TableSheet 视图，以便轻松导航或分析当前数据。请参阅以下主题以了解更多信息：

| 特性 | 描述 |
|--- |--- |
| [锚定/取消锚定](gcdocsite__documentlink?toc-item-id=0b681e51-8c90-43c2-bb49-bc2e7d71b768) | 将行或列锚定到当前表格视图的顶部或左侧。 |
| [排序和筛选](gcdocsite__documentlink?toc-item-id=2276aff6-b5d6-47ec-81f1-6cafe2386676) | 按代码或通过筛选对话框排序和筛选列。<br /><br /> |
| [行动作](gcdocsite__documentlink?toc-item-id=e9df7972-64f6-4063-a91d-fbd41322f6ac) | 显示数据行状态或执行操作。<br /><br /> |
| [分组](gcdocsite__documentlink?toc-item-id=91cdc22b-1a69-43e1-935b-b1ddee4cfe37) | 按指定字段对数据源进行分组。<br /><br /> |
