# firstvalue

该函数返回窗口帧中第一行的参数值。它不需要使用ORDERBY子句。

## 语法

`FIRSTVALUE(value_function)`

## 参数
该函数提供以下参数。

| **参数** | **描述** |
| -------- | ----------- |
| *value\_function* | [必选] 字段名或公式。 |

## 示例

```
// WINDOW(FIRSTVALUE([@sold]), PARTITIONBY([city]),ORDERBY([month]))

city    |  month   |   sold   | first_value
----------------------------------------------
Paris        1          500       500
Paris        2          300       500
Paris        3          400       500
Rome         2          200       200
Rome         3          300       200
Rome         4          500       200
```
