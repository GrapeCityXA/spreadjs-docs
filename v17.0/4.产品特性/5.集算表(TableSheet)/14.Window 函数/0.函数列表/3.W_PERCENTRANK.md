# wpercentrank

该函数计算一个行在行分区内的相对排名所占的百分比。为了计算百分比，使用行的排名和总行数进行计算，公式为(rank-1) / (rows-1)，百分比的范围为[0,1]。
为了对行进行排序，该函数需要使用ORDERBY子句。相同值的行将根据ORDERBY字段的组合值进行标识。如果不使用ORDERBY，则所有行都被视为相同并返回0。它不接受窗口帧定义，例如FRAMEROWS和FRAMERANGE。默认情况下，它包括NULL值并将其视为最小可能值。

## 语法

`W_PERCENTRANK()`

## 示例

```
//WINDOW(W_PERCENTRANK(), ORDERBY([sold]))

city     |    sold    |  percent_rank  |  rank-1
--------------------------------------------------------------
Paris         100          0               0
Berlin        150          0.25            1
Moscow        200          0.5             2             
Rome          200          0.5             2         
London        300          1               4

// WINDOW(W_PERCENTRANK(), ORDERBY([sold], [city]))

city    |    sold   |    percent_rank  |  rank-1
--------------------------------------------------------
Paris        100           0               0
Berlin       150           0.25            1
Moscow       200           0.5             2
Rome         200           0.75            3           
London       300           1               4
```
