# data-operations

TableSheet提供了行操作的形式与数据交互的能力，如创建、读取、更新和删除行操作。通过这些操作，您可以方便地将编辑的行数据与数据库同步。

以下类方法可用作TableSheet行操作：

| 方法 | 描述 |
|--- |--- |
| [addRow](gcdocsite__documentlink?toc-item-id=8dc0b7a4-ace7-4c61-b4a7-00790d5584fe#addRow) | TableSheet新增行 |
| [removeRow](gcdocsite__documentlink?toc-item-id=8dc0b7a4-ace7-4c61-b4a7-00790d5584fe#removeRow) | TableSheet删除特定行 |
| [saveRow](gcdocsite__documentlink?toc-item-id=8dc0b7a4-ace7-4c61-b4a7-00790d5584fe#saveRow) | 将TableSheet中指定行的更改保存到数据管理器，包括更新的行或插入的行 |
| [resetRow](gcdocsite__documentlink?toc-item-id=8dc0b7a4-ace7-4c61-b4a7-00790d5584fe#resetRow) | 重置表TableSheet中指定行的更改。 |

### 不同的异步模式

TableSheet与数据管理器交互以更改表数据。如果要将更改的数据与远程数据库同步，还应启用自动更新或批量更新。

使用[addTable](gcdocsite__documentlink?toc-item-id=d168d582-7001-4e98-a184-2aafa89215e1#addTable)方法时，可以设置自动同步模式或批处理模式，这些特性及用途如下所示。

-  **autoSync** 模式自动将更改同步到远程源，该模式主要适用于低频数据操作场景。
```JavaScript
var myTable = dataManager.addTable("myTable", {
    // 其它设置
    autoSync: true // 启用自动同步模式
});
```


-  **batch** 模式通过手动调用 **submitChanges** 方法将更改同步到远程数据源，此模式主要适用于数据经常被操作的场景。
```JavaScript
var myTable = dataManager.addTable("myTable", {
    // 其它设置
    batch: true, // enable the batch mode
    remote: {
        //其它设置
        batch: {
            url: BatchApiUrl // 指定URL
        }
    }
});

// 保存所有修改
tablesheet.submitChanges();
// 放弃所有修改
tablesheet.cancelChanges();
```





### 自定义远程请求

TableSheet支持自定义函数来配置远程请求选项。默认情况下，TableSheet通过对象配置远程请求，因此如果您想自己处理请求，请用函数替换对象，数据更改将传递给函数。

使用自定义函数时，自动同步和批处理模式具有以下参数：

- 自动同步（autoSync）: create、update、delete函数的参数是数据项，返回值是远程包装该数据项的Promise，read函数返回的是所有封装数据的Promise。
- 批处理（batch）: 批处理函数的参数包含发生变化的数据，函数的返回值是一个Promise，它封装了来自远程的成功信息。

### 错误处理

当服务器返回连接错误（例如HTTP 404、HTTP 500）和服务器数据库错误（例如duplicated primary key, update failed）时，TableSheet允许用户通过回调来处理或显示错误。

行标题会显示一个红色报警图标，当用户将鼠标悬停在该图标上时，会显示错误提示。
