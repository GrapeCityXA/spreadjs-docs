# tablesheet-interactive-behavior

TableSheet 具有丰富的交互行为，有助于让用户方便的访问和使用表格。



### 放大和缩小

TableSheet 支持使用 Ctrl 键 + 鼠标滚轮进行放大和缩小

使用 Ctrl + 鼠标滚轮向上放大，使用 Ctrl + 鼠标滚轮向下缩小。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-zoom.gif)



### 调整列大小

TableSheet 支持通过拖动列标题单元格的右边缘来调整列大小。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-resizecol.gif)

您可以通过双击列标题单元格的右边缘来自动调整列宽。也可以设置[AutoFitType](gcdocsite__documentlink?toc-item-id=e98720ce-9275-4b95-a6d3-aa6dcab99de1)枚举选项“ cellWithHeader”。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-resizecol-autofit.gif)

如果您想追溯更改相邻列的宽度以及调整选定列的大小，可以将 **columnResizeMode** 设置为“split”以更改默认行为。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-resizecol-splitmode.gif)

以下代码示例显示如何将列调整大小设置为自动适合模式以及将调整大小模式更改为split。


```JavaScript
// 将 autoFitType 设置为 cellWithHeader
spread.options.autoFitType = GC.Spread.Sheets.AutoFitType.cellWithHeader;
// 将 ResizeMode 设置为 split
spread.options.columnResizeMode = GC.Spread.Sheets.ResizeMode.split;
```

您还可以使用[ViewOptions](/spreadjs/api/GC.Data.ViewOptions.html)类的 **defaultColumnWidth** 属性为 TableSheet 视图设置默认列宽。默认情况下，列宽为 60。


```JavaScript
var view = customerTable.addView("myView", [
    { value: "customerKey", caption: "Customer Key" },
    { value: "customer", caption: "Customer" },
    { value: "billToCustomer", width: 200, caption: "Bill To Customer" },
    { value: "category", width: 120, caption: "Category" },
    { value: "buyingGroup", width: 180, caption: "Buying Group" },
    { value: "primaryContact", width: 170, caption: "Primary Contact" },
    { value: "validFrom", width: 150, caption: "Valid From" },
], false, {
    // 设置默认列宽
    defaultColumnWidth: 100
});
```



### 剪切、复制和粘贴

TableSheet 支持使用快捷键或通过上下文菜单剪切、复制和粘贴单元格、行或列。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-cutcopypaste-shortcutkeys.gif)

剪贴板操作支持以下快捷键：

| 操作 | Windows | Mac |
|--- |--- |--- |
| Cut | Ctrl + X | Command + X |
| Copy | Ctrl + C | Command + C |
| Paste | Ctrl + V | Command + V |

右键单击一个选中的单元格、行或列选择将显示包含剪贴板操作的上下文菜单。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-cutcopypaste-contextmenu.gif)

如果要在新行中粘贴多行，则应将 **allowExtendPasteRange** 选项设置为 true。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-cutcopypaste-extendpasterange.gif)

以下代码示例显示了如何在 SpreadJS 中启用 allowExtendPasteRange 选项。


```JavaScript
// 启用“allowExtendPaster”选项，可在新行中粘贴多行
spread.options.allowExtendPasteRange = true;
```



### 拖拽操作

TableSheet 支持各种拖拽操作，如拖拽填充、拖放和拖拽复制。

-  **拖拽填充** 通过单击所选区域的右下角，然后向下移动鼠标来完成。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-dragfill.gif)
直接拖动时，该单元格被复制，或者在按下CTRL键拖动时填充序列。
拖动填充结果可以通过弹出菜单更改为“复制单元格”或“填充系列”。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-dragfill-contextmenu.png)
-  **拖放** 通过拖动所选区域的选择边框并在目标单元格释放鼠标来完成。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-dragdrop.gif)
-  **拖拽复制** 通过拖动所选区域的边框在按下CTRL键并在目标单元格释放鼠标来完成。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-dragcopy.gif)



### 快捷键

TableSheet支持各种快捷键，包括tablesheet的一些特定操作，例如“保存所有插入和更新的行”。

下表列出了 TableSheet 支持的所有快捷键。

| 操作 | 快捷键 |
|--- |--- |
|  **通用**  |
| 复制 | Ctrl+C |
| 剪切 | Ctrl+X |
| 粘贴 | Ctrl+V |
| 进入编辑 | F2 |
| 直接输入 | Char |
| 退出编辑 | Esc |
| 删除 | Del |
| 删除并输入编辑 | BackSpace |
| 输入提交，向下移动 | Enter |
| 输入提交，向上移动 | Shift + Enter |
| 下一行输入 | Alt+Enter, Ctrl+Enter |
| 保存所有插入和更新的行 | Ctrl + Shift + S |
|  **导航**  |
| 向上移动 | Up key |
| 向下移动 | Down key |
| 向左移动 | Left key |
| 向右移 | Right key |
| 向下移动 | Enter |
| 向右移动 | Tab |
| 向左移动 | Shift + Tab |
| 移动到顶部/底部/左侧/右侧的第一个单元格 | Ctrl + Arrow |
| 移动到下一页 | PageDown |
| 移动到上一页 | PageUp |
|  **选择**  |
| 扩展鼠标单击选择 | Shift + Mouse click |
| 扩展单元格选择 | Shift + Arrow |
