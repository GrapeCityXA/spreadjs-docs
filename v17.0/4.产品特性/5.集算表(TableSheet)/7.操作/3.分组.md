# tablesheet-grouping

TableSheet 支持按指定字段对数据源进行分组，即自动将相同的单元格内容合并到一个单元格中。 分组列放置在基本列的最左侧，它们由以下类型的列组成：

- 基本列: 包含原始列值。
- 汇总列：包含由用户定义的公式计算得出的汇总结果。
- 切片列：包含聚合结果的切片。

下图显示了TableSheet分组中不同类型的列。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-grouping.png)

您可以使用 TableSheet类的[groupBy](gcdocsite__documentlink?toc-item-id=8dc0b7a4-ace7-4c61-b4a7-00790d5584fe#groupBy)and[removeGroupBy](gcdocsite__documentlink?toc-item-id=8dc0b7a4-ace7-4c61-b4a7-00790d5584fe#removeGroupBy)方法来添加和删除分组。以下代码示例显示如何添加分组列，包括汇总列和切片器列。


```JavaScript
function grouping() {
    //按照单个字段分组，包含汇总字段和切片字段
    sheet.groupBy([
        {
            caption: "Selling Package", field: "sellingPackage", width: 150, style: { backColor: "#F9CA9A" },
            summaryFields: [
                {
                    caption: "SUM(Unit Price)",
                    formula: "=SUM([unitPrice])",
                    slice: { field: "=YEAR([@validFrom])", width: 120, style: { backColor: "#FCE3CA", formatter: "#,##0.00" } },
                    width: 150,
                    style: { backColor: "#FAD7B2", formatter: "#,##0.00" }
                }
            ]
        }
    ]);
}
```



### 分组

TableSheet分组可以提供用于展开或折叠组条目及其相关基本列内容的。

默认情况下，组与视窗一起放置在列标题中。您还可以将其配置为显示在行标题区域，或同时显示在行标题和列标题中，或者您也可以完全隐藏组。[GroupOutlinePosition](gcdocsite__documentlink?toc-item-id=fc52a1cc-2e9f-4249-8e59-6cada4e8027f)枚举选项可用于设置分组的位置或隐藏它。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-grouping-outlineposition.gif)

以下代码示例显示了如何在行标题中设置组或将其隐藏，如上面的 GIF 所示。


```JavaScript
function grpOutlinePosition() {
    // 将 GroupOutlinePosition 设置为 rowHeader
    sheet.groupOutlinePosition(GC.Spread.Sheets.TableSheet.GroupOutlinePosition.rowHeader);
}

function grpOutlineHide() {
    //  将 GroupOutlinePostion 设置为隐藏
    sheet.groupOutlinePosition(GC.Spread.Sheets.TableSheet.GroupOutlinePosition.none);
}
```

您还可以通过将[detailColumnsVisible](gcdocsite__documentlink?toc-item-id=8dc0b7a4-ace7-4c61-b4a7-00790d5584fe#detailColumnsVisible)方法的boolean 参数设置为 false 来完全隐藏分组后的基础列。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-grouping-hidedetailcols.gif)


```JavaScript
function detailColumnVisible() {
    // 隐藏明细列
    sheet.detailColumnsVisible(false);
}
```



### 多级分组

TableSheet 支持多级分组，可以在 groupBy 方法中定义多个字段来创建多级分组。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-grouping-multiple.png)

下面的代码示例展示了如何在 TableSheet 视图中设置多级分组。


```JavaScript
function grpByMultipleFields() {
    // 首先按“salesPackage”字段分组，然后使用 DATEPART 公式按可用年份的季度进行分组
    sheet.groupBy([
        { caption: "Selling Package", field: "sellingPackage", width: 150, style: { backColor: "#FAD7B2" } },
        { caption: "Year Quarter", field: `=DATEPART([@validFrom],"yyyyQQQ")`, width: 150, style: { backColor: "#FCE3CA" } }
    ]);
}
```



#### 多级分组的行为

在 TableSheet 中应用多级分组时，默认布局会占用更多空间。多级分组的以下行为可以帮助以更好的方式显示分组结果。

- 折叠分组时，明细列的单元格将显示为空。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-grouping-multiplecollapse1.png)
- 当父分组折叠时，子分组的单元格也将显示为空。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-grouping-multiplecollapse2.png)

您也可以使用[expandGroup](gcdocsite__documentlink?toc-item-id=8dc0b7a4-ace7-4c61-b4a7-00790d5584fe#expandGroup)和[expandGroupItem](gcdocsite__documentlink?toc-item-id=8dc0b7a4-ace7-4c61-b4a7-00790d5584fe#expandGroupItem)方法设置多个分组的展开或折叠状态。



### 在分组中排序

TableSheet 支持在组列和基本列之间进行排序。

下图显示排序结果基于分组结果，其中“Selling Package”组列按升序排列，而“Year Quarter”组列和“Stock Item Key”基础列按降序排列。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-grouping-sort.png)

在 TableSheet 分组中使用排序时会观察到以下行为。

- 排序状态在分组列和其源列之间共享。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-grouping-sortsame.png)
- 在分组级别只能对一列进行排序
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-grouping-sortsingle.gif)
- 应用 groupBy之前和应用removeGroupBy方法之后的最后排序状态会被保留。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-grouping-sortstatus.gif)
