# tablesheet-pin-unpin

您可以固定 TableSheet 中的行和列，以便在滚动时将它们显示在当前视图的顶部或左侧。，这个称之为锚定

通过右键单击特定行或列标题并选择“Pin/Unpin”选项来执行此操作。如下图所示，在锚定的行和列之后显示单独的行。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-pinned.png)

同样，您可以通过选择“Pin/Unpin”选项取消固定行或列。TableSheet 视图中最多只能固定 10 行或列。


> **注意:** 筛选和排序功能不会影响固定的行和列。<br /><br />不支持撤消和重做操作。<br /><br /> 
您可以通过使用[TableSheet.togglePinnedRows](gcdocsite__documentlink?toc-item-id=8dc0b7a4-ace7-4c61-b4a7-00790d5584fe#togglePinnedRows)或[TableSheet.togglePinnedColumns](gcdocsite__documentlink?toc-item-id=8dc0b7a4-ace7-4c61-b4a7-00790d5584fe#togglePinnedColumns)方法切换行或列的固定状态，如以下代码示例所示。


```JavaScript
// 将视图绑定到tablesheet
myView.fetch().then(function () {
    sheet.setDataView(myView);
    sheet.togglePinnedRows([4,5]);  // 锚定行
    sheet.togglePinnedColumns([1,3]); // 锚定列
});
```
