# select

使用SpreadJS，您可以在表单中选择单元格，行，列或多个范围。 通常，在选择大量单元格或多个单元格范围时，如果您错误地选择了一些单元格并想要取消选择它，那么取消选择整个选择然后再次重新选择的整个过程将变得非常麻烦。 SpreadJS不仅可以节省大量时间，还可以通过使用户从所选范围内取消选择特定单元格并在处理表单时根据其要求自定义选择内容来避免冗余。

为了开始在表单中选择一个区域，只需用鼠标左键单击并拖动以选择一个单元格，列或行块。 您还可以使用鼠标单击和Ctrl键选择多个单元格区域。

要取消选择某个选项，只需按键盘上的ctrl键或cmd键，然后使用向左，向上，向右或向下箭头键取消选择所需的单元格。 为了在表单中启用取消选择行为，必须将 **allowUserDeselect** 属性设置为boolean“ true”。默认情况下，此选项设置为true。但是，如果用户不希望取消选择行为 使用SpreadJS，他们可以将此选项设置为“ false”。

导航键在[键盘导航快捷键](gcdocsite__documentlink?toc-item-id=25c4e746-96e9-4e30-ba1f-f839c4ab515c)。您可以使用 **selectionUnit** 方法来指定选择单位的类型（单元格，列或行）。 您可以指定选择范围 (单个单元格，区域或多区域）使用 **selectionPolicy** 方法。 您可以使用 **options.selectionBackColor** 和 **options.selectionBorderColor** 属性设置选择颜色和边框。 您可以使用标准颜色和主题颜色。



#### 示例代码

本示例选择一个单元格区域。


```JavaScript
activeSheet.addSelection(4, 0, 2, 2);
//activeSheet.clearSelection();
var sels = activeSheet.getSelections();
alert(sels.length);
```



#### 示例代码

本示例允许选择单行或块行。


```JavaScript
activeSheet.selectionUnit(GC.Spread.Sheets.SelectionUnit.Row);
activeSheet.selectionPolicy(GC.Spread.Sheets.SelectionPolicy.Range);
```



#### 示例代码

本示例为所选区域和边框设置颜色。


```JavaScript
activeSheet.options.selectionBackColor = "Accent 6";
activeSheet.options.selectionBorderColor = "Accent 1";
```



#### 示例代码

本示例说明了如何在表单中取消选择。


```JavaScript
var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
var sheet = spread.getActiveSheet();

// 对于“ Excel之类的精确选择”，用户需要将allowUserDeselect传播选项设置为true。 默认情况下，此选项为true。 如果您不希望“像Precision Selection这样的Excel，则需要将此选项设置为false”
         
spread.options.allowUserDeselect = true;
```
