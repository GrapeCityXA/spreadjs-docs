# corner-fold

**SpreadJS** 支持在单元格的拐角处设置折角样式（ConerFold）。在突出显示单元格状态（例如,当您要显示单元格的无效状态）时，折角功能非常有用。
IDecoration 接口提供了折角选项，用于设置角折大小、位置和颜色。
折角选项继承自 ICornerFold 接口，该接口提供大小、位置和颜色等参数配置。
下面的快照显示了 B6 和 B8 单元格朝向左上角位置的橙色折叠样式。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/e89163df-9462-4186-9f56-3bcf7b915acb/image.b7c0de.png)
折角样式（ConerFold）选项的默认值如下所示：

| 大小 | 位置 | 颜色 |
| --- | --- | --- |
| 6 | GC.Spread.Sheets.CornerPosition.leftTop | #FF3D00 |

以下代码实现说明如何使用 ICornerFold 接口和 setStyle 方法设置折角样式

```javascript
var style = new GC.Spread.Sheets.Style();
style.decoration = {
    cornerFold: {
        size: 10,
        position: GC.Spread.Sheets.CornerPosition.leftTop,
        color: "orange"
    }
}
sheet.setStyle(5, 1, style);
```
