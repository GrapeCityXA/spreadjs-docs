# autofit

SpreadJS允许用户使用自动调整功能自动调整表单中行和列的大小。 此功能会自动调整列的宽度和行的高度，以确保数据值完全适合单元格内。

用户在处理表单时可以执行以下两种自动调整操作。

- 自动调整列宽-此选项用于调整列宽，以容纳单元格中的大数据值，如下所示。
或者，您也可以双击列标题的右边缘以调整列的大小以适合列中最长的文本字符串。
- 自动调整行高-当您要在单元格中存储多行文本或大字体的文本时，可以使用此选项。 自动调整行高以适合行中的数据值。
或者，您也可以双击行标题的底部边缘以调整行的大小。

AutoFit适用于隐藏的列和行，筛选的列和行，分组的列和行以及视口中未显示的选定列和行。 如果列或行的可调整大小的方法为false，则不应用自动调整。

您可以使用 **autoFitColumn** 方法, **autoFitRow** 方法调整宽高, 以及 **Commands** 类. 在将AutoFit与 **options.autoFitType** 属性一起使用时，还可以包含标题文本。 您也可以选择多个列或行或整个表单，然后双击一个选定的列或行以将自动调整应用于所有选定的列或行。

您可以使用Alt + Enter输入多行，如果该方法对单元格为true。
> 您可以使用Alt + Enter输入多行，如果 **wordWrap** 该方法对单元格为true。 


#### 示例代码

本示例使列的宽度适合文本。


```JavaScript
activeSheet.setValue(0, 1, "testing");
activeSheet.autoFitColumn(1);
```



#### 示例代码

本示例设置行的高度以显示文本。


```JavaScript
activeSheet.setValue(0, 1, "testing\r\nmultiple\r\nlines");
activeSheet.getCell(0,1).wordWrap(true);
activeSheet.autoFitRow(0);
```
