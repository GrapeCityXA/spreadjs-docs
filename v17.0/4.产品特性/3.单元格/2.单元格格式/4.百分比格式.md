# percentage-format-in-cells

用户可以轻松高效地使用表单中的数字和百分比。 SpreadJS提供了对将百分比格式应用于其的单元格自动在输入末尾（数字0-9）附加百分比'％'符号的支持。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/percent.gif)

SpreadJS对不同的输入应用了不同的功能，同时附加了如下所示的百分比符号：

 **情况1：输入数字** 

如果在百分比格式的单元格中输入数字，则SpreadJS会在其中添加％符号。 例如，在单元格中输入值6会将其格式化为6.00％。

 **情况2：输入字符** 

如果在百分比格式的单元格中输入字符，符号或字母，则SpreadJS不会在其后附加％符号。

 **情况3：在数字后添加字符** 

如果您在百分比格式的单元格中的数字（例如“ 6”）之后添加字母（例如“ h”），则SpreadJS仍将附加百分比符号（格式为6h％）。

 **情况4：在单元格编辑模式下删除百分比符号** 

如果您在单元格编辑模式下输入数字并从该数字中删除％符号并退出该单元格，则该数字将再次转换为百分比格式。

 **情况5：在未格式化的单元格中插入带％符号的数字** 

如果您未在单元格中设置百分比格式，而是直接键入带有“％”符号的数字（例如“ 11％”），则该百分比格式将自动设置。

 **情况6：双击一个单元格并插入数字** 

如果双击百分比格式的单元格并在单元格编辑模式下插入数字，则该数字将首先转换为百分比格式，并在其中添加％符号。 也就是说，如果我们双击该单元格并添加45，则其格式为4500.00％。

 **情况7：用数字添加+或-** 

您可以在百分比格式的单元格中的数字之前添加+或–符号。 例如，+ 2变为2.00％，-5变为-5.00％。



#### 示例代码

本示例描述了在表单单元格中使用百分比格式。


```JavaScript
// 对于区域A1：F10，设置格式
for (var i = 0; i < 10; i++)
for (var j = 0; j < 6; j++)
    activeSheet.getCell(i, j).formatter("0.00%");
```
