# SettingRichTextCell

SpreadJS通过允许用户设置表单中行标题，列标题和视口区域中显示的文本的样式，支持单元格中的富文本格式。 富文本格式使用户可以增强表单的美观外观，并以有效的方式处理数据。

使用富文本功能，您可以格式化具有不同样式的文本，包括下标，上标，文本修饰，文本对齐，垂直方向上的文本，自动换行和文本缩进以及一些内置功能，例如JSON序列化和反序列化，excel I / O，缩小以适合，自动适合等

将富文本格式应用于单元格后，它将把单元格值转换为普通值。 默认情况下，当您在单元格中输入文本信息时，表单的视口区域中的字母将显示为没有任何格式样式，如下面的单元格A1中所示。 但是，在单元格中应用富文本格式时，将显示字母，如下面共享的截图中的单元格A3所示。

#### 示例代码

此示例代码在表单的视口区域的列标题单元格，行标题单元格和单元格中设置富文本。


```JavaScript
var SpreadJS =
{
            richText: [{
                style: {
                    font: "bold 36px Calibri",
                    foreColor: "rgb(78,133,242)"
                },
                text: "S"
            },
            {
                style: {
                    font: "bold 36px Calibri",
                    foreColor: "rgb(228,65,52)"
                },
                text: "p"
            },
            {
                style: {
                    font: "bold 36px Calibri",
                    foreColor: "rgb(247,188,32)"
                },
                text: "r"
            },
            {
                style: {
                    font: "bold 36px Calibri",
                    foreColor: "rgb(78,133,242)"
                },
                text: "e"
            },
            {
                style: {
                    font: "bold 36px Calibri",
                    foreColor: "rgb(65,168,87)"
                },
                text: "a"
            },
            {
                style: {
                    font: "bold 36px Calibri",
                    foreColor: "rgb(228,65,54)"
                },
                text: "d"
            }
            ]
};
var sJS =
{
            richText: [
                {
                    style: {
                        font: "bold 24px Calibri",
                        foreColor: "rgb(78,133,242)"
                    },
                    text: "S"
                },
                {
                    style: {
                        font: "bold 24px Calibri",
                        foreColor: "rgb(65,168,87)"
                    },
                    text: "p"
                },
                {
                    style: {
                        font: "bold 24px Calibri",
                        foreColor: "rgb(247,188,32)"
                    },
                    text: "r"
                },
                {
                    style: {
                        font: "bold 24px Calibri",
                        foreColor: "rgb(78,133,242)"
                    },
                    text: "e"
                },
                {
                    style: {
                        font: "bold 24px Calibri",
                        foreColor: "rgb(65,168,87)"
                    },
                    text: "a"
                },
                {
                    style: {
                        font: "bold 24px Calibri",
                        foreColor: "rgb(228,65,54)"
                    },
                    text: "d"
                }
            ]
};

var sheet = spread.getActiveSheet();
// 在视图的单元格中应用富文本格式
 sheet.setValue(3, 0, SpreadJS, 3);
sheet.setValue(2, 2, sJS, GC.Spread.Sheets.SheetArea.viewport);
// 将富文本格式应用于列标题单元格
sheet.setValue(0, 4, { richText: [{ style: { font: 'bold 36px Arial ', foreColor: 'blue' }, text: 'Spread' }] }, GC.Spread.Sheets.SheetArea.colHeader);
sheet.setValue(0, 1, SpreadJS, GC.Spread.Sheets.SheetArea.colHeader);
// 将富文本格式应用于行标题中的单元格
sheet.setValue(2, 0, sJS, GC.Spread.Sheets.SheetArea.rowHeader);
```
