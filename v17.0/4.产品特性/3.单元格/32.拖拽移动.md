# dragmove

SpreadJS支持使用鼠标拖拽移动单元格或单元格块。

用户可以使用鼠标选择一个或多个单元格并将其移动到新位置。 将指针移到所选列，行或单元格的边缘，然后单击并将所选范围拖动到新位置。

下图显示带有拖拽图标的所选单元格块：

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/cdragmove.png)

将块移动到新位置。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/cdragmove1.png)

松开鼠标以在新位置显示数据。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/cdragmove2.png)

您可以选择并拖动多个连续的列或行。

您可以使用 **options.allowUsers DragDrop** 属性阻止或允许用户拖动和移动。



#### 示例代码

此示例允许用户拖放单元格。


```JavaScript
$(document).ready(function ()
                    {
                        var spread =
                        new GC.Spread.Sheets.Workbook(document.getElementById("ss"),{sheetCount:3});
                        var sheet = spread.getActiveSheet();
                       
                        // Enable drag and drop of cells
                        spread.options.allowUserDragDrop = true;
                        sheet.setValue(0, 0, "Text");
                    });
```
