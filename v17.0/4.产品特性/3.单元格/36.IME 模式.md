# imemode

您可以在Internet Explorer或Mozilla Firefox的单元格中指定使用输入法编辑器（IME）模式。

使用 **imeMode** 方法指定IME模式设置。

当活动单元格不是可编辑单元格或单元格被锁定时，IME栏被禁用。

您可以在自定义单元格中使用 **isImeAware** 与 **updateImeMode** 方法。

如果您使用鼠标单击该单元格，则IME栏将回滚该单元格的IME设置。 例如，如果单元格A1中的IME模式处于活动状态，并且活动单元格变更为A1，则IME条变为活动状态。 按Shift键可将IME栏变更为非活动状态。 在单元格A1中单击会导致IME栏变回活动状态。



#### 示例代码

以下代码禁用IME模式。


```JavaScript
activeSheet.getCell(0, 0).imeMode(GC.Spread.Sheets.ImeMode.Disabled);
//或
var style = new GC.Spread.Sheets.Style();
style.imeMode = GC.Spread.Sheets.ImeMode.Disabled;
activeSheet.setStyle(0, 0, style);
```
