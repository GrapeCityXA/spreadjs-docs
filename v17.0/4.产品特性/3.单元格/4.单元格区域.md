# cell-range

SpreadJS提供了一种简单的方法来访问表单区域中的单元格区域。您可以使用[getRange](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#getRange)方法.

它允许用户根据自己的需求方便地选择获取表单区域区域信息的方式，可以是通过行和列索引，也可以是通过区域地址。以下两部分将对此进行讨论。



### 通过行和列索引获取区域

您可以使用 **getRange(row, col, rowCount, colCount, sheetArea)** 方法获得表单区域区域内的一系列单元格。此方法使用诸如行索引、列索引、区域的行计数和列计数等参数。通过这种方式，您可以通过指定表单区域中的行索引和列索引获得单元格的区域。

下图显示了通过行和列索引获取单元格区域的示例。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/row-and-column-info.png)

下面的代码片段描述了如何使用 **getRange** 方法指定具有行和列索引的区域B2: f6。


```Javascript
<script>
    $(document).ready(function () {
        //初始化spread
        var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });
        //获取活动表
        var sheet = spread.getActiveSheet();

        // 通过行和列信息获取区域
        var range = sheet.getRange(1, 1, 5, 5, GC.Spread.Sheets.SheetArea.viewport);
        range.text("Text");
    });
</script>
```



### 按区域地址获取区域

您还可以使用 **getRange(address, sheetArea)** 方法获得表单区域中的单元格区域。此方法使用区域地址字符串获取指定表单区域中的单元格区域。

下图显示了按区域地址获取单元格区域的示例。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/range-address.png)

下面的代码片段描述了如何使用 **getRange** 方法指定具有区域地址字符串的区域A1:E5。


```Javascript
<script>
    $(document).ready(function () {
        //初始化spread
        var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });
        //获取活动表
        var sheet = spread.getActiveSheet();

        // 按区域地址获取区域
        var range = sheet.getRange('A1:E5', GC.Spread.Sheets.SheetArea.viewport);
        range.text("Text");
    });
</script>
```



### 根据数据类型获取区域

您可以使用[getUsedRange](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#getUsedRange)方法根据工作表中可用数据的类型获取区域单元格 。它以枚举选项UsedRangeType作为参数，快速获取不同类型数据的最大范围 。

当您使用不同形式的数据（如迷你图、图表、切片器等）时，这有助于在整个工作表中快速获取不同的数据范围。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/getUsedRange.gif)

下面的代码示例演示如何在工作表中选择所有已应用样式的单元格区域。


```JavaScript
function getRangeStyle() {
    var sheet = spread.getSheet(0);
    var styleRange = sheet.getUsedRange(GC.Spread.Sheets.UsedRangeType.style);
    //  styleRange:{row: 2, col: 2, rowCount: 3, colCount: 3}

    sheet.setSelection(styleRange.row, styleRange.col, styleRange.rowCount, styleRange.colCount, GC.Spread.Sheets.SheetArea.viewport, GC.Spread.Sheets.StorageType.style);
}
```
