# set_text_indentation

在超链接单元格中，您可以为超文本设置文本缩进。

下面共享的图像在超链接单元格中显示文本缩进。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/hyperlink-textindent.png)



#### 示例代码

以下代码为超链接单元格中的超链接设置缩进。


```JavaScript
// 在超链接单元格中设置textIndent
spread.getSheet(0).getCell(1, 1).textIndent(3);
```

下表共享描述了超链接单元格中水平对齐和文本缩进如何同时工作：

|  **水平对齐**  |  **                                                                 文本缩进**  |
|--- |--- |
| Left<br /><br /> |  **textIndent** 中增加缩进量值会将超链接文本向右移动一个标签宽度。<br /><br /> |
| Center<br /><br /> | 超链接文本将居中。<br /><br /> |
| Right<br /><br /> |  **textIndent** 中增加Indent值会将超链接文本向左移动一个标签宽度。<br /><br /> |
