# cellcombo

您可以使用组合框单元格来显示下拉列表。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/cellcombo.png)

您还可以使组合单元格可编辑。 您可以输入单元格的编辑部分，列表中的匹配项将自动被选择。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/cellecombo.png)

如果项目宽度小于单元格宽度，则将项目宽度设置为单元格宽度；否则，将项目宽度设置为单元格宽度。 否则，项目宽度等于最长项目的宽度。

下拉列表中最大可见项目数为20。显示下拉列表时，使用向上或向下箭头键选择项目。 左右箭头键提交所选项目并移至下一个或上一个单元格。 Enter键也将提交选定的项目，而Esc键将取消选定的项目。

使用快速输入模式时，箭头键的行为可能不同。 如果单元格的编辑器状态为EditorStatus.Enter，则按向左或向右箭头键将结束编辑并导航到上一个或下一个单元格。 如果编辑器状态为EditorStatus.Edit，则按向左或向右箭头键不会结束编辑。



#### 示例代码

下面的示例创建一个带有项目列表的组合框单元格。


```JavaScript
var cellType2 = new GC.Spread.Sheets.CellTypes.ComboBox();
cellType2.items(["a","b","c"]);
activeSheet.getCell(2, 2).cellType(cellType2);
```

下面的示例创建一个带有项目列表的可编辑组合框单元格。


```JavaScript
var items2 = ["a", "ab", "abc", "apple", "boy", "cat", "dog"];
var eComboBoxCellType = new GC.Spread.Sheets.CellTypes.ComboBox().items(items2).editable(true);
activeSheet.getCell(1, 3).cellType(eComboBoxCellType);
activeSheet.setColumnWidth(3,120);
```
