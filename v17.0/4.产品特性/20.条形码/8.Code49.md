# SettingCode49

Code 49是二维的高密度堆叠条形码，具有两到八行（每行八个字符）。 每行都有一个开始代码和一个停止代码。 此条形码特别用于编码完整的ASCII字符集。

下面描绘Code49条码迷你图的截图。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/code49.png)



#### 公式定义

您可以使用以下公式在表单中设置Code49迷你图:

=BC_CODE49(value, color, backgroudColor, showLabel, labelPosition, grouping, groupNo, fontFamily, fontStyle, fontWeight, fontTextDecoration, fontTextAlign, fontSize, quietZoneLeft, quietZoneRight, quietZoneTop, quietZoneBottom)



#### 参数

| 名称 | 描述 |
|--- |--- |
| value | 表示条形码编码的数据 |
| color | 条形码的字体颜色(默认值是 'rgb(0,0,0)') |
| backgroundColor | 条形码的背景色(默认值是'rgb(255, 255, 255)')。 |
| showLabel | 是否显示条形码标注 |
| labelPosition | ​条形码标注的位置 |
| grouping | 指定符号模式是否为组字母数字模式。 默认值为“ false”。 |
| groupNo | 代表组中符号索引的值。 默认值为“ 0”。 |
| fontFamily | 一个字符串，代表标签文本fontFamily。 默认值为“ sans-serif”。 |
| fontStyle | 条形码标记的字体样式(默认值是 'normal') |
| fontWeight | 条形码标记的字体粗细(默认值是 'normal') |
| fontTextDecoration | 条形码标记的装饰线(默认值是 'none') |
| fontTextAlign | 条形码标记的文字排列(默认值是'center') |
| fontSize | 条形码标记的字号(默认值是'12px') |
| quietZoneLeft | 条形码左侧静默区的大小 |
| quietZoneRight | 代表右区大小的值 |
| quietZoneTop | 代表顶区大小的值 |
| quietZoneBottom | 代表底区大小的值 |



#### 示例代码

此示例代码在表单中设置Code49迷你图。


```JavaScript
var sheet = spread.getActiveSheet();
// 设置Code49条码迷你图
sheet.setValue(3, 1, "Code49", GC.Spread.Sheets.SheetArea.viewport);
sheet.setValue(3, 2, "6901668002433", GC.Spread.Sheets.SheetArea.viewport);
// 设置样式
sheet.setRowHeight(3, 100);
for (var col = 1; col < 4; col++)
{
sheet.setColumnWidth(col, 200);
}
sheet.getRange(3, 0, 1, 4).hAlign(GC.Spread.Sheets.HorizontalAlign.center);
sheet.getRange(3, 0, 1, 4).vAlign(GC.Spread.Sheets.VerticalAlign.center);
// 设置公式
sheet.setFormula(3, 3, '=BC_CODE49(C4)');
```
