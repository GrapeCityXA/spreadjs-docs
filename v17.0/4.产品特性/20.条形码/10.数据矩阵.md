# SettingDataMatrix

DataMatrix条形码是高密度的二维条形码，带有通常以正方形或矩形矩阵模式排列的正方形模块。

下面共享了描述数据矩阵条形码迷你图的截图。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/datamatrix.png)



#### 公式定义

您可以使用以下公式在表单中设置Datamatrix迷你图：

=BC_DataMatrix(value, color, backgroudColor, eccMode, ecc200SymbolSize, ecc200EndcodingMode, ecc00_140Symbole, structureAppend, structureNumber, fileIdentifier, quietZoneRight, quietZoneTop, quietZoneBottom)



#### 参数

| 名称 | 描述 |
|--- |--- |
| value | 表示条形码编码的数据 |
| color | 条形码的字体颜色(默认值是 'rgb(0,0,0)') |
| backgroundColor | 条形码的背景色(默认值是'rgb(255, 255, 255)')。 |
| eccMode | 代表要使用的ecc模式的值。 它具有以下值：“ ECC000，ECC050，ECC080，ECC100，ECC140，ECC200”。 |
| ecc200SymbolSize | 仅指定ECC200符号大小的值。 默认值为“ squareAuto”。 |
| ecc200EndcodingMode | 指定用于符号的编码方式。 默认值为“auto”。 |
| ecc00_140Symbole | 仅指定ECC000-140符号大小的值。 默认值为“auto”。 |
| structureAppend | 指定符号是否仅是结构化附加消息ECC200的一部分。默认值为'false'。 |
| structureNumber | 表示符号在结构化附加消息中位于哪个块的值。 仅对于ECC200，其值为“ 0-15”。 默认值为“ 0”。 |
| fileIdentifier | 一个指定文件标识的值。 仅对于ECC200，其值为'1-254'。 默认值为“ 0”。 |
| quietZoneRight | 条形码右侧静默区的大小 |
| quietZoneTop | 条形码上侧静默区的大小 |
| quietZoneBottom | 条形码下侧静默区的大小 |



#### 示例代码

本示例创建一个DataMatrix条码迷你图。


```JavaScript
var sheet = spread.getActiveSheet();
// Datamatrix设置条形码迷你图
sheet.setValue(3, 1, "Data Matrix", GC.Spread.Sheets.SheetArea.viewport);
sheet.setValue(3, 2, "Policy:411", GC.Spread.Sheets.SheetArea.viewport);
// 设置样式
sheet.setRowHeight(3, 100);
for (var col = 1; col < 4; col++)
{
sheet.setColumnWidth(col, 200);
}
sheet.getRange(3, 0, 1, 4).hAlign(GC.Spread.Sheets.HorizontalAlign.center);
sheet.getRange(3, 0, 1, 4).vAlign(GC.Spread.Sheets.VerticalAlign.center);
// 设置公式
sheet.setFormula(3, 3, '=BC_DataMatrix(C4)');
```
