# SettingCode93

Code93条码是使用大写字符和数字字符以及一些特殊字符（“％”，“ *”，“ $”，“ /”，“。”，“-”，“ +”）的条形码。

下面描绘Code93条码迷你图的截图。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/code93.png)



#### 公式定义

您可以使用以下公式在表单中设置Code93迷你图：

=BC_CODE93(value, color, backgroudColor, showLabel, labelPosition, checkDigit, fullASCII, fontFamily, fontStyle, fontWeight, fontTextDecoration, fontTextAlign, fontSize, quietZoneLeft, quietZoneRight, quietZoneTop, quietZoneBottom)



#### 参数

| 名称 | 描述 |
|--- |--- |
| value | 表示条形码编码的数据 |
| color | 条形码的字体颜色(默认值是 'rgb(0,0,0)') |
| backgroundColor | 条形码的背景色(默认值是'rgb(255, 255, 255)')。 |
| showLabel | 是否显示条形码标注 |
| labelPosition | ​​条形码标注的位置 |
| checkDigit | 指定符号是否需要校验位。 默认值为“ false”。 |
| fullASCII | 指定是否支持Code93的完整ASCII。 默认值为“ false”。 |
| fontFamily | 条形码标记的字体(默认值是 'sans-serif') |
| fontStyle | 条形码标记的字体样式(默认值是 'normal') |
| fontWeight | 条形码标记的字体粗细(默认值是 'normal') |
| fontTextDecoration | 条形码标记的装饰线(默认值是 'none') |
| fontTextAlign | 条形码标记的文字排列(默认值是'center') |
| fontSize | 条形码标记的字号(默认值是'12px') |
| quietZoneLeft | 条形码左侧静默区的大小 |
| quietZoneRight | 条形码右侧静默区的大小 |
| quietZoneTop | 条形码上侧静默区的大小 |
| quietZoneBottom | 条形码下侧静默区的大小 |



#### 示例代码

此示例代码在表单中设置Code93迷你图。


```JavaScript
var sheet = spread.getActiveSheet();
// 设置Code93条码迷你图
sheet.setValue(3, 1, "Code93", GC.Spread.Sheets.SheetArea.viewport);
sheet.setValue(3, 2, "6945091701532", GC.Spread.Sheets.SheetArea.viewport);
// 设置样式
sheet.setRowHeight(3, 100);
for (var col = 1; col < 4; col++)
{
sheet.setColumnWidth(col, 200);
}
sheet.getRange(3, 0, 1, 4).hAlign(GC.Spread.Sheets.HorizontalAlign.center);
sheet.getRange(3, 0, 1, 4).vAlign(GC.Spread.Sheets.VerticalAlign.center);
// 设置公式
sheet.setFormula(3, 3, '=BC_CODE93(C4)');
```
