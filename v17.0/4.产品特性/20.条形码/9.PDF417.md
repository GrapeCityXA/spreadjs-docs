# SettingPDF417

PDF417条码是一种流行的高密度二维条码，具有符号学功能，能够对多达1108字节的信息进行编码。 该条形码包含一组堆叠的小条形码，最多可以编码35个字母数字字符和2710个数字字符。

#### 公式定义

您可以使用以下公式在表单中设置PDF417迷你图：

=BC_PDF417(value, color, backgroudColor, errorCorrectionLevel, rows, columns, compact, quietZoneLeft, quietZoneRight, quietZoneTop, quietZoneBottom)



#### 参数

| 名称 | 描述 |
|--- |--- |
| value | 表示条形码编码的数据 |
| color | 条形码的字体颜色(默认值是 'rgb(0,0,0)') |
| backgroundColor | 条形码的背景色(默认值是'rgb(255, 255, 255)')。 |
| errorCorrectionLevel | 一个字符串，代表PDF417的纠错级别。 它具有“ auto | 0-8”值。 默认值为“auto”。 |
| rows | 一个值，它指定符号中的行数。 它具有“ auto | 3-90”值。默认值为“ auto”。 |
| columns | 一个值，它指定符号中的列数。 它具有“ auto | 1-30”值。 默认值为“自动”。 |
| compact | 指定它是否是紧凑的PDF417。 默认值为“ false”。 |
| quietZoneLeft | 条形码左侧静默区的大小 |
| quietZoneRight | 条形码右侧静默区的大小 |
| quietZoneTop | 条形码上侧静默区的大小 |
| quietZoneBottom | 条形码下侧静默区的大小 |



#### 示例代码

此示例代码在表单中设置PDF417迷你图。


```JavaScript
var sheet = spread.getActiveSheet();
// 设置PDF417条码迷你图
sheet.setValue(3, 1, "PDF417", GC.Spread.Sheets.SheetArea.viewport);
sheet.setValue(3, 2, "6935205311092", GC.Spread.Sheets.SheetArea.viewport);
// 设置样式
sheet.setRowHeight(3, 100);
for (var col = 1; col < 4; col++)
{
sheet.setColumnWidth(col, 200);
}
sheet.getRange(3, 0, 1, 4).hAlign(GC.Spread.Sheets.HorizontalAlign.center);
sheet.getRange(3, 0, 1, 4).vAlign(GC.Spread.Sheets.VerticalAlign.center);
// 设置公式
sheet.setFormula(3, 3, '=BC_PDF417(C4)');
```
