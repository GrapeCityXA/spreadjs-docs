# display_na_cells_chart

SpreadJS支持将＃N/A单元格显示为图表中的空单元格。 当SpreadJS API中的 **displayNaNAsBlank** 属性设置为true时，会将包含＃N / A值的单元格视为空单元格。

当 **displayNaNAsBlank** 设置为true时，在图表上绘制时空单元格的显示取决于 **displayBlanksAs** 方法的值。 它可以具有三个值：

-  **Connected** - ＃N/A值在图表中显示为“已连接”
-  **Gaps** - ＃N/A值在图表中显示为“空白”
-  **Zero** - ＃N/A值在图表中显示为“零”

有关如何在图表中显示空单元格的更多信息，请参考[Display Empty Cells in Chart](gcdocsite__documentlink?toc-item-id=94b57b09-8a2f-48e8-9423-4a9b84cc71cb).

但是，当 **displayNaNAsBlank** 设置为false时，将根据图表类型显示＃N/A值。 例如：

- 柱形图，饼图或条形图将＃N/A值显示为间隙或零
- 散布图，面积图或库存图显示＃N/A值作为间隙
- 折线图或雷达图显示已连接的＃N/A值


> **Note:** 旭日图和树形图表不允许在图表数据中使用＃N/A单元格。<br /><br /> 


### 代码

请参考以下示例代码，以将＃N/A单元格显示为图表中的空白单元格。 **displayBlanksAs** 方法将空白单元格显示为间隙。


```JavaScript
// 获取表单
var activeSheet = spread.getActiveSheet();
// 创建数组
var na_error = GC.Spread.CalcEngine.Errors.NotAvailable;
var dataArray = [
["", "Apple", "Samsung", "LG", "Motorola", "OnePlus"],
["Jan", 2, na_error, 3, 4, 5],
["Feb", na_error, 3, na_error, 5, 6],
["Mar", 3, 4, 5, na_error, 7],
];
// 设置数据
activeSheet.setArray(0, 0, dataArray);

// 添加图表
var chart = activeSheet.charts.add('Chart', GC.Spread.Sheets.Charts.ChartType.area, 2, 85, 350, 350, 'A1:F4');

// displayNaNAsBlank只是将＃N/A视为“blank”
chart.displayNaNAsBlank(true);
//然后displayBlanksAs会告诉图表“blank”的显示方式，zero/ gaps/ connected
chart.displayBlanksAs(GC.Spread.Sheets.Charts.DisplayBlanksAs.gaps);

// 设置图表标题
chart.title({ text: "Display NAN As Blank" });
```
