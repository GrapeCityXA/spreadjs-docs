# funnel-chart

漏斗图通常用于可视化包含顺序连接阶段的线性过程。这个图表非常适合用于评估企业的销售周期。

在表单的列或行中排列的数据可以在漏斗图中绘制。漏斗图中的每个阶段都代表了总投资的一个比例。因此，它的形状是漏斗，第一阶段最大，每一阶段都比前一阶段小。

下面显示的示例描述了销售管道中每个连续阶段的潜在销售数量，每个阶段关联的条形图的长度表示每个阶段的客户数量。用例在每个阶段分析销售情况，从前景(潜在客户)和合格前景(对你的业务表示感兴趣的客户)开始，然后到报价、谈判和结束销售(确认的客户)。



#### 使用代码

这段代码展示了如何在Spreadsheet中添加漏斗图。


```JavaScript
//获取活动表
var sheet = spread.getActiveSheet();

//准备图表数据
var dataArray = [
    ['Stage', 'Amount'],
    ['Prospects', 500],
    ['Qualified Prospects', 425],
    ['Needs Analysis', 200],
    ['Price Quotes', 150],
    ['Negotiations', 100],
    ['Closed Sales', 90]             
];

sheet.setArray(1, 1, dataArray);

//添加漏斗图
var chart = sheet.charts.add('chart1', GC.Spread.Sheets.Charts.ChartType.funnel, 300, 0, 500, 400, "B2:C8");
        
//设置图表标题
var title = chart.title();
title.text = "Sales Pipeline";
chart.title(title);

//设置数据标签
var dataLabels = chart.dataLabels();
dataLabels.showValue = true;
dataLabels.color = 'white';
chart.dataLabels(dataLabels);
```
