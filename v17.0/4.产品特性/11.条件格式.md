# condformat

SpreadJS支持单元格中的条件格式。 您可以使用各种样式来设置格式化单元格的外观。

可以通过条件格式设置规则将条件格式设置应用于表单。 这些规则具有优先顺序。 规则列表中的最后一个规则具有最高优先级。 列表中的第一条规则具有最低的优先级。 默认情况下，新规则总是最后添加，并且具有最高优先级。 当两个规则冲突时，将应用优先级更高的规则。 如果两个规则不冲突（一个规则使用粗体字体，另一个规则使用单元格背景色），则将应用这两个规则。

有几种类型的条件规则。 它们如下：

- [Average 规则](gcdocsite__documentlink?toc-item-id=7a1a20f4-e22c-4dae-bfba-dce870dbb5b6)
- [Cell Value 规则](gcdocsite__documentlink?toc-item-id=2da4fcd7-f076-4eba-86ee-e769cbb28764)
- [Data Bar 规则](gcdocsite__documentlink?toc-item-id=891513c4-476f-485b-a3af-4811b22aaa24)
- [Date Occurring 规则](gcdocsite__documentlink?toc-item-id=10cdd1ca-715c-4a8d-aca1-dba0ba570a67)
- [Duplicate 规则](gcdocsite__documentlink?toc-item-id=58c96dc2-81d3-4d4e-b2aa-f32810c77610)
- [Formula 规则](gcdocsite__documentlink?toc-item-id=f4fbfc9a-926d-492b-b847-53c62662cb94)
- [Icon Set 规则](gcdocsite__documentlink?toc-item-id=f7e8e064-0196-4b9b-b639-7e71fb585df9)
- [Scale 规则](gcdocsite__documentlink?toc-item-id=82a30fa9-de92-49e9-b33b-a089ba40e24e)
- [Specific Text 规则](gcdocsite__documentlink?toc-item-id=ec22592d-b6fd-4400-8e44-4e46805cbea6)
- [Top 10 规则](gcdocsite__documentlink?toc-item-id=bb44c6c4-9a11-4a69-86b4-1bb15fe25fe4)
- [Unique 规则](gcdocsite__documentlink?toc-item-id=97c07b5d-496d-44b0-af56-6724a75b061c)

下表列出了规则及其说明：

|  **规则**  |  **描述**  |
|--- |--- |
| Average 规则 | Average 规则将会检查选中单元格区域中的单元格在平均值之上还是之下。 |
| Cell value 规则 | Cell Value 规则将会比对 cell 的值。 |
| Date 规则 | Date规则是用来比对日期的。 |
| Formula 规则 | Formula 规则可以让你使用公式来检查单元格的条件。 |
| Data bar 规则 | data bar 在每一个单元格中显示了一个长条。长条的长度与单元格中的数据有关。长条的长度越长，单元格中的值越大。 |
| Icon set 规则 | Icon Set 规则可以基于单元格中的值来显示图标。您可以指定图标的类型以及是否显示图标或图标以及单元格中的数据。 |
| Specific text 规则 | Specific Text 规则用于查找单元格中的字符串。 |
| Top 10 规则 | Top 10 规则用于检查单元格中的值是否较大或者较小。 |
| Unique 规则 | Unique 规则用于检单元格中的值在选中区域内是否唯一。 |
| Duplicate 规则 | Duplicate 规则用于检查单元格中重复的值。 |
| <br /><br />Scale 规则<br /><br /> | 比例尺规则使用滑动色标。 例如，如果1是黄色，而50是绿色，则25将是浅绿色。 比例尺规则可以选择比例尺中的两种或三种颜色。<br /><br />下图是Scale规则。<br /><br />![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/c3scale.png)<br /><br /> |
