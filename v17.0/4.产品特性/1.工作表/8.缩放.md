# zoom

SpreadJS允许您执行缩放操作以放大或缩小表单的视口。可以使用以下任意一种方法执行放大操作：

- Ctrl + 鼠标滚轮
- 状态栏缩放指示器
- 两根手指进行缩放操作（仅在触摸设备上）
- API member sheet.zoom(缩放因子)

单元格大小及其内容将随视口一起放大或缩小。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/czoom.png)

边框，网格线，冻结线，分割条和选择指示器均不受影响。

通过使用sheet.zoom（zoomFactor），可以将缩放系数设置为0.1到4之间的任何值。默认情况下启用缩放操作。 但是，您可以通过将 **options.allowUserZoom** 属性设置为false来选择禁用它。



#### 示例代码

This example sets the **options.allowUserZoom** property.


```JavaScript
activeSheet.zoom(3);
```



## 设定缩放限制

进行缩放操作时，会触发 **ViewZooming** 和 **ViewZoomed** 事件。 这些事件可用于干预缩放过程并应用任何操作，例如设置视口的最小或最大缩放限制。



#### 示例代码

本示例使用 **newZoomFactor** 参数设置表格视图的最小和最大缩放限制。


```JavaScript
// 通过newZoomFactor参数限制缩放动作
// set allowUserZoom to true
spread.options.allowUserZoom = true;
activeSheet.bind(GC.Spread.Sheets.Events.ViewZooming, function (e, info) {
    if (info.newZoomFactor >= 2) {
        info.newZoomFactor = 2; // 最大缩放系数为2
    }
    if (info.newZoomFactor < 1) {
        info.newZoomFactor = 0.5; // 最小缩放系数为0.5
    }
});
```

本示例通过使用 **cancel** 参数设置表格视图的最大缩放限制。


```JavaScript
//通过取消参数限制缩放动作
//将allowUserZoom设置为true
spread.options.allowUserZoom = true;

activeSheet.bind(GC.Spread.Sheets.Events.ViewZooming, function (e, info) {
    if (info.newZoomFactor >= 2) {
       info.cancel = true; // 取消此缩放动作
    }
});
```
