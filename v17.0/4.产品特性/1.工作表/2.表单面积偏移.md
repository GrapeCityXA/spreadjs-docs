# SettingSheetAreaOffset

SpreadJS允许用户确保完整地渲染整个表单。 您可以配置表单区域偏移量，以确保在隐藏行头或列头时完全显示第一列/行的左/顶部边框，网格线，双线和选择边框。



下图说明了在表单中设置表单区域偏移的重要性。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/sheetareaoffset.png)

以下共享的表描述了不同的情况以及在表单中使用表单区域偏移时可能需要参考的描述：

|  **场景**  |  **描述**  |
|--- |--- |
| 当行头可见时 | 第一列是指行头的第一可见列。选择边框将完全呈现。<br /><br /> |
| 当行头隐藏时 | 第一列是指视图的左列。<br /><br />所选内容的左边框不会被裁剪，可以完全呈现。<br /><br />左侧的双线将被部分渲染。<br /><br /> |
| 当列头可见时 | 第一行是列头的第一可见行。选择边框将完全呈现。<br /><br /> |
| 隐藏列头时 | 第一行是指视图的第一行。选择顶部边框不会被裁剪，可以完全呈现。<br /><br />顶部的双线将被部分渲染。<br /><br /> |
| 当选择从第一行/列开始时 | 左/上选择框将丢失。 |
| 当表单具有行分组或列分组时 | 双线未完全呈现。选择边框将完全覆盖轮廓区域。<br /><br /> |
| 在打印表单时 | 如果将打印选项：showBorder设置为false，并且表单选项：sheetAreaOffset包含默认值，则它将偏移设置为2像素，以便在左/上边框中呈现双线。如果将打印选项：showBorder设置为true，则行为将与以前相同。<br /><br /> |
| 在支持触控的设备中滚动表单时 | 左侧或顶部的双线将始终在表单之外呈现。<br /><br />左边框或上边框可以完全呈现。<br /><br /> |



#### 示例代码

本示例说明如何在表单中设置表单区域的偏移量。


```JavaScript
sheet.options.sheetAreaOffset= {left : 2, top : 2};
```
