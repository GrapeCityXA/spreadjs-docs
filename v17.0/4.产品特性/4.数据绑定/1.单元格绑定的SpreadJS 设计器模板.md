# designertemplate

您可以使用SpreadJS设计器通过模板创建与数据的绑定关系。 通过减少编码量来节省时间。

设计器中的 **Template** 选项用于设计单元格绑定模板。 **Template** 选项位于 **Data** 标签下。 使用模板创建与实际数据字段匹配的字段节点。 您还可以设置数据的单元格类型（ **Home** 标签和 **CellType** 选项）。 使用 **AutoGenerateLabel** 选项自动创建绑定路径标签。

选择绿色加号以添加字段节点。 然后键入字段名称（例如，名称）。 您可以使用下拉箭头指定字段选项，例如 **CheckBox** 。 下图说明了添加字段节点的区域。

将节点拖到单元格区域以生成布局。 您还可以使用 **CellType** 选项变更单元格设置（例如从复选框单元格中删除标题）。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/SpreadJSbindingtemplate2.png)

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/SpreadJSbindingtemplate1.png)

如果以后要重新设计模板，请保存到SpreadJS设计器文件（ssjson）。 保存到js文件以在HTML页面中使用。 JSON对象另存为变量字段。 字段名称与文件名相同。 使用 **File** 标签下的 **Export** 选项将其保存到SSJSON或Javascript文件。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/SpreadJSbindingtemplate4.png)



#### 示例代码

将代码添加到引用js文件的页面。 本示例使用一个名为binding.js的文件。 添加类似于以下内容的代码：


```JavaScript
<!DOCTYPE html>
<html>
<head>
<title>SpreadJS Binding</title>
<link type="text/css" href="./css/gc.spread.sheets.13.0.0.css" rel="stylesheet" />
<script src="http://code.jquery.com/jquery-2.0.2.js" type="text/javascript"></script>
<script type="text/javascript" src="./scripts/gc.spread.sheets.all.13.0.0.min.js"></script>
<script type="text/javascript" src="binding.js"></script>
<script type="text/javascript">
$(document).ready(function () {
var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"),{sheetCount:3});
var data = { name: "bob", age: 20, gender: "Male", email: "bob@test.com",
married: true }; // 客户的数据源。
spread.fromJSON(binding); //使用fromJSON方法加载模板，此处的模板变量字段在binding.js中定义。
var sheet = spread.getActiveSheet();
sheet.setDataSource(new GC.Spread.Sheets.Bindings.CellBindingSource(data)); //setDataSource with CellBindingSource.
});
</script>
</head>
<body>
<div id="ss" style="width: 600px; height: 250px; border: 1px solid gray">
</div>
</body>
</html>
```
