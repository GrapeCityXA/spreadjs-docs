# fill-effects

SpreadJS 允许您在形状中添加填充效果，以通过创建不同的 UI 效果来增强其外观。



### 实体填充

您可以使用ShapeFillType枚举将实体填充应用于形状。它提供了创建以下填充效果的solid 和none 值：

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/solid-no-fill.png)

T下面的代码示例对形状应用Solid和none。


```JavaScript
//  添加一个带有实体填充的形状
var shape1 = activeSheet.shapes.add("myShape1", GC.Spread.Sheets.Shapes.AutoShapeType.diamond, 200, 50, 150, 150);
var style = shape1.style();
style.fill = { type: GC.Spread.Sheets.Shapes.ShapeFillType.solid, color: 'red'};
shape1.style(style);
            
// 添加一个没有填充的形状 
var shape2 = activeSheet.shapes.add("myShape1", GC.Spread.Sheets.Shapes.AutoShapeType.diamond, 400, 50, 150, 150);
var style = shape2.style();
style.fill = { type: GC.Spread.Sheets.Shapes.ShapeFillType.none };
shape2.style(style);
```



### 渐变填充

您可以通过创建颜色混合效果将渐变填充应用于提供 3D 颜色外观的形状。可以在stops属性中指定每种颜色的起始位置，也可以设置颜色的亮度和透明度比例。

SpreadJS 提供两种类型的渐变填充：

-  **线性渐变:** 填充由方向或角度定义的形状。如果同时提到方向和角度，则方向优先。
-  **径向渐变:** 填充由中心点的方向定义的形状。
