# sparkline-shape

迷你图通常用作小型、简单且数据丰富的图形，以视觉上吸引人的方式传达信息。
但是，SpreadJS 允许您创造性地将迷你图呈现为形状或图像，以增强视觉设计或在可以移动、缩放或旋转的各种上下文中传达含义。
作为形状和图片的迷你图可用于演示文稿，以简洁易懂的方式传达信息，或用于用户界面以显示任务的进度。
![迷你图形状图片](https://documentsitestorage.blob.core.windows.net/document-site-files/images/df1fe1ee-eb3c-4da7-8c20-a0d8d2b7e734/sparkline-shapepic.fcdc3c.gif)
您可以通过将图片填充的src或style.fill.src属性绑定到迷你图公式来将迷你图呈现为图像。
同样，迷你图公式可以绑定到自动形状的style.fill.src属性，此外，SpreadJS 允许您在绑定到src属性时向迷你图添加渐变、纯色和其他填充。
以下示例代码显示了如何将矩形添加为形状并将其绑定到列迷你图。

```javascript
/ add auto shape 
var rect = sheet.shapes.add("rect", GC.Spread.Sheets.Shapes.AutoShapeType.rectangle, 0, 300, 142, 162); 

// set picture fill 
var style = rect.style(); 
style.fill = { src: '' }; 
rect.style(style); 
sheet.setValue(11,0,"Sales: "); 
sheet.setValue(11,3,"Note: "); 

// bind sparkline formula to src of picture fill 
rect.setFormula('style.fill.src', '=COLUMNSPARKLINE(Sheet1!B3:B9,0)'); 
```

下面的示例代码展示了如何使用 Pie Sparkline 绑定图片形状并设置纯色背景填充。

```javascript
 // add picture shape 
var pic = sheet.shapes.addPictureShape("pic", '', 400, 300, 142, 162); 

// bind sparkline formula to src of picture 
pic.setFormula('src', '=PIESPARKLINE(Sheet1!B3:B8,"#919F81","#D7913E","CEA722","#B58091","#8974A9","#728BAD")'); 

// set solid background 
var style = pic.style(); 
style.fill = { color: '#4F80BC' }; 
pic.style(style); 
```
