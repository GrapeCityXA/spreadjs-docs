# resize-shape

SpreadJS 支持调整工作表中形状的大小。
为此，ShapeBase 类提供了 allowResize 属性。 该属性可以有不同的调整大小模式和布尔值。
![resizing-allshapes.88ae90](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/e89163df-9462-4186-9f56-3bcf7b915acb/resizing-allshapes.88ae90.87f1bc.gif)
ResizeMode 枚举提供以下类型的大小调整模式：

* <strong>纵横比（Aspect）</strong>：纵横比调整模式显示所有调整大小的锚点，即北、南、东、西、西北、东北、西南和东南锚点。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/e89163df-9462-4186-9f56-3bcf7b915acb/image.612c39.png)
* <strong>水平（Horizontal）</strong>：水平调整大小模式仅显示 west 和 east 调整大小处理程序，以便可以水平调整形状的大小。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/e89163df-9462-4186-9f56-3bcf7b915acb/image.bf7e91.png)
* <strong>垂直（Vertical）</strong>：垂直调整大小模式仅显示南北调整大小处理程序，以便可以垂直调整形状的大小。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/e89163df-9462-4186-9f56-3bcf7b915acb/image.5b8ca8.png)

请参考以下示例代码使用 allowResize 方法调整形状大小。

```javascript
// Resize the shape in aspect order
shape2.allowResize(GC.Spread.Sheets.Shapes.ResizeMode.aspect);
// Resize the shape in horizontal order
shape3.allowResize(GC.Spread.Sheets.Shapes.ResizeMode.horizontal);
// Resize the shape in vertical order
shape4.allowResize(GC.Spread.Sheets.Shapes.ResizeMode.vertical);
```

您还可以禁用形状上的所有调整大小处理程序，并通过在 allowResize 方法的参数中将值传递为 false 来阻止用户调整形状大小。
同样，要启用形状上的所有调整大小处理程序，您可以在 allowResize 方法的参数中将值作为 true 传递。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/e89163df-9462-4186-9f56-3bcf7b915acb/image.661bc1.png)

```javascript
// Disable shape resize
shape1.allowResize(false);
```

#### 支持的形状类型和默认值

下表列出了不同的形状类型和默认的调整大小模式值：

| 形状类型 | 默认值 |
| ---- | --- |
| Shape | true |
| Group Shape | true |
| Connector | true |
| Form control | true |
| Picture shape | aspect |
| Camera shape | aspect |

**注意：allowResize 属性只影响 UI 行为。 形状的宽度和高度属性不受影响。**
SpreadJS 支持“Shift + 鼠标”调整大小的行为，就像在 Excel 中一样。 因此，如果在调整形状大小时按下 Shift 键，形状将保持纵横比不变。 此行为仅在 allowResize 属性设置为 true 时生效。
调整连接器形状
在 aspect、horizontal、vertical 或 true 等调整大小模式下，当鼠标移动到连接点时，它将被定向到连接点。

#### 使用表格编辑器（Designer)

要使用设计器调整形状大小，请执行以下步骤：

1. 选择形状。
2. 右键单击以从上下文菜单中选择“设置形状格式”选项。 这将调用右侧的格式形状面板。
3. 使用面板中的“调整大小模式”选项选择不同的调整大小模式。
