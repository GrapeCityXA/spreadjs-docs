# task-operation

甘特表允许您执行不同的操作，以按下表中列出的方式展示项目日程安排。

| **操作** | **描述** |
| --- | --- |
| Add | 将任务添加/插入到甘特表，无法在根任务之前添加/插入任务 |
| Remove | 从GanttSheet中删除一个任务。请注意，无法删除根任务 |
| Indent | 提升任务级别 |
| Outdent | 降低任务级别 |

请参考：[https://www.grapecity.com/spreadjs/demos/features/ganttsheet/tasks/purejs](https://www.grapecity.com/spreadjs/demos/features/ganttsheet/tasks/purejs)
