# 1600

此版本的产品中包含以下功能和增强功能：

* SpreadJS 现在实现了表单控件（Form Control）。
* SpreadJS 支持将单元格装饰设置作为样式的一部分。
* SpreadJS 支持形状大小调整增强功能。
* SpreadJS 现在支持一种新的文件格式（New File Format）来打开、保存、导入和导出文件。
* SpreadJS 支持共享公式，因此用户不必为列中的每个单元格添加公式。
* SpreadJS 现在在源数据中实现层次结构数据。
* SpreadJS 现在允许用户使用数据模式实现字段名映射。
* SpreadJS 现在支持工作表中形状的 shift + 鼠标调整行为。
* SpreadJS 在运行时在模板/面板 UX 上提供更好的 UX 设计，并在 TableSheet 中使用设计器。
* SpreadJS 现在支持无效的公式输入行为和样式，例如 Web Excel 和 Google Sheet。
* SpreadJS 表格编辑器现在支持层次结构数据。
* SpreadJS 表格编辑器现在支持工作表中选择级别的查找和替换功能。
* 在设计器形状功能区、图片格式选项卡和图表设计选项卡中添加了格式窗格图标。
* SpreadJS 现在增强了剪贴板事件，以便用户可以获取剪贴板的当前状态以执行他们需要的各种功能。
* SpreadJS 增强了 EditEnding 和 EditEnded 事件，以便用户可以知道在事件触发时提交值更改的时间。
