# 1620

## 前一个版本的增强功能

> type=danger
> 重要改动：
>
> * <span style="color: #181818">用户可以使用计算选项自动或手动地重新计算公式 从此版本开始，不再推荐使用现有的</span>`sheet.recalcAll()`<span style="color: #181818">方法来重新计算单元格中的公式，而是可以使用</span>`spread.calculate()`<span style="color: #181818">方法</span>
> * <span style="color: #181818">实现了一个新的公式编辑器面板，可以方便地创建、编辑和理解公式</span>
> * <span style="color: #181818">现在可以通过 NPM 获取单独的模块</span>
> * <span style="color: #181818">添加支持设置单元格的默认值，当单元格在数据源中没有数据或者数值时使用</span>
> * <span style="color: #181818">添加了支持创建甘特表插件 [beta] 的功能：甘特表是一个快速的、数据绑定的 DataTable 视图，具有甘特图行为和电子表格用户界面</span>

以下功能和改进已经添加到本产品的这个版本中

* 添加支持以及在设计组件初始化时获取默认活动选项卡的功能
* 添加支持使用日期时间选取器下拉菜单和滑块下拉菜单选择日期和数字范围
* 添加支持使用自定义主题和字体样式来改变工作表的外观
* 添加支持使用 SpreadJS 设计器导入和导出加密的 Excel 文件
* 支持 Angular 16
* 在集算表中实现了 WINDOW 函数来进行数据分析
* 现在可以通过 NPM 获取单独的模块
* 添加支持在 SpreadJS 设计器的名称管理对话框中设置只读的自定义名称，这些名称无法被编辑或删除
* 增加了对增强型 CSS 属性的支持，可以调整工作表中单元格内公式文本框和弹出元素的布局
* 添加了为单元格设置替代文本的支持，以提供更好的内容可访问性 用户可以根据需求设置、查看、复制、移动和修改单元格的替代文本
* 冻结行和列的显示效果已经增强，与 Excel 中的相同行为
* 添加了从 Spread 到 Excel 正确复制单元格的 Excel 样式和数据的支持
* 在导出到 Excel 时，现在可以使用没有许可证或试用许可证的评估表
* 在正则表达式函数语法中替换了 GC 前缀为 SJS
