# rnotesv8




此版本的产品已添加以下功能。

- 控件特性- 支持bootstrap主题。





# 与先前版本相比的变化

此产品版本具有以下变更。

- 名称空间已从$.wijmo.wijspread变更为GcSpread.Sheets。
- 对于Knockout和AngularJS，wijspread名称已变更为gcspread-sheets。
- 不再需要useWijmoTheme属性。
- TypeScript定义文件已变更为gcspread.sheets.d.ts。



# 解决的问题

自上次发行以来，以下解决的问题。

- 下拉列表现在可以在Microsoft Internet Explorer 9中正确显示。[114100]
- 分组图已正确导出到Excel格式的文件。 [113961]
- 某些带有公式的Excel格式文件可以在SpreadJS设计器中正确加载。[113531]
- 在设计器中导入文件后，表单顺序是正确的。[113246]
- 某些公式可以正确地用于数组。[113198]
- DragFillBlock事件中的fillRange属性可以正常工作。[113031]
