### 问题：请问在模板方式下如何进行数据绑定

***

#### 背景：

客户在论坛发帖，想知道已经在设计器设计了字段模板，导入这个模板ssjson文件，如何与数据源相绑定呢？
在SpreadJS学习指南中有介绍3种数据绑定方式，不过都是通过代码来设置相应字段的，一些刚上手SpreadJS的小伙伴可能混淆代码的使用。
本节教程就来带领大家学习，如何导入设计好的字段模板，与数据源进行绑定。

#### 实现方式：

1、在前面的教程中有演示如何通过设计器来设置相应的字段，如果小伙伴对此还不太熟悉，可以通过这里链接先去学习下。
[https://gcdn.grapecity.com.cn/showtopic-90168-1-1.html](https://gcdn.grapecity.com.cn/showtopic-90168-1-1.html)
或通过教学视频学习：
[https://gcdn.grapecity.com.cn/course-358.html](https://gcdn.grapecity.com.cn/course-358.html)
2、设计好模板后，可以通过设计器的导出ssjson功能导出此文件
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.3a6f85.png?width=1000)

3、以附件demo为例，testTableBinding.ssjson文件为我刚才导出的模板文件。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.f0100b.png)

4、在demo中导入此文件，点击”点击绑定数据源按钮“，数据已成功绑定。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.2ab360.png)
以下为点击按钮执行数据绑定的代码：

```js
var dataSource = {
  person: [
    { name: "a", age: "b", address: "c" },
    { name: "a", age: "b", address: "c" },
    { name: "a", age: "b", address: "c" },
    { name: "a", age: "b", address: "c" },
  ],
};
var datasource = new GC.Spread.Sheets.Bindings.CellBindingSource(dataSource);
sheet.setDataSource(datasource);
```

在实际业务中，将数据源替换为我们实际的数据即可，本教程只是做演示功能用，数据较为简单。
完整代码见论坛精华帖：[https://gcdn.grapecity.com.cn/forum.php?mod=viewthread&tid=90171&fromuid=59119](https://gcdn.grapecity.com.cn/forum.php?mod=viewthread&tid=90171&fromuid=59119)
