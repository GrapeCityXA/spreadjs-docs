# remove-all-header-filters

### 问题：如何去除所有表头筛选条件？

***

#### 背景：

当表头开启筛选功能后，可以根据录入的筛选条件过滤网格数据。若对多个表头进行筛选时，如何一次性清除所有的筛选条件，恢复到未进行筛选的网格数据呢？

#### 实现方式：

直接调用filter的reset接口即可，代码如下：

```javascript
$(document).ready(function () {
  var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
  var sheet = spread.getActiveSheet();
  var range = new GC.Spread.Sheets.Range(-1, 0, -1, 2);
  var rowFilter = new GC.Spread.Sheets.Filter.HideRowFilter(range);
  sheet.rowFilter(rowFilter);
  $("#reset").click(function () {
    rowFilter.reset();
  });
```
