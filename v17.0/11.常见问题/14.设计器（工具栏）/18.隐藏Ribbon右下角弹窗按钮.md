# hide-the-pop-up-button-in-the-lower-right-corner-of-the-ribbon

### 问题：如何隐藏Ribbon右下角弹窗按钮

***

#### 背景：

在某些情况下，为了限制最终用户的某些操作，想要隐藏掉Ribbon中右下角的弹窗按钮，如下图所示：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.b98757.png?width=900)

#### 解决方案：

这些按钮的配置是存放在designerConfig中的，因此为了达成隐藏弹窗按钮的目的，需要对designerConfig进行修改。

观察Designer的defaultConfig发现，在有弹窗的buttonGroups中有一个indicator属性：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.ba1449.png?width=900)

这个indicator属性就是控制弹窗按钮是否显示的关键。

通过下面的代码来删除indicator，即去掉这个弹窗按钮：

```javascript
window.onload = function () {
  let designerConfig = JSON.parse(
    JSON.stringify(GC.Spread.Sheets.Designer.DefaultConfig)
  );
  delete designerConfig.ribbon[0].buttonGroups[2].indicator;
  let designer = new GC.Spread.Sheets.Designer.Designer(
    "gc-designer-container",
    designerConfig
  );

  let spread = designer.getWorkbook();
  let sheet = spread.getActiveSheet();
};
```

效果如下：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.82d14c.png?width=900)

可以看见原本的弹窗按钮现在已经消失。
