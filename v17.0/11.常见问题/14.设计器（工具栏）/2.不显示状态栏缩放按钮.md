# not-show-status-bar-zoom-button

### 问题：如何不显示状态栏缩放按钮

***

#### 背景：

SpreadJS提供了类似Excel的状态栏，位于工作表的下方,可以显示工作表的状态或者概要。如下图：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.20292f.png?width=900)
部分客户想要不显示右下角的缩放按钮，该如何实现呢？

#### 实现步骤：

1、状态栏缩放部分实际上是一个dom。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.9caef9.png?width=900)
可以在初始化时执行以下代码使其不显示：

```javascript
document.getElementsByClassName("gc-statusbar-statusitem-container")[2].style.display = "none"
document.getElementsByClassName("gc-statusbar-statusitem-container")[1].style.display = "none"
```

2、删除状态栏与缩放相关的item项。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.492d2f.png)

```javascript
var items = statusBar.all();
for(var i=0; i<items.length; i++) {
    if(items[i].menuContent == "缩放滑块" || items[i].menuContent == "缩放") {
        items.splice(i);
    }
}
```
