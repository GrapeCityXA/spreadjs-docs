# added-cell-value-format

### 问题：如何新增单元格数值格式

***

#### 背景：

单元格格式这个对话框内有内置的各种类型的格式。
有用户反馈，Excel单元格格式中的数值格式，会有”红色负数“这样的格式，但是组件版编辑器里面并没有。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.37172a.png?width=900)

#### 解决方案：

内置单元格格式的数据都是存储在resource中的，先获取看一下内置的数据格式有哪些。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.1acef4.png)
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.403799.png?width=900)

在此基础上新增”红色负数“的单元格格式：

```javascript
var res = GC.Spread.Sheets.Designer.getResources();
res.negativeNumbers = {
    "-1234.10": "-1234.10",
    "red:1234.10": "1234.10",
    "(1234.10)": "(1234.10)",
    "red:(1234.10)": "(1234.10)",
    "red:-1234.10": "-1234.10"
}
res.numberCategoryFormats = [
    "0",
    "0;[Red]0",
    "0_);(0)",
    "0_);[Red](0)",
    "0;[Red]-0",
    "#,##0",
    "#,##0;[Red]#,##0",
    "#,##0_);(#,##0)",
    "#,##0_);[Red](#,##0)"
]
```

最后将修改后的res重新setResources回去：
`GC.Spread.Sheets.Designer.setResources(res);`

此时再打开单元格格式弹窗，会发现“红色负数”格式已新增成功。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.961d18.png?width=900)
