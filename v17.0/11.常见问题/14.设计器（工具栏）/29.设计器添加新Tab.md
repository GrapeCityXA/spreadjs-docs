# designer-adds-new-tab

### 问题：如何在设计器中添加新的Tab

***

#### 背景：

有客户希望能够在Ribbon上添加新的Tab，以添加一些自定义操作按钮。

#### 实现步骤：

通过`GC.Spread.Sheets.Designer.DefaultConfig;`获取默认的config配置，然后使用代码在配置上通过代码动态添加新的tab，然后再将修改过后的config配置交给designer进行初始化。
首先需要找到config配置中tab的位置，从下图可以看出tab位于config的ribbon上。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.457355.png?width=900)

接下来就需要添加具体的tab了，如下图代码所示：

```javascript
config.ribbon.push({
  id: "customTab",
  text: "自定义Tab",
  buttonGroups: [
    {
      label: "在这里填写您想要填写的内容",
      commandGroup: {
        children: [],
      },
    },
  ],
});
```

给ribbon用push方法插入一个对象，对象中有我们定义tab的名称，id等内容。
