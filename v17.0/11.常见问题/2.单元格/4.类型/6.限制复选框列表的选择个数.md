# limit-checkbox-count

### 背景

***

SpreadJS支持复选框列表，在默认情况下是不会对选择的个数有限制，也就是说默认情况下有多少个就能选择多少个。
单选框列表只能单选一个，而复选框列表可以不限个数，有限制选择的需求，我们可以通过 `ValueChanged` 实现。

### 实现思路

首先看复选框选中之后`getValue` 拿到的是什么。从下图中可以看到，返回的是一个数组。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.f6dfed.png?width=600)
想要限制选中的个数，可以通过限制这个数组的长度实现。
例如上面有三个复选框，我们想要限制最多只能选择两个。也就是说，当数组长度大于2时，我们将其值还原。利用下面的代码。

```javascript
sheet.bind(GC.Spread.Sheets.Events.ValueChanged, function (e, info) {
    var arr = info.newValue;
    if(arr.length > 2){
        sheet.setValue(0,1,info.oldValue)
    }
});
```
