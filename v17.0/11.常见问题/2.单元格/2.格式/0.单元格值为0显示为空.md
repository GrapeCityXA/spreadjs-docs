# show-zero-as-null

### 问题：如何在SpreadJS中实现单元格值为0显示为空

***

我们在日常的业务需求中，经常碰到需要单元格为0时显示为空的需求。对于这样的需求通过自定义单元格来做是一种非常方便的显示方式。
通过下面的代码可以将所有的单元格这样显示：

```js
var oldPaint = GC.Spread.Sheets.CellTypes.Text.prototype.paint;
GC.Spread.Sheets.CellTypes.Text.prototype.paint = function (
  ctx,
  value,
  x,
  y,
  w,
  h,
  style,
  context
) {
  if (value === 0) {
    oldPaint.call(this, ctx, "", x, y, w, h, style, context);
  } else {
    oldPaint.apply(this, arguments);
  }
};
```

如果想要单独设置，可以新建一个celltype去继承text而不是重写text的paint方法， 在新建的类型中重写paint方法，然后给指定的单元格设置为该类型就可以了。
