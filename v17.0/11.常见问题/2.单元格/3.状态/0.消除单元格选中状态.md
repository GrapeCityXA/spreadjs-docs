# remove-selected-style

### 问题：如何取消单元格选中

***

在使用SpreadJS过程中，有同学会问，以下图片中的效果应该如何去除呢？
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.3df8df.png)
其实很简单，只需要一行代码即可：

```
spread.focus(false);
```

那么如果说想要去掉这个绿色的框线呢？
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.8e67d0.png)
也很简单，也只需要一行代码：

```
spread.getActiveSheet().setActiveCell(null);
```
