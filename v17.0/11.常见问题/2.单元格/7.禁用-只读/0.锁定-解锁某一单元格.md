# cells-lock

### 问题：如何锁定/解锁某一单元格

#### 背景：

正常情况下，所有的单元都是锁定状态，想要针对单元格进行锁定或解锁的操作，可以使用`sheet.getCell(r,c).locked()`接口来实现，这是设置某一个单元格的锁定状态的方法，那么如何设置一片区域的单元格的锁定状态呢？

#### 解决方案：

可以先用`getRange`方法获取到要设置的单元格区域，然后调用`locked`接口来实现，如：`sheet.getRange(-1, 3, -1, 1, GC.Spread.Sheets.SheetArea.viewport).locked(true)`
范围再扩大一点，我想要给所有的单元格都设置一个默认的锁定状态应该如何设置呢？
每一个 sheet 都有一个默认的单元格样式，可以修改这个单元格样式来实现，如下：

```javascript
var sheetStyle = sheet.getDefaultStyle();
sheetStyle.locked = false;
sheet.setDefaultStyle(sheetStyle);
```

还有其他方式能够设置单元格的锁定状态吗？
有的，还可以通过`style`去设置，如：

```javascript
sheet.options.isProtected = true;
var style = new GC.Spread.Sheets.Style();
style.backColor = "red";
style.locked = false;
sheet.setStyle(1, 1, style, GC.Spread.Sheets.SheetArea.viewport);
```

以上代码就可以设置B2单元格的锁定状态为False了。
