# disabled-validator-dropdown

### 问题：如何禁止基于列表的验证器的下拉选择

***

<span style="color: rgb(54, 54, 54); font-family: 'Microsoft Yahei', Simsun; font-size: medium; font-style: normal; font-variant-ligatures: normal; font-variant-caps: normal; font-weight: 400; letter-spacing: normal; orphans: 2; text-align: start; text-indent: 0px; text-transform: none; widows: 2; word-spacing: 0px; -webkit-text-stroke-width: 0px; white-space: normal; background-color: rgb(255, 255, 255); text-decoration-thickness: initial; text-decoration-style: initial; text-decoration-color: initial; display: inline !important; float: none;">SpreadJS的</span>数据验证是一个你可以使用定义的约束来表明一个单元格上可以或者应该设置什么样的数据的特性。你可以通过配置数据验证来阻止用户输入无效的数据，我们可以使用createListValidator来创建基于列表的验证器。

```js
var dv1 = new GC.Spread.Sheets.DataValidation.createListValidator(
  "Fruit,Vegetable,Food"
);
dv1.inputTitle("Please choose a category:");
dv1.inputMessage("Fruit, Vegetable, Food");
sheet.setDataValidator(1, 1, dv1);
```
