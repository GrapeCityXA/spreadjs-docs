# how-to-copy-custom-cells-within-the-framework

### 问题：框架内如何实现复制自定义单元格

***

#### 背景：

有小伙伴在使用自定义单元格时，发现无法对其复制粘贴。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.206e2d.png)
尝试设置了typeName后，纯JS的demo中复制粘贴没有问题了。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.e20212.png)
但是在vue等框架中该设置似乎是“无效”的，这是什么原因呢？

#### 解决方案：

在纯JS的demo中，自定义单元格函数（如：FivePointedStarCellType）是注册到window上的。
所以设置typeName字段名之后，复制粘贴时可以自动从window中获取FivePointedStarCellType。
但是在框架内，FivePointedStarCellType并不是定义在window上的，所以我们需要重写 `getTypeFromString` 函数来手动解析自定义单元格类型的字符串。

```javascript
GC.Spread.Sheets.getTypeFromString = function (typeStr) {
    if (typeStr === 'FivePointedStarCellType') {
        return FivePointedStarCellType;
    }
}
```

```javascript
export class FivePointedStarCellType {
    constructor() {
        this.typeName = "FivePointedStarCellType";
        this.size = 10;
    }
}
```
