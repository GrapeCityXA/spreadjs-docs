# updateCornerIcon

### 问题：如何在SpreadJS中修改表角图标

#### 背景：

SpreadJS表角展示的是一个灰色的小三角，并且这个三角颜色、大小均与Excel对应主题显示一致。如下所示：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.f54244.png?width=400)
但是，Web端项目，客户经常会有一些自己内部的图标风格，希望能替换此处的小三角。

#### 实现方案：

整体实现方式，其实和自定义单元格是一致的，只不过自定义单元格，覆盖的是单元格类型的paint方法。而对于表角，覆盖GC.Spread.Sheets.CellTypes.Corner的paint方法即可。paint里边本质还是使用的Canvas相关的技术。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.1ff173.png?width=400)
关于paint方法中，每个参数的详细解释，可以参考下图解释：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.8a21cd.png?width=400)
具体可以看下面的代码

```
GC.Spread.Sheets.CellTypes.Corner.prototype.paint = function(ctx,value,x,y,w,h,style,context){
    if (!ctx) {
        return;
    }
    ctx.save();
    // draw inside the cell's boundary    ctx.rect(x, y, w, h);
    ctx.clip();
    ctx.beginPath();
    ctx.fillStyle = "orange";
    let size = 10;
    var dx = x + w / 2;
    var dy = y + h / 2;
    ctx.beginPath();
    var dig = Math.PI / 5 * 4;
    ctx.moveTo(dx + Math.sin(0 * dig) * size, dy + Math.cos(0 * dig) * size);
    for (var i = 1; i < 5; i++) {
        ctx.lineTo(dx + Math.sin(i * dig) * size, dy + Math.cos(i * dig) * size);
    }
    ctx.closePath();
    ctx.fill();

    ctx.restore();
}
```
