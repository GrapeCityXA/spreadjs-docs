# 新增行如何继承前一行的样式

### 问题：新增行如何继承前一行的样式

***

#### 背景：

在数据填报过程中，在预留好的数据区域中设置了样式，在实际填报过程中，往往需要增加行数来添加数据。此时需要新增好的时候继承前一行设置好的样式。

#### 解决方案：

新增行后从上一行拷贝样式即可。可以参考下面的代码。
```javascript
        var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
		var sheet = spread.getActiveSheet();
		sheet.getRange(1,0,1,sheet.getColumnCount(), GC.Spread.Sheets.SheetArea.viewport).backColor("pink");
		sheet.getRange(2,0,1,sheet.getColumnCount(), GC.Spread.Sheets.SheetArea.viewport).backColor("pink");
		sheet.getRange(3,0,1,sheet.getColumnCount(), GC.Spread.Sheets.SheetArea.viewport).backColor("pink");
		sheet.getRange(sheet.getRowCount()-1,0,1,sheet.getColumnCount(), GC.Spread.Sheets.SheetArea.viewport).backColor("pink");
		sheet.addSpan(1,0,3,5);
		
		$("#click").click(function(){
			spread.repaint();
			var intIndex = 2;
			sheet.addRows(intIndex,1);
			for(var i=0;i<sheet.getColumnCount();i++){
				var actualStyle = sheet.getActualStyle(intIndex-1,i);
				sheet.setStyle(intIndex,i,actualStyle);
			}
			spread.resumePaint();
		});
```
