### 问题：SpreadJS如何禁用右键菜单

***

#### 背景：

对于一些仅需要浏览，不需要操作的场景，例如报表展示，可以通过下面的方式来禁用右键菜单，避免使用者通过右键菜单进行操作。

#### 解决方案：

allowContextMenu 表示 SpreadJS 或 designer 右键菜单是否可用。
使用使用下方代码查看 SpreadJS 或 designer 的右键菜单可用状态：
`spread.options.allowContextMenu;`
如下示例：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.6752d8.png)
使用下方代码允许SpreadJS 或 designer 的右键菜单可用：
`spread.options.allowContextMenu = true;`
使用下方代码禁用SpreadJS 或 designer 的右键菜单：
`spread.options.allowContextMenu = false;`

### 在线表格编辑器如何禁用右键菜单？

#### 解决方案：

在线表格编辑器，它的右键菜单相关的结构如下：
![image](https://docs.grapecity.com.cn/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.ab05f6.png)
可以看到，它并没有显示区域workArea的标记。这是因为设计器中的右键菜单是根据配置信息动态处理而来。如果想修改设计器的右键菜单，需要从GC.Spread.Sheets.Designer.DefaultConfig中去更改.
![image](https://docs.grapecity.com.cn/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.38e3f6.png)
如上图所示，config中的contextMenu代表的就是右键菜单命令字符串，调用GC.Spread.Sheets.Designer.getCommand("contextMenuCut")可以得到命令的详细信息，其中visibleContex代表的就是右键菜单显示的条件。
![image](https://docs.grapecity.com.cn/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.9b38ab.png)
如果想要禁用工作表页签处的右键菜单，只需将visibleContext中包含“TabStripSelected”的数组项删除即可

```javascript
let config = GC.Spread.Sheets.Designer.DefaultConfig
for(let i=0;i<config.contextMenu.length;i++){
    if(GC.Spread.Sheets.Designer.getCommand(config.contextMenu[i]).visibleContext && GC.Spread.Sheets.Designer.getCommand(config.contextMenu[i]).visibleContext.indexOf("TabStripSelected")!=-1){
        config.contextMenu.splice(i,1)
        i--
    }
}

let designer = new GC.Spread.Sheets.Designer.Designer("designer-container",config)
```
