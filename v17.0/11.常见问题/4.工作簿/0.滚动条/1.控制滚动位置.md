# set_scroll_position

### 问题：滚动位置是否能控制

#### 背景

在表格行列数比较多的时候，想要控制滚动条的位置将某一行或列显示在可视区域。

#### 解决方案

一般的需求是滚动到某一行某一列，可以通过下面的接口进行控制
显示某一行[showRow](https://demo.grapecity.com.cn/spreadjs/help/api/classes/GC.Spread.Sheets.Worksheet#showrow)

```jsavascript
activeSheet.showRow(9, GC.Spread.Sheets.VerticalPosition.top);
```

显示某一列[showColumn](https://demo.grapecity.com.cn/spreadjs/help/api/classes/GC.Spread.Sheets.Worksheet#showcolumn)

```jsavascript
activeSheet.showColumnOutline(false);
```

已经显示某个单元格[showCell](https://demo.grapecity.com.cn/spreadjs/help/api/classes/GC.Spread.Sheets.Worksheet#showcell)（同时控制行列滚动）

```jsavascript
activeSheet.showCell(3, 3, GC.Spread.Sheets.VerticalPosition.top, GC.Spread.Sheets.HorizontalPosition.left);
```

上述方法中的的最后一个或者两个参数，VerticalPosition，HorizontalPosition 可以控制显示行列的方位.

[VerticalPosition](https://demo.grapecity.com.cn/spreadjs/help/api/enums/GC.Spread.Sheets.VerticalPosition)为单元格或行的垂直位置枚举值
可以枚举值为

* bottom 底部
* center 中心
* nearest 最近边缘
* top 顶部

[HorizontalPosition]((https://demo.grapecity.com.cn/spreadjs/help/api/enums/GC.Spread.Sheets.HorizontalPosition))为单元格或列的水平位置

* center 中心
* left 左侧
* nearest 最近边缘
* right 右侧
