# is_scroll_to_end

### 问题：如何判断横向或纵向滚动条快要滚动到底部？

#### 背景

在用SpreadJS进行开发时，有些小伙伴需要判断滚动条是否快滚动到底部或最右侧，在进行一些相应的提示。

#### 解决方案

SpreadJS 中提供两个事件：[LeftColumnChanged](https://demo.grapecity.com.cn/spreadjs/help/latest/content/SpreadJS~GC.Spread.Sheets.Events~LeftColumnChanged_EV.html)、[TopRowChanged](https://demo.grapecity.com.cn/spreadjs/help/latest/content/SpreadJS~GC.Spread.Sheets.Events~TopRowChanged_EV.html?highlight=toprowchanged%2C)
在最左侧列，或最顶行改变时会触发这两个事件，所以可以根据触发这个事件时返回的oldTopRow、newTopRow 等参数进行判断，是否滚动到了最后行、列。

情况一：滚动条设置： spread.options.scrollbarMaxAlign = false 此设置为默认设置
在这种情况中，表单最后一行可以滚动到最顶端，判断返回的newTopRow是否为 总行数，即可判断是否滚动到了最后一行。

```javascript
sheet.bind(GC.Spread.Sheets.Events.TopRowChanged, function(s,e) {
    var rowCount = sheet.getRowCount()
    if (args.newTopRow=== rowCount - 1) {
        console.log('滚动到底部了');
    }
})
```

情况二：滚动条设置： spread.options.scrollbarMaxAlign = true 此设置下，表格无法将最后一行滚动至最顶部，故无法用args.newTopRow=== rowCount - 1进行判断。这种情况下可以用getViewportTopRow方法获取视图顶部行索引，进行判断

```javascript
sheet.bind(GC.Spread.Sheets.Events.TopRowChanged, function(s,e) {
    var row = sheet.getViewportTopRow(1);
    console.log(row)
    var rowCount = sheet.getRowCount()
    if (row === rowCount - 1) {
        console.log('滚动到底部了');
    }
});
```
