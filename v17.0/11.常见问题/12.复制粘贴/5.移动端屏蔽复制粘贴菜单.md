# DisableCopyPasteMenuOnMobile

### 问题：设置了表单保护，但是移动端仍然会出现复制粘贴菜单，如何将其屏蔽

#### 背景：

已经设置了`options.isProtected=true`，在电脑浏览器显示正常，但在手机等触摸设备上，手指一点到控件上，自动显示选中了单元格，并且，很容易出现复制、剪切的悬浮菜单，请教如何屏蔽该菜单？
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.0e5cba.png)

#### 实现方式：

通过监听[TouchToolStripOpening](https://demo.grapecity.com.cn/spreadjs/help/api/classes/GC.Spread.Sheets.Events#touchtoolstripopening)事件，通过参数handled将触摸工具栏阻止弹出。

```javascript
sheet.bind(GC.Spread.Sheets.Events.TouchToolStripOpening, function (e, info) {
  info.handled = false;
});
```
