# typescript

您可以将TypeScript支持添加到SpreadJS。 TypeScript提供强类型访问和有关代码的更好信息。

您可以下载TypeScript并从TypeScript网站获取其他信息，[https://www.typescriptlang.org/](https://www.typescriptlang.org/).

SpreadJS的TypeScript定义文件位于主产品文件夹下的定义文件夹中（SpreadJS \ definition \ GC.Spread.Sheets.d.ts）。

使用以下步骤将TypeScript支持添加到SpreadJS。

- 将GC.Spread.Sheets.d.ts和jquery.d.ts引用添加到您的typescript文件。

```ts
/// <reference path="path/jquery.d.ts" />
/// <reference path="path/GC.Spread.Sheets.d.ts" />
```
- 将代码添加到您的应用程序。 如以下示例所示，显示有关SpreadJS的信息。
