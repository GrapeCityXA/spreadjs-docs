# save-changes

接下来介绍将表格变更保存到数据库的步骤。



### 步骤 1: 获取脏单元格信息并将其转换为JSON字符串

- 创建 **saveToDB** 函数，使用 **getDirtyCells** 方法获取已变更单元格的信息，即脏单元格。
- 使用 **JSON.stringify** 方法将脏单元格信息转换为JSON字符串。
```JavaScript
//1: Create saveToDB()
function saveToDB() {
    //获取活动表 from the DOM element "ss"
    var ss = GC.Spread.Sheets.findControl(document.getElementById("ss"));
    var sheet = ss.getActiveSheet();
    // 将脏单元格信息存储在dirtyCells变量中
    var dirtyCells = sheet.getDirtyCells();
    // 通过id "msg"获取HTML <div> 元素 , 在步骤2中创建
    var div = document.getElementById("msg");
    // 在div元素中显示JSON字符串，以可视化变更后的单元格信息
    div.innerHTML = JSON.stringify(dirtyCells, null, 4);
    // 注意: 向数据库发布变更
}
```





### 步骤 2: 将变更保存到数据库

- 在SpreadJS元素之后创建id为msg的HTML`<div>`元素来显示JSON字符串。
- 创建一个输入按钮Save to DB，在其中调用saveToDB函数。当单击Save to DB按钮时，捕获并转换为JSON字符串的变化将显示在id为msg的中。带有所有button的新的HTML `<body>`和 `<div>` 元素将看起来如下:
```JavaScript
<body>
    <h1>Save changes made to the spreadsheet to a database</h1>
    <p>
        During this section we will create a Save to DB button and a DIV to
        display the changes as a JSON string when the Save to DB button is
        clicked.
    </p>
    <!-- 创建刷新按钮 -->
    <input type="button" value="Refresh" onclick="refresh()" />
    <!-- 创建 Save to DB <div>和 button -->
    <input type="button" value="Save to DB" onclick="saveToDB()" />
    <br />
    <br />
    <div id="ss" style="height:400px;width:900px"></div>
    <!-- 改变 <div> -->
    <div class="options-container">
        <h4> Changes saved to database: </h4>
        <div id="msg" style="width: 100%; height: 260px; border: 1px solid grey;"></div>
    </div>
</body>
```
