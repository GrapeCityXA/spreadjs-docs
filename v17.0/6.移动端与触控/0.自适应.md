# touchautoresize

您可以在AutoFit中使用触控手势。

点击列标题可在列标题的右侧显示调整大小指示符。 点击行标题的底部边缘以显示行的调整大小指示器。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/touchautosize1.png)

双击调整大小指示器。 列或行会自动调整大小以适合文本。
