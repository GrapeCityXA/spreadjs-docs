# HEX2OCT

此函数将十六进制数转换为八进制数。



#### 语法

HEX2OCT( *number* , *places* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *number*  | 要转换的十六进制数值，必须在FFE0000000和1FFFFFFF之间。 |
|  *places*  | [可选] 要使用的字符数。如果不是整数，则将截尾取整。 |



#### 注释

如果 number 不是有效的十六进制数字，则 HEX2OCT  返回 #NUM！ 。

如果省略 places，则 HEX2OCT 使用必要的最小字符数。 Places 可用于在返回的值前置 0（零）。



#### 数据类型

接受数值数据。返回数值数据。



#### 示例

HEX2OCT("2B")
