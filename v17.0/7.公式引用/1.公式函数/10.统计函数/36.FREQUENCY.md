# FREQUENCY

此函数计算值在某个范围内出现的频率，然后返回一个垂直的数字数组。



#### 语法

FREQUENCY( *dataarray* , *binarray* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *dataarray*  | 要对其频率进行计数的一组数值或对这组数值的引用。 |
|  *binarray*  | 要将 dataarray 中的值插入到的间隔数组或对间隔的引用。 |



#### 注释

返回的数组中的元素比 binsarray 中的元素多一个。 返回的数组中的额外元素返回最高的间隔以上的任何值的计数。

使用[ INDEX ](gcdocsite__documentlink?toc-item-id=61ae5b9c-8a40-4dfe-a7ad-ee6c4c7d9cd1)函数从返回的数组中获取单个元素。



#### 数据类型

接受区域。返回一个数组。



#### 示例

FREQUENCY(A1:A7,C2:C5)
