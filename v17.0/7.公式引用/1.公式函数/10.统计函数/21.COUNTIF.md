# COUNTIF

此函数用于统计满足某个条件的单元格的数量



#### 语法

COUNTIF( *cellrange* , *condition* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *cellrange*  | 要计数的单元格区域；单元格引用区域。 |
|  *condition*  | 确定要计数的单元格的条件，是文本，数字还是表达式。 |





#### 数据类型

接受单元格引用区域。返回数值数据。



#### 示例

COUNTIF(A1:G5,"test")

COUNTIF(R6C3:R9C4,"<2")
