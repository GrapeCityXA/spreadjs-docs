# FISHER

此函数返回 x 的 Fisher 变换值。



#### 语法

FISHER( *value* )



#### 参数

一个大于1且小于-1的数值，将在该点进行变换。



#### 注释

该变换生成一个近似正态分布而非偏斜的函数。使用此函数可以完成相关系数的假设检验。

其中x 是参数 value



#### 数据类型

接受数值数据。返回数值数据。



#### 示例

FISHER(A43)

FISHER(R4C12)

FISHER(-0.65) 得出结果 -0.7752987062
