# GAMMA.INV

此函数返回伽玛累积分布函数的反函数值。



#### 语法

GAMMA.INV( *p* , *alpha* , *beta* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *p*  | 伽玛分布相关的概率。 |
|  *alpha*  | 分布参数 |
|  *beta*  | 分布参数 |



#### 注释

此函数返回伽玛累积分布函数的反函数值。 如果 p = GAMMA.DIST(x,...)，则 GAMMA.INV(p,...) = x。如果 beta = 1，则 GAMMA.INV 返回标准伽玛分布。



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

GAMMA.INV(A3,3,4)

GAMMA.INV(0.8902,R3C8,R3C9)

GAMMA.INV(0.75,2,3) 得出结果 8.077903586669088
