# PERCENTILE.INC

此函数返回区域中数值的第 K 个百分点的值，K 为 0 到 1 之间的百分点值，包含 0 和 1。



#### 语法

PERCENTILE.INC( *array* , *k* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *array*  | 定义相对位置的数组或数据区域。 |
|  *k*  | 0 到 1 之间的百分点值，包含 0 和 1。 |



#### 注释

如果 array 为空，返回 #NUM！ 错误值。

如果 k 为非数值型，则返回 #VALUE！ 。

如果 k < 0 或 k > 1，返回 #NUM！ 。

如果 k 不是 1/（n - 1）的倍数，则该函数插以确定第 k 个百分点的值。



#### 数据类型

接受两个参数的数值数据。返回数值数据。



#### 示例

PERCENTILE.INC(A1:A12,0.95)

PERCENTILE.INC(R1C1:R1C45,0.866)

PERCENTILE.INC({5,15,25,50,65},0.45) 得出结果 5
