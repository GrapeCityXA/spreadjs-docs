# NORM.DIST

此函数返回指定平均值和标准偏差的正态分布函数。



#### 语法

NORM.DIST( *x* , *mean* , *stdev* , *cumulative* )



#### 参数

该函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *x*  | 需要计算其分布的数值。 |
|  *mean*  | 分布的算术平均值。 |
|  *stdev*  | 分布的标准偏差，值必须大于0。 |
|  *cumulative*  | 决定函数形式的逻辑值。 如果累积性为 TRUE，则为 "标准"。DIST 返回累积分布函数;如果为 FALSE，则返回概率密度函数。 |



#### 注释

如果 mean =0、 stdev = 1，且 cumulative = TRUE，则 NORM.DIST 返回标准正态分布，即 NORM.S.DIST。



#### 数据类型

x ，mean和stdev参数接受数值数据。cumulative参数接受逻辑数据。返回数值数据。



#### 示例

NORM.DIST(10,A3,B17,FALSE)

NORM.DIST(10,R3C1,R17C2,FALSE)

NORM.DIST(37,41.125,9.86,TRUE) 得出结果 0.3378430609671818
