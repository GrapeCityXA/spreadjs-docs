# F.DIST

此函数返回 F 概率分布函数的函数值。



#### 语法

F.DIST( *value* , *degnum* , *degden,cumulative* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *value*  | 用来计算函数的值。 |
|  *degnum*  | 分子自由度。如果不是整数，则将截尾取整。 |
|  *degden*  | 分母自由度。如果不是整数，则将截尾取整。 |
|  *cumulative*  | 决定函数形式的逻辑值。 如果 cumulative 为 TRUE，则 F.DIST 返回累积分布函数；如果为 FALSE，则返回概率密度函数。 |



#### 数据类型

除cumulative以外的所有参数接受数值数据。返回数值数据。



#### 示例

F.DIST(A1,2,2,TRUE)

F.DIST(R1C1,2,1,TRUE)

F.DIST(16.83975,5,3,TRUE) 得出结果 0.9789999175380504
