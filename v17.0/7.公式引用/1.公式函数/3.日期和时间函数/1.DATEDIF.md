# DATEDIF

此函数计算两个日期之间相隔的天数、月数或年数。



#### 语法

DATEDIF( *date1* , *date2* , *outputcode* )



#### 参数

前两个参数是任何日期，例如字符串，数字值或DateTime对象。

您希望返回的信息类型，其中：

| Code | 描述 |
|--- |--- |
|  *"D"*  | 一段时期内的天数。 |
|  *"M"*  | 一段时期内的整月数。 |
|  *"Y"*  | 一段时期内的整年数。 |
| "YD" | date1 与 date2 的日期部分之差。 忽略日期中的年份。 |
| "YM" | date1 与 date2 之间月份之差。 忽略日期中的天和年份 |
| "MD" | date1 与 date2 之间天数之差。 忽略日期中的月份和年份。 |



#### 数据类型

接受字符串，数值和DateTime对象。字符串和数字将转换为DateTime对象。



#### 示例

DATEDIF(A1,B1,C1)

DATEDIF(R1C1,R1C2,R1C3)

DATEDIF("2001/1/1","2003/1/1","Y")
