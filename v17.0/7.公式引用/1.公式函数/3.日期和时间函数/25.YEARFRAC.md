# YEARFRAC

此函数计算两个日期（startdate 和 enddate）之间的天数（取整天数）占一年的比例。



#### 语法

YEARFRAC( *startdate* , *enddate* , *basis* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *startdate*  | 一个代表开始日期的日期。 |
|  *enddate*  | 一个代表终止日期的日期。 |
|  *basis*  | [可选] 要使用的日计数基准类型。请参考[Day Count Basis](gcdocsite__documentlink?toc-item-id=23b72e94-94be-44ed-9302-d582747f59dd)。 |



#### 注释

如果 startdate 或 enddate 不是有效日期，YEARFRAC 会返回错误值 #VALUE! 。



#### 数据类型

basis参数接受数值数据，其余参数接受数值、字符串、DateTime对象数据。返回数值数据。



#### 示例

YEARFRAC(A1,A2,A3)
