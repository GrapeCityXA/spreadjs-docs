# filter-dynamic-array

此函数基于定义的条件筛选一系列数据。

为了组合两个或更多的筛选条件，用户可以使用“*”操作符和“+”操作符。操作符*将两组条件相乘，以将筛选条件与AND逻辑连接起来[当两个筛选条件都必须为true时]。+操作符将简单地用OR逻辑将两组条件连接起来[当一个筛选条件为true而另一个条件为false时]。



#### 语法

FILTER(array,include,[if_empty])



#### 参数

此函数有以下参数

| 参数 | 描述 |
|--- |--- |
| array | [必需]你想要筛选的区域或数组。 |
| include | [必需] 布尔值数组，其高度或宽度与数组相同。 |
| if_empty | [可选] 所含数组中的所有值都为空（筛选不返回任何内容）时返回的值。 |



#### 数据类型

接受要筛选的单元格区域或数据数组。返回经过筛选的数组。



#### 示例

例如，下面图片中的单元格F5包含公式“=FILTER(A5:D17, C5:C17=F1)”。这个公式根据一个筛选条件筛选单元格区域A5到D17(当单元格区域C5到C17匹配单元格F1中的产品值即Apple)。因此，单元格区域A5到D17中包含产品为“Apple”的所有值将被显示。

在另一个例子中，以下图像中的单元格F14包含公式“=FILTER(A5:D17， (C5:C17=F1)*(A5:A17=F2)”。这个公式根据乘法(*)操作符指定的两个筛选条件筛选单元格区域A5到D17。第一个条件是区域C5到C17应该匹配区域F1即Apple的产品值，第二个条件是区域A5到A17应该匹配区域“East”。结果显示单元格A5到D17中Product为“Apple”和Region为“East”的所有值。



#### 可用版本

此函数可以在SpreadJS 13或更高版本中使用。
