# FORMULATEXT

该函数以字符串的形式返回公式。



#### 语法

FORMULATEXT( *reference* )



#### 参数

对单元格或单元格区域的引用。



#### 注释

如果您选择引用单元格，则 FORMULATEXT 函数返回编辑栏中显示的内容。

reference 参数可以表示另一个表单或工作薄。

如果 reference 参数表示整行或整列，或表示包含多个单元格的区域或定义名称，则 FORMULATEXT 返回行、列或区域中最左上角单元格中的值。



#### 数据类型

接受单元格引用作为参数。返回字符串数据。



#### 示例

FORMULATEXT(B7) gives the value #N/A
