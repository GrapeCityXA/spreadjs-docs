# FORMULA_INDEX

此函数返回表格或区域中的值或值的引用。



#### 语法

INDEX( *return* , *row* , *col* , *area* )



#### 参数

参数如下，如果不是整数则截尾取整。

| 参数 | 描述 |
|--- |--- |
|  *return*  | 返回值、单元格或单元格区域的引用。 |
|  *row*  | 区域的行数 |
|  *col*  | 区域的列数。 |
|  *area*  | [如果返回单元格区域引用] 单元格区域。 |



#### 数据类型

接受数值数据。返回数值数据。



#### 示例

INDEX(A2:C3,2,2)

INDEX(R2C1:R3C3,5,3)
