# LOGNORMDIST

此函数返回 x 的对数累积分布函数的函数值。



#### 语法

LOGNORMDIST( *x* , *mean* , *stdev* )



#### 参数

该函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *x*  | 用来计算函数的值。 |
|  *mean*  | ln(x) 的平均值。 |
|  *stdev*  | ln(x) 的标准偏差。 |



#### 注释

如果 p = LOGNORMDIST(x,...) 则 LOGINV(p,...) = x.



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

LOGNORMDIST(0.92,B8,G22)

LOGNORMDIST(42,2,1.2) 得出结果 0.926199546
