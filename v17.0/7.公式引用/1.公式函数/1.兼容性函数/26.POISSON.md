# POISSON

此函数返回泊松分布。



#### 语法

POISSON( *nevents* , *mean* , *cumulative* )



#### 注释

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *nevents*  | 事件数，如不是整数则截尾取整，值必须 >= 0。 |
|  *mean*  | 期望值，值必须 >= 0。 |
|  *cumulative*  | 逻辑值，确定所返回的概率分布的形式。 如果 cumulative 为 TRUE，则 POISSON 返回发生的随机事件数在零（含零）和 x（含 x）之间的累积泊松概率；如果为 FALSE，则 POISSON 返回发生的事件数正好是 x 的泊松概率密度函数。 |

#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

POISSON(A3,B4,TRUE)

POISSON(R1C2,3,FALSE)

POISSON(7,4,TRUE) 得出结果 0.948866384

POISSON(7,4,FALSE) 得出结果 0.059540363
