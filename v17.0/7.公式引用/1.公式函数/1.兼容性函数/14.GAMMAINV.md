# GAMMAINV

此函数返回伽玛累积分布函数的反函数值。



#### 语法

GAMMAINV( *p* , *alpha* , *beta* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *p*  | 伽玛分布相关的概率。 |
|  *alpha*  | 分布参数 |
|  *beta*  | 分布参数 |



#### 注释

此函数返回伽玛累积分布函数的反函数值。 如果 p = GAMMADIST(x,...)，则 GAMMAINV(p,...) = x。



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

GAMMAINV(A3,3,4)

GAMMAINV(0.8902,R3C8,R3C9)

GAMMAINV(0.75,2,3) 得出结果 8.0779035867
