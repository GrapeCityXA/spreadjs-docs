# YIELD

此函数返回定期支付利息的债券的收益。



#### 语法

YIELD( *settle* , *maturity* , *rate* , *price* , *redeem* , *frequency* , *basis* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *settle*  | 有价证券的结算日。 |
|  *maturity*  | 有价证券的到期日。 |
|  *rate*  | 有价证券的年息票利率。 |
|  *price*  | 有价证券的价格（按面值为 ￥100 计算）。 |
|  *redeem*  | 面值 ￥100 的有价证券的清偿价值。 |
|  *frequency*  | 年付息次数, 如果按年支付，frequency = 1；按半年期支付，frequency = 2；按季支付，frequency = 4。 |
|  *basis*  | [可选] 要使用的日计数基准类型。请参考[Day Count Basis](gcdocsite__documentlink?toc-item-id=23b72e94-94be-44ed-9302-d582747f59dd)。 |



#### 注释

如果settle或maturity不是有效日期，则返回 #VALUE！ 。

如果 frequency 是除1、2或4以外的任何数字，返回 #NUM！ 。

如果 price <= 0 或 redeem <= 0，返回 #NUM！ 。

如果settle≥maturity，返回 #NUM！ 。

settle、maturity、frequency 和 basis 将被截尾取整。



#### 数据类型

接受数值数据和日期。返回数值数据。



#### 示例

YIELD(A1,A2,A3,A4,A5,A6,A7)
