# ACCRINT

该函数用于计算定期付息证券的应计利息。



#### 语法

ACCRINT( *issue* , *first* , *settle* , *rate* , *par* , *frequency* , *basis* )



#### 参数

该函数具有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *issue*  | 有价证券的发行日。 |
|  *first*  | 有价证券的首次计息日。 |
|  *settle*  | 有价证券的结算日。 |
|  *rate*  | 有价证券的年息票利率。 |
|  *par*  | [可选] 证券的票面值。 如果省略此参数，则 ACCRINT 使用 ￥10,000。 |
|  *frequency*  | 年付息次数。 |
|  *basis*  | [可选] 要使用的日计数基准类型。 count (参考[Day Count Basis](gcdocsite__documentlink?toc-item-id=23b72e94-94be-44ed-9302-d582747f59dd).) |



#### 备注

如果 issue ≥ settlement，则 ACCRINT 将返回 #NUM! 错误值。如果 rate ≤ 0 或 par ≤ 0，则 ACCRINT 将返回 #NUM! 错误值。 如果 frequency 不是数字 1、2 或 4，则 ACCRINT 将返回 #NUM! 错误值。

如果 basis < 0 或 basis > 4，则 ACCRINT 将返回 #NUM! 错误值。



#### 数据类型

接受数字和DateTime对象数据。 返回数值数据。



#### 示例

ACCRINT(A1,A2,A3,B4,D9,E9,0)

ACCRINT(DATE(2003,1,1),DATE(2003,1,7),DATE(2005,1,7),0.5,1000,2) 结果为 1008.33333
