# DDB

此函数返回指定期间内某项固定资产的折旧值。



#### 语法

DDB( *cost* , *salvage* , *life* , *period* , *factor* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *cost*  | 资产原值。 |
|  *salvage*  | 折旧末尾时的值（有时也称为资产残值）。 |
|  *life*  | 资产的折旧期数（有时也称作资产的使用寿命）。 |
|  *period*  | 您要计算折旧的时期。 Period 必须使用与 life 相同的单位。 |
|  *factor*  | [ 可选] 余额递减速率。 如果省略影响因素，则假定为 2（双倍余额递减法）。 |

所有参数都必须是正数。



#### 注释

DDB 使用下面的公式计算一个阶段的折旧值：

cost – salvage(total depreciation from prior periods) x factor/life



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

DDB(B1,1000,10,1)

DDB(R1C2,10000,10,1)

DDB(500000,5000,5,1,4) 得出结果 $40,0000
