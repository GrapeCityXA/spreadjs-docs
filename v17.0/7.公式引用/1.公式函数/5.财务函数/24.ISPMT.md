# ISPMT

此函数计算付薪（或投资）指定期间内（甚至本金付款）支付的利息（或接收）。



#### 语法

ISPMT( *rate* , *per* , *nper* , *pv* )



#### 注释

该函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *rate*  | 投资的利率。 |
|  *per*  | 要查找其利息的期间，并且必须介于1和 Nper 之间。 |
|  *nper*  | 投资的总支付期数。 |
|  *pv*  | 投资的现值。 |



#### 注释

请确保rate和 Nper的单位保持一致。

对于所有参数，支出的款项，如银行存款或其他取款，以负数表示；收入的款项，如股息支票和其他存款，以正数表示。



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

ISPMT(B1,C4,C5,1)

ISPMT(R1C2,R4C3,R6C3,R7C3)
