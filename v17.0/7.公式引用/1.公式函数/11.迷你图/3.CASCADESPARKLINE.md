# CASCADESPARKLINE

此函数返回用于表示级联迷你图的数据集。



#### 语法

CASCADESPARKLINE( *pointsRange, pointIndex, [labelsRange, minimum, maximum, colorPositive, colorNegative, vertical, itemTypeRange, colorTotal]* )



#### 参数

| 参数 | 描述 |
|--- |--- |
|  *pointsRange*  | 表示包含值的单元格区域的引用，例如“B2:B8”。 |
|  *pointIndex*  | 表示点索引的数字或参考。pointIndex >= 1，例如 1 或“D2”。 |
|  *labelsRange*  | (可选) 表示包含标签的单元格范围的引用，例如“A2:A8”。默认值为无标签。 |
|  *minimum*  | (可选) 表示显示区域最小值的数字或参考。默认值为总和（点值的总和）的最小值，例如 -2000。<br /><br />您设置的最小值必须小于默认最小值；否则，使用默认最小值。<br /><br /> |
|  *maximum*  | (可选) 表示显示区域最大值的数字或参考。默认值为总和的最大值（点值的总和），例如 6000。<br /><br />您设置的最大值必须大于默认最大值；否则，使用默认最大值。<br /><br /> |
|  *colorPositive*  | (可选)表示第一个或最后一个正迷你图框颜色的字符串（该点的值为positive）。默认值为“#8CBF64”。<br /><br />如果第一个或最后一个框表示positive值，则框的颜色设置为 colorPositive。中间的正框设置为比 colorPositive 浅的颜色。<br /><br /> |
|  *colorNegative*  | (可选) 表示第一个或最后一个负迷你迷你图框颜色的字符串（该点的值为negative）。默认值为“#D6604D”。<br /><br />如果第一个或最后一个框表示negative值，则框的颜色设置为 colorNegative。中间的负框设置为比 colorNegative 浅的颜色。<br /><br /> |
|  *vertical*  | (可选)一个布尔值，表示框的方向是垂直还是水平。默认值为FALSE<br /><br />您必须将一组公式的垂直设置为true或false，因为所有公式都代表整个迷你图。<br /><br /> |
|  *itemTypeRange*  | (可选) 表示数据范围的所有项类型的数组或引用。<br /><br />值应为 {"-", "+", "="} 或 "A1:A7" 引用 {"+", "-", "="} 的值，其中 "+" 表示正变化， “-”表示负变化，“=”表示总列。<br /><br /> |
|  *colorTotal*  | (可选)一个字符串，当 itemTypeRange 不存在时表示最后一个迷你图框的颜色，或者当 itemTypeRange 存在时表示生成的迷你图框的颜色。 |



#### 数据类型

返回迷你图。



#### 例子

activeSheet.setFormula(1, 2, '=CASCADESPARKLINE(B2:B8,1,A2:A8,,,"#8CBF64","#D6604D",false)');
