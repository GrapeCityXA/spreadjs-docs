# database-functions

Spread 提供以下数据库函数，按字母顺序列出。

| 函数 | 描述 |
|--- |--- |
| [DAVERAGE](gcdocsite__documentlink?toc-item-id=d36656e2-fd7d-4004-a71c-ce925c86ae88) | 此函数计算列表或数据库列中与指定条件匹配的值的平均值。 |
| [DCOUNT](gcdocsite__documentlink?toc-item-id=35b07627-72ac-4216-a1ae-42bf317fea86) | 此函数计算列表或数据库列中包含与指定条件匹配的数字的单元格。 |
| [DCOUNTA](gcdocsite__documentlink?toc-item-id=fcb9550f-1a83-4d6f-a3c9-94bfdb8b4407) | 此函数计算列表或数据库中符合指定条件的列中的非空白单元格。 |
| [DGET](gcdocsite__documentlink?toc-item-id=35436a32-d974-45a2-a0d4-3534eef73a3d) | 此函数从与指定条件匹配的列表或数据库的列中提取单个值。 |
| [DMAX](gcdocsite__documentlink?toc-item-id=843bcaa6-c1bd-4fd3-8341-74c243e53a37) | 此函数返回列表或数据库列中与指定条件匹配的最大数字。 |
| [DMIN](gcdocsite__documentlink?toc-item-id=601b2d18-16b1-4063-9cf1-629853610841) | 此函数返回列表或数据库列中与指定条件匹配的最小数字。 |
| [DPRODUCT](gcdocsite__documentlink?toc-item-id=e3cbec1a-29d8-4b75-8575-02332184847b) | 此函数将列表或数据库中与指定条件匹配的列中的值相乘。 |
| [DSTDEV](gcdocsite__documentlink?toc-item-id=b5110c78-12c3-40b4-ba59-c661d2a33a9e) | 此函数通过使用与指定条件匹配的列表或数据库列中的数字来估计基于样本的总体的标准偏差。 |
| [DSTDEVP](gcdocsite__documentlink?toc-item-id=da10f38f-b98b-40f4-8ec7-8f840dba041d) | 此函数使用与指定条件匹配的列表或数据库列中的数字，基于整个总体计算总体的标准差。 |
| [DSUM](gcdocsite__documentlink?toc-item-id=30005e19-32ca-419a-9216-c4a5d9e90682) | 此函数在列表或数据库的列中添加与指定条件匹配的数字。 |
| [DVAR](gcdocsite__documentlink?toc-item-id=d4ff48bd-13bf-4b18-8886-bd0545167a27) | 此函数通过使用列表或数据库中与指定条件匹配的列中的数字来估计基于样本的总体方差。 |
| [DVARP](gcdocsite__documentlink?toc-item-id=b61a85df-8374-4f79-90cc-6d7c3ddc9d19) | 此函数通过使用列表或数据库中与指定条件匹配的列中的数字，基于整个总体计算总体的方差。 |
