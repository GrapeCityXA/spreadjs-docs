# IF

此函数执行比较，并基于该比较返回两个比较值之一。



#### 语法

IF( *valueTest* , *valueTrue* , *valueFalse* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *valueTest*  | 要比较的值或表达式 |
|  *valueTrue*  | 比较结果为true时返回的值。 |
|  *valueFalse*  | 比较结果为flase时返回的值。 |



#### 注释

计算valueTest的值，如果为非零（或TRUE），则返回valueTrue。如果为零（或FALSE），则返回valueFalse。 valueTest的值可以包含关系运算符之一：大于（>），小于（<），等于（=）或不等于（<>）。



#### 数据类型

接受数字（布尔）数据。返回任何数据类型。



#### 示例

IF(A3<>2000,1900,2000)

IF(R1C2>65,1000,2000)

IF(C4,B2,B4)

IF(1>2,5,10) 得出结果 10

IF(1<2,""dogs"",""cats"") 得出结果 dogs
