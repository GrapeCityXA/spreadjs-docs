# lambda-function

此函数允许创建和命名可像任何其他函数一样调用的自定义可重用函数。



#### 语法

=LAMBDA([parameter1, parameter2, …,], calculation)



#### 参数列表

LAMBDA函数有如下参数：

| 参数名 | 描述 |
|--- |--- |
|  *parameter*  | [可选]传递给函数的值，例如单元格引用、字符串或数字。 最多可以输入253个参数值。 |
|  *calculation*  | [必选]要执行并作为函数结果返回的公式。它必须是最后一个参数，并且必须返回一个结果。 |



#### 说明

- 如果向 LAMBDA 函数提供的参数数量不正确或超过 253 个，则返回 #VALUE！ 错误。
- 如果将错误数量的参数传递给 LAMBDA 函数,则返回 #VALUE！ 错误。
- 如果从自身内部调用 LAMBDA 函数并且调用是循环的，则返回 #NUM！ 错误。
- 如果在单元格中创建 LAMBDA 函数而不在单元格中调用它，则返回 #CALC！ 错误。

如果 lambda 函数是递归的，那么最大递归深度与浏览器有关。
> **提示:** 如果 lambda 函数是递归的，那么最大递归深度与浏览器有关。 


#### 数据类型

简洁格式返回一个文本值，而严格格式返回一个与输入相同大小和形状的数组类型。



#### 示例

以下示例代码显示了 LAMBDA 函数的基本用法。


```JavaScript
//LAMBDA 函数使用一个参数时的基本用法
sheet.setValue(1, 1, "Converted Temp");
spread.addCustomName('ToCelsius', 'LAMBDA(temp, (5/9) * (temp-32))');
sheet.setFormula(2, 1, 'ToCelsius(104)'); // result is 40
            
//LAMBDA 函数使用两个参数时的基本用法
sheet.setValue(1, 3, "Calculated Hypotenuse");
spread.addCustomName('Hypotenuse', 'LAMBDA(a, b, SQRT((a^2+b^2)))');
sheet.setFormula(2, 3, 'Hypotenuse(3, 4)'); // result is 5
```
