# webservice

此函数从 Internet 或 Intranet 上的 Web 服务返回数据。



#### 语法

WEBSERVICE( *url* )



#### 参数

此函数具有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *url*  | [必需] 要调用的 Web 服务的 URL。 |



#### 备注：

该功能支持HTTP（http和https）协议。在从服务返回结果之前，SpreadJS 返回“”作为默认值。只有在响应结果为字符串类型时才显示正确的结果。如果使用其他格式，如图像、音频、视频，则返回不可读的代码。

以下场景该函数返回一个#VALUE！错误：

- 如果返回的 URL 是超过 2048 个字符的字符串。
- 如果请求时间超过 10 秒。
- 如果请求不遵循同源策略并且目标网站不支持来自源源的 CORS（跨源资源共享），则在浏览器上。在这种情况下，浏览器会在控制台而不是 SpreadJS 上打印 CORS 错误。
- 如果使用 FTP 或 FILE 协议。



#### 数据类型

此函数接受并返回字符串数据。



#### 示例

WEBSERVICE("https://restcountries.eu/rest/v2/all")

WEBSERVICE("https://jsonplaceholder.typicode.com/users")

WEBSERVICE("https://www.google.com")
