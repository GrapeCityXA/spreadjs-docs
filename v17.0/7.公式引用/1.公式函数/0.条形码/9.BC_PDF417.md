# BC_PDF417

该函数返回一个代表 CODE93 的数据集。PDF417.



#### 语法

BC_PDF417( *value, color, backgroudColor, errorCorrectionLevel, rows, columns, compact, quietZoneLeft, quietZoneRight, quietZoneTop, quietZoneBottom* )



#### 参数

| 参数 | 描述 |
|--- |--- |
|  *value*  | 表示二维码符号上的编码的字符串。 |
|  *color*  | 表示条形码颜色的颜色。默认值为 'rgb(0,0,0)'。 |
|  *backgroundColor*  | 表示条形码背景颜色的颜色。默认值为 'rgb(255, 255, 255)' |
|  *errorCorrectionLevel*  | 一个字符串，表示 PDF417 的纠错级别。它具有“自动|0-8”值。默认值为'auto'. |
|  *rows*  | 一个值，它指定符号中的行数。它具有'auto|3-90' 值。默认值为'auto'. |
|  *columns*  | 一个值，它指定符号中的列数。它具有'auto|1-30' 。默认值为'auto'. |
|  *compact*  | 指定它是否是紧凑的 PDF417。默认值为'false'. |
|  *quietZoneLeft*  | 表示左静区大小的值。 |
|  *quietZoneRight*  | 表示右静区大小的值。 |
|  *quietZoneTop*  | 表示顶部静区大小的值。 |
|  *quietZoneBottom*  | 表示底部静区大小的值。 |



#### 数据类型

接受 35 个字母数字字符和 2710 个数字字符。返回条形码迷你图。



#### 例子

sheet.setFormula(3, 3, '=BC_PDF417(C4)');
