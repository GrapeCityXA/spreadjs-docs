# BC_EAN8

该函数返回一个代表 CODE93 的数据集。EAN8.



#### 语法

BC_EAN8( *value, color, backgroundColor, showLabel, labelPosition, fontFamily, fontStyle, fontWeight, fontTextDecoration, fontTextAlign, fontSize, quietZoneLeft, quietZoneRight, quietZoneTop, quietZoneBottom* )



#### 参数

| 参数 | 描述 |
|--- |--- |
|  *value*  | 指定值长度必须为 7 或 8。 |
|  *color*  | 表示条形码颜色的颜色。默认值为 'rgb(0,0,0)'。 |
|  *backgroundColor*  | 表示条形码背景颜色的颜色。默认值为 'rgb(255, 255, 255)' |
|  *showLabel*  | 指定条形码有标签时是否显示标签文本。 |
|  *labelPosition*  | A value that represents the label position when the label is shown. |
|  *fontFamily*  | 表示标签文本 fontFamily 的字符串。默认值为'sans-serif'. |
|  *fontStyle*  | 表示标签文本 fontStyle 的字符串。默认值为'normal'. |
|  *fontWeight*  | 表示标签文本 fontWeight 的字符串。默认值为'normal'. |
|  *fontTextDecoration*  | 表示标签文本 fontTextDecoration 的字符串。默认值为'none'. |
|  *fontTextAlign*  | 表示标签文本 fontTextAlign 的字符串。默认值为'center'. |
|  *fontSize*  | 表示标签文本 fontSize 的字符串。默认值为'12px'. |
|  *quietZoneLeft*  | 表示左静区大小的值。 |
|  *quietZoneRight*  | 表示右静区大小的值。 |
|  *quietZoneTop*  | 表示顶部静区大小的值。 |
|  *quietZoneBottom*  | 表示底部静区大小的值。 |



#### 数据类型

仅接受七个数字作为字符串来计算校验位。返回条形码迷你图。



#### 例子

sheet.setFormula(3, 3, '=BC_EAN8(C4)');
