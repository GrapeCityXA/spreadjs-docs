# BC_QRCODE

该函数返回一个代表 CODE93 的数据集。QRCode.



#### 语法

BC_QRCODE( *value, color, backgroundColor, errorCorrectionLevel, model, version, mask, connection, connectionNo, charCode, charset, quietZoneLeft, quietZoneRight, quietZoneTop, quietZoneBottom* )



#### 参数

| 参数 | 描述 |
|--- |--- |
|  *value *  | 表示二维码符号上的编码的字符串。 |
|  *color*  | 表示条形码颜色的颜色。默认值为 'rgb(0,0,0)'。 |
|  *backgroundColor*  | 表示条形码背景颜色的颜色。默认值为 'rgb(255, 255, 255)' |
|  *errorCorrectionLevel*  | 表示二维码纠错级别的字符串。它具有'L|M|Q|H'四个纠错级别。默认值为 'L'. |
|  *model*  | 代表二维码模型的值。它有 1 个和 2 个模型。默认值为 2. |
|  *version *  | 模型 1 和模型 2 的版本范围是 1-14。它具有'auto|1-14|1-40'值。默认值为'auto'. |
|  *mask *  | 表示 QRCode 的掩码模式的值。它具有'auto and 0-7' 八个掩码模式 |
|  *connection*  | 一个值，表示符号是否是结构化附加消息的一部分。默认值为false. |
|  *connectionNo*  | 指定符号在结构化附加消息中的哪个块。它具有'0-15' 。默认值为'0'. |
|  *charCode*  | 代表二维码字符集合的值。 |
|  *charset*  | 一个值，表示要使用的字符集。它具有'UTF-8 和 Shift-JIS'. |
|  *quietZoneLeft *  | 表示左静区大小的值。 |
|  *quietZoneRight *  | 表示右静区大小的值。 |
|  *quietZoneTop *  | 表示顶部静区大小的值。 |
|  *quietZoneBottom  *  | 表示底部静区大小的值。 |



#### 数据类型

接受数字字符和字母数字字符。返回条形码迷你图。



#### 例子

sheet.setFormula(3, 3, '=BC_QRCODE(C4)');
