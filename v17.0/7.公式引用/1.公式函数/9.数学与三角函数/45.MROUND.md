# MROUND

此函数返回一个舍入到所需倍数的数字。



#### 语法

MROUND( *number* , *multiple* )



#### 参数

该函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *number*  | 要舍入的值。 |
|  *multiple*  | 要舍入到的倍数。 |



#### 注释

如果数值 number 除以基数的余数大于或等于基数的一半，则函数 MROUND 向远离零的方向舍入。



#### 数据类型

接受两个参数的数值数据。返回数值数据。



#### 示例

MROUND(B14,3)

MROUND(R14C2,5)

MROUND(100,8) 得出结果 104

MROUND (11,8) 得出结果 8

MROUND (12,8) 得出结果 16

MROUND (13,8) 得出结果 16

MROUND (-12,-8) 得出结果 -16

MROUND (50,8) 得出结果 48

MROUND (-50,-8) 得出结果 -48
