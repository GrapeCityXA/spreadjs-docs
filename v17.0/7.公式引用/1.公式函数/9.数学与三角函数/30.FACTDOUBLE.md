# FACTDOUBLE

此函数返回数字的双倍阶乘。



#### 语法

FACTDOUBLE( *number* )



#### 参数

为其返回双倍阶乘的值。



#### 注释

number必须为非负数值。 如果 number 不是整数，将被截尾取整。

如果参数 Number 为偶数：

n!! = n(n-2)(n-4) ... (4)(2)

如果参数 Number 为奇数：

n!! = n(n-2)(n-4) ... (3)(1)



#### 数据类型

接受数值数据。返回数值数据。



#### 示例

FACTDOUBLE(E3)

FACTDOUBLE(R3C5)

FACTDOUBLE(6) 得出结果 48
