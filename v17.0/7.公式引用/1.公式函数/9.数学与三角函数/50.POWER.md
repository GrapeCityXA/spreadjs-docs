# POWER

此函数返回数字乘幂的结果。



#### 语法

POWER( *number* , *power* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *number*  | 基数。 可为任意实数。 |
|  *power*  | 基数乘幂运算的指数。 |



#### 注释

可以使用“^”代替 POWER，以表示基数乘幂运算的幂，例如 5^2。



#### 数据类型

接受两个参数的数值数据。返回数值数据。



#### 示例

POWER(A3,B4)

POWER(R1C2,3)

POWER(16,3) 得出结果 4096
