# SheetRefFormula

公式可以引用同一表单上的单元格或其他表单上的单元格，以及表单上单元格的范围。

在下面显示的示例中，我们为单元格引用使用A1（字母数字）表示法，但对于R1C1（数字编号）表示法同样有效。 不论样式如何，只要在单元格引用之前加上表单名称即可，如此处所述。

当对单元格的引用包括对另一张表单上单元格的引用时，这称为跨表单引用。

使用加法运算符的公式中的跨表格引用示例如下：

(FirstRoundData!A2 + SecondRoundData!A2)

其中一个表单的名称为“ FirstRoundData”，另一表单的名称为“ SecondRoundData”。 表单名称位于单元格引用的前面，表单名称后跟一个感叹号（！）。 该公式可以在Spread中的任何表单上，因为它明确地将每个单元格的表单命名为操作数。 本示例将值添加到两个不同的表单中的单元格A2中。 通过使表单名称明确，就不会混淆哪个单元格A2。 如果不包括表单名称，则使用当前表单（其中存在该公式）。 如果以上示例中的公式位于SecondRoundData页面上，则该公式可以写为：

(FirstRoundData!A2 + A2)

将单元格放在当前页面的第一位可能会比较容易混淆，如下所示：

(A2 + FirstRoundData!A2)

只要表单名称符合常规变量名规则（第一个字符为字母或下划线，其余字符为字母，数字或下划线），则公式可以仅使用表单名称，后跟感叹号。 否则，表单名称需要用单引号引起来。 如果表单名称本身包含单引号，则在公式中使用两个单引号。 例如，如果表单的名称在给定月份的销售这些名称中包含单引号（或单引号），则对表单的引用在公式中将如下所示：

('November''s Sales'!A2 + 'December''s Sales'!A2)



('East Coast Sales'!A2 + 'West Coast Sales'!A1)

如果表单名称中有引号，则需要添加该语言所需的定界符。 例如，在C＃中，如果表单名称为“ Zippy” Sales（引号是表单名称的一部分），则包含对该表单的引用的公式可能如下所示：

('/"Zippy/" Sales'!A2 + 'West Coast Sales'!A1)

单引号括住整个表单名称，反斜杠（/）分隔符位于引号之前。 对于Visual Basic，您将使用两个双引号字符，如下所示：

('""Zippy"" Sales'!A2 + 'West Coast Sales'!A1)

对于跨页引用另一页中的单元格区域，请在该范围之前添加表单名称。 例如：

SUM(SecondRoundData!A2:A10)

这会将值添加到名为SecondRoundData的表单的单元格A2到A10中。 由于单元格位于同一张纸上，因此没有理由在范围参考的后半部分中包含纸名。 您不能在一个范围内指定两个不同的图纸； 单元格的范围仅在特定的表单上，而不在表单之间。
