# operatorsinaformula

下表列出了可用的运算符。 对于每个运算符，给出了一个使用文字值以及单元格引用的语法的示例。 对于每种类型的运算符，都给出了返回值的类型。

| 运算符类型 | 语法范例 | 结果 |
|--- |--- |--- |
| 运算符 | 描述 | Literal & Literal | Cell Ref & Literal | 返回类型 |
| 二元运算符 |
| + | Add | 5 + 3 | A1 + 3 | double |
| – | Subtract | 5 – 3 | A1 – 3 | double |
| * | Multiply | 5 * 3 | A1 * 3 | double |
| / | Divide | 5 / 3 | A1 / 3 | double |
| ^ | Exponent | 5 ^ 3 | A1 ^ 3 | double |
| & | Concatenate | "F" & "p" | A1 & "p" | string |
| = | Equal |  | A1 <> 3 | boolean |
| < > | Not Equal |  | A1 = 3 | boolean |
| < | Less Than |  | A1 <3 | boolean |
| > | Greater Than |  | A1 > 3 | boolean |
| <= | Less Than Or Equal |  | A1 <= 3 | boolean |
| >= | Greater Than Or Equal |  | A1 >= 3 | boolean |
| 一元运算符 |
| - | Negate | -(5/3) | -(A1/3) | double |
| + | Plus | +(5/3) | +(A1/3) | double |
| % | Percent | (5/3)% | (A1/3)% | double |

运算符指定要对公式的元素执行的计算类型。 大多数运算符为数学运算返回双精度浮点值，为比较运算符返回布尔（或逻辑）值。

在SpreadJS中，所有算术运算符（包括一元+）都会检查其参数，如果任何参数是无法转换为数字的字符串，则返回#VALUE错误。 这是数学上正确的行为，不能被覆盖。 例如，三个公式+B5和0 +B5和--B5都应产生相同的结果，并且在SpreadJS中，它们确实可以产生相同的结果。

有关运算符的更多信息，请参见[优先顺序](gcdocsite__documentlink?toc-item-id=605bbe82-a009-4cc1-8d46-4a919f9c1050)与[带有日期和时间的运算符](gcdocsite__documentlink?toc-item-id=5a7c474e-d2b7-44c6-b415-1fe19d08b666)。
