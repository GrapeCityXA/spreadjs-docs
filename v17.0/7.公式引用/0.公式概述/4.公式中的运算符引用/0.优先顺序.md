# orderofprecedence

当公式中有多个运算符时，该公式将按特定顺序执行操作。 根据公式中每个运算符或函数的特定顺序，从左到右解析该公式。 您可以通过在公式中使用括号来区分操作顺序的优先级。

如果将多个运算符组合在一个公式中，则将按照下表所示的顺序执行这些运算。 一元运算先于二进制运算。 如果公式包含具有相同优先级的运算符，则会从左到右计算运算符。 要变更计算顺序，请将要计算的公式部分首先用括号括起来； 这是最高优先级。 如果两个运算符的优先顺序相同，则从左到右计算公式。

| 优先顺序从最高到最低 |
|--- |
|
| 从左到右 | 描述 |
| ( ) | 括号（用于分组） |
| – | 负号 |
| + | 加号 |
| % | 百分号 |
| ^ | 指数 |
| * and / | 乘和除 |
| + and - | 加和减 |
| & | 组成瀑布 |
| =, <, >, <=, >=, <> | 比较 |
