# excelsheetex

下表总结了SpreadJS导出到Excel格式的文件时如何处理表单设置。 除非另有说明，否则这些函数在GC.Spread.Sheets.Worksheet类中。

|  **Sheet 设置**  |  **Excel 设置与备注**  |
|--- |--- |
| name | Excel使用此设置。 |
| defaults : rowHeight, columnWidth,<br />columnHeaderRowHeight, rowHeaderColumnWidth | Excel仅使用default.colWidth设置，但将其他设置加载到列或行标题。 |
| columns | Excel使用此设置。 |
| rows | Excel使用此设置。 |
| autoGenerateColumns | Excel忽略表单设置。 这特定于SpreadJS。 |
| dataSource | Excel忽略表单设置。 这特定于SpreadJS。 |
| frozenRowCount or frozenColumnCount | Excel使用此设置。 |
| frozenTrailingRowCount or frozenTrailingColumnCount | Excel忽略表单设置。 这特定于SpreadJS。 |
| rowCount | Excel忽略表单设置。 这特定于SpreadJS。 |
| columnCount | Excel忽略表单设置。 这特定于SpreadJS。 |
| data | Excel loads the data from SpreadJS. |
| sparkline | Excel使用此设置。 |
| spans | Excel使用此设置。 |
| selections | Excel使用此设置。 |
| selectionBackColor | Excel忽略表单设置。 这特定于SpreadJS。 |
| selectionBorderColor | Excel忽略表单设置。 这特定于SpreadJS。 |
| activeRowIndex | Excel使用此设置。 |
| activeColumnIndex | Excel使用此设置。 |
| gridline | Excel使用此设置，但是如果垂直或水平网格线是隐藏的，则两者都将在Excel中导出为隐藏状态。 |
| allowCellOverflow | Excel忽略表单设置。 allowExcelOverflow在Excel中始终为true。 |
| zoomFactor | Excel使用此设置。 |
| theme | Excel将第一个表单主题用作当前主题，并忽略其他表单主题设置。 |
| showRowOutline or showColumnOutline | Excel忽略表单设置。 Excel使用显示的区域组。 |
| rowOutlines or columnOutlines | Excel使用此设置。 |
| rowFilter | Excel使用此设置。 |
| conditional formats | Excel使用此设置。 |
| sheetTabColor | Excel使用此设置。 |
| frozenlineColor | Excel忽略表单设置。 这特定于SpreadJS。 |
| rowHeaderAutoText(Index) or colHeaderAutoText(Index) | Excel忽略表单设置。 这特定于SpreadJS。 |
| rowHeaderVisible or colHeaderVisible | Excel使用此设置。 |
| row header column count | Excel忽略表单设置。 这特定于SpreadJS。 |
| column header row count | Excel忽略表单设置。 这特定于SpreadJS。 |
| clipboardOptions | Excel忽略表单设置。 这特定于SpreadJS。 |
| isProtected | Excel使用此设置。 |
| borderColor | Excel忽略表单设置。 这特定于SpreadJS。 |
| borderWidth | Excel忽略表单设置。 这特定于SpreadJS。 |
| table | Excel使用此设置。 |
| named styles | Excel使用此设置。 |
