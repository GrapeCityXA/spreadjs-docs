# excelformimp

下表总结了SpreadJS从Excel文件导入数据时如何处理与公式相关的单元格设置。

|  **Excel 设置**  |  **SpreadJS 设置**  |  **备注**  |
|--- |--- |--- |
| 单元格引用 |  | SpreadJS从Excel导入这些作为公式的一部分。 请参阅此表中的公式注释。 |
| 单元格参考样式 |  | 如果Excel的参考样式为R1C1，则当Spread导入表单时，Sheet.setColumnHeaderAutoTest函数将设置为1（显示数字）。 请参阅此表中的公式注释。 |
| 公式 |  | 公式从Excel导入SpreadJS。 当导入遇到包含公式或函数的单元格时，SpreadJS中的相应单元格将设置为适当的单元格类型。 如果导入遇到具有不支持的公式的单元格，则该单元格可能留空或给出错误值。 |
| 运算符 |  | SpreadJS导入Excel运算符。 请参阅此表中的公式注释。 |
| 函数 |  | SpreadJS支持Excel中提供的许多功能。 如果导入遇到具有其不支持的功能的单元格，则该单元格可能会留空或使用#NAME？ 错误值。 请参阅此表中的公式注释。 |
