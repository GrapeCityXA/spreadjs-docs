# LocalebasedDateFormatImported

SpreadJS 允许您在导入 Excel 文件时根据系统区域设置自定义日期格式。

例如，在 EN 文化中导入日期格式为 dd/mm/yyyy 的 Excel 文件时，日期格式在 SpreadJS 中显示为 dd/mm/yyyy。但是当以法语文化导入相同的Excel文件时，日期格式在SpreadJS中显示为yyyy-MM-dd，因为它是法语中的默认日期格式。法国文化的默认数字格式 ID 为 14。您可以将默认数字格式 ID 设置为任何其他数字格式，例如：{14: yyyy-Md} 以显示自定义日期格式。

在将 Excel 文件导入到SpreadJS中之前，可以使用LocalNumberFormat字段将自定义日期格式指定为默认数字格式 ID 。

可以使用以下步骤设置自定义日期格式：

- 获取[ Excel 内置数字格式](https://docs.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.numberingformat?view=openxml-2.8.1).
- 创建新的文化信息并将 Excel 数字格式设置为自定义格式。
- 将文化信息设置为文化管理器。
- 导入 Excel 文件。

下面的示例演示了如何将自定义日期格式设置为法语文化的默认数字格式 ID。


```JavaScript
// 初始化Spread
var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });
// 获取工作表
var sheet = spread.sheets[0];
var excelIO = new GC.Spread.Excel.IO();
$("#button1").click(function () {
    spread.suspendPaint();
    //创建新的文化信息
    var culture = new GC.Spread.Common.CultureInfo();
    culture.LocalNumberFormat = {
       14: "yyyy/m/d"
    };
    // 设置文化信息到文化管理器
    GC.Spread.Common.CultureManager.addCultureInfo("fr", culture);
    GC.Spread.Common.CultureManager.culture("fr");
    // 导入 Excel 文件
    var excelFile = document.getElementById("fileDemo").files[0];
    excelIO.open(excelFile, function (json) {
        var workbookObj = json;
        spread.fromJSON(workbookObj);
    }, function (e) {
        console.log(e);
    });
    spread.resumePaint();
```
