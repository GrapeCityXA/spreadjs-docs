# excelwbimp

下表总结了SpreadJS从Excel格式的文件中导入数据时如何处理工作簿设置。

|  **Excel 设置**  |  **SpreadJS 设置**  |  **备注**  |
|--- |--- |--- |
| Password-protected files | Excel IO options | SpreadJS可以打开受密码保护的文件（在Excel IO导入API服务中指定密码设置）。 |
| NamedStyles | Spread.addNamedStyle | Excel文件中的命名样式将导入SpreadJS。 |
| ActiveSheetIndex | Spread.setActiveSheetIndex | SpreadJS从Excel导入设置。 |
| ReferenceStyle | Spread. **referenceStyle**  | SpreadJS从Excel选项导入设置。 |
| StartSheetIndex | Spread.startSheetIndex | SpreadJS从Excel导入设置。 |
| SheetCount | SpreadJS.length | SpreadJS从Excel导入设置。 |
| Scroll bar | Spread. **showHorizontalScrollbar** or Spread. **showVerticalScrollbar**  | SpreadJS从Excel选项导入设置。 |
| Show sheet tabs | Spread. **tabStripVisible**  | SpreadJS从Excel选项导入设置。 |
