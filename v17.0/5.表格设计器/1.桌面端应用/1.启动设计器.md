# spdesignerstart

要运行Spread Designer，请双击Designer文件夹中的 **Spread.SheetsDesigner.exe** 文件。

打开SpreadJS设计器后，您可以使用可用的菜单选项来编辑提供的表单。 有关更多信息，请参见[在设计器中工作](gcdocsite__documentlink?toc-item-id=dd2bd832-e49f-40d4-ac00-f38d39372c65)。 如果要打开现有的文件表单文件，请按照[打开并保存文件](gcdocsite__documentlink?toc-item-id=7b2665d3-90dd-4b83-bb24-95bc9641cb37)中的说明将其打开。 您可以打开现有的Excel格式（.xlsx），逗号分隔（.csv）和传播文件（.ssjson）文件。

如果您想了解有关设计器中可用选项卡的更多信息，请参见[ SpreadJS设计器选项卡](gcdocsite__documentlink?toc-item-id=b3ba7488-3d02-4403-a3fc-28298d5d2ba3)。 有关设计器界面中可用菜单的更多信息，请参见[ SpreadJS设计器界面菜单](gcdocsite__documentlink?toc-item-id=c7272fb8-18b0-4217-a7ce-48cd076592c3)。
