# print-designer

SpreadJS表格编辑器提供了一个打印菜单，可以让用户预览和打印包含所需信息的工作表或工作簿的全部或部分内容。 用户可以使用所有可用的打印设置，进行设置并控制打印的内容。 打印菜单在与新建、导入、导出选项相同的“文件”窗口中访问。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/designer-print.png)



打印菜单中提供以下功能：

| 功能 | 描述 |
|--- |--- |
| 打印预览 | 此区域（在右列）预览页面和打印前应用的所有设置。 |
| 打印按钮 | 单击打印按钮时会弹出浏览器打印对话框。 对话框中的内容基于打印区域。 |
| 设置 |
| 打印区 | 包含可供选择打印的工作簿区域的下拉列表。<br /><br /> |
| 页面开始 | 设置起始页。<br /><br />默认值和最小值为 1。如果设置值非法，则值为 1。<br /><br /> |
| 页面结束 | 设置最后一页。<br /><br />默认值为打印页数。 如果设置值非法，则值为 1。<br /><br /> |
| 页面方向 | 将页面方向设置为横向或纵向。<br /><br />默认情况下，工作表以纵向打印（高而不是宽）。<br /><br /> |
| 页面大小 | 设置纸张尺寸。<br /><br />默认值为字母 (8.5'' x 11'')。<br /><br /> |
| 边距 | 设置打印区域的边距大小。<br /><br />从提供的常用格式中进行选择或创建自定义格式。<br /><br /> |
| 缩放 | 相应地设置所选打印区域的比例以适合数据。<br /><br />默认情况下，不应用缩放，因此工作表以实际大小打印。<br /><br /> |

打印具有大图像的纸张可能会花费大量时间。 所以当打印内容图片较多或图片较大时，页面预览加载缓慢属于正常现象。
> **提示:** 打印具有大图像的纸张可能会花费大量时间。 所以当打印内容图片较多或图片较大时，页面预览加载缓慢属于正常现象。 
打印菜单由左栏部分末尾的“页面设置”选项组成，该选项打开一个对话窗口。 此“页面设置”窗口扩展了上面讨论的功能以及更多功能。 要了解更多信息，请参阅[页面设置](gcdocsite__documentlink?toc-item-id=3aecd0d9-be47-48e8-a705-bee66097cfbd)。
