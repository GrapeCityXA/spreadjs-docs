# tablesheet-designer

SpreadJS设计器提供了在工作簿中添加TableSheet的功能。 “TableSheet” 功能区按钮可以在“插入”>“表格”选项卡组中找到。单击功能区按钮会在打开的工作簿中添加一个TableSheet页。并激活TableSheet设计选项卡。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-designer-intro.gif)

您可以创建数据源，首先单击“数据”>“数据绑定”选项卡组中的“数据源”功能区按钮。出现 DataSource 选项卡，您可以在其中添加表并为 CRUD（创建、读取、更新和删除）功能设置远程 URL。您也可以通过“列”选项卡获取表数据。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-designer-data.gif)

您可以单击列项以通过设置其属性、架构类型或添加关系来显示或编辑列项。也可以通过单击列表末尾的“添加计算列”来添加计算列。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-designer-column.gif)

在设计器中添加数据源后，用户现在可以通过设计器的TableSheet面板将表格数据源绑定到TableSheet中。通过“绑定表”下拉菜单选择现有的表数据源或创建新的表数据源。TableSheet 视图将加载到以前的空白区域。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-designer-bind.gif)

TableSheet字段区域和组区域的工作方式与其运行时对应项相同。要了解更多信息，请参阅[TableSheet 组件](gcdocsite__documentlink?toc-item-id=f58b8103-d578-42b7-9a3a-0603567c1be9).

DataSource sheet不会导出到 SSJSON 或 Excel 文件，但带有table 选项的 DataSource tables包含在 SSJSON 中。
> **Note:** DataSource sheet不会导出到 SSJSON 或 Excel 文件，但带有table 选项的 DataSource tables包含在 SSJSON 中。
