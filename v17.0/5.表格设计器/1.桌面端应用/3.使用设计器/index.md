# spdesignerwork

SpreadJS Designer提供了一种用于自定义表单的WYSIWYG环境。 您可以使用设计器中的菜单选项为单元格，列，行和表单以及整个表单指定设置。

在此图中，用户正在设置表单的网格线颜色。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/spdesigner_setting_stuff.png)

请注意以下有关在设计器中工作的信息：

- 如果选择换行，除非用户通过按Alt + Enter插入换行符，否则文本不会换行。
- 在设计器中编辑或创建表单之后，可以保存或导出表单，然后稍后在设计器中重新打开它，或者让SpreadJS小部件将其加载到应用程序中。 有关在设计器中保存和打开文件的信息，请参见[打开和保存文件](gcdocsite__documentlink?toc-item-id=7b2665d3-90dd-4b83-bb24-95bc9641cb37)。
- 如果希望在设计器中使用自动功能，请参见[自动求和函数](gcdocsite__documentlink?toc-item-id=d89c1b83-4e2b-48ac-bf29-eaef0fe5731d)。
