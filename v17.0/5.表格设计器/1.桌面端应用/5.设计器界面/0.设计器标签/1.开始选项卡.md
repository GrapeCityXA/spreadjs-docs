# spdesignhometab

 **Home** 标签允许你在表单中剪切，复制，粘贴，设置格式，设置条件格式。你也可以添加表格或者格式化表格，对表格进行排序，筛选和搜索。

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/hometab.png)

下表列出了 **Home** 标签的各个区域和选项；

|  **区域**  |  **描述**  |
|--- |--- |
|  **Clipboard**  | 提供了剪切，复制和粘贴操作。 |
|  **Fonts**  | 提供了关于单元格文字的选项比如字形，文字颜色，和文字大小。 |
|  **Alignment**  | 提供了单元格文字对齐，自动折行，合并单元格等操作。 |
|  **CellType**  | 提供了 CellType 相关的操作。 |
|  **Styles**  | 提供了单元格样式，表格样式和条件格式相关的操作。 |
|  **Cells**  | 提供了插入，删除，隐藏行和列，设置列宽，设置行高，锁定单元格的操作。 |
|  **Editing**  | 提供了自动填充，清除数据和格式，排序，筛选和搜索的操作。 |

点击右下角的箭头，即可弹出 **Format Cells** 对话框。
