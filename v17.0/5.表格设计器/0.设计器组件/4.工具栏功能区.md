# designer-toolbar-ribbon

组件版设计器提供了两种不同的功能区模式，如下所示：

 **默认功能区模式** 

 **工具栏功能区模式** 

工具栏功能区模式对移动设备特别有用。



### 切换到工具栏功能区模式

SpreadJS 设计器组件以默认功能区模式启动。但是，您可以按[快速入门](gcdocsite__documentlink?toc-item-id=f5fcc86f-418a-4f58-a087-6dc8bc83186b)中的步骤，通过在[setConfig](SpreadJSDesigner~GC.Spread.Sheets.Designer.Designer~setConfig)方法中设置[GC.Spread.Sheets.Designer.ToolbarModeConfig](SpreadJSDesigner~GC.Spread.Sheets.Designer.ToolBarModeConfig)来切换到工具栏功能区模式， 如下所示。


```JavaScript
// 使用默认功能区模式初始化设计器组件
var designer = new GC.Spread.Sheets.Designer.Designer(document.getElementById('gc-designer-host'));

// 切换到工具栏功能区模式
designer.setConfig(GC.Spread.Sheets.Designer.ToolBarModeConfig);
```



### 在默认和工具栏功能区模式之间切换

以下示例显示了如何在默认功能区模式和工具栏功能区模式之间切换。


```JavaScript
var switchConfig = true;

window.onload = function () {
    var designer = new GC.Spread.Sheets.Designer.Designer(designer_host);
    document.getElementById('btn').addEventListener('click', function () {
        designer.setConfig(switchConfig ? GC.Spread.Sheets.Designer.ToolBarModeConfig : GC.Spread.Sheets.Designer.DefaultConfig);
        switchConfig = !switchConfig;
    });
}

// 给页面添加一个按钮控件
<input type="button" id="btn" value="Switch Mode"/>
```

### 在工具栏模式下设置功能区高度

您可以使用工具栏配置中的ribbonHeight选项在工具栏模式下设置功能区高度。工具栏模式的ribbonHeight默认和推荐值为50。

以下代码示例将功能区高度设置为 80。


```JavaScript
var designer = new GC.Spread.Sheets.Designer.Designer(document.getElementById("designerHost"));
var config = GC.Spread.Sheets.Designer.ToolBarModeConfig;

// 设置功能区高度
config.ribbon.ribbonHeight = 80;

// 设置自定义配置
designer.setConfig(config);
```

将生成以下输出：

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/designer-toolbarmode-ribbonheight.png)


> **注意:** 默认功能区模式的推荐功能区高度为 115 或未定义。要保留工具栏功能区模式，ribbonHeight应设置为小于 115。<br /><br />
