# designer-vue

您可以执行以下步骤在 Vue 应用程序中添加 SpreadJS 组件版设计器:

## Vue 3

<span style="color: rgb(34, 34, 34); font-family: Trebuchet MS, Tahoma, Verdana, Arial, sans-serif; font-size: 16px; font-style: normal; font-variant-ligatures: normal; font-variant-caps: normal; font-weight: 400; letter-spacing: normal; orphans: 2; text-align: left; text-indent: 0px; text-transform: none; white-space: normal; widows: 2; word-spacing: 0px; -webkit-text-stroke-width: 0px; text-decoration-thickness: initial; text-decoration-style: initial; text-decoration-color: initial; display: inline !important; float: none;">1\. 通过在命令提示符中键入以下命令来创建 Vue 项目。</span>

```JavaScript
npm init vue@latest
```

<span style="color: rgb(34, 34, 34); font-family: Trebuchet MS, Tahoma, Verdana, Arial, sans-serif; font-size: 16px; font-style: normal; font-variant-ligatures: normal; font-variant-caps: normal; font-weight: 400; letter-spacing: normal; orphans: 2; text-align: left; text-indent: 0px; text-transform: none; white-space: normal; widows: 2; word-spacing: 0px; -webkit-text-stroke-width: 0px; text-decoration-thickness: initial; text-decoration-style: initial; text-decoration-color: initial; display: inline !important; float: none;">该命令将提示项目名称和其他可以添加到 Vue 项目的可选功能。</span>
<span style="color: rgb(34, 34, 34); font-family: Trebuchet MS, Tahoma, Verdana, Arial, sans-serif; font-size: 16px; font-style: normal; font-variant-ligatures: normal; font-variant-caps: normal; font-weight: 400; letter-spacing: normal; orphans: 2; text-align: left; text-indent: 0px; text-transform: none; white-space: normal; widows: 2; word-spacing: 0px; -webkit-text-stroke-width: 0px; text-decoration-thickness: initial; text-decoration-style: initial; text-decoration-color: initial; display: inline !important; float: none;">2\. 在项目中导入以下 SpreadJS 和 SpreadJS Designer Vue 模块。</span>

```JavaScript
npm install @grapecity-software/spread-sheets-designer-resources-cn
npm install @grapecity-software/spread-sheets-designer
npm install @grapecity-software/spread-sheets-designer-vue
npm install @grapecity-software/spread-sheets
npm install @grapecity-software/spread-excelio
npm install @grapecity-software/spread-sheets-barcode
npm install @grapecity-software/spread-sheets-charts
npm install @grapecity-software/spread-sheets-languagepackages
npm install @grapecity-software/spread-sheets-print
npm install @grapecity-software/spread-sheets-pdf
npm install @grapecity-software/spread-sheets-shapes
npm install @grapecity-software/spread-sheets-pivot-addon
npm install @grapecity-software/spread-sheets-tablesheet
```

<span style="color: rgb(34, 34, 34); font-family: Trebuchet MS, Tahoma, Verdana, Arial, sans-serif; font-size: 16px; font-style: normal; font-variant-ligatures: normal; font-variant-caps: normal; font-weight: 400; letter-spacing: normal; orphans: 2; text-align: left; text-indent: 0px; text-transform: none; white-space: normal; widows: 2; word-spacing: 0px; -webkit-text-stroke-width: 0px; text-decoration-thickness: initial; text-decoration-style: initial; text-decoration-color: initial; display: inline !important; float: none;">3\. 在 main\.js 文件中将 SpreadJS Designer Vue 组件注册到应用程序。</span>

```JavaScript
import { createApp } from 'vue'
import App from './App.vue'
import Designer from "@grapecity-software/spread-sheets-designer-vue"
let app = createApp(App);
app.component("gc-spread-sheets-designer", Designer);
app.mount('#app');
```

<span style="color: rgb(34, 34, 34); font-family: Trebuchet MS, Tahoma, Verdana, Arial, sans-serif; font-size: 16px; font-style: normal; font-variant-ligatures: normal; font-variant-caps: normal; font-weight: 400; letter-spacing: normal; orphans: 2; text-align: left; text-indent: 0px; text-transform: none; white-space: normal; widows: 2; word-spacing: 0px; -webkit-text-stroke-width: 0px; text-decoration-thickness: initial; text-decoration-style: initial; text-decoration-color: initial; display: inline !important; float: none;">4\. 通过修改 App\.vue 文件将 SpreadJS Designer Vue 组件添加到应用程序中。</span>

```JavaScript
<script setup>
import '@grapecity-software/spread-sheets/styles/gc.spread.sheets.excel2013white.css';
import "@grapecity-software/spread-sheets-designer/styles/gc.spread.sheets.designer.min.css";
import * as GC from "@grapecity-software/spread-sheets";
import "@grapecity-software/spread-sheets-print";
import "@grapecity-software/spread-sheets-shapes";
import "@grapecity-software/spread-sheets-pivot-addon";
import "@grapecity-software/spread-sheets-tablesheet";
import "@grapecity-software/spread-sheets-designer-resources-en";
import "@grapecity-software/spread-sheets-designer";

</script>
<script>
export default {
    name: "App",
    data: function () {
    return {
        styleInfo: { height: "98vh", width: "100%" },
        config: config,
        spreadOptions: {
        sheetCount: 2,
        },
        designer: null,
    };
    },
    methods: {
    designerInitialized(value) {
        this.designer = value;
    },
    },
};
</script>

<template>
    <div id="gc-designer-container">
    <gc-spread-sheets-designer
        :styleInfo="styleInfo"
        :config="config"
        :spreadOptions="spreadOptions"
        @designerInitialized="designerInitialized"/>
  </div>
</template>

<style>
</style>
```

<span style="color: rgb(34, 34, 34); font-family: Trebuchet MS, Tahoma, Verdana, Arial, sans-serif; font-size: 16px; font-style: normal; font-variant-ligatures: normal; font-variant-caps: normal; font-weight: 400; letter-spacing: normal; orphans: 2; text-align: left; text-indent: 0px; text-transform: none; white-space: normal; widows: 2; word-spacing: 0px; -webkit-text-stroke-width: 0px; text-decoration-thickness: initial; text-decoration-style: initial; text-decoration-color: initial; display: inline !important; float: none;">5\. 运行应用程序。</span>

```JavaScript
npm run dev
```

## 设置组件版编辑器授权

指定版本的许可证许您使用 SpreadJS Designer 组件的所有功能。您需要为 SpreadJS、ExcelIO 和 Designer 组件设置许可证密钥，这可以使用以下代码片段来完成。

```JavaScript
import '@grapecity-software/spread-sheets-designer-resources-en'
import { Designer } from '@grapecity-software/spread-sheets-designer-vue'
import * as GC from '@grapecity-software/spread-sheets'
import * as ExcelIO from '@grapecity-software/spread-excelio'
// license keys
var sjsLicense = 'sjs-distribution-key'
GC.Spread.Sheets.LicenseKey = sjsLicense
ExcelIO.LicenseKey = sjsLicense
GC.Spread.Sheets.Designer.LicenseKey = 'designer-component-distribution-key'
```
