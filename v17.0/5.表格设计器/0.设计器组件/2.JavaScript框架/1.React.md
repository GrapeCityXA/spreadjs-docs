# designer-react

您可以执行以下步骤在React应用程序中添加SpreadJS Designer:

* 在package.json中添加以下所需的包。

```plaintext
@grapecity-software/spread-excelio
@grapecity-software/spread-sheets
@grapecity-software/spread-sheets-barcode
@grapecity-software/spread-sheets-charts
@grapecity-software/spread-sheets-languagepackages
@grapecity-software/spread-sheets-pdf
@grapecity-software/spread-sheets-print
@grapecity-software/spread-sheets-resources-zh
@grapecity-software/spread-sheets-shapes
@grapecity-software/spread-sheets-tablesheet
@grapecity-software/spread-sheets-pivot-addon
@grapecity-software/spread-sheets-designer-resources-cn
@grapecity-software/spread-sheets-designer
@grapecity-software/spread-sheets-react
@grapecity-software/spread-sheets-designer-react
```

* 现在，您可以使用以下代码片段导入设计器和资源模块。

```Javascripts
import * as GC from '@grapecity-software/spread-sheets';
import '@grapecity-software/spread-sheets-print';
import '@grapecity-software/spread-sheets-shapes';

// 根据需要引入，需注意，引入pivotTable时必须要引入shape
import '@grapecity-software/spread-sheets-pivot-addon';

// 根据需要引入
import '@grapecity-software/spread-sheets-tablesheet';
import '@grapecity-software/spread-sheets-resources-zh';
import '@grapecity-software/spread-sheets-designer-resources-cn';
import {Designer} from '@grapecity-software/spread-sheets-designer-react';
import "@grapecity-software/spread-sheets-designer/styles/gc.spread.sheets.designer.min.css"
import "@grapecity-software/spread-sheets/styles/gc.spread.sheets.excel2013white.css"
import * as ExcelIO from '@grapecity-software/spread-excelio';
GC.Spread.Common.CultureManager.culture("zh-cn");
```

* 为了呈现设计器组件，您可以使用以下代码片段。

```Javascripts
function App() {
  return (
    <Designer styleInfo = {{width: "100%", height: '98vh'}} spreadOptions = {{sheetCount: 3}} designerInitialized={designerInitialized}></Designer>
  );
}
```
