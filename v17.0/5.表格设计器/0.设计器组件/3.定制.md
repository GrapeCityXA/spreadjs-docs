# customizations

SpreadJS组件版设计器允许您执行各种定制，如:

- 为常用命令添加一个新的ribbon选项卡
- 在选项卡中添加一个新的按钮来保存数据
- 添加一个新的上下文菜单项来锁定单元格
- 为自定义操作添加一个新对话框

### 创建样本文件来定义可定制的配置

default_config。json文件与SpreadJS.Designer.Release.xxxx.zip目录一起提供。它包含命令树结构中组件版设计器的默认配置。使用这个，你可以创建一个config.js文件，如下所示:


```config.js
var config =
//default_config.json中现有的命令树结构
```

您可以在config.js中进行所需的定制，并在web应用程序中引用它。然后，在初始化组件版设计器时，将这个可定制的配置作为参数传递。这在下面一节中作了解释。



### 使用可自定义配置初始化组件版设计器

After 定制配置。将可定制的配置作为参数传递给GC.Spread.Sheets.Designer。设计器类。它最多可以使用3个参数，定义如下:


```HTML
// 用可自定义配置和扩展初始化组件版设计器
var designer = new GC.Spread.Sheets.Designer.Designer(document.getElementById("designerHost"), config, spread);
```

Here:

- designerHost - 表示设计器的宿主元素的HTMLElement
- config - 表示布局的可自定义配置JSON的对象
- spread - 表示连接到设计器的SpreadJS实例的工作簿实例

“config”和“spread”参数是可选的。当没有提供时，设计器使用默认组件版设计器并生成一个新的表格。



### 可以定制

以下几点解释了在组件版设计器中可能的自定义范围:

- 设计器的第一级组件，包括功能区、上下文菜单、文件菜单和侧面板可以删除，但不能修改或添加。
- 第二层和相应的子层，包括按钮、选项卡、上下文菜单选项等都可以自定义。
- 每个元素的响应或交互可以通过设置commandMap来注册命令来定制。
