# designer-localization

您可以使用[getResources](SpreadJSDesigner~GC.Spread.Sheets.Designer~getResources)和[setResources](SpreadJSDesigner~GC.Spread.Sheets.Designer~setResources)方法自定义设计器本地化 。通过以下步骤帮助修改本地化资源：

- 使用[getResources](SpreadJSDesigner~GC.Spread.Sheets.Designer~getResources)方法获取原始设计器资源对象 。
- 修改资源对象的内容。
- 使用[setResources](SpreadJSDesigner~GC.Spread.Sheets.Designer~setResources)方法设置修改后的资源对象 。
- 初始化设计器。

如果在初始化设计器后设置资源，则必须在设计器中修改和设置配置才能生效。
> **注意:** 如果在初始化设计器后设置资源，则必须在设计器中修改和设置配置才能生效。 

```JavaScript
var resources = GC.Spread.Sheets.Designer.getResources();
resources.ok = "OK!";
resources.formatDialog.title = "Format Dialog!"
resources.ribbon.home.home = "HOME!";
resources.ribbon.home.paste = "Paste!";
GC.Spread.Sheets.Designer.setResources(resources);   
var designer = new GC.Spread.Sheets.Designer.Designer(document.getElementById("designerHost"), '', spread);
```
