# touchsupport

SpreadJS在控件的许多区域都支持触控手势。 您可以将触控手势用于筛选，调整大小，选择，分组以及进行许多其他类型的交互。 需要触控屏（触控显示器或带触控屏的智能本笔记本电脑）。

支持的浏览器和平台是：

- Windows桌面（Microsoft Internet Explorer 9和更高版本，Google Chrome，Mozilla Firefox和Opera）。
- 平板电脑-Surface（Microsoft Internet Explorer 10及更高版本）。

触摸支持要求控件支持基本的触摸手势。 触摸手势有几种类型，例如基本或通用以及捏或拉伸。

基本的触摸手势包括：

|  **手势**  |  **描述**  |
|--- |--- |
| 点按 | 一根手指触摸屏幕并抬起。 |
| 按下并按住不动 | 一根手指触摸屏幕并保持在原位。 |
| 移动 | 一个或多个手指触摸屏幕并向同一方向移动。 |
| 滑动 | 一个或多个手指触摸屏幕并向同一方向移动一小段距离。 |
| 捏 | 两个或多个手指触摸屏幕，并向彼此分开或靠近。 |
| 旋转 | 两个或更多个手指触摸屏幕，然后以顺时针或逆时针方向移动。 |
| 切换 | 两根或更多根手指触摸屏幕并移开更远。 |

SpreadJS在缩放时使用标准的捏合和拉伸手势。
