# AvoidUsingVolatileFunctions

对于常用功能，仅当从属单元格值变更时，才重新计算值。

但是， 对于Volatile 类函数（例如INDIRECT函数，RAND函数，NOW函数，TODAY函数）， 每次变更单元格值时都会重新计算这些值，不管单元格是否在依赖关系树中。就效率而言，这会对整体性能产生负面影响，因为无论何时打开或刷新表单，计算引擎都会重复进行重新计算。.

因此，建议用户避免使用任何易失性功能。 这将帮助您获得最佳性能，尤其是当您需要处理涉及大量数据计算的表单时。



### 替代解决方案

如果您使用的表单需要频繁使用易失性函数，那么您将无法避免使用它们； 那么另一种解决方案是避免嵌套易失函数以获取单元格值（主要使用数组公式）。 而是，您可以简单地在表单上的特定单元格中设置易失函数，然后从其他 non-volatile函数创建对该单元的引用。 这样做将大大减少易失性功能对性能的负面影响。
