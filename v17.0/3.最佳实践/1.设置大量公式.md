# SettingLargeAmountsofFormulas

每次用户调用 API 变更公式时，SpreadJS 都会自动计算以响应修改。
如果用户想一次在公式中集成很多变更，但又不想看到中间计算结果，建议使用 `suspendCalcService` 方法和 `resumeCalcService` 方法。
`suspendCalcService` 方法将停止计算过程，直到公式设置完成， 之后，可以调用 `resumeCalcService` 方法来还原计算系统。 
这两种方法都可以在很大程度上提高性能，尤其是当用户拥有包含大量公式的大量表单时。
请参考以下代码段，以使用 `suspendCalcService` 方法和 `resumeCalcService` 方法在表单中设置大量公式。

```javascript
var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), {
    sheetCount: 1
});
var sheet = spread.getSheet(0);
spread.suspendPaint();
sheet.suspendCalcService(true);
sheet.setRowCount(10000);
sheet.setColumnCount(100);
for (var i = 0; i < 10000; i++) {
    for (var j = 0; j < 100; j++) {
        sheet.setFormula(i, j, "DATE(2019,3,11)", GC.Spread.Sheets.SheetArea.viewport);
        sheet.getCell(i, j).formatter("yyyy/mm/dd");
        sheet.setColumnWidth(j, 80.0, GC.Spread.Sheets.SheetArea.viewport);
    }
}
sheet.resumeCalcService(false);
spread.resumePaint();
```
