# UsingsuspendEventandresumeEvent

每当用户调用API以变更数据或修改现有样式时，都会触发CellChanged事件。 如果在短时间内重复触发事件，则此过程可能会导致大量开销，进而对总体性能造成负面影响。

因此，建议使用 **suspendEvent** 方法和 **resumeEvent** 方法，尤其是当您计划一次合并很多变更但又不想触发任何Spread事件时。

suspendEvent方法将停止事件处理，直到所有变更都完成为止，resumeEvent方法允许您还原事件处理。 这两种方法对于在SpreadJS中处理事件时提高性能都是有用的。

请参考以下代码段，以使用 **suspendEvent** 方法和 **resumeEvent** 方法，以便在使用SpreadJS时提高性能。


```JavaScript
var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
var sheet = spread.getActiveSheet();
spread.bind(GC.Spread.Sheets.Events.CellChanged, function (sender, args) {
console.log('CellChanged event fired for Cell[' + args.row + "," + args.col + "] having value " + sheet.getValue(args.row, args.col));
});
spread.suspendPaint();
spread.suspendEvent();
for (var i = 0; i < 20; i++) {
for (var j = 0; j < 10; j++) {
sheet.setValue(i, j, "111");
}
}
spread.resumeEvent();
spread.resumePaint();
/* 在这种情况下，将仅对Cell [22,2]触发CellChanged事件
    而不是其他单元格，因为Cell [22，2]的值是在suspendEvent（）& resumeEvent（）方法的边界之后设置的 */
sheet.setValue(22, 2, "222");
```
