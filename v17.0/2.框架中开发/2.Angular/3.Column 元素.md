# a2colelement

下表列出了gc-column元素：

| 属性 | SpreadJS API | 类型 | 注释 |
| --- | ------------ | --- | --- |
| dataField | columnInfo.name | string | 设置Worksheet.bindColumn（index，columnInfo）函数 |
| headerText | columnInfo.displayName | string | 设置Worksheet.bindColumn（index，columnInfo）函数 |
| width | CellRange.width(value) | number |  |
| visible | CellRange.visible(value) | boolean |  |
| resizable | CellRange.resizable(value) | boolean |  |
| autoFit | Worksheet.autoFitColumn(column) | boolean | 如果autoFit为true，则列在数据绑定后应用自动拟合 |
| style | Worksheet.setStyle(-1, index, value) | GC.Spread.Sheets.Style | 设置列样式 |
| headerStyle | Worksheet.setStyle(-1, index, value, GC.Spread.Sheet.GC.Spread.Sheets.SheetArea.colHeader) | GC.Spread.Sheets.Style | 设置列标题样式 |
| cellType | Worksheet.setCellType(-1, index, value) | GC.Spread.Sheets.CellTypes.Base |  |
| formatter | Worksheet.setFormatter(-1, index, value) | string |  |

以下示例使用列元素：

```JavaScript
@Component({
      selector: 'my-app',
      template: `<gc-spread-sheets>
                      <gc-worksheet>
                          <gc-column [width]="columnWidth" [style]="columnStyle"></gc-column>
                      </gc-worksheet>
                 </gc-spread-sheets>`,
    })
    export class AppComponent {
        columnWidth: 300;
        columnStyle = new GC.Spread.Sheets.Style();
    }
```
