# angular-excelio

使用SpreadJS中的Excel IO元素和Angular，您可以在网页上快速呈现和显示Excel工作表，同时执行导入和导出操作，而无需任何麻烦。

1. **全局安装Angular CLI**
    打开命令提示窗口并键入以下命令：

    ```bash
    npm install -g @angular/cli
    ```
2. **使用 Angular CLI 创建新项目**
    使用以下命令创建新项目并导航到项目目录：

    ```bash
    ng new spread-sheets-angular-cli --style css --ssr false
    cd spread-sheets-angular-cli
    ```
3. **安装 SpreadJS Npm 软件包**
    使用以下命令安装SpreadJS Npm软件包：

    ```bash
    npm install @grapecity-software/spread-sheets
    npm install @grapecity-software/spread-sheets-angular
    ```
4. **在项目中安装Excel IO Angular Module和FileSaver Angular Module**
    使用以下命令在项目中安装Excel I/O和文件保护程序模块：

    ```bash
    npm install @grapecity-software/spread-excelio
    npm install file-saver --save
    npm install @types/file-saver --save
    ```
5. **在angular.json中配置SpreadJS CSS**
    在angular.json中配置SpreadJS CSS，如下所示：

    ```json
    @import "../node_modules/@grapecity-software/spread-sheets/styles/gc.spread.sheets.excel2013white.css";
    ```
6. **在Angular应用中使用Excel IO**
    修改 **app.html** 以查看SpreadJS组件，如下所示：

    ```html
    <div>
        <input id="selectedFile" type="file" accept=".sjs, .xlsx, .ssjson" />
        <label for="exportFileType">File Type:</label>
        <select id="exportFileType">
            <option value="xlsx">Excel</option>
            <option value="ssjson">SSJson</option>
            <option value="sjs">SJS</option>
        </select>
        <button id="exportBtn">Export</button>
        <gc-spread-sheets [hostStyle]="hostStyle" (workbookInitialized)="initSpread($event)">
            <gc-worksheet></gc-worksheet>
        </gc-spread-sheets>
    </div>
    ```

    修改 **app.ts** 以使用Excel IO元素并为SpreadJS组件准备数据；如下图所示：

    ```javascript
    import { Component, enableProdMode } from "@angular/core";
    import { bootstrapApplication, BrowserModule } from '@angular/platform-browser';
    import { SpreadSheetsModule } from "@grapecity-software/spread-sheets-angular";
    import GC from "@grapecity-software/spread-sheets";
    import "@grapecity-software/spread-sheets-io";
    import { saveAs } from "file-saver";
    @Component({
      selector: "app-root",
      templateUrl: "app.html",
      standalone: true,
      imports: [SpreadSheetsModule, BrowserModule],
    })
    export class App {
      autoGenerateColumns = false;
      spread!: GC.Spread.Sheets.Workbook;
      hostStyle = {
        width: "100%",
        height: "600px",
      };
      constructor() { }
      fileTypeMap = { sjs: "sjs", xlsx: "xlsx", ssjson: "ssjson" };
      initSpread($event: any) {
        this.spread = $event.spread;
        let spread = this.spread;
        let sheet = spread.getActiveSheet();
        sheet.setValue(0, 0, "Hello World!");
        document.getElementById("selectedFile")!.addEventListener("change", (e) =>
          this.loadFile((e as any).target.files[0])
        );
        document.getElementById("exportBtn")!.addEventListener("click", () => {
          this.exportFile();
        });
      }
      getFileType(fileName: String) {
        // console.log( fileName);
        return fileName.split(".").pop();
      }
      loadFile(file: any) {
        const type = this.getFileType(file.name);
        const fileType =
          type === "xlsx"
            ? GC.Spread.Sheets.FileType.excel
            : GC.Spread.Sheets.FileType.ssjson;
        if (type === this.fileTypeMap.sjs) {
          this.spread.open(
            file,
            () => console.log("SJS File Loaded"),
            console.error
          );
        } else if (
          ([this.fileTypeMap.xlsx, this.fileTypeMap.ssjson] as any).includes(type)
        ) {
          this.spread.import(
            file,
            () => console.log("File Loaded"),
            console.error,
            { fileType }
          );
        } else {
          console.error("Unsupported file type");
        }
      }
      exportFile() {
        const type = (document.getElementById("exportFileType") as any).value;
        const fileName = `export.${type}`;
        const fileType =
          type === "xlsx"
            ? GC.Spread.Sheets.FileType.excel
            : GC.Spread.Sheets.FileType.ssjson;
        if (type === this.fileTypeMap.sjs) {
          this.spread.save((blob: any) => saveAs(blob, fileName), console.error);
        } else if (
          type === this.fileTypeMap.xlsx ||
          type === this.fileTypeMap.ssjson
        ) {
          this.spread.export((blob: any) => saveAs(blob, fileName), console.error, {
            fileType,
          });
        }
      }
    }
    enableProdMode();
    bootstrapApplication(App);i
    ```
7. **使用Angular CLI构建并运行项目**
    使用以下命令生成并运行新项目：

    ```bash
    ng serve
    ```
