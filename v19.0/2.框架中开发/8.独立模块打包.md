# spreadjs-with-individual-modules

SpreadJS 模块可以在NPM上获得。许多现代的 JavaScript 构建工具和打包工具（如Webpack、Rollup、ESBuild和Vite）与 SpreadJS 的 NPM 包（包括模块、插件和资源）无缝协同工作。
此外，将SpreadJS整合到项目的构建过程中非常顺利，并且可以充分利用这些工具的功能。
在使用 SpreadJS 与单独模块时，请参考以下主题列表：


### 使用 AMD 的核心模块

以下代码示例展示了如何使用 AMD 和核心模块：

```html
<!DOCTYPE html>
<html>
<head>
    <title>Test SJS Modules with AMD</title>
    <link rel="stylesheet" type="text/css"
        href="./@grapecity-software/spread-common/styles/gc.spread.sheets.excel2016colorful.css" />
</head>
<body>
    <div id="testDiv" style="width:100%;height:300px;"></div>
    <script type='text/javascript' src="./require.js"></script>
    <script type='text/javascript'>
        window.onload = function () {
            require.config({
                paths: {
                    '@grapecity-software/spread-common': './@grapecity-software/spread-common/dist/gc.spread.common.min',
                    '@grapecity-software/spread-sheets-core': './@grapecity-software/spread-sheets-core/dist/gc.spread.sheets.core.min'
                }
            });
            require(['@grapecity-software/spread-common', '@grapecity-software/spread-sheets-core'], function (GC) {
                var spread = new GC.Spread.Sheets.Workbook(document.getElementById("testDiv"));
            });
        };
    </script>
</body>
</html>
```

```javascript
import * as GC from "@grapecity-software/spread-common";
```

### 使用 CommonJS 的 sparklines 模块

以下代码示例展示了如何使用 CommonJS 和 sparklines 模块：

```javascript
import * as GC from "@grapecity-software/spread-common";
import "@grapecity-software/spread-calc-engine";
import "@grapecity-software/spread-sheets-core";
import "@grapecity-software/spread-sheets-calc-engine";
import "@grapecity-software/spread-sheets-sparklines";
var spread = new GC.Spread.Sheets.Workbook(document.getElementById("testDiv"));
var sheet = spread.getActiveSheet();
sheet.suspendPaint();
sheet.setFormula(0, 0, '=PIESPARKLINE(0.25, "red"');
sheet.setRowHeight(0, 60);
sheet.resumePaint();
```

### 使用 CommonJS 的 print 模块

以下代码示例展示了如何使用 CommonJS 和 print 模块：

```javascript
import * as GC from "@grapecity-software/spread-common";
```
