# UsingtheColumnElement

下表列出了column元素的属性。

| **属性** | **API 参考** | **类型** | **备注** |
| --- | ------ | --- | --- |
| dataField | columnInfo.name | string | 设置Worksheet.bindColumn（index，columnInfo）函数 |
| headerText | columnInfo.displayName | string | 设置Worksheet.bindColumn(index, columnInfo) 函数 |
| width | CellRange.width(value) | number |  |
| visible | CellRange.visible(value) | boolean |  |
| resizable | CellRange.resizable(value) | boolean |  |
| autoFit | Worksheet.autoFitColumn(column) | boolean | 如果将autoFit设置为true，则该列将在数据绑定后自动进行自动调整。 |
| style | Worksheet.setStyle(-1, index, value) | GC.Spread.Sheets.Style | 设置列的样式 |
| headerStyle | Worksheet.setStyle(-1, index, value, GC.Spread.Sheet.GC.Spread.Sheets.SheetArea.colHeader) | GC.Spread.Sheets.Style | 设置列标题的样式 |
| cellType | Worksheet.setCellType(-1, index, value) | GC.Spread.Sheets.CellTypes.Base |  |
| formatter | Worksheet.setFormatter(-1, index, value) | string |  |
