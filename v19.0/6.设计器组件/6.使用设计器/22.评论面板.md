# threaded-comments-panel

评论面板是 SpreadJS 的内置组件，用于显示、管理和交互当前工作表中的所有 **评论**。
它提供了直观的界面，让用户可直接在面板内审阅、回复和筛选对话评论，提升电子表格环境中的协作效率。该面板与工作簿的评论系统完全同步，会随着评论的添加、编辑或删除动态更新。

### 筛选评论

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image-20260127.fc8ae0.png)
目前支持三种筛选条件：

* 评论中是否提及当前用户（**@提及我**）
* 评论状态 —— **仅活动（Active Only）** 或 **仅已解决（Resolved Only）**

**全部重置（Reset All）** 选项可快速清除所有已应用的筛选条件。

## 评论导航键盘快捷键

当面板中选中某条评论时，可通过以下快捷键高效切换评论评论：

| **按键** | **功能** |
| --- | --- |
| 上箭头（Arrow Up） | 导航到上一条评论 |
| 下箭头（Arrow Down） | 导航到下一条评论 |

## 通过 API 集成面板

使用 `ThreadedCommentPanel` 类将内置的评论侧边栏添加到 UI 中。面板附加到工作簿后，会自动列出所有评论。

```javascript
// 初始化工作簿
let workbook = new GC.Spread.Sheets.Workbook("spread-host");
// 初始化评论面板
let threadedCommentPanel = new GC.Spread.Sheets.ThreadedComments.ThreadedCommentPanel("threaded-comment-panel-host");

// 将面板附加到工作簿
threadedCommentPanel.attach(workbook);
```
