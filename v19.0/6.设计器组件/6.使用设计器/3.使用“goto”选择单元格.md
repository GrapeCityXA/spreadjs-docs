# select-cells-goto

“开始”>“编辑”>“查找”功能区按钮中的“转到”选项提供了一种通过命名区域和单元格引用导航工作簿的快速方法。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/goto-option.png)
“转到”对话框提供了一个输入框，您可以在其中输入命名区域或单元格引用以访问它们。您还可以从最近的历史记录部分选择访问以前的查询。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/goto-dialog.png)
## 转到特殊选项
您可以使用“转到特殊”选项浏览活动工作表。它有助于在工作表中选择特殊的单元格组。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/goto-special-option.png)
“转到特殊”对话框提供了 15 种不同的定位方法，可用于选择单元格。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/goto-special-dialog.png)
| 定位法 | 描述 |
| --- | --- |
| Notes | 选择目标区域中所有带注释的单元格。 |
| Constants | 选择直接在单元格中输入的所有常量值。例如，数字、文本、逻辑（TRUE 或 FALSE）。如果该值是通过公式计算的，则不会被选中。 |
| Formulas | 选择由公式生成的所有值，包括数字、文本、逻辑值。如果直接在单元格中输入值，则不会选择它。 |
| Blanks | 选择目标区域中所有没有值的单元格。如果目标区域中只有一个单元格，则目标区域由从（0,0）到工作表中最后一个数据的单元格组成。 |
| Current region | 选择从目标区域开始并扩展到周围区域的所有单元格，直到遇到空行和列。 |
| Current array | 选择数组公式生成的所有单元格值和当前目标区域中存在的数组公式区域。 |
| Objects | 选择目标区域中包含插入对象的所有单元格，包括图形、文本框、图片、艺术字等。 |
| Row differences | 选择与所选行中的活动单元格不同的所有单元格。对每一行独立进行比较，每行中用于比较的单元格与活动单元格在同一列。 |
| Column differences | 选择与所选列中的活动单元格不同的所有单元格。对每一列独立进行比较，每列中用于比较的单元格与活动单元格在同一列中。 |
| Precedents | 在选定的活动单元格或目标区域中选择公式引用的所有单元格。 |
| Dependents | 选择引用活动单元格或目标范围的公式被选中的所有单元格。 |
| Last cell | 选择所选目标范围右下角带有数据或格式的单元格。 |
| Visible cells only | 选择所有可以在选择中看到的单元格（不包括隐藏的单元格）。 |
| Conditional formats | 选择所有应用了条件格式的单元格。 |
| Data validation | 选择应用了数据验证的所有单元格。 |
