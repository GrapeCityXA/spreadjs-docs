# dockable-side-panel

SpreadJS 设计器的可停靠侧边栏极大地提升了用户体验和工作效率。它使用户能够根据个人偏好或工作流程需求灵活调整面板位置，在保持设计视口不受阻挡的同时优化屏幕空间。此外，它还提供了对常用功能的快速访问。

## 侧边栏拖放

![sidePanel](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1f04de1b-0add-4f88-889e-295f2a2e218b/sidePanel.0db589.gif)

* **拖放行为：**
    只有侧边栏支持拖放功能。它只能被拖动到工作簿的左侧或右侧，而不能拖动到顶部、底部或其他任何位置。
* **停靠提示：**
    当点击并按住侧边栏的标题栏时，会出现停靠提示按钮。要停靠面板，用户必须在将鼠标悬停在所需的停靠按钮上时松开点击操作。

## 侧边栏选项卡

当同时显示多个侧边栏时，可以使用选项卡对它们进行整理。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1f04de1b-0add-4f88-889e-295f2a2e218b/image.f6fa86.png)

* **默认选项卡行为**
    当多个侧边栏显示在同一侧时，默认情况下它们会自动以选项卡的形式出现。
* **并排显示选项**
    用户可以通过配置文件中的设置将面板配置为并排显示（而不是以选项卡形式显示）。
* **通过拖放进行选项卡分组**
    要将面板分组到选项卡中：
    * 将一个面板拖到另一个面板的停靠提示按钮上。
    * 当目标面板的选项卡区域高亮显示时松开鼠标。
        这样会将被拖动的面板添加到目标面板的选项卡组中。
* **接口**

    ```typescript
    export interface ISidePanel {
        /* ... */
        canStack?: boolean; // 默认值为 true
    }
    
    ```

当 **canStack** 设置为 false 时：

* 侧边栏将与其他面板以并排布局的形式显示。
* 选项卡分组功能将被禁用。
* 此设置保留了与旧版本实现的向后兼容性。

## 示例

```javascript
const config = GC.Spread.Sheets.Designer.DefaultConfig;
config.sidePanels.forEach((panel) => {
    panel.canStack = false;
});
const designer = new GC.Spread.Sheets.Designer.Designer('gc-designer-container', config);
```
