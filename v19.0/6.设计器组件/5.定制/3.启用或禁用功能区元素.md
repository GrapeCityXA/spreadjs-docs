# enable_disable_ribbon_elements

按照以下步骤禁用“INSERT”选项卡中的“Table”字段按钮。

1. 打开 config.js 文件以识别与“Table”按钮关联的命令，在本例中为“insertTable”命令。

    ```config.js
    // Configure Workbook and Worksheet
    var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'));
    var activeSheet = spread.getActiveSheet();
    
    // Access the default config
    var config = GC.Spread.Sheets.Designer.DefaultConfig;
    
    console.log(config);
    
    // Find the below snippet for "Table" button
    
    // "ribbon": [
    // {
    //  ...
    //
    //   "id": "insert",
    //   "text": "INSERT",
    //   "buttonGroups": [
    //     {
    //       "label": "Table",
    //       "thumbnailClass": "ribbon-thumbnail-table",
    //       "commandGroup": {
    //         "commands": [
    //           "insertTable"      // Associated command
    //         ]
    //       }
    //     }]
    // }]
    
    ```
2. 在上面的命令（insertTable）上应用 [getCommand](gcdocsite__documentlink?toc-item-id=7e131f20-7eab-40bd-9f75-5ed6b663680e#getcommand) 方法来识别它的状态表达式。

    ```JavaScript
    console.log(GC.Spread.Sheets.Designer.getCommand('insertTable'));
    // commandName: "insertTable"
    // enableContext: "AllowInsertTable  && !IsProtected"
    ```
3. 在您的项目中将上述命令设置为 commandMap，并通过设置 **enableContext** 选项禁用相应的状态表达式。

    ```JavaScript
    config.commandMap = {
        insertTable: {
            commandName: 'insertTable',
            // To disable the Table button
            enableContext: '!AllowInsertTable',
        },
    };
    
    ```
4. 通过传递“config”参数来初始化设计器实例

    ```JavaScript
    // 初始化设计器实例
    var designer = new GC.Spread.Sheets.Designer.Designer(document.getElementById("designerHost"), config);
    ```
