# bind-file-import-events

你可以在 SpreadJS 设计器组件的文件导入操作过程中添加功能。

## 绑定方法

设计器组件在 [Designer ](gcdocsite__documentlink?toc-item-id=4114df43-88a3-43c4-b3b8-15a79a777157)类中提供了事件绑定方法 `bind`、`unbind` 和 `unbindAll`。这些方法有助于在设计器组件中添加或移除事件。

| **方法** | **描述** |
| --- | --- |
| `bind` | 将一个事件绑定到设计器上。接受事件的类型以及事件发生时要运行的函数。 |
| `unbind` | 移除某个事件在设计器上的绑定。接受事件的类型以及要移除其绑定的函数。 |
| `unbindAll` | 移除所有事件在设计器上的绑定。 |

## 事件

设计器组件在 [Designer.Events](gcdocsite__documentlink?toc-item-id=3443da8c-6542-4964-93f4-fe89bbe84cf2) 类中提供了与文件导入相关的事件，即 `FileLoading` 和 `FileLoaded`。在 `bind` 方法中，这些事件作为字符串被接受，以便在 SpreadJS 设计器组件中执行用户指定的函数。

| 事件 | 描述 |
| --- | --- |
| `FileLoading` | 当由于 Spread.Sheets.Designer 的文件操作而导致文件正在加载时发生。 |
| `FileLoaded` | 当由于 Spread.Sheets.Designer 的文件操作而导致文件已加载完成时发生。 |

这些事件在将 JSON、Excel 或 CSV 文件导入到 SpreadJS 中时会触发，但你也可以使用 [FileType ](gcdocsite__documentlink?toc-item-id=5254e66d-7f1f-463a-bbf9-257feca0f49b)枚举选项（如 `Json`、`Excel` 和 `CSV`）来指定特定格式的事件。

## 示例

以下代码示例设置了 `FileLoading` 事件，以便在导入的文件格式为 Excel 且工作表数量大于或等于三个时，显示工作表的数量。它还会在文件导入完成时显示一条消息。

```JavaScript
var designer = new GC.Spread.Sheets.Designer.Designer(document.getElementById('designerHost'), '', spread);
// 在 bind 方法中使用 FileLoading 事件
designer.bind(GC.Spread.Sheets.Designer.Events.FileLoading, function (type, message) {
    if ((message.fileType = GC.Spread.Sheets.Designer.FileType.Excel)) {
        let spreadJsonData = message.data;
        if (spreadJsonData.sheetCount >= 3) {
            window.alert('工作表数量: ' + spreadJsonData.sheetCount);
        }
    }
});
// 在 bind 方法中使用 FileLoaded 事件
designer.bind(GC.Spread.Sheets.Designer.Events.FileLoaded, function (event, data) {
    window.alert('文件已加载');
});
// 使用 unbind 方法移除 FileLoaded 事件
designer.unbind(GC.Spread.Sheets.Designer.Events.FileLoaded);
// 使用 unbindAll 方法移除所有事件
designer.unbindAll();
```
