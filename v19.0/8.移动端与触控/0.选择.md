# touchselect

你可以使用触摸手势选择列、行、单元格区域以及整个控件。
## 选择单元格区域
1. 点击一个单元格以选择该单元格，并在其左上角和右下角显示选择控制柄。
    ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/touchgripper.5253b3.png)
2. 按住单元格选择控制柄并滑动。
3. 松开手指以选择一个单元格区域。
4. 下图显示了一个已选择的单元格区域。
    ![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/touchrange.ef78ca.png)
## 选择列标题或行标题
点击列标题（或行标题）以选择一列（或一行）。然后，你可以按住选择控制柄并滑动以选择一个列区域（或行区域）。松开手指以完成选择。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/touchcolheader.3ce49e.png)
你可以通过点击角落的标题来选择整个控件。
## 选择多个区域
你可以按照以下步骤选择多个区域：
1. 选择一个区域。
2. 按住 Ctrl 键并点击一个新的单元格位置以开始新的选择。
3. 松开 Ctrl 键。
4. 按住并滑动选择控制柄以选择新的区域。
你还可以通过按住选择控制柄并向任意方向滑动来更改所选单元格区域的大小。松开手指以完成操作。
