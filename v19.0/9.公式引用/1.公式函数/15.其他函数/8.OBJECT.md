# object-function

OBJECT函数用于定义一个对象，并指定 props和values。对象函数的结果将是这些props和values的对象。

OBJECT函数可用于创建[RANGEBLOCK](gcdocsite__documentlink?toc-item-id=80ab7ba1-5a1d-4e2a-965d-8bad609d4718)微线图。



#### 语法

OBJECT( *property1, expression1, property2, expression2, ...* )

OBJECT( *properties_range, expressions_range* )

OBJECT( *property1, expressionArray1, property2, expressionArray2, ...* )



#### 参数

OBJECT(property1, expression1, property2, expression2, ...) 函数有四个参数::

|  **参数**  |  **描述**  |
|--- |--- |
| property1 | 引用当前对象的第一个属性。它可以是字符串或单元格引用。 |
|  *expression1*  | 引用当前对象的第一个属性值。它可以是任何类型值或单元格引用。 |
| property2 | 引用当前对象的第二个属性。它可以是字符串或单元格引用。 |
| expression2 | 引用当前对象的第二个属性值。它可以是任何类型值或单元格引用。 |

OBJECT( *properties_range, expressions_range* )函数有四个参数:

|  **参数**  |  **描述**  |
|--- |--- |
|  *properties_range1*  | 引用当前对象的第一个属性。它应该是一个范围引用。 |
|  *expressions_range1*  | 引用当前对象的第一个属性值。它应该是一个范围引用，并且这个范围的长度应该等于属性范围的长度。 |
| properties_range2 | 引用当前对象的第二个属性。它应该是一个范围引用，并且这个范围的长度应该等于第一个属性范围的长度。 |
| expressions_range2 | 引用当前对象的第二个属性值。它应该是一个范围引用，并且这个范围的长度应该等于第一个属性范围的长度。 |

OBJECT(property1, expressionArray1, property2, expressionArray2, ...) 函数有4个参数：

|  **参数**  |  **描述**  |
|--- |--- |
|  *property1*  | 引用当前对象的第一个属性。它可以是字符串或单元格引用。 |
|  *expressionArray1*  | 引用当前对象的第一个属性值。它应该是一个引用数组。 |
| property2 | 引用当前对象的第一个属性。它可以是字符串或单元格引用。 |
| expressionArray2 | 引用当前对象的第二个属性值。它应该是一个引用数组，其长度应该等于第一个属性值的长度。 |



#### 备注

如果参数不是键-值顺序和成对的，OBJECT函数将返回calcerror。



#### 数据类型

OBJECT(property1, expression1, property2, expression2，…)和OBJECT(properties_range, expressions_range)返回对象值数据类型，而OBJECT(property1, expressionArray1, property2, expressionArray2，…)返回对象数组数据类型。



#### 示例


```JavaScript
<script>
        $(document).ready(function () {
            //初始化spread
            var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });
            //获取活动表
            var sheet = spread.getActiveSheet();
            // 数据源是数组
            let dataSource = [
                {
                    "NAME": "James Smith",
                    "POSITION": "AVP",
                    "OFFICE": "Fox Studios",
                    "EXTN": 71,
                    "START_DATE": '3/08/2008',
                    "JOINING_YEAR": 2008
                }
            ];
            let colInfos = [
                { name: "NAME", displayName: "NAME", size: "2*" },
                { name: "POSITION", displayName: "POSITION", size: "*" },
                { name: "OFFICE", size: "*" },
                { name: "EXTN", size: "*" },
                { name: "START_DATE", size: 100 },
                { name: "JOINING_YEAR", size: 100 }
            ];
            // 创建样式
            var style = new GC.Spread.Sheets.Style();
            style.cellButtons = [
                {
                    imageType: GC.Spread.Sheets.ButtonImageType.dropdown,
                    command: "openMultiColumn",
                    useButtonStyle: true,
                }
            ];
            style.dropDowns = [
                {
                    type: GC.Spread.Sheets.DropDownType.multiColumn,
                    option: {
                        width: 600,
                        height: 150,
                        dataSource: dataSource,
                        bindingInfos: colInfos
                    }
                }
            ];
            // 设置样式格式
            style.formatter = '=PROPERTY(@, "OFFICE")';
            // 设置样式
            sheet.setStyle(0, 1, style);
            // 设置文本
            sheet.setText(0, 0, "数据源是数组, return data parsed to the value of property 'OFFICE'.");
            // 设置自动换行
            sheet.getCell(0, 0).wordWrap(true);
            sheet.getCell(0, 1).wordWrap(true);
            //设置列宽
            sheet.setColumnWidth(0, 200);
            sheet.setColumnWidth(1, 400);
            // 设置行高
            sheet.setRowHeight(0, 70);
        });
    </script>
```
