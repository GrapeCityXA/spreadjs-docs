# DAVERAGE

此函数对列表或数据库中满足指定条件的记录字段（列）中的数值求平均值。



#### 语法

DAVERAGE( *database, field, criteria* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *database*  | 构成列表或数据库的单元格区域。 |
|  *field*  | 指定函数所使用的列。 |
|  *criteria*  | 为包含指定条件的单元格区域。 |

database参数是组成数据库的一系列单元格。每列代表一个字段。第一行代表字段标签。其余各行代表数据记录。

field 参数确定要使用数据库中的哪一列。 field 参数可以是字符串（字段标签）或数字（字段索引）。

criteria参数是一个单元格区域，这些单元格指定数据库中的哪些行包含选择数据库中数据子集的条件。第一行代表字段标签。其余行代表条件。使用AND运算合并同一行中的条件。使用OR操作将不同行中的条件组合在一起。每个条件可以是数字或字符串。该字符串可以包括比较运算符（=，＆lt;＆gt;，＆lt;，＆gt;，＆lt; =，＆gt; =）。如果不包括运算符，则假定等于运算符（=）。

criteria参数不支持通配符。



#### 注释

这是将单元格区域视为数据库的几种数据库或列表函数之一。



#### 数据类型

接受数据库和条件的单元格区域。接受字段的字符串或数字。返回数值数据。



#### 示例

DAVERAGE(A4:E10,3,A4:E10)

DAVERAGE(A1:A9,"Income",D5:D8)
