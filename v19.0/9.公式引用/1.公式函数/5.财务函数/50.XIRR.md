# XIRR

此函数返回一组不一定定期发生的现金流的内部收益率。



#### 语法

XIRR( *values* , *dates* , *guess* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *values*  | 与 dates 中的支付时间相对应的一系列现金流。 |
|  *dates*  | 与现金流支付相对应的支付日期表。Dates 中的数值将被截尾取整。 |
|  *guess*  | [可选]对函数 XIRR 计算结果的估计值。 |



#### 注释

若要计算一组定期现金流的内部收益率，请使用函数[IRR](gcdocsite__documentlink?toc-item-id=6588fa01-d557-44b4-a224-0ba99dab3faa)。

XIRR 要求至少一个正的现金流和一个负现金流，否则返回 #NUM！ 。

如果日期中的任何数字在开始日期之前，则返回 #NUM！ 。

如果值和日期包含不同数目的值，则返回 #NUM！ 。

如果该函数在尝试100次后仍然找不到有效的结果，则返回错误值。



#### 数据类型

接受values、guess的数值数据，dates的DateTime对象。返回数值数据。



#### 示例

XIRR(B2:B6,C2:C6,0.2)
