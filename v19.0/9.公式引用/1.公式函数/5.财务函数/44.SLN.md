# SLN

此函数返回一个期间内的资产的直线折旧。



#### 语法

SLN( *cost* , *salvage* , *life* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *cost*  | 资产原值。 |
|  *salvage*  | 折旧末尾时的值（有时也称为资产残值）。 |
|  *life*  | 资产的折旧期数。 |



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

SLN(B1,1000,10)

SLN(R1C2,1000,10)

SLN(500000,20000,5) 得出结果 $96,000
