# AMORDEGRC

返回每个结算期间的折旧值。 如果某项资产是在该结算期的中期购入的，则按直线折旧法计算。



#### 语法

AMORDEGRC( *cost* , *datepurchased* , *firstperiod* , *salvage,period,drate* , *basis* )



#### 参数

本函数有3个参数:

| 参数 | 描述 |
|--- |--- |
|  *cost*  | 资产原值 |
|  *datepurchased*  | 购入资产的日期 |
|  *firstperiod*  | 第一个期间结束时的日期 |
|  *salvage*  | 资产在使用寿命结束时的残值 |
|  *period*  | 期间 |
|  *drate*  | 折旧率 |
|  *basis*  | [可选] 要使用的年基准 (参考[Day Count Basis](gcdocsite__documentlink?toc-item-id=23b72e94-94be-44ed-9302-d582747f59dd)) |



#### 注释

此函数返回折旧值，截止到资产生命周期的最后一个期间，或直到累积折旧值大于资产原值减去残值后的成本价。折旧系数为:

| 资产的生命周期 | 折旧系数 |
|--- |--- |
| 3 到 4 年 | 1.5 |
| 5 到 6 年 | 2 |
| 6 年以上 | 2.5 |

最后一个期间之前的那个期间的折旧率将增加到 50%，最后一个期间的折旧率将增加到 100%。 如果资产的生命周期在 0 到 1、1 到 2、2 到 3 或 4 到 5 之间，将返回 #NUM! 错误值。

此函数不同于[AMORLINC](gcdocsite__documentlink?toc-item-id=4121d83e-616f-4df9-82a0-8034a754d619), 不同之处在于该函数中用于计算的折旧系数取决于资产的寿命。



#### 数据类型

接受数值和DateTime对象数据。返回数值数据。



#### 示例

AMORDEGRC(B1,B2,B3,B4,B5,B6,B7)

AMORDEGRC(2800,DATE(2003,9,4),DATE(2006,12,31),200,1,0.02,1) 得出结果 117
