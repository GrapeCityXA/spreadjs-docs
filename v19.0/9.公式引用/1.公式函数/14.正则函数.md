# regex

Spread 提供了以下正则表达式函数，按字母顺序列出。

| **函数** | **说明** |
| --- | --- |
| [REGEXEXTRACT](gcdocsite__documentlink?toc-item-id=cd690065-dec7-407d-a7fd-ab2823204503) | 此函数根据指定的正则表达式从字符串中提取文本。它支持提取第一个匹配项、所有匹配项，或从第一个匹配项中提取捕获组。 |
| [REGEXTEST](gcdocsite__documentlink?toc-item-id=378f4f9f-8346-4a8b-9b89-a808ea1e9a1b) | 此函数可让你检查所提供文本的任何部分是否与正则表达式（“regex”）匹配。如果匹配则返回 TRUE，如果不匹配则返回 FALSE。 |
| [REGEXREPLACE](gcdocsite__documentlink?toc-item-id=935a3a67-af8b-4c88-bcba-ea70b87ebcb4) | 此函数有助于根据指定的正则表达式模式替换字符串中的文本。 |
