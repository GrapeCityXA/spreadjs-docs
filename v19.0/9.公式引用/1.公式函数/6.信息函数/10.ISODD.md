# ISODD

如果参数为奇数，返回 TRUE，否则返回 FALSE。



#### 语法

ISODD( *cellreference* )

ISODD( *value* )

ISODD( *expression* )



#### 参数

参数可以是单元格引用，数字或文本值或表达式。



#### 注释

使用此功能可以测试单元格、数字、文本值、函数或表达式的内容。

如果参数引入的数字为奇数，则该函数返回TRUE。如果参数引入的数字为偶数，则该函数返回FALSE。如果参数引入的数字为零，则该函数返回FALSE。如果参数指定的数字指向空单元格或没有数据，则该函数返回TRUE。



#### 数据类型

接受参数的任何数据类型。返回布尔（TRUE或FALSE）数据。



#### 示例

ISODD(B3)

ISODD(R1C2)

ISODD(12) 得出结果 FALSE

ISODD(2.5) 得出结果 FALSE

ISODD(3.6) 得出结果 TRUE

ISODD(ROUND(3.6)) 得出结果 FALSE
