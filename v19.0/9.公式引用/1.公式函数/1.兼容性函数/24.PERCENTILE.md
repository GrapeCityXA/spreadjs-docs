# PERCENTILE

此函数返回区域中数值的第 n 个百分点的值。



#### 语法

PERCENTILE( *array* , *n* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *array*  | 定义相对位置的数组或数据区域。 |
|  *n*  | 0 到 1 之间的百分点值，包含 0 和 1。 |



#### 数据类型

接受两个参数的数值数据。返回数值数据。



#### 示例

PERCENTILE(A1:A12,0.95)

PERCENTILE(R1C1:R1C45,0.866)

PERCENTILE({5,15,25,50,65},0.45) 得出结果 23
