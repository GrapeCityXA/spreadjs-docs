# TDIST

此函数返回学生 t 分布的百分点（概率）。



#### 语法

TDIST( *x* , *deg* , *tails* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *x*  | 需要计算分布的数值。 |
|  *deg*  | 一个表示自由度数的整数。如果不是整数则截尾取整。 |
|  *tails*  | 指定的分布尾数。如果 Tails = 1，则 TDIST 返回单尾分布。 如果Tails = 2，则 TDIST 返回双尾分布。如果不是整数则截尾取整。 |



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

TDIST(A1,B45,2)

TDIST(0.245,2,1)得出结果 0.414651
