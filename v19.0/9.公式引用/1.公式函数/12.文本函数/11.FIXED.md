# FIXED

此函数将数字舍入到指定的小数位数，使用句点和逗号，以十进制数格式对该数进行格式设置，并以文本形式返回结果。



#### 语法

FIXED( *num* , *digits* , *notcomma* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *num*  | 要进行舍入并转换为文本的数字。 |
|  *digits*  | [可选] 小数点右边的位数。 |
|  *notcomma*  | [可选] 一个逻辑值，如果为 TRUE，则会禁止 FIXED 在返回的文本中包含逗号。 |



#### 数据类型

接受前两个参数的数值数据；接受第三个参数的逻辑值。返回字符串（文本）数据。



#### 示例

FIXED(B3)

FIXED(R3C2,2,FALSE)

FIXED(4.2365,3)
