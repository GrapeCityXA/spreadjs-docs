# REPT

此函数将文本重复一定次数。



#### 语法

REPT( *text* , *number* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *text*  | 需要重复显示的文本。 |
|  *number*  | 用于指定文本重复次数的正数。如果不是整数则截尾取整。如果 number_times 为 0（零），则 REPT 返回 ""（空文本）。 |



#### 注释

REPT 函数结果的长度不能超过 255 个字符。



#### 数据类型

接受text的字符串数据和number的数值数据。返回字符串数据。



#### 示例

REPT(D9, 2)

REPT(R9C4, 2)

REPT(""*4"", 3) 得出结果 *4*4*4
