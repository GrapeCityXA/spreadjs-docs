# SUBSTITUTE

此函数用新字符串替换现有字符串中的指定字符。



#### 语法

SUBSTITUTE( *text* , *old_piece* , *new_piece* , *instance* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *text*  | 需要替换其中字符的文本 |
|  *old_piece*  | 要替换的字符串 |
|  *new_piece*  | 使用新字符串代替现有字符串 |
|  *instance*  | [可选] 指定要用 new_piece 替换 old_piece 的事件。 |



#### 注释

如果需要在某一文本字符串中替换特定位置处的任意文本，请使用函数[REPLACE](gcdocsite__documentlink?toc-item-id=a9c420ba-68f4-4c0b-948f-32f7cb615ee7)



#### 数据类型

接收text、old_piece、new_piece参数的字符串数据，以及instance参数的数值数据。返回字符串数据。



#### 示例

SUBSTITUTE(""Down Trend"",""Down"",""Up"") 得出结果 Up Trend

SUBSTITUTE(""Feb 1, 1991"",""1"",""2"", 3) 得出结果 Feb 1, 1992
