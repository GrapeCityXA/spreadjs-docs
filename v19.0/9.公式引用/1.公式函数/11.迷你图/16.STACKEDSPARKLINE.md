# STACKEDSPARKLINE

此函数返回用于表示堆叠迷你图的数据集



#### 语法

STACKEDSPARKLINE( *points, [colorRange, labelRange, maximum, targetRed, targetGreen, targetBlue, tragetYellow, color, highlightPosition, vertical, textOrientation, textSize]* )



#### 参数

| 参数 | 描述 |
|--- |--- |
|  *Points*  | 表示包含值的单元格区域的引用，例如“A1:A4”。 |
|  *ColorRange*  | (可选)表示包含所有颜色的单元格区域的引用，例如“B1:B4”。默认值由颜色生成。 |
|  *LabelRange*  | (可选)表示包含所有标签的单元格区域的引用，例如“C1:C4”。默认值为空。 |
|  *Maximum*  | (可选) 表示迷你图最大值的数字。默认值是所有正值的汇总。 |
|  *TargetRed*  | (可选)表示红线位置的数字。默认值为空。 |
|  *TargetGreen*  | (可选) 表示绿线位置的数字。默认值为空。 |
|  *TargetBlue*  | (可选) 表示蓝线位置的数字。默认值为空。 |
|  *TargetYellow*  | (可选) 表示黄线位置的数字。默认值为空 |
|  *Color*  | (可选) 如果省略了 colorRange，则表示颜色的字符串。默认值为“#646464”。 |
|  *HighlightPosition*  | (可选) 一个数字，表示高亮区域的索引。默认值为空。 |
|  *Vertical*  | (可选) 一个布尔值，表示是否垂直显示迷你图。默认值为false。 |
|  *TextOrientation*  | (可选) 表示标签文本方向的数字。默认值为 0（水平）。垂直设置为 1。 |
|  *TextSize*  | (可选) 一个表示标签文本大小的数字。默认值为 10。单位为 px。 |



#### 数据类型

返回sparkline.



#### 例子

activeSheet.setFormula(2, 4, '=STACKEDSPARKLINE(B3:D3,B8:D8,B2:D2,40000)');
