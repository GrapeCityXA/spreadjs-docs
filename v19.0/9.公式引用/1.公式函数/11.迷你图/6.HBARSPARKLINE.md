# HBARSPARKLINE

此函数返回用于表示 Hbar 迷你图的数据集。



#### 语法

HBARSPARKLINE( *value, [colorScheme, axisVisible, barHeight]* )



#### 参数

| 参数 | 描述 |
|--- |--- |
| value | 表示条形长度的数字或参考。该值应介于 100% 和 -100% 之间。 |
| colorScheme | (可选) 表示条形颜色的字符串。默认值为"grey". |
| axisVisible | (可选) 一个布尔值，指示是否显示轴。默认值是true. |
| barHeight | (可选) 一个大于 0 且小于或等于 1 的数字，表示条形高度与单元格高度的百分比。 |



#### 数据类型

返回迷你图。



#### 例子

activeSheet.setFormula(0, 1, '=HBARSPARKLINE(A1,"red", FALSE, 0.5)');
