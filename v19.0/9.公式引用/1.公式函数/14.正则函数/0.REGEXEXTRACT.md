# extract

## 总结
REGEXEXTRACT 函数根据指定的正则表达式从字符串中提取文本。它支持提取第一个匹配项、所有匹配项，或从第一个匹配项中提取捕获组。

## **语法**
```javascript
=REGEXEXTRACT(text, pattern, [return_mode], [case_sensitivity])
```

## **参数**
| 参数 | 说明 |
| ---- | ---- |
| **text**<br>必填 | 输入文本或包含要从中提取文本的单元格引用。 |
| **pattern**<br>必填 | 定义要匹配的模式的正则表达式。 |
| **return\_mode** | 指定提取模式：<br>​**​0​**​（默认值）：返回第一个匹配项。<br>​**​1​**​：以数组形式返回所有匹配项。<br>​**​2​**​：以数组形式返回第一个匹配项的捕获组。<br>注意：捕获组是用括号 (...) 括起来的正则表达式子模式，可用于提取特定的匹配片段。 |
| **case\_sensitivity** | 控制大小写敏感性：<br>​**​0​**​（默认值）：区分大小写。<br>​**​1​**​：不区分大小写。 |

## 示例
```cpp
=REGEXEXTRACT("10 apples, 12 oranges","[0-9]+")  // 10
=REGEXEXTRACT("10 apples, 12 oranges","[0-9]+", 1)  // [10, 12]
=REGEXEXTRACT("09/12/1998 from James","\d{1,2}/\d{1,2}/\d{2,4}\b") // 09/12/1998
=REGEXEXTRACT("Sonia (378) 555-4195","\d{3}-\d{4}") // 555-4195
=REGEXEXTRACT("O my Luve red rose", "O my (\w+) red (\w+)") // O my Luve red rose
=REGEXEXTRACT("O my Luve red rose", "O my (\w+) red (\w+)", 2)  //["Luve", "rose"]
```

> REGEXEXTRACT 函数与 Excel 的实现方式一致。旧版的 SJS.REGEXEXTRACT 函数已弃用，但仍保持向后兼容。主要区别如下：

| **特性** | **REGEXEXTRACT** | **SJS.REGEXEXTRACT** |
| ---- | ---- | ---- |
| 参数类型 | 使用数值型的 return\_mode 和 case\_sensitivity。<br>`=REGEXEXTRACT("aa","A",1,1)` | 使用字符串修饰符（例如，"ig"）。<br>`=SJS.REGEXEXTRACT("aa","A","ig")` |
| 捕获组 | 当 **return\_mode**=2 时启用<br>`=REGEXEXTRACT("O my Luve is like a red, red rose","O my (\w+) is like a red, red (\w+)",2)` | 默认启用<br>`=SJS.REGEXEXTRACT("O my Luve is like a red, red rose","O my (\w+) is like a red, red (\w+)")` |
| 提取所有匹配项 | 使用 return\_mode=1<br>`=REGEXEXTRACT("O my Luve is like a red, red rose. O my Luve is like a red, red rose","O my (\w+) is like a red, red (\w+)",1)` | 需要 `"g"` 修饰符<br>`=SJS.REGEXEXTRACT("O my Luve is like a red, red rose. O my Luve is like a red, red rose","O my (\w+) is like a red, red (\w+)","g")` |
| 提取第一个匹配项 | 默认行为<br>`=REGEXEXTRACT("O my Luve is like a red, red rose. O my Luve is like a red, red rose","O my (\w+) is like a red, red (\w+)")` | 不支持 |
| 多行处理 | 需要正则表达式语法<br>`=REGEXEXTRACT("aaa`<br>\`aaa","^a | \\na",1)\` |
| 非字符串输入 | 转换数字<br>`=REGEXEXTRACT(1234,"1")` | 对于非字符串返回 `#VALUE!`。 |
