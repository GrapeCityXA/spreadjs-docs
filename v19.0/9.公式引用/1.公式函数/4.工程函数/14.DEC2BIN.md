# DEC2BIN

此函数将十进制数转换为二进制数。



#### 语法

DEC2BIN( *number* , *places* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *number*  | 要在-512到511区域内转换的十进制数值 |
|  *places*  | [可选] 要使用的字符数。如果不是整数，则将截尾取整。 |

如果省略 places，则 DEC2BIN 使用必要的最小字符数。 Places 可用于在返回的值前置 0（零）。



#### 注释

如果 number、places为非数值型则 DEC2BIN 返回 #VALUE！ 。

如果 number <-512 或 number > 511，DEC2BIN 返回 #NUM！ 。



#### 数据类型

接受数值数据。返回数值数据。



#### 示例

DEC2BIN(3,3)
