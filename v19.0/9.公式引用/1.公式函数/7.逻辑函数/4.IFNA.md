# IFNA

如果公式返回错误值 #N/A，则该函数返回您指定的值；否则返回公式的结果。



#### 语法

IFNA( *value, value_if_na* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *value*  | 用于检查错误值 #N/A 的参数。 |
|  *value_if_na*  | 公式计算结果为错误值 #N/A 时要返回的值。 |



#### 注释

如果 value 或 value_if_na 是空单元格，则 IFNA 将其视为空字符串值 ("")。



#### 数据类型

接受两个参数的数值，字符串（或任何表达式）数据。



#### 示例

IFNA(VLOOKUP("Sweden",$A$6:$B$8,0),"Not found") 得出结果 Not found.
