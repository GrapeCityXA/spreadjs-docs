# IFS

该函数检查是否满足一个或多个条件，且返回符合第一个 TRUE 条件的值。



#### 语法

IFS( *condition,value1, [condition2,value2],...* )



#### 参数

此函数有以下参数:

| 参数 | 描述 |
|--- |--- |
|  *condition1*  | 计算结果为 TRUE 或 FALSE 的条件。 |
|  *value1*  | 当 condition1 的计算结果为 TRUE 时要返回的结果。 可以为空。 |
|  *[condition2,value2],...*  | [可选] 要比较的更多条件（嵌套IF语句）。 |



#### 注释

最多可以测试127种不同的条件。



#### 数据类型

接受两个参数的数值（布尔）数据。返回任何数据类型。



#### 示例

IFS(A2 89,"A",A2 79,"B") 得出结果 B.
