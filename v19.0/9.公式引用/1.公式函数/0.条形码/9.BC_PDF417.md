# BC_PDF417

此函数返回一个表示 PDF417 条码的数据集。

## 语法

`BC_PDF417(value, color, backgroudColor, errorCorrectionLevel, rows, columns, compact, quietZoneLeft, quietZoneRight, quietZoneTop, quietZoneBottom)`

## 参数

| 参数 | 说明 |
| ---- | ---- |
| *value* | 一个表示在二维码符号上进行编码内容的字符串。 |
| *color* | 表示条码颜色的一种颜色。默认值为 'rgb(0,0,0)'。 |
| *backgroundColor* | 表示条码背景颜色的一种颜色。默认值为 'rgb(255, 255, 255)'。 |
| *errorCorrectionLevel* | 一个表示 PDF417 纠错级别的字符串。其值有 'auto'（自动）。 |
| *rows* | 一个指定符号中行数的值。其值有 'auto'（自动）。 |
| *columns* | 一个指定符号中列数的值。其值有 'auto'（自动）。 |
| *compact* | 指定它是否为紧凑型 PDF417。默认值为 'false'（否）。 |
| *quietZoneLeft* | 一个表示左侧空白区大小的值。 |
| *quietZoneRight* | 一个表示右侧空白区大小的值。 |
| *quietZoneTop* | 一个表示顶部空白区大小的值。 |
| *quietZoneBottom* | 一个表示底部空白区大小的值。 |

## 数据类型

接受 35 个字母数字字符和 2710 个数字字符。返回条码迷你图。

## 示例

`sheet.setFormula(3, 3, '=BC_PDF417(C4)');`
