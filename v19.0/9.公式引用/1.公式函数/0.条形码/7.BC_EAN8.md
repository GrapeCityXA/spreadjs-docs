# BC_EAN8

此函数返回一个表示 EAN8 条码的数据集。

## 语法

`BC_EAN8(value, color, backgroundColor, showLabel, labelPosition, fontFamily, fontStyle, fontWeight, fontTextDecoration, fontTextAlign, fontSize, quietZoneLeft, quietZoneRight, quietZoneTop, quietZoneBottom)`

## 参数

| 参数 | 说明 |
| ---- | ---- |
| *value* | 指定值的长度必须为 7 位或 8 位。 |
| *color* | 表示条码颜色的一种颜色。默认值为 'rgb(0,0,0)'。 |
| *backgroundColor* | 表示条码背景颜色的一种颜色。默认值为 'rgb(255, 255, 255)'。 |
| *showLabel* | 指定当条码带有标签时是否显示标签文本。 |
| *labelPosition* | 一个表示显示标签时标签位置的值。 |
| *fontFamily* | 一个表示标签文本字体系列的字符串。默认值为 'sans-serif'（无衬线字体）。 |
| *fontStyle* | 一个表示标签文本字体样式的字符串。默认值为 'normal'（常规）。 |
| *fontWeight* | 一个表示标签文本字体粗细的字符串。默认值为 'normal'（常规）。 |
| *fontTextDecoration* | 一个表示标签文本文本装饰样式的字符串。默认值为 'none'（无装饰）。 |
| *fontTextAlign* | 一个表示标签文本文本对齐方式的字符串。默认值为 'center'（居中）。 |
| *fontSize* | 一个表示标签文本字体大小的字符串。默认值为 '12px'。 |
| *quietZoneLeft* | 一个表示左侧空白区大小的值。 |
| *quietZoneRight* | 一个表示右侧空白区大小的值。 |
| *quietZoneTop* | 一个表示顶部空白区大小的值。 |
| *quietZoneBottom* | 一个表示底部空白区大小的值。 |

## 数据类型

仅接受由七个数字组成的字符串来计算校验位。返回条码迷你图。

## 示例

`sheet.setFormula(3, 3, '=BC_EAN8(C4)');`
