# INT

此函数返回将数字向下舍入到最接近的整数。



#### 语法

INT( *value* )



#### 参数

参数为任意数值。



#### 注释

您可以使用此函数通过从单元格中的值减去该单元格的值来返回单元格中值的小数部分，如第一个示例所示。

TRUNC和INT函数的相似之处在于它们都返回整数。使用[ TRUNC ](gcdocsite__documentlink?toc-item-id=012cbd02-a044-4b21-8f49-56fc9d1b51a7)函数删除数字的小数部分，TRUNC函数不向上或向下取整。使用INT函数可将数字四舍五入到最接近的基于整数的小数部分。使用负数时，这些函数也有所不同：TRUNC（–4.2）返回–4，但是INT（–4.2）返回–5，因为–5是较小的数字。



#### 数据类型

接受数值数据。返回数值数据。



#### 示例

INT(A3)

R1C2-INT(R1C2)

INT(2.85) 得出结果 2

INT(-2.85) 得出结果 -3
