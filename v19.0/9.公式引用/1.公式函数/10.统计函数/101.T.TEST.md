# T.TEST

此函数返回与学生 t-检验相关的概率。



#### 语法

T.TEST( *array1* , *array2* , *tails* , *type* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *array1*  | 第一个数据集。 |
|  *array2*  | 第二个数据集。 |
|  *tails*  | 指定的分布尾数。 |
|  *type*  | 要执行的 t 检验的类型。 |



#### 注释

参数 tails 和 type 将被截尾取整。如果 tails 或 type 为非数值型，则 T. TEST 返回 #VALUE！ 。



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

T.TEST(A1:A17,B1:B17,4,3)

T.TEST({2,2,2,3,4},{2,3,3,4,5},1,2) 得出结果 0.1260360000000153
