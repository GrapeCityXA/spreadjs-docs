# QUARTILE.EXC

此函数基于 0 到 1 之间（不包括 0 和 1）的百分点值返回数据集的四分位数。



#### 语法

QUARTILE.EXC( *array* , *quart* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *array*  | 要求得四分位数值的数组或数字型单元格区域。 |
|  *quart*  | 指定返回哪一个值。 |



#### 注释

四分之一是25％。因此，四分位数是0（数据集中的最小值）和4（数据集中的最大值）之间的整数，如下表所示。

| 如果number为... | 函数 QUARTILE 返回... |
|--- |--- |
| 0 | 最小值 |
| 1 | 第一个四分位数（第 25 个百分点值） |
| 2 | 中分位数（第 50 个百分点值） |
| 3 | 第三个四分位数（第 75 个百分点值） |
| 4 | 最大值 |

如果 array 为空，则返回 #NUM！ 。



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

QUARTILE.EXC(A1:A17,2)

QUARTILE.EXC(R1C1:R17C1,3)

QUARTILE.EXC({11,21,42,27,18,29,32,52},1) 得出结果 18.75
