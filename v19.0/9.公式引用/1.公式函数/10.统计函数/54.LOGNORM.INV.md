# LOGNORM.INV

此函数返回 x 的对数累积分布函数的反函数值。



#### 语法

LOGNORM.INV( *prob* , *mean* , *stdev* )



#### 参数

该函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *prob*  | 用来计算函数的值。 |
|  *mean*  | ln(x) 的平均值。 |
|  *stdev*  | ln(x) 的标准偏差。 |



#### 注释

如果 p = LOGNORM.DIST(x,...)，则 LOGNORM.INV(p,...) = x。如果任一参数为非数值型，则 LOGNORM.INV 返回 错误值 #VALUE!。



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

LOGNORM.INV(0.92,B8,G22)

LOGNORM.INV(0.88,2,1.2) 得出结果 30.264764580330958
