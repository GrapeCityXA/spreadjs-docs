# RANK.AVG

此函数返回一列数字的数字排位。



#### 语法

RANK.AVG( *number* , *array* , *order* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *number*  | 要找到其排位的数字。 |
|  *array*  | 对数字列表的引用。 |
|  *order*  | [可选]如何对数字进行排序，以降序（0或省略）或升序（非零值 |



#### 注释

返回一列数字的数字排位：数字的排位是其大小与列表中其他值的比值；如果多个值具有相同的排位，则将返回平均排位。



#### 数据类型

接受 number 的数值数据，array 的引用和order 的数值数据。 返回数值数据。



#### 示例

RANK.AVG(B3,B1:B8,1)

RANK.AVG(R3C2,R1C2:R8C2,1)
