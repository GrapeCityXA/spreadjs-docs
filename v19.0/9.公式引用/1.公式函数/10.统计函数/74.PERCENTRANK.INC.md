# PERCENTRANK.INC

此函数返回某个数值在数据集中的排位作为数据集的百分比值，此处的百分比值的范围为 0 到 1（含 0 和 1）。



#### 语法

PERCENTRANK.INC( *array* , *n* , *sigdig* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *array*  | 定义相对位置的数值数组或数值数据区域。 |
|  *n*  | 需要得到其排位的值。 |
|  *sigdig*  | [可选] 用于标识返回的百分比值的有效位数的值。如果省略，则 PERCENTRANK.INC 使用 3 位小数 (0.xxx)。如果不是整数则截尾取整。 |





#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

PERCENTRANK.INC(A1:A12,0.95)

PERCENTRANK.INC(R1C1:R1C45,0.866)

PERCENTRANK.INC(A1:A17,23,3)

PERCENTRANK.INC(R1C1:R43:C1,255.4,2)

PERCENTRANK.INC({10,12,13,14,14,14.5,16,17.5,17.75,20,22},18,4) 得出结果 0.8111

PERCENTRANK.INC({10,12,13,14,14,14.5,16,17.5,17.75,20,22},18,1) 得出结果 0.8
