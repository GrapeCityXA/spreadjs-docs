# LINEST

此函数计算某直线的统计值



#### 语法

LINEST( *y* , *x* , *constant* , *stats* )



#### 参数

直线公式为 y=mx+b or y=m1x1+m2x2+...+b.

该函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *y*  | 关系表达式 y = mx + b 中已知的 y 值集合。 |
| x | (可选) 关系表达式 y = mx + b 中已知的 x 值集合。 |
|  *constant*  | 一个逻辑值，用于指定是否将常量 b 强制设为 0。如果 const 为 TRUE 或省略，b 将按正常计算。 如果 const 为 FALSE，b 将被设为 0，并同时调整 m 值使 y = mx。 |
|  *stats*  | 一个逻辑值，用于指定是否返回附加回归统计值。如果为 TRUE返回附加的回归统计值，如果为 FALSE 或省略，则返回系数 m 和常量 b。 |



如果省略 x，则假设该数组为 {1,2,3,...}，其大小与 y 相同。



#### 注释

使用[ INDEX ](gcdocsite__documentlink?toc-item-id=61ae5b9c-8a40-4dfe-a7ad-ee6c4c7d9cd1)函数从返回的区域中获取单个元素。



#### 数据类型

接受区域。返回区域。



#### 示例

LINEST(A2:A7,C2:C7,,FALSE)
