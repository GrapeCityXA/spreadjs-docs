# CrossWorkbookFormula

SpreadJS 支持通过引用和使用不同工作簿中的数据来计算值的公式。这些公式被称为跨工作簿公式，可以通过以下语法使用：
`filePath[workbookName]sheetName'!CellOrRangeAddress`
例如：“=[Calc.xlsx]Sheet1!A1”，“=[Calc.xlsx]Sheet1!A1:B3”

> **注意**：跨工作簿引用不支持动态数组溢出或 INDIRECT 函数。

## 更新引用

你可以使用工作簿 JSON 设置或更新外部数据源的数据。[updateExternalReference ](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0#updateexternalreference)方法接受以下参数。

| **参数** | **描述** |
| --- | --- |
| linkName | 表示外部数据源的文件名；通常以“.xlsx”结尾。 |
| data | 表示外部数据源的 JSON 数据。<br>它可以是 `spread.toJSON()`，也可以通过 `data[工作表名称][行索引][列索引]` 获取数据。 |
| filePath | 表示文件路径或文件链接。<br>如果没有重复的 linkName，此参数的值可以为 null。 |
| isMergeUpdate | 表示是否通过合并进行更新。<br>请注意，如果此参数设置为 false，整个外部工作表的数据将被覆盖。 |

以下 GIF 展示了在“工作簿 1”中更新 A1 单元格时，SpreadJS 如何更新“工作簿 1”和“工作簿 2”中设置的外部引用。
![cross-workbook-formula](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/cross-workbook-formula.722fc4.gif)

```JavaScript
var spread1 = new GC.Spread.Sheets.Workbook(document.getElementById('ss1'), { sheetCount: 1 });
var spread2 = new GC.Spread.Sheets.Workbook(document.getElementById('ss2'), { sheetCount: 1 });
            
// 在 Spread1 的 A1 单元格中设置值
spread1.sheets[0].setValue(0, 0, 5);

var spread1Task;
function updateSpread1() {
    if (!spread1Task) {
        spread1Task = setTimeout(() => {
            spread1.updateExternalReference("calc.xlsx", spread2.toJSON());
            spread1Task = null;
        })
    }
}

var spread2Task;
function updateSpread2() {
    if (!spread2Task) {
        spread2Task = setTimeout(() => {
            spread2.updateExternalReference("result.xlsx", spread1.toJSON());
            spread2Task = null;
        })
    }
}

spread1.bind(GC.Spread.Sheets.Events.ValueChanged, updateSpread2)
spread1.bind(GC.Spread.Sheets.Events.RangeChanged, updateSpread2)
spread2.bind(GC.Spread.Sheets.Events.ValueChanged, updateSpread1)
spread2.bind(GC.Spread.Sheets.Events.RangeChanged, updateSpread1)

// 示例
spread1.updateExternalReference("calc.xlsx", spread2.toJSON());
spread2.updateExternalReference("result.xlsx", spread1.toJSON());
spread1.sheets[0].setFormula(1, 0, "='[calc.xlsx]Sheet1'!A1");
spread2.sheets[0].setFormula(0, 0, "='[result.xlsx]Sheet1'!A1^2");
```

此外，通过将 `isMergeUpdate` 参数设置为 true，还可以部分更新外部数据源的数据。以下是设置跨工作簿公式并部分更新外部数据源的示例。

```javascript
var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });
spread.getActiveSheet().setFormula(0, 0, "=SUM('D:\\[calc.xlsx]Sheet1'!A1:B2");  	// spread 的 A1 单元格值为 #REF!
spread.updateExternalReference("calc.xlsx", { "Sheet1": [[1, 2], [1, 3]] });  	// spread 的 A1 单元格值为 7
spread.updateExternalReference("calc.xlsx", { "Sheet1": [[], [11, 13]] }, "D:\\" /* 或 null */, true); 	// spread 的 A1 单元格值为 27，外部数据为 {"Sheet1":[[1, 2],[11, 13]]}
spread.updateExternalReference("calc.xlsx", { "Sheet1": [[], [1, 13]] }, null /* 或 "D:\\" */); 	// spread 的 A1 单元格值为 14，外部数据为 {"Sheet1":[[null, null],[1, 13]]}
```

## 获取引用

你可以获取当前工作簿的跨工作簿引用列表。[getExternalReferences ](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0#getexternalreferences)方法返回一个对象数组，其中包含跨工作簿引用的文件名和文件路径。
以下代码示例展示了如何获取当前工作表中使用的外部引用列表。

```JavaScript
var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"), { sheetCount: 1 });
var sheet = spread.getActiveSheet();
sheet.setFormula(0, 0, "='[Jackson.xlsx]Sheet1'!A1");
sheet.setFormula(1, 0, "='[Petrosky]Sheet1'!A1");
console.log(spread.getExternalReferences());

// 输出：
// Array(2)
// 0: { name: 'Jackson.xlsx', filePath: '' }
// 1: { name: 'Petrosky', filePath: '' }
```
