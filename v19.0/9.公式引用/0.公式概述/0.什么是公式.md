# whatisaformula

公式可以由值、运算符和函数组成。数据可以来自其他单元格、另一个单元格中的数据与硬编码数据的组合（例如，A1 + 2），或者仅仅是硬编码数据（例如，SUM(4, 5)）。公式可以对其他单元格中的值执行数学运算，如加法和乘法，也可以比较其他单元格中的值。公式可以通过绝对单元格位置或相对于包含该公式的单元格的相对位置来引用同一工作表中的单元格；它们可以引用单个单元格或一系列相邻的单元格。如果被引用单元格中的值发生变化，那么公式所在单元格的值也会改变。
公式可以由以下部分组成：
* 单元格引用和单元格区域（表示单元格地址的符号）
* 运算符（作用于一个或两个值）
* 内置函数（预定义的公式）
* 常量或常量数组（您输入的不会改变的值）
## 公式示例
使用 `Worksheet` 类中的 `setFormula` 方法来指定公式。返回 `formula` 属性的值会得到一个包含公式书写表达式的字符串，例如，SUM(A1:B1)。
在代码中，用 JavaScript 设置公式的方式大致如下（仅作示例）：
`sheet.getCell(2, 0).formula = "SUM(A1:A10)"`
如果是最终用户在单元格中输入的公式则为：
`=SUM(A1:A10)`
在本文档中，展示的示例公式如下：
`SUM(A1:A10)`
或者
`SUM(3,4,5) 的结果为 12`
以此表示该公式的结果会在单元格中显示值 12。
