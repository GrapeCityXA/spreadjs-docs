# CustomPDFExport

**savePDF** 方法的 **Workbook 类** 可用于在处理工作表时执行导出PDF操作。
在SpreadJS中，用户可以使用 **printInfo** 对象根据工作簿中指定的打印设置执行自定义PDF导出。 对于每张工作表，用户可以通过指定工作表的printInfo选项来设置详细选项。
本示例说明如何使用 **printInfo** 对象为自定义PDF导出设置详细选项。

```JavaScript
var sheet = SpreadJS[0];
var printInfo = sheet.printInfo();
printInfo.showGridLine(false);
printInfo.showRowHeader(GC.Spread.Sheets.Print.PrintVisibilityType.show);
printInfo.showColumnHeader(GC.Spread.Sheets.Print.PrintVisibilityType.show);
```

用户还可以使用 **printInfo** 对象的 **blackAndWhite** 属性将工作表导出为黑白PDF文件。
本示例说明如何使用 **blackAndWhite** 属性以黑白格式导出PDF文件。

```JavaScript
// 初始化Spread
var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });
// 获取工作表
var activeSheet = spread.getSheet(0);

var dataArray = [
    ['', '2012', '2013', '2014', '2015', '2016', '2017'],
    ['Chrome', 0.3782, 0.4663, 0.4966, 0.5689, 0.623, 0.636],
    ['FireFox', 0.2284, 0.203, 0.1801, 0.156, 0.1531, 0.1304],
    ['IE', 0.3214, 0.2491, 0.2455, 0.1652, 0.1073, 0.0834],
];
activeSheet.setArray(0, 0, dataArray);

var chart = activeSheet.charts.add('line', GC.Spread.Sheets.Charts.ChartType.bar, 0, 100, 400, 300, 'A1:D4');
var legend = chart.legend();
legend.visible = true;
chart.legend(legend);
chart.title({ text: 'Bar Chart' });

// PDF black & white
var printInfo = new GC.Spread.Sheets.Print.PrintInfo();
printInfo.blackAndWhite(true);
printInfo.savePDF = true;
activeSheet.printInfo(printInfo);
spread.print(0);
```
