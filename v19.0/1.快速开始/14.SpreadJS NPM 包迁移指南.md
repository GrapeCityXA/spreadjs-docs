# npm-package-migration-guide

自 **19 版本**起，所有 SpreadJS 库将统一发布在新的 [@grapecity-software](https://www.npmjs.com/package/@grapecity-software/spread-sheets) NPM 命名空间下。原有的 [@grapecity](https://www.npmjs.com/package/@grapecity/spread-sheets) 命名空间将不再更新和维护。

>type=info
> **注意：** 所有 @grapecity 包仍会保留在 NPM 上，供旧项目使用，但在 18.2.5 版本后将不再更新或提供技术支持。

**请务必迁移**：如需获得最新功能、修复和技术支持，请将项目依赖从 `@grapecity` 迁移到 `@grapecity-software`。

***

## 1\. 迁移步骤

请按照以下步骤安全地完成迁移：

### 步骤 1：打开您的项目

1. 用您常用的代码编辑器（如 **VS Code**）打开项目文件夹。
2. 建议在操作前备份项目或确保有最新的提交记录。

### 步骤 2：更新命名空间引用

需要将所有 `@grapecity/` 替换为 `@grapecity-software/`，主要包括：

* `package.json` 中的依赖项
* 源代码中的 import 语句

**推荐使用编辑器的查找替换功能：**

1. 打开查找替换（VS Code 可按 `Ctrl + Shift + F`）。
2. 查找内容输入：

    ```auto
    @grapecity/
    ```
3. 替换为：

    ```auto
    @grapecity-software/
    ```
4. 全部替换（或逐条确认）。
5. 保存所有修改过的文件。

### 步骤 3：更新依赖

1. 打开终端，执行：

    ```auto
    npm install
    ```

    或者如果使用 yarn：

    ```auto
    yarn install
    ```
2. 这将从新的 `@grapecity-software` 命名空间下载并安装所有依赖包。

### 步骤 4：验证迁移结果

1. 检查 `package.json`，依赖应类似如下：

    ```json
    {
      "dependencies": {
        "@grapecity-software/spread-sheets": "^19.0.0",
      }
    }
    ```
2. 检查代码中的 import 语句，例如：

    ```js
    import * as GC from "@grapecity-software/spread-sheets";
    ```
3. 运行项目，确保 SpreadJS 功能正常。

### 步骤 5：清理（可选）

迁移完成后，可清理缓存和旧包：

```auto
npm prune
npm cache clean --force
```

## 2\. 常见问题与排查

| 问题 | 可能原因 | 解决方法 |
| --- | ---- | ---- |
| 构建报缺少模块 | 仍有 `@grapecity` 引用 | 全局查找并替换所有 `@grapecity/` |
| 版本冲突 | 依赖版本不一致 | 确保所有 `@grapecity-software/spread-*` 包为同一主版本号 |
| TypeScript 类型报错 | 新旧命名空间混用 | 删除 `node_modules`，重新安装依赖 |
