## SpreadJS 授权

通过以下步骤给 SpreadJS 添加授权：

1. 将下载的 SpreadJSLicensedX.XX.XXXX.X.zip 解压缩到试用版所在的位置，然后替换该位置上的所有现有文件。
2. 添加对您在购买产品时收到的SpreadJS许可证的引用。 在工作簿初始化之前添加引用。
    例如：

    ```JavaScript
    <script src="./scripts/evaluation/gc.spread.sheets.all.14.1.0.min.js" type="application/javascript"></script>
    <script>
       GC.Spread.Sheets.LicenseKey = "xxx";
    </script>
    ```

    或者

    ```JavaScript
    <script src="./scripts/evaluation/gc.spread.sheets.all.14.1.0.min.js" type="application/javascript"></script>
    <script src="./scripts/evaluation/licensekey.js" type="application/javascript"></script>
    <script>
    window.onload = function () {
        var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'));
        var activeSheet = spread.getActiveSheet();
    };
    
     </script>
    
    // licensekey.js file:
    GC.Spread.Sheets.LicenseKey = "xxxxxx";
    ```

>type=info
> **注意:** 如果您没有试用或生产许可证，则 SpreadJS 只能在本地计算机上使用（例如：http(s)://localhost 或http(s)://127.0.0.1。

SpreadJS 同样支持多种 JavaScript 框架。在应用程序中使用 SpreadJS 时，若存在有效的 SpreadJS 许可证密钥，请在初始化组件前添加该密钥。

```javascript
<script>
    GC.Spread.Sheets.LicenseKey = "xxxx";        // 输入有效的许可证密钥。      
</script>
```

## **SpreadJS 许可证错误处理（v18.2.0 及以上版本）​**

自 18.2.0 版本起，SpreadJS 增强了许可证验证反馈功能，以简化问题排查流程。目前主要的错误场景包括：

1. **许可证缺失（Missing License）**
2. **许可证字符串无效（Invalid License String）**
3. **产品不匹配（Product Mismatch）**
    a. 针对“设计器功能区（Designer Ribbon）”会明确标识具体产品。
    b. 其他产品不匹配情况则显示通用的“无效许可证（Invalid License）”。
4. **版本兼容性（Version Compatibility）**
    a. 对 ≥16.0.0 版本的发行版强制进行版本校验。
5. **许可证过期（Expired License）**
6. **域名验证（Hostname Validation）**

**多错误处理（Multi-Error Handling）**
当存在多个问题时，系统会优先提示最关键的错误（例如，版本不匹配会优先于许可证过期显示）。

## SpreadJS 设计器

没有许可证密钥的SpreadJS Designer可以免费试用30天。
选择锁定图标，然后输入您的许可证密钥以解锁SpreadJS Designer。

## 插件授权

你可以选择连同插件功能一起购买 SpreadJS 许可证。下表描述了两种情况下的产品行为：

| **使用场景** | **许可证密钥（SpreadJS 和插件）** | **许可证密钥（SpreadJS）** |
| ---- | ------------------- | --------------- |
| 无授权 | 不适用 | 所有 SpreadJS 功能都可用，并且可以在本地机器上运行。 |
| 有试用授权 | 所有 SpreadJS, 透视表, 甘特表, 报表, 数据表, 设计器组件的功能均可用，直到试用过期。（插件的功能取决于您的授权类型） | 所有 SpreadJS 的功能均可用，直到试用过期。 |
| 有正式授权 | 所有 SpreadJS, 透视表, 甘特表, 报表, 数据表, 设计器组件的功能均可用。（插件的功能取决于您的授权类型） | 所有 SpreadJS 的功能均可用。 |

>type=info
> **注意**： 如果在本地添加并使用数据透视表、甘特图工作表、报表、数据图表或设计器功能区组件脚本而没有密钥，将显示水印。如果你在应用程序中使用该脚本，必须为该功能激活 SpreadJS 生产许可证密钥。

## 升级到最新版本

将 SpreadJS 升级到最新版本可确保你能使用最新的功能和增强功能。当你将 SpreadJS 从旧版本升级到最新版本时，需要采取以下操作：

* **替换许可证密钥**：获取最新版本 SpreadJS 的新许可证密钥，并更新应用程序中的 `LicenseKey` 字符串。
* **更新引用**：确保系统中的所有引用都指向与最新版本相关联的新脚本文件。

>type=info
> **注意**：SpreadJS 是向后兼容的，因此即使在升级后，你之前的配置和数据也将继续无缝工作。
