# 190

## 新增特性

### 协作服务器

**[实时协作](gcdocsite__documentlink?toc-item-id=bbf7441b-5b6a-423b-b146-2fbda7053f92)**: SpreadJS 的实时协作功能已结束 Beta 测试并正式发布。该功能通过协作服务器端组件，支持多名用户同时编辑同一个电子表格。

* 实时同步单元格编辑、格式更改和结构修改
* 协作解决方案中支持 [协作式撤销/重做](gcdocsite__documentlink?toc-item-id=386ef288-dac1-4aea-b859-67c8ccb4a8d9)
* 切片器操作现在在协作模式下得到完全支持
* 为企业部署的协作插件添加了许可机制

### AI 助手插件

全新的 [AI 助手插件](gcdocsite__documentlink?toc-item-id=bd497cc2-8c3e-43fc-b7c0-48eb450a9347) 已正式发布，这款可选插件引入了 AI 驱动的功能，让用户能够通过自然语言更轻松地创建和分析电子表格。

* **[公式生成与解释](gcdocsite__documentlink?toc-item-id=eb5d8069-dba5-4f5f-b8e7-a9e9ad9a76ea)** — 通过自然语言即时创建和理解复杂公式。
* **[AI 驱动的数据透视表创建](gcdocsite__documentlink?toc-item-id=bf70efa1-9523-4a87-b5ac-e1a2a60a0f29)** — 通过简单的描述性输入生成数据透视表并获取数据洞察。
* **[AI 工作表函数](gcdocsite__documentlink?toc-item-id=73aa0482-aefc-4f75-b456-18583c374168)** — 直接在单元格中执行文本处理、数据提取和智能分析任务。

### 性能和计算

* [使用 Web Worker 运行增量计算](gcdocsite__documentlink?toc-item-id=8b1aba5c-57d2-4307-8a29-1343a0697f26#%E4%BD%BF%E7%94%A8-web-worker-%E8%BF%90%E8%A1%8C%E5%A2%9E%E9%87%8F%E8%AE%A1%E7%AE%97): SpreadJS 现在利用 Web Worker 技术提升增量计算性能。通过并行化工作表渲染和计算任务，这一更新显著提高了 UI 响应速度，减少了界面延迟，并增强了整体性能和稳定性。

### Excel 兼容性

* **[单元格评论](gcdocsite__documentlink?toc-item-id=0b56f33f-0ad4-488f-833f-7edb23b81832)**: SpreadJS 现在支持 Excel 风格的单元格评论，允许用户直接在单元格评论中回复和讨论。评论功能无缝集成到现有注释界面中，通过缩进的回复提供更好的协作和上下文理解。
* **[两端对齐](gcdocsite__documentlink?toc-item-id=6ec6893b-05b8-4ead-9ff8-708e58688961)**: 新增了“两端对齐”（Justify）的水平和垂直对齐方式，匹配 Excel 的文本对齐功能。
* **[排序时排除标题行](gcdocsite__documentlink?toc-item-id=2110f53e-fcd2-48aa-a84d-522e4934c729#%E6%8E%92%E5%BA%8F%E6%97%B6%E6%8E%92%E9%99%A4%E6%95%B0%E6%8D%AE%E6%A0%87%E9%A2%98%E8%A1%8C)**: 用户现在可以通过勾选“数据包含标题”选项，在排序操作中排除标题行，与 Excel 的行为保持一致。

### 数据透视表（Pivot Table）

* **[拖放自定义排序](gcdocsite__documentlink?toc-item-id=f84bad32-54ce-4e94-87ac-1069f6db9724#%E6%8B%96%E6%94%BE%E6%8E%92%E5%BA%8F)**: 用户现在可以在数据透视表中拖放项目进行自定义排序，匹配 Excel 中手动排列透视项目的行为。
* **[日期分组步长值](gcdocsite__documentlink?toc-item-id=2243a886-847b-4ada-ae70-eac8cfd46d3d#%E5%88%86%E7%BB%84%E6%97%A5%E6%9C%9F)**: 新增了在数据透视表中设置自定义日期分组间隔的支持。用户现在可以按特定天数（例如，7 天用于每周分析）对数据进行分组。
* **[受保护工作表中的数据透视表](gcdocsite__documentlink?toc-item-id=b2d458d5-d6cc-44fe-a1aa-f986a9aad760#%E5%9C%A8%E5%8F%97%E4%BF%9D%E6%8A%A4%E5%B7%A5%E4%BD%9C%E8%A1%A8%E4%B8%AD%E5%90%AF%E7%94%A8%E6%95%B0%E6%8D%AE%E9%80%8F%E8%A7%86%E8%A1%A8%E5%8A%9F%E8%83%BD)**: 即使启用了工作表保护，数据透视表的筛选和数据分析功能现在也可以正常使用。

### 报表（ReportSheet）

* **[导出时保留公式](gcdocsite__documentlink?toc-item-id=30020391-039f-44ce-9549-0acab26e40e7)**: 将预览报表导出为 Excel 格式或转换为普通工作表时，某些公式（计算式、查找式、引用式）现在可以保留在单元格中，确保功能持续可用。
* **[容器汇总显示](gcdocsite__documentlink?toc-item-id=d7b85b3c-830f-4218-806b-b0827af257f8)**: 新增了在 ReportSheet 中使用容器时显示汇总行或汇总列的功能，实现聚合数据的展示。
* **[分页空白行填充](gcdocsite__documentlink?toc-item-id=0278f810-d804-4a90-a627-35782e02ece7)**: 生成分页报表时，当最后一页的记录数少于预期数量，用户现在可以自动用空白行填充剩余空间。
* **[基于分组的分页](gcdocsite__documentlink?toc-item-id=c907de26-fb16-4b16-833b-2a9a7fb86a77)**: ReportSheet 分页功能现在支持基于每个分组内的数据进行分页。
* **[增强型页面公式](gcdocsite__documentlink?toc-item-id=f7c52ba3-85bd-4f80-b9c3-9ad646c07f5b)**: `R.CurrentPage` 和 `R.PageCount` 公式现在支持 `useGroupContext` 参数，可获取分组内的页码。
* **[模板区域容器](gcdocsite__documentlink?toc-item-id=24f7b9b2-d4bb-4727-8b95-4a4c705a1b3f)**: 新增了对模板区域容器的支持，实现更灵活的报表模板设计。

### 数据图表（DataChart）

* **[组合图](gcdocsite__documentlink?toc-item-id=0bdfc6ad-ba3a-43f1-b93f-ff513ff7f38c)**: 数据图表现在支持组合图功能，允许在单个图表中使用多种图表类型（如柱形图和折线图），实现全面的数据可视化。
* **[瀑布图](gcdocsite__documentlink?toc-item-id=0a8cfe61-483b-46d2-ac26-e28cd543e5a6)**: 新增瀑布图类型，用于展示初始值如何通过一系列连续的增减变化演变为最终结果。
* **[K线图](gcdocsite__documentlink?toc-item-id=e610c77e-ce6e-48f1-80c0-ee3256e6feeb)**: 新增 K线图类型，用于金融数据可视化，展示开盘价、最高价、最低价和收盘价。
* **[开高低收图（OHLC图）](gcdocsite__documentlink?toc-item-id=369a9971-c272-4394-8042-8bcf691e9a4c)**: 新增开高低收（OHLC）图类型，适用于技术分析和交易场景。

### 设计器（Designer）

* **增强的分列功能**：优化了“分列”功能的性能，避免在处理大型数据集时出现浏览器崩溃。
* **[批量删除名称](gcdocsite__documentlink?toc-item-id=3405eaa9-d0d2-4dd3-aaee-d84a310e9bad#%E6%89%B9%E9%87%8F%E5%88%A0%E9%99%A4%E8%87%AA%E5%AE%9A%E4%B9%89%E5%90%8D%E7%A7%B0)**: 名称管理器对话框现在支持批量删除自定义名称，可通过 Shift+单击、Ctrl+单击或 Shift+方向键组合进行多选。

### 框架支持（Framework Support）

* **[Angular 20](gcdocsite__documentlink?toc-item-id=a8544786-9ff3-403c-a179-48cd6981eee3)**: SpreadJS 运行时和设计器组件的 Angular 封装现在已完全支持 Angular 20，包含更新后的 ng-packer 和演示示例。
* **[Nuxt.js 4](gcdocsite__documentlink?toc-item-id=6151e698-b68e-4297-a8d3-a1551ef0d8d6)**: 新增对 Nuxt.js v4 正式版的支持。

### 可访问性（Accessibility）

* **[WCAG 2.1 AA 标准兼容性优化](gcdocsite__documentlink?toc-item-id=7a01412b-1c48-4624-bc87-58892c2d240f)**: 增强了 SpreadJS 和设计器功能区组件的可访问性支持，优化了 ARIA 角色层级和表单元素标签，更好地符合 WCAG 2.1 AA 标准。
