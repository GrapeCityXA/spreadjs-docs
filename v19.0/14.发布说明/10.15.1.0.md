# rnotesv151




此版本的产品中包含以下功能和增强功能

- SpreadJS TableSheet 现在支持[多列头](tablesheet-views#i-heading-column-caption-multiple-headers)，以显示相关列的公共列头以及现有列。
- 向表格视图添加[添加列头](tablesheet-views#i-heading-free-header-area)，您可以在其中描述和显示表格的信息。
- SpreadJS Designer 引入了[TableShee设计模式](gcdocsite__documentlink?toc-item-id=ac09b6e6-9be4-4f73-83be-b945f3bb26d8)来添加多列头和自定制列头。
- 用户现在可以创建一个[Tablesheet层叠列头](gcdocsite__documentlink?toc-item-id=82fd1dec-c526-4aba-b29d-389ad61e198d)，在单个行视图中显示来自多个相关表的字段。
- 集算表视图[堆栈列头适应模式](tablesheet-views#i-heading-column-header-fit-mode)已得到增强，当列彼此相邻时，将以交叉调整方式与垂直模式一起显示。还引入了一个新的API选项来设置堆栈行高度。
         has been enhanced to display alongside the vertical mode in a cross-fit way when the columns are adjacent to each other. A new API option has also been introduced to set the stack row height.
- 数据透视表现在支持[显示无数据项](pivot-table-settings#i-heading-show-items-with-no-data)，使其能够在字段中显示空白单元格。
- 引入了[数据透视表时间线切片器](pt-slicer#i-heading-timeline-slicers)，可按日期、月份、年份和季度快速筛选数据。
- SpreadJS 现在支持使用[tablesheet作为数据源](create-pivot-table#i-heading-using-tablesheet-as-a-data-source)来创建数据透视表。
- 用户可以选择是否[自动扩展筛选区域](filter-operations#i-heading-auto-extend-filter-range)到原来的筛选区域之外。
- PROPERTY 公式函数现在支持[点运算符“.”](property-function#i-heading-dot-operator)，可以用作速记。
- [打印区域](gcdocsite__documentlink?toc-item-id=db693267-9b67-4f25-bdb1-8501cecc6be6)已得到增强，可以在用户定义打印区域时创建和维护自定义名称“Print_Area”。
- SpreadJS 现在在选项卡条中提供了一个[“所有工作表“](tabstrip#i-heading-the-all-sheets-button)按钮，有助于更快地导航到工作簿中的特定工作表。
- 引入了[跨工作簿公式](gcdocsite__documentlink?toc-item-id=5a4d7d0a-d763-4a1d-96ed-2337077d3246)，通过引用和使用来自不同工作簿的数据来计算值。
- 用户可以对工作表设置veryHidden，使不能通过UI操作[隐藏工作表](work-with-worksheets#i-heading-hide-or-unhide-worksheet)。/li>
- [形状的属性](gcdocsite__documentlink?toc-item-id=e8e242fd-7dd6-43d5-9975-9a845160fdd3)现在可以通过在公式中引用它们与工作表单元格链接。
- 支持[根据数据类型获取单元格区域](cell-range#i-heading-get-range-by-type-of-data)。
- [使用方法添加的迷你图](createspark#i-heading-sparklines-with-non-continuous-ranges)现在支持使用非连续数据区域，其中可以使用工作表中的随机值。
- 引入了新的[CellRange](gcdocsite__documentlink?toc-item-id=64f05fd4-fafa-47dc-9856-b74263f357ec)方法来设置单元格区域中的样式和命名样式。
- [拖放操作](dragdrop)增强，包括用于在工作表和表格中插入单元格的新移位操作。
- 可以使用[SpreadJS全球化](gcdocsite__documentlink?toc-item-id=eeca48ae-aa7b-4298-9164-d5f6c9b3ab0f)JavaScript 库在 Spread 工作表中使用其他文化信息。
- 用户现在可以在 SpreadJS 设计器组件中[自定义格式文化对话框](gcdocsite__documentlink?toc-item-id=7e9f71b1-646d-466b-ac59-34c105aff080)，以使用[CultureInfo](gcdocsite__documentlink?toc-item-id=36975826-ad1b-46dc-905c-05542a548c85)类定义新的文化选项。
- SpreadJS组件版设计器现在支持 Vue 3。请参阅[此处](gcdocsite__documentlink?toc-item-id=d066c949-916f-4e61-b987-8debe42703e1)以在 Vue 应用程序中添加 SpreadJS组件版设计器。
