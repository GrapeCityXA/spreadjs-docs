# 1901

## 问题修复

* 修复了在图表导入与导出之间，图表系列格式（如颜色、线型等）不一致的问题。
* 修复了在图表数据区域中删除行时，坐标轴会多出额外标签的问题。
* 修复了在自定义区域设置下，取消编辑公式后公式参数分隔符会从分号变成逗号的问题。
* 修复了导入 Excel 后，以工作表为单位导出 ssjson 时部分样式丢失的问题。
* 修复了导入某些 Excel 文件后导出为 PDF 时可能出现文件读写异常的问题。
* 修复了当 Data Table 的列名中包含点号（.）时行为异常的问题，提升带特殊列名数据源的兼容性。
* 修复了在数据源绑定到 TableSheet 后，触发型公式未能正确应用的问题，确保绑定数据后公式能按预期计算。
* 修复了设计器粘贴选项与 Excel 行为不一致的问题
