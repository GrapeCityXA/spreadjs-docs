# 1902

## 问题修复

* 修复了部分公式计算结果与 Excel、GcExcel 不一致的问题，提升公式计算的准确性。
* 修复了在启用增量计算后，部分单元格公式结果计算不正确的问题，确保在增量重算场景下结果与预期一致。
* 修复了在使用 setColumnDataFormula 设置列公式时计算耗时过长的问题，显著提升大数据量场景下的公式填充性能。
* 修复了在设计器中对已过滤数据点击“求和”按钮时仍使用 SUM 而非 SUBTOTAL 的问题，使行为与 Excel 保持一致。
* 修复了筛选项丢失的问题，确保在多次操作后筛选条件能被正确保留和展示。
* 修复了导出的 xlsx 文件中单元格边框未正确显示的问题，确保导出文档的样式与设计器中保持一致。
* 修复了在数据透视表字段较多时，双击字段名弹出的对话框无法关闭的问题，提升字段配置时的交互体验。
* 修复了在 Table 中自定义插入行并调整 Table 大小时，边框样式异常变为粗实线的问题，使表格边框样式在调整后保持一致。
* 修复了当数据行数少于列数时，股票图（Stock Chart）无法正常渲染的问题。
* 修复了 ReportSheet 中 “Expense Budget（支出预算）” 示例无法正常运行的问题。
* 修复了在 ReportSheet 中删除包含模板区域详情（Template Range Detail）的所有行或列时，可能导致界面崩溃的问题。
* 修复了在使用 Web Worker 进行增量计算时，通过 Range 接口设置公式可能导致计算结果不正确的问题。
* 修复了在特定 SJS 文件中修改单元格公式后，计算速度异常缓慢导致界面卡顿的问题。
* 修复了导入部分包含 XLOOKUP 函数的 Excel 文件时，XLOOKUP 公式会返回 #VALUE! 错误的问题。
* 修复了当 TableSheet 列标题（Caption）中包含方括号 [] 时，引用该列的公式会报错的问题。
* 修复了在使用 Gemini 模型的公式编辑 AI 助手时，返回的公式被错误地整体包裹在引号中的问题。
* 修复了特定日期时间字符串（如 "2026-02-28T17:07:59"）与数字相加时返回 #VALUE! 而非数值的问题。
* 优化了异步计算接口 evaluateExpressionAsync，使其支持 convertNullToZero 配置，以与同步接口保持一致。
* 修复了通过 TableSheet 侧边栏添加计算字段后，刷新数据源会导致 TableSheet 分组、列选择等状态丢失的问题。
* 修复了 TableSheet API 中 IColumn.style 和 IMenuItemVisibility 两处 TypeScript 类型定义错误的问题。
* 修复了导入 Excel 文件后，下拉列表选项可能被错误地显示为日期而不是文本的问题。
* 修复了在打印设置（printInfo）中将方向设置为纵向（Portrait）时，浏览器打印预览中可能出现多余空白页的问题。
* 修复了数据透视表（PivotTable）在高度受限的容器中打开筛选菜单时，布局可能发生偏移并产生空白区域的问题。
* 修复了在数据透视表中执行特定 UI 操作序列（如连续删除标题后按求和汇总）可能导致组件崩溃的问题。
* 修复了复选框（CheckBox）在切换模式后对齐方式显示异常的问题。
* 修复了 ReportSheet 设计器中“命名样式”列表右侧滚动条显示不完整的问题。
* 更新了帮助文档中与 React 相关的内容，使示例全面采用 Vite 和函数式组件（Functional Components）形式。
