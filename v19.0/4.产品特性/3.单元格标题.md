# headers

SpreadJS 允许您对单元格标题执行各类操作。

## 设置标题的高度与宽度

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/codehwid.9c6dc1.png)
本示例用于修改列标题高度与行标题宽度。

```javascript
$(document).ready(function () {
   // 初始化 Spread
   var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"), { sheetCount: 3 });
   // 获取活动工作表
   var sheet = spread.getActiveSheet();

   // 修改列标题高度
   sheet.setRowHeight(0, 90.0, GC.Spread.Sheets.SheetArea.colHeader);
   // 修改行标题宽度
   sheet.setColumnWidth(0, 90.0, GC.Spread.Sheets.SheetArea.rowHeader);
});
```

## 设置标题文本

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/codecheader.96b651.png)
本示例在标题中添加自定义文本。

```javascript
$(document).ready(function () {
    // 初始化 Spread    
    var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"), { sheetCount: 3 });
    // 获取活动工作表
    var sheet = spread.getActiveSheet();

    // 在标题中设置指定字符串
    sheet.setValue(0, 1, "列标题", GC.Spread.Sheets.SheetArea.colHeader);
    sheet.setValue(1, 0, "行标题", GC.Spread.Sheets.SheetArea.rowHeader);
    sheet.setColumnWidth(1, 120.0, GC.Spread.Sheets.SheetArea.colHeader);
    sheet.setColumnWidth(0, 90.0, GC.Spread.Sheets.SheetArea.rowHeader);
});
```

## 设置标题颜色

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/codecolor.1f2da5.png)
本示例用于设置标题的背景色与前景色。

```javascript
$(document).ready(function () {
   // 初始化 Spread
   var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"), { sheetCount: 3 });
   // 获取活动工作表
   var sheet = spread.getActiveSheet();

   // 为整个列标题设置背景色与前景色
   var row = sheet.getRange(0, -1, 1, -1, GC.Spread.Sheets.SheetArea.colHeader);
   row.backColor("Red"); // 背景色设为红色
   row.foreColor("White"); // 前景色设为白色

    // 为第二个行标题设置背景色
    sheet.getCell(1, 0, GC.Spread.Sheets.SheetArea.rowHeader).backColor("Yellow"); // 背景色设为黄色
});
```

## 合并标题单元格

![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/codespan.dd3168.png)
以下代码用于合并标题中的单元格。

```javascript
$(document).ready(function () {
    // 初始化 Spread    
    var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"), { sheetCount: 3 });
    // 获取活动工作表
    var activeSheet = spread.getActiveSheet();

    // 将列标题的行数设为 3
    activeSheet.setRowCount(3, GC.Spread.Sheets.SheetArea.colHeader);

    // 以列标题单元格（0,0）为起点，合并 3 列
    activeSheet.addSpan(0, 0, 1, 3, GC.Spread.Sheets.SheetArea.colHeader);

    // 以列标题单元格（1,0）为起点，合并 2 行
    activeSheet.addSpan(1, 0, 2, 1, GC.Spread.Sheets.SheetArea.colHeader);

    // 为合并后的单元格设置文本
    activeSheet.setValue(0, 0, "合并列", GC.Spread.Sheets.SheetArea.colHeader);
    activeSheet.setValue(1, 0, "合并行", GC.Spread.Sheets.SheetArea.colHeader);

    // 将行标题的列数设为 2
    activeSheet.setColumnCount(2, GC.Spread.Sheets.SheetArea.rowHeader);

    // 以行标题单元格（1,0）为起点，合并 2 行 2 列
    activeSheet.addSpan(1, 0, 2, 2, GC.Spread.Sheets.SheetArea.rowHeader);

    // 为合并后的单元格设置文本
    activeSheet.setValue(1, 0, "合并行与列", GC.Spread.Sheets.SheetArea.rowHeader);
});
```

## 在标题中创建多列多行

您可以显示多个列标题和行标题，并指定默认标题中显示字母、数字还是不显示任何内容，也可在标题中添加自定义文本。可使用**setRowCount**和**setColumnCount**方法指定标题的行数和列数。
默认情况下，点击某个标题会选中对应的行或列；将指针移到标题边缘的线条上时，还可调整列或行的大小——指针会变为双向箭头，此时拖动即可将列或行调整到新的宽度或高度。
在代码中，可通过`options.colHeaderAutoTextIndex`、`options.colHeaderAutoText`、`options.rowHeaderAutoTextIndex`和`options.rowHeaderAutoText`属性修改默认标题文本。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/codemultiple.000a08.png)

### 代码实现

本示例在标题中创建多行多列。

```javascript
// 初始化 Spread    
var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"), { sheetCount: 3 });
// 获取活动工作表
var activeSheet = spread.getActiveSheet();
// 将列标题的行数设为 3
activeSheet.setRowCount(3, GC.Spread.Sheets.SheetArea.colHeader);
// 将行标题的列数设为 4
activeSheet.setColumnCount(4, GC.Spread.Sheets.SheetArea.rowHeader);
});
```

本示例指定标题文本的类型和位置，并创建自定义标题文本。

```javascript
activeSheet.setRowCount(2, GC.Spread.Sheets.SheetArea.colHeader);
activeSheet.setColumnCount(2, GC.Spread.Sheets.SheetArea.rowHeader);
activeSheet.setValue(0, 2, "列", GC.Spread.Sheets.SheetArea.colHeader);
activeSheet.options.rowHeaderAutoTextIndex = 1;
activeSheet.options.rowHeaderAutoText = GC.Spread.Sheets.HeaderAutoText.numbers; // 行标题自动显示数字
activeSheet.options.colHeaderAutoTextIndex = 1;
activeSheet.options.colHeaderAutoText = GC.Spread.Sheets.HeaderAutoText.letters; // 列标题自动显示字母
```

## 在标题中添加/删除行与列

可使用**addRows**和**addColumns**方法在标题的指定位置添加行或列，这两个方法接受行索引/列索引、要添加的行数量/列数量等参数。
类似地，可使用**deleteRows**和**deleteColumns**方法从标题的指定位置删除行或列。
![addrow-header](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/addrow-header.7a3311.8731cf.png)
以下代码示例展示如何在列标题的指定位置添加行：

```auto
// 向列标题添加行
activeSheet.addRows(0, 1, GC.Spread.Sheets.SheetArea.colHeader);
// 向行标题添加列
activeSheet.addColumns(1, 3, GC.Spread.Sheets.SheetArea.rowHeader);
```

> **注意**：`addRows`/`addColumns`/`deleteRows`/`deleteColumns`方法不会自动调整`colHeaderAutoTextIndex`和`rowHeaderAutoTextIndex`选项。

## 通过鼠标点击获取标题单元格索引

本示例通过鼠标选中标题单元格时，获取该单元格的索引。

```javascript
$(document).ready(function () {
    var spread = new GC.Spread.Sheets.Workbook($("#ss")[0]);
    var activeSheet = spread.getActiveSheet();
    activeSheet.setRowCount(4, GC.Spread.Sheets.SheetArea.colHeader);
    $("#ss").click(function (e)

    // 从鼠标点击的列标题单元格位置获取单元格索引
    var offset = $("#ss").offset();
    var x = e.pageX - offset.left;
    var y = e.pageY - offset.top;
    var target = spread.getActiveSheet().hitTest(x, y);

     if (target && target.rowViewportIndex === -1 &&
     (target.colViewportIndex === 0 || target.colViewportIndex === 1))
         {
            console.log("鼠标点击的列标题单元格行索引：" + target.row);            
            console.log("鼠标点击的列标题单元格列索引：" + target.col);         
         }
});
```

## 在标题中添加公式与迷你图

您可以在电子表格的行标题区域和列标题区域添加公式（如平均值、最小值、最大值等）和迷你图（LineSparkline 折线迷你图、ColumnSparkline 柱形迷你图、WinlossSparkline 盈亏迷你图、CascadeSparkline 层级迷你图、PieSparkline 饼图迷你图等）。用户可便捷地绑定数据源，在标题区域实现数据可视化和数据聚合，无需浏览所有数据值就能查看整体进度并分析数据错误。在标题中添加公式的效果类似冻结行和列，无论用户滚动到何处，这些公式都会始终显示。
以某组织中安德烈（Andrey）、迈克尔（Michael）和约翰（John）三位员工 2012-2019 年这 8 年的业绩评估为例：在下方用例图中，“实际销售额”代表三位员工某一年的销售总和，“销售目标”代表公司某一年的目标销售额，“销售差额”则代表实际销售额与销售目标的差值。
在此示例的销售业绩分析仪表盘中，列标题使用**折线迷你图**公式展示员工 8 年的销售额变化，使用**柱形迷你图**公式展示实际销售额与销售目标；此外，“销售差额”列标题中的**盈亏迷你图**公式则展示了实际销售额与销售目标的差值情况。
同时，为了在列标题中展示数据聚合结果，示例使用了内置函数公式，呈现出员工销售额、实际销售额、销售目标及销售差额的最小值、平均值和最大值。
在仪表盘中使用迷你图和数据聚合公式时，用户无需查看具体数值，就能轻松识别不同维度的业绩表现。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/sparklineex-header.520885.png)

### 代码实现

以下代码片段展示了如何在标题中使用迷你图和公式：

```javascript
        $(document).ready(function () {
            // 初始化Spread
            var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 2 });
            spread.suspendPaint(); // 暂停绘制
            // 获取活动工作表
            var activeSheet = spread.sheets[0];
            // 设置工作表区域偏移选项
            activeSheet.options.sheetAreaOffset = { left: 1, top: 1 };
            // 隐藏网格线
            activeSheet.options.gridline = { showVerticalGridline: false, showHorizontalGridline: false };
            // 隐藏行标题
            activeSheet.options.rowHeaderVisible = false;
            // 设置行和列的数量
            activeSheet.setRowCount(8, 3);
            activeSheet.setColumnCount(8, 3);
            // 设置列宽
            activeSheet.setColumnWidth(0, 100);
            for (var i = 1; i < 7; i++)
                activeSheet.setColumnWidth(i, 180);
            // 创建数据数组
            var dataArray =
                [
                    [2012, 242, 234, 135, , 700],
                    [2013, 234, 244, 522, , 900],
                    [2014, 214, 322, 111, , 500],
                    [2015, 23, 114, 45, , 300],
                    [2016, 222, 152, 345, , 700],
                    [2017, 22, 633, 622, , 1000],
                    [2018, 533, 634, 211, , 1700],
                    [2019, 111, 22, 442, , 600],
                ];
            // 为图表设置数据
            activeSheet.setArray(0, 0, dataArray);
            // 为第0行列标题设置数据及其格式
            activeSheet.setValue(0, 0, "员工销售业绩（百万美元）", GC.Spread.Sheets.SheetArea.colHeader);
            activeSheet.getRange(-1, 0, -1, 7).hAlign(GC.Spread.Sheets.HorizontalAlign.center);
            activeSheet.setRowHeight(0, 35, GC.Spread.Sheets.SheetArea.colHeader)
            activeSheet.addSpan(0, 0, 1, 7, GC.Spread.Sheets.SheetArea.colHeader);
            // 设置列标题行数
            activeSheet.setRowCount(4, 1);
            // 为第1行列标题设置数据
            activeSheet.setValue(1, 0, '年份', GC.Spread.Sheets.SheetArea.colHeader);
            activeSheet.setValue(1, 1, '安德烈', GC.Spread.Sheets.SheetArea.colHeader);
            activeSheet.setValue(1, 2, '迈克尔', GC.Spread.Sheets.SheetArea.colHeader);
            activeSheet.setValue(1, 3, '约翰', GC.Spread.Sheets.SheetArea.colHeader);
            activeSheet.setValue(1, 4, '实际销售额', GC.Spread.Sheets.SheetArea.colHeader);
            activeSheet.setValue(1, 5, '销售目标', GC.Spread.Sheets.SheetArea.colHeader);
            activeSheet.setValue(1, 6, '销售差额', GC.Spread.Sheets.SheetArea.colHeader);
            // 为"实际销售额"列和"销售差额"列设置公式
            for (var i = 1; i < 9; i++) {
                activeSheet.setFormula(i - 1, 4, "SUM(B" + i + "+C" + i + "+D" + i + ")", GC.Spread.Sheets.SheetArea.viewport);
                activeSheet.setFormula(i - 1, 6, "E" + i + "-F" + i, GC.Spread.Sheets.SheetArea.viewport);
            }
            // 为数据区域单元格设置边框
            activeSheet.getRange("A1:G8").setBorder(
                new GC.Spread.Sheets.LineBorder("black", GC.Spread.Sheets.LineStyle.thick),
                { top: true, bottom: true, left: true, right: true }, GC.Spread.Sheets.SheetArea.viewport);

            
            activeSheet.addSpan(2, 5, 1, 2, GC.Spread.Sheets.SheetArea.colHeader);
            activeSheet.setRowHeight(2, 60, GC.Spread.Sheets.SheetArea.colHeader);
            activeSheet.setText(2, 4, "盈亏图表", GC.Spread.Sheets.SheetArea.colHeader);

            activeSheet.setFormula(2, 1, '=LINESPARKLINE(Sheet1!B1:B8,0,,,"{seriesColor:#02888F,highMarkerColor:#FFD34C,lowMarkerColor:#E89796,lineWeight:3,displayEmptyCellsAs:0,showHigh:true,showLow:true,maxAxisType:0,minAxisType:0}")', GC.Spread.Sheets.SheetArea.colHeader);

            style1.foreColor = "black";
            style1.backColor = "#9FD5B7";
            style1.hAlign = GC.Spread.Sheets.HorizontalAlign.center;
            style1.vAlign = GC.Spread.Sheets.VerticalAlign.center;
            activeSheet.setStyle(0, 0, style1, GC.Spread.Sheets.SheetArea.colHeader);
            // 设置第1行和第3行列标题的样式
            var style = new GC.Spread.Sheets.Style();

            style.foreColor = "black";
            style.backColor = "#D3F0E0";
            style.hAlign = GC.Spread.Sheets.HorizontalAlign.center;
            style.vAlign = GC.Spread.Sheets.VerticalAlign.center;
            for (var i = 0; i < 7; i++) {
                activeSheet.setStyle(1, i, style, GC.Spread.Sheets.SheetArea.colHeader);
                activeSheet.setStyle(3, i, style, GC.Spread.Sheets.SheetArea.colHeader);

            var style2 = new GC.Spread.Sheets.Style();

                activeSheet.setStyle(2, i, style2, GC.Spread.Sheets.SheetArea.colHeader);
```

## Excel 导入/导出

Excel不支持自定义标题区域。但如果用户想要在Excel中导入和导出带公式的标题，可以使用SpreadJS的`frozenColumnsAsRowHeaders`或`frozenRowsAsColumnHeaders`以及`rowHeadersAsFrozenColumns`或`columnHeadersAsFrozenRows`属性。启用这些属性后，标题区域中的公式将被保留。此外，在导出时这些公式会被转换为冻结区域，在导入时会被转换回标题区域。

>type=info
> **注意**：标题可以引用视口，但标题的引用只能引用其自身。不过，这无法处理跨冻结情况的范围。另外，标题区域中的迷你图（SparklineEx）不支持Excel导入/导出。
