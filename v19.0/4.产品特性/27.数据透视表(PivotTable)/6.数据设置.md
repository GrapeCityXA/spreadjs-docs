# refresh-data-source

数据透视表允许你在数据透视表中反映数据源的变化。它还支持以下几种方式来编辑数据透视表数据区域中的值：

* **刷新数据源**
* **更改数据源**
* **数据值编辑**

## 刷新数据源

如果数据透视表的数据源在任何时候发生变化，都需要刷新数据透视表以反映最新信息。SpreadJS 允许你通过使用数据透视表的 `updateSource` 方法来刷新数据源，并在数据透视表中显示最新数据。
以下 GIF 展示了如何通过 “刷新数据源” 按钮，在数据源发生任何变化时刷新数据透视表。
![refresh-datasource](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/refresh-datasource.7cdd53.gif)
以下示例代码展示了如何在数据源发生任何变化时刷新数据透视表。

```javascript
function refreshDataSource() {
    myPivotTable.updateSource();
}
```

你也可以使用 SpreadJS 设计器刷新数据透视表数据。具体操作是，选中数据透视表，显示 “数据透视表分析” 选项卡，然后在 “数据” 组中选择 “刷新” 按钮。

## 更改数据源

数据透视表允许你更改数据源，并将现有布局信息同步到新的数据源，这使得使用数据透视表更加便捷。当你需要添加更多行或修改现有数据集时，此功能非常有用。
要更改当前数据源，可使用 `updateSource` 方法，并按以下示例代码指定新数据。

```javascript
// Configure different data sources
var sourceSheet = spread.getSheet(0);
var sheet = spread.getSheet(1);
sheet.name('Pivot Table');
spread.setActiveSheet('Pivot Table');
var sourceData = [
    ['Date', 'Buyer', 'Type', 'Amount'],
    ['01-Jan', 'Mom', 'Fuel', 74],
    ['15-Jan', 'Mom', 'Food', 235],
    ['17-Jan', 'Dad', 'Sports', 20],
    ['21-Jan', 'Kelly', 'Books', 125],
];
sourceSheet.setArray(0, 0, sourceData);
sourceSheet.tables.add('sourceData', 0, 0, 5, 4);

var newSourceData = [
    ['Date', 'Buyer', 'Type', 'Amount', 'Location', 'Notes'],
    ['10-Feb', 'Mom', 'Fuel', 74, 'Gas Station', 'Paid in cash'],
    ['27-Mar', 'Mom', 'Food', 235, 'Supermarket', 'Bought snacks'],
    ['13-Jan', 'Dad', 'Sports', 20, 'Sports Store', 'Discount applied'],
    ['21-May', 'Kelly', 'Books', 125, 'Bookstore', 'Fiction novels'],
    ['03-Apr', 'John', 'Electronics', 340, 'Electronics Store', 'New phone case'],
    ['19-Jun', 'Mom', 'Clothing', 89, 'Mall', 'Sale purchase'],
    ['15-Jul', 'Dad', 'Tools', 75, 'Hardware Store', 'DIY project'],
    ['08-Aug', 'Kelly', 'Furniture', 450, 'Furniture Shop', 'Living room decor'],
    ['23-Sep', 'John', 'Gaming', 120, 'Online Store', 'Pre-ordered game'],
    ['11-Oct', 'Mom', 'Garden', 55, 'Garden Center', 'Flower seeds'],
    ['06-Nov', 'Dad', 'Fuel', 64, 'Gas Station', 'Highway stop'],
    ['20-Dec', 'Kelly', 'Toys', 92, 'Toy Store', 'Birthday gifts'],
];
sourceSheet.setArray(10, 0, newSourceData);
sourceSheet.tables.add('newSourceData', 10, 0, 13, 6);

// Create the pivot table
var layout = GC.Spread.Pivot.PivotTableLayoutType.compact;
var theme = GC.Spread.Pivot.PivotTableThemes.medium2;
var options = { showRowHeader: true, showColumnHeader: true };
sheet.pivotTables.add('pivotTable_1', 'sourceData', 1, 1, layout, theme, options);
var pivotTable = sheet.pivotTables.get('pivotTable_1');
var panel = new GC.Spread.Pivot.PivotPanel('myPivotPanel', pivotTable, document.getElementById('panel'));
panel.sectionVisibility(GC.Spread.Pivot.PivotPanelSection.fields + GC.Spread.Pivot.PivotPanelSection.area);
pivotTable.add('Buyer', 'Buyer', GC.Spread.Pivot.PivotTableFieldType.rowField);
pivotTable.add('Type', 'Type', GC.Spread.Pivot.PivotTableFieldType.columnField);
pivotTable.add('Amount', 'Sum of Amount', GC.Spread.Pivot.PivotTableFieldType.valueField, GC.Pivot.SubtotalType.sum);
sourceSheet.setValue(1, 3, 1000);

// Get the pivot data source
var pivotDataSource = pivotTable.getSource();
console.log(pivotDataSource);
// Update pivot data source
pivotTable.updateSource('newSourceData');
```

SpreadJS 设计器也支持通过以下步骤更改数据源：

1. 选中数据透视表，然后转到功能区中的 “数据透视表分析” 选项卡。
    ![ChangeDataSource.4f27b7](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ChangeDataSource.4f27b7.d870dc.png)
<br>
2. 在 “数据” 组中，点击 “更改数据源”。
3. 在 “更改数据透视表数据源” 对话框中，重新选择或修改数据范围。
    ![ChangeDataSourceDialog.26846b](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ChangeDataSourceDialog.26846b.ec0e10.png)
<br>

>type=info
> **注意：**
> \> 也支持整列作为数据源，例如“=Sheet\!$A:$B”，但不支持相对引用。

4. 点击 “确定” 以使用新数据重新生成数据透视表。

>type=info
> **注意**：
>
> * 如果在更改数据源后找到了字段名：
>     * 该字段的信息将保留。但是，该字段对应的项目将更新为新数据源中的内容。
>     * 该字段的切片器将保留，并且数据将更新。
>     * 如果该字段有对应的项目组字段，SpreadJS 中源字段的项目将更新为最新数据，而组字段将保留其原始项目。
> * 如果在更改数据源后未找到字段名：
>     * 计算字段将显示空值。
>     * 分组字段将被删除。
>     * 缺失字段的切片器将丢失。
> * 如果新数据源已被另一个数据透视表使用，将直接引用现有数据。
> * 数据透视表的更改数据源操作不支持撤销操作。但是，在更改数据源后，数据透视表支持撤销操作。

## 数据值编辑

SpreadJS 数据透视表允许你编辑或覆盖其数据区域的值。仅允许将数值类型设置为覆盖节点值。
数据透视表仅支持 5 种类型的计算方式来计算分类汇总：

* GC.Pivot.SubtotalType.sum
* GC.Pivot.SubtotalType.count
* GC.Pivot.SubtotalType.countNums
* GC.Pivot.SubtotalType.max
* GC.Pivot.SubtotalType.min

如果分类汇总类型不在上述列表中，则仅会覆盖特定单元格，而分类汇总结果不会改变。
要在运行时编辑数据透视表中的值，你可以将数据透视表的 **enableDataValueEditing** 选项设置为 true。enableDataValueEditing 的默认值为 false。不过，要通过代码覆盖数据透视表数据值，你可以使用数据透视表的 **setNodeValue** 方法，该方法接受节点信息数组和要覆盖的值。节点信息数组既可以使用 **getNodeInfo** 方法获取，也可以为特定值创建节点数组。你还可以使用 getNodeValue、getOverwriteList、clearOverwriteList 方法分别获取节点值、覆盖单元格值列表以及清除覆盖值列表。需要注意的是，在更新数据透视表源时，覆盖值列表将丢失。

>type=info
> **注意**：对于 JSON 输入/输出，其中会包含覆盖值列表。但是，对于 Excel 导入导出以及数据透视表的序列化和反序列化，覆盖值列表将被忽略。

以下 GIF 展示了如何在运行时编辑分类汇总值。
![editdatavalue.5f944c](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/editdatavalue.5f944c.f46bf9.gif)
以下代码展示了如何将 enableDataValueEditing 选项设置为 true。

```JavaScript
// 启用数据值编辑
pivotTable.options.enableDataValueEditing = true;
```

以下代码展示了如何使用 getNodeInfo 和 setNodeValue 方法更新数据透视表的数据值。

```JavaScript
// 你也可以通过以下代码获取节点信息
var nodeInfo = pivotTable.getNodeInfo(7, 5);
// 使用代码更改单元格 (7,5) 的值
pivotTable.setNodeValue(nodeInfo, 5000);
```
