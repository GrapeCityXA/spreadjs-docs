# sort-pt

SpreadJS 的 **数据透视表排序** 功能允许开发者控制数据透视表中数据项的顺序，实现更清晰、高效的数据分析。
排序可通过 `PivotTable.sort()` API 与 `sortInfo` 对象 **通过编程方式** 配置，也可 **通过设计器交互方式** 操作。开发者可按字段名称、值或自定义逻辑指定排序顺序，还可选用高级功能，如 **自定义回调函数排序**、**自定义列表排序**（“首要关键字排序顺序”列表）和 **手动拖放重新排序**。
这些选项为工作表中的数据透视表提供了灵活定义和维护一致排序行为的方式。

## 相关 API

| **类型** | **名称** | **描述** |
| --- | --- | --- |
| 枚举 | [SortType](gcdocsite__documentlink?toc-item-id=acbb573f-e92e-4be9-bad2-f6b9f427622f) | 排序类型枚举：`asc`（升序）、`desc`（降序）、`custom`（自定义）。 |

| 方法 | [PivotTable.sort(fieldName, sortInfo)](gcdocsite__documentlink?toc-item-id=834cde90-a458-41b2-b9c9-043ddf95e926#sort) | 设置或获取字段的排序配置。 |
| 方法 | [PivotTable.autoSortState(fieldName, enabled?)](gcdocsite__documentlink?toc-item-id=834cde90-a458-41b2-b9c9-043ddf95e926#autosortstate) | 查询或切换字段的自动排序状态（默认启用）。<br>启用时，`PivotTableManager.customList`（共享自定义列表）不生效。 |
| 方法 | [PivotTable.getItemsByField(fieldName, sorted?)](gcdocsite__documentlink?toc-item-id=834cde90-a458-41b2-b9c9-043ddf95e926#getitemsbyfield) | 返回字段的所有项。<ul><li>`sorted=true`：返回当前排序后的顺序。</li><li>`sorted=false`：返回未排序的原始列表。</li></ul>若按值排序，返回最新标签排序对应的内部标签顺序。 |
| 方法 | [PivotTableManager.customList(customList?)](gcdocsite__documentlink?toc-item-id=9e3a903e-843a-4b36-8318-a0b911872346#customlist) | 获取或设置工作表级别的共享自定义排序列表。<br>仅当字段的 `autoSort`（自动排序）禁用且 `sortType` 为 `asc`/`desc` 时生效。 |

>type=note
> **注意事项**：
>
> * **排序优先级**：`autoSort`（默认启用）优先级高于工作表共享的 `customList`。仅当 `autoSort = false` 且 `sortType ∈ {asc, desc}` 时，共享自定义列表才会影响排序顺序。
> * **作用域**：`PivotTableManager.customList` 仅适用于同一工作表内的所有数据透视表，非工作簿级作用域。
> * **持久性**：共享自定义列表不会保存到 `Workbook.options.customList`，也不会在 Excel 导入/导出时保留。
>
> 有关详细的行为说明和设计原理，请参阅 **设计注意事项和限制** 部分。

## 使用示例

### 基础代码

本节所有示例均基于以下基础配置，该配置创建了一个包含示例数据的工作簿和数据透视表：

```javascript
// 初始化工作簿并创建基础数据透视表
// 以下代码为所有示例共享

var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"),{sheetCount:3});
var sourceSheet = spread.getSheet(0);
var sheet = spread.getSheet(1);

// 示例数据源
var sourceData = [["Date","Buyer","Type","Amount"],
                  ["01-Jan","Mom","Fuel",74],
                  ["15-Jan","Mom","Food",235],
                  ["17-Jan","Dad","Sports",20],
                  ["21-Jan","Kelly","Books",125]];
sourceSheet.setArray(0, 0, sourceData );
sourceSheet.tables.add('sourceData', 0, 0, 5, 4); // 创建数据表

// 数据透视表配置
var layout = GC.Spread.Pivot.PivotTableLayoutType.compact; // 紧凑布局
var theme = GC.Spread.Pivot.PivotTableThemes.medium2; // 主题样式
var options = {showRowHeader: true, showColumnHeader: true}; // 显示行列标题

// 创建数据透视表
var pivotTable = sheet.pivotTables.add("pivotTable_1",'sourceData',1,1,layout,theme,options);

// 添加字段
pivotTable.add("Buyer","Buyer",GC.Spread.Pivot.PivotTableFieldType.rowField); // 行字段
pivotTable.add("Type","Type",GC.Spread.Pivot.PivotTableFieldType.columnField); // 列字段
pivotTable.add("Amount","Amount",GC.Spread.Pivot.PivotTableFieldType.valueField); // 值字段

pivotTable.autoFitColumn(); // 自动调整列宽
```

### 设置排序模式

通过 `sortInfo` 对象的 `sortType` 属性设置排序模式：

```javascript
// 升序排序
pivotTable.sort("Buyer", { sortType: GC.Pivot.SortType.asc });

// 降序排序
pivotTable.sort("Buyer", { sortType: GC.Pivot.SortType.desc });

// 自定义排序（需配合回调函数或列表）
pivotTable.sort("Buyer", {sortType: GC.Pivot.SortType.custom });
```

>type=note
> **注意**：
> 选择 `custom` 模式（`GC.Pivot.SortType.custom`）时，需通过 `customSortCallback`（自定义回调函数）或 `customSortList`（自定义列表）指定排序规则。

### 按字段项名称排序

调用 `pivotTable.sort(fieldName, sortInfo)` 方法，通过 `sortInfo` 中的 `sortType` 指定排序顺序（升序、降序或自定义），实现按字段项名称排序：

```javascript
pivotTable.sort("Buyer", { sortType: GC.Pivot.SortType.desc });
// 结果：["Mom", "Kelly", "Dad"]（按名称降序排列）
```

### 按值字段排序

可基于另一个字段的聚合值对数据透视表字段进行排序。调用 `pivotTable.sort()` 时，需在 `sortInfo` 对象中配置以下属性：

* `sortType` – 定义排序方向（升序或降序）。
* `sortValueFieldName` – 指定作为排序依据的值字段名称。
* `sortByPivotReferences` – 定义排序依据的透视区域（如特定列）。

```javascript
pivotTable.sort('Buyer', {
    sortType: GC.Pivot.SortType.asc,
    sortValueFieldName: 'Amount', // 按 Amount 字段的值排序
    sortByPivotReferences: [
        {
            fieldName: 'Type',
            items: ['Books'], // 仅基于 Type=Books 的 Amount 值排序
        },
    ],
});
// 结果：["Dad", "Mom", "Kelly"]（按 Books 类型的 Amount 升序排列）
```

### 按自定义回调函数排序

将 `sortType` 设置为 `GC.Pivot.SortType.custom` 并提供 `customSortCallback` 函数，可定义字段的自定义排序逻辑。该回调函数接收目标字段的所有项组成的数组（`list`），并返回重新排序后的数组。支持实现任意自定义规则（如按字符串长度、字母模式或外部排名排序）：

```javascript
pivotTable.sort('Buyer', {
    sortType: GC.Pivot.SortType.custom,
    customSortCallback: function (list) {
        // 按名称长度升序排序
        return list.sort((a, b) => a.length - b.length);
    },
});
// 结果：["Mom", "Dad", "Kelly"]（名称长度：3 → 3 → 5）
```

### 按自定义列表排序

将字段的 `sortType` 设置为 `GC.Pivot.SortType.custom` 并指定 `customSortList`，可定义字段项的固定排序顺序。`customSortList` 中的项定义了字段项的精确显示顺序：

>type=note
> **注意事项**：
>
> * 仅对数据透视表字段中存在的项生效，列表中不存在的项将被忽略。
> * 排序不区分大小写。
> * 未包含在 `customSortList` 中的项将显示在指定项之后，保留其默认顺序。

```javascript
// 示例 1：完整自定义列表（不区分大小写）
pivotTable.sort('Type', {
    sortType: GC.Pivot.SortType.custom,
    customSortList: ['FOOD', 'sports', 'Books', 'fUel'], // 大小写不敏感
});
// 结果：["Food", "Sports", "Books", "Fuel"]（按列表顺序排列）

// 示例 2：部分自定义列表（未列出项保留默认顺序）
pivotTable.sort('Type', {
    sortType: GC.Pivot.SortType.custom,
    customSortList: ['Food', 'Sports'], // 仅指定部分项的顺序
});
// 结果：["Food", "Sports", "Books", "Fuel"]（未列出项按默认顺序排列）
```

两个示例的排序结果一致：第一个示例展示了不区分大小写的匹配规则，第二个示例展示了未列出项保留默认顺序的特性。

### 结合自定义列表与自动排序状态

可将自定义列表与数据透视表的排序行为结合。需先禁用自动排序（`autoSortState`），再应用 `PivotManager.customList`：

```javascript
pivotTable.autoSortState('Type', false); // 禁用 Type 字段的自动排序
sheet.pivotTables.customList(['Food', 'Sports']); // 设置工作表共享自定义列表

// 升序模式（按自定义列表顺序）
pivotTable.sort('Type', { sortType: GC.Pivot.SortType.asc });
// 结果：["Food", "Sports", "Books", "Fuel"]（自定义列表项在前，其余项默认顺序）

// 降序模式（自定义列表顺序反转）
pivotTable.sort('Type', { sortType: GC.Pivot.SortType.desc });
// 结果：["Fuel", "Books", "Sports", "Food"]（自定义列表项在后，其余项默认顺序反转）
```

### 手动拖放排序

全局排序后，用户可通过拖放字段项手动重新排序。更改即时生效，并保存为 **自定义排序** 状态：

有关详细操作，请参阅 **拖放排序** 部分。

### 获取和清除排序信息

通过 `pivotTable.sort()` 方法可获取或清除字段的排序信息：

```javascript
// 获取当前排序信息
let info = pivotTable.sort("Buyer");

// 清除排序（恢复默认顺序）
pivotTable.sort("Buyer", null);
```

### 拖放排序

设计器中的 **拖放** 功能允许直接在数据透视表内拖放字段项，直观高效地自定义布局，无需依赖对话框或菜单。

#### 拖放操作步骤

1. **启动拖放**
    * 将光标移动到选中的数据透视字段边框。
    * 光标变为移动图标时，按住鼠标左键开始拖放。
    * 屏幕将显示 **拖放指示器**，标识潜在的插入位置。

    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image.738737-20251226.32f64e.png)
2. **移动并定位字段**
    * **列字段**：光标超过目标列宽度的一半时，指示器显示在右侧；否则显示在左侧。
    * **行字段**：光标超过目标行高度的一半时，指示器显示在下方；否则显示在上方。
    * **父字段**：拖放父数据透视字段时，将自动跳过子字段，确保结构完整性。
3. **释放字段**
    * 松开鼠标左键，将选中的字段插入到新位置。

>type=note
> **注意**：
> 手动重新排列后，打开 **排序选项** 对话框将显示排序模式已设置为 **手动**。

#### 不支持的场景

以下情况 **不支持** 拖放操作：

* 选中整个工作表列或行后进行拖放。
* 尝试拖放多个位于不同父字段下的相同子数据透视字段。

## 设计注意事项和限制

### 排序优先级与交互

自动排序（`autoSortState = true`）优先级高于共享自定义列表，确保动态变化的数据集排序顺序一致。自动排序启用时，`PivotTableManager.customList` 被忽略；仅当自动排序禁用且 `sortType` 为 `asc` 或 `desc` 时，共享列表才生效。

### 作用域与持久性

工作表共享的 `customList` 不会跨工作簿传播，也不会自动写入 `Workbook.options.customList`，Excel 导入/导出时也不保留。这可避免多个数据透视表共存时出现意外的排序顺序继承。

### 自定义排序列表的行为

`customSortList` 采用不区分大小写的匹配规则：

* 若列表包含字段的所有项 → 列表定义完整排序顺序。
* 若列表仅包含部分项 → 升序时列出项在前，降序时列出项在后（顺序反转），未列出项保留原始相对顺序。
* 仅当字段处于升序/降序模式且自动排序禁用时，列表才生效。

### 基于值的排序集成

当字段按值排序（指定 `sortValueFieldName`）时，`getItemsByField(sorted=true)` 返回的标签顺序反映最新基于标签排序的内部标签顺序，确保值驱动更新时显示顺序一致。

### 故障恢复

若 `customSortCallback` 抛出错误或产生不一致的比较结果，数据透视表将回退到按标签排序，确保排序行为可预测且 UI 稳定。
