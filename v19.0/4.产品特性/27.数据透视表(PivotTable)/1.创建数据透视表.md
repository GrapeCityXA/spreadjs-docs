# create-pivot-table

数据透视表是使用 `PivotTable` 和 [PivotTableManager ](gcdocsite__documentlink?toc-item-id=9e3a903e-843a-4b36-8318-a0b911872346)类来进行管理的。要创建一个数据透视表，请按照以下步骤操作：

1. 向项目中添加一个数据源。
2. 使用 [add ](gcdocsite__documentlink?toc-item-id=9e3a903e-843a-4b36-8318-a0b911872346#add)方法创建一个数据透视表。
3. 使用 [PivotTableFieldType ](gcdocsite__documentlink?toc-item-id=61f10387-83f4-4a6b-95b0-ce1f2dca2007)枚举将数据显示到各个字段中。

你可以选择使用普通数据源或现有表格作为数据源来创建数据透视表。此外，该功能支持选择整列作为数据源，但必须包含字段名称的第一行不能为空。不过，该功能不支持相对引用。

## 使用 JSON 作为数据源

您可以使用 JSON 作为数据源来创建数据透视表。例如，一家食品销售公司在不同国家销售食品和饮料产品，并每天记录产品的销售数据。通过使用 JSON 数据源，可以创建一个数据透视表，该表能够呈现有价值的洞察信息，比如：

* 每种产品在不同国家的销售总量
* 每个城市的产品销售总量

数据透视表可以轻松地对销售数据进行分类，并自动计算出小计和总计，如下图所示。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pivottable_quickstart.d55931.png)
以下代码示例创建了数据透视表，并向字段区域添加了字段。

```javascript
$(document).ready(function () {
    // 初始化 Spread
    var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 2 });
    spread.suspendPaint();
    // 获取工作表
    var pivotLayoutSheet = spread.getSheet(0);
    var dataSourceSheet = spread.getSheet(1);
    // 设置工作表名称
    pivotLayoutSheet.name('PivotLayout');
    dataSourceSheet.name('DataSource');
    // 设置行数
    dataSourceSheet.setRowCount(245);
    // 设置数据源
    dataSourceSheet.setArray(0, 0, pivotDB_UseCase);
    // 向 dataSourceSheet 添加表格
    dataSourceSheet.tables.add('tableSales', 0, 0, 245, 8);
    spread.resumePaint();
    // 初始化数据透视表
    initPivotTable(pivotLayoutSheet);
    // 自动调整两个工作表的列宽
    autoFit(pivotLayoutSheet);
    autoFit(dataSourceSheet);
});

function initPivotTable(sheet) {
    // 添加数据透视表
    var myPivotTable = sheet.pivotTables.add('myPivotTable', 'tableSales', 0, 0, GC.Spread.Pivot.PivotTableLayoutType.tabular, GC.Spread.Pivot.PivotTableThemes.dark3);
    myPivotTable.suspendLayout();
    // 显示数据透视表的行标题和列标题
    myPivotTable.options.showRowHeader = true;
    myPivotTable.options.showColumnHeader = true;
    // 添加列字段
    myPivotTable.add('Category', 'Category', GC.Spread.Pivot.PivotTableFieldType.columnField);
    myPivotTable.add('Product', 'Product', GC.Spread.Pivot.PivotTableFieldType.columnField);
    // 添加行字段
    myPivotTable.add('Region', 'Region', GC.Spread.Pivot.PivotTableFieldType.rowField);
    myPivotTable.add('City', 'City', GC.Spread.Pivot.PivotTableFieldType.rowField);
    // 添加值字段并设置小计类型为求和
    myPivotTable.add('Quantity', 'Sum of quantity', GC.Spread.Pivot.PivotTableFieldType.valueField, GC.Pivot.SubtotalType.sum);
    // 添加筛选字段
    myPivotTable.add('OrderDate', 'OrderDate', GC.Spread.Pivot.PivotTableFieldType.filterField);
    myPivotTable.resumeLayout();
    return myPivotTable;
}
function autoFit(sheet) {
    // 自动调整列宽
    let columnCount = sheet.getColumnCount();
    for (let i = 0; i < columnCount; i++) {
        sheet.autoFitColumn(i);
    }
}
```

## 使用集算表作为数据源

您可以使用集算表作为数据源引用来创建数据透视表。这有助于轻松访问数据，以便在数据透视表和集算表中比较和显示信息。它还允许您从集算表向数据透视表中添加计算字段，以便更好地分析数据。
[PivotTableManager.add](gcdocsite__documentlink?toc-item-id=9e3a903e-843a-4b36-8318-a0b911872346#add) 方法接受集算表名称作为 *sourceData* 参数值。
例如，下图展示了一个数据透视表，该表使用集算表中的数据汇总了库存信息，比如购买套餐的最低和最高税率。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pt-ts-reference.50549c.png)
以下代码示例展示了如何在 SpreadJS 中使用现有集算表中的数据来创建数据透视表。

```javascript
// 初始化一个集算表
var sheet = spread.addSheetTab(0, 'TableSheet1', GC.Spread.Sheets.SheetType.tableSheet);
var tableSheetName = 'TableSheet1';

// 将一个视图绑定到集算表
myTable
    .fetch()
    .then(function () {
        var view = myTable.addView('myView', [
            { value: 'stockItemKey', width: 150, caption: '库存项目键' },
            { value: 'stockItem', width: 120, caption: '库存项目' },
            { value: 'buyingPackage', width: 120, caption: '购买套餐' },
            { value: 'sellingPackage', width: 120, caption: '销售套餐' },
            { value: 'unitPrice', width: 150, caption: '单价' },
            { value: 'taxRate', width: 120, caption: '税率' },
            { value: 'validFrom', width: 200, caption: '生效日期' },
        ]);
        sheet.setDataView(view);
    })
    .then(() => {
        var ptSheet = spread.getSheet(0);
        var myPivotTable = ptSheet.pivotTables.add('pivot1', 'TableSheet1', 1, 1, GC.Spread.Pivot.PivotTableLayoutType.outline, GC.Spread.Pivot.PivotTableThemes.dark3);

        // 添加行字段
        myPivotTable.add('buyingPackage', '购买套餐', GC.Spread.Pivot.PivotTableFieldType.rowField);

        // 添加值字段并设置小计类型为最小值和最大值
        myPivotTable.add('taxRate', '最低税率', GC.Spread.Pivot.PivotTableFieldType.valueField, GC.Pivot.SubtotalType.min);
        myPivotTable.add('taxRate', '最高税率', GC.Spread.Pivot.PivotTableFieldType.valueField, GC.Pivot.SubtotalType.max);

        // 自动调整列宽
        for (let i = 1; i < 4; i++) {
            ptSheet.autoFitColumn(i);
        }
    });
```

数据透视表使用集算表中当前可访问的数据，但在以下情况下除外：

* 数据透视表不能包含分组操作后在集算表中新添加的任何组。
* 即使在集算表中设置了隐藏字段，数据透视表仍会显示该字段的数据。
* 数据透视表中的列使用的是集算表的列名，而不是其设置的标题。因此，计算列在数据透视表中会有很长的名称。
