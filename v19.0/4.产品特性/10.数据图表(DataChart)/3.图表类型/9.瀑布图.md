# waterfall-charts

SpreadJS 中的**瀑布图（Waterfall Chart）** 用于展示连续的正负值对累计总额的影响，通过可视化方式拆解每个影响因素的作用。该图表适用于分析利润变化、预算差异、销售业绩或库存趋势等场景。
SpreadJS 提供丰富的自定义选项，包括颜色面板、柱宽、图例、连接线（颜色、宽度、线型）等。此外，`showTotal`（显示总计）、`totalLabel`（总计标签）、`orientation`（图表方向）等属性可进一步控制图表布局。

## 代码实现示例

以下代码创建了一个“年度净利润同比分析”瀑布图，包含自定义图表配置、文本样式、提示框和动画效果：

```javascript
// 基础设置
const sheet = spread.getActiveSheet();
sheet.name("瀑布图示例");
const dataManager = spread.dataManager();

// 创建利润数据表格
function createProfitsTable(dataManager) {
    const records = [
        ["去年净利润", 846.5],
        ["产品销售增长", 235.8],
        ["价格/结构优化", 87.3],
        ["原材料成本上涨", -162.7],
        ["运营费用增加", -95.4],
        ["税收优惠", 38.6],
    ];
  const columns = ["Category", "Value"];
  return dataManager.addTable("Profits", {
    data: records.map(record => {
      const item = {};
      columns.forEach((column, index) => item[column] = record[index]);
      return item;
    }),
  });
}

const ProfitsTable = createProfitsTable(dataManager);
await ProfitsTable.fetch();

// 创建瀑布图
const dataChart = sheet.dataCharts.add('WaterfallChart6', 10, 10, 600, 400);
dataChart.setChartConfig({
  tableName: 'Profits', // 绑定的数据表名称
  plots: [{
    type: GC.Spread.Sheets.DataCharts.DataChartType.waterfall, // 图表类型：瀑布图
    encodings: {
      values: [{ field: 'Value', aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum }], // 值字段（求和聚合）
      category: { field: 'Category' }, // 分类字段
    },
    config: {
      waterfall: {
        totalLabel: '本年度净利润', // 总计列标签
        connectingLineStyle: { // 连接线样式
          stroke: { type: 'CssColor', color: 'red' }, // 线条颜色：红色
          strokeWidth: 2, // 线条宽度：2px
        },        
      },
      text: [{ // 数据标签配置
        template: '{valueField.value}', // 标签模板（显示值字段数据）
        format: { value: '0.00' }, // 数值格式（保留2位小数）
        overlappingLabels: 'Hide', // 重叠标签处理：隐藏
        position: GC.Spread.Sheets.DataCharts.TextPosition.center, // 标签位置：居中
        textStyle: { // 文本样式
          fontFamily: 'Calibri',
          fontSize: 10,
          fontWeight: 'Lighter',
          fontStyle: GC.Spread.Sheets.DataCharts.FontStyle.italic, // 字体样式：斜体
          color: '#333333', // 字体颜色：深灰色
        },
      }],
      tooltip: [{ // 提示框配置
        style: { // 提示框样式
          fill: { type: 'CssColor', color: '#ffffff' }, // 背景色：白色
          stroke: { type: 'CssColor', color: '#e0e0e0' }, // 边框色：浅灰色
          strokeWidth: 1, // 边框宽度：1px
        },
        textStyle: { // 提示框文本样式
          fontFamily: 'Calibri',
          fontSize: 12,
          fontWeight: 'Lighter',
          fontStyle: GC.Spread.Sheets.DataCharts.FontStyle.italic, // 斜体
          color: '#333333', // 深灰色
        },
      }],
      hoverAnimation: { // hover动画配置
        duration: 400, // 动画时长：400ms
        easing: GC.Spread.Sheets.DataCharts.AnimationEasing.linear, // 动画缓动：线性
        scale: 1.5, // 缩放比例：1.5倍
      },
      updateAnimation: { // 更新动画配置
        startDelay: 200, // 延迟开始：200ms
        duration: 1000, // 动画时长：1000ms
        easing: GC.Spread.Sheets.DataCharts.AnimationEasing.linear, // 线性缓动
      },
    },
  }],
  config: { // 图表整体配置
    header: { // 表头配置
      title: '利润桥：年度净利润同比分析', // 图表标题
      padding: { // 内边距
        left: 10,
        right: 10,
        top: 10,
        bottom: 20,
      },
      style: {
        fill: { type: 'CssColor', color: '#f2f2f2' }, // 表头背景色：浅灰色
      },
      textStyle: { // 标题文本样式
        color: 'black',
        fontSize: 18,
        fontStyle: GC.Spread.Sheets.DataCharts.FontStyle.italic, // 斜体
        fontWeight: 'Bold', // 粗体
        alignment: GC.Spread.Sheets.DataCharts.HAlign.left, // 水平对齐：左对齐
      },
    },
  },
});
```
