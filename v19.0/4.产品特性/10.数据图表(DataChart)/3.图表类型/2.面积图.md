# area-charts

**面积图**用于表示一个或多个数据量随时间的变化。与折线图类似，面积图绘制数据点并用线段连接它们，填充线与 x 轴之间的区域以显示颜色。这个填充区域有助于说明不同时间点的数值大小。
SpreadJS 支持各种类型的面积图，可以通过修改图表属性进行自定义，例如设置调色板、图形不透明度、边框样式、类别和数值轴样式等。这些修改可以通过代码或使用 SpreadJS Designer 中的[检查器选项卡](gcdocsite__documentlink?toc-item-id=55f14079-f4d7-48fe-aebc-ed9390deeb94)来完成。

> 本主题中的所有示例均基于[创建数据图表](gcdocsite__documentlink?toc-item-id=83b6d588-0f69-4b37-9a6e-f9aa6a2b714e)页面中的 "salesTable" 数据。因此，请确保您已按照该页面上添加数据图表的主要步骤进行操作。您还可以自定义数据源以满足您的特定需求。

## 面积图

面积图在连续的时间间隔或时间段内显示定量数据。在这种类型的图表中，x 轴与表示数据的线之间的区域被填充颜色，使得很容易看到数值的大小以及它们如何随时间或不同类别的变化。面积图在显示时间趋势、突出显示跨类别的总值以及比较不同组件对整体的贡献方面非常有效。
下面显示了一个面积图的图像：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.585a52.png)
请参考以下示例代码以添加面积图。

```javascript
// Area Chart
const sheet = spread.getActiveSheet();
sheet.name("Area Chart");
const dataChart = sheet.dataCharts.add('data-chart', 10, 10, 600, 400);
dataChart.setChartConfig({
     tableName: 'Sales',
     config: {
         header: {
             title: "Area Chart"
         },
     },
     plots: [
         {
             type: GC.Spread.Sheets.DataCharts.DataChartType.area,
             encodings: {
                 category: {
                     field: "Salesman"
                 },
                 values: [
                     {
                         field: "Sales",
                         aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum
                     }
                 ],
                 color: {
                     field: "Product"
                 },
                 filter: {
                     operate: GC.Spread.Sheets.DataCharts.LogicalOperation.and,
                     conditions: [
                         {
                             field: "Region",
                             excludeMatched: false,
                             operate: GC.Spread.Sheets.DataCharts.ComparisonOperator.in,
                             value: ["East"]
                         }
                     ]
                 }
             },
             config: {
                 axisMode: GC.Spread.Sheets.DataCharts.AxisMode.cartesian
             }
         }
     ]
});
```

## 范围面积图

范围面积图在连续的时间间隔或时间段内表示数据范围。与单条线或区域表示数据系列不同，范围面积图有两条线或区域形成一个阴影区域，以显示最小值和最大值之间的范围。
这种类型的图表特别适用于理解数值的变异性或分布。通过显示最小值和最大值之间的范围，范围面积图提供了数据分布和随时间或类别变化的波动的清晰视觉表示。
范围面积图通常用于金融、统计和项目管理中，以显示如波动的股票价格、温度范围或生产变异性等数据。它们可以有效地突出数据集内的数值范围，并提供有关数据中存在的变异性和趋势的见解。
下面显示了一个范围面积图的图像：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.0b74b6.png)
请参考以下示例代码以添加范围面积图。

```javascript
// Range Area Chart
const sheet = spread.getActiveSheet();
sheet.name("Range Area Chart");
const dataChart2 = sheet.dataCharts.add('data-chart-2', 10, 10, 600, 400);
dataChart2.setChartConfig({
    tableName: 'Sales',
    config: {
        header: {
            title: "Range Area Chart"
        },
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.rangeArea,
            encodings: {
                category: {
                    field: "Salesman"
                },
                details: [{
                    field: "Product"
                }],
                values: [
                    {
                        field: "Sales",
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum
                    },
                    {
                        field: "Return",
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum
                    }
                ],
                filter: {
                    operate: GC.Spread.Sheets.DataCharts.LogicalOperation.and,
                    conditions: [
                        {
                            field: "Region",
                            excludeMatched: false,
                            operate: GC.Spread.Sheets.DataCharts.ComparisonOperator.in,
                            value: ["East"]
                        }
                    ]
                }
            },
            config: {
                axisMode: GC.Spread.Sheets.DataCharts.AxisMode.cartesian
            }
        }
    ]
});
```

## 堆积面积图

堆积面积图显示多个数据系列堆积在一起，每个系列由不同颜色的区域表示。区域累积，显示总值，并使得易于比较时间或类别中的整体大小和每个系列对整体的贡献。
在这种类型的图表中，任何给定点的总高度表示所有堆积值的总和，每个段表示不同的数据系列。此格式允许用户查看总值如何在各个系列之间划分。
下面显示了一个堆积面积图的图像：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.0c49b6.png)
请参考以下示例代码以添加堆积面积图。

```javascript
// Stacked Area Chart
const sheet = spread.getActiveSheet();
sheet.name("Stacked Area Chart");
const dataChart3 = sheet.dataCharts.add('data-chart-3', 10, 10, 600, 400);
dataChart3.setChartConfig({
    tableName: 'Sales',
    config: {
        header: {
            title: "Stacked Area Chart"
        }
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.stackedArea,
            encodings: {
                category: {
                    field: "Salesman"
                },
                color: {
                    field: "Product"
                },
                values: [
                    {
                        field: "Sales",
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum
                    }
                ],
                filter: {
                    operate: GC.Spread.Sheets.DataCharts.LogicalOperation.and,
                    conditions: [
                        {
                            field: "Region",
                            excludeMatched: false,
                            operate: GC.Spread.Sheets.DataCharts.ComparisonOperator.in,
                            value: ["North"]
                        }
                    ]
                }
            },
            config: {
                axisMode: GC.Spread.Sheets.DataCharts.AxisMode.cartesian
            }
        }
    ]
});
```

## 百分比堆积面积图

百分比堆积面积图结合了堆积面积图的特性，并增加了以百分比形式显示数据的元素。此图表的每个区域表示一个类别或时间段的总值，而区域内的各个段显示每个子类别作为总值的百分比。
这种图表类型特别适用于比较多个类别或时间段的总大小，以及了解每个类别的相对分布或组成百分比。百分比堆积面积图以百分比形式显示数据，使得可以简单地图形化比较不同子类别在类别或时间段中的相对贡献。
