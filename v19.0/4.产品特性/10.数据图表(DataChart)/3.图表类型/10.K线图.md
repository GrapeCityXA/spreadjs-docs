# candlestick-charts

**K线图（Candlestick Chart）** 是一种数据可视化工具，用于展示特定时间段内资产的价格波动。该图表类型广泛应用于金融数据分析，可清晰呈现证券的开盘价（Open）、最高价（High）、最低价（Low）和收盘价（Close），帮助用户直观洞察市场趋势。
![K线图示例](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image.17c231-20251229.b41668.png)

每个**K线**代表一个时间单位（如日、周、月），包含以下核心数据：

* **开盘价（Open）** \- 交易周期开始时的价格。
* **最高价（High）** \- 交易周期内的最高价格。
* **最低价（Low）** \- 交易周期内的最低价格。
* **收盘价（Close）** \- 交易周期结束时的价格。

通过 `GC.Spread.Sheets.DataCharts` API 可自定义K线图，支持设置个性化样式、颜色和显示选项，实现交互式数据可视化。

## 数据格式与字段规则

**支持的数据**：K线图要求每个数据点包含**4个数值字段**，按以下顺序排列：`[开盘价（open）、最高价（high）、最低价（low）、收盘价（close）]`。
**字段行为**：

* **开盘价（Open）**：自动取序列中的**第一个值**。
* **最高价（High）**：取序列中的**最大值**。
* **最低价（Low）**：取序列中的**最小值**。
* **收盘价（Close）**：取序列中的**最后一个值**。

图表要求输入数据为**有效且格式规范**的数据。

>type=note
> **注意事项**：
>
> * 必须提供全部4个字段，否则图表无法渲染。
> * 调色板至少需包含两种颜色：第一种用于表示价格上涨，第二种用于表示价格下跌。
> * 若绑定字段缺失或无效，图表可能无法正常显示。

// 配置第一个K线图（单一价格序列）

    tableName: 'Stock1', // 绑定数据表：Stock1
