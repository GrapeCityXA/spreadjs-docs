# ohlc-charts

**OHLC图表（Open–High–Low–Close）** 是一种专用数据可视化功能，用于展示特定时间段内资产的价格波动。该图表广泛应用于金融和股票市场应用，可用于观察日度、周度或月度价格趋势。
![OHLC图表示例](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image.f5c453-20251229.cdd241.png)
OHLC图表中的每个柱状图显示四个价格点：

* **开盘价（Open）** \- 周期开始时的初始价格。
* **最高价（High）** \- 周期内达到的最高价格。
* **最低价（Low）** \- 周期内触及的最低价格。
* **收盘价（Close）** \- 周期结束时的最终价格。

通过OHLC图表，用户可以直观查看价格波动、识别市场模式，并分析一段时间内的交易表现。

## 数据格式与字段规则

**支持的数据**：OHLC图表每个数据点接受 **3个或4个** 数值字段：

* 4值模式：`[开盘价（open）、最高价（high）、最低价（low）、收盘价（close）]`
* 3值模式：`[最高价（high）、最低价（low）、收盘价（close）]`

**聚合规则**：OHLC值 **不得使用** 聚合函数，字段取值逻辑如下：

* 开盘价（Open）：取序列中的第一个值。
* 最高价（High）：取序列中的最大值。
* 最低价（Low）：取序列中的最小值。
* 收盘价（Close）：取序列中的最后一个值。

**其他限制**：

* 不支持悬停动画。
* 图表要求输入数据为**有效且格式规范**的数据。

## 代码实现示例

以下示例从自定义数据集生成两个股票数据图表（OHLC模式和HLC模式）：

```javascript
const sheet = spread.getActiveSheet();
sheet.name("OHLC图表");
const dataManager = spread.dataManager();

// 创建股票数据表
function createStockTable(dataManager) {
    return dataManager.addTable("Stock", {
        data: [
            {
                date: "2025-09-01",
                open: 105,
                high: 120,
                low: 95,
                close: 115,
            },
            {
                date: "2025-09-02",
                open: 115,
                high: 125,
                low: 110,
                close: 120,
            },
            {
                date: "2025-09-03",
                open: 120,
                high: 125,
                low: 110,
                close: 115,
            },
            {
                date: "2025-09-04",
                open: 115,
                high: 118,
                low: 108,
                close: 110,
            },
            {
                date: "2025-09-05",
                open: 110,
                high: 115,
                low: 105,
                close: 108,
            },
            {
                date: "2025-09-08",
                open: 110,
                high: 130,
                low: 110,
                close: 128,
            },
            {
                date: "2025-09-09",
                open: 128,
                high: 133,
                low: 125,
                close: 132,
            },
            {
                date: "2025-09-10",
                open: 132,
                high: 135,
                low: 130,
                close: 134,
            },
            {
                date: "2025-09-11",
                open: 134,
                high: 135,
                low: 125,
                close: 128,
            },
            {
                date: "2025-09-12",
                open: 128,
                high: 130,
                low: 120,
                close: 122,
            },
        ],
    });
}

const StockTable = createStockTable(dataManager);
await StockTable.fetch();

// 创建OHLC图表（4值模式）
const dataChart1 = sheet.dataCharts.add('data-chart1', 10, 10, 600, 400);
// 创建HLC图表（3值模式）
const dataChart2 = sheet.dataCharts.add('data-chart2', 10, 420, 600, 400);

// 配置4值模式OHLC图表
dataChart1.setChartConfig({
    tableName: 'Stock', // 绑定数据表
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.ohlc, // 图表类型：OHLC
            encodings: {
                values: [
                    { field: 'open' },  // 开盘价
                    { field: 'high' },  // 最高价
                    { field: 'low' },   // 最低价
                    { field: 'close' }, // 收盘价
                ],
                category: { field: 'date' }, // 分类字段：日期
            },
        }
    ],
    config: {
        header: { // 图表标题配置
            title: "股票日度价格 - OHLC（4值模式）",
            padding: { // 内边距
                left: 10,
                right: 10,
                top: 10,
                bottom: 10,
            },
            textStyle: {
                color: 'black',
                fontSize: 18
            }
        }
    }
});

// 配置3值模式HLC图表
dataChart2.setChartConfig({
    tableName: 'Stock', // 绑定数据表
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.ohlc, // 图表类型：OHLC（支持3值模式）
            encodings: {
                values: [
                    { field: 'high' },  // 最高价
                    { field: 'low' },   // 最低价
                    { field: 'close' }, // 收盘价
                ],
                category: { field: 'date' }, // 分类字段：日期
            },
            config: {
                palette: ['#FFB74D'], // 调色板：橙色
                tooltip: [{ // 提示框配置
                    style: {
                        fill: { type: 'CssColor', color: '#ffffff' }, // 背景色：白色
                        stroke: { type: 'CssColor', color: '#e0e0e0' }, // 边框色：浅灰色
                        strokeWidth: 1, // 边框宽度：1px
                    },
                    textStyle: {
                        fontFamily: 'Calibri',
                        fontSize: 12,
                        fontWeight: 'Lighter',
                        fontStyle: GC.Spread.Sheets.DataCharts.FontStyle.italic, // 斜体
                        color: '#333333', // 字体颜色：深灰色
                    },
                }]
            },
        }
    ],
    config: {
        dvStyle: { // 图表容器样式
            fill: { type: 'CssColor', color: '#0f2233' }, // 背景色：深蓝色
        },
        header: { // 图表标题配置
            title: "股票日度价格 - HLC（3值模式）",
            padding: { // 内边距
                left: 10,
                right: 10,
                top: 10,
                bottom: 10,
            },
            textStyle: {
                color: '#D7E3F4', // 字体颜色：浅蓝色
                fontSize: 18
            }
        }
    }
});
```
