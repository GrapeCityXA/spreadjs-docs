# combo-charts

**组合图表** 是一种灵活的可视化工具，可将多种图表类型（如柱状图、折线图、面积图）整合到单个统一图表中。这使得用户能够在一个图形界面中展示和对比不同类型的数据（如数量、趋势或百分比）。

>type=note
> **注意事项**：
>
> * 组合图表 **最多支持 4 个子图表**。
> * 部分图表变体（例如范围柱状图、堆叠柱状图和百分比堆叠柱状图）遵循相同的组合规则。
> * 本文未列出相同图表类型的组合示例。若需展示多个同类型数据系列，建议使用多值字段图表而非组合图表配置。

## 组合图表配置

以下表格总结了组合图表的属性作用域和同步行为：
部分设置会在所有子图表中同步（标记为 *通用*），其他设置可按子图表独立自定义（标记为 *独立*）。

| **属性** | **作用域** | **说明** |
| --- | --- | --- |
| 图表名称（Chart Name） | 独立 | 设置当前子图表的 **唯一图表名称**。 |
| 图表类型（Chart Type） | 独立 | - |
| 分类（Category） | 通用 | 组合图表中的所有子图表 **共享同一分类编码字段**。 |
| 数值（Value） | 独立 | 至少需要一个数值字段。 |
| 图表样式（Chart Style） | 独立 | - |
| 数据标签（Data Labels） | 独立 | - |
| 工具提示（Tool Tip） | 独立 | - |
| 动画（Animation） | 独立 | - |
| 图例（Legend） | 独立 | - |
| 外观（Appearance） | 通用 | 影响组合图表的整体背景和边框样式。 |
| 标题（Title） | 通用 | 所有子图表共享的同步标题。 |
| 布局（Layout） | 通用 | 控制组合图表在工作表中的位置、宽度和高度。 |
| 分类轴（Category Axis） | 通用 | <ul><li>仅存在一个分类 X 轴面板。</li><li>所有子图表必须使用该单一分类轴。</li></ul> |
| 数值轴（Value Axis） | 独立/通用 | <ul><li>可配置为独立或跨子图表共享。</li><li>每个子图表可绑定到独立的数值轴。</li><li>每个轴支持自定义刻度和显示设置。</li></ul> |

>type=note
> **注意事项**：
>
> * 单个组合图表仅支持使用一个数据集。
> * 所有子图表共享同一分类轴，分类变更会影响所有子图表。
> * 全局外观设置（外观、标题、布局、分类轴）会在所有子图表中同步。

>type=info
> **使用技巧**：
>
> * 视觉层重叠可能导致折线或数据点遮挡柱状图，可根据需要调整透明度或显示顺序。
> * 当子图表展示不同量级的指标时，使用独立数值轴可提高可读性。

### 组合图表的图例设置

可为每个子图表独立自定义图例，**图例的显示顺序与子图表的创建顺序一致**。

>type=note
> **注意**：
> 仅绑定了 **有效图例字段** 的子图表会显示图例。

```javascript
// 示例：plot1 和 plot2 使用独立的图例设置
{
    plotAreas: [
        {
            legends: [
                { type: 'Color', position: 'Bottom' }, // plot1 的图例（底部显示）
                { type: 'Color', position: 'Top' }, // plot2 的图例（顶部显示）
            ],
        },
    ];
}
```

### 组合图表的数值轴设置

组合图表支持多个数值轴，可在同一图表中展示不同数值范围的数据系列。

#### 轴绑定规则

* 每个子图表必须至少绑定一个数值轴。
* 最多支持 4 个轴（Y1–Y4）。
* 默认情况下，所有数值字段共享一个通用轴（Y1）。
* 绑定顺序不可手动指定，轴会按 Y1 到 Y4 的顺序自动分配，不影响图表输出效果。
* 未使用的轴会在图表中隐藏。

#### 轴自定义

* 每个轴可独立配置刻度、格式和显示样式。

以下示例展示了组合图表中共享数值轴和独立数值轴的配置方式：

```javascript
// 示例 1：plot1 和 plot2 共享同一数值轴
{
    axes: [
        {
            plots: ['plot1', 'plot2'],
            type: 'Y',
        },
    ];
}

// 示例 2：plot1 和 plot2 使用独立数值轴
{
    axes: [
        {
            plots: ['plot1'],
            type: 'Y',
        },
        {
            plots: ['plot2'],
            type: 'Y',
        },
    ];
}
```

## 示例：三图表组合图表

该组合图表整合了柱状图（产品收入）、面积图（客户满意度）和折线图（转化率），展示了如何在同一图表中平衡展示数值型和百分比型指标的区域分布情况。

```javascript
const sheet = spread.getActiveSheet();
sheet.name('Combo Chart');
const dataManager = spread.dataManager();

function createSalesTable(dataManager) {
    return dataManager.addTable('Sales', {
        data: [
            {
                region: '东海岸',
                revenueA: 132489,
                revenueB: 89732,
                satisfaction: 0.84,
                conversion: 0.056,
            },
            {
                region: '中西部',
                revenueA: 115621,
                revenueB: 77484,
                satisfaction: 0.81,
                conversion: 0.049,
            },
            {
                region: '南部',
                revenueA: 141570,
                revenueB: 92596,
                satisfaction: 0.89,
                conversion: 0.061,
            },
            {
                region: '西海岸',
                revenueA: 156343,
                revenueB: 102152,
                satisfaction: 0.91,
                conversion: 0.067,
            },
            {
                region: '加拿大',
                revenueA: 126481,
                revenueB: 83646,
                satisfaction: 0.87,
                conversion: 0.054,
            },
        ],
    });
}

const SalesTable = createSalesTable(dataManager);
await SalesTable.fetch();

// 创建组合数据图表
const dataChart = sheet.dataCharts.add('data-chart', 10, 10, 600, 400);

dataChart.setChartConfig({
    tableName: 'Sales',
    plots: [
        {
            name: '产品 A & B 收入',
            type: GC.Spread.Sheets.DataCharts.DataChartType.column,
            encodings: {
                values: [{ field: 'revenueA' }, { field: 'revenueB' }],
                category: {
                    field: 'region',
                },
            },
            config: {
                palette: ['#A066C9', '#7885CB'], // 紫色、蓝色
            },
        },
        {
            name: '客户满意度',
            type: GC.Spread.Sheets.DataCharts.DataChartType.area,
            encodings: {
                values: [
                    {
                        field: 'satisfaction',
                    },
                ],
            },
            config: {
                palette: ['#F7F7F7'], // 浅灰色
            },
        },
        {
            name: '转化率',
            type: GC.Spread.Sheets.DataCharts.DataChartType.line,
            encodings: {
                values: [
                    {
                        field: 'conversion',
                    },
                ],
            },
            config: {
                palette: ['#4CAF50'], // 绿色
            },
        },
    ],
    config: {
        header: {
            title: '区域销售与业绩概览',
            padding: {
                left: 10,
                right: 10,
                top: 10,
                bottom: 10,
            },
            textStyle: {
                color: 'black',
                fontSize: 24,
                fontFamily: 'Verdana',
                fontWeight: 'Bold',
            },
        },
        plotAreas: [
            {
                axes: [
                    {
                        plots: ['产品 A & B 收入'],
                        type: GC.Spread.Sheets.DataCharts.AxisType.y,
                        format: {
                            type: GC.Spread.Sheets.DataCharts.FormatType.thousands,
                            value: '$0.0 K', // 格式：千位分隔符，以千为单位显示
                        },
                    },
                    {
                        plots: ['客户满意度'],
                        type: GC.Spread.Sheets.DataCharts.AxisType.y,
                        position: GC.Spread.Sheets.DataCharts.AxisPosition.none, // 隐藏该轴
                    },
                    {
                        plots: ['转化率'],
                        type: GC.Spread.Sheets.DataCharts.AxisType.y,
                        position: GC.Spread.Sheets.DataCharts.AxisPosition.none, // 隐藏该轴
                    },
                ],
            },
        ],
    },
});
```
