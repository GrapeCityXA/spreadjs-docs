# user-management

用户管理功能为基于 SpreadJS 的应用程序提供了集中化、可扩展的用户信息管理机制。它定义了用户名、ID、头像等用户数据在线程注释（Threaded Comments）或协作工具（Collaboration tools）等组件中的创建、访问和更新方式。

## 核心概念

### 用户（User）

**用户（User）** 是实现 `IUser` 接口的普通 JavaScript 对象，代表单个用户，包含关键身份属性：

* `id` – 唯一用户标识符（必填）。
* `name` – 用户显示名称（必填）。
* `email`（可选）– 联系信息或参考信息。
* `avatar`（可选）– 视觉标识，支持多种图片源格式（如 URL、数据 URL、Blob 或本地文件）。
* `color`（可选）– 用于用户标记或视觉区分的自定义颜色。

示例用户对象如下：

```json
{
  "id": "user1",
  "name": "爱丽丝",
  "email": "alice@example.com",
  "color": "#5B8FF9"
}
```

### 用户管理器（UserManager）

`UserManager` 对象位于 `GC.Spread.Common` 命名空间下，提供全局函数用于访问和控制电子表格环境中的用户信息：

* 它是 **全局单例对象** – 无需实例化即可使用。
* 控制用户数据在整个应用中的存储、获取和更新。
* 管理所有已注册用户及其关联元数据。
* 支持用户查询、搜索和事件绑定的配置。
* 可在运行时设置或获取当前用户上下文。
* 提供异步函数 `get` 用于获取用户信息。

`UserManager` 作为 SpreadJS 平台中与用户相关操作的共享服务，为各类组件提供统一的用户数据支持。

## 设置与配置

要启用用户管理，需定义应用程序的用户数据，并配置 `UserManager` 如何获取用户信息。配置步骤需告知 SpreadJS：

* 如何通过 ID 获取用户详情。
* 如何执行用户搜索。
* （可选）指定配色方案以确保一致的视觉标识。

### 定义用户

用户由遵循 `IUser` 接口的 JavaScript 对象表示，至少需包含 `id` 和 `name`，可选包含 `email`、`avatar` 或 `color` 等属性：

```json
// 示例
var users = [
  { "id": "user1", "name": "爱丽丝", "email": "alice@example.com" },
  { "id": "user2", "name": "鲍勃",   "email": "bob@example.com" }
];
```

>type=note
> **注意**：
> avatar 属性支持多种图片源格式，如 URL、数据 URL、Blob 或本地文件。

### 配置 UserManager

`UserManager` 需在应用初始化时通过 `configure()` 方法配置一次，该方法接收一个配置对象，定义用户数据的获取和搜索逻辑：

* **get(userId)** – 返回 `Promise<IUser>`，根据用户 ID 解析为对应的用户对象。
* **search(query)** –（可选）实现用户选择 UI 时，返回匹配的用户列表。
* **colorScheme** –（可选）定义自动生成头像或显示颜色时使用的自定义配色方案。

```javascript
// 示例
const options = {
  get: async (userId) => {
        if (userId === undefined) {
            return;
        }
        return new Promise((resolve) => {
            const user = users.find(u => u.id === userId);
            resolve(user);
        });
    },
    search: async (query) => {
        return new Promise((resolve) => {
            // 按用户名或邮箱模糊搜索（不区分大小写）
            resolve(users.filter(u => 
                        u.name.toLowerCase().includes(query.toLowerCase()) || 
                        u.email.toLowerCase().includes(query.toLowerCase())
                    ));
        });
    }
}

GC.Spread.Common.UserManager.configure(options);
```

配置完成后，`UserManager` 作为 **全局单例对象** 工作，使 SpreadJS 的其他功能（如线程注释）能够通过 ID 自动引用用户数据。

## 使用 UserManager

`UserManager` 配置完成后，可用于管理和响应应用中的当前用户上下文，包括设置/获取当前活跃用户、处理用户相关事件等。

### 设置当前用户

`current()` 方法用于获取或设置当前用户的 ID：

```javascript
// 设置当前用户（通过用户 ID）
GC.Spread.Common.UserManager.current("user1");

// 获取当前用户 ID
var currentUserId = GC.Spread.Common.UserManager.current();
```

>type=note
> **注意**：
> 若未设置当前用户，`UserManager` 会自动维护一个内置的“访客（Guest）”用户作为默认全局用户。

自动创建的访客用户包含：

* 随机 UUID 作为 `id`
* 与文化相关的显示名称（例如，英文环境中为“Guest”）

### 处理用户事件

`UserManager` 支持通过以下方法订阅和管理事件：

* `bind(event, handler)`：为事件订阅函数，事件触发时调用处理器。
* `unbind(event, handler?)`：取消函数订阅；若未指定处理器，移除该事件的所有处理器。

#### 支持的事件

* `CurrentUserChanged` – 每当当前用户成功变更时，**异步触发** 该事件。

可通过订阅该事件响应应用逻辑中的用户上下文变更（如更新 UI 或刷新用户特定数据）：

```javascript
// 事件处理器：当前用户变更时触发
function onUserChanged(event, args) {
  console.log(`用户已变更：${args.oldCurrentUser?.id} → ${args.newCurrentUser?.id}`);
}

// 订阅当前用户变更事件
GC.Spread.Common.UserManager.bind(
  GC.Spread.Common.UserManager.Events.CurrentUserChanged, 
  onUserChanged
);

// 取消订阅当前用户变更事件
GC.Spread.Common.UserManager.unbind(
  GC.Spread.Common.UserManager.Events.CurrentUserChanged, 
  onUserChanged
);
```

## 头像处理规则

若未提供头像图片，将按以下规则生成默认头像：

1. 使用 `user.name` 的首字母大写作为头像文本。
2. 头像背景色优先使用 `user.color`（若已定义）。
3. 若未指定 `user.color`，将根据用户 ID 从预设配色方案中选择确定性颜色。

### 默认配色方案

未指定自定义 `colorScheme` 时，SpreadJS 使用以下 20 种颜色的默认调色板：

```javascript
#3B82F6  #10B981  #8B5CF6  #F59E0B  #EF4444
#06B6D4  #EC4899  #84CC16  #6366F1  #14B8A6
#F97316  #A855F7  #22C55E  #EAB308  #F43F5E
#0EA5E9  #D946EF  #65A30D  #DC2626  #7C3AED
```

开发者可在配置 `UserManager` 时，通过 `colorScheme` 数组覆盖默认配色方案：

>type=note
> **注意**：
> 配色方案中的颜色数量可灵活设置，算法会自动将用户 ID 映射到可用颜色。

```javascript
// 示例：配置自定义配色方案
GC.Spread.Common.UserManager.configure({
  get: async (userId) => {
        if (userId === undefined) {
            return;
        }
        return new Promise((resolve) => {
            const user = users.find(u => u.id === userId);
            resolve(user);
        });
    },
    search: async (query) => {
        return new Promise((resolve) => {
            resolve(users.filter(u => 
                        u.name.toLowerCase().includes(query.toLowerCase()) || 
                        u.email.toLowerCase().includes(query.toLowerCase())
                    ));
        });
    },
    colorScheme: ["#5B8FF9", "#61DDAA", "#F6BD16"] // 自定义颜色数组
});
```
