# themes

SpreadJS 中的文档主题使得在整个工作簿中协调颜色和字体变得轻松，便于快速更新。主题通过使用预定义的颜色和字体集来提供统一的外观。例如，“*强调文字颜色 1*” 在 “*Office*” 和 “*Apex*” 主题中的显示可能会有所不同。
SpreadJS 包含内置主题，但你也可以手动设计自定义主题，为工作表实现独特的外观。此外，你还可以根据需要进一步自定义任何现有主题的颜色和字体。
以下是 SpreadJS 开箱即支持的主题：

| @cols=3:**主题** |
| --- | --- | --- |
| 默认 | Office | Apex |
| Aspect | Concourse | Civic |
| Oriel | Origin | Paper |
| Solstice | Technic | Trek |
| Urban | Verve | Equity |
| Flow | Foundry | Median |
| Metro | Module | Opulent |
| Office2007 |  |  |

你可以使用 `currentTheme` 方法将主题应用于工作表：

```javascript
sheet.currentTheme('Apex') //使用内置主题名称
sheet.currentTheme(GC.Spread.Sheets.Themes.Metro) //使用主题实例
```

## **理解文档主题**

SpreadJS 中的 **主题** 由以下部分组成：

* **主题颜色** \- 用于文本、背景、强调文字和超链接的一组预定义颜色。
* **主题字体** \- 应用于整个工作表的标题字体和正文字体的组合。

应用主题可确保工作表中的所有元素遵循一致的设计。

## **主题颜色**

SpreadJS 提供了具有不同配色方案的内置主题（例如 **Office、Apex**）。每个主题都包括：

| 颜色类型 | 描述 | 颜色名称 |
| ---- | --- | ---- |
| **文本/背景** | 用于单元格文本和背景 | <ul><li>`文本 1`</li><li>`文本 2`</li><li>`背景 1`</li><li>`背景 2`</li></ul> |
| **强调文字颜色** | 突出显示关键元素 | <ul><li>`强调文字颜色 1`</li><li>`强调文字颜色 2`</li><li>`强调文字颜色 3`</li><li>`强调文字颜色 4`</li><li>`强调文字颜色 5`</li></ul> |
| **超链接** | 默认链接颜色 | <ul><li>`超链接`</li></ul> |
| **已访问的超链接** | 已访问链接的颜色 | <ul><li>`已访问的超链接`</li></ul> |

### **主题颜色的亮度变化**

每种主题颜色都有较深/较浅的变化（例如，强调文字颜色 1 80、深色 1 50）。主题颜色使用从 -100 到 100 的亮度比例，其中：

* **负值（-100 到 0）** = 较深的变体
* **0** = 基础主题颜色
* **正值（0 到 100）** = 较浅的变体

> **超链接** 和 **已访问的超链接** 主题颜色不支持亮度变化。

你可以通过编程方式应用主题颜色：

```javascript
// 较浅的变体（负值）
sheet.getRange("A1").backColor("Accent 1 -60");  // 深 60%
sheet.getRange("B1").backColor("Background 1 -40");  // 深 40%

// 基础颜色（亮度为 0）
sheet.getRange("C1").backColor("Accent 1 0");  // 默认颜色
sheet.getRange("D1").backColor("Accent 1 0");  // 默认颜色

// 较深的变体（正值）
sheet.getRange("E1").backColor("Accent 1 60");  // 浅 60%
sheet.getRange("F1").backColor("Background 1 25");  // 浅 25%
```

## **主题字体**

主题包含两种命名字体，有助于保持文档外观的一致性。

1. **正文字体**
    * 用于常规文本内容（例如，单元格值、段落或非标题文本）。
    * 通常是像 Calibri 这样清晰易读的字体。
    * 除非被覆盖，否则会自动应用于大多数工作表单元格。
2. **标题字体**
    * 设计用于标题、表头或强调文本（例如，图表标题、表格表头）。
    * 通常是稍微更具特色的字体（例如，Cambria）。
    * 用于轴标签、图例或手动设置格式的标题等元素。

> 主题字体仅定义 “字体系列”，不包括其他字体属性。

在 SpreadJS 的单元格样式中，当同时存在 “themeFont” 和 “font” 时，应用于单元格的实际字体是 “themeFont” 对应的 “字体系列” 与单元格 “font” 设置中的其他字体属性（不包括 “字体系列”）的组合。
例如，当使用内置的 **Aspect** 主题并按如下方式设置单元格样式时：

```javascript
var style = new GC.Spread.Sheets.Style();
style.themeFont = 'Body';
style.fontFamily = 'Arial';
style.fontSize = '20px';
style.fontWeight = 'bold';
style.fontStyle = 'italic';
sheet.setStyle(0, 0, style);
sheet.setValue(0,0,'Cell Fonts');
```

得到的字体将是 “**italic bold 20px Verdana**”

### 使用基于区域文化的东亚字体

SpreadJS 全面支持以拉丁字体和东亚字体显示和测量文本，并能适应不同的区域文化设置。
通过其主题系统，SpreadJS 可通过 [ThemeFont](gcdocsite__documentlink?toc-item-id=5118ccf1-36ce-4015-bd42-729f76b4dead) 类实现对东亚字体的支持。

### 基于区域文化的字体选择

SpreadJS 会根据当前区域文化自动应用合适的字体：

* **拉丁地区**：在标题、单元格、列宽测量等方面使用拉丁字体。
* **东亚地区**：使用东亚字体，忽略拉丁字体配置。

使用 [GC.Spread.Common.CultureInfo](gcdocsite__documentlink?toc-item-id=36975826-ad1b-46dc-905c-05542a548c85) 类配置字体脚本代码：

```javascript
class GC.Spread.Common.CultureInfo {
    fontScriptCode?: string;
}
```

> 为了全面支持 Excel 的导入/导出功能，fontScriptCode 应符合 [https://en.wikipedia.org/wiki/ISO_15924](https://en.wikipedia.org/wiki/ISO_15924) 中的标准。

### 内置区域文化兼容性

为了保持向后兼容性，内置的区域文化不会自动应用 fontScriptCode。要启用此功能：

```javascript
// 为中文（简体）启用
var cultureInfo = GC.Spread.Common.CultureManager.getCultureInfo('zh-cn');
cultureInfo.fontScriptCode = "Hans";
GC.Spread.Common.CultureManager.culture('zh-cn');

// 为日语启用
cultureInfo = GC.Spread.Common.CultureManager.getCultureInfo('ja-jp');
cultureInfo.fontScriptCode = "Jpan";
GC.Spread.Common.CultureManager.culture('ja-jp');

// 为韩语启用
cultureInfo = GC.Spread.Common.CultureManager.getCultureInfo('ko-kr');
cultureInfo.fontScriptCode = "Hang";
GC.Spread.Common.CultureManager.culture('ko-kr');
```

### 配置自定义区域文化

添加支持东亚字体的自定义区域文化：

```javascript
var customCulture = new GC.Spread.Common.CultureInfo();
customCulture.fontScriptCode = 'Thai';
GC.Spread.Common.CultureManager.addCultureInfo('th-TH', customCulture);
GC.Spread.Common.CultureManager.culture('th-TH');
```

配置完成后，SpreadJS 在读取 “标题” 或 “正文” 主题字体时会自动使用东亚字体：

```javascript
// 将单元格主题字体设置为正文（将使用东亚字体）
sheet.getCell(0, 0).themeFont("Body");

// 带有 themeFont 的样式也将使用东亚字体
var style = new GC.Spread.Sheets.Style();
style.themeFont = "Body";
sheet.setStyle(1, 1, style);
```

将带有东亚字体的主题应用于工作表：

```javascript
var theme = sheet.currentTheme();
theme.font().headingEastAsianFont('SimSun'); // 设置东亚标题字体
theme.font().bodyEastAsianFont('SimSun');    // 设置东亚正文字体
sheet.currentTheme(theme);
```

### 字体优先级规则

字体选择遵循以下优先级规则：

1. 主题中指定了东亚字体。
2. 与区域文化的字体脚本代码匹配的字体。
3. 默认的拉丁字体。

示例：

```javascript
// 情况 1：未设置字体脚本代码（返回拉丁字体）
var font = theme.bodyFont(); // 返回 "Calibri"

// 情况 2：设置了字体脚本代码，但主题中没有东亚字体
GC.Spread.Common.CultureManager.getCultureInfo().fontScriptCode = 'Hans';
var font = theme.bodyFont(); // 返回特定区域文化的字体（例如，"DengXian"）

// 情况 3：主题中明确设置了东亚字体
theme.font().bodyEastAsianFont('DengXian');
var font = theme.bodyFont(); // 返回 "DengXian"
```

### 字体脚本字体配置

为特定脚本配置备用字体：

```javascript
GC.Spread.Common.CultureManager.getCultureInfo().fontScriptCode = 'Hans';
theme.font().bodyFontScriptTypeface('Hans', 'SimSum');

// 等同于：
theme.font().bodyEastAsianFont('SimSum');
```

> 在 Excel 中，图表上的文本（如标题、坐标轴、图例和图表区域）遵循特定的字体选择策略。例如，图表区域、坐标轴和图例通常使用主题中的拉丁字体。然而，标题会根据光标的位置自动检测合适的字体。如果附近有东亚文本，它将使用主题中的东亚字体；否则，当在东亚区域设置中打开 Excel 时，它将默认为拉丁字体。同样，形状内的文本也遵循此相同策略。
> 相比之下，SpreadJS 的工作方式不同：图表和形状仅使用与当前主题对应的一种字体，不基于文本的接近程度进行动态字体选择。
