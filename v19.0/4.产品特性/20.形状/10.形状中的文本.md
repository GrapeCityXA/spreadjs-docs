# text-on-shapes

SpreadJS 允许你通过以下方式之一在形状中添加和编辑文本：

* 当 **isTextBox** 设置为 `false`（默认值）时，你需要“双击形状”或“按下 Enter 键”。
* 当 **isTextBox** 设置为 `true` 时，你需要选择形状或单击形状。
* 右键单击形状，然后从上下文菜单中选择“编辑文本”。

当你在形状中添加或编辑文本时，当你单击形状外部的任何位置时，文本编辑器会消失。不过，形状在非编辑状态下不支持选中文本。此外，在拖动形状的角进行调整大小时，仅会反映水平方向的变化。
![text-edit](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/text-edit.acfeab.gif)
当 **isTextBox** 属性设置为 `true` 时，你也可以通过单击或选择形状来在形状中添加和编辑文本。

```javascript
// 要向形状添加文本，需将 isTextBox 属性设置为 true。 
shape.isTextBox(true);
```

当双击形状时，文本编辑器会连同文本格式设置选项一起出现。其中包括所有简单的文本格式设置功能、对齐方式和其他文本选项。不过，不支持富文本。
![formatshapedialog.2d4c8a](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/formatshapedialog.2d4c8a.2cc891.gif)

## 使用场景

此用例考虑了一个会议室会议座位安排的场景。这次会议将有一些重要人员参加，因此他们的座位安排会提前做好规划。座位用自动形状表示，成员的姓名通过形状上的文本显示。如果有任何更改，这些姓名也可以添加、编辑或删除。

## 形状文本的行为

文本编辑器和文本会跟随形状的行为变化。例如，当对工作表执行缩放操作时，文本编辑器和文本也会随之调整大小并重新定位。
![text-edit-zoom](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/text-edit-zoom.8b9dee.gif)
当存在冻结行或列时，滚动时形状会折叠。不过，文本不受影响，仍保持在原位。
![text-scroll](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/text-scroll.607012.gif)

> **注意**：这种行为与 Excel 不同，在 Excel 中，文本和文本编辑器都会随形状一起折叠。

当形状旋转时，文本编辑器和文本也会随之旋转。
![shape-rotate](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/shape-rotate.26f00d.gif)
文本编辑器还允许你根据内容的高度来设置形状的高度。
![resizeshapetext.89a293](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/resizeshapetext.89a293.eec9d7.gif)
你也可以通过将 **resizeToFitText** 属性设置为 `true`，根据内容自动调整文本框形状的高度。

```javascript
// 在编辑文本框时，将 resizeToFitText 设置为 true 以自动调整形状的高度
var oldStyle = shape.style();
oldStyle.textFrame.resizeToFitText = true;
shape.style(oldStyle);
```

> **注意**：在 SpreadJS 中，形状文本框不支持垂直文本和富文本。

## 文本编辑器的行为

文本编辑器在输入内容时会自动换行并自动拉长文本区域。
![editor-area](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/editor-area.7ba9a1.gif)
选择形状并按下 Enter 键时，形状内的所有文本都会被选中。按下“Esc”键可提交形状文本并结束编辑。
![editor-enter-esc](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/editor-enter-esc.ecaeb5.gif)
输入法编辑器（IME）输入也支持作为形状文本。
![shapetext-ime](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/shapetext-ime.1de6dd.gif)
形状文本编辑器的启用或禁用情况如下：

* 如果工作表受保护，且“编辑对象”（“保护工作表”对话框中的选项）已启用，并且形状已锁定，则文本编辑器启用。
* 如果工作表受保护，且“编辑对象”（“保护工作表”对话框中的选项）已禁用，并且形状已锁定，则文本编辑器禁用。
* 如果工作表受保护，但形状未锁定，则文本编辑器启用。

## 文本方向

SpreadJS 允许您控制文档或报表中形状内文本的方向和流向。通过调整文本方向，您可以将文本设置为水平、垂直或堆叠格式显示。
此功能在提升图表和报表的视觉呈现效果方面尤为有效，并且对于适配东亚语言（如中文、日文、韩文）的排版习惯至关重要——这些语言传统上会使用垂直文本。
下表概述了 SpreadJS 支持的所有文本方向配置。

### 使用说明

SpreadJS 支持通过 API 编程和设计器 UI 操作两种方式，配置形状内的文本方向。

#### 使用 API

`GC.Spread.Sheets.Shapes.TextDirection` 提供 7 个枚举值，分别代表不同的文本方向。若要为形状设置文本方向，只需将所需的 TextDirection 枚举值分配给形状 `style.textFrame` 中的 `textDirection` 属性即可。
以下代码演示如何创建一个矩形形状，并将其文本方向设置为 `wordArtVertRtl`：

```javascript
 var rectangleShape = sheet.shapes.add("Shape1", GC.Spread.Sheets.Shapes.AutoShapeType.rectangle, 100, 60, 200, 160);
 var style = rectangleShape.style();
 style.textFrame.textDirection = GC.Spread.Sheets.Shapes.TextDirection.wordArtVertRtl;
 rectangleShape.style(style);
 rectangleShape.text('Rectangle');
```

### 重要规则

#### 1\. 文本换行与断字

形状内的文本会根据形状边界和设置的文本方向，自动换行到下一行。

| **语言** | **规则** | **示例** |
| --- | --- | --- |
| 英语及其他西方语言 | <ul><li>文本通常在空格（空格、制表符、回车等）、标点符号或连字符处断行。</li><li>优先保证单词完整性，而非严格遵守字符数量限制。</li><li>支持自定义断行规则。</li></ul> | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.d844b1.b9e69a.png)<br>![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.01ed40.e346f7.png)<br>![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.9d9fe9.33da64.png) |
| 东亚语言（中日韩） | <ul><li>通常将每个字符视为一个断行单位，必要时可在任意字符后换行。</li><li>支持自定义断行规则。</li></ul> | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.c5678d.png)<br>![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.d376da.png)<br>![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.77e196.png) |

这些换行和断字规则，与应用程序中普通单元格内的文本行为保持一致。

#### 2\. 编辑形状文本

当编辑非水平方向文本的形状时，文本始终以标准水平格式显示和编辑。垂直或堆叠方向仅在编辑完成后，用于文本的显示。
![1](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/1.381bdb.7b6da9.gif)

#### 3\. 自动适配形状大小

手动调整形状大小时，形状内的文本布局会根据当前文本方向自动适配。

* 若文本方向为水平，更改形状宽度会使文本重新流动以适应新宽度。

![2](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/2.e0fb74.37f0d0.gif)

* 若文本方向为垂直，更改形状高度会使文本调整以适应新高度。

![3](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/3.ee9e46.575178.gif)

如果将形状调整到小于文本所需的尺寸，超出形状边界的文本会自动隐藏，不再显示。
![4](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/4.5d8838.dd6db9.gif)

#### 4\. 不规则形状中的文本方向

对于非简单矩形的形状，其文本内容会被包含并放置在一个矩形区域内，该区域包围了形状的文本区域。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.b3a42a.d6e076.png)

#### 5\. 设计器中不同文化的方向选项

为与 Excel 保持一致，设计器工具提供五种文本方向选项（包括水平、垂直、所有文本旋转 90°、所有文本旋转 270° 和堆叠），其中 **“垂直”** 和 **“堆叠”** 配置的行为会根据所使用的 **资源脚本文件** 而有所不同。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.2941c5.png)
下表展示了具体的支持细节：

| **选项** | **英文（EN）** | **中文/日文/韩文（CN/JP/KO）** |
| --- | ------ | ------------------ |
| 水平 | 水平 | 水平 |
| 垂直 | 垂直（LTR） | 垂直 |
| 所有文本旋转 90° | 所有文本旋转 90° | 所有文本旋转 90° |
| 所有文本旋转 270° | 所有文本旋转 270° | 所有文本旋转 270° |
| 堆叠 | 堆叠 | 堆叠（RTL） |
