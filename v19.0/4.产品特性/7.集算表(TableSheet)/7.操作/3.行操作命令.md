# row-action-command

TableSheet 提供了行操作命令，当点击行标题时，可以使用 **command** 属性来实现这些命令以执行特定操作。
![rowaction-command.2bbc0e](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/rowaction-command.2bbc0e.c4e609.gif)
SpreadJS 还提供了一些可在行标题上实现的内置行操作选项。

| **名称** | **描述** |
| --- | --- |
| dirtyStatus | 显示某一行中的数据更改情况 |
| pinRow | 固定某一行 |
| removeRow | 删除某一行 |
| resetRow | 重置某一行中的数据更改 |
| saveRow | 保存某一行中的数据更改 |
| warningInfo | 显示某一行中的警告信息 |

以下代码示例展示了如何使用 **PinRow** 命令来固定所选的行标题。

```javascript
var options = sheetTab.rowActionOptions();
var defaultRowAction = options[0]; 
defaultRowAction.command = 'PinRow'; // 内置的固定行命令 
```
