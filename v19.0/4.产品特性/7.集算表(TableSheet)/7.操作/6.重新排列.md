# reorder

你可以在运行时根据自己的喜好，将集算表（TableSheet）和常规工作表（Worksheet）的顺序一起进行排列。此操作可以通过重新排列选项卡栏的选项卡来完成。你甚至可以将集算表放置在常规工作表之前或它们之间，反之亦然。
![reordertb.244655](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/reordertb.244655.b0f06e.gif)
你还可以使用 **changeSheetPosition** 和 **getSheetPosition** 方法来切换工作表的位置。使用 getSheetPosition 方法获取工作表（无论是常规工作表还是集算表）的当前位置，然后使用 changeSheetPosition 方法更改位置并重新排列工作表。
使用以下代码示例为集算表指定一个新位置，并检索其当前位置。

```javascript
// 更改 TableSheet1 的位置。
spread.changeSheetPosition("TableSheet1", 1); 

// 检索 TableSheet1 的当前位置。
var position = spread.getSheetPosition("TableSheet1");
```
