# table-sheet-data-range

当你将工作表区域中的集算表（TableSheet）作为数据区域进行渲染时，集算表和数据区域是同一个实例。对集算表所做的任何更改都会自动反映在数据区域中，反之亦然。这确保了两种表示形式的一致性。
数据区域继承了集算表中可用的大多数功能，如排序、筛选和样式。这使你能够在工作表的特定区域内利用集算表的强大功能，为管理和显示数据提供一种灵活且一致的方式。因此，如果源集算表被移除，相应的数据区域也将被移除。
以下示例代码将工作表中的集算表作为数据区域进行渲染。

```javascript
var tableSheetName = "TableSheet1";
var dataRangeName = "TableSheetDataRange";
var dataRangeStartRow = 2;
var dataRangeStartCol = 2;
sheet.dataRanges.add(dataRangeName, tableSheetName, new GC.Spread.Sheets.Range(dataRangeStartRow, dataRangeStartCol, -1, -1));
```

如果你希望在滚动时保持集算表的表头可见，请使用正数设置粘性选项。粘性行数将根据集算表列表头中的行数自动确定。这样你就不必手动指定粘性行数。
以下示例代码展示了一个具有粘性表头的集算表。

```javascript
var options = { sticky: { top: 1 } };
sheet.dataRanges.add(dataRangeName, tableSheetName, new GC.Spread.Sheets.Range(dataRangeStartRow, dataRangeStartCol, -1, -1), options);
```

> **注意**：固定的行不包含在粘性表头中。

## 集算表数据区域的策略

当将集算表用作数据区域时，将应用以下策略：

* **对于数据区域：**
    * 集算表数据区域的大小会自动增大或减小。
    * 范围的 `rowCount` 和 `colCount` 属性将被忽略。
    * 集算表中隐藏的列和行不会在数据区域中显示。
    * 始终显示工作表所能容纳的最大行数和列数。
* **对于导出到 Excel：**
    * 集算表数据区域在 Excel 中会作为一个表格导出。
    * 集算表行表头的角和所有列将被裁剪。
    * 如果集算表有多个表头行，仅导出多个表头的最后一行，不包含跨列设置。
    * 大纲组布局将作为压缩组布局导出。

## 限制

以下集算表的功能在数据区域中不受支持：

* 自由表头区域。
* 列表头适配模式，如堆叠式列表头。
* 具有特定自定义属性或行为的列的定义。
