# cumedist

该函数返回一组值中某个值的累积分布。
如果排序方式为升序，则将小于或等于当前行值的行数除以分区内的总行数。否则，应大于或等于，范围为(0,1]。
为了对行进行排序，该函数需要使用ORDERBY。绑定的行由ORDERBY字段的组合值标识。如果不使用ORDERBY，则所有行都被视为绑定，并返回1。它不接受窗口帧定义，例如FRAMEROWS和FRAMERANGE。默认情况下，它包括NULL值并将其视为最低可能值。
## 语法

`CUMEDIST()`

## 示例

```
// WINDOW(CUMEDIST(), ORDERBY([sold]))

city   | sold  | cume_dist
--------------------------
Paris     100     0.2
Berlin    150     0.4
Moscow    200     0.8     
Rome      200     0.8
London    300       1

// WINDOW(CUMEDIST(), ORDERBY([sold], [city]))

city   | sold  | cume_dist
--------------------------
Paris     100     0.2
Berlin    150     0.4
Moscow    200     0.6     
Rome      200     0.8
London    300       1
```
