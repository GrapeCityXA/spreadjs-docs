# function-list

窗口函数根据滑动窗口帧计算结果，该帧由与当前行相关的一组行组成。它允许您同时处理聚合和非聚合的值。

## 聚合函数

Spread提供了许多聚合函数。有关更多详细信息，请参阅[公式函数](gcdocsite__documentlink?toc-item-id=d5c6d3af-b6cf-45e9-a820-96f8dc02b19f)部分。

> **注意**：聚合函数不需要ORDERBY，但它们接受窗口帧定义。

## 排名函数

Spread提供以下按字母顺序列出的排名函数。

| **函数** | **描述** |
| --- | --- |
| [CUMEDIST](gcdocsite__documentlink?toc-item-id=9071e487-63c4-4b6a-ac4b-277cfa9597aa) | 此函数返回累积分布值。 |
| [DENSERANK](gcdocsite__documentlink?toc-item-id=cb80d888-3990-4c36-a934-7070a154d6ad) | 此函数返回分区内当前行的排名，没有间隔。 |
| [ROWNUMBER](gcdocsite__documentlink?toc-item-id=93cf129c-d536-40a7-87c5-3913c8d95d3e) | 此函数返回分区内当前行的编号。 |
| [W_PERCENTRANK](gcdocsite__documentlink?toc-item-id=c2ba4a49-2bcb-486e-806e-7c8c44a275be) | 此函数返回排名值的百分比。 |
| [W_RANK](gcdocsite__documentlink?toc-item-id=7893fa6f-4192-47dd-9dcc-7b86ee931514) | 此函数返回分区内当前行的排名，有间隔。 |

## 分析函数

Spread提供以下按字母顺序列出的分析函数。

| **函数** | **描述** |
| --- | --- |
| [FIRSTVALUE](gcdocsite__documentlink?toc-item-id=8ad58601-9441-4e16-85cc-db5651bf6960) | 此函数返回窗口帧的第一行中参数的值。 |
| [LAG](gcdocsite__documentlink?toc-item-id=43b8a57e-a669-40c5-b71f-5e7f269785bd) | 此函数提供了从当前行前面给定物理偏移量的行中获取值的访问权限。 |
| [LASTVALUE](gcdocsite__documentlink?toc-item-id=3fe8d2f4-844a-41ea-858c-d6fb7863e995) | 此函数返回窗口帧的最后一行中参数的值。 |
| [LEAD](gcdocsite__documentlink?toc-item-id=61a30d41-d5dd-4a92-8eeb-ae4036e1438a) | 此函数提供了从当前行后面给定物理偏移量的行中获取值的访问权限。 |
| [NTHVALUE](gcdocsite__documentlink?toc-item-id=d12a8c52-91dd-4bac-a546-22fe646e2eba) | 此函数返回窗口帧的第N行中参数的值。 |
| [NTILE](gcdocsite__documentlink?toc-item-id=9e4bcf27-d841-44a7-89f5-ffe4997e8fcd) | 此函数返回当前行在其分区内的桶编号。 |

## 限制

由于计算复杂性和数据量的增加，窗口函数的成本会逐渐增加。
