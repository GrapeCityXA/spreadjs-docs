# hierarchy-data-formula

集算表具备强大的数据处理能力，支持与数据源架构中的层次结构数据搭配使用的内置公式。若要为字段指定公式，可在数据源架构的层次结构选项里运用 `summaryFields` 选项。`summaryFields` 属性继承自 `GC.Data.IHierarchySummaryFieldCollection` 接口。

接下来，将为你介绍不同类型的基于层次结构的数据公式：

## 层次结构数据公式类型

### CHILDREN 公式

`CHILDREN` 公式的作用是检索子级数据。它能获取由子级的 `fieldName` 指定的值，这些子级与父级的距离为 “`levelOffset`” 步。不过，若级别偏移量大于当前记录和最低子记录之间的间隔，就无法检索到数据。
公式定义如下：
`CHILDREN(levelOffset, fieldName)`

### ONLYCHILDREN 公式

`ONLYCHILDREN` 公式用于检索特定子项的数据，即由不是父项的子项的 `fieldName` 指定的值。
公式定义如下：
`ONLYCHILDREN(fieldName)`

### PARENT 公式

`PARENT` 公式可用于检索父项数据。它能获取距离当前记录 “`levelOffset`” 步远的父项的字段名称所指定的值。若级别偏移量大于当前记录与最高父级之间的间隔，则无法检索到任何数据。
公式定义如下：
`PARENT(levelOffset, fieldName)`

### LEVEL 公式

`LEVEL` 公式用于获取当前记录的级别。
公式定义如下：
`LEVEL()`

### LEVELROWNUMBER 公式

`LEVELROWNUMBER` 公式用于检索当前记录在父作用域下的行号。
公式定义如下：
`LEVELROWNUMBER()`

## 代码示例

以下代码示例展示了如何设置各种层次结构数据公式：

```javascript
window.onload = function () {
    // 创建 SpreadJS 工作簿实例，指定容器元素并设置初始工作表数量为 0
    var spread = new GC.Spread.Sheets.Workbook(_getElementById('ss'), { sheetCount: 0 });
    // 初始化 SpreadJS 工作簿
    initSpread(spread);
};

function initSpread(spread) {
    // 设置自动调整列宽的类型，使其根据单元格内容和表头进行调整
    spread.options.autoFitType = GC.Spread.Sheets.AutoFitType.cellWithHeader;
    // 清空所有工作表
    spread.clearSheets();
    // 获取数据管理器实例
    var dataManager = spread.dataManager();
    // 初始化层次结构公式
    initHierarchyFormulas(spread, dataManager);
}

function initHierarchyFormulas(spread, dataManager) {
    // 在数据管理器中添加一个名为 'Table' 的数据表
    var table = dataManager.addTable('Table', {
        remote: {
            read: {
                // 指定从远程获取数据的 URL
                url: getBaseApiUrl() + '/Hierarchy_Formula',
            },
        },
        schema: {
            hierarchy: {
                // 设置层次结构类型为 'Parent'
                type: 'Parent',
                // 指定用于构建层次结构的列
                column: 'parent',
                summaryFields: {
                    // 定义 'budget' 字段的计算公式，对下一级子项的 'budget' 求和
                    budget: '=SUM(CHILDREN(1,"budget"))',
                },
            },
            columns: {
                id: {
                    // 将 'id' 列设置为主键
                    isPrimaryKey: true,
                },
            },
        },
    });

    // 在工作簿中添加一个集算表
    var sheet = spread.addSheetTab(0, 'HierarchyFormula', GC.Spread.Sheets.SheetType.tableSheet);
    // 设置表头行的默认高度
    sheet.setDefaultRowHeight(40, GC.Spread.Sheets.SheetArea.colHeader);
    // 禁止在集算表中添加新行
    sheet.options.allowAddNew = false;

    // 从远程获取数据并处理
    table.fetch().then(function () {
        // 在数据表中添加一个视图
        var myView = table.addView('myView', [
            { 
                // 显示部门名称，并包含层级和行号信息
                value: '=CONCAT([@department]," (L",LEVEL(),"-",LEVELROWNUMBER(),")")', 
                caption: 'Department', 
                width: 265, 
                // 将该列设置为层次结构显示列
                outlineColumn: true 
            },
            { value: 'budget', width: 100, caption: 'Budget' },
            { 
                // 计算预算占父级预算的百分比
                value: '=IF(LEVEL()=0,"",[@budget]/PARENT(1,"budget"))', 
                width: 120, 
                caption: 'Percentage', 
                style: { formatter: '0.00%' } 
            },
            { value: 'location', width: 100, caption: 'Location' },
            { value: 'phone', width: 150, caption: 'Phone' },
            { value: 'country', width: 100, caption: 'Country' },
        ]);
        // 暂停界面绘制
        spread.suspendPaint();
        // 将视图应用到集算表
        sheet.setDataView(myView);
        // 恢复界面绘制
        spread.resumePaint();
    });
}
```
