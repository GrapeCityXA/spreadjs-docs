# create-tablesheet

本主题以用例场景为例，说明如何在工作表中创建TableSheet，如下所述。

## 用例场景

考虑一种情况，一个货物进口商和分销商想要从他们的后端数据库处理大量与客户信息有关的数据。TableSheet有助于显示和管理大量数据，并使用户能够通过排序、筛选和分组对其数据执行分析。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/ts-basic.png)
创建TableSheet的步骤如下:

1. 使用[Workbook.addSheetTab](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0#addSheetTab)来初始化一个TableSheet。

    ```JavaScript
    //初始化TableSheet
    var sheet = spread.addSheetTab(0, "TableSheet1", GC.Spread.Sheets.SheetType.tableSheet);
    ```

2. 使用[DataManager](gcdocsite__documentlink?toc-item-id=d168d582-7001-4e98-a184-2aafa89215e1#_ctor)方法初始化数据管理器。

    ```JavaScript
    //初始化数据管理器
    var dataManager = spread.dataManager();
    ```

3. 使用[addTable](gcdocsite__documentlink?toc-item-id=d168d582-7001-4e98-a184-2aafa89215e1#addTable)方法给数据管理器添加数据表，该方法参数为字符串类型的数据表名称和 **IDataSourceOption** 接口。
    IDataSourceOption接口允许您设置两种类型的数据源:
    * 本地数据源：可以是来自JSON的对象数组或来自CSV或XML的字符串
    * 远程数据源： 数据可以来自查询接口、OData、GraphQL。

    您可以在“数据操作”主题中了解有关数据操作的更多信息.
    
    ```JavaScript
    //给数据管理器添加数据表
    var myTable = dataManager.addTable("myTable", {
        remote: {
            read: {
                url: 'https://demodata.grapecity.com/wwi/api/v1/customers'
            }
        }
    });
    ```

4. 使用[addView](gcdocsite__documentlink?toc-item-id=f2382678-7491-4d87-8523-09bfc84e5b68#addView)方法将视图添加到数据管理器的表中并定义列信息。
    默认情况下，视图包含表所有表列。参考[TableSheet视图](gcdocsite__documentlink?toc-item-id=ff337370-d76e-4bb2-a59f-47f72bf4e615)学习更多的列属性设置信息。

    ```JavaScript
    var view = myTable.addView("myView"); //视图默认显示所有表列
    ```

5. 使用数据管理器表的[fetch](gcdocsite__documentlink?toc-item-id=f2382678-7491-4d87-8523-09bfc84e5b68#fetch)方法获取视图，之后使用[setDataView](gcdocsite__documentlink?toc-item-id=8dc0b7a4-ace7-4c61-b4a7-00790d5584fe#setDataView)方法将获取的视图
    绑定到TableSheet。
    fetch方法可以在表和视图上执行，以返回各自的数据。

    ```JavaScript
    //TableSheet绑定视图
    myTable.fetch().then(function () {
        var view = myTable.addView("myView");
        sheet.setDataView(view);
    });
    ```
