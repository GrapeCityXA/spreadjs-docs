# get-rank

这个功能用于获取扩展单元格的排名。

## 语法

`R.RANK(cell,[context_cell],[order],[rank_mode])`

## 参数

此函数具有以下参数：

| **参数** | **描述** |
| --- | --- |
| *cell* | [必需] 指定您想要获取排名的单元格。 |
| *context\_cell* | [可选] 指定上下文单元格。<br>示例：<br>如果A2单元格绑定到年份列，B2单元格绑定到月份列，C2单元格绑定到销售列，则：<br>R.Rank(C2) 返回当前月份销售额在所有年份所有月份中的排名。<br>R.Rank(C2, A2) 返回当前月份销售额在当前年份所有月份中的排名。 |
| *order* | [可选] 指定排序顺序类型，默认值为降序。<br>0: 降序<br>1: 升序 |
| *rank\_mode* | [可选] 指定排名模式，默认值为无并列排名。<br>0: 并列无跳过编号<br>1: 无并列排名<br>2: 并列跳过编号 |

## 示例

```javascript
// Use the formula(R.Rank) to get the rank of the spilled cells.
templateSheet.setFormula(1, 3, "R.RANK(C2)");
templateSheet.setFormula(1, 4, "R.INDEX(C2,A2)");
```
