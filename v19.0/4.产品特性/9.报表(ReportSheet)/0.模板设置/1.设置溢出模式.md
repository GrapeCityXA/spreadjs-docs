# spill-mode

SpreadJS 允许你在报表（ReportSheet）中出现数据溢出时覆盖单元格。要在模板中设置溢出模式，请在 `setTemplateCell` 方法中配置 `spillMode` 属性。
有两种不同类型的溢出模式可供选择。

* **插入**：这是默认模式。在渲染报表时，此模式将插入行和列。
* **覆盖**：在渲染报表时，此模式不会插入新的行和列。它会使报表的布局和大小保持与模板相同。

>type=info
> **注意事项**：
>
> * 当使用 **覆盖** 溢出模式时，模板单元格类型必须设置为“列表”。
> * **覆盖** 溢出模式仅对未合并的单元格有效。

你可以使用以下代码示例来设置单元格的溢出模式。

```javascript
const columns = ['Id', 'Name'];
columns.forEach((columnName, i) => {
       templateSheet.setValue(4, 3 + i, columnName.toUpperCase());
       templateSheet.setTemplateCell(5, 3 + i, {
              type: 'List',
              binding: `Products[${columnName}]`,
              // Set the Spill Mode : "Overwrite" || "Insert"
              spillMode: 'Overwrite'
       });
});
```
