# parameter

在报表（ReportSheet）中，参数用于指定过滤值，以便使用动态参数而非静态值来重新生成数据。
当你使用参数时，生成的数据会根据参数中指定的值进行过滤。此外，报表中的 [参数用户界面（parameterUI）](gcdocsite__documentlink?toc-item-id=709e18f0-feb9-45dd-a78b-7f49cff5e2ca) 允许你通过运行时的用户界面交互来更改参数值并执行过滤操作。

>type=info
> **注意**：你可以在设置 [过滤条件](gcdocsite__documentlink?toc-item-id=a951195a-b590-4bd3-8630-21569bc25a04) 时设置参数。

为了排列参数并使用它们来重新生成数据，SpreadJS 提供了 [GC.Spread.Sheets.IParameter](gcdocsite__documentlink?toc-item-id=09adaaaa-8d3a-4fb9-ade8-05e087ae34ac) 接口。
以下代码示例展示了如何为报表定义参数。

```javascript
const reportSheet = spread.getActiveSheetTab();
const templateSheet = reportSheet.getTemplate();

// 为模板设置值和绑定。
templateSheet.setTemplateCell(2, 0, {
    // A3
    binding: 'Orders[OrderId]',
    type: 'Group',
    filter: {
        condition: {
            and: [
                {
                    parameter: 'startDate', // 参数
                    column: 'orderDate',
                    operator: 'GreaterThan',
                },
                {
                    parameter: 'endDate', // 参数
                    column: 'orderDate',
                    operator: 'LessThan',
                },
                {
                    parameter: 'customerId', // 参数
                    column: 'customerId',
                    operator: 'Equal',
                },
            ],
        },
    },
});
let columns = ['CustomerId', 'orderDate', 'freight', 'shipName', 'shipCity'];

columns.forEach((item, index) => {
    templateSheet.setTemplateCell(2, index + 1, {
        type: 'Group',
        binding: `Orders[${item}]`,
    });
});

// 设置报表参数。
reportSheet.parameter({
    startDate: new Date('1997-01-01'),
    endDate: new Date('1998-01-01'),
    customerId: 'VINET',
});

reportSheet.refresh();
```

## 使用 SpreadJS 设计器

请按照以下步骤在报表中创建并使用参数。

1. 在功能区中选择 **插入** \> **报表**。
2. 在 **报表设计** 功能区中选择 **参数**。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image-20251225.5bd2f2.png)
3. 你可以在 **参数** 对话框的指定部分内 **添加** / **删除** / **编辑** 参数值。
    参数值支持字符串、数字、布尔值和日期等数据类型。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.db368d.png)
4. 通过选择 **报表单元格** \> **过滤** 设置，在模板单元格过滤条件中使用创建的参数。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.c56f06.png)
5. 设计报表模板，如图所示。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.fa2528.png)
6. 预览报表，并查看基于参数值的过滤结果。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.226a3a.png)
