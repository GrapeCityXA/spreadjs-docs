# PrintBackgroundImageAsWatermark

SpreadJS 使用户能够将他们选择的任何背景图像作为水印进行打印。
当用户想要在打印工作表时，同时印上公司标志、标语、版权信息，或者印上嵌入在每一页或多页背景中的任何其他数据，以此来表明其品牌的真实性，或者仅仅是为了防止其内容被其他任何机构复制时，这个功能就特别有用。
可以使用 [PrintInfo ](gcdocsite__documentlink?toc-item-id=6f8e15e8-6dec-4e4f-a772-49bbdae4daa3)类的 [watermark ](gcdocsite__documentlink?toc-item-id=6f8e15e8-6dec-4e4f-a772-49bbdae4daa3#watermark)方法将背景图像作为水印进行打印。
以下代码示例展示了如何将背景图像作为水印进行打印。

```javascript
$(document).ready(function () {
    // 初始化 Spread
    var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { 工作表数量: 1 });
    spread.suspendPaint();

    // 获取活动工作表
    activeSheet = spread.getSheet(0);

    // 设置工作表的行数/列数
    activeSheet.setRowCount(200);
    activeSheet.setColumnCount(8);
    // 设置值
    for (var r = 0, rc = activeSheet.getRowCount(); r < rc; r++) {
        for (var c = 0, cc = activeSheet.getColumnCount(); c < cc; c++) {
            activeSheet.setValue(r, c, r + c);
        }
    }
    spread.resumePaint();
    var printInfo = activeSheet.printInfo();

    // 用于在所有页面上打印水印
    var watermark1 = { x: 0, y: 0, width: 80, height: 80, imageSrc: '../image/gc1.png', page: 'all' };

    // 用于在选定页面上打印水印
    var watermark2 = { x: 650, y: 1000, width: 100, height: 80, imageSrc: '../image/gc2.png', page: '0,1,3' };
    printInfo.watermark([watermark1, watermark2]);
    $('#print').click(function () {
        spread.print();
    });
});
```
