# sjsaitranslate

## 总结

**SJS.AI.TRANSLATE** 是 SpreadJS 中的一个动态数组函数，它能够将指定内容翻译成目标语言。借助人工智能技术，该函数可提供快速且准确的多语言文本转换，非常适用于国际化数据处理、报告翻译以及类似的场景。

## 语法

```javascript
=SJS.AI.TRANSLATE(array, language)
```

## **参数**

| 参数 | 描述 |
| ---- | ---- |
| **array**<br>必需 | 输入文本或包含要翻译文本的单元格引用。 |
| **language**<br>必需 | 目标语言，例如“日语”“中文”“英语”或“韩语”，也可以用语言区域代码表示，如“ja-JP”“zh-CN”“en-US”或“ko-KR”。 |

**备注**：

* SJS.AI.TRANSLATE 是一个异步公式，在分析过程中会返回 #BUSY!。
* SJS.AI.TRANSLATE 是一个动态数组公式，你需要在工作簿中启用动态数组功能。

## 示例

将范围 `A1:B9` 的内容翻译成日语

```sql
=SJS.AI.TRANSLATE(A1:B9, "ja-jp")
//或者
=SJS.AI.TRANSLATE(A1:B9, "Japanese")
```
