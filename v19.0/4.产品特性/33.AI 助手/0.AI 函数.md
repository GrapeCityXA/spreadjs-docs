# ai-functions

SpreadJS 支持以下人工智能功能。请注意，在使用这些人工智能功能之前，你需要根据 [AI 助手](gcdocsite__documentlink?toc-item-id=bd497cc2-8c3e-43fc-b7c0-48eb450a9347) 文档来配置 SpreadJS 的人工智能特性。

| 功能名称 | 描述 |
| ---- | --- |
| [SJS.AI.QUERY](gcdocsite__documentlink?toc-item-id=6d2c2561-3a3d-4770-9586-b78164a83bed) | 此功能允许用户向人工智能模型提交查询，以进行智能数据处理和分析。对于需要基于现有数据进行人工智能增强的转换或获取洞察的场景，此功能特别有用。 |
| [SJS.AI.TRANSLATE](gcdocsite__documentlink?toc-item-id=180f8502-2c29-49ad-89d4-c7b1422d86a2) | 此功能可将指定内容翻译成目标语言。借助人工智能技术，它能提供快速且准确的多语言文本转换，非常适合国际化数据处理、报告翻译等类似场景。 |
| [SJS.AI.TEXTSENTIMENT](gcdocsite__documentlink?toc-item-id=1cdb2dbb-0078-4bbe-ae9d-30ccec77bb79) | 此功能分析单元格中文本的情感倾向，并返回**积极**、**消极**或**中性**的结果。 |
