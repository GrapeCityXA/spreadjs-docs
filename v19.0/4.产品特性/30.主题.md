# styletheme

你可以创建一种样式，并将该样式应用于单元格、行、列或工作表。你还可以为 SpreadJS 控件设置主题。你可以设置当前主题、Excel 主题、Bootstrap 主题，或者使用主题滚轮（ThemeRoller）创建自定义的 jQuery 主题。

## SpreadJS 默认主题

你可以使用 SpreadJS 的默认主题。这需要在 aspx 页面的头部部分添加一个样式链接。例如：
`<link rel="stylesheet" href="css/gc.spread.sheets.x.x.x.css" />`

## Excel 主题

你可以在 SpreadJS 中使用 Excel 主题或样式。这需要在 aspx 页面的头部部分添加一个样式链接。例如：
`<link rel="stylesheet" href="css/gc.spread.sheets.excel2013white.x.x.x.css" />`

你还可以将 Excel 主题与其他主题（如 Bootstrap 主题）结合使用。例如：
`<link rel="stylesheet" href="css/gc.spread.sheets.excel2013white.x.x.x.css" />`
`<link rel="stylesheet" href="css/bootstrap/bootstrap.min.css" title="aa" />`
`<link rel="stylesheet" href="css/bootstrap/bootstrap-theme.min.css" title="aa" />`
如果你更改了主题，请使用 [refresh ](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0#refresh)方法。

## Bootstrap 主题

你可以在 SpreadJS 中使用 Bootstrap 主题。这需要在 SpreadJS 样式链接之后，在 aspx 页面的头部部分添加一个样式链接。例如，如果你的项目的 CSS 文件夹中有 bootstrap.css 和 bootstrap-theme.css，你可以添加以下样式链接。
`<link href=”css/gc.spread.sheets.x.xx.xxxxx.x.css” rel=”stylesheet” type=”text/css” />`
`<link rel="stylesheet" href="css/bootstrap.css" />`
`<link rel="stylesheet" href="css/bootstrap-theme.css" />`
