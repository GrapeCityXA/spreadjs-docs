# AvailableCalcEngineLanguagePackagesForSpreadJS

SpreadJS 为用户提供了 18 种以上的语言包，以便对计算引擎函数名称、表格函数名称、特殊函数逻辑、计算错误名称和布尔值资源实现全球化和本地化支持。使用您选择的语言包，您就可以使用自己偏好的本地语言进行操作，而无需担心翻译问题。
SpreadJS 的默认语言包是 “en”（英语）。为了让用户能够使用其他语言进行操作，SpreadJS 提供了以下语言包以及它们对应的语言代码（括号内）。

|  |  |  |
| --- | --- | --- |
| 1\. China/Chinese \('zh'\) | 7\. French/français \('fr'\) | 13\. Dutch/Nederlands \('nl'\) |
| 2\. Japan/Japanese \('ja'\) | 8\. German/Deutsch \('de'\) | 14\. Spanish/español \('es'\) |
| 3\. korea/Korean \('ko'\) | 9\. Portuguese/português \('pt'\) | 15\. Russian/русский \('ru'\) |
| 4\. Swedish/svenska \('sv'\) | 10\. Italian/italiano \('it'\) | 16\. Danish/dansk \('da'\) |
| 5\. Polish/polski \('pl'\) | 11\. Finnish/suomi \('fi'\) | 17\. Norwegian Bokmål/norsk bokmål \('no'\) |
| 6\. Czech/cestina \('cs'\) | 12\. Hungarian/magyar \('hu'\) | 18\. Turkish/Türkçe \('tr'\) |

用户可以使用 [LanguagePackages ](gcdocsite__documentlink?toc-item-id=0d9808cf-8839-402c-b843-3f1b424c58a5#namespace-languagepackages)类的 [languagePackages ](gcdocsite__documentlink?toc-item-id=0d9808cf-8839-402c-b843-3f1b424c58a5#languagepackages)方法，在不同语言之间进行切换。如果您想要创建并使用自己的自定义语言包，请参考 [创建和使用自定义语言包](gcdocsite__documentlink?toc-item-id=b42276df-6dab-48c7-bbe1-55061a1308b8)。

> **注意**：在 SpreadJS 中使用语言包时，必须牢记以下几点：
>
> * 更改语言包时，用户既可以用默认语言（即英语），也可以用新语言来输入函数名称。不过，结果只会以新语言显示给用户。例如，假设你想从英语语言包切换到法语语言包。现在，你可以用英语 “SUM()” 或法语 “SOMME()” 来输入求和函数。函数名称将始终以新语言显示，在这种情况下就是 “SOMME()”。
> * 使用中文、日文和韩文时，某些函数可能会处理不同的计算逻辑。对于像 Unicode 字符串这类有区域设置依赖的函数，这是 Excel 的标准行为。例如，其中一个这样的函数是 LENB——当使用如中日韩（CJK）这类双字节字符集（DBCS）语言时，Excel 会返回双字节长度，但在其他语言中，它的行为类似于返回单字符长度的 LEN 函数。这些函数名称包括 FINDB、LEFTB、RIGHTB、MIDB、LENB、REPLACEB 和 SEARCHB。这是 Excel 有记录的行为。
> * 导入/导出——Excel 和 SpreadJS 在内部使用英语名称来存储公式。特定语言的名称（通过使用语言包）会根据用户的区域设置以及语言包是否存在而自动显示。这种行为与 Excel 中的一致。
> * 更改公式语言需要调用 “spread.calculate()”。这将更新内部公式表并将解析内容更新为新的函数名称。
