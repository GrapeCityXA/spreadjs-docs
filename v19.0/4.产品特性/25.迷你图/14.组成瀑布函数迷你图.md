# sparkcascade

组成瀑布迷你图通常用于分析随时间变化的值，例如年销售额，总利润，净税等。它被广泛用于金融，销售，法律和建筑等行业。
下面列出了CASCADESPARKLINE公式的不同参数：

| **选项** | **描述** |
| --- | --- |
| pointsRange | 表示包含值的单元格范围的引用，例如“ B2：B8”。 |
| pointIndex | 代表点索引的数字或参考。 pointIndex>=1，例如1或“ D2”。 |
| labelsRange | 表示包含标签的单元格范围的引用，例如“ A2：A8”。 此设置是可选的。 默认值为无标签。 |
| minimum | 代表显示区域最小值的数字或参考。 此设置是可选的。 默认值是总和（点的总和）的最小值，例如-2000。 您设置的最小值必须小于默认最小值。 否则，将使用默认的最小值。 |
| maximum | 代表显示区域最大值的数字或参考。 此设置是可选的。 默认值为总和（点的总和）的最大值，例如6000。您设置的最大值必须大于默认的最大值；否则，最大值为0。 否则，使用默认最大值。 |
| colorPositive | 一个字符串，代表第一个或最后一个正形迷你图框的颜色（此点的值为正）。 此设置是可选的。 默认值为“＃8CBF64”。 如果第一个或最后一个框表示正值，则框的颜色将设置为colorPositive。 中间的正框设置为比colorPositive浅的颜色。 |
| colorNegative | 一个字符串，代表第一个或最后一个负迷你图的框的颜色（此点的值为负）。 此设置是可选的。 默认值为“＃D6604D”。 如果第一个或最后一个框代表负值，则该框的颜色将设置为colorNegative。 中间的负色框设置为比colorNegative浅的颜色。 |
| vertical | 表示框的方向是垂直还是水平的布尔值。 此设置是可选的。 默认值为FALSE。 您必须将一组公式的垂直设置为true或false，因为所有公式都代表整个迷你图。 |
| itemTypeRange | 表示数据范围的所有项目类型的数组或引用。 值应为{“-”，“ +”，“ =”}或“ A1：A7”，它们引用{“ +”，“-”，“ =”}“的值，其中“ +”表示 正变化，“-”表示负变化，“ =“表示总列数。 此设置是可选的。 |
| colorTotal | 一个字符串，当itemTypeRange不存在时，代表最后一个迷你图的框的颜色；或者在itemTypeRange存在时，代表最终的迷你图的框的颜色。 此设置是可选的。 |

## 用例场景

对于“瀑布迷你图（CASCADESPARKLINE）”公式中所使用的参数，瀑布迷你图有不同的用例。以下部分将讨论两个这样的用例。
**用例 1**
瀑布迷你图可用于通过迷你图描绘“推销员的费用与薪酬”，其中“瀑布迷你图（CASCADESPARKLINE）”公式使用以下参数。
`= CASCADESPARKLINE(pointsRange, pointIndex, labelsRange, minimum, maximum, colorPositive, colorNegative, vertical)`
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/sparkcascade.edd61f.png)
以下代码示例在该用例中使用上述公式创建了一个瀑布迷你图。

```javascript
activeSheet.addSpan(0, 0, 1, 3);
activeSheet.getCell(0, 0, GC.Spread.Sheets.SheetArea.viewport).value('一位推销员的费用与薪酬').font('20px Arial').hAlign(GC.Spread.Sheets.HorizontalAlign.center).vAlign(GC.Spread.Sheets.VerticalAlign.center).backColor('purple').foreColor('white');
activeSheet.getRange(1, 2, 7, 1, GC.Spread.Sheets.SheetArea.viewport).setBorder(new GC.Spread.Sheets.LineBorder('transparent', GC.Spread.Sheets.LineStyle.thin), { inside: true });
activeSheet.setValue(1, 0, '工资');
activeSheet.setValue(2, 0, '绩效工资');
activeSheet.setValue(3, 0, '客户维护费用');
activeSheet.setValue(4, 0, '餐饮支出');
activeSheet.setValue(5, 0, '酒店费用');
activeSheet.setValue(6, 0, '理财');
activeSheet.setValue(7, 0, '存款');
activeSheet.setValue(1, 1, 3500);
activeSheet.setValue(2, 1, 2500);
activeSheet.setValue(3, 1, -1000);
activeSheet.setValue(4, 1, -1000);
activeSheet.setValue(5, 1, -900);
activeSheet.setValue(6, 1, 300);
activeSheet.setFormula(7, 1, '=sum(B2:B7)');
activeSheet.setColumnWidth(0, 150);
activeSheet.setColumnWidth(1, 100);
activeSheet.setColumnWidth(2, 340);
activeSheet.setRowHeight(0, 30);
activeSheet.setRowHeight(1, 30);
activeSheet.setRowHeight(2, 30);
activeSheet.setRowHeight(3, 30);
activeSheet.setRowHeight(4, 30);
activeSheet.setRowHeight(5, 30);
activeSheet.setRowHeight(6, 30);
activeSheet.setRowHeight(7, 30);
activeSheet.setFormula(1, 2, '=CASCADESPARKLINE(B2:B8,1,A2:A8,,,"#8CBF64","#D6604D",false)');
activeSheet.setFormula(2, 2, '=CASCADESPARKLINE(B2:B8,2,A2:A8,,,"#8CBF64","#D6604D",false)');
activeSheet.setFormula(3, 2, '=CASCADESPARKLINE(B2:B8,3,A2:A8,,,"#8CBF64","#D6604D",false)');
activeSheet.setFormula(4, 2, '=CASCADESPARKLINE(B2:B8,4,A2:A8,,,"#8CBF64","#D6604D",false)');
activeSheet.setFormula(5, 2, '=CASCADESPARKLINE(B2:B8,5,A2:A8,,,"#8CBF64","#D6604D",false)');
activeSheet.setFormula(6, 2, '=CASCADESPARKLINE(B2:B8,6,A2:A8,,,"#8CBF64","#D6604D",false)');
activeSheet.setFormula(7, 2, '=CASCADESPARKLINE(B2:B8,7,A2:A8,,,"#8CBF64","#D6604D",false)');
```

**用例 2**
瀑布迷你图还可专门用于描绘初始值如何增减，最终得到一个最终值。为此，您可以在瀑布公式中使用 **itemTypeRange** 参数。在会计和财务应用中，itemTypeRange 参数对于展示导致组织的净流入和流出情况很有用。
`CASCADESPARKLINE(pointsRange, pointIndex, labelsRange, minimum, maximum, colorPositive, colorNegative, vertical, itemTypeRange, colorTotal)`
参考以下示例，其中 itemTypeRange 参数已应用于工作表的 E2: E15 单元格范围，在该范围中，“瀑布迷你图（CASCADESPARKLINE）”公式用于展示一家公司净销售额的综合盈亏情况。“营业利润”“税前利润”和“净利润”的迷你图代表总计列，这就是为什么这些列对应的 itemType 为“=”。用“+”和“-”的 itemType 来表示有正向和负向变化的迷你图。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/cascadesparkline.b7d039.png)
以下代码示例在该用例中使用上述公式创建了一个瀑布迷你图。

```JavaScript
// 在单元格中设置文本
sheet.setText(0, 1, '000$');
sheet.setText(0, 2, '标签');
sheet.setText(0, 3, '项目');
sheet.setText(0, 4, '项目类型');
// 创建 displayLabels 数组
var displayLabels = ['综合损益表', '净销售额', '   销售成本', '   研发费用', '   销售、一般及管理费用', '   客户财务减值', '   商誉减值', '   商誉摊销', '营业利润', '   联营公司业绩份额', '   财务收入及费用', '税前利润', '  税费', '   少数股东权益', '净利润'];
// 创建 items 数组
var items = [29616, 17278, 7052, 6239, 292, 103, 206, 1554, 3300, 1506, 3252, 1484, 92, 1676];
// 创建 labels 数组
var labels = [29616, 12338, 5286, -953, -1245, -1348, -1554, 1554, 4854, 6360, 3252, 1768, 1676, 1676];
// 创建 itemTypes 数组
var itemTypes = ['+', '-', '-', '-', '-', '-', '-', '=', '+', '+', '=', '-', '-', '='];
// 设置数组
sheet.setArray(0, 0, displayLabels);
sheet.setArray(1, 2, items);
sheet.setArray(1, 3, labels);
sheet.setArray(1, 4, itemTypes);
// 设置 CASCADESPARKLINE 公式
sheet.setFormula(1, 1, '=CASCADESPARKLINE(D2:D15, SEQUENCE(COUNTA(D2:D15),1,1,1),C2:C15,,,"#66C2A5","#FF7722",false,E2:E15,"#A9A9A9")', 0);
```
