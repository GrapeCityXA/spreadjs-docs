# createspark

在 SpreadJS 中，您可以使用 [setSparkline ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#setsparkline)方法创建柱形、折线和盈亏迷你图。该方法接受不同的参数，例如单元格位置、迷你图类型、迷你图设置以及数据范围的类型。
可以使用两种类型的数据范围，通过连续单元格范围和非连续单元格范围这两种方式来创建柱形、折线和盈亏迷你图。

# 基于连续范围的迷你图

[setSparkline ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#setsparkline)方法接受 `dataRange` 参数，您可以在其中提供数据范围。例如，A1:B10、D12:E20。

# 基于非连续范围的迷你图

您可以提供非连续数据范围来创建迷你图，此时工作表中的随机值可以添加到一个新的用户自定义名称中。这个自定义名称可以传递到 [setSparkline ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#setsparkline)的 `dataRange` 参数中。
例如，像 B4、B5、B11 和 B12 这样的数据单元格可以添加到自定义名称 “range” 中，以创建一个非连续范围。

```javascript
// 创建一个非连续范围
spread.addCustomName("range", "=Sheet1!$B$4,Sheet1!$B$5,Sheet1!$B$11,Sheet1!$B$12", 0, 0, "非连续范围");
```
