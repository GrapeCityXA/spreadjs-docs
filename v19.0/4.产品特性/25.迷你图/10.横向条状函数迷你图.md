# sparkhbar

您可以使用 **HBARSPARKLINE** 公式和单元格值创建横向条状函数迷你图。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/hbar-sparkline.png)
迷你图从正值的单元格左侧开始，向负值的单元格右侧开始。 如果该值大于100％或小于-100％，则显示箭头。
横向条状函数迷你图具有以下选项：

| **选项** | **描述** |
| --- | --- |
| value | 代表钢筋长度的数字或参考。 该值应在100％和-100％之间。 |
| colorScheme | 代表条形颜色的字符串。 此设置是可选的。 默认值为“grey”。 |
| axisVisible | 指示是否显示轴的布尔值。 其默认值为true。 |
| barHeight | 大于0且小于或等于1的数字，表示条高度与单元格高度的百分比。 |

横向条状函数迷你图公式具有以下格式：
`=HBARSPARKLINE(value, colorScheme, axisVisible, barHeight)`
以下代码创建横向条状函数迷你图。

```JavaScript
// 初始化 Spread
var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });
// 获取表单
var activeSheet = spread.getSheet(0);

activeSheet.setValue(0, 0, 0.3);
activeSheet.setValue(1, 0, -0.3);
activeSheet.setValue(2, 0, 2);

activeSheet.setFormula(0, 1, '=HBARSPARKLINE(A1,"red", FALSE, 0.5)');
activeSheet.setFormula(1, 1, '=HBARSPARKLINE(A2,"blue")');
activeSheet.setFormula(2, 1, '=HBARSPARKLINE(A3,"green", TRUE, A3)');

for (var i = 0; i < 4; i++) {
    activeSheet.setRowHeight(i, 40);
}
activeSheet.setColumnWidth(0, 80);
activeSheet.setColumnWidth(1, 200);
```
