# sparkbullet

您可以使用 **BulletSparkline** 公式和单元格值创建项目符号迷你图。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/bullet-sparkline.png)
BulletSparkline函数有以下参数：

| **选项** | **描述** |
| --- | --- |
| measure | 类型为数字或者引用，表示测量条的长度，例如 5 或者 "A1"。 |
| target | 类型为数值或者引用，表示目标线的位置，例如 7 或者 "A2"。 |
| maxi | 类型为数值或者引用，表示这个迷你图中的最大值，例如 10 或者 "A3"。 |
| good | （可选参数）类型为数值或者引用，表示好值条的长度，例如 3 或者 "A4"；默认值是0. |
| bad | （可选参数）类型为数值或者引用，表示坏值条的长度，例如 1 或者 "A5"；默认值是0。 |
| forecast | （可选参数）类型为数值或者引用，表示预测值线的长度，例如 8 或者 "A6"；默认值是0。 |
| tickunit | （可选参数）类型为数值或者引用，表示刻度单位，例如 1 或者 "A7"；默认值是0。 |
| colorScheme | （可选参数）类型为颜色字符串，表示主体颜色的字符串，主体颜色会生成一组颜色来展示这个迷你图。默认值是 "#A0A0A0"。 |
| vertical | （可选参数）类型为布尔值，表示是否让箱线函数迷你图垂直显示；默认值是false，也就是默认是水平显示。 |
| measureColor | 一个颜色字符串，指示测量条的颜色。 |
| targetColor | 指示目标线颜色的颜色字符串。 |
| maxiColor | 指示最大区域颜色的颜色字符串。 |
| goodColor | 一个颜色字符串，指示良好区域的颜色。 |
| badColor | 指示损坏区域颜色的颜色字符串。 |
| forecastColor | 指示预测线颜色的颜色字符串。 |
| allowMeasureOverMaxi | 一个布尔值，指示度量值是否可以超出最大面积，其默认值为false。 |
| barSize | 大于0且小于或等于1的数字值，表示根据单元格宽度或高度的钢筋宽度或高度的百分比。 |

你可以通过子弹函数创建一个子弹函数迷你图，例如
`=BULLETSPARKLINE (measure, target, maxi, good, bad, forecast, tickUnit, colorScheme, vertical, measureColor, targetColor, maxiColor, goodColor, badColor, forecastColor, allowMeasureOverMaxi, barSize)`
