# sparkcomp

您可以使用公式来创建柱状，折线，盈亏迷你图。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/sparkcomp.png)
公式具有以下选项：

| **选项** | **描述** |
| --- | --- |
| Data | 表示迷你图数据的范围参考。 例如：A1：C3。 |
| DataOrientation | 代表迷你图数据方向的数字，0为垂直，1为水平。 |
| DateAxisData | （可选参数）表示迷你图日期轴数据的范围参考。 例如：D1：F3。 |
| DateAxisOrientation | （可选参数）代表迷你图日期轴方向的数字，0表示垂直，1表示水平。 |
| Setting | （可选参数）JSON格式的字符串。 例如：`{{axisColor：rgb(255,255,0),firstMarkerColor：brown，highMarkerColor：red，lastMarkerColor：blue，lowMarkerColor：green，markersColor：purple，negativeColor：yellowgreen，seriesColor:pink,displayXAxis:true,showFirst:true, showHigh:true,showLast:true,showLow:true,showNegative:true,showMarkers:true,lineWeight:3,displayHidden:false, displayEmptyCellsAs:1,rightToLeft:false,minAxisType:1,maxAxisType:1,`<br>`manualMax:5,manualMin:-3}`。 |

下表列出了JSON格式字符串和同等的迷你图设置。

| **Json属性** | **SparklineSetting.Options 属性** |
| ------ | --------------------------- |
| AXISCOLOR | axisColor |
| FIRSTMARKERCOLOR | firstMarkerColor |
| HIGHMARKERCOLOR | highMarkerColor |
| LASTMARKERCOLOR | lastMarkerColor |
| LOWMARKERCOLOR | lowMarkerColor |

| MINAXISTYPE | minAxisType |
| LINEWEIGHT | lineWeight |

柱状，折线，盈亏迷你图公式具有以下格式：
`=LINESPARKLINE(data, dataOrientation, dateAxisData, dateAxisOrientation, setting)`
`=COLUMNSPARKLINE(data, dataOrientation, dateAxisData, dateAxisOrientation, setting)`
`=WINLOSSSPARKLINE(data, dataOrientation, dateAxisData, dateAxisOrientation, setting)`
本示例使用公式创建柱状，折线，盈亏迷你图。
