# button-list-cell

SpreadJS允许用户在表单的单元格内创建按钮列表。
按钮列表是指具有多选值的交互式列表。 它显示嵌入单个单元格中的一组项目，可以选择一个或多个选项来记录最终用户的响应。 用户可以在表单中创建一个按钮列表单元，并根据他们的特定首选项配置按钮列表中各项的布局。

### 使用场景

当用户需要创建可以在多个相关实体（包括联系人，客户，客户，事件，市场列表等）中定位和查询的一组相关项目时，按钮列表很有用。 此单元格类型类似于复选框列表和单选列表的用法，但为用户提供了在处理表单时可以从一系列选项中选择一项或多项的灵活性。

### 自定义按钮列表

在SpreadJS中使用按钮列表单元格类型时，用户可以执行以下任务，以便根据其特定首选项对其进行自定义：

* 用户可以使用 **SelectionMode** 枚举来将按钮单元的文本选择模式指定为单个或多个。
* 用户可以使用 **selectedBackColor()** 方法和 **selectedForeColor()** 方法 **button** 类自定义列表中所选按钮项目的背景色和前景色。
* 用户可以使用 **padding()** 方法来相对于单元格自定义按钮列表中项目的填充（以像素为单位）。
* 用户可以使用 **isFlowLayout()** 方法来识别按钮列表的布局是否自动调整。默认情况下，此方法的value参数设置为“ true”。
* 用户可以使用 **Direction** 枚举将按钮列表单元格类型的顺序设置为水平或垂直。
* 用户可以通过 **maxRowCount()** 方法和 **maxColumnCount()** 方法获取或设置按钮列表的行数和列数的项目。 仅当 **isFlowLayout（）** 方法设置为true，方向为水平。
* 用户可以在两个列表项之间配置间距，以避免单元内部的拥塞和混乱。 这可以通过使用 **itemSpacing()** 方法实现。

### 代码

请参考以下示例代码，以在使用表单时在单元格中创建基本按钮列表。

```JavaScript
// 初始化 Spread
var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });

// 获取表单
var activeSheet = spread.getSheet(0);

// 本示例创建一个ButtonList单元格类型
var buttonListCellType = new GC.Spread.Sheets.CellTypes.ButtonList();
activeSheet.setText(0, 1, "Select Programming Languages : ", GC.Spread.Sheets.SheetArea.viewport);
buttonListCellType.items([{ text: "Javascript", value: 1 }, { text: "Python", value: 2 }, { text: "Java", value: 3 }, { text: "PHP", value: 4 }, { text: "Objective-C", value: 5 }, { text: "Ruby", value: 6 }, { text: "SQL", value: 7 }, { text: "Swift", value: 8 }, { text: "C/CPP", value: 9 }, { text: "C#", value: 10 }]);
activeSheet.getCell(1, 1).cellType(buttonListCellType);

// 将buttonListCellType方向设置为vertical
buttonListCellType.direction(GC.Spread.Sheets.CellTypes.Direction .vertical);

// 设置buttonList中两个项目的空间
buttonListCellType.itemSpacing({
horizontal: 80,
vertical: 20
});

// 设置行高
activeSheet.setRowHeight(1, 250.0, GC.Spread.Sheets.SheetArea.viewport);

// 设置列宽
activeSheet.setColumnWidth(1, 250.0, GC.Spread.Sheets.SheetArea.viewport);
```
