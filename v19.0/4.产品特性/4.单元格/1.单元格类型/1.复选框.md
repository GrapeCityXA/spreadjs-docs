# SpreadJS 复选框（CheckBox）使用指南

**SpreadJS 复选框（CheckBox）** 是一种嵌入单元格的交互式控件，支持用户在电子表格应用中切换二态（选中/未选中）或三态（含不确定状态）。该控件旨在简化数据验证流程、提升用户交互体验，以直观的视觉标记替代了传统的下拉菜单或单选按钮。

## 基础使用（Basic Use）

你可以通过 [GC.Spread.Sheets.CellTypes.CheckBox](gcdocsite__documentlink?toc-item-id=9c6c313f-1184-4a74-87b1-b51775c97386) 类创建并完全自定义 SpreadJS 复选框单元格。通过该类，你可定义复选框的外观、管理状态切换（选中/未选中/不确定）、设置布局（`textAlign`，文本对齐方式），并通过 `textTrue`（选中时文本）、`textFalse`（未选中时文本）、`isThreeState`（是否启用三态）、`boxSize`（复选框尺寸）等核心属性调整交互行为。
以下是一个实用示例，展示如何实例化并配置带有自定义属性的复选框单元格类型：

```javascript
// 本示例创建一个复选框单元格
var activeSheet = spread.getSheet(0); // 获取第 1 个工作表（索引从 0 开始）
var cellType = new GC.Spread.Sheets.CellTypes.CheckBox(); // 创建复选框单元格类型实例

// 设置复选框属性
cellType.caption("caption"); // 设置标题文本
cellType.textTrue("true"); // 设置“选中”状态对应的文本
cellType.textFalse("false"); // 设置“未选中”状态对应的文本
cellType.textIndeterminate("indeterminate"); // 设置“不确定”状态对应的文本
cellType.textAlign(GC.Spread.Sheets.CellTypes.CheckBoxTextAlign.bottom); // 设置文本对齐方式为“下方”
cellType.boxSize(20); // 设置复选框框体尺寸为 20（单位：像素）

// 将复选框单元格类型应用到（1,1）单元格（行索引 1，列索引 1）
activeSheet.getCell(1, 1).cellType(cellType);
```

## 不确定状态（Indeterminate State）

SpreadJS 复选框支持启用三态功能，可表示“选中”“未选中”和 “**不确定**” 三种状态。只需通过 [isThreeState()](gcdocsite__documentlink?toc-item-id=9c6c313f-1184-4a74-87b1-b51775c97386#isthreestate) 方法配置复选框，即可适用于需要表示“部分选中”或“状态未定义”的场景。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.89191a.64b8a7.png?width=400)

你可通过 [value](gcdocsite__documentlink?toc-item-id=64f05fd4-fafa-47dc-9856-b74263f357ec#value) 方法在代码中设置复选框的状态，对应关系如下表所示：

| **值（Value）** | **状态（State）** |
| -------- | --------- |
| `null` | 不确定（Indeterminate） |
| `0` | 未选中（Unchecked） |
| `1` | 选中（Checked） |

### 代码实现（Using Code）

以下示例创建一个支持三态的复选框单元格：

```javascript
// 获取当前活动工作表
var activeSheet = spread.getSheet(0);
// 创建复选框单元格类型实例
var cellType = new GC.Spread.Sheets.CellTypes.CheckBox();

// 设置三态复选框属性
cellType.caption("caption"); // 标题文本
cellType.textTrue("True"); // 选中状态文本
cellType.textFalse("False"); // 未选中状态文本
cellType.textIndeterminate("Indeterminate"); // 不确定状态文本
cellType.textAlign(GC.Spread.Sheets.CellTypes.CheckBoxTextAlign.bottom); // 文本对齐方式为“下方”
cellType.isThreeState(true); // 启用三态功能（设为 true 表示支持不确定状态）
cellType.boxSize(20); // 复选框框体尺寸

// 将三态复选框应用到（1,1）单元格
activeSheet.getCell(1, 1).cellType(cellType);
// activeSheet.getCell(1, 1).value(1); // 可选：手动设置状态为“选中”（值为 1）
```

## 文本换行（Wrap Text）

当复选框标题文本过长、无法在单元格内完整显示时，需将单元格样式的 **wordWrap**（文本换行）属性设为 `true` 以实现文本换行。该属性默认值为 `false`（不换行）。

```javascript
// 设置超长标题文本
cellType.caption("This is a very very long long text"); 
// 将复选框应用到（1,1）单元格
activeSheet.getCell(1, 1).cellType(cellType); 
// 设置第 1 行高度为 120 像素（适配换行后的文本）
activeSheet.setRowHeight(1, 120); 
// 设置第 1 列宽度为 110 像素
activeSheet.setColumnWidth(1, 110); 
// 启用单元格文本换行功能
activeSheet.getCell(1, 1).wordWrap(true);
```

| ----------- | ------------ |
| **wordWrap** = false（默认） | ![wordWrap_false](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/wordWrap_false.a6ede2.4310ad.PNG) <br>（文本超出单元格部分被截断） |

### 换行规则（Line Break Rule）

复选框单元格遵循的换行规则为：优先按“单词”拆分内容；若单词长度仍超出单元格可用空间，则进一步拆分单词内部字符以适配显示。

### 垂直对齐（Vertical Alignment）

若复选框单元格启用了 **wordWrap**（文本换行）且设置了单元格垂直对齐方式，复选框的显示效果如下表所示：

| **垂直对齐方式（Vertical alignment）** | **显示效果（Output）** |
| -------------------------- | ------------ |
| 单元格垂直对齐设为“顶部（top）”：复选框与文本一同靠上对齐 | ![wordWrap_true](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/wordWrap_true.08d8f5.dee7b9.PNG) |
| 单元格垂直对齐设为“中间（middle）”：复选框与文本一同居中对齐 | ![wordWrap_middleAlign](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/wordWrap_middleAlign.f596f7.b3a9b1.PNG) |
| 单元格垂直对齐设为“底部（bottom）”：复选框与文本一同靠下对齐 | ![wordWrap_bottomAlign](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/wordWrap_bottomAlign.f325dc.797f8c.PNG) |

此外，你可根据单元格的 `hAlign`（水平对齐）属性调整换行文本的水平对齐方式。例如：

* 若单元格 `hAlign` 设为“右对齐（right）”，仅标题文本会靠单元格右侧对齐；
* 若 `hAlign` 设为“左对齐（left）”或“居中（center）”，也仅标题文本的对齐方式会相应改为左对齐或居中。

## 切换模式（Toggle Mode）

通过 [CheckBox.mode('toggle')](gcdocsite__documentlink?toc-item-id=9c6c313f-1184-4a74-87b1-b51775c97386#mode) 方法，可将标准复选框转换为交互式切换开关（类似“开关按钮”）。

### 核心功能（Key Features）

* **外观自定义**（Customizable Appearance）通过 `IToggleOptions` 接口配置视觉属性：
    * **尺寸（Dimensions）**：设置固定 `width/height`（宽/高），或启用 `autoSize`（自动适配）以实现文本动态缩放。
    * **颜色（Colors）**：定义“激活态”（`sliderColorOn` 滑块颜色、`trackColorOn` 轨道颜色）和“未激活态”（`sliderColorOff` 滑块颜色、`trackColorOff` 轨道颜色）。
    * **动画（Animation）**：通过 `animationDuration`（单位：毫秒）控制状态切换的平滑度。
    * **布局（Layout）**：调整 `sliderMargin`（滑块与轨道的间距）和 `trackRadius`（轨道圆角大小）。
* **文本对齐**（Text Alignment）除已有的“上、下、左、右”对齐选项外，`CheckBoxTextAlign.inside` 选项支持将文本直接嵌入切换按钮内部，实现更紧凑的布局。

### 使用限制（Usage Constraints）

* **属性禁用（Disabled Properties）**：在切换模式下，`boxSize`（复选框尺寸）、`isThreeState`（三态功能）、`textIndeterminate`（不确定状态文本）等属性**不可用**，无法配置。
* **交互限制（Interaction Limits）**：双击编辑功能**被禁用**；状态切换**仅支持点击切换按钮**（点击单元格其他区域无效）。
* **文本对齐（Text Alignment）**：当 `autoSize: false`（禁用自动适配）且 `textAlign: inside`（文本嵌入按钮）时，`autoFitWidth`/`autoFitHeight`（自动适配宽/高）功能**会忽略文本溢出**，仅考虑切换按钮的尺寸。

### 代码实现（Using Code）

以下示例在复选框单元格中实现切换模式：

```javascript
// 创建 SpreadJS 工作簿实例
const spread = new GC.Spread.Sheets.Workbook();
// 获取当前活动工作表
const sheet = spread.getActiveSheet();
// 创建复选框单元格类型实例
const cellType = new GC.Spread.Sheets.CellTypes.CheckBox();

// 配置切换模式属性
cellType.textTrue('ON'); // 激活态文本
cellType.textFalse('OFF'); // 未激活态文本
cellType.mode('toggle'); // 启用切换模式
// 设置文本对齐方式为“嵌入按钮内部”
cellType.textAlign(GC.Spread.Sheets.CellTypes.CheckBoxTextAlign.inside);
// 配置切换开关的视觉属性
cellType.toggleOptions({
  width: 65, // 开关宽度（像素）
  height: 30, // 开关高度（像素）
  sliderMargin: 2, // 滑块与轨道的间距（像素）
  trackColorOn: '#8cbae8', // 激活态轨道颜色
  trackColorOff: '#9e9e9e', // 未激活态轨道颜色
  sliderColorOn: '#1565c0', // 激活态滑块颜色
  sliderColorOff: '#ffffff' // 未激活态滑块颜色
});

// 将切换模式复选框应用到（0,0）单元格（第 1 行第 1 列）
sheet.setCellType(0, 0, cellType);
```
