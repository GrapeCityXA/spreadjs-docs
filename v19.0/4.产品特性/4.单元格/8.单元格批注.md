# comments

SpreadJS 支持对[单元格批注](gcdocsite__documentlink?toc-item-id=fa2f26f7-131b-4a3d-a32d-96ec8422d2b4)进行丰富的自定义设置，包括视觉样式、布局调整和交互行为。文本格式设置、批注框与指示图标的自定义、显示模式等功能进一步提升了易用性，使开发者能够根据应用需求，精确调整批注的外观和交互方式。

## 创建并自定义批注

通过调用[add](gcdocsite__documentlink?toc-item-id=00b3be73-c027-40b3-aec8-e8b8bf8a9da8#add)方法，可为指定单元格添加批注。

```javascript
// 为单元格(5,5)创建批注
var comment = activeSheet.comments.add(5,5,"new comment!");
```

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1396da6c-cc2b-40ba-bf75-5edf5d507065/image.d2f6ce.86044c.png)

你可以通过[Comment](gcdocsite__documentlink?toc-item-id=8f1c1a63-630d-4beb-b253-498257215856)类自定义批注样式，实现对视觉呈现的精细化控制。
以下是一个简单示例，演示如何对现有批注的批注框和文本进行基础样式配置。

```javascript
// 设置批注样式

// 批注框自定义
comment.backColor("#ff0000"); // 批注框背景色
comment.borderColor("rgb(46, 119, 183)"); // 批注框边框色
comment.borderStyle("dashed"); // 批注框边框样式（虚线）
comment.borderWidth(4); // 批注框边框宽度

// 文本格式设置
comment.fontSize("11pt"); // 字体大小
comment.fontStyle("italic"); // 字体样式（斜体）
comment.fontWeight("bold"); // 字体粗细（加粗）
comment.foreColor("#e7e6e6"); // 文本颜色
comment.horizontalAlign(1); // 水平对齐方式（1 表示居中对齐）
comment.textDecoration(1); // 文本装饰（1 表示下划线）
```

### 设置背景色

SpreadJS 提供**五种输入方式**用于设置单元格批注的`backcolor`（背景色），为自定义提供灵活性和精确性：

1. **RGB（十六进制代码）**：使用十六进制代码定义所需颜色，例如`#FF0000`代表红色。
2. **RGB（数值）**：通过 RGB 数值指定颜色，例如`RGB(255, 0, 0)`代表红色，适合熟悉 RGB 颜色模型的开发者。
3. **预定义颜色名称**：从固定的命名颜色集中选择，无需使用代码，简化操作流程。
4. **[主题颜色](gcdocsite__documentlink?toc-item-id=49874b66-77e9-46e7-8874-d825b5fe0bc6#strong%E4%B8%BB%E9%A2%98%E9%A2%9C%E8%89%B2strong)**：使用与当前文档主题绑定的颜色（如`Background 1`，即“背景色1”），确保与文档整体设计风格一致。
5. **系统主题名称**：源自 Excel 2019 的命名颜色，可确保与 Excel **无缝兼容**。目前支持两种预定义系统主题名称：
    * `SJS_infoBackground`：默认值为`#FFFFE1`，匹配 Excel 的“信息背景色”[80]。
    * `SJS_window`：默认值为`#FFFFFF`，匹配 Excel 的“窗口色”[65]。

>type=info
> **注意**：
> 由于前端无法直接调用 Excel 的系统颜色 API，SpreadJS 已根据 Excel 2019 的公开颜色规范预设了这两个颜色值。若默认颜色与目标场景不匹配，可自定义`SJS_infoBackground`和`SJS_window`的颜色值。

以下示例定义了`SJS_infoBackground`所代表的颜色，并更新了现有批注框的`backColor`（背景色）：

```javascript
// 自定义颜色定义
var infoBkStyle = new GC.Spread.Sheets.Style();
infoBkStyle.name = 'SJS_infoBackground'; // 颜色名称
infoBkStyle.backColor = '#FFFFE1'; // 自定义背景色

// 将自定义颜色添加到 Spread 的命名样式集合中
spread.addNamedStyle(infoBkStyle);

// 设置批注背景色
comment.backColor("SJS_infoBackground");
```

### 选择显示模式

SpreadJS 单元格批注的`displayMode`（显示模式）方法支持两种配置模式：

1. `alwaysShown`（始终显示）：批注永久显示在目标单元格旁边。
2. `hoverShown`（悬停显示）：仅当鼠标悬停在单元格的指示图标上时，批注才会显示。

开发者可根据交互需求，在“持久显示批注”和“上下文触发弹窗”两种方式中选择。

```javascript
// 设置批注为“始终显示”模式
comment.displayMode(GC.Spread.Sheets.Comments.DisplayMode.alwaysShown);
```


### 自定义指示图标

初始化批注时，系统会在目标单元格的右上角自动插入一个红色小三角图标。通过[indicatorColor](gcdocsite__documentlink?toc-item-id=8f1c1a63-630d-4beb-b253-498257215856#indicatorColor)（指示图标颜色）和[indicatorSize](gcdocsite__documentlink?toc-item-id=8f1c1a63-630d-4beb-b253-498257215856#indicatorSize)（指示图标大小）方法，可修改批注指示图标的颜色和尺寸。

以下示例在之前的代码基础上，将指示图标放大并改为绿色：

```javascript
// 设置指示图标颜色为绿色
comment.indicatorColor("green");
// 设置指示图标尺寸为15（单位：像素）
comment.indicatorSize(15);
```

## 锁定批注

若工作表选项[isProtected](gcdocsite__documentlink?toc-item-id=3fb0cf7f-6127-4d8b-946c-778d4b2cd152#isprotected)（是否保护）设置为`true`（已保护），则可锁定批注事件或批注文本。下表展示了批注属性值与工作表受保护时的对应结果：

| **[Locked](gcdocsite__documentlink?toc-item-id=8f1c1a63-630d-4beb-b253-498257215856#locked)**（锁定批注操作） | **[LockText](gcdocsite__documentlink?toc-item-id=8f1c1a63-630d-4beb-b253-498257215856#locktext)**（锁定批注文本） | **结果** |
| -------------- | ---------------- | --- |
| false（未锁定） | false（未锁定） | 批注操作（移动、调整大小等）生效；批注文本可编辑 |
| true（已锁定） | false（未锁定） | 批注操作失效；批注文本可编辑 |
| false（未锁定） | true（已锁定） | 批注操作生效；批注文本不可编辑 |
| true（已锁定） | true（已锁定） | 批注操作失效；批注文本不可编辑 |

## 批注动态调整大小与重新定位

根据[dynamicMove](gcdocsite__documentlink?toc-item-id=8f1c1a63-630d-4beb-b253-498257215856#dynamicMove)（动态移动）和[dynamicSize](gcdocsite__documentlink?toc-item-id=8f1c1a63-630d-4beb-b253-498257215856#dynamicSize)（动态调整大小）方法的设置，调整行或列的大小时，批注的位置和尺寸可能会随之变化。下表展示了`dynamicMove`与`dynamicSize`设置的对应结果：

| **DynamicMove（动态移动）** | **DynamicSize（动态调整大小）** | **结果** |
| ----------------- | ------------------- | --- |
| true（启用） | true（启用） | 批注随单元格同步移动和调整大小 |
| true（启用） | false（禁用） | 批注随单元格移动，但不随单元格调整大小 |
| false（禁用） | true / false（启用/禁用） | 批注不随单元格移动或调整大小 |

## 其他提示

1. 若批注处于编辑模式，可对批注内的文本执行剪切、复制或粘贴操作。
2. 复制单元格时，批注会随单元格一同复制。
3. 对批注文本执行剪切、复制、粘贴操作，或调整批注大小、移动批注、修改批注格式后，可使用撤销（Undo）和重做（Redo）功能。
4. 从 Excel 格式文件导入批注时存在部分限制：
    * 部分边框样式和字体无法导入。
    * 若工作表范围小于原文件中的显示范围，批注位置可能会出现偏差。
    * 仅支持从 XLSX 格式文件导入批注。
