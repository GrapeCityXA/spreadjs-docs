# decoration

您可以使用装饰对象将 SpreadJS 中的装饰应用到单元格或单元格区域。这些对象可以包含折角或图标等设置。

## 设置折角

**SpreadJS** 支持在单元格的角上设置折角样式。CornerFold 功能在突出显示单元格状态时很有用，例如，当您想要显示单元格的无效状态时。
[IDecoration](gcdocsite__documentlink?toc-item-id=c1a98fbf-5545-43bd-ae35-2d7f7cc70622) 接口提供了 **cornerFold** 选项，它允许您设置折角的大小、位置和颜色。 cornerFold 选项继承自 [ICornerFold](gcdocsite__documentlink?toc-item-id=63019ca8-06ca-4f75-bce4-46d6c2887006) 接口，它提供大小、位置和颜色等参数。
下面的快照描绘了左上角位置的单元格 B6 和 B8 上的橙色折角样式。
![cornerfold-styling.962a1e](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/cornerfold-styling.962a1e.8aa101.png)
**cornerFold** 选项的默认值如下：

| 大小 | 位置 | 颜色 |
| --- | --- | --- |
| 6 | GC.Spread.Sheets.CornerPosition.leftTop | #FF3D00 |

以下代码实现显示了如何使用**ICornerFold**接口和**setStyle**方法设置折角样式。

```javascript
var style = new GC.Spread.Sheets.Style();
style.decoration = {
    cornerFold: {
        size: 10,
        position: GC.Spread.Sheets.CornerPosition.leftTop,
        color: "orange"
    }
}
sheet.setStyle(5, 1, style);
```

## 设置图标

SpreadJS 支持使用GC.Spread.Sheets.Style类中的 icons 属性对单元格进行图标装饰，这些单元格可以嵌入电子表格中的单元格内部或外部。
包含文本或值的单元格类型可以用图标装饰，但复选框和组合框等单元格类型不支持图标属性。
![styleicondecoration.4e82ef](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/styleicondecoration.4e82ef.f48d5c.png)
SpreadJS 为图标装饰提供了多种选择，例如 src、宽度、高度和位置。要指定图标的位置，您可以使用下面列出的 IconPosition 枚举值：

| **枚举名称** | **描述** |
| ---- | --- |
| 左边 | 在单元格的左侧 |
| 右边 | 在单元格的右侧 |
| 文本左侧 | 在文本的左侧，如果没有文字，则隐藏图标 |
| 文字右侧 | 在文本的右侧，如果没有文字，则隐藏图标 |
| 外侧左 | 在单元格的外侧，如果单元格被隐藏，则图标隐藏 |
| 外侧右 | 在单元格的右外侧，如果单元格被隐藏，则图标隐藏 |


> **笔记**：
>
> * leftOfText 和 rightOfText 位置值仅适用于文本单元格。
> * 当前视图之外的图标只会影响相邻的列。
> * 当装饰支持多个图标时，图标会被并排绘制，而不管它们的位置。
> * 单元格对齐影响图标垂直对齐。
> * 带有样式装饰图标的单元格不能溢出。

### 使用设计器

要使用 SpreadJS Designer 向单元格添加图标，请按照以下步骤操作：

1. 选择单元格。
2. 右键单击该单元格，然后从上下文菜单中选择 **格式化单元格...选项。** 这将调用电子表格上的 **“设置单元格格式”对话框。** 导航到 **Decoration** 选项卡并设置其属性。

![icon-formatcell.f5dcf2](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/icon-formatcell.f5dcf2.81d127.png)

### 添加/更新图标选项

1. 单击 **“添加”** 按钮以添加新图标选项或选择 src 、位置、宽度或高度以更新图标。
    ![icon-add.c7b6ff](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/icon-add.c7b6ff.dc5363.png)
<br>
2. 单击 **“选择图标”** 选项以浏览图标的位置。
    ![icon-add-src.f2326f](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/icon-add-src.f2326f.645dbd.png)
<br>
3. 您可以使用位置 组合框（可选）指定**位置**。
    ![icon-position.20755d](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/icon-position.20755d.3ea2be.png)
<br>
4. 您还可以使用宽度和高度微调按钮调整图标的**宽度**和**高度。**
    ![icon-width-height.fc457b](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/icon-width-height.fc457b.7164f8.png)
<br>

### 删除图标选项

1. 选择要删除的选项。
    ![icon-delete.77803b](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/icon-delete.77803b.bb8a49.png)
2. 单击删除按钮以删除所选选项。
