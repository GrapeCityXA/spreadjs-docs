# editing

SpreadJS 允许用户控制单元格的编辑操作。单元格的编辑模式默认始终处于启用状态。你可以根据需求启用或禁用单元格的编辑功能。
以下部分将描述用户如何始终启用单元格的编辑模式，以及如何完全禁用单元格的编辑操作。

## 始终处于编辑模式

你可以设置单元格，使其在用户点击时始终处于编辑模式。通常情况下，用户需要输入内容或双击后单元格才会进入编辑模式。
在 [EnterCell ](gcdocsite__documentlink?toc-item-id=8579217b-549b-41f7-aa4f-f0e21c37872e)事件中设置 [startEdit ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#startedit)方法，以便用户点击单元格或使用 Tab 键或回车键移动到该单元格时，该单元格立即进入编辑模式。
以下代码示例在用户点击单元格时将其置于编辑模式。

```javascript
window.onload = function()
{
   var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"),{sheetCount:3});
   var activeSheet = spread.getActiveSheet();
   
   // 设置为始终处于输入模式。
   spread.bind(GC.Spread.Sheets.Events.EnterCell, function (event, data)
   {
      var sheet = data.sheet;
      activeSheet.startEdit(false);
   });
}
```

如果 **startEdit** 方法中的 *selectAll* 参数设置为 `true`，那么在编辑过程中更改文本时会选中所有文本。
以下代码示例在开始编辑时选中文本。

```javascript
$(document).ready(function ()
{
   new GC.Spread.Sheets.Workbook(document.getElementById("ss"),{sheetCount:3});
   var sheet = spread.getActiveSheet();
   sheet.setValue(0, 0, "ABC", GC.Spread.Sheets.SheetArea.viewport);

   // 设置为始终处于输入模式。
   spread.bind(GC.Spread.Sheets.Events.EnterCell, function (event, data)
   {
      var activeSheet = data.sheet;
      activeSheet.startEdit(true);
   });
});
```

## 禁用编辑

SpreadJS 允许你根据需求通过以下方式禁用单元格的编辑功能：

* `GC.Spread.Sheets.Style` 类的 `allowEditInCell` 属性。
* `CellRange` 类的 `allowEditInCell()` 方法。

默认情况下，`allowEditInCell` 属性是启用的。然而，禁用该属性后，单元格无法通过以下方式进入编辑模式：

* 在单元格中双击时
* 使用键盘在单元格或公式文本框中进行编辑时
* 使用 `worksheet.startEdit()` API 时

> **注意**：
>
> * `allowEditInCell` 属性仅在单元格锁定设置为 `false` 时起作用。
> * `allowEditInCell` 属性不影响下拉按钮的工作方式。下拉列表可以更改单元格的值而不使单元格进入编辑模式。
> * 如果 `allowEditInCell` 设置为 `false`，那么公式文本框也将是只读的。
> * `allowEditInCell` 属性适用于所有单元格类型。
>     * `allowEditInCell` 属性不控制使用单元格下拉列表提交值，因为下拉列表不会使单元格进入编辑模式。
>     * `allowEditInCell` 属性控制组合框单元格的打开，因为打开组合框会使组合框单元格进入编辑模式。

以下代码通过使用 `Style` 类的 `allowEditInCell` 属性禁用单元格编辑。

```javascript
var sheet = spread.getActiveSheet();
// 使用 Style 类的 allowEditInCell 属性
var style = new GC.Spread.Sheets.Style();
style.allowEditInCell = false;
sheet.setStyle(1, 1, style);
```

以下代码使用 `CellRange` 类的 `allowEditInCell` 方法禁用单元格编辑：

```javascript
// 使用 CellRange 类的 allowEditInCell 方法
sheet.getRange(1, 1, 1, 1, GC.Spread.Sheets.SheetArea.viewport).allowEditInCell(false);
```

## 使用设计器

SpreadJS 设计器使你能够控制单元格是否进入编辑模式。
请按照以下步骤禁用单元格的编辑功能。

1. 右键单击任何单元格，并从上下文菜单中选择“单元格格式”。
2. 在“单元格格式”对话框中，点击“保护”选项卡。
3. 使用“允许在单元格中编辑”复选框启用/禁用所选单元格的编辑功能。
