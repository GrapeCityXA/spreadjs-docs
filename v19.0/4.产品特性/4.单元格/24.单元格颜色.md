# colors

你可以给 单元格, 列, 行, 标题区域和小组件设置颜色。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/cellcolor.png)
为单元格，列，标题或行设置 **backColor** 或 **foreColor** 方法。你可以设置 **backColor** 方法或使用控件主题。 你可以使用 **options.grayAreaBackColor** 来设置灰色区域（内容区域的空白部分）的背景色
如果您想了解更多关于主题的信息，请访问[Configure Themes](gcdocsite__documentlink?toc-item-id=49874b66-77e9-46e7-8874-d825b5fe0bc6). 你也可以使用样式（Styles）来设置表格的外观。如果你想了解更多关于样式（Styles）的信息，请访问[Set Styles](gcdocsite__documentlink?toc-item-id=b83f13ab-8ddd-49c0-bcec-7c5a886922e1).
本代码为B2单元格设置 **前景色** 与 **背景色** 。

```JavaScript
//设置单元的背景色和原色。
    var cell = activeSheet.getCell(1, 1, GC.Spread.Sheets.SheetArea.viewport);
cell.backColor("Blue");
cell.foreColor("Red");
cell.value("Color");
```

本示例为标题设置前景色和背景色。

```JavaScript
//设置整个列标题的背景色和前景色。
     var row = activeSheet.getRange(0, -1, 1, -1, GC.Spread.Sheets.SheetArea.colHeader);
 row.backColor("Red");
 row.foreColor("White");
 //设置第二行标题的背景色。
     activeSheet.getCell(1, 0, GC.Spread.Sheets.SheetArea.rowHeader).backColor("Yellow");
```

此示例变更活动单元的颜色。

```JavaScript
window.onload = function()
{
   var spread =
   new GC.Spread.Sheets.Workbook(document.getElementById("ss"),{sheetCount:3});
   var sheet = spread.getActiveSheet();
   sheet.getCell(0, 0).backColor("pink");
   sheet.bind(GC.Spread.Sheets.Events.LeaveCell, function (event, infos) {
   
   // 移动之前重置单元的背景色
   infos.sheet.getCell(infos.row, infos.col).backColor(undefined);
   });
  
   sheet.bind(GC.Spread.Sheets.Events.EnterCell, function (event, infos) {
           
   //设置目标单元格（当前活动单元格）的背景色
   infos.sheet.getCell(infos.row, infos.col).backColor("pink");
});
}
```
