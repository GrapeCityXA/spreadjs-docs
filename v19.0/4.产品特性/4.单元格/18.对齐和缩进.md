# cellalign

SpreadJS 提供了灵活的单元格文本对齐和缩进选项，支持通过 API（使用 `hAlign`、`vAlign`、`textIndent` 等方法）编程设置，或在设计器中可视化操作。这些功能让你可以完全控制单元格内容的位置和显示方式。
你可以通过 [hAlign](gcdocsite__documentlink?toc-item-id=64f05fd4-fafa-47dc-9856-b74263f357ec#halign) 方法设置水平对齐方式：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image.57583d-20251226.bd8433.png)

| **水平对齐类型** | **描述** |
| ------ | --- |
| 常规（General） | 根据单元格内容类型自动对齐（文本左对齐，数字右对齐）。 |
| 左对齐（Left） | 内容靠单元格左边缘对齐。 |
| 居中（Center） | 内容在单元格内水平居中。 |
| 右对齐（Right） | 内容靠单元格右边缘对齐。 |
| 跨选区居中（Center Across Selection） | 跨所选范围居中内容，无需合并单元格。 |
| 分布式对齐（Distributed） | 字符在单元格宽度内均匀分布。 |
| 两端对齐（Justify） | 调整间距，使文本行左右边缘均对齐。 |

你可以通过 [vAlign](gcdocsite__documentlink?toc-item-id=64f05fd4-fafa-47dc-9856-b74263f357ec#valign) 方法设置垂直对齐方式：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image.1f62c0-20251229.f6caa2.png)

| **垂直对齐类型** | **描述** |
| ------ | --- |
| 顶端对齐（Top） | 内容靠单元格上边缘对齐。 |
| 居中（Center） | 内容在单元格内垂直居中。 |
| 底端对齐（Bottom） | 内容靠单元格下边缘对齐。 |
| 两端对齐（Justify） | 调整行间距，使文本均匀填充单元格高度。 |

## 跨选区居中对齐（Center Across Selection）

SpreadJS 的“跨选区居中”水平对齐功能可在不合并单元格的情况下，将所选单元格的内容跨列居中显示。该水平对齐方式可通过 `HorizontalAlign.centerContinuous` 枚举值设置。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/centerAcrossSelection-20251226.0c5f16.gif)
以下表格展示了“跨选区居中”对齐的不同行为表现：

| 行为 | 示例 |
| --- | --- |
| 为范围设置该对齐方式后，每个单元格会向右查找连续的空值单元格，最终将内容显示在所有相关单元格的中心位置。 | ![center-selection-1.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/center-selection-1.9c7358-20251226.07d2c8.gif) |
| 若后续在所选范围内输入值，选区和居中效果会自动更新，排除该单元格及右侧所有单元格。 | ![center-selection-2.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/center-selection-2.4e1a03-20251226.8d7ebe.gif) |
| 选区始终从设置格式的单元格开始。若选区延伸至该单元格左侧，左侧单元格不会被包含在居中范围内。 | ![center-selection-3.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/center-selection-3.674f8b-20251226.e36196.gif) |
| 调整列宽时，居中位置会自动适配。 | ![center-selection-4.gif](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/center-selection-4.8169d7-20251226.56c97e.gif) |

以下代码示例演示了如何在工作表中实现“跨选区居中”对齐：

```javascript
activeSheet.getCell(1,1).value("跨选区居中");
// 为单元格范围 (1,1) 到 (1,5) 设置跨选区居中对齐
activeSheet.getRange(1, 1, 1, 5, GC.Spread.Sheets.SheetArea.viewport)
  .hAlign(GC.Spread.Sheets.HorizontalAlign.centerContinuous);
```

“跨选区居中”对齐与 SpreadJS 其他功能的交互方式如下：

* **内容溢出（Overflow）** \- 若“跨选区居中”对齐的内容超出所选范围宽度，会向左右两侧溢出。
* **自动换行（Wrap text）** \- 行高属性会强制单元格在“跨选区居中”区域内自动换行。
* **缩小适配（Shrink to fit）** \- 若启用该选项，会根据宽度属性计算实际字体大小，使内容适配所选范围。
* **会计数字格式（Accounting number format）** \- “跨选区居中”不会直接居中文本，而是将符号和数值向两侧拉伸。
* **文本缩进（Text indent）** \- “跨选区居中”会将缩进锁定为 0。
* **文本方向（Orientation）** \- “跨选区居中”会将文本方向锁定为 0（水平方向）。
* **合并单元格（Merged cells）** \- 合并单元格无法使用跨选区居中样式。若单元格已合并，“跨选区居中”会自动替换为“居中”对齐。

## 分布式水平对齐（Distributed Horizontal Alignment）

在 SpreadJS 中，“分布式”水平对齐会将文本在单元格宽度内均匀分布，是居中对齐与自动换行的结合效果。
启用“分布式”水平对齐后，文本每行的每个单词会在单元格宽度内均匀对齐；应用缩进值时，单元格的左右两侧都会添加内边距。因此，当分布式对齐与缩进结合使用时，每行的左右边距都会与单元格边缘对齐。该水平对齐方式可通过 `HorizontalAlign.distributed` 枚举值设置。
![distributed-halign](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/distributed-halign.b6df2a-20251226.64958f.png)
以下代码示例演示了如何在工作表中实现“分布式”水平对齐：

```javascript
var style = new GC.Spread.Sheets.Style();
style.hAlign = GC.Spread.Sheets.HorizontalAlign.distributed;
activeSheet.setStyle(1, 1, style, GC.Spread.Sheets.SheetArea.viewport);
activeSheet.getCell(1, 1).value("这是分布式对齐示例文本");
```

“分布式”水平对齐与 SpreadJS 其他功能的交互方式如下：

* **自动换行（Wrap text）** \- 分布式对齐的内容会自动启用自动换行功能，单独设置自动换行开关无效果。
* **缩小适配（Shrink to fit）** \- 分布式对齐会禁用该选项。
* **文本缩进（Text indent）** \- 分布式对齐的内容会同时缩进单元格的左右两侧。
* **最后一行两端对齐（Justify Last Line）** \- 分布式对齐会禁用该选项。
* **显示省略号（Show Ellipsis）** \- 分布式对齐会禁用该选项。

## 两端对齐（Justify Alignment）

“两端对齐”功能支持 **水平两端对齐** 和 **垂直两端对齐**，确保文本在单元格的宽度和高度范围内均匀分布。
通过自动启用文本换行并调整单词间距和行间距，两端对齐可帮助用户以最少的手动调整实现专业、整洁的文档格式。以下图表描述了不同布局条件下水平和垂直两端对齐的行为：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image.0d929f-20251226.298b70.png)

| **文本方向** | **行为描述** | **视觉示例** |
| ---- | ---- | ---- |
| 水平方向 | <ul><li>除最后一行外，每行的**首尾字符**分别与**左右边距**对齐。</li><li>**最后一行**或**单行文本**默认**左对齐**。</li><li>自动调整**单词间距**，必要时调整**行间距**，使文本在单元格宽度内均匀分布。</li><li>支持**连字符断词**，可减少单词间的过度间距。</li></ul> | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image.fb8518-20251226.767f48.png) |
| 垂直方向 | <ul><li>第一行与单元格**上边缘**对齐，最后一行与**下边缘**对齐。</li><li>若仅为**单行文本**，则与单元格**上边缘**对齐。</li><li>多行文本时，文本行会在单元格高度内**均匀分布**。</li></ul> | ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/7c3e5757-7200-459c-91d6-c795c0854396/image.77a9f8-20251226.657c80.png) |

### 使用示例

```javascript
var style = new GC.Spread.Sheets.Style();
style.hAlign = GC.Spread.Sheets.HorizontalAlign.justify; // 水平两端对齐
style.vAlign = GC.Spread.Sheets.VerticalAlign.justify; // 垂直两端对齐
activeSheet.setStyle(1, 1, style, GC.Spread.Sheets.SheetArea.viewport);
activeSheet.getCell(1, 1).value("两端对齐段落演示文本。这是一段用于展示两端对齐效果的示例文本，包含多行内容以体现均匀分布的特性。");
```

以下表格描述了两端对齐与其他布局功能（如自动换行、合并单元格、文本方向等）的交互方式：

| **相关功能** | **交互详情** |
| ---- | ---- |
| 自动文本换行（Automatic Text Wrapping） | <ul><li>应用两端对齐后，系统会自动启用自动换行。</li><li>两端对齐激活时，手动切换自动换行开关无效。</li></ul> |
| 合并单元格兼容性（Merged Cell Compatibility） | 两端对齐会自动适配合并单元格的合并后宽度和高度，在扩大的区域内保持文本均匀分布。 |
| 文本方向（Text Orientation） | <ul><li>当文本以**任意角度（< 0° 或 > 0°）** 旋转时，两端对齐失效，由文本方向控制对齐方式。</li><li>**当旋转至 -90° 或 90° 时：**<ul><li>水平两端对齐会使文本在列方向均匀分布</li><li>垂直两端对齐会使文本在行方向均匀分布。</li></ul></li><li>旋转文本模式下，两端对齐的行为类似基于旋转方向的“顶端/底端”或“左侧/右侧”换行对齐。</li></ul> |
| 缩小适配（Shrink to Fit） | <ul><li>单元格包含多行文本时，不应用缩小适配。</li><li>两端对齐激活时，无论内容如何，都会覆盖并禁用缩小适配。</li></ul> |
| 显示省略号（Show Ellipsis） | 启用两端对齐时，“显示省略号”选项无效。 |
| 富文本（Rich Text） | <ul><li>**下划线/删除线**：两端对齐时，线条可能在单词之间断开。</li><li>**列表**：两端对齐下，列表缩进可能显示异常。</li><li>**上标/下标**：应用两端对齐时，上标和下标会按比例缩放。</li></ul> |
| 缩进（Indent） | 水平对齐设置为两端对齐时，缩进功能无效。 |

## 使用 SpreadJS 设计器

你可以通过“设置单元格格式”窗口的“对齐”选项卡使用对齐和缩进功能。操作步骤：点击“开始”选项卡 > “对齐方式”组 > 右下角的箭头按钮，打开“设置单元格格式”窗口。
