# filter

SpreadJS 允许用户根据单元格的数据类型应用条件筛选（数字筛选、文本筛选、日期筛选、颜色筛选、自定义自动筛选）。在工作表中执行筛选操作后，符合筛选条件的行将显示，其他行将隐藏。
对于允许筛选的列，其列标题中会显示一个筛选按钮。用户可以点击该按钮，并使用筛选对话框中的可用选项。
![filter1.541fc4](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/filter1.541fc4.017de2.png)
筛选对话框可帮助您按项目筛选、对项目列表进行排序、隐藏筛选后的行，以及清除应用于某列的任何筛选条件。如果筛选项目过长或过短，无法在筛选对话框中完整显示，用户可以调整对话框大小。
您可以使用 [rowFilter](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#rowfilter) 的 `HideRowFilter` 类以代码形式创建筛选。以下代码示例展示了如何在工作表中添加筛选对话框，并对某个区域应用筛选。

```javascript
// 配置工作簿和工作表
var spread = new GC.Spread.Sheets.Workbook("ss");
var activeSheet = spread.getActiveSheet();    

activeSheet.setValue(0, 0, "North");
activeSheet.setValue(1, 0, "South");
activeSheet.setValue(2, 0, "East");
activeSheet.setValue(3, 0, "South");
activeSheet.setValue(4, 0, "North");
activeSheet.setValue(5, 0, "North");
activeSheet.setValue(6, 0, "West");
activeSheet.setColumnWidth(0, 80);
           
// 设置行筛选
activeSheet.rowFilter(new GC.Spread.Sheets.Filter.HideRowFilter(new GC.Spread.Sheets.Range(0, 0, 7, 1)));

// 按“North”筛选第1列
var rowFilter = spread.getActiveSheet().rowFilter();
var condition = new GC.Spread.Sheets.ConditionalFormatting.Condition(
    GC.Spread.Sheets.ConditionalFormatting.ConditionType.textCondition, {
        compareType: GC.Spread.Sheets.ConditionalFormatting.TextCompareType.equalsTo,
        expected: "North"
});
rowFilter.addFilterItem(0, condition);
rowFilter.filter(0);
```

用户可以使用鼠标或各种键盘按键与筛选对话框进行交互。SpreadJS 提供以下键盘按键用于与筛选对话框交互：

| **按键** | **描述** |
| --- | --- |
| Esc | 取消对话框。 |
| Tab | 移动到不同部分。 |
| 空格键 | 当焦点在列表中的某项上时，选中或取消选中该项。 |
| Enter | 应用筛选。 |
| 左箭头键 | 当焦点在列表中的当前项上时，折叠该项的所有子项。 |
| 右箭头键 | 当焦点在列表中的当前项上时，展开该项的所有子项。 |
| 上箭头键 | 在筛选对话框中向上移动焦点；当列表框的第一个根节点处于焦点时，将焦点移出列表框；或在列表中向上移动焦点。 |
| 下箭头键 | 在筛选对话框中向下移动焦点；当列表框中最后一个可见节点处于焦点时，将焦点移出列表框；或在列表中向下移动焦点。 |

## 自定义筛选对话框

您可以使用 **filterDialogVisibleInfo** 方法控制筛选对话框中显示的信息。此方法有助于获取或设置行筛选的可见信息。
![filter-hide-options](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/filter-hide-options.877bee.png)
以下代码示例展示了如何在筛选对话框中隐藏“按值排序”和列表筛选区域。

```javascript
// 配置工作簿和工作表
var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
var sheet = spread.getActiveSheet();

// 设置行筛选
sheet.rowFilter(new GC.Spread.Sheets.Filter.HideRowFilter(new GC.Spread.Sheets.Range(1, 1, 10, 3)));
            
// 隐藏筛选选项
var filter = sheet.rowFilter();
filter.filterDialogVisibleInfo({
    sortByValue: false,
    sortByColor: true,
    filterByColor: true,
    filterByValue: true,
    listFilterArea: false
})
```

## 筛选对话框列表框

筛选对话框列表框支持分层树形显示。它会显示占据最多单元格的数据类型项目，无论是数字、文本还是日期类型。如果筛选数据包含不同类型的值，筛选项目将遵循特定顺序：日期、数字、文本、逻辑值和空白，与 Excel 相同。
如果筛选范围包括分级显示列，筛选对话框列表框中的层次结构将与分级显示列数据的层次结构相同，并且筛选项目复选框将以选中、未选中和不确定（子项状态不一致）这几种状态来支持树形结构。更多信息，请参考 [分级显示列](gcdocsite__documentlink?toc-item-id=3041367e-17ff-4573-9835-220b2bc3eefb)。
![FilterListBox](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/FilterListBox.735216.png)
在日期树形视图中，不同层次结构具有不同的格式策略，如下所述：

1. 日期树形显示格式基于第一个日期类型单元格的格式。如果用户未设置格式，则应用自动日期格式。
2. 当区域设置为英文（EN）且日期格式化字符串不包含区域设置 ID 时，日期树形视图格式将显示为：年份模式：YYYY，月份模式：MM，日期模式：DD。

日期类型值筛选将根据数据集按以下场景详细显示：

| **场景** | **示例** |
| --- | --- |
| 如果筛选范围的所有值处于不同年份，则任何级别都不展开。 | ![datefilter-year.e6dd11](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/datefilter-year.e6dd11.b70148.png) |
| 如果筛选范围的所有值处于同一年份，则展开年份级别。 | ![datefilter-month.90b1eb](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/datefilter-month.90b1eb.a9a8e6.png) |
| 如果筛选范围的所有值处于同一年份和同一月份，则展开年份级别和月份级别。 | ![datefilter-date.3847c5](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/datefilter-date.3847c5.8bd6c3.png) |

## 按颜色筛选

您还可以基于两种模式在筛选列中应用颜色筛选：

* 按字体颜色筛选 - 显示具有选定字体颜色的单元格。
* 按单元格背景颜色筛选 - 显示具有选定背景颜色的单元格。

当筛选范围包含不止一种单元格背景颜色或字体颜色时，颜色筛选菜单将启用。
