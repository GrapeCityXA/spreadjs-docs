# sort

甘特图工作表提供排序功能，以便在整个项目中高效地组织任务。你可以使用 [GC.Spread.Sheets.GanttSheet.Project](gcdocsite__documentlink?toc-item-id=dd6f4979-2a14-4231-99d3-8b4bba79d476#sort) 类的 `sort` 方法对数据进行排序。
SpreadJS 允许你以不同方式对甘特图工作表的数据进行排序和排列。这些排序选项使你能够根据特定的项目需求修改甘特图工作表中任务的显示方式。

## 升序

将任务或资源按从最低值到最高值的顺序排序（A 到 Z 以及 1、2、3…）。
以下代码示例展示了如何按升序对 “taskNumber” 字段进行排序。

```javascript
// Sort taskNumber field ascending.     
ganttSheet.project.sort(["taskNumber"], [true]);    
```

## 降序

将任务或资源按从最高值到最低值的顺序排序（Z 到 A 以及 …3、2、1）。
以下代码示例展示了如何按降序对 “taskNumber” 字段进行排序。

```javascript
// Sort taskNumber field descending.     
ganttSheet.project.sort(["taskNumber"], [false]);
```

## 保持大纲结构

为了保持大纲结构完整，甘特图工作表在排序任务时会保留原始的任务树结构。在这种情况下，子任务与父任务之间的关系保持不变。这意味着子任务将始终与它们的父任务相关联。甘特图工作表也可以在不维护大纲结构的情况下进行排序。
以下代码示例展示了如何在不保持大纲结构的情况下，按降序对 “taskNumber” 字段进行排序。

```javascript
// Sort taskNumber field descending, not to keep structure. 
ganttSheet.project.sort(["taskNumber"], [false], false);
```

SpreadJS 还支持[平面排序](https://demo.grapecity.com.cn/spreadjs/SpreadJSTutorial/features/worksheet/sort/purejs)，但这会破坏甘特图工作表的原始任务树结构。平面排序还会忽略分组中的数据。请注意，一旦对甘特图工作表进行了平面排序，将禁止执行以下操作：

* 根节点不参与排序。
* 如果你在不保持大纲结构的情况下进行排序，该项目将是临时的。因此，
    * 禁止所有折叠 / 展开行为。
    * 缩进 / 取消缩进将不起作用。
    * 无法对任务重新编号。

## 永久重新编号任务

甘特图工作表的排序可以是临时的，也可以是永久的。在进行永久排序时，任务的 ID 编号会根据新的顺序重新编号。但是，如果你想在数据库中保留排序状态，可以对所有任务重新编号。要重新编号任务，请确保启用 “保持大纲结构” 复选框。
以下代码示例展示了如何在不保持大纲结构的情况下，按降序对 “taskNumber” 字段进行排序，并根据新的排序顺序对任务编号重新编号。

```javascript
// Sort taskNumber field descending and not to keep the structure.
ganttSheet.project.sort(["taskNumber"], [false], true, true);
```
