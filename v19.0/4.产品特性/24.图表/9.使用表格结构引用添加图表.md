# add-charts-using-table-structure-reference

SpreadJS 支持表格中的[结构化引用公式](gcdocsite__documentlink?toc-item-id=452dc248-b712-474a-8438-e2ea33725801)。如果 SpreadJS 中的图表通过表格结构引用绑定到完整的表格或表格的某些列，那么在运行时，表格中的任何更新都会自动更新图表的系列或数据值。
你可以使用三种不同的结构化表格引用策略来创建图表。下面我们将在各个部分中逐一讨论这些策略。

* **如果图表的数据源来自整个表格范围。**
    当使用整个表格范围创建图表，并且表格的范围被调整大小，或者添加、删除行和列，或者影响了自动扩展行为时，图表的系列也会同时更新，如下方的动图所示。
    ![entirerange-chart-table structure.6f98a2](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/entirerange-chart-table%20structure.6f98a2.add391.gif)
    以下代码示例展示了如何使用结构化引用将整个表格设置为图表的数据源。

    ```javascript
    // 添加数据源为整个表格范围的图表。
    var chart1 = sheet.charts.add('chart1', GC.Spread.Sheets.Charts.ChartType.columnClustered, 50, 150, 400, 200, "Table1[[#Headers],[#Data]]");
    ```
* **如果图表的数据源来自表格的特定列。**
    当表格操作更改了绑定到图表的特定列中的数据时，图表会根据新数据进行更新，但系列保持不变，如下方的动图所示。
    ![specific column-chart-table structure.a0b564](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/specific%20column-chart-table%20structure.a0b564.ffd595.gif)
    以下代码示例使用结构化引用从表格的特定列创建图表。

    ```javascript
    // 将图表范围设置为表格的某列范围。
    var chart2 = sheet.charts.add('chart2', GC.Spread.Sheets.Charts.ChartType.columnClustered, 500, 150, 400, 200, "Table1[[#Headers],[#Data],[Name]],Table1[[#Headers],[#Data],[Age]]");
    ```
* **如果图表的数据源是表格结构引用和常规范围的组合。**
    当使用表格结构引用和常规范围的组合来定义图表的数据源时，图表会进行更新，如下方的动图所示。
    ![combo-chart-tablestructure.34a88b](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/combo-chart-tablestructure.34a88b.38da2d.gif)
    以下代码示例展示了如何使用表格结构化引用和常规范围的组合来设置图表的数据源。

    ```javascript
    // 将图表的范围设置为表格结构引用和常规范围的组合。
    var chart3 = sheet.charts.add('chart3', GC.Spread.Sheets.Charts.ChartType.columnClustered, 50, 400, 400, 200, "Table1[[#Headers],[#Data],[Id]],Sheet1!D1:D4");
    ```
