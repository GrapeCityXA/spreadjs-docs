# display-empty-cells-in-chart

在电子表格中可视化数据时，您可能希望在图表中同时绘制空白单元格或空值单元格以及其他数据。
SpreadJS 像 Excel 一样支持在图表中显示空白单元格和空值。此功能有助于在图表中绘制缺失的数据，从而帮助用户快速识别和纠正数据中的任何问题。
借助此功能，用户可以根据自己的需求和特定偏好，将空白单元格或空值显示为间隔、将空白单元格显示为零值，以及用线条连接空白点。默认情况下，引用工作表中空白单元格的图表会通过用线条连接空白点来自动填充缺失的数据。

## 将空白单元格显示为间隔

用户可以使用 [Chart ](gcdocsite__documentlink?toc-item-id=3816be2a-7532-41fa-bd2e-e2f41d1de655)类的 [displayBlanksAs ](gcdocsite__documentlink?toc-item-id=3816be2a-7532-41fa-bd2e-e2f41d1de655#displayBlanksAs)方法，在图表中将空白单元格显示为间隔。
**示例**：下图展示了一个比较两家不同公司年度销售收入的图表。您可能会注意到，电子表格中的 D2 和 D3 单元格包含空白数据。现在，如果您想在图表中将这些空白单元格（D2 和 D3）显示为间隔，只需将 [displayBlanksAs ](gcdocsite__documentlink?toc-item-id=3816be2a-7532-41fa-bd2e-e2f41d1de655#displayBlanksAs)方法的值设置为“gaps”，您的图表将如下图所示进行显示！
![gaps](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/gaps.0e9832.png)

## 用线条连接空白点

用户可以使用 [Chart ](gcdocsite__documentlink?toc-item-id=3816be2a-7532-41fa-bd2e-e2f41d1de655)类的 [displayBlanksAs ](gcdocsite__documentlink?toc-item-id=3816be2a-7532-41fa-bd2e-e2f41d1de655#displayBlanksAs)方法，在图表中将空白数据显示为相连的线条。
**示例**：下图展示了一个比较两家不同公司年度销售收入的图表。您可能会注意到，电子表格中的 D2 和 D3 单元格包含空白数据。现在，如果您想在图表中将这些空白单元格（D2 和 D3）显示为相连的值，只需将 [displayBlanksAs ](gcdocsite__documentlink?toc-item-id=3816be2a-7532-41fa-bd2e-e2f41d1de655#displayBlanksAs)方法的值设置为“connected”，您的图表将如下图所示进行显示。
![connected](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/connected.19f2bb.png)

## 支持的图表类型

所有图表类型都支持此功能。不过，不同图表中空白单元格的显示方式存在一些差异，如下所述：

* 对于折线图、带数据标记的折线图、折线散点图、无数据标记的折线散点图、平滑线散点图、无数据标记的平滑线散点图以及雷达图类型；支持所有三种选项（间隔、零值和相连）。
* 对于组合图，如果它包含以下任何系列类型：折线图、带数据标记的折线图、折线散点图、无数据标记的折线散点图、平滑线散点图、无数据标记的平滑线散点图以及雷达图；那么它将支持所有三种选项（间隔、相连和零值）；否则仅支持两种选项：间隔和零值。
* 对于旭日图、矩形树状图、堆积数据点折线图、百分比堆积数据点折线图、堆积折线图和百分比堆积折线图类型，仅支持零值选项（即用户只能将空白单元格显示为零值）。
* 对于其他非组合图类型，仅支持间隔和零值。

以下代码示例展示了如何在图表中将空白单元格显示为间隔。

```javascript
// 初始化 Spread
var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });

// 获取活动工作表
var activeSheet = spread.getActiveSheet();
activeSheet.suspendPaint();
// 为图表准备数据
activeSheet.setValue(0, 1, 'Y-2013');
activeSheet.setValue(0, 2, 'Y-2014');
activeSheet.setValue(0, 3, 'Y-2015');
activeSheet.setValue(0, 4, 'Y-2016');
activeSheet.setValue(0, 5, 'Y-2017');
activeSheet.setValue(0, 6, 'Y-2018');
activeSheet.setValue(1, 0, 'Gradlco Corp. Ltd');
activeSheet.setValue(2, 0, 'Saagiate Corp. Ltd.');
activeSheet.setColumnWidth(0, 120);
var dataArray = [
    [2331, 4663, , 5689, 6230, 6360],
    [2284, 2030, , 1560, 2324, 1304],
];
activeSheet.setArray(1, 1, dataArray);
// 添加带数据标记的折线图
var chart = activeSheet.charts.add('chart1', GC.Spread.Sheets.Charts.ChartType.lineMarkers, 30, 85, 400, 250, 'A1:G3');
// 配置 - 将空白值显示为间隔
chart.displayBlanksAs(GC.Spread.Sheets.Charts.DisplayBlanksAs.gaps);
// 配置图表标题
var title = chart.title();
title.text = '年度销售记录';
title.fontFamily = 'Cambria';
title.fontSize = 16;
title.color = 'Red';
chart.title(title);
activeSheet.resumePaint();
```
