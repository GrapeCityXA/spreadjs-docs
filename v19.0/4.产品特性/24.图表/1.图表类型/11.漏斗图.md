# funnel-chart

漏斗图通常用于可视化包含一系列相互连接阶段的线性流程。这种图表非常适合评估企业的销售周期。
在工作表中按列或行排列的数据可以绘制在漏斗图中。漏斗图中的每个阶段都代表了总数的一个比例。因此，它呈现出漏斗的形状，第一个阶段最大，随后的每个阶段都比前一个阶段小。
下面展示的示例描绘了销售管道中每个连续阶段的销售潜在客户数量，与每个阶段相关的条形长度代表了每个阶段的客户数量。该用例分析了每个阶段的销售情况，从顶部的潜在客户（潜在顾客）和合格潜在客户（对你的业务表示感兴趣的客户）开始，然后向下依次是报价、谈判，最后是成交销售（已确认的客户）。
![funnel-chart](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/funnel-chart.cfc2d1.png)
以下代码示例展示了如何向电子表格中添加一个漏斗图。

```javascript
// 获取活动工作表
var sheet = spread.getActiveSheet();

// 为图表准备数据
var dataArray = [
    ['阶段', '数量'],
    ['潜在客户', 500],
    ['合格潜在客户', 425],
    ['需求分析', 200],
    ['报价', 150],
    ['谈判', 100],
    ['成交销售', 90]             
];

sheet.setArray(1, 1, dataArray);

// 添加漏斗图
var chart = sheet.charts.add('chart1', GC.Spread.Sheets.Charts.ChartType.funnel, 300, 0, 500, 400, "B2:C8");
        
// 设置图表标题
var title = chart.title();
title.text = "销售管道";
chart.title(title);

// 设置数据标签
var dataLabels = chart.dataLabels();
dataLabels.showValue = true;
dataLabels.color = 'white';
chart.dataLabels(dataLabels);
```
