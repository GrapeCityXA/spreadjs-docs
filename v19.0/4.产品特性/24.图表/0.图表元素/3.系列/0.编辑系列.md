# edit-series

你可以使用一组全面的选项来管理绘制在图表上的数据系列，通过“选择数据源”对话框帮助你自定义图表内数据系列的外观和行为。
要打开“选择数据源”对话框，请在“数据”组中单击“图表设计”>“选择数据”功能区按钮。
![series-datasource-ribbon](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/series-datasource-ribbon.aa416d.832fb0.png)
“选择数据源”对话框允许你为每个系列设置名称和X、Y值。对于“名称”和“Y值”，使用“系列”选项的“添加/编辑”按钮，而“分类轴标签”选项的“编辑”按钮则用于设置“X值”。
![series-datasource](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/series-datasource.aec900.a78ac7.png)
不过，对于[散点图](gcdocsite__documentlink?toc-item-id=22da3aab-65aa-4dff-bd43-9517ddb3a5ff)和[气泡图](gcdocsite__documentlink?toc-item-id=22da3aab-65aa-4dff-bd43-9517ddb3a5ff#%E6%B0%94%E6%B3%A1%E5%9B%BE)，你只能使用“系列”选项来编辑“名称”、“X值”和“Y值”，因为“分类轴标签”选项中的“编辑”按钮是禁用状态。
![series-datasource-scatter](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/series-datasource-scatter.d6a346.45b251.png)
