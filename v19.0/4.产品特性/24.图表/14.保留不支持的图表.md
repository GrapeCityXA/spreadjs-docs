# preserve-unsupported-charts

当从其他文件格式导入时，SpreadJS使您能够保留不受支持的图表。 可以将 **preserveUnsupportedChart** 标志设置为true，以保留图表及其属性。 不受支持的图表也可以导出为其他文件格式。
下图显示了SpreadJS中不受支持的图表类型，其默认文本为“不受支持的图表类型”：
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/unsupported_chart.PNG)
**preserveUnsupportedChart** 的默认值为false，当在SpreadJS中导入时，会将不受支持的图表转换为柱形图。
此示例使用代码从Excel导入SpreadJS后，将其保留在SpreadJS中。

```JavaScript
var sheet = workbook.getSheet(1);
sheet.charts.preserveUnsupportedChart(true);
```

> **注意:** **preserveUnsupportedChart** 标记是在表单级别应用的，因此，在变更活动表单时需要再次调用它。

本示例使用代码在不受支持的图表上定义了自定义文本。

```JavaScript
sheet.charts.preserveUnsupportedChart(true, function (chart, chartHost) {
    var paintElement = document.createElement('div');
    paintElement.innerHTML = 'Chart display not supported';
    chartHost.appendChild(paintElement);
});
```

> **注意:** 图表上显示的文本无法序列化为json数据。

* line3D
* column3D
* area3D
* columnClustered3D
* columnStacked3D
* columnStacked1003D

* barStacked3D
