# datasource

## 概述

DataManager 作为SpreadJS中强大的数据处理中枢，内置高性能解析引擎，支持多种数据源格式的高效处理。您可将其类比为轻量化的前端数据仓库，通过将不同类型的数据源以表（Table）的形式统一纳入管理，为后续的数据处理与展示奠定基础。

## 表（Table）管理机制

在DataManager体系中，数据源均以表（Table）为基本单元进行组织与管理。通过DataManager提供的核心API，用户可便捷地对数据源进行增删等操作，具体包括：

* [addTable](gcdocsite__documentlink?toc-item-id=d168d582-7001-4e98-a184-2aafa89215e1#addtable)：用于添加数据源表
* [removeTable](gcdocsite__documentlink?toc-item-id=d168d582-7001-4e98-a184-2aafa89215e1#removetable)：用于删除指定数据源表

### addTable：添加数据源表

`addTable`方法允许用户在DataManager中创建新的数据表。使用该方法时，需重点关注以下两个核心参数：

* **name**：数据表的唯一标识名称，用于后续对该表的引用与管理。
* **dataSourceOption**：数据源配置参数，用于定义表关联的数据来源及相关解析规则。

以下代码示例展示了如何通过`addTable`方法，将本地JSON格式数据添加至DataManager，并创建名为`Athlete`的数据表：

```javascript
// 定义本地JSON格式数据
var data = [
    { athlete: 'Michael Phelps', age: 23, year: 2008, date: '24/08/2008', sport: 'Swimming' },
    { athlete: 'Michael Phelps', age: 19, year: 2004, date: '29/08/2004', sport: 'Swimming' },
    { athlete: 'Michael Phelps', age: 27, year: 2012, date: '12/08/2012', sport: 'Swimming' },
];
// 配置数据源选项
var dsOptions = {
    data: data,
    schema: {
        type: 'json',
    },
};
// 获取SpreadJS workbook实例
var dataManager = spread.dataManager();
// 添加名为'Athlete'的数据表
var dataTable = dataManager.addTable('Athlete', dsOptions);
```

### removeTable：删除数据源表

`removeTable`方法可用于从DataManager中移除指定名称的数据表。以下代码示例演示了如何删除名为`Athlete`的数据表：

```javascript
// 获取SpreadJS workbook实例
var dataManager = spread.dataManager();
// 删除名为'Athlete'的数据表
dataManager.removeTable('Athlete');
```

> **注意**：DataManager中的数据源表管理仅负责数据存储与基础处理。若需在SpreadJS中可视化展示数据，需结合以下组件协同使用：
>
> * 集算表
> * 报表
> * 甘特表
> * 数据表格
> * 数据图表
