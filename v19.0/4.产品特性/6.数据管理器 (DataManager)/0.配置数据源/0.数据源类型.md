# datasource-type

## 概述

DataManager作为SpreadJS中强大的数据管理工具，支持多种常见及特殊格式的数据类型，能够高效地组织和管理数据，满足多样化的数据处理需求。目前，DataManager支持以下四种数据类型：

* Json
* CSV
* XML
* ColumnJson

本章节将详细介绍这些数据类型的特点，以及如何将它们添加到DataManager中，帮助您充分发挥其数据管理能力。

## 数据类型添加详解

在使用`addTable`方法（[API文档](gcdocsite__documentlink?toc-item-id=d168d582-7001-4e98-a184-2aafa89215e1#addtable)）时，需要传入符合`IDataSourceOption`接口（[API文档](gcdocsite__documentlink?toc-item-id=24e07bc4-c7cc-407c-98d5-0670ccab2cce#idatasourceoption)）的参数。其中，`IDataSourceOption`接口包含一个`schema`属性，其类型为`ISchemaOption`接口（[API文档](gcdocsite__documentlink?toc-item-id=24e07bc4-c7cc-407c-98d5-0670ccab2cce#ischemaoption)）。通过配置`schema`中的`type`属性，即可实现不同类型数据的接入。
为直观展示数据添加效果，添加的表格数据将通过[数据表格](gcdocsite__documentlink?toc-item-id=3a484162-caa2-4630-9959-6fd9482d824d#%E7%BB%91%E5%AE%9A%E5%88%B0%E6%95%B0%E6%8D%AE%E7%AE%A1%E7%90%86%E5%99%A8%E8%A1%A8%E6%A0%BC)与[集算表](gcdocsite__documentlink?toc-item-id=c063f5a4-84eb-40e2-8be3-701a41ae6d8b)两种形式呈现。尽管不同数据类型示例中的数据内容一致，展示效果图基本相同，但在代码实现上，能清晰体现各类数据的添加方式差异。

### JSON

JSON作为一种轻量级的数据交换格式，在数据传输和存储中应用广泛。DataManager支持本地与远端JSON数据的添加，以下为详细示例：
**本地JSON数据添加**：
以下代码示例将在DataManager中添加一个名为`Athlete`的表，用于存储运动员相关数据。

```javascript
async function initSpread(spread) {
    spread.suspendPaint();
    // 定义本地JSON数据
    var data = [
        { athlete: 'Michael Phelps', age: 23, country: 'United States', year: 2008, date: '24/08/2008', sport: 'Swimming', gold: 8, silver: 0, bronze: 0 },
        { athlete: 'Michael Phelps', age: 19, country: 'United States', year: 2004, date: '29/08/2004', sport: 'Swimming', gold: 6, silver: 0, bronze: 2 },
        { athlete: 'Michael Phelps', age: 27, country: 'United States', year: 2012, date: '12/08/2012', sport: 'Swimming', gold: 4, silver: 2, bronze: 0 },
    ];
    // 配置数据源选项
    var dsOptions = {
        data: data,
        autoSync: true,
        schema: {
            type: 'json',
        },
    };
    var dataManager = spread.dataManager();
    var dataTable = dataManager.addTable('Athlete', dsOptions);
    await dataTable.fetch();
    // 将数据绑定到表格
    var table = spread.getActiveSheet().tables.addFromDataSource('Athlete', 0, 0, 'Athlete', GC.Spread.Sheets.Tables.TableThemes.medium7);
    // 通过View将数据绑定至集算表
    var sheet = spread.addSheetTab(0, 'TableSheet1', GC.Spread.Sheets.SheetType.tableSheet);
    var view = dataTable.addView('myView');
    sheet.setDataView(view);
    spread.resumePaint();
}
```

**远端JSON数据添加**：
若需从远端获取JSON数据，只需修改数据源选项`dsOptions`，示例代码如下：

```javascript
var dsOptions = {
    remote: {
        read: {
            url: 'http://localhost:9590/api/data/json', // 替换为实际返回JSON数据的API地址
        },
    },
    schema: {
        type: 'json',
    },
};
```

### XML

XML（可扩展标记语言）常用于标记电子文件，以实现数据的结构化存储与传输。在DataManager中添加XML数据时，需注意`dataPath`属性的配置：
**本地XML数据添加**：
以下代码将本地XML格式字符串数据添加到DataManager，创建`Athlete`表。

```javascript
async function initSpread(spread) {
    spread.suspendPaint();
    // 定义本地XML格式字符串
    var xmlstring = '<athletes><athlete><name>Michael Phelps</name><age>23</age><country>United States</country><year>2008</year><date>24/08/2008</date><sport>Swimming</sport><gold>8</gold><silver>0</silver><bronze>0</bronze></athlete><athlete><name>Michael Phelps</name><age>19</age><country>United States</country><year>2004</year><date>29/08/2004</date><sport>Swimming</sport><gold>6</gold><silver>0</silver><bronze>2</bronze></athlete><athlete><name>Michael Phelps</name><age>27</age><country>United States</country><year>2012</year><date>12/08/2012</date><sport>Swimming</sport><gold>4</gold><silver>2</silver><bronze>0</bronze></athlete></athletes>';
    var dataManager = spread.dataManager();
    // 配置数据源选项
    var dsOptions = {
        data: xmlstring,
        autoSync: true,
        schema: {
            type: 'xml',
            dataPath: 'athletes.athlete', // 用于指定数据层级
        }
    };
    var dataTable = dataManager.addTable('Athlete', dsOptions);
    await dataTable.fetch();
    // 将数据绑定到表格
    var table = spread.getActiveSheet().tables.addFromDataSource('Athlete', 0, 0, "Athlete", GC.Spread.Sheets.Tables.TableThemes.medium7);
    // 通过View将数据绑定至集算表
    var sheet = spread.addSheetTab(0, "TableSheet1", GC.Spread.Sheets.SheetType.tableSheet);
    var view = dataTable.addView("myView");
    sheet.setDataView(view);
    spread.resumePaint();
}
```

**远端XML数据添加**：
获取远端XML数据时，修改`dsOptions`如下：

```javascript
var dsOptions = {
    remote: {
        read: {
            url: 'http://localhost:9595/api/data/xml',
        },
    },
    schema: {
        type: 'xml',
        dataPath: 'athletes.athlete',
    },
};
```

> **注意**：在XML数据示例中，通过配置`schema`属性下的`dataPath`属性，明确告知DataManager数据的层级结构，确保数据正确解析。

### ColumnJson

ColumnJson是一种特殊的JSON格式，其数据以列的形式组织。添加方式与常规JSON类似，通过设置`schema`的`type`属性为`columnJson`实现：
**本地ColumnJson数据添加**：
以下代码将本地ColumnJson格式数据添加到DataManager，创建`Athlete`表。

```javascript
async function initSpread(spread) {
    spread.suspendPaint();
    // 定义本地ColumnJson格式数据
    var data = {
        "athlete": ["Michael Phelps", "Michael Phelps", "Michael Phelps"],
        "age": [23, 19, 27],
        "country": ["United States", "United States", "United States"],
        "year": [2008, 2004, 2012],
        "date": ["24/08/2008", "29/08/2004", "12/08/2012"],
        "sport": ["Swimming", "Swimming", "Swimming"],
        "gold": [8, 6, 4],
        "silver": [0, 0, 2],
        "bronze": [0, 2, 0]
    };
    // 配置数据源选项
    var dsOptions = {
        data: data,
        schema: {
            type: 'columnJson',
        }
    };
    var dataManager = spread.dataManager();
    var dataTable = dataManager.addTable('Athlete', dsOptions);
    await dataTable.fetch();
    // 将数据绑定到表格
    var table = spread.getActiveSheet().tables.addFromDataSource('Athlete', 0, 0, "Athlete", GC.Spread.Sheets.Tables.TableThemes.medium7);
    // 通过View将数据绑定至集算表
    var sheet = spread.addSheetTab(0, "TableSheet1", GC.Spread.Sheets.SheetType.tableSheet);
    var view = dataTable.addView("myView");
    sheet.setDataView(view);
    spread.resumePaint();
}
```

**远端ColumnJson数据添加**：
从远端获取ColumnJson数据，修改`dsOptions`如下：

```javascript
var dsOptions = {
    remote: {
        read: {
            url: 'http://localhost:9590/api/data/column-json',
        },
    },
    schema: {
        type: 'columnJson',
    },
};
```
