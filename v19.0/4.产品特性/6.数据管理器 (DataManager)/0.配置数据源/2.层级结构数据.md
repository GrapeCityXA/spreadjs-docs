# hierarchy-data

## 功能概述

DataManager支持通过**层次结构选项**定义具有层级关系的数据源，为处理结构化数据提供了强大的支持。`hierarchy`配置项继承自[GC.Data.IDataSourceOption](gcdocsite__documentlink?toc-item-id=24e07bc4-c7cc-407c-98d5-0670ccab2cce#idatasourceoption)接口，包含以下核心参数：

* **type**：定义层次结构类型，支持`Parent`、`ChildrenPath`、`Level`、`Custom`四种模式
* **column**：指定用于构建层级关系的关键列
* **levelOffset**：层级偏移量，用于调整层级起始值（默认从0开始）
* **outlineColumn**：继承自[GC.Data.IHierarchyOutlineColumnOptions](gcdocsite__documentlink?toc-item-id=24e07bc4-c7cc-407c-98d5-0670ccab2cce#IHierarchyOutlineColumnOptions)，配置展示为层级结构的列
* **summaryFields**：继承自[GC.Data.IHierarchySummaryFieldCollection](gcdocsite__documentlink?toc-item-id=24e07bc4-c7cc-407c-98d5-0670ccab2cce#IHierarchySummaryFieldCollection)，定义字段的计算规则
* **parse**：继承自[GC.Data.IHierarchyCustomParseOptions](gcdocsite__documentlink?toc-item-id=24e07bc4-c7cc-407c-98d5-0670ccab2cce#IHierarchyCustomParseOptions)，用于将自定义层级主键解析为父键
* **unparse**：继承自[GC.Data.IHierarchyCustomUnparseOptions](gcdocsite__documentlink?toc-item-id=24e07bc4-c7cc-407c-98d5-0670ccab2cce#IHierarchyCustomUnparseOptions)，反向构建自定义层级主键

## 层次结构类型详解

DataManager支持四种层次结构类型，在使用`addTable`方法添加数据表时，可通过`hierarchy.type`配置不同模式。以下结合代码示例与图表展示详细说明：

### 父层次结构（Parent Hierarchy）

**原理**：使用`Parent`类型，通过主键标识层级ID，构建父子关系。
**适用场景**：适用于明确父子关联关系的数据，如组织架构、目录树等。
**示例代码**：

```html
<script>
// 初始化SpreadJS实例
var spread = new GC.Spread.Sheets.Workbook(document.querySelector('#ss'), { sheetCount: 0 });
initSpread(spread);

function initSpread(spread) {
    const dataManager = spread.dataManager();
    initHierarchyParentType(spread, dataManager);
}

function initHierarchyParentType(spread, dataManager) {
    // 添加数据表并配置父层次结构
    var table = dataManager.addTable('hierarchyParentTable', {
        data: initHierarchyParentData(),
        schema: {
            hierarchy: {
                type: 'Parent', // 设置为父层次结构类型
                column: 'parentId', // 指定构建层级关系的列
            },
            columns: {
                id: { dataName: 'id', isPrimaryKey: true }, // 定义主键
                parentId: { dataName: 'parentId', dataType:'reorder' },
            },
        },
    });

    // 创建集算表并配置展示
    var sheet = spread.addSheetTab(0, 'HierarchyParent', GC.Spread.Sheets.SheetType.tableSheet);
    sheet.setDefaultRowHeight(40, GC.Spread.Sheets.SheetArea.colHeader);
    sheet.options.allowAddNew = true;

    table.fetch().then(() => {
        var myView = table.addView('myView', [
            {
                value: 'parentId',
                width: 200,
                outlineColumn: {
                    showImage: true,
                    images: ['httpss://en.onboarding.grapecitydev.com/spreadjs/demos/spread/source/images/task-1.png',
                             'httpss://en.onboarding.grapecitydev.com/spreadjs/demos/spread/source/images/task-2.png',
                             'httpss://en.onboarding.grapecitydev.com/spreadjs/demos/spread/source/images/task-3.png'],
                    expandIndicator: 'httpss://en.onboarding.grapecitydev.com/spreadjs/demos/spread/source/images/increaseIndicator.png',
                    collapseIndicator: 'httpss://en.onboarding.grapecitydev.com/spreadjs/demos/spread/source/images/decreaseIndicator.png',
                },
            },
            { value: 'id', width: 200 },
        ]);
        sheet.setDataView(myView);
    });
}

function initHierarchyParentData() {
    return [
        { id: 1, parentId: -1 },
        { id: 2, parentId: -1 },
        { id: 3, parentId: 1 },
        { id: 4, parentId: 1 },
        { id: 5, parentId: 2 },
        { id: 6, parentId: 2 },
        { id: 6, parentId: 2 },
    ];
}
</script>
```

### 子路径层次结构（ChildrenPath Hierarchy）

**原理**：采用`ChildrenPath`类型，通过指定子节点路径构建层级关系，主键非必需但建议定义。
**适用场景**：适合以树状结构存储的JSON数据，如多级菜单、区域层级等。
**示例代码**：

```html
<script>
var spread = new GC.Spread.Sheets.Workbook(document.querySelector('#ss'), { sheetCount: 0 });
initSpread(spread);

function initSpread(spread) {
    const dataManager = spread.dataManager();
    initHierarchyParentType(spread, dataManager);
}

function initHierarchyParentType(spread, dataManager) {
    // 添加数据表并配置子路径层次结构
    var taskTable = dataManager.addTable('Tasks', {
        data: initHierarchyChildData(),
        schema: {
            hierarchy: {
                type: 'ChildrenPath',
                column: 'TaskChildren',
            },
            columns: {
                TaskName: { dataName: 'name' },
                TaskChildren: { dataName: 'children' },
            },
        },
    });

    // 创建集算表并配置展示
    var sheet = spread.addSheetTab(0, 'HierarchyParent', GC.Spread.Sheets.SheetType.tableSheet);
    sheet.setDefaultRowHeight(40, GC.Spread.Sheets.SheetArea.colHeader);
    sheet.options.allowAddNew = true;

    taskTable.fetch().then(() => {
        var taskView = taskTable.addView('TaskView', [
            {
                value: 'TaskName',
                outlineColumn: true,
                width: '*', // 配置为层级展示列
            },
        ]);
        sheet.setDataView(taskView);
    });
}

function initHierarchyChildData() {
    return [
        {
            name: 'USA',
            children: [
                {
                    name: 'Texas',
                    children: [
                        { name: 'Houston' },
                        { name: 'Dallas' },
                        { name: 'San Antonio' },
                    ],
                },
            ],
        },
        {
            name: 'India',
            children: [
                {
                    name: 'UP',
                    children: [{ name: 'Noida' }, { name: 'Ghaziabad' }, { name: 'Agra' }],
                },
            ],
        },
    ];
}
</script>
```

### 级别层次结构（Level Hierarchy）

**原理**：使用`Level`类型，通过指定层级字段构建层级关系，主键可选。
**适用场景**：适用于预先定义好层级顺序的数据，如行政区划、产品分类等。
**示例代码**：

```html
<script>
var spread = new GC.Spread.Sheets.Workbook(document.querySelector('#ss'), { sheetCount: 0 });
initSpread(spread);

function initSpread(spread) {
    const dataManager = spread.dataManager();
    initHierarchyParentType(spread, dataManager);
}

function initHierarchyParentType(spread, dataManager) {
    // 添加数据表并配置级别层次结构
    var taskTable = dataManager.addTable('Tasks', {
        data: initHierarchyLevelData(),
        schema: {
            hierarchy: {
                type: 'Level',
                column: 'TaskLevel',
            },
            columns: {
                TaskName: { dataName: 'name' },
                TaskId: { dataName: 'id', isPrimaryKey: true }, // 可选主键定义
                TaskLevel: { dataName: 'level' },
            },
        },
    });

    // 创建集算表并配置展示
    var sheet = spread.addSheetTab(0, 'HierarchyParent', GC.Spread.Sheets.SheetType.tableSheet);
    sheet.setDefaultRowHeight(40, GC.Spread.Sheets.SheetArea.colHeader);
    sheet.options.allowAddNew = true;

    taskTable.fetch().then(() => {
        var taskView = taskTable.addView('TaskView', [
            {
                value: 'TaskName',
                outlineColumn: true,
            },
        ]);
        sheet.setDataView(taskView);
    });
}

function initHierarchyLevelData() {
    return [
        { name: 'USA', level: -1, id: 1 },
        { name: 'Texas', level: 0, id: 2 },
        { name: 'Houston', level: 1, id: 3 },
        { name: 'California', level: 0, id: 4 },
        { name: 'San Francisco', level: 1, id: 5 },
        { name: 'Los Angeles', level: 1, id: 6 },
    ];
}
</script>
```

### 自定义层次结构（Custom Hierarchy）

**原理**：通过`Custom`类型，结合`parse`和`unparse`自定义层级解析逻辑，灵活适配复杂层级关系。
**适用场景**：适用于层级规则不固定，需要自定义处理逻辑的特殊场景。
**示例代码**：

```html
<script>
var spread = new GC.Spread.Sheets.Workbook(document.querySelector('#ss'), { sheetCount: 0 });
initSpread(spread);

function initSpread(spread) {
    const dataManager = spread.dataManager();
    initHierarchyParentType(spread, dataManager);
}

function initHierarchyParentType(spread, dataManager) {
    // 添加数据表并配置自定义层次结构
    var taskTable = dataManager.addTable('Tasks', {
        data: initHierarchyChildData(),
        schema: {
            hierarchy: {
                type: 'Custom',
                column: 'id',
                parse: function (options) {
                    // 自定义主键解析逻辑
                    let seg = options.data.TaskId.split('.');
                    return seg.slice(0, seg.length - 1).join('.');
                },
                unparse: function (options) {
                    // 自定义主键构建逻辑
                    let parentIds,
                        currentIndex = options.index,
                        parentData = options.parentData,
                        parentKey = parentData && parentData.TaskId;
                    if (parentKey) {
                        let sp = parentKey.split('.');
                        parentIds = sp;
                    } else {
                        parentIds = [];
                    }
                    parentIds.push(currentIndex + 1);
                    return parentIds.join('.');
                },
            },
            columns: {
                TaskName: { dataName: 'name' },
                TaskId: { dataName: 'id', isPrimaryKey: true }, // 可选主键定义
            },
        },
    });

    // 创建集算表并配置展示
    var sheet = spread.addSheetTab(0, 'HierarchyParent', GC.Spread.Sheets.SheetType.tableSheet);
    sheet.setDefaultRowHeight(40, GC.Spread.Sheets.SheetArea.colHeader);
    sheet.options.allowAddNew = true;

    taskTable.fetch().then(() => {
        var taskView = taskTable.addView('TaskView', [
            {
                value: 'TaskName',
                outlineColumn: true,
                width: '*',
            },
        ]);
        sheet.setDataView(taskView);
    });
}

function initHierarchyChildData() {
    return [
        { id: '1', name: '1' },
        { id: '2', name: '2' },
        { id: '1.1', name: '1.1' },
        { id: '1.1.1', name: '1.1.1' },
        { id: '2.1', name: '2.1' },
    ];
}
</script>
```
