# itemslicer

项目切片器可用于筛选数据。
[GeneralSlicerData ](gcdocsite__documentlink?toc-item-id=e2843bf4-9766-45f5-b0b2-bf639aff4f2c)和 [TableSlicerData ](gcdocsite__documentlink?toc-item-id=3afe4913-3c93-4353-8d26-e6432d44ed0d)类包含要筛选的数据，并且还提供筛选信息属性。[ItemSlicer ](gcdocsite__documentlink?toc-item-id=8b3dc7a2-14a1-4b6e-b481-5723c6a26105)类可与切片器数据配合使用。项目切片器是一个切片器组件，且独立于工作表。[style ](gcdocsite__documentlink?toc-item-id=8b3dc7a2-14a1-4b6e-b481-5723c6a26105#style)方法可用于为项目切片器设置样式。

> **注意**：要在 SpreadJS 工作表中使用项目切片器，用户需要引用以下插件：
>
> * gc.spread.sheets.all.js
> * gc.spread.sheets.slicers.js

## 使用代码

此示例创建一个表格并添加一个项目切片器。

```JavaScript
//创建表格
var dataSource = [
    { Name: "Bob", City: "NewYork", Birthday: "1968/6/8" },
    { Name: "Betty", City: "NewYork", Birthday: "1972/7/3" },
    { Name: "Alice", City: "Washington", Birthday: "2012/2/15" },
];
var table = activeSheet.tables.addFromDataSource("table1", 1, 1, dataSource);
var slicerData = table.getSlicerData();
//创建项目切片器并将切片器数据添加到项目切片器中。
var slicer = new GC.Spread.Sheets.Slicers.ItemSlicer("slicer", slicerData, "Name");
//将项目切片器添加到 DOM 树中。
//“slicerHost” 是你要将切片器的 DOM 添加到的 div 元素。
$("#slicerHost").append(slicer.getDOMElement());
.....
<div id="slicerHost" style="height: 300px; width: 50%"></div>
```

> **注意**：要升级到新的切片器，请参阅 [重大变更](gcdocsite__documentlink?toc-item-id=859de51d-bc4d-425f-b589-499bad917b71)。
