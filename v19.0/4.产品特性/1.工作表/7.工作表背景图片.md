# worksheet-background-image

SpreadJS 支持为工作表设置背景图片，这可以帮助您提升视觉美感，辅助数据可视化（例如叠加地图或参考线），并统一模板风格，在专业性和用户体验之间取得平衡。它适用于报告和仪表板等场景。

## 使用代码

可以使用 **Worksheet** 类的 **backgroundImage** 函数为工作表设置背景图片，参数是一个图片源字符串：

* **图片 URL**
    * 指向位于网络某处的图片的路径。
    * 示例：`"https://example.com/path/to/image.jpg"`
    * 如果使用外部路径，请确保服务器配置了适当的跨域资源共享（CORS）标头，以允许您的应用程序访问该资源。
* **Base64 编码的图片数据**
    * 图片以 Base64 格式编码，可以作为数据 URL 直接嵌入到 HTML 或 CSS 中。
    * 示例：`"data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA..."`
* **相对路径图片**
    * 如果 API 和图片资源在同一服务器上，您可以使用相对路径来引用图片。
    * 示例：`"/images/background.png"`

```javascript
let workbook = new GC.Spread.Sheets.Workbook('ss');
let worksheet = workbook.getActiveSheet();
sheet.backgroundImage('https://cdn.grapecity.com.cn/online/resources/spJS_logo2.png');
```

## 背景图片布局

背景图片始终以其原始大小呈现，不会被拉伸或缩放。这意味着无论工作表的实际大小如何，背景图片都将保持其原始宽度和高度，不会自动调整大小以适应工作表。
例如，如果您有一张 500x300 像素的背景图片，即使工作表的大小大于此尺寸，背景图片也不会被拉伸或缩小。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1f04de1b-0add-4f88-889e-295f2a2e218b/image.fbed33.dbcdda.png)

## 背景图片重复

背景图片将根据工作表的实际大小在 x 轴（水平方向）和 y 轴（垂直方向）上重复，直到填满整个工作表区域。
例如，如果您的工作表是 1900x900 像素，而您的背景图片是 500x300 像素，背景图片将在水平方向重复 4 次，在垂直方向重复 3 次。超出工作表尺寸的图片部分将自动被裁剪，从而填满工作表背景。

## 背景图片裁剪

如果背景图片在 x 轴或 y 轴上超出了工作表的显示区域，为确保背景图片不超出工作表的实际显示区域，超出的部分将自动被裁剪。这意味着背景图片只会在工作表的实际尺寸范围内显示，超出此范围的任何部分都不会显示。
例如，如果您的工作表是 1900x900 像素，而您的背景图片是 2000x1200 像素，那么水平方向超出的 100 像素和垂直方向超出的 300 像素将不会显示。只有与工作表尺寸匹配的部分才会可见。

## 工作表背景图片的层级

工作表背景图片位于工作簿之上，但在工作表的所有对象之下。具体来说，工作表背景图片位于以下对象之下：

1. 单元格背景颜色
2. 单元格边框
3. 形状
4. 图表
5. 添加到工作表的任何其他对象

这意味着无论您向单元格中添加什么内容或对象，这些内容和对象都将显示在背景图片之上。背景图片作为底层装饰，确保它不会干扰用户查看和编辑单元格内容或其他工作表元素的能力。

## 背景图片支持导出到 Excel 和从 Excel 导入

由于 Excel 可以显示无限数量的行和列，而 SpreadJS 有固定的行和列限制，以前将没有数据的 Excel 工作表导入到 SpreadJS 中时，只会显示一个单元格（通常是 A1）。然而，在引入对背景图片的支持后，如果一个空的 Excel 工作表包含背景图片，在将其导入到 SpreadJS 中时，用户需要设置工作表的行数和列数才能显示完整的背景图片。

> 打印或导出为 PDF 时，将忽略工作表背景图片。

## 在设计器中设置工作表背景图片

您可以在设计器的 **页面布局选项卡** 中设置或删除工作表背景图片
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1f04de1b-0add-4f88-889e-295f2a2e218b/image.5425e9.png)

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1f04de1b-0add-4f88-889e-295f2a2e218b/image.3eeff5.png)

> 默认情况下，设计器中的背景图片操作按钮与按工作表设置背景图片的命令相关联。如果用户希望恢复为将背景图片应用于整个工作簿的功能，可以在设计器初始化期间执行以下脚本。

```javascript
var config = GC.Spread.Sheets.Designer.DefaultConfig;
var pageLayout = config.ribbon.filter((item) => {
    return item.id === 'pageLayout';
})[0];
var pageSetup = pageLayout.buttonGroups.filter((item) => {
    return item.thumbnailClass === 'ribbon-thumbnail-page-setup';
})[0];
var pageSetupCmdGroup = pageSetup.commandGroup.children[0].children;
pageSetup.commandGroup.children[0].children = pageSetupCmdGroup.map(function (ele) {
    if (ele === 'worksheetBackground') {
        return GC.Spread.Sheets.Designer.CommandNames.Background;
    } else if (ele === 'deleteWorksheetBackground') {
        return GC.Spread.Sheets.Designer.CommandNames.DeleteBackground;
    }
    return ele;
});
designer.setConfig(config);
```
