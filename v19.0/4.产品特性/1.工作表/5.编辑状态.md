# editor-status

SpreadJS 在 Spread 底部的状态栏中提供有关单元格编辑状态的信息。在与单元格交互时，可能会遇到以下几种单元格编辑状态：

* **就绪（Ready）**：表示单元格的一般状态。这意味着该单元格尚未被操作过。
* **输入（Enter）**：表示空单元格的数据输入模式。如果用户使用导航或选择操作，Spread 会提交当前输入并导航或选择其他单元格。
* **编辑（Edit）**：表示非空单元格的单元格内编辑模式。在编辑单元格时，你无法使用光标键导航到其他单元格。

如果单元格的编辑状态为输入（Enter）或编辑（Edit），编辑器将进入编辑模式。在空单元格中输入内容和双击会使单元格进入输入状态，而在非空单元格中双击会使单元格进入编辑状态。此外，默认情况下，键盘快捷键 F2 键也会使单元格进入编辑状态。
如果单元格处于输入状态，并且你使用鼠标左键点击编辑器，状态将更改为编辑状态。当工作表处于编辑模式时，你可以使用箭头键进行导航。
SpreadJS 允许你通过编程方式检索或更改单元格的编辑状态。更多信息请参考以下部分：

* [检索编辑状态](gcdocsite__documentlink?toc-item-id=9ead105a-d354-4f03-9e2f-f0d8cb8a232e#%E6%A3%80%E7%B4%A2%E7%BC%96%E8%BE%91%E7%8A%B6%E6%80%81)
* [更改编辑状态](gcdocsite__documentlink?toc-item-id=9ead105a-d354-4f03-9e2f-f0d8cb8a232e#%E6%9B%B4%E6%94%B9%E7%BC%96%E8%BE%91%E7%8A%B6%E6%80%81)

## 检索编辑状态

SpreadJS 提供了通过使用工作表类的 [editorStatus ](gcdocsite__documentlink?toc-item-id=a5e8c3ef-95ec-4d6b-ac6e-e43cbea5b3b6)方法来获取单元格编辑状态信息的能力。每当用户交互过程中单元格的编辑状态发生变化时，该方法可用于触发事件并在电子表格中执行特定操作。
SpreadJS 还提供了 [startEdit ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#startedit)方法，该方法与双击操作类似。
以下示例显示了编辑状态，并根据当前单元格状态更改单元格值：
![editor-status](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/editor-status.ff0e8a.gif)

```html
<script>
    $(document).ready(function () {

        var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
        var activeSheet = spread.getActiveSheet();
        spread.commandManager().register("startEditing", { 
        canUndo: false, execute: function (context, options) {
            var sheet = context.getSheetFromName(options.sheetName);
            if (sheet &&!sheet.isEditing()) {
                sheet.startEdit();
            }
        }
        }, 113, false, false, false, false);
        
        setstatus(activeSheet);
        activeSheet.bind(GC.Spread.Sheets.Events.EditorStatusChanged, function (e, args) {
            setstatus(activeSheet, args.status);
        });
    });

    function setstatus(activeSheet, status) {
        var statusnow = status || activeSheet.editorStatus();
        if (statusnow === GC.Spread.Sheets.EditorStatus.ready) {
            activeSheet.setValue(0, 0, "Editor Status: Ready!");
            $("#status").text("Ready");
        } else if (statusnow === GC.Spread.Sheets.EditorStatus.enter) {
            activeSheet.setValue(0, 0, "Editor Status: Enter!");
            $("#status").text("Enter");
        } else if (statusnow === GC.Spread.Sheets.EditorStatus.edit) {
            activeSheet.setValue(0, 0, "Editor Status: Edit!");
            $("#status").text("Edit");
        }
    }
</script>
</head>
<body>
    <div id="ss" style="height:700px;width:900px"></div>
    <label id="status" style="margin: 10px" />
</body>
```

## 更改编辑状态

SpreadJS 允许你使用 **changeEditorStatus** 命令以编程方式更改单元格的编辑状态，该命令在编辑单元格时在输入（Enter）和编辑（Edit）之间切换。
你也可以通过默认的键盘快捷键 F2 键来更改单元格的编辑状态。
SpreadJS 还提供了 **startEdit** 命令，允许你以编程方式开始以编辑模式编辑活动单元格。
你也可以通过默认的键盘快捷键 F2 键开始以编辑模式编辑活动单元格。
要使用 changeEditorStatus 命令更改编辑状态，你需要在活动单元格中以编辑模式开始编辑活动单元格，并使用 startEdit 命令触发 EditStarting 事件。
以下示例显示了编辑状态，并在开始编辑活动单元格时将状态直接更改为输入模式：
![changed-editor-status.b83759](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/changed-editor-status.b83759.459cde.gif)

```javascript
<body>
    <script src="./scripts/gc.spread.sheets.all.0.0.0.min.js" type="text/javascript"></script>
    
    // 添加执行开始编辑命令的按钮。
    <button id="btn1">开始编辑命令</button>
    
    <div class="sample-container">
        <div id="ss" class="sample-spreadsheets"></div>
        <div id="statusBar"></div>
    </div>
    <script>
		let spread = new GC.Spread.Sheets.Workbook("ss");
        
        // 显示状态栏。
        let statusBar = new GC.Spread.Sheets.StatusBar.StatusBar(
            document.getElementById('statusBar')
        );
        statusBar.bind(spread);
        
        // 访问活动工作表。
        let sheet = spread.getActiveSheet();

        // 向工作表添加值。
        sheet.setArray(1, 1, [
            ['Id', 'Name', 'Age', 'Grade'],
            [1000, 'Tom', 23, 98],
            [1001, 'Bob', 22, 80],
            [1002, 'Tony', 23, 99]
        ]);
        
        // 设置列宽。
        sheet.setColumnWidth(1, 80);
        sheet.setColumnWidth(2, 80);
        sheet.setColumnWidth(3, 80);
        sheet.setColumnWidth(4, 80);

        // 定义按钮点击函数。
        document.getElementById("btn1").onclick = () => {

            // 执行开始编辑命令。
            // 这将触发 EditStarting 事件。
            spread.commandManager().execute({ cmd: "startEdit", sheetName: "Sheet1" });

            // 执行 changeEditorStatus 命令，在编辑单元格时将编辑状态切换为输入。
            // 这将触发 EditorStatusChanged 事件。
            spread.commandManager().execute({cmd: "changeEditorStatus", sheetName: "Sheet1"});
        }
    </script>
</body>
```
