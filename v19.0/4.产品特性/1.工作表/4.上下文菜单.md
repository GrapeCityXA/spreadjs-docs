# UsingtheContextMenu

上下文菜单是单级或多级弹出菜单，当用户通过右键单击鼠标操作与表单进行交互时，它会提供一组选项（称为菜单项）。
SpreadJS支持内置上下文菜单和自定义内置上下文菜单。当用户触发表单上的鼠标右键事件时，将显示上下文菜单。 这为用户提供了快速执行表单中某些重要操作或重复操作的灵活性。 菜单项根据表单中单击的区域显示。 您可以添加和删除自定义菜单项，并自定义上下文菜单的结构。

## 内置上下文菜单的自定义

SpreadJS 支持使用 **GC.Spread.Sheets.ContextMenu.MenuView** 类对内置上下文菜单进行自定义。你可以重写已定义的上下文菜单样式类，以应用不同的样式。你还可以根据自己的喜好，为单级和多级上下文菜单添加或删除自定义菜单项。不过，生成的响应基于菜单视图以及菜单内容，具体取决于鼠标点击的区域。
SpreadJS 为上下文菜单提供了与 Spread 类似的主题，因此你可以修改菜单视图的外观及其结构。你也可以更改筛选上下文菜单的数据结果。

### 显示内置上下文菜单

**GC.Spread.Sheets.Workbook** 类的 ***allowContextMenu*** 属性为用户提供了一个选项，用于控制是否显示内置上下文菜单。默认情况下，此选项设置为 true，每次在电子表格上右键单击时，你都会看到一个上下文菜单。
你还可以分别使用 [MenuView ](gcdocsite__documentlink?toc-item-id=6472a2b2-5684-432d-839d-fd82575f5982)类的方法来设置上下文菜单的最大高度以及是否显示可滚动指示器。**MenuView.maxHeight** 方法接受一个整数值，而 **MenuView.scrollable** 方法接受一个布尔值。默认情况下，它设置为 true 以显示滚动指示器。

```javascript
// 如果你不想使用上下文菜单，关闭上下文菜单选项
var spread = $('#ss').data('workbook');
spread.options.allowContextMenu = false;
// 将上下文菜单的滚动属性设置为 true。
spread.contextMenu.menuView.scrollable(true);
spread.contextMenu.menuView.maxHeight(400);
```

### 自定义菜单的视图和结构

此属性允许你使用 [MenuView.createMenuItemElement](gcdocsite__documentlink?toc-item-id=6472a2b2-5684-432d-839d-fd82575f5982#createmenuitemelement) 方法来自定义菜单项的视图和结构。

```javascript
var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'));
function CustomMenuView() {}
CustomMenuView.prototype = new GC.Spread.Sheets.ContextMenu.MenuView();
CustomMenuView.prototype.createMenuItemElement = function (menuItemData) {
    // 自行创建菜单项视图
    // 你可以在此处调用父类的 createMenuItemElement 方法，仅自定义部分菜单项
    // 应返回菜单项视图
};
spread.contextMenu.menuView = new CustomMenuView();
```

### 添加/删除自定义菜单项

这允许你在上下文菜单中添加或删除自定义菜单项。每个选项都遵循 JSON 架构中定义的菜单数据。

```javascript
// 定义菜单数据
var openDialog = {
    text: 'Open Dialog',
    name: 'openDialog',
    command: showLoginDialog,
    workArea: 'viewport'
};
spread.contextMenu.menuData.push(openDialog);
function showLoginDialog() {
    // 执行某些操作
}
// 添加/删除自定义菜单项
$.each(spread.contextMenu.menuData, function (p, v) {
    if (v.name === 'openDialog') { // openDialog 是一个命令的名称
        spread.contextMenu.menuData.splice(p, 1)
    }
});
```
