# presence-client

**[Presence](gcdocsite__documentlink?toc-item-id=a333792f-1831-4fc6-89b2-40245d8e4dd7)**[ ](gcdocsite__documentlink?toc-item-id=a333792f-1831-4fc6-89b2-40245d8e4dd7)类是 `js-collaboration-presence-client` 提供的核心类，用于管理本地用户的在线状态并与服务器通信。它通过 `Connection` 对象与服务器建立连接，支持以下功能：

* 提交本地状态（如选区）
* 监听其他用户的状态变化
* 在界面上展示所有协同者的状态

## 属性

| 属性名称 | 描述 | 类型 |
| ---- | --- | --- |
| `localState` | 本地用户的在线状态对象。 | `P` |
| `otherStates` | 其他用户的在线状态集合，以键值对存储（键为用户ID，值为状态对象）。 | `IPresences<P>` |
| `connection` | 与服务器的连接对象。 | `Connection` |

## 方法

### submitLocalState

将本地状态发送至服务器，服务器会将其广播给其他客户端。[消息类型](gcdocsite__documentlink?toc-item-id=689ee552-5bd1-4ca7-8eba-3a698be9fef1) 为 `"presence"`。

```typescript
submitLocalState(p: P): void;
```

**参数**`p (P)`：本地用户的在线状态对象。**示例**

```typescript
presence.submitLocalState({ userId: xxx, selection: xxx }); // 提交用户ID和选区信息。
```

### submitLocalStateField

更新本地在线状态对象的指定字段并提交至服务器，服务器会将更新信息广播给其他客户端。[消息类型](gcdocsite__documentlink?toc-item-id=689ee552-5bd1-4ca7-8eba-3a698be9fef1) 为 `"presence"`。

```typescript
submitLocalStateField(name: string, value: unknown): void;
```

**参数**

* `name` (`string`)：需要更新的在线状态对象字段名。
* `value` (`unknown`)：要设置的新值。

**示例**

```typescript
presence.submitLocalState({ userId: 'id1', selection: 'range1' }); // presence.localState 为 { userId: 'id1', selection: 'range1' }
presence.submitLocalStateField('selection', 'range2') // presence.localState 为 { userId: 'id1', selection: 'range2' }
```

### removeLocalState

从服务器移除本地在线状态对象，服务器会将此操作广播给其他客户端。

```typescript
removeLocalState(): void;
```

### subscribe

订阅其他用户的状态。

```typescript
subscribe(): Promise<void>;
```

**返回**`Promise<void>`：订阅完成后解析的 Promise，可通过 `presence.otherStates` 访问其他用户的状态。**示例**

```typescript
const uiComponent = new xxx.uiComponent(); // 替换为实际UI组件
await presence.subscribe();
uiComponent.showPresences(presence.otherStates);// 替换为UI组件显示在线状态的函数。
```

### destroy

销毁实例并释放所有资源。

```typescript
destroy: () => void;
```

## 事件

Presence 支持以下事件，通过 `on`、`once` 和 `off` 方法管理：

| 事件名称 | 描述 | 参数 |
| ---- | --- | --- |
| `add` | 用户加入 | `addedPresences: IPresences<P>` |
| `update` | 用户在线状态更新 | `updatedPresences: IPresences<P>` |
| `remove` | 用户离开 | `removedPresencesIds: string[]` |

### on

注册事件监听器。

```typescript
on<NAME extends keyof IPresenceEvents<P>>(name: NAME, f: IPresenceEvents<P>[NAME]): IPresenceEvents<P>[NAME]
```

**参数**

* `name (NAME)`：事件名称，必须为 `IPresenceEvents<P>` 接口的键。
* `f (IPresenceEvents<P>[NAME])`：事件处理函数。

**返回**`IPresenceEvents<P>[NAME]`：已注册的事件处理函数。**示例**

```typescript
presence.on('add', (addedPresences) => {
    console.log(addedPresences);
});
```

### once

注册仅触发一次的事件监听器。

```typescript
once<NAME extends keyof IPresenceEvents<P>>(name: NAME, f: IPresenceEvents<P>[NAME]): void
```

**参数**

* `name (NAME)`：事件名称，必须为 `IPresenceEvents<P>` 接口的键。
* `f (IPresenceEvents<P>[NAME])`：事件处理函数。

**示例**

```typescript
presence.once('update', (updatedPresences) => {
    console.log(updatedPresences);
});
```

### off

移除指定的事件监听器。

```typescript
off<NAME extends keyof IPresenceEvents<P>>(name: NAME, f: IPresenceEvents<P>[NAME]): void
```

**参数**

* `name (NAME)`：事件名称，必须为 `IPresenceEvents<P>` 接口的键。
* `f (IPresenceEvents<P>[NAME])`：事件处理函数。

## 使用方法

### 1\. 安装 npm 包

```bash
npm install @grapecity-software/js-collaboration-client @grapecity-software/js-collaboration-presence-client
```

### 2\. 创建 Presence 实例

```typescript
import { Client } from "@grapecity-software/js-collaboration-client";
import { Presence } from "@grapecity-software/js-collaboration-presence-client";

const conn = new Client('ws://localhost:8080/').connect('room1');
const presence = new Presence(conn);
```

### 3\. 订阅在线状态

```typescript
const uiComponent = new xxx.uiComponent(); // 替换为实际UI组件
await presence.subscribe();
uiComponent.showPresences(presence.otherStates); // 替换为UI组件显示在线状态的函数。
```

### 4\. 监听在线状态变化

```typescript
presence.on('add', () => {
    uiComponent.showPresences(presence.otherStates);
});
presence.on('update', () => {
    uiComponent.showPresences(presence.otherStates);
});
presence.on('remove', () => {
    uiComponent.showPresences(presence.otherStates);
});
```

### 5\. 初始化时提交本地在线状态

```typescript
presence.submitLocalState({ userId: xxx, selection: xxx }); // 替换为实际用户ID和选区信息
```

### 6\. UI 组件状态变化时提交在线状态

```typescript
uiComponent.on('selectionChanges', () => {
    // 部分更新在线状态，仅更新选区，替换为实际选区信息。
    presence.submitLocalStateField('selection', xxx);
});
```

### 完整示例

```typescript
import { Client } from "@grapecity-software/js-collaboration-client";
import { Presence } from "@grapecity-software/js-collaboration-presence-client";

const conn = new Client('ws://localhost:8080/').connect('room1');
const presence = new Presence(conn);
const uiComponent = new xxx.uiComponent(); // 替换为实际UI组件

presence.subscribe().then(() => {
    uiComponent.showPresences(presence.otherStates); // 替换为UI组件显示在线状态的函数。

    presence.submitLocalState({ userId: xxx, selection: xxx }); // 替换为实际用户ID和选区信息

    uiComponent.on('selectionChanges', () => {
        // 部分更新在线状态，仅更新选区，替换为实际选区信息。
        presence.submitLocalStateField('selection', xxx);
    });

    presence.on('add', () => {
        uiComponent.showPresences(presence.otherStates);
    });
    presence.on('update', () => {
        uiComponent.showPresences(presence.otherStates);
    });
    presence.on('remove', () => {
        uiComponent.showPresences(presence.otherStates);
    });
});
```
