# js-collaboration-presence

`js-collaboration-presence` 是基于 `js-collaboration` 的实时协同插件，提供用户在线状态管理和共享功能。它分为客户端（[js-collaboration-presence-client](gcdocsite__documentlink?toc-item-id=4a0d6167-f546-4c23-8d27-209fa359da67)）和服务器端（[js-collaboration-presence](gcdocsite__documentlink?toc-item-id=59f968ab-0464-4276-9c32-480234123766)）。

* **客户端**（[Presence](gcdocsite__documentlink?toc-item-id=a333792f-1831-4fc6-89b2-40245d8e4dd7)）：负责捕获本地用户状态并发送至服务器，同时接收其他用户的状态。
* **服务器端**（[presenceFeature](gcdocsite__documentlink?toc-item-id=59f968ab-0464-4276-9c32-480234123766#presencefeature)）：负责广播和协调所有客户端的状态，确保协同房间内的状态数据一致性。

## 适用场景

适用于需要实时展示用户活动状态的场景，例如显示：

* 文本文档中协同者的光标位置
* 电子表格中的选中区域

## 核心功能

### 实时用户状态共享

* **功能说明**：`js-collaboration-presence` 可管理和共享文档内客户端的实时位置信息（如用户光标位置、选中区域等），让其他用户实时了解文档当前的协同状态。
* **应用场景**：
    * 多用户协同文档编辑时，用户可清晰看到其他用户的编辑位置，避免重复编辑或冲突。
    * 电子表格协同中，用户可实时查看其他用户正在操作的单元格或区域，便于协同工作。

### 用户事件监听与通知

![overview](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1f04de1b-0add-4f88-889e-295f2a2e218b/overview.e3bf59.e7a2fd.png)

* **功能说明**：`js-collaboration-presence-client` 允许开发者订阅和监听用户状态变化，在用户在线状态变更时（如加入、离开或更新状态，包括位置更新、选择变化等）执行特定操作。
* **应用场景**：
    * 新用户加入协同空间时，界面可自动更新以显示新用户的在线状态。
    * 用户更新在线状态（如更改光标位置）时，界面实时更新以确保所有用户看到一致信息。

### 多用户协同支持

![architecture1](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1f04de1b-0add-4f88-889e-295f2a2e218b/architecture1.41753b.2d1a37.png)

* **功能说明**：`js-collaboration-presence` 与 `js-collaboration`、`js-collaboration-ot` 无缝集成，构建完整的协同平台。通过 `js-collaboration` 提供的双向链接和 `js-collaboration-ot` 提供的数据同步与冲突解决，`js-collaboration-presence` 可在实时协同环境中管理用户在线状态。
* **应用场景**：在完整的协同平台中，`js-collaboration-presence` 负责管理用户在线状态，而 `js-collaboration` 和 `js-collaboration-ot` 处理数据同步与一致性，共同为用户提供流畅的协同体验。

## 局限性

`js-collaboration-presence` 不支持数据持久化，在线状态数据仅保留在服务器内存中，存储每个用户的最新状态。

### 潜在影响

* **数据丢失**：服务器重启或客户端断开连接时，所有存储的在线状态（包括用户位置和选择）将丢失。
* **无持久化存储**：在线状态不提供将用户状态保存到磁盘或数据库的功能，因此不适合需要持久化用户状态的场景。

### 推荐解决方案

* **定期备份**：尽管 Presence 不支持内置持久化，但可考虑定期将内存中的状态信息备份到外部存储。
* **自定义持久化**：开发者可实现自定义持久化逻辑，将用户状态保存到数据库，并在服务器启动时恢复这些状态。
