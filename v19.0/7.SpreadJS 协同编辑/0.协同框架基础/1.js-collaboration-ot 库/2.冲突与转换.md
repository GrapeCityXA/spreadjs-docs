# conflicts-and-transform

在协同编辑中，冲突指的是多个用户同时编辑文档的相同或相关部分，导致他们的编辑操作相互影响或干扰，可能破坏文档一致性或用户意图的情况。
当用户并发编辑时，系统需要确保：

* **所有副本的数据一致性**：确保最终每个副本的数据保持一致。
* **尽可能保留用户意图**：最终数据应符合用户预期，但只能最大程度实现。在某些冲突场景中，难以满足所有用户意图。

## 冲突场景示例

>type=warning
> 以下示例中的操作（Ops）已简化以便演示。在实际场景中，Op的结构和内容可能因文档类型、操作复杂度和实现方式而有所不同。

假设一个共享文档初始文本为 "xyz"，由两个客户端（客户端A和客户端B）同时编辑：

* **客户端A**：在位置1（"x"和"y"之间）插入"a"，期望结果为 "xayz"。
* **客户端B**：在位置2（"y"和"z"之间）插入"b"，期望结果为 "xybz"。

如果服务器简单按接收顺序应用并广播操作（ops），将出现如下不一致场景：

> 由于网络延迟等因素，发送和广播的消息并非即时送达，下图对此做了简化处理。

### 说明

1. **初始状态**：所有客户端和服务器的文本均为 "xyz"。
2. **本地操作**：
    1. **客户端A** 执行 `{ pos: 1, text: 'a' }`，在位置1插入"a"，得到 "xayz"。
    2. **客户端B** 执行 `{ pos: 2, text: 'b' }`，在位置2插入"b"，得到 "xybz"。
3. **提交与服务器处理**：
    1. 服务器按顺序应用并广播 `a`（"xyz" → "xayz"），然后应用并广播 `b`（"xayz" → "<span style="color: #ab4642">xabyz</span>"）。
4. **客户端接收与应用**：
    1. **客户端A** 接收 `b`（`{ pos: 2, text: 'b' }`），在"xayz"的位置2（"a"和"y"之间）插入"b"，得到 "xabyz"。
    2. **客户端B** 接收 `a`（`{ pos: 1, text: 'a' }`），在"xybz"的位置1（"x"和"y"之间）插入"a"，得到 "xaybz"。
5. **结果**：客户端A为 "xabyz"，客户端B为 "xaybz"，导致数据不一致。

## OT 技术如何解决冲突

操作转换（Operational Transformation, OT）通过调整操作来解决冲突，确保所有客户端和服务器的最终状态一致。服务器和客户端都会转换接收到的操作，以适应已执行的操作。针对上述示例，可建立以下转换规则：

```typescript
// side 表示哪个操作后到达服务器。若 side === 'left'，表示 op1 比 op2 晚到达服务器。
function transform(op1, op2, side: 'left' | 'right') { 
    if (op1.pos > op2.pos || (op1.pos === op2.pos && side === 'left')) {
        return { pos: op1.pos + op2.text.length, text: op1.text };
    }
    return op1;
}
```

### 说明

1. **初始状态**：所有客户端和服务器的文本均为 "xyz"。
2. **本地操作**：
    1. **客户端A** 执行 `{ pos: 1, text: 'a' }`，得到 "xayz"。
    2. **客户端B** 执行 `{ pos: 2, text: 'b' }`，得到 "xybz"。
3. **提交与服务器处理**：
    1. 服务器接收并应用 `a`，得到 "xayz"。
    2. 服务器接收 `b` 并转换 `b`：`b_transformed = Transform(b, a, 'left')`。
        1. `b.pos (2) > a.pos (1)`，因此 `pos` 增加1（"a"的长度），得到 `{ pos: 3, text: 'b' }`。
    3. 服务器应用 `b_transformed`，在"xayz"的位置3（"y"和"z"之间）插入"b"，得到 "xaybz"。
4. **广播与应用**：
    1. **客户端A** 接收 `b_transformed`（`{ pos: 3, text: 'b' }`），在"xayz"的位置3插入"b"，得到 "xaybz"。
    2. **客户端B** 接收 `a` 并转换 `a`：`a_transformed = Transform(a, b, 'right')`。
        1. `a.pos (1) < b.pos (2)`，因此 `pos` 保持不变，得到 `{ pos: 1, text: 'a' }`。
    3. **客户端B** 在"xybz"的位置1插入"a"，得到 "xaybz"。
5. **结果**：所有客户端和服务器均为 "xaybz"，最终状态一致。

## 总结

操作转换的核心在于动态调整操作，以适应其他并发操作的影响。这种方法无需锁定文档，允许用户自由编辑并确保一致性，非常适合实时协同编辑场景。
