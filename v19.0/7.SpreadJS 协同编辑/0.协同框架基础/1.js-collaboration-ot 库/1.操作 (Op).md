# operation-op

**操作（Op）** 是客户端与服务器通信的核心概念。客户端提交 Op 以描述对文档的修改，而服务器则处理、存储和同步这些 Op。本文将介绍：

- Op 的定义
- 客户端与服务器端 Op 的差异
- 服务器端附加字段的作用

## 定义
Op 是对文档状态单次修改的描述。常见操作包括：

- **插入或修改文档内容**：例如在文档特定位置插入文本。
- **创建文档**：初始化新文档。
- **删除文档**：移除现有文档。

客户端与服务器对 Op 的定义存在差异：

- **客户端 Op**：描述操作的具体内容，如插入文本的位置和内容。
- **服务器端 Op**：在客户端 Op 基础上添加额外元数据（如 `src`、`seq` 和 `v`），用于唯一标识操作、版本管理及在网络不稳定时检测重复提交。

## 差异
### 客户端 Op
客户端 Op 是用户对文档修改的直接描述，通常仅包含操作的具体内容。以下是 Op 示例：

> 以下示例中的 Op 已简化以方便演示。在实际场景中，Op 的结构和内容可能因文档类型、操作复杂度或实现方式而有所不同。

**示例 1：插入文本**  
在文档特定位置插入文本：
```typescript
sharedDoc.submitOp({ pos: 1, text: 'hello' })
```
- `pos: 1`：表示在文档位置 1 插入内容。
- `text: 'hello'`：表示插入的文本内容为 "hello"。

**示例 2：创建文档**  
初始化新文档：
```typescript
sharedDoc.create('Hi!', textType.uri);
```
- `'Hi!'`：表示新文档的初始内容。
- `textType.uri`：表示文档的 OT 类型（如文本类型）。

**示例 3：删除文档**  
```typescript
sharedDoc.del();
```

### 服务器端 Op
服务器接收客户端提交的 Op 后，会添加以下元数据字段对其进行增强：

- **src**：操作的**源标识符**，通常为客户端的唯一标识，用于区分不同客户端。
- **seq**：操作的**序列号**，表示此客户端提交操作的顺序。`src` 和 `seq` 的组合构成操作的唯一标识。
- **v**：文档的**版本号**，表示应用操作时的文档版本，用于版本控制和冲突解决。

这些元数据字段的作用包括：

- **唯一标识**：通过 `src` 和 `seq`，服务器可检测网络不稳定时的重复提交，避免同一操作被重复应用。
- **版本管理**：通过 `v`，服务器可确保操作按正确顺序应用，并处理并发修改导致的冲突。

以下是服务器接收到的 Op 示例，对应客户端的 Op：

**示例 1：创建文档（服务器端）**  
客户端提交的文档创建操作在服务器端如下所示：
```typescript
documentServices.use('submit', async (context, next) => {
    console.log(context.request.op);
    // 输出: { src: '51pX43yjKUiMmSoHAAAB', seq: 1, v: 0, create: { type: 'text-type', data: 'Hi!' } }
    await next();
});
```
- `create: { type: 'text-type', data: 'Hi!' }`：表示创建文档的原始操作内容。
- `src: '51pX43yjKUiMmSoHAAAB'`：客户端的唯一标识。
- `seq: 1`：此客户端的第 1 个操作。
- `v: 0`：应用操作时的文档版本号。

**示例 2：插入文本（服务器端）**  
客户端提交的文本插入操作在服务器端如下所示：
```typescript
documentServices.use('submit', async (context, next) => {
    console.log(context.request.op);
    // 输出: { src: '51pX43yjKUiMmSoHAAAB', seq: 2, v: 1, op: { pos: 1, text: 'hello'} }
    await next();
});
```
- `op: { pos: 1, text: 'hello'}`：客户端提交的原始操作内容。
- `src`、`seq`、`v`：同上，用于标识和版本管理。

**示例 3：删除文档（服务器端）**  
客户端提交的文档删除操作在服务器端如下所示：
```typescript
documentServices.use('submit', async (context, next) => {
    console.log(context.request.op);
    // 输出: { src: '51pX43yjKUiMmSoHAAAB', seq: 3, v: 2, del: true }
    await next();
});
```
- `del: true`：表示删除文档的原始操作内容。
- `src`、`seq`、`v`：同上，用于标识和版本管理。
