# shareddoc-class

[SharedDoc](gcdocsite__documentlink?toc-item-id=9e659419-beff-4587-9334-629c91cea5e8) 表示一个共享文档实例，用于管理文档快照（`snapshot`）和操作（`op`），通过连接（`Connection`）与服务器同步数据。它支持操作转换（Operational Transformation, OT）机制，以确保多用户操作的一致性。本文介绍如何在客户端使用 `SharedDoc`，包括：

* 初始化 `SharedDoc`
* 创建或删除文档
* 请求和更新文档快照
* 提交、接收和转换操作
* 监听事件

## 属性

| 属性名 | 描述 | 类型 |
| --- | --- | --- |
| `id` | 返回共享文档的唯一标识符。 | `string`（只读） |
| `version` | 表示当前快照的版本号。 | `number | undefined` (只读) |
| `type` | 表示快照的操作类型（操作转换类型）。 | `OT_Type<S, T> | undefined` (只读) |
| `data` | 表示当前快照的数据。 | `S | undefined` (只读) |
| `connection` | 返回共享文档的连接对象。 | `Connection`（只读） |

## 方法

### fetch

获取文档的快照数据，结果存储在 `doc.data` 中。

```typescript
fetch(): Promise<void>
```

**返回值**

* `Promise<void>`：返回一个 Promise，在获取快照后解析，获取的快照数据为 `doc.data`。

**示例**

```typescript
try {
    await doc.fetch();
    if (!doc.type) {
        return console.log('文档不存在');
    }
    console.log('文档快照', doc.data);
} catch (error) {
    if (error) {
        return console.error(error);
    }
}
```

### subscribe

获取文档的快照数据并监听后续更新。

```typescript
subscribe(): Promise<void>
```

**返回值**

* `Promise<void>`：返回一个 Promise，在订阅快照后解析，订阅的快照数据为 `doc.data`。

**示例**

```typescript
try {
    await doc.subscribe();
    if (!doc.type) {
        return console.log('文档不存在');
    }
    console.log('文档快照', doc.data);
    
    doc.on('op', (op, source) => {
        console.log('文档已更新', op, source);
    });
} catch (error) {
    if (error) {
        return console.error(error);
    }
}
```

### submitOp

向文档提交一个操作。

```typescript
submitOp(component: T, options?: IOptions): Promise<void>
```

**参数**

* `component` (`T`)：操作组件。
* `options` (`IOptions`)：操作选项（可选）。

**返回值**

* `Promise<void>`：返回一个 Promise，在操作提交后解析。

**示例**

```typescript
// 在位置 1 插入文本 'x'
await doc.submitOp({ pos: 1, text: 'Hi' }, { source: doc.connection.id });
console.log('操作已提交');
```

### create

创建一个新文档。

```typescript
create(data: S, type: string, options: IOptions): Promise<void>
```

**参数**

* `data` (`S`)：用于初始化快照的数据。
* `type` (`string`)：OT 类型的 URI。
* `options` (`IOptions`)：操作选项。

**返回值**

* `Promise<void>`：返回一个 Promise，在文档创建后解析。

**示例**

```typescript
try {
    await doc.create('Hello', textType.uri, {});
    console.log('文档创建成功:', doc.data); // "Hello"
} catch (err) {
    console.error('创建失败:', err);
}
```

### fetchHistorySnapshot

获取文档的历史快照数据。

```typescript
fetchHistorySnapshot(options: IHistorySnapshotRequestOptions): Promise<ISnapshot<S>>
```

**参数**

* `options` (`IHistorySnapshotRequestOptions`)：历史快照请求选项。

**返回值**

* `Promise<ISnapshot<S>>`：返回一个 Promise，在获取历史快照后解析。

**示例**

```typescript
const snapshot = await doc.fetchHistorySnapshot({ version: 6 });
console.log('成功获取文档历史快照，快照内容：', snapshot);
```

### del

删除文档。

```typescript
del(options: IOptions): Promise<void>
```

**参数**

* `options` (`IOptions`)：删除选项。

**返回值**

* `Promise<void>`：返回一个 Promise，在文档删除后解析。

### restore

将文档还原至指定版本。

```auto
restore(targetVersion: number, options?: IOptions): Promise<void>;
```

**参数**

* `targetVersion`（`number`）：要还原到的目标版本号。
* `options`（`IOptions`）：还原选项。
    **返回值**
* `Promise<void>`：返回一个 Promise，在文档还原完成后兑现。
    **示例**

```auto
await doc.restore(10); 
console.log('文档还原成功：', doc.data); // 版本10的数据
```

### hardRollback

强制将快照数据回滚到最新版本。

```typescript
hardRollback(): Promise<void>
```

**返回值**

* `Promise<void>`：返回一个 Promise，在回滚完成后解析。

### destroy

销毁实例并释放所有资源。

```typescript
destroy(): void
```

## 事件

`SharedDoc` 支持以下事件，通过 `on`、`once` 和 `off` 方法管理：

| 事件名 | 描述 | 参数 |
| --- | --- | --- |
| `error` | 发生错误时触发。 | `err`: `OTError` 对象 |
| `load` | 获取或订阅快照后触发。 | 无 |
| `create` | 创建文档时触发。 | `source`: 操作源 |
| `beforeOp` | 应用操作前触发。 | `op`: 操作数据，`source`: 源 |
| `op` | 应用操作后触发。 | `op`: 操作数据，`source`: 源 |
| `del` | 删除文档时触发。 | `data`: 删除前的数据，`source`: 源 |
| `restore` | 文档恢复时触发 | version：恢复版本，source：来源 |
| `hardRollback` | 强制回滚期间触发。 | 无 |

### on

注册事件监听器。

```typescript
on<NAME extends keyof ISharedDocEvents<S, T>>(name: NAME, f: ISharedDocEvents<S, T>[NAME]): ISharedDocEvents<S, T>[NAME];
```

**参数**

* `name` (`NAME`)：事件名，必须是 `ISharedDocEvents<S, T>` 接口中的键。
* `f` (`ISharedDocEvents<S, T>[NAME]`)：事件处理函数。

**返回值**

* `ISharedDocEvents<S, T>[NAME]`：已注册的事件处理函数。

**示例**

```typescript
doc.on('op', (op, source) => {
    if (source !== doc.connection.id) {
        console.log('从服务器接收操作:', op);
    }
});
```

### once

注册只触发一次的事件监听器。

```typescript
once<NAME extends keyof ISharedDocEvents<S, T>>(name: NAME, f: ISharedDocEvents<S, T>[NAME]): void;
```

**参数**

* `name` (`NAME`)：事件名。
* `f` (`ISharedDocEvents<S, T>[NAME]`)：事件处理函数。

**示例**

```typescript
doc.once('op', (op, source) => {
    console.log('op', op, source);
});
```

### off

移除特定的事件监听器。

```plaintext
off<NAME extends keyof ISharedDocEvents<S, T>>(name: NAME, f: ISharedDocEvents<S, T>[NAME]): void;
```

**参数**

* `name` (`NAME`)：事件名。
* `f` (`ISharedDocEvents<S, T>[NAME]`)：要移除的事件处理函数。

## 与 UI 组件集成

下图展示了一个协同流程。
![sharedoc_class](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/1f04de1b-0add-4f88-889e-295f2a2e218b/sharedoc_class.6c68f4.01bad3.png)

```typescript
// 初始化 UI 组件。xxx.uiComponent 是虚构的，应替换为实际的 UI 组件实现，如 Quill 或其他。
const uiComponent = new xxx.uiComponent();

// 订阅文档
doc.subscribe().then(async () => {
    // 如果文档不存在则创建
    if (!doc.type) {
        try {
            await doc.create('Hello', textType.uri, {});
            console.log('创建成功:', doc.data);
        } catch (error) {
            console.error('创建失败:', error);
            return;
        }
    }

    uiComponent.setText(doc.data);

    // 监听操作
    doc.on('op', (op, source) => {
        if (source === doc.connection.id) {
            return;
        }
        console.log('收到操作:', op, '当前数据:', doc.data);

        uiComponent.applyOp(op.pos, op.text); // 优先增量更新
        // 或者 uiComponent.setText(doc.data); // 完全更新
    });    

    // 监听恢复事件，确保界面能反映出已恢复的状态    
      doc.on('restore', (targetVersion) => {        
          console.log(`文档已恢复至版本 ${targetVersion}`);        
          uiComponent.setText(doc.data); // 强制全面更新以匹配快照    
      });

    // 监听 UI 组件操作并提交到服务器
    uiComponent.on('op', (op) => {
        await doc.submitOp(op, { source: doc.connection.id });
    });
})
```
