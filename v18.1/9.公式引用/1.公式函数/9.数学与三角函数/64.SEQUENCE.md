# sequence

SEQUENCE 函数可在数组中生成一系列连续数字，例如，1、2、3、4。



#### 语法

SEQUENCE(rows,[columns],[start],[step])



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
| rows | [必需] 要返回的行数。如果省略默认为1。 |
| columns | [可选]要返回的列数。如果省略默认为1。 |
| start | [可选] 序列中第一个数字。如果省略默认为1。 |
| step | [可选] 数组中每个连续值递增的值。如果省略默认为1。 |



#### 数据类型

接受行数和列数。返回一个数字序列。



#### 示例

例如，下图中的单元格A2包含公式“=SEQUENCE(4,5)”，并返回一个数组，该数组的值溢出到包含4行5列的单元格范围，显示序列1、2、3、4到20中的数字。



#### 可用版本

此函数可在SpreadJS 13或更高版本中使用。
