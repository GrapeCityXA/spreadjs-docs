# AREASPARKLINE

此函数返回用于表示区域迷你图的数据集。



#### 语法

AREASPARKLINE( *points, [min, max, line1, line2, colorPositive, colorNegative]* )



#### 参数

| 参数 | 描述 |
|--- |--- |
|  *Points*  | 一个单元格区域。无效数字将被忽略。 |
|  *Min*  | (可选) 代表迷你图最小值的数字。 |
|  *Max*  | (可选) 代表迷你图最大值的数字。 |
|  *Line1*  | (可选)代表水平线垂直位置的数字。 |
|  *Line2*  | (可选) 代表第二条水平线垂直位置的数字。 |
|  *ColorPositive*  | (可选)表示正值区域颜色的字符串。 |
|  *ColorNegative*  | (可选) 表示负值区域颜色的字符串。 |



#### 数据类型

返回迷你图



#### 例子

activeSheet.setFormula(6, 0, '=AREASPARKLINE(A1:A6,-15,15,5,-5,"red","green")');
