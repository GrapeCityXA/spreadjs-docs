# PARETOSPARKLINE

此函数返回用于表示pareto迷你图的数据集。



#### 语法

PARETOSPARKLINE( *points, pointIndex, [colorRange, target, target2, hightlightPosition, label, vertical, targetColor, target2Color, labelColor, barSize]* )



#### 参数

| 参数 | 描述 |
|--- |--- |
|  *points*  | 表示包含所有值的单元格区域的引用，例如“B2:B7”。 |
|  *pointIndex*  | 表示段的点索引的数字或参考，例如 1 或“D2”。pointIndex >= 1。 |
|  *colorRange*  | (可选)表示包含分段框颜色的单元格区域的引用，例如“D2:D7”。默认值为none. |
|  *target*  | (可选) 表示“target”行位置的数字或引用，例如 0.5。默认值为none.<br /><br />如果显示，target线颜色为#8CBF64。<br /><br /> |
|  *target2*  | (可选) 表示“target2”行位置的数字或引用，例如 0.8。默认值为none.<br /><br />如果显示，target2线颜色为 #EE5D5D。<br /><br /> |
|  *highlightPosition*  | (可选) 一个数字或引用，表示要以红色着色的段的等级，例如 3。默认值为 none。<br /><br />如果将 highlightPosition 设置为 4 等值，则第四个段框的颜色设置为 #CB0000。如果您不设置 highlightPosition，则分段框的颜色将设置为您分配给 colorRange 的颜色或默认颜色 #969696。<br /><br /> |
|  *label*  | (可选) 一个数字，表示段的标签是显示为累积百分比 (label = 1) 还是单个百分比或none (label = 2) 或无，例如 2,1。默认值为 0。 |
|  *vertical*  | (可选) 一个布尔值，表示框的方向是否垂直。默认值为false. |
|  *targetColor*  | (可选)  指示目标线颜色的颜色字符串。 |
|  *target2Color*  | (可选) 一个颜色字符串，指示 target2 线的颜色。 |
|  *labelColor*  | (可选)  指示标签前景色的颜色字符串。 |
|  *barSize*  | (可选) 一个大于 0 且小于等于 1 的数值，表示条形宽度或高度与单元格宽度或高度的百分比。 |



#### 数据类型

返回sparkline.



#### 例子

activeSheet.setFormula(1, 3, '=PARETOSPARKLINE(B2:B7,1,C2:C7,B8,B9,4,2,false,B10,B11,C2,1)');
