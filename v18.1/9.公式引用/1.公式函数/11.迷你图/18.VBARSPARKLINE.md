# VBARSPARKLINE

此函数返回用于表示方差迷你图的数据集。



#### 语法

VBARSPARKLINE( *value, [colorScheme, axisVisible, barWidth]* )



#### 参数

| 参数 | 描述 |
|--- |--- |
|  *value*  | 表示条形长度的数字或引用。该值应介于 100% 和 -100% 之间。 |
|  *colorScheme*  | (可选) 表示条形颜色的字符串。默认值为"grey". |
|  *axisVisible*  | (可选) 一个布尔值，指示是否显示轴。默认值是true。 |
|  *barWidth*  | (可选) 一个大于 0 且小于或等于 1 的数字，表示条形宽度与单元格宽度的百分比。 |



#### 数据类型

返回sparkline.



#### 例子

activeSheet.setFormula(0, 1, '=VBARSPARKLINE(A1,"red", FALSE, 0.8)');
