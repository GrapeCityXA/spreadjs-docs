# MONTHSPARKLINE

此函数返回用于表示月份迷你图的数据集。



#### 语法

MONTHSPARKLINE( *year, month, dataRange, emptyColor, startColor, middleColor, endColor* )MONTHSPARKLINE( *year, month, dataRange, colorRange* )



#### 参数

| 参数 | 描述 |
|--- |--- |
| year | 年数字，例如 2017 年。 |
| month | 月数字，例如 3。月份从 1 开始 (Jan = 1)。 |
| dataRange | 表示区域的引用，其中第一列是日期，第二列是数字，例如“A1:B400”。 |
| emptyColor | 表示没有值或零值的日期的颜色字符串，例如“lightgray”。 |
| startColor | 表示最小日期值的颜色字符串，例如“lightgreen”。 |
| middleColor | 表示具有平均最小值和最大值的日期的颜色字符串，例如"green". |
| endColor | 表示具有最大值的日期的颜色字符串，例如"darkgreen". |
| colorRange | 表示数据为颜色字符串的区域的引用。 |



#### 数据类型

返回sparkline.



#### 例子

activeSheet.setFormula(6, 2, '=MONTHSPARKLINE(2017,1,A2:B32,"yellow","lightgreen","green","darkgreen")');
