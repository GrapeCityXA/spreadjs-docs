# BC_DATAMATRIX

此函数返回一个表示数据矩阵（DATAMATRIX）的数据集。

## 语法

`BC_DataMatrix(value, color, backgroudColor, eccMode, ecc200SymbolSize, ecc200EndcodingMode, ecc00\_140Symbole, structureAppend, structureNumber, fileIdentifier, quietZoneRight, quietZoneTop, quietZoneBottom)`

## 参数

| 参数 | 说明 |
| ---- | ---- |
| *value* | 一个字符串，表示在二维码符号上进行编码的内容。 |
| *color* | 表示条形码颜色的一种颜色。默认值为 'rgb(0,0,0)'。 |
| *backgroundColor* | 表示条形码背景颜色的一种颜色。默认值为 'rgb(255, 255, 255)'。 |
| *eccMode* | 一个表示使用哪种纠错码（ECC）模式的值。它有以下取值：'ECC000、ECC050、ECC080、ECC100、ECC140、ECC200'。 |
| *ecc200SymbolSize* | 一个指定符号使用哪种编码模式的值。默认值为 'auto'（自动）。 |
| *ecc200EndcodingMode* | 一个表示设置用于二维码的是哪种编码的值。它有 'auto'  。 |
| *ecc00\_140Symbole* | 一个仅指定 ECC000-140 符号大小的值。默认值为 'auto'（自动）。 |
| *structureAppend* | 指定该符号是否为结构化追加消息（仅适用于 ECC200）的一部分。默认值为 'false'（否）。 |
| *structureNumber* | 一个表示该符号在结构化追加消息中处于哪个块的值。取值范围是 '0-15'，仅适用于 ECC200。默认值为 '0'。 |
| *fileIdentifier* | 一个指定文件标识的值。取值范围是 '1-254'，仅适用于 ECC200。默认值为 '0'。 |
| *quietZoneRight* | 一个表示右侧空白区大小的值。 |
| *quietZoneTop* | 一个表示顶部空白区大小的值。 |
| *quietZoneBottom* | 一个表示底部空白区大小的值。 |

## 数据类型

接受二维条码。返回条形码迷你图。

## 示例

`sheet.setFormula(3, 3, '=BC_DataMatrix(C4)');`
