# unique

此函数返回数组或区域中的唯一值列表。



#### 语法

UNIQUE(array,[by_col],[occurs_once])



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
| array | [必需] 要从中返回唯一行或列的区域或数组 |
| by_col | [可选] 指示如何比较的逻辑值。TRUE将比较列并返回唯一列，FALSE （或省略）将比较行并返回唯一行 |
| occurs_once | [可选] 逻辑值，它将返回在区域或数组中仅出现一次的行或列。 |



#### 数据类型

接受区域或数组。返回唯一值列表。



#### 示例

例如，下图中的单元格C4包含公式“=UNIQUE(A4:A15)”，并且只返回单元格区域A4到A15中的惟一客户名。根据唯一值的数目，动态数组公式自动溢出到单元格范围C5到C8。



#### 数据类型

This function is available in SpreadJS 13.0 or later.
