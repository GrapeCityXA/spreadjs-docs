# YIELDDISC

此函数返回折价发行的有价证券的年收益率。



#### 语法

YIELDDISC( *settle* , *maturity* , *price* , *redeem* , *basis* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *settle*  | 有价证券的结算日。 |
|  *maturity*  | 有价证券的到期日。 |
|  *price*  | 有价证券的价格（按面值为 ￥100 计算）。 |
|  *redeem*  | 面值 ￥100 的有价证券的清偿价值。 |
|  *basis*  | [可选] 要使用的日计数基准类型。请参考[Day Count Basis](gcdocsite__documentlink?toc-item-id=23b72e94-94be-44ed-9302-d582747f59dd)。 |



#### 注释

如果settle或maturity不是有效日期，则返回 #VALUE！ 。

如果 basis < 0 或 basis > 4，则返回错误值 #NUM!。

如果 price <= 0 或 redeem <= 0，返回 #NUM！ 。

如果settle≥maturity，返回 #NUM！ 。

settle、maturity、frequency 和 basis 将被截尾取整。



#### 数据类型

接受数值数据和日期。返回数值数据。



#### 示例

YIEDDISC(B1,B2,B3,B4,B5)
