# TBILLYIELD

此函数返回国库券的收益率。



#### 语法

TBILLYIELD( *settle* , *mature* , *priceper* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *settle*  | 国库券的结算日。 |
|  *mature*  | 国库券的到期日。 |
|  *priceper*  | 面值 ￥100 的国库券的价格。 |



#### 注释

如果 settle、settle不是有效日期，则返回 错误值 #VALUE!。

settle、mature将被截尾取整。

如果 priceper <= 0 ，则返回错误值 #NUM!。

如果settle > settle或结算后的到期日超过一年, 返回 #NUM! 错误值。



#### 数据类型

接受所有参数的数值和日期时间对象数据。返回数值数据。



#### 示例

TBILLYIELD(A1,B2,C3)

TBILLYIELD("3/31/2003","6/1/2003",98.65)得出结果 0.0794598041299475 (or 5.80%)
