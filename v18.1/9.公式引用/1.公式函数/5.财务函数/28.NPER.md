# NPER

此函数指定基于定期定额支付和固定利率的年金的期数。



#### 语法

NPER( *rate* , *paymt* , *pval* , *fval* , *type* )



#### 参数

该函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *rate*  | 利率以百分比表示（每个期间） |
|  *paymt*  | 指定每个期间的付款 |
|  *pval*  | 指定一系列未来付款或收入的现值 (即当前值)。 |
|  *fval*  | [可选] 指定完成最终付款后所需的未来值或现金余额。如果省略, 则假定为0。 |
|  *type*  | [可选]指定付款到期时间。 如果付款期结束时付款到期, 则使用 0, 或者在期初付款到期时使用1。 如果省略, 则假定为0。 |

对于所有参数, 支付的现金 (如储蓄金额) 用负数表示;收到的现金 (如股利支票) 用正数表示。



#### 注释

请务必按期表达利率。例如，如果您按8％的利率每月偿还贷款，则rate为0.08 / 12。

有关财务方面的公式，请参考[ PV ](gcdocsite__documentlink?toc-item-id=f63c0327-0f4d-444f-a597-323a23beb28b)函数。



#### 数据类型

接受所有参数的数值数据。返回数值数据。



#### 示例

NPER(A1/12,50,1000,0,1)

NPER(R1C1/12,50,1000,0,1)

NPER(0.005,-790,90000,0,1) 得出结果 167.7227522114
