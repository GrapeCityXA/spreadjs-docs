# TBILLEQ

此函数返回国库券的等效收益率。



#### 语法

TBILLEQ( *settle* , *mature* , *discount* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *settle*  | 国库券的结算日。 |
|  *mature*  | 国库券的到期日。 |
|  *discount*  | 国库券的贴现率。 |



#### 注释

如果 settle、settle不是有效日期，则返回 错误值 #VALUE!。

settle、mature将被截尾取整。

如果 discount <= 0 ，则返回错误值 #NUM!。

如果settle > settle或结算后的到期日超过一年, 返回 #NUM! 错误值。

函数 TBILLEQ 的计算公式为 TBILLEQ = (365 x rate)/(360-(rate x DSM))，公式中 DSM 是按每年 360 天的基准计算的结算日与到期日之间的天数。



#### 数据类型

接受所有参数的数值和日期时间对象数据。返回数值数据。



#### 示例

TBILLEQ(A1,B2,C3)

TBILLEQ("3/31/2003","6/1/2003",0.0532) 得出结果 0.054437659 (or 5.44%)
