# TYPE

此函数返回数值的类型。



#### 语法

TYPE(value)



#### 参数

参数总结如下：

| Type值 | 返回值 |
|--- |--- |
| 数字 | 1 |
| DateTime对象 | 1 |
| TimeSpan对象 | 1 |
| 文本 | 2 |
| 逻辑值 | 4 |
| 错误值 | 16 |
| 数组 | 64 |



#### 数据类型

接受多种类型数据。返回数值数据。



#### 示例

TYPE(G15)

TYPE(R15C7)

TYPE(154) 得出结果 1

TYPE("String") 得出结果 2

TYPE(TRUE) 得出结果 4
