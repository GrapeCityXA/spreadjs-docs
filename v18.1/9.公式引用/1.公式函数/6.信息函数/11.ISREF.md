# ISREF

此函数检验引用单元格的值，表达式或内容是否为引用。



#### 语法

ISREF( *cellreference* )

ISREF( *value* )

ISREF( *expression* )



#### 参数

参数可以是单元格引用，数字或文本值或表达式。



#### 注释

使用此功能可以测试单元格、数字、文本值、函数或表达式的内容。

如果参数是引用，则此函数返回TRUE。如果参数不是引用，则此函数返回FALSE。



#### 数据类型

接受参数的任何数据类型。返回布尔（TRUE或FALSE）数据。



#### 示例

ISREF(B3) 得出结果 TRUE

ISREF(R1C2) 得出结果 TRUE

ISREF(12) 得出结果 FALSE
