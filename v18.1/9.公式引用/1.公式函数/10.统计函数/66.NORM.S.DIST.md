# NORM.S.DIST

此函数返回标准正态分布函数。



#### 语法

NORM.S.DIST( *value,cumulative* )



#### 参数

该函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *value*  | 需要计算其分布的数值。 |
|  *cumulative*  | Cumulative 是决定函数形式的逻辑值。 如果 cumulative 为 TRUE，则 NORMS.DIST 返回累积分布函数；如果为 FALSE，则返回概率密度函数。 |



#### 注释

该分布的平均值为 0，标准偏差为 1。

可以使用此函数代替标准正态曲线面积表。

如果 value 为非数值型，则返回 #VALUE！ 。



#### 数据类型

接受value的数值数据，cumulative的逻辑值。返回数值数据。



#### 示例

NORM.S.DIST(F1,TRUE)

NORM.S.DIST(R1C6,TRUE)

NORM.S.DIST(1.288,TRUE) 得出结果 0.901127
