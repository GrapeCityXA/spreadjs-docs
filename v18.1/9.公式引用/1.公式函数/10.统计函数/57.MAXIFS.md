# MAXIFS

此函数返回一组给定条件或标准指定的单元格中的最大值。



#### 语法

MAXIFS( *max_range, range1, criteria1, [range2,criteria2],..* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *max_range*  | 确定最大值的实际单元格区域。 |
|  *range1*  | 是一组用于条件计算的单元格。 |
|  *criteria1*  | 用于确定哪些单元格是最大值的条件，格式为数字、表达式或文本。 |
|  *range2, criteria2...*  | [可选] 附加区域及其关联条件。 |



#### 注释

max_range 和 rangeN 参数的大小和形状必须相同，否则这些函数会返回 #VALUE! 错误。

如果单元格与指定条件不匹配，则此函数将返回0



#### 数据类型

接受所有参数的数值数据，表达式或文本。返回数值数据。



#### 示例

MAXIFS(C4:C7,B4:B7,"325") 得出结果 656

MAXIFS(C4:C7,B4:B7,"55") 得出结果 0
