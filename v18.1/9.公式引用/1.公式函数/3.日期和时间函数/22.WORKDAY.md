# WORKDAY

此函数返回在某日期（起始日期）之前或之后、与该日期相隔指定工作日的某一日期的日期值。



#### 语法

WORKDAY( *startdate* , *numdays* , *holidays* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *startdate*  | 一个代表开始日期的日期。 |
|  *numdays*  | startdate 之前或之后不含周末及节假日的天数。 如果不是整数则截尾取整。 |
|  *holidays*  | [可选] 一个可选列表，其中包含需要从工作日历中排除的一个或多个日期。 |





#### 数据类型

接受数值、字符串或DateTime对象数据。返回数值数据。



#### 示例

WORKDAY(A2,A4)

WORKDAY(R2C1,R5C5)

WORKDAY(A1,A2,A5:A7)
