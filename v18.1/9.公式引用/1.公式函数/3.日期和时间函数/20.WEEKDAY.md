# WEEKDAY

此函数返回对应于某个日期的一周中的第几天。



#### 语法

WEEKDAY( *date* , *type* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |  |
|--- |--- |--- |
|  *date*  | 一个序列号，代表尝试查找的那一天的日期。 |  |
|  *type*  | [可选] 用于确定返回值类型的数字。 |  |
|  | 值 | 返回的数字/td> |
|  | 1 或 省略 | 数字 1（星期日）到 7（星期六） |
|  | 2 | 数字 1（星期一）到 7（星期日）。 |
|  | 3 | 数字 0（星期一）到 6（星期日）。 |



将date参数指定为一个数字(如37806.5中所示)、一个字符串(如“7/4/2003 12:00”中所示)或一个DateTime对象(如date(2003,7,4))。更多信息请参考[Date and Time Functions](gcdocsite__documentlink?toc-item-id=d8ea7482-de27-4981-9afe-2d0c9caec6ec)。



#### 注释

默认情况下，天数是 1（星期日）到 7（星期六）范围内的整数。



#### 数据类型

接受两个参数的数值、字符串或日期时间对象。返回数值数据。



#### 示例

WEEKDAY(A2)

WEEKDAY(R2C1)

WEEKDAY(36828) 得出结果 1 equivalent to Sunday

WEEKDAY(46,2) 得出结果 3
