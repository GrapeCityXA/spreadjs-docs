# WEEKNUM

此函数返回特定日期的周数。



#### 语法

WEEKNUM( *date* , *weektype* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |  |
|--- |--- |--- |
|  *date*  | 代表一周中的日期。 |  |
|  *weektype*  | 数字，确定星期从哪一天开始。 |  |
|  | 值 | 返回数字 |
|  | 1 或 省略 | 星期日 |
|  | 2 | 星期一 |



将date参数指定为一个数字(如37806.5中所示)、一个字符串(如“7/4/2003 12:00”中所示)或一个DateTime对象(如date(2003,7,4))。更多信息请参考[Date and Time Functions](gcdocsite__documentlink?toc-item-id=d8ea7482-de27-4981-9afe-2d0c9caec6ec)。



#### 数据类型

接受两个参数的数值、字符串、DateTime对象或TimeSpan对象。返回数值数据。



#### 示例

WEEKNUM(A2)

WEEKNUM(R2C1,2)

WEEKNUM(23,1) 得出结果 4
