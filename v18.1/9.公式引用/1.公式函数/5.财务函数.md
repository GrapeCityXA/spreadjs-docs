# financial-functions

Spread 提供以下财务函数，按字母顺序排列

| 函数 | 描述 |
|--- |--- |
| [ACCRINT](gcdocsite__documentlink?toc-item-id=03c22248-1175-4529-8bf4-70dfe3391138) | 此函数计算支付定期利息的证券的应计利息。 |
| [ACCRINTM](gcdocsite__documentlink?toc-item-id=dd48ed77-9fe5-4705-82f9-bba156527ab6) | 此函数计算定期支付利息的证券到期时的应计利息。 |
| [AMORDEGRC](gcdocsite__documentlink?toc-item-id=0a62d678-6d36-4f27-8cc4-5450c84e227a) | 此函数返回会计期间的折旧，考虑按比例折旧，并在基于资产寿命的计算中应用折旧系数。 |
| [AMORLINC](gcdocsite__documentlink?toc-item-id=4121d83e-616f-4df9-82a0-8034a754d619) | 此功能计算会计期间的折旧，同时考虑按比例折旧。 |
| [COUPDAYBS](gcdocsite__documentlink?toc-item-id=67c44101-cf94-4793-863e-5cb46b3f7064) | 此函数计算从息票期开始到结算日的天数。 |
| [COUPDAYS](gcdocsite__documentlink?toc-item-id=4be2e8ab-8304-41f4-bb4e-3bf8b6353213) | 此函数返回包含结算日期的息票期中的天数。 |
| [COUPDAYSNC](gcdocsite__documentlink?toc-item-id=8072246a-5998-4e1a-84d4-17920191eb9a) | 此函数计算从结算日期到下一个息票日期的天数。 |
| [COUPNCD](gcdocsite__documentlink?toc-item-id=b02e4c5a-1ed2-4cc6-a89b-ed06d95e1c62) | 此函数返回结算日期之后的下一个息票日期的日期编号。 |
| [COUPNUM](gcdocsite__documentlink?toc-item-id=74c95de7-91aa-460a-aaa1-9e46224649e2) | 此函数返回结算日和到期日之间到期的息票数量。 |
| [COUPPCD](gcdocsite__documentlink?toc-item-id=71bb74f0-c709-4d11-afc7-8fce1ee124de) | 此函数返回结算日期之前的前一个息票日期的日期编号。 |
| [CUMIPMT](gcdocsite__documentlink?toc-item-id=d6ad602e-d6da-41af-ade8-6a81e2928a72) | 此函数返回在开始和结束期间为贷款支付的累计利息。 |
| [CUMPRINC](gcdocsite__documentlink?toc-item-id=40849060-0e56-403e-9e7b-f535415a89e5) | 此函数返回在开始和结束期间为贷款支付的累积本金。 |
| [DB](gcdocsite__documentlink?toc-item-id=6c107de2-e044-4315-b27b-a4e397d1fd4e) | 此函数使用固定余额递减法计算指定期间的资产折旧。 |
| [DDB](gcdocsite__documentlink?toc-item-id=01082de6-2a67-4268-bcc9-fbc08c0322b5) | 此函数使用双倍余额递减法或您指定的其他方法计算指定期间的资产折旧。 |
| [DISC](gcdocsite__documentlink?toc-item-id=46734c40-5611-4a2f-be19-1e44b4d0ff8a) | 此函数计算证券的贴现率。 |
| [DOLLARDE](gcdocsite__documentlink?toc-item-id=1231cae2-b8b7-4e67-a261-688c4a4977a8) | 此函数将分数美元价格转换为十进制美元价格。 |
| [DOLLARFR](gcdocsite__documentlink?toc-item-id=a9165363-c66f-4687-b4c8-59e7196addd7) | 此函数将十进制数字美元价格转换为分数美元价格。 |
| [DURATION](gcdocsite__documentlink?toc-item-id=fe4f9706-cded-489c-aa59-e8361a1291d6) | 此函数返回假定面值为 100 美元的麦考利久期。 |
| [EFFECT](gcdocsite__documentlink?toc-item-id=04e2d30f-2b87-48d4-8c15-e6efea05a355) | 此函数计算给定名义年利率的有效年利率和每年的复利期数。 |
| [FV](gcdocsite__documentlink?toc-item-id=02c5907a-e858-4819-a2b1-86e0d2027024) | 此函数根据现值、定期付款和指定的利率返回投资的未来价值。 |
| [FVSCHEDULE](gcdocsite__documentlink?toc-item-id=2f7835fc-63e7-44c8-85d3-4ffcce739b22) | 此函数在应用一系列复利后返回初始本金的未来值。计算具有可变或可调整利率的投资的未来价值。 |
| [INTRATE](gcdocsite__documentlink?toc-item-id=0658a5f1-9b69-4aee-b20c-cb5fdf4903a4) | 此函数计算完全投资证券的利率。 |
| [IPMT](gcdocsite__documentlink?toc-item-id=5fb18374-83a4-49b6-8dba-1fe3d8c589e6) | 此函数计算贷款利息的支付。 |
| [IRR](gcdocsite__documentlink?toc-item-id=6588fa01-d557-44b4-a224-0ba99dab3faa) | 此函数返回由数组中的数字表示的一系列现金流的内部收益率。 |
| [ISPMT](gcdocsite__documentlink?toc-item-id=c2e9c4c0-7d68-4259-8c3a-aad2b997002e) | 此函数计算特定投资期间支付的利息。 |
| [MDURATION](gcdocsite__documentlink?toc-item-id=919ce4b4-5a12-4404-bb93-2aae7c26be0e) | 此函数计算假定面值为 100 美元的证券的修正麦考利久期。 |
| [MIRR](gcdocsite__documentlink?toc-item-id=4a54848d-1a10-4d3f-b35f-e6541f363879) | 此函数返回一系列定期现金流量的修正内部收益率。 |
| [NOMINAL](gcdocsite__documentlink?toc-item-id=d79631fd-9c46-4635-83e2-2db82b44519a) | 此函数返回给定有效利率和每年复利期数的名义年利率。 |
| [NPER](gcdocsite__documentlink?toc-item-id=558a5023-d73a-4923-ade0-1375ee7fa4a9) | 此函数根据现值、未来值、定期付款和指定的利率返回投资的周期数。 |
| [NPV](gcdocsite__documentlink?toc-item-id=b49caee8-125c-4719-9bdb-9f5e8dd17ab7) | 此函数通过使用贴现率和一系列未来付款和收入来计算投资的净现值。 |
| [ODDFPRICE](gcdocsite__documentlink?toc-item-id=e3b5e02c-17d8-4132-880c-4c686aed1cc5) | 此函数计算具有奇数第一期的证券每 100 美元面值的价格。 |
| [ODDFYIELD](gcdocsite__documentlink?toc-item-id=e016f826-6af3-40d5-9c50-81aa64e90b80) | 此函数计算具有奇数第一期的证券的收益率。 |
| [ODDLPRICE](gcdocsite__documentlink?toc-item-id=5e1e5f8a-35a4-48fa-ac4f-5edceea50881) | 此函数计算每张面值为 100 美元且最后票息期为奇数的证券的价格。 |
| [ODDLYIELD](gcdocsite__documentlink?toc-item-id=c9556b73-dd18-4db4-b1e1-b6c5858f7b53) | 此函数计算最后一个周期为奇数的证券的收益率。 |
| [PDURATION](gcdocsite__documentlink?toc-item-id=5a626f5d-c39e-46bd-aaf8-56e63e01401a) | 此函数返回投资达到指定值所需的期间数。 |
| [PMT](gcdocsite__documentlink?toc-item-id=f9771332-a69b-460b-83d0-34ef0df26262) | 此函数返回给定现值、指定利率和期限数的贷款的支付金额。 |
| [PPMT](gcdocsite__documentlink?toc-item-id=d6e93513-46db-4f3b-9ac9-9293e50e150f) | 此函数返回给定现值、指定利率和期限数的贷款本金支付金额。 |
| [PRICE](gcdocsite__documentlink?toc-item-id=389acfd8-e295-48e4-998a-cc49e37a192b) | 此函数计算定期利息证券每 100 美元面值的价格。 |
| [PRICEDISC](gcdocsite__documentlink?toc-item-id=fa9151c5-1c8d-42ab-b531-2b107228c12d) | 此函数返回每 100 美元面值的折扣证券的价格。 |
| [PRICEMAT](gcdocsite__documentlink?toc-item-id=76c83ee8-c4a9-452b-9c38-966c17371e4c) | 此函数返回每 100 美元面值的支付利息的证券到期时的价格。 |
| [PV](gcdocsite__documentlink?toc-item-id=f63c0327-0f4d-444f-a597-323a23beb28b) | 此函数根据利率、定期付款的数量和金额以及未来价值返回投资的现值。现值是一系列未来付款现在值得的总金额。 |
| [RATE](gcdocsite__documentlink?toc-item-id=6715c393-1bd6-41cd-850f-b26581650016) | 此函数返回年金每期的利率。 |
| [RECEIVED](gcdocsite__documentlink?toc-item-id=a8a65606-ae49-48ce-9a24-fc1cda518dca) | 此函数返回在到期时收到的全额投资证券的金额。 |
| [RRI](gcdocsite__documentlink?toc-item-id=4800dda3-cc3c-4134-8150-33bc0736ae9e) | 此函数返回投资增长的等价利率。 |
| [SLN](gcdocsite__documentlink?toc-item-id=c51eaf65-bb6e-45d9-ba3b-24f2bdfc3f20) | 此函数返回资产在一个时期内的直线折旧。 |
| [SYD](gcdocsite__documentlink?toc-item-id=e71ac42a-4be8-466e-ae1b-2a98be5fe235) | 此函数返回资产在指定时期内的年数总和折旧。 |
| [TBILLEQ](gcdocsite__documentlink?toc-item-id=ea062281-b32e-4f31-89fb-ba3211d74f80) | 此函数返回国库券（或国库券）的等效收益率。 |
| [TBILLPRICE](gcdocsite__documentlink?toc-item-id=13e31555-bbb5-4f81-a88f-67d818d86ca5) | 此函数返回国库券（或国库券）每 100 美元面值的价格。 |
| [TBILLYIELD](gcdocsite__documentlink?toc-item-id=d644c6ed-85ab-4692-9d6a-578cbfd37043) | 此函数返回国库券（或国库券）的收益率。 |
| [VDB](gcdocsite__documentlink?toc-item-id=3664c3d8-6bc0-4443-84ac-b9e914494047) | 此函数返回您使用可变余额递减法指定的任何期间的资产折旧。 |
| [XIRR](gcdocsite__documentlink?toc-item-id=80fcf581-8914-446f-9435-f11fb6d61fe9) | 此函数计算可能不是周期性的现金​​流量表的内部收益率。 |
| [XNPV](gcdocsite__documentlink?toc-item-id=38a5dc71-07a0-4059-8c57-438b0811d91f) | 此函数计算可能不是周期性的现金​​流量表的净现值。 |
| [YIELD](gcdocsite__documentlink?toc-item-id=ee4b7496-f25c-42c1-b764-88586cb61af8) | 此函数计算定期支付利息的证券的收益率。 |
| [YIELDDISC](gcdocsite__documentlink?toc-item-id=1aeed12d-ad6d-480d-923d-e1e01f9dcdcb) | 此函数计算折扣证券的年收益率。 |
| [YIELDMAT](gcdocsite__documentlink?toc-item-id=e5b78a99-942d-4bc1-a499-d38518b990a3) | 此函数计算在到期时支付利息的证券的年收益率。 |
