# replace

## 总结
`REGEXREPLACE` 函数可依据指定的正则表达式模式替换字符串中的文本。

## 语法
```javascript
=REGEXREPLACE(text, pattern, replacement, [occurrence], [case_sensitivity])
```

## 参数
| 参数 | 描述 |
| -------- | ----------- |
| **text**<br>（必需） | 输入的文本或包含待替换文本的单元格引用。 |
| **pattern**<br>（必需） | 要匹配的正则表达式模式。 |
| **replacement**<br>（必需） | 用于替换匹配模式的文本。 |
| **occurrence** | 指定要替换的匹配项：<br>`0`：替换所有匹配项（默认）<br>正整数 N：替换第 N 个匹配项<br>负整数 N：从末尾开始替换第 N 个匹配项 |
| **case_sensitivity** | 大小写处理：<br>`0`：区分大小写（默认）<br>`1`：不区分大小写 |

## 备注
* **返回值**：替换后的修改字符串。

## 示例
```php
=REGEXREPLACE("0000abcd","0","1", 2) // 0100abcd
=REGEXREPLACE("0000abcd","0","1", 0) // 1111abcd
=REGEXREPLACE("0000abcd","0","1", -1) // 0001abcd
=REGEXREPLACE("aaaAbcd","a","0", ,0)  // 000Abcd
=REGEXREPLACE("aaaAbcd","a","0", ,1)  // 0000bcd
=REGEXREPLACE("Sonia (378) 555-4195  Brown(878) 555-8622", "[0-9]+-", "***-")  // Sonia (378) ***-4195  Brown(878) ***-8622
=REGEXREPLACE("JamesHenry","([A-Z][a-z]+)([A-Z][a-z]+)","$2, $1")  // Henry, James
```

> `REGEXREPLACE` 函数在替换旧版 `SJS.REGEXREPLACE` 函数的同时，保持了与 Excel 实现的兼容性。尽管 `SJS.REGEXREPLACE` 已被弃用，但仍保持向后兼容。这两个函数的主要区别包括：

| **特性** | **REGEXREPLACE 函数** | **SJS.REGEXREPLACE 函数** |
| ------- | --------------------- | ------------------------- |
| **参数类型** | 使用数值（0/1）来处理大小写：<br>`=REGEXREPLACE("aaaAbcd","a","0", ,1)` | 使用字符串修饰符（例如，"ig"）：<br>`=SJS.REGEXREPLACE("aaaAbcd","a","0","ig")` |
| **实例替换** | 灵活的匹配项控制：<ul><li>`0`：替换所有匹配项（默认）</li><li>正整数 N：替换第 N 个匹配项</li><li>负整数 N：从末尾开始替换第 N 个匹配项</li></ul>`=REGEXREPLACE("aaaAbcd","a","0", 2,1)`<br>`=REGEXREPLACE("aaaAbcd","a","0", -3,1)` | 限于：<ul><li>第一个实例（默认）</li><li>所有实例（使用 "g" 修饰符）</li></ul> |
| **多行处理** | 需要标准的正则表达式语法：<br>`=REGEXREPLACE("abc`<br>`ABC","\n[A-Z]+","*")` | 支持使用 "m" 修饰符处理多行：<br>`=SJS.REGEXREPLACE("abc`<br>`ABC","^[A-Z]+","*","m")` |
| **非字符串输入** | 接受所有数据类型：<br>`=REGEXREPLACE(2024,24,25)` | 对于非字符串输入返回 `#VALUE!` |
