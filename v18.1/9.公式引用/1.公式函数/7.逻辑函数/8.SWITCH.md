# SWITCH

SWITCH 函数根据值列表计算一个值（称为表达式），并返回与第一个匹配值对应的结果。



#### 语法

SWITCH( *expression,value, result, result_no_match* )



#### 参数

此函数有以下参数：

| 参数 | 描述 |
|--- |--- |
|  *expression*  | 要转换的值 |
|  *value*  | 要匹配的值 |
|  *result*  | 如存在匹配项需返回的值 |
|  *result_no_match*  | 如不存在匹配需返回的值 |



#### 注释

可计算多达 126 个匹配的值和结果。



#### 数据类型

接受任何类型的数据。返回任何类型的数据。



#### 示例

SWITCH(WEEKDAY(A2),1,"Sunday",2,"Monday",3,"Tuesday","No match") 得出结果 No match.
