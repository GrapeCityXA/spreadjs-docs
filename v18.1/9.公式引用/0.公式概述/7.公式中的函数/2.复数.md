# complexnumbers

许多工程函数都涉及复数。一个复数由两部分组成，即实部和虚部。可以把一个复数看作平面上的一个点（x，y）。实数类似于平面 x 轴上的点（x，0）。请注意，实数是虚部系数为零的复数的一个子集。
并不存在一种复数数据类型。相反，复数是用 “x + yi” 这种形式的字符串来表示的，其中 x 和 y 是实数，x 是实部，“yi” 是虚部。例如：
“2 + 3i”
“1.23E4 + 5.67E8i”
下表讨论了处理复数时的一些情况：

| 场景 | 示例 |
| -------- | -------- |
| 如果实部或虚部为零，那么在文本表示中零部分可以视情况省略。 | “3” 等同于 “3 + 0i”“4i” 等同于 “0 + 4i” |
| 实数是复数的一个子集，所以实数可以用来替代 “x + yi” 这种形式的字符串。 | 3 等同于 “3 + 0i” |
| 返回复数的函数会返回 “x + yi” 这种形式的字符串。 | COMPLEX(3, 5) 返回 “3 + 5i” |
| 接受复数的函数既可以接受数字，也可以接受 “x + yi” 这种形式的字符串。 | IMSUM(“1 + 2i”, “3 + 4i”) 返回 “4 + 6i”IMSUM(1, 3) 返回 “4” |
| 当一个字符串无法转换为数字时，Spread 会返回 #VALUE 错误。 | COS(“abc”) 返回 #VALUE!IMCOS(“abc”) 返回 #VALUE! |
| 后缀 “j” 或后缀 “i” 都可以表示虚部。 | “3 + 4j” 等同于 “3 + 4i” |
| 给定的公式无论使用哪种后缀，总是返回后缀为 “i” 的结果。 | IMSUM(“1 + 2i”, “3 + 4i”) 返回 “4 + 6i”IMSUM(“1 + 2j”, “3 + 4j”) 返回 “4 + 6i”IMSUM(“1 + 2i”, “3 + 4j”) 返回 “4 + 6i” |
