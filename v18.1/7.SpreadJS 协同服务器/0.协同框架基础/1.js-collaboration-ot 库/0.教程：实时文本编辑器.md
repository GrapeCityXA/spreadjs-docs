# real-time-text-editor

本教程将指导您使用 `js-collaboration` 和 `js-collaboration-ot` 构建基于操作转换（OT）的实时协同文本编辑器。用户可在同一房间内实时编辑富文本内容，所有变更将同步至其他客户端。

> 本示例使用 Quill 作为富文本编辑器组件，您也可替换为其他编辑器组件。

## 前置条件

* 安装 Node.js v16+ 和 npm
* 具备 JavaScript 和终端操作基础知识

## 步骤 1：初始化项目

### 1\. 创建项目文件夹

创建名为 `ot-text-editor` 的新文件夹并进入：

```bash
mkdir ot-text-editor
cd ot-text-editor
```

### 2\. 初始化 Node\.js 项目

运行以下命令创建 `package.json` 文件：

```bash
npm init -y
```

编辑 `package.json` 以启用 ESM 模块并添加以下脚本：

```json
{
  "name": "ot-text-editor",
  "version": "1.0.0",
  "type": "module",
  "scripts": {
    "start": "node server.js",
    "build": "webpack"
  },
  "dependencies": {} 
}
```

### 3\. 安装依赖

安装服务端和客户端所需的 npm 包：

```bash
npm install @grapecity-software/js-collaboration @grapecity-software/js-collaboration-ot express
npm install @grapecity-software/js-collaboration-client @grapecity-software/js-collaboration-ot-client quill
npm install rich-text
```

安装前端打包工具所需的 npm 包：

```bash
npm install webpack webpack-cli --save-dev
```

### 4\. 创建 Webpack 配置文件

在项目根目录创建 `webpack.config.js` 文件，内容如下：

```javascript
import path from "path";
import { fileURLToPath } from "url";

const __dirname = path.dirname(fileURLToPath(import.meta.url));

export default {
  entry: "./public/client.js",
  output: {
    path: path.resolve(__dirname, "public"),
    filename: "client.bundle.js"
  },
  mode: "development"
};
```

### 5\. 创建基本目录结构

1. 在根目录创建 `server.js` 文件。
2. 在根目录创建 `public` 文件夹，并在其中创建空文件：`index.html`、`styles.css` 和 `client.js`。

此时目录结构如下：

```bash
/ (项目根目录)
├── public/
│   ├── index.html      # 主页面
│   ├── styles.css      # 样式文件
│   └── client.js       # 客户端逻辑
├── server.js           # 服务端逻辑
├── package.json        # 项目配置
└── webpack.config.js   # Webpack 配置
```

## 步骤 2：设置服务端

在 `server.js` 文件中添加以下代码：

```javascript
import express from "express";
import { createServer } from "http";
import { Server } from "@grapecity-software/js-collaboration";
import OT from "@grapecity-software/js-collaboration-ot";
import richText from "rich-text";

const app = express();
const httpServer = createServer(app);
const server = new Server({ httpServer });

// 注册富文本类型
OT.TypesManager.register(richText.type);

// 初始化 OT 文档服务
server.useFeature(OT.documentFeature());

// 提供静态文件服务
app.use(express.static("public"));

// 启动服务器
httpServer.listen(8080, () => {
  console.log("服务器运行在 http://localhost:8080");
});
```

**代码说明**

* 使用 [OT.TypesManager.register](gcdocsite__documentlink?toc-item-id=9ecd1b47-565e-4712-88bc-46ab4cee05b2#register) 注册 `rich-text` 类型。
* [OT.DocumentServices](gcdocsite__documentlink?toc-item-id=e04a3031-c69b-4ba3-8926-c2813134ce43) 提供默认的 OT 文档管理功能。
* [server.useFeature(OT.documentFeature())](gcdocsite__documentlink?toc-item-id=c94e9589-dfdf-4066-af97-776d49d2506e#usefeature) 启用 OT 功能。

## 步骤 3：设置客户端

客户端将使用 Quill 编辑器和 `js-collaboration-ot-client` 实现实时同步。

### 1\. 编写 HTML 文件（`public/index.html`）

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>实时协同文本编辑器</title>
  <link href="https://cdn.quilljs.com/1.3.6/quill.bubble.css" rel="stylesheet">
  <link rel="stylesheet" href="./styles.css">
  <script src="./client.bundle.js" defer></script>
</head>
<body>
  <div class="container">
    <h1>实时协同文本编辑器</h1>
    <div id="editor"></div>
  </div>
</body>
</html>
```

### 2\. 编写样式文件（`public/styles.css`）

```css
html,
body {
    height: 100%;
    margin: 0;
    font-family: Arial, sans-serif;
    background: #f0f2f5;
}

.container {
    height: 100vh;
    display: flex;
    flex-direction: column;
    background: #fff;
    box-shadow: 0 0 10px rgba(0, 0, 0, 0.1);
}

h1 {
    padding: 15px;
    margin: 0;
    color: #333;
    text-align: center;
    border-bottom: 1px solid #ddd;
}

#editor {
    flex: 1;
    border: 1px solid #ccc;
    margin: 15px;
    font-size: large;
}
```

### 3\. 编写客户端 JavaScript（`public/client.js`）

```javascript
import { Client } from "@grapecity-software/js-collaboration-client";
import * as OT from "@grapecity-software/js-collaboration-ot-client";
import richText from "rich-text";
import Quill from "quill";

// 注册富文本类型
OT.TypesManager.register(richText.type);

// 连接服务器并加入房间
const connection = new Client().connect("room-id");
const doc = new OT.SharedDoc(connection);
const quill = new Quill("#editor", { theme: "bubble" });

// 订阅文档
doc.subscribe().then(async () => {
    // 初始化内容（若文档不存在）
    if (!doc.type) {
        try {
            await doc.create([{ insert: 'Hi!' }], richText.type.uri);
        } catch (err) {
            console.error("错误: " + err);
        }
    }
    // 设置初始内容并绑定事件
    quill.setContents(doc.data);
    quill.on("text-change", (delta, oldDelta, source) => {
        if (source !== "user") return;
        doc.submitOp(delta, { source: connection.id });
    });
    // 监听远程操作
    doc.on("op", (op, source) => {
        if (source === connection.id) return; // 忽略本地操作
        quill.updateContents(op);
    });
});

// 错误处理
connection.on('error', (err) => console.error("错误: " + err));
doc.on("error", (err) => console.error("错误: " + err));
```

**代码说明**

1. **共享文档**：[OT.SharedDoc](gcdocsite__documentlink?toc-item-id=9e659419-beff-4587-9334-629c91cea5e8) 管理文档状态并与 Quill 集成。
2. **操作提交**：`quill.on("text-change")` 捕获用户编辑并提交操作。
3. **同步更新**：[doc.on("op")](gcdocsite__documentlink?toc-item-id=9e659419-beff-4587-9334-629c91cea5e8#on) 接收远程操作并更新本地编辑器。

## 步骤 4：运行与测试

### 1\. 打包客户端代码

```bash
npm run build
```

### 2\. 启动服务器

```bash
npm run start
```

您将看到输出：`Server running at http://localhost:8080`。

### 3\. 测试功能

1. 打开浏览器访问 *http://127.0.0.1:8080/index.html*。
2. 在多个窗口中打开相同地址，编辑内容并观察实时同步效果。
