# chat-room

本教程将指导开发者使用 `js-collaboration` 构建实时聊天室，内容包括：

* 在共享房间内建立点对点通信
* 收发即时消息
* 实现服务端/客户端的消息广播协调

## 前置条件

* 安装 Node.js v16+ 和 npm
* 具备 JavaScript 基础和终端操作能力

## 第一步：初始化项目

### 1\. 创建项目文件夹

创建名为 `chat-room` 的新目录并进入：

```bash
mkdir chat-room
cd chat-room
```

### 2\. 初始化 Node\.js 项目

执行以下命令创建 `package.json` 文件：

```bash
npm init -y
```

编辑 `package.json` 以启用 ESM 模块并添加脚本：

```json
{
  "name": "chat-room",
  "version": "1.0.0",
  "type": "module",
  "scripts": {
    "start": "node server.js",
    "build": "webpack"
  },
  "dependencies": {}
}
```

### 3\. 安装依赖

安装服务端和客户端所需的包：

```bash
npm install @grapecity-software/js-collaboration @grapecity-software/js-collaboration-client express
```

安装前端打包所需的 npm 包：

```bash
npm install webpack webpack-cli --save-dev
```

### 4\. 创建 Webpack 配置文件

在项目根目录创建 `webpack.config.js` 并添加以下内容：

```javascript
import path from "path";
import { fileURLToPath } from "url";

const __dirname = path.dirname(fileURLToPath(import.meta.url));

export default {
  entry: "./public/client.js",
  output: {
    path: path.resolve(__dirname, "public"),
    filename: "client.bundle.js"
  },
  mode: "development"
};
```

### 5\. 创建基础目录结构

* 在根目录创建 `server.js` 文件。
* 在根目录创建 `public` 文件夹，并在其中创建空文件：`index.html`、`styles.css` 和 `client.js`。

此时目录结构如下：

```bash
/ (项目根目录)
├── public/
│   ├── index.html      # 主页面
│   ├── styles.css      # 样式文件
│   └── client.js       # 客户端逻辑
├── server.js           # 服务端逻辑
├── package.json        # 项目配置
└── webpack.config.js   # Webpack 配置
```

## 第二步：搭建服务端

我们将创建一个简单的服务端来处理客户端连接、消息收发和广播。在 `server.js` 文件中添加以下代码：

```javascript
import express from "express";
import { createServer } from "http";
import { Server } from "@grapecity-software/js-collaboration";

// 创建 Express 应用和 HTTP 服务器
const app = express();
const httpServer = createServer(app);

// 初始化协同服务器
const server = new Server({ httpServer });

// 服务静态文件（供客户端使用）
app.use(express.static("public"));

// 监听客户端连接
server.on("connect", ({ connection, roomId }) => {
    console.log(`${connection.id} 加入了房间 ${roomId}`);
    // 广播新用户加入的消息（包括用户自己）
    connection.broadcast(`${connection.id} 加入了聊天室`, "", true);
});

// 处理客户端发送的消息
server.on("message", ({ connection, data, roomId }) => {
    console.log(`收到来自 ${connection.id} 的消息: ${data}`);
    // 向房间内所有用户广播消息（包括发送者）
    connection.broadcast(`${connection.id}: ${data}`, "", true);
});

// 监听客户端断开连接
server.on("disconnect", ({ connection, roomId }) => {
    console.log(`${connection.id} 离开了房间 ${roomId}`);
    // 广播用户离开的消息
    connection.broadcast(`${connection.id} 离开了聊天室`, "", true);
});

// 启动服务器
httpServer.listen(8080, () => {
    console.log("服务器运行在 http://localhost:8080");
});
```

### 代码说明

* 使用 express 和 http 创建 HTTP 服务器。
* 使用 `@grapecity-software/js-collaboration` 中的 [Server ](gcdocsite__documentlink?toc-item-id=c94e9589-dfdf-4066-af97-776d49d2506e)类初始化协同服务器。
* 注册 `connect`、`message` 和 `disconnect` 事件，分别处理用户加入、消息发送和离开。
* [connection.broadcast()](gcdocsite__documentlink?toc-item-id=464e75e4-bb2c-4163-8997-3a576676fe36#broadcast) 向房间内所有客户端广播消息，`includeSelf: true` 确保发送者也能看到自己的消息。

## 第三步：搭建客户端

接下来创建简单的 HTML 文件和 JavaScript 客户端，用于连接服务器并实现聊天功能。

### 1\. 编写 HTML 文件（`public/index.html`）

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>实时聊天室</title>
    <link rel="stylesheet" href="./styles.css">
    <script type="module" src="./client.bundle.js" defer></script>
</head>
<body>
    <div class="container">
        <h1>实时聊天室</h1>
        <div id="chat"></div>
        <div class="input-area">
            <input type="text" id="message" placeholder="输入消息...">
            <button onclick="sendMessage()">发送</button>
        </div>
    </div>
</body>
</html>
```

### 2\. 编写客户端 JavaScript（`public/client.js`）

```javascript
import { Client } from "@grapecity-software/js-collaboration-client";

const client = new Client();
const connection = client.connect("chatroom");

connection.on("message", (data) => {
  const chatDiv = document.getElementById("chat");
  const message = document.createElement("p");
  message.textContent = data;
  chatDiv.appendChild(message);
  chatDiv.scrollTop = chatDiv.scrollHeight;
});

window.sendMessage = function () {
  const input = document.getElementById("message");
  const message = input.value.trim();
  if (message) {
    connection.send(message);
    input.value = "";
  }
};
```

### 代码说明

* 使用 `@grapecity-software/js-collaboration-client` 中的 [Client ](gcdocsite__documentlink?toc-item-id=402e864f-93d6-42e2-8aed-59863d91e723)类创建客户端并连接到 "chatroom" 房间。
* 使用 [connection.on("message")](gcdocsite__documentlink?toc-item-id=01f01f56-2c37-4f99-b868-ac32e2c7e57b#on) 监听服务器消息，并在聊天窗口中显示。
* `sendMessage()` 函数从输入框获取消息，并通过 `connection.send()` 发送到服务器。

## 第四步：运行和测试聊天室

### 1\. 打包客户端代码

```bash
npm run build
```

### 2\. 启动服务器

在终端中执行以下命令：

```bash
npm run start
```

您将看到输出：`Server running at http://localhost:8080.`

### 3\. 打开浏览器

在浏览器中访问 *http://localhost:8080*，将看到聊天室界面。

### 4\. 测试功能

* 打开多个浏览器窗口模拟多个用户加入聊天室。
* 在一个窗口中输入消息并点击"发送"，所有窗口应实时显示该消息。
* 关闭一个窗口，其他窗口将收到用户离开的通知。
