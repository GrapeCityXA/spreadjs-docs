# initalizing-client

`js-collaboration-client` 提供了强大的客户端库，用于与服务器建立双向通信。本指南将教您：

* 创建协作客户端
* 连接至服务器房间

## 创建客户端

### 1\. 安装 npm 包

```bash
npm install @grapecity-software/js-collaboration-client
```

### 2\. 创建客户端实例

使用 [Client ](gcdocsite__documentlink?toc-item-id=402e864f-93d6-42e2-8aed-59863d91e723)类创建客户端实例，可选择指定服务器 URL。如果协作服务与前端部署在同一域名下，可直接使用：

```typescript
import { Client } from "@grapecity-software/js-collaboration-client";
const client = new Client(); // 服务器 URL 将从 window.location 对象推导
```

跨域场景下，需显式指定服务器 URL：

```typescript
const client = new Client("ws://server-domain.com:8000");
```

## 连接服务器并加入房间

### 简单连接

使用以下代码 [连接 ](gcdocsite__documentlink?toc-item-id=402e864f-93d6-42e2-8aed-59863d91e723#connect)服务器并加入指定房间：

```typescript
const connection = client.connect('roomId');
```

### 携带附加信息的连接

若需在建立连接时携带附加信息（如用户认证详情），可通过 `query` 和 `auth` [参数 ](gcdocsite__documentlink?toc-item-id=a8f75e63-6e27-47f6-bae4-7481d4f1b505)传递，这些信息可在服务端 `connect` 中间件中访问和使用：

```typescript
const connection = client.connect('roomId', {
    query: {
        myQueryArg: 'xxx',  // 服务端可通过 context.connection.query 访问
    },
    auth: {
        token: 'xxx'  // 服务端可通过 context.connection.auth.token 访问
    }
});
```

实际场景中，可将用户认证信息（如令牌）作为 `auth` 参数传递给服务器，服务器通过中间件获取并验证该认证信息，以决定是否允许用户建立连接。关于用户认证和权限的更多信息，参见 [用户认证与权限](gcdocsite__documentlink?toc-item-id=d7a401c5-ab47-4dd9-9937-37bbc0a548ac)。

## 后续步骤

[Client ](gcdocsite__documentlink?toc-item-id=402e864f-93d6-42e2-8aed-59863d91e723)类是连接服务器的第一步。通过简单的初始化和 [connect ](gcdocsite__documentlink?toc-item-id=402e864f-93d6-42e2-8aed-59863d91e723#connect)调用，即可快速加入协作房间。连接成功后，使用返回的 `Connection` 对象实现双向通信和事件管理。更多细节参见 [Connection 类](gcdocsite__documentlink?toc-item-id=fa18a247-b4f2-45f8-b134-4c30260a7124)。
