# designer-localization

你可以使用 `getResources` 和 `setResources` 方法来自定义设计器组件的本地化设置。这些方法可通过以下步骤帮助修改本地化资源：

1. 使用 [getResources ](gcdocsite__documentlink?toc-item-id=7e131f20-7eab-40bd-9f75-5ed6b663680e#getresources)方法获取原始的设计器资源对象。
2. 修改资源对象的内容。
3. 使用 [setResources ](gcdocsite__documentlink?toc-item-id=7e131f20-7eab-40bd-9f75-5ed6b663680e#setresources)方法设置已修改的资源对象。
4. 初始化设计器。

> **注意：** 如果你在初始化设计器之后设置资源，那么你将不得不修改并设置设计器中的配置，以更改功能区资源。

```JavaScript
var resources = GC.Spread.Sheets.Designer.getResources();
resources.ok = "OK!";
resources.formatDialog.title = "Format Dialog!"
resources.ribbon.home.home = "HOME!";
resources.ribbon.home.paste = "Paste!";
GC.Spread.Sheets.Designer.setResources(resources);
var designer = new GC.Spread.Sheets.Designer.Designer(document.getElementById("designerHost"));
```
