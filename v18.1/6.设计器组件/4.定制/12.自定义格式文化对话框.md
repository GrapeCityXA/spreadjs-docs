# designer-customize-culture

你可以在单元格格式窗口中自定义设计器组件的区域设置对话框。[Spread.Common.CultureInfo](gcdocsite__documentlink?toc-item-id=36975826-ad1b-46dc-905c-05542a548c85) 类可以通过诸如区域设置 ID、显示名称和预定义格式（货币、会计、日期、时间、特殊格式）等属性来帮助定义新的区域设置选项。

1. 初始化设计器实例。

    ```JavaScript
    // 初始化设计器组件
    var designer = new GC.Spread.Sheets.Designer.Designer(document.getElementById("designerHost"));
    ```
2. 使用 [CultureInfo ](gcdocsite__documentlink?toc-item-id=36975826-ad1b-46dc-905c-05542a548c85#_ctor)构造函数方法获取区域设置信息实例。它代表自定义区域设置类。

    ```JavaScript
    // 获取区域设置信息实例
    var cultureInfo = new GC.Spread.Common.CultureInfo()
    ```
3. 设置区域设置信息属性，以便在格式窗口中进行指定。请参考 [Microsoft 区域设置 ID 定义](https://docs.microsoft.com/en-us/openspecs/windows_protocols/ms-lcid/63d3d639-7fd2-4afb-abbe-0d5b5551eef8) 了解所有可用的区域设置 ID。

    ```JavaScript
    // 为德语设置新的区域设置信息
    cultureInfo.displayName = "德语（德国）"
    cultureInfo.name = function () { return "de-DE" }
    cultureInfo.id = 0x407;
    cultureInfo.predefinedFormats.Accounting = '_-* #,##0. [$€-407]_-;-* #,##0. [$€-407]_-;_-* "-". [$€-407]_-;_-@_-';
    cultureInfo.predefinedFormats.Currency = [
        "#,##0. [$€-407]",
        "#,##0. [$€-407];[Red]#,##0. [$€-407]",
        "#,##0. [$€-407];-#,##0. [$€-407]",
        "#,##0. [$€-407];[Red]-#,##0. [$€-407]"
    ];
    cultureInfo.predefinedFormats.Date = [
        "yyyy-mm-dd;@",
        "d.m;@",
        "d.m.yy;@",
        "dd.mm.yy;@",
        "[$-407]d. mmm.;@",
        "[$-407]d. mmm. yy;@",
        "[$-407]d. mmm yy;@",
        "[$-407]mmm. yy;@",
        "[$-407]mmmm yy;@",
        "[$-407]d. mmm yy;@",
        "[$-409]d/m/yy h:mm AM/PM;@",
        "d.m.yy h:mm;@",
        "[$-407]mmmmm;@",
        "[$-407]mmmmm yy;@",
        "d.m.yyyy;@",
        "[$-407]d. mmm. yyyy;@"
    ]
    cultureInfo.predefinedFormats.Time = [
        "h:mm;@",
        "[$-409]h:mm AM/PM;@",
        "h:mm:ss;@",
        "[$-409]h:mm:ss AM/PM;@",
        "mm:ss.0;@",
        "[h]:mm:ss;@",
        "[$-409]d/m/yy h:mm AM/PM;@",
        "d.m.yy h:mm;@"
    ]
    cultureInfo.predefinedFormats.Special = {
        "邮政编码": "00000",
        "邮政编码 (A)": "\A-00000",
        "邮政编码 (CH)": "C\H-00000",
        "邮政编码 (D)": "\D-00000",
        "邮政编码 (L)": "L-00000",
        "保险证明编号 (D)": "\[@\]",
        "社会保险号码 (A)": "0000-00 00 00",
        "社会保险号码 (CH)": "000\.00\.000\.000",
        "ISBN 格式 (ISBN x-xxx-xxxxx-x)": "I\S\B\N #-###-#####-#",
        "ISBN 格式 (ISBN x-xxxx-xxxx-x)": "I\S\B\N #-####-####-#",
        "ISBN 格式 (ISBN x-xxxxx-xxx-x)": "I\S\B\N #-#####-###-#"
    }
    ```
4. 使用 [addCultureInfo ](gcdocsite__documentlink?toc-item-id=1d75c6d6-9498-4322-bb74-dde3cc8b8ce4#addCultureInfo)方法添加新的区域设置信息对象。

    ```JavaScript
    // 添加新的区域设置信息
    GC.Spread.Common.CultureManager.addCultureInfo(cultureInfo.name(), cultureInfo);
    ```
