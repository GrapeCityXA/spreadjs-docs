# task-tab

**任务**选项卡提供了在甘特图中执行各种任务操作以管理项目进度的选项。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.e52bb6.png)
下表列出了任务选项卡的部分、可用功能选项及其描述：

| **部分** | **功能选项** | **描述** |
| --- | ---- | --- |
| @rows=3:计划 | 任务完成 | 可将任务完成度快速调整为 0%、25%、50%、75% 和 100% 的选项。 |
| 缩进 / 取消缩进任务 | 增加或降低任务层级的选项。 |
| 链接 / 取消链接任务 | 链接或取消链接任务以设置或移除与前置任务关系的选项。 |
| @rows=3:任务 | 手动计划 | 将所选任务模式更改为自动的选项。 |
| 自动计划 | 将所选任务模式更改为手动的选项。 |
| 模式 | 为新任务设置默认模式的选项。 |
| @rows=3:插入 | 任务 | 在所选任务之前插入任务的选项。 |
| 摘要 | 在所选任务之前插入摘要任务的选项。添加时，所选任务的层级会改变。 |
| 里程碑 | 在指定位置插入里程碑任务的选项。 |
| 属性 | 信息 | 查看所选任务的常规和高级信息的选项，如任务名称、持续时间、完成百分比、计划模式、开始时间、完成时间、前置任务等。 |
| @rows=2:编辑 | 滚动到任务 | 将所选任务滚动到中间的选项。 |
| 查找 | 在项目中搜索字符串或数字数据以及用其他内容替换特定数据的选项。 |

如果需要了解更多关于任务操作的信息，请参见[操作任务](gcdocsite__documentlink?toc-item-id=254f4e99-02ad-4fbb-a31e-600532517943)。
