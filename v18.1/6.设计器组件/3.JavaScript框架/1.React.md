# designer-react

你可以按照以下步骤在 React 应用程序中添加 SpreadJS 设计器组件：

1. 在命令提示符中输入以下命令来创建一个 React 项目。

    ```Shell
    npm install -g create-react-app
    create-react-app designer-component
    cd designer-component
    npm start
    ```
2. 安装以下 SpreadJS React 模块以使用 SpreadJS 设计器组件。

    ```Shell
    npm install @grapecity-software/spread-excelio
    npm install @grapecity-software/spread-sheets
    npm install @grapecity-software/spread-sheets-io
    npm install @grapecity-software/spread-sheets-barcode
    npm install @grapecity-software/spread-sheets-charts
    npm install @grapecity-software/spread-sheets-languagepackages
    npm install @grapecity-software/spread-sheets-pdf
    npm install @grapecity-software/spread-sheets-print
    npm install @grapecity-software/spread-sheets-shapes
    npm install @grapecity-software/spread-sheets-tablesheet
    npm install @grapecity-software/spread-sheets-pivot-addon
    npm install @grapecity-software/spread-sheets-designer
    npm install @grapecity-software/spread-sheets-designer-resources-en
    npm install @grapecity-software/spread-sheets-react
    npm install @grapecity-software/spread-sheets-designer-react
    ```
3. 在 `App.js` 中使用以下代码片段导入所需的模块。

    ```JavaScript
    import '@grapecity-software/spread-sheets-designer-resources-en';
    import {Designer} from '@grapecity-software/spread-sheets-designer-react';
    import '@grapecity-software/spread-sheets-designer/styles/gc.spread.sheets.designer.min.css'
    import '@grapecity-software/spread-sheets/styles/gc.spread.sheets.excel2013white.css'
    ```
4. 在 `App.js` 中使用以下代码片段渲染设计器组件。

    ```JavaScript
    function App() {
       return (
          <Designer styleInfo = {{width: "1500px", height: '90vh'}}></Designer>
       );
    }
    export default App;
    ```
5. 运行应用程序。

    ```Shell
    npm start
    ```

## 访问 SpreadJS 实例

你还可以通过使用 `designerInitialized` 事件来访问 SpreadJS 实例。请遵循上述的步骤 1、2 和 3，并继续以下操作：

1. 要渲染设计器组件并访问 SpreadJS 实例，可以使用以下代码片段。

    ```JavaScript
    function App() {
        return (
            <Designer designerInitialized={designer => { getDesigner(designer) }}
            styleInfo={{ width: "100%", height: '98vh' }}></Designer >
        );
    }
    // 获取设计器的函数
    function getDesigner(designer) {
        // 这是托管的 Spread 实例
        var workbook = designer.getWorkbook();
        var sheet = workbook.getActiveSheet(); sheet.setValue(1, 1, 'Test');
    }
    ```

## 设置授权

授权版本允许你使用 SpreadJS 设计器组件的所有功能。你需要为 SpreadJS、ExcelIO 和设计器组件设置许可证密钥，可以使用以下代码片段完成。

```JavaScript
import React from 'react';
import '@grapecity-software/spread-sheets-designer-resources-en';
import * as GC from '@grapecity-software/spread-sheets';
import '@grapecity-software/spread-sheets-designer';
import {Designer} from '@grapecity-software/spread-sheets-designer-react';
import * as ExcelIO from "@grapecity-software/spread-excelio";
 
var sjsLicense = "sjs-distribution-key";
GC.Spread.Sheets.LicenseKey = sjsLicense;
ExcelIO.LicenseKey = sjsLicense;
 
GC.Spread.Sheets.Designer.LicenseKey = " designer-component-distribution-key ";
```
