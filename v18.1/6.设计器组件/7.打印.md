# print-designer

SpreadJS 设计器组件提供了一个打印菜单，使您能够预览和打印工作表或工作簿的全部或部分内容以及所需的信息。您可以进行设置，并利用所有可用的打印设置来控制打印的内容。
**打印** 菜单与新建、导入和导出选项位于同一个 **文件** 窗口中。
![print-component](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/print-component.27aff3.292143.png)
打印菜单中提供了以下功能：

| 功能 | 描述 |
| --- | --- |
| 打印预览 | 此区域（右列）会在您打印之前预览页面以及应用的所有设置。 |
| 打印按钮 | 当您点击打印按钮时，会弹出浏览器的打印对话框。内容基于打印区域。 |
| @cols=2:设置 |
| 打印区域 | 一个下拉菜单，包含可供选择的工作簿区域用于打印。<ul><li>打印活动工作表</li><li>打印整个工作簿</li><li>打印所选内容</li></ul> |
| 从第...页 | 设置起始页。默认值和最小值为 1。如果设置的值不合法，则取值为 1。 |
| 到第...页 | 设置最后一页。默认值为打印页数。如果设置的值不合法，则取值为 1。 |
| 页面方向 | 将页面方向设置为横向或纵向。默认情况下，工作表以纵向（高大于宽）方式打印。 |
| 页面大小 | 设置纸张大小。默认值为信纸尺寸（8.5 英寸×11 英寸）。 |
| 页边距 | 设置打印区域的页边距大小。可从提供的常用格式中选择，也可以创建自定义格式。 |
| 缩放 | 设置所选打印区域的缩放比例，以便相应地适配数据。默认情况下，不应用缩放，因此工作表将按实际大小打印。 |

> **注意：** 打印包含大图片的工作表可能会花费大量时间。因此，当打印内容包含许多图片或有一张大图片时，页面预览加载缓慢是正常现象。

打印菜单在左列部分的末尾有一个“页面设置”选项，点击该选项会打开一个对话框窗口。这个“页面设置”窗口扩展了上述功能以及更多其他功能。如需了解更多信息，请参阅 [打印设置](gcdocsite__documentlink?toc-item-id=3aecd0d9-be47-48e8-a705-bee66097cfbd)。
