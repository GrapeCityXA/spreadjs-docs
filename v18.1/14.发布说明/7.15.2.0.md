# rnotesv152

# 与上一版本相比的重大更改

切片器现在得到了增强，可以使用表格和形状基础而不是 DOM 基础。使用表格切片器、表格切片器数据、项目切片器和数据透视切片器时，必须添加新插件 gc.spread.sheets.slicers.js。
由于切片器是基于形状的功能，因此 gc.spread.sheets.shapes.js 插件作为依赖项优先添加。

# 此版本的产品中包含以下功能和增强功能

* SpreadJS 现在将图片实现为形状而不是浮动对象。
* SpreadJS 支持图片几何类型、透明度、对比度、亮度和裁剪。
* SpreadJS 支持在图片中重新着色。
* SpreadJS Designer 使用图片格式选项卡进行了增强。
* 当工作表受到保护时，SpreadJS 支持 InvalidOperation 事件以进行更多操作。
* SpreadJS 支持使用 tab/shift+tab 键和 enter/shift+enter 键进行选择导航。
* SpreadJS 支持名称框组件。
* SpreadJS 的单元格类型得到了增强，以支持工作表单元格中的数据对象。
* TableSheet 现在支持 API 使用 getchanges 方法获取当前更改信息。
* 表格切片器支持多选选项。
* TableSheet 现在支持组合框和多列列表以增强查找列的呈现。
* 添加了动态引用标志以增强计算性能并降低内存使用量。
* 数据透视表得到了增强，以支持 EnableDataValueEditing 选项，该选项可以在运行时编辑数据透视表中的值。
* 用户可以获得跨工作簿公式的来源和目标。
* 用户现在可以将可变样式应用于悬停单元格状态中的不同范围。
* 用户可以通过动态更改数据源来加载没有数据的表格模板。
* 用户可以使用新的 Excel 数组操作函数。
* 用户可以使用新的 Excel 文本操作功能。
* 用户可以使用 fetch 方法在不刷新页面的情况下更新 Tablesheet 的数据源。
* 用户可以使用格式化程序公式显示自定义列值。
* SpreadJS 现在支持 React 18。
* SpreadJS 现在支持 Angular 14。

* SpreadJS 中的切片器已更新为使用特殊字符导出。

* SpreadJS 已解决导入表格切片器的问题。
* 用户现在可以替换过滤行中的值。
* 用户现在可以在 getUsedRange 的帮助下访问已使用的范围。
* SpreadJS 已更新以设置所选系列的数据标签。
