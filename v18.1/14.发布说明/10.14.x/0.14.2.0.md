# rnotesv142




此版本的产品包含以下功能和增强功能。

- SpreadJS Designer 支持Go To Special功能以在工作表中选择一组特殊的单元格。
- 引入了附加键盘快捷键
- 用户可以在 SpreadJS Designer 组件中绑定文件导入事件
- SpreadJS Designer 支持查找和替换功能。
- Designer UX 已得到增强。
- SpreadJS 设计器组件现在包含一个带有 React 模块的 d.ts 定义文件。
- 设计器中的名称框可用于处理单元格范围
- 用户可以使用StatusBar.findControl方法自定义设计器组件状态栏
- SpreadJS 设计器中的“插入”选项卡布局已更新。
- SpreadJS Designer 组件支持工具栏功能区模式
- 用户可以自定义设计器组件本地化
- SpreadJS 现在支持Vue 3和Angular 12版本。
- SpreadJS Designer 为带有公式的单元格范围提供自动区域分组
- 用户可以使用折叠功能区启动设计器组件。
- 用户可以在 SpreadJS 中移动工作表和复制工作表。这些操作也可以在SpreadJS Designer中执行。
- SpreadJS 现在支持 iOS14 和 iPadOS14。
- SpreadJS Designer 提供了格式刷按钮来将格式从一个对象复制并粘贴到另一个对象。
- 用户可以在 SpreadJS 设计器中取消隐藏多个工作表
- SpreadJS Designer 提供了形状选择窗格来管理和排列工作表中的多个形状。
- 用户可以在 SpreadJS 中通过背景颜色和字体颜色对单元格进行排序。
- 增量加载功能在增量加载回调函数中提供了一个新参数，用于访问工作表相关信息。
- 用户可以在 SpreadJS 设计器组件中创建和使用自定义组件
- 该工作簿构造已得到增强，接受主机ID字符串。
- 用户现在可以在设计器组件中编代码方式关闭对话框。
- 用户可以自定义现有的语言包并将它们翻译成特定的语言。
- 当设计器宽度小到可以隐藏功能区按钮和导航选项卡时，SpreadJS 设计器启用功能区滚动。
- 粘贴格式选项已增强根据目标区域的大小来调整粘贴格式。
