## 相比上一版本的改进

本版本产品纳入了以下功能和改进内容：
**性能与优化**

* 减小了 SpreadJS 设计器组件的 JS 和 CSS 文件大小，以实现更快的加载速度。
* 提升了数据透视表的性能，使数据操作更加流畅。

**设计器改进**

* **侧面板灵活性**：设计器的 [侧边栏](gcdocsite__documentlink?toc-item-id=6676b5db-5dfd-437c-9133-68eae53c51ec) 现在支持停靠和浮动模式。
* **命令面板**：增加了对 [命令面板](gcdocsite__documentlink?toc-item-id=8044bffd-63f5-47e1-92f6-b8a5a1153eb1) 的支持，以简化工作流程。
* **功能区复选框样式**：更新了功能区复选框的外观，以实现更好的视觉一致性。
* **滚动条控制**：添加了 `scrollIgnoreHidden` 选项，用于自定义滚动条的行为。
* **图表自定义**：
    * 在设计器中支持调整图表轴的 `labelAngle`（标签角度）。
    * 为 [气泡图](gcdocsite__documentlink?toc-item-id=22da3aab-65aa-4dff-bd43-9517ddb3a5ff) 添加了 `BubbleScale`（气泡比例）选项。
    * 在 [数据图表](gcdocsite__documentlink?toc-item-id=17820e1d-8560-424e-8958-7351656f92b4) 面板中，支持设置分类轴标签格式化和单位。

**用户界面与样式**

* **[工作表选项卡自定义](gcdocsite__documentlink?toc-item-id=ca743d24-50e8-45b7-b06a-dd5d0500d8b1)**：支持对工作表选项卡设置自定义的边框圆角样式。
* **[工作表背景](gcdocsite__documentlink?toc-item-id=2c95a949-410c-49f9-bf48-4ce00f5981bc)**：增加了对工作表级背景图片的支持。
* **[主题字体](gcdocsite__documentlink?toc-item-id=49874b66-77e9-46e7-8874-d825b5fe0bc6)**：主题中增加了对东亚字体的支持。

**公式与计算**

* **新函数**：支持 [`TRIMRANGE`](gcdocsite__documentlink?toc-item-id=ab09f8ab-a180-47ed-87a8-99b3a41aaa29) 函数。
* **[正则表达式兼容性](gcdocsite__documentlink?toc-item-id=fcf3909d-d32b-4551-8a09-8276bffca053)**：完全兼容 Excel 的正则表达式函数。
* **API 增强**：[`evaluateFormula()`](gcdocsite__documentlink?toc-item-id=0f2da260-277b-4e6f-b839-4a3c8934f9bf) 现在会返回完整的结果数组。

**数据透视表改进**

* **[格式化](gcdocsite__documentlink?toc-item-id=b71c9fb7-156a-4fa3-8dc0-8285f94e1a61)**：使用设计器的“数字格式”对话框简化了数据透视表字段的格式化操作。

**AI 功能 - 预览版**

* **[AI 助手](gcdocsite__documentlink?toc-item-id=bd497cc2-8c3e-43fc-b7c0-48eb450a9347)**：SpreadJS 现在集成了人工智能功能。
* **[公式编辑器面板](gcdocsite__documentlink?toc-item-id=eb5d8069-dba5-4f5f-b8e7-a9e9ad9a76ea)**：在公式编辑器面板中提供由人工智能驱动的建议和帮助。
* **[数据透视表面板](gcdocsite__documentlink?toc-item-id=bf70efa1-9523-4a87-b5ac-e1a2a60a0f29)**：数据透视表面板现在支持人工智能辅助功能。

**框架支持**

* **[Angular 19](gcdocsite__documentlink?toc-item-id=86b615f1-dc92-4c6a-98a0-10d83bbb3cf0)**：增加了对 Angular 19 的完全兼容。

## 已解决的问题

自上一版本以来，以下问题已得到解决：
**性能与导入/导出**

* 修复了由于条件格式导入缓慢和数据验证列膨胀问题导致的 Excel 文件加载停滞问题。
* 重构了数据验证模块的缓存逻辑（从字典结构改为 rbush 结构），以解决导入 Excel 文件后出现的卡顿问题。
* 修复了由于数据透视表字段名称区分大小写导致的 XLSX 文件导出失败问题（现在与 Excel 不区分大小写的行为保持一致）。
* 修复了 XLSX 文件导出过程中 XML 节点不匹配的问题，该问题会导致数据透视表布局出现错误（例如，空白行、小计错误）。
* 提高了在表格绑定场景中通过数据管理器添加行数据时的性能。
* 解决了由于形状数量过多（超过 21,477 个）导致的文件加载失败问题。
* 修复了在 `IncludeBindingSource=true` 时导出异常的问题，该问题会导致 XML 输出中字符串/数字单元格值冲突。
* 修复了在定义打印区域时，设置 `printInfo` 或打印缓慢会触发所有公式重新计算的问题。
* 修复了包含重复范围条件格式规则的 Excel 文件导致渲染缓慢的性能问题。现在导入时会自动移除重复范围。

**图表与数据可视化**

* 修复了图表中数据点工具提示显示不正确和点击测试错误的问题。
* 使气泡图的缩放和图例布局与 Excel 的行为保持一致。
* 修复了由于单位转换差异导致的 PDF 形状渲染不一致问题（例如，虚线显示错误）。

**数据透视表**

* 修复了鼠标离开时筛选框过早关闭的问题（现在与 Excel 的行为一致）。
* 纠正了数据透视表标题样式问题（字体粗细优先级现在与 Excel 主题一致）。
* 修复了由于未验证的列标题范围导致的数据源更改错误。
* 解决了删除计算字段后出现空白工作表的问题（改进了数据透视表缓存刷新逻辑）。
* 修复了拖放功能错误覆盖底层数据的问题。
* 修复了数据透视表在“值显示方式”模式下对特殊数据输出“NAN”的问题。

**公式与计算**

* 修复了 `ExternalReference` 与 `SUMIFS` 无法更新链接值的问题（例如，`#VALUE` 错误）。
* 修复了 `XIRR` 公式由于未解析的日期格式（例如，“Mar 2017”）返回 `#NUM` 的问题。
* 确保动态数组公式在范围扩展后重新计算。
* 使 `SORT` 函数的参数处理与 Excel 的行为保持一致。

**用户界面与设计器组件**

* 为截断的表格绑定路径添加了工具提示，以改善调试体验。
* 修复了页眉/页脚字体解析问题（例如，“맑은 고딕”字体的加粗样式）。
* 纠正了超链接对话框在编辑后回显内容不匹配的问题。
* 修复了甘特图工作表标题名称在点击后重置为默认值的问题。
* 防止在移除 `.sjs` 文件中的下划线样式后，下划线样式再次出现。
* 修复了在延迟加载或搜索导航期间 `ActiveSheetChanged` 事件不触发的问题。
* 修复了 SpreadJS（布尔值/数字）与 Excel（仅数字）之间字体 `TextDecoration`（文本装饰）类型冲突的问题。
* 修复了工作表选项卡背景颜色应用失败的问题（数据透视表命令错误）。

**数据验证与命令**

* 修复了插入新行后“选择性粘贴 - 转置”功能失败的问题。
* 通过改进单元格级别的缓存更新，优化了验证性能。
* 修复了由于未处理的未定义自定义名称导致的 `sheet.getDependents` 崩溃问题。
* 修复了重叠单元格中按钮触发的命令问题。
* 使数据验证回调按钮的行为与 Excel 保持一致。

**其他杂项**

* 标记了无效的工作表名称引用（例如，`'!A1`），以符合 Excel 的解析器规则。
* 修复了由于背景颜色/图案组合逻辑导致的上传时边框丢失问题。
* 确保在工作表 JSON 序列化/反序列化后注释被正确替换。
* 限制了受保护工作表中按 Tab 键时表格的自动扩展（与 Excel 的行为一致）。
* 使筛选规则在错误处理情况（`CalcError`）下与 Excel 保持一致。
* 通过优化自定义名称计算，减少了公式管理器的延迟。
* 修复了影响自定义公式和布局重建时机的增量加载模式问题。
* 修复了启用延迟/增量加载时切换工作表出现白屏的问题。
* 修复了 `renameSheet` 命令未按预期更新工作表名称的问题。
* 修复了数据透视表数据源解析中的无效输入错误。
* 修复了不同屏幕 DPI 下形状边框复制不一致的问题。
* 修复了工作表名称中日语字符处理不当导致文件打开失败的问题。
* 修复了表格公式调整后公式引用范围同步问题。
* 修复了在刷新数据透视表时，未加载工作表导致的自定义名称解析错误。
* 修复了设计器富文本编辑器错误解析加粗格式的问题。
* 修复了 Excel 与 SJS 格式之间单元格边框样式转换的问题。
* 修复了在向折叠节点添加行时，大纲列状态与文本缩进不同步的问题。
* 修复了在集算表中使用 `cancelChanges` 时，通过 `view.fetch(true)` 重新加载数据时未正确重置数据属性和行顺序的问题。这影响了分层父子结构，使得同级操作在重新加载后无法恢复到初始状态。
