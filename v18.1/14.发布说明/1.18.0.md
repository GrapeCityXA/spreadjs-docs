## 上一版本以来的增强功能

本版本产品整合了以下功能和增强特性：

* 新增可选的 DataChart 插件，开发人员可借此创建直接绑定到 SpreadJS 数据管理器的图表，无需在 SpreadJS 工作簿中存储数据，且与传统图表相比，其样式设置更强大灵活。DataChart 还可与 ReportSheet 插件配合，在 ReportSheet 中创建图表。
* ReportSheet 增强功能：
    * 新增容器支持，用于创建结构化的数据显示和分析模板。
    * 在字段值编辑器对话框中添加下拉选择功能，以便为列选择参数值。
    * 支持对角线单元格类型，可在单元格内插入对角线。
    * 支持管理所有单元格的展开和折叠状态。
    * 新增选项用于管理报表中单元格的初始展开状态。
    * 可通过在搜索框中输入列字段来搜索特定列数据。
    * 在 ReportSheet 设计向导中新增添加聚合函数的选项。
* 能够管理是否显示各个字段的分类汇总数据。
* 现在用户可使用 allowEditInCell API 控制单元格是否可编辑。
* 增强了对 ComboBox 单元格类型动态绑定数据源（如数据表名称或公式查询）的支持。
* 改进了对单元格文本、标签、注释、值或公式的搜索功能。
* 支持函数引用（eta 缩减 lambda），可通过去除不必要的抽象来简化函数。
* 现已支持 Angular 18。
* 新增 startEdit 和 changeEditorStatus 命令，可通过编程将单元格的编辑器状态切换为编辑模式。
* 增强了使用 TableResizing 事件限制表格行数或列数的支持。
* 改进了现有的 getUsedRange API，使其能够检索带有单元格标签的单元格区域。
* 用户现在可使用样式的 textDirection 属性将单元格文本方向更改为从右到左。
* 增强了在数据透视表中更改数据源并同步现有布局信息的支持。
* SpreadJS 支持数据范围容器，可将数据视图注入工作表。
* SpreadJS 现在支持将工作表表格绑定到数据管理器表格作为数据源，以实现动态数据交互。
* 新增支持 GROUPBY、PIVOTBY 和 PERCENTOF 等聚合函数。
* SpreadJS 和 SpreadJS Designer 组件现在支持带有 TypeScript 的 Vue 包装器。
* 新增支持使用鼠标滚轮和 Shift 键水平滚动工作表。
* 支持在 SpreadJS Designer 中搜索不可见区域。
* 数据透视表筛选对话框和筛选行 / 列对话框现在支持键盘导航。
