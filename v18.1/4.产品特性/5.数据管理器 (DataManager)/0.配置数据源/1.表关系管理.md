# relationships

## 概述

在数据库管理领域，建立表与表之间的关联关系是极为常见且重要的操作。DataManager 同样支持为两个表设置关系，以此实现表间数据的联动与交互。

![ts-relationview-flowchart](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ts-relationview-flowchart.21924f.png)

如上图所示，Tablesheet 关系通过定义相关表及其字段，可完美适配具有主键 - 外键关系的表结构场景。在 DataManager 中，关系涉及的两个数据表将进行双向绑定，用户能够便捷访问两个表中的所有属性，实现数据的高效整合与利用。

### 将表添加到 DataManager

使用 [addTable](https://docs.grapecity.com.cn/spreadjs/help/api/classes/GC.Data.DataManager#addTable) 方法，可轻松将多个表添加至数据管理器。具体代码示例如下：

```JavaScript
// 将客户表添加到 DataManager
var customerTable = dataManager.addTable('customerTable', {
    remote: {
        read: {
            url: 'https://demodata.grapecity.com/wwi/api/v1/customers',
        },
    },
});

// 将销售表添加到 DataManager
var salesTable = dataManager.addTable('salesTable', {
    remote: {
        read: {
            url: 'https://demodata.grapecity.com/wwi/api/v1/sales?PageNumber=10&PageSize=500',
        },
    },
});
```

### 在表之间添加关系

通过 [addRelationship](https://docs.grapecity.com.cn/spreadjs/help/api/classes/GC.Data.DataManager#addRelationship) 方法，能够在表之间建立关系。该方法需传入源表、字段名称、关系名称，以及目标表、字段名称、关系名称等参数。
以下代码示例展示了如何通过 customerTable 的 customerKey 字段与 salesTable 的 customerKey 字段建立关系：

```JavaScript
// 在销售表和客户表之间添加关系
dataManager.addRelationship(customerTable, "customerKey", "mySales", salesTable, "customerKey", "myCustomer");
```

## 移除关系

在 DataManager 中，当为两个表建立关系时，实际上创建了两种双向关联关系。以上述示例为例，为 customerTable 建立了名为 mySales 的关系，用于链接 salesTable；同时为 salesTable 建立了名为 myCustomer 的关系，用于链接 customerTable。
若需移除两个表之间的关系，可使用任意一个关系名称进行操作。一旦两个表中的单向关系被移除，其反向关系也将自动同步移除。具体移除代码如下：

```JavaScript
dataManager.removeRelationship("mySales");
// 或者
dataManager.removeRelationship("myCustomer");
```
