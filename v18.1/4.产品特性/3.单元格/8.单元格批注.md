# comments

SpreadJS支持单元格中的注释。 您可以指定评论和评论图标的外观。 您还可以调整大小，移动或编辑注释。

### 自定义批注

您可以在单元格中添加批注并指定外观。 您还可以调整大小，移动或编辑批注。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/comment.png)
下图显示了调整大小和移动指示符图标。 选择批注时，将显示调整大小图标。 当指针位于批注边框上方时，将显示移动图标。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/commentmove.png)
如果表单选项 **isProtected** 设置为true，则可以锁定评论事件或评论文本。 下表显示了批注属性值和表单受保护的结果。

| **Locked** | **LockText** | **Result** |
| ------ | -------- | ------ |
| false | false | 批注生效；可以编辑 |
| true | false | 批注作无效；可以编辑 |
| false | true | 批注生效；无法编辑 |
| true | true | 批注无效；无法编辑 |

调整行或列的大小可能会导致评论的位置和大小根据 **dynamicMove** 与 **dynamicSize** 方法设置。下表显示了 **dynamicMove** 和 **dynamicSize** 设置的结果。

| **DynamicMove** | **DynamicSize** | **Result** |
| ----------- | ----------- | ------ |
| true | true | 批注随单元移动并调整大小 |
| true | false | 批注已移动，但未用单元格调整大小 |
| false | true or false | 批注未随单元格移动或调整大小 |

如果注释处于编辑模式，则可以在注释中剪切，复制或粘贴文本。 如果复制单元格，则注释将与单元格一起复制。
如果您剪切，复制或粘贴评论文本，调整评论大小或移动评论或变更评论的格式，则撤消和重做操作将适用。
从Excel格式的文件导入批注时有一些限制。 某些边框样式和字体未导入。 如果表单范围小于原始文件中显示的范围，则批注位置可能会有所不同。 批注是从XLSX文件导入的。

> **注意**：从Excel格式的文件导入批注时有一些限制。 某些边框样式和字体未导入。 如果表单范围小于原始文件中显示的范围，则批注位置可能会有所不同。 批注是从XLSX文件导入的。

#### 示例代码

以下代码在单元格中添加批注，并设置颜色和显示模式。

```JavaScript
var comment = activeSheet.comments.add(5,5,"new comment!");
comment.text("new comment!");
comment.backColor("red");
comment.displayMode(GC.Spread.Sheets.Comments.DisplayMode.AlwaysShown);
```

### 自定义批注图标

插入批注时，默认情况下，单元格的右上角会出现一个红色的小三角形。 您可以使用 **indicatorColor** 和 **indicatorSize** 方法来变更批注图标的默认颜色和大小。
下图显示了带有绿色批注图标的表单单元格。
![](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/041236cd-4159-4f89-9e42-7be2bb789d22/images/comment-icon.png)

#### 示例代码

以下代码将批注添加到单元格，并设置批注图标的颜色和大小。

```JavaScript
// 创建批注
var comment = new GC.Spread.Sheets.Comments.Comment();
comment.text("This is comment for Cell[2,2]");

// 设置indicatorSize
comment.indicatorSize(25); // 6 as default

// 设置indicatorColor
comment.indicatorColor('green'); // 'red' as default

// 添加批注
activeSheet.comments.add(2, 1, comment);
```
