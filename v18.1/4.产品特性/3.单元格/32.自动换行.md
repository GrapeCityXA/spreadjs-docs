# WrapTextInCell

通常，当输入到单元格中的数据太大而无法放入其中时，您的文本要么显示为已截断，要么数据倾向于在水平方向上溢出到单元格外部。
为了在单个单元格中显示完整的内容，SpreadJS允许用户在单元格中包装文本（包含空格或连字符）。 将文本换行应用于单元格时，该单元格内的文本将自动换行以适合列宽，并且内容将以多行显示。 如果以后变更列宽，则换行的文本会在单元格中自动调整。

在处理表单时，文本换行功能非常有用，特别是在用户希望：

* 在单元格中存储冗长的文本信息块，同时在整个表单中保持列宽的一致性。
* 在单元格中显示文本时，避免被截断和溢出。
* 增强文本的可读性，使其更适合打印。
* 无需输入手动换行符即可调整单个单元格中的大内容。

### 如何启用自动换行

要在SpreadJS中使用文本换行, 用户 只需将 **wordWrap()** 方法的value参数设置为true。然后，在运行时，如果用户增加或减少列宽，将像在Excel中一样显示换行的文本。 如果分隔符后面的文本不能容纳在指定的列宽内，则将换行。
请参考以下示例代码，以便在单元格中包装包含连字符的文本。

```JavaScript
// 初始化 Spread 控件
var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 2 });

// 获取表单
activeSheet = spread.getSheet(0);
activeSheet.setColumnWidth(0, 200);
activeSheet.setRowHeight(0, 200);
activeSheet.getCell(0, 0, 3).value('test1-test2-test3-test4').wordWrap(true);
sheet2 = spread.getSheet(1);
sheet2.setColumnWidth(0, 200);
sheet2.setRowHeight(0, 200);
sheet2.getCell(0, 0, 3).value('test1 test2 test3 test4').wordWrap(true);
```

SpreadJS 还使你能够将自动换行的文本块复制并粘贴到另一个 SpreadJS 工作表中，或者粘贴到 Excel 工作表中。
