# SetVerticalTextDirectioninaCell

和 Excel 一样，SpreadJS 允许用户根据自己的偏好设置单元格中的文本方向，这增强了电子表格中数据展示的灵活性和可读性。

## 垂直文本方向

当你在单元格中输入文本时，字母默认是水平显示的。不过，如果你希望文本垂直显示，可以对文本进行垂直样式设置，如下方图片所示。
![vertical-text_img1](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/vertical-text_img1.6b096d.png)
要将单元格中的文本方向切换为垂直方向，你可以使用 [CellRange ](gcdocsite__documentlink?toc-item-id=64f05fd4-fafa-47dc-9856-b74263f357ec)类的 **isVerticalText** 方法。该方法接受布尔参数——true 或 false。在这个方法中传入布尔值 true 表示文本将垂直显示，传入布尔值 false 则表示文本将水平显示（与默认情况相同）。
Spread JS 中的垂直文本方向功能支持水平和垂直对齐。你可以通过自定义 [vAlign ](gcdocsite__documentlink?toc-item-id=64f05fd4-fafa-47dc-9856-b74263f357ec#valign)方法（用于垂直对齐）和 [hAlign](gcdocsite__documentlink?toc-item-id=64f05fd4-fafa-47dc-9856-b74263f357ec#halign)（用于水平对齐）来指定对齐方式。下方图片展示了一个示例。
**在垂直文本方向下使用 vAlign 和 hAlign**
你还可以使用 [textIndent ](gcdocsite__documentlink?toc-item-id=64f05fd4-fafa-47dc-9856-b74263f357ec#textindent)方法在设置单元格垂直文本方向时控制文本缩进。下方图片展示了一个示例。
![vertical-text_img3](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/vertical-text_img3.05eba9.png)
通常，一个单词在垂直文本的单元格中可能看起来太长而无法完整显示。在这种情况下，你可以使用 [wordWrap ](gcdocsite__documentlink?toc-item-id=64f05fd4-fafa-47dc-9856-b74263f357ec#wordwrap)方法使其适应同一单元格。下方图片展示了一个示例。
![vertical-text_img4](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/vertical-text_img4.7bb72c.png)
如果你不想在单元格中使用自动换行功能，可以使用 [shrinkToFit ](gcdocsite__documentlink?toc-item-id=64f05fd4-fafa-47dc-9856-b74263f357ec#shrinktofit)方法让 Spread 自动缩小垂直文本的字体大小。下方图片展示了一个示例。
![vertical-text_img5](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/vertical-text_img5.17af5d.png)
如果你既不想使用自动换行功能，也不想使用缩小字体填充功能，可以让 Spread 自动调整单元格的宽度和高度，以便将所有内容都显示在同一单元格中。这可以通过使用 [AutoFitType 枚举](https://docs.grapecity.com.cn/spreadjs/api/v18/enums/GC.Spread.Sheets.AutoFitType) 来实现。下方图片展示了一个示例。
![vertical-text_img6](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/vertical-text_img6.131e55.png)
以下代码示例通过在 [isVerticalText ](gcdocsite__documentlink?toc-item-id=64f05fd4-fafa-47dc-9856-b74263f357ec#isverticaltext)方法中传入布尔值 “true”，将单元格 D4 的文本方向设置为垂直方向。

```javascript
var sheet = spread.getActiveSheet();
sheet.setRowHeight(3,150);
sheet.getCell(3,3).value("SpreadJS").isVerticalText(true);
sheet.getCell(3,4).value("SpreadJS").isVerticalText(false);
```

## 从右到左文本方向

使用 SpreadJS，你可以将单元格中文本的方向从从左到右更改为从右到左。通过使用 [TextDirectionType ](gcdocsite__documentlink?toc-item-id=ceea8221-b2a1-4ae6-96ca-120cbe1d34f3)枚举将样式的 **textDirection** 属性设置为 **rightToLeft**，甚至标点符号也会显示在文本的左侧。
从右到左（RTL）的单元格文本方向适用于从右向左书写和阅读的语言和文字。它确保了使用这些语言时数据能够正确、自然地显示。

> **注意**：目前，SpreadJS 仅为阿拉伯字母和希伯来字母指定从右到左的文本方向。

![righttoleft-textdirection.9e5051](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/righttoleft-textdirection.9e5051.b7c49e.png)
以下代码示例使用 **TextDirectionType** 枚举来设置文本方向。

```javascript
// 此示例使用 getCell 方法和 textDirection 方法。
activeSheet.getCell(0, 0).textDirection(GC.Spread.Sheets.TextDirectionType.rightToLeft).value("هذه الفقرة باللغة العربية ، لذا يجب الانتقال من اليمين إلى اليسار.");

// 或者
// 此示例使用 getRange 方法和 textDirection 方法。
activeSheet.getRange(1, -1, 1, -1).textDirection(GC.Spread.Sheets.TextDirectionType.rightToLeft);
activeSheet.setValue(1, 1, "هذه الفقرة باللغة العربية ، لذا يجب الانتقال من اليمين إلى اليسار.");
activeSheet.setValue(1, 3, "هذه الفقرة باللغة العربية ، لذا يجب الانتقال من اليمين إلى اليسار.");

// 或者
// 此示例使用 setStyle 方法和 textDirection 属性。
var style = new GC.Spread.Sheets.Style();
style.textDirection = GC.Spread.Sheets.TextDirectionType.rightToLeft;
activeSheet.setStyle(2, 2, style, GC.Spread.Sheets.SheetArea.viewport);
activeSheet.setValue(2, 2, "هذه الفقرة باللغة العربية ، لذا يجب الانتقال من اليمين إلى اليسار.");
```

SpreadJS 中的文本方向支持打印和导出为 PDF 文件。在导入/导出 .sjs、.ssjson 和 .xlsx 文件时，也支持设置文本方向。

> **注意**：从右到左的文本方向不支持图表、形状、批注和切片器。此外，SpreadJS 设计器不允许你在集算表、甘特图工作表和报表工作表中更改文本方向。

**限制**

* 从右到左的文本方向对英语、中文、日语和韩语字符不起作用。
