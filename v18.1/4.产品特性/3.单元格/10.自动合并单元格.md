# auto-merge-cells

SpreadJS支持自动合并功能，允许用户自动合并包含重复文本的相邻单元格。 在自动合并操作期间，在此过程中不会丢失任何数据。

### 使用自动合并的好处

自动合并功能可帮助用户：

* 在大型数据集中创建清晰可视化。
* 合并相同的单元而不会丢失任何数据。
* 消除冗余（重复文本）以消除表单中不必要的混乱。
* 节省大量时间和精力，而无需手动扫描重复的单元格以将它们一一合并。

### 自动合并原理？

自动合并功能会自动合并具有相同文本的连续单元格，并调整合并单元格的文本位置。
此功能在您要合并的单元格不应属于任何跨度范围的条件下起作用。 使用SpreadJS时，用户可以使用 **autoMerge()** 方法 将自动合并功能应用于指定范围，包括范围，行，列和整个表单。
SpreadJS 支持以下两种模式 **AutoMergeMode** 枚举:

* 自由模式-在此模式下，具有相同值的单元格会自动与相邻的单元格合并。
* 受限模式-在此模式下，只有在前一行或前一列中的相应单元格以类似方式合并时，具有相同值的单元格才会与相邻单元格合并。

要在SpreadJS中使用 **addSpan** 的选择功能支持自动合并, 使用 **Worksheet** 类下的 **autoMerge** 方法的参数 **SelectionMode**
您可以将 **SelectionMode** 参数设置为 **source** 或 **merged** 。 下面介绍了这两个选项：

* **source** : 在此模式选项中，您可以选择自动合并区域中的单个单元格。
* **merged** : 在此模式选项中，您可以在自动合并区域中选择整个合并的单元格。

### 使用场景

在表单上执行数据分析时，用户可能希望合并包含相同文本的多个单元格，以增强数据表示和更好的结构。
例如-在生成销售报告时，最好将匹配的州或城市名称自动合并在一起，使其看起来更整洁，干净，同时确保不会丢失任何信息，并且合并后的单元格中的数据保持完整。

### 自动合并单元格与生成和合并单元格

在表单中执行“自动合并单元格”操作和“跨单元合并”的基本区别是：

* 在SpreadJS中使用“自动合并”功能时，即使执行了合并操作，单元仍保持可导航和可编辑状态。 相反，在执行单元格的合并和合并时，变更单元格值时会自动调整跨度和合并的单元格。
* 当用户滚动浏览表单时，文本在合并的跨度中保持可见（粘滞）状态。 与常规合并跨度不同，自动合并的像元具有相同的值。

> **注意:** 使用自动合并功能时，必须牢记以下限制：
>
> * While adding a row or column
> * While removing a row or column
> * While setting row count or column count
> * The auto-merge range is affected when a user executes the following operations in the spreadsheet
> * While printing or saving to a PDF file (using the savePDF method), all the merged cells will automatically be treated as normal span ranges.
> * The copy or move operation will not affect the auto-merge range, and will not treat the automatically merged cells as normal span ranges.
