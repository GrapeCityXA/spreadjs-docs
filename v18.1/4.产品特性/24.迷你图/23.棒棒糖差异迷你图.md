# lollipop-variance-sparkline

棒棒糖差异迷你图是一种强大的数据可视化技术，可用于展示数据集中的绝对差异和相对差异。SpreadJS 允许您使用 `LOLLIPOPVARISPARKLINE` 方法创建棒棒糖差异迷你图。
棒棒糖差异迷你图传达的信息与条形图相同，但它通过将矩形转换为线条来减少显示空间，突出数据点，使显示更简洁。因此，在处理大量数据时，棒棒糖图表在美观上更具优势。
![lollipop-sparkline-labels.12e586](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/lollipop-sparkline-labels.12e586.bcac7c.png)
上图展示了一个棒棒糖差异迷你图及其组成元素：

| **元素** | **说明** |
| --- | --- |
| 参考值 | 所有值都相对于此参考值进行偏移。 |
| 棒棒糖 | 棒棒糖的长度表示差异大小。 |
| 最小值标识 | 表示棒棒糖迷你图能够绘制的最小值。 |
| 最大值标识 | 表示棒棒糖迷你图能够绘制的最大值。 |
| 标签 | 表示数据的准确数值。 |
| 箭头 | 仅当值大于最大值或小于最小值时显示。<br>箭头的显示方向取决于当前差异是正还是负，以垂直或水平方向显示。<br>**水平方向**：<ul><li>如果差异为正：箭头显示在单元格右侧。</li><li>如果差异为负：箭头显示在单元格左侧。</li></ul>**垂直方向**：<ul><li>如果差异为正：箭头显示在单元格顶部。</li><li>如果差异为负：箭头显示在单元格底部。</li></ul> |
| 刻度单位 | 用户可以设置的基本单位。 |
| 正差异颜色 | 表示当差异值大于参考值时，棒棒糖条的填充颜色。 |
| 负差异颜色 | 表示当差异值小于参考值时，棒棒糖条的填充颜色。 |

棒棒糖差异迷你图公式有以下选项：

| **参数** | **类型** | **默认值** | **说明** |
| --- | --- | --- | --- |
| plannedValue<br>[必填] | 数字或引用 |  | 指定要在计划值区域的整个范围内传入的预期数据集。 |
| actualValue<br>[必填] | 数字或引用 |  | 指定在实际值区域的整个范围内传入的实际数据集。 |
| index<br>[必填] | 数字或引用 |  | 指定 **plannedValue** 和 **actualValue** 的数据索引。<br>对于水平绘图，这与行索引相关；对于垂直绘图，这与列索引相关。<br>索引从 0 开始。 |
| absolute<br>[可选] | 布尔值 | false | 指定棒棒糖迷你图显示的是绝对差异还是相对差异。<ul><li>false - 差异值之间互不影响。</li><li>true：差异严格按比例绘制，这意味着它们相互影响，并且参考值、最大值标识和最小值标识参数不起作用。</li></ul> |
| reference<br>[可选] | 数字或引用 | 0 | 指定参考线的位置。 |
| mini<br>[可选] | 数字或引用 | -1 | 指定迷你图的最小值。 |
| maxi<br>[可选] | 数字或引用 | 1 | 指定迷你图的最大值。 |
| tickunit<br>[可选] | 数字或引用 | 0 | 指定刻度单位。 |
| legend<br>[可选] | 布尔值 | FALSE | 指定是否显示数据标签。 |
| colorPositive<br>[可选] | 字符串 | “green“（绿色） | 设置差异大于参考值时的颜色。 |
| colorNegative<br>[可选] | 字符串 | “red”（红色） | 设置差异小于参考值时的颜色。 |
| lollipopHeaderColor<br>[可选] | 字符串 | “black“（黑色） | 通过此参数设置棒棒糖头部的填充颜色。 |
| vertical<br>[可选] | 布尔值 | FALSE | 指定是否垂直显示迷你图。 |

棒棒糖差异迷你图公式具有以下语法：
`=LOLLIPOPVARISPARKLINE(plannedValue,actualValue,index,absolute,reference,mini,maxi,tickunit,legend,colorPositive,colorNegative,lollipopHeaderColor,vertical);`

## 使用场景

设想这样一个场景，一个组织想要创建一份经济数据报告，以帮助他们分析不同地区的利润差异（以计划利润的百分比表示），从而反映现实与预期之间的差距。
当值大于最大值或小于最小值且数据超出预期时，棒棒糖差异迷你图还会在图表中显示一个箭头。
![lollipop-sparkline.76dded](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/lollipop-sparkline.76dded.8cad59.png)

```javascript
var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'), { sheetCount: 1 });
var sheet = spread.getActiveSheet();
sheet.name('Lollipop variance sparkline');
sheet.setRowCount(20);
sheet.setColumnCount(40);
sheet.suspendPaint();
sheet.addSpan(0, 0, 1, 5);
sheet.setValue(0, 0, '区域销售数据分析统计表');
sheet.getCell(0, 0).backColor('#196a99');
sheet.setArray(1, 0, [
    ['地区', '销售目标', '实际销售', '差异', '差异百分比'],
    ['亚洲', 4500, 3500],
    ['欧洲', 3758, 3920],
    ['北美洲', 4525, 5002],
    ['南美洲', 3200, 3480],
    ['大洋洲', 1540, 1800],
    ['非洲', 430, 430],
]);
for (let i = 2; i < 8; i++) {
    sheet.setFormula(i, 3, '=LOLLIPOPVARISPARKLINE($B$3:$B$8,$C$3:$C$8,' + (i - 2) + ',true,,,,200,true,"#cecece","#cecece","#ffa501")');
    sheet.setFormula(i, 4, '=LOLLIPOPVARISPARKLINE($B$3:$B$8,$C$3:$C$8,' + (i - 2) + ',false,0,-0.2,0.2,0.1,true,"green","red","skyblue")');
}
widthList = [100, 100, 100, 300, 300];
for (let i = 0; i < widthList.length; i++) {
    sheet.setColumnWidth(i, widthList[i]);
}
heightList = [50, 50, 50, 50, 50, 50, 50, 50, 50, 50, 50, 50];
for (let i = 0; i < heightList.length; i++) {
    sheet.setRowHeight(i, heightList[i]);
}
sheet.getRange('A1:E13').hAlign(1).vAlign(1);
sheet.getRange('A1:E1').font('bold normal 15px normal');
sheet.getRange('A1:A13').font('bold normal 15px normal');
sheet.getRange(2, 3, 6, 1).setBorder(new GC.Spread.Sheets.LineBorder('#fff', GC.Spread.Sheets.LineStyle.empty), {
    inside: true,
});
sheet.resumePaint();
```

## 使用设计器

您可以使用 Spread 设计器设置棒棒糖差异迷你图，方法是在 **插入** \> **迷你图** 选项卡组中选择 **棒棒糖差异迷你图** 按钮。
