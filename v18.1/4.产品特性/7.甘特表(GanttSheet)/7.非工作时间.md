# non-working-time

甘特图的图表区域也会显示非工作时间。甘特图以不同方式突出显示工作时间和非工作时间，以便用户能够清晰区分。默认情况下，甘特图使用灰色来表示非工作时间。你可以使用 `nonWorkingTime` 属性来更改非工作区域的绘制模式、颜色和样式图案。
以下代码示例展示了如何更改非工作区域的不同属性。

```javascript
// 更改非工作时间的样式。
// 将颜色更改为绿色。
ganttSheet.project.timescale.nonWorkingTime.color = "green";
// 将图案更改为交叉线。
ganttSheet.project.timescale.nonWorkingTime.pattern = "lineCross";
// 将绘制模式更改为无。
ganttSheet.project.timescale.nonWorkingTime.drawMode = "None";
```
