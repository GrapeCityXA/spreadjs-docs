# task-operation

你可以在甘特图工作表（GanttSheet）中执行各种任务操作来管理项目进度，具体如下所述。

## 添加普通任务

你可以将普通任务添加或插入到指定位置。在插入任务时若未指定其层级，该任务将被置于目标任务之前，并且相邻任务将决定其层级：

* 如果前一个任务是摘要任务，新插入的任务将成为其子任务。
* 如果前一个任务因大纲折叠而不可见，插入的任务将与目标任务的层级对齐；否则，插入任务的层级将与紧挨着它的前一个任务的层级相对应。

> **注意**：SpreadJS 不允许在根任务之前插入任务。根任务是只读任务，其字段值不可编辑。

下图展示了插入一个持续时间为 1 天且没有任何前置任务的新任务的示例。
![GS-AddTask.c00dc8](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/GS-AddTask.c00dc8.d2843e.png)
你可以使用 [GC.Spread.Sheets.GanttSheet.Project](gcdocsite__documentlink?toc-item-id=dd6f4979-2a14-4231-99d3-8b4bba79d476) 类的 `addTasks` 或 `insertTasks` 方法来添加或插入新任务，如下方代码示例所示。

```javascript
// Add a new task
function addTask(ganttSheet) {
    ganttSheet.suspendPaint()
    var project = ganttSheet.project;
    var selections = ganttSheet.getSelections();
    var insertedRow = Math.min(...selections.map(r => r.row), project.tasks.length)
    var rowCount = selections.map(r => r.rowCount).reduce((pre, current) => { return pre + current });
    var taskData = createTaskDataList(rowCount, () => ({ name: "<New Task>" }));
    project.insertTasksByRow(insertedRow, taskData); 
    ganttSheet.resumePaint();
}
function createTaskDataList(count, initializer) {
    var array = new Array(count);
    for (var index = 0; index < count; index++) {
         array[index] = initializer();
    }
    return array;
}
```

## 添加摘要任务

摘要任务是其他任务的父任务。你可以将相关任务分组，以便更清晰地查看和更好地管理项目。
下图展示了一个新的摘要任务。
![GS-AddSummaryTask.0b3b41](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/GS-AddSummaryTask.0b3b41.c31cda.png)
要在甘特图工作表中插入摘要任务，请使用 `insertTasks` 方法，如下方代码示例所示。

```javascript
// Add a new summary task.
function addSummary(ganttSheet) {
    ganttSheet.suspendPaint()
    var project = ganttSheet.project;
    var selectedRange = ganttSheet.getSelections()[0];
    var insertedRow = selectedRange.row;
    var insertedTaskNumbers = ganttSheet.getTaskByRow(insertedRow).taskNumber || project.count;
    var selectedTasks = getSelectedRowIndexes().map((row) => ganttSheet.getTaskByRow(row)).filter((row) => !!row);
        if (selectedTasks.length == 0) {
            project.insertTasks(insertedTaskNumbers, [{ name: "<New Summary Task>" }, { name: "<New Task>" }]);
            project.indentTasks(insertedTaskNumbers + 1);
        } else {
            project.insertTasks(insertedTaskNumbers, { name: "<New Summary Task>" }, selectedTasks[0].level);
            project.indentTasks(selectedTasks.map((t) => t.taskNumber));
        }
        ganttSheet.setSelection(insertedRow, -1, 1, -1);
        ganttSheet.resumePaint();
}
function getSelectedRowIndexes() {
    var rows = [];
    var selections = ganttSheet.getSelections();
    for (var range of selections) {
        for (var row = range.row; row < range.row + range.rowCount; row++) {
            rows.push(row);
        }
    }
    return rows;
}
```

## 添加里程碑任务

甘特图中的一个重要元素是里程碑，它代表持续时间为零的任务，显示项目时间轴中的重要成果。
下图展示了插入一个持续时间为零的新里程碑任务的情况。当你设置里程碑任务时，日期文本将在甘特图区域中与里程碑图标一起显示。
![GS-AddMilestoneTask.753018](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/GS-AddMilestoneTask.753018.67fe5c.png)

你可以使用 `insertTasksByRow` 方法在甘特图工作表中插入里程碑任务，如下方代码示例所示。

```javascript
// Add a new milestone task.
function addMilestone(ganttSheet) {
    var project = ganttSheet.project;
    var selections = ganttSheet.getSelections();
    var rowCount = selections.map(r => r.rowCount).reduce((pre, current) => { return pre + current });
    var insertedRow = Math.min(...selections.map(r => r.row), project.tasks.length);
    var taskData = createTaskDataList(rowCount, () => ({ name: "<New Milestone>", duration: 0 }));
    project.insertTasksByRow(insertedRow, taskData);
    ganttSheet.setSelection(insertedRow, -1, rowCount, -1);
}
```

## 移动任务

当任务排程模式设置为“手动”时，Spread 允许你使用 `moveInWeeks` 和 `moveInWorkingDays` API 在甘特图工作表项目中移动任务。

> **注意**：根任务是只读的，因此其字段值不可编辑。

## 删除任务

如果任务未被使用，你可以从甘特图工作表中删除它。请注意，Spread 不允许你从甘特图工作表中删除根任务。如果你删除摘要任务或包含该摘要任务的任务范围，该摘要任务下的所有子任务也将被删除。
你可以使用以下方法删除任务或任务范围：

* `removeTasks`
* `removeTasksByRange`
* `clearTasks`
* `clearTasksByRange`

以下示例代码展示了如何使用 `removeTasks` 方法删除任务。

```javascript
// Delete a task.
function deleteTask(ganttSheet) {   
    var project = ganttSheet.project;   
    var rowIds = getSelectedTaskNumbers();   
    project.removeTasks(rowIds);
}
```

## 缩进/取消缩进任务

在甘特图工作表中，每个任务都有对应的层级，根任务的层级为 0。你可以对选定的任务进行缩进或取消缩进操作来调整任务的层级。当你缩进一个任务时，它的层级会增加 1，并使前一个任务成为摘要任务；而当你取消缩进一个任务时，它的层级会减少 1，并使选定的任务成为摘要任务。
以下 GIF 展示了任务层级的缩进和取消缩进操作。
![GS-indent-outdent.4feb5c](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/GS-indent-outdent.4feb5c.b8d4a7.gif)

你可以一次性调整一个或多个任务的层级。要对任务进行缩进和取消缩进操作，请使用 [GC.Spread.Sheets.GanttSheet.Project](gcdocsite__documentlink?toc-item-id=dd6f4979-2a14-4231-99d3-8b4bba79d476) 类的以下方法：

* `indentTasks`
* `indentTasksByRange`
* `outdentTasks`
* `outdentTasksByRange`

以下代码示例展示了如何使用 `indentTasks` 和 `outdentTasks` 方法在甘特图工作表中更改任务层级。

```javascript
// Indent a task.
function indentTask(ganttSheet) {            
    var project = ganttSheet.project;            
    var rowIds = getSelectedTaskNumbers();            
    project.indentTasks(rowIds);        
}        
// Outdent a task.
function outdentTask(ganttSheet) {            
    var project = ganttSheet.project;            
    var rowIds = getSelectedTaskNumbers();            
    project.outdentTasks(rowIds);        
}
```

## 链接/取消链接任务

你可以在甘特图工作表中链接任务，以建立它们与前置任务的关系。为此，请使用 `addDependency` 方法，并通过 `fromTaskNumber` 和 `toTaskNumber` 参数在项目中的任务之间创建依赖关系。任务依赖关系有四种不同类型，如下表所示。

| **任务依赖类型** | **示例图片** |
| ------ | ---- |
| FS（完成 - 开始） | ![GS-dependencytype-FS.03e554](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/GS-dependencytype-FS.03e554.0366e7.png) |
| SS（开始 - 开始） | ![GS-dependencytypes-SS.a58354](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/GS-dependencytypes-SS.a58354.f31367.png) |
| FF（完成 - 完成） | ![GS-dependencytypes-FF.f3f102](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/GS-dependencytypes-FF.f3f102.22b8b0.png) |
| SF（开始 - 完成） | ![GS-dependencytypes-SF.bc09f9](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/GS-dependencytypes-SF.bc09f9.26d47e.png) |

你可以使用 [GC.Spread.Sheets.TaskDependencyType](gcdocsite__documentlink?toc-item-id=f3d567b2-6885-4950-a156-71d03a3e5d89#taskdependencytype) API 设置所需的依赖类型。默认类型为 FS（完成 - 开始）。你还可以使用 `removeDependency` 方法取消任务链接以移除依赖关系。
下图展示了链接和取消链接任务的示例。
![GS-link-unlink.191ddb](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/GS-link-unlink.191ddb.3fe0ea.png)

以下示例代码展示了如何在甘特图工作表中链接和取消链接任务。

```javascript
// Link tasks.
function linkTask(ganttSheet) {
    var project = ganttSheet.project;
    var links = [];
    var selections = ganttSheet.getSelections();
    var previous = -1;
    for (var range of selections) {
        if (previous != -1) {
            links.push([previous, range.row]);
        }
        for (var row = range.row + 1; row < range.row + range.rowCount; row++) {
            links.push([row - 1, row]);
        }
        previous = range.row + range.rowCount - 1;
    }
    if (links.length <= 0) {
        return;
    }
    project.suspendSchedule();
    for (var link of links) {
        var [fromTaskNumber, toTaskNumber] = link;
        try {
            project.addDependency({ fromTaskNumber, toTaskNumber });
        } catch { }
    }
    project.resumeSchedule();
}
// Unlink tasks.
function unlinkTask(ganttSheet) {
    var project = ganttSheet.project;
    var taskNumbers = getSelectedTaskNumbers();
    var dependencies = [];
    if (taskNumbers.length == 1) {
        var task = project.getTaskByRow(taskNumbers[0]);
        dependencies = [...task.predecessorDependencies, ...task.successorDependencies];
    } else {
        var taskNumberSet = {};
        for (var taskNumber of taskNumbers) {
            taskNumberSet[taskNumber] = true;
        }
        dependencies = project.dependencies.filter(dp => taskNumberSet[dp.from.taskNumber] && taskNumberSet[dp.to.taskNumber]);
    }
    if (dependencies.length >= 1) {
        project.removeDependency(dependencies);
    }
}
```

> **注意事项**：
>
> * 摘要任务不能链接到子节点。
> * 如果任务已经相互链接，则不能再添加重复的链接。
> * 链接线不能交叉。
>     例如，如果摘要任务 2 链接到摘要任务 8，摘要任务 2 的子节点可以链接到摘要任务 8 的子节点，但摘要任务 8 的子节点不能链接到摘要任务 2 的子节点。
> * 摘要任务的前置依赖关系只能是 FS（完成 - 开始）或 SS（开始 - 开始）。

## 更改任务进度状态

甘特图工作表在“完成”字段中以百分比形式显示任务进度，范围从 0 到 100。为此，你需要确保源数据包含“完成”字段。添加“完成”字段后，进度条将在甘特图视图的任务栏内可见，如下图所示。
![GS-Progressbar.02aa86](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/GS-Progressbar.02aa86.4e392f.png)

你需要将鼠标悬停在任务栏上并拖动进度条来更改任务栏内的完成值。请注意，普通任务的完成百分比可以在甘特图工作表中手动更改。Spread Designer 还提供了按钮，可将任务完成情况快速调整为 0%、25%、50%、75% 和 100%。
然而，摘要任务的完成情况是根据以下公式自动计算的：
**摘要任务完成百分比 = 任务的总实际持续时间 / 任务的总估计持续时间 \* 100%**
当你重新排程时，摘要任务的计算将完成，因此添加/删除/缩进/取消缩进以及更改子任务的持续时间和完成情况将导致重新排程。
以下代码示例创建了一个包含“完成”字段的甘特图工作表。

```javascript
// Create a new GanttSheet and define the columns for the Gantt chart view.
var ganttSheet = spread.addSheetTab(0, "GanttSheet1", GC.Spread.Sheets.SheetType.ganttSheet);
var view = myTable1.addView("myView1", [
    { value: "taskNumber", caption: "编号", width: 60 },
    { value: "name", caption: "任务名称", width: 200 },
    { value: "duration", caption: "持续时间", width: 90 },
    { value: "predecessors", caption: "前置任务", width: 120 },
    { value: "complete", caption: "完成百分比", width: 120 }
]);
```

你可以使用 [GC.Spread.Sheets.GanttSheet.Task](gcdocsite__documentlink?toc-item-id=9a96d87c-2424-4dd0-a46d-bbf987a349a0) 类的 `complete` 属性来设置或获取任务完成百分比。此外，你可以使用 `completeThrough` 属性来设置或获取表示任务进度报告截止日期的日期值。以下示例代码展示了如何在甘特图工作表中设置或获取 `complete` 和 `completeThrough` 属性。

```javascript
var task = ganttSheet.getTaskByRow(10);
// Get complete.
console.log(task.complete);
// Set complete.
task.complete = 0.5;
// Get complete through.
console.log(task.completeThrough);
// Set complete through.
task.completeThrough = task.finish;
```
