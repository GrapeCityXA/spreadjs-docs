# task-properties

任务是甘特图项目计划的基本单元，有开始时间、结束时间以及持续时间。
你可以[向项目中添加多个任务](gcdocsite__documentlink?toc-item-id=254f4e99-02ad-4fbb-a31e-600532517943)，每个任务具有不同的[层级](gcdocsite__documentlink?toc-item-id=f1efa1af-0073-46e2-ba31-0148dfe63ca5)，并设置[任务之间的依赖关系](gcdocsite__documentlink?toc-item-id=254f4e99-02ad-4fbb-a31e-600532517943#%E9%93%BE%E6%8E%A5%E5%8F%96%E6%B6%88%E9%93%BE%E6%8E%A5%E4%BB%BB%E5%8A%A1)，以帮助你更有效地组织和管理项目。

接下来，我们将在以下部分讨论甘特图任务的属性。

## 任务类型

在甘特图中，任务分为三种类型：

* **普通任务**：普通任务是最常见的任务类型。
* **汇总任务**：汇总任务是其他任务的父任务。
* **里程碑**：项目里程碑是一种持续时间为零的任务，用于表示项目中的重要成果。

## 任务排程模式

在甘特图项目中，任务可以通过两种不同的模式进行排程：

* **自动模式**：表示任务是自动排程的。这意味着开始时间、结束时间和持续时间字段是根据任务依赖关系和其他项目设置计算得出的。请注意，仅当任务处于自动模式时，持续时间值才有效。如果设置了任务的持续时间，任务将使用该持续时间。如果未设置，则每个任务的默认持续时间为一天。
* **手动模式**：表示任务是手动排程的。你可以为每个任务手动设置开始时间、结束时间和持续时间值。每个任务的持续时间是从根节点开始计算的，并且任务之间的关系是根据对前置任务和后续任务的依赖关系来安排的。

使用手动模式时，需考虑以下情况：

* 如果仅指定了结束时间，该任务将成为**仅结束时间**任务。
* 如果仅指定了开始时间，该任务将成为**仅开始时间**任务。
* 如果仅指定了持续时间，该任务将成为**仅持续时间**任务。
* 如果甘特图中的某个任务没有前置任务，它将与父节点同时开始。但是，如果有前置任务，它将在前一个任务完成时开始。
* 如果未指定开始时间、结束时间或持续时间，自动模式将根据其他字段计算缺失的值。
* 如果指定了开始时间、结束时间和持续时间，但持续时间与开始时间和结束时间之间的差值不匹配，则使用开始时间和持续时间值。
* 如果结束日期早于开始日期，默认情况下将持续时间设置为一天。
* 如果排程后结束日期早于开始日期，该任务将成为持续时间为 0 的里程碑。

请注意，当你手动调整开始时间、结束时间和持续时间时，任务的颜色会发生变化以反映这些调整，如下图所示。

#### 排程的重新计算

在以下情况下会重新计算任务排程：

* [初始化项目时](gcdocsite__documentlink?toc-item-id=8cf4e704-fe0f-4f19-ba01-a539f7b828fc)。
* [设置项目的开始时间或日历](gcdocsite__documentlink?toc-item-id=29a29170-1356-4f01-aa7d-78768532bed9)时。
* [执行与任务相关的操作](gcdocsite__documentlink?toc-item-id=254f4e99-02ad-4fbb-a31e-600532517943)时，例如添加、删除、缩进、取消缩进、排序。
* [在任务之间创建依赖关系](gcdocsite__documentlink?toc-item-id=254f4e99-02ad-4fbb-a31e-600532517943#%E9%93%BE%E6%8E%A5%E5%8F%96%E6%B6%88%E9%93%BE%E6%8E%A5%E4%BB%BB%E5%8A%A1)（前置任务或后续任务）时。

> **注意**：所有排程重新计算均从根节点开始。每个节点都有父子层级关系以及对前置任务 / 后续任务的依赖关系。

### 任务前置任务和后续任务

* **前置任务**：“前置任务” 字段列出了当前任务开始或结束之前必须完成的前置任务的任务 ID 号。每个前置任务通过特定类型的任务依赖关系以及提前或滞后时间与另一个任务相关联。
* **后续任务**：“后续任务” 字段与前置任务字段类似。唯一的区别是，“后续任务” 字段列出了在开始或结束之前依赖于当前任务完成的后续任务的任务 ID 号。
