# scroll

您可以按像素、按一刻度、按指定单位或按指定日期滚动甘特图时间刻度以及视口区域。
您可以使用 `timescale` 类的滚动方法启用水平或垂直方向的滚动。除了此方法之外，您还可以使用以下属性，这些属性会通过以下方式影响滚动行为。

## 按像素滚动时间刻度

您可以使用 `scroll(pixels)` 方法以像素为单位滚动时间刻度。时间刻度将滚动到最近的刻度。正像素将向前滚动，负像素将向后滚动。
以下代码示例演示如何在时间刻度中启用像素滚动。

```javascript
// Scroll timescale by pixel.
// To scroll forward.
var pixels = 50;
ganttSheet.project.timescale.scroll(pixels);
// To scroll backward.
var pixels = -50;ganttSheet.project.timescale.scroll(pixels);
```

## 将时间刻度滚动一刻度

您可以使用 `scrollOneTick()` 方法将时间刻度滚动一刻度。将值设置为“true”将向前滚动时间刻度，“false”将向后滚动。
以下代码示例展示了如何在时间刻度中启用一刻度滚动。

```javascript
// Scroll timescale by One Tick.
// To scroll forward.
ganttSheet.project.timescale.scrollOneTick(true);
// To scroll backward.
ganttSheet.project.timescale.scrollOneTick();
```

## 按指定单位滚动时间刻度

您可以使用 `scrollBy(count,unit)` 方法将时间刻度滚动指定的单位数。滚动单位是 `GC.Spread.Sheets.GanttSheet.TimescaleUnit` 类型参数，包含年、半年、季度、月、thirdsOfMonth、周、日、小时和分钟。
时间刻度将滚动到最近的刻度。正像素将向前滚动，负像素将向后滚动。
以下代码示例显示如何启用时间刻度中指定的单位滚动。

```javascript
// Scroll timescale by specified unit.
// To scroll 3 days forward.
var unit = GC.Spread.Sheets.GanttSheet.TimescaleUnit.days;
var count = 3;
ganttSheet.project.timescale.scrollBy(count, unit);
// To scroll 5 months backward.
var unit = GC.Spread.Sheets.GanttSheet.TimescaleUnit.months;
var count = -5;
ganttSheet.project.timescale.scrollBy(count, unit);
```

## 按指定日期滚动时间刻度

您可以使用 `scrollTo(date)` 方法将时间刻度滚动到指定日期。时间刻度将滚动到最近的刻度。
以下代码示例演示如何在时间刻度中按指定日期启用滚动。

```javascript
// Scroll timescale by specified date.
var date = new Date("2023/8/20");
ganttSheet.project.timescale.scrollTo(date);
```

您可以控制目标日期需要滚动的视口位置的百分比。默认百分比为 0，即滚动到视口左侧的目标日期。
以下代码示例显示如何启用滚动到视口中间的目标日期。

```javascript
// Scroll to the target date at the middle of viewport.
var date = new Date("2023/8/20");
var percentOfViewport = 0.1;
ganttSheet.project.timescale.scrollTo(date, percentOfViewport);
```
