# taskbar-style

在甘特图中，任务条样式对于可视化项目数据起着重要作用。通过更改任务条样式，你可以提高特定任务的清晰度和突出度。你可以使用指定的样式规则修改特定任务条的样式，然后该样式将应用于所有符合该规则的任务。在甘特图中，你可以使用 Spread 设计器用户界面中的“甘特图格式”>“格式”>“条形图样式”选项来自定义任务条的颜色、形状、末端类型、图案和文本。
![甘特图 - 条形图样式](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/GS-barstyles.548ee3.47f4ea.png)

> **注意**：只有在存在主键的情况下才能更改任务条样式。

## 内置任务条类型

任务条的类型基于其字段值。例如，如果你将一个普通任务的“模式”字段从“自动”更改为“手动”，该任务将变为手动调度任务，然后它将显示不同的样式以与其他普通任务条区分开来。
修改后的任务条样式始终对应于特定的任务条类型。下表列出了每种任务类型的规则名称。

| **名称** | **显示对象** | **起始位置** | **结束位置** |
| --- | ---- | ---- | ---- |
| task | 普通任务，非手动调度 | 任务开始 | 任务结束 |
| progress | 普通任务，非手动调度 | 任务开始 | 完成进度 |
| manualTask | 普通任务，手动调度 | 任务开始 | 任务结束 |
| manualProgress | 普通任务，手动调度 | 任务开始 | 完成进度 |
| milestone | 里程碑任务，非手动调度 | 任务结束 | 任务结束 |
| summary | 汇总任务，非手动调度 | 任务开始 | 任务结束 |
| manualSummary | 汇总任务，手动调度 | 任务开始 | 任务结束 |
| projectSummary | 项目汇总 | 任务开始 | 任务结束 |
| durationOnly | 活动任务，手动调度，但不是里程碑任务 | 任务开始 | 任务结束 |
| startOnly | 手动调度，非里程碑任务 | 任务开始 | 任务开始 |
| finishOnly | 手动调度，非里程碑任务 | 任务结束 | 任务结束 |
| manualMilestone | 里程碑任务，活动的，手动调度 | 任务结束 | 任务结束 |
| durationOnlyMilestone | 里程碑任务，手动调度 | 任务结束 | 任务结束 |
| startOnlyMilestone | 里程碑任务，手动调度 | 任务开始 | 任务开始 |
| finishOnlyMilestone | 里程碑，手动调度 | 任务结束 | 任务结束 |

## 获取内置样式规则

SpreadJS 根据 [GC.Spread.Sheets.GanttSheet.TaskbarStyleRuleName](gcdocsite__documentlink?toc-item-id=f3d567b2-6885-4950-a156-71d03a3e5d89#taskbarstylerulename) 类型为每种任务条类型提供了几个内置样式规则。每个任务条都有“起始”、“中间”和“结束”区域，可以独立进行自定义。任务条的起始和结束区域允许更改形状、类型和颜色，而中间区域的自定义选项包括形状、图案和颜色。此外，你还可以在任务条的不同侧面添加文本信息，如左侧、右侧、顶部、底部和内部。

##### 示例 1

以下代码示例展示了如何更改任务条起始区域的颜色，并为任务条添加左侧和顶部文本。这里使用了 [taskStyleRules](gcdocsite__documentlink?toc-item-id=25e3c2ac-ee4d-4e25-97fd-76eeddb8121d) 集合的 `getRule()` 方法来获取样式规则，然后使用修改后的样式对象更新目标样式规则的任务条样式。

```javascript
// 更改任务条起始区域的颜色。
var targetBuiltInStyleRuleName = "task";
var targetStyleRule = ganttSheet.project.taskStyleRules.getRule(targetBuiltInStyleRuleName);
var targetStyle = targetStyleRule.style.taskbarStyle;
targetStyle.startColor = "red";
targetStyleRule.style.taskbarStyle = targetStyle;
// 配置左侧文本和顶部文本。
var targetBuiltInStyleRuleName = "task";
var targetStyleRule = ganttSheet.project.taskStyleRules.getRule(targetBuiltInStyleRuleName);
var targetStyle = targetStyleRule.style.taskbarStyle;
targetStyle.leftText = "taskNumber";
targetStyle.topText = "=[@duration]";
targetStyleRule.style.taskbarStyle = targetStyle;
```

让我们再看一个示例，从项目中获取一个任务实例，然后使用 [GC.Spread.Sheets.GanttSheet.TaskbarStyle](gcdocsite__documentlink?toc-item-id=f3d567b2-6885-4950-a156-71d03a3e5d89#taskbarstyle) 类型通过一些特定字段更新任务条样式。

##### 示例 2

```javascript
// 获取任务的样式并更改其样式属性。
var task = ganttSheet.project.getTask(8);
console.log(task);
var newBarStyles = {};
newBarStyles["summary"] = {
      taskbarStyle: {
             startShape: "lineShape",
             startType: "solid",
             startColor: "Red",
             middlePattern: "diagonalLeft",
             middleShape: "rectangleBar",
             middleColor: "Yellow",
             endShape: "lineShape",
             endType: "solid",
             endColor: "Green",
             leftText: "taskNumber",
             bottomText: "duration",
             topText: '="Task Name: " & [@name]',
       }
}
task.style = newBarStyles;
var summaryTask = ganttSheet.project.getTask(4);
var summaryTaskStyles = {};
summaryTaskStyles["summary"] = {
        taskbarStyle: {
               startShape: "triangleRight",
               startType: "dashed",
               startColor: "#3a5823",
               middlePattern: "lineVertical",
               middleShape: "rectangleMiddle",
               middleColor: "#579863",
               endShape: "triangleLeft",
               endType: "dashed",
               endColor: "#3a5823",
               topText: "duration",
        }
}
summaryTask.style = summaryTaskStyles;
```

## 创建自定义样式规则

SpreadJS 还允许你基于 [GC.Spread.Sheets.GanttSheet.TaskbarStyleRule](gcdocsite__documentlink?toc-item-id=a1deee47-e1a5-48d4-bdec-c68f012b5de5) 类创建自定义样式规则。一旦创建，任务条样式规则将更改符合该规则的任务的样式。

```javascript
// 创建新的自定义样式规则。
var ruleName = "My Progress";
class MyProgressRule extends GC.Spread.Sheets.GnattSheet.TaskBarStyleRule {
    constructor() {
        super(ruleName);
        this.style = {
            taskbarStyle: {
                middleColor: "#3B87D4",
                middleShape: "rectangleMiddle",
                middlePattern: "solidFill"
            }
        };
    }
    match(task: GC.Spread.Sheet.GanttSheet.Task): boolean {
        return task.complete > 0;
    }
    getFromDate(task: GC.Spread.Sheet.GanttSheet.Task) {
        return task.startDisplayed;
    }
    getToDate(task: GC.Spread.Sheet.GanttSheet.Task) {
        return task.completeThrough;
    }
}
// 将自定义样式规则添加到任务条样式规则集合中。
var styleRules = ganttSheet.project.taskStyleRules;
var customStyleRule = new MyProgressRule();
styleRules.add(customStyleRule);
// 更新现有的自定义样式规则。
var ruleName = "My Progress";
var styleRules = ganttSheet.project.taskStyleRules;
var customStyleRule = styleRules.getRule(ruleName);
if (customStyleRule) {
    var style = customStyleRule.style.taskbarStyle;
    // 更新样式。
    style.middleColor = "red";
    // 更改样式。
    customStyleRule.style.taskbarStyle = style;
}
```

## 删除自定义样式规则

除了添加或更新任务条样式规则的样式外，你还可以使用 [GC.Spread.Sheets.GanttSheet.Project](gcdocsite__documentlink?toc-item-id=dd6f4979-2a14-4231-99d3-8b4bba79d476#taskstylerules) 类的 `TaskStyleRules` 集合的 `remove()` 和 `clear()` 方法来删除或清除规则。
