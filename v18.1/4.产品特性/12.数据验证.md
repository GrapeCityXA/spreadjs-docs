# datavalidate

SpreadJS 允许用户创建验证器，以便验证输入的数据并限制无效信息。您可以为用户显示有效值列表，并且一旦用户在单元格中输入无效数据，就会显示无效数据标识。
您可以通过以下方式验证在工作表中输入的信息：

## 使用不同类型的数据验证

SpreadJS 支持以下类型的数据验证：

### 日期验证

[createDateValidator ](https://docs.grapecity.com.cn/spreadjs/help/api//modules/GC.Spread.Sheets.DataValidation#createdatevalidator)方法可用于验证单元格的特定日期条件。
日期验证可限制用户在电子表格中输入无效的日期信息（即不符合特定单元格指定日期条件的信息）。例如，假设您创建一个日期验证器，允许用户输入 2017 年 12 月 31 日至 2018 年 12 月 31 日之间的任何日期。任何超出此范围的日期输入都将被视为无效数据输入。
以下代码示例创建了一个日期验证器：

```javascript
spread.options.highlightInvalidData = true;
var dv = GC.Spread.Sheets.DataValidation.createDateValidator(GC.Spread.Sheets.ConditionalFormatting.ComparisonOperators.between, new Date(2017, 12, 31), new Date(2018, 12, 31));
dv.showInputMessage(true);
dv.inputMessage("Enter a date between 12/31/2017 and 12/31/2018.");
dv.inputTitle("Tip");
activeSheet.setDataValidator(1, 1, 1, 1, dv, GC.Spread.Sheets.SheetArea.viewport);
```

### 公式验证

[createFormulaValidator](https://demo.grapecity.com.cn/spreadjs/help/api//modules/GC.Spread.Sheets.DataValidation#createformulavalidator) 方法可用于验证在单元格中输入的公式。
以下代码示例创建了一个公式验证器：

```javascript
spread.options.highlightInvalidData = true;
//如果公式条件返回 true，则公式验证器有效。
var dv = GC.Spread.Sheets.DataValidation.createFormulaValidator("A1>0");
dv.showInputMessage(true);
dv.inputMessage("Enter a value greater than 0 in A1.");
dv.inputTitle("Tip");
activeSheet.setDataValidator(0, 0, 1, 1, dv, GC.Spread.Sheets.SheetArea.viewport);
```

### 公式列表验证

[createFormulaListValidator ](https://docs.grapecity.com.cn/spreadjs/help/api//modules/GC.Spread.Sheets.DataValidation#createformulalistvalidator)方法可用于验证电子表格中的公式列表。公式列表验证器使用一系列单元格来创建有效值列表。
如果公式条件返回 true，则公式验证器有效。当应用的单元格值无效时，会触发 [ValidationError ](https://docs.grapecity.com.cn/spreadjs/help/api//classes/GC.Spread.Sheets.Events#validationerror)事件。
以下代码示例根据公式指定的一系列单元格创建了一个有效值列表：

```javascript
activeSheet.setValue(0, 2, 5);
activeSheet.setValue(1, 2, 4);
activeSheet.setValue(2, 2, 5);
spread.options.highlightInvalidData = true;
var dv = GC.Spread.Sheets.DataValidation.createFormulaListValidator("$C$1:$C$3");
dv.showInputMessage(true);
dv.inputMessage("Pick a value from the list.");
dv.inputTitle("tip");
activeSheet.setDataValidator(1, 1, 1, 1, dv, GC.Spread.Sheets.SheetArea.viewport);
var validList = activeSheet.getDataValidator(1, 1).getValidList(sheet, 1, 1);
```

### 列表验证

[createListValidator ](https://docs.grapecity.com.cn/spreadjs/help/api//modules/GC.Spread.Sheets.DataValidation#createlistvalidator)方法基于列表创建一个验证器。
以下代码示例创建了一个有效值列表，显示输入提示，并且如果输入了不正确的值，则显示无效数据标识：

```javascript
spread.options.highlightInvalidData = true;
var dv = GC.Spread.Sheets.DataValidation.createListValidator("1,2,3");
dv.showInputMessage(true);
dv.inputMessage("Value must be 1,2 or 3");
dv.inputTitle("tip");
activeSheet.setDataValidator(1,1,1,1,dv,GC.Spread.Sheets.SheetArea.viewport);
alert(activeSheet.getDataValidator(1,1).getValidList(activeSheet,1,1));
```

SpreadJS 还支持为列表中的每个段落插入逗号（通过转义字符），如下图所示。单元格 B2 表示一个数字列表，单元格 D2 表示一个运算符列表。
![data-valid-separator](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/data-valid-separator.88466b.png)
以下代码示例展示了使用两个不同列表的列表验证 - 一个是数字列表，另一个是用逗号分隔的运算符列表。不同单元格（B2 和 D2）中的两个列表验证条件限制用户在输入数据时从下拉列表中列出的值中进行选择：

```javascript
// 设置列宽
sheet.setColumnWidth(0, 200.0, GC.Spread.Sheets.SheetArea.viewport);
sheet.setColumnWidth(1, 120.0, GC.Spread.Sheets.SheetArea.viewport);
sheet.setColumnWidth(2, 200.0, GC.Spread.Sheets.SheetArea.viewport);
sheet.setColumnWidth(3, 120.0, GC.Spread.Sheets.SheetArea.viewport);
// 在验证列表中使用逗号
var dv1 = new GC.Spread.Sheets.DataValidation.createListValidator("123\\,456,234\\,567,789\\,564");
sheet.setText(1, 0, "Choose a number from cell B2");
dv1.inputTitle("Please choose a number:");
dv1.inputMessage("Number of money");
sheet.setDataValidator(1, 1, dv1);
var dv2 = new GC.Spread.Sheets.DataValidation.createListValidator("\\,,>,<,*,/");
sheet.setText(1, 2, "Choose an operator from cell D2");
dv2.inputTitle("Please choose an operator:");
dv2.inputMessage("operator of calculator");
sheet.setDataValidator(1, 3, dv2);
```

### 数字验证

[createNumberValidator ](https://docs.grapecity.com.cn/spreadjs/help/api//modules/GC.Spread.Sheets.DataValidation#createnumbervalidator)方法可用于验证在单元格中输入的数字。
数字验证可限制用户输入超出为该单元格指定的验证条件的数值。
以下代码示例使用一个数字验证器，显示输入提示，并且如果输入了不正确的值，则显示无效数据标识：

```javascript
spread.options.highlightInvalidData = true;
var dv = GC.Spread.Sheets.DataValidation.createNumberValidator(GC.Spread.Sheets.ConditionalFormatting.ComparisonOperators.between, "5", "20", true);
dv.showInputMessage(true);
dv.inputMessage("Value must be between 5 and 20.");
dv.inputTitle("tip");
activeSheet.setDataValidator(1, 1, 1, 1, dv, GC.Spread.Sheets.SheetArea.viewport);
```

### 文本长度验证

[createTextLengthValidator ](https://docs.grapecity.com.cn/spreadjs/help/api//modules/GC.Spread.Sheets.DataValidation#createtextlengthvalidator)方法可用于验证在单元格中输入的文本长度。
您可以使用文本长度验证来限制在单元格中输入的字符数量。
以下代码示例使用一个文本验证器，显示输入提示，并且如果输入了不正确的值，则显示无效数据标识：

```javascript
spread.options.highlightInvalidData = true;
var dv = GC.Spread.Sheets.DataValidation.createTextLengthValidator(GC.Spread.Sheets.ConditionalFormatting.ComparisonOperators.greaterThan, "4", "20");
dv.showInputMessage(true);
dv.inputMessage("Number of characters must be greater than 4.");
dv.inputTitle("tip");
activeSheet.setDataValidator(1, 1, 1, 1, dv, GC.Spread.Sheets.SheetArea.viewport);
```

## 使用不同的高亮样式进行数据验证

您可以使用不同的高亮样式来指示单元格中的无效信息，这些样式包括高亮类型、位置、颜色和标识图像。SpreadJS 支持三种不同的高亮类型（圆圈、折角和图标）以及六种不同的高亮位置（`topLeft`、`topRight`、`bottomRight`、`bottomLeft`、`outsideLeft` 和 `outsideRight`），以便用户在电子表格中指示无效数据。默认情况下，高亮类型为 “圆圈”，高亮位置为 `topRight`，高亮颜色为 “红色”。对于图标高亮样式中的图像，您可以指定图像 URL 或图像的 base64 数据。
除了不同的高亮样式外，您还可以为用户显示输入提示，并显示一个下拉按钮，该按钮显示有效值列表，如下图所示：
![invalidtip](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/invalidtip.0bf1e7.png)

![invaliddrop](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/invaliddrop.740b50.png)
必须将 `highlightInvalidData` 属性设置为 true 才能高亮显示无效信息。**highlightStyle** 方法可用于控制高亮显示的错误的样式，每种类型都有不同的样式属性。
在下面所示的图像中，单元格 B2 中的高亮类型表示圆圈样式，单元格 D2 表示折角样式，单元格 F2 表示图标样式。此外，单元格 D2 的高亮位置设置为 `topLeft`，单元格 F2 的高亮位置设置为 `outsideLeft`。
![data-valid](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/data-valid.f60270.png)
