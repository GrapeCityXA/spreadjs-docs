# sjsaitextsentiment

## 总结

**SJS.AI.TEXTSENTIMENT** 是 SpreadJS 中的一个动态数组函数，用于分析单元格中文本的情感倾向，并返回**积极**、**消极**或**中性**的结果。
此功能适用于以下场景：

* 客户评价分析
* 社交媒体情感监测
* 产品反馈分类
* 其他文本情感分析场景

## 语法

```javascript
=SJS.AI.TEXTSENTIMENT(array, positive, negative, [neutral])
```

## **参数**

| 参数 | 描述 |
| --- | --- |
| **array**<br>必需 | 输入文本或包含待分析文本的单元格引用（例如 `B2:B9`）。 |
| **positive**<br>必需 | 若情感倾向为**积极**时返回的值。 |
| **negative**<br>必需 | 若情感倾向为**消极**时返回的值。 |
| **neutral**<br>可选 | 若情感倾向为**中性**时返回的值。若省略该参数，可能返回空白。 |

**备注**：

* SJS.AI.TEXTSENTIMENT 是一个异步公式，在分析过程中会返回 #BUSY!。
* SJS.AI.TEXTSENTIMENT 是一个动态数组公式，你需要在工作簿中启用动态数组功能。

## 示例

假设 `B2:B4` 单元格中包含客户评价，我们希望将其分类为**好评**、**差评**或**中评**。

```bash
=SJS.AI.TEXTSENTIMENT(B2:B4, "好评", "差评", "中评")
```
