# drag-row-and-column-header

使用 SpreadJS，您可以在 MouseDown 事件中通过拖动标题来移动和插入列和行，这需要使用 allowDragHeaderToMove 枚举选项，其默认值为 none。该枚举接受四个值，如下表所述：

| 枚举类型 | 值 | 描述 |
| ---- | --- | --- |
| none | 0 | 指定行或列标题不能被拖动移动。 |
| column | 1 | 指定只能拖动列标题进行移动。 |
| row | 2 | 指定只能拖动行标题进行移动。 |
| both | 3 | 指定可以拖动列和行标题进行移动。 |

当鼠标悬停在可拖动的标题上时，光标会变成抓手形状，表示可以进行拖动操作。当开始拖动时，光标会变成抓取手形状。

### 代码示例

参考以下代码，当 `allowDragHeaderToMove` 枚举设置为 `both` 时，可以拖动列和行：

```javascript
let dragcolumrowheader = spread.options.allowDragHeaderToMove.both;
```

### 使用 Designer

您还可以通过在 Spread 设置对话框中的拖动标题以移动下拉列表中选择所需的枚举值，使用 SpreadJS Designer 启用此功能。

### **限制**

* TableSheet、GanttSheet 和触摸手势不支持拖动标题来移动行和列
