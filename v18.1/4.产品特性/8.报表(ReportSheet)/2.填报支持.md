# data-entry-support

报表插件通过 DataManager 支持数据输入。用户需要在 DataManager 中配置数据源，并在报表模板的数据输入设置中进行设置。
报表插件在`ReportSheet`类中提供了一组数据输入方法，以执行各种报告数据操作。

* `addRecordAt()`：根据指定单元格添加记录。
* `deleteRecordAt()`：根据指定单元格删除记录。
* `updateCellValue()`：用新值更新指定单元格的值。
* `submit()`：根据 DataManager 的数据输入设置，将更改提交到远程数据库。

注意，如果一次提交中提交了多条记录，保存在数据库中的记录顺序可能会改变。
您可以使用以下代码示例来设置数据输入方法。

```javascript
// Add record.
reportSheet.addRecordAt(1, 2);
// Update cell value.
reportSheet.updateCellValue(2, 2, 'test');
// Delete record.
reportSheet.deleteRecordAt(4, 5);
// Submit changes.
reportSheet.submit();
```

SpreadJS也允许您使用设计器中上下文菜单中的添加记录、删除记录和提交选项来添加、删除和提交数据录入记录。

此外，报表插件允许在数据输入预览中自定义脏单元格的样式。
如果在预览中修改了单元格值，将以应用的脏样式显示。报表表格将脏单元格的默认样式设置为红色角折叠。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca82939a-5d1a-4838-9f3f-69a0f7ebeeb5/image.a69841.png)
您可以使用`IReportOptions`接口的`dirtyStyle`选项来自定义脏单元格的样式。
以下代码示例设置了红色背景以表示报告中的脏单元格。

```javascript
// Create a style.
const style = new GC.Spread.Sheets.Style();
style.backColor = 'red';
reportSheet.options.dirtyStyle = style;
reportSheet.refresh();
```
