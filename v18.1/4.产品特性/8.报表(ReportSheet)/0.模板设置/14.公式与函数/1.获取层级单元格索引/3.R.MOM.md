# rmom

这个功能用于获取环比增长率。

## 语法

`R.YOY(ValueCell, ContextCell1, [ContextCell2])`

## 参数

此函数具有以下参数：

| **参数** | **描述** |
| --- | --- |
| *cell* | [必需] 指定您想要获取环比增长率的值单元格。 |
| *ContextCell1* | [可选] 指定上下文单元格1，通常是年份单元格。<br>示例：<br>如果 A2 单元格绑定到年份列，B2 单元格绑定到月份列，C2 单元格绑定到销售额列，那么 R.YOY(C2, A2) 将返回年度环比增长率。 |
| *ContextCell2* | [可选] 指定上下文单元格2。<br>如果值单元格是交叉单元格，您需要指定上下文单元格2。 |
