# expansion-direction

扩展方向是指数据从一个单元格自动溢出到相邻单元格，并根据需要扩展以容纳结果。
通过在 `setTemplateCell` 方法中设置 `spillDirection` 属性的值，您可以控制数据如何溢出到报表中的单元格。
SpreadJS 支持以下 `spillDirection` 属性值：`Vertical`（默认值）、`Horizo​​ntal` 和 `None`。

设置报表模板中扩展方向的步骤：

1. 在 DataManager 中定义表格源。
2. 在模板单元格中配置类型和绑定选项。
3. 在模板单元格中设置`spillDirection`属性值。

以下代码示例展示了如何为单元格设置不同的扩展方向。

```javascript
// Vertical Spill Direction
const columns = ['customerId'];
columns.forEach((columnName, i) => {
    templateSheet.setValue(0, i, `${columnName[0].toUpperCase()}${columnName.substring(1)}`);
    templateSheet.setTemplateCell(1, 0, {
        type: 'Group',
        binding: `Orders[CustomerId]`,
        spillDirection: 'Vertical',
    });
});

// Horizontal Spill Direction
const columns = ['customerId'];
columns.forEach((columnName, i) => {
    templateSheet.setValue(0, i, `${columnName[0].toUpperCase()}${columnName.substring(1)}`);
    templateSheet.setTemplateCell(1, 0, {
        type: 'Group',
        binding: `Orders[CustomerId]`,
        spillDirection: 'Horizontal',
    });
});

// No Spill Direction
const columns = ['customerId'];
columns.forEach((columnName, i) => {
    templateSheet.setValue(0, i, `${columnName[0].toUpperCase()}${columnName.substring(1)}`);
    templateSheet.setTemplateCell(1, 0, {
        type: 'Group',
        binding: `Orders[CustomerId]`,
        spillDirection: 'None',
    });
});
```
