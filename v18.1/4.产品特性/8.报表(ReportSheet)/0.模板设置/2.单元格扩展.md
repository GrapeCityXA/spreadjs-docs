# cell-expansion

如果一个单元格的溢出方向不是“无”，则静态单元格将在同一行中扩展。您可以使用 autoExpand 属性来控制单元格是否可以扩展。
这个 autoExpand 设置适用于静态单元格、列表单元格、分组单元格和汇总单元格。
您必须在 setTemplateCell 方法中配置 autoExpand 属性，以配置 TemplateSheet 中的扩展。
autoExpand 设置有不同的值，例如：

* 水平：单元格只扩展列数，保持与模板单元格相同的行数。
* 垂直：单元格只扩展行数，保持与模板单元格相同的列数。
* 无：单元格保持与模板单元格相同的行列数。

默认情况下，报表模板中启用了水平和垂直扩展。
以下代码示例展示了如何设置不同的单元格 autoExpand 设置。

```javascript
// Set the cell autoExpand as None.
templateSheet.setTemplateCell(0, 0, {
    autoExpand: 'None',
});

// Set the cell autoExpand as Horizontal.
templateSheet.setTemplateCell(0, 0, {
    autoExpand: 'Horizontal',
});

// Set the cell autoExpand as Vertical.
templateSheet.setTemplateCell(0, 0, {
    autoExpand: 'Vertical',
});
```
