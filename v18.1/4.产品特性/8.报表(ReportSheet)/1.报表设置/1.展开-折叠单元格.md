# expandcollapse-cells

SpreadJS 通过控制报表工作表（ReportSheet）内单元格的展开与折叠，提升了报表管理功能。除了依据特定输入来切换单个单元格的展开或折叠状态外，用户还能够折叠或展开与特定父单元格或模板单元格相关联的所有单元格。
为了简化分层数据管理，SpreadJS 提供了 ReportSheet 类的 `toggleCollapseState` 方法。该方法允许用户通过一次操作，折叠或展开特定父单元格的所有子单元格。
以下示例代码展示了如何使用 `toggleCollapseState` 方法，来切换特定单元格所有子单元格的折叠或展开状态。

```javascript
// Specify the cell.
var regionCells = reportSheet.getCells(2, 0);
var secondRegionCell = regionCells[1];

// Get Collapsed State
var isCollapsed = reportSheet.getCollapseState(secondRegionCell.row, secondRegionCell.col);

// Toggle the Collapsed State
var newCollapsedState = isCollapsed ? "Expanded" : "Collapsed";

// Toggle All Its Descendents Cells
reportSheet.toggleCollapseState(secondRegionCell.row, secondRegionCell.col, newCollapsedState, true);
```

## 使用设计器

若要管理特定父单元格下所有子单元格的展开与折叠，请遵循以下步骤：

1. 选择你希望展开或折叠其子单元格的目标分组单元格。
    ![expand-all-1.b9ee2e](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/expand-all-1.b9ee2e.ae69b2.png)
2. 右键单击指定单元格，打开上下文菜单，然后根据需求选择 “全部折叠” 或 “全部展开”。
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.2c15ac.png)
