# grouping

SpreadJS 提供了根据标题将行或列分组显示为分级显示（大纲）的功能。这会在标题之外创建一个单独的区域，其中包含用于展开或折叠行或列级别的分级显示。
“级别编号”按钮会显示分级显示存在的级别数。可以使用“级别编号”按钮或展开或折叠图标来展开或折叠组。
![rangegroup](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/rangegroup.9a9391.png)
可以通过使用不同的 CSS 类来修改区域组的外观。有关更多信息，请参阅 [自定义区域分组](gcdocsite__documentlink?toc-item-id=c2afd69d-fa06-490f-b200-7aef1c90ef67)。

## 创建行或列组

**Outline** 类的 [group ](gcdocsite__documentlink?toc-item-id=1037e6f8-da75-44ce-90d9-7ffa12133618#group)方法可用于创建区域组，而 [unGroup ](gcdocsite__documentlink?toc-item-id=1037e6f8-da75-44ce-90d9-7ffa12133618#ungroup)方法可用于移除区域组。下图展示了一个行组和列组。
![cgroup](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/cgroup.8b8cdb.png)
请参考以下示例代码来创建行组和列组。

```javascript
activeSheet.setRowCount(34);
// 设置单元格值
activeSheet.setValue(0,0,"Product");
activeSheet.setValue(0,1,"2019 in Sales");
activeSheet.setValue(0,2,"2020 in Sales");
activeSheet.setValue(1,0,"Mobiles");
activeSheet.setValue(1,1,"350,000");
activeSheet.setValue(1,2,"500,000");
activeSheet.setValue(2,0,"Laptops");
activeSheet.setValue(2,1,"200,000");
activeSheet.setValue(2,2,"400,000");
// 设置行组和列组
activeSheet.rowOutlines.group(1,2);
activeSheet.columnOutlines.group(1,2);
//activeSheet.rowOutlines.expand(0,false);
//activeSheet.columnOutlines.expand(0,false);
spread.invalidateLayout();
spread.repaint();
```

或者，你可以指定命令 **outlineRow** 或 **outlineColumn**，并使用 [execute ](gcdocsite__documentlink?toc-item-id=471e9c45-6625-4afa-86f9-8d4ce6b69103#execute)方法来创建行组或列组。

```javascript
var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
var activeSheet = spread.getActiveSheet();
spread.commandManager().execute({cmd: "outlineRow", sheetName: activeSheet.name(), index: 4, count: 3}); // 指定操作并使用 execute 方法
```

> **注意**：大纲列功能还可用于在电子表格中创建树状结构，以便更好地组织数据。有关更多信息，请参阅 [大纲列](gcdocsite__documentlink?toc-item-id=3041367e-17ff-4573-9835-220b2bc3eefb)。

## 设置组方向

你可以使用 `direction` 选项中的 `OutlineDirection` 枚举将区域组的方向指定为向前或向后。

| **向前方向** | **向后方向** |
| ---- | ---- |
| ![rangegroup-forward-direction](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/rangegroup-forward-direction.b81b18.gif) | ![rangegroup-backward-direction](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/rangegroup-backward-direction.fd4704.gif) |

以下代码示例展示了如何设置行组和列组的方向。

```javascript
activeSheet.rowOutlines.group(1,2);
activeSheet.columnOutlines.group(1,2);
activeSheet.rowOutlines.direction(GC.Spread.Sheets.Outlines.OutlineDirection.backward);
activeSheet.columnOutlines.direction(GC.Spread.Sheets.Outlines.OutlineDirection.forward);
spread.invalidateLayout();
spread.repaint();
```

## 查找并折叠组

你可以使用 `OutlineState` 选项来查找并折叠或展开一个组。

```javascript
activeSheet.rowOutlines.group(0,5);
var rgi = activeSheet.rowOutlines.find(1, 0);
rgi.state(GC.Spread.Sheets.Outlines.OutlineState.collapsed); // 查找并折叠一个组
spread.invalidateLayout();
spread.repaint();
```

## 在工作表中显示分级显示

你可以使用 **showRowOutline** 和 **showColumnOutline** 方法来指定是否显示行分级显示和列分级显示。如果未设置值，这些方法会返回布尔值以指示是否显示分级显示。

```javascript
// 设置 showRowOutline 和 showColumnOutline activeSheet.showRowOutline(true);
activeSheet.rowOutlines.group(0, 2);
activeSheet.showColumnOutline(true);
activeSheet.columnOutlines.group(0, 2);
//activeSheet.rowOutlines.ungroup(0, 2);
//activeSheet.columnOutlines.ungroup(0, 2);
spread.invalidateLayout();
spread.repaint();
```
