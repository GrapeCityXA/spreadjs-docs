# custom-pivot-table-styles

SpreadJS 允许您通过添加、删除和修改表格样式来管理自定义数据透视表主题，然后将这些样式应用于您的数据透视表。要应用这些样式，您只需为数据透视表设置一个样式名称
您可以使用 `GC.Spread.Sheets.WorkBook` 类的 `customPivotTableThemes` 属性来自定义数据透视表样式
`CustomPivotTableThemesManager` 类提供了以下方法来管理自定义数据透视表主题：

* `all`: 获取所有自定义数据透视表主题
* `get`: 通过名称获取特定的自定义数据透视表主题
* `add`: 使用样式对象或名称添加新的自定义数据透视表主题
* `remove`: 通过名称删除自定义数据透视表主题
* `update`: 通过名称或样式对象更新现有的自定义数据透视表主题

此外，`GC.Spread.Sheets.WorkBook` 类的 `defaultPivotTableTheme` 方法允许您有效地管理默认的数据透视表样式，以确保所有数据透视表具有一致的外观和感觉

> type=warning
> 注意事项：
>
> * 数据透视表样式名称必须唯一
> * 例如，如果您已经有一个名为 "TEST" 的自定义数据透视表样式，则不能创建另一个具有相同名称的数据透视表样式
> * 数据透视表样式名称不区分大小写
> * 当将样式名称添加到数据透视表时，它会通过名称查找样式
> * 如果样式名称匹配内部样式，它将直接应用。如果不匹配，它将搜索 customStyles 集合中的相应样式。如果找到，将应用该样式，否则将使用默认样式
> * defaultPivotTableTheme 应该是表示数据透视表样式名称的字符串
> * 如果创建数据透视表时未明确指定样式，并且存在具有此默认名称的样式，则该样式将应用于该数据透视表
> * 自定义数据透视表主题不支持旧版本的 Excel IO

## 使用代码

以下代码示例演示了管理自定义数据透视表主题的不同方法
添加新的数据透视表主题：

```javascript
const spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));

// 添加一个名为 "custom0" 的新数据透视表主题
const pivotTableStyle = spread.customPivotTableThemes.add("custom0");
const firstColumnStripeStyle = new GC.Spread.Pivot.PivotTableStyle();
firstColumnStripeStyle.backColor = "skyblue";
pivotTableStyle.firstColumnStripeStyle(firstColumnStripeStyle);
```

获取数据透视表主题：

```javascript
// 获取数据透视表主题
const pivotTableStyle = spread.customPivotTableThemes.get("custom0");
```

应用数据透视表主题：

```javascript
// 创建数据透视表
const sourceData = [
    ['Date', 'Buyer', 'Type', 'Amount'],
    ['01-Jan', 'Mimi', 'Fuel', 74],
    ['15-Jan', 'Mary', 'Food', 235],
    ['17-Jan', 'Denny', 'Sports', 20],
    ['21-Jan', 'Kelly', 'Books', 125],
];
activeSheet.setArray(0, 0, sourceData);
activeSheet.tables.add('sourceData', 0, 0, 5, 4);

// 设置数据透视表主题
const pivotTable = activeSheet.pivotTables.add('pivottable1', 'sourceData', 1, 1, GC.Spread.Pivot.PivotTableLayoutType.compact, GC.Spread.Pivot.PivotTableThemes.medium2);

// 将样式应用于数据透视表
pivotTable.theme('custom0');
```

修改数据透视表主题：
当您对现有的数据透视表样式进行更改时，它会自动更新所有之前应用了该样式的表格

```javascript
// 修改数据透视表主题
const pivotTableStyle = spread.customPivotTableThemes.get("custom0");
pivotTableStyle.firstColumnStripeStyle().backColor = "red";

// 更新数据透视表主题
spread.customPivotTableThemes.update("custom0", new GC.Spread.Pivot.PivotTableTheme());
```

删除现有主题：
当您删除自定义数据透视表样式时，所有使用该已删除样式的表格将切换到默认样式

```javascript
// 删除数据透视表主题
spread.customPivotTableThemes.remove("custom0");
```

设置默认主题：

```javascript
// 设置默认数据透视表主题
spread.defaultPivotTableTheme("custom0");
```

## 使用 Designer

您还可以使用 SpreadJS Designer 组件通过以下步骤格式化自定义数据透视表样式：

1. 单击 DESIGN > PivotTable Styles 组中的 PivotTableStyles 按钮
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.88cf95.png?width=600)
2. 单击下拉箭头并选择 "New Pivot Table Style.." 选项，通过设置所需的样式元素来添加新的数据透视表样式
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.7bf3fb.png?width=600)
3. 所有用户创建的数据透视表样式显示在数据透视表样式集合列表的 Custom 部分下
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.c13bb6.png?width=300)
4. 右键单击自定义数据透视表样式，并根据需要执行应用、修改、复制、删除和设置为默认等操作
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.af3f90.png?width=200)

> type=warning
> 注意：您不能修改或删除内置的数据透视表样式
