# filter-pt

你可以对数据透视表应用特定筛选器，仅查看所需信息，同时隐藏其余数据。

## 行和列字段筛选

当需要对行或列的数据进行筛选时，可以应用行和列字段筛选。以下图片展示了应用于数据透视表的筛选器，以仅显示东部地区的数量。
![rowfilter.ffa400](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/rowfilter.ffa400.56cdde.png)
以下代码示例展示了如何筛选“地区”列，仅显示东部地区的数据。

```javascript
// 添加筛选字段
myPivotTable.add("OrderDate", "OrderDate", GC.Spread.Pivot.PivotTableFieldType.filterField);
let itemList = ["East"];
myPivotTable.labelFilter("Region", { textItem: { list: itemList, isAll: false } });
```

## 值筛选

值筛选可用于根据汇总值（如总和、计数、最大值、最小值、平均值等）筛选数据透视表中基于值的字段。以下图片展示了应用于数据透视表的值筛选，以显示“类别”列中“数量总和”大于2000的数据。
![valuefilter.1be9cf](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/valuefilter.1be9cf.d29e83.png)
以下代码示例展示了如何应用值筛选，以显示“数量总和”大于2000的数据。

```javascript
// 添加筛选字段
myPivotTable.add("OrderDate", "OrderDate", GC.Spread.Pivot.PivotTableFieldType.filterField);
// 使用FilterInfo应用“数量总和”大于2000的值筛选
let valueFilter = { condition: { conType: GC.Pivot.PivotConditionType.value, val: [2000], operator: 2 }, conditionByName: "Sum of quantity" };
myPivotTable.valueFilter("Category", valueFilter);
```

## 标签筛选

标签筛选可用于筛选行标签项。它根据要筛选字段的数据类型提供不同选项。例如，对于字符串或数字数据类型，提供的选项有等于、不等于、以……开头、包含、大于等；而对于日期数据类型，提供的选项有之前、之后、明天、下周等。以下示例展示了如何对“地区”列字段应用标签筛选，以显示以“S”开头的城市。
![labelfilter.261e08](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/labelfilter.261e08.126bf8.png)
以下代码示例展示了如何对以“S”开头的城市应用标签筛选。

```javascript
// 添加筛选字段
myPivotTable.add("OrderDate", "OrderDate", GC.Spread.Pivot.PivotTableFieldType.filterField);
// 使用FilterInfo对以“S”开头的“城市”名称应用标签筛选
let labelFilter = { condition: { conType: GC.Pivot.PivotConditionType.caption, val: 'S', operator: 2 } };
myPivotTable.labelFilter("City", labelFilter);
```

你也可以使用手动筛选来代替为标签筛选定义条件。以下图片展示了应用手动筛选以显示“泽西”和“西雅图”城市的数据。
![manual-filter.71e1c7](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/manual-filter.71e1c7.600790.png)
以下代码示例展示了如何应用手动筛选。

```javascript
// 添加手动筛选
let parent = { textItem: { list: ["Jersey", "Seattle"], isAll: false } };
myPivotTable.labelFilter("City", parent);
```

你还可以通过将`allowMultipleFiltersPerField`选项设置为`true`，选择同时应用手动筛选和基于条件的标签筛选。以下示例展示了如何在数据透视表中应用多个筛选器。
![multiple-filter.d27e93](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/multiple-filter.d27e93.5f4974.png)
以下代码示例展示了如何在数据透视表中应用多个筛选器。

```javascript
myPivotTable.options.allowMultipleFiltersPerField = true;
// 当allowMultipleFiltersPerField设置后，两个筛选器即都生效
var labelFilter = {
    textItem: { list: ['Jersey', 'San Francisco'], isAll: false },
    condition: { conType: GC.Pivot.PivotConditionType.caption, operator: GC.Pivot.PivotCaptionFilterOperator.beginsWith, val: 'S' },
};
myPivotTable.labelFilter('City', labelFilter);
```

## 日期类型筛选

日期类型筛选可用于指定应用于数据透视表中日期类型项的条件。以下图片展示了应用于数据透视表的日期类型筛选，以显示季度数据。
![datetypefilter.d06639](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/datetypefilter.d06639.ac895e.png)
以下代码示例展示了如何应用日期类型筛选。

```javascript
let groupInfo = {
    originFieldName: 'OrderDate',
    dateGroups: [{ by: GC.Pivot.DateGroupType.quarters }, { by: GC.Pivot.DateGroupType.years }],
};
myPivotTable.group(groupInfo);
myPivotTable.add('OrderDate', 'Qtr', GC.Spread.Pivot.PivotTableFieldType.columnField);
// 使用FilterInfo应用标签筛选
let labelFilter = { condition: { conType: GC.Pivot.PivotConditionType.date, val: [], operator: GC.Pivot.PivotDateFilterOperator.Q1 } };
myPivotTable.labelFilter('Qtr', labelFilter);
```

你还可以使用以下内置的日期到日期筛选器：

* 季度至今（QTD）：从当前季度开始到当前日期结束的时间段。
* 月度至今（MTD）：从当前日历月开始到当前日期结束的时间段。
* 年度至今（YTD）：从当前年份开始到当前日期结束的时间段。

除上述选项外，你可以通过将`isParallel`属性设置为`true`来使用并行日期筛选。并行日期筛选允许你获取与实际时间段对应的上一个或下一个日期（取决于数据透视表中的数据）的相同时间段。例如，假设今天是2021年11月23日，数据透视表包含从2021年9月1日到2021年12月31日的数据。

* 月度至今筛选：2021年11月1日 - 2021年11月23日
* 并行月度至今筛选：
    * 2021年9月1日 - 2021年9月23日
    * 2021年10月1日 - 2021年10月23日
    * 2021年11月1日 - 2021年11月23日
    * 2021年12月1日 - 2021年12月23日

以下代码示例展示了如何应用日期到日期筛选。

```javascript
function DateToDateFilter() {
    var condition = {
        conType: GC.Pivot.PivotConditionType.month,
        operator: GC.Pivot.PivotDateFilterOperator.dateToDate,
        val: [new Date(2021, 7, 15), new Date(2022, 6, 20)],
        isParallel: false,
        isDynamicEndDate: true,
        by: GC.Pivot.PivotAdvancedDateFilterBy.month,
    };
    var filterInfo = {
        condition,
    };
    myPivotTable.labelFilter('OrderDate', filterInfo);
}
```

## 创建筛选信息

上述筛选器是通过创建筛选信息来应用的。以下表格描述了可用于创建筛选信息的条件：

| **条件** | **conType** | **operator** | **val** | **conditionByname** | **type** | **isWholeDay** |
| --- | ------- | -------- | --- | --------------- | ---- | ---------- |
| GC.Pivot.IPivotCaptionConditionFilterInfo | GC.Pivot.PivotConditionType.caption | GC.Pivot.PivotCaptionFilterOperator | Array.\<string> | / | / | / |
| GC.Pivot.IPivotDateConditionFilterInfo | GC.Pivot.PivotConditionType.date | GC.Pivot.PivotDateFilterOperator | Array.\<Date> | / | / | boolean |
| GC.Pivot.IPivotTop10ConditionFilterInfo | GC.Pivot.PivotConditionType.top10 | GC.Pivot.PivotTop10FilterOperator | number | / | GC.Pivot.PivotTop10FilterType | / |
| GC.Pivot.IPivotValueConditionInfo | GC.Pivot.PivotConditionType.value | GC.Pivot.PivotValueFilterOperator | Array.\<number> | string | / | / |

## 隐藏筛选按钮

你可以使用`showFilter`选项从数据透视表中隐藏筛选按钮。
![hide-filter-button.4141a1](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/hide-filter-button.4141a1.62eb61.png)
以下示例代码展示了如何隐藏筛选按钮。

```javascript
// 将showFilter设置为false
myPivotTable.options.showFilter = false;
```

## 筛选对话框

你可以通过点击数据透视表中的列标题来使用筛选对话框。它提供了各种排序和筛选选项。你需要从筛选对话框的列表框中选择所需项目来应用筛选。以下图片展示了筛选对话框。
![filter_dialog.bd11cd](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/filter_dialog.bd11cd.e61921.png)
筛选对话框还提供了一个搜索框，方便你应用筛选设置。
你可以输入不区分大小写的搜索项，还可以使用“将当前选择添加到筛选器”选项，将所选项目与先前的筛选信息合并。如果未选中此选项，当前选择将覆盖先前的筛选信息。
它还允许你使用正则表达式字符进行搜索，如：“?”、“\*”和“\~”，如下图所示。
![filter_dialog_search_box.cfafde](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/filter_dialog_search_box.cfafde.252778.png)
你还可以使用鼠标或各种键盘按键与筛选对话框进行交互。SpreadJS提供了以下键盘按键来与筛选对话框进行交互：

| **按键** | **描述** |
| --- | --- |
| Tab | 将焦点切换到下一个部分。 |
| Shift + Tab | 将焦点切换到上一个部分。 |
| 左箭头键 | 当焦点在列表中的当前项目上时，折叠该项目的所有子项。 |
| 右箭头键 | 当焦点在列表中的当前项目上时，展开该项目的所有子项。 |
| 上箭头键 | 在筛选对话框中将焦点向上切换，或者当列表框的第一个根节点处于焦点时，将焦点移出列表框，或者在列表中将焦点向上切换。 |
| 下箭头键 | 在筛选对话框中将焦点向下切换，或者当列表框中最后一个可见节点处于焦点时，将焦点移出列表框，或者在列表中将焦点向下切换。 |
| 空格键 | 当焦点在列表中的项目上时，选中或取消选中该项目。 |
| Enter | 应用筛选。 |
| Esc | 关闭筛选对话框或返回上一个对话框。 |
