# sort-pt

SpreadJS 允许你对数据透视表数据进行排序，以便你可以对其进行整理，从而实现快速便捷的分析。在处理大量数据时，排序功能尤其有用。你可以使用 `PivotTable.sort` 函数对数据进行排序，该函数接受 `sortInfo` 对象作为参数。
SpreadJS 允许用户以四种不同的方式对数据透视表数据进行排序和排列：

1. 按字段项名称排序
2. 按值排序
3. 按自定义字段项值排序
4. 按自定义回调函数排序

## 按字段项名称排序

要按某个字段对数据透视表数据进行排序，你可以指定字段名称，并使用 `sortInfo` 的 `sortType` 属性，将排序顺序设置为升序、降序或自定义。
下图展示了对 “类别” 字段应用降序排序的情况。
![pivot-sort-by-field-name.6635c7](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pivot-sort-by-field-name.6635c7.fd30a3.png)
以下代码示例展示了如何按字段项名称对数据透视表数据进行排序：

```javascript
let pivotTable = spread.getActiveSheet().pivotTables.get('PivotTable');
var sortInfo = {
    sortType: GC.Pivot.SortType.desc,
};
pivotTable.sort('Category', sortInfo);
```

### 使用设计器

你也可以通过设计器对数据进行排序，方法是从某个字段的 “筛选下拉菜单” 中点击 “更多排序选项...”。此选项会打开一个 “排序字段” 对话框，在其中你可以选择目标字段，并将排序类型设置为升序或降序。
下图展示了如何使用设计器按字段项名称进行排序：
![pivot-sort-by-field-name.6dac76](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pivot-sort-by-field-name.6dac76.dc8514.gif)

## 按值排序

要按某个字段的值对数据透视表数据进行排序，你可以设置 `sortInfo` 类的 `sortType` 和 `sortValueFieldName` 属性。`sortValueFieldName` 属性可让你指定要按其对数据进行排序的字段名称。此功能可让你按 “总计” 列中的值对数据透视表数据进行排序。
下图展示了按 “数量” 值对 “类别” 字段进行升序排序的情况。
![pivot-sort-by-value.b7e3ef](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pivot-sort-by-value.b7e3ef.103c88.png)
以下代码示例展示了如何对数据透视表应用按值排序。

```javascript
let pivotTable = spread.getActiveSheet().pivotTables.get('PivotTable');
var sortInfo = {
    sortType: GC.Pivot.SortType.asc,
    sortValueFieldName: 'Quantity',
};
pivotTable.sort('Category', sortInfo);
```

### 使用设计器

你也可以通过设计器对数据进行排序，方法是从某个字段的 “筛选下拉菜单” 中点击 “更多排序选项...”。此选项会打开一个 “排序字段” 对话框，在其中你可以选择目标字段，并将排序类型设置为升序或降序。

## 按自定义字段项值排序

要按自定义字段项值对数据透视表数据进行排序，你可以使用 `sortInfo` 对象的 `sortByPivotReferences` 属性。
下图展示了根据 “订单日期” 字段中 “第一季度” 的数据，对 “类别” 字段进行升序排序的情况。
![pivot-sort-by-custom-value.58dbfa](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pivot-sort-by-custom-value.58dbfa.ccd96a.png)
以下代码示例展示了如何设置按自定义字段项值进行排序：

```javascript
let pivotTable = spread.getActiveSheet().pivotTables.get('PivotTable');
var sortInfo = {
    sortType: GC.Pivot.SortType.asc,
    sortValueFieldName: 'Quantity',
    sortByPivotReferences: [
        {
            fieldName: 'OrderDate',
            items: ['Qtr1'],
        },
    ],
};
pivotTable.sort('Category', sortInfo);
```

### 使用设计器

你也可以通过设计器对数据进行排序，方法是从某个字段的 “筛选下拉菜单” 中点击 “更多排序选项...”。此选项会打开一个 “排序字段” 对话框，在其中你可以为目标字段选择排序顺序，然后点击 “更多选项...” 按钮以打开另一个 “排序” 对话框。在此对话框中，默认情况下会选择 “总计”，这会得到与按值排序相同的结果。要按自定义字段项值进行排序，请使用 “所选列中的值” 的范围选择器选择一个范围，然后点击 “确定”。

> 对于行或列区域字段，对话框选项会被禁用。例如，在这种情况下，如果你点击 “类别” 字段的 “更多选项...” 按钮，它将被禁用，因此你必须选择 “数量” 字段，然后点击 “更多选项...” 按钮。
> 以下图片展示了如何使用设计器按自定义字段项值进行排序：

## 按自定义回调函数排序

要使用自定义逻辑对数据透视表数据进行排序，而不是按值的升序或降序进行排序，你可以使用自定义回调函数。
下图展示了使用自定义回调函数对 “总销售额” 列进行排序的情况。
![pivot-sort-by-custom-callback.ac07df](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/pivot-sort-by-custom-callback.ac07df.fabffa.png)
以下代码示例展示了使用自定义回调函数对 “总销售额” 列进行排序的情况：

```javascript
let pivotTable = spread.getActiveSheet().pivotTables.get('PivotTable');
var sortInfo = {
    sortType: GC.Pivot.SortType.desc,
    customSortCallback: (fieldItemNameArray) => {
        alert('sorting from custom callback');
        return fieldItemNameArray.sort((a, b) => b - a);
    },
};
pivotTable.sort('TotalSales', sortInfo);
```
