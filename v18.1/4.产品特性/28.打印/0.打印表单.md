# printsheet

你可以在 SpreadJS 中打印单张工作表或所有工作表。
在 SpreadJS 中进行打印时，会打印以下内容：

* 边角、行标题、列标题或视口中可见的行或列
* 单元格文本
* 单元格样式
* 合并单元格
* 溢出内容

以下信息不会被打印：

* 隐藏的行或列
* 浮动对象
* 批注
* 标签栏
* 滚动条
* 分组
* 筛选按钮
* 数据验证按钮或高亮圆圈
* 活动效果
* 选中区域
* 冻结线

使用 [print ](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0#print)方法来打印一张或多张工作表。可以使用索引指定特定的工作表，若不使用索引则打印所有可见工作表。你可以使用 [PrintInfo ](gcdocsite__documentlink?toc-item-id=6f8e15e8-6dec-4e4f-a772-49bbdae4daa3)类指定许多打印选项，例如是否打印标题、边框、网格线等等。

> **注意：** 打印需要在页面中添加打印模块（gc.spread.sheets.print.*.*.\*.min.js）。

以下代码示例展示了如何打印一张工作表。

```JavaScript
<script src="./scripts/pluggable/gc.spread.sheets.print.x.x.x.min.js" type="application/javascript"></script>
...

// 初始化 SpreadJS
var spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"),{sheetCount:3});
var activeSheet = spread.getActiveSheet();
activeSheet.suspendPaint();

// 设置值
for (var r = 0, rc = activeSheet.getRowCount() - 5; r < rc; r++) {
    for (var c = 0, cc = activeSheet.getColumnCount() - 5; c < cc; c++) {
        activeSheet.setValue(r, c, r + c);
    }   
}
activeSheet.resumePaint();
$("#button1").click(function () {
    spread.print(0);
});
```
