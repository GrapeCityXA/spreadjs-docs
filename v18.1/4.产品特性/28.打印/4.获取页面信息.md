# GetPageInformation

SpreadJS 允许用户在处理电子表格时获取关键的页面信息，这些信息包括总页数、行数、列数，以及每一页的行索引和列索引。尤其是当用户想要在打印工作表数据之前了解有关页面的重要信息时，这个功能就非常有用。
例如，假设你正在使用一个以 Excel 作为报表工具的财务应用程序。现在，你想在工作表执行打印任务之前获取页面信息，并且你还想创建一个“索引页”。借助这个功能，用户能够确定：

1. 准确的页数（工作表将打印出多少页）；
2. 每一个打印页面上的打印范围[也就是页面的行和列信息]。

这将帮助用户高效地打印出所需的数据。
以下代码示例展示了在处理电子表格时如何获取页面信息。

```javascript
// 初始化 Spread
var spread = new GC.Spread.Sheets.Workbook(document.getElementById('ss'),
{ 工作表数量: 1 });
spread.suspendPaint();

// 获取活动工作表
var sheet = spread.getActiveSheet();
for (var i = 0; i < 20; i++)
{
  for (var j = 0; j < 18; j++)
  {
    sheet.setValue(i, j, "第" + i + "行 第" + j + "列");
  }
}
spread.resumePaint();
var pageInfos = spread.pageInfo(0);
console.log("总页数: " + pageInfos.pages.length);
for (var p = 0; p < pageInfos.pages.length; p++) {
  console.log("第[" + p + "]页的列数为: " + pageInfos.pages[p].columnCount);
  console.log("第[" + p + "]页的行数为: " + pageInfos.pages[p].rowCount);
}
```
