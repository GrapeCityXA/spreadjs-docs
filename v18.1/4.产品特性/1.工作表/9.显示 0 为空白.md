# display-zero-as-blank

默认情况下，SpreadJS 在数字类型单元格中将零值显示为“0”。
但是，您可以通过将工作表的**showZeros选项设置为false**将零值显示为空白。
以下示例代码显示如何使用 showZeros 选项将零值显示为工作表中的空白单元格。

```javascript
sheet.options.showZeros = false;
// input "=1-1" in cell A1, the A1 cell display blank.
```

此选项仅影响单元格的显示值，而不影响实际值。因此，涉及零值单元格的任何计算或图表都没有变化。
相反，过滤器对话框使用显示值，因此在 showZeros 选项设置为 false 时显示空白。
同样，在水印单元格中，当零值显示为空白时，SpreadJS 会显示水印。

> **注意：**以下情况适用于 showZeros 选项为false时。
>
> * 字符串“0”不显示为空白。选项仅适用于数字类型的单元格。
> * 如果单元格的值不为 0，但格式结果为 0，则单元格显示“0”。例如，格式为 #,##0 的 0.01。
> * OADATE(0)，即sheet.setValue(0,0,new Date(1899, 11, 30)); 显示为空白。
> * 当 showFormulas 设置为 true 时，零值按原样显示。

## 使用设计器

您还可以通过 SpreadJS 设计器启用此功能，方法是选中**工作表设置对话框中的“显示零值单元格**”复选框。
