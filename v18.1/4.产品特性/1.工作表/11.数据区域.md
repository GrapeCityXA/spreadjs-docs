# worksheet-data-range

在 SpreadJS 中，数据区域功能允许您在工作表的坐标轴系统内定义和管理特定的工作表区域。对于显示和处理复杂的数据结构特别有用。它在工作表坐标轴和数据区域坐标轴之间转换范围单元格的坐标 “行” 和 “列”，为用户提供转换，以便用户专注于业务逻辑，而不是手动处理坐标。
数据区域将内部工作表的存储和样式存储从内部工作表抽象到用户定义的接口。这允许用户将其专门的数据结构直接渲染到工作表中，并具有所有正常的工作表渲染和交互。例如，数据透视表是一种专门为数据分析设计的特殊数据存储，它使用数据区域将其数据和样式渲染到工作表中。这允许用户设计类似于数据透视表的自定义解决方案，例如分析报告、财务报告和虚拟服务器数据视图。通过高效检索和聚合数据并使用数据区域进行渲染，用户可以避免手动将数据写入工作表单元格，从而提高性能和可用性。

> **注意**：数据区域不应相交，并且必须具有唯一的名称。

## 主要功能

* **数据管理**：在大型数据集中定义逻辑边界，以便进行可视化或分析等有针对性的操作。
* **可定制的数据显示**：支持样式设置、合并和条件格式设置，以增强可读性。
* **动态数据交互**：通过事件驱动的钩子、固定行和 JSON 序列化实现实时更新。
* **提升用户体验**：诸如固定表头、交替行样式和键盘导航等功能优化了可用性。
* **数据区域输入 / 输出**：将数据区域导出为 JSON 或 Excel 格式，保持一致的数据表示。

## 使用数据区域的步骤

按照以下步骤，您可以在工作表中使用数据区域：

1. 通过实现`IDataProvider`接口创建自定义数据提供程序。
2. 在工作表中选择目标区域。
3. 使用数据区域管理器将数据区域添加到工作表。

## 设置数据提供程序

数据提供程序是用户定义的实例。您可以使用`GC.Spread.Sheets.DataRange.IDataProvider`接口来设置值、获取值、撤销更改，还可以使用数据提供程序自定义单元格值。

### 设置值

数据区域中单元格值的读取和写入由数据提供程序控制，您可以利用此功能方便地连接数据源。当工作表渲染数据区域中的单元格时，使用`getValue`方法获取值。类似地，`setValue`方法可让您为数据区域内的单元格赋值。
以下是一个自定义数据提供程序的示例，用于从数据源获取和设置值。

```javascript
 class CustomerDataProvider {
     // Values
     dataSource = [
         ["ID", "Name", "Age"],
         ["1", "Mike", "18"],
         ["2", "Joe", "19"],
         ["3", "Nick", "30"],
         ["4", "Sam", "26"]
     ]
     getValue(row, col) {
         return this.dataSource[row][col];
     }
     setValue(row, col, value) {
         this.dataSource[row][col] = value;
         return true;
     }
 }
```

但是，如果您想要撤销 / 重做所做的更改，则需要在`changes`参数中记录更改，然后使用`changes`参数在数据提供程序中实现`undo`方法。

```javascript
   class CustomerDataProvider {
       // Values
       dataSource = [
           ["ID", "Name", "Age"],
           ["1", "Mike", "18"],
           ["2", "Joe", "19"],
           ["3", "Nick", "30"],
           ["4", "Sam", "26"]
       ]
       getValue(row, col) {
           return this.dataSource[row][col];
       }
       setValue(row, col, value, changes) {
           var oldValue = this.getValue(row, col);
           if (changes) {
               // create a change object with necessary information for recovering state when undo
               var change = {
                   row: row,
                   col: col,
                   oldValue: oldValue,
                   type: "value" // mark the change with some key, then convenient for you to identify when undoing
               };
               changes.push(change);
           }
           this.dataSource[row][col] = value;
           return true;
       }
       undo(change) {
           if (change.type === "value") { // marked in setValue method
               var row = change.row;
               var col = change.col;
               var oldValue = change.oldValue;
               this.setValue(row, col, oldValue);
           }
       }
   }
```

### 数据区域中的样式设置

使用`getStyle`方法，您可以自定义数据区域的外观，如表头和主体样式、交替行样式等。如果需要，您还可以使用`GC.Spread.Sheet.Style`类在数据提供程序中使用公共样式属性，如`formatter`。

```javascript
 class CustomerDataProvider {
     //  Styles
     headerRowCount = 1;
     styles = {
         header: () => {
             var style = new GC.Spread.Sheets.Style();
             style.backColor = "#217346";
             style.foreColor = "white";
             return style;
         },
         body: () => {
             var style = new GC.Spread.Sheets.Style();
             style.foreColor = "#217346";
             style.backColor = "lightgray";
             return style;
         }
     }

     step = 2;
     alternatingRowStyle = () => {
         var style = new GC.Spread.Sheets.Style();
         style.backColor = "#EEEEEE";
         return style;
     }
     getStyle(row, col) {
         // when row index is at the row header area
         if (row < this.headerRowCount) {
             return this.styles.header();
         }

         // Alternating Row Styles
         if (row % this.step === 0) {
             return this.alternatingRowStyle();
         } else {
             return this.styles.body();
         }
     }
 }
```

### 条件格式设置

您还可以使用`applyColumnIndex`属性对数据区域的某一列应用条件格式，以增强数据的可读性。

```javascript
class CustomerDataProvider {
    // Conditional Formatting
    headerRowCount = 2;
    applyColumnIndex = 2; // the applied conditional format column index
    condition = (value) => value > 18;
    highlightStyle = () => {
        var style = new GC.Spread.Sheets.Style();
        style.foreColor = "red";
        style.cellPadding = "10 0 0 0";
        style.watermark = "ADULT";
        style.labelOptions = { visibility: 0, foreColor: "#CCCCCC", font: '10px Arial' };
        style.vAlign = GC.Spread.Sheets.VerticalAlign.center;
        return style;
    }
    normalStyle = () => {
        var style = new GC.Spread.Sheets.Style();
        style.vAlign = GC.Spread.Sheets.VerticalAlign.center;
        return style;
    }
    getStyle(row, col) {
        if (row < this.headerRowCount) {
            var style = new GC.Spread.Sheets.Style();
            style.backColor = "#217346";
            style.foreColor = "white";
            return style;
        }
        if (row >= this.headerRowCount) {
            // if match the condition
            if (col === this.applyColumnIndex && this.condition(this.getValue(row, col))) {
                return this.highlightStyle();
            }
            return this.normalStyle();
        }
    }
}
```

### 合并单元格

您可以通过在数据提供程序中使用`getSpans`方法创建多行或多列的表头。

```javascript
class CustomerDataProvider{
    headerRowCount = 2;

    // Spans
    spans = [new GC.Spread.Sheets.Range(0, 0, 2, 1), new GC.Spread.Sheets.Range(0, 1, 1, 2)]
    getSpans(row, col, rowCount, colCount) {
        const spans = [];
        for (let span of this.spans) {
            if (span.intersect(row, col, rowCount, colCount)) {
                spans.push(span);
            }
        }
        return spans;
    }
}
```

## 使用数据区域管理器

`sheet.dataRanges`属性可帮助管理工作表中的多个数据区域。您可以执行以下各节中提到的任务。
要使用名称、数据提供程序实例和区域添加新的数据区域，可使用`dataRanges`类的`add`方法。

```javascript
sheet.dataRanges.add(
  "DataRangeName",
  CustomDataProvider,
  new GC.Spread.Sheets.Range(2, 2, 4, 4)
);
```

要通过数据区域名称删除数据区域，可使用`dataRanges`类的`remove`方法。

```javascript
sheet.dataRanges.remove("DataRangeName");
```

要清除工作表中的所有数据区域，可使用`dataRanges`类的`clear`方法。

```javascript
sheet.dataRanges.clear();
```

要通过数据区域名称获取数据区域，可使用`dataRanges`类的`get`方法，该方法将数据区域的名称作为参数。

```javascript
var dataRange = sheet.dataRanges.get("DataRangeName");
```

要获取工作表中的所有数据区域，可使用`dataRanges`类的`all`方法。

```javascript
var dataRanges = sheet.dataRanges.all();
```

在数据源更改后，您可以根据需要重新绘制数据区域，并更改其大小和位置。
要重新绘制数据区域本身，可使用`repaint`方法。

```javascript
dataRange.repaint();
```

要更改数据区域的大小，您可以在`range`方法中传入新的`rowCount`和`colCount`。

```javascript
var oldRange = dataRange.range();
dataRange.range(oldRange.row, oldRange.col, oldRange.rowCount + 1, oldRange.colCount + 1);
```

要更改数据区域的位置，您可以在`range`方法中传入新的`rowindex`和`colindex`。

```javascript
var oldRange = dataRange.range();
dataRange.range(oldRange.row + 1, oldRange.col + 1, oldRange.rowCount, oldRange.colCount);
```

## 管理数据区域选项

您可以将数据区域的顶部行固定为工作表中第一个可见行，固定行的数量可以使用`sticky`属性定义，并且稍后可以更改。使用`IDataRangeOptions`接口来配置其他选项，如固定行。

```javascript
sheet.dataRanges.add("DataRangeName", CustomDataProvider, new GC.Spread.Sheets.Range(2, 2, 4, 4), {
  sticky: { top: 2 }
});
```

## 导出数据区域

SpreadJS 允许将数据区域导出为 JSON、SJS 和 Excel 格式，确保数据的一致呈现。以下是导出数据区域的基本注意事项。
**JSON 格式**
自定义数据提供程序类不能直接序列化。因此，您必须在数据提供程序中定义一个`typeName`，其字符串值应与类名相同。确保您的数据提供程序类在全局实例（如`window`）中可访问，以便在反序列化时能够定位相应的自定义数据提供程序类。

```javascript
class CustomDataProvider {
  constructor () {
    this.typeName = "CustomDataProvider";
  }
}
window.CustomDataProvider = CustomDataProvider;
```

**SJS 格式**
将数据区域导出为 SpreadJS 格式以用于 SpreadJS 应用程序时，所有导出的 JSON 数据将以 “无损” 格式存储。
**Excel 格式**
由于 Excel 不支持数据区域，这些区域将作为标准单元格导出，包括其值和样式。

## 数据区域策略

在 SpreadJS 中使用数据区域时，需要牢记以下一些重要策略：

* 行和列索引必须介于 0 和工作表中的总行数与总列数之间。
* 对行数和列数没有限制，但工作表之外的任何数据区域将被忽略。
* 数据提供程序钩子的所有输入参数基于数据区域坐标轴，而非工作表坐标轴（如行和列）。
* 当在数据区域之前插入或删除行或列时，数据区域将移动；当在数据区域之外插入或删除行或列时，数据区域不会采取任何行动。
* 当清除包含整个数据区域的区域时，数据区域将被移除。
* 当前上下文为数据区域时，筛选对话框和上下文菜单中的排序选项将隐藏。
* 如果数据提供程序中未实现`toJSON`钩子，将使用自定义数据提供程序的`typeName`属性生成默认的 JSON 数据输出。
* 使用`fromJSON`时，如果没有匹配的数据提供程序，则不会创建相应的数据区域。
