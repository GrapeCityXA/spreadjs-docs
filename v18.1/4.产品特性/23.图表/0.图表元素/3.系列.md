# ConfiguringSeries

在 SpreadJS 中，你可以在创建图表时绘制一个或多个数据系列。每个系列代表图例中的一个项目。你可以从图表的系列集合中获取、插入和删除系列项目，还可以使用 [series 方法](https://docs.grapecity.com.cn/spreadjs/help/api//classes/GC.Spread.Sheets.Charts.Chart#series) 和 [SeriesCollection 类](https://docs.grapecity.com.cn/spreadjs/help/api//classes/GC.Spread.Sheets.Charts.SeriesCollection#class-seriescollection) 为每个系列项目自定义系列名称、边框宽度、边框颜色、y 值、x 值和填充颜色。
除此之外，你还可以自定义数据系列的线条类型。可以使用 `LineDashStyle` 枚举来实现这一点，并且可以将系列线条类型设置为实线、方形点、长划线、短划线、系统点划线、双点划线等等。SpreadJS 设计器的图表侧边面板还会显示 “虚线类型” 下拉字段，该字段提供了各种选项来为图表系列选择线条类型。

以下代码示例展示了如何在图表中配置系列。

```javascript
//配置系列
var series = chart.series();
var seriesItem = series.get(0);
seriesItem.yValues = "Sheet1!$B$5:$E$5";
seriesItem.backColor = "#d3d3d3";
seriesItem.border.width = 2;
series.set(0, seriesItem);                      
```

以下代码示例展示了如何在图表中自定义系列线条类型。

```javascript
// 设置图表系列(0)的线条类型
var series1 = chart.series().get(0);
series1.border.lineType = GC.Spread.Sheets.Charts.LineDashStyle.dashDotDot;
chart.series().set(0, series1);

// 设置图表系列(1)的线条类型
var series2 = chart.series().get(1);
series2.border.lineType = GC.Spread.Sheets.Charts.LineDashStyle.longDash;
chart.series().set(1, series2);

// 设置图表系列(2)的线条类型
var series3 = chart.series().get(2);
series3.border.lineType = GC.Spread.Sheets.Charts.LineDashStyle.sysDashDot;
chart.series().set(2, series3);
```
