# ConfiguringDataLabel

数据标签用于标识数据系列中数据点的详细信息。它们的作用是确保用户能够轻松理解和解读图表中绘制的信息。
在 SpreadJS 中，你可以使用 [dataLabels ](gcdocsite__documentlink?toc-item-id=3816be2a-7532-41fa-bd2e-e2f41d1de655#dataLabels)方法和 [DataLabelPosition ](gcdocsite__documentlink?toc-item-id=b2f6b8aa-cce6-46eb-8f42-f515702f1e1a)枚举来获取或设置数据标签，更改它们的位置和颜色，并控制是否在图表中显示数据标签。
下面展示了一个配置了数据标签的基本图像。
![data_labels](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/data_labels.d251e9.png)
以下代码示例展示了如何在图表中配置数据标签。

```javascript
//配置数据标签
var dataLabels = chart.dataLabels();
dataLabels.showValue = true;
dataLabels.showSeriesName = false;
dataLabels.showCategoryName = false;
dataLabels.color = "#000000";
var dataLabelPosition = GC.Spread.Sheets.Charts.DataLabelPosition;

// 这个位置有很多选项。不同的图表类型适用不同的位置值
dataLabels.position = dataLabelPosition.outsideEnd;
chart.dataLabels(dataLabels);        
```

你还可以通过设置背景颜色、透明度或边框颜色、宽度、透明度等来自定义数据标签的样式。此外，你可以为图表的不同系列配置不同的样式，如下图所示。
![style_data_label](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/style_data_label.7364fb.png)
以下代码示例展示了如何为不同的图表系列配置数据标签的样式。

```javascript
// 获取系列 0 和 1 并设置其属性
for (var i = 0; i < 2; i++) {
    var series = chart.series().get(i);
    series.dataLabels = {
        showValue: false,
        showSeriesName: true,
        showCategoryName: false,
        showPercentage: false,
        separator: ",",
        position: GC.Spread.Sheets.Charts.DataLabelPosition.Center,
        format: "#,##0;-#,##0",
        color: "white",
        backColor: "red",
        borderColor: "blue",
        borderWidth: 2
    };
    chart.series().set(i, series);
}

// 获取系列 2 并设置其属性
var series = chart.series().get(2);
series.dataLabels = {
    showValue: false,
    showSeriesName: true,
    showCategoryName: false,
    showPercentage: true,
    separator: ",",
    position: GC.Spread.Sheets.Charts.DataLabelPosition.Center,
    format: "#,##0;-#,##0",
    color: "white",
    backColor: "skyblue",
    borderColor: "green",
    borderWidth: 2
};
chart.series().set(2, series);
```

## 将单元格区域显示为数据标签

你可以在数据标签中设置单元格引用，并将所选单元格区域的值显示为图表中的数据标签，这与 Excel 的功能类似。

> **注意**：数据标签中的单元格区域引用支持单行或单列区域。
>
> * 如果是单行，数据标签将从左到右依次显示每个单元格的文本。
> * 如果是单列，数据标签将从上到下依次显示文本。

要在数据标签中使用单元格引用，请使用 [IDataLabels ](gcdocsite__documentlink?toc-item-id=c70efbc6-53c8-44f7-a86a-12e1d4585681)接口的 `dataLabelsRange` 属性。此属性支持静态值数组。当更改所引用的单元格区域时，图表将刷新并相应地更新数据标签。

### 使用代码

以下代码示例展示了如何将 B4 到 D4 单元格的值显示为数据标签。

```kotlin
 // 添加图表数据标签以显示单元格区域引用文本。
 let series = chart.series().get(0);
 series.dataLabels.showDataLabelsRange = true;
 series.dataLabels.dataLabelsRange = "Sheet1!$B$4:$D$4";
 chart.series().set(0, series);
```

### 使用设计器

要将单元格区域显示为数据标签，你可以按照以下步骤操作：

1. 右键单击数据系列、图表或数据标签，打开上下文菜单。
2. 选择可用的格式选项。
3. 从下拉菜单中选择 **标签选项**。
    所有标签选项都显示在 **设置数据标签格式** 下。
4. 在 **标签包含** 下，选中 **单元格中的值** 复选框，然后单击 **选择区域…**。
5. 当出现 **数据标签区域** 对话框时，在工作表中选择要将其单元格值显示为数据标签的区域。
6. 选择后，**数据标签区域** 对话框将显示所选区域。
7. 单击 **确定**。
    现在，单元格值将在你的图表中显示为数据标签。如果这些单元格中的值发生更改，图表标签将自动更新。

### 限制

* 单元格区域引用不支持多行多列区域。
* 不支持为单个点数据标签设置 `ShowDatalabelsRange` 属性。
* `dataLabelsRange` 属性不支持用于引用单元格的自定义名称。
