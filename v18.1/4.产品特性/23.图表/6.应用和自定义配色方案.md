# apply-and-customize-color-schemes-in-charts

配色方案是一组相互协调的颜色，用于提升图表的外观。若要根据您的偏好更改图表的配色方案，请使用 [GC.Spread.Sheets.Charts](gcdocsite__documentlink?toc-item-id=64916dee-f784-44ce-8be8-4c14fbdc69f3) 类的 `ColorScheme` 属性。

## 应用内置配色方案

SpreadJS 使您能够使用任何内置选项轻松应用图表的内置配色方案，例如 *colorfulPalette1*、*colorfulPalette2*、*colorfulPalette3*、*monochromaticPalette1*、*monochromaticPalette2*、*monochromaticPalette3* 等。图表的默认配色方案是 **colorfulPalette1**。
以下代码示例展示了如何应用内置配色方案：

```javascript
// 应用一种配色方案。
var chart = activeSheet.charts.add('Chart1', GC.Spread.Sheets.Charts.ChartType.columnClustered, 250, 100, 600, 400, 'A1:D4');
chart.colorScheme(GC.Spread.Sheets.Charts.ColorSchemes.colorfulPalette2);
```

## 自定义配色方案

您可以使用 `GC.Spread.Sheets.Charts.ColorRule` 枚举来自定义您自己的配色方案。下表列出了可用的 `ColorRule` 枚举值：

| 颜色规则 | 描述 |
| ---- | --- |
| cycle | 从颜色列表中依次选择一种颜色，应用到图表中的每个系列。当选择到列表中的最后一种颜色时，再从第一种颜色开始。 |
| withinLinear | 从颜色列表中最暗和最亮的颜色之间等间距的索引位置选择一种颜色，并将这些颜色应用到图表系列。 |
| acrossLinear | 与 withinLinear 类似，从颜色列表中最暗和最亮的颜色之间等间距的索引位置选择一种颜色，并将颜色应用到图表系列。如果有多个颜色列表，例如 *颜色列表 1* 和 *颜色列表 2*，则按照 *颜色列表 1* 的最暗颜色和 *颜色列表 2* 的最暗颜色的顺序，从 *颜色列表 1* 和 *颜色列表 2* 的最暗到最亮的色调中交替选择颜色。 |
| withinLinearReversed | 与 withinLinear 相反，从颜色列表中最亮到最暗的颜色之间等间距的索引位置选择颜色，并将它们应用到图表系列。 |
| acrossLinearReversed | 与 acrossLinear 相反，从颜色列表中最亮和最暗的颜色之间等间距的索引位置选择颜色，并将其应用到图表系列。如果有多个颜色列表，例如 *颜色列表 1* 和 *颜色列表 2*，则按照 *颜色列表 1* 的最亮颜色和 *颜色列表 2* 的最亮颜色的顺序，从颜色列表 1 和 2 的最亮到最暗的色调中交替选择颜色。 |

以下代码示例展示了如何定义和应用自定义配色方案：

```javascript
// 自定义配色方案。
var chart = activeSheet.charts.add('Chart1', GC.Spread.Sheets.Charts.ChartType.columnClustered, 250, 100, 600, 400, 'A1:D4');
let myColorScheme = [GC.Spread.Sheets.Charts.ColorRule.cycle, ['#00aefe', '#3368e7', '#8e43e6', '#b74592', '#ff4f80', '#ff6d5f', '#ffc268', '#2cde98', '#1dc7d1']];
chart.colorScheme(myColorScheme);
```

## 从自定义方案中检索颜色

您可以使用 `getColor()` 方法获取配色方案中指定的颜色。
以下代码示例展示了如何使用 `getColor()` 方法从配色方案中获取一种颜色：

```javascript
// 自定义配色方案。
var chart = activeSheet.charts.add('Chart1', GC.Spread.Sheets.Charts.ChartType.columnClustered, 250, 100, 600, 400, 'A1:D4');
let myColorScheme = [GC.Spread.Sheets.Charts.ColorRule.cycle, ['#00aefe', '#3368e7', '#8e43e6', '#b74592', '#ff4f80', '#ff6d5f', '#ffc268', '#2cde98', '#1dc7d1']];

// 从配色方案中获取索引为 3 的颜色。
let color = GC.Spread.Sheets.Charts.getColor(myColorScheme, 3);
```

请注意，更改配色方案不会更新现有系列或数据点的颜色。它仅在您添加新系列或数据点时才会生效。如果您想立即应用新的配色方案，则需要按照以下代码示例所示重置系列或数据点的颜色：

```javascript
// 重置系列或数据点的颜色。
function resetSeriesColor(chart, colorScheme) {
    let series = chart.series().get();
    for (let i = 0, len = series.length; i < len; i++) {
        let seriesItem = series[i];
        seriesItem.backColor = GC.Spread.Sheets.Charts.getColor(colorScheme, i, len);
        chart.series().set(i, seriesItem);
    }
}
```
