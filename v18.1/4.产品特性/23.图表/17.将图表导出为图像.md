# export-charts-as-image

您可以在 SpreadJS 中将图表导出为图像源。在工作表中插入图表后，可以使用 `chart.toImageSrc()` API 获取图像源。

## 使用代码

以下代码示例展示了如何将工作表上的形状对象保存为图像源。

```javascript
// 添加柱状图。
// 准备图表数据。
sheet.setArray(0, 0, [
    ['', 'Chrome', 'FireFox', 'IE', 'Safari'],
    ['2020', 51, 34, 11, 27],
    ['2021', 23, 31, 73, 64],
    ['2022', 36, 24, 83, 89],
]);

// 添加图表。
let chart = sheet.charts.add('Chart1', GC.Spread.Sheets.Charts.ChartType.columnClustered, 100, 100, 500, 280, 'A1:E4');

// 获取图表作为图像源。
let chartImageSrc = sheet.charts.all()[0].toImageSrc();
```

## 使用设计器

当您在 Spread Designer 中选择图表时，也可以通过点击“另存为图片”选项将其保存为图像。
以下是将图表保存为图像的步骤：

1. 打开工作表
2. 根据需要插入数据
3. 插入图表
4. 右键点击图表，然后点击“另存为图片”
    ![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/ca67eb79-8e4a-4469-a993-ae6efd83c8ca/image.5b334d.png?width=500)
5. 选择要保存图像的位置。
6. 命名文件并点击保存。

> type=warning
> 注意：
>
> 1. 目前，导出的文件格式为 PNG，文件名为默认对象名。例如，Chart 1
> 2. 如果选择了多个图表对象，它们将一起导出，并且所有图表将默认导出为名为 SpreadShapes 的文件
