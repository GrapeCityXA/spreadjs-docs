# add-source-linked-cell-formatter

图表使用链接单元格应用单元格数字格式，以便将单元格格式动态更新到数据标签、坐标轴和工具提示等图表元素上。SpreadJS 中的图表提供了 `IDataLabels` 接口和 `IAxes` 接口的 `numberFormatLinked` 属性来实现此功能。

## 为数据标签设置源链接格式设置器

当 `numberFormatLinked` 属性设置为 **true** 时，数据标签的 “值” 字段将保留数据源单元格的格式，而不受链接到数据标签的格式代码的影响；而如果 `numberFormatLinked` 属性设置为 **false**，数据标签中的 “值” 字段将使用指定的格式设置器。
**示例**：假设您想为不同的浏览器创建一个性能仪表板，用于跟踪每月的销售数据。该仪表板包含一个簇状柱形图，用于显示每个浏览器的平均月销售额，并且您希望确保图表的数据标签能根据用户对平均销售数据的选择偏好动态更新其格式。以下图表展示了 `numberFormatLinked` 属性设置为 true 时的销售数据。
![charts-datalabels.1eafb0](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/charts-datalabels.1eafb0.14ed69.png)
以下代码示例展示了如何使用链接单元格实现单元格数字格式设置，以动态更新图表的数据标签。

```javascript
// 获取系列并设置数据标签属性。
for (var i = 0; i < 3; i++) {
    var series = chart.series().get(i);
    series.dataLabels = {
        显示值: true,
        显示类别名称: false,
        显示百分比: false,
        分隔符: ',',
        位置: GC.Spread.Sheets.Charts.DataLabelPosition.Center,
        格式: '#,##0',
        颜色: 'white',
        背景颜色: 'red',
        边框颜色: 'blue',
        边框宽度: 2,
    };
}

// 为数据标签设置源链接格式设置器。
series.dataLabels.numberFormatLinked = true;
chart.series().set(i, series);
```

> **注意**：[散点图](gcdocsite__documentlink?toc-item-id=22da3aab-65aa-4dff-bd43-9517ddb3a5ff) 是个例外，其中数据标签中的 “x 值”、“y 值” 和 “气泡大小” 字段使用用户指定的格式设置器。

## 为坐标轴设置源链接格式设置器

当 `numberFormatLinked` 属性设置为 **true** 时，图表的坐标轴将保留数据源单元格的格式，而不受链接到坐标轴的格式代码的影响，其中：

* 如果坐标轴类型是 **文本** 坐标轴，所有坐标轴标签都将根据系列点的格式设置器进行格式化。
* 如果坐标轴类型是 **日期** 坐标轴或 **值** 坐标轴，所有坐标轴标签都将根据系列的第一个点的格式设置器进行格式化。

当 `numberFormatLinked` 属性设置为 **false** 时，图表的坐标轴将使用指定的数字格式设置器。不过，对于值坐标轴，所有坐标轴标签都将根据系列的第一个点的格式设置器进行格式化。
**示例**：假设您想为不同的浏览器创建一个性能仪表板，用于跟踪每月的销售数据。您的仪表板包含一个簇状柱形图，用于显示每个浏览器的平均月销售额，并且您希望确保图表的 x 轴能根据用户对日期格式的选择偏好动态更新其格式。以下图表展示了 `numberFormatLinked` 属性设置为 true 且坐标轴类型设置为 “文本” 时，图表 x 轴上销售数据的日期显示情况。
![charts-axis.fee71a](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/charts-axis.fee71a.9ffc70.png)
以下代码示例展示了如何使用链接单元格实现单元格数字格式设置，以动态更新坐标轴。

```javascript
// 为坐标轴设置源链接格式设置器。
var chart = activeSheet.charts.all()[0];
var axes = chart.axes();
axes.primaryCategory.categoryType = GC.Spread.Sheets.Charts.CategoryType.CategoryScale;
axes.primaryCategory.numberFormatLinked = true;
chart.axes(axes);
var series = chart.series().get(0);
series.dataLabels.numberFormatLinked = true;
chart.series().set(0, series);
```

## 局限性

* 如果更新了数据源格式设置器，图表需要额外的支持来刷新数据。
