# spread-object-data

表格工作表会创建一个带有默认列的视图，其中 **fields** 对象显示为一个对象列。SpreadJS 允许你构建一个将 fields 对象显示为多列的视图。从服务器获取 JSON 文件，并通过指定要展开的对象列来更新数据源架构。
在表格工作表代码的架构列定义中，你可以使用 **spread** 属性将列展开为一级属性，从而展平分层数据。这种将嵌套对象展开为普通对象的功能，使用户阅读表格工作表更加轻松便捷。
以下代码展示了定义的数据源。

```javascript
{
    "records": [{
        "customerKey": 0,
        "customer": "Unknown",
        "fields": {
            "billToCustomer": "N/A",
            "category": "N/A",
            "buyingGroup": "N/A",
            "primaryContact": "N/A",
            "postalCode": "N/A",
            "validFrom": "2013-01-01T00:00:00",
            "validTo": "9999-12-31T23:59:59.9999999"
        }
    }, {
        "customerKey": 1,
        "customer": "Tailspin Toys (Head Office)",
        "fields": {
            "billToCustomer": "Tailspin Toys (Head Office)",
            "category": "Novelty Shop",
            "buyingGroup": "Tailspin Toys",
            "primaryContact": "Waldemar Fisar",
            "postalCode": "90410",
            "validFrom": "2013-01-01T00:00:00",
            "validTo": "9999-12-31T23:59:59.9999999"
        }
    }, // 更多条目
```

以下代码示例展示了在定义架构列时，如何将列字段的 spread 属性设置为 true。

```javascript
// 数据源架构
      schema: 
        { 
          dataPath: 'records', 
             columns: 
                {
                   fields: { spread: true }
                } 
        } 
```

## 使用点分隔符

在 SpreadJS 中，你还可以使用点分隔符作为 spread 属性的替代方式。在将视图绑定到表格工作表时，可以使用点分隔符。
以下代码示例展示了如何使用点分隔符将视图绑定到表格工作表。

```javascript
// 将视图绑定到表格工作表
 customerTable.fetch().then(function (data) 
 { 
     var view = customerTable.addView("myView", 
       [ 
          "customerKey", 
          "customer", 
          "fields.billToCustomer", 
          "fields.category", 
          "fields.postalCode", 
          "fields.validTo" 
     ], 
     undefined, 
      { 
       defaultColumnWidth: "*" 
      }); 
// 该视图包含表格的所有默认列
sheet.setDataView(view); 
}); 
```
