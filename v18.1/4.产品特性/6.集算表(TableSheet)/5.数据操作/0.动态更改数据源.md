# change-datasource-dynamically

TableSheet 提供了无需刷新网页即可实时从数据源注入相应数据的功能。例如，在实时服务器返回连接错误等许多场景下，此功能可帮助你将数据源切换到备份服务器。
若要动态更新数据源，请按照以下步骤操作：

1. 调用 **fromJSON** 方法。

    ```JavaScript
    spread.fromJSON(spreadJson);
    ```
2. 在 **Promise** 的 **resolve** 方法中，将数据源包装为一个对象，以此来更新表格数据源选项。

    ```JavaScript
    let myTable = spread.dataManager().tables["myTable"];
    myTable.options = { 
       remote: {               
           read: function () { 
               return Promise.resolve(dataSource); 
                   } 
             } 
    };
    ```
3. 使用新的 reload 参数调用表格的 **fetch** 方法。此步骤会刷新数据源，并使用更新后的数据源调用 **setDataView** 方法。

    ```JavaScript
    myTable.fetch(true).then(function()
    {
        let myView = myTable.views["myView"];
        let sheet = spread.getActiveSheetTab();
        sheet.setDataView(myView);
    });
    ```

> **注意**：视图的 fetch 方法和表格的 fetch 方法具有相同的新 reload 参数。因此，setDataView 方法有助于在再次获取数据视图后清除缓存状态。
