# nthvalue

该函数返回窗口帧内第n行的参数值。如果没有这样的行，则返回值为null。它不需要使用ORDERBY子句。

## 语法

`NTHVALUE(value_function, n)`

## 参数

该函数提供以下参数。

| **参数** | **描述** |
| -------- | ----------- |
| *value\_function* | [必选] 字段名或公式。 |
| *n* | [必选] 窗口帧内的第n行。<br>n应为正整数值。 |

## 示例

```
// WINDOW(NTHVALUE([@sold], 2), PARTITIONBY([city]),ORDERBY([month]))

城市     |   月份  | 销售额 | 第n值
----------------------------------------------
Paris      1       500       null
Paris      2       300       300
Paris      3       400       300
Rome       2       200       null
Rome       3       300       300
Rome       4       500       300
```
