# select_multiple_worksheets

SpreadJS 允许用户选择多个工作表，并对其执行删除或隐藏操作。[isSelected ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#isselected)属性可用于选择或取消选择多个工作表。当选择多个工作表时，可以通过上下文菜单选项对其应用隐藏或删除操作。
下图展示了工作簿中多个被选中的工作表。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.284793.png)
也可以使用`isSelected`属性或 [SheetChanging ](gcdocsite__documentlink?toc-item-id=8579217b-549b-41f7-aa4f-f0e21c37872e#sheetchanging)事件来更改活动工作表的选中状态。当活动工作表被取消选中时，其视图会变为 “activeNotSelected”。即使使用了 [reset ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#reset)方法，工作表的选中状态仍会保留。

## 支持的用户交互

SpreadJS支持通过键盘和鼠标点击操作来更改工作表的选中状态。不过，活动工作表始终处于选中状态，无法通过用户界面操作取消选中。

| **用户界面操作** | **已选中的工作表标签** | **未选中的工作表标签** |
| ------ | --------- | --------- |
| 单击 | 将单击的工作表设为活动工作表。 | 将单击的工作表设为活动工作表，并取消选中所有已选中的工作表。如果所有工作表都被选中，且单击了非活动工作表，则单击的工作表成为活动工作表，其他所有工作表被取消选中。 |
| Ctrl或Cmd + 单击 | 取消选中已选中的工作表（活动工作表除外）。 | 将单击的工作表添加为选中的工作表之一。 |
| Shift + 单击 | 对于已选中或未选中的工作表，此操作： |  |

### 限制

* 触摸操作不支持选择多个工作表。
* 不支持撤销或重做操作。
* 隐藏的工作表无法被选中。

## 使用代码

此示例代码用于设置工作簿中多个工作表的选中状态。

```js
// 获取活动工作表
var activeSheet = spread.getSheet(0);

// 设置特定工作表的选中状态
spread.getSheet(1).isSelected(true);
spread.getSheet(2).isSelected(false);
spread.getSheet(3).isSelected(true);
spread.getSheet(4).isSelected(true);

// 获取特定工作表的选中状态
var selectedState = spread.getSheet(3).isSelected();
```
