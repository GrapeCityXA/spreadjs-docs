# UsingtheStatusBar

SpreadJS为用户提供一个状态栏，该状态栏出现在表单的底部，并显示有关当前单元格模式，平均值，计数，数值计数，最小，最大，所选单元格的总和，缩放滑块和缩放百分比的信息。
下表共享描述了状态栏中所有可用的选项及其简短说明。

| **选项** | **描述** |
| --- | --- |
| Cell Mode | 此选项显示所选单元格的单元格模式。 |
| Average | 此选项显示包含数值的所选单元格的平均值。 |
| Count | 此选项显示所选单元格的数量。 |
| Numerical Count | 此选项显示包含数值的所选单元格的数量。 |
| Minimum | 此选项显示所选单元格中的最小值。 |
| Maximum | 此选项显示所选单元格中的最大值。 |
| Sum | 此选项显示所选单元格中数值的总和。 |
| Zoom Slider | 此选项显示一个带有加号和减号按钮的滑块，用于变更缩放选项。 |
| Zoom (100%) | 此选项显示缩放级别。 选择缩放百分比以显示一个对话框，允许您设置其他放大率选项。 |

状态栏为以下六个主题以及SpreadJS Workbook主题提供支持。

* Spread JS
* Excel 2013 White
* Excel 2013 Light Gray
* Excel 2013 Dark Gray
* Excel 2016 Colorful
* Excel 2016 Dark Gray

## 显示状态栏

请参考以下代码，以便在表单中显示状态栏。

```JavaScript
// 创建状态栏，将其添加到宿主并在上下文中绑定它。
var statusBar = new GC.Spread.Sheets.StatusBar.StatusBar(document.getElementById('statusBar'));
statusBar.bind(spread);
```

## 自定义状态栏

请参考以下代码，以自定义表单中的状态栏。

```JavaScript
// 通过GC.Spread.Sheets.StatusBar.StatusItem自定义状态项
var spanItem = new GC.Spread.Sheets.StatusBar.StatusItem('spanItem', { menuContent: 'Current span', value: 'Span test' });
var statusBar = new GC.Spread.Sheets.StatusBar.StatusBar(
document.getElementById('statusBar'),
{ items: [spanItem] }
);
statusBar.bind(spread);

// 通过扩展gc.spread.sheets.statusbar.statusitem自定义状态项
var statusbar = new gc.spread.sheets.statusbar.statusbar(document.getelementbyid('statusbar'));
statusbar.bind(spread);
var statusitem = gc.spread.sheets.statusbar.statusitem;
function labelitem(name, options)
{
statusitem.call(this, name, options);
}
labelitem.prototype = new statusitem();
labelitem.prototype.oncreateitemview = function (container) {
var item = document.createelement('div');
item.innertext = this.value;
item.style.background = 'blue';
container.addeventlistener('click', function (e)
{
// 点击
});
container.appendchild(item);
};
labelitem.prototype.onupdate = function ()
{
 // 上下文菜单项检查变更时执行某些操作
};
statusbar.add(new labelitem('labelitem', { menucontent: 'test label', value: 'test option' }));
```

## 删除状态栏

请参考以下代码，以便从表单中删除状态栏。

```JavaScript
// 移除状态栏
statusBar.dispose();
```
