# nameboxcomponent

SpreadJS 提供了一个类似 Excel 的名称框组件来显示选定的范围、项目和命名范围。 此功能有助于在项目中添加名称框组件以及扩展控件。
名称对话框（Name Box）通常显示所选单元格的地址。 名称对话框（Name Box）由一个选择器（Selector）和一个下拉菜单（Dropdown）组成。

## 创建名称对话框（Name Box）实例

要创建名称对话框（Name Box），请执行以下步骤：

1. 在 HTML 中添加 gc.spread.sheets.all.x.x.x.min.js 引用。

    ```HTML
    <script type="text/javascript" src="scripts/modules/gc.spread.sheets.all.x.x.x.min.js"></script>
    ```
2. 添加 DIV 容器

    ```HTML
    <div id="NameBox" style="width:100px"></div>
    ```
3. 将 名称对话框（Name Box）元素绑定到 SpreadJS 实例。

    ```JavaScript
    var sheet = spread.getActiveSheet();
    var nameBox = new GC.Spread.Sheets.NameBox.NameBox(document.getElementById('NameBox'), spread);
    ```

您可以进一步添加名称对话框（Name Box）选项，请参阅以下设置名称对话框（Name Box）选项部分。

## 设置选项

您可以添加各种选项来控制 NameBox 的行为，例如设置下拉列表高度、添加自定义名称、导航到范围以及使用 INameBoxOptions 界面显示自定义名称。

| 选项 | 值 | 描述 |
| --- | --- | --- |
| dropDownMaxHeight | 数字 | 表示下拉列表的最大高度。默认值为500像素。 |
| enableAddCustomName | 布尔值 | 表示在输入选择器中不存在的名称时，是否添加自定义名称。默认值为true。 |
| enableNavigateToRange | 布尔值 | 表示在输入命名区域或绘图项的名称，或者点击自定义列表项时，是否导航到该命名区域或绘图项。默认值为true。 |
| showCustomNameList | 布尔值 | 表示是否显示自定义名称列表的下拉指示符。 |

以下代码显示了如何设置 NameBox 选项：

```JavaScript
 var nameBox = new GC.Spread.Sheets.NameBox.NameBox(document.getElementById('NameBox'), spread, {
     showCustomNameList: false,
     dropDownMaxHeight: 200,
     enableAddCustomName: false,
     enableNavigateToRange: false
 });
```
