# UsingHitTesting

命中测试会在图形用户界面上生成对用户操作的响应。
SpreadJS通过允许用户获取鼠标单击事件的单元格索引来支持命中测试。 当您需要访问表单中的任何元素并响应用户选择时，此功能很有用。 使用命中测试，您可以从工作簿中的X和Y坐标获取指定的命中区域，并知道用户单击了表单的哪些部分。
**hitTest** 方法在 **Workbook** 类允许用户从工作簿中的X和Y坐标获取特定的点击区域。 使用此方法，可以快速识别哪个元素位于工作簿中的指定屏幕坐标处。
请参考下表以了解工作簿中的不同点击区域及其在不同点击区域中的子区域（称为点击区域元素）。

| 表单区域 | 点击区域标签 |
| ---- | ------ |
| Worksheet | corner, rowHeader, colHeader, viewport |
| Sheet Tab | prevArrow, nextArrow, sheetName, blank, resize |
| Horizontal Scroll Bar | leftButton, rightButton, thumbButton, trackButton |
| Vertical Scroll Bar | upButton, downButton, thumbButton, trackButton |
| Footer Corner | footerCorner |

## 使用代码

本示例展示如何使用 [hitTest ](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0#hittest)方法进行命中检测。当用户在工作簿中的某个区域点击时，会调用 [hitTest ](gcdocsite__documentlink?toc-item-id=8a4039d6-22a0-4e4c-81a6-dd3e37d185b0#hittest)方法，它会根据工作簿中的X和Y坐标返回命中区域。

```javascript
var hitArea = workbook.hitTest(0,0)
```
