# formula-auditing

SpreadJS通过允许用户显示公式与单元格之间的关系，为公式审核提供了广泛的支持。这可以通过追踪工作表中的引用单元格和从属单元格来实现。

## 公式审核的好处

公式审核有助于用户在使用电子表格时识别计算瓶颈、调试公式以及验证结果的准确性。此外，此功能还能帮助用户：

* **保持法规遵从性** \- 在处理财务、会计和其他复杂应用程序时，公式审核功能对于保持法规遵从性非常有用。
* **检查错误** \- 公式审核可帮助用户识别错误来源，否则这将是一项极其困难的任务，尤其是当工作表中的公式使用了引用单元格或从属单元格时。
* **定位循环引用** \- 通过公式审核，用户可以通过追踪工作表内的引用单元格和从属单元格快速找到所有循环引用，从而节省数小时的时间。
* **检测不一致性** \- 在大型工作表中，用户可以推测公式中的任何列是否存在不一致性，而无需在验证数据时手动检查每个公式。

## 追踪引用单元格和从属单元格

引用单元格是指被另一个单元格中的公式所引用的单元格。从属单元格是指包含公式并引用其他单元格的单元格。
例如，如果单元格D10包含公式“=B5”，那么单元格B5将被视为单元格D10的引用单元格，而单元格D10将被视为单元格B5的从属单元格。
在审核工作表中的公式时，您可以使用 **getPrecedents()** 方法来追踪引用单元格，并使用 **getDependents** 方法来追踪从属单元格，以可视化和显示与所选公式单元格相关的单元格。

## 使用场景

例如，假设您正在处理一个金融或银行应用程序，其中使用电子表格中的公式分析每月交易（贷方和借方），并为每个客户生成月度报告。在这种情况下，单个计算错误可能会直接导致损失，因此在与客户共享月度会计报告之前审核公式成为一项先决条件。

// 将引用单元格涂成黄色
function ColorPrecedents(sheet, row, col)
{
  if (oldPrecedentCells)
  {
    oldPrecedentCells.forEach(function (node)
    {
      sheet.getCell(node.row, node.col).backColor(undefined);
    });
  }
  var precedentCells = sheet.getPrecedents(row, col);
  if (precedentCells)
  {
    setTimeout(function ()
    {
      oldPrecedentCells = precedentCells;
      precedentCells.forEach(function (node) {
      sheet.getCell(node.row, node.col).backColor("yellow");});}, 10);
  }
}
// 将从属单元格涂成绿色
function ColorDependents(sheet, row, col)
{
  if (oldDependentCells)
  {
    oldDependentCells.forEach(function (node) {
    sheet.getCell(node.row, node.col).backColor(undefined);
    });
  }
  var dependentCells = sheet.getDependents(row, col);
  oldDependentCells = dependentCells;
  if (dependentCells) {
    dependentCells.forEach(function (node) {
      sheet.getCell(node.row, node.col).backColor("green");
    });
  }
}
