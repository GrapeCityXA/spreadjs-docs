# calculating-formulas-outside-worksheets

SpreadJS 提供了一个强大的计算引擎，使你能够在工作表单元格之外计算公式并执行计算。[`GC.Spread.Sheets.CalcEngine`](https://docs.grapecity.com.cn/spreadjs/help/api//modules/GC.Spread.Sheets.CalcEngine) 模块包含多个实用方法，用于解析、计算和转换公式，而无需直接在工作表中设置这些公式。
准备一个包含销售数据的表格。

## evaluateFormula：计算指定的公式字符串并返回结果。

**使用场景**：

* 当你需要在代码中动态计算公式结果时（例如，在后端处理数据或对公式逻辑进行批量验证时），无需依赖工作表的渲染或用户操作。
* 当你需要保留数组公式的多个输出时，使用 `preserveArrayResult: true` 来获取完整的数组。
* 当在代码中生成或解析 R1C1 格式的公式时。

**方法**：`evaluateFormula(context, formula, baseRow?, baseColumn?, useR1C1?, preserveArrayResult?)`
**参数**：

* **`context`**（对象）——计算上下文（通常是活动工作表对象）。
* **`formula`**（字符串）——要计算的公式字符串。
* **`baseRow`**（数字，可选）——相对引用的基行索引。
* **`baseColumn`**（数字，可选）——相对引用的基列索引。
* **`useR1C1`**（布尔值，可选）——是否使用 R1C1 引用样式（默认值：`false`）。
* **`preserveArrayResult`**（布尔值，可选）——如果为 `true`，则返回数组结果；否则，返回单个值。

**示例 1**：直接获取计算结果。

```javascript
var sheet = spread.getActiveSheet();
GC.Spread.Sheets.CalcEngine.evaluateFormula(sheet, '=SUM(Table1[[#Data],[Units]])')
//结果: 84878
```

**示例 2**：结合 baseRow 和 baseColumn 使用相对引用。

```javascript
var sheet = spread.getActiveSheet();
GC.Spread.Sheets.CalcEngine.evaluateFormula(sheet, '=Table1[@[Sales Rep]]',2,0);
//结果: Tom
GC.Spread.Sheets.CalcEngine.evaluateFormula(sheet, '=Table1[@[Sales Rep]]',5,0);
//结果: Sal
GC.Spread.Sheets.CalcEngine.evaluateFormula(sheet, '=Table1[@[Sales Rep]]',12,0);
//结果: Amy
```

**示例 3**：结合 baseRow 和 baseColumn 使用 R1C1 样式。

```javascript
var sheet = spread.getActiveSheet();
GC.Spread.Sheets.CalcEngine.evaluateFormula(sheet, '=R[3]C[3]',0,0,true);
//结果: Grape
GC.Spread.Sheets.CalcEngine.evaluateFormula(sheet, '=R[3]C[3]',2,1,true);
//结果: 5323
```

**示例 4**：使用 preserveArrayResult 检索数组结果。

```javascript
var sheet = spread.getActiveSheet();
spread.options.allowDynamicArray = true; 
GC.Spread.Sheets.CalcEngine.evaluateFormula(sheet, '=UNIQUE(Table1[[#Data],[Product]])')
//结果: Apple
GC.Spread.Sheets.CalcEngine.evaluateFormula(sheet, '=UNIQUE(Table1[[#Data],[Product]])',null,null,null,true)
//结果: [['Apple'],['Grape'],['Pear'],['Banana']]
```

## expressionToFormula：将表达式转换回公式字符串。

**使用场景**：

* 动态构建复杂公式（以避免字符串拼接的风险），通常与 formulaToExpression 一起使用。
* 解析自定义名称的表达式并生成相应的公式。

**方法**：`expressionToFormula(context, expression, baseRow?, baseColumn?, useR1C1?)`
**参数**：

* **`context`**（对象）——上下文（通常是活动工作表对象）。
* **`expression`**（GC.Spread.CalcEngine.Expression）——要转换的表达式树。
* **`baseRow`**（数字，可选）——相对引用的基行索引。
* **`baseColumn`**（数字，可选）——相对引用的基列索引。
* **`useR1C1`**（布尔值，可选）——是否使用 R1C1 引用样式（默认值：`false`）。

**示例**：将命名表达式转换为公式字符串。

```javascript
var sheet = spread.getActiveSheet();
sheet.addCustomName('averageUnits', '=AVERAGE(Table1[[#Data],[Units]])');
var cname = sheet.getCustomName("averageUnits");
var expr = cname.getExpression();
GC.Spread.Sheets.CalcEngine.expressionToFormula(sheet,expr);
//结果: AVERAGE(Table1[[#Data],[Units]])
```

## formulaToExpression：将公式字符串解析为表达式。

**使用场景**：

* 你需要通过编程方式解析现有公式，修改某些参数或逻辑，然后重新生成公式。
* 检查公式中引用的单元格、函数或依赖项，以进行数据流分析或审计。
* 当在 R1C1 和 A1 样式之间转换时，需要先将公式解析为表达式树，然后再进行重构。
* 避免使用字符串进行公式验证；使用表达式可以进行更好的分析。

**方法**：`formulaToExpression(context, formula, baseRow?, baseColumn?, useR1C1?)`
**参数**：

* **`context`**（对象）——计算上下文（通常是活动工作表对象）。
* **`formula`**（字符串）——要计算的公式字符串。
* **`baseRow`**（数字，可选）——相对引用的基行索引。
* **`baseColumn`**（数字，可选）——相对引用的基列索引。
* **`useR1C1`**（布尔值，可选）——是否使用 R1C1 引用样式（默认值：`false`）。

**示例**：将公式转换为表达式对象。

```javascript
var sheet = spread.getActiveSheet();
var expr = GC.Spread.Sheets.CalcEngine.formulaToExpression(sheet, '=CONCAT(Table1[@Region],Table1[@[Sales Rep]],Table1[@Product])',4,0)
//结果:
//expr.functionName 是 CONCAT
//expr.arguments.length 是 3
```

## formulaToRanges：将公式字符串转换为引用的单元格区域数组。

**使用场景**：

* 快速获取公式引用的所有单元格区域，以构建数据依赖图或进行影响链分析。
* 在用户界面中突出显示公式引用的所有单元格，以帮助用户直观地理解公式逻辑。
* 当你需要处理公式的物理位置信息（行和列索引）而不是其逻辑结构时，此方法比 formulaToExpression 更直接和高效。

**方法**：`formulaToRanges(sheet, formula, baseRow?, baseCol?)`
**参数**：

* **`sheet`**（GC.Spread.Sheets.Worksheet）——基础工作表。
* **`formula`**（字符串）——要分析的公式。
* **`baseRow`**（数字，可选）——相对引用的基行索引。
* **`baseColumn`**（数字，可选）——相对引用的基列索引。

**示例**：获取公式中所有引用的区域。

```javascript
var sheet = spread.getActiveSheet();
var result = GC.Spread.Sheets.CalcEngine.formulaToRanges(sheet, '=SUM(A1,A2,A5:C8)');
//结果:
//result.sheetName 是 Sheet1
//result.ranges:[
//  Range {row: 0, rowCount: 1, col: 0, colCount: 1}
//  Range {row: 1, rowCount: 1, col: 0, colCount: 1}
//  Range {row: 4, rowCount: 4, col: 0, colCount: 3}
//  Range {row: 2, rowCount: 16, col: 4, colCount: 1}
//]
```

## rangesToFormula：将区域数组转换为公式字符串。

**使用场景**：

* 当你需要根据运行时数据动态构造区域引用公式时（例如，根据用户选择或数据量自动调整区域）。
* 当在代码中处理工作表引用时，避免手动拼接复杂的引用字符串。
* 你需要灵活地在相对引用和绝对引用之间切换。

**方法**：`rangesToFormula(ranges, baseRow?, baseCol?, rangeReferenceRelative?, useR1C1?)`
**参数**：

* **`ranges`**（GC.Spread.Sheets.Range[]）——要转换的区域。
* **`baseRow`**（数字，可选）——相对引用的基行索引。
* **`baseColumn`**（数字，可选）——相对引用的基列索引。
* **`rangeReferenceRelative`**（RangeReferenceRelative，可选）——指定引用的相对性（绝对/相对）。
* **`useR1C1`**（布尔值，可选）——是否使用 R1C1 样式。

**示例**：将区域数组转换为相应的公式。

```javascript
var ranges = [
    new GC.Spread.Sheets.Range(0,0,1,1),
    new GC.Spread.Sheets.Range(3,3,5,5),
];
GC.Spread.Sheets.CalcEngine.rangesToFormula(ranges,0,0,GC.Spread.Sheets.CalcEngine.RangeReferenceRelative.allRelative);
//结果: 'A1, D4:H8'
GC.Spread.Sheets.CalcEngine.rangesToFormula(ranges,0,0,GC.Spread.Sheets.CalcEngine.RangeReferenceRelative.allRelative);
//结果: '$A$1, $D$4:$H$8'
GC.Spread.Sheets.CalcEngine.rangesToFormula(ranges,0,0,GC.Spread.Sheets.CalcEngine.RangeReferenceRelative.colRelative);
//结果: 'A$1, D$4:H$8'
GC.Spread.Sheets.CalcEngine.rangesToFormula(ranges,0,0,GC.Spread.Sheets.CalcEngine.RangeReferenceRelative.allRelative, true);
//结果: 'RC, R[3]C[3]:R[7]C[7]'
```
