# formula-edit-panel

在狭窄的公式栏或单个单元格框中查看和编辑冗长复杂的公式十分困难。因此，公式编辑器允许你以多行缩进的形式显示冗长复杂的公式，方便阅读和编辑。
SpreadJS 以插件的形式提供此功能，该插件依赖于 `gc.spread.sheets.formulapanel.x.x.x.min.js` 脚本文件。因此，若要使用公式编辑器面板，你需要在应用程序中引入此脚本文件。为使工作簿与公式编辑器面板同步工作，你需要使用 `attach()` 方法将它们绑定在一起。
以下代码示例将工作簿绑定到公式编辑器面板。

```javascript
let workbook = new GC.Spread.Sheets.Workbook("spread-host");
let formulaEditor = new GC.Spread.Sheets.FormulaPanel.FormulaEditor("formula-editor-host");
formulaEditor.options.formatWidthLimit = -1;
formulaEditor.options.tabSize = 4;
formulaEditor.attach(workbook);
......
<!--DOM 元素-->
<div id="spread-host" style="width:100%; height:250px;border: 1px solid gray;"></div>
<div id="formula-editor-host" style="width:100%; height:300px;border: 1px solid gray;"></div>
```

公式编辑器提供了 **formatWidthLimit** 选项，可根据所选限制更改公式文本的宽度。可用的值如下：

| **值** | **描述** |
| --- | --- |
| Auto | 根据 DOM 容器的宽度调整公式文本的宽度。如果文本长度超过 DOM 容器的宽度，则仅将公式拆分为多行。 |
| 数字 | 当公式表达式（包括子表达式）的长度超过指定值时，调整公式文本的宽度。如果将值设置为 -1，则将公式表达式格式化为多行。 |

此外，**tabSize** 选项用于在按下 Tab 键时，在公式表达式前插入制表符空格。

## 主要功能

以下是公式编辑器的主要功能。
**格式化器**：调整公式的缩进、间距、换行等，使公式更易读、更易于维护。
![Formula adjustments.c2855a](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/Formula%20adjustments.c2855a.602e44.png)
**自动补全建议**：提供公式自动补全、函数参数提示等功能，提高编写公式的效率。在输入公式时，它会智能地建议可用的函数、自定义名称、枚举参数等。
![image.aa0fb0](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.aa0fb0.1600f8.png)
**灵活的大纲视图**：允许在公式编辑器中折叠和展开公式视图。
![ExpandCollapsePanel.bfa73a](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ExpandCollapsePanel.bfa73a.669341.png)
**语法高亮**：通过突出显示公式中的不同语法元素，增强可读性和可用性。
![image.c6d484](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.c6d484.94cb79.png)
**语法检查选项**：提供错误提示，如函数参数使用不当、括号不匹配等，以减少错误。
![ErrorMessage.0659ab.7d2b0b](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/ErrorMessage.0659ab.7d2b0b.d1ba1a.png)
**工具提示信息**：当用户将鼠标悬停在函数上或输入函数时，显示包含函数详细信息的工具提示。
![image.8f955d](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.8f955d.0a5959.png)
**主题定制**：提供多种主题，并允许自定义现有主题，以更改编辑器的外观。
![FormulaEditorTheme.40ff2c.ec542c](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/FormulaEditorTheme.40ff2c.ec542c.703e28.png)
通过修改 CSS 文件，你可以更改公式编辑器的外观，如字体、工具提示、背景、前景、引用区域等。
以下 CSS 代码展示了如何定义公式编辑器面板中函数、字符串、前景和背景的字体族和颜色。

```javascript
// 定义函数标记的颜色
.gc-formula-editor-token-function {
 color: blue;
}

// 定义字符串标记的颜色
.gc-formula-editor-token-const-string {
  color: red;
}

// 定义公式编辑器的颜色、背景颜色和字体
.gc-formula-editor-content {
color: black;
background-color: white;
font: 16px, sans-serif;
}
```

## 在设计器中使用

要在 Spread Designer 中开始使用公式编辑器，你需要选择包含要编辑公式的单元格，然后点击位于 FORMULAS > Formulas Auditing 选项卡组中的 **Show Formula Editor** 按钮。
公式编辑器允许你选择公式在面板上的显示方式。你可以编辑公式视图以及公式文本。编辑后的公式可以使用 **Save** 按钮保存。保存后，SpreadJS 会自动将编辑器中的文本同步到单元格中。你也可以使用 `editor.commandManager` API 进行异步操作。此外，**Format** 按钮可用于获取应用公式的格式化树状视图，还能更改公式宽度和制表符大小限制。

## 快捷键

在使用格式编辑器格式化公式时，你可以使用以下快捷键。

| **快捷键** | **操作** |
| --- | --- |
| Alt+Shift+F | 格式化文档 |
| F4 | 切换绝对引用和相对引用 |
| Ctrl+S | 将内容提交到活动单元格 |
| ESC | 退出编辑/关闭提示 |
| Ctrl+Shift+空格 | 显示提示 |
