# custom-name

自定义用户定义名称是表示工作表中信息的标识符。一个自定义名称可以引用一个单元格区域或一个公式。
你可以定义一个自定义名称，然后在公式中使用该名称。当计算公式时，会引用并计算该自定义名称的值。使用 [addCustomName ](gcdocsite__documentlink?toc-item-id=995f2b70-17d8-47a4-8e09-962f84b4dfc1#addCustomName)方法来创建一个自定义名称。
以下代码示例创建了一个自定义名称。

```javascript
activeSheet.setValue(0, 0, 1);
activeSheet.setValue(0, 1, 2);
activeSheet.setValue(0, 2, 3);

// 通过将 isReadOnly 参数设置为 true 来添加自定义名称
activeSheet.addCustomName("customName1","=12", 0, 0, 'readonly', true);

activeSheet.addCustomName("customName2","Average(20,45)", 0, 0);
activeSheet.addCustomName("customName3", "=$B$1:$C$1", 0, 0);

activeSheet.setFormula(1, 0, "customName1");
activeSheet.setFormula(1, 1, "customName2");
activeSheet.setFormula(1, 2, "sum(customName3)");
```

在 SpreadJS 设计器中，SpreadJS 不允许你从 [名称管理器对话框](gcdocsite__documentlink?toc-item-id=3405eaa9-d0d2-4dd3-aaee-d84a310e9bad#%E4%BD%BF%E7%94%A8%E5%90%8D%E7%A7%B0%E7%AE%A1%E7%90%86%E5%99%A8%E5%AF%B9%E8%AF%9D%E6%A1%86) 中更改或删除只读的自定义名称。如果你选择了一个只读的自定义名称，“编辑” 和 “删除” 按钮将被禁用，并且双击该只读自定义名称将不会有任何反应。自定义名称的只读状态只能通过 API 来设置或更改。

## 更新自定义名称

你可以使用 [NameInfo ](gcdocsite__documentlink?toc-item-id=45d80708-1600-4d63-b809-2721f631d86b)类的 `set` 方法来更新公式或任何其他信息，例如更改现有自定义名称的名称或注释。
以下代码示例可让你更新自定义名称信息：

```javascript
// 重命名自定义名称时，所有引用的公式都会重新计算。
activeSheet.getCustomName("customName2").set("updatedName");
```

若工作表内未定义自定义名称，那些未指明工作表名称的自定义名称公式，会自动调整为使用工作簿（Spread）实例中的自定义名称 。
以下代码示例可让你使用电子表格的自定义名称：

```javascript
spread.sheets[0].setFormula(0, 0, "=customName1+1");
spread.sheets[0].setFormula(1, 0, "=Sheet1!customName1+1");
spread.addCustomName("customName1", "111"); // A1 显示 111，A2 保持 #NAME!
spread.getCustomName("customName1").set("customUpdateName1"); // A1:=bbb+1 A2:=Sheet1!customName1+1
```

但是，如果要更新的自定义名称已经存在，则会抛出 “**无效的自定义名称**” 错误。例如：

```javascript
activeSheet.addCustomName("updatedName", "222");
activeSheet.getCustomName("customName2").set("updatedName");
```

SpreadJS 支持的用于更新自定义名称信息的其他各种场景如下：

1. 当旧名称未在公式中使用，而新名称在公式中被引用时，在设置名称后，新名称所引用的单元格公式会被重新计算。例如：

    ```javascript
    activeSheet.setFormula(2, 0, "updatedName+1"); // 公式结果为 #NAME!
    activeSheet.getCustomName("customName1").set("updatedName"); // 公式结果为 13
    ```
2. 当新名称和旧名称都在公式中被引用时。例如：

    ```javascript
    // 会抛出异常 '当前名称和新名称都在单元格公式中被引用'。
    activeSheet.setFormula(1, 0, "customName1");
    activeSheet.setFormula(1, 1, "updatedName");
    activeSheet.getCustomName("customName1").set("updatedName");
    ```
3. 更新公式并重命名自定义名称。例如：

    ```javascript
    activeSheet.getCustomName("customName2").set("updatedName","SUM(20,45)");
    ```
4. 使用基行和基列更新自定义名称公式并更新注释。例如：

    ```javascript
    activeSheet.getCustomName("customName2").set(null,"=A1", 0,1, "左上角相邻的单元格");
    ```
5. 更新自定义名称注释。例如：

    ```javascript
    activeSheet.addCustomName("customName4", "=$A$1");
    activeSheet.getCustomName("customName4").set(null, null, null, null, "当前工作表中的 A1 单元格");
    ```
6. 更新在另一个自定义名称中使用的自定义名称。例如：

    ```javascript
    activeSheet.addCustomName("customName4", "=$A$1");
    activeSheet.addCustomName("customName5", "=customName4+1");
    activeSheet.getCustomName("customName4").set("customName6", "=$C$2", null, null); // 自定义名称 customName5 将变为 "=customName6+1"
    ```
7. 更新在另一个自定义名称中使用的自定义名称，其中旧名称未被使用但新名称已在使用。例如：

    ```javascript
    activeSheet.addCustomName("customName4", "=$A$1");
    activeSheet.addCustomName("customName5", "=customName6+1");
    activeSheet.getCustomName("customName4").set("customName6", "=$D$2", null, null); // customName4 将更改为 customName6
    ```

> **注意**：SpreadJS 不会根据工作簿的自定义名称来修改公式。
