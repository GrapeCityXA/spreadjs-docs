# create-data-charts

要创建数据图表，请按照以下步骤操作：

1. 添加以下CSS和脚本文件以使用数据图表。

    ```javascript
     <link href="css/gc.spread.sheets.x.x.x.css" rel="stylesheet" />
     <script src="scripts/gc.spread.sheets.all.x.x.x.min.js"></script>
     <script src="scripts/gc.spread.sheets.shapes.x.x.x.min.js"></script>
     <script src="scripts/gc.spread.sheets.datacharts.x.x.x.min.js"></script>
    ```
2. 使用标记为 `async` 的函数运行 `window.onload` 事件。然后，在 SpreadJS 环境中创建一个 spread 实例并检索工作表以添加数据图表。

    ```javascript
    let spread = new GC.Spread.Sheets.Workbook("spreadjs-host");
    const sheet = spread.getActiveSheet();
    ```
3. 使用 `dataManager` 方法初始化数据管理器实例。

    ```javascript
    const dataManager = spread.dataManager();
    ```
4. 在数据管理器中创建一个表，并使用 `fetch()` 方法从指定源获取数据。
    使用 `await` 确保代码执行暂停，直到数据完全获取。注意，`await` 仅在 `async` 函数中有效。

    ```javascript
    const salesTable = createSalesTable(dataManager);
    await salesTable.fetch();
    ```

6. 使用 `sheet.dataCharts.add()` 方法在指定坐标创建数据图表。

    ```javascript
    const dataChart = sheet.dataCharts.add('data-chart', 10, 10, 600, 400);
    ```
7. 使用 `setChartConfig()` 方法配置数据图表的特定设置。在此示例中，应用了类型和编码值、类别和颜色。
    然而，数据图表有多个元素可以在添加时自定义。要了解更多信息，请参阅 [数据图表元素](gcdocsite__documentlink?toc-item-id=17820e1d-8560-424e-8958-7351656f92b4)。

    ```javascript
    dataChart.setChartConfig({
        tableName: 'Sales',
        config: {
            header: {
                title: "Bar Chart"
            }
        },
        plots: [
            {
                type: GC.Spread.Sheets.DataCharts.DataChartType.bar,
                encodings: {
                    values: [
                        {
                            field: "Sales",
                            aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum
                        }
                    ],
                    category: {
                        field: "Product"
                    },
                    color: {
                        field: "Product"
                    }
                },
    
            }
        ]
    });
    ```
