# scatter-charts

**散点图**通常用于说明各个项目或类别之间的关系。这种类型的图表常用于表示科学数据，并强调所收集数据与预测数据或结果的偏差。
SpreadJS 提供了多种类型的散点图，可通过修改图表属性（如调色板、图形不透明度、点符号、数据标签样式以及类别轴和数值轴的样式）进行自定义。这些更改可以通过代码实现，也可以使用 SpreadJS 设计器中的 [“检查器”](gcdocsite__documentlink?toc-item-id=55f14079-f4d7-48fe-aebc-ed9390deeb94) 选项卡来完成。

> 本主题中的所有示例都基于[创建数据图表](gcdocsite__documentlink?toc-item-id=83b6d588-0f69-4b37-9a6e-f9aa6a2b714e)页面中的 “salesTable” 数据。因此，请确保你已遵循该页面中提到的添加数据图表的主要步骤。你也可以自定义数据源以满足你的特定需求。

## 散点图

散点图直观地展示了两个数值变量之间的关系。图表上的每个数据点对应于所绘制的两个变量的一次观测。每个点的位置由其 x 坐标（水平轴）和 y 坐标（垂直轴）确定。
如下所示为散点图的示例图像：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.ecf851.png)
请参考以下示例代码添加散点图：

```javascript
// Scatter Chart
const sheet = spread.getActiveSheet();
sheet.name("Scatter Chart");
const dataChart = sheet.dataCharts.add('data-chart', 10, 10, 600, 400);
dataChart.setChartConfig({
    tableName: 'Sales',
    config: {
        header: {
            title: "Scatter Chart"
        }
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.scatter,
            encodings: {
                values: [
                    {
                        field: "Return",
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum
                    },
                    {
                        field: "Sales",
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum
                    }
                ],
                color: {
                    field: "Product"
                }
            }
        }
    ]
});
```

## 气泡图

气泡图展示了散点图的变体，其中数据点被气泡取代，并且以气泡的形状表示第三个维度（z 轴）。每个气泡的位置由其在 x 轴和 y 轴上的值决定，而气泡的大小表示第三个数值。
如下所示为气泡图的示例图像：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/image.61b2f5.png)
请参考以下示例代码添加气泡图：

```javascript
// Bubble Chart
const sheet = spread.getActiveSheet();
sheet.name("Bubble Chart");
const dataChart2 = sheet.dataCharts.add('data-chart-2', 10, 10, 600, 400);
dataChart2.setChartConfig({
    tableName: 'Sales',
    config: {
        header: {
            title: "Bubble Chart"
        }
    },
    plots: [
        {
            type: GC.Spread.Sheets.DataCharts.DataChartType.bubble,
            encodings: {
                values: [
                    {
                        field: "Return",
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum
                    },
                    {
                        field: "Sales",
                        aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum
                    }
                ],
                color: {
                    field: "Product"
                },
                size: {
                    field: "Return",
                    aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum
                }
            }
        }
    ]
});
```
