# data-label

数据标签直接在图表上显示关于数据点的额外信息。你可以添加、设置格式和自定义数据标签以满足特定的用户需求。
在 `GC.Spread.Sheets.DataCharts` 命名空间中使用 `IPlotConfigTextOption` 接口来配置和管理数据图表中的数据标签。它提供了几个属性用于自定义标签的外观和行为，包括模板、文本样式、偏移量和连接线样式等。此外，使用 `OverlappingLabels` 和 `TextPosition` 枚举，你可以分别管理重叠标签的可见性和标签文本的定位。

## 数据标签属性

以下列出了 `IPlotConfigTextOption` 接口的关键属性：

| 属性 | 描述 |
| --- | --- |
| template | 自定义数据标签的结构。 |
| format | 自定义数据标签值的格式。 |
| style | 自定义数据标签的外观和样式，如填充、填充不透明度、描边、描边宽度、描边虚线数组、描边不透明度。 |
| textStyle | 自定义数据标签内的文本样式，如字体大小、字体粗细、字体系列、颜色、字体样式和溢出处理方式。 |
| maxWidth | 设置数据标签的最大宽度。如果数据标签文本超出最大宽度，文本将根据 `textStyle.overflow` 设置显示。 |
| offset | 调整数据标签相对于原始数据标签位置的偏移量。 |
| overlappingLabels | 控制重叠数据标签的可见性。 |
| position | 指定数据标签相对于数据点的位置。 |
| connectingLineStyle | 自定义数据点和数据标签之间连接线的样式，如描边、描边宽度、描边虚线数组等。需要注意的是，对于设置连接线样式：可见连接线的 `strokeWidth` 值必须大于 0；在饼图中使用 `firstLineLength` 和 `secondLineLength` 来调整标签连接。 |

## 使用代码

参考以下示例代码在数据图表上配置和自定义数据标签。
请注意，此示例使用了 “[创建数据图表](gcdocsite__documentlink?toc-item-id=83b6d588-0f69-4b37-9a6e-f9aa6a2b714e)” 页面中提到的 “salesTable” 数据。因此，请确保你已完成该页面概述的主要步骤来设置数据图表。完成后，你可以使用以下代码配置数据标签。此外，你还可以根据具体需求灵活自定义数据源。

// 1. Data Label Template
const sheet = spread.getSheet(0);
sheet.name("Template");
sheet.setValue(23, 0, "Template Applied: '{colorField.name}: {colorField.value}\n{valueField.name}: {valueField.value}'");

const dataChart = sheet.dataCharts.add('data-chart', 10, 10, 800, 400, GC.Spread.Sheets.DataCharts.DataChartType.column);
dataChart.setChartConfig({
     tableName: 'Sales',
     plots: [
         {
             type: GC.Spread.Sheets.DataCharts.DataChartType.column,
             config: {
                 text: [{
                     // Set the Template To the Data Label
                     template: '{colorField.name}: {colorField.value}\n{valueField.name}: {valueField.value}', // string
                     position: GC.Spread.Sheets.DataCharts.TextPosition.outside, // GC.Spread.Sheets.DataCharts.TextPosition
                 }]
             },
             encodings: {
                 values: [{ field: 'Sales', aggregate: GC.Spread.Sheets.DataCharts.Aggregate.sum }],
                 category: { field: 'Product' },
                 color: { field: 'Product' },
             }
         }
     ]
});
