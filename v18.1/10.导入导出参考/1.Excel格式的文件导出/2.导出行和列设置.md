# excelrowcolex

下表总结了SpreadJS导出到Excel格式的文件时如何处理列和行设置。 除非另有说明，否则这些函数在GC.Spread.Sheets.Worksheet类中。

|  **导出行和列设置**  |  **Excel 设置与备注**  |
|--- |--- |
| Column 或 Row Visible | Excel使用此设置。 |
| Row Height | Excel使用此设置。 |
| Column Width | Excel使用此设置。 |
| Row Width | Excel忽略表单设置。 这特定于SpreadJS。 |
| Column Height | Excel忽略表单设置。 这特定于SpreadJS。 |
| Row 或 Column allowUserResize | Excel忽略表单设置。 这特定于SpreadJS。 |
| Starting Column 与 Row | 目前不支持。 |
