# UseCustomFontforPDFExport

SpreadJS 中的导出为 PDF 功能允许用户嵌入标准字体和自定义字体。如果用户在导出为 PDF 时不想使用标准字体，他们可以使用自定义字体。
使用自定义字体时，PDF 文件中会嵌入该字体的子集。但用户在执行导出操作时必须嵌入字体文件。
要为导出 PDF 注册自定义字体，可以使用 PDFFontManager 类的 registerFont 方法。 你还可以使用 PDFFontManager 类的 fallbackFont 方法为特定字体字符串提供自定义字体文件。
> **注意：** SpreadJS 不支持导出.ttc 字体。只有 True Type 字体（.ttf 字体）和 Open Type 字体（.otf）可以成功导出。如果用户想使用.ttc 字体，他们可以使用在线转换器将其转换为.ttf 格式，然后在导出为 PDF 时使用。
此示例展示了如何使用 registerFont 方法注册自定义字体。
```JavaScript
var font = {
    normal: fonts['SIMSUN.ttf']
};
GC.Spread.Sheets.PDF.PDFFontsManager.registerFont('SimSun', font);
```
以下代码示例展示了如何使用 fallbackFont 方法为特定字体字符串提供自定义字体文件。
```JavaScript
GC.Spread.Sheets.Print.PDFFontsManager.fallbackFont = function (font) {
    var fontInfoArray = font.split(' '), fontName = fontInfoArray[fontInfoArray.length - 1];
    if (fontName === 'Calibri') {
        return Calibri.ttf(使用 base64 编码);
    }
    return Arial.ttf(以 ArrayBuffer 形式)
}
```
> **注意：** 在导出 PDF 时使用自定义字体时，必须确保该字体包含你所使用的所有字符集。否则可能会导致你的 PDF 文件无法读取。
