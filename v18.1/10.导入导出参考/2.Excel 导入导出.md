# excelclient

SpreadJS 支持使用以下提到的方式导入和导出 Excel 文件：

* 在客户端导入和导出 Excel 文件
* 使用 SJS 文件格式进行导入和导出
* 导入和导出加密的 Excel 文件

## 在客户端导入和导出

你可以在客户端使用 `import` 和 `export` 方法将 Excel 文件（.xlsx）导入为 JSON 格式，并将 JSON 对象导出为 Excel 文件。
导出的 Excel 文件是锁定的，因为该文件来自互联网。Excel 文件的导出发生在客户端，而不是服务器端。因此，在客户端下载会导致文件被锁定。所以，当你首次打开该 Excel 文件时，它会显示一条警告消息。
你必须包含 `<!DOCTYPE html>` 才能正确显示组件，并且需要引用文件 `gc.spread.sheets.io.x.x.x.min.js` 来导入和导出 Excel 文件。
你可以在本地下载 Excel 文件，或者获取返回的 Excel 文件（类型：blob）并将其发送到服务器。

### 使用代码

以下示例展示了导入和导出 Excel 文件的操作。请注意，代码的第一部分列出了客户端导入和导出所需的依赖项。

```javascript
<!DOCTYPE html>
<html lang="en">
<head>
    <link href="css/gc.spread.sheets.excel2013white.x.x.x.css" rel="stylesheet" />
    <script src="scripts/gc.spread.sheets.all.x.x.x.min.js" type="application/javascript"></script>
    <script src="scripts/gc.spread.sheets.io.x.x.x.min.js"></script>
    <script src="scripts/FileSaver.js"></script>
    <script>
        var spread;
        window.onload = function () {
            spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"));
        }
        // 将 xlsx、ssjson、csv 文件导入到 spread 中。
        function ImportFile() {
            var file = document.getElementById("fileDemo").files[0];
            spread.import(file, function () {
            // 成功回调函数，可在此处执行一些操作
            }, function (e) {
               console.log(e); // 错误回调函数
            }, {
               fileType: GC.Spread.Sheets.FileType.excel
            });
        }
        // 将 spread 导出为 xlsx、ssjson、csv 文件。
        function ExportFile() {
            var fileName = "fileNamehere.xlsx";      
            spread.export(function (blob) {
                // 将 blob 保存为文件
                saveAs(blob, fileName);
            }, function (e) {
               console.log(e);
            }, {
               fileType: GC.Spread.Sheets.FileType.excel
            });
        }
    </script>
</head>
<body>
    <div>
        <input type="file" name="files[]" id="fileDemo" accept=".xlsx" />
        <input type="button" id="loadExcel" value="Import" onclick="ImportFile()" />
        <input type="button" class="btn btn-default" id="saveExcel" value="Export" onclick="ExportFile()" />
        <div id="ss" style="width:100%; height:500px"></div>
    </div>
</body>
</html>
```

## 使用 SJS 文件格式进行导入和导出

你可以使用 `open` 和 `save` 方法将 Excel 文件（.xlsx）导入为 .SJS（SpreadJS 文件类型）格式，并将 .SJS 文件导出为 Excel 文件。使用 .SJS 格式，在处理非常大的 Excel 文件时，导入的文件可以显著提高加载速度并减少内存使用。在重新保存时，它还会显著减小文件大小。
以下示例展示了使用 `open` 和 `save` 方法打开和保存 Excel 文件的操作。

```javascript
// 打开 SJS 文件并加载到 spread 中。
function OpenFile() {
    var excelFile = document.getElementById('fileDemo').files[0];
    spread.open(
        excelFile,
        () => {},
        function (e) {
            console.log(e);
        }
    );
}
// 将 spread 保存为 xlsx 文件。
function SaveFile() {
    var fileName = document.getElementById('exportFileName').value;
    if (fileName.substr(-5, 5) !== '.xlsx') {
        fileName += '.xlsx';
    }
    spread.save(
        sjs,
        function (blob) {
            saveAs(blob, fileName);
        },
        function (e) {
            console.log(e);
        }
    );
}
```

## 导入和导出加密的 Excel 文件

你可以通过在应用程序中添加以下 IO 引用来导入和导出加密的 Excel 文件：
`<script src="scripts/gc.spread.sheets.io.x.x.x.min.js"></script>`

### 导入加密的 Excel 文件

要导入受密码保护的 Excel 文件，你需要在 spread 的 `import` 方法中传递 `password` 属性。如果提供了正确的密码，文件将成功导入。但是，如果提供的密码无效或不正确，将触发 `errorCallBack` 函数，并返回一个错误。使用 [ErrorCode ](gcdocsite__documentlink?toc-item-id=b0402cc0-c3b6-42ec-9df3-eecd781d7998)枚举的成员，你可以指定错误消息。
以下代码示例展示了如何导入加密的 Excel 文件：

```javascript
const userPassword = 'Asdf0123';
// 导入一个带密码的 Excel 文件。
const errorCallback = (e) => {
    if ((e.errorCode = GC.Spread.Sheets.IO.errorCode.invalidPassword)) {
        console.log('密码无效！');
    } else if ((e.errorCode = GC.Spread.Sheets.IO.errorCode.noPassword)) {
        console.log('请输入密码！');
    }
};
spread.import(file, () => {}, errorCallback, {
    fileType: GC.Spread.Sheets.FileType.excel,
    password: userPassword,
});
```

### 导出加密的 Excel 文件

你可以通过指定 spread 的 `export` 方法的 `password` 属性来导出受密码保护的 Excel 文件。在这种情况下，如果输入了密码，SpreadJS 将导出加密的 Excel 文件，否则将导出未加密的原始 Excel 文件。
以下代码示例展示了如何导出加密的 Excel 文件：

```javascript
const userPassword = 'ABC0123';
const fileName = 'encrypt-export.xlsx';
// 导出一个带密码的 Excel 文件。
spread.export(
    (blob) => saveAs(blob, fileName),
    (e) => console.log(e),
    {
        fileType: GC.Spread.Sheets.FileType.excel,
        password: userPassword,
    }
);
```

### 使用设计器

你也可以在 SpreadJS 设计器中导入或导出受保护的 Excel 文件时提供密码。
要导入加密的 Excel 文件，点击 **文件**，然后选择 **导入**。在 **导入** 菜单页面上，选择 **Excel 文件**，指定导入文件的设置，在 **密码** 框中输入密码，然后点击 **导入 Excel 文件**。
