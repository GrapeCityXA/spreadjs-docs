# UsingtheExcelIOElement

在React中使用SpreadJS的Excel输入输出（IO）元素，你可以快速在网页上呈现和展示Excel工作表，同时轻松执行导入和导出操作。

1. **创建React项目**
    打开命令提示符窗口，输入以下命令：

    ```Shell
    npm install -g create-react-app
    create-react-app quick-start
    cd quick-start
    npm start
    ```

    完成后，React项目将在目录中的指定位置创建。有关如何创建React项目的更多信息，请参阅[https://reactjs.org/docs/create-a-new-react-app.html](https://reactjs.org/docs/create-a-new-react-app.html)。
2. **在项目中安装SpreadJS React模块**
    使用以下命令在项目中安装SpreadJS React模块：

    ```Shell
    npm install @grapecity-software/spread-sheets
    npm install @grapecity-software/spread-sheets-react
    ```
3. **将SpreadJS CSS导入到index.js文件**
    使用以下代码将SpreadJS CSS导入到你的index.js文件中：

    ```TypeScript
    import '@grapecity-software/spread-sheets/styles/gc.spread.sheets.excel2013white.css';
    ```
4. **在项目中安装Excel IO React模块和FileSaver React模块**
    使用以下命令在项目中安装Excel输入输出（I/O）和文件保存（file-saver）模块：

    ```Shell
    npm install @grapecity-software/spread-excelio
    npm install file-saver --save
    ```
5. **在React应用程序中使用Excel IO**
    根据你的需求修改App.js文件。浏览器窗口刷新时，更改将立即生效。例如，你可以使用以下示例代码：
    此示例展示了如何在React应用程序中使用Excel IO元素。

    ```TypeScript
    import React from'react';
    import './App.css';
    import GC from '@grapecity-software/spread-sheets';
    import { SpreadSheets, Worksheet } from '@grapecity-software/spread-sheets-react';
    
    // 导入ExcelIO模块
    import * as ExcelIO from "@grapecity-software/spread-excelio";
    
    // 导入文件保存模块
    import saveAs from 'file-saver';
    var SpreadJSKey = "xxx";
    GC.Spread.Sheets.LicenseKey = SpreadJSKey;
    
    // 你需要使用相同的许可证密钥单独授权ExcelIO模块
    ExcelIO.LicenseKey = SpreadJSKey;
    class App extends React.Component {
        constructor(props) {
            super(props);
            this.hostStyle =
                {
                    width: '1100px',
                    height: '800px'
                };
        }
    
    // 处理工作簿初始化事件
        workbookInit = (spread) => {
            this.setState({
                spread: spread
            });
        }
    // 导入Excel
        importFile = () => {
            var excelFile = document.getElementById("fileDemo").files[0];
            // 获取IO类的实例
            let excelIO = new ExcelIO.IO();
            excelIO.open(excelFile, (json) => {
                this.state.spread.fromJSON(json);
            }, (e) => {
                console.log(e);
            });
        }
    // 导出Excel
        exportFile = () => {
            // 获取IO类的实例
            let excelIO = new ExcelIO.IO();
            let fileName = document.getElementById("exportFileName").value;
            if (fileName.substr(-5, 5)!== '.xlsx') {
                fileName += '.xlsx';
            }
            var json = JSON.stringify(this.state.spread.toJSON());
            excelIO.save(json, (blob) => {
                saveAs(blob, fileName);
            }, (e) => {
                console.log(e);
            });
        }
        render() {
            return (
                <div>
                    <input type="file" name="files[]" id="fileDemo" accept=".xlsx" />
                    <input type="button" id="loadExcel" value="导入" onClick={this.importFile} />
                    <input type="button" id="saveExcel" value="导出" onClick={this.exportFile} />
                    <input type="text" id="exportFileName" placeholder="导出文件名" value="export.xlsx" />
                    <SpreadSheets backColor={this.spreadBackColor} hostStyle={this.hostStyle} workbookInitialized={this.workbookInit}>
                        <Worksheet>
                        </Worksheet>
                    </SpreadSheets>
                </div>
            )
        }
    }
    export default App;
    ```
