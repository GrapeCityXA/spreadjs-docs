# knockout

SpreadJS 支持 Knockout。
Knockout 是一个 JavaScript 的 MVVM 库，它使得使用 JavaScript 和 HTML 创建丰富的、类似桌面应用的用户界面变得更加容易。Knockout 使用观察者模式，让用户界面自动与底层数据模型保持同步，同时还具备一套强大且可扩展的声明式绑定。
一个 Knockout 绑定由两部分组成，绑定名称和值，中间用冒号分隔。例如：

```HTML
<span data-bind="text: myMessage"></span>
```

在使用Knockout时，SpreadJS需要自定义绑定。关于自定义绑定的更多信息，请参考 [https://knockoutjs.com/documentation](https://knockoutjs.com/documentation/custom-bindings) 。SpreadJS的绑定名称是 `gc-spread-sheets`。
以下代码示例创建了一个自定义绑定。如果有可用的有效SpreadJS许可证密钥，你也可以在初始化组件之前添加它。

```JavaScript
<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8" />
    <title>Hello SPJS Knockout</title>
    <script src="https://code.jquery.com/jquery-2.1.1.min.js" type="text/javascript"></script>
    <script type='text/javascript' src='scripts/knockout-3.4.0.js'></script>
    <link href="css/gc.spread.sheets.x.x.x.css" rel="stylesheet" />
    <script src="scripts/gc.spread.sheets.all.x.x.x.min.js"></script>

    <script type="text/javascript">

        // 授权SpreadJS。
        GC.Spread.Sheets.LicenseKey = "xxx";        // 输入有效的许可证。

        // 首先定义绑定值。
        // 定义视图模型
        function Product(id, name, price, discontinued) {
            this.id = ko.observable(id);
            this.name = ko.observable(name);
            this.price = ko.observable(price);
            this.discontinued = ko.observable(discontinued);
        }
        var ViewModel = function (items) {
            this.items = ko.observableArray(items);
        };

        // 创建视图模型
        var initialData = [
            new Product(104, "Computers", 262, false),
            new Product(95, "Washers", 709, true)
        ];
        var viewModel = new ViewModel(initialData);

        // 应用绑定
        $(function () {
            ko.applyBindings(viewModel);
        });

    </script>

</head>
<body>
    // 将SpreadJS绑定到html元素以使用Knockout。
    <div id="ss" data-bind="gc-spread-sheets: {
                            sheetCount: 1,
                            tabStripVisible: true,
                            sheets: [
                                {
                                    data: items,
                                    columns: [
                                        { displayName: 'ID', name: 'id', size: 80},
                                        { displayName: 'Name', name: 'name', size: 120},
                                        { displayName: 'Price', name: 'price', size: 80},
                                        { displayName: 'Discontinued', name: 'discontinued', size: 120}
                                    ]
                                }
                            ]

                        }" style="width:50%; height:200px;border: 1px solid gray;">
    </div>
</body>
</html>
```
