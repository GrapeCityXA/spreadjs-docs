# angular-cli

SpreadJS 支持在 Angular CLI 开发环境中一起使用单独的模块和插件。

### 使用模块与插件

包含以下步骤:

1. **全局安装 Angular CLI**
    打开命令提示符窗口并键入以下命令。

    ```shell
    npm install -g @angular/cli
    ```
2. **使用 Angular CLI 创建一个新项目**
    使用以下命令创建一个新项目并导航到项目目录：

    ```shell
    ng new my-app
    cd my-app
    ```
3. **在项目中安装SpreadJS模块和插件**
    使用以下命令安装 SpreadJS NPM 模块和插件：

    ```shell
    npm install @grapecity-software/spread-common @grapecity-software/spread-calc-engine @grapecity-software/spread-sheets-core @grapecity-software/spread-sheets-calc-engine @grapecity-software/spread-sheets-print @grapecity-software/spread-sheets-angular
    ```

5. **在 Angular 应用程序中使用 SpreadJS**
    修改app.module.ts以导入模块，如下所示：

    ```typescript
    import { NgModule } from '@angular/core';
    import { BrowserModule } from '@angular/platform-browser';
    import { AppComponent } from './app.component';
    import { SpreadSheetsModule } from '@grapecity-software/spread-sheets-angular';
    @NgModule({  
        declarations: [   
             AppComponent  
    ],  
    imports: [    
        BrowserModule,    
        SpreadSheetsModule  
    ],  
    providers: [],  b
    ootstrap: [AppComponent]})
    export class AppModule { }
    ```

    修改app.component.html以查看SpreadJS组件，如下所示：

    ```html
    <gc-spread-sheets [hostStyle]="hostStyle" 
    (workbookInitialized)="initSpread($event)">
    </gc-spread-sheets>
    ```

    修改app.component.ts为SpreadJS组件准备数据，如下所示：

    ```typescript
    import { Component } from '@angular/core';i
    mport * as GC from "@grapecity-software/spread-common";
    import "@grapecity-software/spread-calc-engine";
    import "@grapecity-software/spread-sheets-core";
    import "@grapecity-software/spread-sheets-calc-engine";
    import "@grapecity-software/spread-sheets-print"; 
    @Component({  
        selector: 'app-root',  
        templateUrl: './app.component.html',  
        styleUrls: ['./app.component.css']
    })
    export class AppComponent { 
        hostStyle = {    
            width: '100%',    
            height: '600px',    
            overflow: 'hidden',    
            float: 'left'  
    };  
            initSpread($event: any) {    
                let spread: GC.Spread.Sheets.Workbook = $event.spread;    
                let sheet = spread.getActiveSheet();    
                sheet.setValue(0, 0, "Hello SpreadJS");    
                spread.print();  
        }
    }
    ```

6. **使用 Angular CLI 构建并运行项目**
    使用以下命令构建并运行项目：

    ```shell
    npm start
    ```
