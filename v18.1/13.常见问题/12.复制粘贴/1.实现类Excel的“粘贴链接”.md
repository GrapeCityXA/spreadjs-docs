# HowToAchieveExcelLikePasteLinks

### 需求：如何像Excel一样实现一个粘贴链接功能

***

#### 背景：

“粘贴链接”是Excel提供的剪切板粘贴的一个特色功能，会把复制区域的单元格的地址引用粘贴到目标单元格。
举例，在A1单元格使用Ctrl+C进行复制，然后在A5单元格右键点击，选择“粘贴链接”图标，效果如下

可以看到A5被设置了一个公式，引用A1单元格的绝对地址。

#### 实现方式：

目前SpreadJS暂不支持此功能，但是我们可以通过自定义命令来实现这个功能。
首先我们需要修改原生的复制操作：

```javascript
let contextcopycommand =
    GC.Spread.Sheets.Designer.getCommand("contextMenuCopy");// 把右键复制指令拿出来
let oldExecute = contextcopycommand.execute;// 将执行参数拿出来
contextcopycommand.execute = function (context, propertyName, args) {// 重写复制指令
    oldExecute.call(this, context, propertyName, args);
    let range = context.Spread.getActiveSheet().getSelections()[0];// 选中的单元格
    let formulastr = "";
    formulastr = GC.Spread.Sheets.CalcEngine.rangeToFormula(range);// 将单元格位置转换成公式常用的A1的形式
    context.setData("copyLink", formulastr);//设置全局键值对
    console.log("我是contextMenuCopy");
};

let copycommand = GC.Spread.Sheets.Designer.getCommand("copy");
oldcopyExecute = copycommand.execute;
copycommand.execute = function (context, propertyName, args) {
    oldcopyExecute.call(this, context, propertyName, args);
    let range = context.Spread.getActiveSheet().getSelections()[0];
    let formulastr = "";
    formulastr = GC.Spread.Sheets.CalcEngine.rangeToFormula(range);
    context.setData("copyLink", formulastr);
    console.log("我是copy指令");
};
```

接着在执行粘贴按钮的时候将全局键值对中对应的值拿出来

```
config.commandMap = {
    pasteLink: {
        text: "粘贴链接",
        group: "contextMenuPaste",
        iconClass: "gc-spread-pasteAll",
        commandName: "pasteLink",
        execute: async (context) => {
            setTimeout(() => {
                if (context.getData("copyLink")) {
                    let sheet = context.Spread.getActiveSheet();
                    var referenceCellRange = GC.Spread.Sheets.CalcEngine.formulaToRange(
                        sheet,
                        context.getData("copyLink")// 把全局键值对中对应的参数拿出来即可
                    );
                    console.log(referenceCellRange);
                    var isRelative =
                        referenceCellRange.rowCount == 1 &&
                            referenceCellRange.colCount == 1
                            ? GC.Spread.Sheets.CalcEngine.RangeReferenceRelative.allRelative
                            : GC.Spread.Sheets.CalcEngine.RangeReferenceRelative
                                .allAbsolute;
                    for (var r = 0; r < referenceCellRange.rowCount; r++) {
                        for (var c = 0; c < referenceCellRange.colCount; c++) {
                            var formulastr = GC.Spread.Sheets.CalcEngine.rangeToFormula(
                                sheet.getRange(
                                    referenceCellRange.row + r,
                                    referenceCellRange.col + c
                                ),
                                null,
                                null,
                                isRelative
                            );
                            sheet.setFormula(
                                sheet.getActiveRowIndex() + r,
                                sheet.getActiveColumnIndex() + c,
                                formulastr
                            );
                        }
                    }
                }
            }, 0);
        },
    },
};
```
