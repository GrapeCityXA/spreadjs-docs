# collapse-toolbar

### 问题：如何在使用Designer时令顶部工具栏不可见？

关于这个需求，SpreadJS提供了两种设置方案，通过工具栏折叠按钮隐藏工具栏，或者在Designer的DefaultConfig对象中清除工具栏数据以永久性删除工具栏。请阅读下文了解上述两种方案详情。

***

**背景：**
在某些场景下，工具栏的展开会影响表单区域的显示，所以需要折叠工具栏。
熟悉Excel操作的用户很容易了解到，点击工具栏右下角的向上三角符号，即可实现折叠。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.d5a0c7.png)
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.734093.png)
那么在初始化designer的时候可以默认折叠工具栏吗？答案是可以的，下面将介绍实现思路。

**思路：**
工具栏的折叠状态是由"isRibbonCollapse"这个字段控制的，我们可以通过getData方法获取到当前的折叠状态。

```javascript
var designer = GC.Spread.Sheets.Designer.findControl(document.getElementById("gc-designer-container"));
designer.getData("isRibbonCollapse");
```

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.a48051.png)
如果想修改为折叠，那可以通过setData方法传参true。

```javascript
designer.setData("isRibbonCollapse",true);
```

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.b89c80.png)
需要注意的是，这里的折叠并不是真正的“隐藏”。在折叠状态下，点击工具栏某个tab时会自动展开，这一设计也是与Excel一样的。

**补充：**
如果说想实现真正的“隐藏”，建议直接使用spreadJS就好，不需要引入deisgner组件。
当然也有用户会问，如果我既不想显示工具栏，又想使用designer具有的一些功能（如右键菜单），应该怎么做？
可以重设Designer的配置DefaultConfig对象，将其中的ribbon属性值设置为空数组，ribbon属性值保存了工具栏中的各项数据。
之后，将重置ribbon后的DefaultConfig对象重设给Designer即可看到顶部工具栏已消失。

```javascript
var designer = GC.Spread.Sheets.Designer.findControl(document.getElementById('gc-designer-container'));
var config = GC.Spread.Sheets.Designer.DefaultConfig;
config.ribbon = [];
designer.setConfig(config);
```
