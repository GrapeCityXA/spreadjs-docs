# ScrollingLoadOfData

### 问题：SpreadJS如何动态加载数据

***

#### 背景

假如现在有10000条数据，每次加载1000条数据，当鼠标滚动到900行的时候，需要分页请求服务器返回第二页的1000条数据回来，那么，此时应该用什么方法可以不覆盖之前的1000条数据，继续在EXCEL中绑定第二页数据？加载方法时用了表单绑定的方式，返回的第二页数据绑定方式能沿用表单的绑定。

#### 实现思路

解决该需求的方法关键在于咱们数据绑定的底层机制，当数据源发生变化时，数据绑定的结果也会发生变化，因此我们只要对数据源进行修改即可

##### 1\. 获取当前1000行数据

```javascript
var rowcount = sheet.getRowCount();
sheet.addRows(rowcount, 1000);
var datasource = sheet.getDataSource();
```

##### 2\. 监听事件并为数据增加10000行

```javascript
for (var i = 0; i < 10000; i++) {
    datasource[i + rowcount] = newdata[i];
}
```

这个时候有小伙伴问了，增加数据为啥不用push方法批量添加呢，for循环添加不是损耗性能吗？
这个就主要是因为我们 SpreadJS 对于数据绑定的设定就是双向绑定的，即`setDataSource`后，修改源数据，sheet页会发生变化， 修改sheet页，源数据会发生变化。
