# hide-ascending-descending-order-option

### 问题：如何隐藏表格筛选中的升序降序选项？

#### 背景：

点击表格（table）筛选按钮时，你会在打开的筛选框中看到 升序降序选项。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.f3b8c9.png)
如果想将升序降序选项隐藏，应该如何实现呢？

#### 实现方式：

首先获取table的筛选，在filer中有一个filterDialogVisibleInfo方法，可以用来<span style="color: rgb(58, 70, 82); font-family: 'Microsoft Yahei', 'PingFang SC', Verdana, Simsun, 'Segoe UI', Tahoma, Arial, sans-serif; font-size: 16px; font-style: normal; font-variant-ligatures: normal; font-variant-caps: normal; font-weight: 400; letter-spacing: normal; orphans: 2; text-align: start; text-indent: 0px; text-transform: none; widows: 2; word-spacing: 0px; -webkit-text-stroke-width: 0px; white-space: normal; background-color: rgb(255, 255, 255); text-decoration-thickness: initial; text-decoration-style: initial; text-decoration-color: initial; display: inline !important; float: none;">获取或设置行筛选的可见信息。</span>
所以可以根据实际需求将sortByValue属性设置为false。
下为示例代码：

```javascript
var filter = sheet.tables.all()[0].rowFilter();
filter.filterDialogVisibleInfo({
  sortByValue: false, //SortByValue item is visible.
});
```
