# Set-Table-Style-Transparent

### 需求：SpreadJS如何设置表格table样式为透明

***

#### 背景：

在组件版表格编辑器中，表格table样式可通过UI按钮设置为透明，如下图所示：
![102113ksk1v1r95mk5r811](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/102113ksk1v1r95mk5r811.6dd1ac.png)
那么如果想使用SpreadJS通过代码实现同样效果，应该如何设置呢？
如下代码示例：

```javascript
var table = sheet.tables.add('table1', 0, 0, 4, 4);
table.style(undefined)；
sheet.repaint()
```
