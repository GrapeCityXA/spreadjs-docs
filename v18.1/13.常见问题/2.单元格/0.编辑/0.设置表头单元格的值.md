# set-header-cell-value

### 问题：如何设置表头单元格的值

#### 背景：

在默认情况下，我们是无法对列头的值进行修改的，但是通过一些操作可以弹出一个输入框来实现允许编辑的操作。

#### 解决方案：

在如下的Demo中，我们设置了第二列的值可以修改，具体的表现为点击了第二列的列头，列头就会弹出一个输入框，输入任意值后再点击任意位置就可以将值应用上去。
完整代码如下，供参考：

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Demo</title>
    <link href="http://cdn.grapecity.com/spreadjs/hosted/css/gc.spread.sheets.excel2013white.16.1.4.css"
        rel="stylesheet" type="text/css" />
    <script type="text/javascript" src="http://ajax.googleapis.com/ajax/libs/jquery/1.8.0/jquery.min.js"></script>
    <script type="text/javascript"
        src="http://cdn.grapecity.com/spreadjs/hosted/scripts/gc.spread.sheets.all.16.1.4.min.js"></script>
    <script type="text/javascript"
        src="http://cdn.grapecity.com/spreadjs/hosted/scripts/resources/zh/gc.spread.sheets.resources.zh.16.1.4.min.js"></script>
</head>

<body>
    <div id="ss" style="width: 98vw; height: 95vh;"></div>
    <input id="edit" type="text" style="display:none;position: absolute;" />
    <script>
        $(document).ready(function () {
            let spread = new GC.Spread.Sheets.Workbook(document.getElementById("ss"), { sheetCount: 3 });
            let sheet = spread.getActiveSheet();
            let target;
            $("#ss").click(function (e) {
                let offset = $("#ss").offset();
                let x = e.pageX - offset.left;
                let y = e.pageY - offset.top;
                target = spread.hitTest(x, y);
                if (target?.worksheetHitInfo) {
                    if (target.worksheetHitInfo.hitTestType === 1 && target.worksheetHitInfo.col == 1) {
                        $("#edit").css({ left: e.pageX, top: e.pageY });
                        $("#edit").show();
                        spread.focus(false);
                        $("#edit").focus();
                    } else {
                        $("#edit").val("");
                        $("#edit").hide();
                    }
                }
            });

            $("#edit").blur(function () {
                let value = $("#edit").val();
                let col = target.worksheetHitInfo.col;
                let row = target.worksheetHitInfo.row;
                sheet.setValue(row, col, value, target.worksheetHitInfo.hitTestType);
                $("#edit").hide();
            });
        });
    </script>

</body>

</html>
```
