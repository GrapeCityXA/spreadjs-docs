# automatically-merge-cells-to-export-to-Excel

### 问题：自动合并后的单元格导出excel后合并单元格消失的问题？

***

#### 背景：

SpreadJS有一个特别好用的功能，相邻区域中如果内容一样，将自动合并。有客户发现，在SpreadJS中，确实合并了。但是导出Excel后，发现合并失效，那么如何做才能再导出Excel后合并单元格不消失呢？

#### 方案：

UI上可以勾选这个选项
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.e24682.png)
代码上可以添加这个[导出选项](https://demo.grapecity.com.cn/spreadjs/help/api/modules/GC.Spread.Sheets#exportoptions)，includeAutoMergedCells设置为true
完整代码是：

```
   $("#exportExcel").click(function () {
            const fileName = 'exportExcel.xlsx';
            spread.export(function (blob) {
                saveAs(blob, fileName);
            }, e => {
                console.log('失败', e.errorMessage);
            }, {
                includeBindingSource: true, 
                saveAsView: true,
                includeAutoMergedCells: true,
                fileType: GC.Spread.Sheets.FileType.excel,
            });
        });
```
