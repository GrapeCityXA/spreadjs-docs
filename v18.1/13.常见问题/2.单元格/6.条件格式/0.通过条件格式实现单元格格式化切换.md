# checkbox-conditional-format-change

### 问题：通过条件格式实现单元格格式化切换

***

#### 背景：

对于部分内容，用户需要切换checkbox来实现单元格格式化的切换，例如对于部分数据，在特定场景下，希望切换到百分比格式，用百分比的形式展现。

#### 解决方案：

本文会从UI及代码层面讲解该需求的实现方式。
（1）UI层面
添加复选框，控制是否切换格式。在SpreadJS在线表格设计器中选择开始-单元格类型-复选框，给当前sheet页添加复选按钮。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.cd6eeb.png)
选中之后，在弹出的界面中，添加如下信息：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.771d7b.png)
如上所示，选定状态文字不填写时，默认会以布尔值对复选框单元格的值做标记，标替用于提示复选框选中时的作用。操作完成之后，复选框的设置就已经完成了。接下来，需要对目标数据添加条件格式。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.83d4d5.png)
通过上边的几步操作之后，就已经实现切换格式的需求了。这里，格式化可以根据自己的需求去做调整，也可以采用自定义格式化内容。

（2） 代码实现
代码实现与UI实现原理相同，我们需要使用的核心API为添加[复选框](https://demo.grapecity.com.cn/spreadjs/SpreadJSTutorial/features/cells/cell-types/checkbox/purejs)和[条件格式](https://demo.grapecity.com.cn/spreadjs/SpreadJSTutorial/features/cells/conditional-format/conditional-rules/purejs)相关的。使用如下代码，即可实现与UI层面相同的效果。

```js
let textAlignCellType = new GC.Spread.Sheets.CellTypes.CheckBox();
textAlignCellType.isThreeState(false);
textAlignCellType.caption("百分比展示");
textAlignCellType.textAlign(GC.Spread.Sheets.CellTypes.CheckBoxTextAlign.right);
sheet.setCellType(4, 5, textAlignCellType);
let style = new GC.Spread.Sheets.Style();
style.formatter = "0.00%";
sheet.conditionalFormats.addFormulaRule("=Sheet2!$F$5=TRUE", style, [
  new GC.Spread.Sheets.Range(5, 0, 10, 6),
]);
```

参考学习指南和api文档，可以很容易理解上边的代码，这样设置完成后，即可以实现对特定区域应用格式切换。
