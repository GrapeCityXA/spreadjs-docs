# modify-dropdown-style

### 问题：如何修改单元格下拉菜单列表的样式

***

#### **背景：**

如下图，为单元格下拉菜单默认样式：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.98a01a.png)
需求希望修改下拉框的相关样式

#### **解决方案：**

SpreadJS 未提供修改下拉框样式的相关接口，不过可以通过修改css样式来实现。
1、修改下拉列表背景色

```css
.gc-list-control {
    background-color: yellow !important;
}
```

2、修改下拉项hover背景色

```css
.gc-list-control-item:hover {
    background: pink !important;
}
```

3、设置下拉列表滚动条

```css
.gc-list-control {
    max-height: 300px;
    overflow: scroll;
}
```
