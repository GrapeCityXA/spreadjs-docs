# delete-file-menu-item-2

### 问题：如何删除文件菜单项

***

#### 背景：

有用户在使用设计器时，在文件模板中可能有一些不需要的项，因此需要做删除。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.66ba7c.png?width=900)

#### 实现步骤：

此处文件按钮本质上是一个Template，可以通过下面的代码对这个模板结构进行分析来层层找到要删除部分：
`GC.Spread.Sheets.Designer.getTemplate(GC.Spread.Sheets.Designer.TemplateNames.FileMenuPanelTemplate);`

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.7fbdad.png?width=900)
这里以“新建”这部分为例，通过下面的代码将这部分内容及其children删除。

```javascript
var fileMenuPanelTemplate = GC.Spread.Sheets.Designer.getTemplate(
  GC.Spread.Sheets.Designer.TemplateNames.FileMenuPanelTemplate
);
fileMenuPanelTemplate.content[0].children[0].children[0].children[0].children[1].items.splice(
  0,
  1
);
fileMenuPanelTemplate.content[0].children[0].children[1].children.splice(0, 1);
```

删除后，使用registerTemplate注册回去。

```javascript
GC.Spread.Sheets.Designer.registerTemplate(
  GC.Spread.Sheets.Designer.TemplateNames.FileMenuPanelTemplate,
  fileMenuPanelTemplate
);
```

点击"文件"发现"新建"已经删除了，但是右侧是一片空白，接下来处理这个空白。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.d13592.png?width=900)

将这句代码通过控制台打印检查一下，可以发现这里的`activeCategory_main`指的还是被删除的”新建“。
`console.log(GC.Spread.Sheets.Designer.getCommand('fileMenuPanel').getState(designer))`

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.746b8d.png?width=900)

那么可以把这个new字段给到删除之后的第一个item，实现默认显示内容，也就是下面两句代码。

```javascript
fileMenuPanelTemplate.content[0].children[0].children[0].children[0].children[1].items[0].value =
  "New";
fileMenuPanelTemplate.content[0].children[0].children[1].children[0].visibleWhen =
  "activeCategory_main=New";
```
