# relative-reference-absolute-reference

### 问题：如何实现相对引用和绝对引用的相互转换？

***

背景：Excel中<span style="color: rgb(64, 64, 64); font-family: -apple-system, BlinkMacSystemFont, 'Apple Color Emoji', 'Segoe UI Emoji', 'Segoe UI Symbol', 'Segoe UI', 'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', 'Helvetica Neue', Helvetica, Arial, sans-serif; font-size: 16px; font-style: normal; font-variant-ligatures: normal; font-variant-caps: normal; font-weight: 400; letter-spacing: normal; orphans: 2; text-align: start; text-indent: 0px; text-transform: none; widows: 2; word-spacing: 0px; -webkit-text-stroke-width: 0px; white-space: normal; background-color: rgb(255, 255, 255); text-decoration-thickness: initial; text-decoration-style: initial; text-decoration-color: initial; display: inline !important; float: none;">单元格引用包含3种方式，分别为：相对引用、绝对引用和混合引用。</span>那么在SpreadJS中，如何通过代码方式进行相对引用和绝对引用的转换。
我们首先给单元格设置引用其他单元格的公式，代码如下：

```js
sheet = spread.getSheet(0);
// 设值
sheet.setValue(0, 0, 1, 3);
sheet.setValue(1, 0, 50, 3);
sheet.setValue(2, 0, 100, 3);
sheet.setValue(3, 0, 2, 3);
sheet.setValue(4, 0, 60, 3);
sheet.setValue(5, 0, 90, 3);
sheet.clearSelection();
// 添加selection
sheet.addSelection(2, 0, 3, 1);
var range = sheet.getSelections();
// 获取range字符串
var rangeStr = GC.Spread.Sheets.CalcEngine.rangeToFormula(
  range[0],
  0,
  0,
  GC.Spread.Sheets.CalcEngine.RangeReferenceRelative.allRelative
);
// 使用选定区域创建公式
var formula = "Sum(" + rangeStr + ")";
// 在表单的单元格中设置公式
sheet.setFormula(5, 5, formula, GC.Spread.Sheets.SheetArea.viewport);
```

在界面中查看效果：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.0da043.png)

接下来我们用rangesToFormula()将相对引用区域转换为绝对引用区。

```js
//获取原公式
let formula2 = sheet.getFormula(5, 5);
//获取原表达式
let expression1 = GC.Spread.Sheets.CalcEngine.formulaToExpression(
  sheet,
  formula2,
  0,
  0
);
//将原区域相对引用转换为绝对引用
let rangesStr = GC.Spread.Sheets.CalcEngine.rangesToFormula(
  range,
  0,
  0,
  GC.Spread.Sheets.CalcEngine.RangeReferenceRelative.allAbsolute
);
console.log(rangesStr);
// 将原表达式函数和转换后的区域拼接为新的公式
let formula = expression1.functionName + "(" + rangesStr + ")";
// 在表单的单元格中设置公式
sheet.setFormula(5, 5, formula, GC.Spread.Sheets.SheetArea.viewport);
```

这样就可以实现相对引用和绝对引用的转换了。
