# set-formula-times

### 问题：如何设置某列为某两列的乘积？

***

背景：用户想对某一列设置公式，公式为其他两列的乘积，如果一个一个去设置公式，太麻烦了。那么是否有简单做法呢？答案是有的，还不止一种方案。下面将分别介绍。
首先为A列和B列创建数值，如下图所示：设置了A列，B列的数值，对C列设置公式，其值为A列和B列的乘积。
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.86bb7f.png)
一、数组公式
数组公式的介绍可以参考该[链接](https://demo.grapecity.com.cn/spreadjs/SpreadJSTutorial/features/calculation/array-formulas/basic-array-formula/purejs)。

```javascript
sheet.setArrayFormula(0,2,13,1,'=A1:A13*B1:B13')
```

二、共享公式
在v16版本，SpreadJS推出了共享公式，其目的是解决具备相同表示表达式的公式重复设置的问题。其用法是
![download](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/5fefd5d8-238b-4c13-893b-6f22fcc5b9dd/download.4904bb.png)
所以，针对本文的需求，可以使用如下代码来实现

```javascript
sheet.getRange(0,2,13,1).formula('=A1*B1',true)
```
