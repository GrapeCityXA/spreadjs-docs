# differentiated-export

### 问题：用户表格在展示的时候需要将表格的内容完全展示，但是导出Excel的时候删除某行或者某列

***

#### 实现思路

我们在初始化的时候可以创建两个workbook，一个用于数据展示，一个用于导出Excel。
将展示的workbook1通过toJSON转为ssjson，再通过formJSON导入到workbook2。
这时候需要的操作（删除行列等）都在workbook2中进行。Excel也是将workboo2导出。
代码如下实现：

```html
<div id="ss" class="sample-spreadsheets"></div>
<div id="ss1" class="sample-spreadsheets" style="display: none;"></div>
```

然后，我们将workbook1的数据toJSON，并在workbook2 fromJSON

```javascript
spread.fromJSON(jsonData);
var str = spread.toJSON()
spread1.fromJSON(str);
```

此时，我们需要删除最后两列导出，只需在workbook2中操作，这部分用户是无感知的

```javascript
var sheet = spread1.getActiveSheet();
sheet.deleteColumns(6,2);
```
