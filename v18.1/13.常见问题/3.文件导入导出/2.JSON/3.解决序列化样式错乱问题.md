# copy-style-error-cross-workbook

### 问题：如何解决将spreadA中的sheet复制到spreadB中，出现样式混乱的问题

***

#### 背景

用户将spreadA中的sheet添加到spreadB中，出现了样式混乱问题，如图所示：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.b0351b.png)
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.abab13.png)

#### 解决方案：

出现上述情况的原因是用户在通过toJSON导出该sheet页时并未携带这些样式的名称，所以导入到spreadB后，spreadB找不到对应name的样式，所以出现了样式混乱，具体原理可以参考[这个](https://www.grapecity.com.cn/blogs/sjs-single-sheet-loading)
因此解决方式就是将命名样式注册到全局能让spreadB能够拿到即可，如下所示：

```js
function openExcel(e){
    let File = document.getElementById('fileField').files[0];
    let excelIo = new GC.Spread.Excel.IO();
    excelIo.open(File, (json) => {
        spreadA.suspendPaint();
        spreadA.fromJSON(json);
        spreadA.resumePaint();
        spreadA.removeSheet(0);
    })
}

function addSheetB(e){
    var sheetJson = JSON.stringify(spreadA.getSheet(0).toJSON());

    spreadB.suspendPaint();
    spreadA.getNamedStyles().forEach(function (namedStyle) {
        spreadB.addNamedStyle(namedStyle);
    })
    spreadB.getSheet(0).fromJSON(JSON.parse(sheetJson));
    spreadB.resumePaint();
}
```
