# how-to-get-all-tag

### 问题：怎么获取设置的所有单元格Tag？

***

#### 背景

需要获取所有单元格中的Tag信息。

#### 解决方案

目前没有接口可以直接获取sheet中所有已经设置的Tag，原因是Tag信息本身就是存储在单元格中的。并不是作为数组存储在sheet中

可以通过下面的两种方式获取所有Tag

**1.通过遍历单元格获取**

```js
for(var i=0;i<sheet.getRowCount;i++){
   for(var j=0;j<sheet.getColumnCount;j++){
           sheet.getRange(i,j)
  }
}
```

**2.通过循环查询当前sheet中的单元格获取**
worksheet的search方法支持tag查询，将**searchTarget**设置为**cellTag**即可
具体的循环查找的步骤可以参考[学习指南](https://demo.grapecity.com.cn/spreadjs/SpreadJSTutorial/features/workbook/search/purejs)
在学习指南代码的基础上，仅需要额外设置

```js
searchCondition.searchTarget = GC.Spread.Sheets.Search.SearchFoundFlags.cellTag;
```
