# culture

### 问题：右键菜单如何汉化

#### 背景：

初始化SpreadJS或designer的时候，发现右键菜单是英文的，这不符合中文阅读习惯。

#### 解决方案：

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.7734bc.png)

SpreadJS本身支持本地化功能，通过加载相应的资源文件 gc.spread.sheets.resources.xx.x.x.x.min.js。可以实现不同语言的本地化。
进行汉化则需引入相应的中文资源文件，通过下面的方法可以实现对SpreadJS 或 在线表格编辑器 进行汉化。

##### 对于SpreadJS：

当前，首先需要添加相应的中文资源文件，例如：

```html
<script src="xxx/scripts/resources/zh/gc.spread.sheets.resources.zh.xx.x.x.min.js" type="text/javascript"></script>
```

然后，可以选择其中一种方式来切换资源文件：
（1）设置本地化 meta 标签：

```html
<head>
   ...
   <meta name="spreadjs culture" content="zh-cn" />
   ...
</head>
```

（2）通过调用 GC.Spread.Common.CultureManager.culture 方法来设置本地化

```html
GC.Spread.Common.CultureManager.culture("zh-cn");
```

运行后效果如下：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.478c32.png)

##### 对于在线表格编辑器

如果您使用的是在线表格编辑器，由于在线表格编辑器有着自己独特的右键菜单（与SpreadJS右键菜单选项不同），需要引入下面这个js文件：

```html
<script src="xxx/scripts/gc.spread.sheets.designer.resource.cn.xx.x.x.min.js" type="text/javascript"></script>
```

这是因为designer也需要引入自己的语言文件，以满足不同文化场景下的需求。
此时designer的汉化就已经完成了，如下图所示：

![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.e23c25.png)

##### <span style="color: #ff0000">注意：</span>

在线表格编辑器中，在引入gc.spread.sheets.designer.resource.cn.xx.x.x.min.js的同时，还需要引入gc.spread.sheets.resources.xx.x.x.x.min.js

```html
<script src="xxx/scripts/gc.spread.sheets.designer.resource.cn.xx.x.x.min.js" type="text/javascript"></script>
<script src="xxx/scripts/resources/zh/gc.spread.sheets.resources.zh.xx.x.x.min.js" type="text/javascript"></script>
```

如果缺少gc.spread.sheets.resources.zh.xx.x.x.min.js的引用，会导致部分功能没有完全被汉化。例如下图所示：
![image](/DOCUMENT_SITE_LINK_PREFIX_HERE/document-site-files/images/b33c4f64-6b99-4132-a675-8dc7b59765f1/image.f200e2.png)

##### 总结

虽然是介绍的右键菜单，但实质上右键菜单的本地化（汉化）只是本地化（汉化）的其中一个部分。
除了右键菜单外，工具栏、弹窗、筛选框等等功能，都会用到本地化资源。
所以，在后续的使用中如果遇到类似问题，可以参考这篇文章的介绍。
